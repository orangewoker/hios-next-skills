## 1. 产品毛绒化的核心思路

产品毛绒化不是给产品P一层毛，而是把产品重新雕塑为毛绒玩具——保留产品核心辨识点（形状、logo、标志性细节），把材质替换为绒毛，把比例调整为Q版卡通化。

关键判断：产品的哪个特征最值得被毛绒化放大？
- 形状有辨识力的（如润唇膏、水杯、食品包装）→ 形状毛绒化，轮廓圆润化
- 触感是卖点的（如毛巾、枕芯、毛毯）→ 触感双重强化，毛绒材质本身就是触感的视觉化
- IP联名的（如品牌吉祥物）→ IP角色毛绒化，产品作为道具

## 2. 按品类的产品角色

### 美妆个护
- 产品角色：触感放大器——毛绒材质把"涂抹在皮肤上的感觉"提前可视化
- 毛绒类型：短绒丝绒感，配色忠于产品包装色
- 常见卖点钩子：柔软、贴肤、治愈
- 合规：不暗示护肤功效，毛绒化仅为视觉风格

### 食品饮料
- 产品角色：可爱化身——把食品变成毛绒角色，增加情绪价值
- 毛绒类型：中绒蓬松感，配色忠于食品本色
- 常见卖点钩子：治愈、陪伴、解压
- 合规：注明"毛绒化风格展示，非实物食品"

### 服装/家纺
- 产品角色：触感证据——毛绒材质本身就是产品触感的视觉证明
- 毛绒类型：长绒蓬松感或圈绒羊羔绒感
- 常见卖点钩子：柔软、保暖、包裹感

### 消费电子
- 产品角色：反差萌——冰冷的电子产品变成柔软毛绒，制造反差记忆点
- 毛绒类型：中绒饱满感，保留产品的几何轮廓
- 常见卖点钩子：亲和力、随身陪伴

### 潮玩/IP周边
- 产品角色：角色本身——产品就是毛绒角色
- 毛绒类型：按IP原设定选择
- 常见卖点钩子：收藏、陪伴、限量

## 3. 毛绒类型选择指南

| 类型 | 质感关键词 | 适用场景 |
|---|---|---|
| 短绒 | 丝绒、缎面绒、密实、微珠光 | 美妆个护、精致小物 |
| 中绒 | 经典毛绒玩具、蓬松、柔软 | 玩具、潮玩、IP角色 |
| 长绒 | 拖把感、飘逸、蓬松到炸 | 家纺、冬装、暖冬营销 |
| 圈绒 | 羊羔绒、卷曲、颗粒感 | 服装、宠物用品、秋冬 |

## 4. 配色策略

- **原色还原**：忠于产品/对象原本配色，毛绒化只改变材质不改色。适用于电商主图。
- **品牌色融入**：在毛绒化的同时把品牌色作为主色调或背景色。适用于品牌联名、TVC。
- **暖色治愈**：整体偏暖（奶白、蜜桃、薄荷绿、薰衣草），强化Q版可爱感。适用于种草图、社媒。

## 5. 电商主图 vs 种草图 vs TVC

| 用途 | 画幅 | 光照 | 背景 | 构图 |
|---|---|---|---|---|
| 电商主图 | 1:1或3:4 | 柔光均匀，无明显方向 | 纯色或渐变底，干净 | 产品居中，留白充足 |
| 种草图 | 3:4或9:16 | 侧逆光，暖调氛围 | 场景化（床边、桌面、窗台） | 产品偏一侧，生活方式感 |
| TVC | 16:9或9:16 | 影视级布光，有光比 | 毛绒化场景，景深虚化 | 动态构图，beat推进 |

## 6. prompt 句式库

### 电商主图（短绒·美妆个护）
```
Q版卡通毛绒风格产品主图，@图片1所示的润唇膏被重新雕塑为毛绒玩具形态，保留管状轮廓和品牌色彩，表面覆盖短绒丝绒材质，密实微珠光，圆润可爱比例，柔和均匀正面光照，纯奶白色渐变背景，产品居中，大面积留白，治愈温暖氛围，1:1画幅
```

### 种草图（中绒·潮玩IP）
```
Q版卡通毛绒风格场景图，@图片1所示的IP角色变成蓬松中绒毛绒玩具，坐在毛绒化的窗台上，侧逆暖光从右侧照入，绒毛边缘有金色轮廓光，背景是毛绒化的窗帘和花朵虚化，薄荷绿主色调配奶白点缀，生活化治愈氛围，3:4画幅
```

### TVC食品毛绒化（长绒）
```
Q版卡通毛绒风格，@图片1所示的饼干盒变成圆滚滚的长绒毛绒角色，炸毛蓬松，从画面左侧蹦跳入场，落地后弹了两下，表面绒毛随弹跳波动，暖黄色厨房毛绒化场景，柔和侧光，毛绒道具散落，治愈活泼氛围
```

## 7. 落 prompt 前自检

- 产品核心辨识点是否保留（形状、logo、配色）？
- 毛绒类型是否匹配品类（美妆短绒、玩具中绒、家纺长绒）？
- Q版比例是否到位？
- 配色是否忠于产品或品牌？
- 光照是否匹配用途（电商柔光/种草氛围光/TVC影视光）？
- 电商主图是否留白充足、背景干净？
- 参考图是否正确引用？
- 食品毛绒化是否注明非实物？
