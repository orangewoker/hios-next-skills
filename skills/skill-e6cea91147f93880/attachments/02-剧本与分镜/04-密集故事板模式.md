# 密集故事板模式

## 何时使用

- 需要把大量剧本镜头快速生成预览。
- 每个镜头不需要最高保真，而是验证节奏和构图。
- 先生成分镜图，再挑选关键镜头升级为最终视频。

## 密集模式流程

1. 按场景分组镜头。
2. 每个镜头只保留：主体、动作、景别、光、情绪。
3. 先生成静态分镜图（如用图片模型），验证构图与连续性。
4. 把通过的分镜图作为 I2V 首帧，生成短视频预览。
5. 挑选可用镜头后，再用完整提示词精修。

## 密集模式提示词模板

```text
[主体] + [核心动作] + [景别/角度] + [单一直观光源] + [情绪色调]
约束：保持 [关键道具/服装] 不变；不出现 [禁止元素]。
```

## 密集模式 vs 精修模式

| | 密集模式 | 精修模式 |
|---|---|---|
| 目的 | 快速验证 | 最终输出 |
| 每个镜头信息 | 精简 | 完整 |
| 运动 | 单一 | 精确控制 |
| 声音 | 可省略 | 明确写入 |
| 连续性 | 标注关键锁 | 完整交接 |
