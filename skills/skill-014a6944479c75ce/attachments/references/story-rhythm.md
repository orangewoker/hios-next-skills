## 场景的因果核心

先写场景状态变化：

`进入状态 → 角色目标/策略 → 阻力升级 → 关键选择或揭示 → 离开状态`

至少改变一项：关系、知识、权力、承诺、风险、位置或可用选择。只提供背景信息而不改变状态的场景，合并、压缩或重新赋予冲突。

用五个变量检查：

| 变量 | 问题 |
|---|---|
| Objective | 谁现在想要什么可观察结果？ |
| Obstacle | 什么主动阻止他？ |
| Stakes | 现在失败会失去什么？ |
| Tactic | 角色如何改变策略？ |
| Turn | 哪一刻让后半场不再能按前半场方式继续？ |

## Beat 拆分法

beat 不是一句台词、一个镜头或固定秒数。只在以下任一变化时划分：

- 角色改变策略
- 新信息改变判断
- 权力或亲密距离重排
- 风险进入新等级
- 观众问题被回答或替换
- 行动跨过不可逆点

为每个 beat 写七列：

`编号｜角色目标｜策略｜阻力｜观众所知｜压力 1–5｜结束变化`

没有结束变化的 beat 通常只是重复。重复可以用于喜剧升级、仪式感或压迫，但每次重复必须改变幅度、语境或预期。

## 张力与信息（tension and information）

把 suspense、surprise、mystery 区分开：

- **悬念**：观众知道威胁或期限，等待角色遭遇。
- **惊讶**：观众与角色几乎同时获得突发信息。
- **谜团**：观众知道有缺口，主动寻找解释。

先决定观众相对角色的信息位置，再决定 POV、遮挡、插入和反应镜头。

张力不是持续升高的音量。组合以下手段：

- 缩短可用时间或空间
- 增加失败代价
- 让策略失效并迫使换招
- 延迟一个已被承诺的答案
- 给出部分答案，制造更大的问题
- 让角色行动与真实意图产生反差
- 在高潮前留出安静的确认或犹豫

## 建立节奏波形

用 `建立—压缩—悬置—释放—余波` 画段落，不要让每格都标“更强”。

节奏的五个旋钮：

1. **信息密度**：单位时间出现多少需要处理的新信息。
2. **镜头持续**：观众有多少时间扫描构图、读表演、等待动作完成。
3. **动作脉冲**：动作何时启动、受阻、完成或被打断。
4. **声音预期**：画外声、音乐句尾、静默和声画错位如何制造等待。
5. **情绪消化**：揭示后是否给反应与余波，还是故意剥夺。

快节奏不一定短镜头；长镜头内的调度、信息转移和逼近可以很快。慢节奏也不一定长镜头；重复、空镜和延迟反应可制造停滞。

## 时间预算

先分配段落时长，再分配镜头时长。检查总和等于目标时长，并为片头、字幕、呼吸、转场和平台界面留空间。

粗略规划模板：

| 段落 | 功能 | 观众问题 | 时长 | 进入/退出状态 |
|---|---|---|---:|---|
| Hook | 立即制造异常、承诺或冲突 | 我为什么继续看？ |  |  |
| Setup | 建立人物、规则、目标 | 谁想要什么？ |  |  |
| Escalation | 使原策略失效 | 他会怎么应对？ |  |  |
| Turn | 改写意义或方向 | 原来发生了什么？ |  |  |
| Payoff | 兑现设置与选择 | 代价/答案是什么？ |  |  |
| Button | 留下最终图像、笑点或余味 | 我带走什么？ |  |  |

这些名称可删改；不要强行把所有作品套成同一比例。

## 载体差异

### 长片/长剧

- 让场景同时推进外部目标与内部关系，但不要要求每场都完成大反转。
- 追踪 setup/payoff、承诺/兑现、角色选择与主题反复。
- 用序列级问题维持中段，而不是只依赖最终结局。

### 短片

- 限制核心人物、地点和主要转折。
- 尽早进入具有变化潜力的情境，避免用完时长解释前史。
- 让结尾回照开场图像、行为或命题。

### 竖屏微短剧/短视频

- 让首屏出现人物、异常、欲望、风险或强烈未完成动作之一；不要仅靠大字标题冒充 hook。
- 在小屏上优先可读的面部、手部、道具与前后景关系，减少横向分散调度。
- 用段落问题推动继续观看；反转应重释已有信息，而不是凭空加入新事实。
- 给关键反应留出可读时长。连续快剪如果没有信息层级，只会变成噪声。

### 广告

- 把产品利益写成角色可见结果，不要只拍包装。
- 区分 attention、problem、demonstration、proof、brand、action；可合并但不可全部含糊。
- 让品牌/产品在因果链中有角色，而非结尾硬贴。

### MV/氛围影像

- 以音乐结构、视觉母题和情绪递进代替传统因果，但仍要定义变化。
- 决定剪辑是服从节拍、反拍、歌词、音色变化还是表演呼吸。

## 节奏诊断

| 症状 | 可能原因 | 优先修正 |
|---|---|---|
| 开头慢 | 没有未完成问题；前史先于冲突 | 从异常、选择或后果切入 |
| 中段塌 | 策略重复；风险不变 | 让策略失效、代价升级或答案换问题 |
| 反转假 | 没有 setup，或只靠新信息 | 提前植入可双重解释的行为/物件 |
| 高潮无感 | 选择不难；没有失去可能 | 让价值冲突具体化并付出代价 |
| 结尾拖 | payoff 后继续解释 | 用反应、动作或最终图像收束 |
| 全程很赶 | 没有层级和余波 | 减少 beat，给关键变化更多时长 |

## 输出前检查

- 每场是否有可观察目标与结束变化？
- 每个 beat 是否改变策略、信息、权力或风险？
- 观众问题是否被建立、延迟、替换或回答？
- setup 是否获得 payoff？反转是否能回看验证？
- 时间预算是否真实相加？
- 高强度段落前后是否有对比与余波？
