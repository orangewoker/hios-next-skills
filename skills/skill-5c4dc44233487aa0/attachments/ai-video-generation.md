# AI 生成视频方法论

核心理念：**选择大于努力**。AI 时代人的最大价值是判断——先选方法，再动手。四条原则：判断优先、资产先行（资产越丰富效果越好）、一次做对、客户视角（低质素材不外发）。

## 一、遇到问题：五优先级（严格按序，可融合）

| 优先级 | 方法 | 要点 |
|-|-|-|
| **P1 补充资产** | 补参考图/三视图/站位图/场景图 | 动线不对→补第一、第二位置参考图或自绘动线喂模型；道具常错→生成三视图加强约束 |
| **P2 优化提示词** | 检查提示词本身 | 模型对提示词遵循率高，先自查；可交给 DeepSeek/豆包 优化 |
| **P3 片段修复** | 只重做问题片段 | 找剪辑点→按最小时间段切分→只重做问题片段；**绝不整片重新生成** |
| **P4 问人** | 问带教或熟手 | 不要死磕，卡住就先搁置换思路，及时求助 |
| **P5 更换模型** | 前面都没问题再换 | 超复杂调度（一镜到底、多层动线）向上兼容更新的模型 |

融合示例：P1+P3 同时用——专门修复问题片段，并为该片段生成新框架资产约束站位、动线、道具。

**四条禁止的坏习惯**：每次修改都整条重生成；宁可改两小时提示词也不补资产；发现瑕疵图省事不备注；把"些许瑕疵"都谈不上的素材发给客户。

## 二、模型选型速查（选型比努力重要）

| 模型 | 擅长 | 短板/注意 |
|-|-|-|
| **Seedance 2.5** | 高复杂、高动态、高调度（一镜到底、复杂动线）；穿帮更少 | 动作细节描述不足会卡壳/定帧；30 秒生成上限；简单对话素材用它是浪费；会字面执行"动态模糊/极限速度"类词导致拖影（删掉即可） |
| **Seedance 2.0** | 画面自主延展、自然丝滑动态 | 会"脑补"不听话；真人脸部麻麻赖赖、动态差 |
| **MiniMax H3** | 2D 画面 | — |
| **Wan 3.0** | 超 30 秒、画质要求不高的草稿 | — |
| **可灵** | 真人质感、无大幅度调度；不卡审 | 嘴型易出问题，高动态差 |

口诀：高复杂调度用 2.5；2D 动画用 H3；长草稿用 Wan 3.0；要丝滑动态用 2.0；真人质感用可灵。SD2.5 的提示词同样适用于 2.0、Wan 3.0、H3 且遵循率高，草稿环节统一用一套。

生图模型选型与提示词模板见 [references/prompt-playbook.md](references/prompt-playbook.md)。

## 三、"AI 感太重"五归因排查（客户反馈时逐条查，不要泛泛重 roll）

1. **AI 偷懒 = 放权过度**：只给大而全的提示词→拆成分镜提示词/分镜图逐格约束
2. **没做全景人物占位参考图**：多人位置、透视飘→先做全景站位参考图锁死位置
3. **参考音频没生效**：音色参考不识别→改用 RH 克隆音色，别硬怼参考音频
4. **只有"电影感"没有真实感细节**：补实景光源、噪点、真实物理碰撞等"脏细节"
5. **导演逻辑错误**：AI 不审常识（孕妇跳远、学生进夜店）→只能人审

## 四、画面生产红线（低级错误，必须杜绝）

- **画面拉伸**：横改竖必须对比横版检查；各环节互相提醒
- **噪点/脏图**：脏图必须"洗"一遍再用；底图脏优先换底图，必要时超分
- **瑕疵不备注**：草稿发现的瑕疵必须备注在素材旁
- **命名不规范**：批次迭代命名严格按规范（2.0 素材需标注 2.0）
- **错别字**：脚本和产出文案都要查
- **对比不明显**：前后对比类素材对比必须一眼可辨，否则打回
- **低质外发**：整体框架有问题的素材内部直接打回，不给客户看

# 附录 A · 提示词工程与模板库

目录：结构化提示词八模块 / 脚本三层创作法 / 专项模板（横改竖、延时与一镜到底、真实感公式）/ 生图模型选型 / 物料逆推法 / 提示词通用纪律

## 一、结构化提示词八模块

提示词不是"写一段描述"，而是一份结构化工程文档：

| 模块 | 作用 | 要点 |
|-|-|-|
| 生成目标 | 一句话说清这条视频要发生什么 | 承接上一段剧情，明确本段叙事任务 |
| 主体与空间关系 | 锁定人物外貌、服装、站位 | 用 @ 引用人物/道具资产；写清谁在哪、中间隔着什么、谁不抢视觉中心 |
| 参考素材职责 | 给每个 @ 资产划职责边界 | 明确每个资产"负责什么、不负责什么"（如环境图只负责氛围与路人，不定义人物面部） |
| 初始状态 | 规定第一个画面 | 直接承接上一段最后一帧；已离场的人/物不再出现 |
| 镜头脚本 | 逐分镜写清内容 | 分镜号｜时间码｜景别与运镜｜画面内容；台词用 {} 包裹，一整句台词不拆到多个镜头 |
| 声音 | 环境声与台词规则 | 指定谁说哪句、其余人自然闭口；口型与台词同步；不显示对白字幕 |
| 结束状态/保持一致 | 给下一段留接口，锁死连续性 | 每个角色只有一个连续实例；道具数量、归属、状态连续（吃掉的一口肉不恢复，掉地的刀不回台面） |
| 排除内容 | 负面清单 | 禁手指异常、餐具穿透、食物悬空、道具瞬移、新增人物、字幕水印 |

**模型特性应对**：
- SD2.5 会字面执行"动态模糊/极限速度"类描写，成片拖影或主体模糊时删掉这类句子。
- SD2.5 有 30 秒生成上限，长片按结构拆两段（如 0-16s / 16-30s）接龙生成。
- 多场次分镜提示词**自包含**：角色外貌、服装、气质的统一描述每场完整复写，不依赖上一场上下文，防跨场人脸漂移；多机位场次用时间段切分（0-2s / 2-4s），每段只承载一个镜头意图。
- 必备约束别漏：「全片无 BGM，全片无字幕」；多生成 1 秒防结尾突兀。

## 二、脚本三层创作法（创意 → 可执行提示词）

| 层级 | 任务 | 案例（清洁工与舞者） |
|-|-|-|
| ① 故事核 | 一句话说清情节 | "男清洁工半夜看到女主跳舞，被女主拉近仙境漫游，日光照进，男主醒来发现自己杀死了女主" |
| ② 人工润色 | 文学化扩写：补人设、情绪、画面意象与反转 | "她像圣洁的女神下凡……阳光照在男子脸上，男子双眼通红看着自己鲜红的双手" |
| ③ 提示词脚本 | 转成八模块结构化工程文档 | 基础设定＋氛围画质＋声音规则＋分镜脚本＋禁令清单 |

**润色层四个要点**：
- 转场：相邻镜头落幅与起幅由同一视觉元素衔接，全程无硬切
- 配色：按 60:30:10 分配
- 灯光：只用场景内实际光源（practicals），摄影机始终在人物阴影侧
- 声音即叙事：环境音随段落出现/消失/回归

**剧本打磨五检查点**：开场 3 秒给冲突钩子、台词口语化有活人感、指代必须直观、回忆闪回改画外音更稳、情绪打点前置。

**新视频类型不会写提示词** → 把对标参考视频发给 AI（如通义 Qwen）分析，反推提示词框架再改造成自己的脚本提示词。

### 信息流脚本创作规范

- **脚本四大类型**：夸张搞笑 / 写实冲突 / 时代热梗翻拍 / 冲突反转吸睛。
- **框架优先级**（选爆款框架按优先级来，不要什么火用什么）：P0 无尽冬日 → P1 肥鹅 → P2 未来水世界 → P3 客户创意。
- **内容打点优先级**：P0 打脸/冲突/猎奇 → P1 擦边暧昧 → P2 比拼争抢 → P3 逆袭/热梗/IP。
- **硬规则**：台词必须口语化"说人话"；拒绝硬广、不要 CTA；一条脚本只用一个爆款框架；时长 15–25 秒；至少一个钩子、一个反转；拒绝用字幕传信息。

## 三、专项提示词模板

### 横图改竖图（重绘模板，不重做）

```
重绘图片1，9:16竖版构图，和图片1完全一致的画风、场景与光影，保持原图100%一致的人物、场景、色彩、细节，不拉伸、不裁剪、不畸变，仅调整画面比例为9:16竖版构图，画质清晰，构图完整，比例「9:16」
```

### 延时摄影 / 一镜到底（四段式）

1. **固定机位声明**：开篇写明镜头固定不动，杜绝模型乱加运镜
2. **时间线锚点（不变项列表）**：构图、人物位置、光线基调、场景主体逐项锁死
3. **渐进式变化指令**：按 0–30% / 30–60% / 60–100% 三段分别描述变化，让时间流逝有节奏
4. **禁止项**：末尾列不允许的变化（镜头移动、人物增减、场景切换等）

注意：一镜到底**不要套用分镜脚本提示词**（会中间跳切），要专门写一套。

### 道具/产品真实感公式

```
细节丰富但略凌乱 + 自然窗光 + 轻微噪点 + 抓拍感 + 真实生活照片 + 非摆拍 + 纪实摄影 + 照片级真实
```

画风不统一时直接生成真实道具图，局部标注替换。

### 通用画质约束（放分镜图提示词开头或结尾）

```
画面干净，通透，材质完整，自然纹理平滑，统一，主体清晰，背景层次分明，避免过度锐化色斑，噪点碎纹崩坏和畸变。
```

### 人物三视图要点

摄影参数前置（24mm 焦距、f/1.4、全画幅、电影级布光）；上面 1/3 为正面脸部超特写（完整头部），下面 2/3 为颈部以下正/侧/背三视图（不出现头部），双手自然垂落、灰色背景；风格"克制的细节表达，大色块优先，材质统一干净，避免堆砌细碎纹理"。三视图中**不要出现「男A/NAN A」编号和英文名**，用「王哥、小美」等称呼代替。

### 场景/道具设定图提取话术

- 场景：只分析脚本内的场景信息，结合时代背景；大纵深、视觉美学、冷暖撞色、实景光源；剧情只发生在一个场景就只出一个场景的设定图
- 道具：出三视图（正/侧/背）加关键位置特写
- 共同要点：image 生图易过度锐化、杂乱、畸变、脏色块，话术里着重针对——核心要求永远是画面干净、通透、清晰、电影质感

## 四、生图模型选型

| 模型 | 擅长 | 短板/注意 |
|-|-|-|
| 即梦 / 豆包 / MJ8.1 | 初步定视觉方向：大场景、色彩参考、艺术氛围 | 即梦/豆包审美偏可爱、游戏 CG、AI 味重；MJ 艺术氛围浓但不可控；**MJ 横版构图明显优于竖版，竖版需求也优先出横图** |
| image | 单图复杂设定（三视图、场景设定、道具设定、宫格分镜） | 最好不要多参/喂图（会出不可控噪点和逻辑混乱）；文生图效果最好 |
| Nanobanana Pro | 图片编辑：局部改图、多图融合、细节/画质修复 | 审美一般、有油腻感，底图很重要；复杂人物站位/空间不如 image |
| mini | 新人测提示词效果 | — |

**3A 画风流程**：先用 image 生成，再用 nano pro 洗一遍图——画风更符合 3A 质感、画面更干净。
**画风对齐纪律**：客户给对标视频时，人物、场景、道具都向对标风格靠拢；分镜脚本模板、场景图风格提示词同步更换；**画风先确认再开工**。

## 五、物料逆推法（开做之前先想易错点）

| 易错点 | 逆推出的前期物料 |
|-|-|
| 多人场景位置不稳、透视飘 | 先做一张全景人物站位参考图 |
| 不同镜头色调不统一 | 先产出色卡，所有镜头对着色卡调 |
| 区别不大的场景/道具反复生成不稳定 | 一张图多宫格产出，一次锁定多个变体 |
| 分镜图做到一半不够用 | 按旁白/脚本估算张数，宁多勿少，直接 16 宫格甚至 25 宫格备用 |

## 六、提示词通用纪律

- 提示词不是越多越好：几秒的视频提示词不宜过长；先让 AI 分析剧本精简到核心画面描述；参考图里已有的内容不要重复赘述
- 动作和台词**分开描述**，同步描述会导致台词说不清
- AI 不理解"时间先后否定"：写「还没有出现破洞」也会把破洞提前渲染——有先后顺序的画面不要写进同一段提示词，改用剪辑切镜表现
- 角色大幅位移后模型丢失空间锚点：动作发生后的镜头要再次强调角色空间位置（如「她仍在下层」）
- 情绪写饱满，不要字正腔圆（会丧失真人感）；说话语气平淡时加强语气提示词
- 打磨好的提示词存档到文档；AI 对话重命名带脚本号+关键词

# 附录 B · 问题排查库（问题 → 解法）

目录：提示词写法 / 人物与三视图 / 场景与图稿 / 视频生成与穿帮 / 音频与音色 / 剪辑与后期 / 横改竖专项 / 工作方法。标注 **[高频]** 的是多人多次踩过的坑，优先掌握。

## 一、提示词写法

- **[高频] 提示词越堆越多，视频反而生不出来、越来越卡** → 几秒的视频提示词不宜过长；先让 AI（DeepSeek/豆包）分析剧本精简到核心画面描述；参考图里已有的内容不要重复赘述。
- **画面脏、有噪点** → 加负面/反向提示词；点状雪是噪点主因，把「点状雪」改成「大片积雪」；图稿阶段先洗图/高清化再生视频。
- **人物太假/太写实/不像参考图** → 提示词写明「人物形象参考 xx」；真人感过强就换文生图重新生成，或找参考照片让 AI 照着写提示词。
- **人物不动、只有镜头在动** → 检查是否有「游戏广告片头定格画面」这类词，删掉并补人物动线。
- **台词/动作提前或错乱** → 写清每个人物说话的具体时间和动作；动作和台词分开描述。
- **没接触过的视频类型不会写提示词** → 把对标视频发给 AI 分析，反推提示词框架再改造。
- **AI 不理解时间先后否定** → 有先后顺序的画面别写进同一段提示词，改用剪辑切镜表现。

## 二、人物与三视图

- **[高频] 人物站位与脚本不符/站位穿帮** → 做人物站位参考图（正确站位截静帧）在生视频阶段引用；分镜图上用标注固定走位；提示词没问题站位仍错时换 sd2.5 试试；站位图/分镜图用之前先洗一遍图，否则视频比 480p 还糊。
- **[高频] 人物忽隐忽现、跨镜头消失** → 把遗漏人物补进全景人物参考图；长视频拆开分镜，冲突动作分到两个分镜。
- **[高频] 人物设定 2.0 与 3.0 资产混用** → 做三视图前先确认脚本要求的设定版本；两版资产不能混用；脚本描写与设定版本不符时先确认再动手。
- **三视图与脚本设定不一致** → 贴图前先看脚本；细节与三视图保持一致；不用「男A」编号和英文名，用称呼代替。
- **人物形象风格不稳** → 按客户要求定调（如无尽冬日：亚洲脸、服装夸张非日常、辨识度高非网红脸、游戏 CG 感）；人物不要太好看，避免画面割裂。
- **人物比例怪（霍比特人）** → 别死磕提示词，先优化人物三视图，再用人物参考生成图稿。
- **人物表情平淡/情绪不对** → 让 DeepSeek 把情绪写饱满；夸张表情可在剪映加特效（如红脸）补救。
- **三视图脸部油腻、锐化过重** → 给一张合格三视图做参考，提取其提示词改风格和脸部细节再生成。
- **AI 生成人脸模糊不清** → 根因是中远景占比过高、人物太小、运镜复杂焦点不稳：大幅增加单人特写和近景比例，关键台词全部用固定机位单人特写，简化运镜。
- **[高频] 过审红线（人物向）** → 女性角色不能擦边；肌肉男不靠裸露体现魁梧；军事元素一律避开；衣服不连体的三视图大幅度动作会露点，要改三视图。

## 三、场景与图稿

- **[高频] 场景细节穿帮、不符合脚本** → DeepSeek 优化提示词 + 画布标注法改图；场景图做完先检查是否适合脚本再继续。
- **[高频] 道具/产品图不真实（水果、礼盒）** → 用真实感提示词公式（见 prompt-playbook）；局部标注替换。
- **场景太小气、层次单薄** → 不是非要大远景，而是提升场景密度（伐木场加散落工具、半成品车轮）；也可用鸟瞰/上帝视角。
- **画面空间太挤** → 空间挤会导致视频穿帮，场景图要留足人物活动空间。
- **画风前后不一致** → 不符合的版本重新优化提示词再生一版；剪映里统一每张图色彩；同一视频不混用成人版和 3D 动漫人物；前后道具不一致时生成后一张图参考上一张内容。
- **「标注大法」** → 参考图不听话时（平民形象、城堡带围墙），在 LibTV 里用标注改图，比重写提示词有效；标注要描述清楚详细（换成什么颜色、什么样子），最好附资产图参考。
- **图稿噪点多** → 能换模型的换模型重抽，不能换的用 NanoBanana / LibTV 洗图；竖版图稿尤其注意。
- **连续一致性画面（如中世纪场景）** → 不要用 MJ 生图，直接在 TapNow 里九宫格/四宫格生图保持一致性；宫格人物不正确时用 sdr5.0 洗，还不行用标注大法。
- **客户要求横截面画面（房间内外同屏）** → 先生成横截面侧面场景图 + 人物参考图再生视频；把用到的剖面图合并成一张图，生视频时用「xx-xx 秒全景参考@」引用，防止剖面展示不出、人物消失。
- **分镜图数量不够用** → 生成前按旁白/脚本估算张数，宁多勿少，直接 16/25 宫格备用。

## 四、视频生成与穿帮

- **[高频] 高清视频和草稿用同一提示词却穿帮** → 截取正确帧做高清参考；穿帮部分参考草稿的深度视频；必要时换模型（sd2.5 实测穿帮更少）。
- **[高频] 用 480p 草稿直接超帧做高清** → 人物模糊还出闪点；高清要按正常流程重新生成，不要拿草稿超帧顶替。
- **一镜到底动作穿帮多** → 不要用切镜方式拼，重新生成一套专门的一镜到底提示词；搭配 sd2.5 穿帮明显减少。
- **分段衔接不自然/跳一下** → 首帧图生视频会比原图小一点：拉宽 + 叠化转场 + 组合去频闪；确认用的是上一段真正的尾帧；长视频一坏全坏，优先分镜生成。
- **20 秒长视频前后半不衔接** → 用 Seedance 2.5 把场景图和标注图都参考进去生成，一次成功率高。
- **参考视频带入了上一条的声音/人物** → 在剪映里先删掉参考视频的音频再参考；提示词约束音频无效。
- **全景画面脏/糊** → 参考图去噪点 + 快速前推运镜；全景易糊可换景别或后期 RunningHub 超分。
- **运镜让动作失真**（俯摇跟拍像飞起来）→ 换仰拍跟随等更贴合脚本动作的运镜。
- **画面 AI 常见 bug** → 炮弹弹道异常、人物牵牛后退、多余人物跳出等，生成后务必整体检查。
- **视频小失误别推翻整条** → 局部穿帮/朝向不对时，单独生成 4 秒片段替换；可在同一片段前 2 秒一种景别、后 2 秒换另一种，对比择优。
- **角色大幅位移后丢失空间锚点**（坠落后两层房间融合成一层）→ 后续镜头提示词再次强调角色所在空间位置。
- **分段视频一致性差** → 提示词加限制词尽量完善，效果不理想就增添资产。
- **展示向视频** → 每一段分开生成，后续在剪映加转场即可；用简单固定镜头，不要多余切镜。
- **画面没气势**（如叛军攻城）→ 让人物比例小一点、移动速度加快、动作凶猛；优化提示词无效就直接修改图稿再参考生成视频。
- **结尾太平淡** → 原因常是只有镜头缓慢运动：镜头运动幅度加大，人物加些小动作；但运动幅度不能太大（观众会晕）也不能太小（太平淡）。
- **动作没逻辑**（汤汁、嗦面）→ 去掉升格镜头，按物理逻辑描述动作链。
- **延时摄影的颜色渐变模型理解不了** → 生一张目标状态的图稿丰富资产，参考进去。
- **视频没音效、质感不高** → 可以没有背景音，但不能没有音效。

## 五、音频与音色

- **[高频] 各段音色不统一** → 台词摘出来统一生成；或截取满意音频在生视频阶段做参考引用；单句不对可用克隆声音单独替换这一句；建议建自己的声线库，分段生成时不用等第一段。
- **半截音频/单句只念一半** → 把单句台词重复写两遍；尾音突然消失时把最后一句话复制两遍；SS 模型不稳换 RunningHub 其他音频模型。
- **音频把括号里的提示词也念出来** → 剪辑时剪掉，或去掉括号重新生成。
- **AI 朗读多音字发音错误**（如「下载」）→ 用同音字或拼音替代（「宰」「仔」）重新生成。
- **说话语速太快** → 在台词后面加符号（逗号句号），让人物说完一句等 1-2 秒再说下一句；或将参考视频设为无声视频再生成。
- **音频太短参考不进去**（如女 A 音频只有 1.4 秒）→ 先参考生成看效果，相差太大就用第二段的声线参考替换第一段音频。
- **选音色** → 中年和青年男声各生一版对比，一般中年更合适；语速 40 秒左右最佳，不要太慢；提示词注重情绪，不要字正腔圆。
- **说错词/缺字**（如「避难所」说成「避难屋」）→ 替换字体和标注拼音都不太好用，直接重新生成这一句替换。
- **音频规范（客户反馈高发区）** → 视频生成一定要使用人物资产里的音频参考；注意音色提示词的输入格式，生成前检查引入的音频是否正确；音量大小要统一——音量不统一、音频用错、错别字是客户反馈的三大高发问题。

## 六、剪辑与后期（剪映）

- **横改竖画面变窄、比例失调** → 用画面放大功能重新构图。
- **转场生硬** → 剪映转场库里调；或用提示词描述转场并引用上一段视频结尾画面做无缝转场。
- **迭代视频时长显示不对** → 同名文件剪映识别错乱，重启剪映即可。
- **节奏慢、超时** → 修剪 + 变速控制时长，避免无用镜头。
- **细节** → 竖版字幕不超过 11 个字；字幕条与音频对齐不要有间隔；替换字体背景用纯绿色好抠图；记得开自动保存。
- **明星混剪节奏超 15 秒、素材重复、标题刻板** → 一条混剪至少用 3 个素材；节奏卡点控制在 15 秒内；标题字体样式方正，主副标题配色区分。
- **素材没有纯净版且镜像字会反转** → 把画面扩大到无文字区域，用蒙版把 UI 扣下来。

## 七、横改竖专项

- **[高频] 竖版个别几秒穿帮/人物不说话** → 不要整条重抽：截取横版的首帧/中间帧/尾帧做参考图，去掉无关物料，用文字生视频只重生有问题的几秒；展示向也可先把横版图片生成竖版图片，再用竖版图片生视频。
- **竖版人物比例不对** → 截取横版首帧图改为竖版，再用文字生视频；或修改提示词中的景别后用文字生成。
- **横改竖上下多出画面与原场景有差异穿帮** → 用文字生成视频，把景别缩小。
- **竖版与横版时长不一致** → 横版多少秒竖版就生成多少秒，防穿帮。
- **素材混乱导致竖版难做** → 能用图稿+提示词生成的就别用参考视频；尝试两次不行再换参考视频。
- **参考视频效果差** → 灵活变通换文字生视频，不要死磕参考视频。
- **横改竖参考视频带马赛克特效** → 参考视频不要打马赛克，否则生成画面与原视频不符、台词不清。
- **竖改横不能直接复用竖版物料** → 参考图重新做成横版，提示词让 DeepSeek 优化后再检查一遍确认无误再生成。
- **RunningHub 横改竖生成的视频自带字幕** → 可在 RunningHub 里直接去除字幕，不用回剪映。

## 八、工作方法与协作

- **[高频] 卡住死磕** → 做草稿/资产前先沟通定方案；改不明白及时问；卡住就先放一放换思路。
- **拿到脚本先读懂再动手** → 先做删减增添（去掉会让画面变脏的词），不要直接扔给 AI。
- **素材管理** → 开工先建好文件夹，做完即归档；确认图稿顺序与命名一致。
- **客户反馈处理** → 修改版不要覆盖旧版，放后面做对照；颜色类主观问题先生成几版让客户挑选；客户说"人脸变形"请其截帧指出位置，拿到精确证据再改。
- **修改保真原则** → 改稿前先列「必须保留的元素清单」，改完逐条核对再交付，别把脚本里原有的好点子弄丢。
- **脚本人物标注错误**（哥哥一会儿男A一会儿男B）→ 认真阅读脚本，手动纠正。
- **修改的最短路径** → ①先读懂客户反馈想要的效果；②梳理最短修改路线，物料备齐再动手；③片段问题优先用分镜思维修改，不整条重做；④目标：修改完一波过审。
- **缺料处理** → 发现缺人设图等物料，立刻反馈给对应生图的人补齐，表格里做备注，并单独跟客户确认。
- **踩坑沉淀成规范** → 被客户挑出一次问题（如命名），就整理成规范文档发给客户确认——一次踩坑，永久免疫。
- **场景/画面拿不准时参考对标视频** → 客户给了对标视频就严格参考（场景远近关系、画面衔接、画风），能少去很多穿帮麻烦；效果不理想就直接参考对标视频。
- **卡点就搁置** → 解决不了的问题当下报上来、记录问题、跳过做下一项，统一时段讨论解决，不让一个卡点堵死一整天的产能。

# 附录 C · 生产流水线 SOP 与交付规范

目录：流水线分工 / 七阶段 SOP / 横竖版六步流程 / 成本与质量策略 / 审核红线与擦边边界 / 卡审自检 / 花字五原则 / 明星与迭代素材规范 / 打包交付 / 客户项目要点

## 一、流水线分工

分镜师（撰写分镜脚本）→ 导演（优化脚本）→ 分镜师（逐行生成分镜图）→ 抽卡师（分镜图生视频）→ 剪辑师（拼接+包装）→ 导演审查 → 不合格分镜单独打回重抽（不牵连其他分镜）→ 交付。

分镜颗粒度：每行一个分镜，可多个分镜一起出视频；打回只针对单行分镜重新抽卡，最大化复用已通过内容。

## 二、七阶段 SOP

1. **草稿**：拆解脚本，最快路径产出第一版草稿；个人审核穿帮、简单优化到约 80% 成片效果；粘贴对接文档等待内审。
2. **内审**：根据反馈优化草稿；通过后自动推进客审。
3. **客审**：根据客户反馈重复前两阶段，直到过审，自动推进成片。
4. **成片**：720P 重新用提示词跑，或 480P 超分至 2K；修复越轴、穿帮、木头人；优化音频（克隆音频、数字人对口型、AI 配音）；专人超分、专人剪辑包装（纯 A 面即可，注意警示语）；剪辑者上传对接文档，推进客审终审。
5. **客审终审**：原素材问题→剪辑反馈给 AI 师改原片；包装问题→剪辑自己改；重复直至通过，推进打包。
6. **打包**：专人打包，按需求衔接 B 面或迭代版本，同步项目负责人后交付。
7. **验收**：检查打包命名、素材瑕疵（跳帧、版本错误、BGM 重叠等），上传工单后台，订单验收。

修改责任划分：简单的修改由出草稿的同学在工程里直接改；涉及分镜控制、复杂调度的复制工程并标注，交给高手改——"难改的让会改的人来改"。

## 三、横竖版六步流程

1. **出单版本草稿**：真人用 480P 视频草稿；奔奔王国用图稿（含 BGM、配音、创意 UI）。无尽冬日优先竖版，奔奔王国优先横版。
2. 内审 + 客审修改草稿，直至过审。
3. **成片制作**（含包装、BGM、音效、字幕、警示语、logo）：无尽冬日 480P 超分或重新生成 720P，最终成片原素材需 1080P（超分）；奔奔王国 720P 即可。
4. 内审 + 客审修改成片，直至过审。
5. 一旦有过审成片，**直接生成另一个版本**的成片，不用再核对草稿。
6. 所有素材过审后打包。

## 四、成本与质量策略

- **草稿统一 480P**：最低成本验证创意，客户过了再加人脸模糊、高清化、横改竖。
- **简单修改直接出高清**：不涉及提示词大改的反馈，直接用 SD2.0 满血版出 720P。
- **首批次不计成本**：新批次第一批素材派最强的人直接出 720 高质量——第一印象决定客户对整个批次的信任。
- **大迭代分批交付**：按时间节点分批，不憋到最后一次性交。

## 五、审核红线与擦边边界

**绝不能出现**：屎尿屁道具和语言梗；乳沟、性感部位特写；血液、极端残忍；性暗示、男女捆绑、亲嘴、强烈暗示姿势。

**可以擦边**：情侣正常暧昧（搂抱、按摩、睡一张床）；不见血的暴力动作；黑丝高跟等性感服饰（不特写、不露肉）。

**虚假宣传红线**：互相矛盾的卖点不能同框（如"只玩一个月"和"熔炉 30 级"）。

**内审前置**：太次的作品不要给客户审，内部直接打回——低质外发 = 客户觉得供应商水平不稳定。

### 卡审自检七条（交付前逐条查）

1. 车牌有没有打码
2. 男的漏点、女的露沟
3. 人物有血迹
4. 战力等级没有添加包装
5. 错别字
6. 不看脚本：素材严重脱离脚本设计、包装缺少标题元素
7. 横改竖素材有没有对比横版检查拉伸

### 包装三规则

- 人名条始终存在
- 出现游戏画面后添加 logo，每 10 秒换一次位置，不能遮挡 UI
- 注意添加警示语

## 六、信息流花字五原则

1. **大到不礼貌**：主标题撑到画面 70% 宽度
2. **白字黑边是万能安全牌**：同色系配色等于融进背景
3. **字体就是语气**：气质匹配内容（末日 SLG 要粗黑力量型，圆润综艺字显廉价）
4. **禁用廉价感三件套**：渐变填充、彩虹描边、默认投影
5. **排版要有层级**：主标题巨大、副标题缩到 1/3，间隔号 + 装饰线

## 七、明星 / 迭代素材规范

**明星迭代十条**：A+B 结构（接 UE 的 B 面）全片 ≤60 秒；1080P 30 帧；混剪须符合逻辑；提到熔炉/战力/幸存者数量必须加对应包装；必须加警示语且无错别字（字体推荐新青年）；提到玩法加小屏 UE 画面；不用卡通/真人贴纸（版权）；不恶搞明星、不用极端话术；避免跳帧、逻辑混乱、UE 画面不匹配；礼包码字幕用中文。

**混剪迭代八条**：第一幕必须明星本人出现并加人名条；利益点处原视频无游戏画面的优先加 UE 小屏；杜绝割裂 BGM、跳切、闪帧、错别字，全片始终有警示语；成片 ≤60 秒、A 面 ≥15 秒；混剪逻辑通顺；可发挥创意（标题文案、二次构图、模拟营销号、默剧、包袱前置）；迭代素材差异化，平均分配使用；不同交付包的素材分开打包。

**三版本产出体系**：正常推流（带画中画包装、警示语、音乐音效）/ 官微推流（不带画中画和警示语，保留音乐音效字幕）/ 纯净版（只有演员干声和音效）。

**落版匹配规则**：名称含 AI 且不含明星/达人 → AI 落版；含素人或多明星 → 普通落版；含具体明星名 → 该明星专属落版；横竖版和 APP/小程序两端各一版。

**B 面管理**：卡审能改的改、不好改的直接换 B 面；横竖版必须对应；输出命名同步改成新 B 面关键词；打包前用关键词在打包文件里搜一遍防重复；A 面 B 面数量要配套，不够用先和客户确认能否重复。

## 八、打包与交付

- **命名格式**：最外层「下单时间+客户名称+项目名称+打包序号」（如「8.17TW无尽冬日打包2」）；素材命名结构：工单编号_素材类型_主题_形式_渠道尾缀_关键词_横竖版标注；混剪类形式字段统一用"混剪"；视频按素材编号命名。
- **打包前必查**：编号、命名、时长、抽查四点；确认视频尺寸 1080p 和编码 H.264（否则对方打不开）；检查前半段警示词；MX 导出确认透明背景设置；A 面比例不对时放剪映放大后重新导出再打包。
- **B 面语句不完整** → 换对应的打包软件重新打包（明星素材用明星打包软件）。
- **文件夹备注**：注明人物是设定 2.0 还是 3.0；B 面筛选少放避免重复，横竖各类型都要放。
- **效率**：先打包一部分上传，剩下的继续打；做完一个标记一个。
- **过审即备份**：过审素材下载后上传网盘备份。
- **审核状态机**：草稿过审=横竖版草稿客审列任一打勾；全部过审=成片横竖版客审都打勾才可打包；计入待打包=进度列"成片待审核"且成片过审处已打勾。标黄=已修改，标红字=客户反馈；全部过审的条目直接推进，不等齐。
- **打包注意四条**：按客户要求决定是否出现落版（有的客户明确不要）；确认 B 面是否有警示语和 logo；可以超 60 秒但尽量不超过 100 秒；错别字检查。

## 九、客户项目要点速查

- **TW 无尽冬日**：亚洲脸、服装夸张非日常、符合冰雪末日设定、辨识度高非网红脸、游戏 CG 感不要太写实；命名要细心；明星混剪注意错别字（如吴樾）。
- **DD 奔奔王国**：3D 画风但不写实也不太动漫；国王永远用成人形象；叛军统一红色；不可随意增删改客户脚本；生图稿推荐 LibTV seedream5.0 或 RunningHub 全能图片 G2；不用 image 直出（画面脏噪点多），脏图用 Seedream5.0 Pro 或 MX Nano Banana 洗；流程：先出 12 宫格图稿确认画风 → 让豆包/DeepSeek 分析画风构图 → 单独生成单图，人物不合适用标注法修改。
- **通用**：展示向视频用简单固定镜头，不要多余切镜；转场不要太夸张。

## 十、客户沟通方法论

| 方法 | 要点 |
|-|-|
| 确认式复述 | 接到需求先用自己的话复述并举例，客户确认后再批量执行 |
| Q&A 前置 | 脚本疑问集中标注，开工前一次性问清，不边做边问 |
| 给选择题不给问答题 | 有歧义时直接做 2-3 版供客户挑选 |
| 主动暴露困难 | AI 达不到预期时第一时间同步并附替代方案（先做图或文字描述确认） |
| 需求边界管理 | 脚本内微调免费改到位；脚本外新增先对齐确认再动手 |

底层原则：不能让客户感觉同一个问题反反复复地说；信任一旦有裂痕，要花更大代价修复。
