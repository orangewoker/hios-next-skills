# Seedance 2.5 提示词结构骨架

苹果风产品片最终输出的视频提示词遵循此结构。全程纯正向描述，单条控制在 2500 中文字符内。

## 核心概念

- **板块 = 一次生成单元**：一条完整提示词对应一次视频生成。多镜头长片拆成多个板块，逐个生成后拼接。
- **三支柱**：主体（产品）+ 场景/氛围 + 画面动作。缺一不可。
- **一致性锚定**：产品外观、风格核心、画幅在第一个板块定义清楚，后续板块只写"变化"，用引用锚定同一产品。

## 六段式结构

```
板块N：[场景一句话摘要]

【基础设定】
产品：[品类、造型、材质、配色、标志性设计特征、工艺质感。若有产品图用图片引用锚定]

【道具】
[衬托产品的关键元素及其状态与关系。苹果广告道具极少，宁缺毋滥；无道具可写"画面仅有产品本体"]

【场景】
[空间类型、时间、光线、环境氛围。如"纯净无缝影棚空间，柔和雾面背景"]

【声音】
[对白/音效/环境声/音乐。苹果风常写：声轨由极简音效与环境静默构成]

【氛围与画质】
风格核心：[一句锁定整体风格，如"极简高级产品广告、苹果发布会美学"]
视觉基调：[摄影机型号 + 镜头类型 + 景深特性]
色彩与影调：[饱和度、色调、布光、对比、画幅比例]
风格参考：[可选，如"Apple 产品发布会影片美学"]

【画面内容】
分镜一：
景别：[微距/特写/中景/远景 + 拍产品哪个部位]
构图：[产品位置、留白、视觉重心]
运镜手法：[缓慢环绕/匀速推进/悬浮旋转/精准轨道]
画面内容：[具体物理动作、光影变化、材质呈现的可观察描述]

分镜二：
...
```

## 时间轴写法（长镜头 / 精确节奏时用）

需要精确控制节奏时，可在【画面内容】里用时间轴：

```
0-2秒：产品局部在黑暗中被一束光唤醒，金属倒角高光缓缓亮起。
2-5秒：镜头匀速环绕，光线滑过金属表面，反光条随之流动。
5-8秒：产品悬浮旋转至正面，屏幕点亮，色彩从中心晕开。
8-10秒：镜头拉远，产品静置于纯净负空间中央，光线聚焦定格。
```

## 常见错误（写成正向目标即可规避）

- ❌ 堆砌摄影参数却没有动作 → ✅ 每个分镜都要有可观察的运动/光影变化。
- ❌ 一条提示词塞进整条 30 秒广告 → ✅ 拆板块，一条 = 一个生成单元。
- ❌ 用否定式"不要抖动/没有文字/避免杂乱" → ✅ 改写为"固定机位构图稳定/画面纯净只有产品/背景大面积留白"。
- ❌ 产品外观每个板块重写导致跨镜不一致 → ✅ 首板块定义，后续引用锚定。
- ❌ 场景与运镜互相矛盾（无重力黑场却写桌面反光）→ ✅ 场景、道具、运镜逻辑自洽。

## 正向化对照表

想表达的限制正向写法镜头别抖固定机位 / 匀速环绕，构图持续干净稳定不要文字水印画面纯净，仅呈现产品本体背景别杂乱纯白无缝影棚背景，大面积负空间别失真变形产品造型稳定清晰，材质反光真实不要杂音声轨由极简音效与环境静默构成
