# 图片安全审核失败回退策略

## 适用条件

仅当 `character_reference` 或 `boarding_pass_reference` 的图片请求明确返回安全审核未通过、内容审核拦截或等价安全拒绝时触发。网络错误、超时、模型繁忙或画质不满意不适用。

## 固定回退链

1. 原模型安全审核失败：保持原始提示词完全不变，切换 Navo Pro。
2. Navo Pro 仍安全审核失败：保持同一原始提示词完全不变，切换 Navo2。
3. Navo2 仍安全审核失败：仅最小化调整可能触发审核的合规措辞后重试。
4. 仍失败：停止并说明限制，提出不改变旅行换装核心目标的安全替代方向。

这不是绕过审核。不得通过谐音、错拼、编码、拆分或伪装受限内容继续请求。可做的最小调整包括：明确成年、移除第三方肖像/真实明星复刻、移除不必要的性化或危险化描述，并保留角色旅行换装、纯白时尚摄影棚和连续转场目标。
