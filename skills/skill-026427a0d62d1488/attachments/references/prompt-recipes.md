## 1. 基础与长视频骨架

### 简单镜头

```text
【一句话总述】
[主体]在[地点/时间]完成[核心动作]，[题材与视觉风格]，[核心机位与运镜]。

【画面与动作】
[开场状态]；随后[动作过程与物理反馈]；最后[结束状态]。前景[元素]，背景[元素]，光线[方向与质感]。

【声音】
[环境音/动作音效/对白/BGM]。

【收束】
保持[主体/服装/道具/场景]一致；动作连贯、受力真实；[字幕与 BGM 要求]；无多余主体、Logo、水印、闪烁或突兀跳切。
```

### 4–30 秒多镜头

```text
【输出参数】
总时长[xx秒]，画幅[16:9]，[模式]。

【素材映射】
@图1只锁定[角色外形/服装]；@视频1只参考[动作/运镜/节奏]；@音频1作为[角色]音色/全片BGM。

【全局设定】
基础环境与质感：[时间、地点、天气、材质、物理规则]
视觉风格：[题材、色彩、打光、景深、画质]
镜头原则：[一镜到底/多镜头、运动风格、剪辑节奏]
主体设定：[角色或产品]
表演核心：[最重要的动作或情绪]
声音原则：[对白、环境音、音效、BGM]
连续性：[外观、站位、道具、光线与空间锁定]

【时间戳分镜】
[00:00–00:04] 镜头一｜[镜头名]
景别/机位/运镜：……
画面与动作：……
声音：……
转场/结束状态：……

[00:04–00:09] 镜头二｜……
……

【全局收束】
……
```

### 30–180 秒超长视频

在普通长视频骨架前增加：

```text
全片总时长[xx秒]，画幅[比例]，使用超长视频模式。全片为同一连续故事/同一视觉主题；严格锁定主角脸、发型、服装、体型、核心道具和场景空间关系。每一段从上一段结束状态自然接续，不重置人物站位、道具或天气。
```

按 5–15 秒分段。每段同时写：

- 本段叙事功能：建立、推进、反转、高潮、缓冲或收束。
- 开始状态与结束状态。
- 一项主动作、一项镜头策略、一项声音变化。
- 与下一段的转场接口。

## 2. 真人角色配方

按需选择，不必机械填满：

```text
[年龄/族群]：[具体年龄]，[族群/地域特征]，[风格气质]的[脸型/骨相]。
[肤色/皮肤]：[冷暖色调与肤色]，保留真实微细毛孔、肌肤纹理与合理瑕疵，拒绝塑料感和过度磨皮。
[面部辨识点]：[眼型]、[眉骨]、[鼻梁/鼻头]、[唇形]、[颧骨/下颌线]中的至少三项。
[眼神/灵魂]：[目光状态]，像[可视化比喻]，底层情绪是[情绪]。
[头发]：[发色]、[长度/卷度/发型]、[发丝质感]，与风/雨/动作产生[互动]。
[服装]：[版型与颜色]的[服装]，材质为[材质]，带有[新旧/褶皱/湿润/磨损]细节。
[体型/气质]：[骨架与体态]，[动作/视线]，整体散发[气质]。
```

多角色不要复用同一组泛化形容词。为每人至少设置两个互不相同的辨识点和一套专属服装色块。

## 3. 动作、文戏与声音

### 文戏

把情绪翻译成可见表演：

```text
她先直视对方，呼吸停顿半拍；视线缓慢移开，嘴角短暂牵起又落下；再次抬眼时眼眶微红但泪水未落；说到最后一个字时声音轻微颤抖，随后眉心缓缓松开。
```

不要只写“悲伤地看着他”。给表情变化设置顺序和触发点。

### 武戏/复杂动作

```text
准备：双脚错开、重心下沉、肩胯预旋。
执行：前脚蹬地，力量沿腿—胯—肩—手臂传递，武器从右下向左上挥出。
接触：命中点产生明确冲击、火花/水花/碎屑与短促镜头震动。
反作用：攻击者手臂回弹，受击者上身后仰、脚步滑移，不穿模。
结果：双方重新落地并承接下一动作，衣料、头发和环境粒子继续受惯性影响。
```

### 声音

```text
对白：角色A用[语言/口音/音色]说：“……”，语速[快慢]，情绪[情绪]，口型严格同步。
环境音：[风、雨、人群、空间混响]。
动作音效：[发生时刻]出现[音效]，距离和方位与镜头一致。
BGM：[风格]，在[时刻]进入/抽离/到达重拍；若不要则明确“全程无BGM”。
```

## 4. 视频延长与转场

### 连续续写

```text
参考@视频1的完整内容，向后延长[xx秒]。从原视频最后一帧无缝延续：严格保持[人物外形、服装、站位、手中道具、动作方向、相机速度、焦距、光线、天气和声音]不变。新增段落中，[动作过程]。要求动作衔接自然、惯性连续、镜头呼吸感一致，禁止生硬切镜、瞬移、站位重置或物体凭空出现。
```

### 转场式续写

```text
参考@视频1，向后延长[xx秒]。前段结尾为[镜头A状态]；使用[转场类型]：由[具体触发物/动作]在[方向]遮挡/匹配/带动镜头，[形状、位置、大小、方向或运动速度]保持连续；转场后显现[镜头B场景与开场状态]，景别由[景别A]变为[景别B]。必须自然切换，禁止黑屏、跳帧、闪烁或物体凭空出现。
```

### 转场选择

- 自然镜头切换：常规叙事；给镜头呼吸与停留时间。
- 淡入淡出：开头、结尾、时间跨越或段落结束。
- 叠化：回忆、梦境、柔和情绪或缓慢时间推移。
- 白闪/黑闪：重拍、爆点、快门、枪声或强冲击。
- 擦除：明确地点转换、复古风或图形化表达。
- 遮罩转场：树叶、人物背影、墙、伞、裙摆等完全遮住镜头后换空间。
- 相似物转场：圆月到杯口、瞳孔到隧道等形状/色彩匹配。
- 动作/甩镜转场：保持甩动方向与力度，利用运动模糊连接。
- 动态接力：人物跳出画框，再从另一场景同方向落入。
- 拉近/拉远：进入瞳孔、镜面、锁孔或微观细节，再展开宏观世界。
- 水墨转场：古风、人文、回忆；明确墨迹出现时机，禁止提前水墨化。

## 5. 智能/高级编辑

### 智能编辑

```text
编辑@视频1的[00:00–00:08]：把[具体对象A]替换/修改/消除为[对象B或补全结果]。变化从[时刻]开始并在[时刻]完成/全片保持一致。除[目标属性]外，人物脸、皮肤、身体、动作、镜头、背景、光影、色调、画质、声音与字幕全部保持原样。修改结果要跟随运动稳定，不漂移、不闪烁、不留下残影。
```

### 高级编辑/视频编辑

```text
在[时间标签]对应的画面中，将[红框内/红色箭头指向/定位点处/红线左侧]的[具体对象]，[替换/增加/删除/改色]为[结果]。修改在[全片/指定秒数]生效。自然补全原本被遮挡的纹理、透视、阴影和边缘；保护[不可改变项]。
```

## 6. 创意迁移与空间视角

### 创意迁移

```text
参考@视频1的[创意形式、镜头节奏、运镜轨迹、转场方式、表情状态、喜剧节拍、光影氛围]，把主体替换为@图1的[角色]，场景替换为@图2的[场景]。只迁移上述创意内核，不照搬@视频1的人物、服装、品牌、文字、背景或原始画面质感。严格保持@图1的核心外形和@图2的空间特征，形成同类创意但独立的新视频。
```

### 空间视角修改

```text
把@视频1的[原视角/多机位]修改为[目标视角]。相机从[起点]以[速度与路径]运动到[终点]，焦距/景别由[起始]变化为[结束]。保持人物、动作、场景布局、时间、光影与声音不变；对原画面外新增区域按既有建筑、地面和光线逻辑自然补全，比例与透视合理。
```

## 7. 音色、多语言与多人

### 音色绑定

```text
@音频1只作为角色A的音色参考，保留其[低沉/清亮/沙哑]声线、呼吸、语流和情绪起伏，不把原音频内容或背景音乐带入成片。角色A在[时间]用[情绪]说：“……”，自然断句，口型严格同步。
```

### 多角色

```text
角色A参考@图1，穿[服装]，位于画面左侧；角色B参考@图2，穿[服装]，位于右侧。A先[动作]，B在看到A之后才[反应]；两人接触点为[手/肩/道具]，遮挡关系自然。A使用@音频1，B使用@音频2。全片身份、脸、服装、台词和音色不互串，不生成重复人物或多余肢体。
```

### 多语言

直接写目标语言台词。另写：

```text
全片对白使用[语言]，采用自然的[地区]口音和真实语速，断句流畅，口型同步。画面文字/字幕只允许使用[语言]；禁止混入中文、英文或乱码。
```

## 8. 绿幕与白模

### 绿幕

```text
将@视频1的绿幕主体自然合成到@图1/@视频2的[新场景]。完整保留主体动作、轮廓、发丝/半透明材质与时序；彻底去除绿色背景和绿色溢色。根据新场景重建主光、轮廓光、接触阴影、反射、景深、运动模糊和空气透视；主体比例、地面接触点、透视和相机运动与背景一致，不漂浮、不抖动、不闪边。
```

### 粗颗粒白模

```text
@视频1是粗颗粒白模，只参考运镜、动作、动线、站位、光影变化和节奏。将白色[形状/模型]映射为@图1的[角色A]，将[另一模型]映射为@图2的[角色B/道具]。按白模顺序执行[完整动作序列]；场景使用@图3。最终画面采用[风格、材质、光影]，完全去除白模质感、辅助线和坐标信息，角色一致、不穿模、不变脸。
```

### 细颗粒白模

```text
将@视频1的细颗粒白模动画渲染为最终成片。
[00:00–00:05]：[场景、色调、主体材质、光影与特效]
[00:05–00:11]：[转场触发点、转场后场景、材质变化]
全程保持模型结构、动作、运镜和比例不变；移除轨迹线、坐标线和相机锥体；使用[PBR/HDR/体积光/商业布光等]；声音为[要求]。
```

## 9. 无缝转场与多宫格

### 两段视频无缝连接

```text
将@视频1和@视频2无缝衔接，禁止修改两段原视频主体内容，只生成两者之间的过渡。@视频1结尾的[物体/动作]以[方向与速度]接近并填满画面；在衔接点保持其形状、位置、大小和运动方向一致，同时材质/颜色逐渐变化为@视频2开头的[对应物]。场景从[A]自然变化为[B]，情绪从[情绪A]过渡到[情绪B]。镜头连续平滑，无黑屏、硬切、跳帧、闪烁、文字、Logo 或字幕。
```

### 多宫格分镜

```text
@图1为完整[九宫格/多宫格]电影分镜，共包含[N]个连续镜头；每格代表一个完整镜头，而不是独立角色或场景设定图。角色A参考@图2，角色B参考@图3，场景参考@图4。

镜头1（00:00–00:03，对应第1格）：[景别、机位、构图、运镜、动作、声音、结束状态]
镜头2（00:03–00:06，对应第2格）：从镜头1的[结束状态]接续，[具体内容]
……

严格按分镜顺序，保持时间、空间、角色位置、动作方向和光线连续；线稿只控制构图与调度，最终画面按[视觉风格]渲染。
```

## 10. 常用收束句

按需选取，不要全部堆叠：

- 保持角色脸、发型、服装、体型与核心道具全片一致，不换脸、不变装、不增减人物。
- 保持镜头前后空间方位连续，角色不瞬移、不重置站位，物体不凭空出现或消失。
- 动作遵循真实重力、惯性、碰撞与反作用力，肢体不穿模、不扭曲、不多手多脚。
- 保持材质、天气、光线方向、色温与阴影连续，画面不闪烁、不跳色。
- 纯净视频，全程无字幕、无Logo、无水印、无乱码；[无BGM/仅保留环境音与动作音效]。
- 转场必须由明确动作、遮挡物、相似形状或镜头运动触发，禁止生硬跳切。
