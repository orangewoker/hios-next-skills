# 职场风云风（Workplace Drama）分镜指令库

> **主打风格**：冷调都市质感、玻璃与金属的反射、强调空间层次和权力关系的视觉表达。
> **加载时机**：`/分集 {N}` Phase 2 时，若题材判定为职场 / 商战 / 行业 / 逆袭，加载本文件复用分镜。

| 分镜名称 | 完整指令 |
| -------- | -------- |
| **会议室对峙** | 长焦压缩构图，会议室冷白色LED灯照射。巨大的玻璃圆桌倒映着天花板的灯阵，两侧各坐三人形成对称的对抗阵势。焦点锁定在会议桌正中央的一份文件上——一只涂着红色指甲油的手和一只戴着机械腕表的手同时伸向文件。背景是落地窗外的城市天际线，云层在玻璃上投下移动的暗影，如同棋盘上流动的局势。 |
| **电梯偶遇** | 极窄的封闭空间构图，电梯内冷调镜面反射。镜面不锈钢内壁映出三个人的多重视角，狭小的空间被放大。男主靠在轿厢角落，领带松了半截，眼底有青色的疲惫阴影。女主站在对面，盯着跳动的楼层数字，两人的视线在镜面中短暂交汇又迅速移开——电梯的轻微晃动感让整个画面有一种"悬在半空"的不安。 |
| **加班独坐** | 大广角，深夜写字楼的暖黄台灯光与落地窗外的深蓝夜空形成强烈冷暖对比。空旷的办公区只剩一盏台灯亮着，光影中尘埃缓慢飘浮。女生蜷缩在办公椅上，电脑屏幕的冷蓝光打在她疲惫的脸上，桌上堆着咖啡杯和外卖盒。窗外是无尽的城市灯火，玻璃上倒映着她孤独工作的身影——城市那么大，此刻只有她一个人。 |
| **辞职递信** | 过肩近景，清晨办公室的自然漫反射光线。镜头从男主的肩膀后方拍摄，他的手微微颤抖地将一个白色信封放在办公桌上。对面的女老板正低头签字，笔尖顿了一下，缓缓抬起头——镜片后的目光从信封移到男主脸上，嘴角勾起一个意味不明的弧度。信封在白色桌面上投下一小片阴影，像一道不可逾越的界线。 |
| **天台解压** | 侧面中景，傍晚的"蓝调时刻"光线。写字楼天台的围栏上搭着一件西服外套，男主坐在水泥台阶上，领带扯下来搭在膝盖上。他仰头灌了一罐啤酒，喉结上下滚动。风吹过来，他的头发被吹乱——远处是渐次亮起的城市灯火和正在变紫的天空。他掏出手机看了一眼屏幕，又塞回口袋，对着空旷的天际线长出了一口气。 |
