# 可选创作配置

获取文章内容后读取本文件。目标是让用户能够选择配置，同时避免一次抛出过多问题。

## 收集规则

- 一次只问一个编号选择题，收到回答后再问下一项。
- 用户已提供某项配置时直接记录并跳过，不重复确认。
- 不使用开放式问题收集视频风格、封面风格、时长、画幅、配音、字幕、音乐或交付阶段。
- 用户说“你决定”“直接生成”或“用默认”时立即使用默认值，不继续提问。

## 第 1 问：配置方式

1. **快速默认** — 约 90 秒、9:16、内容自适应视频风格与封面风格，直接生成视频文件和独立封面图片两个结果
2. **只选视频与封面** — 只选择视频风格和封面风格，其余使用默认值
3. **完整自定义** — 逐项选择风格、时长、画幅、素材比例、配音、字幕、音乐和交付阶段

选择 1 时停止配置提问。选择 2 时只执行“视频风格”和“封面风格”。选择 3 时按下列顺序逐项询问。

## 视频风格

读取 [视频风格](video-style-options.md)，向用户展示其中 8 个编号选项。

## 时长

1. **30 秒** — 单一观点或强钩子
2. **60 秒** — 紧凑知识解说
3. **90 秒** — 默认，兼顾信息和节奏
4. **180 秒** — 完整教程或案例
5. **根据内容自动决定**

口播始终不得超过 1000 个汉字。

## 画幅

1. **9:16 竖屏** — 默认，短视频平台
2. **16:9 横屏** — 视频号横屏、B 站或演示
3. **3:4 竖版** — 小红书图文式封面或特殊发布需求
4. **1:1 方形** — 信息流或多平台复用
5. **根据平台自动决定**

视频封面默认跟随视频画幅，不单独改变比例。

## 原文图片使用方式

所有选项都必须使用与正文相关且可访问的 Markdown、本地和 CDN 图片，不提供“完全不使用原图”选项。

1. **原图证据优先** — 在原文对应论点处展示，其他镜头可生成补充素材
2. **原图主导** — 原图、截图和图表占主要画面时长，建议达到 60% 以上
3. **图文平衡** — 默认，原图与生成画面均衡组合
4. **根据文章自动决定**

## 封面风格

读取 [封面风格](cover-style-options.md)，向用户展示其中的编号选项。用户只选择风格时，其余封面细节由对应模板决定；用户明确要求“细调封面”时才继续逐项收集人物、动作、素材、背景、字体、颜色和标题。

## 配音

1. **温和女声**
2. **清晰活力女声**
3. **沉稳男声**
4. **年轻活力男声**
5. **中性自然旁白** — 默认
6. **无配音，仅音乐和字幕**
7. **根据内容自动决定**

## 字幕

1. **关键词大字高亮** — 默认，适合知识短视频
2. **干净标准字幕** — 信息克制、阅读稳定
3. **步骤卡片字幕** — 适合教程和清单
4. **综艺贴纸字幕** — 适合轻松、测评和种草
5. **无字幕**
6. **根据视频风格自动决定**

## 音乐

1. **轻科技节奏**
2. **轻快活力**
3. **温暖分享感**
4. **沉稳纪录感**
5. **克制商务感**
6. **无背景音乐**
7. **根据内容自动决定** — 默认

## 交付阶段

1. **直接生成视频和封面** — 默认
2. **先看口播**
3. **先看口播、素材清单和分镜**
4. **先看封面制作卡** — 先确认封面标题、风格、主体、构图、字体和配色

选择 2—4 时停在指定阶段，等用户确认后再继续。
