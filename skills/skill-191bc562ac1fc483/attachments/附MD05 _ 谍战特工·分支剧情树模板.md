## 八、附MD05 | 谍战特工·分支剧情树模板

```markdown
# 附MD05 | 谍战特工·分支剧情树模板

**所属主SKILL：** 谍战特工 | 上架Steam的互动影游  
**版本：** V2.0 融合合规版

## #做什么

本模块为“谍战特工 | 上架Steam的互动影游”的专属分支剧情树模板。

解决互动影游“剧情线混乱、分支无收束、假选项泛滥、路径无法抵达结局”的痛点。通过统一的节点命名规范、严密的三幕结构与收束铁律，确保所有分支最终收束回主线，每条路径都能抵达结局，零死胡同。

## #需要什么输入

**最少提供：**
- 主线剧情节点清单（N01-N08）
- 核心抉择点设计与变量影响
- 路线设计（地下党线/军统线/双面线/隐藏线）

**可选提供：**
- 结局数量与路径偏好
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律
本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。分支剧情树环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则，确保所有分支逻辑闭环。

### 二、节点命名规范（强制执行）
1. 主线剧情节点：N+两位数字，如N01、N02、N05、N06。
2. 路线节点：N+两位数字+路线代号，如N05A、N06B、N07C。
3. 好结局/普通结局：E+两位数字，如E01、E02、E03、E04、E05。
4. 坏结局/死局：D+两位数字，如D01、D02至D10。
5. 变量初始化节点：StoryInit。
6. 结局判定节点：ENDING_CHECK。
7. 核心铁律：所有节点ID、视频文件名、代码中的引用必须100%完全一致，严禁中文、空格、字母O混入数字0。

### 三、剧情树核心结构（发散-回流-锁定-再发散）

1. N01 开场·潜伏任务（start节点）
2. N02 抉择点1·初入敌营（branch节点）
   - N02A 隐忍低调，暗中布局（获得密电码本）
   - N02B 主动出击，直面试探（增加身份暴露度）
3. N03 核心情报浮现（normal节点）
4. N04 抉择点2·第一次博弈（branch节点·核心）
   - N04A 选择地下党线（锁定地下党线）
   - N04B 选择军统线（锁定军统线）
   - N04C 选择双面线（锁定双面线）
   - N04D 选择隐藏线（需前置道具）
5. N05A/B/C/D 情报判定（normal节点）
6. N06A/B/C/D 抉择点3·阵营质问或反派试探（branch节点）
7. N07A/B/C/D 抉择点4·谍战博弈收尾（branch节点）
8. N08 抉择点5·最终一搏（branch节点）
9. ENDING_CHECK 结局判定
   - E01/E02/E03/E04/E05 正结局
   - D01-D10 坏结局

### 四、分支收束铁律（核心铁律）
1. 每一章末尾必须收束回主线，防止分支指数爆炸。
2. 关键选择后路线锁定，不可逆。
3. 单章分支层级不超过3级。
4. 每条路径最终抵达结局，无死胡同。
5. 零假选项：每个选择必须改变至少一项变量或后续节点。
6. 所有路径必须能抵达结局，不允许无限延伸。

### 五、谍战特工专属分支模板

#### 第一幕：潜伏（N01-N04）
1. N01：潜伏任务，特工潜入敌方特务机关。
2. N02：抉择点1，特工对局势的态度。
3. N03：核心情报浮现，特工获得关键情报。
4. N04：抉择点2，第一次博弈，四条路线选择，锁定后续走向。

#### 第二幕：博弈（N05-N06）
1. N05A：地下党线·情报判定·上线降临，情报值+40·信任度+25。
2. N05B：军统线·情报判定·军统联络人沉默，情报值+30·军令+30。
3. N05C：双面线·情报判定·敌方头子震惊，情报值+20·双面+20。
4. N05D：隐藏线·情报判定·神秘势力降临，全员信任+20·身份暴露度+20。
5. N06A：地下党上线质问身份，选择A1/A2/A3，影响忠诚值。
6. N06B：军统联络人要求回报，选择B1/B2/B3，影响军令值。
7. N06C：敌方头子私下试探，选择C1/C2/C3，影响双面值与道具。
8. N06D：隐藏线全员试探，选择D1/D2/D3，影响全员信任。

#### 第三幕：收束（N07-N08）
1. N07A：地下党阵营施压，选择A1/A2，影响信任度。
2. N07B：军统出手阻挠，选择B1/B2，影响军令值与人物关系。
3. N07C：敌方头子真相摊牌，选择C1/C2，影响双面值。
4. N07D：隐藏线全员摊牌，选择D1/D2，影响任务进度。
5. N08：最终一搏，选择A再博弈一次；选择B收手；选择C全员豪赌。
6. ENDING_CHECK：根据所有变量与路线自动判断。

### 六、结局路径示例（以E04家国天下为例）

N02B 主动出击（身份暴露度+10）  
→ N04D 参悟·双面档案（情报值+20·全员信任+20）  
→ N06C-2 反问堵住敌特（身份暴露度-20）  
→ N07C-2 抬头直视敌特微笑（获得双面档案）  
→ N08C 全员豪赌（情报值+30·全员信任+30）  
→ E04 家国天下（全员信任≥20·双面档案=true）

### 七、灵魂七问（每个抉择点必须过审）
1. 玩家为什么选它？（动机）
2. 它改变了什么？（信息/关系/资源/风险/路线）
3. 即时后果是什么？
4. 延迟后果在哪个后续节点出现？
5. 是否可能造成独特失败或隐藏路线？
6. 是否只是换台词而没有剧情差异？（绝不允许）
7. 是否与角色动机和世界规则一致？
