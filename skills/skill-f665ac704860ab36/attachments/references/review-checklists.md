# 审计清单、验收评分与根因路由

## 1. 阶段1 物理与叙事审计（逐镜清零）

1. 道具去向闭合：交出、损毁、遗留必须有画面或声音交代；交出者不得回原处；
2. 机位物理存在：机位在场景地理卡上站得住；
3. 装造过渡有承接：发型/服装/伤口/湿度跨镜变化有中间态或时间跳跃标记；
4. 变形期人身位置有解：变身时人在哪、被什么接住；
5. 跨段声音不重复：段尾声音事件与下段开场不撞（刻意母题除外，需登记）；
6. 知识链无泄露：角色不得在获知前表现已知；
7. 读数单调：倒计时/时钟/里程只按剧情方向变化；
8. 轴线登记：对话轴、行进方向、画外视线逐场景声明。

## 2. 验图（关键帧/资产回传）

逐项检查：身份对canonical（眼距/鼻梁/嘴型并排比对）、标记侧、造型态、手与道具、场景地理、轴线视线、构图可剪性、光线影调、文字路线、风格指纹。输出 `pass|conditional_pass|fail`＋失败项归链。

## 3. 验片（视频Take回传）

在验图项基础上加：动作因果完整、起止状态符合acceptance_criteria、无身份漂移帧、无违规文字、声底符合audio_route、时长与把手达标。conditional_pass须列后期可修项。

## 4. 八链逐链检查点

身份：五官/体型/标记侧｜装造：发型/服装/伤污湿｜道具：持有人/位置/数量｜空间：地理/方向/轴线/出入口｜时间：时刻/天气/光线/读数｜声音：声场/承接/母题登记｜知识：谁知道什么/何时得知｜情绪：基线/转折动机。

## 5. 根因路由表

症状根因层级首选修法换镜变脸/身份漂移资产回canonical重锚，重编译关键帧方向或镜像错关键帧朝向加锁重出首帧，标记侧写入排除变身糊/跳变提示词诊断版细分时间片或拆触发镜＋结果镜道具凭空增减剧本修镜头表交接，广播受影响段文字乱码路线改后期叠字，生成端只出干净载体动作乱/接触失败提示词单一主动作化，拆镜或加遮挡全段风格漂资产/合同核style_line是否被稀释，重发空间锁多次重抽无效节点能力校准后换路线或降级fallback

失败升级：①收紧动作与结束状态 ②重建关键帧 ③拆镜/降复杂度 ④换能力路线 ⑤回剧本层。每级一次机会，超预算止损。

## 6. 成片级交付自检（阶段5）

时长≥30s｜情节起承转合完整｜剪辑切点服务节奏＋必要转场｜音乐重音对齐切点｜中英双语字幕齐全且在安全区｜影调统一暗部有细节｜精确文字全部后期路线完成｜恢复快照已导出。
