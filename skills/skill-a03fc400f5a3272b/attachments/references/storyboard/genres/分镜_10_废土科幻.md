# 废土科幻风（Wasteland Sci-Fi）分镜指令库

> **主打风格**：高反差光影、机械冷硬感与末日废土的破败感，视觉冲击力极强。
> **加载时机**：`/分集 {N}` Phase 2 时，若题材判定为废土科幻 / 末日 / 赛博朋克，加载本文件复用分镜。

| 分镜名称 | 完整指令 |
| -------- | -------- |
| **霓虹审讯** | 极近特写，冷蓝与暗红交织的霓虹顶光。生锈的审讯椅上，短发女佣兵双手虽被电磁光环锁死，身体却极具侵略性地向前倾，机械义眼的金属接缝处渗出黑色机油，眼神桀骜不驯地怒视镜头，背景是模糊闪烁的全息警报灯，压迫感极强。 |
| **沙海拾荒** | 超大远景，黄昏时分的漫反射逆光。漫天黄沙中，一座倾颓的巨型齿轮建筑投下巨大的斜影。戴着防毒面具的少年艰难攀爬在风化的钢筋上，粗糙的帆布斗篷被狂风吹得猎猎作响，极具末日孤寂感。 |
| **地下黑市** | 过肩主观镜头，高对比度的单侧伦勃朗光。拥挤潮湿的地下集市，水洼倒映着荧光招牌。前景是主角穿着磨损皮夹克的宽阔肩膀，焦点在对面的机械改造人摊主身上，摊主正递过来一支发着幽绿光芒的血清，周围蒸汽弥漫。 |
| **飞行舱坠落** | 倾斜构图，刺眼的红色警报闪光。狭窄的驾驶舱内，失重状态下杂物悬浮半空。驾驶员被安全带死死勒在座椅上，额头青筋暴起，双手死死拉住操纵杆，护目镜上倒映着急速放大的地面废墟，生死一瞬的极度紧张。 |
| **雨夜觉醒** | 俯拍中景，冰冷的月光与路灯混合冷调。暴雨倾盆的巷道底端，仿生人少女蜷缩在垃圾堆旁，水滴顺着她苍白通透的硅胶面颊滑落。她缓缓抬起残破的机械左臂，指尖亮起微弱的蓝色启动光束，充满破碎与重生感。 |
