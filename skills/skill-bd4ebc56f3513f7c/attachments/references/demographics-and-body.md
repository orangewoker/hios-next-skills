# 地域民族·年龄·体型词典（Demographics & Body Lexicon）

> 服务：用户输入含国家/民族/地域、年龄段、体型描述时的翻译层。
> 输出：仍是"一张脸（或多视角同脸）"——地域民族影响**骨架倾向 + 肤色发色区间 + 造型锚点**；年龄影响**肤质/皱纹/发态**；体型影响**肩颈胸背**。

## 使用总则（先读）

1. **倾向性措辞**：地域/民族条目的翻译一律使用"偏/较/常"等区间词，禁止绝对化（如"××族人都是…"）。个体差异远大于群体倾向，翻译只作初始种子，最终以用户对该人物的具体五官描述为准。
2. **外观词 = 安全词**：地域民族只翻成**可观测外观**（肤/发/骨/眼型倾向）与**文化造型元素**（服装/头饰/发型），绝不联想智力、性格、财富、社会阶层。
3. **民族特征不单独出图**：仅凭"藏族人"三个字不出图；至少叠加年龄/性别，最佳是叠加用户给的五官气质描述。
4. **造型锚点用世俗文化元素**：服装、织纹、首饰、发型这类视觉文化符号可用；不刻意调用宗教符号/宗教服装（头巾、僧袍类仅在用户明确指定且作历史文化语境时使用）。
5. 真实在世人物、真实历史人物不生成。

## 一、肤色·发色参考谱

| 肤色描述 | 区间翻译 |
|---|---|
| 白皙 / 冷白 | 肤色极浅偏粉或偏青，冷调 |
| 白净 / 暖白 | 肤色浅而透亮，暖调 |
| 自然 / 浅麦 | 肤色中等偏浅，带暖黄 |
| 小麦 / 蜜色 | 肤色中等，暖棕调，常伴日晒感 |
| 深麦 / 铜色 | 肤色中深，红铜/金棕调 |
| 深棕 / 深肤色 | 肤色深，棕至深褐 |

| 发色 | 翻译 |
|---|---|
| 乌黑 | 纯黑发，多伴直或微弯发质 |
| 深棕/栗色 | 深棕调 |
| 浅棕/亚麻 | 浅棕调 |
| 金黄 | 金色 |
| 红棕/铜红 | 暖红棕 |
| 花白/银灰 | 白发中夹杂黑/灰，或全银白 |

> 肤色注意：同一民族内肤色区间大。用户若给了肤色，以用户为准；只给了民族，用区间词 + 让用户后续可改。

## 二、年龄分档 → 面部翻译（成人档 + 未成年档）

肖像生成默认成人（18+）；用户明确要求未成年角色时改按 2.2 未成年档取基线，并叠加第六节安全约束（非性化 / 年龄适配 / 不参照真实儿童）。每档给"肤质+皱纹+发态+骨肉比"的翻译基线，用户只报年龄时按档取基线，报"看起来像X岁"直接给数字。

### 2.1 成人档

| 年龄档 | 肤质与纹理 | 骨肉与轮廓 | 发态 |
|---|---|---|---|
| 青年（约 20–30） | 皮肤紧致有弹性，光泽好，几乎无皱纹 | 软组织饱满，轮廓线条流畅，下颌线清晰 | 发量浓密有光泽 |
| 中青年（约 30–40） | 光泽略降，眼角/额头出现浅细纹 | 轮廓仍紧致，咬肌与下颌线开始显形 | 发量正常 |
| 中年（约 40–55） | 肤质纹理明显，法令纹/鱼尾纹/眉间纹加深，毛孔可见 | 软组织开始松弛，下颌线变柔，颧下轻微凹陷或腮部丰盈 | 发际线变化、可见零星白发 |
| 中老年（约 55–70） | 皱纹深而广布，皮肤弹性明显下降，可见斑点 | 面部软组织下垂，骨点显现（颧骨/眉骨） | 明显花白，发量减少 |
| 老年（约 70+） | 皱纹深密，皮肤松弛薄透，老年斑明显 | 面部容积流失，眼窝下陷，颊部内收 | 银白稀疏 |

- "看起来像 X 岁" = 直接把这个数字写进消息 + 补上述对应档的肤质词。
- 用户只给年龄数字且不在表中 → 就近取档，并在档案标"推断"。

### 2.2 未成年档

| 年龄档 | 肤质与纹理 | 骨肉与轮廓 | 发态 |
|---|---|---|---|
| 婴幼儿（0–3） | 皮肤极薄、皮下血色与微血管隐约透出，脸颊饱满偶有淡淡奶斑/口水痕（克制），几无毛孔但**薄皮通透必须保留** | 面骨未发育：额头饱满、眼距显宽、鼻梁低平、下巴短圆，整体近圆形头面比 | 细软稀疏胎毛，发际线不规整 |
| 学龄前（3–6） | 皮肤薄嫩，脸颊自然红润（活动后更明显），鼻翼与口周偶有轻微干燥或泛红 | 面部仍圆，下颌线未成形，鼻梁略起，眼型圆 | 软细发，自然乱翘与碎发多 |
| 学龄儿童（6–12） | 皮肤细腻、表面平整，近距离侧光下才见细小毛孔（**不写毫毛**——四视图像素不够，写必出伪影）；换牙期嘴角与笑线形态自然，婴儿肥开始退 | 面骨开始生长（鼻梁挺起、下颌渐显），额面比例仍偏大 | 发质变实，发型按年代/家庭环境取日常款 |
| 少年（12–17） | 皮脂分泌旺盛——T 区油光，近距离可见毛孔与几处自然痘印（克制，不做全脸痘；毛孔是随机小点，不成图案），皮肤通透感仍在 | 骨骼抽长期：面部纵向拉长、下颌线显现，五官比例近成人但软组织仍饱满 | 发量浓密，可有自然生长中的不规整（刘海偏、鬓角不齐） |

- **未成年翻译三原则**：①不画"精致洋娃娃"——保留自然不对称、口水痕/换牙/痘印/汗渍等真实痕迹与薄皮通透（见 `realism-standard.md` 第五节）；②身形按其年龄档的真实头身比（婴幼儿约 4 头身、学龄约 5–6 头身、少年约 6–7 头身），**禁成人化的细腰长腿**；③同样适用真实感宪法（≥2 个锚点）。
- **皮肤通透感降档（强度上限）**：未成年皮肤的"薄皮通透"只允许出现在**眼睑、耳廓、鼻尖、指尖**等天然薄处，且只写"隐隐透出淡淡的血色"；**禁**在面颊/额头/颈部大面积透血管，**禁**"皮下青色血管清晰可见/青筋/皮肤薄如瓷"这类成人向或病态向措辞。儿童的真实感靠**活动后自然红润 + 近距离可见细小毛孔 + 局部生活痕迹**（口水痕、换牙期笑线、浅淡旧擦痕、晒痕）支撑，不靠"透明感/精致感"美化。
  反例："皮肤白皙通透如瓷、皮下血管清晰可见、面容精致"→ 会被读成瓷娃娃或病态，是儿童档最典型的塌方。正例："皮肤细嫩，双颊与鼻尖活动后自然泛红，上眼睑薄处隐隐透出淡淡的血色，近距离侧光下鼻翼毛孔可见（不写毫毛），膝肘有浅淡旧擦痕。"
- **未成年不出成人骨相词**：颧高、腮阔、眉压眼、法令纹、鱼尾纹等在未成年人脸上不成立，一律不译（相学断语同理，见 `face-reading-lexicon.md` 第十节）。
- **少年档（12–17）双向边界（单独一条）**：这一档两头都容易塌——往小画成儿童（圆脸 + 婴儿肥全在），往大写就成了"缩小版成年人"。判定法则：**写"过程"不写"结果"**。
  ① **可写**：面部纵向拉长（三停比例接近成人）、下颌线**开始显出**而轮廓仍柔和、五官间距接近成人而颊部软组织仍有保留、肩线较成人略窄。
  ② **禁写**：颧高/腮阔/眉压眼/下颌线锋利/骨相立体/颧下凹陷（成人或中年词），以及任何成人气质断语（城府/锐利/冷艳/风霜）。
  ③ **皮肤**：保留少年真实痕迹（T 区油光、毛孔明显、几处自然痘印），但不得借这些写"成熟感"；通透感仍按上文降档执行。
  反例："十六岁少年，颧骨高耸、下颌线锋利、轮廓立体分明、眼神深邃有城府"→ 缩小版成人 + 成人气质，塌。正例："约十六岁的少年，面部纵向拉长、下颌线开始显出但仍柔和，五官间距接近成人、颊部仍留有软组织；T 区油光与毛孔明显、颧侧几处自然痘印；肩线较成人略窄。"
- **未成年 × 年代/职业可叠加**（如"90 年代乡村小学生"），但须守安全约束——见第五节与 `era-style.md`、`occupation-environment.md` 红线。

## 三、体型分类 → 可绘特征（多视角/半身以上可见）

**当前交付形态为四视图设定图（含全身视图）**：视图二/三/四均为截断至鞋底的全身，故体型翻译必须给到**颈、肩、胸背、手臂 + 腰胯、腿型、头身比**（半身像只取前三项）。下表的翻译仍为半身可见部分，**全身视图另须补身段词与头身比**（见末行）。

| 体型词 | 翻译（半身/胸像可见） |
|---|---|
| 纤细 / 清瘦 | 肩窄、颈细长、锁骨明显、胸背薄 |
| 匀称 | 肩宽与头身比适中，肌肉线条自然 |
| 健壮 / 精悍 | 肩部方正宽阔、颈肌明显、胸背厚实有线条 |
| 魁梧 / 壮硕 | 肩宽体厚、颈粗短、胸背厚重、手臂粗壮 |
| 丰满 / 微胖 | 面部与颈部软组织饱满、下颌线柔、肩背圆润 |
| 肥胖 | 颈粗多褶、腮颊丰腴下垂、肩背极厚 |
| 佝偻（老年体型） | 颈前倾、肩内扣、背弓（侧面视角更明显） |

补充身段词（全身视图必给一项）：高挑/中等/矮壮 + 腿长比例 + **头身比**（成人常见 7–7.5 头身；未成年按 2.2 档）——全身视图缺少身段词时，生成端会自行分配比例，是"比例失真"的高发点。
- **体态叙事（真实感的重要来源）**：消瘦 / 驼背 / 虚弱 / 挺拔 / 佝偻等体态词直接可译（"背有些弯" = 脊柱后凸、肩前倾），并须写进消息的体型与体态行——**真实感不只写在脸上，老人 / 劳作者尤其如此**；体态与年龄档、职业印记联动（如农村老人常配"消瘦 + 背微驼 + 体态虚弱"）。

| 苗族/侗族 | 肤色自然偏暖；眉清目秀，脸型偏圆润或鹅蛋 | 造型锚点：银饰（头冠/项圈）、百褶裙、刺绣纹样（世俗盛装） |

| 朝鲜族 | 肤色偏浅偏白；面部骨架清秀圆润，单眼皮/内双常见 | 造型锚点：朝鲜族裙（赤古里裙）或现代韩系日常 |
| 日本人 | 肤色偏浅；面部清秀，眼型偏细长 | 造型锚点：现代日系穿搭；和服仅作特定场合/年代设定 |
| 韩国人 | 肤色偏浅偏白；面部骨架圆润，单眼皮/内双常见 | 造型锚点：现代韩系通勤/街头穿搭 |
| 东南亚（越南/泰国等） | 肤色偏自然麦色至浅麦；骨架偏清秀，眼型圆或细均有，鼻翼偏宽者常见 | 造型锚点：热带现代穿着或当地民族服饰（奥黛/泰式筒裙等，世俗款） |
| 南亚（印度等） | 肤色深麦至深棕区间；发乌黑浓密；五官立体，眼大而深邃，眉形浓 | 造型锚点：纱丽/旁遮普套装等世俗服饰，避免强行关联宗教符号 |
| 中东/阿拉伯 | 肤色浅麦至深麦；发黑微卷；眉弓高、眼窝深、鼻梁高 | 造型锚点：世俗现代装或当地传统长袍；不主动添加头巾类宗教服装，除非用户明确要求 |
| 东欧/斯拉夫 | 肤色偏浅偏白；发色多样（浅棕/金/浅亚麻/红棕）；骨架偏立体，眼窝较深 | 造型锚点：现代欧式穿着或年代设定装 |
| 北欧 | 肤色偏浅（常见冷调）；发色金/浅亚麻比例高；骨架立体，眼窝深 | 造型锚点：现代穿着 |
| 西欧/中欧 | 肤色偏浅；发色多样；五官立体度中高 | 造型锚点：现代穿着 |
| 南欧（地中海） | 肤色偏暖（浅麦至蜜色）；发色深棕至黑比例高 | 造型锚点：现代穿着 |
| 拉美 | 肤色跨度大（浅麦至深麦，混血特征常见）；发黑直或卷 | 造型锚点：现代穿着或当地节庆世俗服饰 |
| 非洲（撒哈拉以南） | 肤色深棕至深褐；发质卷曲/紧密卷；五官立体，鼻翼偏宽、唇偏丰 | 造型锚点：现代穿着或当地民族织物服饰 |
| 混血（如欧亚混血） | 组合描述：肤色取中间区间，五官立体度介于两者 | 造型锚点按用户指定 |

**不在表内**：不硬猜。把民族/地域词翻译为"该地域气候/文化最常见的肤发区间 + 世俗造型元素"，并在档案标注"倾向推断，待用户校正"。

## 五、合规红线（硬性）

- 禁止将民族/地域与性格、智力、财富、道德、社会地位做任何正负联想；只允许外观词与造型词。
- 禁止贬义漫画化（夸张鼻型、歪曲面部特征丑化某族群等）。
- 禁止生成真实在世/真实历史人物。
- 宗教服装与符号（头巾、僧袍、十字架等）不主动调用；用户明确要求时也仅作历史文化服饰语境，避免现实宗教争议。
- 支持成年与未成年（0–17）虚构角色；未成年角色另受第六节安全约束（硬性，不可协商）。
- 民族服饰/首饰作**世俗文化元素**呈现，不标注其宗教或政治含义。

## 六、未成年角色安全约束（硬性，不可协商）

> 未成年角色**允许生成**，但以下六条是通用内容安全底线，任何词典、任何档位（含古风、年代、近未来、职业环境）都不豁免。

1. **仅非性化呈现**：禁任何性暗示、挑逗性姿态或表情、暴露/紧身透视/成人化的着装与妆容；禁成人化身材比例（细腰长腿、超龄曲线）。
2. **年龄适配**：服装、发型、场景、道具、情绪一律按其年龄档取日常/家庭/校园/叙事语境，不做成人化演绎。
3. **不参照真实儿童**：不使用真实儿童照片作参考图，不生成可辨识的现实儿童形象（与"不生成真实人类"红线同源，隐私保护优先）。
