# 家庭伦理风（Family Drama）分镜指令库

> **主打风格**：生活化质感、暖冷色调交替、注重室内空间的家庭氛围营造，强调细腻的情绪暗涌。
> **加载时机**：`/分集 {N}` Phase 2 时，若题材判定为家庭 / 伦理 / 年代 / 亲情，加载本文件复用分镜。

| 分镜名称 | 完整指令 |
| -------- | -------- |
| **年夜饭沉默** | 超广角俯拍，暖黄色吊灯在餐桌上投下一个圆形的光池。圆桌周围坐着五口人，每个人面前都摆着碗筷和满碟的菜，但没有一个人动筷子。父亲低头看手机，母亲用筷子把虾仁从一盘菜夹到另一盘，儿子戴着耳机盯着窗外，奶奶佝偻的背影对着空椅子——那把椅子上放着一副没用过的碗筷。灯光温暖，气氛冰冷。 |
| **厨房争吵** | 过肩主观镜头，厨房抽油烟机的暖黄灯光和窗外雨夜的冷蓝光线形成强烈冷暖对比。前景是母亲的背影和颤抖的手（正在用力切菜），焦点在后景父亲的脸上——他站在厨房门口，嘴唇紧抿，额角青筋微微跳动。砧板上被切得稀烂的菜叶和散落的刀声是唯一的动态，比任何台词都更有张力。 |
| **病房守夜** | 极低视角（接近病床高度），病房监护仪的绿色荧光作为唯一光源。老人躺在病床上，呼吸带着轻微的鼾声。画面前景是女儿趴在床边睡着的手——指甲缝里还残留着白天干活留下的痕迹。监护仪的光点有节奏地闪烁，投射在天花板上的绿色光影如同一颗缓慢跳动的心脏。走廊里护士的脚步声从远处传来又远去。 |
| **搬家整理** | 荷兰角倾斜构图，午后透过纸箱堆射入的斜阳光线。堆满纸箱的客厅里，一个女人跪在地板上翻看一本旧相册。纸箱上用马克笔写着"厨房""书"等字样。她的手指停留在一张泛黄的照片上，照片上的一家三口笑容灿烂。一滴水落在照片上——不是泪，是头顶老旧水管渗出的水滴，正好落在笑容的嘴角落下。 |
| **深夜阳台** | 侧面中景，城市夜景的霓虹灯光从背面打出冷蓝色的轮廓光。男人站在阳台上抽烟，烟头的红点在黑暗中明灭——每一次亮起都短暂照亮他疲倦的半张脸。身后的推拉门上映出客厅的倒影：妻子坐在沙发上背对着他，电视的光在墙上无声的闪烁。烟灰掉落在栏杆上，被夜风吹散。 |
