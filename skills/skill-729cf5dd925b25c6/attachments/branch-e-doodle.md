- 风格块：`style-locks.md` → STYLE_LOCK_E
- 模型（自动匹配）：图像 Seedream 5.0 / 备 Midjourney V7；视频 可灵 Kling 3.0 / 备 Wan 2.6

- 转场：橡皮擦擦除/翻页做成 0.5-1s 转场片段（尾帧图生视频，prompt 描述擦除/翻页运动）

## 关卡衔接（上游已定）

风格样板与调参（G6）、节奏与输出格式（G7）已在上游确认；模型自动匹配。

- 换风格 / 调样板 → 回退 G6 ｜ 调节奏 / 换输出格式 → 回退 G7

**G6 样板图生成**：图片节点 → Seedream 5.0 → STYLE_LOCK_E + 剧本代表性场景，一次出 3 张（简笔人物特写/白板概念图中景/满版涂鸦全景）。

**E 分支精细调参备查（G6 阶段使用）**：

- 画笔工具: 马克笔(粗线条饱和色) / 粉笔(黑板粉末边缘) / 水彩笔(晕染透明叠色) / 铅笔(细灰素描) / 圆珠笔(蓝黑细线笔记感) / 混合(马克笔主体+铅笔阴影+粉笔高光)
- 线条风格: 流畅一笔(干净) / 抖动自然(手绘真实) / 粗犷速写(重叠线/飞白)
- 上色方式: 纯线稿 / 局部填色 / 水墨淡彩(留白+晕染) / 全彩填色
- 背景画布: 白板(纯白现代) / 黑板(深绿黑底+彩粉笔) / 牛皮纸方格本(笔记感) / 透明玻璃板(写字楼) / 墙绘涂鸦墙(砖纹喷漆)
- 手写字体: 出现 / 不出现 / 仅关键词

## G15 — 逐镜视频片段（分批）

```
[关卡G15-E: 视频确认 | 第N/N批]
  ├─ 👤模式
  ├─ ✅/🔄/🎯
  ├─ 🏃运动(偏中慢):
  │    ├─ 镜头: 推近/拉远/平移/固定
  │    ├─ 🖊手绘专属动画(E专属):
  │    │    ├─ 逐笔生长(线条一笔笔画到终点)
  │    │    │    └─ 顺序: 轮廓先→细节后/同时画/随机
  │    │    ├─ 手写文字出现(像有人正在写)
  │    │    │    └─ 书写速度: 快/正常/一笔一划
  │    │    ├─ 圈画强调(画圈→放大→高亮)
  │    │    ├─ 箭头绘制(画箭头→指向→目标突然出现)
  │    │    ├─ 涂鸦上色(线稿→颜色渗入填满)
  │    │    ├─ 橡皮擦擦除(部分擦→改写新内容)
  │    │    └─ 粉笔字抖动(写完的字微微抖动)
  │    └─ 🧑角色(如有): 手在画面书写(第一人称)/简笔走路跳跃/与画面互动
  ├─ 📝手写文字内容: 本镜要写什么(从素材提取)
  ├─ ⏱时长: 默认5s→3/4/6/8s(书写类≥5s)
  └─ 🔢绘制顺序: 轮廓→填充→标注/同时/分步骤
```
