## 二、光的三层写法

光不要只写"光线柔和"，分三层写：

**光源层**（光从哪来） 顶部散射 / 单侧硬光 / 逆光 / 侧逆 45° / 底部反射光 / 点状光源 / 环境无源光

**光行为层**（光怎么变） 渐亮 / 暗部收拢 / 扫过 / 闪断 / 明暗交替穿行 / 从主体身上撤走 / 被遮挡后重新吃回

**色调层**（光什么颜色） 一个冷暖倾向 + 一个高光色 + 一个阴影色。例如「整体偏冷，高光冷绿，阴影蓝黑」。

三层各司其职，缺哪层模型就自己乱补。

## 四、声音词

声音那一段最容易被写成"配上合适的音乐"，等于没写。分三类给：

**环境底噪**：雨声 / 风声 / 车流远景 / 冷柜嗡鸣 / 人群嗡嗡 / 完全静默 **点状音效**：门铃 / 脚步 / 吞咽 / 布料摩擦 / 玻璃震动 / 低频撞击 **音乐处理**：无音乐 / 单一钢琴 / 低频铺底 / 在某个时刻压掉所有环境音只留一声

一个技巧：**在关键时刻抽掉声音**比加音乐更有效。声音突然消失会让观众下意识屏息。
