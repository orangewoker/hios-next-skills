## 物料清单(每项可独立操作)

### 📹 视频成片

- 1080p MP4 (H.264 + AAC, 30fps)
- 根据关卡9确认的格式输出

### 🖼 动态海报包 / 📊 动画PPT

- 根据关卡9确认的格式输出

### 📝 朋友圈文案 ×3

- 三个不同角度话术,适配视频封面
- 调性可选: 专业/亲切/紧迫/幽默/文艺
- 包含: 标题/正文/话题标签/评论区引导
- 字数适配朋友圈折叠规则(≤6行)

### 💬 社群转发话术

- 带钩子的分享文案
- 包含: 痛点引入/价值提炼/行动引导
- 适配企微/微信群直接复制发送

### 📩 1v1 私信脚本

- 给销售/招生顾问用的触达话术
- 包含: 开场白/价值陈述/异议处理/CTA
- 可分场景: 初次触达/跟进/逼单

### 🖼 封面缩略图

- 高点击率设计
- 尺寸支持: 视频号封面/公众号封面/抖音封面

### 🖼 通用海报（5类型 × 3尺寸）

**海报类型**:

1. **活动宣传海报** — 活动主题/时间/地点/报名入口
2. **品牌形象海报** — 品牌理念/视觉大片/品牌色
3. **优惠促销海报** — 折扣/满减/限时/价格锚点
4. **课程/产品介绍海报** — 核心卖点/规格/价格/购买入口
5. **倒计时/紧迫感海报** — 限时/限量/名额/倒计时数字

**尺寸**:

- 1:1 正方形(朋友圈/Instagram)
- 3:4 竖版(小红书/抖音图文)
- 16:9 横版(公众号封面/视频号)

### 📄 落地页文案

- 移动端H5/小程序落地页结构
- 包含: 头图/痛点/方案/优势/数据/案例/CTA

### 📱 公众号推文大纲

- 标题备选(2-3个)
- 段落结构/配图建议/排版风格

### 🌐 多语言版

- 将以上所有文案翻译为英文版
- 可选: 其他语言(日语/韩语/繁体中文)

## 关卡10交互

```
[关卡10: 物料包确认]
  ├─ ✅ 通过 → 交付全部文件,打包ZIP
  ├─ 📋 物料清单 → 选择要/不要哪些
  │
  └─ 逐项细节:
       ├─ 📝 朋友圈文案 → 重写/改调性(专业↔亲切↔紧迫↔幽默↔文艺)
       ├─ 💬 社群话术 → 重写
       ├─ 📩 私信脚本 → 重写/改场景(初次↔跟进↔逼单)
       ├─ 🖼 缩略图 → 重生成/换风格
       ├─ 🖼 通用海报 → 新增/跳过/改类型/改尺寸/改数量
       │    ├─ 海报类型: 活动/品牌/促销/产品/倒计时
       │    ├─ 尺寸: 1:1/3:4/16:9
       │    └─ 数量: 1张/3张(九宫格)/5张(轮播)
       ├─ 📄 落地页 → 新增/跳过
       ├─ 📱 推文大纲 → 新增/跳过
       └─ 🌐 多语言 → 英文/其他
```
