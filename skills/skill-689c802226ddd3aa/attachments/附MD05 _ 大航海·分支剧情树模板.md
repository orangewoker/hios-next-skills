# 附MD05 | 大航海·分支剧情树模板

**所属主SKILL：** 大航海 · 海盗狂潮 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“剧情线混乱、分支无收束”的痛点。

## #需要什么输入

- 主线剧情节点清单。

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·遭遇风暴（start节点）
2. N02 抉择点1·如何应对风暴（branch节点）
   - N02A 冲进风暴眼（船只耐久-20，可能发现宝藏线索）
   - N02B 绕道躲避（消耗淡水食物，浪费时间）
3. N03 发现神秘海岛（normal节点）
4. N04 抉择点2·面对叛变的大副（branch节点）
   - N04A 直接火拼（士气下降，但铲除内鬼）
   - N04B 用金币收买（消耗财宝，士气上升）
5. N05-N08 层层推进（如：海神三叉戟的争夺、皇家海军决战）
6. ENDING_CHECK 结局判定
