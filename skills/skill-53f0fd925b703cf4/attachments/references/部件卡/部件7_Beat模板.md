# 部件卡7 · Beat模板导演指令版（打斗子镜头）

## 每拍句数上限（2026-08-07新增·全段适用·执行层规则）
```
一个节拍（时间块）内句子≤3句（简报原文：max three sentences per beat——
overloaded beats, the model smears 过载的节拍模型会涂抹）。
事件多的段拆节拍，不堆句子。
✅ 事件多→切2拍（每拍2-3句）；❌ 一个节拍塞5-6句=退回。
（与万物生拆拍理念兼容：万物生事件多就切节拍）
```

## 打斗子镜头结构（每子镜头动作事件≤2个）
```
【打斗Beat·导演指令版】
镜头：[景别+机位+运镜方向+节奏定性词，单句]
动作事件1：[谁+什么动作+什么结果（结果级动词）]（节奏括号）
  结果分解：[命中部位崩坏/飞溅/瘫软/环境痕迹/镜头反应，≥2句]
动作事件2（可选）：[同上格式]
打击帧：结果动词 + "拟声词" + （镜头猛地一震）——自然嵌入
接触白名单（近身擦碰时≤1处）：(只接触X不接触Y)
收束（可选）：一句对峙/结果构图 + 伴随音效收束句
HARD CUT → 下一Beat
```

## 示范（雾夜街式）
```
「铁傀蹬地爆发，沿直线猛冲向云游，重踏踩碎湿石板上的水膜（动作快速，每一步落地镜头短促一震）。
长枪直刺她胸前——枪尖到达的一瞬她侧身让开，枪只擦过左肩衣料刺空（枪尖不接触皮肤），
铁傀收不住势头冲过头。」
```
❌ 旧编舞工程版（禁用）：预备[重心变化+蓄力姿态]→执行[路径+速度]→碰撞[双方反应]→附属延迟→恢复。逐动作分解=模型在执行清单不是在演打斗。

## 打击三要素·自然嵌入版
```
① 结果级动词（打飞/干飞/豁开/缠死/扯飞/捏爆）
② "拟声词引号"（"clang""duang""嗖——"）
③ 镜头震（（镜头猛地一震/一顿/一抖）括号 或 短句"画面猛地一震"）
✅ 「长枪脱手砸在湿石板上"clang"一声脆响、镜头猛地一震」
✅ 「一记重拳把它干飞出画，金属挥击与甲壳碎裂的脆响同时炸开、画面剧烈一顿」
```

## 结果分解铁律
动作一句带过，结果分解≥2句。细节预算给后果，不给过程。
✅「精准捏住头部（一句）→ 头壳碎裂、复眼爆裂、体液从指缝炸裂溅出、身体瘫软、残骸坠落（分解）」
❌「重心移至右脚，腰腹带动，肩随后，头最后跟随（过程分解）→ 触及（结果一句）」

## 连续打击规则
攻击方式与命中部位逐次不同（胸→头→腹），靠惯性焊接句衔接（"推进没有减速/拔枪的瞬间利用惯性转向"）。

## 攻防时序
防御启动必须早于攻击停稳。禁"攻击者停稳→防御者才反应"倒挂。
