# 情绪曲线与镜头逻辑（成片补强）

天野流不用传统起承转合，而是**呼吸式情绪曲线（即「无叙事呼吸式」）**——全片统一一个空灵主题，不靠戏剧冲突推进，也不写故事脚本。

---

## 一、双模式情绪曲线

### 线稿模式（呼吸式）
```
静滞 → 微动 → 凝视 → 羽化消散
```
- 静滞：主体悬浮于白，几乎不动
- 微动：发/翼/衣袂开始同向微浮
- 凝视：光环第二次强化，眼神与画外某点静默对望
- 羽化消散：线条尾端渐溶入白，留白吞没主体

### 完成彩稿模式（华美式）
```
华美展开 → 凝滞神性 → 余韵
```
- 华美展开：金线/装饰在黑底上逐层浮现
- 凝滞神性：人物定格，神性疏离达顶点
- 余韵：金箔微光退散，留一丝冷艳

---

## 二、视觉符号重复（首尾呼应）

主符号（翼 / 光环 / 长发 / 月）必须在片中**重复≥2 次**且**首尾呼应**：
- 例：镜1 翼初现（几根线）→ 镜4 翼满展 → 镜末 翼溶入白/金，与开头同一根线呼应。
- 这是 LibTV 2.2.2 风格美学垂类的完整性硬指标（替代五要素）。

---

## 三、镜头语言（运镜动机）

- **无重力缓浮**：推/拉极慢，模拟失重漂浮，非手持抖动。
- **极浅景深**：主体锐、背景气线虚，强化"梦"。
- **溶解转场**：镜间用线条尾端溶解 / 金箔晕开过渡，禁硬切。
- **运镜动机 = 角色漂移或羽落**：镜头随发/翼/衣袂的同向微动而移，**禁无动机随机抖动**（AI 最易犯）。
- 画幅：2.39:1 宽银幕（天野签名画幅）。

---

## 四、情绪段落 × 音乐同步映射（默认空灵 Ambient）

天野流无强节拍，不用传统主歌/副歌结构。剪辑点对齐「情绪顶点」而非「鼓点重拍」。

| 情绪段落 | 视觉 | 与音乐同步 |
|----------|------|------------|
| 静滞 / 铺底 | 主体悬浮留白 | 长镜停留，pad 铺底 |
| 微动 / 初显 | 发翼微浮 + 符号初现 | 偶发钢琴单音咬符号出现 |
| 凝滞 / 顶点 | 凝视 / 华美满展 | 弦乐长音咬情绪顶点 |
| 余韵 / 收尾 | 羽化消散 | 乐句渐隐入混响，溶解收尾 |

---

## 五、红线（风格美学 2.2.2）

- 真实感可放宽（天野梦幻非写实，天然合规）。
- 完整度 = 统一视觉主题 + 情绪曲线 + 符号呼应，不以叙事五要素计（**无叙事呼吸式**）。
- **无台词纯氛围**（默认）：成片不加字幕 / 旁白 / 任何文字，只有画面 + 音乐。
- 六维视听语言：运镜/剪辑点须与情绪/音乐同步（见上），禁无动机随机抖动机位。
