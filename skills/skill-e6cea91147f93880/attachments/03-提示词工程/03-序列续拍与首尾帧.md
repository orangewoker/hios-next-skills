# 序列续拍与首尾帧

## 续拍原则

- 已接受的成片是唯一的真相。
- 不要从计划结尾开始，要从实际末帧开始。
- 不要重放已完成的节拍。
- 不要提前泄露预留的未来节拍。

## 续拍类型

| 类型 | 说明 |
|---|---|
| 无缝续拍 | 同一镜头、同一空间、同一运动延续 |
| 有意下一镜 | 一次剪辑点，不承诺帧连续 |
| 已知状态间桥接 | 首帧→尾帧，生成两者之间的运动 |
| 修复尾部 | 上一段最后几秒失败，先修复再继续 |
| 漂移后重新锚定 | 回到规范参考或最强的已接受末帧 |

## 续拍必需输入

- 项目/镜头 ID
- 父级镜头
- 场景 ID 与场景边界
- 完整故事目标与最终结果
- 下一镜头的叙事任务
- 意图回声（felt_intent）
- 已接受上一镜头或末帧
- 观察到的结束状态
- 连续性锁
- 已完成节拍排除项
- 预留未来节拍

## 正典规则

- 已接受成片优先于计划状态。
- 被拒绝的成片永不更新正典。
- 达到 `max_chain_depth`（默认 2，硬上限 3）时，必须重新锚定。

## 首尾帧（FLF2V）

`@Image1` 为首帧，`@Image2` 为尾帧。提示词只描述：
- 连续转场逻辑
- 摄影机行为
- 灯光连续性
- 音频意图
- 必须保持不变的内容

模板：

```text
@Image1 为首帧，@Image2 为尾帧。保持 [主体/服装/场景结构] 不变。从 [起始状态] 连续移动到 [尾帧状态]，[动作路径]。镜头：[运动或锁定]。灯光：[光源连续性]。声音：[环境声/音效]。约束：不要 [禁止变化]。
```

## 输出契约

1. 续拍类型
2. 来源证据
3. 观察到的结束状态
4. 下一镜头契约
5. 意图回声
6. 连续性锁与允许变化
7. 已完成节拍排除项
8. 预留未来节拍排除项
9. 仅针对当前镜头的最终提示词
10. 更新的项目状态胶囊
