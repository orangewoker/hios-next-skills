# 仙侠新中式基线分析档案（全新第一版）

## 基线结论

参考素材彻底脱离了早期数字修仙图的廉价与虚假感，进化为一套极其注重**“物理真实材质”**与**“仙气氛围”**并重的全新视觉语言。仙侠神话元素（神兽、法器、云海）被锚定在高度写实的光影与纹理之中。背景回归纯净，光线回归胶片的柔和，材质达到微距级别的精细。

## 核心视觉特征转化

### 1. 从“杂乱特效”到“浅暖素净”
- **旧模式**：背景充斥高对比度的雷电、强光、繁复不清的建筑。
- **新基线**：以“浅暖米色柔和素净背景”为主调。无论远景是云还是山，都罩上一层温润的、低饱和的暖光。为海报文字排版和产品KV展示留出了极佳的视觉呼吸感。

### 2. 从“CG光污染”到“复古漫射柔光”
- **旧模式**：强烈的青橙对比、高亮轮廓光（Rim Light）、HDR泛光。
- **新基线**：复古暖调漫射柔光。光线像透过柔光布或云层洒下，没有刺眼的受光面，没有死黑的阴影。高光柔和细腻，带有胶片人像质感。

### 3. 从“塑料贴图”到“超精细实物细节”
- 画面所有物品均为真实物理材质，细节完整无缺失：
  - **织物**：织金绸缎，能看到丝线的反光与金线的厚度。
  - **饰品**：玉石首饰，具有温润透光感和微小的内部絮状纹理。
  - **植物**：鲜花花瓣，展现娇嫩的质地、微小的褶皱与真实的脉络。
  - **奇幻生物**：龙麟兽皮，鳞片有骨质的坚硬感，兽毛蓬松且根根分明。
  - **环境**：绵软云景，像真实的棉花或厚重的雾气，有体积感但无刺眼反光。

### 4. 从“AI网红脸”到“真实自然人像”
- 真人五官，柔和自然，摒弃了过度磨皮、夸张比例和僵硬表情。
- 发丝蓬松，带有真实的毛发纹理，有随风飘动的轻盈感，与胶片摄影中的人物状态高度一致。
- 柔和浅景深：焦点牢牢锁定在人物脸部或核心道具上，虚化背景，增强胶片立体感。

## 适用场景（综合功能）
该风格不仅仅适用于单张插画，其“素净背景”与“高质感细节”非常适合扩展为：
- **影视/游戏宣发海报**：主体突出，背景可自然延展留白。
- **社交媒体页面 (Instagram/小红书)**：网感极佳的复古调色，适合传播。
- **产品统一 KV 视觉图**：可以将美妆、国潮产品替换为画面的视觉中心，神兽与云海作为陪衬。
