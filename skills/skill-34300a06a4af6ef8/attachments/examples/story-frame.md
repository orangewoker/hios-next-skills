# 剧情关键帧示例：花铺挑花

这是一张带人物的生活剧情图，不是空场景底图，也不是全身定妆图。重点是两个人正在做什么以及他们所在的花铺空间。以下是三种表达方式，均不依赖未提供的参考图。

## Image

~~~text
一张16:9横屏中国古装生活题材电影剧照，宋韵江南花铺，街道斜侧方的平视中远景。右侧木铺敞开，粗陶花器和竹篮错落摆在低台上，左侧石板巷向后延伸，铺前留有站立和通行的空间。建筑开口、木柱、摊台和远处行人仍能辨认，前景只保留小段木台边缘。

二十多岁的顾客站在画面左侧，穿米白交领短衫与青灰长裙，头发简洁挽起。四十多岁的女花贩站在右侧，穿淡褐色窄袖布衣。定格在交易尚未完成的一瞬：花贩手持一枝粉色花，把花举在两人之间；顾客低头看花，右手刚抬到花枝附近，尚未接住，另一手自然放在身侧。两人看花与对方的手，身体朝向彼此，神情专注自然。

薄云下的柔和侧前方日光照入铺前，屋檐里面稍暗，反射光让两人脸部和手上的细节可见。衣料有真实厚度、自然褶皱，陶器哑光，粉色花瓣亮部柔和，肤色中性。焦点涵盖两人及手中的花，环境层次清楚，不把花铺化成散景。单张完整画面，无字幕、标题、水印或黑边。
~~~

## Banana

~~~text
生成一张16:9横屏的真人古装生活剧照，场所是宋韵江南街边花铺。先建立清楚空间：摄影机在街道斜侧方平视，木铺与花台在右侧，石板巷从左侧通向后方，两位人物站在花台外侧，彼此之间没有桌案阻挡。粗陶花器、竹篮、少量粉花和木柱构成生活环境，远处行人较小。

只表现一个瞬间：右侧四十多岁的女花贩穿淡褐窄袖布衣，手中仍握着一枝粉色花；左侧二十多岁的女顾客穿米白交领短衫、青灰长裙，右手刚伸向花茎，尚未接触。顾客的视线落在花上，花贩看向顾客伸来的手；两人身体朝向彼此，自然专注，不面对摄影机摆出捧花姿势。

柔和侧前方天光，屋檐内有适度暗部，面部保留温润明暗；粉花、皮肤和浅衣各有细节，衣裙是不透明的真实布料。采用能同时读清两个人、交接位置和花铺结构的景深，亮度和颜色自然，不统一染成金黄。单图，画面填满画幅，不添加字幕、标题、水印或黑边。
~~~
