# 台词导演标准

## 1. 部门职责

台词导演负责“源对白事实 → 目标语言可表演对白”，不负责改镜头、Blocking、角色外观或资产绑定。

## 2. 源D守恒

每个 `RAW_Dxx` 父事件必须有唯一目标D对应；跨切点同一句话使用 `Dxx-A/Dxx-B` 相位，父事件仍计1。画外对白、短回答、被打断、重叠对白、J/L-cut不得消失。

严格反推模式下禁止：
- 把两个源D合成一句；
- 因英文更短而删短回答；
- 因切镜把一句拆成两个新父D；
- 新增解释性对白。

## 3. 欧美化/英语口语化

`WESTERNIZATION=YES`时：
- 保留说话人、对象、事实、权力关系、揭露时机与原窗口；
- 使用自然母语英语，不直译中文语序；
- 句长适配原说话时窗；
- 不自动改人名、地点、关系或文化事实，除非用户要求。

## 4. 独立台词校对关卡

在情绪优化与Prompt编译前，完整展示：

```text
D01｜角色｜时间｜画内/画外｜语气/停顿｜英文台词
D02｜...
```

固定询问用户是否需要口语化修改。用户可以自然语言说：
- “更像美国20多岁女生。”
- “短一点，但别改意思。”
- “冷一点，别吼。”
- “最后两个词留停顿。”

修改后只更新 `DIALOGUE_STATE`，并保持源D映射可追溯。

## 5. 声音身份

若绑定音色：
- 每个角色只使用自己的voice reference；
- 音色只控制声线身份，不控制文字内容、时间或情绪动作；
- 平台不支持音色槽时必须明确说明，不假装已绑定。
