# 附MD02 | 修仙玄幻·角色锚点库

**所属主SKILL：** 修仙玄幻 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“修仙玄幻 | 上架Steam的互动影游”的专属角色锚点库。

解决AI生成修仙玄幻内容时“角色跨镜头换脸、服装漂移、发型不一致、仙魔气质混淆、法宝错乱”的痛点。通过统一的角色锚点规范与跨镜头一致性锁定，确保全片所有角色形象100%一致。

## #需要什么输入

**最少提供：**

- 主角A、主角B、仙尊/帝者、魔道/反派、群像角色的姓名与设定
- 角色三视图 + 面部特写（用户上传或AI生成）
- 角色标志性服装与法宝

**可选提供：**

- 特定服装风格偏好（道袍/仙裙/战甲/龙袍）
- 特定伤痕或战损状态
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。角色锚点环节重点参考【提示词】底座的物理光学参数与【情绪大师】的七层微表情拆解规则。

### 二、角色锚点命名规范

- **格式**：角色名\_角度\_版本号
- **示例**：主角A\_正面三视图\_v1、主角B\_仙裙特写\_v2
- **核心铁律**：所有锚点ID必须在跨节点、跨分支时绝对一致，严禁“同角色两套ID”。

### 三、主要角色锚点

1\. 主角A

- **身份定位**：散修/剑修/帝路争锋者
- **外貌特征**：面部轮廓硬朗，眼神锐利，身形挺拔，黑发束冠或披发。
- **服装**：素色道袍或战甲，材质真实，有磨损感。
- **核心微表情**：下颌紧绷、瞳孔收缩、眉心微蹙、嘴角微收。
- **光影锚定**：主光冷白，逆光仙气金边。
- **锚点ID示例**：i-xxxxxxx（用户上传三视图后替换）

2\. 主角B

- **身份定位**：道侣/羁绊者/宿命同行者
- **外貌特征**：素雅仙裙或劲装，气质空灵或坚定，长发垂落。
- **服装**：飘带自然垂落，仙气环绕，材质真实。
- **核心微表情**：眼眶泛红、嘴角轻抿、视线不离主角A。
- **光影锚定**：柔和侧逆光，暗金点缀。
- **锚点ID示例**：i-xxxxxxx（用户上传三视图后替换）

3\. 仙尊/帝者

- **身份定位**：天庭主宰、仙道至尊
- **外貌特征**：金色龙袍，平天冠，玉珠帘，帝王压迫感。
- **服装**：金砖拉丝质感，龙纹浮动，暗金帝气环绕。
- **核心微表情**：沉默权谋、眼神如刀、嘴角微扬。
- **光影锚定**：顶光金色，暗金帝气环绕。
- **锚点ID示例**：i-xxxxxxx（用户上传三视图后替换）

4\. 魔道/反派

- **身份定位**：魔道至尊、仙魔战场宿敌
- **外貌特征**：深色甲胄或血袍，气质阴冷，与主角形成视觉反差。
- **服装**：暗红魔气环绕，鬼气森森，材质真实。
- **核心微表情**：冷笑、眯眼、目光阴狠、舔血。
- **光影锚定**：暗红魔气环绕，冷光侧逆。
- **锚点ID示例**：i-xxxxxxx（用户上传三视图后替换）

5\. 群像角色

- **身份定位**：天兵天将、魔道修士、仙门弟子
- **外貌特征**：有辨识度但不抢主角戏，五官清晰。
- **服装**：统一风格，细节有差异，禁止黑压压一片无面部细节。
- **核心要求**：必须可被后期虚化处理，禁止背景人物崩坏。

### 四、战损状态锚点（修仙玄幻专属）

1. **初始状态**：道袍整洁，法宝完好，仙气内敛。
2. **中度战损**：衣衫微破，脸上有灰，法力消耗可见。
3. **重创战损**：道袍碎裂，血迹斑斑，仙气微弱。
4. **濒死状态**：浑身血污，眼神涣散，但仍紧握本命法宝。

### 五、跨镜头一致性锁定（核心铁律）

1. 同角色在不同镜头必须用同一人物锚点ID。
2. 所有镜头共用同一套角色锚点库。
3. 情绪切换必须使用同一角色的不同锚点帧，禁止换脸。
4. 服装、配饰、发型、法宝在全片中必须保持绝对一致。
5. 若剧情需要角色换装，必须单独建立新的锚点ID并明确标注。
6. 仙魔气质必须严格区分，禁止仙气变魔气或魔气变仙气。

### 六、生成与合成

根据上述角色锚点与一致性规范，调用底层视频生成Skill，输出MP4视频文件。
