## 任务目标

- 本Skill用于：从题材构思到最终交付的完整AI视频电影制作流程，致敬诺兰IMAX胶片美学
- 能力包含：需求解析与风格路由、叙事结构与导演语法、IMAX摄影工艺方案、去AI感工程与画质锁、逐镜声景设计、七段式镜头整合输出、双重Quality Gate与五重会审

## 调用时先判断模式

完整影片有三种互不合并的模式。在开始分镜或实现前，先判断用户是否已经明确选择；已经选择时直接执行，不重复询问，也不要改成另一种模式。

1. **模板复用模式**：用户点名某风格/参考影片/特定镜头卡时，视为模式已选定。直接按该模板/参考的镜头结构、运镜语法、节奏参数执行，只替换角色/场景/台词，不重新设计视觉方向。
2. **自主自由创作模式**：用户说"你全权决定""直接做""不用问我"时，Agent 从需求解析连续推进到终检，不逐阶段等待确认。用户已有的明确要求始终是约束，不能被 Agent 默认选择覆盖。
3. **共同创作模式**：默认模式。Agent 先提出有依据的判断和方案，由用户依次确认需求解析、视觉方向、分镜；分镜放行后再进入最终 prompt 输出。

**例外一：用户已点名具体镜头卡时，镜头约束已选定。** 例如"用 slow-push-tension 做这个镜头"。此时不要介绍模式，直接读取 references/shot-cards/ 对应卡片全文，按参数表和已知坑执行。

**例外二：用户只给了单场戏/单镜头且明确要 prompt 时，视为单镜头任务。** 直接走七段式输出，不做全片需求解析和风格路由。

## 输入清晰度判断（DETAIL / BASIC 双模式）

在模式判断之后，根据用户输入的清晰度选择工作模式：

**DETAIL 模式（面对含糊/高风险构建时的默认模式）**

- 用户输入模糊、缺少关键信息（角色/场景/台词/参考图）、或存在高风险失败点时
- 收集上下文，提出2-3个有针对性的澄清问题，**然后**进行优化和输出
- 绝不要提出超过3个问题

**BASIC 模式（用户只想立刻得到提示词，或明确要求跳过问题）**

- 用户说"直接给我完整提示词""开始吧""不用问"，或输入已经足够清晰（有角色/场景/台词/参考图）
- 修正关键问题，应用核心技术，立即交付提示词
- 不逐阶段确认，不提问

**判断信号：** 粘贴一段剧本+参考图+"帮我转成视频prompt"属于BASIC。模糊的"我需要一个电影镜头"属于DETAIL。用户明确说"直接做"时强制BASIC。

## 核心理念（始终生效，每条配执行标准）

以下理念从大量实战反馈中提炼，是质量底线不是建议：

1. **表演是压力之下的行为，不是情绪的展示。** 每个角色必须有目标（动词，指向对手）、障碍、策略（每场戏≥2次策略变换）、节拍变化（2-4次，每次行为可见）。禁止AI刻板轮流朗读、禁止情绪同步爆发、禁止瞬间大量流泪、禁止死眼神。
2. **每个镜头只讲一个动效/一个情绪节拍。** 一种运镜手法（推/拉/摇/跟）全片只当一次主角，重复镜头、重复tagline一律删。一个镜头里同时推近+摇移+变焦=炫技，观众读不出重点。
3. **节奏偏好是单向的：放慢/停留。** 历史反馈全部指向"太慢了"从未出现，所有"太快了/没看清/情绪没到位"都来自节奏过快。执行标准：情绪落定 hold ≥1.5秒，动作收尾留0.5秒静止，开场主体动作给足3秒，急推/爆点后hold≥3秒。排时间线时预先给 hold/rest 留帧预算。
4. **电影感来自运镜、光影、节奏与声音的配合，不来自炫技动画。** 被反复认可的是：单主角完整动作弧（聚光→推近→反应→归位）、物理隐喻驱动的加速度、侧斜机位、riser→impact→sparkle的声音句式。批量元素入场靠运动本身，不靠逐个发光。
5. **视觉语言必须从角色和场景自身生长，不能另造一套"宣传片皮肤"。** 做分镜前先从角色设定/场景参考中提取设计spec：服装色系、材质、灯光来源、空间比例。片中所有光影、色彩、运镜都必须复用或克制扩展这套spec。
6. **验收贯穿全程，首检永远不能交给用户。** 每个镜头prompt输出后必须自检（叙事/摄影/合规三维），交付前必须做独立终检。制作者对自己的产出有确认偏差，自检不通过的不交付。
7. **确定性优先，随机是敌人。** 角色外貌、服装、场景布局、光影方向全程锁定，禁止中途漂移。同一角色在不同镜头中五官/发型/服装必须完全一致。
8. **已知坑标注的参数不得降档。** 镜头配方卡中标注"命门"的参数是质量底线（如急推6-8帧、特写停留≥4秒），不得为了省事降低标准。质量标准只升不降。

## 操作步骤

**完整操作步骤详见以下文件：**

- Phase 1-4：references/workflow-phases-1-4.md
- Phase 5 七段式输出：references/seven-segment-output.md
- Phase 6-7：references/workflow-phases-6-7.md

各Phase摘要如下：

### Phase 1：需求解析报告

收集用户输入后，输出结构化需求解析报告。读取 style-routing.md 获取风格路由表和复杂度档位定义。报告字段：题材/流派、核心情绪、时长/画幅、节奏档位、复杂度档位、风格路由、巨物检测、表情检测、是否有角色、资产清单、故事语言/对白语言、声音需求、信息充足判断。

### Phase 2：AGENT-1A 叙事结构 + AGENT-1B 摄影工艺

两个智能体并行设计，输出后合并。AGENT-1A负责：情绪曲线、节奏档位判定与继承、镜头配方卡选型、逐镜规划表（含单镜时长计算公式：时长=台词字数÷3.5+其他时长，单镜≤15秒）、分镜详细参数标准返回格式、声音节拍点、声画关系、目标情绪标注。AGENT-1B负责：摄影机系统、镜头系统、帧率/快门、布光方案、色彩方案。

### Phase 3：Quality Gate 1

读取 quality-gate-spec.md 获取检查清单。四维审查：①叙事情绪↔光影色彩匹配？②镜头焦段↔摄影机画幅兼容？③运镜选择↔叙事理由成立？④色彩方案↔题材路由一致？全部通过→进入Phase 4；任一不通过→回到Phase 2修正。

### Phase 4：串行精修

三个智能体串行执行。AGENT-2A去AI感工程：瑕疵美学注入（≥3项跨≥2类别，暗角全局禁用）、肤质引擎逐层检查、角色面部微表情校验。AGENT-2B画质锁：微观质感描述、分辨率保障关键词、时间稳定性。AGENT-2C声景设计：读取 post-production.md，涉及角色时读取 ai-real-person-dialogue.md，逐镜设计对白层/动作音效/环境声场/声画关系。

### Phase 5：AGENT-3 七段式整合输出

读取 storyboard-spec.md 获取七段式输出格式。对每个镜头按七段式结构输出：①画幅与摄影机系统 ②叙事核心与镜头语法 ③光线架构与氛围 ④色彩科学与胶片质感 ⑤质感与去AI感工程（含镜头配方卡已知坑校验） ⑥放大保真质量锁 ⑦声景空间设计。

七段式设计完成后整合为完整视频生成提示词。**prompt分层架构（强制）**：顶层声明→通用固定参数→主体参考→角色行为锚定→时间码分镜→角色名台词→人物微观生命力→负面约束。含角色行为锚定规则、超自然视觉锚定规则、环境氛围硬规则、镜头内运镜规则、武器/道具出场仪式规则、台词类型标注规则、风格级反向禁令、人物微观生命力规则、负面约束精准化规则、完整prompt示例。

**每镜头输出后立即三维自检（不可跳过）**：①叙事 ②摄影 ③合规。自检不通过当场重写。

### Phase 6：Quality Gate 2

读取 quality-gate-spec.md。三代自检：第一轮叙事、第二轮摄影、第三轮合规。五重会审：IMAX摄影大师、导演大师、剪辑大师、声景设计师、去AI工程师。全部通过→进入确认门。

### Phase 7：确认门
