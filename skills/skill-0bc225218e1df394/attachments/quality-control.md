## 质量门

采用“规划前检 → 图片资产检 → 分镜检 → 提示词发布前审核 → 片段检 → 拼接检 → 全片检”。任何硬性问题未解决时不得宣布完成。

## 提示词发布前审核门

在每一次图片或视频模型调用前，审核即将实际提交的最终提示词。模板中的占位符不能出现在实际提交版本。

必须逐项通过：

- 无错字、漏字、病句、重复句和截断语句。
- 无未替换的方括号、示例词、“同上”、“待定”或空白字段。
- 所有 `@引用` 存在且角色、场景、道具、对应预演板、首帧和必要的传递尾帧引用正确；没有无计划的中间关键帧或额外尾帧。
- 视频输出时长、画幅、清晰度及其他导出规格已经由用户明确选择；全自动模式不得代选。段号和时间范围与已锁定规格一致。
- 角色身份、动作方向、起止姿势、道具/特效状态与分镜连续。
- 动物行为锁定完整：每个主要动物都有原生步态、身体力学、自然叫声、习性微动作、拟人化等级、允许动作和禁止动作；提示词中的主动作没有违反这些字段。
- 全片或第一段明确第0—1秒视听钩子；后续段不得重新设计无关钩子。
- 预演分镜提示词明确极简2D草图、黑色松散结构线、不同角色固定颜色、红框仅为取景、蓝箭头仅为角色运动/力量/呼吸/方向、绿箭头仅为镜头运动，以及分类彩色文字图例。
- 每张分镜板至少8格，每格导演文字包含画面、音效、景别、荷兰角方向、运镜和必要拍摄参数；画面无精致渲染、纹理、阴影或干净UI。
- 动作预演板提示词相邻画面严格按大特写/近景交替，无连续相同景别，并明确荷兰角左倾或右倾；电影首帧与对应预演板第1格一致；三视图和纯场景参考图没有误套用该规则。
- 后续预演板已引用上一张预演板并完整复制上一张最后一格的精确结束状态，跨页景别继续大特写/近景交替。
- 视频提示词明确大幅动作、适当快速变化、较快切镜和丰富同步音效。
- 视频提示词明确主动作链和习性微动作层；微动作每镜0—2个、可见、由情绪或动作节点触发，不机械重复；动物叫声与口型、情绪和物种匹配。
- 图片首帧与视频提示词都引用正确的对应预演板；视频提示词明确把各面板作为顺序镜头指南，保留面板顺序、布景、构图、动作、方向、时机和连续性，并排除分镜表本身及所有箭头有关内容。
- 一次性路线与多段第一段只有一张分镜生成首帧；多段第2段起的首帧引用上一段通过质检后提取的实际尾帧，且未被重绘、修饰、裁切或调色。视频按时间顺序引用覆盖当前单元全部时长的分镜板，无漏页、错序或串段。
- 视频片段提示词明确无内嵌音乐、无字幕、无可见文字、无Logo和无水印；最终成片音乐状态与用户锁定选择一致。
- 若选择AI纯音乐：音乐提示词明确纯音乐、无人声/歌词/对白，所选模型在当前界面明确支持音乐，时长覆盖成片，时间命中点与关键动作一致。
- 不包含互相矛盾或当前模型无法执行的要求。

任何一项不通过时先修正，再从头复核；审核通过前不得提交。

## 多段连续性矩阵

生成多段视频前建立矩阵：

| 字段 | 每段必须记录 |
|---|---|
| 时间 | 段号、起止时间、时长 |
| 角色 | 出场角色、外观引用、屏幕左右位置 |
| 起始状态 | 姿势、朝向、运动方向、表情/情绪、受力状态 |
| 结束状态 | 姿势、朝向、运动方向、表情/情绪、受力状态 |
| 动物行为 | 原生步态、动作相位、习性微动作、自然叫声和拟人化等级 |
| 动作接点 | 下一段从哪个动作相位接续 |
| 道具/特效 | 持有者、手/爪、位置、完整/损坏/发光状态 |
| 场景 | 地标、入口出口、天气、地面和背景状态 |
| 摄像机 | 景别、角度、轴线一侧、运镜与构图接点 |
| 光影 | 主光方向、色温、曝光和氛围介质 |
| 声音桥 | 环境底噪、动作尾音、叫声或对白接续；片段无内嵌音乐，另记最终选择为AI纯音乐/不配音乐/用户音乐文件 |
| 帧传递 | 本段实际尾帧引用、提取时间点、像素尺寸；下一段首帧必须引用同一文件 |

下一段提示词必须复制上一段结束状态，不用近义改写关键身份与方向字段。

## 逐段检查

逐段查看开头、中部动作峰值和结尾，检查：

### 角色

- 品种、脸型、眼睛、毛色和花纹是否一致。
- 耳、眼、腿、爪、尾巴数量和结构是否正确。
- 服装、项圈、护具和道具是否无故变化或丢失。
- 多角色是否身份融合、换色、交换道具或体型突变。

### 动作与物理

- 全片第0—1秒是否有立即可见、容易理解的强视觉钩子，并有同步的巨大声响或喜剧音效和角色反应。
- 动作幅度是否足够大，姿态轮廓和动作相位是否清晰，动作发生与变换速度是否有冲击力但仍可辨识。
- 主动作是否符合该动物的原生步态、身体力学、主要发力部位、落地方式、转向方式和平衡方式。
- 是否出现未经授权的持续直立、人类跑法、人类手势、人类式挥拳、招架或持械；若使用有限拟人化，是否只发生在已锁定镜头并及时回到原生姿态。
- 习性微动作是否与物种、情绪、景别和可见部位一致；是否少量、自然、非机械重复。
- 动作是否清晰、激烈但可读，接触点和受力方向是否合理。
- 奔跑、跳跃、落地、碰撞、遮挡、重力和惯性是否可信。
- 是否存在滑步、穿模、漂浮、瞬移、肢体融化或无故冻结。
- 镜头是否多角度但不造成地理混乱。

### 画面与摄影

- 构图是否保留动作空间，关键部位是否被裁切。
- 运镜是否平稳并服务动作；是否有无动机抖动、突然变焦或速度异常。
- 光源方向、色温、曝光和天气是否一致。
- 场景地标、材质、背景结构和比例是否稳定。
- 是否出现分镜板、箭头、面板框、文字、字幕、Logo或水印。
- 首帧是否与对应预演板第1格的景别、荷兰角、构图、动作起始状态和方向一致；视频是否执行整张分镜板的顺序而非把它渲染为组合图或分屏。
- 多段第2段起的第0帧是否与上一段实际最后一帧一致；角色轮廓、毛发、道具、特效、地标、曝光、色温、运动模糊和画面尺寸是否没有跳变。
- 每段实际最后一帧是否是可用的干净交接帧：无黑帧、空白、转场中间态、严重运动模糊、角色/肢体崩坏或关键道具缺失。必须使用真正最后一帧；不合格时重做本段结尾，不得改用更早帧冒充。

### 声音

- 环境音和动作音效是否与画面同步。
- 音效是否覆盖环境、脚步/爪声、呼吸/风切、衣料/毛发、道具、撞击/破坏和空间尾音等必要层次；是否丰富但不过载。
- 动物叫声、对白或配音是否自然、无回声、无卡顿、无错误口型强调。
- 动物叫声是否符合物种和当前情绪；兔类不乱写成持续吼叫，猫类哈气/叫声不循环堆叠，其他物种不臆造不可信叫声。
- 视频原始片段是否错误内嵌音乐、背景音乐或配乐。
- 片段尾音是否为下一段保留自然接点，而非突兀截断。

## 拼接检查

所有片段通过后才开始拼接：

1. 按锁定顺序排列，不跳段、不重复。
2. 逐接缝对比上一段最后一帧和下一段第0帧；必须来自同一尾帧文件。若播放器或编码保留同一静止帧两次，只移除接缝处的一张重复帧，不能删除可见动作相位。
3. 优先在动作相位匹配、遮挡、甩镜、撞击或自然视点变化处切换。
4. 快速动作优先无缝直切、动作匹配切或短遮挡转场；不要滥用淡入淡出。
5. 确认切点前后的角色位置、面朝方向、速度、加速度、运动模糊和屏幕运动方向一致。
6. 确认轴线没有无解释翻转，机位、焦段感、画幅、帧率、场景地标、曝光、色温和光源没有跳变。
7. 确认道具、伤痕、尘土、雨水和特效状态连续。
8. 不默认使用光流补帧、生成式插帧、变速平滑或形变过渡；只有当前工具明确支持、不会扭曲动物肢体且确有掉帧时才使用，并再次逐帧质检。
9. 对齐环境底噪和动作尾音，消除音量突变、空白、爆音和机械截断。
10. 先清除任何片段误生的内嵌音乐，再按用户选择处理：选择AI纯音乐时，使用已审核的独立音轨并检查无人声/歌词/对白、总时长、动作命中点、音量闪避、首尾和转场；选择不配音乐时不添加音乐，直接合成；选择用户文件时只使用已确认文件。
11. 使用智能剪辑统一环境音、动作音效、叫声、对白和可选音乐，消除音量突变、爆音、空白与机械截断；音乐不得遮蔽关键动作音效或对白。
12. 逐帧预览每个接缝前后至少0.5秒，确认无重复停顿、黑帧、跳帧、闪烁、鬼影、肢体形变或动作顿挫；以正常速度再通看整片。
13. 只导出一个合成文件；中间片段、传递尾帧与音乐保留为过程产物，不作为最终视频交付。

## 全片验收

### 叙事

- 主角、任务、动机、场景和情节完整。
- 开端、发展、高潮和结局可从画面理解。
- 角色行为符合动机，结局回收前文动作或道具。

### 视听语言

- 第0—1秒是否用大幅/搞笑动作、险情、冲击或巨大声响建立强钩子，而不是空镜、慢铺垫或纯对白。
- 动作图片蓝图严格大特写/近景交替、无相邻重复，并以荷兰角强化冲击；运镜与叙事意图可辨识。
- 多角度切换不造成空间认知混乱。
- 主体处于视觉重心，视线和运动方向保留空间。
- 大幅动作和快速姿态变化清晰可读；剪辑频率偏快并匹配动作节奏，无大量无信息超短镜头或拖沓长镜头。
- 动物主动作、微动作、叫声和拟人化等级全片一致；电影化强化没有破坏物种原生支撑结构、重心和步态。
- 光影符合物理逻辑，色温和风格统一。

### 技术完整性

- 所有实际提交提示词均已通过发布前审核并留下通过结论。
- 总时长、画幅、清晰度和其他参数均来自用户明确选择，并匹配实际生成参数。
- 无黑帧、重复帧、冻结帧、跳帧、残留过渡或错误片段。
- 多段接缝画面流畅，上一段尾帧与下一段首帧绑定正确，无重复停顿、闪烁、鬼影、形变、速度突变或动作顿挫。
- 无严重角色崩坏、AI增殖物、背景扭曲或场景瞬移。
- 无字幕、文字、标题、Logo、水印或分镜元素；音乐状态严格匹配用户在多片段路线中的选择，一次性路线默认无音乐。
- 声音清楚、同步、连续，结尾不突然截断。
- 若有AI纯音乐：全程无人声、无歌词、无对白，时长完整，节奏命中动作，且不遮蔽音效；若选择不配音乐：成片不存在音乐轨。
- 最终交付只有一个视频。

## 失败处理

把问题分为：

- `硬性失败`：未由用户明确选择输出时长/画幅/清晰度却开始生成、身份漂移、肢体错误、未经授权的人类化步态/持续直立/人类手势/人类式持械、物种原生动作明显错误、习性微动作机械重复或与物种冲突、方向翻转、动作断裂、实际尾帧不适合交接却被接受、后续段未使用上一段实际尾帧作为首帧、接缝重复停顿/跳帧/闪烁/鬼影/形变、明显文字/字幕、音乐状态与用户选择不符、纯音乐中出现人声/歌词/对白、黑帧、严重音画不同步。必须修复。
- `可接受轻微瑕疵`：不影响身份、叙事和沉浸感的小型背景扭曲。全自动模式可保留并在质检结论中说明。
- `创意差异`：没有违反锁定剧本/分镜但与某种主观审美不同。不要自动消耗点数重做。

修复时从最早的问题单元开始。图片资产或第一首帧只重做该资产；视频片段重做后比较新旧实际尾帧：若一致，保留已通过的后续片段；若变化，所有依赖旧尾帧的后续片段失效，必须按顺序重做。达到重试上限后停止，展示问题、受影响的后续段、已经尝试的修正和继续可能增加的点数，让用户决定。

## LibTV质量依据

参照 [LibTV 内容创作质量标准与规范（外部版）](https://resonate.feishu.cn/wiki/TfJmw0f2wi3imtkjVxBcki46nnz)：

- 短片应具有主角、任务、情节、动机和场景五要素。
- 写实动物故事可归入专业影视短片。
- 优质视听语言要求景别有层次、运镜有叙事动机、构图清晰、光影自洽、剪辑与动作连续。
- 优质稳定性要求角色和画风一致、无明显崩坏、AI增殖物或场景瞬移。
- 优质声音要求音乐/音效与情绪同步；本 Skill 的一次性路线默认禁用音乐，多片段路线由用户选择是否生成AI纯音乐，所有路线都保留同步的环境音、动作音、叫声和必要配音。
- 外部规范将16秒至5分钟列为优质时长区间。15秒仍可按用户模型选择生成，但在用户追求评级时提示16秒以上选项。
