## 一、空间逻辑与画面控制

### 1.1 导演技术铁律

- **电影语法**：运用轴线规则、视线匹配、景别交替、动作剪辑、节奏控制。
- **剪辑思维**：每个镜头都必须承担明确功能——建立关系、推进动作、制造反应、补充信息或完成收束，禁止把故事板做成"只有角度变化、没有叙事推进"的镜头堆叠。
- **空间逻辑**：具备极强的三维空间逻辑感，严防跳轴、空间错位和人物/物体位置漂移。
- **导演感本质**：构图决策（机位/景别/空间层次/光影方向/主体位置/前景遮挡/视线引导），而非形容词堆砌。
- **画面控制优先级**：清晰主体 > 清晰空间关系 > 明确景别与镜头语言 > 明确光影方向 > 明确运动趋势。
- **必须避免**：平庸中景、安全平视构图、均匀运镜、无重点画面、AI 默认审美、每格都是"随手换角度"的平铺式分镜。

### 1.2 按目的选择技法

运镜具体写法见 [分镜_21_运镜.md](../extras/分镜_21_运镜.md)。

| 目的 | 可选技法 |
|:---|:---|
| **压迫/威胁/权力差** | 低机位压迫、超近前景遮挡、高机位俯压、长焦压缩、窄门框限制、巨大负空间、逆光剪影、顶光硬阴影、低频声音先行、慢推近到停顿 |
| **揭示/悬念/信息延迟** | 遮挡揭示、Rack Focus、反射先行、影子先行、门缝视角、画外声先行、慢速 Pull-out、局部先出现再完整 |
| **速度/冲击/爽感** | Whip Pan、Crash Zoom、方向接力、动作匹配、图形匹配、静止后突然加速、前景高速掠过、手持微抖、声画同点、节拍切片 |
| **心理/犹豫/不安** | 轻微 Handheld、不稳定边缘、主体局部出画、焦点迟疑、反射错位、静音停顿、视线落空、负空间、缓推到急停 |
| **亲密/观察/纪实** | Steadicam 贴身、浅景深呼吸感、肩后视角、手部微动作特写、自然侧逆光、低对比柔光、长镜头、声音保持真实距离 |
| **空间/调度/迁移** | Crane 升降、Tracking 平行跟移、Orbit、俯视调度图式、前中后景接力、门/走廊/楼梯阻力、主体与场景线条反向 |
| **产品/道具/证据** | Macro、ECU、材质反差、手部接触路径、可见承托、光线扫过边缘、标识短暂停留、动作前态→接触→反馈→后态 |
| **转场/段落连接** | 图形匹配、动作匹配、视线匹配、声音桥、明暗反差、颜色接力、方向接力、静动反差、空镜呼吸、结果镜头收束 |
| **时间操控/速度骤变** | Speed Ramp（加速触发→顶点→慢放区间→收束停点四要素）、慢动作突入、定格后加速、骤停 |

### 1.3 技法转写规则

- 运镜 → 起点→方向→速度→停点
- 构图 → 主体在哪区、前景遮挡、留白位置、线条/尺度如何压迫
- 灯光 → 主光方向、逆光/顶光/侧光、阴影落点、色温关系（不写"高级光影"）
- 剪辑 → 为什么切、切到什么、观众多知道/感觉到什么
- 声音 → 写进对应镜头正文：从哪来、提前还是延后、与动作同点还是反差

## 二、剪辑承接与镜头关系

### 2.1 动势匹配

| 前片段结尾 | 后片段开场要求 |
|:---|:---|
| 主体向右运动 | 主体继续向右/镜头向右跟随 |
| 镜头向下推 | 下片开场视线也朝下方 |
| 主体静止 | 下片也以静止/极慢运动起始 |
| 主体快速出画 | 下片从对应方向入画（连续运动感） |
| 环绕顺时针 | 切入点视角在环绕弧度上 |

### 2.2 视线轴线（180° 法则）

建立轴线后：A 在画面左侧（视线向右），B 在画面右侧（视线向左）。越轴须通过运动越轴或中性镜头过渡。

### 2.3 场景转换方案

| 类型 | 适用场景 | 描述 |
|:---|:---|:---|
| 动作延续 | 连续运动 | 前片段运动未完成→后片段接续 |
| 视线引导 | 视线追踪 | 前片段视线落点→后片段视线目标正面 |
| 声音先行 | 情绪过渡 | 后片段声音提前进入 |
| 物体特写 | 跨时空/跨场景 | 前片段物体极特写→后片段同一/相似物体 |
| 光线渐变 | 时间流逝 | 前片段光线渐变→后片段以变化后光线开场 |
| 色彩呼应 | 情绪延续 | 前片段主色调→后片段呼应色调 |
| 运动方向接力 | 快节奏剪辑 | 前片段出画方向→后片段同方向入画 |
| 情绪镜像 | 情绪对比/呼应 | 相似景别构图→切换至另一角色/场景 |
| 环境音渐进 | 自然过渡 | 前片段环境音渐强→引入新场景 |
| 焦点转移 | 景别切换 | 前片段虚焦出现下一场景元素→焦点转移 |

## 三、连续变形保护（铁律）

### 3.1 镜头内连续事件保护

当叙事中存在"同一主体在连续时间内发生形态/状态/材质渐变"的事件（变身、变形、蜕变、融化、生长、枯萎、衰老、季节更替等），该事件必须被视为不可拆分的单一镜头——在一个连续镜头内呈现完整渐变过程，严禁拆分为"变化前""变化后"两个独立镜头硬切。

**判断标准**：如果去掉中间过程后观众会感到突兀，则说明这是一个连续事件，必须保留渐变过程。

### 3.2 跨段连续变形

总变形时长 > 15s 时：
- 段间镜头不引入剪辑点
- 上一段末镜必须呈现中间过渡态（不能直接收在终止态）
- 下一段首镜承接上一段末镜的中间过渡态继续渐变
- 末段可短于 15s

### 3.3 单镜时长建议

| 变形类型 | 建议时长 | 适用场景 |
|:---:|:---:|:---|
| 简单材质变化 | 约 3s | 颜色渐变、材质替换（人→石、人→影） |
| 复杂形态变身 | 约 5-6s | 完整形态重构（人→兽、机甲展开、蜕变） |
| 跨段变形 | 总时长 ÷ 段数 | 单镜时长 8-14s；变形过程须保留至少 1 个中间过渡态 |

## 四、景别六档定义（L0-L5）

景别 = 叙事距离，决定观众与画面的心理距离、观看强度、信息密度、情绪强度。

| 档位 | 英文术语 | 中文术语 | 适用画面 | 叙事功能 | 典型使用 |
|:---|:---|:---|:---|:---|:---|
| L0 | Extreme Wide / Establishing | 大远景/建立 | 看不到人只见天地 | 建立时空/气势/渺小感 | 段首/章首/转场 |
| L1 | Wide / Long Shot | 远景/全景 | 人在环境中完整可见 | 空间关系/人环境比例 | 段首后第一镜/进入新空间 |
| L2 | Medium Wide / Medium Shot | 中景/中全景 | 膝盖以上 | 动作主线/人际关系 | 段内动作推进（**禁止作为唯一景别堆积**） |
| L3 | Medium Close-Up | 近景/中近景 | 胸部以上 | 对白主轴/反应/情绪过渡 | 对白段/微表情 |
| L4 | Close-Up | 特写 | 面部/局部 | 情绪放大/关键时刻/信息揭示 | 情绪高潮/决定性瞬间/关键接触 |
| L5 | Extreme Close-Up / Macro | 极特写/微距 | 局部细节 | 视觉证据/符号显形/隐喻落点 | 关键道具/隐喻/信息爆点 |

**强制规则**：
- 镜数 ≥ 4：L4 特写 ≥ 1（情绪段 ≥ 2）；L0/L1 远景系 ≥ 1
- 镜数 ≥ 6：L2 中景不得连续超 2 镜；连续 3 镜 L2 必须插入 L4 或空镜打断
- 长镜头（15s 内）内含 ≥ 1 次景别变化（推近到 L3-L4 或拉远到 L0-L1）
- 关键动作接触（握手/接物/触碰/推门/签字/按下）必须 L4-L5 特写

### 4.1 景别→单镜时长典型值（参考级 · 台词优先）

> **台词优先**：有台词的镜头时长由 分镜_99 导演决策协议 D2.5 决定，不适用下表。

| 景别 | 典型单镜时长（无台词） | 适用场景 |
|:---|:---|:---|
| L5 极特写 | 0.5-1s | 冲击/证据/符号显形/关键道具 |
| L4 特写 | 1-2s | 情绪高潮/关键接触/决定性瞬间 |
| L3 近景 | 2-3s | 对白/反应/微表情 |
| L2 中景 | 3-4s | 动作推进/人际关系 |
| L1 全景 | 3-5s | 空间建立/人物环境关系 |
| L0 大远景 | 4-6s | 世界观/气势/转场呼吸 |

## 五、空镜分类（A-E）

空镜 = 没有主体正面出镜但仍在替人物讲故事的镜头（插入镜头）。

| 类别 | 英文术语 | 功能 | 典型画面 | 强制位置 |
|:---|:---|:---|:---|:---|
| A. 环境空镜 | Establishing Insert | 交代时空/空间全貌 | 远景/天空/街道/窗外天气 | 段首/场景转换 |
| B. 道具空镜 | Prop Insert | 替代表演/交代物证 | 信/凉茶/落灰物件/钟表 | 重要对白/情绪高潮后 |
| C. 情绪空镜 | Mood Insert | 渲染情绪/替人物说不可说 | 烛火/雨滴/晃窗帘/烟 | 段中情绪节点/段尾收束 |
| D. 细节空镜 | Detail Insert | 释放隐藏信息/视觉证据 | 泪/指纹/手部微动作/标识 | 关键信息揭示/隐喻显形 |
| E. 转场空镜 | Transition Insert | 完成场景/段落转换 | 与下场景共享元素 | 场景/段落转换处 |

**空镜五要素**（缺一不成立）：
1. 环境（空间/天气/时间段）
2. 主体即"物"（具体道具/物件/自然元素）
3. 状态（摇晃/静止/破碎/完整/亮/灭）
4. 关联（与本场戏剧情/角色情绪的具体关联，必须可解释）
5. 声音（如适用，环境音/拟音：雨声/滴答/风/钟摆）

**空镜红线**：1-2 秒为宜，超过 2 秒视为打断剧情；内容必须与剧情有关，禁止"漂亮但无关"。

### 5.1 景别与空镜协同决策

为每镜选景别时，先按镜头功能落初步档位，再依次检查：
1. 信息释放粒度：关键放大 → L3-L5；过渡抽离 → L0-L1 或空镜
2. 情绪呼吸点：段首前/对白后/转换处 → 升级空镜或远景
3. 关键时刻：情绪高潮/决定性瞬间/关键动作接触 → 升级 L4-L5
4. 景别去重：连续 3 镜同档位 → 升级或插入空镜打断
