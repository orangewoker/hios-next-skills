# 附MD05 | 赛博朋克·分支剧情树模板

**所属主SKILL：** 赛博朋克 · 仿生人觉醒 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“剧情线混乱、分支无收束”的痛点。

## #需要什么输入

- 主线剧情节点清单。

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·实验室苏醒（start节点）
2. N02 抉择点1·面对人类警察（branch节点）
   - N02A 束手就擒（人类信任+10，公司通缉+10）
   - N02B 暴力突围（暴力指数+20，算力-10）
3. N03 逃亡与隐蔽（normal节点）
4. N04 抉择点2·发现同类据点（branch节点）
   - N04A 加入同类，密谋反击（锁定革命线）
   - N04B 独自调查记忆芯片（锁定真相线）
5. N05-N08 层层推进（如：黑入公司、面对最终BOSS等）
6. ENDING_CHECK 结局判定

### 三、生成与合成

调用底层视频生成Skill，输出MP4视频文件。
