# Prompt 生成标准

## 1. 外部结构

第二部分只使用“资产与提示词总表”和待生成资产卡。卡标题、字段与顺序固定为：`### ID｜名称`、`成品规格`、`参考素材`、`完整生成提示词`、`Negative Prompt`。所有解释、用途、范围和生成依据写在表格字段或卡元数据中；Prompt正文只描述成品。

第三部分严格使用正式镜头组模板。第二部分资产Prompt没有15秒和4000字限制；第三部分每组≤15秒且≤4000可见字。

## 2. 通用写法

按“成品对象与数量 → 画幅与版式 → 主体 → 结构与尺度 → 材质与状态 → 视角／构图 → 光线与色彩 → 跨格一致性 → 质量 → Negative Prompt”的顺序。每条必须能单独复制，不依赖模型阅读第一部分。只写有项目事实或参考依据的内容，不用空泛的“高级、电影感、质感好”代替可见关系。

资产Prompt不得出现：剧情推进、镜头组编号、适用镜头、后续用法、上传／审核／等待／状态、平台操作步骤、本地绝对路径、其他项目事实或第二套素材编号。

## 3. 色卡 CLR

必须生成七个确定性色彩条目，每项具备中文名、HEX与视觉职责。画面只包含七个色块、必要的材质样本、明暗梯度和规整留白；文字应由确定性排版实现，图片模型部分不依赖乱码文本。不得出现人物、行为、剧情、镜头、故事板、海报或场景叙述。正文可见中文至少400字。

推荐顺序：成品与画幅、七色列表、主辅关系、材质采样、明暗梯度、白平衡与饱和度、排版留白、色块边界、跨样本一致性、输出清洁度、Negative Prompt。

## 4. 人物 CHAR

### 4.1 分类

主要人物：多次出镜、跨组身份连续、重要近景／特写、连续继承妆造伤损身体状态、或用户明确要求。一次性次要人物：单场景或短段落出现、无跨组连续性、无重要特写；不建立CHAR，在第三部分直接描述。

已有完整多视图人物板：登记直接使用，无Prompt。只有单视图真人参考：必须原样使用案例库 `case-char-reference-human` 的固定扩展Prompt，不能删改、重排或同义替换；只允许在末尾追加参考图中真实可见的疤痕、缺牙、晒斑、衣物磨损等短段落。

### 4.2 无参考主要人物

成品固定1张9:16人物设定板，不等分2×2。上半区占高度1/3：左为正面脸部特写，右为纯侧面脸部特写，头肩紧凑。下半区占2/3：左为更近、更满的正面服装展示，人物从肩颈以下入画到鞋，头部完整裁出，手脚与身体主体不得裁切；右为头到鞋完整背面全身。四格同一身份、年龄、骨相、体型、肤色、发型、服装、配饰和材质。

正文按：输出对象、9:16版式和比例、人物身份与年龄、脸部骨相与真实皮肤、发型、身体结构与比例、服装层级和合体关系、材质与磨损、配饰与鞋、四格分别构图、统一灰棚与三点光、跨格一致性、真实感与分辨率、Negative Prompt。可见中文至少800字，建议1200—2500字。只写人物，不写其所在故事、行动、场景、镜头组或使用方法。

特殊身材、儿童、老人、非人或动画角色保留四格职责，比例和材料服从设定，不强行“超模感”。

## 5. 道具 PROP

只有反复出现、重要近景、连续性、复杂结构、关键交互或用户指定对象独立资产化。简单道具写一张干净设定图即可；复杂道具默认1张16:9等分2×2，四格为正面、侧面、关键结构和材质／界面／握持关系。写清真实尺度、重量感、中心结构、活动部件、表面材质、磨损、接缝、反射、握持或开启关系以及跨格同一性。复杂道具正文至少400字，建议600—1500字。只写物体，不写人物行动、剧情、场景或“用于某镜头”。

## 6. 场景 SCN

### 6.1 拆分

室内与室外、不同封闭房间、不同楼层／主要高度、尺度或关键结构明显变化、或无法由同一中心建立四向关系时，必须拆分SCN。不得把室内外或互不连贯区域塞进同一四格。

### 6.2 成品与固定朝向

每个SCN只生成1张16:9画布。画布内部四个等大且彼此独立的16:9横向画格，用细黑分隔线构成2×2；不得有外部黑框、大面积黑缝、九宫格或俯视格。

- 左上：摄影机位于空间南侧，向北看。
- 右上：摄影机位于空间北侧，向南看。
- 左下：摄影机位于空间西侧，向东看。
- 右下：摄影机位于空间东侧，向西看。

四格均为正面、平视建立镜头，默认机高约1.6米、35mm。必须共享同一空间中心、边界、结构、主要固定物位置、尺度、材料、损耗、光源方向、时间和天气。空场，无人物、人物影子、人物倒影；无文字、标签、箭头、数字、水印、Logo、UI。

### 6.3 细节顺序

正文依次写：

1. 输出对象与1张16:9画布；
2. 四个等大独立16:9横格与细黑分隔；
3. 场景类型；4. 时间；5. 天气；6. 地理与气候；7. 时代；8. 空间中心；9. 尺度；10. 地面；11. 四周边界；12. 顶部／天空；13. 固定结构；14. 材质；15. 磨损；16. 主视觉对象；17. 反射与透明关系；18. 色彩与白平衡；19—22. 四个固定方向逐格描述；23. 相邻格对应关系；24. 跨格一致与空场；25. 清洁质量；随后Negative Prompt。

每一格都必须写机位位置、朝向、正前方、左侧、右侧、地面、顶部和与相邻格的结构对应。正文可见中文至少700字，建议1000—2200字。项目事实不明确的门窗、出入口、楼梯、电梯、扶梯、家具、通道或障碍不得补造。

## 7. 空间结构与调度 BLK

卡的参考素材必须引用一个或多个已登记SCN编号。Prompt以这些SCN和剧本空间事实为唯一结构依据，忠实整理平面边界、层级、高差、固定结构、真实出入口、障碍、可通行区、人物起终点与路线、摄影机起点／路径／朝向／落点；未知尺寸使用相对关系，不伪造坐标。不得重设计SCN、移动固定物或新增连接设施。

简单空间可不建BLK。复杂单层优先俯视结构／路线图；多层按需使用横切面与分层俯视。路线重叠影响可读时可拆为人物与摄影机两张，同一BLK关系保持一致。数量按空间表达清晰度，不按视频时长。

## 8. 后期BGM MUS

以资深电影作曲家、配器师和声音叙事设计者视角写纯器乐Prompt。至少明确：后期用途、总时长、情绪起点、发展、结尾、BPM范围、拍号、节拍稳定度、段落结构、主奏与辅奏乐器、真实或合成音色、音区分配、动态曲线、旋律密度、和声张力、节奏织体、为对白与环境声留出的频段和密度、可剪辑段落、头尾剪辑余量、循环方式、采样率／位深或交付格式。正文至少300可见中文字。

必须禁止歌词、演唱、吟唱、哼唱、念白、对白、拟声人声、突然过响、廉价预设、过度煽情和受版权保护作品的独特旋律。MUS只供后期，不进入第三部分素材锁定。

## 9. Negative Prompt

所有资产卡的负面段标题只允许 `#### Negative Prompt`。不得使用“音乐禁区”“负面提示词／音乐禁区”或混合标题。正文应针对该类型的可见失败：人物一致性、裁切、肢体、版式；道具结构漂移；场景方向与空场；BLK结构篡改；MUS人声与情绪污染。不要把正向内容整段重复一次。

## 10. 第三部分镜头组

按正式模板编译。素材锁定可引用第二部分登记的CLR、CHAR、PROP、SCN、BLK，无论其资产情况为“已有，直接使用”还是“需要生成”；不得引用MUS。镜头组应自足写清当前身份和妆造、真实空间、摄影机、构图、人物距离、动作起止与物理反馈、微表演、光影、对白、同期声、固定无BGM原句和视觉拼接锚点。

时间码不得超过15秒、重叠或倒退。单组可见文字不得超过4000字。完整对白集中在【配音／对白】，分秒调度只写说话时机与动作同步。声音只服务当前组；拼接锚点不写声桥、先声、尾声或跨组声音接口。

## 11. 案例库调用

生成任一触发资产类型前，先读取 `../examples/annotated-casebook.md` 中同类章节。案例只提供密度、顺序、版式、细节层级、一致性和Negative Prompt方法；人物、剧情、服装、场景、道具、世界观和具体数值必须来自当前项目。固定单视图真人扩展Prompt是唯一要求逐字复用的例外。
