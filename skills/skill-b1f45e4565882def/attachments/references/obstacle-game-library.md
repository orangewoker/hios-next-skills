# 固定水上综艺赛场与随机关卡库

## 固定赛场合同

所有视频使用同一类阳光白天户外大型水上闯关综艺赛场：碧蓝水池、蓝黄撞色软垫障碍、起点高台与蓝黄拱门、远处满座欢呼观众席、强日光和清晰水花。不得改成室内演播厅、森林、城市街头、充气城堡主题场地或其他世界观。

所有路线的最终目标固定为：主角通过最后一段攀登/登台，抵达高台顶部，清晰按下一个实体红色通关按钮，按钮亮起后欢呼爆发。无奖品时主角在高台上胜利定格；有奖品时才在高台领奖区与奖品合影。禁止扣篮、拿篮球、摇铃、冲线、金色按钮、旗帜作为终点替代。

## `water_run` 抽取规则

- 每次从下表均匀随机抽取一条完整 `water_run`；用户禁用某类障碍时，排除包含它的路线再随机。
- 抽中后，必须把该路线完整六段链原样填入最终视频提示词。不得用原案例的“浮墩 -> 浮块 -> 荡绳 -> 拿球 -> 扣篮”替换、补充或混入其中任何一段。
- 最近三次已使用的路线不得重复；没有历史时优先从非 `浮墩` 起始路线抽取。
- 所有障碍必须是可信的水上综艺安全装置；不出现危险坠落、硬质撞击或跨场景道具。

## 随机性约束

同一 `water_run` 内可随机改变软垫色块排列、观众服装、角色运动鞋颜色和红色按钮高台的装饰摆位，但不得改变六段功能和红色按钮终点。不要让一条视频同时出现两个路线的标志性障碍。

## 画面洁净规则

所有 `water_run` 均不添加计时器、倒计时、分数牌、数码表、HUD 或常驻数字贴片。
