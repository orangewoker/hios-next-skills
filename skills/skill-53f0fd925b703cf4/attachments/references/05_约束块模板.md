## 四层架构

每段末尾必须有【约束块】，四层结构。**叙事正文零否定——所有否定进约束块。**

```
【约束块】
①守住几条（正面不变量）：
  [本段不可破坏的正面规则：构图锁定/行为锁定/入画方向/比例锁定]
②无X（品类禁区）：
  [按风格选：无CG光滑质感/无3D渲染感/无动漫平涂/无塑料材质/无过度饱和/无音乐/
   无稳定镜头/无HUD…] + 画面中不出现任何文字、英文、签名、手写字、水印、logo
③修正层（翻车沉淀，初始可为空但保留标题）：
  [对象+必须/禁+精确状态——来自本项目《翻车修正库》]
④重申层（本段关键约束正面重申）：
  [状态机三拍/同框比例/情绪弧/接触白名单/镜头行为]
```

**两源合一**：①来自万物生「这一镜从头到尾必须守住几条」（正面不变量）；②③④来自渊【负面提示词】块（负面禁区+迭代沉淀+状态重申）。

## 各层写法细则

### ①守住几条（正面不变量）

万物生式：「这一镜从头到尾必须守住几条：A；B；C；D」
可锁维度：构图（始终居中/不居中偏X）、景别（锁死腰部以上）、入画方向（人与物只从侧缘/下缘擦入，绝不从深处冒出）、行为（步频不变/双手不晃）、视线（始终望向镜头）。
✅「守住几条：丹眉始终居于画面正中；景别从头到尾锁死在她腰部以上；所有迎面而来的人与物都从画面侧方边缘或下缘擦入；丹眉自始至终面无表情、步频不变」

### ②无X（品类禁区）

按段型/风格选，不堆无关项：
- 实拍系：无CG光滑质感、无3D渲染感、无动漫风格光影、无电子游戏质感、无塑料材质感、无完美反射、无数字锐化、无过度饱和色彩
- 3A游戏系：非真人实拍、非动漫平涂、非破败感（已在风格行的不重复）
- 相机：无稳定镜头/无平滑运镜/无固定机位（L4-L5段）；无手持晃动（L1-L2段）
- 界面：无HUD/无文字UI（或反之：HUD简洁——只有瞄准环，无复杂界面）
- 通用收尾（必写）：画面中不出现任何文字、英文、签名、手写字、水印、logo
- 音轨：无音乐/不配背景音乐（按需）

**文字转译例外**（剧情需要文字元素时，转译为非文字视觉形态+后期声明，不写进无X层）：
✅ 舆图标记=红色圈点形态非文字 / 衣襟题诗=炭痕模糊笔意文字不可辨 / 碑文招牌=模糊处理后期叠加
——AI直接生成中文字极易错乱，凡需可读文字一律转译+声明后期叠加

### ③修正层（翻车沉淀）

格式：「对象+必须/禁+精确状态」。来自本项目《翻车修正库》（ref04双写工作流）。
✅「炽翎是暗红色，不是银蓝色」「蓝色火焰只在翼尖和脚底喷射，背部没有主引擎喷口」「扫描状态播报由电脑合成语音完成，不是芮晨的声音」

### ④重申层（关键约束正面重申）

- **状态机**：「待命状态为红光——通讯接入前是红光。通讯接通时红光熄灭，冷蓝色光亮起。落幅蓝光保持稳定亮着」
- **同框比例**：「凛翼约8米，炽翎约6.5米，同框时凛翼高出近一头/残骸只到凛翼腰部」
- **情绪弧**：「霜鹭表情变化：担忧（起幅）→如释重负（通讯后）→眼神坚定（回复时）」
- **接触白名单**：「枪尖只擦过衣料，不接触皮肤不穿透身体，与躯干保持可见间隙」
- **镜头行为**：「落幅后镜头跟随凛翼脸部继续向前飞行，不是静止定格」

## 段型填槽示例

### 打斗段（雾夜街示例）
```
【约束块】
守住几条：云游面部始终克制无大表情；长枪脱手后始终横在两人之间地面原位；
  墨线发光仅为暗金#B8860B，不作为环境光源。
无X：无夸张特效，无能量冲击波，无多余粒子爆炸，无音乐。
  画面中不出现任何文字、英文、签名、手写字、水印、logo。
修正层：（空——首次生成）
重申层：枪尖只擦过衣料，不接触皮肤不穿透身体，与躯干保持可见间隙；
  墨线缠的是铁傀右腕装甲，不缠脖颈不缠躯干；两人间距始终不超过一杆长枪。
```

### 移动/行走段
```
守住几条：角色始终[居中/偏X]；步频[定性]全程不变；入画人与物只从画面[侧缘/下缘]进入。
无X：（按风格选）+ 文字负面声明。
重申层：[若有状态元素：前→触发→后]
```

### 静态/氛围段
```
守住几条：机位[固定/运动幅度极小]；[主体]保持[姿态]；环境元素[极光/雾]只做氛围不做主体。
无X：（按风格选）+ 文字负面声明。
重申层：微动作通道为[呼吸/视线]；[若有突静：突静后接的新信息]
```

### 对话段
```
守住几条：正反打不越轴；每镜前景元素[桌沿/尾甲]保持；[角色]不看镜头。
无X：（按风格选）+ 文字负面声明。
重申层：情绪弧[X→Y→Z]；[音色归属：旁白/画外音为X的声音，不是Y的]
```

### 奇观/大场面段
```
守住几条：各单位比例——[A如六层楼房，B如小型战车只到A甲壳下沿，C如大型犬]；
  [巨物]不进行细节刻画，仅保留动态表现与数量感。
无X：（按风格选）+ 文字负面声明。
重申层：[特效颜色归属：爆炸为蓝白色电磁脉冲，不是橙红色常规爆炸]；[数量：X只有一头/数百只不是数十只]
```
