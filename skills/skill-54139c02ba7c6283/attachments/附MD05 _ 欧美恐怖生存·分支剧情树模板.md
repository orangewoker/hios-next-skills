# 附MD05 | 欧美恐怖生存·分支剧情树模板

**所属主SKILL：** 欧美恐怖生存 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“剧情线混乱、分支无收束、假选项泛滥”的痛点。

## #需要什么输入

- 主线剧情节点清单、核心抉择点设计。

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·汽车抛锚，抵达木屋（start节点）
2. N02 抉择点1·第一夜怎么睡（branch节点）
   - N02A 分头睡，各回各房（怪物仇恨+20，触发突袭）
   - N02B 聚在客厅，轮流守夜（理智值-10，但存活率上升）
3. N03 发现地下室的血迹（normal节点）
4. N04 抉择点2·面对怪物的脚步声（branch节点）
   - N04A 躲进衣柜，屏住呼吸（检测理智值，&lt;50会尖叫）
   - N04B 拿枪冲出去拼了（消耗弹药，触发追逐战）
5. N05-N08 层层推进（如：寻找出口、同伴背叛、最终反杀）
6. ENDING_CHECK 结局判定

### 三、灵魂七问（每个抉择点必过审）

1. 玩家为什么选它？（求生本能/保护同伴）
2. 它改变了什么？（怪物位置、理智值）
3. 即时后果是什么？
4. 延迟后果在哪个节点出现？
5. 是否可能导致致命死局？
6. 是否有新的信息增量？
7. 是否符合B级恐怖片的经典逻辑？
