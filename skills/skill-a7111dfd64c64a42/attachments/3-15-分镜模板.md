# 分镜脚本模板库

分镜脚本由 AI 在第六阶段自动生成，是 Skill 内部使用的核心技术文档。用户不直接查看分镜表格文字，而是通过后续生成的分镜图/场景图来预览每个镜头的画面效果。

---

## 一、分镜格式规范（10列标准）

### 1.1 列定义

| 列序号 | 列名 | 说明 | 示例 |
|--------|------|------|------|
| 1 | 镜号 | 从1开始顺序编号 | 1, 2, 3... |
| 2 | 时间码 | 该镜头的起止时间 | 00:00-00:03 |
| 3 | 景别 | 画面取景范围 | 特写 |
| 4 | 运镜 | 摄像机运动方式 | 缓推 |
| 5 | 画面描述 | 画面内容、构图、环境、光线 | 商品居中，背景虚化，暖色调侧光 |
| 6 | 产品露出 | 商品在画面中的展示方式和位置 | 商品正面，占画面60% |
| 7 | 台词旁白 | 配音文字，标注（旁白）/（对话）/（独白）/（无） | （旁白）清晨第一口的清爽 |
| 8 | 音效 | 背景音乐/环境音/特效音 | 轻快钢琴BGM+开瓶声 |
| 9 | 时长 | 该镜头持续秒数 | 3s |
| 10 | 备注 | 运动方向 + 特殊说明（转场/特效/注意事项）。运动方向标注主体运动方向（→左到右/←右到左/↑前到后/原地），相邻镜头不得矛盾 | 运动方向：→左到右；溶解转场；需保持与镜头1色调一致 |

### 1.2 格式示例

```
镜号 | 时间码 | 景别 | 运镜 | 画面描述 | 产品露出 | 台词旁白 | 音效 | 时长 | 备注
-----|--------|------|------|----------|----------|----------|------|------|-----
1 | 00:00-00:03 | 特写 | 缓推 | 商品居中，背景虚化，暖色调侧光，产品表面光泽 | 商品正面，占画面60% | （旁白）清晨第一口的清爽 | 轻快钢琴BGM+开瓶声 | 3s | 运动方向：原地；溶解转场
2 | 00:03-00:06 | 中景 | 固定 | 生活场景，阳光透过窗户，商品放置在木桌上 | 商品侧面，占画面40% | （旁白）唤醒整个夏天的味道 | BGM持续+鸟鸣环境音 | 3s | 运动方向：原地；硬切转场
3 | 00:06-00:09 | 近景 | 缓拉 | 品牌Logo淡入，Slogan出现 | Logo居中，占画面50% | （无） | BGM渐弱 | 3s | 运动方向：原地；淡出结尾
```

## 二、景别选择规则

### 2.1 景别定义与适用

| 景别 | 画面范围 | 适用场景 | 情感表达 |
|------|---------|---------|---------|
| **大远景** | 广阔环境，商品极小或不可见 | 场景建立、氛围渲染 | 宏大、渺小、孤独 |
| **远景** | 环境为主，商品占画面<20% | 场景交代、空间感 | 开阔、自由 |
| **全景** | 商品完整+部分环境，商品占画面30-50% | 商品全貌展示、使用场景 | 完整、客观 |
| **中景** | 商品主体+少量环境，商品占画面50-70% | 商品使用过程、功能展示 | 自然、亲切 |
| **近景** | 商品局部，商品占画面70-90% | 细节展示、情感表达 | 聚焦、亲近 |
| **特写** | 商品关键细节，商品占画面>90% | 材质/工艺/细节展示 | 精致、强调 |
| **微距** | 极细微纹理/结构 | 材质质感、微观世界 | 震撼、专业 |

### 2.2 景别与广告目标匹配

| 广告目标 | 景别偏好 | 说明 |
|---------|---------|------|
| 品牌曝光 | 全景+特写 | 品牌整体形象+细节质感 |
| 促销转化 | 中景+特写 | 使用场景+产品细节 |
| 新品上市 | 全景+近景+特写 | 全貌+差异化细节 |
| 活动引流 | 全景+中景 | 活动场景+参与感 |

### 2.3 景别变化节奏

- **快节奏**（促销/科技）：景别变化频繁，每镜切换
- **中等节奏**（生活方式/种草）：景别有规律变化，2-3镜一循环
- **舒缓节奏**（品牌/情感）：景别变化少，同一景别持续多镜

## 三、运镜选择规则

### 3.1 运镜类型与效果

| 运镜 | 视觉效果 | 适用场景 | 情感表达 |
|------|---------|---------|---------|
| **固定** | 画面稳定，无运动 | 产品展示、对话场景 | 稳定、客观 |
| **推** | 从远到近，聚焦主体 | 强调细节、引导注意 | 聚焦、深入 |
| **拉** | 从近到远，揭示环境 | 揭示全貌、结束镜头 | 释放、回顾 |
| **摇** | 水平或垂直转动 | 展示宽度、跟随主体 | 探索、跟随 |
| **移** | 摄像机平移 | 跟随运动、平行展示 | 流畅、陪伴 |
| **跟** | 跟随主体运动 | 运动场景、使用过程 | 动感、参与 |
| **升** | 摄像机上升 | 揭示高度、结束 | 升华、开阔 |
| **降** | 摄像机下降 | 进入场景、开始 | 进入、聚焦 |
| **旋转** | 围绕主体旋转 | 360°展示、强调 | 环绕、全方位 |
| **手持** | 轻微晃动，真实感 | 纪实风格、第一视角 | 真实、临场 |

### 3.2 运镜与风格匹配

| 视觉风格 | 推荐运镜 | 避免运镜 |
|---------|---------|---------|
| 简约极简 | 固定、缓推 | 手持、快速旋转 |
| 高端奢华 | 缓推、缓拉、缓慢旋转 | 手持、快切 |
| 自然清新 | 固定、缓移、轻微手持 | 快速推拉 |
| 工业硬核 | 手持、快速推拉、旋转 | 缓慢固定 |
| 3D科技 | 旋转、推拉、移 | 手持 |
| 生活方式 | 固定、缓移、轻微手持 | 快速旋转 |
| 促销爆款 | 快速推拉、快切 | 缓慢固定 |
| 国潮东方 | 缓推、缓慢摇、缓慢旋转 | 手持、快切 |
| MG动画 | 图形变换（模拟推拉） | 手持 |
| 3D卡通 | 夸张推拉、弹性运动 | 缓慢固定 |
| 国漫动画 | 缓慢摇、缓慢推拉 | 手持、快切 |

### 3.3 运镜节奏控制

- **快节奏**：运镜速度快、变化频繁、多用手持和快速推拉
- **中等节奏**：运镜速度适中、变化有规律
- **舒缓节奏**：运镜缓慢、固定为主、变化少

## 四、分镜数量与时长对应

### 4.1 镜头数量指导

| 总时长 | 镜头数量 | 平均镜头时长 | 节奏特征 |
|--------|---------|------------|---------|
| 5秒 | 2-3个 | 1.5-2.5秒 | 极快，瞬间冲击 |
| 10秒 | 3-5个 | 2-3秒 | 快速，无废话 |
| 15秒 | 5-7个 | 2-3秒 | 紧凑，节奏感强 |
| 30秒 | 8-12个 | 2.5-4秒 | 张弛有度 |
| 60秒 | 12-20个 | 3-5秒 | 可有叙事节奏 |

### 4.2 镜头时长分配原则

- **开场镜头**：1-3秒（快速抓住注意力）
- **主体镜头**：2-5秒（信息展示）
- **特写镜头**：1-3秒（细节强调）
- **片头/片尾**：按品牌元素规则
- **转场镜头**：0.5-1秒（如果需要单独转场）

### 4.3 镜头时长与景别关系

| 景别 | 建议时长 | 原因 |
|------|---------|------|
| 大远景 | 3-5秒 | 需要时间感知环境 |
| 远景 | 2-4秒 | 需要时间理解空间 |
| 全景 | 2-3秒 | 完整展示商品 |
| 中景 | 2-3秒 | 展示使用过程 |
| 近景 | 1.5-2.5秒 | 聚焦细节 |
| 特写 | 1-2秒 | 快速强调 |
| 微距 | 1-2秒 | 瞬间震撼 |

## 五、分镜图生成规则

### 5.1 分镜图定义

分镜图是每个镜头的视觉预览图，用于让用户确认画面效果，再进入场景图和视频生成阶段。

**分镜图 vs 场景图：**
- 分镜图：快速预览，构图参考，用于确认镜头设计
- 场景图：高质量成品图，用于视频生成的参考帧

### 5.2 分镜图生成流程

```
1. 基于分镜脚本，逐镜头生成分镜图
2. 每张分镜图必须体现：
   - 景别（取景范围）
   - 运镜方向（用箭头或动态模糊表示）
   - 商品位置和展示方式
   - 整体氛围和色调
   - 画面比例（与最终视频一致）
3. 分镜图不需要：
   - 高质量渲染（快速生成即可）
   - 完全一致的商品细节（参考性质）
4. 展示给用户：按镜号顺序展示，标注镜号和关键信息
5. 用户确认：整体节奏和构图是否满意
```

### 5.3 分镜图 Prompt 构建

```
生成第[X]镜头的分镜图：

【画面内容】
- 景别：[景别]
- 构图：[商品位置+环境]
- 主体：[商品/人物/环境]
- 动作：[如有]

【视觉风格】
- 整体风格：[第二阶段选定风格]
- 色调：[色调]
- 光照：[光照方向和强度]

【技术要求】
- 画面比例：[X:X]
- 标注运镜方向：[运镜类型+方向箭头]
- 快速草稿风格，不需要高质量渲染
```

## 六、分镜与剧本的对应关系

### 6.1 对应原则

- 分镜是剧本的视觉化执行方案
- 每个剧本镜号对应一个或多个分镜镜头
- 分镜可以细化剧本（一个剧本镜头拆分为多个分镜镜头）
- 分镜不可改变剧本的核心信息（台词、卖点、品牌元素）

### 6.2 细化规则

| 剧本镜头特征 | 分镜处理方式 |
|------------|------------|
| 单一画面描述 | 1个分镜镜头 |
| 包含多个动作/变化 | 拆分为2-3个分镜镜头 |
| 需要展示过程 | 拆分为多个分镜镜头（过程分解） |
| 纯台词无画面变化 | 保持1个分镜镜头，可加运镜增加动感 |

### 6.3 信息一致性检查

分镜生成后，必须检查：
- ✅ 所有剧本台词在分镜中都有对应
- ✅ 所有卖点在分镜中都有视觉展示
- ✅ 品牌元素（Logo/Slogan）在分镜中的位置和时机与剧本一致
- ✅ 片头片尾时长符合规则
- ✅ 总时长与目标时长一致

## 七、多商品分镜编排规则

### 7.1 时长分配

- 主角商品：占总时长60%
- 配角商品：均分剩余40%

### 7.2 出场顺序

| 编排方式 | 适用场景 | 说明 |
|---------|---------|------|
| **主角开场** | 品牌曝光、新品上市 | 主角商品先登场，建立印象 |
| **主角压轴** | 促销转化 | 配角铺垫，主角最后登场，制造期待 |
| **交替出现** | 套装组合 | 各商品穿插展示，最后合体 |
| **场景串联** | 生活方式 | 按使用场景自然引入各商品 |

### 7.3 转场衔接

- 商品间转场需自然，禁止硬切无逻辑跳跃
- 可使用：道具转场、动作转场、颜色转场、场景转场
- 主角商品与配角商品的转场可以有差异化（主角更突出）

## 八、分镜质量检查清单

分镜脚本生成后，必须通过以下检查：

```
分镜质量检查：
□ 镜头数量符合时长要求
□ 每个镜头时长合理（不过长/过短）
□ 景别选择符合广告目标和风格
□ 运镜选择符合风格匹配
□ 台词与镜头时长匹配（语速校验）
□ 所有卖点都有视觉展示
□ 品牌元素植入位置和时机正确
□ 片头片尾时长符合规则
□ 多商品时长分配正确
□ 转场衔接自然
□ 总时长与目标时长误差≤1秒
□ 合规检查通过
□ 每个镜头备注栏已标注运动方向
□ 相邻镜头运动方向不矛盾（无方向反转）
□ 人物动作时序连贯（无倒序/重复）

全部通过 → 进入分镜图生成
有问题 → 自动修正或提示用户
```

## 九、人物出镜的分镜编排规则（仅当人物出镜=是时适用）

### 9.1 人物在分镜中的位置规则

| 镜头类型 | 人物位置 | 商品位置 | 画面比例分配 |
|---------|---------|---------|------------|
| **人物特写** | 画面主体（占60-80%） | 手持/佩戴，可见即可 | 人物为主，商品为辅 |
| **人物+商品并列** | 画面一侧（占40-50%） | 画面另一侧（占40-50%） | 平分，视觉平衡 |
| **人物使用商品** | 画面中心（占50-60%） | 人物手部/面前（占20-30%） | 人物为主，商品清晰可见 |
| **商品为主+人物辅助** | 画面边缘/背景（占20-30%） | 画面主体（占50-70%） | 商品为主，人物增加场景感 |
| **人物动态展示** | 画面中心，有运动方向 | 人物身上/手中 | 人物动态为主 |

### 9.2 人物走位与镜头衔接

- **连续镜头中人物朝向一致**：如果前一镜头人物面朝右，下一镜头不应突然面朝左（除非有明确的转身动作）
- **人物运动方向与运镜方向配合**：
  - 人物向右走 → 运镜可用「跟」或「移」（同方向）
  - 人物走向镜头 → 运镜用「固定」或「缓拉」
  - 人物远离镜头 → 运镜用「固定」或「缓推」
- **人物出画与入画**：
  - 人物从画面左侧出画 → 下一镜头可从右侧入画（保持运动连贯）
  - 禁止人物在同一方向连续出画两次（观众会困惑）

### 9.3 人物-商品互动镜头编排

| 互动类型 | 分镜编排要点 | 景别建议 |
|---------|------------|---------|
| **手持展示** | 先展示人物手持商品的近景 → 再展示商品细节特写 | 近景→特写 |
| **使用过程** | 人物开始使用 → 使用中的状态 → 使用后的效果 | 中景→近景→特写 |
| **佩戴/穿戴** | 人物佩戴动作 → 佩戴完成的全貌 → 细节展示 | 中景→全景→特写 |
| **品尝/饮用** | 人物举杯/拿起 → 品尝表情 → 满足状态 | 中景→近景（面部）→近景 |
| **推荐/展示** | 人物面向镜头展示商品 → 商品特写 → 人物满意表情 | 中景→特写→近景 |

### 9.4 人物分镜的质量检查

- ✅ 人物外貌与人物描述卡一致（面部/发型/服装）
- ✅ 人物动作自然，不违反物理规律
- ✅ 人物与商品的大小比例合理
- ✅ 人物表情与情绪节奏匹配
- ✅ 人物朝向/运动方向在连续镜头中连贯

## 十、转场类型详细规则

### 10.1 转场类型库

| 转场类型 | 视觉效果 | 适用场景 | 时长 | 情感表达 |
|---------|---------|---------|------|---------|
| **硬切** | 直接切换，无过渡 | 快节奏、同场景切换 | 0秒 | 干脆、紧凑 |
| **溶解** | 前一画面渐隐+后一画面渐显 | 时间流逝、场景转换 | 0.5-1.5秒 | 柔和、过渡 |
| **淡入/淡出** | 从黑/白渐变或渐变为黑/白 | 段落分隔、开始/结束 | 0.5-1秒 | 结束感、仪式感 |
| **遮罩转场** | 物体遮挡镜头后切换到新场景 | 创意转场、空间转换 | 0.5-1秒 | 巧妙、惊喜 |
| **动作匹配转场** | 前后镜头动作方向一致，利用动作连贯切换 | 运动场景、流畅叙事 | 0秒（动作连贯） | 流畅、动感 |
| **相似体转场** | 前后镜头中有形状/颜色相似的元素 | 创意叙事、隐喻 | 0秒 | 巧妙、有设计感 |
| **声音引导转场** | 下一镜头的声音先于画面出现 | 场景转换、悬念 | 0秒 | 期待感 |
| **运镜转场** | 利用运镜的动势完成切换（如快速摇向某处→切到新场景） | 空间转换、节奏感 | 0秒 | 流畅、有冲击力 |
| **变焦转场** | 快速变焦模糊后切换到新画面 | 节奏变化、时间跳跃 | 0.3-0.5秒 | 速度感、冲击 |
| **分屏/画中画** | 画面分割展示多个内容 | 对比展示、多线叙事 | 持续展示 | 信息丰富、对比 |

### 10.2 转场与风格匹配

| 视觉风格 | 推荐转场 | 避免转场 |
|---------|---------|---------|
| 简约极简 | 硬切、淡入淡出 | 花哨遮罩、分屏 |
| 高端奢华 | 溶解、淡入淡出、运镜转场 | 硬切过多、变焦转场 |
| 自然清新 | 硬切、溶解、动作匹配 | 变焦、分屏 |
| 促销爆款 | 硬切、变焦转场、运镜转场 | 缓慢溶解 |
| 科技未来 | 硬切、变焦转场、遮罩转场 | 淡入淡出 |
| 国潮东方 | 溶解、运镜转场、相似体转场 | 变焦、分屏 |
| MG动画 | 图形变换（遮罩/相似体）、硬切 | 淡入淡出 |
| 3D卡通 | 动作匹配、遮罩、硬切 | 缓慢溶解 |

### 10.3 转场使用规范

- **单支广告转场类型不超过3种**（避免视觉混乱）
- **硬切是默认转场**，其他转场按需使用
- **节奏匹配**：快节奏多用硬切，慢节奏可用溶解/淡入淡出
- **逻辑连贯**：转场前后画面必须有逻辑关联（时间/空间/动作/主题）
- **时长控制**：转场时长不超过1秒（快速广告不超过0.5秒）

## 十一、镜头衔接逻辑

### 11.1 视觉连贯性原则

相邻镜头之间必须保持以下至少一项连贯：

| 连贯维度 | 说明 | 示例 |
|---------|------|------|
| **色彩连贯** | 相邻镜头色调不突变 | 暖色调镜头后不直接切冷色调 |
| **构图连贯** | 主体位置有呼应关系 | 上一镜头主体在左→下一镜头主体在右（平衡感） |
| **运动连贯** | 运动方向和速度有逻辑 | 向右移动的物体→下一镜头继续向右或自然停止 |
| **光线连贯** | 同一场景内光线方向一致 | 光源从左侧来→所有镜头光源都从左侧来 |
| **空间连贯** | 场景空间关系合理 | 人物在A位置→下一镜头移动到B位置（有逻辑路径） |
| **情绪连贯** | 情绪节奏平稳过渡 | 高潮后不直接跳到平淡（需要缓冲镜头） |

### 11.2 镜头衔接禁忌

- ❌ **跳跃剪辑**：同一主体在同一角度突然跳变位置（除非刻意制造不安感）
- ❌ **轴线越界**：对话场景中，摄像机不应越过对话轴线（180度规则）
- ❌ **光线矛盾**：同一场景内光线方向前后不一致
- ❌ **色彩断层**：相邻镜头色温差异过大（如从暖黄直接切到冷蓝）
- ❌ **运动矛盾**：上一镜头向左运动→下一镜头无交代直接向右运动
- ❌ **动作倒序/重复**：人物已完成某个动作（如开车门、下车），下一镜头又重复该动作或执行该动作的前置步骤
- ❌ **运动方向未标注**：分镜备注栏未标注主体运动方向，或标注方向与实际画面描述矛盾

### 11.3 分镜衔接自检

每条分镜生成后，检查相邻镜头：
- ✅ 色调是否有明显断层？
- ✅ 主体位置是否突兀跳变？
- ✅ 运动方向是否连贯？（对照备注栏标注的方向）
- ✅ 人物动作时序是否连贯？（无倒序、无重复）
- ✅ 光线方向是否一致（同场景内）？
- ✅ 情绪节奏是否平稳过渡？

## 十二、分镜与情绪节奏对应

### 12.1 情绪曲线在分镜中的落地

分镜是将剧本的情绪节奏转化为视觉语言的关键环节。每个镜头的景别、运镜、时长都必须服务于当前镜头所处的情绪阶段。

> 情绪节奏曲线详见 `2-09-剧本生成详细规则.md` 第十节。

### 12.2 情绪阶段→分镜参数映射

| 情绪阶段 | 景别选择 | 运镜选择 | 镜头时长 | 剪辑节奏 |
|---------|---------|---------|---------|---------|
| **冲击/钩子** | 特写或大远景（反差感） | 快速推进或快速切换 | 短（1-2秒） | 快切 |
| **铺垫/建立** | 全景→中景（渐进） | 缓慢平移或固定 | 中（2-4秒） | 平稳 |
| **发展/递进** | 中景→近景（聚焦） | 跟随或缓慢推进 | 中（2-3秒） | 渐快 |
| **高潮/爆发** | 特写+快切（冲击力） | 快速切换/动感运镜 | 短而密集（1-2秒/镜） | 快切 |
| **升华/情感** | 中景→全景（释放） | 缓慢拉远或升格 | 中（2-4秒） | 放慢 |
| **收束/CTA** | 中景或特写（稳定） | 固定 | 中（2-4秒） | 稳定 |

### 12.3 分镜节奏自检

- ✅ 开场镜头是否在1-2秒内建立视觉焦点？
- ✅ 高潮段落是否用了短镜头+快切？
- ✅ 高潮前后是否有缓冲（不会让观众疲劳）？
- ✅ 结尾镜头是否稳定收束？
- ✅ 整体景别变化是否有层次感（不是全程同一景别）？

## 十三、分镜图→场景图的衔接规则

### 13.1 分镜图与场景图的定位差异

| 维度 | 分镜图 | 场景图 |
|------|--------|--------|
| **目的** | 确认镜头设计和节奏 | 作为视频生成的参考帧 |
| **质量** | 草稿级，快速预览 | 高质量，精细化 |
| **细节** | 构图/位置/氛围大致准确 | 商品细节/人物细节/光照/材质必须精确 |
| **一致性要求** | 大致风格统一 | 强制一致（商品/人物/风格/光照） |
| **用户确认** | 确认镜头编排是否合理 | 确认每个镜头的画面效果 |

### 13.2 分镜图→场景图必须继承的元素

| 继承元素 | 说明 | 优先级 |
|---------|------|--------|
| **构图** | 主体位置、画面比例、取景范围 | 必须继承 |
| **景别** | 远景/全景/中景/近景/特写 | 必须继承 |
| **运镜方向** | 运镜类型和方向 | 必须继承 |
| **商品位置** | 商品在画面中的位置和展示方式 | 必须继承 |
| **人物位置** | 人物在画面中的位置和姿态 | 必须继承 |
| **色调倾向** | 整体色调和氛围 | 必须继承 |
| **光照方向** | 光线方向（在同场景内一致） | 必须继承 |

### 13.3 分镜图→场景图可以优化的元素

| 优化元素 | 说明 |
|---------|------|
| **材质细节** | 从草稿级升级为真实材质质感 |
| **光照质感** | 从简单光照升级为精细化光照（高光/阴影/反射） |
| **背景细节** | 从简单背景升级为丰富但不抢主体的背景 |
| **景深效果** | 添加虚化/景深层次 |
| **色彩精度** | 从大致色调升级为精确色彩控制 |

### 13.4 衔接自检

场景图生成后，与对应分镜图对比：
- ✅ 构图是否一致？（主体位置、取景范围）
- ✅ 景别是否一致？
- ✅ 商品/人物位置是否一致？
- ✅ 色调是否一致？
- ✅ 整体氛围是否一致？
- 如有偏差 → 以分镜图为准调整场景图

## 十四、运动方向轨迹图

### 14.1 定义

运动方向轨迹图是分镜脚本完成后自动生成的一张**全片运动方向可视化示意图**，用于让用户和 Skill 直观检查所有镜头中人物、车辆、商品等主体的运动方向是否连贯、是否存在矛盾。

### 14.2 生成时机

分镜脚本生成完毕后（6.1 完成后），在进行质量检查和用户确认之前自动生成。与分镜脚本摘要一同展示给用户。

### 14.3 图形规范

- **布局**：所有镜头按时间顺序从左到右横向排列，形成时间轴
- **每个镜头**：用简笔框图（方块）表示，标注镜号
- **运动标注**：
  - 用**虚线 + 箭头**标注该镜头中主体（人物/车辆/商品）的运动方向和路径
  - 标注格式：→左到右 / ←右到左 / ↑前到后 / ↓后到前 / ↻原地旋转 / 无箭头表示静止
  - 每个镜头框内只标注主要运动主体；多个主体时分别标注
- **镜头连接**：相邻镜头之间用连接线串联
- **矛盾标记**：相邻镜头运动方向矛盾时（如前一镜→右，后一镜←左，且无合理转身/转向说明），用红色 ⚠️ 标记在连接处

### 14.4 作用

- 让用户在视频生成前就能发现运动方向不一致的问题
- 为分镜质量检查（铁律7）提供可视化依据
- 减少"成片后才发现方向矛盾"导致的返工

### 14.5 示例

```
时间轴 →

┌─────┐      ┌─────┐      ┌─────┐      ┌─────┐
│ 1   │─────→│ 2   │─────→│ 3   │──⚠──→│ 4   │
│特写  │      │中景  │      │近景  │      │全景  │
│→左到右│     │→左到右│     │↑前到后│     │←右到左│
└─────┘      └─────┘      └─────┘      └─────┘

镜头3→4 运动方向矛盾：镜头3物体向前运动，镜头4突然向右运动，需检查是否需要调整
```

### 14.6 检查规则

轨迹图生成后，Skill 自动检查：
- ✅ 所有镜头是否都标注了运动方向
- ✅ 相邻镜头运动方向是否连贯（无矛盾或矛盾已有合理转向说明）
- ✅ 人物动作时序是否连贯（无倒序/重复动作）
- 发现矛盾 → 自动标红并提示用户修正分镜脚本
