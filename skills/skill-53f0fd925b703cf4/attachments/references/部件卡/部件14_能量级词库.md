# 部件卡14 · 能量级速度词库

## 四档能量级（写动作/运镜前选词）
| 能量级 | 速度定性词库（选≥3个） | 示例 |
|:------|:--------------------------------|:----|
| L1 静止凝视 | 极缓、微动、几乎不动、悬停、锁定不动 | 静态眼瞳光/微呼吸/衣摆极缓摆 |
| L2 日常行动 | 稳步、均匀、从容、节拍感、不快不慢 | 「像踩着一个缓慢而固定的节拍」 |
| L3 急促行动 | 急促、快速、步频明显加快、迅猛、紧凑 | 「快速有目的有节奏的行走步速」 |
| L4 爆发动作 | 爆发、骤然、猛然、急骤、瞬间、一次完成 | 「迅猛冲刺」「瞬间爆发」 |

## 能量级变化（同一子镜头内切换）
```
能量级：L3急促 → L1静止（镜尾5秒处切换）
速度词库选"高潮能量级"和"低潮能量级"各2个，确保速度定性词覆盖整段。
```

## 禁词
- 空载体慢词（缓慢/匀速/平稳/轻微）在L1/L2段必须有可见运动载体（节拍感+微细节≥3），空写"缓慢地X"无载体=违禁
- 运镜禁词：不可察觉/barely perceptible（改成"呼吸级"表述，见SKILL.md）
