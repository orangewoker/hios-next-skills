## 二、题材叠加规则

**S级组合**（爆款概率最高）：
- 霸道总裁+甜宠（最主流）
- 重生穿越+古装宫廷（复仇+权谋双线）
- 重生穿越+霸总（现代先知碾压）
- 替身文学+追妻火葬场（虐→反转→甜）
- 先婚后爱+萌宝（契约→孩子助攻→真爱）

**A级组合**（差异化强）：
- 软科幻+甜宠（未来设定反差萌）
- 悬疑探案+都市情感（探案中谈恋爱）
- 性别反转+职场反卷（双重反差）
- 战神归来+都市情感（强武力+柔情）

## 三、平台合规红线

### 绝对禁止（出现即下架）

| 类别 | 具体内容 |
|:---|:---|
| **政治类** | 涉及国家领导人、敏感历史事件、分裂主义、邪教组织、政治隐喻 |
| **暴力类** | 血腥肢解、虐待酷刑、自杀方法细节、校园霸凌美化、家庭暴力美化 |
| **色情类** | 裸露性器官、性行为描写/暗示、色情交易、未成年人性暗示 |
| **违法类** | 吸毒/制毒、赌博技巧、诈骗方法、非法集资、侵犯隐私 |

### 高风险灰区（需技巧处理）

| 类别 | 风险点 | 处理方式 |
|:---|:---|:---|
| **价值观** | 拜金主义、嫌贫爱富、以貌取人 | 主角最终靠实力而非财富/美貌获胜 |
| **关系类** | 小三上位、乱伦暗示、师生恋 | 设置道德边界，明确对错立场 |
| **表现手法** | 过度恐怖、长时间血腥、密集恐惧 | 用光影/音效替代直接画面，控制时长 |

### 题材常见踩坑点

| 题材 | 风险 | 规避 |
|:---|:---|:---|
| 战神归来 | 武力滥用、以暴制暴 | 设置正当防卫前提，体现"守护"而非"施暴" |
| 霸道总裁 | 物化女性、强取豪夺 | 女主保持独立人格，有自主选择权 |
| 重生穿越 | 篡改历史、架空涉政 | 明确"纯属虚构"，避免真实历史人物 |
| 古装宫廷 | 宫斗价值观负面 | 给予正义结局，体现善恶有报 |
| 悬疑探案 | 过度血腥、模仿犯罪 | 省略作案细节，强调正义必胜 |

## 四、正向价值观要求

- 结局必须体现"善恶有报"：反派受到应有惩罚，主角凭借努力/智慧/善良获胜
- 爱情观健康：禁止美化出轨/包养/权色交易，主角关系基于平等尊重
- 反面对照处理：反派行为必须有明确的负面后果，不能让观众模仿
- 女性角色独立：不能沦为男性附属品，有独立的欲望/目标/成长线

## 五、合规自检

### 逐集自检（Phase 2 分镜输出前）
- [ ] 是否有涉及政治/暴力/色情/违法的红线内容？
- [ ] 反派行为是否有明确的负面后果？
- [ ] 主角价值观是否正向？
- [ ] 是否有可被模仿的危险行为（打架招式/自杀方式/犯罪手法）？
- [ ] 女性角色是否有独立人格？

### 出海额外注意
- 避免中式叙事陷阱：长篇背景铺垫、含蓄情绪表达、等级观念美化
- 出海翻译注意：称谓体系（兄/姐/叔/姨→名字或Mr/Ms）、成语典故→直白表达
- 已验证出海爆款元素：狼人/吸血鬼/亿万富翁/契约婚姻/秘密继承人/双重身份
