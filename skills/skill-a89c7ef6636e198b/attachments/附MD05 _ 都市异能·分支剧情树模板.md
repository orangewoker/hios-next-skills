# 附MD05 | 都市异能·分支剧情树模板

**所属主SKILL：** 都市异能 · 超级英雄 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“剧情线混乱、分支无收束”的痛点。

## #需要什么输入

- 主线剧情节点清单、核心抉择点设计。

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·异能觉醒（start节点）
2. N02 抉择点1·面对抢劫犯（branch节点）
   - N02A 动用异能阻止（暴露风险，破坏度+10）
   - N02B 隐忍不救（英雄值-10，理智值-10）
3. N03 引起神秘组织注意（normal节点）
4. N04 抉择点2·面对堕落英雄（branch节点）
   - N04A 与其合作，加入体制（声望+20，底线-20）
   - N04B 拒绝并宣战（被追杀，城市破坏+20）
5. N05-N08 层层推进（如：突袭总部、天台决战）
6. ENDING_CHECK 结局判定
