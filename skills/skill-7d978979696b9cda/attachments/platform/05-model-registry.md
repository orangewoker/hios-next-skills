# 在网页确认模型与实际选项

立项模型意向、首次生成、网页配置变化、操作失败或换模型时使用。输入是用户偏好/锁定、当前网页会话中Agent实际可见的模型与工具选项、任务用途和预算。读取这些信息是Agent的工作，不要求用户准备开发者资料。

## 三层身份

用户展示名、工具返回的平台标识（如有）、底层厂商型号分别保存。未提供的底层映射留未知，不妨碍使用实际可用的网页模型。例如Lib Image仍写Lib Image，不改称GPT Image 2；Seedream5.0Pro不沿用Lite，Seedance2.5不沿用2.0或旧Beta参数。

偏好与锁定分开：常用模型优先，用户明确本次必须用则保持该选择边界。查询失败、旧缓存缺项不是换模型许可。仅在用户已允许的网页模型范围内比较替代；否则说明具体可选项和影响。能力不足不导向CLI、外部API或外部剪辑。

## 按本次用途登记

| 信息 | 实际保留什么 |
|---|---|
| 目标与身份 | 用户要求、网页展示名、当前选中项，工具实际返回的标识及来源 |
| 可用输入 | 本次工具说明/网页选项所接受的内容、模式和限制；schema如实际提供则自行使用，不要求取得未暴露的底层字段 |
| 引用与媒体 | 当前接受的素材和引用方式、与本次操作有关的数量/时长/格式限制、结果位置及可观察范围 |
| 执行与恢复 | 实际回执/状态、已有查询和恢复方式；取消或幂等不凭空假定 |
| 费用 | 计费单位、业务数量、提示或报价日期与上界；显示耗时不是价格 |
| 证据状态 | 按[核心记录](../core/03-records.md)区分documented/verified/unknown/unavailable，注明范围 |

表格不要求每个未知项都补齐才写剧本或调用无关能力。真正需要某项而无法确定时，只限制依赖它的操作。厂商资料和旧CLI研究仅是有边界的参考，不代替当前网页选项或结果；工具可用也不证明本场表演成功。

## 选择与故障分支

1. 当前网页Agent已能选择目标模型、接受本次输入：按实际工具方式核对引用、预算和保存条件，交[调度](../generation/04-scheduling.md)，不额外要求用户给model key/schema。
2. 只见过展示名，但当前没有可用的相关操作：保留偏好和具体缺口，继续不依赖该操作的写作/导演/提示语义方案，不虚构已经可生成。
3. 名称重名、选项含义不清或结果与说明冲突：Agent核对自己可见的信息并收窄到本次操作，不猜字段；需要用户决定时只问创作选择或费用范围。
4. 当前网页明确不支持该操作或权限不足：记录条件，继续可做部分；不因缺失底层schema就宣称模型不可用，也不寻求外部执行。
5. 配置或选择变化：新Job版本保留实际输入变化与影响，旧Attempt快照不原地改写。

2026-09-06基线：既有网页菜单显示Lib Image、Seedream 5.0 Pro、Seedance 2.5，尚未在本候选中实际生成。Seedream5.0Pro和Seedance2.5有厂商发布证据，Lib Image底层映射未证实。名称展示不能证明引用、收费或生成质量，但无需把索取全平台工具资料交给用户。各模型方法见[Lib Image](02-lib-image.md)、[Seedream](03-seedream-5-pro.md)、[Seedance](04-seedance-25.md)，证据见[平台](01-libtv-capabilities.md)与[来源](../evidence/01-sources.md#models)。
