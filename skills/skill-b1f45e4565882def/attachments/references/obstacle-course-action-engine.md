# 真人水上闯关动作引擎

## 路线锁定合同

先加载 `obstacle-game-library.md` 并抽取一个完整 `water_run`。将其六段链逐字复制为 `locked_route`；最终提示词的每一段只能使用 `locked_route` 对应位置的障碍和动作。不得回退到默认浮墩、浮块、荡绳、篮球或扣篮链，也不得从其他路线借用关卡。

固定使用碧蓝水池、蓝黄软垫、起点高台和欢呼观众席。所有路线最后一段均为：攀登到高台顶部，按下实体红色通关按钮。

## 画面洁净合同

- 全程不添加右上角计时器、倒计时、分数牌、数码表、HUD 或常驻数字贴片。
- 镜头切换与观众反应承担节目节奏，不依赖文字或数字叠层。

## 安全与可读性

- 角色是成年参赛者；所有落点为本次路线的软垫、平台、网绳、水池或安全高台。
- 动作要有清楚起跳、穿越、落点和起身，不生成摔伤、失控坠水、危险碰撞或不合理肢体。
- 红色通关按钮必须是实体、圆形或蘑菇头式、安装在高台顶部可按面板上；不是 HUD、悬浮图标或文字按钮。
