# 附MD04 | 宫斗·变量与结局扩展

**所属主SKILL：** 宫斗 · 步步惊心 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“变量设定空洞、结局无分支”的痛点。

## #需要什么输入

- 核心变量清单。

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 恩宠值：counter，0-100，默认0；≥60宠冠六宫。
2. 谋略值：counter，0-100，默认0；≥60算无遗策。
3. 太后好感：relationship，0-100，默认0；≥70获得庇护。
4. 宫人敬畏：faction，0-100，默认0；≥80无人敢欺。
5. 杀机值：risk，0-100，默认0；≥80暗杀降临。

### 二、结局体系（共15个）

正结局（5个）

1. E01·垂帘听政：恩宠+谋略双高，扶持幼帝。
2. E02·一世荣宠：恩宠值极高。
3. E03·宫外逍遥：假死出宫。

坏结局（10个）

1. D01·打入冷宫：恩宠值&lt;10。
2. D02·一丈红：被反派陷害。
