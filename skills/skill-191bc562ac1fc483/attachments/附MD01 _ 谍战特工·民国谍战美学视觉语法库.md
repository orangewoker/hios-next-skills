# 附MD01 | 谍战特工·民国谍战美学视觉语法库

**所属主SKILL：** 谍战特工 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“谍战特工 | 上架Steam的互动影游”的专属民国谍战美学视觉语法库。

解决互动影游在AI生成时“视觉风格漂移、谍战氛围不足、民国质感缺失、暗调氛围廉价、场景质感降级”的痛点。确保全片画面保持高度一致的民国谍战美学调性，特工冷峻，身份分明，压迫感强。

## #需要什么输入

**最少提供：**

- 剧本或故事梗概
- 特工与关键阵营NPC的姓名、设定、外貌锚点
- 核心场景清单（如百乐门舞厅、76号特务机关、密室电台、雨夜街巷等）

**可选提供：**

- 核心情报道具设定（如密电码本、发报机、假证件等）
- 特定光影偏好
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。视觉语法环节重点参考【提示词】底座的物理光学参数与【大导演思维】的镜头逻辑。

### 二、核心美学基调

1. **民国谍战写实**：低饱和、高反差、深暗部、暗青暗红主调。
2. **百乐门舞厅**：霓虹灯牌、舞池灯球、烟雾缭绕、纸醉金迷。
3. **特务机关**：阴冷走廊、铁门禁闭、审讯室、档案室。
4. **雨夜街巷**：青石板路、黄包车、霓虹倒影、雾气弥漫。
5. **密室电台**：烛光摇曳、发报机嘀嗒、密电码堆积。
6. **东方写实**：仿真人质感、民国高级感、电影级厚重，拒绝塑料感与廉价CG感。

### 三、色彩系统（强制锁定）

1. **暗青**：色值 #2A3A4A；用途为雨夜、特务机关、压抑基调。
2. **暗红**：色值 #8B0000；用途为霓虹灯牌、血迹、危险警示。
3. **复古黄褐**：色值 #8B6F47；用途为老上海建筑、黄包车、旧报纸。
4. **暖黄**：色值 #D4782F；用途为百乐门灯光、密室烛光、台灯。
5. **冷白**：色值 #E8E4D8；用途为审讯室、医院、月光。
6. **纯黑**：色值 #000000；用途为深色空间、压暗对比。

**绝对禁止**：高饱和荧光色、赛博朋克紫、廉价塑料质感、明亮清新色调。

### 四、专属场景视觉语法

1\. 百乐门舞厅

- 视觉特征：霓虹灯牌、舞池灯球、烟雾缭绕、乐队演奏。
- 主光源：暖黄霓虹+舞池灯球，色温3200K，高反差。
- 材质：玻璃灯球、丝绒座椅、金属栏杆。

2\. 76号特务机关

- 视觉特征：阴冷走廊、铁门禁闭、审讯室、档案室。
- 主光源：顶光冷白，色温5000K，明暗对比强烈。
- 材质：水泥墙面、铁门锈蚀、木质档案柜。

3\. 雨夜街巷

- 视觉特征：青石板路、黄包车、霓虹倒影、雾气弥漫。
- 主光源：霓虹冷光+路灯暖黄，色温4000K。
- 材质：湿滑石板、砖墙斑驳、玻璃反射。

4\. 密室电台

- 视觉特征：老旧发报机、密电码、烛光台灯、暗格。
- 主光源：烛光暖黄，色温2800K，局部照明。
- 材质：木质桌面、金属发报机、纸质密电码。

5\. 火车车厢

- 视觉特征：木质车厢、窗外飞逝的风景、皮质座椅、行李架。
- 主光源：车厢顶光，色温3800K，暖调为主。
- 材质：木质车厢、皮革座椅、金属行李架。

6\. 教堂/暗巷

- 视觉特征：哥特式建筑、暗巷转角、雨幕、霓虹倒影。
- 主光源：霓虹冷光+教堂彩窗，色温4500K。
- 材质：青石墙面、玻璃彩窗、铁艺栅栏。

### 五、角色视觉语法

1\. 特工

- 外貌：气质冷峻睿智，五官深邃，眼神锐利，身形挺拔。
- 服装：民国深色风衣、高定西装或旗袍，材质真实，有质感。
- 光影：主光冷白，逆光暗红。
- 微表情：眼神锐利、嘴角微抿、眉心微蹙、下颌紧绷。

2\. 关键阵营NPC（上线/联络人/敌方特务头子）

- 上线/联络人：气质沉稳，眼神坚定，或沧桑历练。
- 敌方特务头子：气质阴鸷，眼神游移，面带微笑但暗藏杀机。
- 服装：根据身份设定，但必须与世界观统一。
- 光影：冷调侧光，暗部浓重。

3\. 关键女性角色（舞女/歌女/女特工）

- 外貌：气质鲜明，与身份匹配，眼神透露心思。
- 服装：高定旗袍或洋装，材质真实，有身份符号。
- 光影：柔和侧光或局部照明。

4\. 反派/叛徒

- 外貌：气质阴冷或伪装温和，眼神暗藏杀机。
- 服装：深色高定或素色长袍，配金属配饰。
- 光影：暗红冷光，阴森压抑。

### 六、核心情报道具视觉语法

1. 密电码本：纸质泛黄，墨迹清晰，蜡封完整，有密级符号。
2. 发报机：金属拉丝，按键磨损，有年代感。
3. 假证件：纸质泛黄，照片泛旧，印章清晰。
4. 微型手枪：金属拉丝，口径小，有隐秘感。
5. 毒药：玻璃小瓶，液体透明，有危险暗示。
6. 暗号信物：金属或木质，小巧精致，有隐蔽性。

### 七、交互UI视觉语法（互动影游专属）

1\. 选择界面规范

- 字体：极简无衬线或打字机字体。
- 主色：暗金 #D4AF37。
- 警告色：暗红 #8B0000。
- 背景：半透明黑色80%。
- 按钮：档案夹样式或密电码样式，金色描边。
- 变量提示：身份暴露度+40·情报值+25（按项目实际变量替换）。

2\. 变量变化视觉反馈

- 变量增加时：屏幕飘出暗金色+数字。
- 变量减少时：屏幕飘出暗红色-数字。
- 触发死亡结局时：屏幕闪红+黑屏。
- 触发真结局时：屏幕闪金+慢镜头。

3\. 结局画面情绪收尾

- 好结局：暖光+缓慢拉远+余韵。
- 坏结局：冷光+黑屏+一句话收尾。
- 真结局：暗金史诗感+环形镜头。

### 八、光影与运镜专属规范

1. 绝境压抑：顶光/底光，色温2700K，低角度仰视。
2. 悬念对峙：侧光，色温3200K，中景。
3. 真相揭露：逆光，色温4000K，超广角仰拍。
4. 结局收尾：晨光，色温5500K，远景缓拉。

### 九、防崩要求

1. 谍战光效必须冷调，禁止高饱和死光。
2. 百乐门霓虹必须克制，禁止廉价赛博朋克。
3. 情报道具必须1:1真实物理比例，禁止缩小放大。
4. 阵营NPC必须有辨识度，禁止撞脸。
5. 服装必须民国高定质感，禁止廉价塑料感。
6. 人物面部必须保持真实毛孔质感，禁止磨皮美颜。
7. 血腥必须克制，禁止过度血腥。
