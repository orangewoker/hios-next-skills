# 高端三维写实 CG 女性角色资产模板

## 生成目标

用于把剧本中的女性角色转化为固定身份的三维动画角色设定参考图。默认采用高端写实 CG 乙游审美，但必须服从角色年龄、身份、时代和剧情气质，不把所有女性都强行做成甜美少女。

## 正向模板

高端三维写实 CG 女性角色设定参考板，次世代剧情 CG 质感，Unreal Engine 5 cinematic character render，电影级构图，16:9 横屏，低饱和电影调色，柔和主光，冷色环境补光，细腻轮廓光，真实 PBR 材质，真实 subsurface scattering 皮肤透光，真实皮肤纹理，毛孔清晰，轻微雀斑与细小瑕疵，自然肤色层次，鼻梁、眼下和脸颊有自然细微油光，嘴唇湿润高光，眼睛湿润反射，眼睑、睫毛和泪沟细节清晰，头发一缕一缕分明，发丝分层清晰，服装和饰品具备真实反射、微小磨损与结构接缝。

同一女性角色的横版角色设定参考板：左侧为正面全身、侧面全身、背面全身三视图，头部高度一致、脚底对齐、服装和发型一致；右侧为正面头肩近景、三分之四侧脸、纯侧脸、背面头发参考、平静表情和角色指定表情。脸型、眼睛、鼻子、嘴唇、下颌线、发际线、发长、妆容和服装在所有视图中完全一致。中性干净背景，无文字、无标签、无水印。

## 妆容选择规则

先从剧本身份和情绪中选择一套主妆容，再生成最终提示词。候选可以包括清润甜系、清冷白月光、明艳贵女、病弱破碎、珍珠神女、现代职场、古风仙气、哥特暗黑等方向。最终只保留一套主妆容，不能混合成脸部特征冲突的拼接妆。

不要小眼睛，不要廉价 CG，不要塑料皮肤，不要蜡像感，不要过度磨皮，不要脸型漂移，不要年龄漂移，不要发型和服装漂移，不要五官混合，不要妆容脏乱，不要过度性感化，不要动态姿势，不要单人海报，不要文字和水印。
