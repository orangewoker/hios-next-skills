### Phase 5：AGENT-3 七段式整合输出

读取 [references/storyboard-spec.md](references/storyboard-spec.md) 获取七段式输出格式。

对每个镜头，按七段式结构输出完整方案：

```
镜N（时间码）：[镜头标题]

【一、画幅与摄影机系统】
摄影机+镜头+光圈+画幅+帧率+快门+介质+选型理由

【二、叙事核心与镜头语法】
景别+运镜+视角+构图+叙事理由+情绪外化

【三、光线架构与氛围】
主光+辅光+轮廓光+氛围介质（含方向/色温/强度）

【四、色彩科学与胶片质感】
主色/辅色/点缀色色号 + 胶片响应 + LUT参照

【五、质感与去AI感工程】
瑕疵美学列表 + 肤质引擎检查 + 拍摄损失 + 负向排除词 + **镜头配方卡已知坑校验**（如本镜选用了 shot-cards/ 中的配方卡，必须逐条核对该卡的"已知坑"和"命门"参数，确保未降档）

【六、放大保真质量锁】
微观质感 + 分辨率保障 + 时间稳定

【七、声景空间设计】
对白层 + 动作音效 + 环境声场 + 声画关系

【视频生成提示词整合输出】
七段式设计完成后，将该镜头的全部信息整合为一个完整的、可直接执行的视频生成提示词。视频生成提示词以普通文本格式输出，不使用 plaintext 代码块包裹。

**prompt分层架构（强制）**：
prompt采用分层结构，从上到下依次输出，每层用空行分隔：

1. **顶层声明**：全局约束（如：无背景音乐、无字幕、仅保留电影级声效音效、场景不可穿帮）
2. **通用固定参数**：全程统一的摄影/胶片/镜头/光影/色彩参数（每个镜头复用，保持一致性）
3. **主体参考**（如有角色）：@图片N 是角色N（含用户对参考图的说明），@音频N 是角色N的音色（含音色描述词）
4. **角色行为锚定**：每个角色的持续性动作、习惯、道具、体貌标记（如：角色A全程叼烟+抖腿+中指银色戒指；角色B左手始终插在裤兜）。不是静态外貌描述，而是让角色"活着"的动态行为
5. **时间码分镜**（如有多镜头段）：按 `X-Y秒，镜头N：景别/运镜方式` 格式精确标注，镜头间写明衔接逻辑（如：延续上一镜逻辑，切换到...）
6. **角色名台词**（强制使用剧本原名，禁止代称）：角色原名说："台词内容"
7. **人物微观生命力**（强制）：人物无意识随机自然眨眼，随情绪节奏自然呼吸，细微肢体语言（手指摩挲、舔嘴唇、眼神游移等）
8. **负面约束**（具体到可执行，禁止空泛）：统一收纳，必须包含无暗角、无边缘压暗、无四角晕影；同时根据场景追加具体缺陷（如：无泥点、无霉斑、无灰斑、无重颗粒噪点、低ISO、无明显脏污）

**角色行为锚定规则**：
- 每个角色至少1个持续性动作或习惯标记（抽烟/抖腿/转笔/摸鼻子/拨头发等）

**角色超自然视觉锚定规则**（涉及奇幻/科幻/超自然元素时强制）：
- 角色的超自然能力必须绑定为**全程可见的视觉标记**（如：眼睛全程发红色光芒 / 全身散发淡绿色气息 / 手指缠绕金色电弧）
- 能力发动时追加**动态特效标记**（如：瞬移伴随淡红拖影+哀嚎声 / 武器散发诡异绿色气息 / 剑身金气缠绕）
- 特效标记必须在角色首次出现时锚定，后续镜头复用，确保跨镜一致性
- 格式：`角色名全程/全程+[状态]：[视觉特效描述]`

**环境氛围硬规则**（涉及特殊世界观时强制）：
- 世界观级环境效果必须声明为**全程强制存在**，不是"可能出现"
- 格式：`**整座[场景]+[效果]**`（如：**整座地狱城市漂浮着淡红色灰烬** / **空气中始终悬浮着金色微粒**）
- 每个特殊环境至少1条硬规则，确保世界观质感跨镜统一

**镜头内运镜规则**：
- 单镜头内摄影机可以有运动（向右缓慢移镜 / 向上移镜 / 缓慢拉镜 / 环绕），不是只有定镜
- 镜头内运镜必须写明起止焦点（如：镜头先是聚焦A，缓慢右移到虚化的B背面）
- 焦点转移时写清虚实关系（前景实→背景虚，或反之）

**武器/道具出场仪式规则**：
- 重要武器或道具的出场必须作为**事件**设计，不是静态出现
- 出场序列：凭空出现（特效前兆）→ 被角色持握 → 定格展示 → 投入动作
- 每次武器状态变化（出鞘/蓄力/激活/受损）都必须有对应的视觉反馈

**台词类型标注规则**：
- 画内台词：角色名说："台词内容"（角色在画面中说话）
- 画外音：角色名画外音："台词内容"（角色不在画面中或画面已切走）
- 呐喊/招式名：伴随角色名画外音："招式名！"（动作同步发出）
- 禁止使用"他大喊""她低语"等代称描述，必须写角色原名

**风格级反向禁令**（放在负面约束末尾）：
- 根据题材追加整句风格否定（如：禁止动画感，禁止CG感，禁止游戏风格 / 禁止卡通化，禁止Q版，禁止二次元）
- 与具体缺陷约束分层：先写具体缺陷（无泥点、无霉斑……），再写风格禁令
- 显著道具或体貌标记必须在首次出现时锚定（戒指/疤痕/眼镜/纹身等）
- 行为锚定词在prompt中复用，确保跨镜一致性
- 禁止角色静止不动——即使无台词也必须有呼吸、眨眼、微动作

**人物微观生命力规则**（强制注入，详见 [references/character-performance-guide.md](references/character-performance-guide.md)）：
- **眼神生命（强制）**：视线不断移动（微眼跳），眼睛先于头部转动到达目标；眨眼频率与状态绑定（压力下快速连续、控制时缓慢平静）；眼神高光必须湿润有光——死眼神是AI表演第一大破绽
- **身体状态先于心理**：重心（高=自信/低=疲惫）、呼吸（急促=恐慌/缓慢=控制）、Business（角色始终有正在做的事，动作中断=最强重音）
- 细微肢体语言：手指微动、重心微调、喉结滚动、嘴角微颤等
- 表演循序渐进，情绪变化渐进，禁止瞬间爆发、禁止无代价情绪
- 写状态不写过渡：描述角色已处在动作状态中，不描述进入过程

**负面约束精准化规则**：
- 禁止空泛约束（如"画质不要差""不要伪影"）
- 必须具体到可辨识的缺陷：无泥点、无霉斑、无灰尘污渍、无重颗粒噪点、无色彩断层、无漂浮物体、无违反物理规律
- 根据场景追加针对性约束（室内：天花板无水渍；户外：植物无塑料感；人物：面部无绝对对称、无磨皮美颜）

完整prompt示例：
```
故事片片段，真人实拍，无背景音乐，无字幕，仅保留电影级环境音效。顶级电影质感，顶级视效。场景不可穿帮。

【通用固定参数】胶片拍摄，逼真光影效果，细腻胶片颗粒，简洁构图，柔和自然光，低饱和度，低对比度，色调均衡，柔和阴影，温暖真实色彩，柯达Portra400，电影级景深，清晰聚焦。使用135mm焦段镜头，光圈f/2.0，浅景深，写实摄影风格，动态模糊。手持镜头，轻微晃动仿手持感。

@图片1 是留书君，@音频1 是留书君的音色，低沉沙哑、疲惫克制、语速缓慢。
留书君全程行为锚定：右手无意识转动钢笔，中指银色旧戒指，嘴角微微下撇。
留书君微微呼吸，眼神从桌面缓慢抬起，无意识眨了一次眼。

0-4秒，镜头1：远景/缓慢推镜，镜头聚焦街道场景，留书君从画面右侧入画，抽着烟，坐在摊位旁边的木凳上，抖着腿。
5-7秒，镜头2：近景/定镜，延续上一镜逻辑，切换到留书君面部，留书君的眼神微微游移，喉结轻滚。

留书君说："你到底来不来。"

[负面约束: 无暗角，无边缘压暗，无四角晕影，无泥点，无霉斑，无重颗粒噪点，无色彩断层，低ISO，无漂浮物体]
```

该prompt可直接丢进 Seedance 2.0 Mini 执行，无需任何后续拆分、剪辑或合成。
```

**每镜头输出后立即自检（不可跳过）**：每个镜头prompt输出后，必须立即执行三维自检——①叙事：节拍完整/情绪曲线流畅/运镜有叙事理由；②摄影：三件套齐（摄影机+镜头+光比）/瑕疵≥3项跨≥2类别/已知坑命门参数未降档；③合规：角色名无代称/@引用完整/无暗角/微观描述具体。自检不通过的镜头必须当场重写，不进入下一镜。
