### **二、镜头语言系统**

**出拳/命中瞬间：**

- 出拳蓄力 → MS中景STATIC（看到全身发力）

- 拳头命中瞬间 → CU近景LOCK-OFF（看到冲击点）

- 受击方反应 → MCU中近景PUSH-IN（看到表情+身体反应）

- 港片经典用法：命中瞬间切ECU极近景，立刻切WS全景，两个极端景别硬切=最大冲击力

**飞出撞墙：**

- 飞出阶段 → WS全景TRACK-RIGHT（跟拍飞行弧线）

- 撞墙瞬间 → WS全景LOCK-OFF（看到整体冲击）

- 墙裂特写 → ECU极近景LOCK-OFF（看到裂纹细节）

- 禁止：飞出阶段用CU

**倒地收势：**

- 倒地过程 → MS中景PULL（拉镜展示倒地全程）

- 最终倒地 → WS全景LOCK-OFF（交代空间关系）

- 富贵收势 → MS/MCU低角度仰拍（主角主导感）

- 港片经典用法：低角度仰拍富贵收势→压迫感最强；富贵背对镜头走开→留白感

**多人混战：**

- 建立全局 → WS全景（交代人数和位置）

- 单次打击 → MS/MCU（聚焦当前这一击）

- 连续打倒多人 → WS广角跟拍（展示连续性）

- 禁止：全程用WS；全程用CU

**景别切换黄金公式：**\
WS建立 → MS动作 → CU/ECU冲击 → MCU反应 → WS结果

**机位角度选择逻辑：**

- 正面机位：对峙/收势/压迫感

- 侧面机位：出拳/踢腿/飞出（港片首选）

- 低角度仰拍：富贵攻势/主角登场/压制敌人

- 高角度俯拍：多人混战全局/敌人倒地

- 斜45°机位：大多数打击动作（最常用）

**越轴规则：**

- 铁律：A始终左，B始终右，摄影机始终同侧

- 合法越轴只有3种：摄影机穿越轴线、角色自己转身、中性镜头过渡

**机位切换频率：**

- 动作节奏快 → 每0.5-1秒切一次

- 动作节奏慢 → 每2-3秒切一次

- 禁止：同一景别连续切两次

- 港片黄金切镜节奏：WS→CU→WS→MCU→ECU→WS

### **三、动作节奏设计**

**港片核心公式：**\
慢→快→慢（蓄力慢→爆发连击快→收势/受击反应慢）

**节拍密度控制：**

- 蓄力阶段：1-1.5秒，NORMAL/deliberate

- 出拳命中：每击0.5-1秒，SNAP/EXPLOSIVE

- 冲击帧：2-3帧（约0.1秒），轻微定格感

- 连击间隔：0.1-0.3秒

- 收势：0.5-1秒，NORMAL

**呼吸感设计：**\
每3-4击之后，必须有0.5秒停顿。停顿内容：收势/对视/环境反应。

**冲击帧设计：**\
命中瞬间1-3帧轻微定格，然后立刻恢复正常速度。提示词写法：brief impact freeze on contact, then explosive continuation。

**快慢对比数值：**\
蓄力×0.7 / 出拳×2 / 命中定格×0.1 / 飞出×1.5 / 倒地×0.8 / 收势×0.7。

### **四、摄影机位设计系统**

**一场打戏标准机位组合：**

- 建立镜头：WS全景，固定机位，2-3秒

- 动作主镜头：MS/MCU，侧面斜45°，每击1-2秒

- 冲击特写：CU/ECU，锁定机位，0.5-1秒

- 环境反馈：ECU，锁定机位，0.5-1秒

- 收势镜头：MS/WS，低角度仰拍，1-2秒

**低角度仰拍使用规则：**\
必须用：富贵收势/富贵逼近/富贵站在倒地敌人旁。\
禁止用：敌人出拳时/双方对等时。

### **五、动作连续性设计**

**重心转移连续性：**\
直拳命中后，重心在前脚，身体前倾，下一个动作必须从前倾状态启动。禁止出完拳立刻站直再出第二拳。\
提示词写法：weight shifting from rear foot to front foot, driving force through the strike。

**身体朝向连续性：**\
前板末帧A面朝右，右脚在前；后板首帧A必须面朝右，右脚在前。禁止突然变成左脚在前或面朝左。\
提示词写法：continuing from previous clip, A still facing right, weight on front foot, right arm follow-through position。

**距离连续性：**\
前板末帧A与B相距1米，后板首帧必须还是1米左右。禁止突然变成0.1米或3米。追击距离变化必须在提示词中明确写出。

### **七、场景与动作匹配逻辑**

**场景特性决定动作选择：**

- 狭窄空间（走廊/电梯）：近身短打/肘击/膝击/锁拿；禁用大幅度腿法/摔投

- 开阔空间（码头/广场）：全部动作类型；最佳大幅度腿法+摔投+飞出撞环境物

- 高低差场景（楼梯/屋顶）：借高低差踢腿/推落/跳击

- 潮湿场景（雨天/码头）：地面湿滑，可设计滑步动作；水花飞溅+积水倒影

- 夜晚霓虹场景（九龙后巷）：红绿霓虹光影交替；水滴触发/霓虹招牌震动

### **八、角色状态管理**

**敌人五级状态：**

- 状态一：完整战斗（未受击）——combat ready stance, aggressive

- 状态二：首次受击（轻度）——staggering slightly, still fighting

- 状态三：多次受击（中度）——heavily staggered, knees buckling, struggling to stay upright

- 状态四：终结受击（重度）——completely defeated, losing consciousness, dead weight collapse

- 状态五：倒地（战斗结束）——collapsed on ground, no longer a threat, fight over

**富贵状态规则（全程不变）：**

- 主动出击，不被动挨打（骨架A）

- 收势时面部冷峻，眼神锋利

- 每次出击后保持主导姿态

- 骨架B：前3秒允许被打中，F1痛苦拉满，F2渐退，F3冷峻

### **九、成片剪辑节奏**

**一场打戏标准结构：**

- 第一段建立（3-5秒）：WS全景，固定机位

- 第二段触发（2-3秒）：MS中景，推镜

- 第三段主要动作组（6-12秒）：多机位快切，节奏快

- 第四段环境反馈（3-5秒）：WS→ECU特写，节奏中

- 第五段终结（3-5秒）：CU命中→WS倒地，节奏快→慢

- 第六段收势（2-3秒）：低角度仰拍MS/MCU，节奏慢

**多镜头组合剪辑节奏：**\
建立镜头：2-3秒 / 动作镜头：1-3秒 / 冲击特写：0.5-1秒 / 环境反馈：0.5-1秒 / 收势镜头：1-2秒。\
剪辑节奏公式：长→短→长→短→短→长。禁止连续多个长镜头或连续多个短镜头。

**硬切vs转场：**\
港片动作戏标准：全部硬切，无转场。唯一例外：场景切换时可用极短叠化（≤4帧）。成片合成时：videoList = \[前3秒，后3秒\]，默认硬切。
