## 层1b 本类骨架清单（写正文前必抄，2026-08-04补）
```
本类场景（大场面/奇观）万物生原段里最值得抄的固定骨架，按需提取2-6条：
① 绝对化比例句：「[主体]从画面最[方位]一直延伸到画面最[方位]」（禁"很大"）
② 相对锚点句：「[主体]的头顶仅仅达到[参照物]的[部位]」（画"人头到人腰"比画"2倍高"可靠）
③ 群体参差句：「有的[维度1]、有的[维度2]、有的[维度3]形成参差错落的[群体状态]」（禁"各不相同"）
④ 大动作连锁声句：「每一次锤落整个铁匠摊的木架都在剧烈颤动,挂着的铃铛被震得叮当作响」（动作→环境连锁≥2级）
⑤ 逐级体型落差句：「紧贴在他摊位的左右两边各有一个正常体型的部落摊主...头顶仅仅达到铁匠的腰部位置」
⑥ 时间锚逐次升级句：「第七到第八秒之间人群涌入→第九到第十秒之间近景背影入画」
本类不抄：群体动作细节（给AI填充空间，用模糊数词"数十艘""数不清"）
```

## 层2 11样抄什么（每样配本类原段例句）
```
1.初始状态帧：例「铁匠的体型异常巨大,他在画面中的纵向高度从画面最顶部一直延伸到画面最底部」
2.运镜句：例「镜头在他面前缓慢横向滑过,从不同的横向位置展示他的庞大体型」（横移展示尺度）
3.分层句：例「紧贴在他摊位的左右两边各有一个正常体型的部落摊主...头顶仅仅达到铁匠的腰部位置」（逐级落差）
4.遮挡关系句：例「巨大的圆形大肚腩、宽阔得不成比例的胸膛、粗壮如柱的手臂」（体型逐部位锁定）
5.虚实焦句：例「近景巨物实焦+远景人群虚化」（远近分层）
6.声画绑定句：例「每一次锤落整个铁匠摊的木架都在剧烈颤动,挂着的铃铛被震得叮当作响」（大动作→连锁声）
7.声学属性句：例「锤头砸向砧上的清脆铛铛声clang clang clang」（重复打击声）
8.动作边界句（否定写正文）：例「人群一闪而过,继续向画面左方涌去」（去向锁定）
9.反应链句：例「人群中央抬着刘回...刘回的高度也仅仅到达铁匠的胸膛位置」（尺度反应链）
10.节拍切分句：例「第七到第八秒之间人群涌入→第九到第十秒之间近景背影入画」（时间锚逐次升级）
11.硬切声音延续句：例「市集嘈杂声跨镜延续」（切镜段抄）
```
