# 分镜指令库（主索引）

> **定位**：分镜提示词资料库的**主索引**文件，按题材拆分为独立子文件，便于 `/分集 {N}` Phase 2 时按需加载调用。
> **使用方式**：先根据本集题材检索下表 → 读取对应子文件 → 复制/改写分镜指令 → 嵌入分集生成流程。
> **适用模型**：即梦 Seedance、GPT Image 2、Midjourney v7、Flux 等通用文生图 / 文生视频模型。

---

## 前置必读：三层金字塔架构

整个分镜资料库按「宏观选型 → 微观执行」分为三层。Phase 2 生成分镜时，**按层级逐层调用，下游层不可跳过上游层**。

```
        ┌─────────────────────────┐
        │  ① 宏观选型层            │
        │  导演风格词库 / 渲染技巧库 │  ← 选定整部剧的视觉方向
        └───────────┬─────────────┘
                    │ 选定风格后
        ┌───────────┼───────────┐
        ▼           ▼           ▼
  ┌──────────┐ ┌──────────┐ ┌──────────┐
  │ ② 题材底盘│ │ ② 执行规则│ │ ② 增强模块│  ← 拿具体 Prompt 公式
  │ 10~18    │ │ 01~06/09 │ │ 07/19/   │
  └────┬─────┘ └────┬─────┘ │ 20/21    │
       │            │        └────┬─────┘
       └────────────┼─────────────┘
                    ▼
          ┌──────────────────┐
          │  ③ 输出模板       │
          │  分镜_03          │  ← Module 3 故事板 + Module 4 即梦视频
          └──────────────────┘
```

### 关键规则

1. **先选型，再执行**：必须先在 ① 层选定方向，再到 ② 层拿公式，最后填入 ③ 层模板。跳过 ① 层会导致分镜风格散乱。
2. **② 层按需叠加**：题材底盘（10~18）必选 1 个；增强模块（07/19/20/21）可选 0~4 个。普通文戏仅加 0~1 个增强；武打场景通常加 2~3 个。
3. **② 层模块不互相引用**：07/19/20/21 各自独立，通过 ③ 模板组合而非文件中互相链接。

## 三、组合加载规则

| 场景类型 | 加载组合 |
|---------|---------|
| **普通单题材** | 仅加载对应题材子文件（如古风 → 11） |
| **含打斗戏份** | 题材子文件 + **武打专项 19** 强制组合（如仙侠 + 战斗 → 11 + 19） |
| **强调光影质感** | 题材子文件 + **电影布光 20**（如权谋肖像 → 11 + 20） |
| **强调运镜节奏** | 题材子文件 + **电影运镜 21**（如动作打斗 → 14 + 19 + 21） |
| **统一画面色调** | 题材子文件 + **电影调色 07**（如赛博悬疑 → 12 + 07 + 20） |
| **FPV 微观视角** | 题材子文件 + **FPV 08**（如赛博仓鼠逃生 → 10 + 08） |
| **混合场景** | 多题材子文件按场景切换顺序依次加载 |

## 四、分镜使用流程

1. **定位题材** → 在「题材检索矩阵」中检索本集所属题材，定位子文件编号
2. **加载子文件** → 使用 `Read` 工具读取对应子文件全部分镜
3. **适配角色/场景** → 将分镜中的"主角""反派""建筑"等占位词替换为本集角色档案中的实际名称
4. **追加特殊元素** → 若本集含打斗，追加 [分镜_19_武打专项.md](./分镜_19_武打专项.md)；若是 FPV 场景，追加 [分镜_08_FPV.md](../core/分镜_08_FPV.md)；强调光影质感时追加 [分镜_20_电影布光.md](./分镜_20_电影布光.md)；强调镜头运动时追加 [分镜_21_运镜.md](./分镜_21_运镜.md)；统一画面色调时追加 [分镜_07_调色.md](../core/分镜_07_调色.md)
5. **校验清单** → 武打 → [分镜_19_武打专项.md](./分镜_19_武打专项.md) §六；布光 → [分镜_20_电影布光.md](./分镜_20_电影布光.md) §七；运镜 → [分镜_21_运镜.md](./分镜_21_运镜.md) §九；调色 → [分镜_07_调色.md](../core/分镜_07_调色.md) §四
