# 附MD05 | 互动影游Agent双引擎协同与算力分发规范

**所属主SKILL：** 互动影游Agent | 自动串联调度下层Skill\
**版本：** V2.0 融合合规版

## #做什么

本模块为互动影游Agent的双引擎协同与算力分发规范库。

解决影视制作Agent（现金流底盘）与互动影游Agent（核心壁垒）之间“资源不共享、算力分配不清、产能调度混乱、现金流与壁垒协同边界模糊”的痛点。通过双引擎资源复用规则、算力预算分配与产能调度优先级，确保双引擎协同高效、成本可控。

## #需要什么输入

**最少提供：**

- 当前项目类型（影视制作/互动影游）
- 项目主题与目标时长
- 目标平台

**可选提供：**

- 已完成的上游项目清单
- 双引擎产能排期
- 算力预算上限

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。

### 二、双引擎架构与资源复用

1. 影视制作Agent（现金流底盘）：复用底层Skill矩阵，专注短剧/漫剧量产，提供稳定现金流。
2. 互动影游Agent（核心壁垒）：自动将120分钟剧本拆解为100+分支树，批量生成高密度素材。
3. 两者共享的底层Skill矩阵：总制片人、葵花宝典、大导演思维、情绪大师、提示词、硬核武术指导、诺兰/维伦纽瓦/卡梅隆/胡金铨/徐克等导演美学。
4. 两者各自独立的专属能力：影视制作Agent专属风格TVC与短视频Skill；互动影游Agent专属【顶级游戏开发大师】与风格影游选调库。

### 三、算力预算分配

1. 双引擎共享一个总算力预算池。
2. 影视制作Agent按项目量产节奏，占用稳定比例算力。
3. 互动影游Agent按分支数量与结局数量，占用弹性算力。
4. 单项目止损红线：任何项目连续2次废片，必须停止，执行引擎切换或算力重分配。
5. 全站止损红线：算力消耗超过预算30%，必须停工复审。

### 四、产能调度优先级

1. 有稳定现金流预期的项目（短剧/漫剧/TVC）优先级最高。
2. 有明确截止日期的项目（大赛/客户交付）优先级次高。
3. 探索性项目（互动影游Demo验证）优先级中等，但必须有明确止损线。
4. 严禁无明确产出的探索性项目占用超过总预算的40%。

### 五、双引擎协同边界

1. 两个Agent平级，互不隶属。
2. 调用记录必须分开归档。
3. 共享Skill的调用必须记录使用来源。
4. 各自维护独立的调度链路与异常处理流程。
5. 跨引擎协同必须由用户明确指令触发。

### 六、生成与合成

根据上述双引擎协同与算力分发规范，调用底层视频生成Skill，输出MP4视频文件。
