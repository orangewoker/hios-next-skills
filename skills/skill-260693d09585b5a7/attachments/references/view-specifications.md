# 固定视角规范

## 坐标约定

- 将 V01 主展示面定义为“前”。
- 以 V01 画面坐标定义左右：V03 展示原 V01 左边缘对应的侧面；V04 展示原 V01 右边缘对应的侧面。
- V07 固定展示 V04 对应的右侧部分，形成右前 3/4 视角，任何情况下都不得镜像或改为左前；V08 默认沿用该右前方向。用户要求左前时，将其作为自定义指定视角，不标记为 V07。
- 所有机位都瞄准同一产品视觉中心，保持近似相同焦距、画面占比和垂直方向。

## V01–V08

| 编号 | 名称 | 几何定义 | 必需证据 |
|---|---|---|---|
| V01 | 正面 | 主展示面中心线正对镜头，水平旋转 0°、俯仰 0° | 清晰正面及结构比例 |
| V02 | 背面 | 背面中心线正对镜头，相对 V01 水平旋转 180° | 背面照片、模型或完整原稿 |
| V03 | 左侧面 | V01 左边缘对应侧面中心正对镜头 | 左侧照片、模型或完整原稿 |
| V04 | 右侧面 | V01 右边缘对应侧面中心正对镜头 | 右侧照片、模型或完整原稿 |
| V05 | 正面仰视 | 产品悬浮，保持 V01 水平朝向和正面居中；降低相机约 8°–15°并瞄准中心，清楚露出瓶底/产品底部 | 清晰正面加完整底部/下缘结构 |
| V06 | 俯视正面 | 保持 V01 水平朝向；提高相机约 8°–15°并瞄准中心 | 正面加顶部结构 |
| V07 | 右前斜仰视 | 产品悬浮，保持右前旋转 30°–45°；降低相机约 8°–15°并瞄准中心，清楚露出瓶底/产品底部 | 正面、右侧面和完整底部/下缘结构 |
| V08 | 斜俯视 | 默认右前 30°–45°；提高相机约 8°–15° | 正面、对应侧面和顶部结构 |

## 几何要求

- V05 只改变相机高度与俯仰，不改变水平朝向；主展示面正对镜头并在画面水平居中，不错误露出侧面。
- V07 保持右前旋转方向，右侧可见宽度服从真实透视，不镜像成左前方向。
- V05、V07 的产品必须悬浮，瓶底/产品底部清楚可见；底部形状、凹槽、厚度和接缝服从参考，不使用桌面、展台或接触阴影伪装悬浮。
- V07/V08 默认使用相同的右前旋转方向和近似角度；V07 始终保持右前，左前需求作为自定义指定视角处理。
- 方盒正视时不错误露出侧面或顶部；斜视时侧面宽度服从真实透视。
- 圆柱标签随旋转自然包裹，中心变形最小，越靠轮廓横向压缩越明显。
- 软管和袋体保留柔性，不把褶皱全部抹平成硬盒。
- 异形产品以参考轮廓为准，不规则化为普通瓶、罐或盒。

## 跨视角一致性

保持同一品牌、文字、图案、结构比例、部件尺寸、材料、颜色、标签位置、接缝、背景、光源系统和产品视觉尺寸。视角变化产生的高光、阴影、反射、折射和标签压缩必须符合同一个三维对象。

若某个视角会暴露未知包装面、未知标签接缝或未知部件，不生成该视角。
