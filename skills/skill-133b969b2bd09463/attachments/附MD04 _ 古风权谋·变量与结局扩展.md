# 附MD04 | 古风权谋·变量与结局扩展

**所属主SKILL：** 古风权谋 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“古风权谋 | 上架Steam的互动影游”的专属变量系统与结局体系扩展库。

解决互动影游“变量设定空洞、结局无分支、选项假大空、数值不驱动剧情”的痛点。通过严格的变量字典、严密的结局触发条件与路径推演，确保玩家的每一次选择都能真实改变主角与阵营的因果命运。

## #需要什么输入

**最少提供：**

- 核心变量清单（如权势值、声望值、阵营信任、阴谋值、皇帝疑心等）
- 路线设计（忠臣线、权臣线、帝王线、隐藏线）
- 主角与阵营NPC的信任设定

**可选提供：**

- 结局数量与类型偏好
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。变量与结局设计环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则，确保结局路径逻辑闭环。

### 二、变量字典（强制锁定）

核心变量

1. 权势值：counter，0-100，默认0；≥60权倾朝野；&lt;30人微言轻。
2. 声望值：relationship，0-100，默认0；≥70万民敬仰；&lt;30名声扫地。
3. 阵营信任：faction，0-100，默认0；≥80阵营支持；&lt;20阵营敌对。
4. 阴谋值：risk，0-100，默认0；≥70阴谋缠身；≥90阴谋败露。
5. 皇帝疑心：counter，0-100，默认0；≥80皇帝起疑；≥90赐死。

路线专属变量

1. 忠臣线专属忠诚：relationship，0；≥50忠臣线锁定；&lt;20忠臣线崩塌。
2. 权臣线专属野心：relationship，0；≥50权臣线锁定；&lt;10权臣线失效。
3. 帝王线专属帝运：relationship，0；≥50帝王线锁定；&lt;10帝王线失败。
4. 全员声望：relationship，0；≥80解锁真结局条件。

道具与旗标变量

1. 虎符：item，false；true且兵权≥60可触发帝王线结局。
2. 密折：item，false；true且阵营信任≥60可触发权臣线结局。
3. 传国玉玺：item，false；true且全员声望≥20可触发隐藏真结局。

### 三、结局体系（共15个）

正结局（5个）

1. E01·权倾朝野：权臣线，权势值≥60，阴谋值&lt;70。
2. E02·辅佐明君：忠臣线，声望值≥70，皇帝疑心&lt;50。
3. E03·登基称帝：帝王线，帝运≥50，权势值≥80。
4. E04·千古一帝：隐藏真结局，解锁传国玉玺+全员声望≥20+权势值≥80。
5. E05·功成身退：任意路线，权势值30-59，阴谋值&lt;30。

坏结局（10个）

 1. D01·阴谋败露：阴谋值≥90。
 2. D02·皇帝赐死：皇帝疑心≥90。
 3. D03·阵营反目：阵营信任&lt;20。
 4. D04·忠臣冤死：忠臣线，忠诚&lt;20。
 5. D05·权臣覆灭：权臣线，野心&lt;10。
 6. D06·帝王梦碎：帝王线，帝运&lt;10。
 7. D07·身败名裂：声望值&lt;20。
 8. D08·满门抄斩：全员声望&lt;10且阴谋值≥70。
 9. D09·因果清算：所有变量失控。
10. D10·夺嫡失败：N02选项B+阴谋值≥70。

### 四、结局触发条件表（快速查表）

1. E01：N02A→N04A→N06A-2→N08B；权势值≥60·阴谋值&lt;70·阵营信任≥30。
2. E02：N02A→N04B→N06B-1→N08B；声望值≥70·皇帝疑心&lt;50·忠诚≥30。
3. E03：N02B→N04C→N06C-2→N07C-1；帝运≥50·权势值≥80·阴谋值≥40。
4. E04：N02B→N04C→N06C-2→N07C-2→N08C；传国玉玺=true·全员声望≥20·权势值≥80。
5. E05：N02A→N04B→N06B-3→N08B；权势值30-59·阴谋值&lt;30。
6. D01：任意路线累积阴谋值≥90。
7. D06：N04A→N06A-1→N08A；帝运&lt;10。

### 五、结局路径示例（以E04千古一帝为例）

N02B 质问天命（阴谋值+10）\
→ N04C 参悟·传国玉玺（权势值+20·全员声望+20）\
→ N06C-2 反问堵住权臣（阴谋值-20）\
→ N07C-2 抬头直视皇帝微笑（获得传国玉玺）\
→ N08C 全员豪赌（权势值+30·全员声望+30）\
→ E04 千古一帝（全员声望≥20·传国玉玺=true）

### 六、变量锚定规则（核心铁律）

1. 每个节点提示词末尾必须标注：节点ID+变量变化。
2. 变量名全部用英文（power/fame/faction/intrigue/suspicion/route），禁止中文变量名。
3. 变量一旦定义，中途不能改名。
4. 所有变量必须有定义、有使用、有结局影响。
5. 禁止无意义变量（定义了但从不影响结局）。

### 七、子级专属提示词模板（示例）

```text
节点ID：N05A
变量变化：权势值+40·声望值+25·阴谋值+20·路线锁定=权臣线
分支标识：权臣线朝堂判定
结局条件：权势值≥60·阴谋值<70
```

\
（注：以上“主角、权臣、传国玉玺”仅为示例，实际使用时由用户自定义替换）
