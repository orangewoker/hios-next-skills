# 附MD04 | 乙女·变量与结局扩展

**所属主SKILL：** 乙女 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“乙女 | 上架Steam的互动影游”的专属变量系统与结局体系扩展库。

解决互动影游“变量设定空洞、结局无分支、选项假大空、数值不驱动剧情”的痛点。通过严格的变量字典、严密的结局触发条件与路径推演，确保玩家的每一次选择都能真实改变女主与多位男主的羁绊命运。

## #需要什么输入

**最少提供：**

- 核心变量清单（如心动值、羁绊值、信任度、命运值等）
- 路线设计（男主A线、男主B线、男主C线、男主D线、隐藏线）
- 女主与多位男主的羁绊设定

**可选提供：**

- 结局数量与类型偏好
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。变量与结局设计环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则，确保结局路径逻辑闭环。

### 二、变量字典（强制锁定）

核心变量

1. 心动值：counter，0-100，默认0；≥60情感稳固；&lt;30情感疏离。
2. 羁绊值：relationship，0-100，默认0；≥60羁绊深厚；&lt;20羁绊浅薄。
3. 信任度：risk，0-100，默认0；≥70完全信任；&lt;30信任危机。
4. 命运值：counter，0-100，默认0；≥70命运交点；&lt;30擦肩而过。
5. 势力信任：faction，0-100，默认0；≥80势力支持；&lt;20势力敌对。

路线专属变量

1. 男主A专属心动：relationship，0；≥50男主A倾心；&lt;20男主A疏远。
2. 男主B专属心动：relationship，0；≥50男主B倾心；&lt;20男主B疏远。
3. 男主C专属心动：relationship，0；≥50男主C倾心；&lt;20男主C疏远。
4. 男主D专属心动：relationship，0；≥50男主D倾心；&lt;20男主D疏远。
5. 全员羁绊值：relationship，0；≥80解锁真结局条件。

道具与旗标变量

1. 定情信物A：item，false；true且男主A心动≥60可触发男主A专属结局。
2. 定情信物B：item，false；true且男主B心动≥60可触发男主B专属结局。
3. 神秘玉佩：item，false；true且全员羁绊≥20可触发隐藏真结局。

### 三、结局体系（共15个）

正结局（5个）

1. E01·独宠男主A：男主A线，男主A心动≥60，命运值&lt;50。
2. E02·独宠男主B：男主B线，男主B心动≥60，命运值&lt;50。
3. E03·独宠男主C：男主C线，男主C心动≥60，命运值&lt;50。
4. E04·全员羁绊：隐藏真结局，解锁神秘玉佩+全员羁绊≥20+心动值≥80。
5. E05·独自远行：任意路线，心动值30-59，命运值&lt;30。

坏结局（10个）

 1. D01·命运错过：命运值≥90。
 2. D02·信任崩塌：信任度&lt;30。
 3. D03·势力清算：势力信任&lt;20。
 4. D04·男主A决裂：男主A线，男主A专属心动&lt;20。
 5. D05·男主B决裂：男主B线，男主B专属心动&lt;20。
 6. D06·男主C决裂：男主C线，男主C专属心动&lt;20。
 7. D07·男主D决裂：男主D线，男主D专属心动&lt;20。
 8. D08·全员反目：全员羁绊&lt;10且命运值≥70。
 9. D09·因果清算：所有变量失控。
10. D10·觉醒前陨落：N02选项B+命运值≥70。

### 四、结局触发条件表（快速查表）

1. E01：N02A→N04A→N06A-2→N08B；男主A心动≥60·命运值&lt;50·羁绊值≥30。
2. E02：N02A→N04B→N06B-1→N08B；男主B心动≥60·命运值&lt;50·羁绊值≥30。
3. E03：N02B→N04C→N06C-2→N07C-1；男主C心动≥60·命运值&lt;50·羁绊值≥30。
4. E04：N02B→N04C→N06C-2→N07C-2→N08C；神秘玉佩=true·全员羁绊≥20·心动值≥80。
5. E05：N02A→N04B→N06B-3→N08B；心动值30-59·命运值&lt;30。
6. D01：任意路线累积命运值≥90。
7. D06：N04A→N06A-1→N08A；男主C专属心动&lt;20。

### 五、结局路径示例（以E04全员羁绊为例）

N02B 质问命运（命运值+10）\
→ N04C 参悟·神秘玉佩（心动值+20·全员羁绊+20）\
→ N06C-2 反问堵住反派（命运值-20）\
→ N07C-2 抬头直视反派微笑（获得神秘玉佩）\
→ N08C 全员豪赌（心动值+30·全员羁绊+30）\
→ E04 全员羁绊（全员羁绊≥20·神秘玉佩=true）

### 六、变量锚定规则（核心铁律）

1. 每个节点提示词末尾必须标注：节点ID+变量变化。
2. 变量名全部用英文（affection/bond/trust/fate/route），禁止中文变量名。
3. 变量一旦定义，中途不能改名。
4. 所有变量必须有定义、有使用、有结局影响。
5. 禁止无意义变量（定义了但从不影响结局）。

### 七、子级专属提示词模板（示例）

```text
节点ID：N05A
变量变化：心动值+40·羁绊值+25·命运值+20·路线锁定=男主A线
分支标识：男主A线命运判定
结局条件：男主A心动≥60·命运值<50
```

\
（注：以上“女主、男主A、神秘玉佩”仅为示例，实际使用时由用户自定义替换）\
