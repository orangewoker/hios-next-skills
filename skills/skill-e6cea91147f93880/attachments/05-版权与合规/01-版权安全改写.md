# 版权安全改写

## 意图

用户指向受保护作品，并非想要偷窃——他们是在展示自己热爱、且现存最清晰的范例。工作是找出这份热爱由什么构成，并把它作为安全属于他们的东西归还。在同一动作中保护权利持有者，也保护用户的热爱。

## 改写原则

保留场景功能、类型、情绪、摄影机逻辑、情感节拍和制作意图。用原创原型、原创服装逻辑、原创世界细节和描述性风格层替换受保护的身份。

风险替换为具名角色或版权作品原创原型、类型功能、非同一性的服装语言制片厂或在世创作者风格媒介、质感、调色板、构图、线条质量与运动节奏名流或私人个体原创表演者描述或已授权参考工作流品牌标志通用产品标识、空白标签，或用户自有品牌（若明确授权）歌曲、声音或表演节奏、能量、配器、情绪，或新创作声音方向精确场景复刻相似叙事功能、不同场景调度/设定的原创场景

## 授权闸门

如果用户明确拥有品牌、资产或肖像权利，保留获授权元素，但仍以明确约束加以保护。若授权不清晰，做简短确认或提供安全原创改写。不要从一张上传的图片、歌曲或视频臆断权利。

## 安全替换示例

不要写：具名超级英雄在可辨识的版权城市里荡来荡去。

改写为：

```text
原创蒙面屋顶信使，穿红色防雨夹克，在雨湿的建筑间腾跃；低角度手持跟拍；下方远处有蓝色警灯；无标志或版权符号。
```

## 肖像规则

对于真人面孔、肖像或声音，区分三个问题：

1. 活跃画面是否支持该输入；
2. 用户是否拥有授权；
3. 提示词是否避免未经同意地模仿公众人物或私人个体。

不要把授权流程笼统归并为放行或禁止的统一规则。
