# 图片视觉方案与 Midjourney V8.2 工作流

## 1. 先确定生活状态

主题不是完整剧情，而是“季节/空间 + 同行状态”，例如水乡闲游、秋山共读、溪畔嬉游、庭院午后、山坡追风。用户已有主题时直接沿用，不重复提问。

## 2. 规划一组可剪辑的图片

一组图要在同一视觉世界中变化空间、景别和亲密程度。推荐混合：

- 1–2张环境全景：交代水乡、湖岸、山坡、小镇或庭院。
- 3–5张中景群像：交谈、共读、分享、整理衣物、乘船或散步。
- 2张近景：甜美面容、手与衣料或小道具。
- 1–2张同行感镜头：隔着枝叶、布幔、船舷或屋檐自然观察。
- 1–2张轻动态：奔跑、涉水、回头招呼、裙摆与树叶产生惯性。

比例可按用户选图结果调整，不机械凑数。相邻画面避免使用同一景别、同一人数和同一构图。

## 3. 每张图的事件强度

每张只保留一个轻事件和一个视觉中心。人物可以轻声交谈、相互靠近、递一件小物、看同一本书、乘船看岸、沿水边行走或牵手跑过草地。描述重点是氛围、关系和构图，不展开操作步骤。

## 4. MJ 提示词结构

使用英文正文、中文标题，顺序为：

1. 人数、甜美中国女性与核心轻事件。
2. 人物之间的自然关系和错落状态。
3. 椭圆脸、杏眼、淡桃妆容、传统发型与服装配色。
4. 场景与少量正在使用的道具。
5. 景别、机位、前中后景和自然遮挡。
6. 明亮通透光线、暖中性色、开放阴影、受控高光、浅景深与胶片质感。
7. 参数和与当前画面真正相关的排除项。

用户未另行指定时，每条完整提示词不超过1024字符。输出前实际检查字符数。

## 5. 已验证参数区间

本系列优先使用：

`--ar 16:9 --v 8.2 --raw --stylize 205–220 --chaos 6–8`

- 安静近景或中景：`--stylize 205–210 --chaos 6`
- 群像、树林、水乡：`--stylize 210–220 --chaos 6–7`
- 奔跑、涉水、较自由动态：`--stylize 215–220 --chaos 7–8`

排除项只针对实际风险，例如：`--no static group portrait, athletic sprint, dark faces, harsh contrast, blown highlights, modern objects, text, watermark, logo`。

## 6. 出图节奏

默认先给5张差异明显的测试提示词。用户确认方向后再扩展至完整组图。收到生成结果后，只修正用户指出的维度，例如甜美度、亮度、人物数量、景别或同行感；保留已经验证成功的其他要素。

图片方案通过不等于视频方案通过。必须等用户确认实际成图，才能把该图交给 CVLM 5.5。
