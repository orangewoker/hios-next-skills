# 对话归属与多人空间连续性

当台词有两个以上说话者，或任一镜头出现两个以上有叙事作用的人物时读取。目标是避免双人对白被改成画外音，以及人物在正反打和连续镜头中无因换侧、跳位或越轴。

## 1. 先做台词归属表

拆镜前逐句确定：

原台词说话者接话者发言方式同框要求问句角色A角色B画面内现场对白A必须在画面内，B可同框聆听答句角色B角色A画面内现场对白B必须在画面内，A可同框聆听

默认规则：

- `问/答`、角色名加冒号、引号轮流发言，均视为现场对话。
- 只有用户明确写出“旁白、画外音、内心独白、广播、电话另一端”等非画面内发声方式时，才可让说话者不出现在画面里。
- 不因缺少第二人物参考图而改成旁白。可创建一名外貌、服装、年龄和气质固定的非主角人物，并在全板保持一致。
- 说话者必须有可见发言证据：嘴唇自然开合、视线指向接话者、身体朝向合理；接话者具有聆听证据：视线回应、眼睑变化、呼吸或轻微姿态反应。

## 2. 建立空间地图

在第一个多人镜头前写出固定地图，不只写“站在一起”。至少包含：

- 角色A的物理位置、屏幕方位、朝向和视线；
- 角色B及其他角色的物理位置、屏幕方位、朝向和视线；
- 门、窗、桌椅、主光源、关键道具的位置；
- 摄影机所在区域与人物之间的180度轴线。

双人桌面对话示例：

```text
A坐在桌子左侧，屏幕左方，面向右；B坐在桌子右侧，屏幕右方，面向左。
窗在B身后右侧，门在A身后左侧。A与B视线连线是对话轴，摄影机始终位于轴线南侧。
```

三人示例：

```text
A左前面向右，B右前面向左，C后中面向前偏左；三人的椅子、桌面道具和背景门窗固定。
```

## 3. 正反打与过肩镜头

- 建立镜头确认A左/B右后，A的单人近景仍保持屏幕左侧、面向右；B的单人近景仍保持屏幕右侧、面向左。
- 拍B的过肩镜头时，可见A的肩膀位于左前景，B位于右侧焦点区；反打拍A时，B的肩膀位于右前景，A位于左侧焦点区。
- 镜头可推近、侧移、拉焦或小幅环绕，但不得穿过对话轴。构图反转不等于角色换位。
- 视线高度、视线方向和人物间距离必须匹配；禁止两人都朝同一方向看却被描述为面对面。

## 4. 合法改变站位

只有以下情况可更新空间地图：

1. 一个连续建立镜头完整展示人物起身、走动、换座或互换位置；
2. 摄影机在不中断的可见运动中越过轴线，并在运动结束后重新建立左右关系；
3. 明确的时间或地点跳转，同时用新的全景重新建立空间。

遮挡切、特写切、匹配剪辑、光线变化和普通转场不能解释人物瞬移。没有建立镜头时，默认继承上一格站位。

## 5. 逐格检查

每格输出前核对：

- 当前台词是否由正确的画面内角色说出；
- 说话者和接话者是否都有可见表演证据；
- A/B/C的屏幕左右、前后层级、朝向和视线是否继承上一格；
- 门窗、桌椅、道具和主光方向是否仍处于同一空间；
- 是否出现无因换侧、越轴、瞬移、重复人物或背景人物复制主角脸；
- 若站位已改变，是否存在一个可见的合法换位镜头并更新了空间地图。
