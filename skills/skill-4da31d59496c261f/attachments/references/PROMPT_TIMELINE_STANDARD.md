# FINAL_VIDEO_PROMPT 逐镜时间轴与复核标准

本文件承接 `PROMPT_DIRECTOR_STANDARD.md`。不得单独使用；必须先完成全局结构与资产职责合同。

## 8. P3-P7 精确时间轴

### 8.1 每个 SH 的固定结构

每个真实镜头独立成块，按真实顺序编号：

`SH01｜00:00.000-00:02.440｜连续镜头。`

或：

`SH02｜00:02.440-00:05.000｜硬切。`

每个 SH 依次写：

1. `构图与开场：` 起始景别、角度、主体、前后景、视线/轴线关系；
2. `动作：` 起始 -> 过程 -> 结束，只写真实可见行为；
3. `表演与微表情：` 只写已经通过 `EMOTION_DIRECTION_REVIEW` 的可见表演变化，按发生顺序组织；
4. `Cxx：` 当前镜头唯一的运镜/焦点阶段；
5. 当前镜头实际发生的 `Dxx`、`Fxx`、`Axx` 事件；
6. `ENDxx：` 镜尾人物/道具/相机/声音的稳定或未完成状态。

不要把 P3/P4/P5/P6/P7 分成多个重复时间线。动作、摄影机、对白、拟音、环境声都必须绑定回唯一 SH 块内。

### 8.2 时间格式

- 所有 SH/D/F/A/C 相关时间使用三位毫秒精度：`00:05.280-00:05.980`；
- SH 时间必须首尾相接；
- 第一镜从 `00:00.000` 开始；
- 最后一镜精确结束于总时长；
- 不使用模糊词“约”“左右”“随后几秒”；
- 若事件持续全段，可以在首次出现处定义并标明“持续全段”，事件索引只列一次。

### 8.3 镜头守恒

- `FINAL_SH_COUNT` 必须等于 `RAW_SH_COUNT_LOCK`；
- 每个 `RAW_SHxx` 必须有唯一最终 `SHxx` 对应；
- 没有最短镜头时长豁免，极短反应镜、插镜、脚/手/道具特写同样守恒；
- 每个真实切点都必须体现在 SH 边界；
- 隐藏切被确认后按真实镜头处理；
- 不允许模型自行合并反应镜、插镜或重新设计转场；
- 第一镜若承接上段但当前段从新镜头起步，仍只写当前段已成立状态，不写来源。

### 8.4 表演与微表情

只使用 `EMOTION_DIRECTOR_STANDARD.md` 已通过的 `DIRECTED_EMOTION`。最终模型可见文本必须是可观察的表演序列，而不是抽象情绪标签。

要求：

- 关键情绪镜至少使用眼神/眉眼/口颌/呼吸或吞咽/头颈或重心中的2类可见信号；
- 每个情绪节拍通常只保留2-4个主要信号，避免堆砌器官动作；
- 按“刺激 -> 第一反应 -> 控制/升级 -> 镜尾状态”的真实顺序写；
- 表演强度默认不高于源视频，除非用户在 `EMOTION_DIRECTION_REVIEW` 明确要求；
- 原地微表情不能变成新的空间位移，走位继续服从 Blocking；
- 呼吸/吞咽若只是视觉表演线索，写在此处；只有真实可听且具有独立事件意义时才进入 F；
- 不得只写“愤怒、震惊、悲伤、紧张、爱慕、心虚”等情绪词；
- 不得用角色参考图已经负责的五官/脸型/妆造描述冒充表演；
- 不强制写FACS/AU编号，最终Prompt优先使用Seedance 2.5可直接理解的自然视觉语言。

示例：

`表演与微表情：先停止眨眼，视线固定在对方脸上；上眼睑轻抬，嘴唇短暂微张又重新合上；下巴轻微回收，吸气停住，没有后退。`

### 8.5 C 运镜/焦点阶段

默认一镜一个 `Cxx`，且 `Cxx` 与 `SHxx` 一一对应，除非反推审计明确证明单镜头存在必须拆分的多个阶段并在 P0 同步计数。

C 必须说明：

- 机位起始；
- 是否固定/推/拉/摇/移/跟/手持/稳定器；
- 方向；
- 速度阶段；
- 是否人工变焦；
- 焦点对象与必要焦点转移；
- 镜尾是否停稳或保留惯性。

禁止为了“更电影感”自行增加运镜。

### 8.6 D 对白单元

格式示例：

`D01｜00:05.280-00:05.980：Seb，画内、口型清楚、语气压低但坚决，使用Seb音色参考，说：“Get down.”；句尾短停，不增加称呼或第二句。`

每个 D 必须绑定：

- 唯一角色；
- 精确时间；
- 画内/画外；
- 口型可见性；
- 必要语气/停顿/打断/重叠；
- 目标语言原句；
- 对应音色参考（若绑定）。

`FINAL_D_PARENT_COUNT` 必须等于 `RAW_D_PARENT_COUNT_LOCK`。不得把一句拆成多个父 D 来凑计数，也不得把多句合并后改变原说话窗口。

若同一句真实台词跨越切镜，使用父事件 + 相位，例如 `D03-A` 位于 SH04、`D03-B` 位于 SH05；父事件仍只计作一个 D。画外对白、J-cut/L-cut、重叠对白必须按真实声音时间保留，不能为了“一镜一D”而删除。

### 8.7 F 物理拟音/表演声

每个 F 只描述真实可见或真实可听事件：落脚、衣物动态、呼吸、吸气、物件接触、门、杯、手机、桌面接触等。

- 声音严格同步动作；
- 不把动作接触声设计成节拍；
- 不使用音乐性 whoosh、hit、sting；
- 同一连续动作组可作为一个 F，但内部接触密度服从可见动作；
- 跨段事件按父 ID + 相位后缀处理。

### 8.8 A 环境声

A 是环境状态或真实变化，不是每镜头重复创建的新事件。

例如一个开放屋顶环境可定义：

`A01：开放屋顶夜风、远处酒会人群低声与城市远景底声，宽而克制，持续全段。`

后续 SH 只写 `A01连续`，不重复新增 A02/A03。

### 8.9 END 镜尾状态

每个 SH 必须有唯一 `ENDxx`。END 用于锁下一镜或下一段连续性，至少记录本镜头真正需要继承的：

- 人物位置/朝向/动作相位；
- 支撑状态；
- 道具状态/持有手；
- 门窗/容器状态；
- 摄影机末速/停稳；
- 焦点状态；
- 对白/呼吸/拟音/环境/混响尾音。

最后一个 `ENDxx` 必须与 25-30 秒段尾完全一致，不得补写之后的剧情结果。

## 9. 事件核对索引

精确时间轴后必须添加 `【事件核对索引】`。

至少列出：

- 每个 D：`角色/时间/台词`；
- 每个 F：简短事件名称；
- 每个 A：环境状态；
- C 说明：`C01-Cxx分别对应SH01-SHxx的唯一摄影机/焦点执行阶段`，或按实际多阶段结构明确映射。

索引是核对账本，不得引入正文中不存在的新事件。

## 10. P9 最终硬性约束

P9 必须再次锁定：

- SH/D/F/A/C 精确计数；
- 孤儿事件 = 0；
- 重复事件 = 0；
- 不增、不删、不合并、不重排；
- 关键切点精确时间；
- 结尾精确动作/声音相位；
- 不展示当前段之外的后果；
- 无 BGM / 无音乐 / 无音乐性音效；
- 无字幕，除非用户明确要求；
- 本地化项目中无源语言前景对白；
- 参考图控制的角色基础外观不得被文字重写；
- 各角色只使用各自音色参考；
- 不允许人物身份回弹；
- `表演与微表情` 必须来自已通过的情绪导演版本，不得退化成笼统情绪词或擅自增强戏剧强度；
- 不允许模型自行改编镜头、反应镜或转场。

若某一约束与当前段无关，不照搬无意义条目；但计数守恒、时间轴、零音乐、身份稳定、禁止自行改编始终保留。

## 11. PROMPT_USER_REVIEW 前的强制编译自检

提交前逐项验证：

1. 首行 EP/S、画幅、总时长与当前生成配置一致；
2. 所有 SH 时间段首尾连续，覆盖 `00:00.000` 到总时长，无 gap/overlap；
3. SH 数量与 P0/P9 一致，且 `FINAL_SH_COUNT == RAW_SH_COUNT_LOCK`；
4. D/F/A/C 的父 ID 唯一数量与 P0/P9 一致，且 `FINAL_D_PARENT_COUNT == RAW_D_PARENT_COUNT_LOCK`；
5. 每个 RAW_SH 都有唯一最终 SH 对应，没有极短镜头、反应镜、插镜在编译时消失；
6. 每个 RAW_D 父事件都有最终 D/相位对应，画外对白、短回答、打断、重叠和跨切点台词均未消失；
7. 跨镜头同一句台词使用父 D + 相位，父事件只计一次；
8. SH 主时间轴无 gap/overlap；D/F/A 保留源视频真实重叠关系；
9. 每个 D/F/A/C 都能回到 SH、跨 SH 相位或明确的全段状态；
10. 每个 SH 都有构图与开场、动作、表演与微表情（无明显情绪变化时允许写明确的稳定表演状态）、C、END；
11. 每个“表演与微表情”都能回溯到 `SOURCE_EMOTION` 或用户明确修改的 `DIRECTED_EMOTION`，没有仅用抽象情绪词代替表演，也没有擅自增加情绪强度/走位/剧情行为；
12. 每个 C 与 SH 映射明确；
13. 每个 D 的说话人、音色、语言、口型与时间窗一致；
14. 每个 F 与实际物理动作/表演声一致，不音乐化；
15. 每个 A 只定义真实环境状态/变化，不因切镜重复计数；
16. `事件核对索引` 与正文事件一一对应，无新事件；
17. 最后 END 与段尾时间、未完成动作/声音相位一致；
18. 若有跨段事件，相位后缀与父事件计数正确；
19. 最终提示词不含原人物名、原演员名、原人物旧外貌、反推视频/上一段视频等来源词；若实际绑定衔接视频，只允许P1出现一句简短职责声明，且P1之外不得再出现衔接视频来源词；
20. BINDING_MANIFEST 不含当前反推视频、上一段完整成片或未裁剪连续性视频；若存在有效连续性，`CONTINUITY_VIDEO_REFERENCE` 必须且只能有1条、仅3-5秒，并确认最终生成页实际绑定成功；
21. 音乐目标事件数 = 0；
22. 没有停帧、慢动作、空镜、虚构反应、新对白或无意义停顿补时长；
23. 不存在未解决疑似切点或 `UNCERTAIN_SPEECH`，且 RAW 两次视觉/两次对白盘点差异已解释并锁定；
24. Prompt首行/P0/最后SH/最后END全部结束于 `SOURCE_TIMELINE_DURATION`，没有错误延长到 `GENERATION_DURATION`；
25. Prompt外生成参数预览明确显示：Seedance 2.5、画幅、默认480P或用户改选值、`SOURCE_TIMELINE_DURATION`、`GENERATION_BUFFER`、`GENERATION_DURATION` 与正式裁切终点。

任一项失败：返回 `PROMPT_COMPILE` 修正，禁止进入用户Prompt复核。全部通过后仍必须把完整最新版Prompt交给用户检查；用户未明确回复“提示词通过/正确/可以”，禁止 `PROMPT_FREEZE` 和Seedance 2.5生成。


## 12. 用户强制Prompt复核

内部编译自检通过后，向用户完整展示整份 `FINAL_VIDEO_PROMPT`，不得只展示摘要或变更片段。Prompt后追加一个不属于Prompt正文的参数预览：

```text
【Seedance 2.5 生成参数预览】
模型：Seedance 2.5
画幅：<ratio>
分辨率：480P（平台支持时默认；若用户改选则显示改选值）
反推视频实际时长：<SOURCE_TIMELINE_DURATION>
生成技术缓冲：+<2.000s~3.000s，默认2.500s>
Seedance 2.5生成调用时长：<GENERATION_DURATION>
正式成片裁切终点：<SOURCE_TIMELINE_DURATION>
```

用户必须检查镜头、对白、动作、时间码、声音、人物/道具、连续性与生成参数。只有明确回复“提示词通过/正确/可以”才允许冻结。任何修改都会使旧审批失效，必须重新编译、自检并完整展示最新版。
