## 都市犯罪/悬疑对峙 (黑暗骑士系)

**参考影片**: 《黑暗骑士》《蝙蝠侠: 侠影之谜》《失眠症》
**摄影师**: 瓦利·菲斯特
**默认强度**: L2

### 核心场景
雨夜追凶、审讯室对峙、高楼天台对话、暗巷交易、都市夜景、追车

### 光影氛围
```
hard side-backlight, light ratio 1:8,
half face in shadow half in cold blue-white,
rain-slicked ground doubling light sources via reflection,
glass refraction creating secondary light patterns,
large black areas with sparse cold point lights (streetlamp, neon sign),
volumetric light through rain/fog/steam,
wet surfaces reflecting amber and blue simultaneously
```

### 构图语言
```
low angle shot making figure silhouette against urban backdrop,
nested frame composition: door frame / car window / corridor framing subject,
symmetrical architecture composition emphasizing order vs chaos,
extreme wide shot with figure small against massive Gotham skyline
```

### 声音设计
```
Base: rain on asphalt, distant traffic hum, city low-frequency drone
Rhythm: irregular low pulse, 70-80 BPM
Texture: leather shoes on wet pavement, distant siren echo, metal gate clang
Tension: low cello sustained drone, sub-bass rumble building
Vocal: dialogue slightly recessed, spatial reverb from concrete walls
Silence: dead silence before key action moment
```

### 需删减
- 时间残影、空间折叠等科幻元素
- 暖调明亮画面、金色史诗感

### 负面词强化
```
cyberpunk neon glow, bright warm tones, cartoon crime style,
comic book aesthetic, anime action, cheerful urban scene
```

## 时空科幻/概念烧脑 (盗梦/信条系)

**参考影片**: 《盗梦空间》《信条》
**摄影师**: 瓦利·菲斯特(盗梦) / 霍伊特(信条)
**默认强度**: L2-L3

### 核心场景
梦境空间、时间倒流、建筑折叠、平行时空、科幻实验室、失重环境

### 光影氛围
```
cold white geometric light cutting through impossible architecture,
sharp angular shadows from non-euclidean geometry,
extreme spatial depth with razor-sharp edges throughout frame,
subtle motion trail on moving objects suggesting temporal distortion,
edge-of-frame slight light aberration / chromatic fringing,
volumetric dust particles suspended defying gravity
```

### 时空氛围 (二选一，不可叠加)

**梦境向 (盗梦空间)**:
```
frame edges slightly soft focus while center remains sharp,
distant buildings subtly warping and bending,
sky-ground boundary dissolving and becoming ambiguous,
multiple layered透视 creating recursive depth illusion
```

**逆时间向 (信条)**:
```
objects carrying reverse motion trail / afterimage,
smoke and water flowing in reverse direction,
frame edges showing subtle negative color fringing,
light behaving unnaturally - shadows preceding objects
```

### 构图语言
```
center symmetry perspective with vanishing point at impossible axis,
receding nested frames creating infinite depth tunnel,
zero-gravity tilted composition with horizon at 45-90 degrees,
character centered against massive folding/rotating architecture
```

### 声音设计
```
Base: deep sub-bass rumble 20-40Hz, electromagnetic hum
Rhythm: ticking clock or reversed mechanical pulse, 60-120 BPM
Texture: glass cracking, steel groaning, debris falling upward
Tension: Shepard tone rising continuously, BRAAAM brass hit at structural moments
Vocal: heavy breathing, no dialogue in extreme moments
Silence: complete silence at moment of gravitational/temporal inversion
```

### 需删减
- 雨夜元素、复古颗粒感、暖调史诗感
- 外星生物、奇幻魔法

### 负面词强化
```
cyberpunk VFX, alien creatures, fantasy magic elements,
flashy sci-fi costumes, video game aesthetic, space opera
```

## 宏大史诗/自然宇宙 (星际穿越系)

**参考影片**: 《星际穿越》《敦刻尔克》(部分)
**摄影师**: 霍伊特·范·霍特玛
**默认强度**: L2

### 核心场景
太空航行、荒漠戈壁、雪山冰川、巨型建筑、人类群像、海洋

### 光影氛围
```
natural light primary source, low angle side light elongating shadows,
Tyndall effect through dust/water vapor/atmospheric particles,
extreme contrast between warm stellar light and cold ambient darkness,
single hard light source (sun/star) creating sharp shadows in vacuum,
space exterior: absolute black vs blinding highlight, no middle grey
```

### 构图语言
```
extreme scale contrast: tiny human figure vs massive environment,
horizon centered in vast landscape/sky, massive sky-to-ground ratio,
character centered in frame with large area of negative space above/below,
practical spacecraft/vehicle miniature against painted/imax backdrop
```

### 声音设计
```
Base: spacecraft life support hum (interior) / absolute vacuum silence (exterior)
Rhythm: slow clock tick at 48 BPM (1.25 seconds = 1 day on Earth)
Texture: mechanical clicks, suit breathing, hull vibration
Tension: pipe organ swelling, cathedral reverb, cosmic hymn
Vocal: breathing inside helmet, radio communication with delay
Silence: absolute silence in space exterior, only breathing inside suit
```

### 需删减
- 高反差硬光(都市型)、霓虹、时间折叠元素
- 清新风光片质感

### 负面词强化
```
pastoral landscape photography, cartoon space, saturated planet colors,
cheerful adventure tone, bright cosmic colors, fantasy nebula
```

## 心理悬疑/人性博弈 (致命魔术系)

**参考影片**: 《致命魔术》《记忆碎片》
**摄影师**: 菲斯特(记忆碎片) / 其他(致命魔术)
**默认强度**: L2

### 核心场景
密室对决、镜面空间、复古剧场、记忆闪回、身份迷局、地下通道

### 光影氛围
```
top light + side light combination creating facial shadow masks,
mirror reflection creating multiple overlapping light layers,
character outline blurred with faint double-image at edges,

selective focus: sharp on key detail, soft on everything else,
practical light sources: stage lamps, candles, flickering bulbs
```

### 时空氛围
```
frame edges slightly out of focus suggesting unreliable perception,
local area double-exposure overlay suggesting memory overlap,
motion trail with jump-cut stutter on movement paths,
color shift between timelines: warm sepia (memory) vs cold blue (present)
```

### 构图语言
```
mirror double composition: real subject sharp, reflection slightly虚,
asymmetrical confrontation: two figures unbalanced in frame,
low angle close-up on key prop (watch/document/key) with blurred background,
narrow corridor/doorway framing creating claustrophobic compression
```

### 声音设计
```
Base: hollow room echo (reverb decay >= 2 seconds), distant mechanical hum
Rhythm: heartbeat thud, irregular and accelerating
Texture: mirror glass tap, paper turning, clock mechanism
Tension: Shepard tone,断续 piano single notes, dissonant string
Vocal: breathing clearly audible, swallowing, whispered dialogue
Silence: sudden dead silence breaking continuous sound pattern
```

### 需删减
- 宏大史诗感、科幻特效、明亮自然光
- 清晰直白的画面

### 负面词强化
```
bright warm tones, clear straightforward imagery, comedy tone,
happy ending aesthetic, romantic soft focus, sitcom lighting
```

## 历史传记/现实正剧 (奥本海默系)

**参考影片**: 《奥本海默》
**摄影师**: 霍伊特·范·霍特玛
**默认强度**: L1-L2

### 核心场景
历史事件重现、人物访谈、办公室博弈、演讲场景、实验室、时代群像

### 光影氛围
```
soft hard natural light, restrained contrast,
clear character rim light separating from background,
interior warm tungsten light vs exterior cold daylight conflict through windows,
IMAX extreme close-up on face with razor-thin depth of field,
natural skin texture visible: pores, wrinkles, subtle imperfections
```

### 构图语言
```
symmetrical formal composition suggesting institutional order,
character centered in严肃 framing, low angle reinforcing authority,
interview setup: subject slightly off-center with negative space,
crosscutting visual contrast: warm subjective vs cool objective
```

### 声音设计
```
Base: quiet room tone, paper shuffling, pen writing
Rhythm: subtle violin pulse (accelerating like chain reaction)
Texture: chalk on blackboard, typewriter keys, telephone ring
Tension: gradual build from silence to overwhelming volume
Vocal: dialogue clear and primary with minimal reverb
Silence: nuclear detonation - flash first (complete silence), then delayed blast wave
```

### 需删减
- 时间残影、空间折叠、高反差明暗
- 偶像剧质感

### 负面词强化
```
beauty filter, skin smoothing, melodramatic acting,
idol drama aesthetic, warm romantic glow, exaggerated expressions
```

## 日常叙事/写实剧情 (轻量系)

**参考影片**: 诺兰所有影片的日常段落
**默认强度**: L1

### 核心场景
室内对话、街道行走、日常通勤、生活化场景、等待、思考

### 光影氛围
```
natural diffused light, soft shadow transitions,
no strong contrast, gentle light ratio 1:2 to 1:3,
practical interior lighting (overhead, desk lamp, window),
no atmospheric effects, clean air, natural color rendering
```

### 构图语言
```
natural realistic composition, slight symmetry without forcing,
no deliberate visual tricks or extreme angles,
character positioned naturally in environment,
foreground elements providing subtle depth without distraction
```

### 声音设计
```
Base: natural environment sound (room tone, street ambience)
Rhythm: subtle or absent, maybe distant clock
Texture: everyday sounds (footsteps, fabric, objects)
Tension: minimal or absent, very subtle low drone at most
Vocal: dialogue primary and clear, natural reverb
Silence: natural pauses in conversation
```

### 需删减
- 所有时空特效、强反差光影、史诗感元素
- 任何刻意的风格化处理

### 负面词强化
```
indie film warm filter, web drama flat look, exaggerated acting,
sitcom bright even lighting, music video aesthetic
```
