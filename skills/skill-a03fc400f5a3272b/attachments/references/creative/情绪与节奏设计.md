# 情绪与节奏设计 · v2.0 — 零铺垫·冲击驱动

> **v2.0 重大变更**：砍掉四阶段节奏波形、砍掉"减速手段"、砍掉"信息钩"、新增镜头语言多样化四维约束。全剧从"起势→攀升→风暴→决战"的教科书弧线改为"冲击段连续叠加→终结段收束"的冲击驱动模型。单集微结构从"前30s钩子→中间发展→最后30s卡点"改为"每段=冲突切入→冲突推进→钩子收尾"的连续冲击。
> ⚠️ **v3.6 决策锁定表**：本文件为判断知识库。执行 `/目录` 时，情绪弧线、钩子类型、兼容性判断、四维镜头语言要求先在 `creative.md` §0.2 分集决策锁定表中锁死，后续 Phase 0/1/2 只引用锁定表。

## 一、核心设计原则

| 原则 | 说明 |
|:---|:---|
| **零铺垫·冲突先行** | 每段从冲突中间切入，不使用任何"建立空间""角色定位""场景引入"等铺垫段落。15s 只做一件事 |
| **节奏快** | 段内无喘息段落。冲突切入→推进→钩子一气呵成。全剧不设"过渡集""缓冲集" |
| **冲突密** | 每段一个核心冲突事件。段与段之间冲突不降级不缓和，钩子直接衔接到下一段冲突 |
| **反转猛** | 反转钩优先于信息钩。反转必须在观众意料之外——身份反转/局势反转/认知反转 |
| **信息融入冲突** | 所有角色背景/关系/动机/前情，在冲突进程中以对话/动作/视觉符号自然释放。不给"交代段" |
| **视觉丰富** | 每段 15s 内运镜/景别/角度/构图至少各变化 2 种（详见 §四） |

## 二、全剧情绪结构：二阶段冲击模型

### 2.1 二阶段波形

| 阶段 | 集数占比 | 情绪强度 | 核心任务 |
|:---|:---:|:---|:---|
| **冲击段** | 前 80% | 7→10/10 | 每集围绕一个核心冲突事件从中间切入，连续推进，不设"建立集"。第 1 集即入冲突核心 |
| **终结段** | 后 20% | 8→10/10 | 全剧收束。所有未闭合线索在此解决，但保持冲突密度——拒绝"讲道理式结局" |

### 2.2 单集冲击结构

一集 = N 个冲击段连续叠加。无"中间发展部分"独立区域：

```
S1A：冲突切入 → 冲突推进 → 钩子收尾
S1B：钩子接续 + 冲突升级 → 新钩子
S1C：钩子接续 + 冲突升级 → 新钩子
...
S1H：冲突转折 → 终局钩子（情绪强度 ≥ 8/10）
```

每段 15s 内部三段式：
- **0-3s 冲突切入**：身体关系叙事或动作中间瞬间直接入画。无空镜/定位/建立
- **3-12s 冲突推进**：对话+动作+光影同步升级。背景信息在冲突进程中以对白/动作自然释放（如"你三年前就背叛了我"）
- **12-15s 钩子收尾**：悬念/反转/情绪/危机四选一，强度 ≥ 8/10

### 2.3 开场类型（0-3s）

两种开场均可，由具体冲突内容决定：

| 开场类型 | 核心机制 | 示例 |
|:---|:---|:---|
| **身体关系叙事** | 画面内人物位置关系和身体距离直接讲述权力/关系/情绪故事 | 仰拍A下颌线紧绷俯视 + 俯拍B瞳孔放大仰视 → 不等权力 |
| **动作中间瞬间** | 从某个关键动作的中间帧切入，观众被"发生了什么"驱动观看 | 一只手刚好把杯子摔碎、一个耳光刚好打到脸前 0.5 秒、刀尖停在喉咙前 1cm |

**禁止的开场类型**：
- ❌ 场景空镜/环境建立（"雨夜，便利店荧光灯闪烁"）
- ❌ 角色站位交代（"顾沉舟站在收银台旁"这种静态姿势）
- ❌ 因果前置解释（"因为三年前的事，他决定..."）
- ❌ "先给观众看看这是哪里"的任何变体

## 三、钩子体系（精简为四类）

### 3.1 四类钩子

裁掉信息钩——"抛出一个关键信息但不完全揭示"本质是编剧卖关子，与"信息在冲突进程中自然释放"原则矛盾。

| 钩子类型 | 核心机制 | 典型表现 |
|:---|:---|:---|
| **悬念钩** | 建立期待→接近答案→在揭晓前切断 | 面具即将掉落、门即将打开、身份即将暴露 |
| **反转钩** | 观众以为A → 最后一秒揭示其实是B → 切断 | 善良面孔露出獠牙、温柔声音变冷酷、死亡是假象 |
| **情绪钩** | 强烈情感冲击→高潮点切断→下一集从余韵开始 | 眼泪落下瞬间、拥抱前的最后一帧、崩溃嘶吼的嘴型 |
| **危机钩** | 生存/命运/关系临界点切断 | 刀刃刺入前1帧、坠落半空、爆炸闪光吞噬画面 |

### 3.2 钩子质量自检

- 删掉钩子后，观众会主动想问"然后呢？" → 通过
- 钩子能用一句话说清"观众想知道什么" → 通过
- 钩子和本段冲突有直接因果关联 → 通过
- 下一段/下一集有能力和意愿回应这个钩子 → 通过

### 3.3 钩子使用约束

- 每段结尾至少 1 个钩子
- 禁止同类型钩子连续使用超过 2 段（观众免疫阈值下降）
- 情绪钩 + 反转钩是最强组合——先调动情绪再进行认知颠覆
- 终结段末集结尾必须用反转钩或危机钩（情绪强度 ≥ 9/10）
- **禁止钩子架空**：钩子必须比上一段的情绪高点更强烈

## 四、镜头语言多样化（四维约束·阻断级）

每段 15s 必须满足：

| 维度 | 最低要求 | 禁止 |
|:---|:---|:---|
| **运镜** | 至少 2 种不同运镜类型 | 全程固定位/全程微动、全程同一种运镜重复 |
| **景别** | 至少跨越 3 档（L0-L5） | 全程中景正反打、全程近景对话、景别无变化 |
| **角度** | 至少 2 种角度 | 全程平视 |
| **构图** | 至少 2 种构图策略 | 全程主体居中对称为正、构图无变化 |

### 4.1 运镜变化要求

从以下中选择至少 2 种（由分镜_21_运镜.md 展开）：
- 急推/急拉（快速景别变化，用于情绪爆发点）
- 手持跟拍（轻微晃动，用于紧张/逃跑/对峙）
- 升降（上下空间转换，用于权力关系表达）
- 甩镜/快摇（快速空间切换，用于惊吓/发现）
- 环绕（围绕主体旋转，用于孤立感/被包围）
- 低角度推进（自下而上压迫感）

### 4.2 景别变化要求

每段必须包含至少 1 个极特写(L5) 或大远景(L0)，打破中景/近景的视觉疲劳。景别跳变 ≥ 2 档必须有明确的情绪理由——"冲突爆点""反转揭示""情绪冲击"均为合法理由。

### 4.3 角度变化要求

- 仰角：权力压迫、威胁感、角色强势
- 俯角：渺小感、被控制、命运俯瞰
- 倾斜（荷兰角）：心理失衡、危险逼近、世界崩塌
- 平视仅用于冲突核心对话段，不得连续超过 2 镜

### 4.4 构图变化要求

从以下中选择至少 2 种（由分镜_22_构图.md 展开）：
- 边缘出画（主体偏置，大面积留空）
- 前景切割（前景物切割主体，三层纵深）
- 对角线驱动（主体沿X型排列）
- 负空间吞噬（主体小比例，环境压迫）
- 权力压迫（主体压到框底/角落）
- 尺度反差（同框内一大一小极端对比）

## 五、情绪弧线（保留·适配二阶段模型）

### 5.1 六种基础弧线

| 弧线 | 波形 | 情绪走向 | 适用题材 |
|:---|:---|:---|:---|
| ARC-SWEET 甜蜜上升波 | ↗↗↗ | 甜→更甜→腻 | 甜宠、校园 |
| ARC-ANGST 虐心深谷波 | ↘↘↘↗ | 虐→更虐→极点→反转 | 虐恋、复仇 |
| ARC-BITTER 酸甜交替波 | ↗↘↗↘ | 甜→虐→甜→虐→终局 | 都市、家庭 |
| ARC-POWER 爽感阶梯波 | →↗→↗ | 平台→突破→新平台→再突破 | 男频爽文、升级流 |
| ARC-SUSPENSE 悬疑螺旋波 | ↗↘↗↘（振幅递增）| 线索→误导→新线索→真相反转 | 悬疑、探案 |
| ARC-COMEDY 欢乐脉冲波 | ↗↗↘↗↗ | 笑点→笑点→小危机→笑点收束 | 喜剧、日常 |

### 5.2 弧线×二阶段耦合

```
冲击段：弧线核心区 → 连续冲突推进，拒绝起势/攀升的缓升模式
终结段：弧线终局区 → 收束但保持冲突密度
```

### 5.3 12种情绪模板速查

| 情绪 | 适用弧线 |
|:---|:---|
| 悲伤/崩溃/强颜欢笑 | ARC-ANGST 虐心深谷波 |
| 喜悦/心动 | ARC-SWEET 甜蜜上升波 / ARC-BITTER 酸甜交替波 |
| 愤怒 | ARC-ANGST / ARC-POWER 爽感阶梯波 |
| 恐惧/惊讶/震惊 | ARC-SUSPENSE 悬疑螺旋波 |
| 厌恶/思念/紧张 | 任意弧线过渡帧 |

### 5.4 单集情绪指令生成

每集从情绪耦合中读取：`dominant_emotion`（主导情绪）、`arc_intensity`（强度值，0-100）、`scene_mood_progression`（情绪递进路径）。

强度映射到表演档位：0-20→L1 / 20-40→L2 / 40-60→L3 / 60-80→L4 / 80-100→L5。

## 七、自检清单

### 7.1 每次 /目录 时检查

- [ ] 是否选定了主导情绪弧线？
- [ ] 二阶段（冲击段/终结段）是否分配了不同的情绪强度区间？
- [ ] 每集是否有明确的核心冲突事件+情绪高点+钩子类型标注？
- [ ] 是否有连续的"建立世界观""场景引入""背景交代"等铺垫标签？
- [ ] 每集结尾是否使用了四类钩子之一（悬念/反转/情绪/危机）？
- [ ] 是否有连续超过 2 段使用同类型钩子？
- [ ] 终结段是否使用了最强钩子（反转钩/危机钩）？
- [ ] 背景信息是否全部嵌套在冲突进程中释放？
- [ ] 第一集是否即进入冲突核心（无"建立"集）？

### 7.2 兼容性阻断

- 情绪弧线类型与题材不兼容（如甜宠选 ARC-ANGST）→ 阻断
- 冲击段情绪强度 < 7/10 → 阻断
- 存在"建立""过渡""缓冲""场景引入"标签 → 阻断
- 信息钩出现在钩子类型中 → 阻断
