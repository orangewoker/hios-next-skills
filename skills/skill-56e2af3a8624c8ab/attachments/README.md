# 镜叙｜电影关键帧导演

面向 AI 图像与视频创作者，把故事想法转化为有事件、有空间关系、能继续运动的电影感单帧、组图和视频关键帧。

## 使用

输入主题、故事梗概或画面目标；可选提供主体设定、场景、情绪、画幅、镜头数量和参考图。镜叙会自动选择合理画幅，输出一个可直接生产的提示词、连续性锁、负面约束和验收标准。

需要修复现有结果时，附上生成图并说明最重要的问题；镜叙会优先诊断最高影响变量，一次只修改一个变量。

## 边界

- 不点名复制具体电影、导演、艺术家、品牌或摄影作品。
- 不把低饱和、黑边、浅景深或器材名当作电影感本身。
- 只有取得实际结果文件时，才把任务标记为已生成。
