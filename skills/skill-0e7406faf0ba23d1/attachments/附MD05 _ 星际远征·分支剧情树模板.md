# 附MD05 | 星际远征·分支剧情树模板

**所属主SKILL：** 星际远征 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“剧情线混乱、分支无收束”的痛点。

## #需要什么输入

- 主线剧情节点清单、核心抉择点设计。

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·收到微弱求救信号（start节点）
2. N02 抉择点1·是否偏离航线去救援（branch节点）
   - N02A 前往救援（消耗燃料，可能触发外星陷阱）
   - N02B 保持航线（船员信任下降，可能错过关键道具）
3. N03 遭遇陨石群或小型外星巡逻舰（normal节点）
4. N04 抉择点2·面对被感染的科学官（branch节点）
   - N04A 隔离/冷冻科学官（船员信任下降，但保留线索）
   - N04B 冒险救治（可能获得外星抗体，也可能导致全员感染）
5. N05-N08 层层推进（如：发现外星遗迹、反物质核心的争夺）
6. ENDING_CHECK 结局判定

### 三、灵魂七问（每个抉择点必过审）

1. 玩家为什么选它？（求生/道德/大局观）
2. 它改变了什么？（资源消耗/船员情绪）
3. 即时后果是什么？
4. 延迟后果在哪个节点出现？
5. 是否会导致资源彻底枯竭？
6. 是否有新的科幻设定揭露？
7. 是否符合星舰生存的硬核逻辑？
