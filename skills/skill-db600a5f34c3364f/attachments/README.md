# mahua-chinese-heritage-poster

中国古风 / 中国古建筑高端文化海报设计 Skill。

## 安装

将整个 `mahua-chinese-heritage-poster` 文件夹放入 Codex Skills 目录。

目录结构：

```text
mahua-chinese-heritage-poster/
└── SKILL.md
```

## 使用

安装后，可以直接提出类似请求：

- 用这个 Skill 做一张故宫文化海报
- 做一张敦煌古建筑海报
- 把颐和园做成“裂境”视觉
- 做一套中国古建筑系列海报
- 分析我上传的参考图，然后生成同一视觉体系的海报

## 核心风格

不是简单的“国潮”或“古风”，而是：

传统中国建筑 + 中国画 / 壁画质感 + 博物馆视觉 + 当代高级海报构图 + 超现实空间叙事 + 克制排版。

## 推荐输出

默认优先：
- 2:3 竖版
- 大面积留白
- 一个主建筑
- 1–3 个极小人物
- 矿物颜料 / 宣纸 / 壁画 / 岩壁质感
- 墨黑、赭石、朱砂、青绿、黛青、旧金等低饱和色系
