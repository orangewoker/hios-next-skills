# 万物生有切镜头的提示词（参考全文）

> 来源：知识库ima「万物生。」· 笔记"万物生有切镜头的提示词" 用途：合并判定逻辑+声画匹配剪辑+环绕弧线装置范例。涉及合并/切镜的段必读。

## 一、声画匹配剪辑范例（刘回笑声跨场景延续）

```
在刘回的笑声爆发到达最饱满音量的瞬间,画面发生硬切HARD CUT声音匹配剪辑——

切换到室内场景。新镜头是刘回的中景,镜头水平拍摄刘回,机位高度大约在他坐着时的脸部高度,
画面框住他从腰部以上到头部的范围。刘回的上半身后仰,他的脸上还泛着醉酒的红晕,头发凌乱,
肩膀放松下垂,胸膛随大笑的余韵起伏。他正在继续刚才那阵从外景延续过来的爽朗大笑——
笑声在声音轨道上是连续不间断的,从外景的画外音直接接续到室内画面里刘回正在张嘴大笑的状态,
声音的连续性掩盖了画面的硬切。
```

```

不至呆板；正反打切换时机位跳到这条弧线的对侧，但环绕的旋转方向始终保持顺时针不变，不越过
两人之间的轴线。...
```

## 三、画外音纵深事件范例（对白镜不只是脸）

```
此时画外传来琉璃继续说话的声音（画外音）："能不能请你救救我们，现在只有你能做得到了..."。
在这段画外音进行的过程中，画面左侧那片远景的焦点适时由虚转实、推到那座如山丘般的盲可汗身上——
左侧大幅画幅里只见盲可汗探出的一截巨大头颈与张开的巨口，一个三米高的魁梧巨人铁匠此刻已被卡在
它上下颚之间、双手死死撑住兽王的上颚与下颚、肩背绷紧、双腿抵着下颚奋力角力，徒劳地撑着不让
那张巨口合拢。僵持片刻，铁匠的手臂终于一软、力竭垮下，盲可汗的上下颚轰然合拢、仰头将铁匠整个
吞入...就在这一幕发生的瞬间，仍冷淡面对镜头的丹眉，头几不可察地朝画面左侧那个方向偏了一下、
视线也随之往那边极轻微地瞥去，旋即又收回。
```

## 四、运镜触发范例（随动作触发，不是独立声明）

```
画外传来一声呼喊"爸！"...刘回女儿手攥布袋从画面右侧入画、占据画面右半部，她入画即半蹲下身，
镜头随她下蹲缓缓向下摇移pan down、跟到画面底部沙地上一个此前不在画面中、趴伏昏迷的原版刘回...
喊到最后一声"爸！"，女儿猛地一顿、抬起头，旋即将头转向画面深处、背对镜头朝甲壳兽尾巴的方向望去。
随女儿这一转头，镜头顺势缓缓上升并向后拉远crane up and dolly back，把甲壳兽尾甲的上缘带进画面、
在尾甲顶上让出一片纵深空间——先是江流一颗湿漉漉的头从甲壳兽尾巴后方的左侧慢慢探出来...
```

## 五、多镜组音轨声明范例（底层声场+台词叠压）

```
底层远景的混乱声场全程铺满——低频地鸣、远处人群惊叫、房屋崩塌的坍塌声、巨物碾地与碰撞的钝重
声响交错此起彼伏、全程不断；台词与近景动作音因贴近镜头而清晰浮于声场之上。
```

## 六、环境声学属性范例（音质间接感）

```
画外音从画面里前景或中景的岩窟洞口位置传出——那是女儿和刘回继续他们的对话,声音的音质带有从
室内穿出岩窟门口的轻微闷响质感和岩壁的轻微回声,声音听起来不是直接录音棚清晰的,而是从洞口
飘出来的间接感,但对话内容仍然清晰可辨。
```
