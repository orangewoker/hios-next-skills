# 热血动作风（Action & Combat）分镜指令库

> **主打风格**：夸张透视、肌肉紧绷感、速度线与画面破坏力。
> **加载时机**：`/分集 {N}` Phase 2 时，若题材判定为热血 / 动作 / 战斗 / 机甲，加载本文件复用分镜。
> **配合使用**：含打斗戏份时，同时加载 [分镜_19_武打专项.md](./分镜_19_武打专项.md) 获取 29 组武打专用提示词。

| 分镜名称 | 完整指令 |
| -------- | -------- |
| **蓄力爆破** | 极低仰拍鱼眼镜头，从下而上的高燃火光照射。肌肉贲张的格斗家半蹲蓄力，右拳重重砸在碎裂的混凝土地面上，蜘蛛网般的裂纹向四周疯狂蔓延。周身环绕着沸腾的红色蒸汽，汗水从他咬紧的下颌滴落，充满极致的破坏力。 |
| **空中拦截** | 空中平移跟拍，冷峻的金属反光与蓝白气流。机甲战士在千米高空极速坠落，耳边是肉眼可见的白色音爆云。他强行扭转腰部，腿部装甲弹开推进器，在半空中拉出一道湛蓝色的尾焰，眼神死死锁定下方的坠落物，速度感爆棚。 |
| **剑刃相交** | 微距刀锋视角，冷暖光强烈冲撞。画面正中心是两把激烈摩擦的残破刀刃，火星四溅并带有极强的动态模糊。刀刃两侧分别是主角沾满血污的怒目和反派充满戏谑的冷笑，构图极度紧凑压抑，火药味一点即燃。 |
| **破窗强攻** | 室内向外的逆光抓拍，刺眼的破晓白光。特警男主撞碎巨大的玻璃幕墙飞身入室，无数折射着光芒的玻璃碎片如钻石般悬浮在半空（时间凝滞感）。他身穿防弹衣，在半空中已完成拔枪上膛的动作，身体极度舒展，充满暴力的几何美学。 |
| **残血反杀** | 特写慢推，阴暗废墟中的一束微弱顶光。满身泥泞和伤痕的主角背靠着残垣断壁大口喘息。突然，他猛地抬起头，原本涣散的瞳孔重新聚焦，眼底燃起狂暴的杀意。手中紧握的短匕首在黑暗中划出一道致命的银色冷光，绝境逢生张力拉满。 |
