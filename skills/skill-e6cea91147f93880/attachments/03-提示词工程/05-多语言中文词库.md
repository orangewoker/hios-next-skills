# 多语言中文词库

## 中文提示词原则

- 用中文描述主体、动作、场景、情绪最自然。
- 镜头术语可保留英文以保证精确（如 dolly-in, rack focus, tracking）。
- 参考标签统一用 `@图片1` / `@视频1` / `@音频1`。

## 常用镜头中文

| 中文 | 英文对照 | 用途 |
|---|---|---|
| 大远景 | extreme wide shot | 环境、规模、出场 |
| 远景 | wide shot | 场面调度、舞蹈、运动 |
| 中景 | medium shot | 对白、产品使用 |
| 中近景 | medium close-up | 对话、情绪 |
| 特写 | close-up | 情绪、质感、口型 |
| 微距 | macro | 材质、食物、珠宝 |
| 推近 | dolly-in / push-in | 发现、顿悟、亲密 |
| 拉远 | pull-back | 揭示环境、撤离 |
| 横向跟拍 | lateral tracking | 行进、队列、编舞 |
| 环绕 | orbit | 产品主视觉、雕塑感 |
| 摇臂 | crane | 规模、出场、揭示 |
| 无人机 | drone | 航拍、地理 |
| 手持 | handheld | 纪实、紧张 |
| 固定机位 | locked-off | 口型、产品、文字、logo |
| 变焦对焦 | rack focus | 注意力转移 |
| 低角度 | low angle | 压迫、崇高 |
| 高角度 | high angle | 脆弱、监控 |
| 俯拍 | overhead | 桌面、舞蹈、地图 |
| 过肩 | over-shoulder | 对话、关系 |
| 侧视 | profile | 剪影、行进 |
| 插入镜头 | insert | 道具、细节 |

## 常见套路陷阱（中文）

| 空词 | 替换为 |
|---|---|
| 电影感 | 具体镜头 + 具体光源 |
| 高级感 | 材质 + 灯光 + 简洁构图 |
| 氛围感 | 天气/雾气/光源 + 颜色 |

| 震撼感 | 低角度大景 + 主体运动 |
