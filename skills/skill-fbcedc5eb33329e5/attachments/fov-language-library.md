# 视场角语言库与镜头决策系统

本文档提供6种FOV视场角的完整可观察结果描述、镜头决策树、长焦/广角可视结果组合、防漂移锁定。用于视频生成提示词中的光学与摄影机层。

## 核心原则

Seedance 对"可观察到的镜头结果"的响应，比对摄影机元数据的响应更好。不要把毫米数、f-stop、ISO、镜头品牌名当作主要控制手段。优先使用：以角度表示的对角视场角、摄影机与主体的物理距离、可见的光学结果、内容与FOV的匹配。

## 一、6种视场角语言库

### 47° 标准常规视角

```
47° 对角视场角，标准常规镜头特征，摄影机距离主体3-5米，自然的人眼视角。无明显畸变，面部与身体比例自然，景深舒适，背景清晰可读但不过度夸张，构图经典、扎实、有电影感。
```

**适用：** 自然纪录片式动作、标准常规叙事镜头、中景对话。

### 84° 经典广角

```
84° 对角视场角，经典广角镜头特征，摄影机距离主体1-1.5米，必要时略微低机位。广角具有明显但自然的透视扩张，前景身体存在感更大、更近，环境一直可见到画面边缘，空间纵深清晰可读，建筑直线保持笔直，不出现鱼眼弯曲。
```

**适用：** 宽广环境动作、Cuarón亲密广角、身体非常靠近摄影机的内容、空间展示。

### 107° 直线型超广角

```
107° 对角视场角，直线型超广角镜头特征，摄影机距离前景主体0.5-0.8米。最近前景明显放大，周围环境向画面所有边缘大幅展开，边到边都保持较深的清晰度，直线保持笔直，画面边缘允许轻微色差，不要圆形暗角，不要鱼眼气泡感。
```

**适用：** 大规模空间地理、极端环境沉浸、整个节拍都是环境动作。

### 29° 短焦远摄肖像

```
29° 对角视场角，短焦远摄肖像镜头特征，摄影机距离主体4-6米。近景构图通过镜头焦距实现，而不是靠摄影机物理接近。主体锐利清晰，背景开始被压缩到主体身后，面部比例稳定自然，背景融化成柔滑散景，主体从环境中清晰凸显。
```

**适用：** 中景肖像、对话近景、需要背景压缩但保留一定环境。

### 18° 经典远摄

```
18° 对角视场角，经典远摄镜头特征，摄影机距离主体6-8米。背景压缩明显，远处元素看起来层层堆叠在主体身后，极薄焦平面突出眼睛与关键面部特征，前景和背景都融入柔和散景，画面带有远距离观察感。
```

**适用：** 紧凑情绪特写、观察式肖像、孤立感。

### 8° 超远摄观察

```
8° 对角视场角，超远摄观察镜头特征，摄影机距离主体20-25米。背景被极度压缩并铺平成柔和色块，只有主体清晰，其余全部融化成柔滑散景。画面像远距离狗仔、野生动物纪录片或体育转播的观察视角。必须有前景遮挡：失焦的前景物体以大块深色散景形状占据画面下方约30%-45%，从远处框住主体。
```

**适用：** 远距离隐蔽观察、体育转播、狗仔视角、压缩式监控肖像。

## 二、镜头决策树

在写最终提示词之前，根据内容类型静默选择镜头特性。

### 如果内容类型是人脸肖像

- 近距离亲密人脸，同时保留环境 → **84° Cuarón亲密广角**
- 中景肖像 → **29° 短焦远摄肖像**
- 紧凑情绪特写 → **18° 经典远摄**
- 远距离隐蔽观察 → **8° 超远摄观察 + 前景遮挡**

### 如果内容类型是环境动作

- 自然纪录片式动作 → **47° 标准常规视角**
- 宽广环境动作 → **84° 经典广角**
- 大规模空间地理 → **107° 直线型超广角**
- 极端环境沉浸 → 只有当整个节拍都是环境动作时，才使用135°超宽环境视野

### 如果内容类型是细节或微距

- 标准细节 → **29° 或 18°**
- 宽环境中的细节 → 只有明确需要时才使用SNAKE CAM风格
- 除非使用明确命名的技术，否则不要在同一个节拍中混合微距细节与宽环境动作

### 如果内容类型是远距离观察

- 体育转播、狗仔或野生动物观察 → **8° 超远摄观察**
- 压缩式监控肖像 → **18° 或 8° telephoto + 前景遮挡 + 大气雾霭**

## 三、内容-FOV匹配规则

镜头选择必须匹配镜头内容。

- **广角**最适合：环境、空间、身体动作、沉浸感，或身体非常靠近摄影机的内容。
- **长焦**最适合：肖像、观察、孤立、压缩感或远距离注视。
- **微距/细节**最适合作为独立插入节拍。

**不要在同一个镜头节拍里混合不兼容的内容类型。** 人脸肖像 + 环境地理 + 微距细节同时放在同一个节拍中，会造成镜头漂移。如果场景需要不同内容类型，使用受控内部剪辑，并为每个镜头分别分配镜头特性。

## 四、长焦可视结果组合

任何长焦镜头至少包含以下4条可观察描述：

- 背景完全虚化成柔和的暖色色块
- 主体保持极锐利对焦
- 只有主体清晰，其余全部柔化
- 主体身后形成柔滑散景色块
- 背景被压缩并平铺在主体身后
- 主体在融化的背景前清晰凸显
- 近景构图通过镜头焦距实现，而不是物理靠近
- 摄影机在物理空间中远离主体
- 摄影机与主体之间存在空气雾霭
- 前景遮挡以柔和深色散景框住主体

## 五、广角可视结果组合

任何广角镜头至少包含以下3条可观察描述：

- 前景身体存在感被透视放大
- 主体周围的环境持续可见
- 边到边保持较深清晰度
- 直线保持笔直
- 宽广空间一直可见到画面边缘
- 摄影机在物理空间中靠近主体
- 沉浸式近距离透视
- 不出现远摄压缩
- 除非明确要求，否则不要柔滑的肖像散景

## 六、防漂移锁定

只在相关时使用。

**长焦：**
```
这个镜头的任何部分都不能变成广角或标准镜头覆盖。需要更宽的构图时，应保持同一远摄镜头并让摄影机后退，而不是切换镜头。每一帧的背景都保持压缩并虚化。
```

**广角：**
```
这个镜头的任何部分都不能变成远摄肖像覆盖。主体周围的环境始终可见，摄影机保持物理上的近距离，画面持续保持广角式空间扩张和清晰可读的纵深。
```

**标准镜头：**
```
不要极端广角畸变，不要远摄压缩。画面保持自然、扎实，并接近中性人眼视角。
```

## 七、多镜头镜头一致性

如果序列内部有剪辑，为每个镜头定义镜头特性。

**如果多镜头使用同一镜头：**
```
所有镜头统一使用X°视场角，不得更改。每个镜头开头写：镜头锁定A = X°。每个镜头结尾写：镜头检查A：保持X°，无漂移。
```

**如果多镜头混合不同镜头：**
- 只有当内容类型发生变化时，才给不同镜头分配不同镜头特性
- 不同镜头特性之间只使用硬切
- 不要进行平滑FOV过渡
- 单个镜头内部不要随机发生镜头漂移
- 除非新镜头开始，否则不要改变镜头特性

**每一次内部剪辑都保持：** 活跃角色、场景地理、屏幕方向、视线、身体朝向、灯光方向、道具状态、伤口状态、血/雪/泥的连续性、世界物理规律。

## 八、光学反模式

不要写：

- 极端广角镜头（作为指令而非具体FOV）
- 把"广角全景"当作镜头指令
- 把"建立镜头"当作镜头指令
- "拉远" + "广角"（矛盾）
- 紧凑广角构图
- 把f-stop、ISO或镜头品牌元数据作为主要控制
- 在同一镜头中叠加多个复合摄影机运动
- 在一个节拍中混合不同内容类型
- 只使用负向镜头控制
