# 反推初期镜头与对白零丢失标准

本文件是收到反推视频后的强制摄取规范。目标不是先理解剧情，而是先建立不可丢失的源证据账本。任何角色替换、欧美化、剧情概括、FINAL_VIDEO_PROMPT 编译都只能在已锁定账本上继续。

## 1. 核心原则：先盘点，后解释

收到视频后先完成 `RAW_RECON_CENSUS`，再进入人物关系解释与本地化。

必须分别建立两个互不依赖的原始账本：

- `RAW_SH_LEDGER`：只回答“画面到底切了几次、每个真实镜头从哪里到哪里”。
- `RAW_D_LEDGER`：只回答“到底说了几段可理解的人类语言、谁说、从哪里到哪里”。

不要在第一次观看时边理解剧情边直接写最终 SH/D。剧情理解会天然压缩重复反应、短插镜、画外台词、重叠台词和跨切点台词，容易导致丢失。

## 2. 媒体完整性预检

在盘点前先确认：

- 视频可从首帧播放到末帧；
- 原始声音存在且可听；
- 实际总时长可读取；
- 若工具暴露帧率/音轨信息，记录但不要凭空推测；
- 若文件播放、音轨或尾部损坏，立即阻断，不得用剧情猜测补齐。

## 3. Pass A：静音镜头普查

先关闭或忽略对白，只看画面，完整播放一遍；随后对所有疑似切点进行慢速/逐帧复核。

为每个真实镜头建立 `RAW_SHxx`，至少记录：

- 起始时间；
- 结束时间；
- 切换类型：连续 / 硬切 / 明确转场 / 疑似隐藏切；
- 首帧主体与构图；
- 末帧主体与构图；
- 是否属于高风险短镜头。

硬规则：

- **没有最短镜头时长门槛。** 2-3 帧的插镜、反应镜、脚部/手部/道具特写，只要是真实编辑镜头就必须登记。
- 同一人物、同一动作、同一场景连续出现，也不能因为“剧情上是一件事”而合并镜头。
- 前景遮挡、甩镜、运动模糊、闪白、黑场、快速推拉、主体越过镜头等可能掩盖隐藏切，必须复核。
- 反应镜、建立镜、脚部插镜、手机/信件/戒指等道具插镜属于高丢失风险，强制二次检查。
- `RAW_SH` 主时间轴必须从 `00:00.000` 到视频末尾首尾相接，**无 gap、无 overlap**。

完成后锁定第一次计数：`RAW_SH_COUNT_PASS_A`。

## 4. Pass B：只听声音的对白普查

第二遍把视觉剧情判断放到一边，只听原始声音。必要时在工具支持的情况下以正常速度 + 较慢速度复听，但不得改变原事件时长。

每一段**可理解、具有词汇内容的人类发声**建立一个 `RAW_Dxx` 父事件。包括：

- 极短命令：如“走”“停”“No.”“Wait.”；
- 呼唤、称呼、短回答；
- 画外对白；
- 被打断的半句话；
- 两人重叠说话；
- 镜头切换前开始、切换后继续的同一句话；
- 段首或段尾只出现一部分的跨段台词。

不要因为字幕没有显示就忽略听见的对白；也不要因为画面中没人张嘴就删除画外对白。

每个 `RAW_Dxx` 至少记录：

- 父事件 ID；
- 起止时间；
- 源语言原句/可辨识内容；
- 说话人源标签 `SRC-xx`，无法确定时写 `UNKNOWN_SPEAKER`，不要猜角色名；
- 画内 / 画外 / 不确定；
- 是否被打断；
- 是否与另一 D 重叠；
- 是否跨镜头切点；
- 是否跨生产段边界。

### D 与 F 的分界

- 有可理解词汇内容：记为 `D`。
- 纯吸气、喘息、笑、哭、呻吟、非词汇惊呼：记为 `F`。
- 如果无法判断某声音是否具有词汇内容，标记 `UNCERTAIN_SPEECH`，不得直接丢弃。

完成后锁定第一次计数：`RAW_D_PARENT_COUNT_PASS_B`。

## 5. Pass C：对白-镜头交叉映射

把 `RAW_D_LEDGER` 映射回 `RAW_SH_LEDGER`，但不得为了方便而强行改变源事件。

### 5.1 单镜内对白

一句话完全落在一个镜头内：直接映射到该 SH。

### 5.2 台词跨切点

同一句真实台词跨越两个或更多镜头时：

- 保留一个父事件，例如 `D03`；
- 在各镜头内使用相位 `D03-A`、`D03-B`；
- `D03` 的父事件计数仍为 1；
- 不得因为切镜把一句话错误拆成两句，也不得因为想保持“一镜一D”而删除后半句。

### 5.3 J-cut / L-cut / 画外对白

对白可以先于说话人画面开始，或在切走后继续。此时按真实声音时间保留，不要求嘴型必须位于同一镜头。

### 5.4 重叠对白

两个角色真实同时说话时，建立两个独立 D 父事件，并保留真实重叠时间。

**重要：无 gap / 无 overlap 只约束 SH 主时间轴。**

D、F、A 在真实视听中允许互相重叠，也允许两个 D 在源视频确实重叠时重叠。禁止为了让事件看起来“不重叠”而错开、缩短或删除源声音。

## 6. Pass D：高风险视觉二扫

再次静音检查以下区域：

- 所有小于 1 秒的镜头；
- 所有疑似 0.5 秒以下的微镜头；
- 快速甩镜、人物经过镜头、前景完全遮挡、闪白/黑场附近；
- 对白说到一半发生切镜的位置；
- 反应镜与动作结果之间；
- 脚、手、道具、手机屏幕、信件、门锁等局部特写。

“小于 1 秒/0.5 秒”仅用于提高检查优先级，**绝不是删除阈值**。

形成 `RAW_SH_COUNT_PASS_D`。

若 Pass D 新发现镜头，使用并集更新账本，而不是维持第一次计数。

## 7. Pass E：对白二扫

至少再做一次完整对白复听，并结合：

- 静音看口型；
- 画外人物反应；
- 字幕/自动转写（若存在）作为辅助证据；
- 音频波形/语音活动区间（若工具实际提供）。

字幕和自动转写永远不是唯一真相来源：

- 有声音无字幕：保留声音；
- 有字幕无可听对白：不凭字幕创建 D，标记异常后复核；
- 自动转写漏掉短词、姓名、重叠对白时，以原始声音为准。

形成 `RAW_D_PARENT_COUNT_PASS_E`。

## 8. 三次强制对账

只有以下三关全部通过，`RAW_RECON_CENSUS` 才能锁定。

### Gate 1：镜头计数对账

比较 Pass A 与 Pass D：

- 数量相同且边界一致：通过；
- 数量不同：取证据并集，逐个解释新增/删除原因，再复核；
- 任何疑似切点仍未确认：`SHOT_UNRESOLVED=true`，禁止进入后续 Prompt 编译。

最终锁定：`RAW_SH_COUNT_LOCK`。

### Gate 2：对白计数对账

比较 Pass B 与 Pass E：

- 父 D 数量相同、说话人与时间窗一致：通过；
- 数量不同：取证据并集，重点查短词、画外、重叠、跨切点、段边界；
- 任何 `UNCERTAIN_SPEECH` 未解决：禁止进入最终 D 编译。

最终锁定：`RAW_D_PARENT_COUNT_LOCK`。

### Gate 3：交叉映射对账

必须满足：

- 每个 `RAW_D` 父事件至少有一个 SH 映射或明确跨 SH 相位映射；
- 每个跨切点 D 的所有相位首尾连续，无缺口、无重复；
- 每个 SH 均有明确画面内容，不存在“空编号”；
- 所有已识别画外对白仍存在；
- 所有重叠对白仍保持重叠；
- 段首/段尾未完成台词保留相位，不提前补完。

通过后：`RECON_CENSUS_LOCKED=true`。

## 9. 原始计数冻结规则

锁定后，后续步骤默认必须满足：

- `FINAL_SH_COUNT == RAW_SH_COUNT_LOCK`；
- `FINAL_D_PARENT_COUNT == RAW_D_PARENT_COUNT_LOCK`；
- 每个 `RAW_SHxx` 都有对应最终 `SHxx`；
- 每个 `RAW_Dxx` 都有对应最终 `Dxx` 或其相位；
- 欧美化只能改目标语言表达，不能删除父 D；
- 角色替换只能改说话人输出身份，不能删除父 D；
- 剧情概括不能合并真实镜头。

只有在后续逐帧复核证明“原先登记的是假切/重复音频/非语言声误判”时才允许修改锁定计数，并必须先更新原始账本与修改理由，再重新执行三次对账。

## 10. 欧美化防丢失规则

欧美化必须一对一继承 `RAW_D` 父事件：

- 不因英文更简洁而删除短回答；
- 不把两个源 D 合成一句英文；
- 不把一个源 D 随意拆成多个新父 D；
- 若一句英文跨镜头，仍使用同一父 D 的相位；
- 保留打断、重叠、停顿、画外状态和揭露时机；
- 英文长度适配原时间窗，但事实与说话行为守恒。

## 11. 进入 RECON_AUDIT 的最低内部账本

至少维护：

```text
RAW_RECON_LEDGER
- media_duration
- RAW_SH_COUNT_PASS_A
- RAW_SH_COUNT_PASS_D
- RAW_SH_COUNT_LOCK
- RAW_D_PARENT_COUNT_PASS_B
- RAW_D_PARENT_COUNT_PASS_E
- RAW_D_PARENT_COUNT_LOCK
- raw_sh_ledger[]
- raw_d_ledger[]
- cross_sh_dialogue_phases[]
- offscreen_dialogue_ids[]
- overlapping_dialogue_pairs[]
- unresolved_shot_candidates[]
- uncertain_speech[]
- recon_census_locked
```

这个账本属于 `ANALYSIS_ONLY`，不得进入 Seedance 2.5 模型绑定页，也不得把源角色姓名/旧人物外貌带入最终提示词。

## 12. 硬阻断条件

出现任一项即停止后续编译：

- `RAW_SH_COUNT_LOCK` 未建立；
- `RAW_D_PARENT_COUNT_LOCK` 未建立；
- Pass A / Pass D 镜头差异未解释；
- Pass B / Pass E 对白差异未解释；
- 存在未解决疑似切点；
- 存在未解决 `UNCERTAIN_SPEECH`；
- 任一 RAW_D 没有映射到 SH/相位；
- FINAL SH 数量与 RAW_SH 锁不一致；
- FINAL D 父事件数量与 RAW_D 锁不一致；
- 画外对白、重叠对白或跨切点台词在转换后消失。

任何阻断都必须回到反推账本修正，而不是在最终 Prompt 中“凭感觉补一句/补一镜”。
