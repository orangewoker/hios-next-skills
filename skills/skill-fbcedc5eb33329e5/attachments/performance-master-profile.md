# 角色表演主档案与表演诊断系统

本文档提供结构化的角色表演主档案模板、糟糕表演诊断图谱、群戏空间规则、人际距离与地位工具。用于视频生成提示词中的表演层编写与审查。

## 一、角色表演主档案

每个反复出现的角色只拥有**一个**主档案——关于这个角色如何表演的永久事实来源。只写一次，然后按每个场景进行适配。

**目标长度：150-220个词，一个连贯段落，全部可观察、可拍摄。**

### 模板（各区块顺序固定）

```
以[姓名]的身份进行角色表演。[年龄、体型、身体状态、姿势——让身体本身成为人物经历的记录]。[用一个从句概括心理驱动力——解释这种身体状态的内在动力]。声音特征：[音高/音色、口音/来源、语速与表达方式，以及情绪压力下声音如何破裂或变化]。关键身体习惯与小动作：[标志性小动作及其触发因素；压力小动作及其触发因素；掩饰行为——他们如何隐藏真实感受；面部面具，以及它在什么精确条件下裂开]。步态风格：[把步态作为人物塑造——给它一个明确名称，并具体说明重量、节奏与落脚方式]。然而，当[情绪触发因素]出现时，[变化——姿势、步态和面部如何改变]。[可选：软化目标——唯一一个会让面部真正柔和下来的人或事物]。
```

### 编写规则

1. **只写可观察行为。** 每种内在状态都必须对应一个身体标志。永远不要写"他很紧张"——要写下嘴唇颤抖、用力吞咽、张嘴长吸一口气再从抿紧的嘴唇中急促呼出。
2. **每个小动作都必须有触发因素。** 格式：[小动作] + [何时/为什么]。没有触发因素的小动作只是装饰；带触发因素的小动作才是戏剧构作。
3. **给步态命名。** 在引号中放入令人记得住的自创名称，锚定其生物力学："权力步伐""孔雀式昂首阔步""画廊步""攻城锤式大步""无畏舰式步伐"。然后拆开说明：重量、步伐、躯干和手臂如何运动、头部如何运动。
4. **同时建立面具和裂缝。** 每份档案至少带有一个"然而，当X出现时——……"的从句。外在伪装，以及让它崩塌的精确触发因素。一个角色同时在表演两种真实，正是木偶与活人的区别。
5. **只设一个软化目标。** 如果适合，只给面部设定一个会让它真正柔和下来的人/动物/物体。只能一个。
6. **不要写服装。** 衣服和造型属于提示词的场景/视觉区块，绝不属于表演档案。
7. **不要写摄影机，不要写颜色。** 表演只驱动表演本身、面部、声音和动作。
8. **体态承载人物经历。** 年龄、体型和姿势的选择要能讲出人物过去。

### 场景适配——主档案要重写，绝不能直接粘贴

主档案描述的是角色**是谁**。每一个场景，都要把它**重写**成此时此刻的状态：

1. **只写当前出现的角色。** 角色不在画面里 → 不写段落。
2. **保留恒定核心。** 身份、声音特征、标志性小动作、眼神生命和情绪贯穿线在每一场戏中都保持一致。
3. **为这一场戏重新表达。** 选择、强调、修改或删去具体行为，使其适配该场景的姿势、动作和节拍、情绪状态以及时间。
4. **转换，不要删除。** 某个行为由于物理原因无法发生时，把它转换而不是删除：原本焦躁踱步的人瘫坐在沙发上时，同样的紧张驱动力转移成持续的轻微晃动、甩动手腕和撕纸。
5. **一个连贯段落。** 提示词内部不要使用项目符号、标题。

### 声音锁定

表演会针对每场戏重写；**声音是锁定的**。每个角色只有一个声音提示词——永久的声音身份。当角色有台词时，把声音提示词**逐字原样**粘贴。绝不要针对不同场景修改它。

**声音提示词公式（1-2句）：**
```
"一位[年龄]岁的[来源/口音描述]。[音色与声区]；[语速与表达方式]；[声音的情绪特征——以及它在压力下如何变化]。"
```

## 二、15种糟糕表演图谱（诊断与修正）

| # | 症状 | 看起来是什么样 | 提示词层面的修正 |
|---|------|--------------|-----------------|
| 1 | 示意式表演（挤眉弄眼） | 脸在"描绘"情绪：挑眉、做鬼脸 | 不要让脸承担任务；写目标，并给双手一个Business |
| 2 | 表演结果 | 角色从第一秒开始就提前演出这场戏最终会发生的结果 | 只写角色**此刻**知道的东西 |
| 3 | 等待提示 | 对手演员说话时，脸是空的 | 让反应从对方台词说到一半时就开始 |
| 4 | 单一策略 | 整场戏只有一种颜色（一直喊/一直哀求） | 标出节拍；每个节拍使用一个新的策略动词 |
| 5 | 手势说明台词 | 手势重复词语含义（说"很大"——双手张开） | 手势要么先于想法，要么与台词矛盾，要么不存在 |
| 6 | 无代价情绪 | 没有铺垫和触发事件就突然流泪/暴怒 | 建立阶梯：克制→崩裂；情绪必须付出代价 |
| 7 | 身体与经历不符 | 混混却有舞者的姿势；瘾君子身体却像刚训练出来一样清新灵活 | 设置身体档案：重心、节奏、磨损 |
| 8 | 语言对阶层过于干净 | 街头人物却说着文学式长句 | 给语言加入杂质：打断、吞掉结尾、重复 |
| 9 | 提前发出威胁信号 | 暴力前出现"阴险"的停顿、眯眼、缓慢转身 | 威胁应当日常化；暴力不蓄势 |
| 10 | 群体同步 | 所有人同时做出完全相同的反应 | 让反应像波浪一样错开，并改变强弱 |
| 11 | 死停顿 | 沉默中什么都没发生 | 用评估或Business填满——或者剪掉 |
| 12 | 情绪重置 | 强烈事件之后，角色立刻"恢复正常" | 状态具有惯性；余波要带入下一个节拍 |
| 13 | 对角色作评论 | 表演对观众眨眼示意（"我们都知道这很好笑"） | 完全相信情境；喜剧要一本正经地演 |
| 14 | 特写过度表演 | 特写中出现主动、夸张的表情活动 | 镜头越近，动作越少：只留下眼睛和想法 |
| 15 | 死眼神 | 视线冻结、不眨眼、无眼跳、高光像玻璃 | 完整应用眼神生命规则——绝不是可选项 |

## 三、表演等级（自检）

- **0 —— 人体模型。** 台词被说出来了，但没有行为。
- **1 —— 朗诵者。** "富有表现力"地说台词，直接示意情绪，用身体说明台词。
- **2 —— 认真但僵硬。** 大致能猜出目标，但只有一种策略，反应太晚，停顿空洞。
- **3 —— 熟练工。** 有目标和节拍，会倾听对手演员，身体逻辑成立。缺少：潜台词、意外的策略、状态惯性。
- **4 —— 活着。** 行为连续、策略有反差、潜台词与台词分离、地位存在于身体中、反应先于台词，至少有一个出乎意料但真实的选择。
- **5 —— 磁场。** 拥有"4"的全部，并且加入悖论：角色把彼此不相容的东西放在一起——好笑又可怕、残酷又迷人、撒谎却又令人动容。**双重真实规则：达到5级时，角色始终同时表演两种真实。**

每个核心角色镜头都要以4+为目标；任何自检只有2分或更低的段落，都要在交付前重写。

## 四、群戏与空间规则

- **群体反应要像波浪一样传播，绝不能同步。** 一个人先听懂笑点，第二个人慢半拍，第三个人完全没反应。
- **反应比动作更有价值。** 每次事件发生后，最有价值的画面是看到这件事的那个人的脸。
- **威胁出现时冻结。** 群体始终有持续的微动作——换重心、打手势、身体前倾——但在关键威胁出现时，一切**停止**。忙乱→静止的反差就是标点。
- **移动 = 动机。** 没有人会在没有内在冲动的情况下穿过房间：要么朝某样东西靠近，要么远离某样东西。
- **强者静而轻；弱者躁动并大喊。** 危险感并不是由那个危险人物"演出来的"，而是由周围所有人对他的紧张反应演出来的。威胁不需要蓄势。
- **损耗会累积。** 如果一个角色在整个故事中逐渐被磨损，就要让身体累积这种变化——更灰败、更沉重、反应更慢——绝不能每场戏之间重置。

## 五、人际距离（Proxemics）——用距离制造戏剧

角色之间的距离，是他们关系的可视化图表：

- **亲密区（0.5米以内）**——爱或暴力；未经允许进入这个范围就是攻击；在距离一张脸10厘米的位置低声说出威胁，比隔着房间大喊更可怕。
- **个人区（0.5-1.2米）**——信任。
- **社交区（1.2-3.5米）**——事务、戒备。
- **公共区（3.5米以上）**——疏离、等级。

场景中的戏剧，很多时候只是在讲距离的故事：谁靠近，谁拉开，谁僵住。**距离变化 = 节拍变化。**

## 六、地位（Status）——看不见的等级

地位取决于你**做什么**，而不是你是谁。

- **高地位：** 头部几乎不动、动作缓慢、长时间凝视、回答前停顿、占据空间、触碰别人的东西。
- **低地位：** 忙乱、频繁触摸自己（脸、头发）、说话断裂、用笑声填空、用眼神寻求许可。

表演里最有意思的东西是**地位破裂（status breaks）**：老板有一秒钟露出恐惧；下属突然停止微笑。一种有力的场景形状是：以高位进入并崩塌，或以低位进入却翻转整个房间。

## 七、发送前检查清单

- [ ] 画面中的每个角色都有一个以动词表达、指向对手演员的目标
- [ ] 障碍和利害关系存在；失败的代价真实存在
- [ ] 有2-4次节拍变化，并且每一次都能从行为中看见（停顿/姿势/节奏/视线）
- [ ] 反应在对方台词结束前就开始；存在评估时刻
- [ ] 每个角色都有Business；动作中断的重音被有意识地使用
- [ ] 距离会发生变化，并且变化有动机；地位存在于身体中
- [ ] 所有小动作都有触发因素；面具有自己的裂缝（"然而，当X……"）
- [ ] 明确写出眼神生命：眼跳、眨眼质感、眼神高光、眼睛先于想法
- [ ] 角色说话时，声音提示词逐字原样粘贴；沉默时则省略
- [ ] 写状态，不写过渡；表演内部不包含服装、摄影机或颜色
- [ ] 群体反应错开；强者=静止，弱者=躁动
- [ ] 等级检查：这个段落能达到4+吗？
