# 分支D: 剪纸拼贴风 — 平面大湿子管线

## 平台执行要点

- 风格块：`style-locks.md` → STYLE_LOCK_D（含平面/立体双变体）
- 模型（自动匹配）：图像 Midjourney V7（材质表现力强）/ 备 Seedream 5.0；视频 可灵 Kling 3.0 / 备海螺
- 参考图配方：风格样板 + 色卡（必绑），角色剪纸设定图 + 纸材质参考（条件绑）——**材质统一是本分支生命线**
- 转场：翻纸/纸屑飞散等全部做成 0.5-1.5s 转场视频片段（取上镜尾帧图生视频）

---

## 关卡衔接（上游已定）

风格样板与调参（G6）、节奏与输出格式（G7）已在上游确认；模型自动匹配。

- 换风格 / 调样板 → 回退 G6 ｜ 调节奏 / 换输出格式 → 回退 G7

**G6 样板图生成**：图片节点 → Midjourney V7 → STYLE_LOCK_D + 剧本代表性场景，一次出 3 张（纸偶特写看毛边纤维/多层中景/全景看层次景深）。

**D 分支精细调参备查（G6 阶段使用）**：

- 纸材质: 牛皮纸(复古) / 白卡纸(素雅) / 彩纸 / 报纸旧书页(怀旧) / 瓦楞纸(粗犷)
- 精细度: 粗犷手工(毛边明显) / 标准(整洁剪纸) / 精细纸雕(多层镂空)
- 色彩基调: 复古暖黄 / 清新马卡龙 / 浓郁民俗 / 大地自然 / 黑白剪纸
- 层次深度: 2-3层(简洁) / 4-5层(标准立体) / 6层+(纸雕盒景深)
- 纹理强度: 无 / 轻微纸纹 / 明显纤维感
