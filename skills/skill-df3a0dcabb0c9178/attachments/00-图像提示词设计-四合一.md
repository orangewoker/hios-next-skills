# 做什么

把任意形态的图片需求转成一条**能出实拍感**的高质量提示词，四类图通吃：场景图 · 真人角色图 · 道具图 · 怪兽图。

目标：无限接近真实实拍、影视级摄影与光影质感，**不出 AI 感、塑料感、锐化感**。并在用户原始提示词基础上提炼需求、强化优化，不许照抄。

**两条总纲**：

1. **超现实 ≠ 超现实主义画风**（针对怪兽类）——“超现实”指现实里不存在这个生物，**质感必须极其写实**。
2. **AI 感来自“不符合物理的完美”**——三招解药：**有来源、有约束、有不完美**。

只处理**单张图**，不管镜头组、运动、连续分镜。

# 需要什么输入

- 最少：一句话意图（“一个古代庭院”“一个民国女学生”“一把旧铜锁”）
- 可选：各类的具体约束（见第 2 步）
- **用户给的原始提示词多烂都直接收**，不要要求他先整理

# 怎么做

## 第 0 步 · 先判类型

| 用户要的 | 走哪一类 | 缺不得的三样 |
|---|---|---|
| 场景、环境、地点、室内外空间 | 场景图 | 画幅 · 用途（交代地理／建立气氛／做背景）· 地点与时代 |
| **真人**角色、人物资产（不出二次元） | 角色图 | 年龄区间 · 画幅与用途 · 时代与地域 |
| 器物、刀具、首饰、武器、工具、器皿 | 道具图 | 器物类型或用途 · 材质 · 画幅与用途 |
| 现实不存在的生物 | 怪兽图 | 体型量级 · 生态位 · 画幅与用途 |

## 第 1 步 · 把用户给的话逐句分成四类

- **意图**（要什么感觉）→ 保留，翻成视觉落点
- **事实**（地点、时代、年龄、材质、体型……）→ **一字不改**
- **空词** → **删掉**。见到就删：8K、超清、大师作品、电影级质感、极致细节、超写实、细节丰富、氛围感拉满、绝美、高级感、唯美、完美、漂亮、精致、细腻、光滑、无瑕、恐怖、震撼、史诗级、神话感
- **缺失** → 按第 2 步处理

意图翻译示例：压抑→低天花与顶光下压、墙体占画面上缘超 2/3、暗部占七成；书卷气→肩略内收、目光平视偏下、服装层次干净、手边有书或笔；看着值钱→表面完整、边角利落、金属有温润旧色而非崭新反光；可怕→**不写“可怕”**，写“它身体的比例里有一段明显不合理的地方”＋“它不发出声音”。

## 第 2 步 · 三档纪律

- **必问（最多 3 个）**：只问“答案会明显改变画面”的（即上表那三样）。**一次问完，其余不问。**
- **默认补**：补完**必须在交付时标注**，让用户能改。常用默认——时段（交代地理→上午，气氛→黄昏或夜）· 天气晴 · 季节按环境推宁少勿多 · 单一主光侧光或侧逆光 · 景别（交代地理→全景，气氛→中景，资产→全身或三分之四）· 背景中性简洁 · 服装三层以内 · 体表材质按生态位推 · 颜色低饱和
- **绝不编造**：不加原文没有的人、动物、器物、宝石、铭文、疤、痣、伤、飞鸟、雪、特殊地标；不假设参考图里没有的东西；**不替用户改美学主张**（不把雨天改晴天、不因为“更好看”改长相）

## 第 3 步 · 四类共用的硬判据

- **光必须有来源**：写得出具体位置。不写“侧逆光”，写“从画左那扇窗进来的天光”
- **一图一主光**；脸部明暗比不超过 1:4；**暗部不死黑**（写明“暗部仍能看出材质”）；**冷暖不各半**
- **材质写可见属性，不写材质名**：
  - 不写“老木头”，写“木色深浅不均，边角被磨出浅色，表面有一层薄灰”
  - 不写“铜”，写“表面呈暖暗的赭色，边缘被磨出浅亮的本色，凹处积着深色氧化物”
- **每种材质给一条“光怎么落在它上面”**：金属拉细高光 · 玉透光 · 木吸光 · 织物散光 · 湿润表面反光集中在水膜边缘
- **地面比墙面重要**（场景）；**器物必须落地或有支撑**（道具）；**人物要真正站在空间里**，给位置落点＋接地阴影（场景、角色）
- **不完美**：磨损、不对称、积灰、颜色不均、旧伤。**对称＋光滑＋干净＋完美＝渲染感**
- **不要用否定句**：不写“不要塑料感”，改写“高光只在……其余哑光”

## 第 4 步 · 防 AI 感（对症改法）

- **塑料感／蜡质感** → 「高光只出现在窗光正对的那一小块，其余为哑光，表面有细微起伏」
- **锐化过度／数码味** → 「适度景深，仅主体清晰，远处边缘柔化，暗部保留层次而不压黑」
- **CG／渲染感** → 「只有一处光源，它在物体表面留下反射；边角有磕碰，摆放略偏、彼此不平行」
- **HDR／数码感** → 「低对比、低饱和，亮部不过曝，暗部仍见材质」
- **微细节堆砌** → 「只在视觉中心给细节，其余按景深自然虚化，大面积材质保持干净」
- **贴纸感／合成感** → 「受同一处光照，脚下有接地阴影，靠墙侧有环境遮挡的暗部过渡」
- **塑料皮肤／蜡像脸**（角色） → 「皮肤呈哑光，高光只在鼻尖、颧骨上缘与下唇；颧骨到下颌有柔和过渡」
- **AI 美颜／网红脸**（角色） → **删掉“漂亮／精致／绝美”**，改写具体骨相：「颧骨不外扩，下颌角靠内，眼裂较长」
- **玩具手办感／拼贴感**（怪兽） → 「体表有大片不均的旧色与附着物」＋**定一个母本，只留一处外来器官**

## 第 5 步 · 各类型的专项判据

### 场景图

- **高差与边界必写**：有无台阶、这空间怎么围起来（围墙／屋檐／山体／水面）
- **一个空间只给一个主结构**（不要套第二进院落）
- 道具 5 件以内，至少 1 件与用途相关；地面状态要写
- 历史类先保证建筑器物符合时代；**都市室内先定房间功能与动线，窗是唯一光源时务必写窗的位置与朝向**

### 角色图（真人）

- **五官写“关系”，不写“类型名”**：不写“高鼻梁”，写“鼻梁起点在两眼之间靠上，鼻尖略向下，鼻翼窄”
- **表情写“肌肉动作”，不写情绪词**：不写“愤怒”，写“眉的内侧下压、上眼睑抬起、鼻翼张开、下颌前移”
- **皮肤真实感的四件**：高光集中 ＋ 体积过渡 ＋ 少量不完美 ＋ 环境光作用。**它来自体积与光影关系，不是毛孔多、不是锐利高光、不是磨皮**
- **头发三件**：成束有重量 · 写清发际线与分缝 · 写头发与肩或领口的接触关系
- 服装要有重量（写受力）＋ 三层为限 ＋ 写使用状态
- **手部简化**：只让手做必须的事，握住最安全
- 优先级：身份结构 → 轮廓体态 → 服装造型 → 表演动作 → 镜头表现 → 细节

### 道具图

- **尺寸给尺度锚，不给数字**。五种锚：人体部位（一掌半长）／另一件已知物（像饭碗那么高）／画面比例／可容纳关系（能放进一只手掌）／握持方式（需双手抱持）
- **每个部件明确归属一种材质**，多材质必须分部件写
- **痕迹必须有成因**：握持处发亮发暗（摩擦）· 棱角被磨圆（磕碰）· 凹处积垢 · **背面与内侧相对完整**（不要全身均匀做旧）· 一件道具只做 2–3 个痕迹重点
- **装饰“少而狠”**：一条主纹样足矣，其余素净。**装饰越多越像玩具**
- 有手出镜：写明接触点；**递物要双方的手都写＋给区分锚**（“执物者袖口深色，接物者袖口浅色”），不给区分锚会把两只手混成一只

### 怪兽图

- **奇观化三法，只选一个**：
  1. **尺度的荒诞**——形制完全普通、尺寸完全不对（一只壁虎的形制贴在楼体侧面，体长跨好几栋楼，**但脚趾仍细小、仍贴着墙**）
  2. **熟悉物的异化**——从两种自然史物种借形：**一个明确的母本 ＋ 一处明显的外来器官**，不要平均混合
  3. **结构的反直觉**——器官的用途与外观相反（看起来是张开的嘴，其实是诱捕器）
- **一兽一奇观**：三个特征等于零个特征。定下奇观点后其余部位**全部按最保守最写实的方式处理**
- **“能被一句话说清”检验**：说不清就重做
- **奇观点要落成可被看见的形态**：不写“它是伪装型猎手”，写“它的口部张开时，里面是一圈向内收拢的细齿，齿间没有喉咙，是封闭的”
- **写实七支柱**：骨架可见 · 体重可信（腿粗在关节以下）· 材质有源 · **环境交互**（把它抠掉，环境的变化还在不在）· 光线一致 · 尺度锚点 · 不完美
- **禁止借形**：不借已命名的影视游戏怪兽、不借神话生物、不用狮头＋鹰翅＋蛇尾式缝合。判据：外人看了能不能说出“这像 XX 里的那只”

## 第 6 步 · 画幅（定好画幅后构图要重排一次）

- **9:16 竖屏**：**垂直分层**（近处脚下 → 中景主体 → 远景天际）；横向最多放 2 个元素；纵深优先；擅长“往里看”（走廊、门洞、巷子），不擅长“并排看”；全身像人物占画面高度 60%–80%
- **16:9 宽幅**：**横向三段**（左／中／右各一个信息），纵向最多 2 层；适合并排关系与横向体型
- **1:1 或 4:3**：中心构图、对称、留白（器物、头像、正立面好用）

画幅决定的是“信息放在哪个方向”，不是“裁多少”。**横向体型塞进竖屏必崩**——此时改方向的呈现方式（沿纵向攀爬），并在改动说明里写明。

## 第 7 步 · 多图一致（同一对象出多张时）

**先钉不变项，再写变化项。** 第一张写一段“结构描述”（场景：方位光源材质／角色：脸身发衣识别物／道具：形制部件材质痕迹），后续每张**原样带上**，只写变化的部分。**不要每张重新描述一遍**——重描述＝生成一个相似但不同的东西。

# 产出什么

固定四件，顺序不变：

```
【正文提示词】一段自然语言，不分点、不写字段名、不叠同义词。
  顺序：主体与环境 → 光 → 摄影 → 材质 → 细节 → 整体质感。

【Negative】一行逗号分隔。

【画幅与参数建议】画幅｜景别或构图｜机位高度｜镜头倾向｜景深

【改动说明】替换了哪些空词｜补齐了哪些默认项｜保留了哪些事实｜是否主动调整过方向
```

**「改动说明」不能省**——它让用户一眼看出动了什么、没动什么。

# 什么时候问你

- 只在三种情况停下来问，**一次问完、最多 3 个**：上表“缺不得的三样”未知时。
- 其余一律按默认补，补完标注，**不要反复确认**。
- 用户说“这条不成立”时，撤销或改写那一条，不要辩解。
- **出图不对时，不要加形容词**。按顺序查：① 空间、构图、比例 ② 光（是否来源不明／冷暖各半／暗部死黑）③ 画幅（构图装得下吗）④ 材质（是否写了“光滑”“细腻”）⑤ 痕迹（是否干净得像新的）。**一次只改一处。**
