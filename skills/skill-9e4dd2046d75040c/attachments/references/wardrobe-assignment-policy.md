# 国内四站服装分配策略

## 固定城市与分配规则

固定顺序：BEIJING 北京、SHANGHAI 上海、GUANGZHOU 广州、DALI 大理。每次执行从每座城市的造型池中选一套；四站必须不重复主色、轮廓、鞋型和主道具。开场服装不计入四站造型，但必须来自角色卡。

| 城市 | 造型池 | 主道具 |
| --- | --- | --- |
| 北京 | 风衣/短夹克、针织上衣、直筒裤或中长裙、乐福鞋或短靴 | 复古相机或皮质托特包 |
| 上海 | 衬衫或短西装、半裙或阔腿裤、低跟鞋或玛丽珍鞋 | 精致手袋或小型杂志 |
| 广州 | 轻薄衬衫、亚麻套装或轻盈连衣裙、凉鞋或帆布鞋 | 冰饮、折扇或藤编小包 |
| 大理 | 针织背心叠穿长袖、层叠长裙或宽松工装、堆堆靴或布鞋 | 帆布旅行袋或小花束 |

## 随机但受控

按角色性别表达、身形与原服装气质选择兼容造型。随机只发生在同一城市的可控池内；若某个候选会造成与前站重复主色、轮廓、鞋型或道具，必须重选。

每次输出先列出本次四站造型，供用户在预览确认时只修改某一站。不要让用户重新设计整套转场逻辑。

## 登机牌视觉

- 北京：暖红或故宫朱砂色边条，`BEIJING 北京` 大号水印。
- 上海：深蓝或银灰边条，`SHANGHAI 上海` 大号水印。
- 广州：草绿或暖黄边条，`GUANGZHOU 广州` 大号水印。
- 大理：浅蓝或米白边条，`DALI 大理` 大号水印。

NAME / FLT / GATE / SEAT 等小字是装饰，不要求精确可读；城市中英文、边条色和卡片层叠关系是优先条件。
