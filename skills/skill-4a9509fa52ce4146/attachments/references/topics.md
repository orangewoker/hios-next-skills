# 竖屏短剧题材全类别选项库

> 用途：问询题材时，必须向用户展示以下**全部类别**（可按大类和编号列出），让用户挑选主题材；同一类别下可进一步选细分方向；允许"主题材+副题材"组合（如"都市情感"+"重生复仇"）。展示选项时用简洁列表，附每类一句核心爽点 + **爆火原理分析**，帮助用户快速选择；不要只问开放题。
>
> **推荐规范**：给出任何推荐时，必须附"为什么推荐它 + 它的爆火原理"（情绪机制、目标人群、验证过的数据/案例），不得只列选项不给理由。

## 大类一：都市情感（受众最广，以女性向为主）

1. 豪门恩怨 / 家族内斗
2. 隐婚 / 闪婚 / 契约婚姻
3. 离婚之后 / 前夫前妻（追妻火葬场）
4. 总裁霸总 / 先婚后爱
5. 破镜重圆 / 久别重逢
6. 暗恋成真 / 双向奔赴
7. 姐弟恋 / 年下恋
8. 带球跑 / 萌宝助攻
9. 凤凰男 / 扶弟魔 / 现实婚恋
- 核心爽点：身份反差、情感推拉、打脸反转、甜虐交织
- **爆火原理**：婚姻/恋爱是全民级情绪池，用户代入门槛最低；"先虐后甜/先抑后扬"制造强烈情绪落差，转化率和复刷率高；豪门、隐婚自带阶层幻想，满足"灰姑娘"心理。

1. 赘婿翻身 / 上门女婿逆袭
2. 战神归来 / 龙王归来 / 隐世大佬
3. 废柴崛起 / 天才回归
4. 扮猪吃虎 / 低调大佬
5. 职场逆袭 / 打脸同事上司

- **爆火原理**：底层身份开局 + 高身份揭露 = 最强"爽点引擎"，观众把自身压抑投射进主角，通过"打脸"获得替代性满足；每 10-30 秒一次打脸符合多巴胺回路，弃坑率最低。

## 题材选择建议规则

- 用户没给方向时：优先推荐当前平台热门的组合（如"都市情感+总裁霸总"、"重生复仇+豪门"、"战神归来"），**每个推荐附爆火原理分析**，并说明理由。
- 用户给灵感时：从灵感中识别隐含题材，向用户确认归类，并提示可叠加的副题材以增强爽感（同样附分析）。
- 组合规则：主题材决定情感基调，副题材负责叠加爽点；建议至多"1 主题材 + 1~2 副题材"，避免元素过杂。
- 推荐分析模板：**"推荐理由（一句话）→ 爆火原理（情绪机制/人群/数据）→ 与用户灵感的结合点"**，三者缺一不可。
