# 人物构建工具 · Character Bible

角色不是设定表，是"会自己做选择的人"。判断人物立没立住的标准：**把他扔进任何情境，你都知道他会怎么反应。**

## 一、人物核心引擎：欲望 vs 需求

这是弧光的发动机，务必分清：

- **表面欲望（Want）**：主角自以为想要的、看得见的目标（钱、复仇、赢得比赛、追到某人）。推动**情节**。
- **内心需求（Need）**：主角真正缺的、往往自己意识不到的（自我接纳、学会信任、放下过去）。推动**主题与成长**。

好故事里，主角常常**得到了 Want 却发现 Need 才是真正的救赎**，或**为了 Need 主动放弃 Want**（高光时刻）。

- 例：主角拼命想赢比赛（Want），最终明白比输赢更重要的是重拾对父亲的爱（Need），于是放弃夺冠去陪父亲最后一程。

## 二、伤口与心魔（The Wound）

性格缺陷不是凭空的，来自过去的"伤口"：

- **伤口**：过去发生的、造成心理创伤的事件（被抛弃、背叛、失败、丧亲）。
- **谎言（The Lie）**：伤口让主角相信了一个错误信念（"我不值得被爱""相信别人就会受伤""只有钱能带来安全感"）。
- **缺陷/心魔**：谎言外化成的行为模式（冷漠、控制欲、逃避、伪装）。
- **成长弧光**：故事的过程就是主角**识破谎言、治愈伤口、放下缺陷**的过程。

## 三、弧光类型（Arc）

1. **正向弧光（成长）**：从相信谎言 → 认清真相 → 成为更好的人（最常见，励志、成长片）
2. **负向弧光（堕落）**：从有真相 → 逐渐相信谎言 → 走向毁灭（悲剧、反英雄，如《教父》麦克）
3. **平弧光（坚守）**：主角自身不变，但用其坚定的真相去改变周围世界（超级英雄、《阿甘正传》）

## 四、人物关系网

- **对手/反派**：最好是主角的**镜像**——想要类似的东西，却走了相反的路，映照主角"如果不成长会变成什么样"。反派越强、动机越合理，主角越显英雄。
- **导师**：给主角工具或真相，常在低谷前退场。
- **盟友/搭档**：功能上互补，性格上制造摩擦。
- **爱情线/B故事人物**：常常是"说出主题"的人，帮主角触及 Need。

## 五、声口设计（Voice）— 详见 [dialogue.md](http://dialogue.md)

每个主要角色回答四个问题，确保语言指纹独一无二：

1. 他说话是**快是慢**？长句还是短句？
2. 他的**词汇来自哪**？（书本/街头/职业/网络）
3. 他有什么**口头禅或语癖**？
4. 他**最回避谈什么**？（一碰就转移话题的软肋）

## 七、短剧人设速成（爽剧专用）

短剧人物求"鲜明可爽"，不求复杂弧光：

- **主角**：低开高走，前期被压制（激起观众怒火），身份/实力藏得深（马甲），逆袭时越狠越爽。
- **恶人**：坏得纯粹、拉满仇恨值，专门用来"被打脸"。
- **误解者**：势利眼、狗眼看人低，负责"真香"反转。
- **真心人**：在主角落魄时留下的人，负责情感兑现。
- 关键：**人设即冲突**。身份差、认知差越大，反转越爽。
