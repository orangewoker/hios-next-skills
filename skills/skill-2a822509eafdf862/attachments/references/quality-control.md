# 质量检查

## 风格一致性

检查背景、转场、字幕和卡片是否共享：

- 同一主色与强调色逻辑；
- 同一圆角、描边和阴影语言；
- 同一字重层级与对齐逻辑；
- 同一留白密度和视觉重心；
- 同一插画或图标风格。

局部好看但明显不属于整套系统的素材判为失败。

## 内容准确性

逐项对照口播稿：

- 标题没有改变原意；
- 数字、日期、金额、比例完全一致；
- 人名、产品名和术语无错字；
- 引用没有被改成用户自己的观点；
- 图表和流程没有添加稿件不存在的关系。

## 文字处理

把以下情况判为不可交付：

- 乱码、错别字、伪汉字；
- 长段文字模糊；
- 同一词在不同素材中写法不一致；
- 字体过小或超出安全区。

优先在同一 LibTV 会话中定向重做。两次仍无法得到准确文字时，要求输出无字底板，并在 manifest 中保存准确文案、字体角色、位置和对齐方式，供剪辑阶段叠加。

## 视觉可用性

- 背景不能抢夺字幕可读性。
- 卡片必须留出真实文案所需空间。
- 人物安全区不能被主要元素遮挡。
- 透明素材边缘不能出现明显脏边。
- 动态素材不能在第一帧或最后一帧突然截断。
- 不交付带平台 UI、第三方水印或参考账号标识的结果。

## 修正顺序

1. 错误文字和错误数据；
2. 风格偏离；
3. 构图与安全区；
4. 元素冗余；
5. 细节装饰。

每次只描述需要修改的差异，保留已经正确的部分。
