# 贯通演练：修理店里的钥匙与空椅

**本例全部为原创假设、离线演算。没有生成图片/视频/声音，没有真人排练、平台提交、媒体观察或真实计费。** 下文的 ID 是逻辑示例；Take、帧数、观察和金额是明确给定的模拟条件，不是平台产物或回执。用于检查从场功能到返修是否连贯，不证明 LibTV 具备执行能力。

适用于从一场现成文戏设计覆盖、资产、任务及试剪的学习/自查。需要原场文本、前后人物状态、项目表达目标；真实生产另外需要能力、预算和持久性证据。全流程术语来自[核心记录](../core/03-records.md)。

## 1. 场功能与原场文本

父亲去世后，姐姐林岚和弟弟林舟第一次一起清点将关闭的修理店。林舟要赶末班车，想归还钥匙后离开；林岚想请他一起认完父亲留下的账，却不愿直接求人。本场让疏离出现一点共同承担，不在一场内完成和解。

> 内景，修理店，夜。  
> 林舟站在门内，包还背着。  
> 林舟：末班车快到了。  
> 林岚没抬头：钥匙留下。  
> 林舟把钥匙放在账桌靠门的一角，手缩回来。  
> 林岚把账本转向身旁的空椅：爸的字，你认得。  
> 林舟看一眼门，把包卸下，绕过桌角，拉开那把椅子。  
> 林舟：从哪儿开始？  
> 林岚把笔放到两人中间。

Scene S-repair v1 的进入状态是“一个要结束交接，一个不愿求助”；离开状态是“弟弟愿意参与眼前的清点”。后续不能直接写双方已和解或弟弟已放弃长期离开计划。末班车构成压力；没有事件证明他已错过车。

## 2. 行动和空间使选择可见

行动谱保留明确触发：赶车 → 姐姐说“钥匙留下” → 弟弟完成交还并收手 → 姐姐转账本、含蓄邀请 → 弟弟看门、卸包 → 绕桌拉椅、开口 → 姐姐把笔置中。允许停顿和细微反应，不要求落泪。

本例空间草案采用[局部A/B/C/D墙](../assets/05-scene-and-blocking-templates.md#scene-example)：桌中央，林岚在A侧偏D，空椅在A侧偏B；B墙靠C端为门。林舟到桌B/C角放钥匙，沿桌B侧绕到A侧空椅。局部方向不是实测北向，世界位置不随反打变，画面左右另由机位决定。

本例增加两项**导演草案**，不假装原文已规定：卸下的包放在桌B侧靠C且不挡通路的位置；拉椅后入座，使共同处理成为可见后果。具体手别暂未锁定，待预演检查钥匙、包与绕桌动作是否顺畅再登记。没有实际预演前，不报路径已验证。

## 3. 比较覆盖而非平均分配特写

方案 A：一个能见门、桌角和两把椅子的主镜头，完整保留站位变化。方案 B：主镜建立空间，邀请后切林舟的倾听与看门反应，再回主镜完成卸包、绕桌和共同处理。两方案共用 S-repair v1、E1—E6、同一资产/故事状态版本和“留下仍是听者选择”的观看问题；Shot集合、Timeline、总时长和剪辑可以不同。两方案都可以完整承担E1—E6；A把选择交给共同空间与持续动作，B把短暂的注意力贴近听者。B不只在主镜缺信息时才可用，代价是两段表演和动作出口需要试接；A也可能因人物过小或停顿过平而失去选择层。不能预判哪版更专业，实际组合前保留两版。

| 必要事件 | Shot 方案 | 为什么不能无声删掉 |
|---|---|---|
| E1 赶车与仍背着包 | Sh-master v1 | 离开是进入状态，不是台词装饰 |
| E2 钥匙落桌并收手 | Sh-master v1；仅必要时补交接覆盖 | 交还责任须有实际动作，不能只拍桌上已有钥匙 |
| E3 转账本并邀请 | Sh-master v1 | 留下的选择要有触发 |
| E4 听后看门，包仍在肩 | Sh-master 或 Sh-reaction v1 | 必须在选择前保留另一条可走的路 |
| E5 卸包、绕桌/拉椅入座 | 两镜按动作相位交接 | 从反应到行动后果；不能由站门口直接跳成已坐下 |
| E6 “从哪儿开始”、笔置中 | Sh-master v1 | 共同承担落在具体行为，不等同彻底和解 |

钥匙特写不强制存在，只要主镜可清楚承担 E2。两镜之间不能假定同一次表演，要检查肩包、钥匙归属、手的位置和反应起点。

两种合法纸面取舍：A保持完整空间和较长余韵，检查林舟的注意转移、握包与放包是否在宽景中可读；B在邀请句尾或其后一个明确动作相位切入倾听者，检查切点是否过早宣布答案、回主镜时包和钥匙状态是否连续。两版都不得提前卸包、跳过邀请或把暂时共同处理写成和解；没有实际画面和声音时只记录预期，不填优胜结论。

## 4. 资产与任务包

资产需求先于素材资格：A-Lan/A-Zhou 身份需求、A-shop 空间布局、A-props 的钥匙/账本/笔与包状态。角色母版不烘焙本场所有光照；A-shop 要能解释门—桌角—两椅的关系。没有图时这些只是 Asset 需求，不是可绑定素材。

## 4A. Seedance2.5完整请求草案

本例填写[唯一七段规范](../platform/04-seedance-25.md#seven-section-template)，不另建模板。目的为修理店完整主镜覆盖E1—E6；正文标签“主镜”对应Sh-master v1 / J-master v1。纸面 Director Pack `DP-S-repair-v1`（镜头级，状态 `accepted-for-generation`）承载观看问题“留下仍是听者选择”、E1—E6事件映射、门—桌—椅布局、覆盖/接缝、声音职责和本例验收判据；角色/资产级字段在本镜只写“沿用对应资产记录”，不重复整套母版字段。第4节资产合格只是演算给定条件，未给任何当前平台标记或槽位；本草案不能直接报已绑定/可提交，制作前由[映射流程](../assets/03-reference-binding.md#reference-map)接入确切来源。选择反应覆盖时另编它的时段与职责。

【Subject 主体】
林岚与林舟。林舟穿当夜工作服，入场仍背肩包；林岚坐在账桌一侧。人物身份、衣着与体态在本镜保持稳定。钥匙、账本、笔和包的持有状态随下述事件变化。

【Action 动作】
主镜：林舟站在门内说“末班车快到了”；林岚未抬头说“钥匙留下”。林舟到靠门桌角放下钥匙，收回手，钥匙接触声与落桌同步。林岚把账本转向身旁空椅，说“爸的字，你认得”。听完句尾，林舟看向门，握肩带的手停住，随后才取下包并放在靠门桌角旁且不挡通路的地面；沿账桌邻近入口的一侧绕过桌角，走到林岚身旁的空椅，拉椅坐下，问“从哪儿开始？”林岚把笔置于两人中间。结束时两人共同面对账本，钥匙留在原桌角，包在地面；不加入拥抱、道歉或和解台词，关系变化只由上述选择和共同处理的动作承担。店内底声保持，不凭空加末班车驶离声。

【Setting 场景】
夜间修理店。账桌居中，入口靠近放钥匙的桌角；林岚与空椅在桌的远离入口一侧，空椅位于林岚邻近入口的一边。林舟沿账桌邻近入口的一侧绕过桌角可到空椅，包留在靠门桌角旁的地面，不挡绕行通路；这些世界位置保持稳定。

【Camera 运镜】
主镜：连续双人宽景，视点能同时辨认门、放钥匙桌角、空椅和林舟绕桌通路；停顿读取点保持手、脸、门的关系可读，身体/包不被桌遮住关键变化，克制固定观察，不因每句对白切特写。

【Lighting 光影】
店内台灯为桌面主光，门口弱外光区分林舟轮廓；沿走位自然改变受光，不为情绪转折强加无来源光变。

【Style 风格】
生活化写实质感，保留旧修理店使用痕迹，表演与摄影节制。

【Constraints 约束】
保留赶车压力、交还钥匙、含蓄邀请、听后选择与共同参与。包在选择前仍在肩，听完句尾后手停住才取下，钥匙落桌后不跟人移动；不提前入座，不加入拥抱、道歉或未写入剧本的和解台词。关系目标的解释放在七段外的验收说明，不把心理结论当模型动作指令。

参数与验收：人物身份与服装正式制作时分别接入本时段合格源，仅消费已核用途，不继承母图姿态或光照；实际布局/调度应与正文地标关系对照。若本机位不能覆盖动作，返回覆盖设计，不删听后选择。原场未规定的画面文字/配乐不借用其他案例禁令。以上均是Agent制作与检查事项，不发送为七段正文。时长从表演/预演与当前入口核实，本草案没有真实秒数/分辨率/回执。新提交前核正文、真实附件与本时段状态；返回后分别观察E1—E6画面、邀请/问句/钥匙声及声画同步，若改用反应覆盖再试接相邻片段。

## 5A. 两版事实都成立但场景偏平：纸面诊断

下面仍是虚构演练，不是真实看片。假设方案 A 与方案 B 都完整覆盖 E1—E6，身份、钥匙、肩包、绕桌和入座顺序都正确；差别来自观看体验。连续观看记录为：A 的听后停顿过短，林舟看门后立即卸包，选择显得已经有答案；B 保留同一必要事实，但句尾后手停在肩带上、视线在门与账本之间停留，再取下包，倾听关系更清楚。这里不把“0.5秒”当成通用阈值，实际区间须由媒体观察取得。

| 字段 | 方案 A | 方案 B |
|---|---|---|
| 共同基准 | S-repair v1、E1—E6、同一资产/故事状态、同一观看问题 | 同左 |
| 可观察事实 | 事件顺序正确；停顿占位不足，卸包过早宣布决定 | 事件顺序正确；手停、视线转移和卸包先后可读 |
| 原因假设 | Action没有把邀请句尾到卸包之间的可见行为写出来，Camera也没有给停顿足够读取范围 | Action与Camera共同保留停顿承载动作，反应镜可能增加剪辑接缝风险 |
| 候选改法 | 保留空间主镜，重编停顿句式并复看；若宽景仍不可读，再比较反应覆盖 | 保留B作为候选，同时检查新增反应是否切断姐姐句尾或改变相邻动作相位 |
| 收益与代价 | 代价是一次受限重试或覆盖比较，收益是选择不再提前宣布 | 收益是倾听更清楚，代价是时长增加、声桥和回主镜接缝需实测 |

结论不预填优胜。先按同一观看问题观察 A/B 的实际区间、相邻接缝和声音；若没有可听来源，声音列记 `unobservable`，仍可保留视觉比较。若一次改写未改变可观察问题，回导演/覆盖设计，不机械连续重生。

## 6. 一个错误试剪与修正

错误 Timeline v1 只取主镜 `[0,144)` 加 `[384,720)`。两段局部视觉都合格，却把 E2 交钥匙、E3 邀请、E4 选择过程删了。观众只见“我要走”后变成“已经坐下”，不能按 S-repair v1 的因果通过。

修正为**纸上 Timeline v2**；源和 Timeline 均假设24 fps，所有区间均半开 `[start,end)`，普通速度、硬切、无重叠：

| C-R-choice v1 / T-reaction-2 v1 / A-R-2 / J-reaction v1 | [48,216) | [288,456) | 7秒 | E4、E5卸包 |
| C-M-end v1 / T-master v1 / A-M-1 / J-master v1 | [384,720) | [456,792) | 14秒 | E5绕桌入座、E6画面 |

总长792帧/33秒；它比原主镜长3秒，因为反应选段替换了原96帧时段而用了168帧。不能为了回到“30秒”无声删掉选择。变速、冻结或转场若另选，须增写源—Timeline 映射及余量，按[剪辑](../post/02-editing.md)执行，不直接改此表总长假装成立。
