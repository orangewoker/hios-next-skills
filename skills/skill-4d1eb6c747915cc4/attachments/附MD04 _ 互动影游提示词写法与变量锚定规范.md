## #做什么

本模块为互动影游专属的提示词写法与变量锚定规范库。

解决AI生成互动影游提示词时“画面崩坏、角色漂移、变量无锚定、无法直接对接引擎”的痛点。通过填空公式与变量锚定规则，确保所有分支节点提示词不崩、不漂移、能直接接引擎。本模块只锁定通用写法与变量锚定底线，具体角色与场景锚点ID由子级扩展。

## #需要什么输入

**最少提供：**

- 节点ID与分支标识
- 角色锚点ID与场景锚点ID（由子级提供）
- 变量名称与变量变化值
- 选择界面UI描述

**可选提供：**

- 特定导演风格标签
- 目标画幅与帧率

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。提示词生成环节重点参考【提示词】底座的物理光学参数与【大导演思维】的镜头逻辑，确保提示词与镜头语言完全对齐。

### 二、图片提示词·八要素填空公式

1. 【画面构图：机位/景别】
2. 【无角色 或 人物空间与互动关系：位置/距离/朝向】
3. 【极具体的微表情与面部特写：物理器官描述，禁止抽象词】
4. 【明确的场景环境元素与前景/背景道具：精确罗列实物】
5. 【光影几何与大气效果：光源方向/颜色/明暗气氛】
6. 【视觉风格/胶片质感：导演名或风格标签】
7. 【技术参数：相机/镜头/光圈】
8. 【负面提示词：禁止文字/Logo/水印/现代物品】

**案例：**

> 极近景平视机位 + 主角位于画面黄金分割点，跪姿，锁链缠绕 + 下颌紧绷、瞳孔收缩、额头冷汗 + 斩仙台玄铁地面、红色封印符文、万仙列阵 + 乌云压顶、金色神光从云缝透出、色温5200K + 经典写实武侠 + 东方神话美学 + 100mm微距、f/1.8 + 禁止文字、Logo、水印、现代元素。

### 三、视频提示词·七要素填空公式

1. 【时长与镜头运动：3-5秒/推/拉/摇/移】
2. 【角色一致性锁定：首帧参考/人物锚点ID】
3. 【动作因果链：脚步→重心→物理反馈】
4. 【光影与色调锁定：环境光/主光源/色温】
5. 【声音叙事：无BGM，纯物理音效】
6. 【防崩指令：禁止飞檐走壁/威亚/悬浮】
7. 【输出规格：16:9/24fps/720P以上】

**案例：**

> 5秒 + 低角度仰拍缓慢推进 + 孙悟空首帧参考i-6j9vke5nbu92 + 破云而降、金箍棒砸地、地面青石板碎裂飞溅 + 乌云压顶、金色神光从云缝透出、色温5200K + 无BGM，仅金箍棒破风声+金属共振 + 禁止飞檐走壁、威亚特效、人物悬浮 + 16:9/24fps/1080P。

### 四、互动影游专属追加三要素

1. 【节点ID与分支标识：N05A/N06B/N07C】
2. 【变量变化提示：因果值+40·天罚风险+25·路线锁定=A】
3. 【选择界面UI描述：卷轴按钮/变量显示/倒计时】

**案例：**

> 3秒 + 时间重启、天道金印从云端压下 + 孙悟空首帧参考i-6j9vke5nbu92 + 天道金印降落、古篆文字环绕流动 + 金光罩住主角、众神将后退 + 无BGM，仅天道判定音+金属共振 + 禁止画面出现文字、Logo + 节点ID：N05A·A线天道判定 + 变量变化：因果值+40·天罚风险+25·西方教敌意+20·路线锁定=A。

### 五、变量锚定规则

每个节点提示词末尾必须标注：

- 节点ID：N05A
- 变量变化：因果值+40·天罚风险+25·路线锁定=A

### 六、分支一致性锁定（核心铁律）

- 同角色在不同分支的提示词必须用同一人物锚点ID。
- 禁止分支A用锚点ID-001，分支B用锚点ID-002。
- 所有分支共用同一套角色锚点库。
- 所有分支共用同一套场景锚点库。

### 七、引擎对接规则

1. **节点ID**：对应JSON字段 [node.id](http://node.id)。
2. **节点标题**：对应JSON字段 node.title。
3. **场景描述**：对应JSON字段 node.sceneDesc。
4. **选择按钮**：对应JSON字段 choices 数组中的 text。
5. **变量变化**：对应JSON字段 choices 数组中的 effects。
6. **跳转目标**：对应JSON字段 choices 数组中的 targetNodeId。

### 八、负面提示词清单

禁止：

- 文字、Logo、水印、乱码
- 现代物品（手机、汽车、高楼）
- 飞檐走壁、威亚特效、人物悬浮
- 塑料感皮肤、过度美颜
- 手部穿模、肢体融合

### 九、子级扩展规则

子级可在此母级基础上追加专属提示词模板：

- 子级A（洪荒西游）：追加斩仙台、孙悟空、玉帝、如来专属提示词模板。
- 子级B（乙女影游）：追加男主苏点、心动瞬间专属提示词模板。
- 子级C（悬疑互动剧）：追加线索收集、真相反转专属提示词模板。
- 子级D（男频后宫）：追加修罗场、后宫结局专属提示词模板。

### 十、生成与合成

根据上述提示词写法与变量锚定规则，调用底层视频生成Skill，输出MP4视频文件。
