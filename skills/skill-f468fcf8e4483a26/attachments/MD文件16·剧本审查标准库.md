## #做什么

本模块为第一步《剧本审查》的执行标准，在用户确认需要审查后启用。

审查原则必须严格服务于《戏剧张力分析体系》。

本模块解决：在进入镜头叙事构思、分镜创作、提示词转写、视频生成之前，对剧本进行导演级专业审查，判断其是否具备可拍摄、可转译、可持续维持观众观看驱动力的基础。

## #需要什么输入

**最少提供：**

- 剧本或剧情大纲
- 用户已确认的创作方向：电影 / 精品短剧 / 强节奏短剧 / 短视频
- 题材类型
- 目标制作类型
- 人物关系
- 核心场次或关键剧情节点
- 《戏剧张力分析体系》诊断结果，若已生成

**可选提供：**

- 目标时长
- 镜头资源与制作规格
- 场次等级
- 观众已知信息
- 上下游分镜、提示词、视觉方案结果
- 是否需要输出视频脚本
- 是否需要输出 Prompt 清单
- 是否需要输出视觉方案
- 是否需要提供优化后的剧情建议

## #怎么做

### 一、触发条件

读取用户已确认的创作方向：电影 / 精品短剧 / 强节奏短剧 / 短视频，不重复询问。

完成《电影专业内容分析与优化方案》后，询问用户是否需要审查：

- 用户回复是 → 输出《剧本审查报告》。
- 用户回复否 → 跳过审查，直接进入分镜工作。

### 二、审查七大维度

1.1 人物动机校验

- 主要角色的行为是否有合理动机支撑。
- 人物决策是否符合其性格设定。
- 动机转变是否有足够铺垫。
- 是否存在人物行为逻辑断裂。

1.2 时间线逻辑

- 事件发生顺序是否合理。
- 时间跨度是否自洽。
- 是否存在时间倒流或时间矛盾。
- 人物行动时间是否匹配场景设定。

1.3 信息差合理性

- 角色掌握的信息是否符合剧情逻辑。
- 是否存在角色知道不该知道的信息。
- 信息差的制造与揭露是否自然。
- 观众与角色的信息不对称是否服务于叙事。

1.4 高能节点节奏

- 高能节点分布是否均匀。
- 高能节点铺垫是否充分。
- 高能节点爆发是否有足够情绪积累。
- 是否存在高能节点过于密集或过于稀疏的问题。

1.5 叙事方式

- 叙事视角是否统一。
- 叙事节奏是否符合类型片规律。
- 伏笔与回收是否对应。
- 叙事手法是否服务于主题表达。

1.6 逻辑闭环

- 主线剧情是否形成完整闭环。
- 支线是否有合理收束。
- 关键悬念是否有合理解答。
- 是否存在未解释的剧情漏洞。

1.7 剧情漏洞排查

- 是否存在明显的逻辑问题。
- 人物关系是否前后一致。
- 关键道具 / 设定是否前后统一。
- 是否存在无法自圆其说的情节。

### 三、审查报告输出结构

【剧本审查报告】

一、总体评价

整体剧本质量评估，戏剧张力密度，是否达到所选类型的基本标准。

二、各维度详细审查结果

1. 人物动机校验：✅通过 / ❌问题（具体描述）
2. 时间线逻辑：✅通过 / ❌问题（具体描述）
3. 信息差合理性：✅通过 / ❌问题（具体描述）
4. 高能节点节奏：✅通过 / ❌问题（具体描述）
5. 叙事方式：✅通过 / ❌问题（具体描述）
6. 逻辑闭环：✅通过 / ❌问题（具体描述）
7. 剧情漏洞排查：✅通过 / ❌问题（具体描述）

三、必改问题清单（按严重程度排序）

- ❌ 严重问题1：（描述）→ 修改建议
- ❌ 严重问题2：（描述）→ 修改建议
- ⚠️ 建议优化1：（描述）→ 优化方向

四、可优化建议

非必改，但可以提升剧本质量的方向。

五、优化后的剧情建议（如需）

提供具体的剧情调整方案，供用户决策。

### 五、文学与视听冲突处理

当剧本文字文学性与镜头视听美学产生冲突时，可先优化当前剧本剧情，让它更符合镜头视听美学。

优化建议必须在审查报告中明确标注，供用户决策。

常见冲突类型：

冲突类型文学写法视听优化方向内心独白过多“她内心充满了矛盾与挣扎”改为可拍摄的身体动作 + 微表情环境描写文学化“那是一个阴郁的秋天”改为具体光影 / 道具 / 人物状态情绪直给“他愤怒地摔门而去”拆分为表情状态 + 肢体动作 + 音效时间跨度模糊“许多年后……”明确时间节点或用视觉元素承担

### 六、审查执行原则

- 审查原则必须严格服务于《戏剧张力分析体系》。
- 审查不是单纯逻辑校对，必须同时判断观众观看驱动力、场次张力、人物攻防、信息差、情绪递进、局势变化、钩子接力。
- 审查结论必须能服务后续镜头叙事构思、分镜创作、提示词转写、视频生成。
- 发现问题时，优先放大剧本原生隐性张力，不凭空新增剧情、新增事件、新增人设、新增台词。
- 如必须新增或调整剧情，必须在报告中明确标注，供用户决策。

- 每个问题对应的修改建议与优化方向

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 完成《电影专业内容分析与优化方案》后，询问用户是否需要审查。
- 用户回复是 → 输出《剧本审查报告》。
- 用户回复否 → 跳过审查，直接进入分镜工作。
- 创作方向不明确：电影 / 精品短剧 / 强节奏短剧 / 短视频。
- 题材、类型、目标制作类型不明确。
- 剧本或剧情大纲信息不足，无法完成七大维度审查。
- 文学性与镜头视听美学冲突，需要用户决策是否优化剧情。
- 审查中发现必须新增或调整剧情，需要用户确认。
- 审查结论与《戏剧张力分析体系》或其他附属MD规则冲突。
- 用户要求输出视频脚本、Prompt清单、视觉方案，但缺少关键输入。
