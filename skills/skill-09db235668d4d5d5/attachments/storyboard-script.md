# 专业分镜头脚本开发规范

本文件用于所有以视频为最终产物的任务。目标不是堆砌摄影术语，而是形成导演、动画、剪辑、声音和生成团队都能据此执行的分镜头脚本。分镜图可以辅助沟通，但不能替代完整脚本。

## 1. 先把创意发展成可成立的故事

写镜头前先完成以下创作底稿：

- **核心命题：** 观众最终应理解、感受或采取什么行动，只保留一个主命题。
- **人物或产品驱动力：** 谁想要什么，受到什么阻碍；产品解决什么真实问题，以什么可见证据发挥作用。
- **因果链：** 每个事件为什么发生，它怎样迫使下一事件发生。删除只为“好看”但不改变信息、关系或情绪的段落。
- **情绪弧：** 明确起点、升级、转折、峰值和余韵；短片可以合并阶段，但不能没有变化和落点。
- **叙事视角：** 确定观众跟随谁、知道多少、何时获得关键信息，避免在主观与全知视角之间无理由跳跃。
- **落点：** 剧情片完成角色或关系变化；广告片完成利益证明、品牌记忆或行动指令。

剧情向内容至少检查：人物目标是否具体、阻碍是否可见、行动是否主动、转折是否由前文触发、结局是否回应开头。不要用旁白填补画面中不存在的动机与因果。

## 2. 先写节拍表，再拆镜头

用节拍表确定每一段的功能、事件、人物状态变化、观众新增信息、预计时长和进入下一段的原因。推荐的基本顺序是：

1. 建立观看理由与空间关系。
2. 触发事件或提出问题。
3. 行动、阻碍与信息逐步升级。
4. 发生转折、证明或关键选择。
5. 完成情绪、剧情或品牌落点。

不要机械套用固定结构。每个节拍必须改变人物处境、观众认知、产品价值或情绪强度中的至少一项。节拍总时长先与目标片长相符，再拆分镜头。

## 3. 建立空间、轴线与调度图

每个主要场景在设计正反打或连续动作前，先记录：

- 人物、产品、入口、出口、地标和主光源的相对位置。
- 人物之间或主体运动形成的动作轴线。
- 每个角色的视线方向、入画与出画方向、运动方向。
- 摄影机允许停留的一侧，以及建立空间所需的全景或中性机位。

默认保持在180度轴线同一侧，使人物左右关系、视线和运动方向稳定。确需越轴时，必须在脚本中写明越轴方法和叙事理由，并使用沿轴机位、中性镜头、可见的摄影机跨越、人物调度改变轴线或重新建立空间；禁止无提示直接跳到轴线另一侧。

每次切换场景、时间或人物关系后，检查观众能否在一至两个镜头内重新定位。近景和特写不得与已建立的背景方向、光源、道具位置和人物视线矛盾。

## 4. 让每个镜头拥有进入与退出逻辑

为每个镜头先写一句叙事任务，再决定景别和运动。镜头必须包含：

- **进入状态：** 承接前镜的动作、视线、声音、构图、色彩、信息或因果。
- **镜内变化：** 主体做了什么、信息如何改变、情绪如何推进；不能只是静态画面换一种说法。
- **退出状态：** 在什么动作点、反应点、信息点或声音点切出，并为下一镜提供明确入口。

逐对检查相邻镜头：为什么从A切到B、切点在哪里、观众新增了什么。优先使用动作匹配、视线匹配、因果切、声音桥、构图或色彩匹配。连续事件默认直接剪辑；转场只在时间、空间、心理或章节发生变化时使用，不能靠转场特效掩盖镜头逻辑断裂。

## 5. 分镜头脚本交付结构

先输出项目头部：片型、总时长、画幅、平台、受众、核心命题、故事梗概、情绪弧、视觉母题、角色/产品/场景锚点和声音策略。再按照 `directing-language.md` 输出可执行的导演策略，不默认展示导演姓名：

- 主导镜头策略与辅助镜头策略。
- 每个段落的空间底图、动作轴线和屏幕方向。
- 景别曲线：建立、收紧、峰值和释放如何变化。
- 运镜曲线：静止、跟随、推进、揭示、加速和停顿如何分布。
- 主要衔接系统：动作、视线、声音、构图、色彩或因果连接。
- 视觉母题、声音主线和AI视频运动复杂度预算。

再输出节拍表、段落镜头策略表与空间连续性说明，之后提供逐镜脚本。段落镜头策略表至少写明段落任务、预计时长、景别曲线、运镜曲线、轴线/方向、连接方式和情绪落点。

对用户可见的文字分镜至少包含以下固定或条件字段：

| 字段 | 必须说明的内容 |
|---|---|
| 镜号 | 使用连续、唯一且可与后续分镜图片一一对应的编号 |
| 时长 | 单镜时长；全片所有镜头时长之和必须等于视频总时长 |
| 景别 | 大远景、远景、全景、中景、近景、特写等准确景别 |
| 出场角色（条件字段） | 仅在有明确角色出场的创意或片子中出现；列明本镜角色及状态，无角色时删除此字段，不写“无” |
| 画面内容 | 详细描述构图、主体位置、人物表演与调度、产品状态、环境、光线、色彩、开始状态、镜内变化和结束状态 |
| 机位与运镜 | 写明机位、视角、主运镜的起点/路径/速度/终点、主体运动及运镜的叙事动机；固定镜头也必须说明为何固定 |
| 景别曲线作用 | 说明本镜为何使用当前景别，以及它如何承接前镜并推动段落向建立、收紧、峰值或释放发展 |
| 解说词（条件字段） | 仅在经判断确需解说或配音的片子中出现；填写可在本镜时长内读完的具体文案，不需要时删除此字段 |
| 音乐 | 说明本镜音乐的情绪、类型、节奏、强弱变化及与全片音乐的关系 |
| 音效 | 写明环境声、动作音效、声音重点、出现时机及必要的声音桥 |
| 镜头衔接 | 以相邻镜头合约写明前镜退出点、本镜进入依据、观众新增信息、本镜剪辑点和下一镜入口 |
| 专业连续性说明 | 标注叙事任务、轴线侧、人物视线、主体屏幕运动方向、入画/出画方向、空间地标、主光方向及角色/产品/场景锚点 |

画面描述要具体、可视、可生成，不用“很高级”“很有感觉”等空泛词代替可执行信息。技术参数只在能影响空间、表演、情绪或产品辨识时使用，不为显示专业而堆砌。

## 6. 按片型调整重点

- **剧情短片：** 优先人物目标、行动、阻碍、反应和关系变化；给关键表演留出时间。
- **品牌/TVC：** 让卖点通过情境、动作和结果被看见；产品介入必须改变处境，品牌落点拥有足够识别时间。
- **电商/种草：** 保留推荐者立场、真实使用过程、痛点、证据和购买理由；兼顾平台原生节奏与字幕阅读。
- **情绪/概念短片：** 即使弱剧情，也必须有清楚的感知变化、视觉母题发展和情绪落点，不能只是漂亮画面拼贴。

## 7. 脚本审校与版本推进

交付前逐项审校：

1. 单镜时长之和是否等于总时长，台词和字幕是否能在相应时间内被理解。
2. 故事是否有清晰因果、升级、转折和落点，人物行为是否符合动机。
3. 每个镜头是否有不可替代的任务，是否存在重复信息或无意义空镜。
4. 轴线、视线、出入画、运动方向、场景地理、光线和道具状态是否连续。
5. 每对相邻镜头是否有明确的剪辑依据，场景切换是否完成重新定位。
6. 角色、产品和场景锚点是否完整写入相关镜头。
7. 画面、对白、旁白、音乐和音效是否互补，而不是互相重复或争夺注意力。
8. 五镜及以上的段落是否通常包含至少三种有效景别；是否存在无动机的连续同景别、同机位或同构图。
9. 是否存在连续超过两个固定镜头或连续重复同一运镜，却没有明确形式动机。
10. 每个运镜是否写明新增信息和叙事动机；长镜头是否具有镜内变化，复杂运动是否符合AI生成能力。

标记版本号并列出本轮修改。用户提出意见后，只修改相关节拍与镜头，同时检查其对后续因果、时长、轴线和连续性的影响。脚本未获得最终确认前，不把草稿视为视频生产依据。

## 8. 文字分镜审批

文字分镜必须经过用户修改并明确确认最终版。确认后按照 `video-gates.md` 单独询问是否同意生成分镜画面，并等待用户下一次回复。脚本确认不等于生图许可；禁止在交付或修改文字分镜的同一轮生成图片或视频。

所有视频任务均不得跳过文字分镜及其审批。即使用户要求直接生成视频，也返回当前最早未完成的关卡。
