# 生产模式

只读取并执行与用户真实目标对应的模式。进入任何模式前，必须完成 `SKILL.md` 的《需求分析与确认》，并使用已经确认或经用户授权后推荐的最终交付物、画幅比例、投放平台与视频时长。涉及反复出现的角色、产品或场景时，还必须通过 `preproduction.md` 的前期开发关卡。所有视频模式严格按照 `video-gates.md` 推进：“基础创意讨论与确认 → 文字分镜制作、修改与最终确认 → 询问并取得分镜生图许可 → 按镜号生成和修改分镜图片 → 用户确认全部图片 → 询问并取得视频生成许可 → 生成视频”。不得设置豁免。

## 模式一：单张核心画面

适用于主视觉、海报、概念图、封面和单个故事瞬间。

1. 提炼画面唯一的叙事命题与情绪焦点。
2. 根据已确认的画幅比例与投放平台，确定主体动作、环境证据、景别、视角、视觉重心和负空间。
3. 建立三层空间、主要明度组、主导色温和一个受控的对比色温。
4. 使用 `reference.md` 的厚涂规则生成画面，并检查缩略图可读性与风格偏移。
5. 交付最终图片；用户要求说明时再补充简短视觉控制信息。

## 模式二：视觉资产套组

适用于角色设定、服装、道具、产品、场景和世界观开发。

1. 建立资产清单并区分核心锚点与可变项。
2. 角色按照 `preproduction.md` 建立外观圣经、服化道连续性、模卡与表演锚点；需要多角度时保持同一设计，不重新创作。
3. 产品按照 `preproduction.md` 核准结构、比例、颜色、材质、标志、包装与关键功能事实；真实产品不得用相似设计代替。
4. 场景锁定平面关系、主要入口、地标、关键物体、光源、时代材质和色彩基调。
5. 先完成核心资产，再生成表情、动作、视角、天气或时间变化。
6. 交付用户需要的角色图、道具图、产品图、场景图或视觉设定组合。

## 模式三：系列分镜

适用于故事板、连续关键帧、镜头脚本和提案分镜。

1. 按照 `directing-language.md` 和 `storyboard-script.md` 先建立故事梗概、人物或产品驱动力、因果链、情绪弧、节拍表与段落镜头策略，再按节拍分配必要镜头，不按固定数量机械切分。
2. 确认可复用的角色、产品与场景主锚点，建立场景地理、动作轴线、人物视线和出入画方向；锚点或空间关系未锁定时返回前期开发。
3. 为每个镜头确定编号、时间码、叙事功能、画面与表演、景别及其曲线作用、机位、首尾状态、主体与摄影机运动及动机、声音、前后镜头合约和连续性锚点。
4. 逐对检查相邻镜头的因果、动作、视线、方向、声音或构图连接；需要越轴时写明过轴方式和理由，禁止无提示越轴。
5. 控制景别变化、运镜曲线、信息递进和情绪节奏，删除重复信息、默认固定镜头、无动机运镜与无法承接下一镜的孤立画面。
6. 输出专业分镜头脚本；需要分镜图时，再按脚本生成对应画面并逐镜检查人物、空间、道具、光线和色彩。

## 模式四：动画短片

适用于绘本动画、叙事短片、情绪短片和故事预告。

1. 使用已确认的视频总时长、画幅比例与投放平台，与用户讨论叙事视角、人物目标、阻碍、转折、结构、风格、氛围、情绪曲线、节奏、声音方向，以及 `directing-language.md` 的主导/辅助镜头策略、景别曲线与运镜曲线；持续修改直到用户明确同意进入文字分镜阶段。
2. 有明确角色时完成并锁定角色模卡与表演锚点；同时锁定场景和关键道具，作为基础创意方案的一部分确认。
3. 按照 `storyboard-script.md` 完成专业文字分镜，逐镜写明景别曲线作用、运镜动机、轴线方向和相邻镜头合约；交付用户调整并复查因果、时长、景别、运镜、轴线和衔接，直到用户明确确认最终版。
4. 单独询问是否同意生成分镜画面并暂停；用户下一次明确同意后，才按镜号一一对应生成图片。
5. 交付全部分镜图并询问满意度；按反馈修改，直到用户明确确认所有图片无问题。
6. 单独询问是否同意进入视频生成并暂停；用户下一次明确同意后，才组织动态镜头。
7. 严格按已确认文字分镜与分镜图执行景别曲线、运镜曲线、镜头方向、衔接、声音和成片检查；不得把计划的运动降级为默认固定镜头，也不得擅自改变已经批准的叙事、角色、产品、场景、构图方向或风格。
8. 交付完整短片；需要时附最终采用的文字分镜与分镜图。

## 模式五：TVC广告

适用于产品广告、品牌片、信息流广告和商业短片。

1. 使用已确认的视频总时长、画幅比例与投放平台，再确认受众、传播目标、核心卖点、可信证据、品牌气质和行动指令；产品外观与事实尚未核准时返回 `preproduction.md`，不进入分镜。
2. 把卖点转化为可见的情境、动作或结果，不用旁白代替画面证明。
3. 使用“吸引注意 → 建立需求或冲突 → 产品介入与利益点证明 → 品牌记忆点”的结构，可根据创意调整顺序，但不能丢失产品作用。
4. 设计产品英雄镜头、品牌露出、包装或标志定格，并保持产品事实准确。
5. 用厚涂绘本语言服务品牌和产品，不让风格遮蔽卖点、名称和关键信息。
6. 把视频结构、说服逻辑、视觉风格、氛围情绪、节奏、声音方向、产品呈现、品牌落点，以及 `directing-language.md` 的主导/辅助镜头策略、景别曲线与运镜曲线整理为基础创意方案，持续修改直到用户明确同意进入文字分镜阶段。
7. 按照 `storyboard-script.md` 完成专业文字分镜，逐镜写明景别曲线作用、运镜动机、轴线方向和相邻镜头合约；交付用户调整并复查卖点因果、产品状态、总时长、景别、运镜、轴线和衔接，直到用户明确确认最终版。
8. 单独询问是否同意生成分镜画面并暂停；用户下一次明确同意后，才按镜号一一对应生成图片。
9. 交付全部分镜图并询问满意度；按反馈修改，直到用户明确确认所有图片无问题。
10. 单独询问是否同意进入视频生成并暂停；用户下一次明确同意后，才生成动态镜头。
11. 严格按已确认文字分镜与分镜图统一卖点顺序、产品呈现、品牌露出、景别曲线、运镜曲线、镜头衔接和成片节奏；不得把计划的运动降级为默认固定镜头，不得擅自改变已批准内容。
12. 交付完整广告成片；需要时附角色、场景、产品图、最终文字分镜和分镜图。

## 模式六：风格诊断与修正

适用于已有提示词、图片、分镜或视频的风格统一与问题修复。

1. 先判断问题属于叙事、构图、摄影、色彩、连续性、厚涂质感还是完成度偏差。
2. 只指出三个最影响结果的问题，并按影响程度排序。
3. 保留原有项目内容，修正镜头设计、画面控制或生成指令。
4. 图片成品可直接组织重做或修正；涉及现有视频重做、续作或重新生成时，把已有内容作为输入材料，仍从 `video-gates.md` 最早未完成的关卡开始，不得直接生成视频。
