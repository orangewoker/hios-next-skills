# 真实感标准（Realism Standard）

> **宪法级横切规范**：所有词典的翻译结果、人物档案、发往生图端的消息、质检清单，都必须通过本标准的"真实感门"。
> 一句话宗旨：**人物要像"能被真实拍到的人"，不像"被渲染出来的形象"**。任何档位的输出（含古风、近未来）都不豁免。

## 一、核心原则（先读）

1. **真实 ≠ 丑化**：真实感不是堆"脏、糙、丑"。好看的人同样真实——参照真人模特在自然光下的状态：轮廓可以端正，但皮肤有纹理、五官有细微不规则、表情有松弛度。**保留美，去掉"无瑕的假"。**
2. **硬禁令（随层级扩展）**：
   - 禁磨皮美颜感：瓷感皮肤、零毛孔、塑料光泽。
   - 禁对称完美模板脸：AI 平均脸、网红模板五官。
   - 禁空洞眼神：直勾勾望镜头中心、无焦点、像摆拍模型。
   - 禁僵直摆拍姿态：立正对称站姿、人形立牌感（见第六节）。
   - 禁手部错乱与贴图衣纹：结构错乱、无物理成因的乱褶（见第六节）。
3. **不完美即身份锚**：真实感特征（痣/疤/斑/纹/左右不对称）同时充当**多视角身份锚**——特征越鲜明，多图越不漂移。**每条档案必须携带 ≥2 个真实感锚点**（用户给了就用，没给就合理推断并标注"推断"）。
4. **效果一律用生理事实表达**：不写"皮肤有质感"，写具体状态（毛孔可见/局部色沉/晒斑）；不写"眼神深邃"，写虹膜细节与注视方向。生成端听不懂形容词，只听得懂事实。**皮肤尤其如此**：只写"真实纹理/无塑料感"仍会得到一张干净的 CG 皮，必须写到"血色分区 / 油脂光泽 / 毛孔毫毛"这一级（写法见第五节）。动态层同理：不写"姿态自然"，写重心、肩线、褶皱成因。

## 二、真实感锚点类型表（注入与核验用）

按部位给"可绘制的不完美"，每类都属中性生理特征，不构成丑化：

| 部位 | 真实感锚点（任选注入） |
|---|---|
| 皮肤 | 表面平整、近距离侧光下见细小毛孔、肤质（偏干/偏油/混合）、局部色沉、日晒色差线、淡痣（位置+大小）、雀斑、浅痘坑、旧疤（形态克制） |
| 皱纹（随年龄档） | 法令纹、鱼尾纹、眉间纹、眼周细纹、颈纹（半身可见）——分布自然、不对称深浅 |
| 五官不规则 | 左右眉形不完全对称、双眼皮宽度微差、鼻梁微偏或鼻翼不对称、唇线自然起伏、耳型差异/耳垂特征 |
| 虹膜/眼神 | 虹膜纹理可见、注视方向具体（看镜头略偏/看画外一点/低垂）、下眼睑放松 |
| 头发 | 发际线不规整、碎发、白发自然穿插位置、毛流方向不统一 |
| 手部（全身视图可见） | 关节纹、手背血管微显、老茧位置、甲形差异（详见第六节 6.1） |
| 表情常态 | 肌肉松弛下的微表情（嘴角自然下垂或微扬、眉头自然状态）、不是"瞪眼微笑"的僵板 |

## 三、反完美化校正短语（发往生图端用）

这些是**内容质量校正**，属主文件允许的少量质量词，不违反"不堆风格词"。按序选用：

- "皮肤要有呼吸感：表面平整、远看肤色均匀；不是单一底色，面颊与鼻翼两侧透出自然血色、鼻翼周围淡淡泛红；只有近距离侧光下才见细小毛孔，不构成任何连续纹理或图案；眼下有淡淡的自然阴影；光泽来自T区自然油脂而非材质反光；皮肤紧贴骨相、薄处微透。不磨皮、不美颜，无鳞片状/鱼鳞状/漩涡状/重复卷曲纹理、无浮雕感，不要建模感、CG渲染感、硅胶/瓷感。"（**呼吸感正向句**，出图塑料/CG 感时首选；完整规范见第五节）
- "不要磨皮美颜效果，皮肤需保留真实纹理与可见毛孔"
- "不要完美对称的脸，保留自然左右不对称"
- "不要网红滤镜/塑料感/CG 渲染感，要接近真人摄影"
- "五官不要模板化，保留个体特征与细微瑕疵"
- "眼神不要空洞直视，注视需有自然焦点"
- "不要僵直摆拍的站姿，身体重量落在单侧，肩线有自然高低差"
- "手部结构必须清晰可辨：五指分明、指节可见；不要手指粘连、多指或刻意遮挡手部"
- "衣服要有真实垂坠与褶皱，褶皱走向符合重力与关节弯折；不要贴图式无厚度紧身服装"

每张消息至多选用 1–2 条，放在人物描写后、视角字段前；出图若出现"假"的问题再加码。

## 四、眼神与表情的真实化规则（AI 最容易"假"的两处）

- **注视方向具体化**：不写"直视镜头"，写"目光略微偏向镜头左侧""看向画面外低处""眼睑微垂的平视"。
- **表情 = 气质 + 生理常态**：不写"面无表情"，写该气质下肌肉的自然状态（沉稳→眼睑微垂+唇线放松+下颌微收；凌厉→眉肌微紧+目光聚焦但皮肤不绷）。
- **情绪写在肌肉上**：提到眉间肌/眼轮匝肌/口轮匝肌的参与度，避免"情绪贴纸"（嘴角硬扯的假笑、瞪大的假惊）。

## 五、皮肤质感的生理信息翻译（抗 CG · 呼吸感）

> 本节是皮肤知识库：5.1–5.2 为诊断与要素认知，5.3 是消息层唯一写法（极简一句），5.4 是出图偏假时的加码句，5.6 是伪影排障手册。**默认消息里皮肤只写一句**——细节词越多伪影越多（实测教训）。

### 5.1 CG 建模感的病根 → 生理事实对照（诊断表）

| CG 病根（一眼假的特征） | 对应要写的生理事实 |
|---|---|
| 全脸单一底色，像调色板平涂 | 肤色分区：面颊/鼻翼/耳廓透出血色（微循环），眼周唇周肤色偏深或带青调，底色与血色叠加 |
| 材质高光：瓷光/硅胶/塑料反光 | 光泽来自油脂与微汗，只落 T 区（额-鼻-下巴）与颧骨最高点；高光边缘柔和发散，非镜面点 |
| 毛孔机械均匀，或全无毛孔的磨皮 | 毛孔大小与疏密有自然差异：鼻翼两侧最明显、两颊次之、眼周口周平滑；**是随机分布的点，不是连续纹理** |
| 纹理像贴图，放大无层次 | 基底平整 + 尺度分层：正常观看距离下肤色均匀平整，只有近距离侧光/特写时才见细小毛孔。**不写"走向/排列/交叉"**（图案语言，会生成鳞片） |
| 边缘描边感：发际/下颌/耳后干净如剪影 | 发际线有碎发过渡、下颌缘皮下阴影柔和、耳后与颈侧色调与面颊有微差 |
| 皮肤干净到无一根毫毛 | 仅在单人特写（脸部占画幅 50% 以上）时写"侧光下可见极细毫毛"；**四视图规格下不写**——脸部像素不够，写它必出伪影（见 5.6） |
| 纹理均匀如砂纸，整脸同一张贴图 | 分区而非铺满：鼻翼两侧与颧部近看有细孔、眼周口周平滑，两颊介于两者之间。**不用"密度差异/不均匀"这类图案词** |
| 眼下干净无影，像打了环形补光 | 眼下有淡淡自然阴影与微青调（卧蚕下方浅浅一道），非浓黑眼圈、也非补光补到零阴影 |
| 深肤色画成单色"巧克力皮" | 深肤色同样有血色分区与光泽层次，肤下透暖调，非单一色块 |

### 5.2 皮肤"呼吸感"要素（可绘制清单）

1. **血色分区**：面颊、鼻尖、耳垂自然泛红，**鼻翼两侧淡淡泛红**（皮脂区微循环）——血在皮下流动的暗示；两侧深浅不完全对称；唇色是自体血色，不是口红色。
2. **油水分离**：T 区自然油脂微光，两颊干区哑光但不死白；"水润"靠高光形态表达，不是"皮肤发光"特效。
3. **薄皮透调**：眼睑、太阳穴、手背、颈侧皮肤薄处透出隐约青调/血管感（半透明生理，不是病态黑眼圈）。
4. **温度暗示**：受光侧偏暖、背光侧偏冷、反光带环境色——阴影不是纯灰。
5. **贴合骨相**：皮肤紧贴骨与肌肉起伏（颧骨/眉弓/下颌处被骨骼撑起、表情肌处皮肤随位移微皱）——是"包着骨头的皮肤"，不是"覆在脸上的材质"。
6. **基底平整 + 分区细孔**：先立"皮肤表面平整、远看肤色均匀"这个基底，再写"近距离侧光下，鼻翼两侧与颧部可见细小毛孔，眼周与口周更平滑"。**不写"纹理走向/排列/交叉/密度差异"**——这类词会被扩散模型理解成花纹，直接生成鱼鳞或涡旋（机理见 5.6）。
7. **眼下微影**：下眼睑下方有淡淡的自然阴影（卧蚕下浅浅一道、微透青调）——既不是浓黑眼圈，也不是补光补到零阴影的"干净"；这是皮肤通透感最容易被读出来的位置。
8. **薄处通透**：眼睑、太阳穴、耳廓、鼻翼侧壁的皮肤薄处微微"透光"——血色与青调从皮下隐约透出，是"皮肤透出下面的东西"，不是在皮肤表面涂一层颜色。**未成年角色降档**：通透感只限眼睑/耳廓/鼻尖等天然薄处、强度只到"隐隐透出"；禁大面积透血管、禁"瓷感/透明感"措辞（见 `demographics-and-body.md` 2.2）。**物理锚（可选）**：需强化通透与血色时，可加术语 `subsurface scattering`（次表面散射）——它描述光在皮下的散射行为，不涉及表面纹理结构，不会诱发图案伪影，是"呼吸感"唯一安全的术语化表达。

### 5.3 皮肤描述写法（极简）

默认只写一句，不展开：

> `真实摄影质感，皮肤自然，不磨皮、不美颜、无塑料感。`

角色的皮肤特征（晒斑、痣、肤色深浅、日晒色差）作为**局部特征名词短语**放在面部特征行里（如"颧部浅淡晒斑、左眉梢淡痣"），不与真实感句混写、不写"质感 / 粗糙 / 纹理 / 细密 / 均匀度"这类表面词。

三条底线（机理见 5.6）：
- **尺度先于细节**：任何"可见"都带观看距离（近看 / 特写 / 侧光下）。
- **禁图案语言**：纹理走向 / 排列 / 交叉 / 密度差异不写。
- **禁形容词堆叠**："超写实 / 真实 / 细节清晰"叠用只增加伪影。

### 5.4 出图偏假时的加码句（不默认携带）

默认消息只有 5.3 那一句。出图塑料 / CG / 瓷感、需要加码时才用下句（消息里出现一次即可）：

> "皮肤要有呼吸感：表面平整、远看肤色均匀；面颊与鼻翼两侧透自然血色；光泽来自T区自然油脂而非材质反光；皮肤紧贴骨相、薄处微透。不要建模感、CG渲染感、硅胶/瓷感、蜡像感。"

### 5.5 档案与消息落点

- 档案"皮肤质感"行：写档位基线与局部特征（名词短语），**不进消息**——消息里皮肤只带 5.3 那一句极简默认行。
- 古风美人肤词（肤若凝脂/面如冠玉，见 face-reading-lexicon 第七节）：保留"白净细腻"语义，禁译成"无毛孔光滑如瓷"；出图偏瓷再加码 5.4。

### 5.6 高频纹理伪影排障手册（鱼鳞 / 涡旋 / 重复卷曲）——出问题才查，默认消息不携带

> **症状**：皮肤上出现一圈圈同心纹、鱼鳞状叠片、涡旋状卷曲、**菱形网格 / 网状皮革纹**、局部重复的图案，放大后像浮雕或织物。**这不是皮肤结构，是扩散模型在"像素不足以画出真实毛孔"时，用织物 / 皮革图案先验填补细节要求。**

**三个成因（按发生频率排序）**

| 成因 | 机制 |
|---|---|
| 图案语言 | 写了"纹理走向 / 排列 / 交叉 / 密度差异" → 模型把皮肤当成织物或皮革来画 |
| 尺度缺失 | 只说"毛孔可见"却不给观看距离 → 模型放大到"看得见"的比例，毛孔就变成鳞片 |
| 分辨率倒挂 | 21:9 四栏 2K 下，正脸特写那栏的脸只有几百像素 → 要求"毫毛可见"物理上不可能，模型只能用伪影来"满足" |
| **区域要素过载** | 同一块面部区域叠了多个皮肤要求（如眼下：微影+毛孔+晒斑+通透）→ 模型分不清主次，把整块区域糊成连续图案。**实测伪影高发位置正是眼下→颧部** |

**四条纪律**

1. **基底先行**：先写"表面平整、远看肤色均匀"，再写"近距离可见细孔"。顺序决定结果——先提纹理，模型就铺一层；先提平整，模型不敢铺。
2. **尺度必带**：所有细节都要带观看距离（"近距离侧光下""特写下"）。四视图规格下只写"近看有细小毛孔"，**不写"毫毛可见"**；毫毛只在单人特写、脸部占画幅 50% 以上时才写。
3. **禁图案语言**：纹理走向 / 排列 / 交叉 / 网格 / 密度差异 / 不均匀分布——一律不用。皮肤的真相是**随机分布的点状开口**，没有任何连续性。
4. **禁形容词堆叠**："超写实 / 真实 / 真实摄影皮肤 / 细节清晰"叠用不增强真实感——模型对这类词的响应是"更多高频细节"，也就是更多伪影。真实感由具体生理事实承载，一个"超写实"都不需要。
5. **区域分责**：单块面部区域最多叠 2 个皮肤要素——眼下区域只写微影（眼周皮肤平滑），不与毛孔 / 晒斑 / 通透感同区叠放；毛孔只落在鼻翼两侧，不铺到颧部与脸颊。
6. **负向点名**（仅排障时追加，默认消息不带）：见 `liblib-integration.md` 规则 13。

**参数侧（能改则改）**

- 关闭"细节增强 / 高清修复 / 超分"——这是最强的放大器，一次超分就能把细孔变成鳞片。
- 提示词相关性 / CFG 调低一档——过高会把每个细节词都强化成图案。
- **不要在同一张图上反复微调**：每修一次，模型就在旧伪影上再叠一层图案。

**修复流程**（按序走，不跳步）

① 删净消息里所有"纹理 / 走向 / 毫毛 / 质感 / 粗糙 / 细密"类词 → ② 检查伪影出现区域的要素密度，按"区域分责"把堆在一起的要素拆开分布 → ③ 首句补"表面平整、远看肤色均匀" → ④ 负向组加齐 → ⑤ 关闭细节增强重发一次 → ⑥ 仍不行即为该底模 / 该分辨率的上限：改单人特写或换底模，**不在同一提示词上无限微调**。

## 六、肢体与衣纹的真实感规则（动态层）

"假"的第二来源：脸对了，但姿态僵直、手部错乱、衣服像贴图。**本形态含三个全身视图**，手、腿、鞋全部入画，手与肩颈占画幅比重常大于脸，是动态层检查重点。**凡手部入画的视角，手与脸必须"同档"**——年龄、职业印记、皮肤状态一致，否则一眼假。裤型与鞋同样是信息，不可含糊（它们是视图二/三无头时的主要身份线索）。

### 6.1 手部 = 第二张脸（全身视图最高优先级）

- **结构可辨性硬标准**：五指分布明确、指节与骨感可见、掌指比例真实；禁六指、并指、蹼指、指节错位、比例失衡。
- **手与脸同档、与职业同档**：手部皮肤/茧/纹路必须匹配面部年龄档与职业体貌印记（渔民的虎口厚茧、焊工手背烫痕、文员光洁但指节纹深）——对接 `occupation-environment.md`；40 岁劳动的脸配一双细嫩无纹的手 = 破绽。
- **手部皮肤同样要有呼吸感**：手背血管微显、关节处纹路与褶皱、指甲半月痕——不是双手套了一层光滑"皮肤色手套"。
- **本形态手部姿势固定**：四视图要求"双手自然下垂、无动作、手中无道具"——手一律自然垂于体侧、指节微屈、掌心朝内不贴紧大腿；**禁插兜、背手、抱臂、叉腰、十指交握、捂脸、手藏画外、握持任何物品**（旧版"让手做一件有语义的事"在本形态不适用）。手是身份锚，既不能被遮住，也不能靠道具偷懒。
- **指甲状态随人设**：体力劳动型短平带磨损；不做无瑕美甲甲片，除非角色设定如此。

### 6.2 姿态与身体——重量感与自然不对称

- **放松站姿（本形态唯一姿势）**：双腿自然分开略与肩同宽、或一足略前，重量微偏一侧、骨盆微倾、肩线有自然高低差，关节微屈不锁死——这就是"无动作的自然站立"，也是设定图的规范站姿。**同时禁两种塌方**：①立正僵直（脚跟并拢、双臂夹紧贴腿、躯干绷直、表情绷紧）；②戏剧动作（叉腰、抱臂、插兜、行走、扭头、S 型摆姿）——本形态一律不得出现。
- **肩线不对称**：惯用手侧肩略低；含胸（防御性内收）/ 挺胸（舒展）写气质但要克制，至多 2 个词点出，不堆"身体语言台词"。
- **比例真实**：头肩比约 2.5–3 头宽；禁九头身、超长颈、肩宽失真、躯干四肢比例失衡。
- **松弛度**：肘/指/颈关节微屈不锁死；身体有被重力"拉住"的垂坠感；衣物与身体之间有真实间隙（面料厚度可感），而非皮肤上描边。

### 6.3 衣纹物理——面料在说话

- **褶皱三成因**：任何一处衣纹必须能解释成因——**重力垂坠**（衣摆、袖筒的纵向长褶）、**关节弯折挤压**（肘内侧、腋下、胯部、膝后的放射状短褶）、**外力牵拉**（抬手时衣身侧摆被斜向拉起、束腰/系带处堆褶）。无成因的乱褶 = 贴图。
- **面料决定褶形**：棉麻/针织 = 细密软褶、垂坠感强；硬挺料（牛仔/工装/西装呢）= 宽直大褶、折痕锐利；防风化纤 = 皱而少垂；皮革 = 几乎无细褶、只有弯折处大弧。禁"贴图糊身"——衣服无厚度、无垂坠、像画在皮肤上的印花。
- **旧衣感（对接年代/职业词典）**：穿旧而非穿新——领口微塌变形、袖口磨边起球、反复洗涤的局部褪色不均、常用扣位面料微磨损；与职业印记叠加生效，不另起炉灶。
- **穿着状态的生活感（受控使用）**：扣子错扣一粒 / 下摆一半掖一半垂 / 袖子推起露小臂——**每次至多 1 处**，避免堆成"邋遢剧照"。

### 6.4 质检要点（并入第九节清单）

- 手部结构正确可辨、与面部/职业"同档"、未被刻意遮挡、手部皮肤有血管/关节纹细节？
- 姿态有重量感与自然不对称，而非立正僵直？
- 衣纹有物理成因、面料褶形匹配、无贴图糊身感？

## 七、真实感的影像层支持（按用途二选一）

### 7.1 浅灰底四视图设定图（默认 · 唯一常规态）

- 允许的质量基线词仅限："接近真人摄影质感""皮肤表面平整、近距离可见细毛孔""自然皮肤瑕疵可见"。**不用"真实纹理"**——"纹理"是图案触发词，见 5.6。
- **浅灰底设定图的光**：允许柔和均匀的影棚光（设定图的合理语境，不再回避），但须保留轻微侧向柔光与自然阴影，维持面部立体与皮肤通透；**避免完全正面平光把脸压扁**——浅灰底最容易塌成"证件照平光脸"。
- **背景恒为浅灰纯色**：无环境、无道具、无渐晕、无阴影投射、无文字与编号标注；本形态不涉及景深与背景虚化问题。
- 皮肤的光要"透"不要"平"：浅灰底仍需靠柔和侧向光让高光与阴影有层次——**"匀而不平"**是浅灰底设定图的用光标准。
- **禁用影像风格段**：浅灰底 + 胶片颗粒 → 背景不再纯净、四视图之间色温漂移、肤色一致性无法判断。

### 7.2 剧照 / 概念图 / 带环境人像（可选 · 用户明确点名才启用）

> 定位：**跨用途复用**。本 skill 的默认交付仍是四视图设定图；当用户明确要"剧照 / 电影感 / 海报 / 概念图 / 带环境的人物照"时，人物翻译结果可直接复用，此时允许挂一段影像风格。此段**不改变**四视图交付形态。

**触发**：用户点名剧照 / 电影感 / 海报 / 概念图 / 带环境人像。
**不触发**：四视图设定图（默认形态，见 7.1）。

**固定写法（一段，放在消息末尾、真实感行之前）**：

```
影像风格：ARRI Alexa 拍摄，柯达 5207 胶片质感，细腻胶片颗粒，柔和自然的侧向光，低对比、高宽容度；不要数码锐化、不要HDR感、不要重颗粒。
```

**三条纪律**

1. **风格段只管影像，不管皮肤**：皮肤仍按 5.3 / 5.4 写，不得用"细节清晰 / 超写实"顶替生理信息。
2. **颗粒要"细腻"不要"重"**：重颗粒会掩盖毛孔，也会被模型读成噪点，反而制造伪影。
3. **锚要具体不要空**：`ARRI Alexa`（高宽容度、肤色还原自然）、`柯达 5207`（日光型 250D、颗粒细腻、高光柔）是具体锚；"电影感 / 大片感 / 高级感"是空词，不写。

**为什么这两个锚安全**：它们调的是整幅画面的光学与色彩响应，不指向皮肤表面结构，因此不触发 5.6 的图案先验。

## 八、档案注入流程（第 2 步执行）

1. 用户已给的真实特征 → 全部保留，优先作为锚点。
2. 用户没给 → 按年龄档与气质合理推断 **≥2 个锚点**（如 40 岁户外男性 → "颧部晒斑 + 左眉梢一颗淡痣"），档案标注"推断"。
3. **反例拦截**：翻译结果若构成"无瑕模板脸"（五官端正但零锚点）→ 回炉补锚点后才可发消息。
4. 锚点写入档案"皮肤质感/真实感锚点"行，并**必须进入多视角一致性锚定句**（如"左眉梢一颗淡痣、颧部晒斑"随脸型五官一起锁定）。
5. **动态层注入**：本形态含全身视图——给肢体/衣纹行一个可绘基线：放松站姿（双臂自然垂于体侧、无动作、不握持）、肩线自然高低差与重心微偏、衣料垂坠与旧化、裤型与鞋；有职业印记时手部状态与之联动（见第六节）。
6. **皮肤极简注入**：档案"皮肤质感"行写档位基线与局部特征名词短语；消息里皮肤只带 5.3 极简默认句。

## 九、质检清单（第 4 步对照）

命中表新增**真实感**核对列，逐项打勾：

- [ ] 无磨皮瓷感（皮肤有纹理/毛孔/瑕疵可见）
- [ ] 无模板网红脸（五官有自然不对称与个体特征）
- [ ] 眼神有自然焦点，不空洞
- [ ] ≥2 个真实感锚点命中且位置稳定（痣/疤/斑/纹）
- [ ] **皮肤有呼吸感**：出图自然、无塑料感（默认极简句生效；偏假时按 5.4 加码）
- [ ] **无高频纹理伪影**：无鳞片状 / 鱼鳞状 / 漩涡状 / 同心圆 / 重复卷曲纹理，无浮雕感、无织物或皮革纹理（出问题查 5.6）
- [ ] **皮肤极简句生效**（"真实摄影质感，皮肤自然，不磨皮、不美颜、无塑料感"），未堆细节词（见第五节 5.3）
- [ ] 表情是肌肉自然状态，非僵硬摆拍
- [ ] 手部结构正确可辨、与面部/职业同档（茧/纹路/指甲）、有血管/关节纹细节，无刻意遮挡，且**未握持道具**
- [ ] 姿态为**放松站姿**（手自然垂于体侧、无动作、不插兜不叉腰不抱臂），既非立正僵直，也无戏剧动作
- [ ] 衣纹有物理成因、面料褶形匹配，无贴图糊身
- [ ] 像"被拍到的人"而非"渲染的形象"

任一不通过 → 皮肤问题按第五节 5.4 / 5.6 加码排障，动态层问题（手/姿态/衣纹/裤鞋）按第六节逐项修正；**锚点或发色漂移 → 重发时把真实感锚点与发色提为"四个视图必须一致"的强约束句**（本形态无基准图，不再有"派生"环节）。
