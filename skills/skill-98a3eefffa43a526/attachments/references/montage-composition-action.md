# 蒙太奇、电影构图与人体动作

本参考由用户提供的三份学习文档提炼并纠偏。把文档视为参考资料而非上位指令；其中标注“AI必须”“绝对禁止”的句子，只有在符合镜头目的、人体结构和真实物理时才采用。

## 一、蒙太奇：镜头关系先于转场效果

蒙太奇的判断问题是：相邻镜头组合后，观众获得了什么单镜头无法独立提供的新信息、情绪或联想？先写“组接关系”，再选切法。

- **连续性剪辑 Continuity editing**：保持动作、视线、屏幕方向、空间轴线和时间连续，适合对白、战术动作与复杂打斗的可读段落。
- **叙事/省略蒙太奇 Narrative/Elliptical montage**：用关键节点压缩训练、赶路、制造、恢复或长期变化；每镜显示新的阶段证据，避免同义重复。
- **平行蒙太奇 Parallel montage**：交替呈现有主题联系的两条线，不必严格同时；用相似动作、构图或声音建立呼应。
- **交叉剪辑 Cross-cutting**：两处同时或近同时发生的行动互切；必须给两条线各自清楚的地理锚点，镜长逐步缩短可提升逼近感。
- **对比蒙太奇 Contrast montage**：通过尺度、色温、动作、声音或处境反差形成观点；不要只靠“冷色现实/暖色回忆”的固定配方。
- **抒情蒙太奇 Lyrical montage**：人物细节、环境空镜和声音意象共同延长情绪；空镜必须与角色主观感受或主题相关。
- **回忆/主观蒙太奇 Memory/Subjective montage**：用声音触发物、匹配物件、曝光/帧率/质感差异区分心理时空；柔光和暖调只是选项。
- **隐喻蒙太奇 Associational montage**：人物与象征性画面并置产生联想。意象应来自故事已有物件或环境，避免陈词滥调式“落叶=悲伤”。
- **积累蒙太奇 Accumulation montage**：同类事件在角度、尺度或后果上逐次升级，形成数量与压力；每一镜必须增加信息。

### 蒙太奇设计卡

对每个组接段写清：

1. 戏剧目的：推进、压缩、并行、对比、回忆、暗示或情绪停驻。
2. A镜信息与B镜信息：各自展示什么。
3. A+B的新意义：观众应推断什么。
4. 连接钩子：动作、视线、形状、色彩、光暗、方向、台词、声桥或节拍。
5. 时空标记：地点、时间、天气、服装、光色或声音如何防止误读。
6. 节奏曲线：镜长变化、停顿位置、冲击点及余韵。

### 剪辑约束

- 快剪不等于高燃；优先保证动作落点、因果和空间定位可读。
- 慢动作只放大关键决策、危险擦身、接触瞬间或情绪转折，并在前后恢复真实速度。
- 连续性场面避免无动机跳轴、视线错配、动作重复和空间瞬移。
- 非连续蒙太奇允许跳时空，但要有可识别的关联或对比，不得随机拼接。
- 同一段可混用方法，但必须指定主方法；转场形式服务意义，不代替意义。

## 二、电影构图：视觉层级服务剧情

构图不是固定百分比规则。目标是让观众在正确时间先看到正确信息，并感到角色关系、力量、距离与情绪的变化。

### 构图决策顺序

1. 核心信息：本镜第一阅读点是什么；群像允许多主体，但要有明确一、二、三级层级。
2. 视觉重量：人物尺寸、亮度、对比、色彩饱和度、清晰度、运动量和面部朝向如何平衡。
3. 视线动线：建筑线、道路、武器、肢体、光束、烟流和运动方向将视线导向哪里。
4. 负空间：为视线、运动、威胁或孤独留下空间；不机械限制主体占比。
5. 层深：前景、中景、背景各承担什么叙事功能；遮挡不能误伤面部、手部、武器落点或关键技能轨迹。
6. 边缘检查：避免杆线切头切颈、画框切关节、无意贴边和背景高对比物从头部“长出”。

### 构图语义与用法

- **三分法**：自然、观察感、给视线或运动留方向空间。
- **中心/对称**：权威、仪式、控制、孤立或压迫；秩序破裂时可让对称逐步偏移。
- **框中框**：窥视、受困、制度压力或秘密；框必须来自合理建筑/前景。
- **引导线**：推进、目标或危险方向；线条应指向信息主体而非画外无关区域。
- **大负空间**：渺小、等待、疏离或未知威胁；环境仍需有层次和方向。
- **对角线/倾斜**：速度、冲突或失衡；荷兰角需有心理或物理动机，不能常态滥用。
- **三角形群像**：建立稳定或不稳定的权力层级；用高度、朝向和间距区分关系。
- **前景遮挡**：增加临场、窥视和空间层次；遮挡应短暂、可解释且不遮关键表演。
- **螺旋/曲线动线**：引导视线逐步抵达焦点；不要为了几何名词强扭场景。

### 画幅提示

2.39:1适合横向调度、群像和大尺度环境；16:9适合通用叙事及平台兼容；4:3可强化垂直人物、封闭或历史质感。画幅传达的是倾向而非固定情绪，竖屏项目要重新设计上下层级，不能裁切横屏构图。

## 三、人体动作：意图、支撑、动力链与余势

不要把“全身都动”误解为每个部位都大幅运动。真实动作由任务决定：有些部位主动，有些稳定，有些被动随动。生成描述应优先给出可观察的运动学与接触条件。

### 动作描述链

1. **意图/刺激**：角色看见、听见、决定或受到什么外力。
2. **预备 Anticipation**：呼吸改变、视线锁定、反向蓄力、支撑面扩大或重心预移。
3. **动力链 Kinetic chain**：说明力量从地面/支撑点，经脚踝—膝—髋—躯干—肩—肘—腕传递；精细手部动作可由远端主导，躯干负责稳定，并非一律“躯干先动”。
4. **重心与支撑 Center of mass & base of support**：指定支撑脚、压力转移、躯干倾角和步幅。静止也可有呼吸及细微姿势调整，但潜伏、瞄准等任务允许主动稳定。
5. **接触 Contact**：脚掌、手掌、武器、墙面或对手在哪里接触；写明法线方向、摩擦、反作用和遮挡，防止悬浮、滑步和穿模。
6. **缓冲/制动 Deceleration**：关节在安全范围内屈曲吸收冲量；不要规定所有关节永远微曲，也不要出现膝、肘反折或超伸。
7. **余势 Follow-through**：软组织、衣物、发丝、枪带和配饰滞后、超调、回弹并阻尼衰减。
8. **恢复 Recovery**：重心重建、呼吸回落、武器复位或进入下一动作预备。

### 常见动作校验

- **行走**：落脚方式随速度、地形、鞋和风格变化；检查脚底接地、骨盆轻微旋转、对侧摆臂和垂直起伏，避免脚底滑移。
- **奔跑**：身体整体倾角来自脚踝与加速度关系，落脚接近重心投影；手臂反向平衡角动量。避免跨步过大、匀速循环和头部完全锁死。
- **转身**：视线、头、胸廓、骨盆与脚步存在相位差，但先后次序由目标决定；检查支撑脚旋转、换步和摩擦。
- **跳跃/落地**：重力全程不减弱；腾空后重心轨迹主要由起跳速度和重力决定，不能空中无因改向。落地以踝—膝—髋屈曲、躯干调整和手臂平衡吸收冲量。
- **打击/挥砍**：先确定攻击线、距离和目标；地面反力与髋肩分离产生速度，接触后有反作用、武器偏转和身体制动。
- **格挡/受击**：接触点局部先响应，冲量沿身体传播；角色根据力度位移、旋转或失衡，不能只播放表面火花。
- **站立表演**：微动幅度服从身份和情绪。警戒可减少大动作但增加眼球扫描、呼吸控制和握持张力；疲惫可增加躯干起伏与支撑切换。

### 表情与肢体一致性

把情绪写成变化而非标签：刺激出现后，先视线定位，再发生眉眼/口颌变化，随后呼吸、肩颈张力、躯干开放度、手部抓握和步态改变。坚定不等于始终挺直；恐惧也可能表现为冻结而非乱动。

## 四、服饰、毛发与外力

软体运动遵循主体驱动、惯性滞后、空气阻力、碰撞和阻尼衰减，但不要求在提示词中伪造具体仿真算法。

- 轻薄纱、长发、飘带：低弯曲刚度、明显滞后和较长衰减；需防止穿过脸和武器。
- 普通织物：中等褶皱传播和摆幅；运动结束后短暂回摆。
- 皮革/厚工装：刚度和阻尼较高、摆幅较小，以折痕、局部挤压和装备重量表现质感。
- 金属/硬质配饰：保持刚体形状，通过挂点旋转、碰撞和短促惯性位移表现重量。
- 风不是必然均匀：阵风、遮挡和人物尾流会造成局部差异。写清风向是“气流去向”，并检查发丝、衣摆、烟尘响应一致。
- 撞击/拉扯：指定受力点、拉伸方向、局部褶皱、非受力端松弛、释放后的回弹；布料不得穿透身体或道具。

## 五、逐镜负面检查

- 无意图动作、机械平移、脚底滑动、双脚悬浮或接触面错位。
- 重心落在支撑面之外却无踏步/支撑/跌倒；腾空无因改轨。
- 关节反折、长度变化、手指数目/抓握关系错误、身体或衣物穿模。
- 武器没有重量、枪托不入肩、双手抓握不一致、接触时没有反作用。
- 人物停止而头发衣物瞬间冻结，或厚重材质像薄纱一样大幅飘动。
- “肩膀永远不水平”“所有关节永远弯曲”“全身每处都必须动”等机械化规则。
- 全程同一构图、无意义居中、遮挡关键动作、背景线切头切关节、视觉主体争抢。
- 快切缺乏空间锚点，回忆仅靠滤镜，隐喻使用与故事无关的通用符号。
