# 分支C: 商务信息图风 — 平面大湿子管线

## 平台执行要点

- 风格块：`style-locks.md` → STYLE_LOCK_C
- 模型（自动匹配）：图像 Seedream 5.0（排版文字较好）/ 备 Midjourney V7；视频 可灵 Kling 3.0 / 备 Wan 2.6
- 参考图配方：风格样板 + 色卡（必绑），同系列图表参考（保证图表语言统一）
- 转场：克制，多为硬切拼接；需要过渡时生成 0.5-1s 数据流动转场片段
- **数据真实性铁规**：画面中所有数字/图表比例必须来自「数据素材关卡」确认的数据源，禁止编造

## C 专属 · 数据素材关卡（G8 分镜确认后自动触发）

```
[关卡C-数据: 数据素材提供]
  ├─ 📁 上传数据文件(Excel/CSV/文档) → 智能体解析提取，列出数据清单
  ├─ 📤 从已有素材自动提取 → 列出提取到的关键数据供确认
  ├─ ✍️ 手动输入关键数据点 → 逐条录入(指标名+数值+对比基准)
  └─ 🎲 智能体示例数据 → 明确标注"示例"，交付前必须替换确认

  输出: 确认后的数据源清单登记 manifest（字段: 指标/数值/基准/出处）
  铁规: 关键帧中的所有数字与图表比例必须来自该清单；
        G14 关键帧验收增加「数据与源核对」检查项，不符即弃图
```

## G14 — 逐镜关键帧（分批）

```
[关卡G14-C: 关键帧确认 | 第N/N批]
  ├─ 📊当前节奏/👤模式

  ├─ 📊数据与源核对: 数字与 manifest 数据源清单一致? 图表比例合理? → 不符即弃
  ├─ 调参:
  │    ├─ 信息层级: 标题/核心数据/辅助说明的视觉权重

  │    ├─ 强调色: 指定本镜高亮色
  │    └─ 留白: 跟随节奏/手动覆盖
  └─ ⏸暂停
```
