# 整体画面风格库（视觉定调）

> 用途：问询阶段向用户推荐整部剧的**整体画面风格**（色调、光线、质感、视觉基调），确定后贯穿全剧分镜的"光线色彩""场景美术"列，保证视觉统一。推荐时必须附分析：为什么推荐它 + 适配原理/爆火原理。

## 一、推荐规范

- 向用户展示全部风格选项（编号+一句话特征），结合题材/人物/情绪给出 2-3 个优先推荐，**每个附"推荐理由 + 适配原理 + 与剧本的结合点"**。
- 用户选定后，该风格成为全剧视觉总纲：分镜脚本每场的"光线色彩""场景美术"列必须与其一致；交付文档附"整体画面风格说明"一节。
- 允许"主风格 + 局部变化"（如全剧冷峻暗调，梦境/回忆段落切换暖调），变化处须在分镜中注明。

## 三、推荐逻辑（结合灵感时）

- 先看题材情绪：复仇/悬疑→冷峻暗调系（1/3/5）；甜宠治愈→明亮柔光系（2/7）；玄学奇幻→中式玄学风（6）。
- 再看文化碰撞点：跨文化题材（如道士留学韩国）优先推荐"**中式玄学风 + 韩剧电影质感/都市夜场风**"的组合——水墨朱砂 vs 首尔夜景的视觉对撞，正是这类剧的记忆点。
- 最后给用户 2-3 个组合方案，每个附原理分析，让用户拍板。

## 四、落地要求

- 风格确定后，全剧分镜"光线色彩"列按风格统一用光（主光/环境光/色温/色彩基调），"场景美术"列按风格统一布景道具色调。
- 风格变化点（梦境/回忆/反转段）必须在分镜"转场设计"与"光线色彩"列标注变化。
- 交付文档开头附"整体画面风格"一节：风格名、视觉特征、用光与色调总则、全剧统一要求。
