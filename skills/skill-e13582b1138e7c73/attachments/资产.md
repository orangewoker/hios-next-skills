# 即梦编译、资产与片段衔接

## 1. 能力核验

即梦是平台名称，不能只凭平台名称推定具体模型、版本、输入格式或长度。新项目准备实际提交参数时，根据用户可见界面、用户给出的设置或当前官方资料核验：

```text
平台／模型显示名称／输入模式／核验日期／证据来源：
单次时长选项／允许画幅与分辨率／输出帧率和编码已知情况：
文生视频／图生视频／首尾帧／多参考素材／续接功能：
参考图数量、格式、用途与绑定方式：
音频、对白或口型能力／负面词独立输入框：
可实际设置的参数／仅提示词表达的意图／未知项：
```

不知道的字段写未知。不能把第三方逆向 API 的参数当作即梦网页或 App 的设置；不杜撰 @角色、--ar、seed 等语法。缺少能力信息时照常完成专业设计和自然语言提示词，给可落地的后期替代；只有实际调用依赖的必要参数才需补充核验。

2026-09-08 查看 [即梦官网](https://jimeng.jianying.com/)：公开页面介绍中文创作、文／图生视频及首尾帧输入。该页面不能证明用户所选模型拥有所有能力，也未据此确认账户可用的单次长度、分辨率、参考数量、音频或收费。执行时以实际模型与界面为准。

模型信息未确定时，采用“导演规划时长＋待映射提交长度”，不要将示例中的 8 秒、12 秒或 15 秒变成平台限制。

## 2. 资产与版本

为跨镜稳定先建立所需资产，而不是每镜重新随机定义人物。

资产类型 必须记录 人物 AS-CHAR 唯一编号、年龄范围、体态、脸部识别点、发型、肤色、服装材质颜色、磨损、配件；参考文件及版本 场景 AS-LOC 平面图、尺寸假定、门窗、主光和实景灯、材料、固定陈设、关键观察方向；参考文件及版本 道具 AS-PROP 形状、颜色、材质、相对尺寸、左右手、放置方向、归属及随剧情变化的状态 视觉 AS-LOOK 有效画幅、光学家族、肤色、黑位、高光、颗粒与色彩归属 声音 AS-SOUND 角色声音方向、台词版本、环境声空间、音乐或静默策略

资产表中的 ID 是制作索引，不是可被即梦自动识别的调用语法。实际绑定参考素材时使用已确认的界面方式。没有上传参考图，就不能在提示词或说明中声称已使用它。

修改资产后标明受影响的 SH/CL；只重做依赖镜头。设计阶段可以输出资产需求和提示词，不必自动生成图片或消耗积分。

## 3. 三层编号

- SC01：连续场景或戏剧段落。
- SH0101：成片中的一个镜头；构图或运动发生变化但没有切镜时仍可属于同一 SH。
- CL0101-A：一次生成任务或一个可生成片段。

一个 SH 可由多个 CL 尝试构成，但只有实际衔接通过检查才可视为连续镜头。一个生成结果包含多个实际切镜时，按成片切镜拆分 SH 或标明其来源，不能把它误报为连续运镜。

## 4. 拆段决策

1. 比较镜头需要的动作时长与已确认的模型单次长度。
2. 在确认可用的续接或首尾帧模式下，为下一片段给明确终态参考和动作路径；仍需实际检查衔接。
3. 如果必须通过剪辑衔接，优先选择落杯、转头、起身、遮挡、反应、重要物件或声音桥等有意义的切点。
4. 无法维持连续镜头时改写覆盖，重新编号 SH，更新主时间线与风格预算。不要用无动机闪白或黑场掩盖空间错误。
5. 同一片段只围绕一个主要动作／关系变化组织信息；复杂群像分配主次，减少同时独立事件。
6. 生成头尾可保留余量，记录“生成长度／截取 in-out／成片占用”。余量长短按实际模型和剪辑需要确定。

长对白可采用稳定关系镜头、反应镜、道具信息镜和画外对白组织剪辑。只有任务允许、且不需要可见口型同步时，才以画外对白替代正面说话。未经用户允许不要把关键对白删成无声画面。

## 5. 每段交付四个独立部分

### A. 提交说明

片段编号、对应 SH、模型和模式、导演规划时长、实际生成设置及未知项；需要上传的参考文件、各自用途；成片取用区间；是否需后期对白、音效、字幕或裁切。

### B. 可直接复制的中文视频提示词

按顺序写成完整自然语言段落：

```text
画幅和单镜头意图；人物身份、外观与完整服装锚点；
地点、年代或世界设定、可见材料、门窗和人物的起始空间关系；
起始景别、构图、机位、画面左右及焦点；
按秒或先后顺序写人物动作、视线、台词或聆听、摄影机起停；
主光动机、方向、覆盖与软硬，人物暗面、背景与实景灯的关系；
人物、环境、道具的色彩归属，肤色、黑位、高光、材质与空气；
与能力相符的声音意图；
结束构图、人物位置、手部和道具状态；
与本段有关的少量关键限制。
```

不能只写“昆汀风格”“电影级”“同前镜”。风格名称可以作辅助，但可见构图、行为、光色和节奏必须完整表达。每段重述必要身份、服装、场景、光源和状态；不要为“完整”反复复制与本段无关的世界背景。

专业镜头卡中精确数值保留在设计层。提示词选择模型可理解的数值和可见效果：例如“先固定，再沿桌边向右平移，停止时门口被完整露出”。禁止同时给互斥运镜、多个最终画幅或不相容光源。

动作时序既可用秒，也可用清楚阶段；秒数是规划，不承诺逐帧准确。输入过长时优先保留身份、空间、动作、构图运动和主要光色，删除重复修辞与无视觉作用的设备名，不删掉关键连续性。

### C. 首帧／尾帧提示词

仅当用户需要或模型输入模式实际需要时输出。首尾各自独立说明人物、服装、场景、光线、构图和道具状态；单张静帧只描述一个时刻。尾帧变化应来自已写动作，不允许突然多出人物、伤口、物件或不同服装。

存在参考图时明确其功能为身份、构图、场景或结束状态；若各参考互相冲突，先统一资产，再编译视频。

### D. 必要负面约束与后期说明

只保留本段相关的问题，例如身份和衣服不变、无额外人物、不换手、不越轴、不穿模、不变灯光方向、不随机推拉、不曝光跳变、不自动加字幕。

已确认支持独立负面词框时放入该框；否则把关键限制写进自然语言正文。不要假装负面词能够保证零错误。

对白原文、说话者、语气与开始时间可以作为声音设计；音频功能未确认时，明确独立配音／拟音／后期同步路线。用户要求可见准确口型时，须核验对应能力或声明待同步，不能标为已解决。

## 6. 状态衔接表

边界 上段结束 下段开始 镜头关系 声音关系 核验结果 CL 或 SH 对 位置、朝向、视线、站坐、左右手、道具、服装、表情和动作阶段 对应全部必要状态 同轴切／有意重置／尝试连续衔接；景别、焦点、方向与光色 对白续接、环境底、动作音或声桥 设计一致／实际一致／待看素材／需重做

杯中液面、开关、伤痕、湿度、烟雾方向、桌椅移位等随动作变化的项目纳入状态，不允许默认复位。画外发生的变化必须有时间和剧情依据。

## 7. 失败与修复

问题 优先修复 人物或服装漂移 统一资产和参考，缩短歧义描述，减少同时主角，不先增加形容词 动作过多、时序错乱 拆成一个主要动作＋一个可读反应；保留剧情信息与总时间线 机位漂移、空间跳变 固定构图或单轴运动，重新明确门窗、人物、轴线和起止状态 道具穿模、手部或液体错误 简化接触动作，明确手与道具归属，必要时设计有因果的细节切镜 灯光闪烁或反打光源翻转 锁世界光源位置和背景明暗，删除互斥描述；保留有意的 L08 与实际故障区别 首尾无法连续接上 调整资产或终态；仍失败则改成有动机的切镜并更新 SH，不宣称无缝 说话时长或口型不符 重新试读和分配时间，使用已确认的音频工作流；必要时提供待用户审查的对白压缩 风格被复杂技术削弱 保留双人关系、试探和留白，减少运镜或效果；不改成无关风格

每次重试记录“观察到的问题／修改变量／期望变化／实际结果”。同一问题连续两次定向修改仍无改善时，采用可复核的简化方案或说明所需条件，不无限随机重试。付费额度和实际生成次数以用户授权为准。
