# 动物黏土化词库

## 特征转译

| 原始特征 | 黏土化改造 | prompt 句式 |
|---|---|---|
| 写实毛发 | 光滑黏土表面，无毛发纹理 | "身体表面光滑的黏土质感，无毛发纹理，亚光漫反射" |
| 写实体型 | 圆润饱满，比例可爱化 | "体型圆润饱满，四肢短粗，整体球状感" |
| 写实五官 | 大眼圆鼻，表情拟人化 | "大而圆的眼睛，纽扣状鼻子，拟人化呆萌表情" |
| 尾巴/耳朵 | 简化为黏土片或圆柱 | "尾巴简化为短粗黏土圆柱，耳朵为圆片状黏土" |

## 呆萌化改造

- 体态整体球形化，缩地短肢
- 眼睛放大至占头部 1/3 以上
- 尾巴和四肢缩短变粗
- 拟人化表情：歪头好奇/眯眼满足/张嘴傻笑

## 色彩方案

| 动物 | 推荐黏土色 | 句式 |
|---|---|---|
| 猫 | 橙黄/灰蓝/白 | "橙色饱和黏土色，带白色腹部色块" |
| 狗 | 棕黄/白/黑 | "棕色黏土色，带白色斑块" |
| 熊 | 暖棕/蜂蜜色 | "暖棕色饱和黏土色" |
| 兔 | 白/粉/灰 | "白色黏土，粉色耳朵内侧和鼻头" |
| 通用 | 原色高饱和 | "高饱和黏土色，色彩明亮活泼" |

## prompt 片段示例

```
黏土手工风格的小猫，整体球状圆润体型，四肢短粗，大而圆的眼睛占头部三分之一，纽扣状粉色鼻子，拟人化呆萌表情歪头好奇。身体表面光滑的黏土质感无毛发纹理，亚光漫反射光泽，橙色饱和黏土色带白色腹部色块。尾巴简化为短粗黏土圆柱，耳朵为圆片状。表面保留指纹压痕和手工捏制的不规则纹理。色彩高饱和。纯色柔光背景。呆萌可爱，让人想捏一把。
```

## 落 prompt 前自检

- [ ] 是否去除毛发纹理改为光滑黏土表面
- [ ] 体型是否球形化
- [ ] 五官是否拟人呆萌化
- [ ] 尾巴/耳朵是否简化
- [ ] 是否有指纹/压痕描述
