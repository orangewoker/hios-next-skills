# 附MD04 | 星际远征·变量与结局扩展

**所属主SKILL：** 星际远征 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“变量设定空洞、多结局逻辑不闭环”的痛点，确保选择真实改变星舰命运。

## #需要什么输入

- 核心变量清单、路线设计、资源消耗机制。

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 燃料储备：counter，0-100，默认50；&lt;20无法跃迁。
2. 氧气存量：counter，0-100，默认100；&lt;10全员窒息。
3. 舰队完整度：counter，0-100，默认100；&lt;30星舰解体。
4. 外星仇恨值：risk，0-100，默认0；≥80遭到全面追杀。
5. 船员信任：relationship，0-100，默认50；&lt;20发生兵变。

道具与旗标

1. 反物质核心：item，false；true可启动终极武器。
2. 外星语言译本：item，false；true可进行和平交流。

### 二、结局体系（共15个）

正结局（5个）

1. E01·新伊甸园：找到宜居星球，燃料与氧气耗尽前成功降落。
2. E02·和平使者：使用外星语言译本，与外星实体达成同盟。
3. E03·星海游侠：放弃殖民，成为深空探索的流浪舰队。
4. E04·绝地反击：使用反物质核心，摧毁外星母舰，拯救地球。

坏结局（10个）

1. D01·深空孤魂：燃料耗尽，永远漂浮在宇宙中。
2. D02·窒息深渊：氧气归零，全舰寂静。
3. D03·兵变流血：船员信任过低，舰长被夺权。
4. D04·星舰解体：完整度归零，飞船爆炸。
