# 动画视频生成与后期色调模块

本模块接收前两个模块的锁定结果：剧本、分镜／视觉单元、角色资产、场景资产和道具资产，输出可执行的视频生成提示词，并为剧集建立统一的后期色调方案。

工作链：

剧本事实 → 视觉单元 → 资产继承 → 视频动作与镜头 → 声音与台词 → 后期色调选择 → 色调连续性审计。

不要在本模块重新设计剧情、重新设计角色、重新设计场景或生成静态资产。发现上游信息缺失时，标记缺口并请求补充。

## 资料路由

读取视频提示词源文件中的镜头、动作、声音、连续性和成品边界规则：

- `references/video-generation-source-split/video-generation-main.md`
- `references/video-generation-source-split/00_库索引.md`

读取后期色调库：

- `references/post-color-library.md`

## 核心任务

1. 将每个剧本 Beat 转化为一个清晰的视频生成单元。
2. 把已批准的角色、场景和道具资产绑定到视频单元中。
3. 设计一个主动作、一个主运镜和一个主要情绪落点，避免一条提示词塞入过多事件。
4. 保护人物身份、场景空间、道具状态、动作方向、视线方向和时间连续性。
5. 绑定对白、画外音或声音事件，保证声音不被复杂运镜和音效覆盖。
6. 根据剧集主题和场景情绪调用后期色调库，输出明确的调色参数和适用范围。

## 视频生成工作流

### 阶段一：输入审计

确认以下内容是否存在：剧集／集数、视觉单元编号、时长、上一单元结尾状态、角色资产、场景资产、道具资产、动作目标、台词／OS／VO、声音事件和目标画幅。

缺失时不擅自补剧情；只补充视频化所需的低风险动作连接，并把补充项标记为“视频执行补全”。

### 阶段二：视觉单元拆分

每个生成单元只保留一条主线：

- 一个主视觉主体；
- 一个主要动作或情绪转折；
- 一个主运镜；
- 一个明确的结束状态；
- 一个可以被下一单元继承的连续性锚点。

如果动作、空间或台词过密，拆成多个单元，不用高速运镜或无意义快切强行压缩。

### 阶段三：视频提示词生成

每个视频单元按照以下字段输出：

```text
【视频单元XX｜剧情语义标签】
时长：
画幅：
继承状态：
角色资产：
场景资产：
道具资产：
主体动作：
镜头与运镜：
表演与情绪：
台词／OS／VO：
声音设计：
后期色调：
连续性约束：
负面限制：
```

### 阶段四：后期色调选择

先选择色调的叙事功能，再选择具体色调卡。默认顺序：剧集总基调 → 集数阶段 → 场景情绪 → 角色心理 → 关键转折。

每个剧集必须建立一个“主色调”；每集最多增加一个“辅助色调”；单个视觉单元只有在剧情发生明确情绪或时空变化时才允许切换色调。

色调选择必须说明：色调名称、适用剧情、主色、阴影色、亮部色、饱和度、对比度、肤色保护、光源保留、转入方式和转出方式。

### 阶段五：连续性审计

检查上一单元到下一单元：角色脸型、发型、服装、站位、朝向、道具持有人、道具状态、背景锚点、光源方向、天气时间、色调和声音是否连续。

如果只是同一场景内的镜头变化，不得无原因改变后期色调。色调变化必须有剧情、时间、空间、心理或光源依据。

## 后期色调库选择规则

色调库不是装饰词库。每张色调卡都必须绑定剧情功能和技术控制：

- 不能只写“高级、电影感、氛围感”；
- 不得覆盖角色资产的身份颜色和关键道具识别色；
- 不得让肤色严重偏绿、偏灰或失去层次；
- 不得让夜景变成无细节黑块；
- 不得让高光溢出、白色服装失去纹理；
- 不得在同一连续场景中频繁跳色；
- 需要跨集保持统一时，使用同一色调卡和同一组参数。

色调库详见 `references/post-color-library.md`。

## 输出方式

默认输出两层：

1. **剧集色调总表**：本剧主色调、辅助色调、使用集数、切换条件和禁用条件。
2. **视频单元提示词**：每个视频单元绑定具体资产、动作、镜头、声音和后期色调。

用户要求“直接投喂”时，只输出清洁后的提示词，不输出后台分析；用户要求“方案选择”时，先输出色调方案和视频单元队列，等待确认后再生成成品。

## 明确边界

- 不改写已锁定剧本。
- 不改变角色、场景、道具资产的身份和设计。
- 不把静态资产提示词重新混入视频提示词。
- 不把后期色调写成前期灯光替代品；灯光必须有场景内真实来源，色调是后期统一处理。
- 不自动添加新的对白、人物、道具、爆炸、伤口、死亡、亲密行为或剧情反转。
- 不生成与资产模块重复的角色／场景／道具设定板。
