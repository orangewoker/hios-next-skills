# 剧本格式规范

> **定位**：Phase 1 剧本的唯一格式基准。以本文件模板逐项填充。缺失任一项 = `verify_phase.py` REJECT。
> **`verify_phase.py` Phase 1 校验（F1-F7）是本文件可执行格式铁律，以脚本输出为准。
> ⚠️ **v3.6 决策锁定表**：本文件为格式基准。剧本结构（核心冲突/情绪高点/钩子类型）以 `creative.md` §0.2 分集决策锁定表的逐集锁定行为准——不可从训练数据自由构建剧情框架。

## 一、单集剧本模板

```markdown
# 第{N}集：{集标题}

> 本集关键词：{3 个关键词}
> 本集爽点：{爽点类型}
> 情绪曲线：{压抑→爆发/悬疑→揭秘等}
> 前情提要：{上一集结尾悬念（非第1集必填）}

---

## 场次1-1：{场次标题}（{日内/日外} {场景名}）

**【音频要素标签】**：BGM:{音乐风格}({情绪}) + 音效:{音效列表} + 角色声音:{角色音色}

**场景：** 内景/外景 · {地点} · 日/夜
**出场人物：** [角色A]、[角色B]
**资产：** [资产A]、[资产B]

△{事件。只写发生什么——角色做了什么、什么变了。不写"怎么拍的""什么颜色""什么材质"。}

**角色A**（{语气/神态指示}）："{台词}"

**角色B**（{语气/神态指示}）："{台词}"

△{事件。同上。}

---

## 结尾钩子

> 🎣 **本集钩子**：{悬念描述}
> 🎬 **最后一镜指令**：{急停黑屏/定格特写/慢动作定格等}
> 💬 **悬念金句**："{最后一句台词}"

## 【BGM音乐描述】

> **说明**：供手动剪辑阶段使用，分镜提示词中无需包含。

**BGM风格**：{如：史诗交响乐/电子科技/悬疑紧张/浪漫抒情}
**情绪基调**：{如：压迫感/史诗感/浪漫感/悬疑感}
**节奏建议**：{如：前缓后急/全程紧绷/张弛有度}
**重点段落**：
- **{时间点或场景名}**：{描述需要的音乐氛围}
```

## 二、格式铁律（F1-F7 · 阻断级）

| 规则 | 内容 | 阻断条件 |
|:---|:---|:---|
| **F1** | 使用 `△` 符号标记动作描写 | 发现 `【画面】` 或无符号 |
| **F2** | 场景头含内景/外景标注 | 缺少"日内/日外/夜内/夜外" |
| **F3** | 场次编号：`## 场次{N}-{M}` | 编号格式错误 |
| **F4** | 每场次含【音频要素标签】 | 缺少音频标签 |
| **F5** | 资产引用：`[资产名]` 格式 | 格式错误或未引用 |
| **F6** | 含动作描写+情绪表达 | 只台词无动作 / 只动作无情绪 |
| **F7** | 台词：`**角色名**（神态）："台词"` | 格式错误 |

## 三、符号系统

| 符号 | 用途 | 示例 |
|:---|:---|:---|
| `△` | 动作描写（只写发生什么） | `△顾沉舟取下一把黑伞。付钱。` |
| `()` | 语气/神态指示，3-5字 | `**角色**（厉声）："出去。"` |
| `OS` | 画外音（画面外同一空间） | `**角色**（OS）："别回头。"` |
| `【闪回】` | 时空切换 | `【闪回】` / `【闪回结束】` |
| `【字幕】` | 字幕标注 | `【字幕：三年后】` |

## 四、动作描写规则

- `△` 后跟动词短语（"取伞""付钱""推门"），不写"怎么走过去的"
- 禁止流水账："他走到X，然后Y，接着Z" → 只写节点
- 禁止在 `△` 后写摄影机位置、景别、剪辑方式——这些是分镜（Phase 2）的工作

**禁止**（分镜指令泄漏到剧本=阻断）：
- ❌ `镜头推进/切换/拉远/跟拍` / `画面切至/切换/定格`
- ❌ 色温数值（`6500K`/`#4a2c5e`）→ 用 `冷白光` / `暖黄调`
- ❌ 音符频率（`f#1-f#2`/`440Hz`）→ 用 `极低频长音`
- ❌ 精确数值（`0.7秒`/`0.5cm`/`30rpm`）→ 用 `瞬间`/`短暂`/`缓慢`
- ❌ 摄影机参数（`35mm焦段`/`T2.0光圈`/`120fps`）
- ❌ 角色代称（`他看着她`）→ 写全名 `顾沉舟看着沈听澜`
- ❌ 文学比喻词（`像/仿佛/犹如/犹如`）→ 客观描述

## 五、万能敷衍词禁入

禁止以下抽象套话，全部替换为具体身体动作：
- `微微一笑/淡淡一笑/笑而不语`
- `若有所思/意味深长/神情复杂`
- `不动声色/轻描淡写`
- `眼底闪过/嘴角勾起/瞳孔微缩`
- `眉头紧锁/紧皱眉头`

（具体替代词见 `分镜_31_表演表情.md`）

## 六、开场铁律

每一集第一个 △ 必须直接呈现钩子画面——一个具体事件，不是空间描述。
第一个 △ 在 30 字内出现：角色名 + 动作 + 关系/冲突暗示。

```
✓ 「△暴雨夜。顾沉舟站在货架前。门外——一个身影从雨幕中走近。」
✓ 「△沈听澜推门进来。顾沉舟转过身。两人对视，没有人先开口。」
✗ 「△深夜便利店。荧光灯冷白。雨水沿落地窗淌成水幕。」
```

## 七、剧本 vs 分镜边界

| 元素 | 剧本（Phase 1） | 分镜（Phase 2） |
|:---|:---:|:---:|
| 场景描写/角色动作/台词/情绪氛围/资产引用 | ✅ | ✅（继承） |
| 摄影机指令/镜位/色温色号/音符频率/时间码/焦段光圈 | ❌ | ✅ |
| 音频要素 | ✅ 文字简述 | ✅ 详细规格 |
