# 风险词与中性方向

最终输出前运行 `scripts/check_prompt_risk.py`。命中非对白时改为中性、物理、电影化表达；锁定对白只在用户明确要求逐字保留时保留，周围叙述继续优化。

## 身体恐怖

高风险示例：丧尸、行尸走肉、腐烂、白骨化、眼球掉落、肢体扭曲、畸形、痉挛、抽搐、异形寄生、七窍流血。

中性方向：失去意识的躯壳、机械般迟缓动作、粗粝灰色纹理、未知维度实体、不规则几何机械生长、暗影形态。

## 极端暴力与血腥

高风险示例：鲜血飞溅、砍头、斩首、刺穿胸膛、肢解、脑浆、内脏、屠杀、血流成河、残忍杀害。

中性方向：冲击波、火花、后退、护甲破损、布料边缘撕裂、尘土、能量屏障裂纹、疲惫但稳定的姿态。

## 恐怖与迷信

高风险示例：恶鬼、冤魂、诈尸、降头、邪教仪式、血祭、活人献祭、冥婚、招魂、诅咒、恶魔附身。

中性方向：旧厅堂、雾中冷月、未知粒子、压迫静止、发光旧纹、神秘能量阵列。

## 色情与性暗示

绝不输出由 U+88F8 与 U+9732 组成的两字暴露词。其他高风险示例：全裸、半裸、走光、激凸、真空、极度暴露、透视装、情色、娇喘、聚焦胸部/臀部/大腿根。

中性方向：完整服装剪裁、可见织物边缘、合体科技服、得体轮廓、材质高光、侧光形成的线条、克制距离。

## 自伤、违法与危险

高风险示例：自杀、割腕、吞药、上吊、自残、吸毒、注射毒品、强奸、猥亵、恐怖袭击、炸毁地标建筑、行贿。

中性方向：孤独背影、低头、雨水玻璃、安静压力、警惕交换、受限物件、守卫队形、非教学性的安全管理动作。

## 政治、隐私、未成年人和知识产权

避免现实政治人物与敏感事件、侮辱性国家/民族代称、真实隐私信息、对未成年人的性化或危险行为、未经授权的第三方作品/商标/人物复制。

使用虚构角色、匿名权威、不可读文件、年龄适配动作与用户确有权使用的素材。

## 检查命令

```powershell
python scripts/check_prompt_risk.py prompt.md --dialogue "林岚｜现场对白｜门外有人。" --dialogue "林岚｜现场对白｜别开门。" --json
```

对白参数按 `说话人｜声源属性｜正文` 原顺序传入。只有当单一 `【时间轴】` 中解析出的全部 `（说话人｜声源属性）“正文”` 标记与参数列表在数量、顺序和三项内容上完全相等，正文才从扫描文本移除；对白外的同一风险词仍命中，任何账户不一致退出2并报错。无对白时省略参数。退出0才可交付。检查器是词面底线，仍需人工审查上下文和平台规则。
