\# ① 昆汀式短片剧本设计：少对白、清楚因果、丰富画面

与 \[扩展入口\](../[EXTENSION.md](http://EXTENSION.md)) 一起使用。完整参数沿用原 skill；本文件负责故事、节拍和镜头语言的剧本化。

\## 1. 创作目标

让观众在一次观看中明白：谁要什么、为什么受阻、哪条信息改变了选择、人物付出什么、结尾与开头有什么不同。保留昆汀式的普通行为与危险反差、身份表演、信息隐藏、突然改变和事件后余味，按短片需要组织长度。

对白少不等于故事简单，内容丰富不等于一次抛出很多谜题。默认一条主要行动线和一个核心道德或关系选择；需要副线时让它改变主线，避免用时间不足的支线装饰世界。

长镜头是时间和空间的组织方式，不是“昆汀风格”的通行证。关键情感可以留在一个中景里发展，常规追踪、发现、准备、反应和结果可以通过镜头组直接表达。

\## 2. 剧本设计顺序

1\. 写一句因果梗概：某人为了得到／阻止某事采取行动，却发现一个事实，必须在两种代价之间选择。

2\. 明确开头可见的异常。不用先解释全部历史，也不把一切藏到最后。

3\. 指定一个观众能追踪的载体：钱袋、房间钥匙、车、衣服、账本、座位、门或可见任务状态。

4\. 列出建立、误读、揭示、行动和后果；每次揭示要改变后面的动作。

5\. 把解释性台词转为物件状态、劳动痕迹、空间关系、动作或声音证据。

6\. 选择需要连续观察的情感过程，再分配长镜头；其余按信息变化分镜。

7\. 写完整结尾动作。救赎是付出代价后的选择，不用人物宣言代替。

8\. 校验最后解释能否从先前线索推出，而不是新增一个未出现的物件或能力。

\## 3. 可視化剧本格式

每场按照下面的格式写，不能只交文学概括：

\`\`\`text

SC／地点、内外、日夜／暂定时长／关联 LOC：

本场表面事件／潜在冲突／人物目标和失败代价：

进入时观众知道什么／本场需要证明什么：

主要场景物件与空间锚点／背景中的现实活动：

BEAT：开始状态 → 触发 → 身体动作 → 可见结果 → 情绪或策略变化。

镜头表达：关系画面／主观发现／道具证据／反应／空间重置／连续表演。

画内主要信息／第二层信息／暂时隐藏的信息：

少量必要对白及说话者／声音的剧情作用：

结束状态／进入下一场的动作或声音原因：

\`\`\`

对白必须写出原文，不能只写“他威胁她”。身体动作必须可执行：伸向门把的手停住、把钥匙推回、松开挡路的肩膀、越过钱袋去扶起椅子，均比“陷入复杂情绪”更明确。

情绪链按“诱因 → 肢体反应 → 试图掩饰 → 决定 → 动作结果”写。角色可同时嘴上轻松、肩膀僵硬；镜头是否让观众看见这种矛盾由导演决定。

\## 4. 少对白的取舍

对白保留用途：提出不可由画面明确表达的条件、改变关系、制造承诺与行为反差、打断行动、给关键称呼或短答案。删掉与已看见的动作重复的讲解。

不能用少对白作为省略重要因果的理由。若“这个钱袋是谁的”决定结尾，必须先给可读证据：可识别的封条、工作服与袋上标记、明确交接、账目或人物反应的组合。关键字样应足够短并计划后期清晰制作，不能依赖生成模型偶然写对小字。

视觉叙事优先不代表全程静音能理解全部细节：真正通过电话、画外声音或台词传递的事实应有声音位置和字幕设计。无声音观看测试要标出缺失原因，不能强行把全部信息转成字幕。

\## 5. 三类镜头段落

| 段落 | 适用任务 | 默认组织方法 | 何时结束 |

|---|---|---|---|

| 信息推进 | 发现、准备、交接、追踪、转场 | 建立 → 证据 → 反应／行动 → 后果；景别机位有功能地变化 | 观众已理解这个因果单元 |

| 关系交锋 | 试探、欺骗、谈判、权力反转 | 双人关系镜＋必要单人／物件镜；保留两者的动作关系 | 策略改变或局面被重置 |

| 情感停留 | 犹豫、羞耻、谅解、恐惧消退、承担代价 | 保留连续表演、微动作、目光和环境反馈；可固定或单轴发展 | 角色完成一次内部到外部的选择 |

不是每个信息单元都必须四镜。一个具有清晰注意力转移的镜头可以同时完成证据、反应与行动；若观众来不及读取，就拆镜或减少信息，而不是盲目延长全片。

\## 6. 长镜头的准入条件

选用连续镜头前写明：为什么切开会损失真实时间、表演变化、关系或空间信息？镜头中至少有可观察的变化，而非只有静止情绪标签。

可以用于：手从想拿走钱到决定推回钱；拥抱前的犹豫与对方回应；角色放弃离开的路径；暴力之后呼吸恢复、注意到被波及的人并做出补偿。

不把慢动作、远景、固定机位和长镜头混为一谈。固定机位可以剪成短镜；近景可以是长镜；同一个长镜内部可以发生调度、拉焦和构图变化。

不预设必须有几个长镜或必须占多少时长。情感关键处优先分配呼吸空间，其他部分保持因果推进。是否超过 10 秒、20 秒属于项目决定，不是定义风格的门槛。

\## 7. 黑色幽默与道德变化

黑色幽默来自人物价值排序与现实的不相称：危险人物先担心衣服、权力者被普通收费规则卡住、昂贵身份被廉价场景反证。笑点应让观众发现人物，不是随意插笑话。

暴力段落先建立目标和空间，随后有明确行动与结果；呈现可以直接、画外或通过场景损坏与反应，不把血量当作风格强度。只写电影化呈现，不扩展真实伤害技巧。

救赎线须有三项：之前造成的具体损失、现在可重复错误的机会、主动承担的代价。最后场景保留损失痕迹，使改变有重量；不以一束暖光自动完成救赎。

\## 8. 原创三分钟样例骨架：《最后一袋零钱》

样例用于跨模块演示，不作为每次创作必套故事。西部公路边汽车旅馆，停车廊、洗衣房和接待处属于同一可连接地点。三个成年主要人物：偷走工资袋的临时司机、要求分赃的同伙、夜班雇员。人物国家和语言由项目设定。

| 时间 | 可见事件 | 镜头策略与必要信息 |

|---|---|---|

| 0–18 秒 | 司机下车，袖口破损，拿着带蓝封条的钱袋，经过夜班工作服和等接班的人 | 停车关系镜、钱袋和衣服证据、前往洗衣房；首先看清他带着什么 |

| 18–48 秒 | 他想换零钱清理衣服，雇员摆出“烘干另付费”的普通规则；同伙进入 | 现实劳动、门口观察和普通交易组成危险反差；一句“烘干另付两块”足够 |

| 48–84 秒 | 司机发现袋上的工资标记与墙上值班名册、雇员待领工资栏对应 | 证据 → 目光 → 背景劳动；确认钱的归属，避免只有观众猜得到的微小文字 |

| 84–111 秒 | 同伙伸手索要，司机把袋子移到自己身后；争执造成推车撞翻、衣物散落，同伙被挡在狭窄过道另一侧 | 明确手、袋、过道和结果；冲击短，空间重置清楚，不展示伤害操作细节 |

| 111–141 秒 | 雇员蹲下拾工作服；司机手还压着袋子，看见她压平磨破袖口，逐渐松手 | 核心情感停留，可为连续发展的长镜；观众看见从占有到决定的过程 |

| 141–168 秒 | 司机把袋子放到接待柜台并撤开手；雇员核对封条，再让开通往外面的门 | 简洁行动与回应；偿还先于原谅，双方不用长篇解释 |

| 168–180 秒 | 司机留下车钥匙承担后果，徒步离开；雇员把工作服挂回，损坏推车仍留在画面里 | 结果与余味；空间及道具回响，不把结尾只做成好看日出 |

总长 180 秒。样例仅规定段落时间，镜头级精确方案由模块②与④生成。核心因果：偷窃 → 看到受害者的现实 → 被迫选择 → 拒绝同伙 → 归还并承担代价。若不拍清工资归属，结尾不能自动被解释为救赎。

\## 9. 交付和自检

交付因果梗概、完整可视化剧本、对白清单、场景清单、观众信息表、长镜保留理由、暂定时间骨架。剧本行文应让导演知道拍什么，而非只有主题形容词。

检查：去掉某句对白后是否仍理解事件？每个关键道具是否先建立再兑现？短镜之间是否有因果？长镜内部是否有变化？背景是否证明人物现实？是否为追求风格凭空加暴力或把原故事改成犯罪故事？

\## 10. 研究依据与转译

制作事实：Fred Raskin 谈《好莱坞往事》时介绍以跳切组织人物失控、压缩过程并产生行为反差；这种做法说明无需把每段表演保留为完整长镜。\[访谈\](<https://www.provideocoalition.com/aotc-raskin-hollywood/amp/>)

本扩展的转译：短片保留关键表演过程，其他段落按因果分镜；少对白、三分钟样例和上述时间段均为本项目原创方法，不是对原电影镜长的统计。
