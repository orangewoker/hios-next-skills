# 镜头任务管理模板｜Minimum 4s版

> 强制区分最终剪辑时长（Edit Duration）与模型生成时长（Generation Duration）。
> 任何单条Generation Duration必须≥4秒。

| 镜头 | Edit Duration | Generation Duration | 内容 | 剧情功能 | 等级 | 人物参考 | 机械参考 | 场景 | 动作参考 | 运镜参考 | 白模 | VFX | Sound | QC重点 | 状态 |
|---|---:|---:|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 001 | 2.0s | 4–5s | | | A/A+/S/S+ | | | | | | | | | | |

## 生成单元拆分
当一个最终镜头包含多个复杂动作时，允许拆成多个生成单元：

| 原镜头 | 生成单元 | Generation Duration | Core Action | 最终Edit取用 |
|---|---|---:|---|---:|
| 004 | GEN004A | 4–5s | 切入+第一刀 | 0.8–1.2s |
| 004 | GEN004B | 4–5s | 第二刀+回斩 | 0.8–1.2s |
| 004 | GEN004C | 4–6s | 终结重劈 | 1.0–1.5s |
