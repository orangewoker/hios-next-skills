# 角色与走位

## 角色契约

为每个角色分配稳定标签：
- `Character A`
- `Character B`
- `@Image1 subject`
- 或用户提供的原创名称

| 字段 | 提示词用法 |
|---|---|
| 标签 | Character A 或 @Image1 subject |
| 身份锚点 | 年龄段、剪影、发型、服装、已授权参考 |
| 位置 | 前景/背景、左/右、坐/站 |
| 动作 | 一个指定的动词与终点 |
| 表情 | 可观察行为：眨眼、瞥视、微笑、握紧、停顿 |
| 约束 | 必须保持不变的内容 |

## 多角色走位

分别分配动作：

```text
角色 A 放下信封；角色 B 留在门口。
```

不要写：

```text
他们戏剧性地争吵。
```

如果发生接触，描述接触点和终点。群像场景确定核心主体，保持背景运动简单。

## 三级动作层级

给每个可见的人只分配一个层级的动作：

1. **持续微动作**（默认）：呼吸、眨眼、轻微肩部晃动、头发飘动、目光游移。
2. **一个聚焦反应**：单个人获得一个带明确时间窗的小反应。
3. **大动作——默认禁止**：在多人镜头中排除站立、行走、转身、姿势改变、拾取物体，除非它是该镜头的唯一节拍。

## 手部与面部稳定性

- 手和脸在复杂编舞下会退化。
- 让手可见但简单，避免快速手指动作。
- 对话期间避免触碰脸部。
- 为对口型或人像保存锁定镜头。
- 面部精度脆弱时，用道具表达情绪。

## 肖像规则

对于真人肖像，不要从上传资源推断同意。若授权不明确，重写为原创角色原型，同时保留场景功能。

## 序列状态

继承服装、发型、屏幕地理、视线、姿势、情绪状态、当前片段范围、连续性锁定、精确参考标签和预留后续节拍。规范身份参考控制身份；已接受素材控制瞬态开场状态。
