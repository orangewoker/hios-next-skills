# 三视图生成详细规则

三视图是整个视频制作的**视觉锚点**——后续所有场景图、视频画面都必须与三视图保持一致。三视图质量直接决定最终成片的商品还原度。

---

## 一、三视图的核心目标

| 目标 | 说明 |
|------|------|
| **外观锁定** | 确定商品的形状、颜色、材质、比例，后续所有画面以此为基准 |
| **风格统一** | 3张图必须保持同一风格、同一光照、同一色调，形成视觉一致性 |
| **信息完整** | 3张图合在一起应能完整描述商品的外观全貌 |
| **锚点功能** | 作为场景图生成时的参考图，确保商品在场景中不变形、不变色 |

---

## 二、实拍路线三视图生成规则

### 2.1 通用生成流程

```
第一步：生成商品形象图
1. 生成一张商品本身的形象图（非三视图），背景为纯白色（#FFFFFF），画面中只有商品本身，没有任何其他元素、道具、装饰
2. 展示给用户确认商品外观是否准确
3. 用户确认后进入三视图生成

第二步：生成三视图
4. 上传商品图（包括已确认的形象图）→ upload_file.py 获取 OSS URL
5. 根据品类查表获取 3 个视角（见品类风格三视图映射.md 第二节）
6. 逐张生成三视图，每张以已确认的形象图为参考锚点，prompt 必须声明引用已确认的形象图
7. 3张全部生成后，检查一致性 → 展示给用户确认
```

### 2.2 Prompt 构建规则

每张三视图的 prompt 必须包含以下要素：

| 要素 | 说明 | 示例 |
|------|------|------|
| 参考声明 | 明确声明以参考图为基础 | "基于参考图中的商品" |
| 视角描述 | 具体角度和拍摄方式 | "正面平视角度" / "正侧面平视角度" |
| 商品描述 | 品类+材质+颜色+核心特征 | "白色陶瓷杯，圆润杯身，金色把手" |
| 风格关键词 | 来自第二阶段选定的风格 | "简约极简风格" |
| 光照条件 | 统一光照，确保3张一致 | "柔和均匀光，无强烈阴影" |
| 背景 | 纯白色背景（铁律要求） | "纯白色背景（#FFFFFF）" |
| 画面比例 | 来自第二阶段选定比例 | "9:16竖版" |
| 一致性约束 | 强调与参考图的匹配要求 | "保持商品外观、颜色、材质与参考图完全一致" |

**Prompt 模板**：
```
基于参考图中的商品，生成[视角]角度的产品摄影图。
商品描述：[品类+材质+颜色+核心特征]。
风格：[选定风格名称]，[风格对应的视觉特征描述]。
光照：[统一光照条件]。
背景：纯白色（#FFFFFF）。
要求：保持商品外观、颜色、材质、比例与参考图完全一致，仅改变拍摄角度。
画面比例：[X:X]。
```

### 2.3 视角选择原则

- **视图1（正面）**：商品正面全貌，展示最具辨识度的主面
- **视图2（正侧面）**：商品正侧面，展示厚度、纵深和侧面结构
- **视图3（背面）**：商品背面，展示背面设计和细节

### 2.4 光照一致性规则

三视图的光照必须统一，否则后续场景图会因光照不一致导致商品"跳戏"：

| 风格类型 | 推荐光照 | 说明 |
|----------|----------|------|
| 简约极简 | 柔和均匀光，无明显阴影 | 突出产品本身 |
| 高端奢华 | 侧光+顶光，强明暗对比 | 营造质感和层次 |
| 自然清新 | 自然光/柔光，明亮通透 | 清新感 |
| 工业硬核 | 硬光+彩色灯光 | 粗犷质感 |
| 3D科技 | 自发光+环境光 | 科技感 |
| 生活方式 | 自然光/暖色室内光 | 温馨感 |
| 促销爆款 | 均匀强光，高饱和 | 突出产品和促销信息 |

### 2.5 背景一致性规则

| 风格类型 | 背景规则 |
|----------|----------|
| 产品特写向（简约/高端/3D科技） | 纯色/渐变背景，3张统一 |
| 场景向（生活方式/北欧/户外/厨房） | 模糊化场景或简洁场景，3张保持同一场景基调 |
| 文化向（国潮/日系/街头/复古） | 与风格匹配的装饰元素，3张保持同一视觉基调 |
| 营销向（促销/新品/种草） | 简洁背景突出产品，3张统一 |

## 三、动画路线三视图生成规则

### 3.1 通用生成流程

```
1. 上传商品图 → upload_file.py 获取 OSS URL
2. 根据动画子风格查表获取设定稿要求（见品类风格三视图映射.md 第二节动画表）
3. 逐张生成，每张以商品原图+风格关键词为参考
4. 3张全部生成后，检查造型一致性 → 展示给用户确认
```

### 3.2 各动画风格的 Prompt 策略

#### MG 动画
```
基于参考图中的商品，生成扁平化几何风格的正面设定图。
将商品简化为几何图形组合，保持品牌主色调（不超过3种主色），
背景为纯色或简单渐变，整体风格干净、现代、信息图感。
要求：保持商品可识别性，造型与参考图核心特征一致。
画面比例：[X:X]。
```

#### 3D 卡通
```
基于参考图中的商品，生成皮克斯/迪士尼3D卡通风格的正面角色设定。
商品[拟人化/卡通化]处理：圆润造型、大眼睛、鲜艳配色、Q弹质感。
保持商品核心特征（颜色、标志性元素）不变，增加可爱/趣味感。
要求：3张设定稿的五官位置、肢体比例、色彩方案必须完全一致。
画面比例：[X:X]。
```

#### 2D 手绘
```
基于参考图中的商品，生成[水彩/线描/彩铅]风格的手绘设定图。
笔触特征：[对应风格的具体笔触描述]，色调柔和低饱和。
保持手绘质感统一，3张图使用相同画笔质感和配色方案。
要求：商品造型可识别，笔触风格3张完全一致。
画面比例：[X:X]。
```

#### 定格动画风
```
基于参考图中的商品，生成定格动画/手工质感风格的正面设定图。
模拟实物定格拍摄效果：手工材质感（黏土/布料/纸板/羊毛毡），
微缩场景道具，温暖的灯光，略微可见的手工痕迹。
要求：保持"手工制作"的质感统一，3张图材质感一致。
画面比例：[X:X]。
```

#### 赛博科幻动画
```
基于参考图中的商品，生成赛博朋克/科幻线框风格的设定图。
视觉特征：霓虹光效边缘（蓝/紫/粉），线框建模结构，HUD标注元素，
深色背景+发光线条，全息投影质感。
要求：线框密度和霓虹色调3张一致，保持科技感统一。
画面比例：[X:X]。
```

#### 国漫动画
```
基于参考图中的商品，生成[水墨/工笔/青绿]国风动画设定图。
画风特征：[对应画风的具体描述]，东方意境，留白构图。
要求：画风必须统一（水墨/工笔/青绿三选一，不可混搭），
商品造型保留核心特征的同时融入国风审美。
画面比例：[X:X]。
```

### 3.3 动画路线一致性重点

| 检查项 | 说明 |
|--------|------|
| 造型一致 | 商品卡通化/风格化后的形状、比例3张完全相同 |
| 配色一致 | 主色、辅色、高光色3张统一 |
| 风格统一 | 笔触/渲染方式/质感3张一致 |
| 特征保留 | 商品的核心辨识特征（logo、形状、标志性元素）在风格化后仍可识别 |

## 四、多商品三视图规则

| 规则 | 说明 |
|------|------|
| 独立生成 | 每个商品单独生成各自的三视图，不混在同一张图里 |
| 风格统一 | 同一广告内所有商品的三视图使用相同风格和光照基调 |
| 主次区分 | 主角商品的三视图更精细，配角商品标准3视图即可 |
| 顺序对应 | 三视图展示顺序与后续分镜中的出场顺序一致 |

## 五、质量检查标准

三视图生成后，展示给用户前 Skill 内部先做一轮自检：

### 5.1 必检项（不通过则重新生成）

| 检查项 | 标准 |
|--------|------|
| 商品可识别 | 三视图中的商品能被明确识别为目标商品 |
| 3张齐全 | 3个视角全部生成成功 |
| 风格一致 | 3张图的风格、色调、光照基调统一 |
| 画面比例正确 | 与第二阶段选定的投放渠道比例一致 |
| 无明显变形 | 商品形状没有明显扭曲或比例失调 |
| 纯白背景 | 背景为纯白色（#FFFFFF），无杂色、无阴影干扰 |

### 5.2 建议检查项（不通过提醒用户注意）

| 检查项 | 标准 |
|--------|------|
| 细节清晰 | 商品细节（纹理/材质/标识）可辨识 |
| 背景干净 | 背景没有干扰商品的杂乱元素 |
| 角度差异足够 | 3张图的视角差异明显，能提供足够的信息量 |

### 5.3 常见失败与处理

| 问题 | 处理方式 |
|------|----------|
| 商品外观与原图差异大 | 在 prompt 中强化"保持与参考图完全一致"的约束，重新生成 |
| 3张风格不一致 | 统一光照和背景描述，使用相同风格关键词，重新生成 |
| 画面比例错误 | 检查 prompt 中的比例描述，重新生成 |
| 某个视角生成失败 | 单独重新生成该视角，替换失败的图 |
| 商品细节丢失 | 增加细节描述的具体程度，重新生成 |

## 六、用户确认环节

### 精细模式
- 展示3张三视图，逐一标注视角名称
- 用户可针对任意一张：
  - A. 确认通过
  - B. 要求重新生成（说明不满意的具体问题）
  - C. 上传替代图片
- 修改后重新走质量检查

### 快速模式
- 自动生成后跳过确认，直接进入下一阶段
- 如用户后续对场景图中的商品外观不满意，可回溯重新生成三视图

---

## 七、三视图与下游的衔接

三视图确认后：
- **场景图生成时**：每张场景图以对应角度的三视图作为参考锚点
- **视频生成时**：以场景图为起始帧，间接以三视图为外观基准
- **回溯修改时**：如果三视图被修改，所有依赖它的场景图和视频片段都需要标记为"需重新生成"
