# 分镜设计模板

## 分镜输出格式

每个镜头交付一段可直接用于视频节点的提示词，结构如下：

```text
[主体] + [动作] + [场景] + [镜头] + [灯光/风格] + [音频] + [约束]
```

## 镜头规划原则

1. 每个片段只保留一个清晰的镜头运动。
2. 每个镜头只服务一个叙事任务或情感转折。
3. 片段结尾的画面必须能成为下一镜头的首帧参考。
4. 多镜头场景先建立地理与屏幕方向，再切入动作与特写。

## 覆盖范式

```text
Shot 1 远景：建立 [空间 / 屏幕方向]。
Shot 2 中景：跟随 [动作]。
Shot 3 近景：揭示 [后果]。
连续性：相同服装、道具、光线方向、视线。
```

## 常用镜头清单

| 任务 | 推荐景别 | 推荐运动 | 注意 |
|---|---|---|---|
| 环境建立 | 大远景/远景 | 摇臂上升/无人机推进 | 人脸/logo 会漂移 |
| 角色出场 | 中远景 | 跟拍或推近 | 保持动作简单 |
| 对话 | 中景/中近景 | 锁定或轻微推近 | 一次只让一个人说话 |
| 情绪特写 | 近景/特写 | 锁定或缓慢推近 | 避免转头、复杂手势 |
| 产品展示 | 中景→微距 | 滑块/推近 | 保持 logo 不变 |
| 动作追逐 | 中远景 | 横向跟拍 | 避免环绕和复杂剪辑 |
|  reveals | 中景→特写 | 推近或揭示 | 一个主体、一个揭晓点 |

## 从剧本到分镜的工作流

1. 把剧本按场景切段。
2. 每个场景内按节拍标镜头。
3. 为每个镜头写一句"画面描述"（what happened）。
4. 把画面描述转写成镜头契约（景别/角度/运动/光/声音/约束）。
5. 检查镜头间连续性（服装、道具、光、屏幕方向）。
6. 输出为 LibTV 视频节点提示词。
