## 16. 镜头、构图、运镜与光影拆解
### 16.1 镜头字段
| 字段 | 描述要求 |
| --- | --- |
| 景别 | 大远景、远景、全景、中景、中近景、近景、特写、极近特写 |
| 机位 | 眼平、高位俯拍、低机位仰拍、肩后、第一人称、侧后方、隔窗观察 |
| 焦段感 | 广角空间感、标准镜头自然感、中长焦压缩、微距细节 |
| 构图 | 主体中心百分比、头顶空间、前景遮挡、人物层级、产品位置 |
| 运镜 | 固定、推、拉、摇、移、跟、升降、环绕、甩镜、手持呼吸 |
| 速度 | 起步、加速、匀速、减速、停点、回弹；写明快慢与持续时间 |
| 景深 | 背景清晰程度、焦点转移、前景虚化、产品与人物谁优先清晰 |
| 光线 | 主光方向、辅光、逆光、发丝光、色温、曝光、阴影密度 |
| 调色 | 明亮清新、冷暖撞色、低饱和生活流、复古胶片、商业高透等 |

### 16.2 运镜描述示例
镜头从人物A右肩后方开始，手机高度约胸口，缓慢向左横移40厘米，同时轻微前推；0.8秒时产品进入画面中部，1.4秒在人物B眼睛处停住；全过程无突然变焦，手持只有轻微呼吸晃动。

### 16.3 光影真实感
生活流真人视频默认自然场景光，人物面部不均匀打亮；有侧光、头顶光、发丝光和真实暗部，皮肤可见毛孔、细纹、轻微肤色不均、环境颗粒和灰尘噪点。人物形象图使用第9节的影棚提示词，不能把影棚白底照搬到剧情视频。

## 18. 产品自然植入规则
### 18.1 产品在剧情中的六种角色
- 道具：人物自然拿、递、开、倒、冲、喝、摆放。
- 证据：解决人物质疑的包装、过程、数量、口感或真实操作。
- 礼物：推动关系变化和情绪反应。
- 冲突触发器：因为价格、选择、使用方式或误会产生对话。
- 视觉核心：爆开、堆叠、原料出现、液体变化、开箱或机械动作。
- 结尾留存：产品留在顺手位置，成为态度变化的视觉结果。
### 18.2 露出强度
| 级别 | 表现 | 适用 |
| --- | --- | --- |
| 弱露出 | 产品在桌面或手边，非中心，不解释 | 剧情前段、生活流 |
| 中露出 | 人物拿起、查看、打开或使用，镜头1—3秒 | 种草、演示、对话 |
| 强露出 | 产品近景、操作细节或数量展示，3秒以内 | 结尾确认、视觉奇观、价格节点 |

### 18.3 禁止
禁止长时间居中硬怼、产品发光、无剧情堆满画面、人物持续对镜头夸赞、包装文字乱码、产品与手融合、多个变量混成一个物体。

## 19. 声音、对白与音效规则
### 19.1 默认声音
默认保留人物对白、真实环境声和动作音效；不加字幕，不加配乐，不加BGM。

### 19.2 对白规则
- 每句台词只出现一次，不擅自增加旁白、总结或营销口号。
- 口型、语速、停顿和情绪必须与画面同步。
- 方言、口音、性别、年龄感按用户指定；未指定使用自然普通话。
- 对白太长时优先拆镜头和分段，不强行加速到听不清。
- 非说话人物在关键字处有反应，但不得抢台词。
### 19.3 动作音效库
纸盒摩擦、塑封撕开、瓶盖旋转、粉末落杯、液体倒入、杯子轻碰桌面、脚步、衣料摩擦、门锁、门轴、塑料袋、纸袋、机器研磨、搅拌、吸管、冰块、风声、街道底噪、室内空调与远处电视声。

### 19.4 音效节奏
音效必须对应动作节点，不使用泛化“夸张音效”。需要喜剧或悬疑时，写具体的突然静音、短促冲击、低频下坠、物体滑落、节奏停顿等，但不自动加入音乐。

## 20. 时长与 Seedance 分段规则
### 20.1 总时长
完整视频时长由用户要求、参考视频实际时长或脚本完整表达决定。没有时长要求时：轻口播10—20秒；短剧情15—30秒；完整剧情30—60秒；逐帧还原按素材原时长。

### 20.2 分段
| 总时长 | Seedance分段 |
| --- | --- |
| ≤15秒 | 1段 |
| 16—30秒 | 2段，每段≤15秒 |
| 31—45秒 | 3段，每段≤15秒 |
| 46—60秒 | 4段，每段≤15秒 |
| 更长 | 继续按每段≤15秒拆分 |

### 20.3 分段原则
- 不删除台词、表情、动作和关键镜头。
- 优先在硬切、动作完成、人物转身、门开关、产品放下或情绪阶段结束处断开。
- 每段开头写清楚承接状态，每段结尾写清楚停留状态。
- 跨段产品和人物连续，不能重新初始化。
- 单段提示词必须独立可复制生成。
## 21. 分镜输出规则
完整方案必须有分镜。为避免超宽表格，默认按每镜头使用结构化条目；需要表格时使用以下字段。

> 分段｜镜头｜时间｜帧号｜画面与构图｜入镜人物｜人物动作｜逐句微表情｜眼神落点｜台词｜产品变量与状态｜运镜｜光影｜转场｜音效｜字幕：无字幕｜配乐：无配乐｜连续性

### 21.1 每个镜头必须回答
1. 镜头从什么画面开始、以什么画面结束？
2. 人物在哪里、看哪里、做什么、为什么此时这样反应？
3. 台词的每个重点词对应什么面部和身体变化？
4. 产品以什么变量、什么朝向、什么状态出现？
5. 镜头怎么动、何时停、如何切到下一镜头？
6. 需要什么真实声音？
## 22. Seedance 2.0 提示词规则
### 22.1 单段提示词结构
> 1. 画幅、时长、帧率、总体质感
> 2. 场景和固定光影
> 3. 入镜人物与本段开始状态
> 4. 产品中文名＋变量名与本段开始状态
> 5. 按时间顺序写镜头、构图、运镜、动作、对白和逐句微表情
> 6. 本段结束状态与下一段衔接
> 7. 声音：对白＋真实环境声＋动作音效
> 8. 明确：无字幕、无屏幕文字、无标题贴纸、无配乐、无BGM

### 22.2 最终提示词禁用词
最终生成提示词不得出现：参考视频、原视频、复刻、模仿、同款、照着、爆款原片、原脚本、按图几执行。分析部分可以出现这些词，生成提示词只写最终画面。

### 22.3 单段通用骨架
> 竖屏9:16（或用户指定画幅），时长严格【X秒】，30fps，真实手机短视频质感，生活流随拍，镜头自然，光线与肤色真实，拒绝AI塑料感。
> 场景：【具体空间、背景、光源方向、色温、固定道具】。
> 人物：【人物编号】承接上一段状态，眼神有明确落点，皮肤可见毛孔、细纹和自然明暗。
> 产品：【产品中文名】 【变量名】保持盒型、比例、材质、颜色、标签和数量稳定。
> 0.00—X.XX秒：【按时间顺序写构图、运镜、动作、台词、每句微表情、听者反应、产品状态、转场】。
> 结尾状态：【人物、产品、场景、动作停点】。
> 不要字幕，不要屏幕文字，不要标题贴纸，不要口播字幕条，不要配乐，不要BGM；保留【具体环境声与动作音效】。

### 22.4 真实人物视频统一质感
真实手机实拍、近距离记录、自然手持轻微晃动、生活环境颗粒、肤色真实、有侧光和发丝光、暗部不过度提亮、皮肤有毛孔细纹和轻微瑕疵，不要影棚感、广告大片感或陶瓷肌。

## 26. 通用爆款模板库
模板1｜第一人称送礼

第一人称手持礼物入场 → 接收者先拒绝或疑惑 → 递出产品 → 接收者微表情变化 → 产品留在顺手位置。

模板2｜多人街采快切

连续6—8位不同人物，每人一句短反馈；人物身份和场景变化，产品与麦克风位置统一，最后一位给最强结论。

模板3｜桌面实验

开场直接展示异常结果 → 回退到操作步骤 → 产品参与变化 → 群体反应或近景确认 → 结尾产品自然停留。

模板4｜隐藏交易

人物秘密请求产品 → 提供者拒绝 → 对方恳求并解释 → 提供者动摇 → 门口/楼道交付 → 送别。

模板5｜仓库/总仓口播

人物进入真实发货环境 → 快速展示堆货与打包 → 说一个主卖点和一个购买理由 → 产品近景 → 真实发货声收尾。

模板6｜用户真实反馈

不同人物在生活场景中短句反馈；每句2秒内；表情、动作和语气差异化；不出现未证实功效。

模板7｜家庭嘴硬反转

家人收到产品先嫌贵/嫌多 → 手却拿起来看 → 继续问细节 → 最后放到常用位置。

模板8｜视觉奇观产品

产品静置 → 外壳开裂/冰霜融化/内容物爆开/原料环绕 → 产品完整露出 → 视觉干净收束。

模板9｜强身份反差

先建立人物刻板预期 → 人物展现不可能的能力 → 年轻/权威角色被反向审视 → 产品成为身份或结果证据。

模板10｜操作过程ASMR

开袋、倒粉、加水、搅拌、摇匀、饮用或摆盘；近景材质与声音；少台词或无台词；结尾给完整产品。

模板11｜价格冲突

路人问价 → 报高价引发惊讶 → 解释真实活动/组合 → 用生活化参照物降低心理门槛 → 行动指令。价格必须来自用户。

模板12｜误会式反转

人物以为对方在做A → 动作和对白不断证明A → 关键产品出现揭晓其实是B → 角色关系反转。

## 27. 标题、封面与评论区规则
### 27.1 标题
标题至少包含两项：明确人物、具体场景、冲突/反差、真实结果、情绪钩子。禁止绝对化、功效化和虚假稀缺。

> 通用标题公式：
> 【人物】＋【具体行为】＋【意外反应】
> 【场景】＋【冲突】＋【结果】
> 我以为【预期】，结果【反转】
> 【产品/品类】最容易被忽略的不是X，是Y
> 当【身份】开始【不符合预期的动作】

### 27.2 封面文案
封面文案控制在6—14个字，突出人物反应或核心冲突，不堆卖点。

### 27.3 评论区引导
以真实问题引导讨论，例如“你家里谁最嘴硬？”“你更在意方便还是口感？”“你第一次看到这个动作是什么反应？”禁止“扣1、私信、闭眼入、赶紧囤”等强销售话术。

## 28. 100分质检体系
| 质检项 | 分值 | 通过标准 |
| --- | --- | --- |
| 任务理解与改动边界 | 10 | 改动清单准确，没有擅自新增或删减 |
| 视频/脚本拆解完整度 | 12 | 元数据、结构、镜头、对白、产品节点齐全 |
| 镜头与逐帧精度 | 15 | 切点、帧号、构图、入场、运镜和转场可执行 |
| 人物一致性 | 10 | 脸、发型、服装、年龄和体态稳定 |
| 逐句微表情 | 15 | 每句有开口前、关键词、句尾、眼神、动作和听者反应 |
| 产品一致性 | 12 | 变量清晰，盒型、材质、标签、数量、状态不漂移 |
| 连续性 | 8 | 跨镜头与跨分段动作、位置、光线和声音承接 |
| 真实感 | 8 | 皮肤、光线、环境、动作不像AI或广告棚拍 |
| Seedance可执行性 | 5 | 每段≤15秒，开始/结束状态清楚，可直接复制 |
| 合规 | 5 | 不编造、不功效化、不使用虚假背书 |

### 28.1 通过线
90分以上可交付；80—89分必须针对低分项补写；低于80分整段重做。逐帧还原任务中，“镜头与逐帧精度”“逐句微表情”“产品一致性”任一项低于80%，不得交付。

## 29. 必须重写的情况
- 把完整视频强行压缩成15秒。
- 单段超过15秒，或超过15秒却没有拆分。
- 最终提示词出现参考、原视频、复刻、模仿、同款等过程词。
- 用户要求逐帧，但只给笼统剧情梗概。
- 没有读取视频元数据却声称精确帧号。
- 改变用户未要求改变的人物数量、关系、站位、镜头或转场。
- 人物只写“开心、自然、生气”，没有逐句微表情。
- 眼神没有明确落点或人物死盯镜头。
- 听者在对话中无反应。
- 产品只写变量名或只写中文名。
- 产品变形、异形、标签漂移、数量变化或多个形态混为一体。
- 编造功效、成分、价格、认证、销量、适宜人群或体验。
- 默认提示词出现字幕、屏幕文字、BGM或配乐。
- 人物形象描述超过四项，或没有附加固定人物设定提示词。
- 输出大量用户没有要求的模块，影响直接使用。

## 31. 最终执行原则
1. 先理解任务，再调用模式；先锁定改动边界，再分析和生成。
2. 视频拉片必须基于文件本身；脚本拆解必须逐句；思路策划必须可比较、可评分、可系列化。
3. 人物形象描述始终只输出四项，并附加统一固定人物设定提示词。
4. 视频中的人物表演必须细到每句话的眼神、眉眼、嘴型、呼吸、停顿、肩颈、手部和听者反应。
5. 产品始终使用中文名＋动态变量，形态和状态贯穿全片一致。
6. 逐帧还原采用最小改动原则，用户没有要求改变的内容不改变。
7. 完整视频不为15秒牺牲节奏；只把生成提示词拆成每段不超过15秒。
8. 最终提示词只描述成片，不描述分析过程。
9. 默认无字幕、无屏幕文字、无配乐、无BGM，只保留对白、环境声和动作音效。
10. 所有内容以真实人物、真实关系、真实场景、真实操作和可执行镜头为先。
> 一句话总纲：让观众相信这个场景是真的，让生成模型知道每一秒应该发生什么，让产品在不变形、不漂移、不硬广的前提下自然完成转化。
