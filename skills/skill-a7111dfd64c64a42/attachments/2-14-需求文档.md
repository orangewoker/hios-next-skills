# 商品广告视频生成 Skill — 需求文档
> 创建时间：2026-08-10
> 最后更新：2026-08-10
> 状态：需求已确认，待搭建框架

---

## 铁律
1. **视频默认只出配音 + 音效**，字幕默认禁止，用户明确选择才添加
2. **BGM 默认禁止**，用户明确选择才添加
3. **所有操作在 Skill 内闭环完成**，不引导用户去 LibTV 画布手动操作
4. **全部内容为全新项目**，不复用任何已有内容
5. **画面比例全程一致**：第二阶段选定的投放渠道比例，贯穿三视图、场景图、视频生成全链路
6. **人物/物品先单独生成形象图再生成三视图**：生成人物或商品的三视图之前，必须先单独生成一张该人物/物品本身的形象图，背景为纯白色（#FFFFFF），画面中只有人物/物品本身，没有任何其他元素、道具、装饰。用户确认形象图后，再基于它生成三视图（正面、正侧面、背面）
7. **相邻镜头运动方向和人物动作必须逻辑连贯**：分镜脚本中每个镜头必须标注明确的运动方向（如→左到右/←右到左/↑前到后），相邻镜头的运动方向不得矛盾（如上一镜车辆向右行驶，下一镜不得突然向左）。人物动作的时序必须连贯，不得出现动作倒序或重复（如已下车不得再开车门）。此约束贯穿分镜脚本、场景图和视频生成全链路。


## 基础规则
- **错误恢复与重试**：单环节生成失败时自动重试1次；仍失败则告知用户，并提供三个选项 → A.再试一次 / B.跳过该环节（后续手动补） / C.用户手动上传替代素材
- **修改轮次上限**：每个修改环节（三视图确认、场景图修改、剧本修改、分镜修改等）建议上限为3轮；超过3轮时主动提醒用户："当前环节已修改X次，是否接受当前效果继续推进？或考虑调整上游参数（如风格、分镜）后重试？"
- **级联依赖链**：三视图 + 分镜 → 场景图 → 视频 构成核心依赖链。修改上游产物时，自动标记下游受影响的部分，提醒用户是否级联更新（如：三视图或分镜重做后，关联的场景图需要重新生成）
- **暂停与退出**：用户可在任意阶段说"暂停"或"放弃"，Skill 保存当前工程进度状态，下次进入时可恢复继续或另起新工程

## 完整流程（10 阶段）

### 第一阶段：商品图获取 + 质量检测
- **线路A**：用户上传商品图 → Skill 自动检测质量（清晰度/角度/背景）→ 不合适则提醒换图
- **线路B**：用户文字描述 → Skill 引导结构化采集商品信息（品类、颜色、材质、尺寸等） → AI 生成商品图
- 可选：商品图确认后可做去背景处理
- 多商品场景（仅套餐商品）：每个商品独立选择线路A/B，并确认主次关系和出场顺序
- → **用户确认商品图** ✓

### 第二阶段：基础定义
- 选定**品类**（食物饮品/服饰鞋包/电子产品/美妆护肤/家居日用/……可扩展）
- 选定**广告目标/CTA**（品牌曝光/促销转化/新品上市/活动引流/……）
- 选定**目标受众画像**（年龄段/性别/兴趣标签/消费场景）
- 选定**风格预设**（按品类动态展示，可多选、可扩展、支持参考案例）
- 可选**微调**（色调、氛围等）
- 参考案例支持：用户上传参考图/视频作为风格参考
- 选定**投放渠道/画面比例**（抖音9:16 / 小红书9:16 / 朋友圈1:1 / 电商横屏16:9 / 自定义）
- 选定**时长**（5秒/15秒/30秒/自定义）
- 选定**全局转场风格**（硬切/溶解/划像/缩放/无转场/混合），分镜在此基础上生成
- 选定**模式**：
  - 快速模式：用默认值推进，仅保留关键确认节点，适合对效果要求不高的快速出片
    - **保留确认**：商品图确认、基础定义选择、剧本摘要确认（展示标题+核心卖点摘要，用户确认方向后再继续）、成片预览（含合规检查）
    - **跳过确认**：三视图确认、分镜图确认、场景图逐张确认、品牌元素确认、参数逐项确认（使用默认值）
    - **不可跳过**：两轮合规检查（剧本+分镜轮、成片前轮）始终执行
  - 精细模式（默认）：每个环节逐步确认，确保质量可控
- → **生成前时间预估** → 确认 ✓（不主动展示成本，用户主动询问时再告知）

### 第三阶段：三视图生成
- **第一步：先生成商品形象图** → 生成一张商品本身的形象图，背景为纯白色（#FFFFFF），画面中只有商品本身，没有其他元素，展示给用户确认
- **第二步：生成三视图** → 用户确认形象图后，基于形象图生成三视图（正面、正侧面、背面）
  - 硬质产品（电子产品、鞋包）→ 正面/侧面/45°
  - 饮品/液体 → 正面标签/俯拍/倾倒动态
  - 服饰 → 正面/背面/细节特写
  - 食品 → 摆盘全貌/特写/场景搭配
- **三视图生成方式**：基于已确认的形象图生成三个不同角度的视图，具体生成技术路径和一致性保障策略待细化（属于框架阶段后续补充细节）
- 多商品套餐：每个商品独立生成各自的形象图和三视图
- → **用户确认三视图** ✓

### 第四阶段：品牌元素与片头片尾确认
- 是否需要 Logo/Slogan（是/否）
- 是 → 用户上传 / Skill 生成
- Skill 生成 Logo/Slogan 后 → **用户确认**（不满意可重新生成或手动上传替代） ✓
- 片头片尾内容确认：
  - 片头：是否需要品牌开场动画/品牌名展示
  - 片尾：是否需要行动引导画面（如"立即购买"按钮画面、二维码、联系方式等）
  - 具体时长分配在分镜阶段按"片头片尾合计不超过总时长1/3"规则执行
- → 确认 ✓

### 第五阶段：剧本
- **线路A（用户上传剧本）**：用户直接上传已有剧本，Skill 解析内容后进入确认
- **线路B（AI生成剧本）**：
  - 前置：Skill 自动提炼 2-3 个核心卖点 → 用户快速确认
  - Skill 根据商品 + 品类 + 风格 + 时长 + 卖点 + 广告目标 + 目标受众自动生成剧本
- 多语言支持：可指定配音语言（中文/英文/……），字幕语言联动
- → **用户确认剧本** ✓

### 第六阶段：分镜脚本
- 剧本 + 三视图 + 风格 + 落版 → Skill 内部生成**行业10列标准分镜脚本**
  - 镜号 / 时间码 / 景别 / 运镜 / 画面描述 / 产品露出 / 台词旁白 / 音效 / 时长 / 备注
- **运动方向轨迹图**：分镜脚本完成后自动生成一张全片运动方向轨迹示意图，用虚线+箭头标注每个镜头中人物/车辆/商品的运动方向和路径，相邻镜头方向矛盾处标红⚠️，供用户直观检查运动连贯性
- → **向用户展示分镜脚本摘要和运动方向轨迹图**（不展示完整10列表格，展示关键信息：镜头数、时长、景别、运镜、画面描述摘要、运动方向、轨迹图、产品露出、转场风格、配音/音效概要），询问用户是否调整
- → **用户确认分镜脚本** ✓
- 多商品套餐：分镜编排逻辑与单商品一致，按已确定的主次关系和时长分配编排各商品出场顺序
- 分镜中绑定：转场风格、音效逐镜头标注、配音时间线
- 时长与分镜数量对应指导：
  - 5秒：2-3个镜头
  - 15秒：5-7个镜头
  - 30秒：8-12个镜头
- 片头片尾时长占比限制：片头+片尾合计不超过总时长的 1/3
- 配音时长 vs 镜头时长自动校验：生成后自动比对每镜头配音预估时长与分配时长，有冲突时提醒用户调整
- 多商品套餐时长分配：主角商品默认占总时长60%，其余商品均分剩余时长（用户可手动调整比例）
- → **合规检查（第一轮：剧本+分镜内容）**：审查广告法合规、夸大宣传、禁用词等（Skill 内部执行）

### 第七阶段：场景图
- 分镜 + 三视图锚点 + 风格 → 批量生成场景图（场景图宽高比须与第二阶段选定的投放渠道比例保持一致）
- 多商品套餐：场景图生成逻辑与单商品一致，按分镜中各商品的出场顺序和画面描述逐镜头生成
- → **用户批量预览**
- 确认通过 / 指定修改（三选一）：
  - A. 整张重新生成
  - B. 局部修改（用户输入要改的内容）
  - C. 用户自定义画面描述
- → **全部确认** ✓

### 第八阶段：广告参数确认
- **旁白/台词内容确认**（配音和字幕的基础）
  - 按镜头顺序展示分镜脚本中所有旁白和台词的完整文本
  - 用户可修改文案内容、调整措辞、增删台词
  - 修改后自动更新分镜中对应镜头的台词/旁白描述
  - 用户确认文案后，后续配音和字幕均基于此版本生成
- 配音风格（调用 LibTV 配音能力，基于已确认的旁白/台词）
  - 配音类型跟随剧本内容：有对话生成对话配音，有旁白生成旁白配音，有独白生成独白配音
  - 用户也可手动指定或输入需求
- 字幕（**默认不加**，用户选择后 → 字体/位置/多语言联动；字幕语言默认与配音语言一致，用户可单独指定字幕语言）
- 标题文字叠加（视频画面上的固定文字层，如商品名称、促销价格、品牌标语，区别于随语音滚动的字幕；用户可选填文字内容和位置）
- 导出格式（默认 MP4）/ 分辨率（默认 1080P，可选 720P/2K/4K）
  - **源素材质量提醒**：若用户选择 2K/4K 高分辨率导出，提醒用户当前源素材（商品图/场景图）的实际分辨率可能不足以支撑高分辨率输出，强行导出可能出现模糊/像素化，让用户确认是否继续
- BGM（**默认不加**，用户选择后由 LibTV 生成）
- 音效（基于分镜中已标注的音效方案，用户可选择）：
  - A. 接受分镜方案：直接使用分镜脚本中规划的音效描述
  - B. 手动修改：用户可针对部分镜头调整音效描述
  - C. AI 重新匹配：忽略分镜中的音效规划，Skill 根据分镜画面内容重新自动判断并生成匹配的音效
- **音视频时长匹配预检**：在进入视频生成前，Skill 自动计算配音总时长与视频分镜总时长，若存在不匹配则提前告知用户并提供选项：
  - A. 自动调整：拉伸/压缩部分镜头时长以匹配配音
  - B. 调整配音语速：加快或放慢配音以匹配视频时长
  - C. 用户手动微调分镜时长分配
- → **用户确认全部参数** ✓（确认后进入视频生成，不可撤回）

### 第九阶段：视频生成
- **分段生成**：按分镜逐镜头生成视频片段（单片段时长受 LibTV 模型上限约束，通常5-10秒/段）
- **用户预览确认各片段**：所有片段生成完毕后暂停，逐个展示给用户预览确认；用户可逐一点评，不满意的片段重新生成，全部通过后才进入合成阶段
- **片段拼接**：按分镜顺序拼接所有片段，自动插入转场效果
- **音频合成**：叠加配音 + 音效（按分镜时间线对齐）；字幕、BGM 仅在用户明确选择时叠加
- → **合规检查（第二轮：成片前最终审查）**：Skill 内部执行，确认最终画面、配音、文字均合规
- → **成片预览**（合规通过后，完整播放给用户，含画面+配音+音效+字幕/BGM）

### 第十阶段：成片确认 + 工程管理
- 满意 → **版本导出**（支持多版本导出）
  - 版本命名规则：自动按"商品名_风格_时间戳"命名，用户可自定义别名
- 不满意 → 可精确到**某个镜头**单独重新生成，或回到具体环节修改
- **回溯修改**：成片后仍可回溯到任意阶段修改，只重生成受影响的部分
- **修改后重新合规检查**：任何修改后重新生成的版本，必须再过一次合规检查
- **工程可重复修改**：成片不是终点，生成的视频是一个可重复修改的工程
- **断点续做**：中断后可从上次进度继续，不需要重新开始
- **素材归档复用**：已生成的素材可归档保存，后续复用时跳过已确认环节
- **线路A/B可切换**：即使已走完某条线路，后续仍可切换回另一条线路重新获取商品图。切换后触发级联依赖链，三视图及所有下游产物（场景图、视频）需重新生成
- **项目级管理**：
  - 项目命名：默认按"商品名_广告类型_创建日期"自动命名，用户可自定义
  - 多项目管理：支持同时维护多个商品广告项目，独立存储互不干扰
  - 多版本派生：同一商品可从任意阶段派生新分支（如同一商品做不同风格/不同投放渠道版本），派生版本继承上游所有已确认产物
  - 项目列表：支持查看所有项目列表，按创建时间/最后修改时间排序，快速进入任意项目继续编辑
