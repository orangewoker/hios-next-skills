# liblib 集成（libtv-skill 通道）

本 skill 通过复用的 **libtv-skill** 脚本与 liblib 交互，不重复实现 API。libtv 的后端 Agent 负责选模型、写底层 prompt、构图布光——本 skill 只负责把"面相翻译结果 + 四视图规格"作为消息发送过去。

## 前置环境

- 必须存在环境变量：`LIBTV_ACCESS_KEY`（Bearer 鉴权）。
- 依赖脚本目录（libtv-skill）：`/Users/gongda/.workbuddy/skills/skill_2053082270621442048/scripts/`
  - `create_session.py`：创建会话 / 发消息
  - `query_session.py`：拉取会话消息（轮询结果）
  - `upload_file.py`：上传参考图（**仅"参考图改造"时用**）
  - `download_results.py`：批量下载结果
- 使用前确认 libtv 脚本目录存在；不存在则提示先安装 libtv-skill。

## 调用命令

```bash
LTV=/Users/gongda/.workbuddy/skills/skill_2053082270621442048/scripts

# 1) 发消息生成（文生图，一条消息即最终成品）
$LTV/create_session.py "……直出消息（见下方模板）……"

# 2) 轮询（每 8 秒，最多约 3 分钟）
$LTV/query_session.py SESSION_ID --after-seq 0 --project-id PROJECT_UUID

# 3) 下载到本地
$LTV/download_results.py SESSION_ID \
  --output-dir "/Users/gongda/Documents/AI项目/人物形象/角色名" \
  --prefix "turnaround"
#   下载后重命名保存为 [角色名]_turnaround_21x9.png
```

- `create_session` 返回 JSON：`projectUuid`、`sessionId`、`projectUrl`。
- 轮询直到 messages 中出现 assistant 角色且 content 含图片/视频 URL。
- 单次查询失败重试 1 次；连续 3 次失败停止并告知用户。
- 3 分钟无结果：告知"生成时间较长，可稍后通过项目画布查看"，不再轮询。
- 任务完成后同时给用户：**结果文件/URL** + **项目画布链接** `https://www.liblib.tv/canvas?projectId=<projectUuid>`。完成前不给画布链接。

## 四视图输出协议（唯一交付 · 单条消息直出）

每个角色**只交付 1 张 21:9 横幅图**——浅灰色纯色背景的**角色四视图设定图（character turnaround）**，无追加图型、无浅灰底前置步骤：

| 交付物 | 文件名 | 内容 | 用途 |
|---|---|---|---|
| 四视图设定图 | `[角色名]_turnaround_21x9.png` | **浅灰色纯色背景四视图横向排列**：① 高清正脸特写 ② 正面无头全身（锁骨上方截断）③ 右侧无头全身（同截断）④ 背面全身（保留头部） | 角色设定 / 转面参考 / 服装与体型核对 |

**执行方式固定为直出**：用 liblib **图片生成器（image 模型通道，如 Seedream 系列，由后端 Agent 选型）**生成单张成品——一条消息、一次直出，规格 **21:9 横幅 · 标准画质 · 2K**。**不先出浅灰底基准图、不做任何本地拼合**（无拼版 / 抹头 / 派生视角等脚本环节）。四个视图在同一张图内一次成型。

|---|---|---|---|
| 视图一 | 最左 | 高清正脸特写 | 正面平视的头部特写，五官清晰；**唯一以五官为主要信息的视图** |

9. **动态层按全身视图检查**：四视图含全身，手部与衣纹必须常态可辨——双手自然下垂、结构清晰、与脸"同档"（茧/纹随职业）；衣装按面料给垂坠与弯折，裤型与鞋也是信息（见 realism-standard 第六节）。

12. **未成年角色的消息纪律**：年龄档词必须显式写出（如"约九岁的男孩"），只按 demographics-and-body 2.2 未成年档填该年龄段成立的形态词；**禁成人骨相词与相学断语**（颧高/腮阔/眉压眼/法令纹/鱼尾纹、格局贵贱类）；全句不得出现成人化着装/妆容/姿态/身材词；服装取其年龄档的日常款；**头身比按该年龄档真实比例**（婴幼儿约 4 头身、学龄约 5–6 头身、少年约 6–7 头身）；**皮肤通透感降档**——只写眼睑/耳廓/鼻尖"隐隐透出淡淡血色"，禁大面积透血管与"瓷感/透明感"措辞；**少年档（12–17）用过程词**（开始显出/渐显/接近/仍有）**不用结果词**（已成形/分明/立体/利落），并禁成人气质断语（城府/锐利/冷艳/风霜）。安全约束见 demographics-and-body 第六节。

14. **影像风格段（可选，默认不挂）**：仅当用户明确要剧照 / 电影感 / 概念图 / 带环境人像时，才在消息末尾加一段固定影像风格——"影像风格：ARRI Alexa 拍摄，柯达 5207 胶片质感，细腻胶片颗粒，柔和自然的侧向光，低对比、高宽容度；不要数码锐化、不要HDR感、不要重颗粒。"（见 realism-standard 7.2）。**四视图设定图（默认形态）一律不加**：胶片颗粒会让浅灰底失去纯净、四视图色温漂移、肤色一致性无法判断。此段只管影像，不替代皮肤描述。

## 参考图改造（图生图）

用户提供参考脸图要求"在此基础上改造/保留这张脸"时：

```bash
# 1) 先上传参考图
$LTV/upload_file.py /path/to/ref.png   # 返回 oss_url

# 2) 再发直出消息（规格行 + 四视图清单 + 统一性要求 + 特征标准块），消息尾携带参考图与一致性锚定句
$LTV/create_session.py "……（同上直出模板）…… 注意：面部必须在参考图人物基础上按上述特征改造；四个视图的面部均须与参考图保持同一人物，其余构图与本消息规格一致。参考图：{oss_url}"
```

- 锚定句写法：`保持面部基准为参考图中的人物：脸型/眉形/眼型/鼻型/唇型不变，仅按上述特征微调 [要改的部位]，发型与服装按上述描写，四个视图同此基准。`
- 参考图存在时，参考图的面部是"长相"的底，特征标准块里描述的改动用词要落在"微调/加/去"上，而非整套替换。
- 参考图的五官细节是视图一（高清正脸特写）的基准；视图二/三无头，只锁服装；视图四锁后脑发态。

## 失败排查

- 报错 `LIBTV_ACCESS_KEY` 缺失 → 提示用户配置环境变量。
- **规格不符**（整卡非 21:9、非 2K）→ 重发规格行"21:9 横幅 · 标准画质 · 2K · 整图就是最终成品"；两次不符 → 告知用户生成端画幅限制，协商可用规格。
- **四视图缺项 / 顺序错乱** → 把四视图清单（视图一~四）逐条前置到消息最开头，并补"必须完整出现四个视图，从左到右依次为：高清正脸特写、正面无头全身、右侧无头全身、背面全身"。
- **无头视图违规**（视图二/三仍画出头、下巴或脖子）→ 追加："视图二与视图三必须自锁骨上方截断，颈部以上完全不存在，截断处保留完整衣领开口与浅灰色纯色背景；不得出现头部、下巴、脖子或残留轮廓。"
- **背面视图缺头**（视图四被画成无头）→ 追加："视图四为背面全身，**保留头部**，可见后脑与发态。"
- **视图间不一致**（脸/发色漂移、服装换款换色、鞋不一致）→ 追加："四个视图为完全相同的一人，服装为同一套（同款同色同细节，含鞋履），不得换装换色；面部特征与发色在全部视图保持一致。"
- **背景非浅灰纯色**（出现环境、渐变、道具、文字编号）→ 追加："浅灰色纯色背景，无环境、无道具、无阴影投射、无文字与编号标注。"
- **画面出现道具 / 手中有物**（工具、包、杯、器械等）→ 追加："手中无任何道具，画面内不出现任何物品（服装与鞋除外）。"
- **姿态带动作**（叉腰、抱臂、插兜、行走、扭头、S 型摆姿）→ 追加："双手自然下垂于体侧、自然站立无动作，不握拳、不插兜、不叉腰、不抱臂。"
- 结果像插画不像真人 → 允许追加唯一质量基线词："接近真人摄影质感，皮肤表面平整、近距离可见细毛孔"。**不要写"真实纹理"**——那是图案触发词（见 realism-standard 5.6）。
- 皮肤出现一圈圈 / 鱼鳞状 / 涡旋状 / 局部重复卷曲纹理（高频细节伪影）→ 见 realism-standard 5.6：删净"纹理 / 走向 / 毫毛"类词、首句补"表面平整、远看肤色均匀"、负向组加齐、关闭细节增强后重发一次；不要靠继续加"更真实"来压，越加越重。
- 磨皮/瓷感/塑料脸/单色 CG 皮 → 追加 realism-standard 5.4 加码句后重发；仍假 → 按 5.6 排障流程处理。
- 模板网红脸、眼神空洞 → 追加校正短语："保留自然左右不对称与皮肤瑕疵（毛孔/细纹/痣），不要磨皮美颜、不要网红滤镜，眼神有自然注视焦点"（见 realism-standard 第三节）。
- 手部错乱（六指/并指/比例失衡）或手与脸不同档（劳动脸配细嫩手）→ 追加："手部结构清晰可辨，五指分明、指节可见；手部皮肤与面部年龄、职业痕迹一致（茧/纹/指甲随人设）"（见 realism-standard 6.1）。
- 衣纹贴图（无垂坠无厚度、乱褶无成因）→ 追加："衣服有真实垂坠与厚度，褶皱符合重力与关节弯折，褶形与面料材质匹配（硬挺料直褶/棉麻软褶/皮无细褶）"（见 realism-standard 6.3）。
- 真实感锚点（痣/疤/斑）丢失或漂移 → 把锚点特征在面部特征段加"必须保留"强调重发。
- 画面出现真实机构标识（徽章/警号/LOGO/品牌字）→ 重发，装束改"无标识素色通用款"。
- 发型/服装跨年代混搭 → 把年代压缩为固定短语（如"1990年代中国北方工厂工人日常造型"）重发，发型按年龄档校正。
- 未成年角色出图成人化（脸老于年龄档 / 身材比例成人化 / 着装超龄）→ 重发时把年龄档词提到句首并补"按该年龄段真实头身比与日常着装"，删净一切成人骨相词与成人化身材词（见 demographics-and-body 2.2 与第六节）。**少年档另查句法**：把"分明/立体/利落/已成形"等结果词替换为"开始显出/渐显/接近/仍有"的过程词，并删去成人气质断语。
- 参考图改造时脸被改得不像参考图 → 锚定句提前加"必须"，并只列"要改的部位"，不重复整段长相描写。
