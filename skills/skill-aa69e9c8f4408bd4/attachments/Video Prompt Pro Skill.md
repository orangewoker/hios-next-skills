# Video Prompt Pro · AI视频提示词全风格专业引擎

## 使用说明

**适用场景：** 用户需要为单条视频片段生成专业级 AI 视频提示词。覆盖从古装漫剧到科幻大片的全部视觉风格。

**输入要求：** 用户用大白话描述想呈现的画面，可包含：人物/动物/物体、环境、时间、想要的氛围/情绪、特殊风格偏好、目标 AI 工具名称。

**关键参数：**

- `描述`：必填，你想要的画面是什么
- `风格`：选填，不指定则自动判断（支持：写实电影/动漫/3D/纪录片/赛博朋克/恐怖/黑白复古/MV/广告/古装/废土/奇幻/科幻等）
- `工具`：选填，目标 AI 视频工具（可灵/即梦/Runway/Sora/Pika/Seedance）
- `模板`：选填，输出模板（全量专业版/精简版/英文版/古装漫剧版）

**预期输出：** 一条包含景别、焦段、运镜、光线、主体描述、环境、风格关键词的完整专业提示词。

**注意事项：**

- 情绪描述会**自动转化为物理细节**（如"孤独"→"肩膀微塌、步伐缓慢、视线低垂"），不会保留情绪标签词
- 如果不指定 AI 工具，默认输出通用兼容版
- 如需多镜头分段提示词，请明确说明每个镜头的内容
- 该 Skill 为单点生成型（单条视频），不是成片型（不输出完整分镜脚本）

## 一、核心工作流

接到大白话描述后，内部分析→输出：

```
Step 1 解析 → 主体·环境·时间·氛围·特殊需求
Step 2 判定风格 → 从风格矩阵匹配
Step 3 选取参数 → 景别·焦段·运镜·光线·色调·构图
Step 4 情绪转化 → 标签词→物理描述（必做，不跳过）
Step 5 适配工具 → 按目标平台调整结构
Step 6 输出 → 选择模板，生成完整提示词
```

### 铁律（四条）

1. **情绪物理化**：不输出"悲伤/愤怒/快乐/害怕"，输出"眼眶泛红/咬肌紧绷/眼尾细纹/瞳孔放大"
2. **段段自洽**：每个镜头完整描述所有元素，禁止"同上/延续/如前"
3. **参数精确**：镜头规格写到品牌+焦段+光圈（如 `Cooke S4/i 50mm T2`），不写"一个镜头"
4. **保留判断**：选模板时询问用户偏好，不在用户不指定工具时强制使用某个平台格式

## 九、台词与旁白同步

当用户描述的画面包含台词或旁白时，**台词必须嵌入动作描述中，与画面同步出现的，不是末尾挂一段文字**。

### 原则

- 台词与动作**交织在一起写**，一句动作接一句台词，不分离
- 描述说话时的口型变化、呼吸节奏、伴随的微表情
- 旁白不写"旁白：XXX"，而写"画外音低沉缓慢'XXX'，伴随画面……"
- 台词内容用引号标注，紧跟说话人的物理状态

### 示例

**用户输入：**

> 老将军站在燃烧的峡谷前，对着溃败的士兵大吼"不许退！"

**输出（精简版）：**

```
中近景，85mm镜头，固定低角度仰拍。入夜，燃烧峡谷的火光从右后方照来，
老将军半张脸在暖橙火光中，另半张没入深影。银盔甲上凝着干涸血渍，
咬肌猛地紧绷，胸腔剧烈鼓起，嘴唇颤抖张开，滚烫声带撕裂式吼出
"不许退——！"，唾沫星飞溅，脖颈青筋暴突。身后火光摇曳，
溃兵人流在远处狼狈奔逃。写实电影质感，35mm胶片颗粒，暖黄火光与冷蓝夜色对比。
不要CGI塑料感。
```

### 多角色对话

**用户输入：**

**输出（精简版）：**


## 十三、内容安全与合规

本 Skill 输出的提示词严格遵守以下原则：

- **不生成暴力/血腥/恐怖内容的详细描写**（如需此类风格，仅输出光线和运镜方案，不描写暴力细节）
- **不生成色情/低俗内容**
- **不生成针对真实人物的负面/诽谤性描述**
- **不生成政治敏感内容**
- **年代/古装场景默认禁止现代违和元素**（电线、手机、塑料制品）
- **中国文化元素使用合规**（非遗、传统服饰等使用正面尊重性描述）
- 如用户输入涉及上述违规内容，Skill 应拒绝生成并说明原因
