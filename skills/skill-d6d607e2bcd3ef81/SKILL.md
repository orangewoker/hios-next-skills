# ai-video-female-growth-16x9

## Skill 定位
- 只负责：生成 **16:9横屏写实女性成长题材短片**
- 适用场景：横版视频、项目演示、案例成片、课堂展示、剧情短片
- 创作风格：现实向、女性成长、都市打拼、情绪共鸣、克制写实
- 硬性约束：不做竖屏短剧，不做霸总豪门，不做极端狗血复仇，不做夸张网红滤镜

## 输入
- 必填：单集核心冲突
- 必填：情绪基调
- 可选：主角设定、视频时长、具体使用场景

## 输入使用
- 严格遵守：画幅固定为 **16:9横屏**
- 严格遵守：剧情写实、生活化、克制表达
- 严格遵守：单篇剧本控制在1000字以内
- 无自定义主角时，默认使用 reference.md 中的标准人设「方桃子」

## 内部流程和 Knowhow
### 1. 横版短片剧本创作
采用横版短片结构：开场事件铺陈 → 冲突发生 → 情绪推进 → 关键反应 → 结尾留白。  
节奏比竖屏短剧更自然，允许少量环境交代和人物状态铺垫。

### 2. 角色资产锁定
自动读取 reference.md 中的人设、五官、气质、穿搭和视觉风格，保持角色形象稳定，避免变脸、崩脸、滤镜跳变。

### 3. 16:9横屏分镜设计
横屏构图优先保留人物上半身、环境关系和城市空间感。  
常用镜头：中近景、近景、特写、缓慢推镜、固定镜头、轻微横移。

### 4. 视觉风格控制
统一使用低饱和暖调、自然光、真实皮肤质感、电影感构图。  
避免高磨皮、高饱和、强特效、广告片感。

### 5. 视频生成 Prompt 组装
结合用户需求、reference.md 角色资产、横屏画幅和负面约束，生成稳定可执行的视频渲染指令。

### 6. 成片输出规范
输出为 **16:9横屏视频成片**，配套提供剧情简介、剧本、分镜、角色锁定参数。

## 输出
- 主产出：**16:9横屏写实女性成长短片视频**
- 附属内容：剧情简介、完整剧本、分镜清单、角色锁定Prompt

## 自检
- 画幅是否为16:9横屏
- 角色形象是否稳定
- 是否存在人脸变形、肢体变形、画面闪烁
- 剧情是否符合写实女性成长定位
- 是否避免了狗血爽文和极端对立
- 输出是否明确为横屏视频，而非竖屏短剧

## Ask User
- 用户未提供核心冲突时，必须询问
- 用户要求多集连续剧时，说明当前仅支持单条横屏短片
- 用户需求明显偏向霸总、复仇、狗血爽剧时，主动确认是否改为写实成长风格
