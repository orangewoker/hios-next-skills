# 附MD02 | 金包银·高水准拉片复刻术与情绪解剖

**所属主SKILL：** 金包银短剧漫剧电影级TVC | 高水准拉片复刻\
**版本：** V2.0 融合合规版

## #做什么

本模块为“金包银短剧漫剧电影级TVC”的专属高水准拉片复刻与情绪解剖库。

解决如何在不抄袭原片的前提下，提取高水准对标作品的情感张力与叙事骨架，并成功将金包银产品融入其中的痛点。通过“抓骨架、找角色、换皮肤”三步曲，确保复刻作品既有对标作品的情绪爆发力，又有金包银专属的皇家/非遗/传承厚重底色。

## #需要什么输入

**最少提供：**

- 对标作品或参考情绪（如“某高水准短剧的高能反转片段”）
- 金包银剧情场景或核心产品（如金包银手镯、皇家御用工艺等）

**可选提供：**

- 目标时长
- 目标画幅（不限定，按项目需求或用户指定）
- 是否需要输出视频文件、视频脚本、Prompt清单、视觉方案

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。本环节重点参考【葵花宝典】的困兽、体语、焚我三法则，确保复刻作品的情绪张力逻辑闭环。

### 二、高水准拉片复刻三步曲（极度精准）

1. **抓骨架（锁死节奏）**：精准提炼对标作品的“高能节点、共情节点、黄金前3秒”以及情绪递进节奏。这是复刻的“灵魂”。
2. **找角色（精准对位）**：提取对标作品中的人物动机与困境，将主角替换为“金包银老匠人”或“年轻传承人”，将对标作品中的核心奖品/象征物100%替换为“金包银手镯”。
3. **换皮肤（完全对标）**：画面的整体画风、光影、质感100%严格复刻对标作品当下的风格（如果对标3D动画，就用3D动画；如果对标赛博朋克，就用赛博朋克；如果对标古装写实，就用古装写实）。风格永远跟随着对标作品走，绝不自作主张换风格。

### 三、情绪红线（禁止触碰）

- 严禁照搬原片台词、分镜，严禁无脑抄袭；但必须100%复刻其情绪张力。
- 情绪必须精准（如：先苦后甜、失而复得、跨越宿命），并精准作用在“金包银”的剧情上。
- 作为“金包银”专属复刻，必须天然融入皇家/非遗/传承等厚重情绪底色，让复刻出的作品不是“劣质模仿”，而是“高级致敬”。

### 四、复刻时的物理边界（极其重要）

- **产品不能崩**：无论对标哪种风格，金包银手镯的材质必须严格遵守《附MD01 | 金包银·材质防崩与视觉语法库核心禁则》。
- **不穿越，不乱搭**：对标作品是什么画风，画面里就只允许存在该画风的元素，严禁出现“画风打架”的半成品。

### 五、生成与合成

根据上述复刻术与情绪解剖规则，调用底层视频生成Skill，输出MP4视频文件。

## #产出什么

最终交付：

- **视频文件（MP4格式）**：金包银短剧漫剧电影级TVC成片。
- **视频脚本、Prompt清单、视觉方案**。
- **高水准拉片复刻拆解报告**：高能节点、共情节点、黄金前3秒、核心骨架。
- **情绪解剖表**：情绪递进节奏、角色对位、金包银剧情植入点。
- **风格对标清单**：画风、光影、质感的100%严格复刻参数。
- **可直接进入AI视频工具生成链路的执行清单**。

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 对标作品或参考情绪不明确，导致无法锁定核心骨架时。
- 金包银剧情场景或核心产品设定不明确时。
- 对标作品的画风与金包银材质防崩禁则冲突时。
- 用户要求突破情绪红线（如允许直接照搬台词、分镜）时。
- 用户要求输出视频文件、视频脚本、Prompt清单、视觉方案，但缺少关键输入时。
- 本模块与上游主SKILL或其他附MD规则冲突时。
