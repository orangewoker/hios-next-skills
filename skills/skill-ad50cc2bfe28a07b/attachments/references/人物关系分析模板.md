# 人物关系分析模板

本文件提供不同场景类型的人物关系分析框架，帮助系统化构建场景模型。

## 一、通用分析流程

处理任何剧本场景时，按以下步骤分析：

### 1. 人物清单整理
- **核心互动人物**（≤5人）：谁在主导对话/动作？
- **重要配角**（≤10人）：谁在观察/反应/支持？
- **群众角色**：数量、情绪状态、可能的行为趋势

### 2. 关系网络构建
- **敌对轴**：谁 vs 谁（主要矛盾）
- **联盟轴**：谁和谁并肩/互助
- **从属轴**：谁指挥谁，谁受制于谁
- **情绪感染链**：A的情绪→B的反应→C的态度

### 3. 空间层次识别
- **垂直分层**：空中/地面/地下，高台/平地/深坑
- **水平分区**：中心/侧翼/外围，室内区域划分
- **距离关系**：亲密（<2m）、对峙（3-5m）、疏远（>5m）

### 4. 动态变化预判
- 可能的位置移动
- 形态转换节点
- 道具交接/使用
- 情绪引发的姿态变化

## 二、场景类型专用模板

### A. 内景对话场景（如山洞洞府/厅堂）

**特点**：封闭空间、坐/站布局、道具交互、情绪累积爆发

**分析要点**：
1. **空间压迫感**：空间多大？天花板多高？光线如何？
2. **座位权力结构**：谁坐主位？谁站侍从位？谁靠门边？
3. **道具交互焦点**：石桌、茶杯、武器、凭证
4. **情绪容器效应**：封闭空间如何放大情绪？

**站位示例框架**：
```
镜头从入口向内推：
【前景】入口光影分割线
【中景】主位区：主导者（主位，挺直） · 来客（侧位，沉稳/不安）
【中后景】次要角色（靠柱，游离） · 侍从（脚边，警惕）
【背景】洞府岩壁、火把/光源、深处阴影
```

### B. 外景对峙场景（如宗门广场/悬崖）

**特点**：开阔空间、多层次站位、群众围观、空中地面互动

**分析要点**：
1. **垂直权力象征**：谁在空中（权威）？谁在地面（挑战）？
2. **群众情绪场**：围观者的态度变化轨迹
3. **空中层细分**：御剑者（最高）→ 悬浮者（稍低）→ 云层（背景）
4. **地面层分组**：主角团队 vs 敌方团队（松散包围）

**站位示例框架**：
```
镜头广角仰拍：
【高空层】御剑飞行的长老（半空中央）
【空中层】其他悬浮角色（四角悬浮，观望）
【地面核心层】主角A（前）· 主角B（后）· 主角C（侧）
【地面外围层】敌方弟子（松散半圆，军心动摇）
【背景层】宗门建筑、旗帜
```

### C. 战斗/动作场景

**特点**：快速移动、阵型变化、进攻向量、防御姿态

**分析要点**：
1. **进攻方向**：谁向谁攻击？轨迹如何？
2. **防守阵型**：如何站位互相掩护？
3. **速度层次**：快速突进 vs 稳步推进 vs 固守阵地
4. **技能范围**：近战贴身 vs 远程攻击 vs 范围效果

**站位示例框架**：
```
镜头跟随进攻线：
【进攻方】角色A（前锋，突进） → 角色B（中锋，策应） → 角色C（侧翼，骚扰）
【防守方】反派（后撤） ← 护卫（左右护持） ← 喽啰（阵型松散）
【移动向量】角色A从地面跃起，45°角斜扑空中反派
```

### D. 情绪转折场景

**特点**：情绪驱动动作、姿态戏剧性变化、空间距离调整

**分析要点**：
1. **情绪触发点**：哪句话/哪个画面引发转折？
2. **身体语言变化**：压抑→释放，紧绷→舒展，退缩→前进
3. **距离调整**：因情绪变化而靠近/远离
4. **群体传染**：个人情绪如何影响群众？

**站位示例框架**：
```
镜头特写情绪爆发：
【情绪前】角色A低头压抑，身体内收，武器下垂
【情绪触发】"你竟然这样对我！" → 眼神变化，嘴角抽动
【情绪爆发】仰天狂笑，身体后仰舒展，武器高举
【情绪扩散】围观者震惊后退，配角瞪大眼睛，对手身体摇晃
```

## 四、复杂场景分解法

当场景过于复杂时（>8个重要人物）：

### 1. 分层分析法
- **第一层**：核心矛盾（主角团队 vs 反派团队）
- **第二层**：关键配角的态度摇摆
- **第三层**：群众反应（围观者的情绪变化）
- **第四层**：环境互动（建筑、法器、天气）

### 2. 分组处理法
将人物分组描述：
- **反派阵营**：反派首领 + 核心手下（名义上跟随）
- **主角团队**：主角A（领袖）· 主角B（爆发点）· 主角C（辅助）
- **围观群体**：情绪从动摇到可能倒戈

### 3. 焦点转移法
不同分段聚焦不同人物：
- 分段1-3：聚焦主角A与反派B的正面对峙
- 分段4-5：聚焦配角B的行动线
- 分段6-7：聚焦主角团队配合阵型
- 分段8-9：聚焦围观者反应变化

## 五、常见错误避免

### ❌ 错误做法
1. **孤立描述**："角色A在左边，角色B在右边"（缺少关系）
2. **坐标化**："站在(10,5)位置"（无叙事意义）
3. **静态描述**：不描述情绪引发的姿态变化
4. **忽略层次**：不区分前景/中景/背景
5. **断裂衔接**：不说明从上一段到本段的变化

### ✅ 正确做法
1. **关系描述**："反派居高临下俯视，主角仰头对峙但气势不输"
2. **动态叙事**："因愤怒而身体前倾，因狂喜而仰天大笑"
3. **层次清晰**："前景表情特写，中景对峙焦点，背景环境氛围"
4. **逻辑衔接**："从地面跃起，扑向空中的对手"
5. **情绪融合**："火光在主角脸上投下决绝的阴影"
