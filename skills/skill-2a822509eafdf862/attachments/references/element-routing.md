# 元素路由规则

## 路由表

根据口播语义选择最小必要元素：

内容信号首选元素备注开场主张、反常识结论开场标题或核心命题卡只保留一句最有力的原意章节变化、话题转折章节转场、小标题一章最多一个主转场概念定义概念卡术语与一句解释分层三至六个步骤步骤卡或流程图保持编号清晰并列清单清单卡超过六项时拆分A 与 B 的差异对比卡、左右结构对比维度必须来自原稿因果、前后关系箭头关系图、流程示意不添加原稿没有的因果数字、金额、比例、日期数据卡、数字强调数字必须逐字核对他人观点或原话引用卡仅在稿件明确引用时使用风险、误区、注意事项提醒卡、警示标签风格保持克制案例、场景、比喻内容插画或场景图画面服务解释，不做无关氛围图最终总结结论卡、行动清单不擅自添加行动建议普通过渡句仅字幕不额外生成卡片

## 密度

避免“每句话一个元素”。

- 60 秒以内：通常 4～8 个非字幕视觉事件。
- 1～3 分钟：通常 8～18 个非字幕视觉事件。
- 3 分钟以上：按章节控制，每章 2～6 个非字幕视觉事件。
- 同一屏幕同时出现的独立信息层不超过三层。
- 连续两个重型卡片之间至少保留一个普通内容段。

如果稿件信息密度低，宁可少生成，也不要用装饰凑数量。

## 文案选择

- 章节标题：通常 4～12 个中文字符。
- 卡片主标题：通常 4～16 个中文字符。
- 卡片正文：只保留理解所必需的信息。
- 字幕：保持口播原文，不用卡片摘要替代字幕。
- 关键词强调：每句最多强调一个短语，除非参考图明确使用多重点结构。

生成短标题时只压缩措辞，不改变立场、因果、程度和数字。

## 静态与动态

- 背景、卡片和字幕底板优先输出静态图片或透明素材。
- 章节转场、开场标题和关键结论可输出短动态片段。
- 无明确需要时不要把所有元素都生成成视频。
- 动效默认 0.4～1.2 秒进入、0.3～0.8 秒退出；章节转场可为 1.5～3 秒。
