# 动作链设计

## 节点卡

为每个动作节点记录：

```text
行动者：
起始姿态与距离：
武器轨迹和身体方向：
脚步与重心：
对手回应：
接触点或避让路径：
结束姿态与新距离：
摄影机对象、方向和反馈：
环境反馈：
生成风险：
```

## 三节点稳定版

一次明确进攻 → 一次清楚防守/闪避 → 一次反击或对峙收束。

## 五节点平衡版

建立距离 → 进攻 → 防守/卸力 → 接触与位置变化 → 反击/结果。

## 高燃版

只在平衡版已清楚时增加速度、复合位移、环境破坏或特效。每增加一项，指出它可能遮挡或破坏的核心信息。

## ACT 反馈

ACT 是视觉反馈选择，不是必须风格：镜头跟随动量、接触瞬间短暂停顿、轻震或跟随受力方。不要让镜头从头到尾无方向乱晃。

## 降级顺序

删除次要特效 → 删除次要镜头运动 → 删除中间招式 → 退回三节点。保留角色与武器绑定、空间、主要接触和结果。
