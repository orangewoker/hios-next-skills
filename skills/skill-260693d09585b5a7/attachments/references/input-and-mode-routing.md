# 输入证据与模式路由

## 先给输入分工

- 用户文字说明：决定目标、禁止项、指定角度和已确认事实。
- 标签展开图或包装原稿：决定文字、LOGO、图案、色块和印刷位置。
- 白模、CAD、3D 模型或结构渲染：决定几何、比例、部件和不可见表面。
- 多角度实拍：决定真实结构、材质、颜色、接缝和各表面内容。
- 单张实拍：只证明画面可见内容，不证明背面或遮挡区域。
- 风格参考：只决定光影、构图和质感，不得覆盖产品事实。

## 模式选择

### A. 原角度精修

选择条件：用户只说“精修、修白底、清理背景、提升质感”，或没有明确要求改变视角。

允许：背景清理、轻度透视修复、边缘和噪点处理、曝光与色彩校正、材质还原、棚拍光影优化。

禁止：自动转正视、改变产品朝向、补造遮挡部件、替换包装内容。

### B. V01 标准正视

选择条件：用户明确要求标准正面/正视图，且主展示面、轮廓与结构比例有足够证据。

证据不足时：请求更正的正面照片或白模；不要从严重斜拍、强遮挡或广角畸变图硬推精确正视。

### C. 白模/模型标签贴模

选择条件：同时具备结构参考与包装/标签原稿。

要求：结构采用模型，包装像素和版式采用原稿，实拍只补充材质与颜色。先确认原稿对应哪个面、标签起止位置和接缝，再生成。

### D. 单一指定视角

选择条件：用户指定 V02–V08 中一个视角，且该视角所需表面有对应照片、模型或完整包装原稿。

证据不足时：只输出可确认的角度，或请求缺失表面参考。

### E. V01–V08 多视角

只有以下任一证据组合成立时才执行完整八视角：

- 清晰多角度实拍覆盖正、背、左右和顶部/底部关键结构；
- 可旋转的 3D/CAD/白模结构加完整标签或包装展开图；
- 用户提供已确认的完整多视图母版。

单张正面图不满足完整八视角条件。V01 审核通过也只能锁定已知身份，不能凭空证明背面和侧面。

## 关键歧义处理

- 材质明显时直接判断；玻璃/透明塑料、金属/电镀塑料等难以区分且影响结果时才询问。
- 文字低清时不转写、不补写；把该区域视为需要高保真的图形结构。
- 标签接缝不可见时不主动添加；视角转到可能出现接缝的一侧且位置未知时，要求展开图或侧面参考。
- 用户要求与图片事实冲突时，先指出冲突；不要静默选择。
- 用户允许创意补全时，可以生成推测内容，但必须明确标记为概念效果，不能称为真实商品还原。

## 范围边界

本技能适合包装型消费品、容器、盒袋、家清洗护、美妆、食品保健品、医疗健康用品包装和消费电子产品外观。人物服装、首饰上身、家具空间、生活方式场景和主图营销排版应使用对应专业技能。
