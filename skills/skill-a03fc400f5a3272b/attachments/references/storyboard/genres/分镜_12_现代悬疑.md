# 现代悬疑风（Modern Suspense）分镜指令库

> **主打风格**：阴冷色调、极度压迫感与心理暗示，用构图和细节制造不安的情绪。
> **加载时机**：`/分集 {N}` Phase 2 时，若题材判定为悬疑 / 惊悚 / 犯罪 / 心理，加载本文件复用分镜。

| 分镜名称 | 完整指令 |
| -------- | -------- |
| **窥探之眼** | 门缝遮挡视角，阴冷发绿的走廊灯光。视线穿过微开的防盗门，聚焦在客厅中央。一个穿着灰色连帽衫的男人正背对着镜头拖拽一个沉重的黑色塑胶袋，地板上留下一道反光的水痕，制造出强烈的偷窥不安感。 |
| **后视镜危机** | 车内后视镜画中画构图，雨夜车灯的刺眼眩光。暴雨拍打挡风玻璃，女司机的双眼在后视镜中惊恐地瞪大。镜子里，后排原本空荡的座位上，悄然浮现出一个模糊的戴着白色面具的黑影，瞬间让人汗毛倒立。 |
| **天台对峙** | 极高俯视广角镜头，阴天冷灰调。摩天大楼的边缘，风衣警探和连环杀手相隔三米站立。大风将两人的风衣衣角吹得疯狂翻飞，警探握枪的手微微颤抖，杀手却张开双臂做出拥抱天空的姿态，背景是深不见底的城市深渊，眩晕且窒息。 |
| **照片线索** | 微距特写，暖黄但暗哑的台灯光晕。杂乱的木质书桌上堆满案件卷宗，一只夹着半截香烟的粗糙大手，正用红色记号笔在一张老照片的背景角落画圈。烟灰摇摇欲坠，照片上那个原本笑着的小女孩，眼神此刻却显得阴森空洞。 |
| **水下挣扎** | 水下仰拍镜头，波光粼粼的幽暗深蓝光。冰冷的浴缸底部，女主的长发像海藻一样在水中凌乱散开，水泡不断从她口中涌出，遮挡了她痛苦扭曲的面部。水面上方，一双穿着黑色皮鞋的脚静静站立，绝望窒息的恐惧感扑面而来。 |
