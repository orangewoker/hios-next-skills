# 画风锁定与 Style Image 图片工作法

只在项目进入画风锁定、资产图或分镜图阶段时读取本文件。

## 一、先建立项目级画风锁定卡

画风不是一句"高级中式美学"，而是一组能在每张图里重复执行的选择。根据故事建立以下字段：

字段必须回答的问题文化坐标具体时代、地域、阶层、礼俗、技艺、文学或哲思来源是什么？媒介真人电影、写实 CG、二维赛璐璐、三渲二、水墨实验或其他？色彩主色 2–3 个、强调色 1 个、禁用色，以及剧情中的色彩变化是什么？光影主光来自哪里，硬/软、冷/暖、晨昏或室内光源如何延续？材质木、石、纸、丝、麻、漆、陶、金属、植被与地面的真实触感是什么？镜头主要焦段、机位高度、留白、对称/非对称、景深和运动气质是什么？空气雨、雾、尘、风、湿度、烟、水汽如何出现？后期清透、低饱和、矿物色、胶片、柔焦、颗粒等如何控制？禁区哪些颜色、建筑、装饰、特效或异文化元素会让项目出戏？

本技能默认基调：古代中式田园 + 中秋氛围 + 写实电影质感克制美学、整体金黄色滤镜。除非用户另立方向，画风锁定卡按此基调建立；默认禁区为现代农村服装、塑料制品、中年外貌、农妇面相、奢华汉服、刻意摆拍（已固化在固定结尾的 --no 中）。

将这些选择压缩成一条 80–220 字符的固定风格锚点句。批准后逐字复制到本项目每条图片提示词中，不要每镜同义改写。

## 二、选择合适的中式美学母体

只选与故事真正相符的一种主母体，必要时加入一种辅母体；不要全部混合。

- 盛唐诗性与天地尺度：开阔山河、人的渺小、饱满矿物色、风与云的运动。适合诗人、远行、宴饮、边塞与盛衰。
- 宋式文人克制：灰青、米白、黛色，疏朗留白，低位自然光，细密器物与日常秩序。适合内心戏、书斋、庭院、别离与哲思。
- 古代中式田园与中秋节令：田野、院落、晒秋、炊烟、桂花、纸灯与月光；金黄、暖褐与月白的自然色系；写实电影质感；节令礼俗（团圆、馈赠、守望、祭月）承载叙事。本技能默认以此母体为基调。
- 中式神话与天宫：从青铜、玉石、云海、星象、礼制和古代宇宙观建立奇观，避免西式教堂、盔甲、天使翅膀与游戏副本感。
- 民间人文与手艺：县城、村落、河埠、戏班、窑火、纸扎、木作、茶馆等真实生活空间；奇观从人的劳动与命运中长出。
- 当代东方诗意现实：现代中国城市/乡镇的真实结构，以季节、家庭、迁徙、职业和代际关系承载中式情感，不强塞古装符号。

不默认使用龙。龙只在题材、权力、信仰或具体情节需要时出现，并明确它在画面中的叙事作用。

## 三、图片路线与最小资产集

### A. 关键资产 + 分镜

优先做：

- 每位高频角色 1 张全身身份图，必要时补 1 张面部近景或主要换装。
- 每个反复出现的主场景 1 张空镜空间图。
- 会被拿起、损坏、交换或触发剧情的关键道具。

获选后立即进入分镜，不为"可能有用"制造资产。

### B. 完整资产优先

- 角色：身份图、正面/四分之三面、主要服装、必要表情；不要在一张图塞过多小格导致面貌模糊。
- 场景：外观建立、内部空间、昼夜或剧情必需状态；空镜优先。
- 道具：中性背景，明确尺度、材质、磨损和独特识别点。

每一类资产单独确认，再进入分镜。

### C. 直接分镜

即使不做资产，也先写内部连续性锚点：

- 固定角色锚点：年龄段、脸型、眼神、发型、体态、服装轮廓、识别色或随身物。
- 固定场景锚点：空间布局、主建筑/主物件、地面、远景、主光方向。

每次角色或场景再现时原样复制锚点，不依赖"同一个人""还是那个地方"这类模型无法落实的表述。

## 四、提示词结构

### 通用结构

按重要性排序，不必机械堆满：

主体身份与数量 → 决定性动作/情绪 → 空间与前中后景 → 景别与构图 → 镜头/机位 → 光影天气 → 关键材质 → 固定风格锚点 → 固定结尾（已含画幅与排除项）

固定结尾必须是：

```
写实电影质感克制美学，整体金黄色滤镜，--no 现代农村服装, 塑料制品, 中年外貌, 农妇面相, 奢华汉服, 刻意摆拍 --chaos 10 --ar 16:9 --stylize 550 --profile nln4ubk cdjyzwx ylefdsr cq694m3 --hd
```

完整末尾示例结构：

```
...写实电影质感克制美学，整体金黄色滤镜，--no 现代农村服装, 塑料制品, 中年外貌, 农妇面相, 奢华汉服, 刻意摆拍 --chaos 10 --ar 16:9 --stylize 550 --profile nln4ubk cdjyzwx ylefdsr cq694m3 --hd
```

不要在固定结尾后追加任何字符、句号或说明；排除项已固化在固定结尾的 --no 中，画幅已锁定 16:9。

### 角色资产提示词

必须包含：单一角色、身份锚点、全身或指定景别、站姿与气质、服装结构、材质、时代依据、简洁背景、均匀可读光线、固定风格锚点。除非用户要求，角色资产图不加入武器特效、复杂剧情动作或喧闹场景。

### 场景资产提示词

必须包含：无人空镜、地理/建筑类型、空间动线、前中后景、主物件位置、时间天气、主光方向、材质与使用痕迹、固定风格锚点。场景不是概念堆砌，要能回答人物从哪里进、到哪里去、光从哪里来。

### 道具资产提示词

必须包含：单一道具、时代与用途、形状、尺度参照、材质、色泽、磨损/使用痕迹、清晰背景和固定风格锚点。普通杯碗桌椅无需单独制作，除非它影响剧情连续性。

### 分镜图提示词

必须包含：镜号对应的单一瞬间、角色锚点、可见动作、视线与站位、场景锚点、景别、焦段感、机位、前景遮挡或纵深、光线、固定风格锚点。不要写镜头运动过程；运动留给视频提示词。

## 五、构图与景别递进

根据情节功能选镜头，不随机轮换：

功能优先画面建立天地与人物尺度极远景/大全景，人物可很小，空间方向清晰建立人物关系双人中景、过肩、前后景错位、视线关系冲突升级低机位、侧向压缩、强前景、倾斜动势但不滥用斜构图情绪暴露近景/特写，减少环境信息，让眼神、手或呼吸成为主体关键线索插入特写、俯拍桌面、微距材质或手部动作反转揭示从遮挡后显露、反打、拉开空间或改变人物大小关系余韵稳定远景、背影、空镜或人物离开后的环境状态

相邻镜头至少改变两个维度：景别、机位、视轴、人物大小、遮挡、焦段感或运动方向。不要让全部画面都成为中央站立、正面看镜头、背景虚化的人像海报。

## 六、输出格式

每条图片提示词采用：

- 镜头/资产编号｜用途｜建议景别
- 一整条可复制的单行提示词，以固定结尾收尾
- 字符数：N/1000

标签、说明与字符数不得放进代码块。若用户只要提示词，就省略创作解释，但保留编号和字符数。
