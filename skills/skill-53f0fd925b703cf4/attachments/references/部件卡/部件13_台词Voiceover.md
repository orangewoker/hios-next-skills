# 部件卡13 · 台词 + Voice-over

## 语音身份文本verbatim（有对白段必写·2026-08-07新增）
```
【语音身份文本verbatim】（从2zc角色填空抄录·逐字粘贴永不改编）
  [语音身份文本，1-2句，与2zc字段一字不差]
  ⚠️ 永不按场景改编。角色说什么话可以变，声音身份永不改。
  ⚠️ 与表演档案内声音档案互验：两者冲突=退回查源头（1jbfj视觉档案）。
【音色锚定】@[XX音色hash] 作为[角色名]说话的音色锚定（保留现有）
  关系：verbatim=文本层声音身份，@hash=资产层音色，两者叠加。
```

## 对白标配写法（2026-08-05强化：说话动作+神情必写）
```
[角色名] [语气描述]，用[角色名]的音色说："[台词内容]。"，[说话时的身体动作或反应]+[神情]。
⚠️ 说话动作+神情 必写（万物生每处对白都带，缺=退回）：
  - 外放型=说话前动作三连：「用手背抹嘴→转头→讪笑→开口说话」（刘回）
  - 克制型=动作最小+神情照写：「说话时她神情冷淡、嘴唇微动、语气平静到没有一丝起伏」（丹眉）
  - 手部绑定：「说话过程中左手伸向符箓，拈起一角」（女儿）
  - 神情级：神情冷淡/平静/审视/紧张/疑惑（半词级，不是整句）
✅「琉璃压低声音急促地说："盲可汗来了……"，尾音发虚，用琉璃的音色。」
✅「螃蟹以飞快的天津腔继续说："每当地龙升天的时候这老盲就会扎堆出来逮龙虱子吃"，蟹钳随语气节奏开合挥动。」
✅「丹眉神情冷淡、近乎面无表情，目光越过甲壳兽尾巴望向对面，开口说"那边趴着的是一头牛吗？"，用丹眉的音色。」
✅「女儿眉头一蹙、脸上是疑惑的神情，用偏成熟略低沉的御姐音色开口问"你是谁？"」
```

## 旁白/内心独白（Voice-over）
```
Voice-over treatment: [角色名]'s [内心独白/画外音] throughout the shot is a non-diegetic voice-over
with intimate close-miked recording quality and subtle internal reverb,
[她的/他的] lips do not move on screen at any point,
the voice exists only as [角色]'s internal thought.
```

## 旁白标注（字数+时长+同步关系）
```
✅「「遗忘是沙漠的本性。」七字，念两秒半，尾音微微拖长，恰好与第二声锤击重叠。」
✅「『通玄』二字与瀑布轰鸣最饱满瞬间同帧」
✅「『大罗天』念完后旁白止，风声单独延续约1秒作为余韵收幅」
被打断：说到「某字」时被[具体事件]打断，旁白戛然而止
旁白身份（非常规旁白时）：不是人在说话，是[沙漠/世界/旁白者]在说话
```

## 旁白速率匹配风格
```
意境片：≤3字/秒+留白（念完旁白止，风声/环境声单独延续1-2秒收幅）
叙事片：4-6字/秒（正常语速）
情绪重场：半句7字约3.5字/秒（慢速承载情绪）
```

## 声场叠台词（多人对话）
先声明底层声场贯穿不断，再写台词叠放方式：
```
✅「远景混乱声场全程铺满——兽王碾地的低频轰隆、远处人群惊叫、龙虱摩擦尖响交错此起彼伏、
  全程不断；台词与近景动作音因贴近镜头而清晰浮于声场之上。」
```

## 台词被打断格式
打断 = 说到第几个字断 + 打断源 + 被断方生理残留：
```
✅「丹眉的话还没说完"但是再不赶紧的话——"被中途打断的瞬间，远处沙漠传来低频嗡鸣……」
✅「玄鹄（画外音，打断她——他没有等她说完）："我一定要去找她！"……霜鹭的嘴唇还微微张着——那句话被截断在喉咙里。」
```

## Voice-over 分段落点格式（长独白按镜头节拍切段）
```
✅「镜头节拍一：正脸近景特写，内心独白以flat analytical deadpan语气响起："莫名其妙来到这种地方，
  大概率是穿越了。"独白持续约3秒钟，镜头环绕到她的右侧大约90度位置。镜头节拍二：……」
```

## 对白使用原则（参考武器打斗）
对白不能连续堆叠，每个镜头只保留必要对白；禁止为了塞台词加速语音、吞字、重叠台词或口型不同步。
