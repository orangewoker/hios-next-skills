# 附MD07 | 互动影游分支剧情树与节点设计规范

## #做什么

本模块为互动影游专属的分支剧情树与节点设计规范库。

解决互动影游“节点命名混乱、分支指数爆炸、路径死胡同、假选项、剧情树结构松散”的痛点。通过统一的节点命名规范、发散-回流-锁定-再发散结构与灵魂七问，确保剧情树逻辑严密、分支可控、路径收束。

## #需要什么输入

**最少提供：**

- 主线剧情节点清单
- 核心抉择点设计
- 路线设计与结局路径

**可选提供：**

- 目标平台（Steam/视频平台/小程序）
- 目标时长
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。剧情树与节点设计环节重点参考【顶级游戏开发大师】的节点设计规则。

### 二、节点命名规范（强制执行）

- **主线剧情节点**：N+两位数字，如N01、N02
- **路线节点**：N+两位数字+路线代号，如N05A、N06B
- **正结局**：E+两位数字，如E01、E02
- **坏结局**：D+两位数字，如D01、D02
- **变量初始化节点**：StoryInit
- **结局判定节点**：ENDING_CHECK
- **核心铁律**：所有节点ID、视频文件名、代码中的引用必须100%完全一致。

### 三、剧情树核心结构（发散-回流-锁定-再发散）

1. 主线节点：推进整体剧情。
2. 抉择点：玩家做出选择，触发分支。
3. 路线锁定：关键选择后路线锁定，不可逆。
4. 结局判定：根据所有变量与路线自动判定。
5. 收束回主线：每一章末尾必须收束回主线，防止分支指数爆炸。

### 四、分支收束铁律（核心铁律）

1. 单章分支层级不超过3级。
2. 关键选择后路线锁定，不可逆。
3. 每条路径最终抵达结局，无死胡同。
4. 零假选项：每个选择必须改变至少一项变量或后续节点。
5. 每一章末尾必须收束回主线。

### 五、灵魂七问（每个抉择点必须过审）

1. 玩家为什么选它？（动机）
2. 它改变了什么？（信息/关系/资源/风险/路线）
3. 即时后果是什么？
4. 延迟后果在哪个后续节点出现？
5. 是否可能造成独特失败或隐藏路线？
6. 是否只是换台词而没有剧情差异？（绝不允许）
7. 是否与角色动机和世界规则一致？

### 六、生成与合成

根据上述剧情树与节点设计规范，调用底层视频生成Skill，输出MP4视频文件。
