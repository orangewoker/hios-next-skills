# 09 · 场景类型策略详解

> 读取时机：步骤3b-2 判定场景类型后，**只读判定到的那一类**（不全读）
> 复述闸：读完向用户复述「本类AI跑偏路径是X，3个必写句式是Y1/Y2/Y3」——说不出来=没读=退回
> 来源：万物生两集+渊+墨染+历史+打斗2个+切镜头版 共8源内容写法精读（2026-07-29）

---

## 核心洞察（写任何段前默念）

**密度不是"写得多"，是"在AI最容易跑偏的位置写多"。**

- 为什么加：AI在这个位置有默认跑偏行为
- 怎么加：针对AI的具体跑偏行为写针对性约束（不是堆物理细节）
- 哪里不加：AI有先验能做好的（打斗动作/武器轨迹/简单对白）+ AI画不出的（心理/过程）+ 外部资源能承担的（图片/胶片型号）
- 加密=防AI跑偏；不加密=AI默认行为已符合需求

**先验分区本质=按"AI在什么位置跑偏"分策略，不是按"打斗/日常"分。** 万物生日常段也极详细，只是详细维度=空间结构+防穿帮，不是物理因果链。

## 类型1 · 日常/街道/室内（主源：万物生第一集）

### 填空工作流（步骤3预检+3.5元素清点·本类专属）
```
【读原文】万物生第一集「铜锣湾街拍段」/「化妆间段」
【AI跑偏清单·选+补】☐美化简化（空旷/特写）☐光影平均 ☐人物从深处冒出 ☐人群同质 ☐其他__
【加密位置填空】
  空间三维坐标：纵深__横向左右__纵向__
  人群密度：__个+__层（前/中/远）+职业枚举__
  入画/出画方向：__（从画面下方/左右下角擦入，禁从深处冒出）
  多色光源色块占比：主光__%（色__）+侧光__%（色__）+点缀__%（色__）
  主体占比数值+不推近：占画面__到__，禁推近到__
  视线流量：从__进入，被__遮挡，停在__
【8维度密度策略】本类=满（万物生10+元素全描述/5层音轨带空间/色名级或hex/30%中英/T1.4参数/Wind可见/空间极高）
```

**AI跑偏路径**：AI默认美化简化——空旷街道、主角特写、光影平均分布、元素随意重叠

**防跑偏策略**：
1. 空间结构三维坐标：纵深方向+横向左右两侧+纵向，锁死机位与人物关系
2. 防穿帮物理否定句：「不在马路上不在电车轨道上」「电车只在画面深处或侧面被看到」
3. 人群密度分层：数量(20-30)+景深分层(前景/中景/远景)+类型列举(白领/潮男/学生)
4. 运镜精确参数：距离(3-4米)+高度(腰部略低)+构图比例(1/3到1/2)+时间分段
5. 光影多色块配比：主光源+侧光+点缀光三层+「紫光占主导+冷蓝勾轮廓+暖橘小面积点缀」

**3个必写句式**：
- 「画面纵深方向：...画面横向左右两侧是...」（三维坐标锁空间）
- 「[元素]在画面[位置]，不在[主角所在位置]」（物理否定防穿帮）
- 「[动元素]是画面中唯一持续运动的元素，与[静物]的绝对静止形成对比」（动静对比声明）

**原文例句**：
> 「画面纵深方向：画面深处是人行道延伸的远端...画面横向左右两侧是人行道边缘——一侧是商铺玻璃橱窗...马路上叮叮电车红色出租车在画面左侧或右侧的远景里穿行**不在丹眉所在的人行道上**」

为什么好：一句话三重信息——画面元素+空间位置+防穿帮否定。AI不会把电车画到主角脚下。

**加密位置**：空间关系/人群分层/物理否定/机位参数/色彩权重
**不加密位置**：对白/单人动作链/通用风格锚定（AI默认就做得好）
**AI边界**：空间坐标和否定句AI完全能执行；「工作日下午繁华时段」氛围描述AI难精确还原，靠人群密度块补足

## 类型2 · 事件/叙事（主源：万物生第二集）

### 填空工作流（步骤3预检+3.5元素清点·本类专属）
```
【读原文】万物生第二集「江流逃跑段」/「地龙袭击段」
【AI跑偏清单·选+补】☐跳过过程 ☐动作缺失 ☐物理失真 ☐无过渡突变画不出 ☐自作聪明加过渡 ☐其他__
【加密位置填空】
  物理推演链：__段（如 弹起→爬→摔→再爬→跑，每段独立声效）
  伴随句式：__层（≥4，每层标来源物+空间）
  瞬间焊：__处（动作+音效同帧）
  无过渡突变：__（with no transition no warm-up no anticipation）
  独白节拍对应镜头落点：__
  零反应反差锚：静止__对比剧烈__
  非语言生理反应声：__（如破音惊叫，非台词）
【8维度密度策略】本类=满（最高·万物生7层音轨/8+元素/hex精确/50%中英/35mm+T1.4/Wind满级/空间极高）
```

**AI跑偏路径**：AI默认跳过过程——动作缺失、物理失真、自作聪明加过渡

**防跑偏策略**：
1. 物理推演+伴随堆叠：事件触发→画面所有可见元素逐个物理反应（伴随98次实证）
2. 瞬间焊：「X的瞬间Y」把动作和音效焊在同一帧（瞬间64次实证）
3. 时间锚逐次升级：从远→近、从环境→主体、从静→动（不均匀撒）
4. 运镜连续因果：起点→方向→过程中画面变化→终点（不是端点描述）
5. 中英双语锁突变：中文给意图+英文给形式约束（violently snaps+explosive motion+single instant）

**3个必写句式**：
- 「[事件]的瞬间，[音效]」（瞬间焊，声画同帧）
- 「伴随[来源物]的[质感][声音]、[来源物]由远及近的[声音]、[远处][声源]穿透[声场]」（伴随堆叠≥4层）
- 「约[X]秒[事件A]。约[Y]秒[事件B]。约[M]秒第二次[同类事件]这一次[更长/细节差异]」（时间锚逐次升级，2026-08-05改：约X秒为万物生主流）

**原文例句**：
> 「2秒静默对视的最后一刻,江流突然被吓得猛地一个全身哆嗦then violently snaps from completely still to explosive motion in a single instant...with no transition no warm-up no anticipation没有任何过渡没有任何预动作没有任何前摇」

为什么好：三重否定焊死防AI加过渡；双语互锁防单语理解偏差。

**加密位置**：事件触发瞬间/人物画面位置/体型比例/音效层/眨眼呼吸微动
**不加密位置**：STYLE LOCK/视觉锚定引用/硬切转场/台词内容（外部资源能承担）
**AI边界**：突变AI做不到（会自动加0.3秒过渡），必须三重否定焊死；"从静到爆"的极端反差AI做不到，必须双语锁定

## 类型3 · 打斗/高动态（主源：打斗参考+武器打斗）

> ⚠️ **类型3必须先判定子类3a/3b**——快打斗和慢打斗的密度策略完全相反，错用必翻车：
> - **3a·快节奏打斗**（武侠快剪/极限闪避/蒙太奇/极速攻防）→ 动作简+镜头语言密+物理链只在关键结果时写
> - **3b·慢节奏打斗**（叙事片中的打斗/仪式动作/单招详展）→ 万物生级密度+逐部位物理链+微表情
> 子类判定看"动作速度意图"——快到看不清完整招式=3a；可看清每招每式=3b

### 子类3a·快节奏打斗（主源：武器打斗223KB·港式武侠快剪）

**核心原则（武器打斗223KB实证）**：
- **动作简写，结果详写**——"侧闪、沉肩、转胯、滑步、低头、贴身换位、擦身反击"一句话扫过
- **禁止逐部位物理链**——快打斗AI一写细就画慢。"震飞出去→摔进泥水→翻滚两圈"事件级即可，禁"右脚→左膝→臀→背"分解
- **禁止慢动作/定格/蓄力等待**——原话"无慢镜头、无定格、无摆姿势、无蓄力等待"
- **追求"看不清完整动作但能看懂攻防结果"**——原话"快到看不清完整招式，只看到剑影一闪、恶徒惨叫、身体倒下"
- **倒地/撞击时才写完整物理过程**——只在关键状态变化时逐部位（如"右脚先向后滑动→左膝撞到泥地→臀部坠落→后背落地→头发惯性散开"），普通攻防禁写

### 填空工作流（步骤3预检+3.5元素清点·3a专属）
```
【读原文】武器打斗223KB「港式武侠快剪段」/打斗参考「科幻武打长镜头段（选慢节奏段对照）」
【AI跑偏清单·选+补】☐穿帮（姿势漂移/空间重叠）☐武器穿模 ☐服装破损不连续 ☐动作画慢 ☐表情失控 ☐血腥越界 ☐对白时间表错乱 ☐其他__
【加密位置填空·见SKILL.md打斗专项填空】
  防穿帮节点：站位连续性__半圆包围__空间关系锁三段__
  武器穿模清单：刀不穿__剑不穿__手不穿__
  动作顺序链：A→B→C→D（只列事件节点，禁关节级分解）
  倒地/撞击物理过程链：__（仅在关键结果时逐部位写，普通攻防禁）
  对白时间表（有对白时）：0.X秒级精度+对白与笑声/动作约束（台词前__台词后__）
  服装破损固定：位置__+三禁（不恢复/不扩大/不换装）
  表演克制：不嚎哭__不抽泣__不扭曲__
  零反应反差锚：静止__对比剧烈__
  快剪节奏链：急推__→甩镜__→贴身跟拍__→低机位__→动作匹配剪辑__→短蒙太奇快切__
【8维度密度策略】3a专属：
  ①音轨：4-6层（不是万物生5-9层）+对白时间表精确到0.X秒
  ②元素：5-8个，关键防穿帮节点加密描述
  ③色值：关键元素带hex（不是每元素都带）
  ④中英混用：镜头语言用英文（whip pan/quick tilt/dolly zoom）+动作结果用中文
  ⑤比喻：1-2处（剑光/沙尘/血雾意象锚）
  ⑥技术参数：35mm胶片+光比明确+焦段
  ⑦Wind anchor：环境可见效果（雨幕/沙尘/落叶被动作带起）
  ⑧空间位置：防穿帮节点必须锁三段（体貌+位置+动作）
  本类密度策略=关键节点密+普通攻防简（非均匀万物生级）
```

**AI跑偏路径（3a）**：AI画慢（写细就慢）/穿帮（姿势漂移/空间重叠）/对白不同步/服装自动修复/血腥越界

**防跑偏策略（3a·两极分化）**：
1. **普通攻防极简**：动作一句话+结果一句话，禁物理因果链，镜头语言独立成行
2. **防穿帮节点极密**：变身/姿势保持反复重述3次+空间站位三重锁定（体貌+位置+动作）+服装破损快照+对白时间表精确0.X秒
3. **镜头语言控制节奏**：急推/急拉/甩镜/低机位/动作匹配剪辑/短蒙太奇快切/贴身跟拍，独立成行标注
4. **禁止慢动作谱系**：除非剧情需要（如子弹时间声明），否则全片无慢镜头
5. **负面约束**：「不要夸张特效/CG/能量光效」精准堵动漫化倾向
6. **声音独立段**：撞击声/金属碎裂/地面震动，与画面分离标注
7. **武器空间约束**：不写轨迹写「结果+意象」（「刀锋切雨」「火星混着雨水炸开」）

**3a的3个必写句式**：
- 「[谁]+[动作]+[结果动词]，[结果分解≥2句]」（一动作一结果，禁因果链）
- 「[谁]保持[姿势]，[变化]，（保持[姿势]）」（防穿帮节点反复重述姿势）
- 「快到看不清完整招式，只看到[剑影/拳影/刀光]+[惨叫/倒下/崩飞]」（快打斗的观感锚定）

**3a原文例句**（武器打斗223KB实证）：
> "整组动作不是花哨摆招，而是疯狂乱砍式的高速杀伤，观感要像男主在人群中来回穿梭切开对手，快到看不清完整招式，只看到剑影一闪、恶徒惨叫、身体倒下"

> "采用急推、急拉、甩镜、动作匹配剪辑、贴身跟拍、低机位、突然变轴和极短蒙太奇快切"

> "对白时间表：0.5—1.7秒领头恶徒"跑啊，怎么不跑了？" ...禁止为了塞台词而加速语音、吞字、重叠台词或出现口型与声音不同步"

为什么好：3a的密度不在动作链（动作简），在对白时间表（0.X秒精度）+空间防穿帮（三重锁）+镜头节奏链（快剪标注）+禁止清单（具体到"禁止四名恶徒同时抓住"）。

**3a加密位置**：对白时间表/防穿帮节点/服装破损/空间锁定/镜头节奏链/禁止清单
**3a不加密位置**：普通攻防动作/武器轨迹/AI有先验能做好的部分
**3a AI边界**：AI有快打斗先验，写多是负担（实测：加物理因果链→AI画慢）；防穿帮节点必须加密

### 子类3b·慢节奏打斗（主源：万物生第二集升格射箭段+叙事片中的打斗段）

**核心原则**：
- **动作详写**——每招每式可见，物理链逐部位分解
- **可慢动作/定格**——升格/子弹时间/呼吸收可用
- **万物生叙事密度**——5-9层音轨+10+元素全描述+hex+比喻2-4处+Wind可见效果满级
- **微表情精度**——特写级精确（眉间/眼轮匝肌/下颌/泪水积聚停顿半秒）

### 填空工作流（步骤3预检+3.5元素清点·3b专属）
```
【读原文】万物生第二集「升格射箭段」/万物生两集叙事打斗段/打斗参考「科幻武打长镜头慢节奏段」
【AI跑偏清单·选+补】☐动作假（无重量感）☐穿帮 ☐武器穿模 ☐慢动作过度 ☐表情失控 ☐其他__
【加密位置填空·见SKILL.md打斗专项填空】
  防穿帮节点：站位连续性__半圆包围__空间关系锁三段__
  武器穿模清单：刀不穿__剑不穿__手不穿__
  动作顺序链：A→B→C→D（每招详写）
  完整物理过程链：__（每个关键动作都逐部位分解，如右脚滑→左膝撞地→臀坠→背落→发散）
  服装破损固定：位置__+三禁
  表演克制：不嚎哭__不抽泣__不扭曲__
  零反应反差锚：静止__对比剧烈__
  慢动作谱系：升格分阶段__/全冻结__/子弹时间声明__
【8维度密度策略】3b专属：
  ①音轨：5-9层（万物生级）+每层标空间位置
  ②元素：10+个全描述+位置+色值
  ③色值：每元素hex精确
  ④中英混用：STYLE LOCK+运镜+动作精度处用从句（30-50%）
  ⑤比喻：2-4处"像/如"锁形态
  ⑥技术参数：焦段+光比+胶片
  ⑦Wind anchor：风/光/粒子可见效果满级
  ⑧空间位置：精确到百分比
  本类密度策略=万物生级均匀满密度
```

**AI跑偏路径（3b）**：动作假（无重量感）/穿帮/慢动作过度/表情失控

**防跑偏策略（3b·万物生级）**：
1. 物理链逐部位分解：每个关键动作都写完整顺序（右脚滑→左膝→臀→背→发散）
2. 结果分解≥2句：命中部位崩坏/飞溅/瘫软/环境痕迹/镜头反应
3. 微表情精度：特写精确级（呼吸/眉间/下颌/泪水积聚停顿半秒）
4. 慢动作谱系明确：升格分阶段/全冻结/子弹时间，独立声明
5. 万物生级密度均匀分布：音轨5-9层+10+元素+比喻2-4处+Wind满级

**3b的3个必写句式**：
- 「[谁]+[动作]+[结果动词]，[结果分解≥2句]」（一动作一结果，3b可加物理链）
- 「[第N秒]，[动作事件]，[物理链逐部位]」（时间锚+物理链）
- 「[谁]保持[姿势]，[变化]，（保持[姿势]）」（防穿帮节点反复重述姿势）

**3b原文例句**（万物生第二集升格段）：
> "第二秒远景声浪渐响→第三秒人物凝固→第七八秒人群涌入→第十秒前景遮挡"（时间锚逐次升级）

> "伴随挂件碰撞clink、鼓点由远及近thud thud、人群声浪、转头时挂件瞬时撞击声"（音效4层堆叠）

**3b加密位置**：物理链/微表情/慢动作谱系/环境动力统一/景深拉焦

> 「铁匠的体型异常巨大,他在画面中的纵向高度从画面最顶部一直延伸到画面最底部...紧贴在他摊位的左右两边各有一个正常体型的部落摊主...他们的头顶仅仅达到铁匠的腰部位置」

```
【读原文】万物生第二集「正反打段」/切镜头版「外景室内硬切段」
【AI跑偏清单·选+补】☐乱接 ☐越轴 ☐跨镜不一致 ☐硬切生硬 ☐眼神不延续 ☐其他__
【加密位置填空】
  环绕弧线正反打不越轴：__个正反打同用一条想象弧线+机位跳对侧+旋转方向__不变+不越轴线
  声音匹配剪辑：在声音最__瞬间HARD CUT+声音连续掩盖画面硬切
  画外音跨硬切连续：台词未说完即切镜__
  引子帧1秒+继承眼神：__
  自然眨眼防呆滞：__
  末段戛然而止：全部音效瞬时消失无渐弱__
  跨镜共享前景锚：__
  三分构图+朝向统一：__
【8维度密度策略】本类=满（切镜头3-4层音轨/5-7元素/10+hex/极高中英/3-4比喻/机型+对标/Wind规则化/空间极高轴线）
```

**AI跑偏路径**：AI乱接/跨镜不一致

**防跑偏策略**（用户偏好叙述型结构，切镜头策略有限融入）：
1. 真硬切点保留高密度：HARD CUT标记+剪辑语法命名（声音匹配/视线匹配/动作匹配）+触发点精确
2. 叙述流保持中低密度：用「画面顺势落到」代替HARD CUT视线匹配，叙述感保留
3. 跨镜一致性锚必须补：音轨/巨物/色卡重复密度（叙述型最容易丢的）
4. 正反打用对话弧线统一：不分镜，写「两人隔着X一来一往，镜头始终沿同一条顺时针弧线缓缓滑移」

**3个必写句式**：
- 「在[声音/动作]到达最饱满的瞬间，画面发生硬切HARD CUT[匹配类型]剪辑」（硬切标记+语法命名+触发点）
- 「[笑声/声音]从[空间A]延续进[空间B]的[角色]脸上——声音的连续性掩盖了画面的硬切」（音轨跨镜连续）
- 「两人隔着[前景元素]一来一往，镜头始终沿同一条[方向]弧线缓缓滑移，不越轴」（正反打共用弧线）

**原文例句**：
> 「在刘回的笑声爆发到达最饱满音量的瞬间，画面发生硬切HARD CUT声音匹配剪辑...笑声在声音轨道上是连续不间断的，从外景的画外音直接接续到室内画面里刘回正在张嘴大笑的状态，声音的连续性掩盖了画面的硬切」

为什么好：把"剪辑机制"告诉AI——不是描述故事，是描述音轨工程。AI看到会知道生成时不能让笑声断、不能加fade。

**加密位置**：剪辑点（HARD CUT前后一句）/音轨底层/背景巨物
**不加密位置**：对话段/动作描写（避免压垮AI）
**AI边界**：单镜内音轨连续AI做得到；跨HARD CUT两段独立生成时，AI难保证音轨严格接续，只能保证两段各自状态正确。

## 附A · 不像AI 8检查维度（所有段触发 · 步骤4d核验闸D层）

> 业界"不像AI"10要素中AI做得到的8条（皮肤四层/景深拉焦为本次补缺）

```
① 环境动力统一：风→所有元素同步反应同一力（防PPT感核心）
   检查：画面里有风吗？风影响的元素都写了同步反应吗？
② 动作同步反应：主要动作+同步细节动作+衣物发丝物理（防动作假）
   检查：主角动的时候，衣服/头发/随身物有同步反应吗？
③ 景深/拉焦：非全清晰，近/中/远三层衰减 或 rack focus（补缺）
   检查：画面全清晰吗？有景深层次吗？
④ 光影因果链：光源+方向+阴影一致+反射呼应
   检查：光源声明了吗？阴影方向和光源一致吗？
⑤ 镜头逻辑：推近-停稳-遮挡收尾（防镜头乱飘）
   检查：运镜有起幅落幅吗？还是飘的？
⑥ 材质细节：类别+磨损/划痕
   检查：物体有材质描述吗？还是"一个桌子"？
⑦ 皮肤四层：纹理/血色/含水含油/光线+禁磨皮（补缺）
   检查：人物皮肤有质感描述吗？还是磨皮感？
⑧ 保留瑕疵：颗粒/暗角/色差/运动模糊（防过度干净）
   检查：画面太干净了吗？有胶片颗粒/暗角吗？
```

## 附B · AI上限3提示（写正文前/诊断时触发 · 步骤4d核验闸F层）

```
① 大面积云/极远全景=AI无真实感锚点→画假
   对策：提示走中景有实物参照，避免极远全景+大面积云
② 人物"从无到有"出现=AI做不到
   对策：写"始终在画面中"，不写"从远处走来进入画面"
③ 万物生级物理推演（发丝成束那种精度）=AI和人类都做不到
   对策：不追精度追策略，在AI容易跑偏的位置加密即可
```

## 附C · 旁白速率匹配风格（补充）
