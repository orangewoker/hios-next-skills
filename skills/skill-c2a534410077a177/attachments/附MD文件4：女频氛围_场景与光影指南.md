# 附MD文件4 | 女频氛围·场景与光影指南

## #做什么

本模块为女频短剧漫剧的场景与光影专属指南，全题材通用。

解决AI生成女频短剧时最容易出现的场景廉价感、光影不统一、氛围表达不当等问题。

本模块只规定场景空间、光影色调、氛围营造的规则，不替代主SKILL的流程调度、戏剧诊断与导演视觉语法库的镜头语言规则。

## #需要什么输入

**最少提供：**

- 故事题材：现代 / 古装 / 科幻。
- 情绪基调与场景上下文。
- 角色设定与物哀美学方向。
- 目标画面比例：9:16竖屏。

**可选提供：**

- 是否需要输出视频脚本、Prompt清单、视觉方案。
- 上下游分镜、提示词、视觉方案结果。
- 目标时长与制作规格。
- 是否需要中日双语字幕。

## #怎么做

### 一、场景空间（由用户故事决定）

- **现代**：顶层豪华公寓 / 总裁办公室 / 雨夜街角 / 私人电梯内。
- **古装**：深夜府邸 / 落雨庭院 / 华丽宫殿 / 偏僻竹林。
- **科幻**：冰冷的实验室 / 未来私人卧室 / 太空舱。
- 绝对禁止：非专业民国风格、普通马路街景、杂乱背景。

### 二、光影与色调（专业质感）

- 主光源：柔和高光，辅以弱暖黄 / 冷蓝反光，营造专业质感。
- 画面基调：大留白、极度克制的低饱和度。
- 绝对禁止：高饱和商业光效、赛博朋克霓虹光效、过度HDR效果。

### 三、氛围营造（核心心法）

- 通过“将落未落的眼泪”、“半掩的门缝”、“暗夜里的微光”等留白镜头，制造强烈的情绪张力。
- 绝对禁止：直白咆哮、过度落泪、夸张失真的情绪。
- 场景与光影方案必须与【顶级大导演思维】的戏剧张力分析保持一致，不得脱离戏剧需求。

## #产出什么

最终交付：

- 场景空间清单
- 光影与色调方案
- 氛围营造清单
- 负面场景与光影Prompt清单
- 视频脚本、Prompt清单、视觉方案所需的场景与光影依据
- 每一帧均可作为独立海报级别的高清壁纸

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 故事题材不明确：现代 / 古装 / 科幻。
- 场景空间与用户故事设定冲突。
- 用户要求突破场景与光影禁则。
- 用户要求输出视频脚本、Prompt清单、视觉方案，但缺少关键输入。
- 本模块与上游主SKILL、导演视觉语法库或其他附MD规则冲突。
