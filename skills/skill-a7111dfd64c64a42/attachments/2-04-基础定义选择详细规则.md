# 基础定义选择详细规则

## 一、引导策略

### 1.1 推荐式引导（默认）

基于第一阶段识别的商品信息，自动生成推荐方案，用户一键确认或微调：

```
根据您的商品「[商品名]」（品类：[品类]），我推荐以下配置：

📌 视觉路线：[实拍/动画]（根据商品特性推荐）
🎨 风格：[首推风格]（[推荐原因，如"该品类最常用/最适合展示材质"]）
🎯 广告目标：[默认推荐促销转化]
👥 受众：[根据品类推测]
📱 投放渠道：[默认推荐抖音9:16]
⏱ 时长：[默认推荐15秒]（15-30秒是广告主流时长，初次建议15秒起步）
🔄 转场：[默认推荐硬切+溶解混合]
👤 人物出镜：[根据品类推荐，如美妆/服饰推荐"是"，数码/家电推荐"否"]

确认使用以上配置？或告诉我需要调整哪些项。
```

### 1.2 逐项引导（用户要求自定义时）

按以下顺序逐项引导，每项给出 2-3 个推荐选项 + 简要说明：

```
1. 视觉路线 → 2. 风格 → 3. 微调 → 4. 广告目标 → 5. 目标受众
→ 6. 投放渠道/比例 → 7. 时长 → 8. 转场风格 → 9. 人物出镜 → 10. 模式
```

每项引导格式：
```
[参数名]：[说明]
推荐：[首推]（[原因]）
备选：[备选项1]（[适用场景]）/ [备选项2]（[适用场景]）
您的选择？
```

## 二、投放渠道与画面比例

### 2.1 渠道规格表

| 投放渠道 | 画面比例 | 分辨率建议 | 视频时长建议 | 注意事项 |
|---------|---------|-----------|------------|----------|
| **抖音** | 9:16（竖屏） | 1080×1920 | 5-30秒（15秒最优） | 前3秒必须有强吸引力；避免顶部/底部安全区放关键信息 |
| **小红书** | 9:16（竖屏）或 3:4 | 1080×1920 或 1080×1440 | 15-60秒（种草类30秒内） | 重视封面图质量；标题文字要大且清晰 |
| **朋友圈** | 1:1（方形） | 1080×1080 | 5-15秒（短平快） | 前1秒抓眼球；文字信息精简 |
| **电商横屏** | 16:9 | 1920×1080 | 15-60秒（详情页可用长视频） | 适合商品详情页、主图视频 |
| **视频号** | 9:16（竖屏）或 16:9 | 1080×1920 或 1920×1080 | 15-60秒 | 中老年用户偏多，字体宜大 |
| **快手** | 9:16（竖屏） | 1080×1920 | 7-30秒 | 真实感强，避免过度精致 |
| **B站** | 16:9（横屏） | 1920×1080 | 30-120秒 | 可接受更长内容；需要信息密度 |
| **自定义** | 用户指定 | 按用户需求 | 按用户需求 | 需明确告知分辨率和比例 |

### 2.2 安全区域规则

不同平台的关键信息显示区域不同，生成画面时需注意：

| 平台 | 顶部安全区 | 底部安全区 | 左右安全区 |
|------|-----------|-----------|-----------|
| 抖音9:16 | 顶部15%（被昵称/标题遮挡） | 底部20%（被评论/互动栏遮挡） | 左右各5% |
| 小红书9:16 | 顶部10% | 底部15% | 左右各5% |
| 朋友圈1:1 | 顶部5% | 底部5% | 左右各5% |
| 电商16:9 | 顶部5% | 底部5% | 左右各3% |

**规则**：商品主体、品牌logo、关键文案必须放在安全区域内。

## 三、时长选择策略

> 💡 **行业提示**：15-30秒是商品广告视频的主流时长。15秒适合信息流投放（抖音/小红书），节奏紧凑；30秒适合电商详情页和种草视频，内容更完整。初次使用建议从15秒起步。

### 3.1 时长与内容密度对照

| 时长 | 内容密度 | 适合场景 | 镜头数 | 节奏要求 |
|------|---------|---------|--------|---------|
| **5秒** | 极简：1个核心卖点 + 1句口号 | 朋友圈广告、信息流插播、品牌logo展示 | 1-2个 | 极快，瞬间冲击 |
| **10秒** | 简洁：1个场景 + 1个卖点 + CTA | 短视频信息流、开屏广告 | 2-3个 | 快速，无废话 |
| **15秒** | 标准：开场+1-2个卖点+CTA | 抖音/小红书信息流、电商主图视频 | 3-5个 | 紧凑，节奏感强 |
| **30秒** | 完整：开场+2-3个卖点+场景展示+CTA | 电商详情页、品牌宣传、种草视频 | 5-8个 | 张弛有度 |
| **60秒** | 深度：故事/场景+多卖点+情感共鸣+CTA | B站/品牌故事、深度种草 | 8-15个 | 可有叙事节奏 |

### 3.2 时长与广告目标匹配

| 广告目标 | 推荐时长 | 原因 |
|---------|---------|------|
| 品牌曝光 | 5-15秒 | 短平快，强化记忆点 |
| 促销转化 | 15-30秒 | 足够展示卖点+营造紧迫感 |
| 新品上市 | 15-30秒 | 需要展示产品细节+差异化 |
| 活动引流 | 5-15秒 | 快速传达活动信息+行动号召 |

### 3.3 时长分配原则

- **片头**（品牌/开场）：不超过总时长的 1/4
- **主体内容**（卖点展示）：占总时长的 1/2 ~ 2/3
- **片尾**（CTA/行动引导）：不超过总时长的 1/4
- **片头+片尾合计**：不超过总时长的 1/3

示例（15秒广告）：
- 片头：≤3秒
- 主体：8-10秒
- 片尾：≤3秒

## 四、广告目标详解

### 4.1 品牌曝光

**核心目的**：让用户记住品牌/产品名称和形象
**创作策略**：
- 品牌 logo/名称至少出现 2 次（片头+片尾）
- 视觉风格与品牌调性高度一致
- 文案侧重品牌理念/slogan，而非具体卖点
- 节奏舒缓，注重氛围营造
- 配音风格：沉稳/大气/温暖（匹配品牌调性）

### 4.2 促销转化

**核心目的**：激发购买行为，提升转化率
**创作策略**：
- 前 3 秒必须亮出核心卖点或价格优势
- 强调「限时」「限量」「优惠」等紧迫感元素（需合规）
- 展示产品使用效果/前后对比
- CTA 明确：「立即购买」「点击下方链接」
- 配音风格：热情/有感染力/节奏快

### 4.3 新品上市

**核心目的**：让用户了解新品、产生兴趣
**创作策略**：
- 强调「新」「首发」「升级」等概念（需合规）
- 突出与旧款/竞品的差异化卖点
- 可加入开箱/揭幕的仪式感
- 细节展示要到位（材质/工艺/功能）
- 配音风格：新鲜感/期待感/科技感

### 4.4 活动引流

**核心目的**：引导用户参与特定活动
**创作策略**：
- 活动信息（时间/地点/参与方式）必须清晰
- 视觉风格与活动主题匹配
- 营造氛围感和参与感
- CTA 指向活动页面/入口
- 配音风格：兴奋/邀请感

## 六、转场风格详解

### 6.1 转场类型说明

| 转场类型 | 视觉效果 | 适用风格 | 适用节奏 | 注意事项 |
|---------|---------|---------|---------|----------|
| **硬切** | 直接切换，无过渡 | 所有风格 | 快节奏/标准信息流 | 最常用；不适合同角度连续切换 |
| **溶解** | 前一画面淡出+后一画面淡入 | 生活方式/自然清新/日系 | 舒缓/中等 | 适合场景变化大的镜头间过渡 |
| **划像** | 画面从一侧推入替换 | 促销爆款/街头潮流 | 快节奏 | 方向需一致（如统一从左向右） |
| **缩放** | 放大/缩小过渡 | 3D科技/新品首发/赛博 | 中快节奏 | 适合从全景到特写的过渡 |
| **遮罩转场** | 利用画面中物体遮挡实现转场 | 所有风格（高级感） | 中等 | 需要画面构图配合，制作复杂度高 |
| **无转场** | 镜头间完全独立 | 产品展示/简约极简 | 任意 | 每个镜头自成一体 |
| **混合** | 组合使用以上多种 | 需要变化感的长视频 | 按内容变化 | 需保证整体节奏统一 |

### A.1 品类→人物出镜推荐

| 电子产品 | 否（推荐） | 产品本体展示为主 | 如需人物：科技商务风 |
| 数码配件 | 否 | 产品特写为主 | 如需人物：简约科技 |
| 家居日用 | 是（可选） | 使用场景增强生活感 | 居家温馨 |
| 家电 | 是（可选） | 操作演示/效果对比 | 现代简洁 |

| 珠宝饰品 | 是（推荐） | 佩戴效果展示 | 优雅/高端 |

| 文具办公 | 否 | 产品特写为主 | 如需人物：商务知性 |
| 健康养生 | 是（可选） | 使用场景/效果展示 | 健康自然 |

### A.2 人物来源与设定流程

用户选择"人物出镜=是"后，进入人物设定子环节：

**来源A：用户上传参考图**
1. 用户上传 1-3 张人物参考图
2. Skill 分析参考图，提取人物特征：
   - 面部特征（脸型/五官/妆容风格）
   - 发型发色
   - 体型比例
   - 整体气质/风格
3. 生成**单张人物形象图**（正面半身/全身）→ 展示给用户确认人物造型是否满意
   - **风格默认沿用商品已选定的视觉路线和风格预设**，用户可自定义覆盖
   - ⚠️ **纯白背景（铁律第6条）**：背景必须为纯白色（#FFFFFF），画面中只有人物本身，没有任何其他元素、道具、装饰
   - 用户不满意可要求调整，满意后进入下一步
4. 用户确认后，生成**人物三视图**（正面、正侧面、背面），用于锁定人物外观一致性
   - 基于已确认的人物形象图生成
   - ⚠️ 不生成表情动态，三个视角仅用于锁定人物外观
   - ⚠️ 三视图背景同样必须为纯白色（#FFFFFF）
5. 生成**人物描述卡**（结构化文本）：
   ```
   【人物描述卡】
   外貌：[面部轮廓/五官特点/发型发色/肤色]
   体型：[身高比例/体态特征]
   服装：[与产品风格匹配的穿着描述]
   气质：[表情基调/整体氛围]
   风格关键词：[用于prompt的一致性关键词]
   视觉参考：[参考图路径/编号]
   ```
6. 用户确认单张人物形象图 + 人物三视图 + 人物描述卡 ✓

**来源B：AI 生成虚拟人物**
1. Skill 基于以下参数生成人物方案推荐：
   - 品类 + 商品风格预设（默认继承，用户无需额外选择）
   - 目标受众（用于推断人物年龄/性别/气质方向）
   - 如用户有特殊需求，可自定义人物风格覆盖默认
   - 推荐 2-3 个人物方案（不同风格方向）
2. 每个方案包含：
   - 人物设定描述（年龄/性别/气质/穿着风格）
   - 推荐理由（为什么适合这个产品）
3. 用户选择方案 → 可微调（如"再年轻一点""换成熟气质""穿休闲装"）
4. Skill 生成**单张人物形象图**（正面半身/全身）→ 展示给用户确认人物造型是否满意
   - **风格默认沿用商品已选定的视觉路线和风格预设**
   - ⚠️ **纯白背景（铁律第6条）**：背景必须为纯白色（#FFFFFF），画面中只有人物本身，没有任何其他元素、道具、装饰
   - 用户不满意可要求调整，满意后进入下一步
5. 用户确认后，生成**人物三视图**（正面、正侧面、背面），用于锁定人物外观一致性
   - 基于已确认的人物形象图生成
   - ⚠️ 不生成表情动态，三个视角仅用于锁定人物外观
   - ⚠️ 三视图背景同样必须为纯白色（#FFFFFF）
6. 生成**人物描述卡**（同来源A格式）
7. 用户确认单张人物形象图 + 人物三视图 + 描述卡 ✓

### A.3 人物风格继承规则

**默认继承**：人物风格自动继承第二阶段已确定的商品视觉路线和风格预设：
- 实拍质感 → 人物为写实真人模特
- MG动画 → 人物为MG扁平风格人物
- 3D卡通 → 人物为3D卡通渲染人物
- 2D手绘 → 人物为手绘风格人物
- 赛博科幻动画 → 人物为赛博风格人物
- 国漫动画 → 人物为国漫风格人物
- 具体风格关键词（如"日系治愈""高端奢华"等）也一并继承

**用户自定义**：用户可明确覆盖默认风格，如：
- "人物用赛博朋克风，产品保持简约极简"
- "人物要写实风格，不要动画"
- 此时人物风格关键词独立于商品风格，但整体画面色调仍需协调

**色彩协调**：人物服装色调与产品品牌色/画面色调协调，避免冲突

**下游传递**：
- 人物描述卡 + 人物形象图 + 人物三视图作为**视觉锚点**，传递给：
  - 第七阶段（场景图生成）：每个涉及人物的镜头，prompt 必须引用人物描述卡、人物形象图和人物三视图
  - 第九阶段（视频生成）：人物动作/表情需符合人物描述卡的气质基调
- 场景图中人物与产品同框时，需确保：
  - 人物不遮挡商品主体
  - 人物动作与商品互动逻辑合理（如手持/使用/展示）
  - 人物与商品的比例关系正确

### A.4 人物出镜引导话术

```
是否需要人物出镜？

推荐：[是/否]（[推荐原因，如"美妆品类建议有模特展示上脸效果"]）

如果选择"是"，请选择人物来源：
A. 上传人物参考图（1-3张）
B. AI生成虚拟人物（我会根据您的产品风格推荐2-3个方案）

💡 温馨提示：涉及人物形象的内容（含AI生成的写实人物和上传的真人参考图），平台审核会比纯商品广告更严格，可能需要多次调整。如果担心审核问题，建议选择"否"使用纯商品+场景方案，或选择非写实风格（如3D卡通、2D手绘）来降低审核风险。
```

## 八、基础定义确认环节

### 8.1 确认内容

所有参数确定后，向用户展示完整的配置摘要：

📋 广告配置确认：

商品：[商品名称]

🎨 风格：[选定风格] + 微调：[微调项]

🔄 转场：[转场风格]
👤 人物出镜：[是（附人物描述卡摘要）/ 否]
⚙️ 模式：[快速/精细]

### 8.2 修改规则

- 确认前：用户可以修改任意参数
- 确认后进入下一阶段：仍可回溯修改，但需提醒"修改[某参数]可能影响已完成的[下游环节]，是否确认修改？"
- 修改风格 → 三视图需重新生成
- 修改时长 → 剧本需重新调整
- 修改投放渠道 → 画面比例变化，三视图/场景图需重新生成
