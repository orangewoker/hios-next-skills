## 二、@引用完整模板

**角色引用**： `@[hash] 作为[角色名]视觉锚定+保持外观完全一致+[关键特征(年龄/服饰/武器)]`

**色卡引用**（必带全部字段）：

```
@[hash] 作为整段画面色卡锚定+所有色彩严格按色卡[N]色执行+不可偏离色板
+本段重点调用[hex1][色名]到[hex2][色名]的[材质/环境]主色
+[材质1][hex][色名]
+[材质2][hex]到[hex][色名]阴影层
+[材质3][hex]与[hex][色名]
+[hex][色名]作为[位置]视觉钉子
```

N = 色卡实际颜色数（13色/22色/24色等），不可留空。

**场景引用**： `@[hash] 作为[场景名]环境视觉锚定。`

**道具引用**： `@[hash] 作为[道具名]道具锚定+严格按六视图执行尺寸结构+[色码]`

**音频引用**（有对话时必写）： `@[音频hash] 作为[角色名]声音锚定。`

**群像多样性约束**（画面≥3个非主要角色时，嵌入 @引用行）： `@[人群hash] 作为人群服装视觉参考，人群中每一个人的长相、年龄、性别、体型都各不相同，共享同一套服装语言。`

**兽群/虫群动作参差声明**（非人角色群）： `[兽群]各自拱地、挪移、掀翻篷帐，动作各不相同、彼此不齐整、此起彼伏、无一同步。`

**①范围限定**（参考图与剧本冲突时）： ✅ `@[hash] 仅作为地龙的鳞甲、质感与形象的视觉锚定，地龙的姿态以本段文字描述为准。`

## 四、打击三要素·自然嵌入版（红线）

**每个打击 = 三要素自然嵌入动作句，不用固定模板句：**

```
① 结果级动词（打飞/干飞/豁开/缠死/扯飞/捏爆——见ref03动词分级表）
② "拟声词引号"（"clang""duang""嗖——"）
③ 镜头震（（镜头猛地一震/一顿/一抖）括号 或 短句"画面猛地一震"）
```

✅ 自然嵌入（万物生/渊式）：

- 「长枪脱手砸在湿石板上"clang"一声脆响、镜头猛地一震」
- 「凛翼手掌精准捏住渊蜓头部——手指合拢，头壳碎裂，复眼爆裂，暗绿色体液从指缝间炸裂溅出」
- 「一记重拳把它**干飞**出画，金属挥击与甲壳碎裂的脆响**同时炸开**、画面**剧烈一顿**」 （"同时炸开"模板句降级为可选强调写法，不强制逐字使用）

**结果分解铁律**：动作一句带过，**结果分解≥2句**——命中部位的崩坏/飞溅/瘫软/环境痕迹/镜头反应。细节预算给后果，不给过程。 ✅「精准捏住头部（一句）→ 头壳碎裂、复眼爆裂、体液从指缝炸裂溅出、身体瘫软、松手、残骸坠落（分解）」 ❌「重心移至右脚，腰腹带动，肩随后，头最后跟随（过程分解）→ 触及（结果一句）」

**逐次触发规则**：震动在每次打击发生处就地标注，不做全局枚举清单。 **连续打击**：攻击方式与命中部位逐次不同（胸→头→腹；穿过→惯性转向→被扑反杀），靠惯性焊接句衔接（"推进没有减速/拔枪的瞬间利用惯性转向"）。

## 五、节奏括号与变速模板（红线）

### 打斗/动作段：节奏括号指令制（替代独立节拍行）

节奏直接嵌在动作句后，每子镜头≥1处： **（动作快速）（慢动作）（停顿）（镜头猛地一震）（镜头摇晃）（镜头停稳）**✅「铁傀蹬地爆发，沿直线猛冲向云游（动作快速，每一步落地镜头短促一震）」 ✅ 入口行同时带节奏定性词：「中近景，侧面、轻微手持晃动跟拍的机位，快节奏。」

**slow隔离规则**：入口含slow时，本镜第一个动作句必须以（动作快速）或L4速度词开头，防止slow从运镜传染到角色动作。

### 移动/静态段：节拍递进结构（保留）

行走/长镜段用节拍递进×景别变化双螺旋（见SKILL.md 五要素）： ✅ 万物生行走段：「退行速度略慢于丹眉迈步速度，景别一档档稳定收紧——起幅腰部以上→胸部以上→肩部以上→特写」+ 事件逐拍升级（龙虱→鞋子→逃命胡人）

### 动作间隙焊接词（保留）

动作链中禁止"摆造型"间隙，用以下词焊接： **「脚步不停/一刻不停/随即/顺势/不等…/便已」+ 惯性焊接句（利用惯性转向/随惯性甩出）**✅「铁傀一把抓空，随即拧身再扫——没有间隙没有重摆架势」

### 子弹时间→加速回正（F型入口完整模板）

```
慢速进入：时间像被拉住一样慢下来，X在慢速中极缓慢地Y。
加速回正：慢速里时间猛地加速回正、一切骤然提速→[动作加速完成]
重回慢速：X完成后画面再次切入子弹时间的极慢速…
```

⚠️ 子弹时间必须有"唯一动元素"（符箓亮起/悬浮血珠）和明确的"回到正常速度"标记。

## 六、役表演锁定模板（方案A6修正）

**固定头部**：`Character performance lock:`（英文头部必写）

### 三档气质模板

**A型·克制型（万物生丹眉式）**： `=沉稳克制的气质，身体有最小反应（[写具体微反应]），但面部表情克制、情绪不外显。动作后立即回基线，不滞留、不重复。`✅「丹眉=沉稳克制的少女气质，脚下踉跄稳住重心，但神情依旧冷淡克制。她伸手拈了拈湿衣袖，又看了看手——生活化的小动作证明她是活人」 ❌「丹眉=全程零反应零情绪，身体完全静止」——锁全身，生成木偶

**B型·常态型**： `=[性格描述]，该慌时慌该稳时稳，自然真实的反应节奏——下意识动作优先于思考反应。`✅「江流=猝不及防的慌乱感，双臂下意识摆动平衡，屏面的青点急促变化，是手忙脚乱的真人反应」

**C型·外放型**： `=[能量描述]，大反应、大动作、情绪外显，无保留。`✅「刘回=狂暴的战斗能量，每一步巨足砸地伴随金属重足的沉闷轰响，每一拳干飞龙虱都用尽全力，无保留」

**克制型人设核心**：「身体有最小反应（证明是活人）+ 表情克制（证明性格）+ 动作后立即回基线（证明内在力量）」

### 克制型补充规则（景别-幅度对照 + 受惊模板）

**景别-反应幅度对照**：景别≥MS（中景及更远）时，「最小反应」必须放大到该景别可见幅度——错半步→横错一整步；偏头→肩线级转开；手指级→手腕级。面部克制在MS以上景别为无效指令（脸不可见），禁止堆砌面部否定句。 ✅「云游=预判式武者气质，闪避幅度刚好让开攻击、没有多余动作——但幅度必须可见：侧身时整个上半身转开、脚下横错一整步，面部保持无表情克制」

**受惊克制版模板**（克制型角色受惊时）： `肩膀瞬间微缩+眼睛快速眨一次+身体本能向后微微一缩——但没有惊叫没有大幅度后退没有夸张表情，旋即回基线`✅ 万物生：「Wednesday-style genuine startle contained within deadpan composure真正受惊但被冷淡气质包裹的小幅惊反应」

**活着声明（万物生式元注释）**：静止角色必须写明"为什么这样是活的"—— ✅「她的身体保持自然的呼吸感——下颌和颈部以上部位随呼吸做出极轻微的起伏，这种呼吸感让她整个人保持活着的状态而不是凝固静止」

## 九、正反打·环绕弧线装置（红线，万物生切镜版原案）

对话段≥3个正反打时，\[STYLE LOCK\]必须声明统一运镜装置：

```
全段[N]个近景特写正反打镜头，同用一条想象中的环绕弧线：镜头自始至终沿同一个
[顺时针/逆时针]方向极缓慢地微微环绕被摄者移动，每个镜头都带着这一抹持续同向的
轻微弧形移动，使画面不至呆板；正反打切换时机位跳到这条弧线的对侧，但环绕的
旋转方向始终保持不变，不越过两人之间的轴线。
```

**每个子镜头**：

- 正打：「\[角色名\]的近景，不居中、偏在画面\[左\]侧，脸朝\[右\]，\[前景元素\]虚焦横切过画面\[位置\]，镜头沿\[顺时针\]弧线极缓慢地微微环绕」
- 反打：「反打，\[对方\]的近景，偏\[右\]脸朝\[左\]。机位跳到环绕弧线的对侧，镜头仍沿同一\[顺时针\]方向极缓慢地微微环绕」
- 复用镜：「反打回\[角色名\]的近景，构图同前、偏\[左\]脸朝\[右\]，前景仍是\[前景元素\]，镜头继续沿弧线微微环绕」

**三要素**：①同一条弧线+同一方向（不越轴）②前景元素每镜重复（尾甲/桌沿虚焦横切）③复用镜用「构图同前」简写。 **≥3人对话**：不用正反打弧线，用群像构图+画外音。

### 匹配剪辑两种（红线，HARD CUT的升级形态）

**视线匹配**： ✅「匹配丹眉向下一瞟的视线，硬切到一个略带俯角的低特写：正蹲跪在沙地上抱着昏迷刘回的女儿的下半身——…」

**声音匹配（声桥/J-cut）**： ✅「在刘回的笑声爆发到达最饱满音量的瞬间，画面发生硬切HARD CUT声音匹配剪辑——切换到室内。笑声在声音轨道上是连续不间断的，从外景的画外音直接接续到室内画面里刘回正在张嘴大笑的状态，声音的连续性掩盖了画面的硬切。」 ⚠️ 切点在声音的**最饱满瞬间**，不是开始也不是结束。

### 画外音纵深事件（对话段可用）

「画外音进行过程中，画面\[区域\]的焦点适时由虚转实、推到\[纵深事件\]」——对白镜不只是脸，纵深里可以演戏。 ✅ 万物生：琉璃画外音求援 → 画面左侧远景焦点由虚转实推到盲可汗吞下铁匠 → 丹眉头几不可察地朝那个方向偏了一下旋即收回。
