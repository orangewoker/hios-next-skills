# 输出契约、强制依赖与完整性闸门

> 本文件属于“短视频带货Skills”多层嵌套版。根目录 `SKILL.md` 负责总控路由；本文件只承载对应能力。执行时必须同时遵守根目录的输出契约、强制依赖和完整性闸门。


## 全局输出内容声明

根据任务模式输出：视频元数据与允许改动清单、产品档案和动态产品变量、人物形象描述及固定三视图提示词、逐帧/镜头级时间轴、逐句微表情与听者反应、完整脚本、完整分镜、每段不超过15秒的 Seedance 2.0 可复制提示词、统一与项目专属负面提示词、关键帧/人物图提示词、创意方向与评分、标题/封面/评论区，以及100分质检和合规检查。用户只要求某一模块时按需裁剪。

该声明是能力全集与展示契约，不代表每个任务无差别输出全部模块；必须由主任务模式决定必选项。用户未使用“只、仅、不要其他”等排他表达时，不得主动缩减主工作流。

## 核心原则：主任务与输出形式分离

任务路由决定“必须分析什么、必须调用哪些模块”；输出形式只决定“最终展示哪些模块”。不能因为用户说“给我提示词”，就把主任务误判成 `PROMPT_ONLY`。

- “帮我拉片、逐帧分析、1:1还原、拆解这个视频”属于主任务要求，优先级高于“给我提示词”。
- 只有用户明确说“只给提示词、不要分析、不要分镜、直接给最终提示词”时，才启用精简输出。
- 即使启用精简输出，底层仍必须完成主任务所需的产品、人物、连续性、分段和合规分析，只是不把全部分析过程展开给用户。

## 输出级别

### FULL｜默认完整输出
触发：用户说“按Skills完整输出、帮我拉片、逐帧、拆解、还原、给脚本和提示词”，且没有明确排除模块。

必须输出当前主工作流规定的全部交付项。不得自行省略人物设定、产品变量、逐帧/镜头级时间轴、逐句微表情、完整脚本、完整分镜、Seedance分段提示词、关键帧提示词、负面提示词或质检。创意方向、标题、封面和评论区按任务模式或用户发布需求加载。

### FOCUSED｜聚焦输出
触发：用户明确指定需要若干模块，例如“只要人物设定＋提示词”“只要分镜和提示词”。

只展示指定模块，但仍执行所有强制依赖；影响成片正确性的必要前置信息必须保留。

### PROMPT_PACK｜提示词包
仅在用户明确出现“只给提示词 / 不要分析 / 不要分镜 / 直接一个提示词”时启用。

仍必须输出：
1. 产品中文名＋动态变量；
2. 只要最终画面有人物，就输出每位人物四项形象描述＋固定人物设定提示词；
3. 时长与分段说明；
4. 可复制 Seedance 提示词；
5. 统一＋项目专属负面提示词；
6. 必要的开始状态、结束状态和跨段连续性。

### DIRECTION_ONLY｜方向策划
仅在用户明确只要方向、栏目、选题、立项概念时启用。未要求脚本时，可不展开人物标准像；一旦输出首条完整样片脚本或提示词，若样片有人物，人物设定自动成为必选项。

### IMAGE_ONLY｜人物图/关键帧素材
仅在用户明确只要人物标准像、三视图、首帧、关键帧或产品场景图时启用。

## 人物模块自动触发器

将 `PEOPLE_PRESENT` 设为真，只要满足任一条件：
- 参考视频中有人物，且用户没有要求全部移除；
- 用户明确要求某类人物出镜；
- 脚本、剧情、口播、采访、街采、送礼、用户反馈等形式需要人物；
- 最终 Seedance 提示词中出现可见人物、卡通角色或拟人角色。

当 `PEOPLE_PRESENT = true` 时，必须调用 `modules/character_performance.md`，并输出：
- 每位人物：人物、年龄、外貌面部描述、服饰描述；
- 每位人物后附固定人物设定提示词；
- 有对白或清晰面部表演时，逐句写微表情、眼神路径、呼吸停顿、动作和听者反应。

禁止因为“用户只提供产品”而省略人物设定。先完成创意与脚本；最终脚本只要有人物，就自动补齐人物模块。

## 完整性闸门

交付前逐项判断：

1. 有参考视频吗？有 → 必须读取视频参数、切点和时间轴。
2. 用户要求逐帧或1:1吗？是 → 必须执行L3逐帧级，不得只给剧情概述。
3. 有产品吗？有 → 必须建立产品档案、变量和连续性状态。
4. 最终画面有人物吗？有 → 必须输出人物设定。
5. 有对白或面部表演吗？有 → 必须逐句微表情＋听者反应。
6. 输出脚本或视频提示词吗？是 → 必须有镜头化/分镜逻辑。
7. 总时长超过15秒吗？是 → 必须拆分提示词，不得压缩剧情。
8. 用户明确“只要”了吗？没有 → 使用FULL，不得主动裁剪。
9. 产品、人物、场景、动作跨镜头连续吗？否 → 不得交付。
10. 已执行统一负面提示词与100分质检吗？否 → 不得交付。
