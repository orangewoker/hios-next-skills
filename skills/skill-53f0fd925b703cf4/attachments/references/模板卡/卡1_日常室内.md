## 层1b 本类骨架清单（写正文前必抄，2026-08-04组1实测新增）
```
本类场景（日常/室内静态）万物生原段里最值得抄的固定骨架，按需提取2-6条：
① 锁空间句：三维坐标+占比+方位（「占画面宽度约六分之一」「纵向从画面最顶部到最底部」）
② 节拍对比句：节拍器式稳定 vs 对比物（「稳定如节拍器般有节奏感的步伐...与剧烈晃动的手持镜头形成强烈对比」）
③ 环境微动句：画面唯一动元素 vs 静物静止（「窗帘边缘气流轻微浮动,是画面中唯一持续运动的元素」）
④ 动作物理后果句：动作自带后果成对写（「脚抬起来的瞬间沙粒簌簌从脚底掉落」）
⑤ 环境反应链句：动作→环境连锁≥2级（「每一次锤落整个铁匠摊的木架都在剧烈颤动,铃铛被震得叮当作响」）
⑥ 空间分层句：纵深/横向/纵向三轴（「画面下方约下三分之二是沙地,上方约上三分之一是天空」）
⑦ 声学属性句：拾音距离+底层声场两层结构（「从室内穿出岩窟门口的轻微闷响和岩壁回声质感」）
本类不抄：对白/常规动作链（AI先验强，抄了浪费）
```

## 层2 11样抄什么（每样配本类原段例句）
```
1.初始状态帧：例「起手画面只有空旷的浅金色沙地...无人入画,持续约2秒」
2.运镜句：例「镜头随她下蹲缓缓向下摇移pan down」（触发+方向+目的）
3.分层句：例「画面下方约下三分之二是大片浅金色沙地...画面上方约上三分之一是烤白的浅金色天空」
4.遮挡关系句：例「杂货商占据画面前景左侧,他举着青铜板的双手占据画面前景」
5.虚实焦句：例「画面上方80%被江流靴子那块heavily blurred严重失焦的flat sole主导」
6.声画绑定句：例「挂件随转头的惯性瞬时摆动撞击发出短促响声」
7.声学属性句：例「音质带有从室内穿出岩窟门口的轻微闷响和岩壁回声质感」
8.动作边界句（否定写正文）：例「杂货商的身体保持在画面前景一侧的位置不动」「不居中」
9.反应链句：例「凝固一瞬→听到声音→面具向身后快速转过→方向→惯性→声响」
10.节拍切分句：例「0-2空镜→2-4坐起→4-6摸手机→6-8表情变→8-10下床」
11.硬切声音延续句：本类写NA（无切镜）
```
