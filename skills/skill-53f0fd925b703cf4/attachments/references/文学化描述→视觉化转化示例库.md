# 文学化描述 → 视觉化转化示例库

> **用途**：本文件帮助将文学化/诗意的文字转化为 AI 视频模型可精准执行的纯视觉描述。 **核心原则**：AI 只能理解"能被相机直接拍下来的信息"——动作、形态、颜色、材质、光影、构图。 声音、触感、情绪、比喻、抽象评价 → 必须转化为可见的物理细节。

---

## 一、五大类非视觉内容速查

类别原文特征不能直接写应转化为**听觉/音效**拟声词、声音描述、听觉感受（轰鸣、咔哒、震耳）❌ `金属咬合，咔哒一声脆响`✅ 物理后果：`金属卡扣结构闭合扣死`**触觉/体感**疼痛、沉重、拉力、酸胀（痛、扯、压、绷）❌ `肩关节被猛地一扯`✅ 外在痕迹：`肩部衣物被拉力扯得变形，肩线倾斜`**心理/情绪**内心活动、情绪名、认知（她知道、专注、恐惧）❌ `不是恐惧，是锁死目标的专注`✅ 动作/微表情：`瞳孔收缩，全身稳定无多余晃动`**比喻/修辞**像、如、仿佛、好似（像旗子、像箭、如钢缆）❌ `像一面被狂风吹起的旗子`✅ 本体特征：`斗篷被气流完全撑开，衣摆剧烈飘摆`**抽象定性**评价类形容词（待发、不可阻挡、精密、震撼）❌ `处于待发状态`✅ 具体细节：`手指紧扣握柄，前臂肌肉微绷，重心下沉`

> ⚠️ **Seedance 适配说明**：转化后的视觉内容直接嵌入叙事正文即可，不需要独立成【音效设计】等模块。Seedance 对嵌入式音效和动作描述的理解力优于独立模块。

## 二、逐类转化对照表

### 第1类：听觉/音效 → 物理后果

❌ 原文（不可直接写入）✅ 转化后画面内容（嵌入叙事）✅ 音效嵌入叙事喉鸣声从极低处轰到可听域，鼓膜都能感到那种压力沙虫破土的冲击波让近处空气产生轻微波纹扭曲，地面沙粒呈环状向外飞溅伴随沙虫破土的低沉轰鸣与沙粒飞溅声金属咬合，咔哒，一声脆响穿透了所有的风沙声钩爪爪尖完全卡进软组织缝隙，金属卡扣结构闭合扣死伴随钩爪咬合的清脆金属撞击声肩袖发出一声闷涩的拉扯声肩部衣物被拉力扯得严重紧绷，布料纹理被拉伸至极限伴随布料绷紧的撕扯声如巨大的丝绸被不停撕扯的声音沙虫环甲划过沙面，扬起连续的絮状沙浪伴随沙粒摩擦环甲的持续粗粝声

### 第2类：触觉/体感 → 外在可见痕迹

❌ 原文（内在感受）✅ 转化后（外在可见）迎面砸来的风沙粒像细砂纸连续打磨皮肤，持续不断的针刺感颧骨、鼻梁、指背皮肤沾满细密沙粒，面部肌肉紧绷，皮肤表面可见沙粒附着的粗糙颗粒质感肩关节被那股拉力猛地一扯右臂肩部衣物被拉力扯得变形，整条手臂呈绷紧的直线，肩线倾斜掌心的皮绳缠绕印痕深深嵌进皮肤里掌心皮绳在皮肤上压出清晰的深色勒痕，指节发白凸起，手背青筋微微显露全身的重量在万分之几秒内全部压到右臂和右肩上右臂肌肉高度紧绷，线条僵硬，身体重心完全偏向右侧，左臂自然张开维持平衡

### 第3类：心理/情绪 → 动作与微表情

❌ 原文（不可直接写入）✅ 转化后（动作/表情）不是恐惧，是锁死目标的专注双眼紧盯钩爪落点，瞳孔收缩，面部线条紧绷，全身姿态稳定无多余晃动她知道（直接删除心理描述）左脚掌在沙面上缓慢微调半寸她有意识地调整了自己的站位方向左脚掌匀速碾过沙面，身体重心平稳转移，站位角度微调至正对沙虫冲出的方向身体像一套精密的减震系统本能地运作着膝盖随虫体起伏匀速屈伸，重心平稳上下移动，躯干始终保持稳定

### 第4类：比喻/修辞 → 本体特征提取

❌ 原文（AI会字面理解）✅ 转化后（纯本体描述）整个身子像一面被狂风吹起的旗子在虫体侧面剧烈甩荡全身被拉力扯得平直展开，在虫体侧面随拖拽力大幅甩动，斗篷被气流完全撑开，衣摆剧烈飘摆整个身子在空中伸展成一条斜线，像一支箭身体在空中完全伸展成倾斜直线，躯干紧绷，朝向目标高速突进前臂的肌束在皮下一条条鼓起来像绷紧的钢缆前臂肌肉束紧绷隆起，线条分明，皮肤下肌肉轮廓清晰可见像一枚灰烬深处最后闪了一下的炭火左眼瞳孔边缘有一圈极淡的铜色反光，逆光下瞬间微弱亮起它们被拉得像三根绷到极限的红色琴弦三根朱砂红绳被气流朝后完全拉直，呈水平直线，绳身紧绷无下垂

### 第5类：抽象定性 → 具体细节拆解

❌ 原文（AI无法落地）✅ 转化后（可精准生成）处于待发状态手指紧扣钩爪握柄，前臂肌肉微微绷紧，三根钢爪尖垂直朝下对准地面，身体重心略微下沉沙虫以不可阻挡的速度向前犁进沙虫头部高速向前推进，身前沙浪向两侧剧烈翻涌，尾部拖出长长的平整沙痕这是整个画面里唯一的动态人物全身静止伫立，只有斗篷边角被风吹动，持续拍打空气极具冲击力的画面沙虫躯体占据画面三分之二空间，人物在画面右下角形成强烈大小对比，沙粒向镜头方向飞溅

## 三、完整段落改写示范

### 改前（文学化版本，不可直接投喂）

```
钩爪咬合之后的那一瞬间——沙虫向前猛地一蹿，拾音整个身子被那一下
拖拽扯得横甩出去，双脚在离地的同时朝前荡起，全身的重量在万分之几秒内
全部压到右臂和右肩上，肩关节被那股拉力猛地一扯、肩袖发出一声闷涩的
拉扯声。她的右手死死攥着钩爪握柄不放，指节发白到骨节突出、掌心的皮绳
缠绕印痕深深嵌进皮肤里，前臂的肌束在皮下一条条鼓起来像绷紧的钢缆。
整个身子像一面被狂风吹起的旗子在虫体侧面剧烈甩荡——铜质披膊在撞击中
啪地拍打在肩头。
```

### 改后（纯视觉版本，可直接嵌入叙事流正文）

```
钩爪咬合的瞬间，沙虫向前猛地一蹿，拾音的身体被拖拽力横向甩起，
双脚离地向前荡开，全身重量全部集中在右臂与右肩，肩部衣物被拉力
扯得紧绷变形，肩线倾斜下沉。她右手死死攥紧钩爪握柄，指节发白凸起，
掌心皮绳在皮肤上压出深深的勒痕，前臂肌肉束紧绷隆起，线条分明。
全身随拖拽力在虫体侧面大幅甩荡，斗篷被气流完全撑开剧烈飘摆，
肩头的铜质披膊随甩动反复撞击肩部。
——伴随布料绷紧的撕扯声、金属披膊撞击声、沙虫前冲的沉闷震动声
```

## 四、核心避坑提醒

1. **不是越干巴越好**——视觉化转化不是删掉所有文采，而是把文采从"文字修辞"转移到"视觉细节"上。氛围感和叙事张力完全可以通过光影、材质、动作节奏来承载。
2. **细节要精准，不是越多越好**——有效细节是"指节发白、皮绳勒痕、沙粒沾在颧骨上"这类可落地的物理细节；无效细节是"很震撼、很有力量感"这类空泛评价。
3. **不要为了转化损失叙事节奏**——动作的先后顺序、快慢节奏、镜头停顿点全部可以保留，只替换非视觉的修饰词。
4. **任何「像、如、仿佛、好似」引导的比喻句，都必须做转化处理。** AI 会字面理解喻体名词。
