# 特效物理词表

> 📁 **文件定位**：本文件是故事板 Skill 的**特效（VFX）专用物理词表**，供动作片/战争片/灾难片/科幻片里出现**爆炸、火焰、冲击波、粒子、流体、毁灭**这类镜头时调用。它与《电影风格手册》并列——那本管"电影感的画面风格"，这本管"特效怎么动、世界怎么反应"。

> 🎬 **什么时候调用本词表（触发条件，记死）**：
>
> 1. 分镜/视频提示词里出现**爆炸、火焰、燃烧、冲击波、扬尘、碎片飞溅、流体（水/油/岩浆）、结构坍塌、音障**等"特效事件"时，**先加载本词表取词**，不要凭印象现编物理词。
> 2. 写视频提示词的**特效段**时，要挑"物理行为词 / 世界反应词 / 相机冲击词 / 声音三区词"时，来本词表查。
> 3. 觉得"特效像贴纸浮在画面上、火是黄色实心斑块、爆炸没重量、碎片运动均匀没层次、没有余波"时，来查本词表的**十大支柱**对症。
> 4. **文戏/日常戏不调用本词表**——范进中举那种"塞银子、抹眼泪"的文戏用不到爆炸物理词，硬塞反而稀释注意力。只有画面里真发生"特效事件"才用。

> 🔴 **取词铁律**：本词表所有词汇都**读过正文原文才收录**，逐字复用、不得凭印象改写。缺某个词宁可查表，也不要自己编一个"听起来像"的英文。特别提醒：`vorticity`**（涡旋量）、**`thermal bloom`**（热膨胀）、**`heat distortion`**（热扭曲）这三个词在 Seedance/Veo 官方特效正文里都不存在**，是道听途说的误记——正确写法是 `smoke ribbons and wisps`（烟缕烟带）、`thermbaric bloom`（温压双闪）、`heat ripple`（热浪涟漪），见下文正文。

## 0. 先读这一条：特效为什么不真（十大支柱）

特效像不像"真的发生了"，不取决于你写"壮观的火球"这种形容词，而取决于你**有没有把它当成一个"有因果、有物理、有痕迹、有反应"的事件**去写。

Seedance 2.0 官方特效指南的「十大支柱」（the Ten Pillars of SFX）给了完整框架。原文原话：

> "Stack them, and the effect feels **captured** rather than **rendered**. Skip them, and you get a pretty fireball floating on top of your footage **like a sticker**."

十个支柱，每根管一个"可信维度"，不用全上，**挑 3-4 根对当前特效最要命的**：

#支柱管什么核心 token（逐字原文）1Cause → Effect → Aftermath三幕结构：触发→峰值→余波，缺余波就假`visible trigger` / `flash frame then roll-off` / `lingering smoke and debris settling` / `scorch marks remain` / `embers fade slowly`2Light & Exposure特效是光源，要照亮世界、该过曝就过曝`volumetric orange bounce light` / `2700K` / `cool 6500K lightning flash` / `first frame clipped highlights then recover`3Shadows/Occlusion/Depth特效在三维空间里，会遮、有体积、有前后遮挡`soft contact shadows` / `smoke occludes background` / `foreground debris occlusion` / `parallax depth` / `volumetric shadows from flames`4Scale Cues用参照物让人读出"大"`human silhouette for scale` / `foreground reference objects` / `distant haze on large explosion` / `low-frequency camera shake` / `slow-motion debris suggests mass`5Physics & Motion碎片走抛物线、受阻力减速、次生运动`debris arcs with gravity` / `cloth and hair react to shockwave` / `secondary motion on environmental props` / `particles decelerate with drag` / `impact ricochet`6Particles & Debris多尺度碎片同场、粒子有生命周期`multi-scale debris cloud` / `ember trails` / `dust bloom then settle` / `particle lifecycle visible` / `smoke ribbons and wisps`7Atmosphere & Volume大气介质让光可见（体积光）`medium-density grey smoke with orange rim from flames` / `volumetric god-rays through haze` / `atmospheric dust catches light`8Camera Behavior & Lens相机会对特效反应（震、炫光、卷帘）`handheld micro-shake on impact, settling over 0.8 seconds` / `35mm lens with slight motion blur` / `subtle anamorphic flare` / `rack focus to explosion then return` / `rolling shutter on brightest frame`9Surface Interaction特效留痕迹，证明发生在真实空间`fresh scorch marks on asphalt` / `glass reflections strobe with flash` / `dust coating settles on surfaces` / `wet residue from steam` / `cracked concrete from impact`10Sound Synchronization声音三区（瞬态/主体/尾音）匹配时间点`tight transient then bassy body with long reverb tail` / `glass tinkle foley` / `debris patter on metal surfaces` / `environmental reverb matching location` / `air suction following blast`

## 7. 一个现成的"主公式"（Veo 3 指南，可直接套）

Veo 3 指南给的爆炸特效主公式（The Master Formula）：

```
[Cinematography] + [Action] + [Physics Modifier] + [Lighting/Atmosphere] + [Audio Cue]
```

即：**摄影机语言 → 动作 → 物理修饰 → 光/大气 → 声音线索**，五段拼一条特效 prompt。
