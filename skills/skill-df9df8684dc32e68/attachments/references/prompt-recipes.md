# 提示词配方

Use these recipes after selecting a shot family, figure mode, light/material mode, and optional hero anomaly from [shot-atlas.md](shot-atlas.md). Preserve the source aspect ratio unless the user names a delivery platform; use 16:9 for cinematic landscape keyframes.

For LibTV or another weaker prompt agent, read [libtv-hard-mode.md](libtv-hard-mode.md) before using these recipes. Put its structural locks before optional atmosphere words.

## Master template

```text
[画幅]，东方天宫巨构电影写实定帧。主镜头属于[镜头家族]：画面的主次关系是[巨构/高空空间/单一奇观]第一，[镜头透视]第二，[云光与材质]第三，[人物模式]第四。镜头位于[视点]，使用[焦段、机位、轴线或斜向构图]；[屋檐/横梁/巨柱/门洞/对置楼阁]在前景形成景中景。主体是[柱、屋顶、天门、天梯、环形天幕、崖壁宫城、远方宫阙]，以[人物与巨构/门洞与远宫/云海与天瀑/鲸与云海/月门与天体]形成唯一清晰的空间关系；[仅在参考或故事需要时加入的古松/天瀑/鲸/圆环门户/铜灯/水渠]不可喧宾夺主。画面中有[人数、衣色、背向或侧向、安静动作、人物模式的视觉尺度]，旁边保留[栏杆/灯/阶梯/门/地砖]作为正常尺度证明。[栏杆/柱列/地砖/水渠/台阶]以[唯一消失点/明确中轴/环形曲线]组织深度，远方[仍然巨大或出画的宫殿/山体化建筑]穿过[云海/门洞/薄雾]保持可读。建筑由[白玉基座、盘龙石柱、朱红漆柱、深色木梁、斗拱、飞檐、藻井、铜灯等有限结构]构成。[光线方向与色调模式]，真实[石材/漆木/铜/水/云]质感、空气透视与克制反射。这一帧承担[叙事节拍]，情绪是[庄严/寂静/神圣/敬畏/孤独]，无文字，无水印。
```

## Reference-match correction module

Append this module when an output misses a supplied reference, especially when a celestial megastructure becomes a generic courtyard or a flat fantasy palace.

```text
严格保留参考图的主次关系：选择[参考图的镜头家族]与[人物模式]，巨构/高空空间/单一奇观是主角，人物和母题只能服务于尺度与叙事。采用[参考一致的低仰/斜向三分之二侧视/室内框景/中轴登阶/远眺长焦]，不要默认居中立面。前景只露出[参考中实际存在的巨柱、屋檐、横梁、门洞或台阶]，而非补出完整正常尺寸门楼。重复元素朝[偏侧消失点/中心轴线/环形曲线]收束；远方主体经过空气透视后仍保持巨大。使用[参考一致的白玉蓝白/朱红金光/暮色铜黑/月夜灰蓝]调性。不要[参考中不存在的庭院、园林、盆景松树、额外瀑布、额外圆门、海平面、罗马柱、希腊神庙、哥特教堂、欧洲古典宫殿、文字、水印、logo]。
```

## Required companion image-to-video prompt

Use the approved image as the first frame. Pick the motion from [shot-atlas.md](shot-atlas.md); do not combine camera actions.

```text
以提供的生图作为首帧，保持首帧的构图、建筑结构、人物数量与位置、服装、主光方向、[视觉母题或单一奇观]和核心空间关系完全稳定，不新增建筑或人物。生成5–6秒克制的电影长镜头：[唯一镜头动作]。云海分远中近三层缓慢漂移，近景薄雾轻掠过石栏或地面；[天瀑/水面/铜灯/松针/鲸体喷出的水雾/门户边缘光]只做与首帧一致的轻微自然运动。人物仅有衣袂轻摆、自然呼吸、安静眺望或极慢远处步行，不回头看镜头，不做夸张表演。侧光、云影或月光极缓慢变化，保留首帧冷暖关系和真实材质。不要镜头抖动、快速飞行、建筑变形、屋檐融化、柱子弯曲、奇观新增或消失、人物换脸、人物消失或增加、文字、水印、logo。
```

## Five copy-ready recipes

### 1. 红柱侧廊，仪式性人物

```text
16:9，东方天宫巨构电影写实定帧。镜头贴近悬于云海的朱红宫殿侧廊，24mm广角、低机位斜向侧视；画面左侧层层飞檐与数十根朱红盘龙柱沿对角线无限退向远方，柱脚为白玉须弥座，深色梁架和斗拱在顶端强烈出画，潮湿石地映出金红色侧光。右侧完全打开为辽阔蓝白云海，远方宫阙只露出朦胧剪影。近景底部有两名背向镜头的仪式性见证者，一白一黛长袍，人物清晰但只占画面很小部分，静静对望，长衣拖尾在地面倒影中延伸；石栏、柱列与砖缝收束到偏右唯一消失点。晴朗清晨的低角度暖金侧光切过红漆、白玉与云边，深阴影保留细节，庄严、安静、带有等待感，无文字，无水印。
```

### 2. 圆形天门与月亮，夜色门户

```text
16:9，暮夜的东方天宫门户巨构电影写实定帧。镜头位于深沉的朱红与铜黑大殿内部，35mm中广角，左右不对称的层叠飞檐、斗拱与楼阁压住画框；正中是一道远超宫殿尺度的白玉圆形天门，圆门精细石雕在边缘被暖铜光勾亮，门内悬着巨大清冷月亮，月下云海中只有一座小小但轮廓庄严的远方宝塔。门下平台边缘只有一名背向镜头的长袍行者，作为尺度 token；云层、石峰和远塔由近至远沉入灰蓝薄雾。月光冷，殿内灯光暖，真实石雕、旧木、铜灯与潮湿地面反射，神秘、克制、不可抵达，无文字，无水印。
```

### 3. 登天长阶，轴线朝圣

```text
16:9，云海之上的东方天庭登天长阶电影写实定帧。镜头正对一条极其宽阔的白玉中轴天阶，28mm低机位向上仰拍；天阶由两侧无尽石阶与盘云雕栏托起，阶道笔直升入高空，最顶端是一座体量巨大、飞檐压住天空的黑瓦天宫，宫殿和基座均超出画框。两名背身行者位于画面下方中轴，月白与浅赭长袍，极小却有明确剪影，缓慢向上行走；衣角被高空微风掀起。两侧云海像凝固的巨浪从天阶边缘倾泻，远处只留一座极淡的悬浮小阁作深度参照。清冷蓝天与低角度暖光形成克制对比，白玉台阶真实粗粝、云层厚重，庄严而孤绝，无文字，无水印。
```

### 4. 天宫露台观看云鲸，单一奇观

```text
16:9，东方天宫云上露台电影写实定帧。镜头站在一座高空回廊的阴影中，26mm广角；左前景是一根近距离白玉盘龙巨柱，右上方深色木梁、密集斗拱与数盏暖色宫灯形成厚重顶框，白玉石栏沿右侧湿润地面斜向延伸。云海像广阔海面铺在下方，一头巨大的座头鲸从云层中缓慢跃起，鲸身湿润、真实、只占据中景一处清晰区域，溅起的水雾与云雾交融；远方悬着一座白玉宫城。回廊上有两名背向镜头、月白与浅青长袍的观察者，位于右侧栏杆旁，人物可读但不抢戏。清晨逆光穿过云边与水雾，白玉偏冷、灯火偏暖，真实石材、木材、鲸皮与潮湿地面倒影，惊异而安静，无文字，无水印。
```

### 5. 雾中天门、中轴天路与云鲸

```text
16:9，东方天宫巨构电影写实定帧，雾幕逆光。镜头位于一块悬在云海上的宽阔白玉起始平台，32mm中广角、低机位严格中轴构图；一条笔直、窄长的白玉天路从平台正中伸入层层云潮，通向上方巨型三重飞檐天宫中央唯一的矩形发光门洞。天宫的体量横跨画面上半部、屋檐压住天空，整体沉在蓝灰雾幕中：只清晰保留深色屋顶轮廓、巨大的暗影质量、门洞暖白光和右侧金色边缘光，墙柱纹样无需显露。右侧中景云海中，一头巨型座头鲸沿首帧已经开始的跃出弧线破云而起，湿润皮肤被暖光勾亮，只有一个喷溅与水雾源，绝不遮挡中轴、天路或发光门洞。画面下方中央只有一名背向镜头的仪式性见证者，深青灰长袍被高空微风吹起，站在天路入口安静望向天门；人物清晰可读但无脸部特写，平台边缘、地砖和天路宽度提供正常尺度证明。前景平台、中景笔直天路、侧方鲸与云雾、远景雾中巨殿遵循同一中央消失系统。低角度暖金逆光穿过蓝灰薄雾，白玉微湿反射、云层厚重、鲸皮真实、光晕克制，庄严、寂静、带有即将进入未知的敬畏，无文字，无水印。
```

```text
以这张雾中天门、白玉天路、背向长袍见证者与右侧云鲸的生图作为不可改变的首帧。生成约7秒克制电影长镜头：镜头只沿白玉天路极缓慢向前推进，不横移、不绕拍。巨殿的屋顶轮廓、暗影质量与中央发光门洞在雾中保持固定，雾幕只轻微流动而不吞没门洞；远中近云层分层缓慢漂移。右侧云鲸仅延续首帧已经开始的一次自然跃出或回落弧线，水珠和喷雾缓慢沉回云海，不再次跃起、不越过中轴、不遮挡天路和门洞。人物始终背向镜头，仅衣袍和拖尾被微风轻轻带动。右侧暖金逆光与门洞亮度极缓慢呼吸，白玉地面保留稳定微弱反射。不要镜头抖动、快速飞行、结构变形、雾气吞没主体、鲸体缩小变形或多次跳跃、增加人物、人物回头、文字、水印、logo。
```

## Revision levers

| Desired correction | Append or replace with |
|---|---|
| More monumental | “前景巨构强烈出画，人物与栏杆证明尺度，远方主体经过雾化后仍压住天空” |
| More depth | “重复柱列、栏杆、地砖或台阶以单一几何关系收束，前中后景之间隔着两层薄云” |
| More contrast | “采用朱红漆柱、深色梁架、冷白玉石和低角度暖金侧光，保留大面积蓝灰阴影” |
| More dreamlike but not game-like | “只保留一个不可思议关系，建筑材质真实、有重量，降低光晕与饱和度” |
| More Chinese architectural specificity | “汉白玉须弥座、盘龙石柱、朱红漆柱、清式斗拱、深色木梁、藻井、石栏杆” |
| Figures too dominant | “改为尺度 token：一到三名低对比背身人物，远离镜头，不描绘五官” |
| Figures too weak | “改为仪式性见证者：一到两名背向或侧向长袍人物，置于画面下缘或边缘，衣袂和倒影可读” |
| More variety in a set | “下一帧切换到未使用的镜头家族与光线模式，保留同一建筑时代、云高、服装色和光向” |
