# 附MD 3 | 维伦纽瓦·电影级镜头与分镜转换

**所属主SKILL：** 维伦纽瓦 | 宏大、孤独、冷峻、诗意科幻大片\
**版本：** V2.0 融合合规版

## #做什么

本模块为“维伦纽瓦 | 宏大、孤独、冷峻、诗意科幻大片”的专属电影级镜头与分镜转换库。

将剧本和角色设定，转化为可直接用于底层生成引擎渲染的电影级动态分镜与生成指令，解决画面“动态海报感”问题。确保每一个镜头都承载叙事功能，具备上映级视听标准。

## #需要什么输入

**最少提供：**

- 《维伦纽瓦式世界观视觉设定集》（参考附MD1）
- 角色三视图与数字角色资产库（参考附MD2）
- 目标时长与镜头节奏要求

**可选提供：**

- 特定镜头语言偏好（如：极远景、缓慢推镜、长时间静止）
- 目标画幅（不限定，按项目需求或用户指定）
- 是否需要输出视频文件、视频脚本、Prompt清单、视觉方案

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。本环节重点参考【提示词】底座的电影级物理参数与【大导演思维】的镜头逻辑。

### 二、镜头设计

根据视频时长自动设计镜头节奏：

- **15秒短片**：设计1-3个核心镜头。
- **2分钟长片**：设计多个镜头，形成完整的叙事弧线。
- **镜头节奏**：铺垫段以长静止为主，高潮段以短切换为主，收尾段以极慢拉远为主。

### 三、镜头语言专业化

每个镜头必须包含景别、焦距、光影、情绪、摄像机运动：

- **景别**：wide shot / medium shot / close-up / macro detail
- **焦距**：24mm / 35mm / 50mm / 85mm / 100mm macro
- **摄像机运动**：slow push in / cinematic dolly / tracking shot / low angle
- **光影与氛围**：volumetric light / atmospheric dust / dramatic shadows

### 四、生成通用生成指令

输出标准格式的生成指令，必须包含以下要素：

- **Subject**：主体描述
- **Character action**：角色动作
- **Environment**：环境描述
- **Camera movement**：摄像机运动
- **Lighting**：光照
- **Atmosphere**：氛围
- **Visual style**：视觉风格（维伦纽瓦式冷峻科幻）

### 五、强制添加负向指令

Negative Prompt 必须包含：bad anatomy, deformed face, extra fingers,\
low quality, cartoon, game style, blurry,\
plastic look, oversaturated, heavy shadows,\
instagram face, low poly

### 六、生成与合成

根据上述镜头设计与生成指令，调用底层视频生成Skill，输出MP4视频文件。

## #产出什么

最终交付：

- **视频文件（MP4格式）、视频脚本、Prompt清单、视觉方案**。
- **全片渲染视频素材**：按分镜要求生成的所有视频片段（包含运镜、景别、光影、动作），且已通过“环境对人物产生因果响应”的逻辑测试。
- **可无缝剪辑的序列镜头**：已确认没有同构图重复、角色脸型未崩坏、场景连贯性达标的视频切片。
- **镜头门禁审查报告**：确认无“动态海报感”，所有镜头均达到上映级标准。

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 当用户对某一镜头的运镜方式（如：俯拍还是平视）无法决断时。
- 当AI生成的镜头连贯性无法满足剧情逻辑时。
- 用户要求突破负向指令（如允许卡通感、游戏CG感）时。
- 用户要求输出视频文件、视频脚本、Prompt清单、视觉方案，但缺少关键输入时。
- 本模块与上游主SKILL或其他附MD规则冲突时。
