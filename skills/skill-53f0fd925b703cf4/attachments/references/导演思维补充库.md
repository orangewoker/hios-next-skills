# 导演思维补充库

## 十一、镜头之间的意义——非影像层面的叙事

> 大师导演和普通导演的区别不在单个镜头的美学，而在镜头之间的**关系**。两个镜头单独看都一般，放在一起突然有力量——这就是蒙太奇。两个镜头单独看都很美，放在一起什么都不是——这就是"漂亮的空壳"。

**镜头并置的四种关系**：

关系效果例**因果**A 发生，B 是 A 的结果——最基础的叙事推进沈渊抬眼（A）→ 铁漠在看他（B）**对比**A 和 B 在尺度/光线/情绪上极端相反——产生新的含义丹眉手上飘入一张票的渺小（A）→ 25米关羽机甲的巨物（B）**平行**A 和 B 在时间/空间/主题上平行——暗示某种联系丹眉在铜锣湾狂奔（A）→ HARD CUT → 动作匹配→上环继续狂奔（B）**缺席**A 之后，观众期待看到 B，但 B 没出现——制造不安关门声"砰"（A）→ 镜头停在空房间，没人回来（B的缺席）

**设计镜头序列时问自己**：这一镜和下一镜之间是什么关系？如果是纯粹的"下一个动作"，能不能替换成"对比"或"缺席"来制造更大的张力？

## 十二、画面里不该出现的东西——负空间与画外空间

> 大师导演知道"不让观众看到什么"和"让观众看到什么"一样重要。画面之外的空间是观众想象力填充的地方，也是最可怕的地方。

**画外空间的四种用法**：

用法效果写法**威胁来自画外**角色听到声音转头，但观众看不到声源——恐惧加倍`她猛地转头看向画面左方——画外传来一声金属拖地的刺耳摩擦声，持续逼近，但画面里始终不出现声源`**角色出画后不回来**角色走出画面——观众等待她回来，但她没有`丹眉从画面右侧走出画，镜头停在空门前。关门声"砰"。画面静止3秒——她没有回来`**信息被前景遮挡**观众知道有事在发生，但看不到——焦虑`露夏在牛公仔正后方脱衣——观众只能从牛公仔两侧边缘看到她的肩膀轮廓，动作100%被挡住`**只给局部不给全貌**观众只看到角色的手/脚/背影——迫使想象力工作`画面只取丹眉胸口至腰腹一段，看不到脸。她的双手在身侧用力摆动，一枚符箓攥在指间`

## 十三、色彩作为叙事——不是调色板，是角色的心理地图

> 色卡不是"这张图用哪几个颜色"——色彩在全片中是有生命力的，它在不同段落承载不同的情感，随角色的状态而演化。

**色彩叙事弧线示例（《沙誓》）**：

```
开篇对峙：暖金沙#C4A35A 主导 = 沙漠的大，人的小
沈渊觉醒：暖金沙#C4A35A + 冷蓝#1A2B3C 对抗 = 内心的分裂
打斗升温：暗红#B22222 占比急速上升 = 暴力入侵
能量爆发：脉冲冷蓝#4169E1 压倒其他所有颜色 = 被力量吞没
收束寂静：暖金沙#C4A35A + 深棕#8B4513 回归 = 尘归尘
```

**设计色彩弧线的方法**：在写分镜之前，先画出全片色彩的主导权转移图——哪个颜色在哪个段落占主导，什么时候一个颜色"打败"了另一个颜色。颜色之间的战争就是角色之间的战争。

## 十四、停留——什么时候不切走

> 新手导演最大的问题不是不会切，是不敢停。一个角色走出画面，新手立刻切走。大师会把镜头停在空房间，停上 3-5 秒——这 5 秒里观众在"等"，而"等"本身就是一种情感。

**该停的时刻**：

时刻为什么不能切停留多久角色刚出画观众还没反应过来"她走了"——切太快等于没给观众感受的空间2-3秒一句重要台词后那句话需要"沉下去"——立刻切等于打断观众的消化1-2秒一次重大物理事件后（爆炸/撞击/倒地）余波需要时间消散——切太快等于否认事件的分量2-4秒一个眼神后那个眼神的含义需要观众自己解读——切走等于替观众做了判断1-2秒一段戏的结尾需要呼吸——观众需要知道"这一段结束了"，然后才能进入下一段3-5秒纯空镜或留白

> ⚠️ AI 默认「面瘫」——不写微表情，角色就像打了肉毒素。参照社区「给过程不给顶点」「肌肉名+量化」「矛盾信号」三大原则。以下为可复制的完整体系。

### 一、面部肌肉词库（AI 可识别的解剖学词汇）

### 二、7 种核心情绪 · 微表情时间轴模板（可复制套用）

> 参照社区「5 秒情绪流」框架：0-1s 触发期（表情凝固）→ 1-3s 发酵期（肌肉激活）→ 3-5s 释放期（情绪完整展开）。

**悲伤/压抑**：

```
0-1s：表情完全静止，呼吸暂停 0.5s，瞳孔僵持在当前直径。
1-3s：内眼角下垂约 2°，上眼睑缓慢遮住瞳孔上部 1/3。口轮匝肌外围纤维向下做 0.5mm 微下拉——嘴角不可逆地开始下沉。
3-5s：嘴角沉降到最低点（两侧各下垂约 2°），下颌轻微内收 1mm，眼眶基底出现湿润光泽但未形成泪滴。呼吸恢复，但节奏比正常慢 30%。
```

**憋笑/压抑喜悦**：

```
0-1s：颧大肌瞬间轻微收缩——嘴角向上跳动了 0.5mm 但被立刻拉回。
1-3s：颧小肌产生反向牵拉（嘴角要上扬但被压住），眼轮匝肌外围开始不受控地收缩（鱼尾纹出现但很浅）。下嘴唇不自觉向内抿 0.5mm。
3-5s：嘴角在「上扬」和「抿住」之间反复微调 2 次——每次幅度 0.3mm。最终嘴角稳定在不上不下的位置。眼神比平时明亮（瞳孔放大 0.5mm），但面部整体保持「端庄」。
```

**隐忍/克制愤怒**：

```
0-1s：下颌线瞬间绷紧——咬肌轮廓在皮肤下方凸显。鼻翼轻微扩张 0.5mm，一次非常短的急促吸气。
1-3s：降眉间肌收缩——眉头内侧向中间聚拢 1mm。嘴唇闭合，上下唇之间压力增大（唇色微泛白）。喉结滚动一次。
3-5s：面部所有肌肉进入「压制」状态——没有爆发，但每块肌肉都在对抗冲动。眉头聚拢但不过度，嘴唇紧闭但不发抖。呼吸深而慢，胸腔起伏幅度 4mm 但节奏控制得很均匀。
```

**疲惫觉醒（睡醒/从迷茫到清醒）**：

```
0-1s：上眼睑从完全低垂开始上移——上眼睑提肌以每秒 0.3mm 速度收缩。眉间无褶皱，额肌无抬纹——是「累」不是「困惑」。
1-3s：瞳孔进入光线——虹膜括约肌收缩至直径 2.5mm（光适应反射）。同时下眼睑轻微收紧，像「想把视线聚焦但眼睛还没完全醒」。
3-5s：上眼睑抬至自然睁开位置，瞳孔完成收缩。嘴角缓慢恢复至中性位置——之前因疲惫而微垂的嘴角复位。一次深呼吸（4s 完成），胸腔起伏幅度 5mm。颈部轻微转动 5°（从低头到平视）。
```

**警觉/危机反应**：

```
0-1s：所有面部微运动瞬间停止——瞳孔立即从直径 3mm 收缩至 1.5mm（注意力极度集中）。呼吸暂停。头部转动 3°（朝向声源方向）。
1-3s：降眉间肌轻微收缩（眉头聚拢 0.5mm）。上眼睑再抬高 0.3mm（增大视野）。鼻翼扩张 0.5mm（增加嗅觉感知）。
3-5s：身体重心前移 2cm，颈部肌肉紧绷。嘴唇轻启（齿间留缝 1mm，准备说话或深呼吸）。瞳孔保持最小直径，锁定声源方向不移动。
```

**释然/放下**：

```
0-1s：上眼睑缓缓垂下至半闭（遮住瞳孔上部 1/4）。眉间所有褶皱同时释放——像硬撑了很久的肌肉突然放弃抵抗。
1-3s：一次深长的呼气（4-5s 完成，比正常呼气长 100%）。肩膀从紧绷位缓慢下沉 1cm。下颌不再咬合，嘴唇自然微启。
3-5s：面部所有肌肉回到中性——没有笑也没有哭，是「终于什么都不用演了」的空白。眼神不再聚焦在任何物体上，进入放空状态。呼吸恢复平稳。
```

**心动/微妙吸引**：

```
0-1s：看见对方——上眼睑抬高 1mm，瞳孔缓慢放大至 4.5mm（兴趣信号）。嘴唇微启 0.5mm。
1-3s：视线短暂躲开——眼轮匝肌轻微收缩（眯眼 0.3mm，不是厌恶，是「被发现了」）。嘴角差一点上扬但被颧小肌立刻压住——在要笑和不笑之间卡了 0.5 秒。睫毛轻轻颤动 2 次。
3-5s：重新抬眼——这次视线停留时间比正常多 0.3 秒。眼神柔软，瞳孔保持微微放大。嘴角压不住地上扬了 1mm 但只持续了 0.5 秒就收回。一次很浅的吸气（想说什么但咽回去了）。
```

### 四、微表情铁律（写入 Skill 铁律）

**铁律六：微表情冻结在情绪转折点**

```
定帧图不是"一帧平静的脸"——是"情绪将变未变的半秒"。

✅ 「嘴角被颧小肌压住——上扬了 0.5mm 但被反向拉回——在笑和抿之间卡住了」
✅ 「瞳孔正在收缩中——直径从 4mm 缩至 3.2mm，虹膜括约肌还在运动——光线刚进入眼睛的瞬间」
❌ 「沈渊表情平静」→ 这是 0 信息量，AI 会生成面瘫脸
```

### 五、Seedance 微表情使用原则（替代旧版模板式写法）

**核心原则：微表情的精度 = 当前镜头的景别决定，不搞一刀切。**

```
当前镜头景别：
├─ 特写（CU/ECU）→ 调用上方「7 种核心情绪·微表情时间轴模板」的肌肉级描述
├─ 中近景（MCU/MS）→ 用情绪级语言即可（"神情冷淡""眉头微蹙"）
└─ 全景/远景（WS/EWS）→ 不写面部，靠身体姿态和动作传递状态
```

> ⚠️ 在叙事流格式的 Seedance 提示词中，微表情不需要独立成段——直接嵌入叙事正文中、在角色面部被镜头拍到时自然写出。全景镜头写微表情是浪费 token。
