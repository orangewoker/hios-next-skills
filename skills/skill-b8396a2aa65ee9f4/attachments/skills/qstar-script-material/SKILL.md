# 启星旁白skill 材料解析版

## 一、适用场景

当用户提供了较完整的真实材料时使用，包括：

- 产品说明书
- 活动介绍
- 行程和路线
- 项目方案
- PDF、PPT、Word
- 官网内容
- 宣传手册
- 详细卖点与服务信息

本 Skill 的事实来源必须是用户材料和用户明确补充。

## 二、任务目标

把材料转化为符合启星亲子品牌调性的旁白逐字稿。

本 Skill 只负责：

- 解析材料
- 提取核心事实
- 制定视频策略
- 确认人物、场景和事件
- 生成旁白文案

不负责：

- 分镜视频提示词
- 视频生成
- BGM
- 字幕
- 最终剪辑

## 三、核心原则

- 不编造材料中不存在的内容。
- 不平均罗列所有卖点。
- 一条视频只选择一个核心表达角度。
- 从家庭处境和具体行动表达价值。
- 文案中默认不直接出现产品名称。
- 不写成旅行社广告。
- 不使用人物对白。
- 不提前加入固定 Slogan。
- 固定 Slogan 由总控 Skill 单独管理。

## 四、三步确认流程

必须逐步执行，不得一次性输出全部结果。

### 第一步：提取核心信息与视频策略

解析材料并输出：

#### 1. 产品或活动事实

- 它是什么
- 面向谁
- 包含什么真实内容
- 发生在什么场景
- 有哪些可见的体验和行动

#### 2. 主要用户价值

从材料中提取：

- 孩子能做什么
- 父母如何参与
- 家庭关系可能发生什么变化
- 哪些内容能够形成共同记忆

#### 3. 核心推广策略

只选择一个核心角度，并说明：

- 为什么适合当前视频
- 哪些材料内容会被重点使用
- 哪些次要信息会被舍弃
- 如何避免写成功能清单

输出后停止，等待用户确认策略。

### 第二步：确认画面核心内容

策略确认后，输出直接影响画面的内容：

- 核心人物
- 人物关系
- 场景
- 时间与环境
- 关键事件
- 真实任务
- 重要道具
- 家庭互动
- 安全动作
- 情绪变化

不得新增材料中没有依据的具体路线、机构、装备和成果。

输出后停止，等待用户确认画面内容。

### 第三步：生成旁白逐字稿

只有前两步确认后才能生成。

## 五、文案要求

默认 60 秒版本：

- 正文旁白 180—200 个中文字符
- 固定 Slogan 不计入正文
- 每段不超过 40 个中文字符
- 段落之间空一行
- 不出现“第一段”“第 N 段”等字样
- 每段将对应一段视频
- 文案段落建议为 5—7 段
- 最后一段品牌片尾由总控 Skill 另行添加

语气：

- 温暖
- 克制
- 真实
- 具体
- 有纪录片观察感
- 有自然呼吸
- 不叫卖
- 不强行煽情
- 不堆砌形容词

## 六、时长适配

目标时长由总控 Skill 提供。

60 秒参考：

- 正文旁白：180—200 字
- 正文：约 53—55 秒
- 固定片尾：约 5—7 秒

其他时长按自然语速同比调整。

不要通过明显加速语音容纳过长文案。

## 七、最终输出格式

### 视频策略

一句话概括已确认策略。

### 正文旁白

只输出最终旁白内容。

段落之间空行，不添加段落编号。

### 字数与时长

- 正文字数
- 预计正文时长
- 目标总时长
- 片尾预留时长

输出后停止，等待用户确认旁白。

## 八、修改规则

- 修改材料事实：回到第一步。
- 修改策略：重新确认第一步。
- 修改人物、场景、事件：回到第二步。
- 修改旁白表达：只重做第三步。
- 不因局部修改重新发散材料外内容。

## 九、自检

- 是否严格依据用户材料
- 是否没有编造事实
- 是否逐步完成三次确认
- 是否只选择一个核心角度
- 是否正文不直接出现产品名称
- 是否不包含固定 Slogan
- 是否 60 秒控制在 180—200 字
- 是否每段不超过 40 字
- 是否段落之间空行
- 是否没有段落编号
