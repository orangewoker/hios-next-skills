# 场景梳理
根据剧情空间需要，列出本集会用到的场景清单。

要求：
- 场景划分以"叙事空间单元"为粒度，而非"镜头构图角度"。
  同一个物理区域内，即使镜头分别拍到田埂、屋前、水渠边等不同局部，
  只要人物没有发生实质性的空间转移（如从中原走到边界），
  就应归为同一个场景，不得拆分。
- 判断是否需要拆分为新场景的标准：
  人物是否发生了空间转移？空间的时代/阵营属性是否发生变化？
  如果两者都没有变化，就不是新场景，只是同一场景内的不同机位/景别。
- 场景数量建议：100秒内不超过3—5个场景（转场镜头除外，
  转场镜头本身可视为场景之间的过渡，不单独计入场景清单）。

给出场景清单示例格式：

| 场景编号 | 场景名称 | 包含的空间范围 |

| 场景A | 中原新垦田野 | 田埂、水渠、村落边缘、茅屋周边，均属同一区域 |
| 场景B | 南疆赤风边界 | 荒草坡、土坡背阴处、边界土坡制高点，均属同一区域 |

# 分镜时间轴方案

## 阶段一・镜头规划

> ⚠️本阶段为内部推导过程，禁止输出到最终回复中。
> 无论本阶段的具体分析多详尽，都只能作为阶段二、三的推导依据，


### 1.1 节奏驱动力分析

先回答以下四个问题，作为后续切分镜头的依据：

- 本集人物最大的心理或认知变化是什么？  
  例如：“从守土者到守民者”。

- 信息应该如何逐步释放，而不是一次性给出？

- 哪一个瞬间必须让观众停留，不能快切？

- 哪些段落需要压缩、加速，以制造压力或紧迫感？

在此基础上，给出一句话节奏曲线。

参考格式：

> 观察建立 → 信息累积 → 冲突压缩 → 情绪爆发 → 余韵沉淀

禁止跳过这一步，直接按照总时长平均切割镜头。

---

### 1.2 镜头数量规划

根据总时长与剧情复杂度确定镜头总数，禁止无限碎切或过度合并。

建议范围：

- 30秒以内：3—5镜
- 60—120秒：6—12镜
- 120秒以上：10—18镜

避免出现以下情况：

- 连续镜头全部等长；
- 单镜头超过20秒，但内部仍无信息变化；
- 连续3个以上镜头短于3秒；
- 明确的加速蒙太奇段落不受上一条限制。

---

### 1.3 镜头分级预案（A/B/C）

本阶段只给出“镜头编号＋大致时间区间＋镜头等级”的简表，不展开具体字段。

#### A级｜人物弧光 / 主题表达镜头

承担人物认知、情感或立场的关键转变。

- 建议时长，不可超过15秒：8—15秒；
- 用于真正的人物转折或主题峰值。

#### B级｜剧情推进镜头

承担信息传递和事件发展。

- 建议时长，不可超过12秒：5—12秒；
- 用于推动剧情、揭示信息或改变局势。

#### C级｜氛围 / 转场 / 呼吸镜头

承担节奏喘息、场景建立或空间过渡。

- 建议时长：2—6秒；
- 用于调整呼吸、建立环境或连接场景。

一集中A级镜头数量建议不超过总镜头数的三分之一，避免“处处都是高潮”，导致真正的情绪峰值被稀释。

### 1.4 A级镜头内部变化链选型

为每个A级镜头从以下变化链库中选择最贴合的一条，并说明选择理由。

每条变化链均采用“四步走”结构，代表人物从一种内在状态过渡到另一种状态。

#### 一、认知 / 信念类

- **观察类**：观察 → 判断 → 动摇 → 选择

- **认知颠覆类**：确信 → 反证出现 → 抗拒 → 重构  
  适用于人物原有世界观或成见被现实击穿的时刻。

- **启蒙顿悟类**：困惑 → 线索累积 → 顿悟 → 行动转变  
  适用于长期不解的问题突然被打通的时刻。

#### 二、情感 / 关系类

- **情感类**：接触 → 防备 → 松动 → 表达

- **信任类**：信任 → 疑点浮现 → 验证 → 巩固 / 崩塌  
  适用于盟友、亲人或部下之间的信任受到考验的时刻。

- **归属类**：孤立 → 群体压力 → 动摇 → 归属 / 对抗  
  适用于个体在集体压力下重新选择立场的时刻。

#### 三、冲突 / 行动类

- **冲突类**：刺激 → 压力 → 决策 → 行动

- **恐惧类**：恐惧 → 逃避冲动 → 直面 → 突破  
  适用于人物必须克服本能恐惧才能行动的时刻。

- **妥协类**：坚持 → 施压 → 权衡代价 → 妥协 / 坚守  
  适用于原则与现实利益发生冲突、人物必须二选一的时刻。

#### 四、身份 / 立场类

- **身份转变类**：旧身份行为 → 冲突触发 → 犹豫 → 新身份确立  
  适用于人物角色定位发生质变的时刻，例如“守土者 → 守民者”。

- **权力更迭类**：掌权状态 → 威胁出现 → 权衡应对 → 权力转移 / 巩固

- **权谋类**：试探 → 隐藏 → 识破 → 反制

#### 五、道德 / 救赎类

- **救赎类**：过错潜伏 → 触发事件 → 悔恨浮现 → 弥补行动

- **牺牲类**：拥有 → 权衡 → 割舍 → 放下

- **复仇类**：仇恨积压 → 机会出现 → 权衡 → 复仇 / 释怀

#### 选型指引

- 优先选择最贴近该镜头核心冲突性质的变化链，不得强行套用固定类型。

- 如果某个A级镜头与现有变化链都不完全贴合，可以在最接近的一条基础上微调节点措辞，但必须保持“四步走”结构。

- 微调变化链时，需要说明调整理由。

- 同一集内的多个A级镜头，建议尽量覆盖不同分组。  
  例如既有认知类，也有情感类或身份类，避免所有A级镜头都使用同一种变化链，导致观感单一。

- 此变化链库可根据项目需要持续扩展，不要求覆盖所有可能情境。

- 阶段一的内部推导过程不得单独占用最终章节编号。



# 可调整的维度（按需替换）

| 维度 | 原版本设定 | 可替换为 |
|---|---|---|
| 题材 | 历史/权谋 | 都市情感、悬疑推理、家庭伦理、职场剧等 |
| 对比结构 | 中原 vs 草原（文明/温度对比） | 富裕vs贫穷、过去vs现在、理智vs情感等 |
| 声音策略 | 全程无配乐，只用环境音 | 可改为"仅结尾处加入配乐"或"全程配乐但风格克制" |
| 时长 | 100秒 | 30秒预告 / 5分钟正片片段 / 完整一集脚本 |
| 收尾方式 | 情绪留白，不留剧情钩子 | 可改为强悬念钩子、反转揭示等 |

# 使用建议

1. **台词部分务必先准备好原始剧本**——这套模板的核心价值在于"围绕既定台词做视听设计"，而非自由生成台词。使用前把本集所有台词整理好粘贴进去。
2. **对比结构是加分项**——如果本集存在两方阵营/两条线索，明确要求AI做视听对照，效果会显著提升。
3. **"潜台词优先"是本模板风格的核心**——如果你希望角色表达更直白（比如短视频快节奏需要更强的信息密度），可以删除相关限制条件。
4. **历史剧务必填写"时代背景锁定"**——这能有效避免AI出现服化道穿帮（如给夏代人物加铁器、马镫等后世元素）。
5. **确认下游用途再决定是否启用"AI视频生成约束模块"**——如果分镜方案最终要喂给Seedance等AI视频生成工具，务必启用4.6节，否则文字方案再完整，生成时也容易因人物/动作/空间调度过于复杂而崩坏；如果是给真人摄制组用，删除这一节即可，不必受此约束。
6. **A级镜头不要贪多**——A级镜头承担人物弧光，篇幅最长、最耗篇幅，建议控制在总镜头数的1/3以内，多了会让"处处高潮"变成"没有高潮"。

## 版本记录

- **v1**：基于第十六集《熟食飘香，草原人心渐生向往》抽象而成。
- **v2**：经第十三集《巡乡观民，草原少女暗生好奇》验证，结构完全适配后新增：
  - "时代背景锁定"可选前置模块（历史剧专用）
  - 内心独白呈现方式的技术说明要求
  - 节奏结构表明确要求标准 Markdown 表格格式，避免渲染塌陷
- **v3**：发现两集的分镜时间轴均出现"机械均分"问题
  （每段时长高度接近，缺乏发展曲线），新增：
  - 要求AI先给出一句"节奏曲线"描述，再倒推每段时长
  - 明确要求同集内最长与最短镜头时长差不小于2倍，避免匀速切分
- **v4**（当前版本）：发现"节奏"被简化为单一的"镜头长度"维度，
  且缺少镜头数量约束、镜头功能分级、镜头间因果关系，重构第4节为：
  - 4.1 节奏驱动力分析（信息释放/认知变化/冲突压力/情绪余韵，
    切分前先回答四个问题，而非直接分配时长）
  - 4.2 镜头数量规划（按时长给出镜头数区间，避免碎切或过度合并）
  - 4.3 镜头A/B/C分级（人物弧光级/剧情推进级/氛围过场级，
    篇幅与时长随等级递减，避免每个镜头平铺同等篇幅）
  - 4.4 镜头因果链（仅要求A级镜头前后说明"问题→回答→新期待"，
    B/C级省略，控制输出篇幅）
  - 4.5 分级输出字段（A级完整字段，B级简化，C级最简）
  - 4.6 可选的AI视频生成约束模块（人物数量/动作复杂度/空间变化/
    镜头运动，仅当下游接入AI视频生成工具时启用）
