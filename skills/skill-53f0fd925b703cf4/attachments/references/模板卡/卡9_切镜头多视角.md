① 硬切触发句：声音/动作最饱满瞬间硬切+命名（「在刘回的笑声爆发到达最饱满音量的瞬间,画面发生硬切HARD CUT声音匹配剪辑」）

## 层2 11样抄什么（每样配本类原段例句）
```
1.初始状态帧：例「引子帧1秒+继承眼神」（切镜段开头引子帧）
2.运镜句：例「镜头自始至终沿同一个顺时针方向极缓慢地微微环绕被摄者移动」（环绕弧线）
3.分层句：例「正反打切换时机位跳到这条弧线的对侧,但环绕的旋转方向始终保持顺时针不变,不越过两人之间的轴线」
4.遮挡关系句：例「前景元素虚焦横切过画面底部,每镜重复出现」（前景元素每镜重复）
5.虚实焦句：例「画外音进行过程中,画面左侧远景焦点由虚转实推到纵深事件」（对白镜纵深演戏）
6.声画绑定句：例「在刘回的笑声爆发到达最饱满音量的瞬间,画面发生硬切HARD CUT声音匹配剪辑」（声音最饱满瞬间切）
7.声学属性句：例「笑声在声音轨道上是连续不间断的,从外景的画外音直接接续到室内」（音轨跨镜连续）
8.动作边界句（否定写正文）：例「不越轴」「末段戛然而止：全部音效瞬时消失无渐弱」
9.反应链句：例「自然眨眼防呆滞」（对话镜人物必写）
10.节拍切分句：例「正打→反打→复用镜（构图同前）」（正反打节拍）
11.硬切声音延续句：本类核心必抄：例「刘回笑声从外景延续到室内,声音的连续性掩盖了画面的硬切」
```

## 层3 3个必写句式（写正文时抄进自己的段）
```

②「[笑声/声音]从[空间A]延续进[空间B]的[角色]脸上——声音的连续性掩盖了画面的硬切」（音轨跨镜连续）

```
