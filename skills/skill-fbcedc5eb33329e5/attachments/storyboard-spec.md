## 七段式输出格式

每个镜头必须按以下七段结构输出完整方案，不可省略任何段落：

```
镜N（时间码）：[镜头标题]

【一、画幅与摄影机系统】
- 摄影机：[型号]
- 镜头：[焦段+类型]
- 光圈：[T值/光圈值]（[景深说明]）
- 画幅：[比例]
- 帧率：[fps] / 快门：[角度]
- 介质：[胶片型号]
- 选型理由：[为什么这个组合适合此镜头]

【二、叙事核心与镜头语法】
- 景别：[起始景别] -> [结束景别]
- 运镜：[运镜方式]（速度[xm/s]）
- 视角：[起始视角] -> [结束视角]
- 构图：[构图法则+主体位置+留白方向]
- 叙事理由：[为什么这样拍]
- 情绪外化：[视觉元素如何外化情绪]

【三、光线架构与氛围】
- 主光：[光源类型] / [方向] / [色温] / [强度]
- 辅光：[光源类型] / [方向] / [色温] / [强度]
- 轮廓光：[描述]
- 光比：[比值]
- 氛围介质：[水汽/扬尘/烟雾等]

【四、色彩科学与胶片质感】
- 色彩方案：[主色+辅色+点缀色，含色号]
- 胶片响应：[胶片型号的色彩特征]
- 饱和度：[方向+数值]
- LUT参照：[参考LUT或胶片曲线]

【五、质感与去AI感工程】
- 瑕疵美学：
  1. [类别] [具体描述]
  2. [类别] [具体描述]
  3. [类别] [具体描述]
- 肤质引擎（场景版）：L1[宏观]✅ L2[中观]✅ L3[微观]✅
- 拍摄损失：[胶片颗粒/色差等]
- 负向排除：[完整负面提示词]

【六、放大保真质量锁】
- 微观质感：[具体到可辨识的最小纹理单元]
- 分辨率保障：[关键词组合]
- 时间稳定：[视频稳定性关键词]

【七、声景空间设计】
- 对白层：[内容] ([音量]dB) / [时间范围]
- 动作音效：[内容列表] ([音量范围]dB) / [时机]
- 环境声场：[内容列表] ([音量范围]dB) / [持续性]
- 声画关系：[J-Cut/L-Cut/同步/对位] + [设计意图]
```

## 七段式完整示例

```
镜1（0-7s）：沧海隆升

【一、画幅与摄影机系统】
IMAX 65mm 15齿孔 胶片摄影机 + 35mm广角定焦镜头
光圈 T/5.6（深景深，全程岩层纹理清晰）
画幅 2.39:1 宽银幕 / 帧率 60fps / 快门 180度
介质 Kodak Vision3 500T
选型理由：IMAX大画幅捕捉地质宏观壮阔，35mm广角强化空间扭曲感，500T高感胶片赋予远古时间质感

【二、叙事核心与镜头语法】
景别：大远景（辽阔深海全景）-> 随地壳抬升转为全景
运镜：广角缓慢拉升（速度0.3m/s）+ 水平平移跟随海水漫流轨迹
视角：低角度仰视（海平面以下10度）-> 随抬升逐渐平视
构图：三分法，海平面占画面下1/3，天空占上2/3，地壳抬升主体居中
叙事理由：低角度建立海洋压迫感，随地壳抬升镜头被迫上升，观众与大地共同经历"沧海变为陆地"
情绪外化：镜头轻微震颤（地壳运动物理振动），海水飞溅颗粒打湿镜头边缘

【三、光线架构与氛围】
主光：L6 顶部漫射天光 / 正上方偏前15度 / 5200K冷白天光 / 厚重云层透射
辅光：海水反射面冷调蓝灰环境填充 / 光比 4:1
轮廓光：岩层边缘暖橙逆光 3200K / 勾勒裸露岩层层叠剪影
氛围介质：厚重水汽 + 地质扬尘 + 海浪水雾

【四、色彩科学与胶片质感】
色彩方案：冷暖双极对抗
主色（海水/天空）：#4A6580 冷蓝灰
辅色（裸露岩层）：#7D5C3A 暖土褐
点缀（岩层边缘）：#C4703A 暗橙
胶片响应：Kodak Vision3 500T / 中等粗颗粒 / 高光自然滚落 / 暗部层次丰富 / 整体低饱和-35%
LUT参照：Kodak Vision3 500T标准色彩响应曲线

【五、质感与去AI感工程】
瑕疵美学：
1. 胶片介质类：Kodak Vision3 500T胶片颗粒，暗部粗颗粒可辨，亮部细腻分层
2. 光学损失类：35mm广角边缘蓝紫色散
3. 环境物理类：海水飞溅水雾附着镜头边缘，轻微水珠折射光斑
4. 时间物理类：岩层风化裂纹清晰，沉积层叠纹理手可触摸般真实
肤质引擎（场景版）：L1宏观地貌形态✅ L2中观岩层纹理✅ L3微观矿物质感✅
拍摄损失：胶片颗粒 / 色差
负向排除：no cartoon, no CG plastic ocean, no oversaturated colors, no watermark, no human figures, no fantasy magic effects, no overexposure, no anime style, no smooth AI texture

【六、放大保真质量锁】
微观质感：岩层断面沉积纹理清晰分层（每层厚度可辨）/ 海水泡沫细腻流动质感 / 海浪飞沫颗粒物理真实
分辨率保障：ultra-detailed IMAX resolution, physically-based geological rendering, high micro-contrast rock strata
时间稳定：flicker-free 60fps, stable film grain, no color grade morphing, geological motion physically consistent

【七、声景空间设计】
对白层：无（此段无画外音）
动作音效：地壳板块撞击低频冲击声（-12dB）/ 海水奔腾浪涛声爆发（-10dB）/ 裸露岩层碎裂声（-18dB）
环境声场：远古大地低沉地壳轰鸣底噪（-30dB）/ 厚重云层狂风呼啸（-32dB）
声画关系：地壳抬升时动作音效同步爆发，环境音全程持续
```

```

参数建议：
- 时长：5-6秒（最大）
- 运镜描述放在提示词末尾
```

### Runway Gen-3模型

```
[胶片前缀] [场景环境描述] [主体描述，包含资产锚点] [具体动作，使用现在进行时] [镜头运动描述] [光影氛围]

参数建议：
- 时长：5秒或10秒
- 支持首帧图片输入，建议配合Midjourney生成的静态帧使用
```

### Pika模型

```
[胶片前缀] [简洁的主体+环境描述] [动作] [镜头运动]

参数建议：
- 时长：3-4秒
- 提示词宜简洁
```

### Sora模型

```
[胶片前缀] [详细的场景描述，包含空间关系] [角色描述与动作，包含资产锚点] [镜头运动与构图] [光影与色彩] [氛围与情绪]

```

- IMAX 1.43:1 -> --ar 143:100
- 2.39:1 -> --ar 239:100

```

### Seedance模型

```
[胶片前缀] [场景环境] [主体描述+资产锚点] [动作/运动描述] [镜头运动] [光影色彩氛围]

## 镜头衔接规则

### 匹配剪辑

- 动作匹配：前一镜头的动作方向与后一镜头一致
- 形状匹配：前后镜头中存在相似的形状或线条
- 色彩匹配：前后镜头的主色调一致或形成刻意对比

### 180度规则

- 对话场景中，摄影机保持在两人连线的同一侧
- 若需越轴，使用中性镜头过渡

### 30度规则

- 相邻两个镜头的机位角度差至少30度
- 例外：刻意使用跳切作为风格化手段

### 声画衔接

- J-Cut：下一镜头声音在当前镜头结束前进入（声音先于画面）
- L-Cut：当前镜头声音延续到下一画面（声音滞后于画面）
- 硬切静默：转场点声音短暂中断0.3s，强化视觉冲击

## 构图情绪映射速查

根据镜头需要传达的情绪/氛围选择对应构图法则：

| 构图法则 | 情绪效果 | 适用场景 |
|----------|----------|----------|
| **中心构图** | 主角感、仪式感、决战感 | 角色登场、关键时刻、对峙、加冕、神明显现 |
| **三分法构图** | 自由感、呼吸感、自然感 | 日常场景、行走、思考、远眺、抒情段落 |
| **对角线构图** | 速度感、动感、张力 | 追逐、打斗、坠落、冲刺、紧张时刻 |
| **对称构图** | 秩序感、权力感、高级感 | 宫殿、神庙、权力场景、库布里克风格、仪式感 |
| **引导线构图** | 控制视线、增强空间感和故事感 | 走廊、道路、河流、队列、视线引导至主体 |
| **框架构图** | 旁观感、隔离感、情绪距离 | 偷窥视角、回忆、孤独、被困、窗中人物 |

### 使用原则

1. **情绪优先**：先确定镜头需要传达什么情绪，再选择构图法则
2. **组合使用**：同一镜头可叠加多种构图（如中心+对称=极致仪式感）
3. **对比制造变化**：相邻镜头使用不同构图法则制造节奏变化
4. **与焦段配合**：
   - 广角+中心构图=压迫性主角感
   - 长焦+三分法=自然呼吸感
   - 广角+对角线=夸张速度感
   - 长焦+对称=压缩秩序感
