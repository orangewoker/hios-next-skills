# 附MD04 | 末世废土·变量与结局扩展

**所属主SKILL：** 末世废土 · 生存 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“变量设定空洞、结局无分支、选项假大空”的痛点。

## #需要什么输入

核心变量清单、路线设计、阵营设定。

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 物资储备：counter，0-100，默认10；&lt;10濒临饿死。
2. 人性值：relationship，0-100，默认50；≥80圣徒；&lt;20暴徒。
3. 辐射感染度：risk，0-100，默认0；≥70重病；≥90变异。
4. 幸存者声望：faction，0-100，默认0；≥80领袖；&lt;20被驱逐。
5. 避难所防御力：counter，0-100，默认0；≥80安全；&lt;20被攻破。

道具与旗标

1. 净水芯片：item，false；true可获得无限水源。
2. 防辐射药剂：item，false；true可降低感染度。
3. 军火库钥匙：item，false；true可开启最终防线。

### 二、结局体系（共15个）

正结局（5个）

1. E01·乌托邦：人性值≥80，建立和平避难所。
2. E02·废土军阀：幸存者声望≥80，以铁腕统治。
3. E03·远走他乡：找到无污染的世外桃源。
4. E04·舍己为人：牺牲自己保全同伴，声望拉满。
5. E05·科技复兴：利用军火库钥匙和净水芯片重建文明。

坏结局（10个）

1. D01·饿死荒野：物资储备&lt;0。
2. D02·变异怪物：辐射感染度≥90。
3. D03·被同伴分食：人性值&lt;10，且物资耗尽。
4. D04·避难所沦陷：防御力&lt;20。

### 三、变量锚定规则

1. 节点末尾必须标注节点ID+变量变化。
2. 变量名全英文（supplies/humanity/radiation/reputation/defense）。
