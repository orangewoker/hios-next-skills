## 1. 镜头角度与情绪映射

### 设计镜头前的三个问题

1. 这个场景的主体是什么？（人物/场景/物品）
2. 想让观众感受到什么情绪？
3. 什么角度最能表达这种感觉？

### 人物出场模式

#### 英雄出场

- 角度：仰视 + 低机位
- 运镜：慢推进，远景 -> 中景 -> 特写
- 效果：权威、力量、仪式感

提示词框架：
```
low angle shot / cinematic hero entrance,
[角色描述],
[角色动作],
camera slowly pushing in,
dramatic lighting,
epic cinematic atmosphere
```

进阶写法（分解式）：
- 从沙地马蹄特写开始（close-up），扬起尘土
- 低机位缓慢向上移动（camera tilt up / slow push-in），掠过马腿和马鞍
- 中景展示风衣随风摆动
- 最终停在脸部特写，眼神坚定，阳光逆光勾勒轮廓

#### 神秘人物出场

- 角度：背面 + 侧面特写 + 遮挡式构图
- 运镜：缓慢推进 + 轻微手持晃动
- 效果：悬念、压迫、未知感

提示词要点：
- 从背影开始（back angle），低机位拍摄脚部和沙地
- slow push-in + handheld subtle shake
- tracking shot 沿身体向上移动，掠过风衣和帽檐
- 帽檐阴影遮住上半脸，保持神秘感
- 人物从明亮走入阴影，面部逐渐被阴影覆盖

#### 故事感出场

- 角度：平视 + 中景
- 运镜：手持跟拍 + 环绕运镜
- 效果：生活气息、代入感、叙事感

提示词要点：
- tracking + orbit + slight crane
- 镜头从不同角度展示人物和周围街景
- 与街景互动，捕捉自然光影
- 保持主角清晰可见，同时捕捉环境细节

### 对话镜头

#### 双人中景

- 适用：交代人物关系，环境氛围丰富
- 运镜增强：可加入高位/低位环绕，从背面绕到正面

提示词框架：
```
双人中景，[角色A]和[角色B]站在[场景]，
[环境氛围描述]，
两人面对面，[情绪氛围]，
[风格关键词]。
包含台词：
[A] says: "[台词]"
[B] replies: "[台词]"
```

#### 过肩反打

- 适用：代入感更强的对话场景，让观众"坐在对话里"
- 结构：在两名角色之间切换视角

提示词框架：
```
过肩镜头，从[B]肩膀后方拍摄[A]。
前景是[B]模糊的肩膀和[特征]轮廓。
[A]在[场景]中，[动作]，[光线]。
[A]说："[台词]"

镜头切换为反打镜头，从[A]肩膀后方拍向[B]。
前景是[A]模糊的[特征]轮廓。
```

### 情绪角度

#### 俯视角度 -> 渺小、无助、被压制

- 人物显得渺小、无助、被压制
- 动态俯视：从平视逐渐提升到俯视，压迫感逐渐增强

提示词要点：
```
电影级俯视压迫镜头。
[人物]背靠[支撑物]半跪在地上，呼吸急促。
镜头从[施压者]视角俯视拍摄，
开始时俯视角度较低，随后缓慢向上提升，
整个画面从人物胸口逐渐到头顶，强化渺小与无助。
```

#### 背面角度 -> 孤独、疏离、与角色一起面对未知

- 让观众"成为"角色，与角色一起面对未知
- 比正面镜头更能表现孤独、疏离感

提示词要点：
```
电影级背面镜头，情绪孤独而压抑。
[环境]，从[位置]向外拍摄，门框作为前景构图。
[人物]背对镜头站在[位置]，
[环境元素]从[方向]呼啸而来。
她迈步走出，艰难前行，
镜头缓慢推进但始终停留在[起点]，
最终被[环境]吞没。
```

#### 斜角镜头（Dutch Angle）-> 不稳定、恐惧、心理失衡

提示词要点：
```
电影级斜角镜头，
[场景]中，[人物]独自前行，
画面倾斜（dutch angle），
气氛压抑、充满心理紧张感，
[风格]写实风格，电影级布光。

视频增强：镜头倾斜并缓慢旋转向前推进（camera tilt and slowly rotate forward）
```

#### 侧面特写 -> 冷静、思考、压抑情绪

提示词要点：
```
侧面特写，[人物]靠在[位置]，
肩膀微倾，身体轻微放松。
[光线]勾勒出人物侧脸轮廓，
室内阴影深沉，光影对比强烈。
固定镜头，中景偏近侧面特写，
前景虚化，背景bokeh效果。
沉思、孤独、内心微动。
```

时间轴细化写法（8秒一镜到底）：
- 0-2s：建立侧面近景，前景肩膀微虚化，背景bokeh
- 2-6s：极缓慢推镜头（dolly in），直逼脸部极近特写，锁定眼角泪光和唇部微颤
- 6-8s：微妙侧移（弧形轨道运动），侧脸光影流动

## 2. 打光类型速查表

### 顶光（Top Light）

- 效果：压迫、神秘、冷酷
- 特征：光源垂直在头顶，眼窝处形成阴影
- 关键词：`顶光照明`、`眼窝处形成阴影`
- 适用：审讯、杀手、权力者

### 侧光（Side Light）

- 效果：戏剧性、内心冲突、明暗对立
- 特征：脸部一半清晰，一半处在阴影中
- 关键词：`正侧光`、`脸部一半清晰一半处在阴影中`
- 适用：内心挣扎、道德抉择、双面性

### 逆光（Backlight）

- 效果：温暖、梦幻、史诗感、神圣
- 特征：勾勒人物边缘金色轮廓，形成人物剪影
- 关键词：`逆光`、`金色的轮廓`、`人物剪影`
- 适用：黄昏告别、求婚、英雄远行

### 伦勃朗光（Rembrandt Light）

- 效果：古典、沉稳、有深度
- 特征：一侧脸形成三角形光斑
- 关键词：`伦勃朗光照明`
- 适用：肖像、沉思、对话

### 硬光（Hard Light）

- 效果：危险、压迫、冷酷
- 特征：阴影边缘锋利，明暗对比大
- 关键词：`硬光`、`质感硬朗`、`阴影边缘锋利`
- 适用：废墟巡逻、牢房、对峙

### 丁达尔光/体积光（Tyndall/Volumetric Light）

- 效果：神圣、朦胧、戏剧性
- 特征：显现光线的体积和路径，尘埃在光柱中飞舞
- 关键词：`丁达尔效应`、`体积`、`路径`
- 适用：教堂、舞台、古墓、废墟

### 黑色电影风格（Film Noir）

- 效果：悬疑、阴谋、危险
- 特征：低调光，明暗对比强烈，单一光源投射浓厚阴影
- 关键词：`黑色电影风格`、`Film Noir`、`悬疑`
- 适用：夜晚台阶、路灯下、侦探

### 黄金时刻（Golden Hour）

- 效果：温暖、怀旧、史诗
- 特征：夕阳光线柔和温暖，逆光勾勒轮廓，影子被拉长
- 关键词：`黄金时刻`、`逆光`、`dusty atmosphere`
- 适用：公路旅行、告别、回忆

### 蓝调时刻（Blue Hour）

- 效果：冷静、忧郁、孤独
- 特征：画面色调偏冷，低调的蓝色和紫色
- 关键词：`蓝调时刻`、`色调偏冷`、`蓝色`、`紫色`
- 适用：失落漫步、空旷站台、城市孤独

## 3. 人物调度系统

### 身体朝向与心理含义

| 朝向 | 心理含义 | 提示词写法 |
|------|---------|-----------|
| 全正面 | 直接展示情绪和心理，观众直面角色 | `strict front view, close-up` |
| 45度正面 | 最常用电影角度，兼具面部表情和空间立体感 | `45-degree front view (three-quarter view)` |
| 纯侧面 | 角色专注于他物，观众是旁观者 | `pure side profile close-up` |
| 45度背面 | 偷窥视角，观众在角色身后观察 | `45-degree back view, close-up` |
| 严格背面 | 孤独、疏离、离去 | `strict back view, camera directly behind` |

### 人物位置关系

#### 高度

- 两者高度一致 -> 情绪平稳，势均力敌
- 一方更高 -> 该方情绪更强烈或处于支配地位

#### 距离

- 远距离 -> 陌生、疏离
- 中距离 -> 社交距离、正常关系
- 近距离 -> 亲密无间或压迫侵略

### 运动轨迹

| 轨迹 | 效果 | 适用场景 |
|------|------|---------|
| 径向移动（朝向/远离镜头） | 视觉冲击强，增加压迫感和紧迫感 | 冲锋、逃跑、对峙逼近 |
| 横向移动 | 表现旅程、过程，展示人物与环境关系 | 行走、追逐、巡视 |
| 对角线移动 | 结合横向和径向，空间纵深感和动感强 | 复杂调度、多方向运动 |

### 运动轨迹组合示例

分镜一（建立）：
```
深夜。老旧砖墙窄巷空镜，昏黄路灯闪烁，地面有积水。
一名灰色连帽衫男子（背影）从画外突然冲入，
全速奔向巷子深处的黑暗，三个黑衣人追逐。
强烈明暗对比，真实夜间摄影质感，轻微手持晃动。
```

分镜二（横向跟随）：
```
电影感中景侧拍，横向跟随。
深夜后巷，男子从右向左横向穿行。
单一路灯作为侧向光源（rim lighting），勾勒轮廓。
```

分镜三（对角线+低角度）：
```
电影感极低角度仰拍，镜头贴近潮湿地面。
男子从背景右侧沿对角线奔向前景左侧。
运动鞋踏过水洼溅起水花，掠过镜头时产生强烈动态模糊（Motion Blur）。
```

## 4. 真实感人物技巧

### 核心原则

AI默认会忽略很多动作细节，导致视频AI味很浓。要让人物真实，必须精细控制面部表情和全身肢体动作。

### 全脸肌肉拆解

真实人类面部约有42块表情相关肌肉。将情绪拆解为具体的动态面部动作：

| 情绪 | 错误写法 | 正确写法（肌肉动作拆解） |
|------|---------|----------------------|
| 生气 | "很生气" | 唇角紧抿，眉头微皱，鼻翼翕张 |
| 失神 | "发呆" | 瞳孔焦距涣散、嘴唇微张、眼角无意识流下一滴泪 |
| 疯癫 | "疯狂大笑" | 快速眨眼、神经质的笑、歪头杀 |
| 释然 | "放松了" | 舒展的眉头、长舒一口气、仰头，肩膀放松 |
| 不屑 | "看不起" | 眼睑略微压低瞳孔短暂停留，转头将视线冷淡扫开，翻白眼，下颌轻微收紧又轻抬，嘴角极短暂下压，轻微耸肩 |

### 全身肢体语言

配合肢体语言增强情感张力：

| 情绪状态 | 肢体表现 |
|---------|---------|
| 心虚 | 下意识摸脖子或咬嘴唇 |
| 焦虑 | 手指无意识摩挲衣角 |
| 精神崩溃/极度疲惫 | 双肩颓然下垂、无力垂下手、身体向下坍塌感 |
| 积极/振作 | 弯曲的脊背瞬间挺直、胸腔因急促吸气而剧烈起伏 |
| 颓然 | 深深叹气，向后仰靠，肩膀下沉 |

### 皮肤真实感技巧

#### 毛孔与细纹

AI默认皮肤过于平滑，需主动添加瑕疵：
- `可见的皮肤毛孔`
- `因思考眯眼而产生的眼角自然细纹`
- `熬夜带来的轻微黑眼圈与皮肤瑕疵`
- `T区自然的油脂感`
- `暖色光勾勒出脸颊上细小的绒毛`

#### 肤色与地域特征

不同地区人物呈现不同肤色特征：
- 高原：`脸蛋上两团可爱的高原红`
- 热带：`粗粝的毛孔、高原红与晒斑`
- 北欧：`苍白肤色，淡青皮下血管可见`

#### 毛细血管反应/血色

正常人肤色随情绪产生"充血"或"失血"反应：
- 害羞 -> 面颊发红
- 悲伤 -> 眼角泛红、通红鼻头
- 极度恐惧 -> 面无血色

提示词示例：
```
通红的眼眶和鼻头，极度悲伤的无力和痛苦。
双眼泛红含泪，泪水在下眼睑轻微颤动，
鼻翼微微颤动，喉咙轻轻吞咽。
```

#### 含水量/含油量

遵循生物代谢自然逻辑：
- 运动 -> 流汗：`大量汗水覆盖额头、太阳穴、颈部与锁骨，汗珠沿着脸颊、下颌、脖颈滑落，发丝被汗水打湿`
- 干燥地区 -> 嘴唇起皮
- 紧张 -> 手心出汗

#### 皮肤质感提示词分类

1. **微观结构与清晰度**：可见毛孔、皮肤纹理、绒毛
2. **物理光影与材质**：次表面散射、光线反射/折射/透射
3. **生理瑕疵与不完美**：雀斑、疤痕、晒斑、不对称
4. **肤色与血色感**：不均匀肤色、皮下血管、红血丝
5. **年龄与特定状态**：皱纹、老年斑、青春痘痘印
6. **摄影与后期术语**：`override AI smoothing`、`no beauty filter`

#### 皮肤负面提示词

```
airbrushed, smooth skin, plastic, blur, cartoon, doll, fake skin,
makeup, filtered, low contrast, flat lighting, wax figure
```

### 毛发与人设匹配

毛发情况暗示人物的精力状态：
- 落魄流浪汉：`邋遢的胡须`、`杂乱的头发`
- 加班白领：`盘好的发丝微乱`、`明显黑眼圈`
- 运动员：`被汗水打湿的短发`

### 情绪留白技巧

#### 加入量词或状态词

精准控制情绪强度，避免用力过度：

| 原始 | 微笑版 | 腼腆版 |
|------|-------|-------|
| 新娘笑了 | 新娘嘴角缓缓勾起，微微一笑 | 新娘微微垂头，嘴角缓缓勾起，露出腼腆的微笑 |

#### 展现情绪酝酿过程

不要拍"正在痛哭"，要拍：
- "准备哭的那一秒"
- "哭完后的空洞"

示例：
```
女生的脸上挂着未干的泪痕，
眼神是剧烈哭泣后的空洞与麻木，
随后缓慢且沉重地闭了一下眼睛，
像是在隐忍泪意，嘴唇微微颤抖。
身体因为强忍的哽咽微微后仰。
```

## 5. 运镜-情绪对照表

### 压抑、不安与恐惧

- 打破平衡或制造视觉"侵略感"
- 快速拉近特写，打破社交安全距离
- `镜头猛地拉近到眼睛，捕捉瞳孔的微小震颤`

### 孤独、渺小与疏离

- 利用空间扩张感，强调角色与世界的断裂
- 极远景 + 缓慢拉后
- `subject becomes a tiny dot in the vast desert`

### 权力、自信与英雄感

- 视角仰望 + 向前动能
- 低角度仰拍 + 缓慢推进
- `dramatic low angle, camera slowly pushes in`

### 亲密、温柔与怀念

- 慢节奏 + 极浅焦深
- 缓慢弧形轨道运动
- `slow orbit, shallow depth of field, soft bokeh`

### 混乱、紧张与动作

- 速度突变 + 重心不稳
- 手持晃动 + 快速横移
- `handheld shake, rapid lateral tracking`

### 内心挣扎、矛盾与沉思

- 表现"脑内剧场"的波动
- 极缓慢推镜 + 侧面特写
- `extremely slow dolly in, side profile`

### 浪漫心动、暧昧与向往

- 光影 + 柔和动态
- 黄金时刻 + 浅景深 + 缓慢推进
- `golden hour, soft bokeh, sun flares, gentle push in`

### 神圣、崇高与史诗感

- 大自然壮丽或使命升华
- 慢动作 + 低角度 + 广角
- `slow motion, low angle, wide lens, epic scale`

### 混乱、精神失常与认知崩塌

- 打破摄影机物理常规
- 斜角旋转 + 不规则运动
- `dutch angle, irregular rotation, disorienting movement`

### 敌意、挑衅与对峙

- 增强空间火药味
- 快速正反打 + 逼近式推镜
- `rapid shot-reverse-shot, aggressive push in`

### 运镜提示词加权技巧

1. **强度增强**：`Dramatic [运镜词]` / `Extreme [运镜词]`
2. **速度词汇**：
   - 优雅/沉重：`Slowly`、`Gradually`
   - 冲击/惊恐：`Fast`、`Rapidly`、`Burst`
3. **镜头连接**：
   - `The camera starts with... and then...`
   - `Seamless transition from [A] to [B]`
4. **光效增强情绪**：
   - 恐惧：`Cinematic lighting, high contrast, chiaroscuro`
