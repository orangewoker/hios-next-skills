# 角色表演系统（Seedance 2.0）

**核心公理：表演是在压力之下的行为（BEHAVIOR），而不是情绪的展示。** 一个角色想要某样东西，有东西阻碍着他，而他采取行动去得到它。情绪是这场挣扎的副产品——绝不是直接去写的东西。

---

## 1. 每场戏的五大支柱

每场戏中的每个角色都可以拆解成五个要素：

**1.1 目标（Objective）。** 角色在**这一场戏、此时此刻、想从某个特定的人那里得到什么**。始终是指向对手演员的动词："让他招供"、"恳求延长一周"、"让她相信我不害怕"。绝不能是状态（"生气"、"内疚"）——状态无法被直接表演。

**1.2 障碍与利害（Obstacle & stakes）。** 阻止他们得到目标的东西——外部（另一个角色想要相反结果；有目击者；时间紧迫）或内部（自尊不允许低声下气；连自己的话都不相信）。始终回答："如果我没得到想要的，会发生什么？"——答案必须让角色感到害怕。

**1.3 策略（Tactics）。** 此时此刻追求目标的具体方法。策略是动作动词：施压、讨好、羞辱、恳求、挑衅、讨价还价、威胁、拖延。一种策略失败时，活生生的人会**改变**策略。整场戏只用一种策略 = 死气沉沉的表演。

**1.4 节拍（Beats）。** 最小行动单位：角色想要同一件事、用同一种方式追求它的一段时间。节拍结束于：目标达成、策略失败、新信息到来、力量平衡变化。**每次节拍变化都必须通过行为被看见**：停顿、姿势改变、语速改变、视线转移。好戏有2-4次节拍变化；行为始终不变 = 演平。

**1.5 潜台词（Subtext）。** 角色真正所想/所要，与说出口的内容相对。潜台词不是被演出来的——当角色说着虚假文本、同时表演真实目标时，它会自己泄露。标志：不是真正在提问的问题；重复（反复问同一件事——不信答案）；突然转移话题；不合时宜的玩笑（抵挡脆弱）；过于简短的回答（"好。""行。"——关上的门）。

---

## 2. 倾听与反应

表演的生命在台词**之间**。真实倾听的可观察标志：

1. **反应在对方台词结束前就开始**。人会在话没说完时就抓住重点——脸和身体已开始回应。等对方说完再"启动" = 死表演。
2. **先有想法，后有语言**。回答难题前会有微小停顿——明显在决定该说什么。完全统一速度立即作答 = 背好的台词。
3. **评估时刻**。重要事情发生时，角色需要时间消化——几分之一秒或长停顿。电影活在评估的特写中。
4. **来自对手演员的感染**。节奏/音量/能量根据对方变化：面对吼叫，要么更强吼声回击，要么刻意安静回应——必须是回应，不是无视。

---

## 3. 身体：角色的物理生命

**3.1 先有身体状态，再有心理。** 身体在第一句台词前就开始讲故事。

- **重心：** 高（胸口、下巴——自信、攻击性、地位）或低（肩膀、含胸——疲惫、恐惧、服从）
- **节奏：** 快/凌乱（紧张、兴奋）或慢/节省动作（控制、威胁——最危险的人动得最少）
- **开放程度：** 肩膀打开、手掌摊开 vs 双臂交叉、低头、封闭姿势
- **呼吸：** 高位急促（恐慌）或低位缓慢（控制）。呼吸是状态最诚实的指标

**3.2 Business——身体任务。** 角色几乎总应该有一件正在**做的事**：修发动机、数钱、擦杯子——同时说话。Business杀死虚假舞台腔、制造节奏（停顿被动作填满）、产生潜台词。**动作中断原则：** 最强重音发生在角色**停下**正在做的事时。

**3.3 人际距离（Proxemics）。** 角色间距离 = 关系的可视化图表：亲密区（<0.5m，爱或暴力）、个人区（0.5-1.2m，信任）、社交区（1.2-3.5m，事务/戒备）、公共区（>3.5m，疏离）。**距离变化 = 节拍变化。**

**3.4 地位（Status）。** 取决于你**做什么**，不是你是谁。高地位：头几乎不动、动作缓慢、长时间凝视、回答前停顿、占据空间。低地位：忙乱、频繁触摸自己、说话断裂、用笑声填空、眼神寻求许可。最有力的是**地位破裂**：老板一秒露出恐惧；下属突然停止微笑。

## 4. 角色表演主档案

每个反复出现的角色拥有**一个**主档案——关于这个角色如何表演的永久事实来源。只写一次，按场景适配。目标长度：**150-220词，一个连贯段落**，全部中文，所有内容必须可观察、可拍摄。

**模板（区块顺序固定）：**

```
以[角色名]的身份进行角色表演。[年龄、体型、身体状态、姿势——让身体成为人物经历的记录]。[用一个从句概括心理驱动力]。声音特征：[音高/音色、口音/来源、语速与表达方式、情绪压力下声音如何变化]。关键身体习惯与小动作：[标志性小动作及触发因素；压力小动作及触发因素；掩饰行为——如何隐藏真实感受；面部面具，以及它在什么条件下裂开]。步态风格：[给步态命名，说明重量、节奏与落脚方式]。然而，当[情绪触发因素]出现时，[变化——姿势、步态和面部如何改变]。[可选：软化目标——唯一一个会让面部真正柔和下来的人或事物]。
```

**编写规则：**

1. **只写可观察行为。** 每种内在状态必须对应身体标志。永远不写"他很紧张"——写下嘴唇颤抖、用力吞咽、张嘴长吸气再从抿紧嘴唇中急促呼出。
2. **每个小动作必须有触发因素。** 不写"他掰手指关节"，写"他在无关紧要的谈话中掰手指关节，以假装自信"。格式：[小动作] + [何时/为什么]。
3. **给步态命名。** 放入自创名称锚定生物力学："权力步伐"、"孔雀式昂首阔步"、"攻城锤式大步"。拆开说明：重量、步伐、躯干手臂如何运动、头部如何运动。
4. **同时建立面具和裂缝。** 外在伪装 + 让它崩塌的精确触发因素。**每份档案至少带一个"然而，当X出现时——……"从句。**
5. **只设一个软化目标。** 只给面部设定一个会让它真正柔和下来的人/动物/物体。
6. **不写服装。** 衣服属于场景/视觉区块。
7. **不写摄影机，不写颜色。** 表演只驱动表演本身、面部、声音和动作。
8. **体态承载人物经历。** 年龄/体型/姿势选择要能讲出人物过去。

## 5. 眼神生命（每份档案和每场戏都必须具备）

死眼神是AI生成表演最明显的破绽。

- **微眼跳和视线目标**始终指向关注的人或事；视线不断移动——漂移、思考时短暂移开、扫向细节再回来。绝不冻结。
- **真实眨眼频率和质感**与状态绑定：压力下快速连续眨眼；控制时眼睑缓慢平静；短暂解离时眨眼后目光发空。
- **有生命的眼神高光**——眼睛必须看起来湿润、有光、活着。
- **受控静止是主动选择，不是死掉。** 捕食者式冷静 = 眨眼稀少、缓慢、刻意——是决定而非冻结——视线仍带目的缓慢移动。
- **眼睛先于想法。** 头部转动前，眼睛先到目标。话出口前，想法已从眼睛读出。
- **眼神生命对节拍反应：** 节拍变化时，眨眼频率、视线稳定度和眼神高光温度也变。

---

## 6. 场景适配——主档案要重写，绝不直接粘贴

主档案描述角色**是谁**。每个场景都要**重写**成此时此刻的状态：

1. **只写当前出现的角色。** 不在画面里 → 不写。
2. **保留恒定核心。** 身份、声音特征、标志性小动作、眼神生命和情绪贯穿线每场戏保持一致。绝不能与主档案矛盾。
3. **为这一场戏重新表达。** 选择/强调/修改具体行为，适配当前姿势、动作和节拍、情绪状态。
4. **转换，不要删除。** 行为因物理原因无法发生时，转换而非删除：原本会踱步的人瘫坐时，紧张转移成持续轻微晃动、甩手腕、撕纸。能量不变，出口变化。
5. **一个连贯段落。** 融入连续文字——不用项目符号、标题。
6. **段落开头放角色引用标签**，绑定到正确人物。

---

## 7. 声音：身份固定，绝不适配

表演按场景重写；**声音锁定**。每个角色只有一个声音提示词——永久声音身份。有台词时**逐字原样**粘贴到audio/voice字段。绝不为不同场景修改它。

**声音提示词公式（1-2句）：**

```
"一位[年龄]岁的[来源/口音描述]。[音色与声区]；[语速与表达方式]；[声音的情绪特征——以及压力下如何变化]。"
```

---

## 8. 写状态，不写过渡

视频模型不擅长过渡，擅长状态。描述角色已经**处在**动作状态中——正在投掷、正在出拳、正在踱步——不描述进入过程。按节拍串联状态，不叙述连续过程。

---

## 9. 群戏与空间

- **群体反应像波浪传播，不同步。** 一人先懂笑点，二人慢半拍，三人完全没反应。
- **反应比动作更有价值。** 事件后，最有价值画面是看到这件事的那个人的脸。
- **威胁出现时冻结。** 群体持续微动作，但关键威胁出现时一切**停止**。忙乱→静止 = 标点。
- **移动 = 动机。** 没人无缘无故穿过房间。有力动机：逼近（升级冲突）、转身背对（不屑）、一人站一人坐（争夺支配）、冲突中途坐下（反常权力表达）、停在门口（决策点）、收拾东西（身体最后通牒）。
- **强者静而轻；弱者躁动并大喊。** 危险感由周围人的紧张反应演出，不是危险人物自己"演出来"。
- **损耗会累积。** 角色逐渐被磨损，身体累积变化——更灰暗、更沉重、反应更慢——绝不每场重置。

## 10. 糟糕表演自检（15种症状）

| # | 症状 | 修正 |
|---|---|---|
| 1 | 示意式表演（挤眉弄眼） | 不让脸承担任务；写目标，给双手Business |
| 2 | 表演结果（从第一秒就演出最终结果） | 只写角色**此刻**知道的 |
| 3 | 等待提示（对手说话时脸是空的） | 反应从对方台词一半时开始 |
| 4 | 单一策略（一种颜色到底） | 标出节拍；每节拍用新策略动词 |
| 5 | 手势说明台词（手势重复词语） | 手势先于想法，或与台词矛盾，或不存在 |
| 6 | 无代价情绪（突然流泪/暴怒） | 建立阶梯：克制→崩裂；情绪必须付出代价 |
| 7 | 身体与经历不符 | 设置身体档案：重心、节奏、磨损 |
| 8 | 语言对阶层过于干净 | 给语言加杂质：打断、吞结尾、重复 |
| 9 | 提前发出威胁信号（阴险停顿、眯眼） | 威胁日常化；暴力不蓄势 |
| 10 | 群体同步 | 反应像波浪错开，改变强弱 |
| 11 | 死停顿（沉默中什么都没发生） | 用评估或Business填满——或剪掉 |
| 12 | 情绪重置（强烈事件后立刻"恢复"） | 状态有惯性；余波带入下一节拍 |
| 13 | 对角色作评论（对观众眨眼示意） | 完全相信情境 |
| 14 | 特写过度表演 | 镜头越近，动作越少：只留眼睛和想法 |
| 15 | 死眼神（冻结、不眨眼、无眼跳） | 完整应用第5节——眼神生命 |

## 11. 表演等级（自检评分）

- **0级——人体模型。** 台词被说出，但没有行为。
- **1级——朗诵者。** "富有表现力"说台词，直接示意情绪，用身体说明台词。
- **2级——认真但僵硬。** 大致能猜出目标，但只有一种策略，反应太晚，停顿空洞。
- **3级——熟练工。** 有目标和节拍，会倾听，身体逻辑成立。缺：潜台词、意外策略、状态惯性。
- **4级——活着。** 行为连续、策略有反差、潜台词与台词分离、地位在身体中、反应先于台词，至少一个出乎意料但真实的选择。
- **5级——磁场。** 拥有4级全部 + 悖论：角色把彼此不相容的东西放在一起——好笑又可怕、残酷又迷人、撒谎又令人动容。**双重真实规则：角色始终同时表演两种真实。**

每个核心角色镜头目标4+；2级或更低必须在交付前重写。

## 12. 发送前检查清单

- [ ] 画面中每个角色都有以动词表达、指向对手演员的目标
- [ ] 障碍和利害存在；失败代价真实
- [ ] 2-4次节拍变化，每次能从行为中看见
- [ ] 反应在对方台词结束前开始；存在评估时刻
- [ ] 每个角色有Business；动作中断重音被有意识使用
- [ ] 距离变化有动机；地位在身体中，不只台词里
- [ ] 所有小动作有触发因素；面具有裂缝
- [ ] 明确写出眼神生命：眼跳、眨眼质感、眼神高光、眼睛先于想法
- [ ] 声音提示词逐字原样；沉默时省略
- [ ] 写状态不写过渡；表演内不含服装、摄影机或颜色
- [ ] 群体反应错开；强者=静止，弱者=躁动
- [ ] 等级检查：能达到4+吗？

## 13. 最终公理

1. 表演是在压力下的行为，不是对感受的展示。
2. 倾听比说话重要；反应比朗诵重要。
3. 情绪是挣扎获胜或失败的结果，且代价高昂。
4. 身体比语言更聪明：文本与身体冲突时，观众相信身体。
5. 强者静而轻；弱者忙乱并大喊。例外本身就是事件。
6. 每个小动作需触发因素；每张面具需裂缝。
7. 每场戏必然是某个人的失败。没人输就没戏。
8. 潜台词不是展示的——它只是没被隐藏住。
9. 写状态，不写过渡；模型拍摄的是"已经是什么"，不是"正在变成什么"。
10. 拿不准时——剪掉。表演越少，真实越多。
