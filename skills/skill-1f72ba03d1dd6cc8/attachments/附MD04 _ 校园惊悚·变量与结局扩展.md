# 附MD04 | 校园惊悚·变量与结局扩展

**所属主SKILL：** 校园惊悚 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 理智值：counter，0-100，默认100；&lt;30出现幻觉；=0精神崩溃。
2. 同伴信任：relationship，0-100，默认50；&lt;20同伴逃跑或背叛。
3. 线索收集：counter，0-100，默认0；≥80查明校园怪谈真相。
4. 怪物仇恨：risk，0-100，默认0；≥80被怪物死盯。
5. 电量：counter，0-100，默认100；&lt;10手电筒熄灭，陷入纯黑。

道具与旗标

1. 保安室钥匙：item，false；true可进入监控室。
2. 遗留的DV带：item，false；true可看到过去的真相。

### 二、结局体系（共15个）

正结局（5个）

1. E01·破晓逃生：天亮，校门开，主角与同伴逃出。
2. E02·真相大白：查出怪谈背后的科学/阴谋真相，彻底终结诅咒。
3. E03·英勇牺牲：救下所有同伴，主角独自面对黑暗。

坏结局（10个）

1. D01·永远留级：被黑影吞噬，成为校园怪谈的一部分。
2. D02·精神崩溃：理智值归零，彻底发疯。
3. D03·孤立无援：同伴全部跑散，被怪物逼入死角。
4. D04·无尽循环：以为逃出去了，推开门发现还在走廊里。
