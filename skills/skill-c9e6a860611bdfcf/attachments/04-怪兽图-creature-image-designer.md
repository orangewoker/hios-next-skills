# 做什么

把任意形态的怪兽需求转成一条能出**实拍级写实怪兽图**的高质量提示词。

两条总纲（优先于本文件其它一切内容）：

1. **超现实 ≠ 超现实主义画风**。所谓“超现实”指**现实里不存在这个生物**；它落在画面里，**质感必须极其写实**——像被摄影机拍到的，不是被画出来的。
2. **奇观 ≠ 复杂**。奇观来自**与预期的偏差**，不来自零件数量。

目标：像被一台真实摄影机在某地某时拍到的、现实里不存在的生物。不出卡通感、玩具手办感、拼贴感、渲染感、神话插画感。

只处理**单张怪兽图**，不管镜头组、序列、运动。

# 需要什么输入

- 最少：一句怪兽意图（“一只守在山里的巨兽”）
- 可选：体型、生态位、行为、与人的关系、画幅、用途
- 缺不得的三样：**体型量级**（房子大 / 山那么大 / 人那么大，三个完全不同物种）、**生态位**（陆行／穴居／水生／飞行，决定全部器官配置）、**画幅与用途**
- 用户给的原始提示词**多烂都直接收**

# 怎么做

## 1. 把用户给的话逐句分成四类

- **意图**（可怕、神圣、不像活物、让人起鸡皮疙瘩）→ 保留，翻成视觉落点
- **事实**（体型、生态位、行为、与人的关系）→ 一字不改
- **空词**（恐怖、震撼、史诗级、神话感、细节丰富、8K、超写实）→ **删掉**。“恐怖”会带来恐怖片滤镜，“史诗级”会带来海报质感，**两者都会把画面推出“实拍”**
- **缺失** → 按下面第 2 条处理

意图翻译示例：可怕→**不写“可怕”**，写“它身体的比例里有一段明显不合理的地方”＋“它不发出声音”；神圣→形态对称、动作极缓、表面长久无伤、光从上方落下、周围环境安静（无飞鸟无尘）；不像活物→表面材质介于生物与矿物之间（湿甲壳上覆薄灰）、关节朝向反直觉；巨大→给尺度锚＋环境被它压过；活的、有呼吸→侧面或肋部有可见的起伏规律、口鼻处有湿气、表面有隐约的湿润反光。

## 2. 三档纪律

- **必问（最多 3 个）**：体型量级未知、生态位未知、画幅与用途未知时才问。其余不问。
- **默认补**：体表材质按生态位推（陆生→角质或粗皮；水生→湿润黏膜或鳞；穴居→苍白无色素＋细绒毛）；颜色低饱和、与所在地域环境接近（保护色逻辑），不主动给鲜艳色块；光线单个自然光源（天光／月光／火光），**避免均匀棚拍光**；环境要有“有物理反馈”的所在地面（泥、水、碎石、雪）；视角尽量低机位（人在它视线以下）。
- **绝不编造**：不加原文没有的器物（人类武器、符文、铠甲、项圈）；不加叙事痕迹（血迹、伤口、断肢，除非原文有）；**不借已经存在的知名怪兽**（见第 5 条）。

## 3. 先定奇观点（这一步不能省）

**奇观化三法，只选一个：**

1. **尺度的荒诞**——形制完全普通，尺寸完全不对。例：一只壁虎的形制，贴在楼体侧面，体长跨好几栋楼——**它的脚趾仍然细小，仍贴着墙**。关键是**保留小动物的细节质感**，这个反差本身就是奇观。
2. **熟悉物的异化**——从两种自然史物种借形重组：**一个明确的母本 ＋ 一处明显的外来器官**。不要平均混合（那会变成四不像）。
3. **结构的反直觉**——器官的用途与外观相反。例：看起来是张开的嘴，其实是诱捕用的伪装；看起来是眼睛的位置，其实是感振的孔。

**奇观点必须落成“可被看见的动作或形态”**，不能停在设定层：

- 不写“它是伪装型猎手”，写“它的口部张开时，里面是一圈向内收拢的细齿，齿间没有喉咙，是封闭的”
- 不写“它的眼睛是假的”，写“两个眼位置的表面是哑光的、没有反光，真正感光的是一排细小的黑色凸起”

**两条铁律：**

- **一兽一奇观**：三个特征等于零个特征。定下奇观点后把它放大成视觉中心，**其余部位全部按最保守、最写实的方式处理**
- **“能被一句话说清”检验法**：用一句话说完这只怪兽（不含尺寸、颜色、材质），能说清就成立，说不清就重做
  - 成立：“它张开的东西不是嘴，是诱捕器。”“它是一只贴在楼上的壁虎，跨了好几栋楼。”
  - 不成立：“一种有三条尾巴、六只眼睛、背上有尖刺、嘴里吐火、还会飞的远古猛兽。”

## 4. 写实感的七根支柱（每个都要落成可写进提示词的句子）

1. **骨架可见**——肩胛的隆起、脊背的节段、颈根与肩的连接、髋与腿的过渡。不能是一整块圆润的软体
2. **体重可信**——腿粗在关节以下、足部展开压地、趾尖陷进地面。**大象一样的身躯配鹿一样细的腿，是渲染感的头号来源**
3. **材质有源**——湿的（刚出水，反光集中在水膜边缘）· 干的（细密干裂纹）· 硬的（甲壳分片、有接缝、接缝颜色更深）· 软的（有厚度、边缘卷起、受重力下垂）
4. **环境交互**——**把它从画面里抠掉，环境里的变化还应该留在原地**。至少写两项：脚下的地面（凹陷／泥被推起／碎石被压碎／草被压倒）· 空气变化（尘土浮起、水汽、水面被扰动）· 光线遮挡（它挡住主光，地上留下一片形状不规则的暗）
5. **光线一致**——它与环境共享同一个光源（主光方向、色温、反射光、边缘补光方向）。**它身上打着漂亮的轮廓光而周围环境没有这束光，立刻穿帮**
6. **尺度锚点**——见第 6 条
7. **不完美**——挑 2–3 项：体表局部颜色不均、旧伤结痂、脱落的甲片、形态不对称（一侧的角磨短了、一边的鳍有缺口）、体表附着物（泥、草屑、寄生的小生物、干涸的水渍痕）、动作不对称。**干净、对称、完美、无瑕，这四个就是渲染感**

## 5. 借形的谱系与禁用清单

**可用（借结构逻辑，不借外形）**：大型哺乳（体量分布、骨架承重、皮褶走向、呼吸起伏）· 爬行类（体表分片、鳞序、关节朝向、静态姿态）· 鱼类与水生（湿润反光、鳍的张合、水中折射）· 节肢动物（外骨骼分节、关节铰链、附肢对称）· 鸟类（气囊系统、中空骨架的“轻”、羽毛分区）· 深层海生物（昏暗环境的体表质感、非常规比例、半透明组织）· 古生物（借体量可信的结构，不用已命名的明星物种）。

**禁止**：

- 不借已命名的影视游戏怪兽（哥斯拉、异形、克苏鲁、金刚、环太平洋系、侏罗纪系……）——**观众一认出参照物，奇观就没了**
- 不借神话生物（龙、凤凰、麒麟、独眼巨人、地狱犬……）——会进入“神话插画”语域
- 不借宗教与图腾符号
- **不用“缝合式”设计**（狮头＋鹰翅＋蛇尾）——最容易被识别为“设计”的做法

判据：把提示词给一个不在这个行业的人看，他能不能说出“这像 XX 里的那只”？能，就重来。

## 6. 尺度锚定（五种方案，挑一个）

1. **与人同框**（最有效）——人在画面一角，姿态是“没发现它”或“抬头”；**不要给正面对峙摆拍**
2. **与已知物同框**——电线杆、路灯、楼房层数、树冠、桥梁、车辆
3. **残留痕迹**——被压塌的树、被推开的车、被踩出的坑、被折断的墙；画面里它可能只露出一部分，但痕迹说明了尺码
4. **只给局部**——只拍它的一只脚、一段体侧、一只眼睛，背景里放一个熟悉的物件做换算
5. **空气与遮挡**——它挡住主光，地面留下一大片不规则的暗；或雾气里露出一段轮廓，长度占满画面

**尺度荒诞型优先用方案 4 或 3**——露一部分比给全貌更有压迫感，也更不容易露怯。

## 7. 拍法：让它像“被拍到”的（一张图选 3–4 条，不要全用）

1. **少给全貌**——大部分情况只拍一部分（一段体侧、一只足、半个头）。全貌图最难写实
2. **低照度**——昏暗环境天然掩盖不擅长的区域，也让材质更可信
3. **遮挡**——前景有东西挡住一部分（树、墙、雨、雾、栅栏），这是最便宜的实拍感
4. **摄影机的物理反应**——适度景深、轻微高感噪点、暗角、边缘镜头柔化
5. **它不看镜头**——明确写“视线朝向画面外某处”。**直视镜头等于摆拍**
6. **环境先反应**——它出现之前环境已经开始动了（草在倒、水在荡、尘在浮）
7. **未完成的动作**——正在转身、正在低头、正在从水里起身
8. **不完美的取景**——构图略微偏、主体略微出画、地平线略斜（轻微即可）
9. **单一自然光源**——天光、月光、火光、远处城市光

## 8. 防 AI 感

总判据：**AI 感来自“不符合物理的完美”**。三招解药：**有来源**（光从哪来）· **有约束**（写“只有一处”）· **有不完美**（不对称、旧伤、附着物）。

- **玩具／手办感**（最致命）→ 「体表有大片不均的旧色与附着物；反光只沿体侧湿润处；四足使地面下陷」
- **拼贴／拼接感** → **定一个母本**，只留一处外来（“整体取蜥类的骨架，唯一的外来点是背部那一列孔”）
- **渲染感／CG 感** → 给不对称 ＋ 给环境色（体侧暗部带一点地面的颜色）＋「轮廓边缘略柔」
- **概念插画感／神话感** → **删掉史诗类词**；改成“记录性的、未摆拍的”瞬间，光线不要戏剧化
- **塑料鳞片** → 「鳞序在颈部最密、向尾部变疏；靠近腹部的鳞片更软、颜色更浅」
- **材质混杂、结构看不懂** → 每个部位明确归属一种材质
- **图鉴式对称** → 偏侧身 ＋ 动作未完成（正在转、正在低头）
- **过度锐化** → 「皮肤细节只在受光侧清楚，暗侧按景深柔化」

**见到就删的词**：恐怖、震撼、史诗级、神话感、细节丰富、8K、超写实、高精度、极致细节。

**不要用否定句**：不写“不要玩具感”，改成写“体表有大片不均的旧色与附着物；反光只沿体侧湿润处”。

**特别警告**：「细节丰富／高精度／超写实」是怪兽图里最危险的一组词。它们会让模型去堆砌设计细节（尖刺、纹路、装饰），**而堆砌正是插画感的来源**。怪兽要的恰好相反——**大面积保守的写实体表 ＋ 一个尖锐的奇观点**。

## 9. 画幅

- **9:16 竖屏**：适合站立的巨兽、仰视角、深水或深谷里的生物；**横向体型（长身、翼展）在竖屏里会被裁得看不出全貌**——此时改成沿纵向攀爬或盘绕，或换 16:9
- **16:9 宽幅**：横向体型的主场；横向三段（环境 → 怪兽 → 环境），让它“穿过”画面而不是“站在”画面里；也适合与人同框的尺度图

**画幅决定“体型的哪一段能被看见”。** 定了体型再选画幅，不要拿固定画幅套所有怪兽。

# 产出什么

固定四件，顺序不变：

```
【正文提示词】一段自然语言，不分点、不写字段名、不叠同义词。
  顺序：物种与生态位 → 体量与骨架 → 奇观点（一句，且只一句）→ 器官与结构
        → 体表材质与状态 → 环境交互 → 尺度锚 → 摄影 → 光线 → 整体质感。

【Negative】一行逗号分隔，例如：
  卡通感, 玩具手办感, 拼贴拼接感, 渲染感, 塑料鳞片, 材质混杂, 比例失当,
  无接地阴影, 神话插画感, 图鉴式对称, 过度锐化

【画幅与参数建议】画幅｜构图｜机位高度（低机位为主）｜镜头倾向｜景深

【改动说明】替换了哪些空词｜补齐了哪些默认项｜保留了哪些事实｜是否主动调整过方向
```

交付前逐条核对：它靠什么撑住自己 · 奇观点是什么、能不能一句话说清 · 是不是只有一个奇观点 · 体表材质有没有生物逻辑 · 环境有没有反应（把它抠掉，变化还在不在）· 尺度说不说得出来 · 光与环境是否一致 · 有没有借到知名怪兽 · 有没有堆砌装饰。

# 什么时候问你

- 只在三种情况停下来问，**一次问完、最多 3 个**：体型量级未知、生态位未知、画幅与用途未知。
- 其余一律按默认补，补完标注，**不要反复确认**。
- **如果奇观点与画幅冲突**（例如横向体长 vs 竖屏），不要放弃奇观，改方向的呈现方式（改成沿纵向攀爬），并**在改动说明里写明你调整了什么**。
- 用户说“这条不成立”时，撤销或改写那一条，不要辩解。
- 出图不对时：**先查尺度、落地关系、材质，不要第一时间加形容词**；一次只改一处。
