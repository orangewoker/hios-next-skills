# 古风相书断语词典（Classical Physiognomy Lexicon）

> 对象：`天庭饱满地阁方圆`、`龙眉凤目`、`五岳朝拱`、`骨格清奇`、`鹰视狼顾`、`桃花眼`……这一脉出自《麻衣神相》《神相全编》《柳庄相法》等古籍的体系化断语。
> 用途：翻译成生图引擎可执行的可视特征，仅服务**虚构角色形象与戏路设定**。

## 古风断语翻译三律（先读）

1. **抽形态，弃命理**：断语里的价值判断（"主大贵/主贵不可言/主刑克/主劳碌"）一律**不翻译、不输出**，只把其中的形态内核转成可视特征。命理判断改译成"戏路/气场提示"。
2. **象形不画形**：`龙形/虎形/凤形`不是让画面长出龙虎，而是取其**气质意象 + 对应部位的形态特征**（见"形相总论"表）。
3. **负面断语受控使用**：`獐头鼠目`、`鹰视狼顾`、`蜂目豺声`这类贬义古语，仅允许用于**反派/悲剧角色的创作**，翻译时用中性形态词描述（头窄目小/目光阴鸷/眼圆露凶），不直接复用侮辱性原词作画面引导。

## 一、五岳四渎（骨架总纲）

古籍以"山岳江河"喻面部骨架格局，是"大格局"断语的来源。

| 术语 | 对应部位 | 可绘翻译 | 戏路提示 |
|---|---|---|---|
| 五岳朝拱 | 额圆、鼻隆、双颧圆衬、下巴方圆 | 面部骨架中正立体：额圆隆、鼻梁中正高耸、颧部圆润、下颌方圆，整体开阔端正 | 主角/贵胄/正剧脸 |
| 中岳独高 | 鼻梁特别高耸 | 鼻梁突出高直，其余骨相平淡，面部立体感集中在中轴 | 孤高/自我/偏执 |
| 四渎 | 耳目口鼻 | 古指"耳目口鼻深长端正为贵"，翻译为：目长、鼻直、口阔方正、耳长贴脑 | 端正沉稳 |
| 五岳低陷 | 额塌、鼻塌、颧平、颐削 | 面盘扁平无起伏，骨相弱 | 平凡/谦和/底层 |

## 二、骨相九骨（骨法）

相书重"骨"胜过"肉"。看懂九骨位置才能翻译"骨相XX"类断语。

| 骨名 | 位置 | 视觉表现 |
|---|---|---|
| 日角骨 | 左眉尾上方额角 | 额角（左）隆起，显贵 |
| 月角骨 | 右眉尾上方额角 | 额角（右）隆起 |
| 龙角骨 | 眉尾上方斜入发际 | 太阳穴上方额侧饱满隆起 |
| 伏犀骨 | 印堂至发际中轴 | 额中一道隆起，俗称"额头有棱" |
| 将军骨 | 颧骨上方连向耳前 | 颧弓上缘到耳前骨线明显 |
| 驿马骨 | 颧骨上方外侧 | 颧骨外上方饱满 |
| 龙宫骨 | 眼眶骨 | 眉骨+眼眶上缘突出，眼显深邃 |
| 巨鳌骨 | 耳后高骨 | 耳后枕骨两侧隆起 |
| 颧骨 | 面颊最高点 | 见主词典颧骨条目 |

**骨相断语翻译总规则**：
- 骨格好 = 面有**支撑感**：眉骨、颧骨、下颌、额骨清晰但不过度嶙峋。
- 骨露 = 骨点突出 + 皮下肉薄（"骨瘦如柴"极端）。
- 骨藏 = 骨骼被软组织包裹，轮廓柔和（"面无骨相"类）。

| 断语 | 可绘翻译 | 戏路提示 |
|---|---|---|
| 骨格清奇 | 骨点清晰立体，面瘦而不枯，轮廓分明利落 | 侠客/隐士/高人 |
| 骨重肉丰 | 骨骼宽厚、肌肉饱满、体量感厚重 | 将帅/豪杰/壮士 |
| 骨露神昏 | 骨点嶙峋、面肉薄削、颧突颊陷 | 沧桑/落魄角色 |
| 丰颐重颐 | 腮部（下颌角到下巴）饱满双叠 | 福态/年长/富商 |
| 印堂骨起 | 两眉之间骨面隆起 | 刚烈/固执 |
| 眉骨高耸 | 眶上缘明显突出，眼窝陷于阴影 | 深邃/冷峻 |

## 三、形神论（古风最高权重：神）

相书云"相形不如论神"。神 = 目光神情，是古风断语里权重最高、也最抽象的一层。翻译落到**目光状态 + 眼部肌肉张力**。

| 断语 | 可绘翻译（眼神/眼部） | 戏路提示 |
|---|---|---|
| 神藏 | 目光内敛有定，不闪不露，眼睑微垂松弛 | 深藏不露/上位者 |
| 神露 | 目光外射、锋芒毕露，眼睁而亮，黑多白清 | 张扬/锋芒外露 |
| 神威 | 不怒自威，目光平视带压迫感，眉眼下压而不皱 | 掌权者/将领 |
| 神清 | 目光清澈明亮，瞳孔清透 | 灵秀/正派 |
| 神昏 | 目光浑浊呆滞，焦点涣散 | 失意/病态/苍老 |
| 眼神如电 | 目光锐利聚焦，似有穿透力 | 精明/高手 |

**古风"眼形"专称表**（比主词典更细的意象分类）：

| 断语 | 可绘翻译 | 气质 |
|---|---|---|
| 龙睛 | 目长而大，黑白分明，眼神定 | 威严/王者 |
| 凤眼 | 目细长上挑，眼尾飞扬 | 俊逸/贵气（常配眉清） |
| 虎睛 | 目圆而有威，眼裂大 | 威猛 |
| 象眼 | 目细长而下弯如垂，带笑纹 | 慈善/佛相 |
| 鹤眼 | 目细长清秀，眼神静 | 清高/脱俗 |
| 猴眼 | 目圆小而灵动，转盼快 | 机敏/跳脱/尖刻 |
| 鹰眼/鹞眼 | 目圆亮，眉压眼，目光锐狠 | 枭雄/反派 |
| 蛇眼 | 目细小长，眼缝微眯，目光阴冷 | 阴毒/反派 |
| 桃花眼 | 目形弯而含情，眼波湿润，卧蚕润 | 多情/桃花相 |

## 四、形相总论（"××形"整体系断语）

古风高段位断语常以"形"断整人。翻译时**不画动物**，取气质意象 + 关键部位特征。

| 断语 | 气质意象 | 关键可绘特征 |
|---|---|---|
| 龙形 | 尊贵威仪 | 额圆隆、眉骨高、目长有神、鼻直、面部轮廓开阔端正 |
| 虎形 | 威猛雄壮 | 头圆额方、颧骨宽、腮颐方厚、目光有威 |
| 凤形 | 俊秀贵气 | 面骨清秀、目细长、眉清、颈背挺拔（多用于女性/俊男） |
| 鹤形 | 清高脱俗 | 清瘦、颈长、骨秀神清、眼神清冷 |
| 龟形 | 敦厚长寿 | 头圆、面颊丰满、颈短粗、肩背厚 |
| 狮形 | 威重豪阔 | 鼻准圆大、口方阔、颧宽、毛发旺盛（虬髯） |
| 象形 | 稳重富态 | 面方肉丰、眼细长垂弯、鼻长肉厚 |
| 蛇形 | 阴冷 | 面长、眼细小长阴冷、唇薄、面肉薄 |
| 猴形 | 机敏/尖刻 | 面窄短、颧突、眼小灵活、下巴尖（贬义时=尖嘴猴腮） |
| 燕形 | 轻灵俊秀 | 面瘦削、下巴尖、颈细、眼神灵活 |

> 猪形/犬形等古书用于贬损的形相：不提供。需要"憨钝"类角色请用"龟形/象形"的厚重版或中性描述。

## 五、古风五官官名系统

古籍五官称"五宫"，每官一职，附一句传统断语（含命理，已剥离）：

| 官名 | 部位 | 古语要点（剥离后） | 可绘翻译 |
|---|---|---|---|
| 保寿官 | 眉 | 眉为保寿，忌短促压眼、散乱 | 眉清而长、顺而不乱、不压眼 |
| 监察官 | 眼 | 目为监察，贵清、深、长 | 眼形清秀细长、黑白分明、不浮肿 |
| 审辨官 | 鼻 | 鼻为审辨，贵隆、直、丰 | 鼻梁高直、鼻头有肉、不歪不塌 |
| 出纳官 | 口 | 口为出纳，贵方、正、棱 | 口型方正、唇线清晰、闭合自然 |
| 采听官 | 耳 | 耳为采听，贵长、贴、轮廓明 | 耳长贴脑、轮廓分明、耳垂有肉 |

**"五官端正"的经典定义 = 上表五条同时达标**：眉清不压眼、目秀有神、鼻直丰隆、口方唇正、耳贴廓明。

## 七、古风"美人"要素（女性角色专用层）

古书女相命理词（旺夫/克夫/淫贱类）**一律剥离不译**。要"古风美人/古典丽人"时用以下要素组合：

| 断语 | 可绘翻译 |
|---|---|
| 柳眉/眉如远山 | 眉形细长弯淡，如远山一抹 |
| 杏眼 | 目圆而清亮（见主词典） |
| 眼如秋水 | 目清润含水光，眼波温柔 |
| 琼鼻 | 鼻梁细直秀气，鼻头小巧圆润 |
| 樱桃小口 | 唇形小巧饱满，唇珠明显 |
| 肤如凝脂 | 皮肤细腻白皙、无毛孔质感 |
| 云鬓花颜 | 鬓发如云（发量丰盈）+ 面容明艳 |
| 粉面桃腮 | 肤色白净 + 双颊透红润 |
| 眉目如画 | 眉眼组合清秀精致、比例匀停 |
| 弱柳扶风（体态） | 清瘦纤细、肩窄颈长（半身可见） |

> 女性角色如需"英气/威仪"而非柔美，用龙形/虎形/凤形的特征组合即可，古风体系对女性角色的正面断语本就以柔美为主，创作时按戏路自行取用。

## 八、帝王相/贵不可言类（敏感层）

`伏犀贯顶`、`龙颜凤姿`、`天庭骨起`、`五岳朝拱`等古书最高级断语历史上与帝王谶纬绑定。创作**虚构权谋/仙侠/古装上位者**角色时可正常使用其形态翻译；但**不得**用于：
- 指向现实中的历史人物姓名/在世人物
- 输出"此人主贵/有帝王命"类现实断言

## 九、与主词典的协作规则

1. 用户输入含**四字古语**（`剑眉星目`等）→ 先查本节速查表，拆出部位后到 `face-reading-lexicon.md` 补足该部位细节。
2. 用户输入是**整相断语**（`此人鹰视狼顾`、`有龙虎之姿`）→ 用第四/六节翻译整套形态。
3. 用户输入含**生僻骨名**（`伏犀骨`、`驿马骨`）→ 用第二节定位到额头/颧骨/眼眶的具体隆起，翻译时落回骨点描述。
4. 组合出现（如"虎头燕颔 + 剑眉星目"）→ 逐条翻译后合并去重，注意骨相与眉目的协调性。
5. 古语只给气质与形态、不给命理；生成消息里**不出现**"主贵/克夫/刑克/帝王命"等词，只保留可绘特征与中性气质词。
