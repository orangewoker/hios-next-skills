## #做什么

本模块为【动作导演】的视觉语法标准库。解决“不同动作奇观（武打/枪战/飞车/爆炸）配合不同情绪时，画面应该长什么样”的问题，确保AI生成的视觉方案具有电影级质感且情绪统一。

## #需要什么输入

**最少提供：**

- 核心情绪动机（如：爆裂复仇、绝望求生）
- 动作奇观类型（武打 / 枪战 / 飞车 / 爆炸 / 非武打情绪动作）
- 题材方向（科幻 / 武侠 / 特工 / 废土等）
- 目标时长与画布规格

**可选提供：**

- 是否有实体物品植入（珠宝、品牌道具等）
- 目标受众定位

## #怎么做

**一、美学风格定调（与情绪动机强制绑定**）用户必须输入画风关键词与情绪动机，系统自动锁定对应视觉语法：

1. **爆裂情绪·写实史诗风**：极致物理真实感，巨物压迫感，冷暖光影对冲，用于复仇、爆发、决战。
2. **疼痛与崩溃·硬派写实风**：赤膊、黄沙、伤痕、泥泞，拳拳到肉，悲壮决绝的宿命感，用于小人物的挣扎与求生。
3. **紧绷与窒息·冷峻特工风**：金属质感，冷白顶光，暗黑狭窄空间，精准致命，高科技感，用于高压对峙与绝境反击。
4. **隐忍与克制·写意武侠风**：留白构图、静止张力、雨雪风霜、动作极简，用于骄傲、遗憾与宿命的对决。
5. **极致疲惫与求生·废土生存风**：粗糙质感、泥泞、血污、破损服装、沉重的喘息与挣扎。
6. **其他自定义**：用户直接输入，系统自动匹配对应情绪基调。

**二、三色光影公式（情绪联动态）**

- **环境冷色**（默认钢蓝 #4A6B8A）：用于背景、空间深处、阴影。隐忍时加深，疲惫时减淡并增加灰雾。
- **灵魂点睛色**（默认暗金 #D4AF37）：用于核心信物、徽章、品牌标识。爆裂时亮度提亮，绝望时饱和度降低。
- **情绪边缘光**（默认火焰橙 #D4782F）：用于核心张力峰值时的逆光、夕阳、火光。愤怒时大光比、硬切光；疲惫时柔和暖光，带有尘埃感。\
  *（铁律：绝对禁止满屏霓虹或纯白刺眼的光污染。）*

**三、画质与质感标准**

1. 强制叠加35mm粗粝胶片颗粒，轻微暗角，高对比低饱和，拒绝现代CG塑料感。
2. **物理真实与情绪外化**：爆裂情绪要求皮肤有汗水、灰尘，肌肉紧绷；疼痛与疲惫要求服装有泥泞、血污、撕裂，皮肤苍白冷汗；隐忍与克制要求环境有雨雪、微风，材质有丝绸或棉麻质感。

**四、镜头语言规范（本SKILL的核心铁律）**

1. 95%中近景/特写，5%全景（仅用于交代环境）。爆裂情绪多用面部大特写+攻击肢体特写；隐忍与克制多用中景、侧面、背身；极致疲惫多用手持近景。
2. 主用固定机位、斯坦尼康缓推、低角度仰拍。爆裂情绪允许短促推镜；紧绷与窒息要求固定机位为主，镜头绝对静止。
3. 击中瞬间强制“0.5秒抽帧定格”，只定敌人，主角发力保持流畅，定格时必须呈现情绪外化微表情。
4. 禁忌：禁止人物悬浮、禁止一镜到底全景、禁止画面出现乱码文字。

**五、枪战/飞车/爆炸的专属视觉语法**

- **枪战**：冷色环境，枪口火光作为情绪边缘光，弹壳抛射与弹孔破坏强调物理真实。恐惧时镜头微晃，决绝时固定机位。
- **飞车**：强调速度感与空间压迫，环境光拉长成线。冷静操控时镜头平稳，失控时镜头晃动并伴随环境模糊。
- **爆炸**：冲击波导致画面瞬间高光过曝，随后灰雾弥漫。人物飞扑时画面轻微失焦，强调本能保护动作。

**六、角色一致性锚定与视觉污染禁令**

1. 跨时代、跨场景一致，换皮不换骨，核心物理骨架必须严格锚定。
2. 绝对禁止：乱码文字、水印、二次元风格、过度美颜塑料皮肤、五颜六色魔法特效、情绪视觉脱节（动作已爆发但光影依然平静）。
