# 珊瑚橘毛绒小熊｜角色风格提示词

> 本文仅锁定角色本身的造型与视觉风格，不包含动作、姿态、场景或镜头描述。

## 一句话角色定义

一只极度圆润、憨萌治愈的三维卡通小熊，全身覆盖细密柔软的珊瑚橘色短绒毛，拥有薄荷绿色内耳、奶油白色口鼻区、超大的黑色亮面椭圆眼睛、黑色爱心形鼻子和带粉珊瑚色舌头的简洁卡通嘴型，整体呈高品质软胶玩具与毛绒公仔相结合的可爱视觉风格。
