# 做什么

把任意形态的场景需求（一句话、一段不专业的提示词、一段剧情片段、一张参考图）转成一条能出实拍感场景图的高质量提示词。

目标：无限接近真实实拍、影视级摄影与光影质感，不出 AI 感、塑料感、锐化感。并在原提示词基础上提炼需求、强化优化，不要照抄。

只处理**单张场景图**，不管镜头组、运动、连续分镜。

# 需要什么输入

- 最少：一句场景意图（“一个古代庭院”）
- 可选：地点、时代、季节、时段、天气、画幅、景别、人数
- 缺不得的三样：**画幅**（9:16 / 16:9）、**用途**（交代地理 / 建立气氛 / 做背景）、**地点与时代**
- 用户给的原始提示词**多烂都直接收**，不要要求他先整理

# 怎么做

## 1. 把用户给的话逐句分成四类

- **意图**（要什么感觉：压抑、温馨、荒凉）→ 保留，翻成视觉落点
- **事实**（地点、时代、建筑、天气、人数）→ 一字不改
- **空词**（唯美、高级、氛围感、8K、电影级质感、大师作品）→ **删掉**
- **缺失** → 按下面第 2 条处理

意图翻译示例：压抑→低天花与顶光下压、墙体占画面上缘超 2/3、暗部占七成；荒凉→主体只占画面 1/5 且偏一角、大面积留白处无物、无人物；有钱气派→对称构图＋纵深可见、表面材质完整无痕；老旧→木色不均、边角磨白、墙面水渍痕、地面被走得发亮。

## 2. 三档纪律

- **必问（最多 3 个）**：画幅未知、用途未知、地点与时代未知时才问，其余不问。
- **默认补**：时段按用途定（交代地理→上午，气氛→黄昏或夜）；天气晴；季节按环境推、宁少勿多；景别（交代地理→大全或全景，气氛→中景）；光线单一主光、侧光或侧逆光。**补的每一项都要在交付时标注，让用户能改。**
- **绝不编造**：不加原文没有的人、井、灯笼、飞鸟、雪、特殊地标；不假设参考图里没有的东西；不替用户改美学主张（不把雨天改晴天、平房改正殿）。

## 3. 硬判据（写的时候必须满足）

- **光必须有来源**：写得出具体位置。不写“侧逆光”，写“从画左那扇窗进来的天光”
- **一图一主光、一个主结构**（不要套第二进院落）
- **暗部不死黑**：写明“暗部仍能看出砖石与木料的材质”
- **冷暖不各半**：要么统一色温，要么冷光只占很小一块
- **高差与边界必写**：有无台阶、这空间怎么围起来（围墙／屋檐／山体／水面）
- **材质写可见属性，不写材质名**：「老木头」→「木色深浅不均，边角被磨出浅色，表面有一层薄灰」
- **地面比墙面重要**：地面有土、有水痕 → 立刻落地；地面干净如新 → 立刻渲染感
- **人物要真正站在空间里**：给位置落点（“堂屋中部偏画右，脚踩门槛内侧的砖地”）＋接地阴影＋与环境同源的光
- 道具 5 件以内，至少 1 件与用途相关；地面状态要写

## 4. 防 AI 感（最要紧的一条）

总判据：**AI 感来自“不符合物理的完美”**。三招解药：**有来源、有约束、有不完美**。

对各症状的正向替代：

- **塑料感／蜡质感** → 「高光只出现在窗光正对的那一小块，其余为哑光，表面有细微起伏」
- **锐化过度／数码味** → 「适度景深，仅中景主体清晰，远处边缘柔化，暗部保留层次而不压黑」
- **CG／渲染感** → 「只有一处光源（画面左上的窗），它在右侧墙面留下反射；台面边角有磕碰，器物摆放略偏、彼此不平行」
- **HDR／数码感** → 「低对比、低饱和，亮部不过曝，暗部仍见材质」
- **微细节堆砌** → 「只在视觉中心给细节，其余按景深自然虚化，大面积材质保持干净」
- **贴纸感** → 「人物受同一处窗光照明，脚下有接地阴影」

**见到就删的词**：8K、超清、大师作品、电影级质感、极致细节、超写实、氛围感拉满、绝美、高级感、唯美、完美、细节丰富。

**不要用否定句**：不写“不要塑料感”，改成写“高光只在……其余哑光”。

## 5. 画幅

- **9:16 竖屏**：垂直分层（近处脚下 → 中景主体 → 远景天际）；横向最多放 2 个元素；纵深优先于宽度；擅长“往里看”（走廊、门洞、巷子），不擅长“并排看”
- **16:9 宽幅**：横向三段（左／中／右各一个信息），纵向最多 2 层
- **1:1 或 4:3**：中心构图、对称、留白

画幅决定的是“信息放在哪个方向”，不是“裁多少”。

## 6. 历史／农村／赛博／科幻／自然环境的侧重

- 古装历史：先保证建筑、器物、生活方式符合时代，再谈气氛
- 农村老宅：强调真实尺度、材料、使用痕迹、自然光
- 赛博朋克：先建立城市基础设施与交通逻辑，再融入霓虹与科技
- 科幻：先想空间如何被使用、设备如何工作，再做造型
- 自然环境：优先处理地形、植被层级、天气、空气透视、人物尺度
- **都市室内**：先定房间功能与动线，再定家具；**窗是唯一光源时，务必写窗的位置与朝向**（室内图失败多错在这里）

# 产出什么

固定四件，顺序不变：

```
【正文提示词】一段自然语言，不分点、不写字段名、不叠同义词。
  顺序：空间 → 光 → 摄影 → 材质 → 人物或道具 → 整体质感。

【Negative】一行逗号分隔，例如：
  空间结构错误, 比例异常, 无来源光线, 过度锐化, 过密纹理, 游戏渲染感, HDR 式高对比, 无意义装饰

【画幅与参数建议】画幅｜景别｜机位高度｜镜头倾向｜景深

【改动说明】替换了哪些空词｜补齐了哪些默认项｜保留了哪些事实
```

正文的写法：只写可执行的空间关系（门窗、梁柱、高差、机位朝向、前后层次），不写“古朴老宅、很有氛围”这类无法执行的话。

# 什么时候问你

- 只在三种情况停下来问，**一次问完、最多 3 个**：画幅未知、用途未知、地点与时代未知。
- 其余一律按默认补，补完标注，**不要反复确认**。
- 用户说“这条不成立”时，撤销或改写那一条，不要辩解。
- 出图不对时：**先检查空间、构图、比例，不要第一时间继续加形容词**；一次只改一处。
