# 参考绑定的用途与资格

## 触发与最小输入

在把图片、视频、声音或实际帧作为生成输入，制作变体，继承某段实际末态，或复用旧版素材时读取。最少输入为当前 Job 版本、所需参考职责、候选 Asset/Take 的确切版本与位置、消费区间/维度、对应观察记录及当前入口的引用契约。

Binding 的定义及用途审查结论见[核心记录](../core/03-records.md)。Binding 是可追溯的生产记录，不是某种平台语法；文件名、人物名字或提示词中写“参照上一张”都不能证明平台已绑定目标素材。

## 先说明职责，再核对资格

每项引用先写一句“用这份源来决定什么”。分开身份、故事状态、空间、动作相位、声音身份/时序、画面风格；同一份源可承担多项，但每项单独核证。登记哪些属性保持、哪些允许改变，避免强制照搬构图、灯光或旧动作。

| 消费用途 | 必需观察 | 不能替代的证据 |
|---|---|---|
| 取某帧作可见身份参考 | 该帧及需要识别的部位真实可见；来源/帧位置可回溯 | 声音好坏与这项身份资格无直接关系；未看的别角度仍无证明 |
| 设定板整板/板内区域职责 | 目标区真实清晰，各区职责明确且不混用；无头正面区仅供服装，不作完整人物。按[现有区域与容量分支](#reference-capacity)核实际引用方式 | 板已生成、其他区好看或看见某区，不证明目标区合格、独立文件已存在或入口支持ROI |
| 取同服装或伤势阶段 | 对应图/区间的状态及故事时段相符，来源身份可用 | 全片角色名一致、旧母版标签 |
| 取空间布局 | 被本镜消费的地标、通路、结构关系可见或已有明确设计证据 | 一张未展示反面的气氛图，不足以证明反面几何 |
| 从实际最后动作延续 | 实际源区间尾部及足够邻近的连续画面；动作相位、位置、道具归属/朝向与拟接点相符 | 封面、首帧、请求时长、计划末态、某个已看过但并非出点的帧 |
| 声音身份/故事声态 | 已听目标角色的确切源版本及区间，可分辨声线与说话者；生效故事范围符合目标 | 人物同名、视觉母版、声线描述、波形或转写不能替代已听资格 |
| 继承声画接续 | 所需画面区间与声音都可观察；对白/声源、时序与同步范围有证据 | 静态截图、转写全文或“音视频生成成功”不证明完整声画接续 |
| 仅取风格 | 所消费的光色、材质或观看方式可见；写明身份/布局等不随之照搬 | 参考作品名称或全局“通过”标签 |

没有“某 Take 整体已接受，所以任何用途都可绑”的捷径。对本用途标为需要修复或不宜使用的源，先修复、换源或重新设计；未观察的维度保持相应限制。用户可以明确接受某些未观察风险，但该决定不等于已观察合格，也不能创造必须继承的真实末态或不存在的引用能力。

<a id="voice-binding"></a>
## 声音引用按角色分开

沿用同一Binding记录，链接[声音母版](01-asset-planning.md#voice-assets)的角色ID、Asset及实际音频/Take版本、源区间/时基、生效范围、已听用途与保持/可变项。多人对白明确“哪位角色消费哪份声音来源”，同一声源里的其他声音不自动分配给另一角色。

只有网页当前工具实际暴露相应音频输入与角色映射时才实施，并按下列读回步骤核实；厂商能力不等于网页可用。工具只能接受文字声线描述时，登记为文字设计意图，不报音频绑定；没有所需引用方式则继续剧本/声音提示方案并标具体缺口。声音变更只调整受影响角色、故事范围和目标Job版本，其他合格引用复用。

<a id="reference-capacity"></a>
## 图组引用与容量不足

按[人物引用路径](04-character-and-performance-templates.md#character-reference-paths)区分身份单图、设定板区域和实际提取/派生文件。整板探索可在当前入口支持图像引用时，以区域职责作有界尝试并观察；不臆造ROI工具，也不要求已有该路线成功结果才允许首次尝试。无头正面区只供服装，不作完整人物。看到总览某格或某帧，不等于它已保存成可独立引用的素材；无真实提取能力就用合格现源或制作必要候选，不伪造定位或免费裁切。

先列本镜不能丢的事件、身份、状态与结构，再选择合格来源。删除重复/无关参考、让一份已有源承担它确已具备资格的多项职责，风格等已有可靠依据的辅助项可让位；不固定“身份高于道具”，关键背面信息或持有归属也是硬要求。

仍超限时，核图像入口自身的容量、编辑/引用能力及已有额度，制作能承担必要职责的镜头参考/首帧候选，实际保存、逐职责观察后才引用；逐步派生的每一步也须有合法输入和费用范围。或由摄影/任务包装调整覆盖与分段，重新核因果、反应和接缝；分批发请求不自动解决同一镜同时超限。无法保住目标则列具体缺口，不静默删事件或假称绑定完成。新候选不预报合格、不越原授权重试。

[调度图](05-scene-and-blocking-templates.md#scene-consumers)可作为设计前置而不直接输入模型；它的设计完成证据与本节真实媒体Binding分别登记，不能用一个替代另一个。

<a id="reference-map"></a>
## 本项目对象到当前入口的映射

在准备实际引用、用户质疑关联、素材重排、恢复新提交或引用失败时，沿用同一Binding记录串起：**原文标记/界面别名/规划ID及其出处 → 本项目实际对象、源版本、人物/道具状态与生效阶段、真实媒体位置 → 本次入口的槽位或正文标记、媒体类型/角色及用途 → 核对依据与实际请求版本**。这是可读记录责任，不是新增平台字段或要求用户提供技术键。源尚未生成时前半仍可写需求，不能把计划ID变成媒体定位。

优先按已有创建回执、可信索引或当前画布/引用选择能力找回；限定在用户提供的项目与已授权资源范围，核同名候选的身份、状态和版本。不因一个ID外形像i-…就认证，也不因标签含空格、Mixed或中文就判非法；用户粘贴是待核线索，自己的映射表不是工具读回证据。零候选只证明本次核对未找到，多候选不能任选，当前存在也不倒推历史已存在。

可靠旧映射在来源、版本与当前入口未变时可复用核对，不每次全画布扫描。字段或定位由Agent从自己可见工具/回执获取，不常规要求用户找node_key；确需用户辨认同名作品或执行入口要求的选材动作时，用可见作品名称及具体限制说明，交[用户输出](../core/06-user-output.md)。

| 当前入口实际证据 | 编译与检查 |
|---|---|
| 生成可核实的正文引用标记 | 使用本次实际标记，对上对象、媒体、顺序/角色与用途；不自行拼装平台语法 |
| LibTV 网页（2026-09-07 documented）：正文 `{{node_key}}`，真实 key 形如 `i-…`/`v-…`，引用后接一句职责（"用于…，不采用图片背景"），槽位序＝传入顺序 | 只用画布/回执取得的真实 key；规划 ID、显示名不得写进 `{{}}`；每个 Job 保存"原文标记→本项目对象/版本→node_key→槽位/职责→依据"映射表，见根 SKILL.md 死线 4 |
| 无正文标记，但附件槽位/顺序可核实 | 记录真实槽位和媒体类型/职责，按入口可理解的表达编译，不因缺@标记暂停 |
| 混合图片/视频/音频 | 核总体槽序与各媒体编号是否相同，按真实入口规则换算；不假定“槽10”就是“图片10”或固定分别编号 |
| 增删、替换或重排输入 | 重建受影响映射，并逐条对照最终正文/参数/真实附件。未知用途的额外媒体先查其职责与来源，不自动删除或假定必需 |
| 对象或当前入口映射不可核实 | 只保留绑定意图；停止消费该缺口的实际提交，独立草案继续，不为凑齐表创建假对象 |

同一人多状态逐阶段登记允许继承项；后期参考若带提前出鞘/悬浮等状态，不可整体用来锁早期动作。只有本用途观察及入口引用方式足以隔离时才限维度复用，否则换合格源或制作必要派生，不能只加一句否定就称污染已排除。

## 绑定判定流程

1. **定位：**能否按真实标识找回确切源与版本？不可定位时保留引用意图，停止依赖该源的提交。相同名称的多个对象逐项辨认，不任选最新一份。
2. **范围：**目标是否仍是当前 Job 版本？源的故事状态及用途范围是否满足它？旧版不自动失效，也不自动沿用；按[变更影响](../core/05-change-impact.md)登记仍适用的理由。
3. **资格：**逐维度比对所消费区间与观察覆盖。不足则去[素材观察](../post/01-observation-selection.md)补看，或缩小用途、换合格源；不能仅靠改提示词宣布缺口已解。
4. **入口：**核对当前入口接受的媒体类型、数量、顺序/角色映射、定位格式与引用方式。未知则到[能力适配](../platform/01-libtv-capabilities.md)，只形成绑定方案；不硬填 CLI 语法、厂商字段或未验证模式。
5. **读回：**依据真实工具契约设置后，核查目标实际收到的源标识、顺序与职责。若工具不提供独立引用回读，但本次实际选材列表、顺序、正文/参数和版本可核对，保存请求快照并标“映射未回读”；这只足以进入项目契约明确的受限小样，不能报正式绑定已验证。若来源、选材或顺序本身无法核对，停止依赖该源的提交；不以规划ID、显示标签或猜测槽位补足证据。

尚无实际产物的“钥匙应在桌角”等属于故事/接续设计，可以独立指导多个任务，不自动等待某段视频。任务明确消费上游真实帧、视频或声音时，建立的是等待该实际媒体作为输入/末态的依赖；布局/调度等必要设计完成并核对的等待另行成立，即使不直接上传模型，也按[设计前置](05-scene-and-blocking-templates.md#scene-consumers)与[调度](../generation/04-scheduling.md)核对。

<a id="reference-diagnosis"></a>
## 质疑与失败后的诊断

用户问“关联是不是错了”先按[本轮边界](../core/02-routing.md)核查，不把问句自动变成更新索引、修图或重投授权。即使已有持续执行授权，未核的源/映射仍不能提交。将用户原文字串、当前入口附件/正文快照与历史请求分别保存，逐行指出哪项已对上、错配或未能定位；只有实际核对后才报相应范围已修复。

用户再次粘贴、Agent承认写错、改显示名或删空格都不是新核验证据。核对错误来自当前输入、入口契约还是未知因素；真实失败/校验未发出/受理不明依[提交恢复](../generation/05-submit-reconcile.md#input-error-recovery)分开。没有原始错误不猜根因，不为试探格式付费重投。修正后的新请求再走上述映射与原有调度；历史Attempt不被新表覆盖。

## 可浏览产物与例子

输出一张紧凑的引用清单：目标 Job 版本、源 Asset/Take 版本和位置、用途、区间/帧与时间基准、保持/可变项、观察证据、入口映射是否核验。参数仍未知的行要直接写“绑定意图，未实际绑定”。

**原创纸面示例，未生成素材：**林舟听完林岚邀请后看门，肩包尚未卸下。

| 拟引用 | 用途判断 | 决定 |
|---|---|---|
| 假设已有第 2 秒的可见身份图，身份和工作服在该帧有观察记录，音频未观察 | 只消费该帧的身份与服装，不消费声音 | 在实际帧定位与当前入口映射核验后，可供此用途绑定；仍不称声音合格 |
| 假设同一 Take 只有首帧可见，却要接它真实结尾的卸包动作 | 所消费的末段未观察 | 阻塞这条接续依赖；可继续林岚独立反应镜的准备 |
| 后期选用中段作为出点 | 消费的是选段末态，可能不同于原 Take 最后一帧 | 按确切 Clip 源区间重新核对；记录为选段出点，不冒称原素材末态 |

## 检查、返修与边界

提交前逐行问：实际引用是谁、为什么引用、消费哪一部分、依据是什么？引用职责互相冲突时先分清优先级或改源；源缺陷交[资产验收](02-asset-build-review.md)或[素材观察](../post/01-observation-selection.md)；目标接法不成立回[接续设计](../visual/04-continuity-seams.md)。每次输入改变建立相应新版本，不改写已提交 Attempt。

[S06](../evidence/01-sources.md#s06)、[S07](../evidence/01-sources.md#s07)支持状态与空间的工艺依据；按用途、维度、区间授予绑定资格是本 Skill 的原创设计。实际参考模式须遵守[模型](../evidence/01-sources.md#models)与[LibTV](../evidence/01-sources.md#libtv)的各自证据作用域，不从“多参创作”展示推导具体参数或效果保证。
