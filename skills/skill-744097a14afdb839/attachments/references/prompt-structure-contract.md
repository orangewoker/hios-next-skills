# Seedance 2.5 Higg短｜单时间轴契约

## 知识与输出分离

本契约只压缩公开输出，不删除后台知识。按入口路由完成事实防火墙、镜头诊断、表演、空间、光学、摄影机、物理、灯光、声音、参考权限、连续性和风险判断后，把必要结果就地写入相关时间拍；不为这些判断建立重复栏目或中间文档。

导演母版的剧情硬事实、对白、总时长和最终结果必须保留；原镜数、原切点、原切型、景别、构图、运镜、焦点、表演外化、光影、物理与声音属于可强化技法。时间轴可以重新切分镜头和时间拍，但不得改变主剧情与关键因果。

## 成功输出形态

只输出一个 fenced Markdown 代码块，代码块外零文字。代码块内只允许一个标题且必须独占一行：

```text
【时间轴】
(00:00-00:03) [Slow Dolly In] [镜头与构图；完整第一帧；触发→动作路径→表演/道具/环境/声音反馈→对白/口型→拍尾状态]
(00:03-00:XX) [Side Tracking] [本拍变化；切镜承接；摄影机、物理、光影、声音与拍尾状态]
```

不得出现 `【生成模式】`、`【场景与全局锁定】`、`【参考体映射】`、`【空间地图】`、`【光学与摄影机】`、`【物理反馈】`、`【角色表演】`、`【连续性接口】`、`【结束状态】` 或任何其他 `【……】` 标题。

标题后的第一个非空行必须是可解析且从 `00:00` 开始的时间拍，不得在第一拍前插入说明性文本或固定音频句。

每个时间拍必须在时间码后紧接一个且仅一个 `camera-move-tags.md` 允许的英文主运镜标签。标签只负责快速识别主运镜，不能替代本拍中文正文中的摄影机物理路径和可见结果。

## 每拍职责

每拍只承担一个主要任务，推荐顺序：

`英文主运镜标签 → 镜头与构图 → 当前状态 → 触发 → 连续动作 → 反馈 → 对白/口型 → 拍尾稳定状态`

- 第一拍写全生成首帧所需的人物、左右、朝向、姿势、手部、道具、地标、摄影机侧、主光和声音。
- 中间拍只写发生的变化与防止真实漂移所需锚点。
- 切镜拍说明切型、原因、下一镜主体/位置与上一拍镜尾承接。
- 最后一拍通过可见动作到达最终状态，不只宣告结果。
- 人物、场景、道具、参考权限、表演、物理、灯光、声音和连续性只在实际相关拍就地写入。
- 参考权限在后台核对，时间轴只写授权后的必要可见锚点；不得输出箭头映射、权限说明、图号、文件名或参考元信息。
- 强化动作、速度、紧张、压迫或冲击的时间拍，必须同步写入摄影机的有动机起止、运动方向、速度曲线、视差或焦点结果以及拍尾落点；若母版明确固定或因果读取要求稳定，则写清固定功能和画内动势，不能让强化退化为人物独自表演。

## 时间码

- 第一拍从 `00:00` 开始。
- 相邻拍首尾相接，无空隙、无重叠。
- 最后一拍结束时间等于母版总时长。
- 分钟与秒字段使用两位数；秒字段小于 60。
- 关键接触、反应、口型切换、落地或道具变化可用 0.5—1 秒；普通过程使用 2—5 秒。
- 每拍结束在可生成、可承接的状态。
- `--duration` 必须有限且大于 0。
- `--segment-cap` 必须为 15 或 30，母版总时长不得超过对应硬上限。已知生产选择时使用原选择；只有独立片段且选择记录不可得时，时长不超过 15 秒使用 15，超过 15 且不超过 30 秒使用 30。

## 对白账户

每句锁定对白固定写成：

`（说话人｜声源属性）“正文”`

所有标记的数量、顺序、说话人、声源属性、正文和标点必须逐项等于按顺序传入的 `--dialogue "说话人｜声源属性｜正文"` 参数。不得出现未结构化的引号对白、额外对白、错人、错声源、换序或标点变化。

说话者对口型，听者闭口；观众专属 OS 闭口且场内不可听；录音、旁白和画外声保留来源及场内可听范围。

## 中文、英文、人物文件与引用证明

普通描述、摄影、风格和技术说明使用中文。允许英文包括：

- 每拍一个来自 `camera-move-tags.md` 的英文主运镜标签，不需要来源证明。
- 通过 `--allow-character-token` 明确声明的英文人物名、人物简称或角色代号，不需要来源证明。
- 通过 `--allow-asset-filename` 明确声明的人物素材文件名或其实际使用的文件基名，不需要来源证明。
- 锁定对白内原样存在的英文。
- 当前母版中原样存在并通过 `--allow-english-token` 与 `--source-file` 精确证明的非技术标识。
- 当前母版中原样存在并通过 `--source-file` 精确证明的自动 `@/#` 引用。

除受控主运镜标签外，摄影、风格与技术英文即使存在于来源也不得使用普通白名单放行。人物英文与人物素材文件名只解除英文词面拦截，不得用来替代可见外形锚点或输出参考权限箭头映射。自动引用必须包含至少一个字母或数字，并与正文用空格或标点分隔；纯下划线/连字符、粘连正文、相似前缀或只出现子串均拒绝。引用出现在锁定对白中也必须完成来源证明。

## 禁止省略

不得使用“同上”“同前”“照旧”“接上段”“继续上一段”“沿用上一段”“沿用上一镜”或“与前文一致”等跨段省略。每个独立提交片段必须自包含。

## 验证

```powershell
python scripts/check_prompt_structure.py prompt.md --duration 15 --segment-cap 15 --dialogue "林岚｜现场对白｜门外有人。" --allow-character-token "Raven" --allow-asset-filename "P07_Raven.png" --allow-english-token "Q-17" --source-file director-higg-short.md --json
python scripts/check_prompt_risk.py prompt.md --dialogue "林岚｜现场对白｜门外有人。" --json
```

结构检查器验证单代码块、唯一独占标题、首行时间拍、每拍唯一受控运镜标签、时间码、硬上限、对白账户、人物英文/文件名声明、其他英文与引用来源、跨段省略。风险检查器验证风险词和严格对白豁免。两个检查器不能替代人工判断事实、因果、表演、参考权限和画面质量。
