# 剧本结构模板

## 标准短剧结构

| 幕 | 功能 | 时长占比 | 关键问题 |
|---|---|---|---|
| 开场钩子 | 让观众立刻知道"这是什么世界" | 0-10% | 谁在？缺什么？ |
| 激励事件 | 打破平衡的事件 | 10-25% | 什么变了？ |
| 上升行动 | 阻力与代价 | 25-50% | 每一步更难吗？ |
| 转折 | 真相揭露或选择 | 50-75% | 主角知道什么观众也知道？ |
| 高潮 | 最大压力下的选择 | 75-90% | 主角付出什么？ |
| 释放 | 情绪着陆 | 90-100% | 观众带走什么？ |

## 镜头卡字段

| 字段 | 说明 |
|---|---|
| 镜号 | 集-镜序号，如 EP1-03 |
| 时长 | 建议 4-10 秒（LibTV 视频模型最短 4s） |
| 景别 | 大远景/远景/中景/近景/特写/微距 |
| 画面 | 可见主体、动作、终点 |
| 镜头 | 运动、起点、终点 |
| 灯光 | 光源、方向、色温、氛围 |
| 声音 | 对白/环境声/音效/音乐/静默 |
| 角色标签 | Character A / Character B / 产品 A |
| 连续性锁 | 服装、道具、位置、屏幕方向、光源 |
| 生成模式 | T2V / I2V / V2V / R2V / FLF2V |
| 备注 | 反套路、版权、平台特殊要求 |
