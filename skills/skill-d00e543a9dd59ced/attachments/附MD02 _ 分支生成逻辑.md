#  附MD02 | 分支生成逻辑

**所属主SKILL：** 互动影游Agent | 自动串联调度下层Skill\
**版本：** V2.1 融合合规修订版

## #做什么

本模块为互动影游Agent的骨架生成器。

将120分钟线性剧本自动拆解为100+分支树，解决行业“分支越多、成本越指数级上升”的痛点。确保每个分支都有独立情绪线、合理因果链和可玩性。

## #需要什么输入

**最少提供：**

- 线性剧本或故事大纲
- 关键抉择点标记（人工预设或AI识别）
- 目标分支数量（如10个、100个）

**可选提供：**

- 路线设计偏好（A线/B线/隐藏线）
- 结局数量与类型偏好
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。分支生成环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则。

### 二、关键抉择点识别

自动扫描剧本，标记三类抉择点：

1. 人物关系转折点。
2. 信息揭露点。
3. 道德困境点。

### 二之二、抉择点双轨校验标准（强制，按70_15 LOCK执行）

互动影游的抉择点设置，必须以情节为主、时间为辅、双轨交叉校验。

1. 主轨道（情节）：抉择点必须落在以下五类情节节点上。

   - 人物关系转折点
   - 信息揭露点
   - 道德困境点
   - 资源分配点
   - 路线锁定点

2. 辅轨道（时间）：

   - 任意5分钟内至少1个抉择点。
   - 任意3分钟内不超过3个抉择点。

3. 抉择点四级分级：

   - S级·路线锁定点：决定后续主线走向，不可逆，全片不超过5个。
   - A级·变量影响点：改变关键变量，影响结局，全片不超过15个。
   - B级·情绪分支点：改变对白与情绪，不改主线，可密集分布。
   - C级·微观抉择点：仅影响小范围变量，可密集分布。

4. 零假选项铁律：任何抉择点必须真实改变至少一项变量或后续节点，否则判定为假选项，必须删除。

5. 密度校验：生成分支树后，必须逐幕检查抉择点密度是否达标，不达标必须补充微观抉择。

### 三、分支树自动生成

1. 基于抉择点，生成N条平行剧情线。
2. 每条线保持独立情绪弧光。
3. 每条分支必须有独立的剧情梗概（50-200字）。
4. 节点命名必须遵循规范：主线节点用N+两位数字，路线节点用N+两位数字+路线代号。

### 四、因果链校验

1. 每个分支的后续剧情必须与前置选择逻辑自洽。
2. 禁止机械外挂式转折。
3. 所有选择必须真实改变至少一项变量或后续节点。

### 五、分支合并机制

1. 允许不同分支在特定节点重新汇合。
2. 合并后必须保留选择感，可通过变量差异、对白差异、情绪差异体现。
3. 合并节点必须明确标注为收束节点。

### 六、算力预算分配

1. 根据分支重要程度，自动分配视频生成算力。
2. 核心分支用视频生成，次要分支可用文字或静图处理。
3. 算力分配必须遵守总制片人的算力预算审查红线。

### 七、生成与合成

根据上述分支生成规则，调用底层视频生成Skill，输出MP4视频文件。
