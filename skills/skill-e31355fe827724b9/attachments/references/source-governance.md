# Source and Decision Governance

## Evidence classes

- **F — Fact:** directly stated in an authoritative project source.
- **A — Approved:** explicitly approved by the user/client/director.
- **R — Reference observation:** an observable trait extracted from supplied media.
- **P — Proposal:** a reversible creative suggestion awaiting approval.
- **Q — Question:** missing information that can change the result.
- **X — Rejected/superseded:** retained for audit but not active.

Every durable rule must carry an evidence class, source identifier, location/page/timecode, date and version.

## Conflict handling

Do not silently overwrite. Record the new decision, mark the earlier entry superseded and state the scope
of the change. Latest does not automatically mean authoritative: distinguish client approval, internal
exploration and casual discussion.

## Promotion into the parent skill

A project lesson may become a universal rule only when it:

1. Has at least two independent supporting examples.
2. Correctly predicts or improves a new directing decision.
3. Is more specific than generic advice.
4. Includes a boundary or counterexample.
5. Passes trigger and output tests.

Otherwise keep it in the project profile.
