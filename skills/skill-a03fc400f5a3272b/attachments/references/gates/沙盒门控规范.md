# 沙盒门控规范（Sandbox Gate）

> **本文件是"一步一确认"机制的单一信源。**
> **硬约束**：每个文件完成后必须立即停、落盘 checkpoint、输出摘要与决策点、等待用户回复。

## 1. 适用范围

| 命令 | 门控 | 深度档 |
|:---|:---:|:---:|
| `/开始` | ❌ | —（由 init_project.py 自身 13 题 AskUserQuestion 处理） |
| `/创作方案` | ✅ | 深档（5-6 决策点） |
| `/角色开发` | ✅ | 中档（3-4 决策点） |
| `/物品档案` | ✅ | 浅档（1-2 决策点） |
| `/场景档案` | ✅ | 浅档（1-2 决策点） |
| `/资产提示词 all` | ✅ | 中档（3-4 决策点） |
| `/目录` | ✅ | 深档（5-6 决策点） |
| `/分集 {N}` | ✅ | 深档（5-6 决策点）——混合确认模式 |

## 2. 工作流（每个文件强制 5 步）

```
[1] 读取 references（以 _routing.yaml 为单源真理）
        ↓
[2] 写入产物文件
        ↓
[3] 落盘 checkpoint：
    echo '[{...}]' | python scripts/sandbox_gate.py write \
        --command /<命令> --product <产物> --project-dir <dir> \
        --summary "<200-400字>" --decision-points-stdin \
        --references-read <列表>
    → 在产物首部追加 Checkpoint-Source 引用
        ↓
[4] 校验：python scripts/sandbox_gate.py verify --command /<命令> --project-dir <dir>
        ↓
[5] 输出摘要 + 决策点 + 半结构化菜单 → 等待用户回复
```

## 3. 摘要与决策点

### 摘要（200-400 字）
包含：产物核心内容概括、关键创意决策、与前置产物的衔接关系、潜在风险点（如有）。

### 决策点格式

```json
[
  {"id":1, "dimension":"维度名", "question":"关键问题", "ai_choice":"AI选择", "reason":"选择理由"}
]
```

### 半结构化菜单
```
请回复：
· 点头 — 回复「继续」或「确认」推进下一文件
· 修改决策点 — 回复「2:N=你的选择」
· 修改文件段 — 回复「3:具体修改要求」
· 重跑 — 回复「4」从本步骤重新执行
· 回退 — 回复「5:M=产物路径」回退到指定步骤
· 暂停保留 — 回复「6」或「暂停」
```

## 4. 安全命令（零弹窗红线）

**禁止命令**（绝对黑名单，出现即 IDE 弹窗拦截）：
- PowerShell：`Remove-Item` / `Remove-Item -Recurse -Force` / `del` / `del /s /f /q`
- Bash：`rm -rf` / `rm -fr` / `rmdir -rf`

**强制替代**：
- 创建/覆盖文件 → `Write` 工具
- 局部修改 → `Edit` 工具
- 删除文件 → `python scripts/_file_ops.py remove <path>`
- 删除目录 → `python scripts/_file_ops.py rmtree <path>`
- 回滚 → `python scripts/sandbox_gate.py rollback --command /<cmd> --product <path> --force`

**临时文件禁止**：禁止创建 `tmp_` / `.tmp` 前缀临时文件。决策点 JSON 通过 `--decision-points-stdin` 管道传入，不先落盘。

## 5. Checkpoint 累积

命名：`.state/checkpoints/{命令}-{ts}-v{n}.md` + `.json`

每次修改产物后重新 `sandbox_gate.py write`（version+1）。产物首部必须追加 `> Checkpoint-Source: {rel}.md@{hash8}`。

## 6. 错误兜底

| 防线 | 机制 |
|:---|:---|
| Hash 引用 | 机器可验证产物与 checkpoint 是否绑定 |
| 强约束提示 | SKILL.md 顶部硬约束不允许一口气跑完 |
| 不静默失败 | verify exit 1 → 明确报告，不假装通过 |
| 自动回滚 | `sandbox_gate.py rollback` 支持回退至指定步骤 |

## 7. 未读 Reference 门控

`--references-read` 参数记录 AI 读取的 reference 文件。`verify` 时检查：声明已读但文件不存在 = 阻断；声明已读但 hash 不匹配 = 阻断。
