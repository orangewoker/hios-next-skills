# 图片安全审核失败回退策略

仅当 `character_reference` 或 `product_reference` 明确因安全审核失败时触发；网络错误、超时、模型繁忙和画质问题不适用。

1. 原模型审核失败：原始提示词完全不变，切换 Navo Pro。
2. Navo Pro 仍审核失败：同一原始提示词完全不变，切换 Navo2。
3. Navo2 仍审核失败：仅最小化调整可能触发审核的合规措辞后重试。
4. 仍失败：停止并提出不改变微缩闯关核心目标的安全替代方向。

不得用谐音、错拼、编码、拆分或伪装受限内容绕过审核。允许的最小调整包括明确成年、移除第三方肖像/明星复刻、移除不必要的性化或危险化表达，同时保留微缩尺度、日常大场景和安全闯关目标。
