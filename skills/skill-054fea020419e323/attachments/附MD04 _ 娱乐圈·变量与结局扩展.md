# 附MD04 | 娱乐圈·变量与结局扩展

**所属主SKILL：** 娱乐圈·养成逆袭 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“变量设定空洞、结局无分支”的痛点，确保选择真实改变命运。

## #需要什么输入

- 核心变量清单
- 路线设计

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 人气值：counter，0-100；≥60当红；&lt;20查无此人。
2. 业务能力：counter，0-100；≥60实力派；&lt;30花瓶。
3. 资本好感：faction，0-100；≥70受捧；&lt;20被资本抛弃。
4. 黑粉/负面舆论：risk，0-100；≥80面临封杀风险。
5. 粉丝忠诚度：relationship，0-100；≥80战斗力强。

道具与旗标变量

1. S级剧本：item，false；true且业务能力≥60可冲击影后/影帝。
2. 顶级公关团队：item，false；true可降低黑粉值。

### 二、结局体系（共15个）

正结局（5个）

1. E01·顶流巅峰：人气≥80，资本好感≥70。
2. E02·实力影后/影帝：业务能力≥80，获得S级剧本。
3. E03·资本大鳄：转型成为幕后老板。
4. E04·完美偶像：粉丝忠诚度极高，口碑极佳。
5. E05·真爱隐退：放弃名利，与真爱远走高飞。

坏结局（10个）

1. D01·全网封杀：黑粉值≥90。
2. D02·资本弃子：资本好感&lt;10。
3. D03·塌房退圈：爆出丑闻（特定节点触发）。
4. D04·过气小透明：人气&lt;10。
