# 时长校验规则

本文档定义配音时长与镜头时长的自动校验逻辑，确保剧本/分镜中的台词能在分配的镜头时间内自然说完。

---

## 一、语速基准

### 1.1 中文语速

| 语速类型 | 每秒字数 | 适用场景 |
|---------|---------|---------|
| 慢速 | 2-3 字/秒 | 品牌宣传片、情感类、高端奢华风格 |
| 正常 | 3-4 字/秒 | 日常种草、生活方式、科普介绍 |
| 快速 | 4-5 字/秒 | 促销广告、快节奏信息流、短视频 |

### 1.2 英文语速

| 语速类型 | 每秒词数 | 适用场景 |
|---------|---------|---------|
| 慢速 | 1.5-2 词/秒 | 品牌宣传、正式场合 |
| 正常 | 2-2.5 词/秒 | 产品介绍、日常对话 |
| 快速 | 2.5-3 词/秒 | 广告促销、信息密集 |

### 1.3 其他语言参考

| 语言 | 每秒音节数 | 备注 |
|------|-----------|------|
| 日文 | 3-4 音节/秒 | 含假名+汉字混合 |
| 韩文 | 3-4 音节/秒 | — |
| 西语/法语 | 3-4 音节/秒 | 语速较快 |

## 二、配音时长计算公式

### 2.1 基础公式

```
预估配音时长（秒） = 字符数 / 每秒字数

中文：字数 ÷ 语速（字/秒）
英文：词数 ÷ 语速（词/秒）
```

### 2.2 修正因子

实际配音时长还需考虑：
- **数字/英文单词混入**：每个数字或英文单词按 0.5 秒计算
- **标点停顿**：逗号 0.3 秒，句号 0.5 秒，问号/感叹号 0.5 秒
- **语气词/停顿标记**：（停顿）、（...）等按实际标记时长计算

### 2.3 计算公式（完整版）

```
预估时长 = 
  中文字符数 / 中文字速 
  + 数字/英文单词数 × 0.5 
  + 逗号数 × 0.3 
  + 句号/问号/感叹号数 × 0.5 
  + 显式停顿标记时长
```

## 三、校验规则

### 3.1 校验时机

| 校验节点 | 校验内容 | 触发条件 |
|---------|---------|---------|
| 剧本生成后 | 总时长匹配 | 每次生成/修改剧本 |
| 分镜生成后 | 镜头时长匹配 | 每次生成/修改分镜 |
| 用户修改后 | 受影响的镜头时长 | 任何修改操作 |
| 成片前 | 全链路时长终审 | 进入第九阶段前 |

### 3.2 校验标准

**合格条件（全部满足）：**

| 校验项 | 合格标准 | 不合格处理 |
|--------|---------|-----------|
| 总时长 | 实际总时长与目标时长误差 ≤ 1秒 | 调整最后一个镜头或整体缩放 |
| 单镜头时长 | 配音预估时长 ≤ 镜头分配时长 × 0.9 | 延长该镜头或精简台词 |
| 片头时长 | ≤ 总时长 × 1/4 | 缩短片头或调整总时长 |
| 片尾时长 | ≤ 总时长 × 1/4 | 缩短片尾或调整总时长 |
| 片头+片尾 | ≤ 总时长 × 1/3 | 缩短片头片尾或调整总时长 |

**缓冲系数说明：**
- 配音时长不超过镜头时长的 90%，留 10% 作为呼吸/停顿空间
- 避免台词塞太满，影响听感

### 3.3 校验失败处理

**情况1：某镜头配音超时**
```
镜头X：台词35字，预估时长10秒，分配时长8秒
→ 自动处理方案：
  方案A：延长该镜头至10-11秒（调整后续镜头时间码）
  方案B：精简台词至28字以内（保持8秒）
  方案C：拆分为两个镜头
→ 优先尝试方案A，若导致总时长超限则尝试方案B
```

**情况2：总时长不匹配**
```
目标时长15秒，实际总时长18秒
→ 自动处理：
  1. 优先压缩非核心镜头（非卖点、非CTA镜头）
  2. 若仍超，按比例缩短所有镜头
  3. 最后手段：建议用户调整目标时长
```

**情况3：片头/片尾超时**
```
→ 自动缩短片头/片尾至合规时长
→ 若无法压缩（如用户指定内容），提醒用户调整总时长
```

## 四、自动调整逻辑

### 4.1 调整优先级

当校验失败需要调整时，按以下优先级处理：

1. **延长镜头时长**（首选，不影响内容）
   - 前提：调整后总时长仍在合理范围
   
2. **精简台词**（次选，保持画面不变）
   - 原则：保留核心信息，删除冗余修饰词
   - 示例："这款产品真的非常非常好用" → "这款产品非常好用"
   
3. **拆分镜头**（影响结构，慎用）
   - 将一个长镜头拆为两个短镜头
   - 需要重新计算时间码
   
4. **建议调整目标时长**（最后手段）
   - 当内容确实无法压缩时

### 4.2 调整记录

每次自动调整后，记录：
```
【调整记录】
- 调整原因：[校验失败原因]
- 调整内容：[具体修改了什么]
- 调整结果：[调整后的状态]
- 是否影响下游：是/否（如影响，需级联更新）
```

## 五、多语言混合场景

### 5.1 中英混合台词

```
示例："这款产品采用AI技术，让你work smarter"

计算方式：
- 中文部分："这款产品采用技术让你" = 11字 ÷ 3.5字/秒 = 3.1秒
- 英文部分："work smarter" = 2词 ÷ 2词/秒 = 1秒
- 总预估：3.1 + 1 = 4.1秒
```

### 5.2 纯英文广告

- 全部按英文语速计算
- 注意：英文单词间的连读可适当缩短时长

## 六、特殊场景处理

### 6.1 无台词镜头

- 纯画面/音乐镜头：时长完全由画面内容决定
- 校验重点：节奏是否与整体匹配

### 6.2 长台词镜头

- 单镜头台词超过 20 秒：建议拆分
- 原因：长镜头容易让观众疲劳，且视频生成质量下降

### 6.3 快速切换镜头

- 连续多个短镜头（每个<2秒）：检查是否过于碎片化
- 建议：适当合并或使用统一转场

## 七、校验输出格式

### 7.1 校验通过

```
✅ 时长校验通过
- 总时长：15秒（目标15秒，误差0秒）
- 各镜头配音时长均合规
- 片头2秒（13%）+ 片尾2秒（13%）= 27% < 33% ✓
```

### 7.2 校验失败（已自动调整）

```
⚠️ 时长校验：已自动调整
- 调整前问题：镜头3配音超时（8秒配音/6秒镜头）
- 调整方案：延长镜头3至9秒，后续镜头时间码顺延
- 调整后总时长：16秒（原目标15秒，超出1秒）
- 建议：接受当前方案 / 精简镜头3台词以压缩时长
```

### 7.3 校验失败（需用户决策）

```
❌ 时长校验失败，需要您决策
- 问题：[具体问题描述]
- 建议方案：
  A. [方案A]
  B. [方案B]
  C. [方案C]
请选择或告诉我您的想法。
```

## 八、与其他模块的联动

| 模块 | 联动方式 |
|------|---------|
| 剧本模板 | 台词字数直接影响时长计算 |
| 分镜模板 | 镜头时长分配需通过校验 |
| 合规检查 | 台词修改后需重新合规检查 |
| 视频生成 | 镜头时长是视频生成的关键参数 |
