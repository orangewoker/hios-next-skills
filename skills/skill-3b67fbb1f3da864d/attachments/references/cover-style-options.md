# 视频封面风格

在询问或生成视频封面时读取本文件。封面借鉴阿囤囤风格的真人抠图、超大标题、#FDFFA7/白色、粗黑描边、绿色勾选、贴纸、箭头和高密度构图，但比例跟随视频画幅。

## 封面制作卡

生成媒体前，单独建立一张封面制作卡，不能只在视频分镜中顺带提一句。制作卡必须包含：

1. 最终封面标题；
2. 风格编号与名称；
3. 输出画幅与建议尺寸；
4. 主体素材、人物或原文图片；
5. 主体位置、标题区域和信息层级；
6. 字体气质、主色和强调色；
7. 必须保留与必须避免的元素。

封面是独立静态图片交付物，不属于视频时间线。生成封面时创建独立图片任务；不得用视频首帧、任意截图、提示词或制作卡文字代替最终封面图。

## 风格选择

向用户展示以下编号选项：

1. **爆款大字压顶风** — 顶部超大标题，人物居中，适合强钩子
2. **巨字拆分冲击风** — 2—4 个核心大词围绕人物，适合概念和认知
3. **小白科普问答风** — 黑灰或界面背景、问号、解释感
4. **教程清单风** — 人物指向 3 条绿色勾选清单，适合步骤教程
5. **产品测评榜单风** — 大数字、箭头和维度标签，适合测评和榜单
6. **种草推荐风** — 人物点赞、emoji 和温暖背景，适合资源推荐
7. **贴纸拼贴入门风** — 人物、截图、Logo 和小卡片组合
8. **黑底效率工作流风** — 深色工具墙、#FDFFA7/白色大字和绿色清单
9. **手指屏幕证据风** — 手指指向电脑中的原文截图、结果或数据，适合教程和案例
10. **原图大字无人物风** — 以原文主图、截图或图表为主体，叠加超大标题
11. **不单独生成封面**
12. **根据内容自动选择**

## 人物和参考图

- 风格 1—8 必须使用与出镜方式匹配的用户参考图：露脸时上传 1 张清晰人脸照或 2—3 张同一人物照片；不露脸时上传手部、半脸边缘、侧脸轮廓或身体局部参考图。两种情况都不得使用默认人物。
- 风格 9 必须使用用户上传的手部、侧身或桌面局部参考图。不要凭空生成一个默认人物或默认博主。
- 用户明确不露脸但选择人物类风格时，局部参考图即可，不再额外要求清晰正脸照。
- 用户没有任何人物或局部参考图时，推荐风格 10；自动选择也只能选风格 10 或使用现有品牌/产品素材。

## 快速风格规则

### 1. 爆款大字压顶风

标题占上方约 35%—45%，人物位于中下方约 45%，背景轻微虚化，少量箭头、emoji 或贴纸强化情绪。

### 2. 巨字拆分冲击风

把标题拆成 2—4 个巨大词块，用 #FDFFA7 和白色交替，人物夹在字块之间，背景压暗。

### 3. 小白科普问答风

人物托腮、认真解释或指向标题，配大问号和 2—3 条绿色标签，背景使用黑灰海报、模糊界面或真实室内。

### 4. 教程清单风

人物指向侧边 3 条绿色勾选清单，原文截图作为结果证据；顶部使用 `#FDFFA7` 与白色混排的超大教程标题，全部加粗黑描边。

### 5. 产品测评榜单风

突出大数字、产品卡片、粗箭头和测评维度；人物指向数字或卡片，深色背景增强对比。

### 6. 种草推荐风

人物点赞或分享，使用圆润粗黑体、温暖室内背景、爱心或工具贴纸，标题亲切但醒目。

### 7. 贴纸拼贴入门风

人物居中，原文图片、截图、Logo 和工具卡片围绕人物错落排布，使用白色边框和轻投影。

### 8. 黑底效率工作流风

深色工具墙或模糊界面背景，#FDFFA7/白色大标题，侧边绿色收益清单，人物位于前景。

### 9. 手指屏幕证据风

电脑屏幕展示原文截图、图表或产品结果，手指明确指向关键区域；标题置于顶部或侧边，不遮挡屏幕证据。

### 10. 原图大字无人物风

选择最能证明主题的原文图片作为主体或卡片，使用超大标题、粗黑描边、箭头和少量标签；不得为了模仿人物封面而虚构人物。

## 细调封面流程

只有用户明确要求细调封面时执行。一次只问一个编号选择题，已提供的选项直接跳过。
每次提问时，把下列斜线分隔的选项展开成编号列表；不要用开放式问题收集偏好。

1. **参考图**：人物类要求图 1 人物参考；不露脸要求手部或局部参考；风格 10 跳过。
2. **人物动作**：张嘴震惊 / 双手点赞 / 指向标题 / 托腮疑惑 / 举拳自信 / 双手打开讲解 / 手指电脑屏幕 / 交给模型决定。
3. **额外素材**：优先自动使用 Markdown 图片；仍需额外素材时询问 1 张 / 2 张 / 3 张以上 / 不增加。
4. **背景**：室内暖光 / 黑灰科技海报 / 深色工具墙 / 模糊软件界面 / 高饱和撞色 / 自动。
5. **字体**：综艺超粗黑体 / 漫画爆款标题字 / 圆润粗黑体 / 科技感粗黑体 / 粗标题加手写涂鸦 / 自动。
6. **颜色**：#FDFFA7 加粗黑描边 / 白色加粗黑描边 / #FDFFA7 与白色混排 / #FDFFA7 加白色高光 / 深底白字加 #FDFFA7 关键词 / 自动。
7. **标题**：文章原题不自动作为封面标题。根据文章提炼 3 个 4—10 字的编号候选；“快速默认”“直接生成”或“你决定”模式自动采用最强候选，其他模式让用户选择后原样使用。若用户明确提供较长封面标题，保留文字并通过分行和层级适配，不自行改写。

## 通用视觉规范

- 视频封面比例跟随视频，默认 9:16；只有用户明确要求小红书图文封面时使用 3:4。
- 建议输出尺寸：9:16 使用 1080×1920，16:9 使用 1920×1080，3:4 使用 1080×1440，1:1 使用 1080×1080；平台不支持指定尺寸时保持对应比例并优先最高可用清晰度。
- 主标题优先 4—10 个字，是视觉第一优先级，使用超粗黑体、漫画标题字或短视频大字；用户明确确认的较长封面标题通过分行适配。
- 黄色统一使用柔和浅黄色 `#FDFFA7`；可与纯白混排，必须使用粗黑描边。不要使用荧光黄、金黄或偏橙黄色。
- 人物占画面约 35%—55%，边缘使用 #FDFFA7、白色或高对比亮色描边；标题不得遮挡眼睛和嘴巴。
- 原文图片可作为产品卡片、屏幕证据、模糊背景或贴纸素材，但不得遮挡关键内容。
- 使用绿色勾选、#FDFFA7 箭头、问号、emoji、贴纸和小卡片强化信息；避免极简留白、细字体、冷淡杂志风和低对比灰字。
- 标题、脸部、屏幕证据、清单和品牌元素必须位于安全区。

## 生成后检查

- 已得到可预览的独立静态图片，不是视频画面截图或文字方案。
- 标题与制作卡完全一致，没有错字、漏字或擅自改写。
- 比例与视频一致，主体、标题和关键信息均处于安全区。
- 人物类封面使用了用户参考图；无参考图时没有虚构人物。
- 封面与视频主题和视觉锚点一致，但在小尺寸信息流中仍具有独立辨识度。

## 自动选择

- 强钩子或经验公开：1。
- 概念、认知、能力：2 或 3。
- 教程、部署、流程：4；已有手部参考和关键截图时可选 9。
- 测评、榜单、横向比较：5。
- 推荐、资源、播客、工具：6。
- 入门、组合、工作流搭建：7。
- 效率方法、工具组合：8。
- 没有人物参考图：10。
