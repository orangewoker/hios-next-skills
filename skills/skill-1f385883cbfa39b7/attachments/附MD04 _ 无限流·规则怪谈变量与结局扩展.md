# 附MD04 | 无限流·规则怪谈变量与结局扩展

**所属主SKILL：** 无限流·规则怪谈 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“无限流·规则怪谈”的专属变量系统与结局体系扩展库。解决“变量设定空洞、结局无分支、选项假大空”的痛点。

## #需要什么输入

**最少提供：**

- 核心变量清单
- 路线设计
- 生存者与副本规则设定

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 理智值：counter，0-100，默认100；&lt;30精神崩溃；=0直接发疯。
2. 污染度：risk，0-100，默认0；≥70出现幻觉；≥90异变死亡。
3. 线索值：counter，0-100，默认0；≥60看破规则漏洞；&lt;30盲人摸象。
4. 存活天数：counter，0-99，默认0。
5. 规则违背次数：counter，0-3，默认0；=3强制抹杀。

道具与旗标变量

1. 核心规则残页：item，false；true可免除一次规则惩罚。
2. 免疫符：item，false；true可在短时间内免疫污染。
3. 隐藏钥匙：item，false；true可开启真结局大门。

### 三、结局体系（共15个）

正结局（5个）

1. E01·破局者：线索值≥60，规则违背次数≤1。
2. E02·幸存者：存活天数达标，成功离开副本。
3. E03·成神之路：看破无限流本质，掌控主神空间。
4. E04·终极救赎：解放所有轮回者，摧毁系统。
5. E05·同归于尽：与最终BOSS一起被抹杀，但拯救了队友。

坏结局（10个）

1. D01·规则抹杀：规则违背次数=3。
2. D02·理智崩溃：理智值=0。
3. D03·异变怪物：污染度≥90。
4. D04·死于非命：被护士长抓住。
5. D05·被队友背刺。

### 六、变量锚定规则（核心铁律）

1. 每个节点提示词末尾必须标注：节点ID+变量变化。
2. 变量名全部用英文（sanity/corruption/clue/days/violations），禁止中文变量名。
3. 禁止无意义变量。

### 八、生成与合成

根据上述规范，调用底层视频生成Skill，输出MP4视频文件。
