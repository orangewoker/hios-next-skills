# 输入契约

## 接受的输入

优先接受五列表格：

`镜号｜时长（s）｜场景｜人物｜提示词`

也可接受字段等价的 TSV、CSV、JSON 或结构化文件。

## 最低字段要求

每镜必须具备：

- 唯一镜号；
- 可解析时长；
- 非空提示词。

场景和人物字段可以用于资产核对，但不得被执行 Agent 改写。

## 解析原则

- Markdown 表格中的 `<br>` 是换行编码；
- CSV 的双引号仅作为字段包装时，不属于提示词正文；
- TSV、CSV、JSON 的解析不得改变字段内部标点、空格和换行；
- 无法确认某个字符是否属于正文时，停止并向用户核对；
- 不得使用语言模型“理解后重建”提示词。

## 无效输入

以下情况停止对应镜头：

- 提示词为空；
- 镜号重复；
- 时长缺失且工具必填；
- 表格断裂导致提示词无法完整提取；
- 提示词被省略为“同上”“见附件”；
- 一个单元格同时包含多个镜号且无法确定边界。

只报告问题，不得补写。
