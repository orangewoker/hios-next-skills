## 从叙事功能到画面选择

按此顺序决定：

`观众该注意什么 → 与谁站在一起 → 需要理解多少空间 → 何时发现信息 → 机位 → 景别 → 镜头族 → 构图 → 运动 → 光色`

不要从“35mm 推近”开始。先说明它要揭示、隐藏、压迫、疏离、连接还是重新排序关系。

## 景别与主观距离

| 景别 | 常见功能 | 风险 |
|---|---|---|
| 大远景/远景 | 地理、规模、孤立、命运压力 | 人物行动和表演不可读 |
| 全景 | 身体、阻碍、群体关系、调度 | 信息层级容易散 |
| 中景 | 动作与表情平衡、关系谈判 | 容易成为无立场的默认景别 |
| 近景 | 微表情、选择、信息控制 | 过早使用会透支强度 |
| 特写/大特写 | 物证、冲击、身体细节、主观锁定 | 缺少建立会失去尺度与意义 |

设计“距离进程”，而不是随机混用。问：何时第一次靠近？何时拒绝给近景？何时退远让角色承担空间后果？

## 机位、透视与镜头

### 先分清三个变量

- **机位/摄影机距离**决定透视关系：前后景尺寸差、面部近大远小、空间拉伸感。
- **焦距**在给定画幅与机位下决定视场与取景范围；换焦距后退回原构图会同时改变透视，因为机位变了。
- **光圈、对焦距离、传感器/底片尺寸与焦距**共同影响景深。

因此，不要写“长焦天然压迫”或“广角天然亲密”而不说明机位和空间。缺少技术条件时，用镜头族加假设：

- 广角环境型：靠近人物仍保留空间，强调前后景差与运动路径
- 标准观察型：减少明显夸张，适合让表演承担意义
- 长焦分离型：较窄视场、远距离观察、压缩可见空间层次

### 角度不是情绪快捷键

高低机位的意义取决于视线、身体姿态、建筑线条和上下镜头关系。低机位不自动等于强大；它也可能显得被困、幼小或怪异。给出具体因果。

## 构图与空间层次

构图先建立注意力层级，再谈规则。把 negative space（负空间）与 depth staging（纵深调度）当作叙事关系，不当作装饰。

### 注意力工具

- 尺寸与位置
- 明暗、色彩和清晰度对比
- 线条、方向与重复
- 运动和静止的反差
- 前景遮挡、框中框与负空间
- 视线、朝向与人物间距

### 关系构图

- **同框**显示人物如何共享、争夺或拒绝空间。
- **分割构图**用门框、墙线、反光或焦平面表达隔离。
- **前景压迫**让权力、监视或未说出口的第三方占据画面。
- **负空间**必须对应等待、缺席、威胁方向或即将进入的信息；不要仅为“高级”。
- **中心构图**可表达秩序、审判、仪式或困住；是否稳定取决于周围力量。
- **边缘构图**可制造逃离、被挤压、窥视或即将出框的张力。

### 深度调度

同时设计前景、中景、后景的叙事职责。允许观众先看见后景威胁，也可以让焦点或遮挡延迟信息。不要把浅景深当默认；深焦能让观众在同一镜头中比较行动和后果。

## 摄影机运动

先选择“保持”还是“改变观众位置”。只有以下动机之一成立时才移动；所有 movement 都要是 motivated camera movement：

- 跟随重要行动
- 揭示此前被遮挡的信息
- 重新组织人物关系或权力
- 从客观观察过渡到主观卷入，或反之
- 与动作、声音或情绪波形形成节奏
- 让空间本身成为阻碍或发现

常用运动的功能不是固定的：

| 运动 | 可用功能 | 检查 |
|---|---|---|
| 推/移近 | 承诺注意、缩小选择、进入意识 | 靠近的触发点是什么？ |
| 拉/移远 | 暴露后果、孤立、重新给出环境 | 新出现的信息是什么？ |
| 横移 | 比较、跟随、揭开遮挡、重组层次 | 路径是否比切镜更有意义？ |
| 环绕 | 权力重排、眩晕、关系封闭 | 是否破坏轴线与背景连续？ |
| 手持 | 身体卷入、不稳定、现场感 | 幅度、频率和何时恢复稳定？ |
| 固定 | 观察、压迫、尴尬、让调度发生 | 画内是否有足够变化？ |

运动写法：`触发 → 路径 → 速度/质感 → 新构图 → 停止原因`。

## 光线、色彩与质感

从故事世界中的动机光源开始：窗、顶灯、火、屏幕、路灯、反射。再决定是否强化或违背真实。

逐场记录：

- 主光方向与硬软
- 明暗比和黑位是否保留信息
- 肤色与环境色的关系
- 色温/色相冲突
- 空气、反射、纹理与高光行为
- 本场与前后场的视觉变化

用色彩做系统：角色、地点、时间、虚实或情绪可以各有规则，但不要让每个象征只对应一个固定颜色。优先设计色彩如何变化、污染、退出或被另一套规则吞没。

## 画幅与竖屏

### 横幅

利用横向距离、并置、群体层级和进出方向。宽画幅并不要求把人物放到两端；空白必须有叙事职责。

### 9:16 竖屏

- 把关键面部、手部、道具和字幕留在平台 UI 安全区；具体安全区会变化，交付前查平台官方模板。
- 使用上下层次、纵深、门框、楼梯、前后景遮挡和人物高度差。
- 避免让同时重要的人物长期分散在画面左右边缘。
- 让动作路径有上下或纵深变化，少依赖长距离横向追逐。
- 先设计首屏是否可立即读懂人物、异常或未完成动作。

### 多画幅交付

若需横竖双版本，拍摄时保留重构空间并分别审查，不要假设中心裁切可自动成立。为关键镜头写出横版和竖版的注意力层级差异。

## 视觉连续与视觉反转

建立可重复的视觉语法，再让转折改变其中一个主变量：

- 远 → 近
- 同框 → 分离
- 稳定 → 漂移
- 深焦 → 隔离
- 对称 → 偏斜
- 被遮挡 → 暴露
- 暖色封闭 → 中性/冷色侵入

一次改变通常比所有变量同时变化更清晰。若全部改变，确保它对应全局性断裂。

## 构图检查

- 第一眼看哪里？第二眼看哪里？这顺序是否服务叙事？
- 画面中每个高对比元素是否值得抢注意？
- 人物与边缘、门、线条、地平线是否形成意外切割？
- 前中后景各自做什么？
- 负空间里等待的是什么？
- 如果换成静止、深焦或更远机位，是否更有力量？
- 这一镜与前后镜头的尺寸、方向、运动和色调如何形成关系？
