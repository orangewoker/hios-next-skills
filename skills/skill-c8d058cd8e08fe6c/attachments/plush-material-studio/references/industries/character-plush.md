## 1. 角色毛绒化的核心思路

把人物/IP角色转化为毛绒玩具形态——保留角色的核心辨识特征（发型、配色、标志性配饰），把身体材质替换为绒毛，比例调整为Q版卡通化，表情简化放大。

关键判断：角色的哪个特征最值得在毛绒化后保留？
- 发型有辨识力的 → 发型毛绒化，保留轮廓但变成绒毛质感
- 配色有辨识力的 → 忠于配色，毛绒材质增强色彩饱和度
- 表情/性格鲜明的 → Q版放大表情，眼睛做大、嘴巴简化

## 2. 角色类型与毛绒策略

### 真人角色毛绒化
- 把真人变成Q版毛绒人偶，保留发型和服装配色
- 毛绒类型：中绒饱满感，面部用短绒保持五官清晰
- 注意：面部绒毛要短而密，不遮挡五官；头发用中长绒保持蓬松

### IP/动漫角色毛绒化
- 忠于原设定配色和标志性特征，材质全替换为绒毛
- 毛绒类型：按角色性格选择（活泼角色中绒炸毛，温柔角色短绒丝滑，粗犷角色长绒蓬松）
- 关键：发型轮廓、标志性配饰（帽子、眼镜、武器）必须保留辨识

### 品牌吉祥物毛绒化
- 吉祥物本身就是品牌符号，毛绒化是它的"实体化"
- 毛绒类型：中绒经典毛绒玩具感，配色忠于品牌色
- 关键：logo位置、品牌色比例、标志性动作

## 3. Q版比例规格

| 部位 | 比例/规格 | 说明 |
|---|---|---|
| 头身比 | 1:1 到 1:1.5 | 大头小身，Q版核心 |
| 眼睛 | 占面部1/3到1/2 | 放大简化，黑亮圆眼 |
| 四肢 | 缩短圆润化 | 手臂不到腰，腿短粗 |
| 手脚 | 简化为圆球或椭圆 | 不画指头 |
| 躯干 | 梨形或椭圆 | 上窄下宽 |
| 鼻子 | 极简或省略 | 一个点或一个三角 |

## 4. 表情与性格毛绒化

- 开心：弯弯眼+大笑嘴，绒毛脸颊微鼓
- 治愈：半闭眼+小微笑，整体松弛
- 活泼：圆睁眼+张嘴笑，绒毛炸起感
- 害羞：低头+腮红点，绒毛顺服
- 困惑：歪头+小问号，绒毛微微竖起

## 5. 服装与配饰毛绒化

- 服装：保留配色和款式轮廓，材质替换为绒毛
- 配饰：标志性配饰保留形状但绒毛化（如毛绒帽子、毛绒眼镜框）
- 接缝线：在四肢、头部、躯干连接处保留毛绒玩具的拼合缝线，增强"玩具感"
- 标签：可在屁股或背后加一个小布标，写品牌名或角色名

## 6. prompt 句式库

### 真人角色毛绒化
```
Q版卡通毛绒风格，@图片1所示的人物转化为毛绒玩具形态，保留其发型轮廓和服装配色，头身比1:1，大头圆身短四肢，全身覆盖中绒毛绒材质，面部短绒五官清晰放大，眼睛大而黑亮，四肢连接处有毛绒玩具拼合缝线，柔和均匀光照，奶白色背景，治愈可爱氛围，3:4画幅
```

### IP角色毛绒化
```
Q版卡通毛绒风格，@图片1所示的角色变成蓬松毛绒玩具，忠于原设定配色和标志性发型，中绒炸毛质感体现活泼性格，圆睁大眼张嘴笑，穿着毛绒化的标志性服装，四肢圆润短小，拼合缝线可见，侧逆暖光照亮绒毛边缘，毛绒化场景背景虚化，1:1画幅
```

### 品牌吉祥物毛绒化（TVC）
```
Q版卡通毛绒风格，品牌吉祥物以经典毛绒玩具形态登场，忠于品牌色的中绒材质，圆润饱满，标志性动作到位，屁股上有品牌小布标，影视级柔和侧光，毛绒化品牌场景背景，16:9画幅
```

## 7. 落 prompt 前自检

- 角色核心辨识特征是否保留（发型、配色、配饰）？
- Q版比例是否到位（头大身小、四肢短圆）？
- 面部绒毛是否够短不影响五官？
- 表情是否匹配角色性格？
- 拼合缝线是否写了（增强玩具感）？
- 参考图是否正确引用？
- 品牌吉祥物的品牌色和logo是否到位？
