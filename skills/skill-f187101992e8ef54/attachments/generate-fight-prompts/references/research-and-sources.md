# 研究与来源

## 何时联网研究

当用户要求现实可信、特定兵器/体系、历史归属或专业招式名称时联网研究。只要创意动作且武器物理简单时，可说明使用常识性上位类别，不编造专有招式名。

## 来源优先级

1. 武术、击剑、兵器或体育官方组织与规则；
2. 博物馆、大学、档案馆和历史兵器收藏机构；
3. 有明确传承或资历的训练机构与教练；
4. 专业动作指导、特技和影视教育资料；
5. 有清晰演示和身份说明的视频；
6. 百科、论坛和社媒仅作线索。

关键事实尽量由两个独立可信来源支持。技术搜索只依赖原始或权威资料，不用无署名聚合转载支撑结论。

## 查询维度

- 武器原文名、类别、基础攻击、防守、步法和距离；
- 两种武器的距离与攻防关系；
- 武器重量、握持和轨迹；
- 动作摄影、命中反馈和一镜到底调度。

## 研究记录

记录动作名、原始名称、轨迹、距离、前置状态、可衔接回应、适用原因、事实/推断/创意标签和来源链接。

名称相同不代表动作相同；保留体系和来源语境。
