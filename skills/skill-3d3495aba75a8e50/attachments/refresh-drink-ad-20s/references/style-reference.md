# 样式说明

## 标准化爽感广告符（目标样式）
参考图1的核心特征：
- 白底或浅色清透背景
- 顶部大标题
- 统一的时间阶段结构
- 彩色圆角信息模块 / 模块化广告结构
- 冰块、水花、气泡、水果、杯体或罐体等爽感产品元素
- 底部五感总结 / 公式条 / 口号条
- 整体像“提案板 / 结构板 / 广告符”
- 不是镜头卡片拼贴，不是故事板

## 不希望的样式
图2式问题：
- 五个镜头画面卡片
- 明显像 storyboard
- 演员和产品一帧一帧排布
- 锁死视频模型想象空间

## 广告色卡
参考清透广告色卡：
- 8-14 个主要色块
- 色值清晰、命名清晰
- 配色来自产品、口味、环境与品牌重点色
- 版式专业、简洁、清透


## 广告符输入策略
生成广告符时，不要携带演员参考图、产品参考图和其他道具参考图。广告符是策略板，不是镜头复刻板。

## 必须保留的文字结构
- 每个阶段的时间标签
- 每个阶段的主标题/副标题
- 每个阶段 3-5 条节奏卖点 bullet
- 底部公式条/总结条
- 底部五感总结区（视觉、听觉、触觉、味觉、嗅觉）
