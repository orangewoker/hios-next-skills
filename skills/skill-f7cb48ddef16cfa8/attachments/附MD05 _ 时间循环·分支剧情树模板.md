# 附MD05 | 时间循环·分支剧情树模板

**所属主SKILL：** 时间循环 · 死亡回溯 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“剧情线混乱、分支无收束”的痛点。

## #需要什么输入

- 主线剧情节点清单、核心抉择点设计。

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·第一次死亡，惊醒（start节点）
2. N02 抉择点1·面对重复的早晨（branch节点）
   - N02A 恐慌、验证时间（心智值-10）
   - N02B 立刻采取行动，前往案发地（真相进度+10）
3. N03 试图警告警察（normal节点）
4. N04 抉择点2·发现身边的NPC（branch节点）
   - N04A 信任好友/搭档（共享线索，可能被背刺）
   - N04B 独自调查（安全，但缺少线索）
5. N05-N08 层层推进（如：锁定真凶、寻找炸弹、绝地反击）
6. ENDING_CHECK 结局判定

### 三、灵魂七问（每个抉择点必过审）

1. 玩家为什么选它？（求生、好奇心、救人）
2. 它改变了什么？（线索收集度、心智值）
3. 即时后果是什么？
4. 延迟后果在哪个循环出现？
5. 是否会导致循环次数过度消耗？
6. 是否有新的时间悖论产生？
7. 是否符合悬疑解谜的硬核逻辑？
