# 物品黏土化词库

## 质感转译

| 原始材质 | 黏土化改造 | prompt 句式 |
|---|---|---|
| 金属 | 亚光黏土表面，漫反射无金属光泽 | "金属转为亚光黏土表面，漫反射无金属反光" |
| 玻璃 | 不透明饱和色块，圆润边缘 | "玻璃转为不透明饱和黏土色块，圆润饱满边缘" |
| 布料 | 光滑黏土表面，无织物纹理 | "布料转为光滑黏土表面，无织物纹理，色块化" |
| 木质 | 均匀黏土色，无木纹 | "木质转为均匀黏土色，无木纹，亚光质感" |
| 食物质感 | 造型饱满圆润，色彩诱人 | "食物造型饱满圆润，色彩饱和诱人，表面有捏制痕迹" |

## 造型原则

- 所有棱角圆润化，无锐利边缘
- 细节简化为色块或浅压痕
- 比例可适当饱满化（比实物更圆润胖感）
- 表面保留指纹和工具压痕

## 物品类型

| 类型 | 关键改造 | 色调 |
|---|---|---|
| 食物（甜点） | 饱满圆润、奶油感、色彩诱人 | 高饱和暖色 |
| 食物（正餐） | 造型简化圆润、色彩分明 | 原色高饱和 |
| 花卉 | 圆片花瓣+球状花心 | 鲜艳高饱和 |
| 日用品 | 简化造型+色块装饰 | 原色高饱和 |
| 电子设备 | 圆润化+不透明色块 | 中性色调 |

## prompt 片段示例

```
黏土手工风格的草莓蛋糕，造型饱满圆润，三层叠加无锐利边缘。奶油转为光滑黏土表面，草莓简化为红色饱满圆锥形黏土点缀。色彩高饱和诱人，红色与白色对比鲜明。表面保留指纹与工具压痕，亚光漫反射光泽。手工捏制的不完美与轻微不对称。纯色柔光背景。呆萌可爱，让人想捏一把。
```

## 落 prompt 前自检

- [ ] 原始材质是否全部转为黏土质感
- [ ] 造型是否圆润饱满无锐利边缘
- [ ] 细节是否简化为色块
- [ ] 色彩是否饱和诱人
- [ ] 是否有指纹/压痕描述
