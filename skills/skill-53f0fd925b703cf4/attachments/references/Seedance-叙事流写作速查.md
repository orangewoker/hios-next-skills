# Seedance 叙事流写作速查
> **共享标注（2026-08-04）**：本文件为 zx-DL-SP-short-film-writer（叙事流分支）共享文件，v4 主流程（骨架抄写格式）不调用本文件。其中时间叙事词汇/景别叙事写法/物理后果三层合一等措辞资源可作参考，但不混入 v4 正文结构。

### 叙事开头句模板

| 场景类型 | 开场句模板 |
|---------|-----------|
| 环境/奇观 | `[镜头位置]视角，镜头[运动方式]。画面下方/上方/远处[第一层空间描述]。` |
| 角色近景 | `[角色名]的[景别]，[画面位置描述]。[光线/色彩描述]。` |
| 动作开场 | `[动作]——[动作结果]：[画面描述]。` |

### 时间叙事词汇库（替代「第X到Xs」）

| 时间跨度 | 可用词汇 |
|---------|---------|
| 从静止到动态 | `开场整整Xs` → `下一刻` → `紧接着` / `猛然` / `骤然` |
| 连续流动 | `正在这时` → `就在…的当口` / `就在…的同时` |
| 快转慢 | `一切骤然提速` / `时间像被拉住一样慢下来` |
| 慢转快 | `慢速里时间猛地加速回正` |
| 因果排序 | `就在那声…里` / `…尚未落尽，…便` |

### 景别在叙事中的自然写法

| 旧写法 | 叙事流写法 |
|--------|-----------|
| `CU近景` | `近到能看清她睫毛的颤动` |
| `MCU中近景` | `框住她的上半身，她的呼吸带动肩膀起伏` |
| `WS全景` | `她整个人在画面中只占一小截高度，身后是无尽的沙海` |
| `EWS远景` | `渺小如一粒沙的剪影在地平线上缓缓移动` |

### 物理后果嵌入写法（替代三层特效法）

```
旧写法（三层分离）：
光效层：「剑身暗金色微光从剑格流向剑尖」
碰撞层：「刀剑交击迸出火花，冲击波扩散」
环境层：「沙地被震出放射状裂纹」

叙事流写法（三层合一）：
剑身暗金色微光从剑格流向剑尖，刀剑交击的刹那迸出一簇青金色火花，冲击波将四周的沙粒吹开——沙面以碰撞点为圆心震出一圈放射状裂纹。
```

### 对话/台词写法速查

| 情况 | 写法 |
|------|------|
| 一般对白 | `说"台词"，用[角色]的音色` |
| 无台词的人声 | `发出[情绪]的[声音描述]，用[角色]的音色` |
| 多人连续对话 | 每句独立写，`HARD CUT硬切转场` 分隔，声场贯穿 |
| 通过音频 @绑定的角色说话 | `用[音频名]的音色` |
| 声场叠台词 | 先声明底层声场贯穿不断，再写台词的叠放方式 |

### 旁白写法速查

| 情况 | 写法 |
|------|------|
| 嵌入叙事 | 在叙事到达那个时间点时自然引出 |
| 字数+时长 | `「台词」（X字，Xs念完）` |
| 与画面同步 | `「台词」尾音与[具体画面事件]重叠/同步` |
| 被打断 | `说到「某字」时被[具体事件]打断。旁白戛然而止。` |
| 旁白身份 | 开头声明：`不是人在说话，是[沙漠/世界/旁白者]在说话` |

### BGM/音效声明固定句式

```
仅生成环境音效与动作音效，不配背景音乐。
（有对话时替换为：）仅白噪音质感的环境音与动作音、人声台词，不配任何旋律性背景音乐。
（有声场时追加：）远景的[环境描述]构成持续不断的环境声场（sound bed），无论镜头切到多近的景别，这一声场都作为底层持续铺满、不得断掉。
（有螃蟹类细小生物台词的追加：）螃蟹/小生物说话时蟹钳[碰触声]叠在底层声场之上。
```

### 微表情分景别选择

> 生成 Seedance 提示词前，先判断当前镜头的景别，再选择对应的微表情粒度：

```
当前镜头是____
├─ 特写（CU/ECU）→ 用解剖学级（0.3mm/肌肉名/量化位移）——参考下方核心情绪模板库
├─ 中近景（MCU/MS）→ 用情绪级（"神情冷淡""惊慌失措""眉头微蹙"）
└─ 全景/远景（WS/EWS）→ 不写面部，靠身体姿态传达
```

> ⚠️ **核心情绪模板库**保留在下方「核心情绪·微表情时间轴模板」中，仅特写镜头调用。全景镜头写微表情是浪费 token。
