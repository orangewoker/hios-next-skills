# 广告导演工作表

## 时长结构

| 时长 | 推荐镜数 | 节奏结构 | 适用场景 |
| --- | ---: | --- | --- |
| 6 秒 | 3–4 | 钩子 → 单卖点 → 产品与 CTA | 信息流补投、再营销 |
| 15 秒 | 6–8 | 钩子 → 痛点/欲望 → 产品证据 → 场景 → CTA | 短视频种草、电商转化 |
| 30 秒 | 8–12 | 钩子 → 冲突 → 证据 → 意义 → 场景 → 英雄镜头 → CTA | 新品发布、品牌与转化兼顾 |
| 60–75 秒 | 16–24 | 钩子 → 世界观 → 工艺/功能证据 → 当代转译 → 多场景 → 情感 → 品牌收口 | 品牌片、非遗文创、节礼广告 |

## “针下山河”可复用方法

只复用导演方法，不复制具体品牌、台词、产品或画面：

1. 用极近景动作制造第一眼悬念。
2. 把微观材质或工艺变成宏观世界，完成视觉升维。
3. 用可观察的制作过程证明价值，而不是只靠旁白宣称。
4. 从传统或技术来源过渡到现代产品设计。
5. 展示真实使用、佩戴、通勤、家庭或赠礼场景。
6. 用一段克制的人际情感把功能变成记忆。
7. 以产品英雄镜头、品牌句、卖点与 CTA 准确收口。

## 分镜表头

| 字段 | 要求 |
| --- | --- |
| 镜号/时间 | 连续且总时长准确 |
| 画面目标 | 本镜唯一主要信息 |
| 画面内容 | 主体、动作、环境、道具与结果 |
| 景别/机位/运动 | 景别、角度、焦段感、运动速度和方向 |
| 产品连续性 | 外观锚点与本镜不可变化项 |
| 旁白/字幕 | 口语化、可朗读、与画面互补 |
| 音乐/音效 | 节奏、环境音、拟音与转场声 |
| 分镜提示词 | 静态构图、光影、材质、风格与画幅 |
| 视频运动提示词 | 主体动作、镜头运动、物理变化、时长 |
| 负面约束 | 错字、变形、结构漂移、风格跳变等 |
| 转场 | 与前后镜头的动作、形状、颜色或声音衔接 |

## 投放类型选择

### 品牌心智

放大世界观、情绪和品牌记忆。产品必须在开头或前 10 秒出现一次，并在结尾用英雄镜头收口。

### 即时转化

优先展示痛点、使用动作、可验证结果、价格或权益与明确 CTA。避免长时间铺垫。

### 非遗与文化产品

让传统成为“产品为什么值得买”的证据。文化镜头之后必须回到当代使用，不把广告拍成与商品脱节的纪录片。

### 节日与礼赠

同时交代送礼对象、时机、情绪价值、包装体面度和到手后的真实用途。

## 交付命名

- `01_hook`
- `02_problem_or_desire`
- `03_product_proof`
- `04_meaning_or_transition`
- `05_usage_scene`
- `06_emotion`
- `07_packshot`
- `08_logo_cta`

镜头更多时保持两位数字与语义后缀，保证剪辑顺序稳定。
