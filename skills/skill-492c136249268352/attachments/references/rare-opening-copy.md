# Rare opening and concise copy

## Hard rule

Open every film with a scarce viewpoint. Default to a giant-scale architectural view. Use a different scarce view only when it reveals the product more truthfully. A conventional full-front, eye-level, tabletop, 45-degree hero, or lifestyle-wide first shot fails.

Build the first 2–3 seconds as:

`impossible clue → 3+ scale cues → recognizable feature → copy turn`

## Rare-view menu

| ID | View | Best use | Required evidence |
|---|---|---|---|
| R01 | giant base-up view | bottles, phones, packs, appliances | camera at base, top outside frame, vertical parallax |
| R02 | surface-as-landscape macro | fabric, condensation, grain, seams | grazing light, material horizon, feature endpoint |
| R03 | canyon passage | gaps, hinges, dual components | real structural walls, occlusion, depth exit |
| R04 | axial interior | openings, lenses, rings, bottle mouths | concentric depth, plausible interior, pull-out reveal |
| R05 | impossible top altitude | kits, variants, caps, controls | orthographic geometry, long descent, exact alignment |
| R06 | shadow-first monument | iconic silhouettes | shadow scale change, delayed object entry, final alignment |
| R07 | edge-only eclipse | thin or curved products | near-invisible edge, controlled rotation, thickness reveal |
| R08 | light-before-object | glossy, glass, translucent products | highlight draws the product before fill reveals it |

## Giant-scale construction

Use at least three, preferably four, of these cues:

- camera height at 0–5% of product height;
- product occupies 130–300% of frame height and extends beyond the frame;
- slow upward, lateral, or orbital parallax with a stable axis;
- a rim or grazing light travels a long distance across the surface;
- multiple depth planes or controlled atmospheric falloff;
- a truthful small reference such as a cap, port, seam, droplet, ingredient, or accessory;
- low-frequency sound with a precise high-frequency feature cue;
- a wide architectural lens with restrained distortion, or a neutral lens from an impossibly low position.

Do not add miniature people, roads, buildings, or vehicles unless the concept explicitly calls for surrealism. Do not warp the product to manufacture scale.

## Copy logic

Write the line only after choosing the image. Use this order:

1. Name the visible fact: big, thin, bright, quiet, dense, clear, rising, aligned, textured.
2. Translate it into a user-provided or safely observable experience.
3. Remove filler adjectives.
4. Keep the selected opening line to roughly 4–14 Chinese characters when possible.
5. Present one selected line and 3–5 alternatives.

The second clause must be supported. If only appearance is known, use sensory or cinematic language rather than performance claims.

## Original formula library

- `岂止于[可见属性]，不止于[真实体验]。`
- `不只是[可见属性]，更是[真实体验]。`
- `[属性]，是第一眼；[体验]，是下一秒。`
- `把[细节]放大，让[体验]被看见。`
- `[细节]向上，[体验]随之而来。`
- `从[局部证据]，到[整体感受]。`
- `[属性]有尺度，[体验]有分寸。`
- `先看见[视觉事实]，再感受[真实体验]。`
- `大有[可证实的体验或动作]。`
- `[产品/部件]很近，[体验]更近。`

Do not mechanically use “大” for every product. Match the formula to the opening evidence.

## Visual-to-copy examples

| Visible opening evidence | Safer concise options |
|---|---|
| giant bottle + rising bubbles | `岂止于大，不止于爽。` / `大，是第一眼；爽，是下一秒。` |
| bubble macro as landscape | `放大每一颗气泡，唤醒这一口。` / `气泡向上，清爽随之而来。` |
| thin profile | `岂止于薄，更轻一步。` only when lightness is supported |
| color field expands | `不只是亮眼，更让这一眼记住。` |
| precise component alignment | `岂止于齐，更在于合。` only when fit/alignment is real |
| material macro | `先看见纹理，再感受质地。` |
| opening mechanism | `一开，新的感受抵达。` |

Examples are patterns, not mandatory taglines. Rewrite for the user’s product and avoid near-copying any known campaign.

## Output block

```markdown
**稀缺性开场：** [R/G ID]｜[camera position]｜[3+ scale cues]｜[recognition endpoint]
**首选文案：** [line]
**画面证据：** [what makes both clauses true]
**备选文案：** [3–5 lines]
**风险检查：** [unsupported claim / known-slogan similarity / text-generation caveat]
```

Add copy in post when exact Chinese typography matters. Do not imitate Apple typography, slogans, or campaign lockups.

For longer copy ladders, punctuation cadence, iteration language, single-focus inversion, and model-name reveals, continue with `launch-copy-cadence.md`.
