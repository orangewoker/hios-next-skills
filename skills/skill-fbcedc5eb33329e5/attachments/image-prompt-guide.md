# 图像提示词系统参考

本文件为图像生成提示词的完整参考系统，覆盖模型路由、防失败规则、构建公式和提示词模板。非专业术语使用中文，模型名和行业专有名词保留原文。

---

## 一、模型路由表

| 任务 | 模型 | 关键说明 |
|------|------|----------|
| 角色设定图 / 肖像 / 选角 | **Soul 2.0**（或 Cinema Studio AI Cast 自动创建） | Soul 2.0 不支持 21:9；AI Cast 为 Higgsfield 独立工具，参数在 UI 中设置无需提示词 |
| 场景 / 环境 / 电影静帧 / 概念设计 | **Soul Cinema** | 支持 21:9；电影纹理+自然颗粒；可将带 Soul ID 的角色放入场景 |
| 道具设定图 / 道具物件 | **NBP** / **GPT Image 2** | 真实物件语境，精确文字渲染能力 |
| 画面编辑（始终优先） | **NBP** | 对原图后期处理，最小改动，逐像素保留 |
| 修复粗糙 AI 纹理（皮肤/织物/表面） | **Seedream 4.5** | 仅用于纹理处理，不用于点状局部编辑 |
| 最精细局部微编辑 / 场景视角变化 | **GPT Image 2** | 最后手段：全局容易变脏但局部能力强 |

**编辑通道固定顺序：** NBP → Seedream 4.5（仅纹理） → GPT Image 2（最后手段）

**关键硬约束：**
- Soul 2.0 **不支持 21:9**，带角色的宽银幕画面使用 Soul Cinema + Soul ID
- 画幅比例和分辨率 = **平台参数**，在 UI 中设置，**严禁**写进提示词正文
- 所有模型**无负向 prompt 参数**，描述想要什么而非不想要什么

## 二、10条防失败规则

### 规则1：自然语言，不堆砌关键词
所有模型解析连贯自然流动的描述。关键词堆砌（"4k, masterpiece, trending"）无效。生成提示词中不使用全大写区块标题；结构化控制区块仅用于编辑任务。

### 规则2：提示词不膨胀
80-150词中文优于400词堆砌。超过某长度后每增加一个从句都稀释注意力，细节开始丢失。删掉填充内容，保留锚点。目标 ≤1500-2000 字符。

### 规则3：正向 > 负向
所有模型无负向 prompt 参数。生成提示词中绝不描述不想要什么，直接描述想要的：
- 干净皮肤 → `干净、干燥的皮肤`（而非`不要痘痘`）
- 空街道 → `空无一人的荒凉街道`（而非`不要有人`）
- 编辑中删除是有效操作（`移除路灯杆`），必须搭配填充内容（`后方由连续完整的砖墙填补`）

### 规则4：画幅比例 = 平台参数
画幅和分辨率在 UI 中设置，不写进正文。构图描述词（`宽幅全景构图`、`竖向全身构图`）可用；参数语法（`--ar`、`16:9`、`4K`）不出现。

### 规则5：技术化灯光 + 具体材质
`单一顶置主光，柔和的 2:1 光比，平滑衰减` 胜过 `戏剧性的电影感灯光`。写具体材质+表面处理（`木模板成型混凝土`、`氧化铜绿表面`）。摄影语言有效：焦距、角度、景别、DOF——但光学/DOF 属于角色，不属于场景。

### 规则6：色板 60/30/10 控制
百分比在所有模型中易懂：`色板：60% 暖赭石、30% 深炭灰、10% 铁锈红`。用真实色相名称；保持 60/30/10 逻辑。配比必须来自用户指令/场景上下文/参考图，**绝不**自行覆盖并发明。

### 规则7：角色一致性 = Soul ID
身份由 Soul ID 承载（Soul 2.0 和 Soul Cinema 的平台参数），文字锚点（`三个画面中都是同一个真实人物`）用于加强。绝不只靠文字描述实现跨镜头一致性。

### 规则8：插画风漂移防护
`角色参考图` 和 `绘画感` 触发插画风格——照片真实感任务中避免。使用 `影棚照片` / `电影角色设定图` / `电影静帧`。修正漂移的方法：加强正向锚点（胶片、镜头、真实材质），而非堆叠 NOT。

### 规则9：文字/纹身/真人处理
- 画面内文字：引号给出**完全准确**的文本 + 字体/字重/颜色（`在标牌上用红色粗体衬线字体写"GENUINE"`），模糊的`添加文字`会糊
- 纹身：具体真实图案（`经典燕子图案`、`老派匕首图案`）+ `干净清晰的线条`
- **严禁**将真实人物姓名写进提示词，转换为描述性特征（脸、体型、能量、年代）
- 提示词中不出现 IP/品牌名称

### 规则10：NBP 优先 + 最小修改 + 完整保留
任何编辑从 NBP 开始，视为对原图的后期处理。一次只做一个改动。所有不变内容列在"严格保留"下。当用户说改过头了 = 改得太多：锁更多，改更少。

## 三、公式与构建模块

### 3.1 胶片颗粒电影基准技术区块

```
照片级真实感，ARRI Alexa LF 搭配 Cooke S4 变形宽银幕镜头，T2.0 光圈；自然的 35mm Kodak Vision3 250D 胶片颗粒，柔和的电影式明暗衰减，电影静帧美学。
```

搭配低饱和调色 + 摄影指导氛围。角色设定图中**不写**`绘画感`。

### 3.2 现代干净数字基准技术区块

```
使用 ARRI Alexa Mini LF 搭配 ARRI Signature Prime 镜头拍摄，干净的现代数字电影质感，清晰自然的细节，极少量细颗粒，柔和的电影式明暗衰减，现代电影静帧品质，超真实摄影细节。
```

搭配：`自然鲜活的肤色，中等对比度，阴影中带轻微冷调，真实现代的色彩，不过度降低饱和度`。

> Soul Cinema 默认具备电影纹理和自然颗粒，技术区块中一行基准即可，不要过度堆叠。

### 3.3 色板包装器模板

```
精致的低饱和色板：[冷色/主色调]占主导，[暖色元素]作为唯一的暖色对比，深沉压黑的黑位，克制的自然主义调色，柔和低对比度，强烈的电影式明暗对照。
```

照片真实感角色任务中删除`绘画感`一词。百分比方式（`60% 暖赭石、30% 深炭灰、10% 铁锈红`）所有模型通用。

### 3.4 摄影指导 / 氛围参考

| Emmanuel Lubezki | The Revenant、Tree of Life | 自然光、广角 |

| Andrei Tarkovsky | Mirror、Stalker | 画中画式室内→室外 |

### 3.5 外科手术式编辑模板

```
编辑这张图像：[用一句话写明目标]。

修改内容：[只写唯一需要变化的内容，并精确描述]。

严格保留：
- [列出所有必须保持完全一致的元素：脸、服装、道具、位置、墙面/地面、摄影机角度、所有现有阴影]
- 调色、色板、对比度、颗粒、明暗衰减

仅修改：[再次说明唯一改动]。除此之外保持 100% 一致。
```

**Seedream 4.5 纹理处理**：目标 = `修复粗糙的 AI 纹理`；修改内容指定表面（皮肤毛孔/织物编织/地面污垢）；严格保留锁定构图/身份/灯光/调色。

**GPT Image 2**（最后手段）：使用相同模板，将"修改内容"缩到最小——全局容易变脏，请求越小结果越干净。

## 四、提示词类型模板

### 4.1 角色设定图（三联画）——Soul 2.0

快速路径：**Cinema Studio AI Cast 自动创建角色参考图**（Higgsfield 独立工具，参数在 UI 设置）。以下模板用于需要完全控制的情况。

平台参数：画幅 16:9，质量 2k；如有 Soul ID 则使用。

```
同一位[人物]的三张影棚照片并排排列在平整的中性中灰色影棚背景上，构成一张电影角色设定图：左侧为正面全身照，中间为背面全身照，右侧为近距离肖像；三个画面中都是同一个真实人物，跨画面保持一致。单侧柔和定向的电影影棚灯光，自然柔和的阴影衰减，干净、中性的电影质感。

[人物]：[年龄、体型、族裔外观类型、面部特征、发型、面部毛发、显著标记——参考现实人物只描述特征，绝不要写姓名]。

[服装，三个画面中保持一致：……]。[显著道具 / 标志性物件。]

左侧画面中，[人物]以中性姿势直立正对摄影机，双臂自然垂在身体两侧，从头到脚完整入镜。中间画面以同样站姿从背后拍摄。右侧画面为头肩近距离肖像，[表情 + 关键面部细节]。

[色板描述]。[技术区块]。
```

**规则：**
- 不写`角色参考图`、不写`绘画感` → 使用`电影角色设定图`/`影棚照片`
- 不写`三分法构图`（角色设定图豁免）
- 一致性锚点：`三个画面中都是同一个真实人物，跨画面保持一致`
- 跨镜头一致性由 Soul ID 承载，文字仅加强
- 纹身/标记：具体图案 + 干净线条

### 4.2 场景 / 环境——Soul Cinema

平台参数：宽银幕 21:9（标准视频则 16:9），质量 2k。

```
[摄影机锚点——明确锁定]。[场景身份]。
[关键建筑 / 自然元素]。[光源 + 方向 + 色温]。
[向画面深处递减的次要元素]。[色板包装器]。[技术区块]。
[氛围 / 摄影指导参考]。[如需空场景则正向写明：空无一人的废弃室内、裸露墙面、静止空气]。
```

**摄影机锚点提示：**
- 简单 > 抽象：`高机位三分之四广角镜头，摄影机位于房间高处，以约 45° 斜向下俯拍`
- 真实设备 + 类型术语（24mm 广角）胜过抽象几何描述
- Soul Cinema 原生具备胶片颗粒，技术区块一行基准即可

### 4.3 道具设定图——NBP / GPT Image 2

平台参数：画幅 1:1（高瘦道具 3:4），分辨率 2k-4k。

```
照片级真实感的[正上方 / 三分之四俯拍]道具摄影：把[道具]单独放置在[中性灰色混凝土]表面上，使用[柔和定向光]。
[具体描述道具、材质和磨损状态]。[不希望出现文字/Logo则正向写空白无品牌表面]。[技术区块]。
```

- 多种状态（干净/损坏/沾血）= 分别生成独立资产
- 设备类道具用中性材质功能描述，避免武器/爆炸物术语
- "不要 Logo" → 正向写 `朴素无品牌包装、空白哑光表面`

### 4.4 图像编辑——始终先用 NBP

使用外科手术式编辑模板。最小"修改内容"、完整"严格保留"、一次只改一件事。

**改变场景视角（反打角度）：**
- GPT Image 2 对视角变化处理良好，默认路由
- 使用 NBP 时必须逐个物体明确写出镜像后布局（主视角沙发在右侧 → 反打视角沙发在**左侧**）

## 六、视频提示词补充规则

- **写状态不写过渡**：描述角色处于动作状态（正在投掷/正在出拳/正在跳跃），而非进入动作的过程（不写`把手伸进包里、拿出来、蓄力`）
- **三分法构图**：所有视频/图像提示词默认加入（角色设定图除外）
