## 资产缺失自动补全规则

用户已有剧本和部分资产，但未提供完整的角色参考图/场景参考图/音色/道具时，**skill 自动补全，不卡住、不强制要求用户提供**。补全方式分两类：

### 第零步：资产需求预判（先判断，再询问）

在询问用户是否有资产之前，skill 必须先根据剧本/需求自动判断**本任务需要哪些资产**，列出资产需求清单，然后再有针对性地询问。

**预判方法：**
1. 读取剧本/需求，提取出场角色列表（含每个角色的服装/外貌关键特征）
2. 提取场景列表（每场戏的地点/时间/氛围）
3. 提取关键道具列表（推动剧情的道具/反复出现的道具）
4. 判断哪些角色有对白（需要音色）、哪些角色只有动作（不需要音色）
5. 判断哪些场景是高穿帮场景（需要多角度设定图）、哪些是过渡场景（文字描述即可）

**预判输出格式：**
```
【资产需求预判】
需要的角色：[角色A（有对白，需参考图+音色）、角色B（无对白，需参考图）...]
需要的场景：[场景1（主场景，需设定图）、场景2（过渡，文字描述即可）...]
需要的道具：[道具1（关键道具，需设定图）、道具2（普通，文字描述即可）...]
已有资产：[用户已提供的@图片N/@音频N列表]
缺失资产：[角色A参考图、场景1设定图、角色A音色...]
```

**然后基于预判结果询问用户：**
- 不要泛泛问"你有什么资产"
- 要针对缺失项问："角色A的参考图和音色你有吗？场景1的设定图有吗？"
- 用户回答"有"→ 让用户提供，纳入 @图片N/@音频N 映射
- 用户回答"没有"→ 进入自动补全流程
- 用户未回复或说"你帮我弄"→ 默认全部自动补全

### 一、生成设定图提示词（用户可拿去生成资产）

当用户缺少以下资产时，skill 自动输出对应的图像生成提示词，标注【待生成资产】，用户可拿去 Soul 2.0 / Soul Cinema / NBP 等模型生成设定图：

| 缺失资产 | 生成模型路由 | 提示词内容要求 |
|---------|------------|--------------|
| 角色设定图（无参考图） | Soul 2.0（或 AI Cast） | 正面/侧面/背面全身 + 6个面部角度九宫格；服装/发型/体型/年龄/关键特征（痣/疤/眼镜等）；影棚照片/电影角色设定图风格；禁止插画风 |
| 场景设定图（无参考图） | Soul Cinema（支持21:9） | 主视角效果图 + 色彩材质参考 + 结构设计 + 多时段氛围；空间布局/家具/光源/窗外景观；电影静帧风格 |
| 道具设定图（无参考图） | NBP / GPT Image 2 | 正面/侧面/细节特写；材质/尺寸/磨损状态；纯白背景产品照风格 |
| 首帧图（高风险镜头） | Soul Cinema | 精确到角色站位/朝向/视线/道具位置/光影方向；用于视频生成首帧锁定 |

**设定图提示词必须遵循 image-prompt-guide.md 的规则**：正向>负向、80-150词、技术化灯光+材质、色板60/30/10、插画风防护、写状态不写过渡。

### 二、文字描述替代（无参考图时直接写入 prompt）

当用户不需要先生成设定图、希望直接出视频 prompt 时，skill 用**详细文字描述**替代 @图片N 引用：

- **角色无参考图**：在主体参考层写详细外貌描述（年龄/性别/发型/五官特征/服装/体型/关键标记），不写 @图片N。描述必须具体到可辨识（如"35岁男性，短发，黑框眼镜，额头偏右有一颗深红色圆形凸起痣，深蓝色丝绸短袖睡衣"），禁止模糊描述（如"一个男人"）
- **场景无参考图**：在场景描述层写详细空间描述（空间类型/尺寸/家具布局/光源/窗外/材质/色调），量化尺寸和距离
- **音色无音频**：根据角色设定推断音色描述词（声线质感/情绪底色/语速节奏），写入主体参考层，不写 @音频N。示例："理新解的音色：中年男性，低沉磁性，温和沉稳，语速中等偏慢"
- **道具无参考图**：在道具描述层写详细外观描述（材质/尺寸/颜色/状态）

### 三、补全流程

1. **资产需求预判**：读取剧本/需求，提取角色/场景/道具列表，判断哪些需要参考图、哪些需要音色、哪些文字描述即可，输出【资产需求预判】清单
2. **针对性询问**：基于预判的缺失项，逐个问用户"XX你有吗？"，不要泛泛问"你有什么资产"
3. **用户回答处理**：
   - 用户说"有"→ 让用户提供，纳入 @图片N/@音频N 映射
   - 用户说"没有"→ 对该缺失项自动补全
   - 用户说"你帮我弄"/未回复→ 默认全部自动补全
4. **自动补全**：对每个缺失项，判断用户意图——要设定图 prompt 走类别一，要直接出视频 prompt 走类别二
5. 已补全的资产在项目状态中标记为【AI暂定】，用户后续提供真实资产时覆盖
6. 七段式输出中，无 @图片N 的角色必须有等价的详细文字描述，不得出现"一个男人""女人"等泛指

### 四、已有剧本+部分资产的标准流程

```
1. 读取剧本，提取角色列表/场景列表/道具列表（资产需求预判）
2. 对照用户已提供的资产，列出缺失项
3. 针对缺失项逐个询问用户"XX你有吗？"（不泛泛问）
4. 用户没有的 → 自动补全（设定图 prompt 或文字描述）
5. 镜头配方卡选型 + 逐镜规划
6. 七段式逐镜输出（有@引用用@引用，无@引用用详细文字描述）
7. 每镜三维自检 → 交付
```

**关键原则**：先判断需要什么资产，再问用户有没有；用户没有的 skill 补上，不卡住、不强制要求用户提供。
