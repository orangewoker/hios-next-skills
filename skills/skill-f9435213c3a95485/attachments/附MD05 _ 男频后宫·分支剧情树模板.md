# 附MD05 | 男频后宫·分支剧情树模板

**所属主SKILL：** 男频后宫 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“男频后宫 | 上架Steam的互动影游”的专属分支剧情树模板。

解决互动影游“剧情线混乱、分支无收束、假选项泛滥、路径无法抵达结局”的痛点。通过统一的节点命名规范、严密的三幕结构与收束铁律，确保所有分支最终收束回主线，每条路径都能抵达结局，零死胡同。

## #需要什么输入

**最少提供：**

- 主线剧情节点清单（N01-N08）
- 核心抉择点设计与变量影响
- 路线设计（女主A线/女主B线/女主C线/女主D线/隐藏线）

**可选提供：**

- 结局数量与路径偏好
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。分支剧情树环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则，确保所有分支逻辑闭环。

### 二、节点命名规范（强制执行）

1. 主线剧情节点：N+两位数字，如N01、N02、N05、N06。
2. 路线节点：N+两位数字+路线代号，如N05A、N06B、N07C。
3. 好结局/普通结局：E+两位数字，如E01、E02、E03、E04、E05。
4. 坏结局/死局：D+两位数字，如D01、D02至D10。
5. 变量初始化节点：StoryInit。
6. 结局判定节点：ENDING_CHECK。
7. 核心铁律：所有节点ID、视频文件名、代码中的引用必须100%完全一致，严禁中文、空格、字母O混入数字0。

### 三、剧情树核心结构（发散-回流-锁定-再发散）

1. N01 开场·命运相遇（start节点）
2. N02 抉择点1·觉醒前的态度（branch节点）
   - N02A 保持低调，暗中观察（获得定情信物A）
   - N02B 主动出击，直面势力（增加修罗场值）
3. N03 核心异能觉醒（normal节点）
4. N04 抉择点2·第一次选择（branch节点·核心）
   - N04A 选择女主A线（锁定女主A线）
   - N04B 选择女主B线（锁定女主B线）
   - N04C 选择女主C线（锁定女主C线）
   - N04D 选择女主D线（锁定女主D线）
   - N04E 选择隐藏线（需前置道具）
5. N05A/B/C/D/E 势力判定（normal节点）
6. N06A/B/C/D/E 抉择点3·女主质问或反派试探（branch节点）
7. N07A/B/C/D/E 抉择点4·情感博弈收尾（branch节点）
8. N08 抉择点5·最终一搏（branch节点）
9. ENDING_CHECK 结局判定
   - E01/E02/E03/E04/E05 正结局
   - D01-D10 坏结局

### 四、分支收束铁律（核心铁律）

1. 每一章末尾必须收束回主线，防止分支指数爆炸。
2. 关键选择后路线锁定，不可逆。
3. 单章分支层级不超过3级。
4. 每条路径最终抵达结局，无死胡同。
5. 零假选项：每个选择必须改变至少一项变量或后续节点。
6. 所有路径必须能抵达结局，不允许无限延伸。

### 五、男频后宫专属分支模板

第一幕：觉醒（N01-N04）

1. N01：命运相遇，男主在都市中觉醒异能。
2. N02：抉择点1，男主对觉醒的态度。
3. N03：核心异能觉醒，男主获得改写命运的能力。
4. N04：抉择点2，第一次选择，五条路线选择，锁定后续走向。

第二幕：博弈（N05-N06）

1. N05A：女主A线·势力判定·女主A降临，综合好感+40·羁绊值+25。
2. N05B：女主B线·势力判定·女主B沉默，综合好感+30·信任度+30。
3. N05C：女主C线·势力判定·女主C震惊，综合好感+20·修罗场值-40。
4. N05D：女主D线·势力判定·女主D雀跃，综合好感+35·羁绊值+20。
5. N05E：隐藏线·势力判定·神秘势力降临，全员羁绊+20·修罗场值+20。
6. N06A：女主A质问身份，选择A1/A2/A3，影响女主A专属好感。
7. N06B：女主B要求回报，选择B1/B2/B3，影响女主B专属好感。
8. N06C：女主C私下试探，选择C1/C2/C3，影响女主C专属好感与道具。
9. N06D：女主D撒娇试探，选择D1/D2/D3，影响女主D专属好感。

第三幕：收束（N07-N08）

1. N07A：女主A阵营施压，选择A1/A2，影响信任度。
2. N07B：女主B出手阻挠，选择B1/B2，影响羁绊值与人物关系。
3. N07C：女主C情感摊牌，选择C1/C2，影响修罗场值。
4. N07D：女主D坦白心意，选择D1/D2，影响综合好感。
5. N07E：全员博弈收尾，选择E1/E2，解锁真结局条件。
6. N08：最终一搏，选择A再搏一次；选择B收手；选择C全员豪赌。
7. ENDING_CHECK：根据所有变量与路线自动判断。

### 六、结局路径示例（以E04全员羁绊为例）

N02B 主动出击（修罗场值+10）\
→ N04E 参悟·神秘玉佩（综合好感+20·全员羁绊+20）\
→ N06C-2 反问堵住反派（修罗场值-20）\
→ N07C-2 抬头直视反派微笑（获得神秘玉佩）\
→ N08C 全员豪赌（综合好感+30·全员羁绊+30）\
→ E04 全员羁绊（全员羁绊≥20·神秘玉佩=true）

### 七、灵魂七问（每个抉择点必须过审）

1. 玩家为什么选它？（动机）
2. 它改变了什么？（信息/关系/资源/风险/路线）
3. 即时后果是什么？
4. 延迟后果在哪个后续节点出现？
5. 是否可能造成独特失败或隐藏路线？
6. 是否只是换台词而没有剧情差异？（绝不允许）
7. 是否与角色动机和世界规则一致？
