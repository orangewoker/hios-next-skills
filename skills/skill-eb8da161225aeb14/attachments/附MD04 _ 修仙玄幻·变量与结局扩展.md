# 附MD04 | 修仙玄幻·变量与结局扩展

**所属主SKILL：** 修仙玄幻 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“修仙玄幻 | 上架Steam的互动影游”的专属变量系统与结局体系扩展库。

解决互动影游“变量设定空洞、结局无分支、选项假大空、数值不驱动剧情”的痛点。通过严格的变量字典、严密的结局触发条件与路径推演，确保玩家的每一次选择都能真实改变主角的仙途命运。

## #需要什么输入

**最少提供：**

- 核心变量清单（如道心值、仙缘值、魔气侵蚀、渡劫成功率等）
- 路线设计（仙道/魔道/帝路/隐藏线）
- 主角A与主角B的羁绊设定

**可选提供：**

- 结局数量与类型偏好
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。变量与结局设计环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则，确保结局路径逻辑闭环。

### 二、变量字典（强制锁定）

核心变量

1. 道心值：counter，0-100，默认0；≥60仙心稳固；&lt;30道心破碎。
2. 仙缘值：relationship，0-100，默认0；≥60仙缘深厚；&lt;20仙缘浅薄。
3. 魔气侵蚀：risk，0-100，默认0；≥70魔气缠身；≥90堕入魔道。
4. 渡劫成功率：counter，0-100，默认50；≥80渡劫可成；&lt;30必死无疑。
5. 帝气值：faction，0-100，默认0；≥80帝路争锋；&lt;20与帝路无缘。

路线专属变量

1. 仙道专属仙心：relationship，0；≥50仙道认可；&lt;20被逐出仙门。
2. 魔道专属魔性：relationship，0；≥50魔道接纳；&lt;10被魔道抛弃。
3. 帝路专属帝运：relationship，0；≥50帝运加身；&lt;10帝运消散。
4. 主角B羁绊值：relationship，0；≥80解锁真结局条件。

道具与旗标变量

1. 本命飞剑：item，false；true且仙缘值≥60可御剑飞升。
2. 古仙玉简：item，false；true且道心值≥60可参悟仙法。
3. 魔道血珠：item，false；true且魔气侵蚀≥70可觉醒魔道天赋。

### 三、结局体系（共15个）

正结局（5个）

1. E01·飞升成仙：仙道线，道心值≥60，渡劫成功率≥80。
2. E02·帝路争锋：帝路线，帝气值≥80，仙缘值≥60。
3. E03·魔道至尊：魔道线，魔气侵蚀≥70，魔性≥50。
4. E04·三界逍遥：隐藏真结局，解锁古仙玉简+三线变量各≥20。
5. E05·散仙归隐：任意路线，道心值30-59，渡劫成功率&lt;80。

坏结局（10个）

 1. D01·道心破碎：道心值&lt;30。
 2. D02·仙缘断绝：仙缘值&lt;20。
 3. D03·魔气噬心：魔气侵蚀≥90。
 4. D04·仙门逐徒：仙道线，仙心&lt;20。
 5. D05·魔道弃子：魔道线，魔性&lt;10。
 6. D06·帝运消散：帝路线，帝运&lt;10。
 7. D07·渡劫身死：渡劫成功率&lt;30。
 8. D08·仙魔同诛：仙道线与魔道线同时失控。
 9. D09·因果清算：所有变量失控。
10. D10·觉醒前陨落：N02选项B+魔气侵蚀≥70。

### 四、结局触发条件表（快速查表）

1. E01：N02A→N04A→N06A-2→N08B；道心值≥60·渡劫成功率≥80·仙心≥30。
2. E02：N02A→N04B→N06B-1→N08B；帝气值≥80·仙缘值≥60·帝运≥20。
3. E03：N02B→N04C→N06C-2→N07C-1；魔气侵蚀≥70·魔性≥50。
4. E04：N02B→N04C→N06C-2→N07C-2→N08C；古仙玉简=true·三线变量各≥20。
5. E05：N02A→N04B→N06B-3→N08B；道心值30-59·渡劫成功率&lt;80。
6. D01：任意路线累积道心值&lt;30。
7. D06：N04A→N06A-1→N08A；帝运&lt;10。

### 五、结局路径示例（以E04三界逍遥为例）

N02B 质问天道（魔气侵蚀+10）\
→ N04C 参悟·古仙玉简（道心值+20·仙缘值+20）\
→ N06C-2 反问堵住魔道（魔气侵蚀-20）\
→ N07C-2 抬头直视仙尊微笑（获得古仙玉简）\
→ N08C 三界豪赌（道心值+30·仙缘值+30）\
→ E04 三界逍遥（三线变量各≥20·古仙玉简=true）

### 六、变量锚定规则（核心铁律）

1. 每个节点提示词末尾必须标注：节点ID+变量变化。
2. 变量名全部用英文（karma/risk/route/seal），禁止中文变量名。
3. 变量一旦定义，中途不能改名。
4. 所有变量必须有定义、有使用、有结局影响。
5. 禁止无意义变量（定义了但从不影响结局）。
