# 视频 Prompt 文法

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## Beat 结构

一段 8-12 秒的视频分为 2-3 个 beat。每个 beat 以相机起手，依次写画面/光线/色彩/声音。beat 之间是同一条 prompt 内的时间轴，不是分段多次生成。≤15 秒的成片用一次视频生成即可拿到完整片段。

### 三拍模板（8-10秒）

```
0-3s: 相机从低角度仰角缓缓上摇。画面展示Scene1的入口区域，Building1的流线型圆弧轮廓在前景，铬金属表面反射Light1的暖光。Palette1的芥末黄色块在建筑饰带上醒目。声音：悠扬的电子环境音渐入。
3-7s: 相机继续上摇并缓慢向前推进。画面揭示Scene1的全貌——Building2的几何穹顶在阳光下闪耀，Vehicle1从画面右上方滑过留下一道浅色尾迹。前景中Character1站在观景平台上眺望。声音：加入轻柔的铜管旋律。
7-10s: 相机稳定在壮阔全景。画面展示Scene1的完整城市天际线，多组流线型建筑在Light1的黄金时段光线下沐浴，地面反射出柔和暖色。远处可见更多穹顶和飞行器轨迹。声音：管弦旋律达到温暖的高点。
```

### 两拍模板（4-6秒）

```
0-3s: 相机水平平移从左至右。画面展示Building1的火箭鳍片造型结构特写，铬金属表面在Light1下闪耀，Palette1的青绿色釉面砖贴覆建筑曲面。声音：电子环境音。
3-6s: 相机缓缓后拉揭示全貌。画面展示Building1所在的Scene1广场全景，几何铺地砖在暖光下反射，远处Vehicle1悬浮停靠。声音：铜管旋律加入。
```

## 实体标签规则

用稳定标签绑定画面中反复出现的实体，确保一致性：

- Scene1/Scene2 — 场景（如"Scene1 = 太空时代城市广场"）
- Building1/Building2 — 建筑（如"Building1 = 火箭鳍片造型观景塔"）
- Vehicle1 — 交通工具（如"Vehicle1 = 白色悬浮胶囊车"）
- Character1 — 人物（如"Character1 = 穿银色mod风连体裙的年轻女性，短发，银色go-go靴"）
- Light1 — 光线（如"Light1 = 黄金时段暖阳，3500K，正面柔和漫射"）
- Palette1 — 色彩体系（如"Palette1 = 芥末黄+青绿+铬白+暖橙"）

标签在 prompt 首次出现时定义，后续 beat 直接引用标签名。

## 措辞规范

- **全部正向描述**：写"流线型圆弧轮廓""铬金属表面反光"，不写"不是方盒子""没有暗沉色调"
- **相机描述具体**：写"从低角度仰角缓缓上摇，速度匀速，约3秒完成上摇"，不写"运镜很酷"
- **建筑描述三维度**：形状轮廓 + 材质 + 色彩（如"倒抛物面穹顶，玻璃纤维外壳，青绿色釉面"）
- **光线描述三维度**：方向 + 色温 + 质感（如"正面柔和漫射光，暖白3500K，无明显硬阴影"）
- **声音描述**：具体到乐器/音色/情绪（如"悠扬的电子环境音，带有木琴质感，渐入"）

## 节奏指导

- 乌托邦风格视频节奏偏**沉稳壮阔**，不宜快切或抖动运镜
- 运镜速度以"缓慢匀速"为主，给观众时间欣赏建筑细节和光影
- beat 之间以运镜的连续性自然过渡，不依赖剪辑跳跃
- 首个 beat 的前2秒需有视觉钩子：一个醒目的建筑轮廓或光线效果抓住注意力

## 落 prompt 前自检

- \[ \] 每个 beat 是否以相机起手？
- \[ \] 建筑描述是否包含形状+材质+色彩？
- \[ \] 光线描述是否包含方向+色温+质感？
- \[ \] prompt 是否全部正向措辞？
- \[ \] 实体标签是否在所有 beat 中稳定一致？
- \[ \] 首个 beat 前2秒是否有视觉钩子？
- \[ \] 运镜是否缓慢平稳，无快切？
- \[ \] 声音描述是否具体到乐器/音色？
