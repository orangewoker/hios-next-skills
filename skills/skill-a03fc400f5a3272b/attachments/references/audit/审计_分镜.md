## 审计步骤

### R1 资产标签出场
Glob `分镜提示词/ep{NNN}/` 下的 `S*_即梦视频.md` 单文件（单文件双模块结构）。
每个单文件内同时含 Module 3（故事板）和 Module 4（即梦视频）两个独立 `text` 代码块。
从 Module 4 部分提取 @图片/@音频 标签，在 Module 4 逐镜指令正文中逐一搜索资产名。未出场→FAIL。

### R1A 独立调度物引用
检查单文件的 Module 4 部分（全能参考索引）。每个 15 秒片段必须列出本段角色（@图片）、独立调度物（@图片）、场景（@图片）、故事板构图（@图片）。本段无独立调度物时跳过该 @图片 行。

若某个独立调度物在逐镜指令中被拿起、递交、打开、摔碎、特写、藏匿或转移归属，但全能参考索引没有列出该物品，判定 FAIL。

### R2 禁止凭空捏造
从 角色档案.md/物品档案.md/场景档案.md 提取已声明资产。搜索分镜中出现的专有名词，对照检查。未声明→FAIL。

### R3 禁止外观重复描述
取 JSON `check_id="R3_NO_REDUNDANT_APPEARANCE"` 相关条目。抽查≥30%用 Read 确认。检查"已修正"但未修正→"伪造修复"。

### R4 资产名称一致性
提取标签名→搜索正文完全匹配。不一致→FAIL。

### R4A 主体绑定内容边界
角色固定外观、配饰、身份标识、能力视觉、固定招式视觉、灵光法相和召唤特效随角色参考图继承。若被拆到独立调度物参考图中，判定 FAIL。

### R4S 尺度关系
检查单文件 Module 4 部分的全能参考索引和逐镜指令。全能参考索引列出本段角色、独立调度物、场景的自身尺度（特殊资产可列条件尺度），但不在 @图片/@音频 行中展开——尺度关系在逐镜指令正文中体现。真实同框、接触、遮挡、承载、穿越或变形镜头必须呈现本镜实际发生的尺度关系。缺少资产自身尺度、真实交互关系或凭空改尺寸，判定 FAIL。

### 时长达标
正则提取 `\d+-\d+秒`，计算时长=end-start。任一段<15秒→FAIL。

### 格式合规
搜索关键词检查单文件双模块结构（Module 3 故事板必含 7 节：动态故事板蓝图/整体风格/跨模块形态锚点引用/镜头框序列/连续变形事件镜头框（如有）/画面要求/视觉控制；
Module 4 即梦视频必含 5 节：全能参考索引/故事线/Tone/风格/画面要求（v1.9：意图/世界/捕捉质感合并为 Tone）。
任一节缺失→FAIL。

### 台词时长
每时间段提取台词，字数÷**3.0**=估算秒数（与[分镜_06_时长](./分镜_06_时长.md) §二、scripts/_rules.py 的 `DIALOGUE_CHARS_PER_SEC` 统一）。>时间段时长→FAIL。

### 表情+R5+R6
表情：检查分镜版万能词(肌肉动作+三层结构)。R5：变形事件不得拆分镜头。R6：混合风格四要素齐全。

同时写入结构化判定文件：

路径：`.pipeline/audit-2.5-ep{NNN}.json`

```json
{
  "phase": "2.5",
  "episode": {NNN},
  "conclusion": "PASS",
  "allow_advance": true,

  "partial_items": [],
```

字段规则：
- `conclusion` 只能是 `PASS`、`PARTIAL`、`FAIL`

- `fail_items` / `partial_items` 填文件、行号和简短证据，不得空口判定
