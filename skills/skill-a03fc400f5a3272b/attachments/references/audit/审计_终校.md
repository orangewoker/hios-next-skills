> **触发**：Phase 3 校验+修复完成，--done 标记 DONE 前
> **前提**：运行 `python scripts/verify_phase.py 3 {N} --project-dir "{项目目录}" --json` 或 `python scripts/validate_ep.py {N} "{项目目录}"`

## 审计步骤

### 1.前置追踪（阻断级）

对 Phase 1 审计报告每个 FAIL 项：Read 剧本对应行号确认修复状态。对 Phase 2.5 审计报告每个 FAIL 项：Read 对应分镜文件确认。任一 FAIL 项未修复→立即整体 FAIL，拒绝继续。

### 2.R1-R4 资产一致性（全量）
逐文件检查所有分镜文件（最终验证不允许抽样）。取 validate_ep.py 中 R1-R4 FAIL 行，逐项用 Read 验证。

追加检查：
- 主体绑定内容随角色参考图引用，包含固定外观、配饰、身份标识、能力视觉、固定招式视觉、灵光法相和召唤特效。
- 每个 15 秒即梦片段列出本段角色参考图、独立调度物参考图、场景空间蓝图、故事板参考图；本段无独立调度物时写“本段无独立调度物参考图”。
- 每个 15 秒即梦片段列出本段资产自身尺度；真实同框、接触、遮挡、承载、穿越或变形镜头呈现本镜实际发生的尺度关系。尺度信息必须来自对应资产提示词。

### 3.时长达标（全量）
全量检查所有分镜文件时间段标注，每段（15 秒片段）≥15秒。单镜头 Tx 自由分配 2-6s。

### 4.格式合规（全量）
全量检查单文件双模块结构：每个 `S*_即梦视频.md` 必须同时含 Module 3 故事板（7 节齐全）和 Module 4 即梦视频（6 节齐全）。

### 5.台词时长（全量）
全量检查台词字数÷**3.0** ≤ 时间段时长（与[分镜_06_时长](./分镜_06_时长.md) §二、scripts/_rules.py 的 `DIALOGUE_CHARS_PER_SEC` 统一）。

### 6.13项要素
取 validate_ep.py 中 13 要素 FAIL 行。列出缺失项。

### 7.运动强度
全量检查每分镜≥1处运动强度标注（0.3-0.9）。

### 8.时间轴
全量检查 0-3/3-6/6-10/10-15秒四段齐全。

### 9.S5 格式铁律 F1-F6
全量检查 F1-F6 逐条验证。

同时写入结构化判定文件：

路径：`.pipeline/audit-3-ep{NNN}.json`

```json
{
  "phase": "3",
  "episode": {NNN},
  "conclusion": "PASS",
  "allow_advance": true,
  "fail_items": [],
  "partial_items": [],
  "summary": "最终审计通过，可发布"
}
```

字段规则：
- `conclusion` 只能是 `PASS` 或 `FAIL`
- Phase 3 不允许 `PARTIAL` 推进
- `allow_advance` 仅在 `PASS` 时为 `true`
- `fail_items` 填文件、行号和简短证据，不得空口判定

## 规则

- 每个判定须有文件路径+行号+原文
- 全部步骤不可跳过
- 禁止编造证据，须用 Read 实际确认
- 前置审计报告不存在或 FAIL 项未修复→拒绝审计
- Phase 3 最终审计全量检查，不允许抽样
- 默认发布不允许
