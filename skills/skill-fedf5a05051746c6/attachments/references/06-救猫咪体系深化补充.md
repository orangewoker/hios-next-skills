# 救猫咪体系深化补充

> 来源：《救猫咪3：反击战！》+ 《救猫咪经典电影剧本探秘》布莱克·斯奈德

## 一、三种世界与变形机器（《救猫咪3》核心贡献）

### 正题→反题→合题

```
正题(Thesis)          反题(Antithesis)         合题(Synthesis)
第一幕                 第二幕                    第三幕
旧世界                 颠倒的新世界               第三条路
"还没改变的世界"        "正题的镜像"              "融合了两者的新世界"
```

- **正题**：故事开始的世界，英雄尚未改变
- **反题**：正题的颠倒版本——必须是颠倒！《训练日》中伊桑从有道义警察变成腐败警察的门徒
- **合题**：第三条路，融合正题和反题的精华。不是回到原点，而是升到更高的层次

### 变形机器

英雄的变化不是一蹴而就的，而是像机器一样一步步完成的：

```
旧自我 → [停滞=死亡] → 觉醒 → [停滞=死亡] → 蜕变 → [停滞=死亡] → 新自我
```

**"停滞=死亡"法则**：每当故事节奏慢下来，就是"死亡时刻"——必须有什么东西死去（旧的信念/关系/希望），才能让新的东西诞生。

- 《星球大战》中卢克看着双日落——他的旧梦想死了
- 每个场景内部也可以有"死亡时刻"——某个期待/假设破灭

## 二、两次撞击法则

"催化剂（推动）"不是一次，而是两次！

1. **第一次撞击**：暗示变化要来了——微弱的信号
2. **第二次撞击**：变化真的来了——无法忽视的冲击

案例：《朱诺》

- 第一次：朱诺发现怀孕（暗示变化）
- 第二次：决定要把孩子送人（真正的推动）

**为什么要两次**？第一次让我们有预感，第二次才真正把英雄推入冒险。两次之间产生了张力。

## 三、五要点结局

每个故事的结局都包含五个关键要点：

1. **风暴袭击城堡**：英雄和盟友向敌人的堡垒发起最后进攻
2. **发现暗藏的真相**：在关键时刻揭示一个改变一切的真相
3. **主题的终极证明**：用行动证明主题（不是说出来的）
4. **最终牺牲/选择**：英雄必须做出最艰难的选择/牺牲
5. **新世界的建立**：合题世界确立，旧秩序被新秩序替代

案例：《魔法奇缘》

1. 公主向邪恶王后的城堡进攻
2. 发现真爱之吻才能拯救
3. 公主可以自救，不需要王子
4. 选择留下真实世界
5. 新的" Happily Ever After"建立

## 四、案板四排法（15→40场景）

### 从15个节拍到40个场景

排对应卡片数说明第一排第一幕10张开场画面到第二幕衔接点第二排第二幕前半10张B故事/娱乐游戏到中点第三排第二幕后半10张坏蛋逼近到第三幕衔接点第四排第三幕（五要点结局）10张5个结局要点×2张卡

### 案板工作法

1. 先放15个节拍点卡（BS2核心骨架）
2. 每个节拍扩展为2-3个场景卡
3. 用不同颜色标记不同人物线
4. 可以滑动、移动场景卡，灵活调整
5. 每张卡写：场景编号+一句话概述+情感色调

## 五、理直主干五问清单

写剧本前/改写时必须回答的五个问题：

1. **这是关于谁的故事？** → 主人公是谁？他的问题是什么？
2. **这个故事讲的是什么？** → 主题是什么？一句话说清
3. **我们为什么关心？** → 利害关系/赌注是什么？
4. **这个故事的合题是什么？** → 英雄最终学到/变成什么？
5. **反面力量是什么？** → 谁是坏蛋？他为什么这么坏？

如果五个问题都能清晰回答，你的主干就理直了。

## 六、绿灯检查清单（50问）

剧本投递前的终极自检，分为以下维度：

### 故事与构思（10问）

- 故事线能否一句话说清？
- 有没有意外/讽刺？
- 片名是否有力？
- 类型是否清晰？
- 目标观众是谁？
- 是否有"哇"的瞬间？
- 与同类型电影相比有何新意？
- 主角的欲望是否清晰原始？
- 利害关系是否够大？
- 能否想象出预告片？

### 人物（10问）

- 主角是否主动？
- 主角是否有清晰的问题？
- 我们是否希望主角赢？
- 坏蛋是否比主角强？
- 坏蛋是否有合理动机？
- 主角是否有弧光？
- B故事是否影响A故事？
- 配角是否有区分度？
- 人物是否有"救猫咪"瞬间？
- 人物行为是否从性格自然流出？

### 结构（10问）

- 前10页是否建立了一切？
- 催化剂是否在第12页左右？
- 情节点I是否清晰有力？
- 中点是否有伪胜利/伪失败？
- 一无所有是否有死亡气息？
- 灵魂黑夜是否足够黑暗？
- 情节点II是否推动入第三幕？
- 每10-15页是否有转折？
- 是否有"停滞=死亡"时刻？
- 是否有两次撞击？

### 场景与对白（10问）

- 每个场景是否推动故事？
- 是否有场景没有转折？
- 对白是否每个人物声音不同？
- 是否有问答式对白？
- 潜台词是否充分？
- 呈示是否隐藏好了？
- 伏笔是否自然？
- 场景描述是否视觉化？
- 是否删了场景头尾？
- 是否有重复的信息？

### 格式与专业度（10问）

- 格式是否正确？
- 是否超过120页？
- 拼写是否检查？
- 是否有镜头指示？
- 是否有演员提示？
- 是否大声朗读过？
- 人物名是否容易区分？
- 场景描述是否简洁？
- 第一页是否抓人？
- 是否已准备充分才寄出？

## 八、行业生存指南（《救猫咪3》第七章）

### 推销你的剧本

1. **7个节拍点推销法**：用7个节拍讲述你的故事（不是15个）
2. **电梯推销**：30秒说清你的故事
3. **穿着得体**：不要穿戏服/太随意
4. **跟进**：会后24小时内发感谢信

### 经纪人/经理人三角

- **经纪人（Agent）**：负责谈判合同、找机会
- **经理人（Manager）**：负责职业规划、发展策略
- **律师（Entertainment Attorney）**：审核合同
- 三个角色各司其职，你需要团队

### 三种面谈会

1. **一般会面（General Meeting）**：互相了解，无具体项目
2. **推介会（Pitch Meeting）**：推销特定项目
3. **剧本会（Script Meeting）**：讨论已写好的剧本
