# 《天空》白模 / Previs参考数据库 V2｜Minimum 4s

> 核心修订：所有白模视频、动作参考视频、Camera参考视频的**截取/生成总时长不得低于4秒**。
> 核心动作可以短于4秒，但必须被包含在4–10秒完整上下文中。

## 0. 统一规则

### 双时长
- Edit Duration：正片最后使用时长，可<4秒。
- Generation Duration：白模/模型实际生成时长，必须≥4秒。

### 参考视频截取
任何影视参考都必须截取≥4秒：
- 动作前上下文
- 核心动作
- 动作后释放

### Previs Clip结构
`Head Handle → Core Action → Tail Handle`
