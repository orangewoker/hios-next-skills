## 技法1：中英混排（万物生核心特征）

规则：每句描述性内容至少含1个英文原文短语/从句，不仅限于专业术语。

✅ `an extreme low-angle handheld dolly-back tracking shot of bare legs walking极低机位手持倒退跟拍一双腿走路`✅ `brisk purposeful rhythmic walking pace with quick clipping footstep tempo快速有目的的有节奏行走步速带着轻快敲击般的脚步节拍`❌ 全中文无英文

**量化底线**：

- 连续机位/极端动作段 ≥4处英文从句级短语
- 固定镜头/静态段 0-1处或纯中文（不禁纯中文叙事）
- 英文用完整从句级（≥5个连续英文词），不用单词级

**体感英文替代技术英文的对照**：

技术英文（单词级）体感英文（从句级）`low angleextreme low angle贴地向正上方仰拍walking fastbrisk purposeful rhythmic walking pace with quick clipping footstep tempono movementwith no transition no warm-up no anticipationcrane upa single rapid vertical crane-up ascent with no intermediate stops no pauses`

规则：每2句至少嵌入1个"全程/始终/持续/贯穿整段"时间锁定词。不只在段尾写一次。

## 技法3：附着式时间标记

**何时用**：多事件并行场景（推荐附着式写法1-2处锁关键节点）；单线叙事（由空间递进控制时序，不推荐用） **怎么写**：「行进至片段中段（约第2秒）」/「整个过程持续约半秒」 **不用时用什么**：过渡词链 + 因果链：「她走入光区→经过店铺时镜头偏转→行至转角处视线扫过」

## 技法4：物理动作代替心理描写

规则：删除所有"知道/觉得/认为/意识到"等心理动词。AI无法理解内省状态，只认外部可观察动作。

✅ `她的肩部在枪尖到达前0.3秒预判性下沉1cm`（不写"她知道"） ✅ `他猛地从坐姿弹起，从喉咙里发出一声短促尖锐破音惊叫`（不写"他害怕了"）

---

## 技法5：否定句品类化（v4口径）

规则：否定句分两类——画面状态指令写进正文（不动/不居中/不是X，万物生正文157次）；品类级排除写负面声明。

- 画面状态否定（不做什么）→ 写进正文（照万物生「不动」「不居中」「不是X」）
- 品类级排除（无CG光滑质感/无3D渲染感/不夸张特效）→ 文字负面声明（STYLE LOCK场景行/重申单块）
- 接触白名单（枪尖不接触皮肤）→ 重申单块
- 翻车修正（X是暗红不是银蓝）→ 项目《翻车修正库》+重申单块

✅ 正面不变量替代细节否定：「守住几条：丹眉始终居中；景别锁死腰部以上；人与物只从侧缘擦入」 ❌ 细节否定堆砌：「没有睁大眼没有屏息没有皱眉/不早不晚/不是直直落下」→ 僵硬病灶（ref04-A） ❌ 同义凑数：「不是加速不是突然停顿」→ 同义，只保留1处

## 技法6：音效内嵌 — 分线规则（方案A5）

**分线执行**：

- **静态段（空镜/对话/凝视）**：\[STYLE LOCK\]第三行写声源概览 + 叙事末尾独立音效收束段（声场演变+拟声词）
- **动作段（打斗/追逐/冲击）**：打击三要素嵌入动作句（ref01/四）+ 每镜末一句伴随收束句

✅ 动作段正确：「长枪脱手砸在湿石板上"clang"一声脆响、镜头猛地一震」 ✅ 静态段正确：收束段独立写「脚步声在段尾渐远渐轻。镜头全程保持同一距离同一角度」 ❌ 打斗段把音效全塞到收束段（失打击的声画同步）

**拟声词规则**：每段≥2种声音类型，拟声词用引号包裹（"嗖——"、"咔！"、"duang"）

### 时间段音效块（≥8s或≥3分镜启用，红线配套）

⚠️ 已改强制：**启用分镜表头就必须为每个分镜配时间段音效块**，二者是配套不是二选一。

每个分镜/时间段配独立音效块，格式：

```
时间段音效：[声源1]——[质感/方位描述]。[声源2]——[演变]。[沉默/留白声明]。
```

✅ 渊式：「时间段音效：翼尖和脚底火焰喷射声——高频冷色调喷气声。翼板撕裂空气的尖锐呼啸——持续升高。落地时沉重金属撞击沙地的低闷声响。一段沉默——吊装臂已展开，等待下一步指令。」

### 音轨行时序三段式（红线·正例）

罗列式（"声源1+声源2+演变"）已废止。音轨行必须有时序结构：

✅ 万物生拔剑段（动作段）：

> 「音轨：仅环境音与动作音，不配 BGM。**起幅**是道观殿内安静的环境底噪——香烟气流的极轻流动、悠远的空间回响；**随拔剑动作推进**，叠入衣料摩擦、脚步碾地、金属出鞘的清越摩擦与剑身震颤的嗡鸣；**收幅**归于一种屏息般的寂静，只余一缕剑鸣余韵与人物克制的呼吸。」

✅ 万物生草浪段（变速段）：「子弹时间慢速段落里这些声音随之拉长、低沉、绵延，加速时骤然收紧回正」——音效随画面事件变形。

场级声浪弧线与主观听觉（多镜组/情绪重场）见 ref08/四。

### 突静三用法（万物生/渊提炼）

音效的"消失"和"出现"同等重要。写法必须带"同一瞬间/没有渐弱过渡"：

- ① 紧张顶峰→突静（反差）：「所有的震颤、嗡鸣、警报——全部在同一个瞬间戛然而止瞬时消失，没有任何渐弱过渡」
- ② 空间切换→声切断：「进入卵膜瞬间——所有外部声音被切断，只剩下液体内部的沉闷、压抑的寂静」
- ③ 段尾收束→全灭：「镜头推进瞳孔时——一声逐渐升高的电子嗡鸣，然后一切声音被切断。黑场。完全的沉默。」 ⚠️ 突静后必须给新信息（疑惑表情/空间揭示/黑场）。

### 五层音效（大场面灾难/战争段强制）

```
最底层[巨物地鸣] → 其上[首领级生物] → 中频层[中型群] → 中高频层[小型群] → 最表层[人群]
+ 声明"随运镜各声源远近比例自然此消彼长"
```

✅ 万物生：地龙超低频地鸣→兽王碾地闷雷→甲壳兽群→龙虱群→奔逃人群，五层交织、无一刻间断。

## 技法7：元注释系统

三种类型：排除型（排除常见AI误读）、重音型（强调关键细节不可忽略）、否定型（批量排除AI高频错误）

✅ `(注意是整个躯干完全静止但衣摆被持续吹动不是一段静止一段突然动)`✅ `(是一次直线滑动不是乱摸不是反复摩擦)`规则：每段至少1处元注释。用于AI容易产生误解的位置。

## 技法8：叙事流连续性

三项强制要求： ① **过渡词≥3处**：用"随着/与此同时/就在/随即/紧接着/然后/就在…的瞬间" ② **因果链≥2处**：用"同步/触发/激活/使得/引起/随即" ③ **动作-镜头联动**：关键事件写在同一句，用"同步/伴随"连接

✅ 「长枪横飞的瞬间镜头同步启动单次急速横摇」 ❌ 「铁傀掷枪。镜头横摇。」（两件事分两句写）

## 技法9：段落信息层数控制

**信息层类型**（9层）： 层①镜头类型/运镜 / 层②空间/构图 / 层③角色姿态/生理 / 层④动作/事件 / 层⑤因果连接 / 层⑥否定锚定 / 层⑦音效 / 层⑧画面快照 / 层⑨对比声明

**分层规则**：

- 锁定段（段首）：3-5层
- **事件段（中间段）：≤3层**（超则拆段）——硬阻塞
- 收束段（末段）：1层，不可与事件段合并
- 例外：全程同一高能量动作（如刘回10秒crowd-surf）允许单段8层，同时满足（①持续能量无边界②字数≥500字）

## 技法11：比喻参照（方案A8·新增）

**规则**：每个非常规视觉元素（特效/巨物/奇观/异常速度）给一个"像/如"视觉锚，每段≥1处。

✅ **万物生原文**：

- 段二：「像幕布被向两边拉开」（龙虱被斩开）
- 段四：「如一道静止的钢铁山脉横躺」（地龙尸体）
- 段五：「像一场自然的兽群大迁徙」（甲壳兽群）
- 块372：「像踩着一个缓慢而固定的节拍」（丹眉慢速行走）
- 段一：「整条地龙是一根从地面直插云霄的擎天巨柱」
- 段一：「如厚重的棉絮般层层堆叠」（云海）
- 段十五：「如移动的山丘」（兽王盲可汗）

❌「她的步伐稳健」→ ✅「她的步伐像踩着一个无形的节拍，每一步间隔拉得很开」

**比喻来源建议**：从剧本核心意象延伸（墨韵→水墨喷涌像幕布掀开；机械→像被扯断的木偶线级）。

## 技法12：状态机三拍（带状态元素必用）

任何会变化状态的元素（屏幕/通讯模块/光环/眼睛/武器充能）写三拍：

```
前状态 → 触发事件 → 后状态（+落幅保持）
正文写一遍，重申单块再写一遍
```

✅ 渊·通讯模块：「红光——待命状态」→「通讯频道突然响起——红光瞬间熄灭，转为稳定的冷蓝色光」→ 落幅「蓝光保持稳定亮着，频道保持接通」 ✅ 万物生·江流面板：眼点熄灭→卫星地图亮起（纯图形无文字）→警报图标跳动beep→✅符号亮起配"bling"一声

## 技法13：惯性焊接句（动作链高级连接词）

连续动作之间用物理量做焊接，比"随即/然后"更有因果质感： ✅「推进系统没有减速——拔枪的瞬间利用惯性转向，龙脊枪划出弧线刺向第二只」 ✅「长发与红穗随旋身的离心甩成一道弧线」 ⚠️ 判别：删掉这句后动作链断不断？断=焊接句（合法）；不断、只是在解释一个已可见的结果=力学解释句（违禁，）。 ❌ 力学解释句：「因装甲自重巨大产生惯性，身体前冲半步才停稳」

## 技法14：打断格式（台词/动作被截断）

打断 = 断在第几个字 + 打断源 + 被断方生理残留： ✅「她话音说到"什"字尚未结束的瞬间，沙面猛然爆裂炸开」 ✅「玄鹄（打断她——他没有等她说完）："我一定要去找她！"……霜鹭的嘴唇还微微张着——那句话被截断在喉咙里」

## 技法15：光随动演化（华彩段）

光线不是固定布景，可以作为"演员"随动作演化。三要素：

```
起幅光质 → 随动作逐步变化（"与动作严格同步"声明） → 关键帧光效爆点
```

✅ 万物生·转身拔剑：「起幅是道观香雾里柔和漫散的乳白逆光…随着她转身背向光源，柔散的环境光逐渐收拢、聚成一束更硬更窄的强逆光…到拔剑亮刃的一刻，这束强逆光正打在剑刃上，剑身迎光被瞬间点燃、炸出一道炽亮到接近纯白过曝的冷白高光——光跟着人转、跟着剑亮而收紧、点燃」

## 慢的规则（方案A10·新增）

**慢≠空**。慢镜头必须有三个要素：

**① 节拍感**：用"像踩着一个固定节拍"比喻声明慢不是随机慢，是有节奏的慢 **② 微细节密度**：慢镜头期间，角色必须有 ≥3 个肉眼可见的微动元素（水珠甩落/肩头起伏/布料褶痕变化/发丝在气流中缓慢摆动/灰尘在光柱中悬浮等） **③ 角色意图**：声明为什么慢（从容/压制/疲惫/酝酿/享受）

✅ 万物生块372：「每一步都从容地落下又抬起、两步之间停顿明显、间隔拉得很开，**像踩着一个缓慢而固定的节拍**一步一步向前。发梢的水珠一颠一颠地甩落，肩头随匀速的步子稳定地小幅起伏，湿布料随上身起伏轻微窸窣」 ❌「她缓慢地走着」——缺节拍感、微细节和角色意图

## 物理规则写法细则（对照 ref03）

> 核心原则：**写可见的身体位移，不写力学推导名词。打斗段动作过程一句带过，细节预算全给结果分解。**

❌ 力学解释句（违禁）✅ 可见视觉结果 / 惯性焊接句（合法）重心越过双足支撑面身体前冲半步才停稳因装甲自重巨大产生惯性，身体前冲半步才停稳铁傀收不住势头冲过头（结果直述）受关节摩擦力影响关节咬合时发出沉闷声力矩不平衡导致旋转她在落地时身体仍带着螺旋的余势又转了半圈弹性碰撞枪杆撞击石板后弹起（动作链之间）随即/然后（弱连接）利用惯性转向/随惯性甩出/推进没有减速（焊接句）

**判别口诀**：写完物理句子后自问——「这句在屏幕上能看到什么？」答不出=力学推导→重写可见结果。再问「删掉它动作链断不断？」断=惯性焊接句，保留。

追逐场景→间距变化趋势声明 / 巨物对比→≥2级尺度参照 / 同类事件重复→逐次升级新细节 / 声音分层→近中远三层 / 多角色同框→角色名开头、每句用全名 / 步态节奏→与镜头运动对比 / 镜头起收→物理遮罩填满终结 等。
