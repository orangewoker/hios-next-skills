适用: 角色听到致命消息的瞬间、情绪爆发点、真相揭露、暴力冲击前的定格、全片最大情绪爆点
时长: 动作0.2-0.3秒 + 前后停留（前hold≥2秒建立全景，后hold≥3秒读特写）
能量: 极高（瞬时冲击，不是持续高能）
意图: 慢推是"请看"，急推是"看这个！"——一拍之内把观众视线砸到目标上，没有选择余地。落位的震屏回弹是物理重量感，不是故障。全片≤2次，用多了=廉价

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|---------|
| 起始景别 | 中全景或中景（建立空间关系） | 冲击感越强→起始越远，推近落差越大 |
| 结束景别 | 面部特写或大特写 | 情绪爆点→面部特写；信息冲击→道具/眼睛大特写 |
| FOV | 起始47°（35mm）→结束18°（85mm）或8°（135mm） | 光学急推（zoom）vs 机位急推（dolly）二选一 |
| 急推时长 | 6-8帧（0.2-0.27秒@60fps） | >10帧=普通推近，冲击感消失；<4帧=看不清发生了什么 |
| 推近曲线 | ease-in 急加速 | 匀速=没有冲击感，必须前慢后快 |
| 震屏 | 到位后高频微震（振幅±8-12像素，指数衰减，τ≈2帧，6帧收干） | 振幅>20像素=故障感；<5像素=不可感知 |
| 回弹 | 震屏后轻微回弹到稳定构图（3-5帧） | 回弹幅度3-6%，过大=弹簧玩具 |
| 运动模糊 | 急推段允许运动模糊（快门角度180°+），落位后必须清晰 | 落位后仍模糊=没对上焦 |
| 声音 | 急推同步impact音效（低频冲击），落位后环境音骤降 | 声音冲击必须与画面急推同步，差1帧=出戏 |

## 已知坑

- **命门：急推时长6-8帧**。>10帧读作普通推近，冲击感完全消失；这是本卡的核心参数，不得降档
- **命门：前后必须有足够hold**。前hold≥2秒建立全景（观众需要知道空间关系），后hold≥3秒读特写（冲击后需要消化时间）。只有急推没有hold=闪一下就没了
- 禁止急推后再震屏再回弹（两款混用=穿帮），震屏和回弹是一个连续动作
- 禁止同一支片急推>2次（手法去重，用多了=廉价特效）
- 禁止落位后画面模糊（急推段可以模糊，落位必须清晰）
- 禁止没有叙事理由的急推（运镜必须有情绪/信息支撑，不是炫技）
- 光学急推（zoom）和机位急推（dolly）视觉效果不同，必须二选一并写明
- 震屏振幅必须过肉眼可感知阈值（≥8像素），但不得超过20像素（读作故障）
