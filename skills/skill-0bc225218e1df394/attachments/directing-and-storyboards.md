## 短片叙事

用最少信息建立完整五要素：

1. 主角：谁在行动，身份特征是什么。
2. 任务：必须达成什么明确目标。
3. 动机：为什么此刻必须行动。
4. 场景：动作发生在何时何地。
5. 情节：开端、发展、高潮、结局之间具有因果。

让15秒故事聚焦一个冲突和一个转折；让30秒故事拥有更清晰的铺垫、升级和回收。不要用旁白补救无法从画面理解的基础因果。

## 首秒钩子

先设计第0—1秒，再设计后续镜头。首秒必须同时具备：

- 一个无需解释即可理解的强视觉事件，例如突然扑向镜头、巨大物体砸落、夸张滑倒后立即反击、爆破冲击、极近距离险情、强烈体型反差或搞笑误触机关。
- 一个与事件严格同步的声音冲击，例如巨响、撞击、爆裂、尖锐机械启动、动物惊叫或空间混响；声音不得比画面提前或滞后到失去因果。
- 一个清晰的角色反应、运动方向或后续目标，让钩子能自然接入故事而非独立噱头。

禁止空镜、Logo、字幕、缓慢推镜、纯对白或无动作站立占据第一秒。不要每次机械复用爆炸；根据故事选择搞笑、危险、惊奇、速度或规模钩子。

## 镜头公式

按以下七槽位编写每个镜头：

`景别 + 角度 + 主运镜（最多一个辅助运镜）+ 主体与动作 + 场景/光线/氛围 + 速度/时间 + 风格/画幅`

几乎每镜都明确景别与角度。把速度、风格和画幅放在镜头描述末尾。

### 景别选择

- 大远景/远景：建立地理、规模和行动路线。
- 全景/中远景：展示动物全身动作和环境互动。
- 中景/中近景：表现攻防、反应和角色关系。
- 近景/特写/大特写：突出眼神、爪部、道具、呼吸和冲击细节。
- 广角/超广角：强化纵深、速度和宏大环境。

通用文字分镜可使用上面全部景别建立空间；但提交给图片模型的动作预演分镜板采用固定近距节奏：`大特写 → 近景 → 大特写 → 近景……`。相邻画面禁止相同景别，每个画面都使用有明确倾斜方向的荷兰角构图。用前后景遮挡、视线、动作方向、地标切片和文字备注补足空间关系，不得为了交代全景而破坏交替规则。电影首帧继承对应分镜板第1格。此限制不用于宠物三视图和纯场景参考图。

### 角度选择

- 平视：自然、中性和清晰交代。
- 低角度仰拍：力量、速度、英雄登场。
- 高角度俯拍：危险地形、受压制或路线展示。
- 荷兰角：失衡、冲击、速度或喜剧张力。动作预演分镜板必须使用，电影首帧继承第1格的倾斜构图；其他资产只在有叙事动机时使用。
- 主观POV/过肩/反打：代入、对峙和视线关系。

### 运镜选择

- 跟拍、低角度跟拍：奔跑、追逐、贴身打斗。
- 推近、拉远：聚焦威胁或揭示更大空间。
- 横移、摇摄、弧形环绕：展示路线、对峙或立体关系。
- 俯冲、升降、航拍：建立规模和场景转换。
- 甩镜、匹配切、动作切：连接快速动作。
- 手持微晃：增强临场感，但不得造成无动机抖动。
- 变焦或移焦：转移注意力；不要和多个复杂运镜同时堆叠。

## 动作节奏

参考节奏：

- 首秒钩子：第0—1秒内完成视觉事件、声音冲击和角色反应，可拆成1—2个紧凑镜头。
- 激烈争斗、追逐：0.4—1秒的快速镜头或动作节拍。
- 日常交代、短反应：1—2秒。
- 情绪、悬念或环境揭示：2—4秒。
- 英雄登场或大招：先用约2—3秒蓄势，再用约1秒爆发；根据总时长压缩。

让动作幅度明显大于日常行为，但放大的是物种原生能力：奔跑、跳跃、蹬地、潜行、扑跃、急停、攀爬、飞行、游动、滑行或环境互动，不默认改成人类跑法、挥拳、持续直立或人类手势。姿态轮廓清晰且变化充分。使用完整的蓄力、爆发、腾空/移动、接触、受力、落地/恢复相位；允许适当加快动作发生和变换速度，但不要快到动作不可辨识。组合快速运动镜头与短暂停顿，让动作具有呼吸。不要把所有镜头都做成同速快切。

每个动作镜头同时写两层：

- `主动作链`：推动叙事和冲击的动作，必须符合角色身份卡中的原生步态、身体力学和拟人化等级。
- `习性微动作层`：每镜0—2个可见细节，例如兔子鼻翼轻动/耳朵转向/前爪洗脸、猫耳后压/胡须变化/尾尖摆动/哈气。微动作只在情绪或动作节点出现，不机械重复，不遮挡主动作。

动作场面优先使用：

- 贴身跟拍＋低角度闪避。
- 多机位同一动作＋动作匹配切换。
- 用近景中的地标、前后景与角色左右关系交代位置，再以大特写冲击插镜，并切回近景确认结果。
- 旋转攻击时让摄像机与动作同步，但保持屏幕方向。
- 爆炸或撞击时用冲击反应、环境反馈和短促镜头震动，不让画面持续失控。
- 使用脚步、风切、喘息、动物叫声、撞击、摩擦、破碎、机械、爆炸、环境反射与尾音构成丰富音效层次；每层都要对应可见动作或空间，不要用音乐掩盖音效不足。

## 空间与连续性

在文字分镜和预演板中显式维护：

- 180度轴线和角色左右关系。
- 角色进入/离开画面的方向。
- 视线方向和视线空间。
- 动作开始姿势、接触点、结束姿势。
- 角色、道具和特效的状态变化。
- 场景地标、天气、光源方向和色温。
- 摄像机所在区域与下一镜切入理由。

除非用明确的越轴镜头建立新轴线，否则不要突然翻转运动方向。

## 双层分镜

### 第一层：导演预演分镜板

每15秒输出一张至少8格的预演板，每格通常承载1—3秒，快速钩子或撞击可更短，但必须保持动作可读。采用白色或浅色素底与黑色松散结构线；不同角色分配固定且互不混淆的颜色并跨页沿用。红框只表示摄像机取景，蓝箭头只表示角色运动/力量/呼吸/方向，绿箭头只表示镜头运动。用不同颜色文字分别标记画面内容、音效、拍摄手法/景别/镜头运动和拍摄参数，并保持类别颜色固定。角色只画火柴式结构、简化动物模型剪影或极简轮廓，无面部、服装、解剖、纹理、阴影或精致渲染。景别从第1格开始按 `大特写 → 近景` 依次交替，禁止相邻重复；每格使用荷兰角并写明倾斜方向。通过不同构图、机位和大幅动作姿态表现节奏；改变倾斜方向时不得翻转屏幕运动方向或180度轴线。仅第一张分镜板的第1格承担全片第0—1秒钩子；后续分镜板从上一张最后一格的精确状态继续。专注布景、机位、运动、时机和连续性，优先可读性而非绘画质量；保持粗糙导演缩略图，不做概念艺术、干净UI或信息图。

30秒内容输出两张连续编号且每张至少8格的分镜板。若最后不足15秒，仍使用一张至少8格的板，根据节奏分配面板；不要用无意义动作填充。

### 第二层：分镜驱动的电影首帧

在预演板锁定后，根据三视图、场景、配角、道具和对应预演板生成最终风格首帧：

- 一次性路线和多段路线第一段只生成一张电影首帧。首帧严格采用对应预演板第1格的景别、荷兰角方向、机位、构图、角色位置、动作起始姿势、运动方向、场景地标、光线和道具/特效状态。
- 多段路线的第2段起，不用图片模型重新生成首帧。先让上一段通过质检，再提取其实际最后一帧并原样设为下一段首帧；不得重绘、修饰、裁切、缩放、调色或重新编码成视觉不同的画面。
- 把粗略的彩色导演标注草图转换为真实动物、真实摄影场景和电影级光影；不得渲染分镜板的彩色角色示意、红色取景框、蓝色/绿色箭头、编号、文字、标签或页面布局。
- 不再为动作转折或主要机位批量生成中间关键帧。多段路线只提取实际尾帧用于后续首帧绑定，并在连续性矩阵中记录精确状态。
- 视频生成时同时引用出场角色、对应预演分镜板和该首帧：分镜板控制整段镜头顺序与动作连续性，首帧只锁定最终画面风格和开场状态。
- 若重做某段使其实际尾帧变化，所有已用旧尾帧作为首帧的后续片段均失效；从该段之后依次重新生成，不能把新前段与旧后段直接拼接。

## 文字分镜字段

每镜按表格输出：

| 字段 | 内容 |
|---|---|
| 编号/时间 | 镜头编号、起止时间、时长 |
| 画面 | 主体、构图、前中后景和关键地标 |
| 景别/角度 | 明确景别与拍摄角度 |
| 运镜 | 一个主运镜，最多一个辅助运镜 |
| 动作链 | 用“动作一 → 动作二 → 动作三”描述可见节拍；注明主动作链与习性微动作层 |
| 连续性 | 入画方向、出画方向、起止姿势、道具/特效状态 |
| 光影 | 主光方向、色温、氛围介质 |
| 声音 | 环境音、动作音、叫声、对白；视频片段本身明确无内嵌音乐，多段成片的音乐在剪辑阶段按用户选择另行处理 |
| 动物行为 | 原生步态、身体力学、自然叫声、习性微动作和拟人化等级是否与角色身份卡一致 |
| 转场 | 硬切、动作匹配、甩镜、遮挡转场等及其动机 |
| 引用 | 角色、场景、配角、道具、对应预演分镜板和首帧引用名 |

最终检查镜头总时长与用户选择的规格完全一致。
