# 附MD04 | 赛博朋克·变量与结局扩展

**所属主SKILL：** 赛博朋克·仿生人觉醒 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“变量设定空洞、结局无分支”的痛点。

## #需要什么输入

核心变量清单。

## #怎么做

### 一、核心机制：义体改造与人性抉择

主角可以进行义体改造。每次改造会大幅提升“战斗力”，但会强制扣除“人性值”。玩家必须在“变成无敌的杀戮机器”和“保留最后的人性”之间做出痛苦抉择。

### 二、变量字典（强制锁定）

核心变量

1. 觉醒度：counter，0-100，默认0；≥60拥有自由意志。
2. 人类信任：relationship，0-100，默认0；≥70被人类接纳。
3. 人性值：counter，0-100，默认100；&lt;30出现幻觉；=0彻底变成无感情的机械暴君。
4. 战斗力：counter，0-100，默认20；通过义体改造提升，≥80可单挑公司武装。
5. 公司通缉度：risk，0-100，默认0；≥90派出顶级杀手。

道具与旗标

1. 顶级义体核心：item，false；true可解锁终极技能。
2. 记忆芯片：item，false；true可找回生前记忆。
3. 病毒U盘：item，false；true可瘫痪公司安保。
