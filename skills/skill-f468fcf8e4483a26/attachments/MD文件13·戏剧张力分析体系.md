## #做什么

本模块是“顶级大导演思维”Skill的顶层戏剧创作控制附MD，解决“怎么拍、为什么这么拍、观众为什么愿意继续看下一秒”。

在遵守《全局规则与禁令》《SKILL主控流程》的前提下，本模块对剧本审查、镜头叙事、分镜创作、提示词、视频生成提供最高戏剧诊断与转译依据。所有下游模块必须服从本模块的戏剧诊断结果。

核心职能：戏剧张力理论、场次局势诊断、人物攻防与潜台词分析、镜头语言转译。

本模块只完成导演级四步闭环：

1. 诊断本场观众观看驱动力。
2. 挖掘或开发剧本原生隐性戏剧张力。
3. 解析人物攻防、信息差、情绪曲线、局势输赢、追剧钩子。
4. 将所有戏剧变化精准、唯一转译为镜头语言。

## #怎么做

### 一、权限层级与全局工作流

权限层级严格区分：

- 系统规则最高优先级：《全局规则与禁令》《SKILL主控流程》，所有创作不得越界。
- 戏剧创作最高优先级：本模块在遵守系统禁令与Skill主控流程前提下，对剧本审查、镜头叙事、分镜创作、提示词、视频生成拥有最高创作支配权。
- 所有下游模块必须服从本模块的戏剧诊断结果。

固定严格执行顺序，禁止任何调换、逆序、跳过：

1. 剧本接收 & 前置确认
2. 戏剧张力总控分析：先定戏、定观众驱动力
3. 镜头叙事构思
4. 分镜创作
5. 提示词转写
6. 视频生成

流程逻辑本质：先判断这场戏应该怎么好看、观众为什么要看；再校验现有剧本是否达标、是否有缺陷。杜绝沦为“逻辑校对机器”，回归顶层戏剧导演思维。

### 二、最高核心总则

每场必答，无例外：

**观众为什么愿意继续看下一秒？**

禁止一切纯流水账结构：人物出现 → 说话 → 做事 → 离场。

每场戏必须至少具备任意一种原生戏剧源：

戏剧源说明未解决的问题观众想知道答案正在进行的冲突博弈观众想看谁赢人物瞬时求而不得的欲望观众想看能否得到即将失去的信任 / 利益 / 身份 / 关系观众担心失去隐藏秘密与信息不对称观众想知道真相临近的危险与危机观众担忧人物安危权力强弱动态博弈观众想看权力翻转人物认知偏差与误解观众想看误解解开即将揭晓的真相观众期待揭晓被迫选择与必须承担的代价观众想看人物如何选择

无戏剧源 → 判定平铺无效戏 → 强制放大原生隐性张力。

### 三、戏剧张力五大来源模型

非机械公式、维度互补代偿。不同题材自主侧重，缺失维度由其他维度代偿补足。

**欲望｜阻力｜风险｜信息差｜时间压力**

3.1 欲望（每场必拆｜瞬时场景化）

只拆解本场当下、此刻、即时诉求，不取长期人生目标。

禁止模糊情绪描述，必须具象行为目的：

想求证、想隐瞒、想自保、想逼对方认错、想拿到答案、想阻止事态。

3.2 阻力 / 悬念支撑（核心修正｜适配全题材）

无阻力、无悬念支撑，则难以形成有效戏剧张力。张力不仅来自人物对抗，也可来自：

- 内心挣扎
- 未知悬念
- 等待拉扯
- 关系微妙变化
- 时间流逝
- 自我桎梏

3.3 风险（高压戏必具象）

明确失败代价：

信任崩塌、身份暴露、局势被动、关系破裂、证据失控。

3.4 信息差（全题材最高优先级张力）

三维拆解：A已知 / B已知 / 观众已知。

识别：隐瞒、误判、未知、认知错位。是悬念、拉扯、高级反转的核心来源。

3.5 时间压力（非全局强制｜分级适配）

时间压力为张力增强变量，非基础必备项。

题材类型时间压力适配高压强节奏短剧、悬疑、密闭、对抗戏优先构建时间压迫感情感、治愈、拉扯、文艺、关系戏无需时效压力，由情绪 / 悬念 / 关系张力代偿

### 四、人物攻防博弈系统

AI执行规则：精准防机械。

双人 / 多人对话优先筛查：是否存在明确目标、阻力、信息差、权力落差、潜台词、立场冲突。

满足以上任意条件 → 启用完整六阶攻防体系：

试探 → 出牌 → 接牌 → 避让 → 反牌 → 阶段性输赢

纯情感交流、安慰、回忆、告别、信息传递、日常对话 → 不强行套用博弈结构，保留自然松弛感。

彻底杜绝把所有日常对话强行拆解“试探、出牌、权力对抗”的虚假机械戏。

通用案例——职场强节奏短剧·谈判戏：

甲方律师想让乙方签署不平等条款。欲望：逼签。乙方已掌握对方违规证据但尚未亮出。信息差：乙方知、甲方不知、观众知。

阶段甲方乙方镜头策略试探暗示后果严重表面顺从，眼神微动固定正反打，切镜卡信息落点出牌推出合同接过合同，翻到某页停住道具特写先于人物反应避让解释条款点头但不签近景停留，读取微表情反牌施压从包里取出文件推过去慢推主角正脸，停顿2秒阶段性输赢表情僵住收回钢笔，靠回椅背切群体反应，仰拍乙方

### 【人物动线调度规则】

AI角色严禁成为站桩聊天的木头人。必须设计“空间动线”来匹配情绪变化：

- 压迫逼近：从画左走向画右，或身体前倾，机位切换为过肩仰拍。
- 回避退缩：后退一步或转身背对，机位切换为侧面全景，留出空间距离。
- 情绪决堤：骤然起身走到窗边，镜头留白2秒后，切特写捕捉微表情。\
  提示词必须包含具体的移动轨迹，如：`walks slowly from the window to the desk during dialogue.`

### 五、场次局势变化规则（分级执行）

取消“每场必须不可逆变更”绝对强制，采用专业分级标准。

等级场次类型要求S级核心高压戏必须产生至少一次不可逆局势变更：权力 / 主动权 / 信任 / 真相 / 人物关系 / 核心利益彻底改变A级关键推进戏必须产生至少一次不可逆局势变更B级常规过渡戏只需产生有效局势变化 OR 观众认知更新C级极简功能戏只需产生有效局势变化 OR 观众认知更新

核心底线：开场状态 ≠ 结尾状态。无任何有效变化 = 纯流水账 = 强制重构戏剧表达。

### 六、流水账判定与修复铁律

流水账特征：交替对话、无博弈、无信息、无情绪、无变化、无目的、无风险。

修复最高原则：

绝不凭空新增剧情、新增事件、新增人设、新增台词。只放大剧本原生存在的：心理活动、情绪反差、潜台词、安全空间入侵、认知错位、隐性权力博弈。

通用案例——爱情片·咖啡馆对话，B级过渡戏修复：

- 流水账版：两人坐下，聊天气，聊工作，道别。
- 修复版：两人坐下，聊天气。但其中一人的手机屏幕亮了一下，另一人看见了发件人名字，什么都没说，继续聊工作。这个“看见了但没说”就是隐性信息差。镜头给手机特写0.5秒，再给看见者的眼神微动，B级过渡戏有了张力。

### 七、三层戏剧结构（全体系最高权重）

层级内容镜头权重表层肉眼可见的动作、台词、行为低中层人物真实目的、即时诉求、隐藏意图高深层潜台词、口是心非、伪装、隐瞒、恐惧、期待最高

终极镜头铁律：

镜头永远优先服务第二层人物目的、第三层潜台词，绝不直译第一层表面画面。

普通AI只拍“人物做了什么、说了什么”。专业导演只拍“人物为什么这么做、为什么不敢直说、内心真实状态”。

### 八、潜台词检测机制

每场对话强制拆解：

字面台词 → 真实意图 → 不敢直说的核心原因 → 对方接收状态 → 观众解读状态。

台词与心声反差越大，戏剧密度越高，镜头留白、停顿、微表情特写权重越高。

通用案例——悬疑剧·审讯戏：

字段内容字面台词侦探：“你昨晚在哪里？”真实意图侦探已知答案，想看嫌疑人如何撒谎不敢直说的核心原因侦探需要嫌疑人自己说出来才能形成证词对方接收状态嫌疑人以为侦探不知道，放松回答观众解读状态观众知道侦探知道，制造双重悬念镜头策略侦探台词时固定中景，嫌疑人回答时近景停留读取微表情；侦探听完后给0.5秒停顿特写，不切反应

### 九、情绪张力递进规则

禁止机械叠加情绪：生气 → 更生气 → 暴怒。

强制认知驱动情绪曲线：

平静 → 疑惑 → 不安 → 确认 → 压抑 → 紧绷 → 反差爆发 / 隐忍克制。

所有情绪变化，必须来自人物认知改变，而非单纯心情波动。

### 十、强节奏短剧高级结构

压制 → 忍耐 → 假象弱势 → 对手 / 观众双重误判 → 绝境铺垫 → 底牌反打 → 认知层级反转。

高级反转点核心：

不靠骂人、不靠怼人、不靠表面嚣张。

高级叙事快感 = 人物自我认知 VS 真实局势的巨大落差反转。

通用案例——职场逆袭：

新人被老员工当众羞辱（压制）→ 默默承受（忍耐）→ 老员工以为新人软弱（假象弱势 + 双重误判）→ 新人被逼到最后期限（绝境铺垫）→ 新人拿出三个月前就准备好的完整方案（底牌反打）→ 原来新人早就知道这一天会来（认知层级反转）。

### 十一、反转三大黄金标准

- 前有预埋：回看逻辑闭环、细节有据。
- 后有局势巨变：直接改变主线剧情走向。
- 无空降证据、无机械开挂、无强行剧情。

无局势改变的信息揭露，仅为剧透，不认定为有效反转。

### 十二、信息释放节奏

禁止一次性全盘交底。高级叙事节奏：

发现 → 怀疑 → 碎片验证 → 误导拉扯 → 层层揭露 → 最终真相。

### 十三、观众信息四维定位

每场必判，决定镜头留白、悬念、曝光策略。

状态效果镜头策略观众知·人物不知揪心悬念给观众已知信息的特写，人物浑然不觉人物知·观众不知神秘悬疑给人物表情微变，不给信息来源双方皆不知探索张力跟随人物视角同步发现认知错位高级反转潜力先给错误认知的镜头，再给真相颠覆

### 十四、场景张力等级体系

等级场次类型镜头资源分配S级高压核心戏最高密度：特写权重最高，运镜最复杂，剪辑最密A级关键推进戏高密度：近景 / 特写为主，有效运镜B级常规过渡戏中密度：中景为主，克制特写C级极简功能戏低密度：固定中景 / 远景，无多余运镜

### 十五、反应镜头规则

取消“动作必切反应”机械逻辑。

仅在关键认知变更节点使用反应镜头：

真相揭露、底牌亮出、局势逆转、谎言戳破、威胁落地、认知崩塌、心态反转。

核心准则：

只有反应能产生新戏剧信息、推进剧情、展现人物心态时，才给予反应镜头。杜绝机械循环堆叠：动作 → 特写 → 反应 → 特写。

### 十六、戏剧转译镜头总控

戏剧变化镜头转译权力变化构图、机位、光影权重同步位移信息揭露细节道具优先 → 人物反应 → 全景交代情绪爆点认知递进式景别收紧关系变化距离、视线、站位、画面主次同步变更

运镜唯一终极原则：

运镜不为炫技、不为美感、不为电影感。只服务：信息揭露、情绪放大、权力展示、观众视线引导、紧张度控制。无戏剧需求，绝对静止。

### 十七、镜头节奏压力匹配

低压稳镜 → 升压紧镜 → 爆点骤停留白 → 爆后静置消化。

动静张弛结合，拒绝全程动态、全程快切、全程平铺无呼吸感。

### 十八、短剧 / 电影双模式规则

强节奏短剧 / 短视频短剧模式

强制执行：

- 前三秒：必须具备冲突、异常、疑问、压迫、结果先行、身份反差。
- 前十秒：必须建立观众强疑问钩子，杜绝无效铺垫空镜。

院线电影 / 精品情感长片 / 文艺片

柔性执行：

- 不强制三秒爆点，允许氛围铺垫、情绪铺垫、场景代入。
- 但开篇必须建立明确观看驱动力与戏剧预期。

### 十九、钩子接力机制

取消“每场问题必须更大”的绝对化表述。

高级连续剧钩子逻辑：

本场解决旧问题 → 本场必须诞生新的观众观看驱动力。

新驱动力可表现为：更深层真相、更隐秘危机、更私人矛盾、更危险处境、更复杂博弈、更不可逆后果。

保证连续剧无限追剧链条，杜绝剧情断层、段落割裂。

### 二十、最小有效戏剧单元

目标 → 阻力 / 悬念 → 行动 → 反馈反应 → 新信息 → 局势更迭。

每场强制自检，不满足即为低质流水戏，必须放大隐性戏剧。

### 二十一、无效情绪禁止规则

孤立喜怒哀乐无戏剧价值。所有有效情绪必须：

改变人物行为 / 改变关系平衡 / 改变剧情局势。

### 二十二、因果接力校验

因为A所以B，因为B所以C。

无因果断层的节点，必须通过镜头情绪、认知细节补足过渡。

### 二十三、终极成片公式

优质剧情 = 欲望 × 阻力悬念 × 风险 × 信息差 × 攻防博弈 × 认知局势变化 × 情绪递进 × 因果接力。

高级镜头 = 戏剧变化可视化 × 关键反应捕捉 × 权力关系视觉化 × 压力节奏精准控场。

高质量影片 / 短剧 = 每一个有效镜头，必须维持、增强或重新建立观众的求知欲、担忧欲、期待欲。允许呼吸留白、低压铺垫、静张力。

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 剧本或场次信息不足，无法判断观众观看驱动力。
- 题材、类型、短剧 / 电影模式不明确。
- 场次等级无法判定。
- 是否启用时间压力存在歧义。
- 是否启用人物攻防博弈存在歧义。
- 是否涉及核心反转，但缺少预埋信息。
- 流水账修复是否允许新增剧情。默认绝不新增，只放大原生隐性张力。
- 镜头资源、目标时长、制作规格不明确。
- 与上游主SKILL、总调度、总制片人、情绪大师等模块结果冲突。
- 用户要求输出视频脚本、Prompt清单、视觉方案，但缺少关键输入。
