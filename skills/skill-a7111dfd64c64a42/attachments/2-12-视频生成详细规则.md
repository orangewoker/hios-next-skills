# 视频生成详细规则

本文档为 Skill 第九阶段「视频生成」的详细执行规则，SKILL.md 通过引用链接使用本文档。

---

## 一、视频生成前置条件

进入第九阶段前，以下产物必须全部就绪：

| 前置产物 | 来源阶段 | 校验项 |
|----------|----------|--------|
| 商品图 + 质检 | 第一阶段 | 合格 |
| 投放渠道 / 画面比例 / 风格 / 时长 | 第二阶段 | 已确定 |
| 三视图 | 第三阶段 | 全部确认 |
| 品牌元素 + 片头片尾 | 第四阶段 | Logo/Slogan/类型/时长 |
| 剧本 | 第五阶段 | 已确认，台词/旁白锁定 |
| 分镜脚本 + 合规检查（第一轮） | 第六阶段 | 完整，第一轮合规通过，时长校验通过 |
| 场景图 | 第七阶段 | 全部确认 |
| **人物描述卡 + 人物形象图 + 人物三视图**（如有人物出镜） | **第二阶段人物设定** | **已确认，与视觉风格一致** |
| 广告参数 | 第八阶段 | 全部确认，时长匹配预检通过 |

**前置检查清单**（Skill 内部自动执行）：
- [ ] 所有场景图已确认（数量 = 分镜镜头数）
- [ ] 配音方案已确定（音色/语速/语言）
- [ ] 音效方案已确定（分镜方案/手动修改/AI重匹配）
- [ ] BGM 已确认（添加+风格 / 不添加）
- [ ] 字幕设置已确认（添加+配置 / 不添加）
- [ ] 标题文字叠加已确认（添加+内容 / 不添加）
- [ ] 导出格式/分辨率/帧率已确认
- [ ] 音视频时长匹配预检通过（差异 ≤ 0.5秒，或用户已接受差异）
- [ ] **若人物出镜=是：人物形象图、人物三视图和描述卡已就位，场景图中人物一致性已验证**
- [ ] 用户已最终确认"开始生成"

任一项缺失 → 阻止进入，回到对应阶段补充。

## 二、生成流程总览

```
步骤1: 生成片头视频片段（如有）
    ↓
步骤2: 逐镜头生成主体视频片段
    ↓
步骤3: 生成片尾视频片段（如有）
    ↓
步骤3.5: 【暂停】用户预览确认所有片段 ← 新增
    ↓
步骤4: 视频拼接 + 转场插入
    ↓
步骤5: 音频合成（配音 + 音效 + BGM）
    ↓
步骤6: 字幕/标题文字叠加渲染（如有）
    ↓
步骤7: 合规检查（第二轮：成片终审）
    ↓
步骤8: 成片预览
```

## 三、步骤1-3：视频片段生成

### 3.1 片段生成策略

**生成顺序**：片头 → 主体（按镜号顺序）→ 片尾

**单片段生成规则**：

| 项目 | 规则 |
|------|------|
| 起始帧 | 使用对应场景图作为起始帧参考 |
| 运动控制 | 按分镜中的运镜描述控制（推/拉/摇/移/跟/升/降/旋转/手持/固定） |
| 时长 | 严格按分镜中标注的镜头时长 |
| 风格 | 沿用第二阶段选定的视觉风格 |
| 一致性 | 商品外观须与三视图/场景图保持一致 |
| **人物一致性**（如有人物出镜） | **人物外观须与人物形象图、人物三视图和描述卡一致；包含人物的片段生成指令中必须引用人物形象图和三视图URL** |
| 画面比例 | 与第二阶段选定比例一致 |

**LibTV 调用方式**：
- 使用 `create_session.py` 发送生成指令
- 指令内容包含：场景图 OSS URL + 运镜描述 + 时长 + 风格关键词
- 以场景图作为起始帧，确保画面与场景图一致
- 轮询获取结果（每 8 秒查询一次）
- 完成后使用 `download_results.py` 下载片段

**单片段超时处理**：
- 轮询 3 分钟无结果 → 告知用户"第 X 个镜头生成时间较长"
- 连续轮询 5 分钟无结果 → 标记为"生成超时"，继续生成后续片段
- 超时片段最后统一重试

### 3.2 片段间一致性保障

视频片段之间的视觉一致性比静态场景图更重要（因为视频是连续播放的）：

**强制一致项**：
- 商品外观：全片段一致（颜色/形状/材质/比例）
- 光照方向和强度：连续镜头间不突变
- 色调：全片统一
- 品牌元素：Logo/Slogan 位置和样式一致
- **人物外观**（如有人物出镜）：全片段人物外貌、服装、气质必须与人物描述卡、人物形象图和人物三视图一致；同一人物在不同镜头中不得出现外貌变化（如发型突变、服装变化）；人物动作/表情须符合描述卡中的气质基调

**镜头衔接检查**：
- 相邻镜头的最后一帧与下一镜头的第一帧须视觉连贯
- 转场效果须与第二阶段选定的转场风格一致
- 运镜方向和速度在连续镜头间须合理过渡

### 3.3 转场效果插入

转场在拼接阶段插入，不在单片段生成时处理：

| 转场类型 | 效果描述 | 额外时长 |
|----------|----------|----------|
| 硬切 | 无过渡，直接切换 | 0秒 |
| 溶解 | 前后画面交叉淡入淡出 | 0.5-1秒 |
| 划像 | 画面从一侧滑入替换 | 0.5秒 |
| 缩放 | 画面缩放过渡 | 0.5秒 |
| 无转场 | 不添加任何过渡效果 | 0秒 |
| 混合 | 根据镜头内容自动选择合适转场 | 0.5-1秒 |

**转场时长约束**：
- 单个转场最长 1 秒
- 所有转场总时长不得超过视频总时长的 10%
- 转场不额外占用镜头时长（从相邻镜头时长中各取一半）

### 3.4 片头片尾生成

**片头片段**（如有）：
- 根据第四阶段确认的片头类型生成：
  - 品牌开场动画 → 品牌 Logo 动画化展示
  - 品牌名展示 → 品牌名文字动画
  - 直接进入 → 无片头，跳过
  - 悬念开场 → 悬念画面 + 文字

**片尾片段**（如有）：
- 根据第四阶段确认的片尾类型生成：
  - CTA 行动引导 → CTA 文字 + 商品展示
  - 品牌收尾 → 品牌 Logo + Slogan
  - 联系方式 → 二维码/联系信息
  - 组合收尾 → CTA + 品牌
  - 无片尾 → 跳过

## 三点五、步骤3.5：用户预览确认所有片段

所有视频片段（片头+主体+片尾）生成完毕后，**必须暂停**，不直接进入拼接和音频合成。

### 展示方式

逐个展示每个片段的预览（视频或首帧截图），标注对应信息：
```
片段预览：

[1/7] 片头（品牌Logo动画）✅ 通过
[2/7] 镜头1 - 商品特写（推镜头，3秒）✅ 通过
[3/7] 镜头2 - 使用场景（固定，4秒）⬜ 待确认
...
[7/7] 片尾 - CTA收尾

请逐个查看，告诉我哪些满意、哪些需要重新生成。
```

### 用户操作

- **满意**：标记该片段为"通过"
- **不满意**：指出具体问题（如"这个镜头商品颜色不对""人物动作不自然"），Skill 重新生成该片段
- **全部通过**：进入步骤4（视频拼接 + 转场插入）

### 动作连贯性重点检查（铁律7）

预览确认时，必须重点检查以下连贯性问题：

| 检查项 | 合格标准 | 不合格表现 |
|--------|----------|------------|
| 运动方向一致性 | 主体在相邻片段中的运动方向与分镜标注一致 | 车辆一会向左开一会向右开 |
| 人物动作时序 | 人物动作连贯，无倒序或重复 | 下车后又回头开车门 |
| 位置关系过渡 | 物体/人物在画面中的位置在相邻片段间合理过渡 | 人物突然从画面左侧跳到右侧 |
| 物体外观一致 | 同一物体在各片段中外观保持一致 | 颜色/形状/大小突变 |

发现不合格时，标记具体片段和问题，重新生成该片段后再次预览确认。

### 重新生成规则

- 仅重新生成用户不满意的片段，已通过的片段保持不变
- 重新生成时仍使用对应的场景图作为起始帧参考
- 单个片段重新生成上限 3 轮；超过时询问用户是否接受当前效果继续
- 重新生成不影响其他已确认片段

### 设计意图

- 避免拼接合成后才发现某个片段有问题，导致整段视频需要拆解返工
- 在合成前锁定每个片段的质量，降低后续修改成本

## 四、步骤4：视频拼接 + 转场插入

### 4.1 拼接顺序

```
片头片段 → 镜头1 → 镜头2 → ... → 镜头N → 片尾片段
```

### 4.2 拼接规则

- 按分镜镜号严格顺序拼接
- 镜头间插入转场效果（根据选定的转场风格）
- 片头/片尾与主体内容之间也插入转场
- 拼接后总时长须与目标时长一致（误差 ≤ 0.5秒）

### 4.3 拼接质量自检

| 检查项 | 合格标准 | 不合格处理 |
|--------|----------|------------|
| 顺序正确 | 与分镜镜号顺序一致 | 重新拼接 |
| 转场正常 | 无跳帧/黑屏/闪烁 | 重新拼接 |
| 时长准确 | 与目标时长误差 ≤ 0.5秒 | 调整 |
| 画面比例 | 全程一致，无黑边/裁切 | 重新拼接 |
| 无明显拼接痕迹 | 镜头间过渡自然 | 重新拼接 |

## 五、步骤5：音频合成

### 5.1 合成顺序

```
1. 生成配音音轨（根据剧本 + 选定音色/语速）
    ↓
2. 生成音效音轨（根据音效方案，逐镜头生成/匹配）
    ↓
3. 生成 BGM 音轨（如选择添加）
    ↓
4. 混音合成（配音 + 音效 + BGM 合并）
```

### 5.2 配音生成

- 使用 LibTV 配音能力（TTS）
- 输入：剧本文本 + 音色 + 语速 + 语言
- 输出：完整配音音轨（含停顿节奏）
- 配音时间线须与分镜时间线对齐（按镜头时间码定位）

**配音分段规则**：
- 有旁白段落 → 旁白配音
- 有对话段落 → 对话配音（多角色需分配不同音色）
- 无台词段落 → 保持静音（仅保留音效）

### 5.3 音效生成

- 根据确认的音效方案（分镜方案/手动修改/AI重匹配）生成
- 每个音效须精确对齐到分镜时间线的对应位置
- 音效时长不超过所属镜头时长的 80%（留白避免重叠）
- 相邻镜头的音效不得重叠混浊

### 5.4 BGM 合成

- 根据确认的 BGM 风格生成/选取
- BGM 从头贯穿到尾（或按用户指定的起止点）
- 音量控制：
  - 有配音段落：BGM 降至配音音量的 20-30%（ducking）
  - 无配音段落：BGM 恢复至正常音量
- 片头淡入 1 秒，片尾淡出 2 秒

### 5.5 混音规则

| 音轨 | 优先级 | 音量基准 |
|------|--------|----------|
| 配音 | 最高（始终清晰可辨） | 100% |
| 音效 | 中（辅助画面表现） | 60-80% |
| BGM | 低（氛围烘托） | 20-30%（配音时）/ 100%（无配音时） |

**混音检查**：
- 配音必须清晰可辨，不被音效/BGM 淹没
- 音效不得盖过配音
- BGM 不得干扰配音和音效
- 整体音量均衡，无突然的音量跳变

## 六、步骤6：文字层渲染

### 6.1 字幕渲染（如选择添加）

- 根据第八阶段确认的字幕配置渲染
- 字幕时间线与配音精确对齐
- 字幕安全区域检查（确保不被平台 UI 遮挡）
- 字幕不得遮挡商品主体

### 6.2 标题文字叠加渲染（如有）

- 根据第八阶段确认的配置渲染
- 文字动画效果正常播放
- 文字安全区域检查
- 文字不得与字幕重叠

---

## 七、步骤7：合规检查（第二轮：成片终审）

**这是全链路第二次也是最后一次合规检查，不可跳过。**

### 7.1 审查范围

审查最终成片的**全部内容**：

| 审查项 | 内容 | 检查方法 |
|--------|------|----------|
| 画面合规 | 所有镜头画面 | 逐帧/逐镜头检查 |
| 配音文字合规 | 配音中的全部台词/旁白文本 | 文本检查（同第一轮词库） |
| 文字叠加合规 | 字幕 + 标题文字叠加内容 | 文本检查（同第一轮词库） |
| 大小字一致性 | 是否存在误导性大小字广告 | 视觉检查 |
| AI 标注要求 | 是否已标注 AI 生成内容 | 检查是否包含 AI 生成标识 |

### 7.2 审查标准

与第一轮合规检查使用相同的词库（`3-17-合规检查词库.md`），但范围更广：

**新增检查项（第二轮特有）**：
- **画面中的文字**：场景图中可能生成的伪文字/乱码文字，须检查是否存在
- **画面中的品牌标识**：是否有未经授权的品牌标识出现
- **大小字一致性**：主要广告语和辅助说明文字的大小是否造成误导
- **AI 生成标注**：根据 2026 年特别规则，AI 生成内容须显著标注

### 7.3 检查结果处理

| 结果 | 处理 |
|------|------|
| ✅ 全部合规 | 进入成片预览 |
| ❌ 存在问题 | 标记具体问题 → 回到对应环节修改 → 重新生成 → 再次合规检查 |

**不合规修改路径**：

| 问题类型 | 回到哪个环节 | 修改内容 |
|----------|-------------|----------|
| 配音文字违规 | 第五阶段（剧本） | 修改违规台词/旁白 → 重新配音 → 重新合成 |
| 字幕/文字叠加违规 | 第八阶段（参数） | 修改文字内容 → 重新渲染 |
| 画面违规 | 第七阶段（场景图） | 修改场景图 → 重新生成对应片段 → 重新拼接 |
| 伪文字/乱码 | 第七阶段（场景图） | 修改场景图 prompt，明确"无文字" → 重新生成 |
| 大小字误导 | 第八阶段（参数） | 调整文字大小/内容 → 重新渲染 |
| 缺少 AI 标注 | 第八阶段（参数） | 添加 AI 生成标注 → 重新渲染 |

修改后必须再过一次合规检查，直到全部通过。

## 八、步骤8：成片预览

### 8.1 预览方式

- 完整播放最终视频（画面 + 配音 + 音效 + BGM + 字幕/BGM）
- 提供视频播放链接给用户

### 8.2 预览信息

随视频一同展示的信息：

```
═══════════════════════════════════════
成片预览
═══════════════════════════════════════

🎬 视频预览：[播放链接]
📐 画面比例：[9:16/1:1/16:9]
📏 分辨率：[1080P/...]
⏱️ 总时长：[X]秒
📦 文件大小：[X]MB

📌 配音：[音色] / [语速] / [语言]
📌 字幕：[有/无]
📌 BGM：[有/无]
📌 音效数：[N] 个
📌 合规检查：✅ 通过
📌 转场风格：[硬切/溶解/...]

═══════════════════════════════════════
```

## 九、错误恢复与重试

### 9.1 单片段生成失败

```
自动重试 1 次（相同参数）
    ↓ 仍失败
降低参数复杂度重试 1 次（如简化运镜/缩短时长）
    ↓ 仍失败
告知用户，提供选项：
    A. 再试一次
    B. 跳过该镜头（后续手动补）
    C. 用户手动上传替代视频片段
```

### 9.2 音频合成失败

```
自动重试 1 次
    ↓ 仍失败
定位失败原因：
    - 配音失败 → 更换音色重试 / 简化文本
    - 音效失败 → 单个音效失败不影响整体，标记缺失
    - BGM失败 → 更换风格重试 / 跳过
    - 混音失败 → 简化音轨组合重试
```

### 9.3 拼接失败

```
自动重试 1 次
    ↓ 仍失败
定位问题：
    - 某片段格式异常 → 重新生成该片段
    - 时长不匹配 → 重新校验并调整
    - 转场效果异常 → 简化转场（改用硬切）重试
```

### 9.4 整体生成超时

- 预估总生成时间 = 镜头数 × 单镜头平均生成时间 + 音频合成时间 + 拼接时间
- 生成过程中定期向用户汇报进度：
  - "正在生成第 X/Y 个镜头..."
  - "视频片段已全部生成，正在合成音频..."
  - "正在进行合规检查..."
- 超过预估时间的 2 倍 → 提醒用户"生成时间较长，可稍后查看"

## 十、成片输出规范

### 10.1 文件命名

```
{商品名}_{风格}_{画面比例}_{时长}秒_{时间戳}.mp4
```

示例：
- `精华液_高端摄影_9x16_15秒_20260810.mp4`
- `零食套装_MG动画_1x1_30秒_20260810.mp4`

### 10.2 文件存储

- 成片存储在项目目录下：`./{项目名}/成片/`
- 中间素材存储在项目目录下：`./{项目名}/素材/`
  - `./{项目名}/素材/场景图/`
  - `./{项目名}/素材/视频片段/`
  - `./{项目名}/素材/音频/`

### 10.3 交付内容

成片确认阶段（第十阶段）向用户交付：

| 内容 | 说明 |
|------|------|
| 成片视频文件 | 最终 MP4/MOV 文件 |
| 视频播放链接 | 在线预览链接 |
| 项目画布链接 | `https://www.liblib.tv/canvas?projectId=` + projectUuid |
| 中间素材包 | 所有场景图/视频片段/音频文件（可选导出） |

## 十一、快速模式视频生成

快速模式下的视频生成策略：

- 使用默认参数生成，跳过中间质量自检
- 合规检查（第二轮）仍然执行，不可跳过
- 成片预览后统一确认，不逐镜头修改
- 修改时回到对应环节，触发级联依赖链
