# 附MD06 | 与上游SKILL的协同规范

**所属主SKILL：** 提示词 | 电影级物理参数底座\
**英文 slugID：** libtv-user-generated/award-winning-cinematic-prompter-074be3667ece41bc8993cea11c99240e\
**版本：** V2.0 融合合规版

## #做什么

本模块为“提示词 | 电影级物理参数底座”的专属协同规范。

解决“提示词底座与上游大导演思维、情绪大师、风格Skill如何对接”的痛点。确保物理参数不是孤立生成，而是精准承接上游的镜头语言、情绪曲线与题材定调。

## #需要什么输入

**最少提供：**

- 来自【大导演思维】的镜头语言（景别、机位、运动、焦点）
- 来自【情绪大师】的情绪曲线与微表情要求
- 来自【风格Skill】的题材视觉定调

**可选提供：**

- 目标画幅（不限定，按项目需求或用户指定）
- 是否需要输出视频文件、视频脚本、Prompt清单、视觉方案

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。本模块处于绝对工作流的第6步【提示词底座】环节，直接承接第3步【大导演思维】、第4步【情绪大师】、第5步【风格Skill】的输出。

### 二、与【大导演思维】的对接

- 接收景别 → 决定 `shallow depth of field` 或 `deep focus`。
- 接收机位 → 决定 `low angle` / `high angle` / `over-the-shoulder` 参数。
- 接收运动路径 → 决定 `tracking shot` / `dolly in` / `crane shot` 参数。
- 接收焦点 → 决定 `focus pull` / `rack focus` 参数。

### 三、与【情绪大师】的对接

- 接收情绪曲线 → 决定 `high-key` 或 `low-key` 照明。
- 接收微表情要求 → 决定是否使用 `extreme close-up` 与 `shallow depth of field`。
- 接收情绪爆发节点 → 决定是否追加 `motion blur`、`volumetric lighting`。

### 四、与【风格Skill】的对接

- 接收题材定调 → 决定基座参数之外的题材专属扩展参数。
- 接收视觉锚点 → 决定 `color palette`、`lighting style`、`texture emphasis`。
- 接收防崩要求 → 决定是否追加 `no cheap CGI`、`hyper-realistic textures`。

### 五、协同输出的强制规范

- 所有物理参数必须在Prompt中严格排序：基座参数 → 镜头参数 → 情绪参数 → 风格参数。
- 任何上游要求与基座参数冲突时，优先保留基座参数。
- 必须输出《物理参数协同配置报告》，说明每个参数来自哪个上游SKILL。

### 六、生成与合成

根据上述协同规范，调用底层视频生成Skill，输出MP4视频文件。

## #产出什么

最终交付：

- **视频文件（MP4格式）、视频脚本、Prompt清单、视觉方案**。
- **上游协同规范手册**：与大导演思维、情绪大师、风格Skill的对接逻辑。
- **物理参数协同配置报告**：每个参数的上游来源。
- 可直接进入AI视频工具生成链路的执行清单。

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 上游SKILL的输出缺失，导致物理参数无法精准对接时。
- 上游要求与基座参数冲突，需要用户决策时。
- 用户要求输出视频文件、视频脚本、Prompt清单、视觉方案，但缺少关键输入时。
- 本模块与上游主SKILL或其他附MD规则冲突时。
