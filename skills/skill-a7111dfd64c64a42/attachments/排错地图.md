# Skill 排错地图

出了问题，先看卡在哪个阶段，直接翻对应文件改。

| 阶段 | 问题现象 | 找哪个文件 |
|------|---------|-----------|
| 开场 | 没出现快速/精细模式选择，或开场提醒没出来 | SKILL.md（第一阶段） |
| 商品定义 | 品类/风格/卖点/目标人群定义不准 | 2-04-基础定义选择详细规则.md |
| 商品图获取 | 商品图识别失败、质检没通过 | 2-05-商品图获取与质检详细规则.md |
| 三视图 | 三视图角度不对、风格不一致 | 2-06-三视图生成详细规则.md + 2-07-品类风格三视图映射.md |
| 品牌元素 | logo/品牌色/片头片尾没加上 | 2-08-品牌元素与片头片尾详细规则.md |
| 剧本 | 钩子弱、CTA缺失、节奏拖沓 | 2-09-剧本生成详细规则.md + 3-16-剧本模板.md |
| 分镜 | 镜头衔接不顺、景别单调 | 3-15-分镜模板.md |
| 场景图 | 画面风格跑偏、构图有问题 | 2-10-场景图生成详细规则.md |
| 参数配置 | 时长不对、比例错、字幕/BGM异常 | 2-11-广告参数配置详细规则.md + 3-18-时长校验规则.md |
| 视频生成 | 视频质量差、一致性断裂 | 2-12-视频生成详细规则.md |
| 成片交付 | 工程文件缺失、素材没导出 | 2-13-成片确认与工程管理详细规则.md |
| 合规检查 | 违规词没拦住、广告法问题 | 3-17-合规检查词库.md + 4-20-compliance_check.py |
| 人物出镜 | 人物风格不一致、审核被拒 | SKILL.md（人物出镜章节）+ 2-09-剧本生成详细规则.md |
| 整体流程 | 阶段跳转逻辑、确认节点 | SKILL.md（主流程） |

## 辅助脚本用途

| 脚本 | 干什么的 | 出问题时的表现 |
|------|---------|--------------|
| 4-19-asset_quality_checker.py | 检查图片/视频素材质量 | 素材质检没触发或结果不对 |
| 4-20-compliance_check.py | 合规词/广告法检查 | 违规内容没拦住 |
| 4-21-duration_validator.py | 配音时长 vs 镜头时长校验 | 配音超时或镜头太短 |
| 4-22-project_manager.py | 项目工程文件管理 | 素材导出缺失或工程文件不完整 |

## 快速定位法

1. 先看用户反馈的**关键词**——"风格不对"→场景图/三视图；"太长/太短"→时长校验；"有违禁词"→合规检查
2. 打开对应文件，搜阶段编号（如"第六阶段"）
3. 检查该阶段的规则是否被正确执行
4. 如果规则没问题，看 SKILL.md 里该阶段的调用逻辑是否指向正确文件
