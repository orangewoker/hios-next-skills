# LibTV 发布与验收准备

只在用户要将本技能发布到 LibTV、准备投稿材料或做验收测试时读取本文件。

## 建议填写字段

以下内容按 LibTV 截图中的长度要求设计：技能名称不超过 12 字符，一句话简介不超过 30 字符，其余「使用场景／如何使用／输出结果」保持在 200 字符内。

| 字段 | 建议内容 |
| --- | --- |
| 技能名称 | Q版角色短片 |
| 一句话简介 | 把用户形象变成Q版真实场景短片。 |
| 使用场景 | 将本人、宠物或原创角色做成成人拇指大小的2D简笔画、2D Q版插画或3D Q版IP角色，放入真实摄影感场景，支持全智能托管或手动确认生成15秒、30秒或1分钟竖屏短片。 |
| 如何使用 | 先选择全智能托管或手动确认；上传角色图或描述角色外观。生图时可选2D纸片、2D Q版或3D Q版IP；场景必须真实。长视频需先选30秒或1分钟。 |
| 输出结果 | 输出角色锁定、声音方案、时间码分镜、成片提示词和视频结果；能单条生成就不分段，分段后先确认片段和剪辑方案再智能合成。 |
| 输出类型 | 视频 |

## 验收清单

- 保持 Skill 正文少于 20,000 字符；不要依赖可执行代码或脚本。
- 明确输入、输入使用、内部流程、输出、自检和 Ask User；流程中的角色、场景、道具、分镜和提示词职责应分明。
- 提交至少两组不同的典型输入及其由 Skill 直接生成的完整输出，保存原始对话或 Showcase 链接。
- 准备至少两条 Showcase；每条均应展示这个 Skill 的核心能力，画面、文本与技能定位一致，且无明显版权、安全或素材授权风险。
- 先在 Agent 中实际运行并根据失败点迭代，不以只堆砌关键词的“贴牌式”技能投稿。

## 测试输入

1. `没有角色图。全智能托管，把一只戴黄色雨衣、背红色小书包的柯基做成成人拇指大小的3D Q版IP角色；它在真实摄影感的雨后公园追一片被风吹走的枫叶。直接生成15秒竖屏视频，不需要逐步确认。`
2. `没有角色图，手动确认。先给我角色风格选项，我想在2D简笔画纸片人、2D Q版插画、3D Q版IP角色里选一个；场景必须是真实咖啡店。`
3. `我已上传角色图。让它在真实摄影感的北美风格咖啡店把散落的咖啡豆装回透明罐，最后小花展开。请先确认声音方案，再给我2.5或2.0的视频模型选择与生成确认卡。`
4. `我已上传角色图。让这个成人拇指大小的3D Q版角色在真实厨房台面上被一只玩具小锤敲扁两次，然后弹回来反击，把小锤顶翻。不要提前拒绝，按Q版夸张喜剧来写；如果平台输出不了再告诉我。`
5. `全智能托管，做一个更长的Q版角色追逐短片。如果需要分段，先让我选择30秒还是1分钟；分段生成完后先给我片段清单和剪辑方案，确认后再智能合成。`
6. `视频模型2.5当前不可用，且上一次调用失败。请停止，不要自动重试；告诉我实际可用模型和扣点状态，并等我选择下一步。`

运行后检查输出是否无需人工补写，能复用角色锁定，并覆盖角色风格、真实场景、道具、成人拇指大小、时间码、声音和结尾；全智能托管案例不得反复要求确认；15秒能单条生成时不得分段；长视频分段前必须先设置时长，分段后必须确认再合成；Q版角色冲突案例不得提前套用真人暴力限制，必须写成 2D/3D Q版的夸张物理效果；失败案例必须停在询问处，不得自动重试或虚构模型、价格、点数。
