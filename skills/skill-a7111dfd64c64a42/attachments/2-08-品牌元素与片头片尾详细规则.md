# 品牌元素与片头片尾详细规则

## 一、品牌标识（Logo）

### 1.1 Logo 获取方式

| 方式 | 适用场景 | 处理流程 |
|------|---------|---------|
| **用户上传** | 用户有现成 Logo 文件 | 接收 → 质量检测 → 处理 → 确认 |
| **Skill 生成** | 用户无 Logo 或需要新设计 | 收集品牌信息 → 生成候选 → 用户确认 |
| **不使用** | 个人商品/无品牌需求 | 跳过，进入片头片尾环节 |

### 1.2 用户上传 Logo 的质量检测

**必须检查项：**

| 检查项 | 合格标准 | 不合格处理 |
|--------|---------|-----------|
| 分辨率 | ≥200×200px | 提醒用户分辨率过低，建议上传更高清版本 |
| 背景 | 透明背景（PNG）或纯色背景 | 复杂背景 → 建议去背景处理 |
| 清晰度 | Logo 文字/图形清晰可辨 | 模糊 → 建议重新上传或 Skill 重新生成 |
| 格式 | PNG/SVG/JPG | 不支持的格式 → 提示转换或尝试处理 |

**自动处理：**
- 非透明背景 → 自动尝试去背景（保留主体）
- 尺寸过大/过小 → 自动缩放到合适尺寸（片头建议使用 300-500px 宽度）

### 1.3 Skill 生成 Logo 的规则

**信息收集（必要项）：**
- 品牌名称（中英文）
- 品牌所属行业/品类
- 风格偏好（简约/复古/科技/国潮等，可与第二阶段风格保持一致）

**生成规则：**
- 风格必须与第二阶段选定的视觉风格一致
- Logo 需简洁清晰，在视频小尺寸下仍可辨识
- 文字内容：仅使用用户明确提供的品牌名称，不自行编造
- 生成 2-3 个候选方案供用户选择

**确认后处理：**
- 去背景（确保透明底）
- 保存为标准尺寸版本（用于片头）和小尺寸版本（用于片尾水印）

### 1.4 Slogan（品牌标语）

**来源优先级：**
1. 用户直接提供 → 直接使用
2. 用户提供品牌信息 → Skill 生成候选（2-3条）→ 用户选择或修改
3. 用户不需要 → 跳过

**Slogan 生成规则：**
- 长度：中文 6-15 字，英文 3-8 词
- 必须与商品/品牌直接相关，不使用空泛口号
- 风格匹配品牌调性（高端/亲切/活力/专业）
- 合规检查：不含有绝对化用语、虚假承诺（按合规词库检查）

## 二、片头设计

### 2.1 片头类型

| 类型 | 说明 | 适用场景 | 建议时长 |
|------|------|---------|---------|
| **品牌开场动画** | Logo 动态展示 + 品牌名出现动效 | 品牌曝光类广告、高端品牌 | 2-4秒 |
| **品牌名展示** | 静态品牌名 + 简短副标题 | 一般品牌广告 | 1.5-3秒 |
| **直接进入** | 无片头，直接展示商品 | 促销转化类、短视频信息流 | 0秒 |
| **悬念开场** | 先展示效果/场景，再揭示品牌 | 新品上市、故事型广告 | 2-3秒 |

### 2.2 片头时长与总时长关系

| 总时长 | 片头最大时长 | 说明 |
|--------|------------|------|
| 5秒 | 0-1秒（或直接进入） | 时间极短，建议无片头或极简logo闪现 |
| 10秒 | 1-2秒 | 简短品牌名展示 |
| 15秒 | 2-3秒 | 标准品牌开场 |
| 30秒 | 3-4秒 | 可以有品牌动画 |
| 60秒 | 4-5秒 | 可以有完整品牌开场叙事 |

**硬性约束**：片头不超过总时长的 1/4。

### 2.3 片头与风格匹配

| 视觉风格 | 推荐片头方式 | 动效特征 |
|---------|------------|---------|
| 简约极简 | 品牌名淡入 | 简洁淡入淡出，无多余动效 |
| 高端奢华 | Logo 金光/光泽动效 | 缓慢展开，金属光泽流动 |
| 自然清新 | 品牌名+植物元素 | 柔和淡入，花瓣/叶片飘落 |
| 工业硬核 | Logo 霓虹闪烁 | 硬切入+故障效果 |
| 3D科技 | Logo 3D 旋转/全息 | 三维旋转展开，粒子汇聚 |
| 生活方式 | 品牌名+场景过渡 | 自然过渡到生活场景 |
| 国潮东方 | 品牌名+水墨/纹样 | 水墨晕散展开、传统纹样装饰 |
| 促销爆款 | 品牌名+爆炸/闪光 | 快速闪现，强调冲击 |
| MG动画 | Logo 图形变换 | 图形变换组合形成Logo |
| 3D卡通 | Logo 弹跳/弹入 | 弹性动画，活泼入场 |
| 国漫动画 | 品牌名+卷轴/水墨 | 卷轴展开或水墨浮现 |

## 三、片尾设计

### 3.1 片尾类型

| 类型 | 说明 | 适用广告目标 | 建议时长 |
|------|------|------------|---------|
| **CTA 行动引导** | "立即购买""了解更多""点击链接"等 | 促销转化、活动引流 | 2-4秒 |
| **品牌收尾** | Logo + 品牌名 + Slogan | 品牌曝光 | 2-3秒 |
| **联系方式** | 电话/微信/官网/二维码 | 需要直接联系的商品 | 3-4秒 |
| **组合收尾** | 品牌Logo + CTA + 联系方式 | 综合需求 | 3-5秒 |
| **无片尾** | 直接结束 | 内容即广告、短视频平台 | 0秒 |

### 3.2 片尾时长约束

- **硬性约束**：片尾不超过总时长的 1/4
- **片头+片尾合计**：不超过总时长的 1/3

| 总时长 | 片尾最大时长 | 片头+片尾合计上限 |
|--------|------------|-----------------|
| 5秒 | 1秒 | 1.5秒 |
| 10秒 | 2秒 | 3秒 |
| 15秒 | 3秒 | 5秒 |
| 30秒 | 5秒 | 10秒 |
| 60秒 | 8秒 | 15秒 |

### 3.3 CTA 文案规范

**合规要求（必须通过合规词库检查）：**
- 禁止使用绝对化用语：最低价、最便宜、全网第一
- 禁止虚假承诺：保证有效、永久、100%
- 时限信息必须明确：「限时优惠」需标注具体截止日期

**CTA 文案模板：**

| 广告目标 | CTA 模板 | 示例 |
|---------|---------|------|
| 促销转化 | 行动动词 + 商品/优惠 | "立即抢购"、"下单享优惠" |
| 新品上市 | 行动动词 + 新品信息 | "立即尝新"、"抢先体验" |
| 活动引流 | 行动动词 + 活动入口 | "点击参与"、"了解更多" |
| 品牌曝光 | 品牌名 + 品牌主张 | "XX，让生活更好" |

### 3.4 二维码/联系方式规则

- 二维码展示时间 ≥ 3秒（确保观众能扫码）
- 二维码尺寸：画面宽度的 15%-25%
- 位置：画面中下部或右下角（安全区域内）
- 联系方式字号：确保在手机屏幕上可辨识

## 四、品牌一致性规则

### 4.1 品牌色彩应用

如果用户指定了品牌色或有品牌 Logo：
- 片头/片尾主色使用品牌色
- 字幕/标注文字颜色与品牌色协调
- 场景图中的道具/装饰可呼应品牌色（不强制）

### 4.2 品牌元素出现位置

| 元素 | 出现位置 | 大小要求 |
|------|---------|---------|
| Logo（片头） | 画面中央 | 画面宽度的 30%-50% |
| Logo（片尾水印） | 画面角落（右上/右下） | 画面宽度的 10%-15% |
| 品牌名 | 片头中央/片尾底部 | 清晰可读，不小于画面宽度 20% |
| Slogan | 片头品牌名下方/片尾 | 字号为品牌名的 50%-70% |

### 4.3 全链路一致性检查

品牌元素确定后，在后续阶段需保持：
- **分镜阶段**：片头/片尾分镜必须使用已确认的品牌元素
- **场景图阶段**：如有品牌露出的场景，需与品牌调性一致
- **视频阶段**：品牌动画/文字动效需与确认方案一致

## 五、确认流程

### 5.1 精细模式确认

逐步确认：
```
Step 1: Logo/Slogan 确认
→ 展示 Logo 效果（上传/生成）
→ 展示 Slogan 文案
→ 用户确认 ✓

Step 2: 片头方案确认
→ 展示片头类型和时长
→ 用户确认 ✓

Step 3: 片尾方案确认
→ 展示片尾类型、CTA文案、联系方式
→ 用户确认 ✓
```

### 5.2 快速模式

合并确认：
```
品牌元素方案（快速模式默认值）：
- Logo：[无 / 已上传 / 已生成]
- Slogan：[无 / 已确认内容]
- 片头：[类型]，时长 [X]秒
- 片尾：[类型]，时长 [X]秒

确认？或告诉我需要调整。
```
