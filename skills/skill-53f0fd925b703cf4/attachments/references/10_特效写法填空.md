# ref10 · 特效写法填空（跨类·有特效的镜头写正文前必填）

> 特效是跨类写法（魔法/科幻/水墨/奇观都可能出现在任何类）。特效段写正文前，先填这张卡。

## 特效落笔前填空

```
本特效属哪类：
  ☐ 魔法（火/电/能量/护盾）☐ 科幻（机甲/激光/爆炸/能量场）☐ 水墨（流体/墨韵/笔触）☐ 奇观（巨物/变身/光效/异象）☐ 其他__

本特效是通用型还是自定型？
  ☐ 通用型（模型见过：爆炸/变身/激光束）→ 也要形态具体化（2026-08-01修正——通用型≠简写）：
      高饱和能量体当主角+层叠结构+来源去向+物理后果绑定；可引用具体范例
      （元启录火球"多层火舌+余烬+热浪折射"——通用型也能写具体）
      简写只用于：低重要度背景特效（如远处爆炸），不用于主角命中特效
  ☐ 自定型（只有你见过，模型没先验）→ 万物生密度锚+魔法物理化（必填下6项）

魔法物理化6项（自定型必填，通用型也要填来源去向）：
  重量__（特效有没有重量感？落地震没震？砸东西有没有重量反馈？）
  惯性__（结束有没有余势/拖尾？转向有没有离心？急停有没有前冲？）
  色散__（不是单色光球——是粗细不同/分叉/回击/断裂/重新连接的层次？色温变化？）
  接触光__（碰到物体/人有没有照亮/折射/热浪扭曲/材质反光？）
  来源__（能量出招前凝于何处——拳锋/腿侧/掌心？能量有来源不悬浮·2026-08-01新增）
  去向__（能量命中后如何消散——爆裂熄灭/残电火花迅速熄灭/光屑落尽？能量有去不留残·2026-08-01新增）
  实证：元启录"火焰飞出后手上火苗迅速熄灭""残余电弧只留一两颗立即熄灭电火花"

拒绝清单（本特效禁出现，逐条确认）：
  ☐ 光滑规则纯圆形光球 ☐ 直线激光无层次 ☐ 贴图感（平面非立体）
  ☐ 单色无层次 ☐ 无重量漂浮（像CG不像物理）☐ 突变无过渡

子弹时间（如有）：
  持续__秒 + 全元素冻结__（人/武器/衣摆/尘埃/金币/烛火逐个列）+ 电光蜗牛爬行__ + 瞬间解除__（禁渐变恢复）

色散分身（如有）：
  本体爆散__个虚影 + 向__方向 + 回收__（禁只散不收）

慢动作谱系（如有，三选一）：
  ☐ 升格分阶段__（万物生式：横抡→转身→搭箭→射出，每阶段独立）
  ☐ 全冻结5秒+__（元启录式：全元素冻结+电光蜗牛+瞬间解除）
  ☐ 子弹时间声明+回正常__（渊式："子弹时间（慢镜头）...回到正常速度"）
```

## 各源特效写法对照（写正文时参考，不照抄）

### 元启录·魔法物理化
- **火球**："外层由多层扭曲火舌、破碎余烬、热浪折射和短促火星组成"——禁光滑规则纯圆形光球
- **闪电**："大量粗细不同、不断分叉、回击、断裂和重新连接的暗红色与亮红色电弧"——禁一条直线激光
- **金币雨**："冲刺路径上的金币和珠宝才受到延迟风压影响，沿整条路径依次轰然升空"——重量+惯性+延迟传播
- **延迟冲击传播**："烟尘镜头一被完全遮挡，镜头二逐渐散开，镜头三残留薄层尘雾，镜头四基本散去，形成连续递减"——分层延迟

### 万物生第二集·生物特效
- **地龙固定锚**："背景里那道庞然的地龙巨大身躯静止不动、如一道顶天立地、横贯整个背景的钢铁绝壁"——巨物作固定背景锚（诗意物理）
- **荧光绿血浆**："断口处大量荧光绿色的血浆朝镜头方向喷溅、缓缓绽放成扩散的绿色血雾"——色彩钉子（荧光绿=唯一高饱和色）
- **被切两半**："被挑开的两半龙虱躯体在升格里朝画面两侧缓缓翻飞分开、像幕布被向两边拉开"——诗意物理比喻

### 渊·科幻特效
- **机甲光源=表情**："蓝光骤然暴涨。从沉稳的暗蓝变为刺目的冷白蓝光，像被点燃的冷焰"——光源承担情绪表达
- **多普勒音效**："凛翼引擎尖啸在环绕中因多普勒效应产生短暂音调变化——渐远"——运动产生音效变化
- **物理痕迹**：沙蚀划痕/冷凝水/铆接节点/加强筋——材质有使用痕迹非CG塑料

### 墨染少女·水墨特效
- **光质随动作演化**："整段是从'柔散高调香雾光'到'硬窄过曝逆光'的连续过渡，光跟着人转、跟着剑亮而收紧、点燃"——光不是静态是动态演化
- **流体材质**："琉璃流水长发与水墨琉璃广袖持续翻涌的轻柔宣纸水流风声"——流体有材质音效绑定
- **琉璃永久不消散**：硬声明流体不会消失，防AI画着画着流体没了

### 第一集·奇观特效
- **活的物理脉动**："红光线像血脉脉动、每秒3-4次脉冲、红光粒子从中心向外流动、同心圆空气震荡波纹"——奇观元素有自身物理规则（脉动+粒子流+震荡）
- **消失/保留规则**："红光爆发瞬间牛牛+孙悟空+观众席全部消失、剧场物理结构依然存在但深陷阴影、只剩丹眉一人"——明确什么消失什么保留
- **变身分阶段**："男主体内长出机械装甲覆盖全身→360环绕镜头仰拍"——变身不是瞬间是分阶段+环绕展示

### 第6源：咒术回战黑闪式（Black Flash·2026-08-01新增·当代动漫战斗番）
- **命中瞬间**："白闪帧+黑红色闪电放射（亮红#FF3B30电弧向外劈开2-3条）+黑色空间裂纹（#1A1A1A玻璃碎裂纹路向四周蔓延）+画面短暂停顿（慢动作感）"
- **能量附着**："拳锋缠绕黑红闪电丝（细电弧在拳面闪现）/踢锋带金色电弧"——能量附着攻击部位不飘空
- **能量管理**："出招前凝于拳锋（来源）→命中后爆发裂开+残电火花迅速熄灭（去向）"
- **物理后果绑定**："每次能量接触同时绑定——衣料掀动/地面裂纹/碎石滚动/鞋底滑地"
- **形态约束**："闪电放射状劈开不缠绕成乱麻；裂纹呈玻璃碎纹不变成花纹"
- **适合场景**：当代热血番打斗（咒术回战/鬼灭/火影系）——高饱和能量体当主角，存在感强

## 注意

1. **特效密度平衡（2026-08-01修正）**："防写太密AI画慢"≠不华丽——具体写法≠堆细节；特效按镜主打≤3，大招镜可峰值堆叠；防的是"分镜级分解每个细节"，不是防"高饱和华丽能量体"（用户反馈"比不上当代动漫"的根因=防太密把华丽也防没了）
2. **通用型vs自定型判断**：爆炸/变身/激光束是通用型（模型见过），但要形态具体化（改6b）；只有你见过的魔法/科幻特效是自定型，必须物理化。判断错（通用型当自定型写太密）会导致AI画慢。
3. **特效+打斗叠加**：打斗段有特效时，两份填空都填（打斗专项+特效填空），核验时两份都抄录核验。
