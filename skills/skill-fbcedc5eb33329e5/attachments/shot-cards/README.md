# 真人电影镜头配方卡索引

本目录是 imax-film-production 的镜头配方卡库，参考 video-shotcraft 的 shots/ 体系，为真人电影场景提供即取即用的镜头语言模板。

每张卡统一格式：name / 一句话 / 适用 / 时长 / 能量 / 意图 / 参数表 / 已知坑 / 参考实现。

## 使用规则

1. **先选卡再写prompt**：分镜阶段先从本目录选卡，读卡全文，再按卡的参数表和已知坑写入七段式输出
2. **已知坑不得降档**：每张卡标注的"命门"参数是质量底线，不得为了省事而降低标准
3. **手法去重**：同一支片同一镜头卡≤2次，重复=廉价
4. **卡是起点不是终点**：参数表是调校过的起点，实战须以真实素材/角色回验调整

## 扩展原则

新增镜头卡须遵循：
1. 统一格式（frontmatter + 参数表 + 已知坑 + 参考实现）
2. 每张卡只讲一个动效/一个情绪节拍
3. 必须标注"命门"参数（不得降档的质量底线）
4. 必须关联到现有 references/ 文档作为参考实现
5. 时长/能量/意图三要素不可缺
