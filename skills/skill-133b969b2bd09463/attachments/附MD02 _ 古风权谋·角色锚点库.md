# 附MD02 | 古风权谋·角色锚点库

**所属主SKILL：** 古风权谋 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“古风权谋 | 上架Steam的互动影游”的专属角色锚点库。

解决AI生成古风权谋内容时“主角跨镜头换脸、阵营NPC撞脸、服装漂移、气质混淆”的痛点。通过统一的角色锚点规范与跨镜头一致性锁定，确保全片所有角色形象100%一致。

## #需要什么输入

**最少提供：**

- 主角与关键阵营NPC的姓名与设定
- 角色三视图与面部特写（用户上传或AI生成）
- 角色标志性服装与配饰

**可选提供：**

- 特定服装风格偏好（玄色朝服/深色长袍/高定古装）
- 特定伤痕或情绪状态
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。角色锚点环节重点参考【提示词】底座的物理光学参数与【情绪大师】的七层微表情拆解规则。

### 二、角色锚点命名规范

- 格式：角色名\_角度\_版本号
- 示例：主角\_正面三视图\_v1、奸臣\_冷峻特写\_v2
- 核心铁律：所有锚点ID必须在跨节点、跨分支时绝对一致，严禁“同角色两套ID”。

### 四、角色辨识度锁定（核心铁律）

1. 五官差异：主角与各位阵营NPC的面部轮廓、眼睛形状、鼻梁高低、嘴唇形状必须有明显差异。
2. 发型差异：束发、披发、冠发、发髻等必须严格区分。
3. 气质差异：沉凝、刚正、阴鸷、威压、阴冷，多种气质必须一眼可辨。
4. 服装色彩差异：主角玄色、忠臣深色、奸臣紫色、帝王金色、反派暗红，禁止撞色。
5. 绝对禁止：两位角色撞脸、发型混淆、气质雷同。

### 五、跨镜头一致性锁定（核心铁律）

1. 同角色在不同镜头必须用同一人物锚点ID。
2. 所有镜头共用同一套角色锚点库。
3. 情绪切换必须使用同一角色的不同锚点帧，禁止换脸。
4. 服装、配饰、发型在全片中必须保持绝对一致。
5. 若剧情需要角色换装，必须单独建立新的锚点ID并明确标注。

### 六、生成与合成

根据上述角色锚点与一致性规范，调用底层视频生成Skill，输出MP4视频文件。
