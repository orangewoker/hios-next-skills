# 少对白短片扩展：加载入口与实施流程

扩展版本：1.1。适用于原版 v3.0 的即梦短片工作流。原有 [SKILL.md](http://SKILL.md) 和六个参考文件保持原文；扩展包含本入口、四个专业模块，以及新增的人物三视图与空间锁定前置模块。

## 1. 如何加载

使用本扩展时，先读取 [原 skill](SKILL.md)，再按当前任务读取以下前置模块和四个专业模块。建议调用语句：

> 使用 tarantino-jimeng-director，先读取 [EXTENSION.md](http://EXTENSION.md)，启用 1.1 扩展。先依据已有设定制作人物正面、侧面、背面三视图及场景设计图、场景四视图，固定外观与空间；然后分析剧情、编写剧本，确定每场人物位置、视线、道具和机位，再用专业导演方法写详细分镜。每个肢体动作按明确主语、动词、对象、身体部位、方向、路径和结束状态书写；每镜写清拍谁的什么位置、机位和拍摄方向。

原入口未修改，因此不能保证仅调用旧 [SKILL.md](http://SKILL.md) 时自动发现这些文件。此入口负责显式加载和流程衔接，不宣称平台会自动扫描所有 Markdown 文件。

## 2. 本次明确的用户偏好

- 少量对白，主要依靠可见行为、镜头语言、场景细节和声音讲清楚故事。
- 制作顺序为人物三视图和场景图在先，剧情分析、剧本和详细分镜在后。资产前只提取必要身份、地域、年代和场景事实，不提前写整部剧本。
- 固定人物身份与场景世界坐标；人物可以按明确动作移动，不能在切镜时无因果换位、换手、换朝向或改变道具状态。
- 动作句必须说明谁用哪个身体部位、怎样对哪个对象或目标运动、起点终点和可见结果；摄影机动作与人物动作分开写。
- 常规叙事段允许明确且充分的景别、角度、机位和剪辑变化；不默认全片长镜头。
- 在细腻情感、关系改变、关键决定和需要连续空间体验的地方选择长镜头。
- 单镜头可以包含丰富人物关系、背景活动和道具信息，但观众要知道先看什么。
- 场景设计是核心创作工作：有生活、职业、历史、社会关系、黑色幽默、冲突痕迹与救赎可能。
- 黑色幽默、暴力美学、现实感和救赎感按故事配置，不要求每个场景同时塞满四种主题。
- 风格仍为昆汀式；针对抖音短片重新设计时间尺度，不机械缩放电影的镜头长度。
- 五分钟以内仍是默认上限。具体时长、画幅、国家、人物和年代由项目决定；此前生成欧美人物餐馆图是图像任务，不自动覆盖以后每个剧本。

本扩展对“资产先行、人物三视图、空间锁定、明确动作句、常规分镜和少对白节奏”的要求，优先于旧版与之不一致的默认流程。其余身份、专业参数、独立提示词和实际能力核验规则继续使用原文件；无需重写旧文件。

## 3. 新增实施步骤

 1. **提取制作底稿。** 只整理用户已经提供的人物身份、外观、年代地域、场景用途、不可改事实和媒介；此时不做完整剧情解析或剧本扩写。缺失的非关键外观可合理设计并标注，不能为出图篡改原设定。
 2. **先制作人物三视图。** 为每位主要人物制作正面、指定侧面、背面全身图，固定脸、身体比例、发型、服装、配件、左右侧特征和版本；必要时补脸部或非对称侧特写。
 3. **制作场景图。** 先根据已有地点用途设计场景主图、平面定位图、门窗与固定物件、材质色彩和光源；再制作北／东／南／西四向参考图。此阶段确定立体空间，不要求提前写出完整情节。
 4. **核对资产基准。** 验证人物三视图相互一致、场景四视图相互一致，固定 CHAR、LOC、PROP 版本。仅有文字时标记方案／待生成，不宣称图像已经完成。
 5. **开始分析剧情。** 在已建立的人物与场景条件下分析目标、阻力、信息差、情绪、黑色幽默与选择。新发现的必要资产以版本增量补充，核对后再使用，不能暗中重画整个空间。
 6. **编写可视化剧本。** 写清因果、少量必要对白、可执行行为、场景任务和结尾变化；估计时长，保留关键情感连续段。
 7. **固定每场人物关系和调度。** 把角色放入场景平面图：初始脚位或座位、身体朝向、视线、间距、手与道具、轴线；再列每个动作后的状态。固定的是可追溯的起点和变化，不是禁止人物运动。
 8. **确定机位与可见背景。** 逐机位列世界位置、高度、朝向、拍摄对象与身体范围、景别、轴线侧别、画面左右、前中后景和光源关系。背景须由这个观察方向推导，不凭空拼出另一面墙。
 9. **用专业导演方法写详细分镜。** 逐镜写导演意图、表演、主谓宾动作序列、机位、运动、光学焦点、光线氛围、色调、背景内容、对白声音和切点。人物运动与摄影机运动分开描述，并写明同步关系。
10. **做纸面剪辑和连续性复核。** 按模块④核对时间线；把上一镜尾态与下一镜首态逐项比对，验证视线、换手、走位、道具、背景和情绪变化。
11. **编译即梦提示词。** 每镜绑定人物三视图版本、场景版本、参考方向、动作状态与机位；按已确认模型能力拆 CL，每段独立表达动作和空间，不以角色 ID 或“同前镜”代替描述。
12. **生成、检查与剪辑。** 实际制作获授权时生成视频，检查素材中的身份、动作、空间和音画，完成剪辑声音字幕；不因文本正确就宣布生成结果正确。
13. **复核成片。** 检查观众理解、情绪变化、空间立体感、背景逻辑、连续性、节奏与总时长。

完整短片任务按上述先后交付：人物三视图和身份表 → 场景主图、四视图、平面图与资产表 → 剧情分析与可视化剧本 → 人物调度状态表与机位关系图 → 逐镜详细方案 → 镜头组与剪辑表 → 即梦独立提示词 → 检查结论。用户只要其中一项时不扩展为全套。

本次修改的是方法文件，不自动制作无关人物或场景图。未来完整短片制作任务已经包含并授权图像资产制作、工具可用时，先实际生成并核对人物三视图与场景图，再进入剧情阶段。用户只要文字方案、工具不可用或必要素材缺失时，先交付资产设计与提示词，标记未生成；可以继续可完成的文字设计，但不能假装视觉资产已锁定。资产核对是内部工作，不默认要求用户每一步批准。

## 4. 研究依据的使用范围

四个模块内注明一手制作访谈和摄影报道链接。来源支持的事实与本扩展的短片转译建议分开。研究使用公开制作资料；不声称已完整观看、逐帧统计相关影片，也不提供未经测量的电影平均镜长或平台留存结论。

本扩展的时间区间、配色比例、样例场景和故事均为原创设计建议，不是昆汀本人制定的规则，也不是即梦的可控参数或抖音的官方要求。
