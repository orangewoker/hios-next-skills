# 和服妖异视觉语法与色系锚点

天野喜孝的「和服妖异」系列聚焦穿和服的妖异美人——狐妖、源氏物语女性、妖精、画皮式幽魅。这一谱系横跨《源氏物语 The Tale of Genji》(1997)、《妖精 Yousei》(1996)、狐妖意象（Sandman 等）、画皮式幽魅意象。其美学灵魂是「妖异而美」，绝非可爱动漫，也绝非志怪恐怖。

---

## 一、美学灵魂：气韵统一三律（第一性原理）

写任何 prompt 前先默念三律，它优先于所有特征清单。

1. **同源**：人物、和服、发、淡线环境，全部同一种极细线语言，不存在两套笔触（人物细线、背景厚涂即破同源）。
2. **同呼吸**：所有元素共享一个缓慢漂浮动势，同向微流动（头发、和服衣袂、环境线同向），不各自为政。
3. **气连**：留白是「气」不是「空」——淡金线 / 银丝气线连主角与背景，画面因此是一体呼吸而非割裂块。

**写法铁则**：先写一句「气韵总纲」统领全画氛围，再用正面气质引导元素；否定词只在 negative 块压死动漫化 / 恐怖化翻车项。**正向绝不堆砌 `no ears / no tail / no skull`**——那会让 AI 把人物当独立规避任务，反而变碎。

---

## 二、四元识别公式（缺一元不是和服妖异）

| 元 | 表现 |
|----|------|
| **极细如烟线条** | 黑 / 金极细毛笔线，有轻重呼吸，尾端消散，轮廓不封闭，碎笔波砺顿挫 |
| **飘逸和服衣袂** | 长线条和服，衣袂 / 腰带随呼吸微动，纹样金线暗示，非满铺写实花纹 |
| **淡线描妖异环境** | 鸟居 / 神社 / 月 / 樱枝用淡金线暗示构造，通透不填实心，不写实 |
| **中性妖异人物** | 尖脸空洞大瞳、拉长肢体、空寂，清冷疏离带淡淡妖艳 / 悲伤，无体积写实皮肤 |

---

## 三、人物基底（和服妖异专属）

- **全身竖版**：默认竖版全身（约 1024×1792），人物占画面主体（≥55%），飘逸和服衣袂拉长身形。构图人物偏置（如偏右 / 偏下），不居中死板。
- **脸**：尖下巴不现实、长窄脸；眼帘低垂或半阖，眼神空洞看向画外或下方（非直视镜头、非正面瞪视、非微笑、非萌脸、非骷髅恐怖脸）；气质清冷疏离、带淡淡妖艳或悲伤，是一种优雅的非人感。
- **肢体**：拉长≥1.3 倍、天鹅颈、无性别、浮游无重量（no anatomical weight）。
- **头发（必须，绝不省略）**：几根决定性长线，尾端消散，和和服 / 发饰共享同一种漂浮呼吸；绝不堆成实心发块，也绝不可漏写导致光头。
- **和服**：飘逸长线条，衣袂 / 腰带随呼吸微动；纹样用金线 / 淡线暗示（如水波、藤蔓、樱），非满铺写实大花纹（禁 dense floral kimono pattern）。

---

## 四、多色系锚点（按真实代表作用色，不固定单一）

和服妖异不默认「金色系统治」。色板按子主题从真实代表作用色提炼，四选一或用户自定：

### ① 源氏金朱（源氏物语 Genji, 1997）
- 色板：哑光金 + 朱红（vermilion）+ 靛蓝（indigo）+ 苍白纸白（pale paper white）
- 媒材：金箔线、朱红淡彩、靛蓝晕染、纸白地
- 气质：华丽典雅妖艳，贵族女性的哀艳
- 禁：满铺红、荧光朱

### ② 妖精群青（妖精 Yousei, 1996）
- 色板：群青（ultramarine）+ 绿青（viridian / malachite green）+ 金线白（gold-line white）
- 媒材：群青绿青水彩罩染、金线勾边、白地透底
- 气质：天真非人、空寂清冷
- 禁：暖红抢戏（仅作极少量点缀）

### ③ 狐妖朱金（狐妖意象）
- 色板：朱红（vermilion / red）+ 金（gold）+ 靛蓝（indigo）
- 媒材：朱红和服、金线纹样、靛蓝背景晕、黑线重描
- 气质：妖艳魅惑、疏离高贵
- 禁：卡通橙毛、荧光

### ④ 画皮苍白（画皮式幽魅）
- 色板：苍白（pale ghostly white）+ 血红（blood red）+ 黑（black）
- 媒材：苍白水彩皮肤、血红点缀（唇 / 衣襟 / 梅）、黑底或黑线
- 气质：阴柔凄艳、诡丽
- 禁：绿脸恐怖、骷髅

**媒材统一句（压写实，所有色系共用）**：
```
traditional illustration: colored inks and gold leaf layered over a visible
pencil underdrawing, re-inked with wispy black line. The black ink line is the
dominant statement; color is a translucent wash laid over it. Flat decorative
clarity — no volumetric shading, no soft 3d skin, no cast shadow, no chiaroscuro.
```

## 五、环境淡线描铁律（核心教训）

1. **人物为主体**：人物占画面≥55%，是绝对主角；环境只作陪衬。
2. **淡线描暗示构造**：环境（鸟居、神社、月、樱枝、水波、远山）仅用淡金线 / 淡色细线勾出「大概构造」——如鸟居 = 两根柱 + 一道横梁的细长线框，通透、不填实心块、不清明暗部。
3. **不写实**：环境不是照片式场景，无环境光、无景深透视、无写实砖石。
4. **不恐怖志怪**：环境不画鬼脸、不画血腥、不画阴森骷髅堆；气质是美学妖异。
5. **气连**：环境线与人物线同源同呼吸，淡线在留白中漂浮，让空白与主体相连。

## 六、跨模式铁律（自检用）

**线条**：① 极细毛笔线有轻重呼吸 ② 轮廓不封闭 ③ 尾端消散 ④ 留白上有同源气线相连 ⑤ 1990s 碎笔 / 波砺顿挫 / 干笔飞白
**色彩**：① 金箔作线非色块、哑光 ② 主色饱和低、透明 ③ 无阴影无投影、光由内发 ④ 无体积 / 无 3D 皮肤 / 无 chiaroscuro
**人物**：① 尖下巴不现实 ② 眼帘低垂、空洞看画外 / 下方，非直视 ③ 肢体拉长无性别空寂、冷艳疏离 ④ 头发长线、非实心块、不省略 ⑤ 和服飘逸长线、纹样金线暗示非满铺
**环境**：① 淡线描暗示构造 ② 通透不填实心 ③ 不写实不恐怖 ④ 与人物同源同呼吸

## 七、和服妖异专属 negative 块（压制两大失真）

直接复制到生成工具 negative 栏：
```
fluffy fox ears, cute kemonomimi, anime catgirl, chibi, mascot anime style,
realistic animal tail, furry ears, plush cosplay, dense floral kimono pattern,
big sparkly anime eyes, moe face, smiling cute face,
skull face, ghoul, horror grotesque, scary face, blood splatter, gore,
rotting flesh, demonic ugly monster, jump-scare,
volumetric shading, soft 3d skin, subsurface scattering, chiaroscuro,
photorealistic, 3d render, octane render, glossy highlight, baroque oil painting,
depth of field photograph, environmental lighting
```

## 八、翻车对照（气韵 / 风格偏离信号）

| 现象 | 根因 | 修正 |
|------|------|------|
| 元素各自为政、图脱 | 堆砌否定词让 AI 分任务规避 | 改气韵总纲统领 + 正面气质引导 |
| 太商业动漫（毛绒兽耳 / 萌脸 / 满花纹） | 缺「美学妖异非动漫」定位 | 去 kemonomimi，加尖脸空洞、长线飘逸、金线暗示纹样 |
| 太诡异恐怖（骷髅脸 / 阴沉） | 去动漫化用力过猛滑向志怪 | 调优雅尖脸、空灵疏离、大留白，删 skull/gore 词 |
| 环境消失（为去恐怖把背景减没了） | 只减不补 | 重加淡金线构造（鸟居 / 月），仍不写实 |
| 块面填太实像简化建筑 | 缺「通透不填实心」 | 线框通透、不填色块、无明暗 |
| 人物缩小变诡异、比例跑偏 | 环境抢戏、人物非主体 | 回归人物为主体（≥55%），环境仅淡线描 |
| 甜美日系脸 | 缺「尖脸空洞、非人」 | 加 razored pointed chin, vacant gaze, not a cherub |
| 彩稿像 3D 肖像 | porcelain skin 等词触发体积光影 | 改「淡彩罩染 + 黑线主导 + 无体积阴影」 |

---

## 九、彩稿起手式（去写实 / 抓妖异气韵）

**先写媒材，再写人物，再写色系与构图**：
```
traditional illustration: colored inks and gold leaf layered over a visible
pencil underdrawing, re-inked with wispy black line, on a deep black / pale
paper ground. The black ink line is the dominant statement; color is a
translucent wash laid over it. Matte gold leaf, no glossy bloom. Flat
decorative clarity — no volumetric shading, no soft 3d skin, no cast shadow,
no chiaroscuro.
```

**天野签名词**：broken brushstrokes, dry-brush fragments, visible pencil sketch, translucent watercolor wash, phantom light, mass dissolved, symbolic color, eerie elegance, restrained palette.
