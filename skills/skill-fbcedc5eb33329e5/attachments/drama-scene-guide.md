## 概述

本指南用于30秒文戏（情绪表演场景）的分镜设计。适用于单人、双人或三人互动的情绪递进场景，包含台词或纯表演。核心能力：

- **50情绪矩阵**：5大分类50种情绪，每种含面部肌肉→视觉结果双层结构
- **情绪强度四档**：L1轻度/L2中度/L3强力/L4极限，肌肉措辞+视觉幅度+姿态+呼吸四层同步换挡
- **复合情绪**：A→B转换链（先后变化）和A×B同刻叠加（两种情绪并存）
- **16-20镜头交付**：事件驱动镜头粒度，不按等长时间切片
- **核心道具状态机**：一个核心道具贯穿全程，持有者/方位/开合/交接逐镜连续
- **双人回声机制**：A输出→B接住并改变下一步→B的反应反推A

## 三阶段门禁工作流

### 阶段一：剧情与镜头大纲

1. 锁定角色、服装、场景、核心道具和台词
2. 用2-4句说明人物目标、冲突、情绪转折和结尾
3. 输出16-20个编号镜头大纲（每镜含机位/景别、主要动作、情绪信号、台词）
4. 检查：主角是否有4-5个连续情绪状态、配角是否改变主角下一步、道具是否连续
5. 发给用户确认，等待

### 阶段二：用户确认后执行

只有用户明确确认后才进入执行。按已确认大纲生成视频提示词。

### 绝对门禁

- 大纲未确认前禁止生成任何提示词
- 用户修改意见必须重新确认后再执行

## 情绪强度四档

任何情绪条目都可整体升阶或降阶。换挡时肌肉措辞、视觉幅度、姿态幅度、呼吸四层必须同步换：

| 档位 | 触发限定词 | 肌肉措辞 | 视觉幅度 | 姿态幅度 | 呼吸 |
|------|-----------|----------|----------|----------|------|
| L1 轻度 | 有点、一丝、隐隐 | 轻度收缩、微微参与 | 微、略、若隐若现 | 局部小动作 | 平稳，省略 |
| L2 中度（默认） | 很、明显 | 中度收缩、持续收缩 | 明显、清晰、可见 | 完整姿态响应 | 略促，可选写 |
| L3 强力 | 非常、压不住 | 强力收缩、持续紧绷 | 大幅、高高、死死 | 幅度大、全身参与 | 必须写，节奏紊乱 |
| L4 极限 | 炸了、崩溃、失控 | 极限收缩、锁死、痉挛 | 暴起、极限、彻底扭曲 | 失控/僵直/瘫垮 | 必须写，崩溃呼吸链 |

换挡规则：
- 档位可以换条目：「有点生气」用12隐忍怒意L1，「气炸了」直接换11雷霆狂怒L4
- L1省略呼吸行，L3起必须写呼吸，L4必须落到完整崩溃呼吸链

## 复合情绪结构

### A→B 转换链（先后变化）

随时间推进的情绪变化，如惊→喜、怒→释然。按起幅/过渡/落幅时间轴设计。

### A×B 同刻叠加（两种情绪并存）

同一时刻两种情绪并存，如又气又委屈、笑中带泪。

调配规则：
1. **定主色，禁止五五开**：主导情绪占据面部高信号区（眼部+眉额），底色情绪占据低信号区（嘴部+面部）
2. **同一肌肉只听一个指令**：若两种情绪争夺同一肌肉，写明对抗态
3. **姿态跟主色，留一个破绽**：整体服从主导，允许1个姿态细节泄露底色
4. **呼吸跟唤醒度更高的那个**

## 基础公式与适配规则

### 原始公式

```
电影级特写肖像，极其注重细节的主体，[情绪关键词组]，穿着休闲优雅的服装，柔和的自然光，浅景深，85毫米镜头，细节极其丰富，获奖摄影级别。
```

### 适配规则

在IMAX电影制作流程中，不可直接套用原始公式，必须根据镜头参数进行适配：

1. **替换服装描述**：将"穿着休闲优雅的服装"替换为角色资产卡中对应场景的服装描述
2. **替换镜头参数**：将"85毫米镜头，浅景深"替换为当前镜头的实际焦段和光圈
3. **替换光线描述**：将"柔和的自然光"替换为当前镜头的光线架构
4. **追加胶片前缀**：在公式最前方添加对应画幅的胶片质感前缀
5. **追加情绪外化**：在情绪关键词后追加肢体语言和情绪外化描述

### 适配后公式示例

```
[胶片前缀] 电影级特写肖像，极其注重细节的主体，[情绪关键词组]，[角色资产卡服装描述]，[当前镜头光线架构]，[景深描述]，[焦段]mm镜头，[情绪外化/肢体语言]，细节极其丰富，获奖摄影级别。
```

## 情绪与摄影参数联动

不同情绪应配合不同的摄影参数强化表达：

| 情绪类别 | 推荐景别 | 推荐焦段 | 推荐光比 | 推荐运镜 |
|----------|----------|----------|----------|----------|
| 喜悦/积极 | 近景/特写 | 85-135mm | 2:1-3:1 | 缓慢推近 |
| 悲伤/低落 | 特写/大特写 | 85-135mm | 3:1-4:1 | 固定/缓慢拉远 |
| 愤怒/不满 | 近景/中景 | 35-50mm | 5:1-8:1 | 手持微晃/快速推近 |
| 惊讶/恐惧 | 特写 | 50-85mm | 4:1-6:1 | 快速推近/轻微震动 |
| 厌恶/轻蔑 | 近景 | 50-85mm | 4:1-5:1 | 固定/缓慢摇移 |
| 思考/内省 | 近景/中景 | 50-85mm | 2:1-3:1 | 固定/缓慢环绕 |
| 暧昧/浪漫 | 特写/大特写 | 85-135mm | 2:1-3:1 | 极缓推近/柔焦 |

## 跨镜情绪连续性

### 情绪过渡规则

角色在同一场景中的情绪变化必须有过渡，不可跳跃：

| 过渡类型 | 示例 | 处理方式 |
|----------|------|----------|
| 渐进过渡 | 平静 -> 微笑 -> 大笑 | 每个镜头情绪递进一级 |
| 突变过渡 | 微笑 -> 震惊 | 中间插入0.5-1s的"愣住/呆滞"过渡 |
| 压抑过渡 | 愤怒 -> 平静 | 中间经过"咬牙切齿 -> 深呼吸 -> 平静" |
| 复合情绪 | 喜极而泣/强颜欢笑 | 直接使用情绪库中的复合情绪词条 |

### 情绪锚点

每个角色在每个场景中设定"情绪起点"和"情绪终点"，中间镜头的情绪必须在这两个锚点之间合理过渡。

### 段间物理承接

每段开头优先承接上一段遗留的物理状态：泪痕未干、泛红未退、笑意刚敛、呼吸还乱。不允许每段重置成「干净的起点」。

## 交付模板

### 四段式字段

```
【全局锁定】
① 约30秒；画幅跟随参考图，无图时默认16:9
② 锁定角色身份、左右位置、外貌、服装、场景和光线
③ 锁定180度轴线和人物视线方向，不翻转左右关系
④ 用户要求过肩时，谁说话就从倾听者肩后拍向谁
⑤ 锁定核心道具的初始持有者、位置、朝向和显露状态

【固定台词】
① 按角色列出所有完整台词
② 每句优先4-16个汉字；长句可在同镜头自然停顿
③ 分镜只能逐字调用，不能临时新增、改写或跨镜拆分
④ 一次只允许一人说话，倾听者闭口

【分镜】
① 使用"镜头1、镜头2……"编号，通常16-20个
② 每镜头写1-3句，只承载一个主导动作或一轮完整对白
③ 说话镜头写清过肩前景、说话者、完整台词和倾听者的一个关键回声
④ 无台词镜头必须提供新信息、决定、距离变化或情绪转折

【禁止项】
文字/UI/水印/Logo/字幕/黑屏/角色错位/左右翻转/越轴/口型错配/台词跨镜/道具瞬移/无因同步变脸
```

### 分镜写法要点

1. **事件驱动镜头粒度**：不按等长时间切片，普通镜头约1-2秒，完整对白镜头约2-4秒
2. **动力链句式**：大于45°的转身按部位先后拆写
3. **物理证据因果对**：主要动作配一个可见的次级运动后果
4. **情绪两件套**：情绪词 + 2-3个部位证据
5. **节奏曲线**：快慢相间，动作峰明确，情绪段落降速
6. **结尾双行**：最后一帧的具体画面 + 枚举式负面清单

### 交付前自检

- [ ] 通常16-20个有效镜头
- [ ] 每句台词完整位于一个镜头
- [ ] 主角有4-5个由事件触发的连续情绪状态
- [ ] 配角反应改变了主角或关系的下一步
- [ ] 核心道具持有者、移动过程与落点连续
- [ ] 说话者、过肩前景、口型归属和视线方向一致
