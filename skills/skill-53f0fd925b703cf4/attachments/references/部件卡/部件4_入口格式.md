# 部件卡4 · 入口6种格式

## 六种入口（写入正文开头，不加类型前缀）
| 分支 | 入口格式 | 适用场景 |
|:----|:---------|:---------|
| A连续机位 | `one continuous unbroken [X] seconds take——[景别]，机位为…` | 复杂运镜长镜头 |
| B固定机位 | 万物生式：`[景别]，[画面主体及空间描述]，[节奏]`（如「远景，固定机位，纯正侧面水平视角拍摄」）。不写"镜头固定fixed shot" | 固定机位群 |
| C正打 | `[角色名]的近景，偏[左/右]脸朝[右/左]，镜头沿[方向]弧线极缓慢地微微环绕。`（照万物生正反打每镜重申环绕） | 对话正打 |
| D反打 | `反打，[角色名]的近景，偏[右/左]脸朝[左/右]，机位跳到环绕弧线对侧，镜头仍沿同一[方向]弧线微微环绕。` | 对话反打 |
| E跳切引入 | `切到[角色名][景别]，机位[平视/俯角/仰角]。` | 快速切入新角度 |
| F特效开头 | `bullet time slow motion…` / `升格慢动作…` | 特殊效果镜头 |

## 入口声明后直接写画面，不加过渡语
❌ 禁止："让我们看到…""这是一个…镜头"

## 万物生原版入口（对照用）
```
镜头一段不间断连续15秒 one continuous unbroken 15 seconds take。整段镜头是一个
complex 360-degree descending spiral orbit around Danmei while she walks forward复杂的
360度下降螺旋环绕镜头围绕走路中的丹眉,镜头一边围绕她顺时针环绕一边随她前进一边逐渐降低高度。
```

## 慢动作/子弹时间（F型完整模板）
```
慢速进入：时间像被拉住一样慢下来，X在慢速中极缓慢地Y。
加速回正：慢速里时间猛地加速回正、一切骤然提速→[动作加速完成]
重回慢速：X完成后画面再次切入子弹时间的极慢速…
⚠️ 必须有"唯一动元素"（符箓亮起/悬浮血珠）和明确的"回到正常速度"标记
```
