# 附MD07 | 双男主·JSON数据与引擎对接

**所属主SKILL：** 双男主 · 双向救赎 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

确保互动影游能落地运行、可直接交付工程。

## #需要什么输入

完整节点清单、变量字典、视频文件。

## #怎么做

### 一、JSON数据结构

包含variables（羁绊值、信任度、黑化值、救赎进度）、nodes、endings。

### 二、Twine/SugarCube 工程规范

严格遵循SugarCube 1.0.35锁定规范。\
变量赋值：set空格美元符号变量名空格等于号空格值。\
跳转：goto语法，链接格式为双方括号。

### 三、视频文件命名规范

N01.mp4（雨夜对峙）、N02A.mp4（放下枪）、N02B.mp4（打偏）等。

### 四、本地测试规范

VS Code + Live Server。

### 五、生成与合成

调用底层视频生成Skill，输出MP4视频文件。
