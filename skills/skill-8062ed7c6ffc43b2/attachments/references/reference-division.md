# 引用分工

在 `reference_nodes` 中插桩。主参考负责身份特征，辅参考负责角度依据，并为底图设置硬性禁令，严禁读取旧五官特征。

## 分工铁律——只迁骨相，不迁妆容

优先级遵循 SKILL.md「相似度优先级」的统一裁决句：骨相相似度与四项必锁冲突时优先保骨相相似度；妆容、光感、色感在不牺牲骨相相似度的前提下尽量满足；表情与眼神始终最高，不让位。

**作用范围澄清**：「骨相相似度第一优先」仅适用于脸型轮廓、下颌线、眼型、鼻型、唇形等**结构特征**；而**肌肉状态与情绪指向**同属「表情眼神」这一不让位类别。即：结构让位规则与表情让位规则分别作用，不得用骨相优先去覆盖情绪基调。

- 从参考脸只迁移「骨相与五官结构」：脸型轮廓、下颌线走向、鼻骨高度与鼻翼宽度、眼裂长度与眼型走向、双眼皮形态、唇形厚薄与唇峰形状、颧骨高度、眉眼间距。
- 「妆容、肤色与皮肤质感」一律保留底图原样，绝不随参考图迁移：唇色与唇质、眉形与眉色、眼影与眼线与睫毛妆感、腮红色调与位置、肤色冷暖、毛孔与肌理、面中高光油润度。
- 必须在 prompt 中用禁令句式显式写出参考脸「不提供任何妆容信息」，并把底图妆面逐项描实（如「暖调豆沙棕唇配缎面微湿润光泽与自然唇纹；随发色偏棕的自然毛流眉；暖橘调腮红；保留真实毛孔与面中窗光下的自然油润高光」），结尾加一句「新五官结构必须化着这套妆，如同底图人物本来就是这个长相，妆面与脸型浑然一体，毫无贴片感」。
- 参考脸为正面照而底图为侧脸时，须按 `references/profile-translation.md` 做侧面转译，禁止正面特征等强度平移。

## 分工对象随路径切换

- **整图路径（路线 A）**：参考脸提供身份特征，原整图作为底图提供妆面、光感、色感、眼神表情、皮肤质感与除五官结构外的一切。
- **裁切腰上像路径（人脸原生宽度 &lt;250px）**：裁切放大后的腰上像图本身即为本次换脸的底图，参考脸提供骨相，腰上像提供妆容、光感、色感、眼神表情、皮肤质感与除五官结构外的一切。四项必锁、情绪基调独立锁定、皮肤质感保真、表情锁定等规则全部照常适用，对象从原整图换成这张腰上像底图。此路径下不再需要「裁切方图仅作角度辅参考、禁止提供五官特征」那套三参考分工（那是为整图直出服务的）。

## 皮肤质感保真（非验收项）

**已定论：经 7 张样本跨各类条件验证，属模型能力上限而非写法问题，故本条款降级为非验收项，仅作精简约束与交付后提示。2K 输出下皮肤质感不作任何期待，仅保留精简约束。**

- 精简约束：皮肤质感须对齐底图，禁磨皮、禁均质化、禁去毛孔与细纹、禁把皮脂高光改柔光哑光。
- 不参与优先级排序，不作为判定成品合格与否的依据，也不作为反复重试的理由。
- 不得因皮肤质感不达标而判定整张失败、不得为此单独重跑、不得在报告中把它列为 ⚠️ 之外的更重等级（只允许标注 ⚠️ 或 ✅）。
- 交付后提示：凡成品皮肤质感明显偏软（与底图对比可见毛孔细节丢失或皮脂高光被抹平），向用户补一句「皮肤质感偏软属模型能力上限，如需可后期局部补纹理」，并说明这不是重跑能解决的问题，不建议为此重复生成。

## 非写实参考的处理

当参考脸为 CG 渲染、插画、古风写真等非写实质感时，除上述妆容禁令外，须追加画风污染禁令：严禁继承其绘画笔触、塑料感皮肤、插画式高光、非写实渲染，并逐条列出该参考特有的妆面特征予以排除。同时须在开工前明确告知用户：非写实参考存在相似度天花板，五官形状可换对但「神似」会打折，建议优先提供写实参考图。

## 裁切辅参考的定位与分工（仅在「用户要求整图交付、同时人脸偏小」的场景下启用）

此条款仅在用户额外要求整图交付、同时人脸偏小时启用。此时裁切肖像方图仅作角度、表情、头部朝向与面部光影依据，禁止提供任何五官特征，并在 prompt 中用禁令句式写死；与参考脸的身份分工、底图的构图分工三者并列声明。
