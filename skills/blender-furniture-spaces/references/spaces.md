# 室内空间

输入平面图时先读尺度、净尺寸与墙厚，区分墙中心线/结构线和净空。没有比例尺时记录估算，不从截图像素伪造毫米精度。建立坐标、地面标高与空间边界后再布置家具。

## 构件和组织

- 场景按 Architecture / Furniture / Lighting / Cameras 组织，每个房间或定制柜单独集合，门窗和五金保留独立对象。
- 墙体需真实厚度，门窗必须是真开口，不能只在实体墙上贴一块深色矩形。`kit.wall_with_openings()` 用分区墙段生成无重叠的直墙与矩形洞口，保留 `openings` 记录；非矩形洞口另用轮廓挤出或布尔。
- 墙面、地面、顶面与家具的材质分开。按真实米制映射纹理，地板木纹长向与铺装方向一致。
- 对柜体检查板厚、门缝、抽屉与开门空间；对沙发桌椅检查落地、接触与通道，不随便等比缩放使板厚失真。
- 已有场景编辑只改指定构件；不要为了室内照片好看擅自隐藏无关用户对象或替换原场景世界。

## 视角与验收

平面/顶视检查布局、墙厚和开口；人视相机检查尺度、遮挡、碰撞和动线。室内相机通常高度约 1.4–1.65 m，避免用极端广角掩盖比例错误。自然光与灯具有合理位置和尺寸，不用强曝光掩盖缺失材质。

交付应列出：输入已知尺寸、推断尺度、空间构件与家具集合、平面预览和人视预览，以及可编辑 `.blend`。仅几何测试通过不等于布局或施工尺寸已验收。
