# 附MD06 | 男频后宫·配音台词与音效规范

**所属主SKILL：** 男频后宫 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“男频后宫 | 上架Steam的互动影游”的专属配音台词与音效规范。

解决互动影游“台词风格不统一、物理音效缺失、都市感不足、情感氛围不到位、旁白与画外音混淆”的痛点。通过统一的声线规范、台词清单与纯物理音效铁律，确保全片配音与音效高度统一，强化都市异能、情感纠葛与势力博弈氛围。

## #需要什么输入

**最少提供：**

- 角色清单与声线设定
- 关键节点台词清单
- 关键音效触发节点

**可选提供：**

- 是否需要BGM（默认仅允许都市情感配乐）
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。配音与音效环节重点参考【情绪大师】的七层微表情拆解，确保配音情绪与画面情绪完全同步。

### 二、配音台词清单格式（每节点必须标注）

每条台词必须包含：

- 角色：谁在说
- 情绪：什么状态
- 语速：快/慢/停顿节奏
- 特殊要求：喘息/颤音/沉默几秒
- 类型：对白/内心独白/旁白/系统提示音

### 三、声线规范

1\. 男主

- 声线：低沉从容，带磁性，25-35岁男声。
- 内心独白与对白：同一演员。
- 情绪切换：冷静→爆发→喘息→决然。
- 特殊说明：不要播音腔，要有都市强者的自信与克制。

2\. 女主A（冷艳御姐）

- 声线：清冷成熟，带气场，25-35岁女声。
- 情绪切换：冷艳→克制→柔软→决绝。
- 特殊说明：语速偏慢，字字有重量。

3\. 女主B（清纯少女）

- 声线：清澈甜美，带灵动，18-25岁女声。
- 情绪切换：羞涩→雀跃→担忧→坚定。
- 特殊说明：语速轻快，句尾微微上扬。

4\. 女主C（温婉知性）

- 声线：温柔细腻，带书卷气，22-30岁女声。
- 情绪切换：温柔→隐忍→坚定→释然。
- 特殊说明：语调平稳，呼吸感强。

5\. 女主D（灵动活泼）

- 声线：明亮活泼，带元气，18-25岁女声。
- 情绪切换：欢快→委屈→认真→深情。
- 特殊说明：语速较快，情绪外放但不夸张。

6\. 反派/对手

- 声线：阴冷傲慢，字字带压迫感。
- 特殊说明：冷笑与威胁交替，台词少但每句扎心。

7\. 旁白

- 声线：沉稳、史诗感、画外音，男声。
- 特殊说明：不同结局情绪不同，好结局暖，坏结局冷。

### 四、台词字数与语速配比（强制）

1. 标准语速：4字/秒。
2. 沉稳/压迫语速：3.2字/秒。
3. 急促/爆发语速：5字/秒。
4. 绝对红线：禁止超过5.5字/秒，否则必然吞字、口型残影。
5. 单镜5秒最多承载16-18字。超过20字必须拆2镜（合计≤10秒）。

### 五、有口型与画外音区分（防废片核心）

1. 有口型对话：必须对口型，最多拆2镜，严格遵守字数与语速配比。
2. 空镜旁白：不需要对口型，不受时长拆分限制，后期剪映慢放补时长。
3. 内心独白：角色不张嘴，不受台词铁律限制，只需保证情绪与内容匹配。
4. 绝对禁止：要求AI对画外音对口型。

### 六、纯物理音效清单

1. 都市环境音：车流低鸣、人群低语、雨声、霓虹电流声。
2. 异能音效：能量爆发、空间裂痕、光效共鸣、低频震动。
3. 战斗音效：拳头打肉、骨骼闷响、玻璃碎裂、金属碰撞。
4. 情感音效：心跳声、呼吸声、轻触声、衣料摩擦声。
5. 古武音效：兵器出鞘、金属铮鸣、木门开合、脚步踩石板。
6. 高层公寓环境音：落地窗外的城市低鸣、室内空调轻响。
7. 地下酒吧环境音：酒瓶碰撞、人群低语、低频音乐。

### 七、配乐边界

1. 默认无BGM或极简配乐。
2. 配乐必须克制，让位给物理音效。
3. 仅允许使用现代都市情感配乐（钢琴、弦乐、电子氛围）。
4. 禁止全程铺满BGM。
5. 禁止仙侠古风吟唱、西方交响乐滥用。
6. 配乐进入与退出必须自然，避免突兀切断。

### 八、声音叙事法则

1. 声画同步：高频音效踩准画面动作切点。
2. 声画错位：情绪高潮前，画面静止但环境音延续，制造预期停顿。
3. 混音优先级：台词 &gt; 环境音 &gt; 音效 &gt; 配乐（最低）。
4. 配音不要全片铺满，必须有大量留白呼吸段。

1. E01·独宠女主A：“从今以后，我眼里只有你。”
2. E02·独宠女主B：“谢谢你，一直在我身边。”
3. E03·独宠女主C：“岁月静好，与你同行。”
4. E04·全员羁绊：“命运不认真相，只认选择。而我，选择你们所有人。”
5. E05·江湖浪子：“江湖路远，我仍是一个人。”
6. D01·修罗场爆发：“你们……全都背叛了我。”
7. D03·势力清算：“看来，这个城市容不下我。”
8. D08·全员反目：“原来，我从未真正拥有过谁。”
