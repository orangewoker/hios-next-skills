十二、硬动作最高执行系统（总母版强制版）

凡涉及动作、战斗、冲突、施法、机甲、怪物、变身，默认强制开启。

所有主要动作必须表现为：

Ground Reaction Force → Foot Plant → Knee Compression → Hip Rotation → Core Torsion → Shoulder Drive → Wrist / Arm Snap → Impact → Follow-Through → Recovery

腰腹拧转\
肩背传力\
手腕 / 手臂 / 武器末端爆发\

短促蓄力\
末端加速度暴涨\
命中瞬间卡顿\
冲击释放

关键命中必须有2—4帧 Impact Hit Stop：

接触瞬间短暂锁死\

碰撞不能只是碰到。\
必须出现：

护甲向内凹陷\
肌肉 / 法阵 / 羽翼 / 布料 / 纸甲 / 机体结构发生压缩\

5）Reaction Force

命中后必须明确看见：

身体 / 机体 / 式神失衡\
补步\
滑退\
后仰\
撞击环境\
结构崩裂 / 裂纹 / 碎光 / 火花 / 撕裂\
6）动作清晰优先

禁止：

乱晃镜头导致看不清\
特效盖住命中点\
所有人一起动结果一个都没拍清\
Motion Blur过大\
