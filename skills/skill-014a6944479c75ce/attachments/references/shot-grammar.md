## 镜头语言的基本单位

把单个镜头视为词，把相邻镜头关系视为语法，把一场戏视为句子。景别、机位和运动本身没有固定意义；意义来自内容、顺序、持续时间及与前后镜头的对比。

先区分：

- **Shot（镜头）**：剪辑成片中的连续画面单位。
- **Setup（机位设置）**：现场某套摄影机、灯光和演员位置；一个 setup 可拍多条 take。
- **Frame（画格/构图）**：某一瞬间画面内部的安排。
- **Coverage（覆盖）**：为同一动作或表演拍摄的可替换角度与景别。

选择镜头时依次问：要建立空间、显示关系、进入主观、突出证据、读取反应、压缩时间，还是故意打断连续性？

## 景别与角度

| 术语 | 画面范围/位置 | 主要用途 | 常见风险 |
|---|---|---|---|
| Extreme wide / EWS | 人物很小，环境占主导 | 规模、地理、孤立、命运压力 | 表演不可读 |
| Wide / long shot / WS/LS | 全身与环境 | 身体动作、群体、障碍、调度 | 注意力分散 |
| Full shot / FS | 人物完整身体 | 姿态、动作完成、服装关系 | 环境信息有限 |
| Cowboy / medium long / MLS | 约大腿以上 | 动作与表情兼顾、多人站位 | 变成无立场默认 |
| Medium / MS | 约腰以上 | 对话、手势、关系谈判 | 缺少强度变化 |
| Medium close-up / MCU | 胸肩以上 | 表情与少量环境平衡 | 过多会视觉单调 |
| Close-up / CU | 面部或关键物体 | 选择、微反应、重要信息 | 过早透支强度 |
| Extreme close-up / ECU | 眼、嘴、手等局部 | 身体性、证据、冲击 | 缺少上下文会不知所指 |

角度需结合人物姿态、背景和前后镜头解释：

- **Eye-level**：减少明显评价，让表演承担意义。
- **High angle**：展示地面关系、困境或俯察；不自动等于弱小。
- **Low angle**：强调高度、建筑压力或主观仰望；不自动等于强权。
- **Bird’s-eye / overhead**：图形化空间、命运视角、路线或尸体/物件关系。
- **Worm’s-eye**：极端仰视、尺度压迫或陌生化。
- **Dutch angle / canted frame**：打破水平稳定；只在失衡有叙事功能时使用。

## 建立空间的镜头

### Establishing shot

建立地点、时间、人物相对位置或行动方向。它不一定是大全景，也不一定必须放在场景开头；可以晚给，让观众先处于角色的局部认知中。

### Master shot

用一个较完整机位覆盖场景的主要动作与对白，保留空间和表演关系。master shot 可以作为成片主体，也可以只是剪辑保险。

### Re-establishing shot

在人物移动、新人进入、轴线改变或长时间近景后重新说明空间。只有观众需要重新定位时才使用。

### Sequence shot / oner

用单一连续镜头完成整场或完整段落。通过人物调度、摄影机位置、焦点和前后景变化完成内部剪辑。不要把长镜头当炫技；每个 beat 仍需形成新构图。

## 正反打与对话语法

### Shot/reverse shot（正反打）

在同一关系轴两侧交替展示人物，通常配合 eyeline match（视线匹配）和一致 screen direction（屏幕方向），让观众感到人物在互相看、互相回应。

正反打成立需要：

- 先建立或让观众推断人物空间关系
- 两边视线方向和高度能够相接
- 景别、机位高度、肩膀面积和镜头距离的差异有意可读
- 切换跟随信息、反应或权力变化，而非每句台词机械轮换

正反打不是天然中立。谁更近、谁占前景、谁有干净背景、谁被遮挡、谁更早获得特写，都会表达关系。

### Over-the-shoulder / OTS（过肩镜头）

以前景人物的肩、头或身体边缘框住对面人物。它把两人保持在同一关系空间，并让观众靠近前景人物的位置。

- 前景肩膀越大，连接、压迫或控制感越强。
- 前景仅略入画，可作为较轻的关系提示。
- 两边过肩尺寸不对称可表达权力差，但要确保是故意设计。

### Dirty single（带肩单人）

主体基本是单人，但画面边缘保留另一人的模糊肩膀、头或身体。适合保留关系压力、监视、亲密或无法摆脱对方的感觉。

### Clean single（干净单人）

只留下主体，不带对方身体。适合隔离、进入更强主观、显示关系断裂或把观众注意力完全交给表演。

从 dirty single 变为 clean single 可以成为关系变化；不要让两者随机混用。

### Two-shot（双人镜头）

同框展示两人，使距离、朝向、遮挡、身高和空间权力可以实时变化。

常见形式：

- **Profile two-shot**：两人侧面对峙，强调距离与界线。
- **Front-facing two-shot**：两人朝相近方向，适合共同观察、联盟或表面并肩。
- **Stacked two-shot**：一前一后，用纵深表达支配、监视、分离或秘密。
- **Moving two-shot**：边走边谈，让移动目标和关系变化同时发生。

### Three-shot / group shot

显示联盟、排斥与第三人反应。三人戏不要给每人平均镜头；先决定当前联盟和谁掌握信息，再通过同框组合变化让阵营可见。

## POV、反应、插入与切出

### POV shot（主观镜头）

经典结构：`看的人 → 所看之物 → 看后的反应`。可省略其中一项来制造不确定，但要知道观众可能不再把镜头理解为严格 POV。

区分：

- **严格主观**：摄影机近似角色眼睛的位置和观看方式。
- **贴近主观**：摄影机靠近角色知识与情绪，但不假装是眼睛。
- **客观观察**：摄影机不受单一角色知识限制。
- **全知视角**：观众看见角色都不知道的信息，用于悬念或主题比较。

### Eyeline match（视线匹配）

镜头 A 显示人物看向画外，镜头 B 显示其所看对象，并让方向、高度和距离感觉相容。它能在没有同框时建立心理与空间连接。

### Reaction shot（反应镜头）

展示人物接收信息后的变化。反应可以比台词更重要，也可以被延迟或省略。没有新解释、潜台词或节奏价值的反应不要保留。

### Insert shot（插入镜头）

从当前场景内部抽出关键细节，如信件、手机、手、锁或证据。它回答“具体是什么”，并应匹配道具位置、手别、动作阶段和光线。

### Cutaway（切出镜头）

暂时离开主要动作，切到相关人物、环境、时钟、旁观者或后果。它可补信息、压缩时间、隐藏连续性拼接或改变意义。

区别：insert 通常是主要场景中被放大的细节；cutaway 通常转向主要动作之外但相关的对象。

## 连续性剪辑

### 180-degree rule

把摄影机保持在人物视线轴或行动轴的一侧，使左右关系和运动方向稳定。若越轴，使用可见跨轴移动、中性机位、重新建立镜头或新行动建立新轴线。

### 30-degree rule

同一主体连续切换机位时，机位角度通常需变化约 30° 或同时显著改变景别，以避免像意外跳动。这是连续性指导，不是数学戒律。

### Match on action（动作匹配）

在动作进行中切换机位，让动作跨镜延续。匹配动作阶段、速度、方向与身体重心；剪辑时常可略去少量重复帧，让动作主观上更流畅。

### Screen direction

人物或物体持续向画面同一方向移动，会被理解为继续前进。反转方向通常暗示返回、对抗或空间变化；先建立原因。

### Graphic match

利用形状、色彩、构图或运动方向相似连接不同时空。相似只是入口，真正价值来自两镜意义的联系或反差。

### Continuity break

故意违反视线、动作、时间或空间匹配，可表达断裂、记忆、焦虑、异化或时间压缩。先建立常态，再破坏；否则更像失误。

## 摄影机运动语法

| 术语 | 技术动作 | 常见叙事用途 | 不要混淆 |
|---|---|---|---|
| Pan | 固定机位水平旋转 | 跟随、比较、揭示画外信息 | 不是横向移机 |
| Tilt | 固定机位垂直旋转 | 揭示高度、身体、建筑、权力路径 | 不是升降机位 |
| Dolly in/out | 摄影机实际靠近/远离 | 改变观众距离与透视、暴露后果 | 不等于 zoom |
| Truck/track | 摄影机横向移动 | 跟随、揭开遮挡、重排前后景 | 不等于 pan |
| Pedestal/boom/crane | 摄影机升降或弧线移动 | 改变层级、揭示规模、离开/进入空间 | 说明起落构图 |
| Handheld | 人体持机产生有机波动 | 身体卷入、不稳定、现场感 | 不等于随意抖动 |
| Steadicam/gimbal | 稳定移动 | 连续探索、跟随调度、流动主观 | 稳定不自动等于优雅 |
| Zoom | 改变焦距而机位不动 | 改变视场、强调媒介感、快速重构 | 透视不因机位改变 |
| Rack focus | 同镜改变焦点平面 | 转移注意、连接前后景、揭示信息 | 它是对焦变化，不是移机 |
| Whip pan | 快速摇摄并产生运动模糊 | 紧迫回应、隐藏切点、喜剧或能量转移 | 需明确落点与方向 |
| Dolly zoom | 移机与反向变焦保持主体大小 | 让背景透视剧烈变化，表达认知冲击 | 高识别度，谨慎使用 |

运动描述必须包含：`触发 → 运动类型与方向 → 速度/稳定性 → 新信息 → 落幅 → 停止原因`。

## 剪辑与转场语法

| 术语 | 做法 | 常见功能 |
|---|---|---|
| Straight/hard cut | 直接从 A 切 B | 默认连接、节奏推进、因果 |
| Shot/reverse shot | 关系轴两侧交替 | 对话、观察、冲突、信息交换 |
| Match cut | 依据动作、图形、声音或概念匹配 | 连续、转义、跨时空连接 |
| Jump cut | 同主体时空发生明显跳跃 | 压缩、焦躁、断裂、过程累积 |
| Smash cut | 强烈声画、尺度或情绪反差 | 冲击、喜剧、惊醒 |
| Cross-cutting | 在不同地点的行动间交替 | 同时性、悬念、因果汇合 |
| Parallel editing | 并置两条行动或主题线 | 比较、对照、建立第三层意义 |
| Montage | 多镜压缩过程、时间或概念 | 变化累积、训练、传播、记忆 |
| Elliptical cut | 省略中间过程 | 压缩时间、保留关键结果 |
| Dissolve | 两画面短暂叠化 | 时间/地点变化、记忆、柔性连接 |
| Fade in/out | 从黑/白进入或退出 | 段落边界、结束、时间停顿 |
| Wipe | 画面边界推动替换 | 明显转场、类型化节奏、空间推进 |
| Freeze-frame | 重复保持单帧 | 强调决定、结局、记忆或媒介感 |
| J-cut | 下一场声音先进入 | 预告空间、平滑转场、制造期待 |
| L-cut | 上一场声音延续到下一画面 | 保留情绪、连接因果、制造反差 |

转场效果越显眼，越需要内容上的理由。不要用叠化、擦除或快速摇摄掩盖没有设计好的段落关系。

## 替代正反打的方法

正反打只是一种选择。考虑：

- **保持 two-shot**：让观众比较说与听、真话与身体反应。
- **长镜头内重构**：人物走位、遮挡、焦点和摄影机移动完成权力变化。
- **只拍听者**：让台词意义落在反应上。
- **拒绝反打**：隐藏对方态度、维持疏离或让画外人物成为压力。
- **Whip pan 往返**：用运动代替切换，制造急迫回应或喜剧节拍。
- **Profile two-shot**：把对抗保持在同一平面，强调距离和边界。
- **前后景深焦**：同时保留行动与后果，让观众自己选择注意力。
- **镜面/反射**：同框但空间关系复杂；先确保视线与身份可读。

决定是否用正反打：

| 当前重点 | 优先考虑 |
|---|---|
| 建立彼此连接和空间 | OTS / dirty singles / two-shot |
| 进入一人主观或关系断裂 | clean single / POV |
| 同时比较两人反应 | two-shot / deep focus |
| 让台词压在听者身上 | reaction shot，保留说者画外声 |
| 隐藏某人真实态度 | 不给 reverse shot 或延迟给出 |
| 权力发生变化 | 改变景别、肩膀比例、机位或从同框转单人 |
| 观众需要重新定位 | master / re-establishing shot |

## AI 视频镜头语法

制作正反打或连续对话时锁定：

- A 在画面哪侧、看向哪侧；B 对应相反方向
- 两边 eyeline 高度、摄影机高度和光线方向
- OTS 中前景肩膀属于谁、占画面多少
- 道具手别、桌面位置、服装左右细节
- 每镜开头姿势、主要动作和结尾姿势

AI 模型容易把左右、肩膀身份、道具手别和背景几何生成漂移。优先分别生成 clean singles，再用已验证的一致角色/场景参考制作 OTS；复杂多人长对话拆成短镜头并用声音桥连接。

## 快速选择表

| 想让观众获得什么 | 镜头语言候选 |
|---|---|
| 理解地点和人物位置 | establishing / master / wide shot |
| 感受两人关系 | two-shot / OTS / dirty single |
| 隔离人物 | clean single / close-up / 负空间 |
| 看角色看到的东西 | looker + POV + reaction |
| 确认关键证据 | insert + reaction |
| 暂离主动作补充意义 | cutaway |
| 保持动作流畅 | match on action / screen direction |
| 同时推进两处行动 | cross-cutting |
| 压缩一段过程 | montage / elliptical cut / jump cut |
| 让声音连接时空 | J-cut / L-cut / sound bridge |
| 让关系在画内变化 | two-shot / oner / rack focus / blocking |

## 常见误用

| 误用 | 问题 | 修正 |
|---|---|---|
| 对话自动正反打 | 镜头只追踪说话人，没有关系变化 | 按信息、反应和权力分配镜头 |
| 两边完全对称 | 忽略人物差异 | 让景别、肩膀比例、背景或距离表达关系 |
| OTS 前景肩膀漂移 | 空间和身份不稳定 | 锁定轴线、镜头高度和前景比例 |
| 把 insert 与 cutaway 混为一谈 | 不清楚镜头是否属于主要动作空间 | 写明它回答细节还是暂离主动作 |
| 同一主体小幅换机位 | 产生意外 jump cut | 遵循 30-degree 指导或显著改变景别 |
| 用 zoom 代替 dolly 的描述 | 技术与透视效果不一致 | 写清机位是否移动 |
| 每个转场都加效果 | 形式抢过内容 | 默认 hard cut，只为叙事变化选显眼转场 |
| 只拍说话人 | 丢失潜台词与关系证据 | 拍关键听者、同框和画外压力 |
| 特写等于重要 | 全场无距离层级 | 把最靠近的镜头留给不可逆变化 |
