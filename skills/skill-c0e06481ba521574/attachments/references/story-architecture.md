# 原创高概念叙事架构

## 1. 双引擎原则

同时建立两台引擎：

- 概念引擎：一个可视化、可验证、有边界和代价的异常规则。
- 情感引擎：一个即使没有异常规则也会让人物痛苦的关系或选择。

让概念迫使主角面对情感问题。避免让机制成为装饰，或让角色只负责解释设定。

使用此句式起步：

> 当【可视化异常规则】发生时，【带有错误信念的主角】必须【不可逆行动】，否则【外部损失】；但真正的代价是【关系或自我认知的损失】。

## 2. 规则设计

为机制填写六项：

| 项目 | 必须回答的问题 |
|---|---|
| 触发 | 什么条件下发生？ |
| 感知 | 观众和角色如何从画面/声音辨认？ |
| 边界 | 什么不能做到？ |
| 代价 | 每次使用会失去什么？ |
| 失败 | 规则被误用时发生什么？ |
| 证据 | 哪三个镜头能证明规则始终一致？ |

把规则控制在一条核心规则和最多两条派生规则。先用行动展示，再用极少对白确认。

### 时间本体

先选择一种时间本体并贯彻到底：固定闭环要求所有改变早已属于历史；可变单线允许历史被覆盖，但必须说明来自被抹除未来的人或物为何消失、保留或成为时间锚；分支世界让改变产生新分支，并说明角色能否返回原分支。不要为结局临时混用三种模型。

若主角的成功会阻止关键物件从未来抵达过去，必须建立“锚定/残留”规则并提前用镜头证明，或重新设计因果链以避免祖父悖论。

## 3. 三张地图

分别建立：

1. **线性真相**：事件在故事世界中实际发生的顺序。
2. **放映顺序**：观众看到事件的顺序。
3. **信息矩阵**：每一段中主角、对手、盟友和观众分别知道什么。

每次打乱顺序都要产生明确价值：悬念、惊奇、反讽、情感重估或因果闭合。若只增加理解成本，恢复线性顺序。

## 4. 时间线表

为两到三条线建立同一标尺：

| 时间线 | 客观区间 | 主角目标 | 观众新增信息 | 视觉/声音识别 | 汇合点 |
|---|---|---|---|---|---|
| A |  |  |  |  |  |
| B |  |  |  |  |  |
| C（可选） |  |  |  |  |  |

让不同线的切换共享动作、形状、声音或语义。避免只靠“X 天前”字幕。

## 5. 八段式节拍

按时长压缩或扩展以下序列：

1. **异常开场**：展示结果或谜面，留下一个可验证的问题。
2. **常态与伤口**：建立主角的错误信念和关系缺口。
3. **规则越界**：主角主动进入机制，付出第一次代价。
4. **交叉升级**：两条时间线互相制造障碍，出现虚假胜利。
5. **中点重释**：已知事实改变意义，但不改变事实本身。
6. **因果收紧**：主角发现自己参与制造了最初的问题。
7. **不可逆选择**：在外部目标和情感真相之间做选择。
8. **回声结尾**：重访开场意象，以新意义闭环，保留可讨论的余波。

短片合并 2/3、4/5、7/8；长片把每段扩展为一个序列。

## 6. 公平揭示

为每个揭示准备三类线索：

- 视觉线索：道具位置、服装磨损、光源方向、空间关系。
- 行为线索：人物回避、错误用词、反常选择。
- 声音线索：重复声响、被截断对白、声画错位。

第一次观看时让线索自然，第二次观看时让它明确。不要用新规则临时解释结局。

## 7. 人物弧光

用五步记录：欲望 → 恐惧 → 错误信念 → 被迫选择 → 新的行动方式。

让对手代表主角错误信念的另一种实践，而不是只充当阻碍。让配角拥有独立目标，并至少一次改变因果链。

## 8. 结构校验

逐项检查：

- 能否用一句线性陈述解释全部因果？
- 每个结果能否追溯到人物行动，而非编剧便利？
- 机制的代价是否在高潮真实兑现？
- 中点和结尾是否“重释”而非“否认”此前信息？
- 删除说明对白后，观众能否从行为和视听线索理解核心？
