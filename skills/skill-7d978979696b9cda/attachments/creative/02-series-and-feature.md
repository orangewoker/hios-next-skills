# 长片与剧集：让后果、人物和信息持续发展

前提已选定，需要全片大纲、季纲、分集、群像、多线收束、前传、跨集改写，或故事中段重复、结尾突兀时读取。用户只要求局部场景时，仅回读与本场相关的故事状态，不把完成全季资料设为前置条件。

## 最小输入

取得当前前提、作品形态、主要人物关系、原作或前作约束、本轮范围，以及现有结局或开放问题。体量、创作权限和交付约定以[项目契约](../core/01-project-contract.md)为准；人物简历、准确集数或结局未定可保留探索，不捏造已确认答案。

故事、集、场的记录身份、版本与故事日期依[核心记录](../core/03-records.md)。回读来源通过[状态恢复](../core/04-state-recovery.md)定位；不要把当前对话摘要当作长篇完整记忆。

## 先辨认作品怎样持续

| 作品形态或症状 | 要回答的问题 | 可成立的选择与边界 |
|---|---|---|
| 有限长片 | 本次体验因何开始、如何积累，到哪里可以结束 | 收束可以是行动完成、关系重组或认识改变，不必解决世界全部问题 |
| 连续剧 | 本集完成什么，全季仍在承受什么后果 | 集尾可以改变问题；不要求每集都靠新谜团或悬崖维持 |
| 单元剧 | 稳定机制怎样进入不同处境 | 局部复位可成立，但不能抹掉已建立的事实与人物知识 |
| 群像与多线 | 谁的选择影响另一条线，观众从何建立关联 | 交汇可由行动、资源、时间或主题对照形成，不必人人见面 |
| 生活流、散文、循环结构 | 重复中观众累积了何种认识与时间经验 | 不强行改写为单线升级；检查重复是否有感知差异 |
| 前传 | 既有终点怎样约束本次起点与转变 | 保留前作事实；新增解释不能抹掉已知经历来方便反转 |

写出戏剧引擎：持续压力、人物可采取的不同选择、选择的代价、资源与世界规则、不能轻易复位的变化。用不同处境试推它：压力减弱、人物得到想要的东西、关系中的强弱位置交换后，还能产生有价值的后果吗？若只剩临时反派、失忆或新秘密，先改引擎；不靠增加集数掩盖问题。

人物弧不等于统一的改善曲线。成长、退步、悲剧、保持原则、迟迟不变或带动他人改变都可成立。区分外部任务、内部认识和关系位置；只有与故事行动有关时才补前史，不为所有配角编造创伤。

## 从全篇到场景，按因果建立骨架

1. 用完整短述写出当前理解的开端、关键选择、代价与收束。终局未决就写明分支及前文差异，不宣称结构完成。
2. 把故事分成有作用的段落：每段进入什么问题、经历什么、离开什么状态。段落长度在已确认交付时长内依体验需要安排，不按固定比例套转折。
3. 给主线与副线分别写持续问题和变化节点。副线可以扩大主题或改变观看主线的角度；它不必每次都物理介入主线，但要说明占据篇幅的价值。
4. 连续剧建立季与集的分工，回读Project已确认格式约束及其来源：目标集长、片头片尾/字幕等固定占用与计入方式，先算正文可用时长，再分配段落。规划数是待读演/预演/剪辑核回的时长，不把结构表称为实际片长。每集有局部经验与全季作用；查看相邻集是否连续提出同一问题却无后果。格式没有规定钩子或悬念时，可平静起止，不擅加固定反转频率。
5. 形成场景索引，把每场独有功能、前置事实与离开状态连起来。正文写作进入[场景写作](03-scene-writing.md)，不要在总纲里穷举每一镜。

对因果线做反向检查：结局依赖什么此前选择、能力、事实或关系？这些是否已被观众经历，还是只存在人物设定页上？巧合可以启动或扰动故事；若关键解决完全依靠临时新增规则，需要更早建立依据或接受其作为明确形式选择的代价。

## 故事日期、知情与承诺要能查到出处

事件发生顺序与观众看到的顺序分开保存。故事日期可用明确日期，也可用有锚点的“停业前一晚／次日”，但不能用集号冒充时间。闪回、平行时段和不可靠叙事另记观众此时看见哪个版本。未知日期注明对伤势、服装、关系和信息判断的影响。

维护与关键决定有关的知识账，不追踪无关琐事：谁亲眼看到、谁听谁说、何时推断、何时误信，以及观众知道什么。听到信息、相信信息、愿意承认信息是不同状态。人物可以撒谎；账中保存真实知情与对外说法的区别。

下表是可读工件示例，属于原创纸面开发，没有生成或真人排练证据：

| 故事时点／关联场 | 经历或信息来源 | 林岚所知与误信 | 林舟所知与误信 | 观众所知 | 行为或关系后果 |
|---|---|---|---|---|---|
| 停业前一晚，修理店交钥匙场 | 林舟把钥匙放下，明确赶车 | 误以为弟弟要结束全部责任 | 知道自己想离开，尚不知道账本难认 | 看见离开压力，不知道后续决定 | 邀请必须在卸包之前，才能构成选择 |
| 同晚，邀请之后 | 林岚把账本转向空椅 | 知道自己已经提出有限请求 | 听见请求，选择帮认账字 | 看见他在离开与留下间选择 | 共同做一项事；不能据此推断全然和解 |
| 次日，尚待发展的场 | 待写，不编造发生事实 | 依据前场更新 | 离城计划是否改变仍未决 | 仍可保有疑问 | 后续不能直接宣布他承诺永久留下 |

伏笔与承诺记录“首次给予观众的线索、当时可推知什么、后续如何改变理解、在哪个范围回收”。谜底、情感承诺和世界规则承诺分开判断。回收可以重新解释或有意悬置；悬置须符合全片体验，不能只因为忘记处理。回读确切场版本后再判断遗漏，不靠记忆宣布闭环。

## 可浏览交付与长篇工作窗口

交付可以由以下相互链接的短文和表组成，已有内容直接引用：

- 全片／季梗概：人物处境、引擎、主要选择与后果、终局或开放问题。
- 人物与关系阶段图：经历 → 所知或误信 → 选择 → 行为／关系后果；注明哪些人物保持稳定。
- 季／分集或长片段落索引：本段功能、主副线推进、进入／离开状态、关键承诺、待写场景；附已确认格式、正文时间预算和未实测的时长估计。
- 故事时间与知情账、伏笔承诺账：只保留有实际后果的条目，链接相关集／场版本。
- 当前写作窗口：本轮场景、必须回读的上游与后续约束、可自由探索处、未决事项。

呈现先给最影响作品的判断，再给可展开的索引。长篇按集／场装载；变更牵涉跨集知识或状态时再读取相关节点，而非每轮把整季镜头表塞入上下文。

## 检查与返修入口

| 问题 | 先查什么 | 返修范围 |
|---|---|---|
| 中段无力 | 人物行动是否改变条件，下一段是否仍有选择 | 改压力、关系或后果；不要先加反转频率 |
| 突然知道、突然会做 | 信息来源、经历与能力铺垫 | 补必要经历或调整行为，核对受影响场 |
| 结尾情感来得太快 | 观众是否经历关系转变，代价是否兑现 | 回到关键选择链，再改结尾对白 |
| 每集像重新开始 | 事件后果、知识与实物状态是否落地 | 检查集间衔接和不可复位变化 |
| 多线只靠巧合交汇 | 行动、资源或观看关系是否早已建立 | 重排连接或保留有说明的并置形式 |
| 剧本成立但样片失效 | 关键行动、反应和覆盖是否实现 | 进入[表演设计](04-directing-performance.md)、[摄影覆盖](../visual/02-cinematography-coverage.md)或[问题返修](../quality/02-repair.md) |

用户要求“全季原有左脸疤改右脸”与“第四集故事中新添右脸伤”是不同生效范围。剧情事实、外观、知识或结局变化统一交[变更影响](../core/05-change-impact.md)扫描实际引用；本模块提供故事日期、人物节点及承诺影响，不自行宣判全部素材作废。资产状态由[资产规划](../assets/01-asset-planning.md)落实，六层接续见[连续性与接缝](../visual/04-continuity-seams.md)。
