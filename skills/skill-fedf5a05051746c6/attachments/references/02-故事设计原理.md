# 故事设计原理

> 来源：《故事：材质、结构、风格和银幕剧作的原理》罗伯特·麦基

## 核心原则

1. **论述的是原理，而不是规则**——原理是"这种方式有效且经过时间验证"
2. **论述的是永恒、普遍的形式，而不是公式**——故事设计丰富多样
3. **论述的是原始模型，而不是陈规俗套**——挖掘普遍性人生体验
4. **论述的是一丝不苟，而不是旁门捷径**
5. **论述的是写作的现实，而不是写作的秘诀**
6. **论述的是如何精通这门艺术，而不是如何揣摩市场**
7. **论述的是对观众的尊重，不是对观众的鄙薄**
8. **论述的是独创，而不是复制**

## 故事价值

- 故事价值是人类经验的普遍特征，可从正面转化为负面
- 例：生/死、爱/恨、自由/奴役、真理/谎言、勇猛/懦弱、忠诚/背叛、希望/绝望

## 结构层次

### 节拍（Beat）

- 最小的结构成分
- 动作/反应中一种行为的交替
- 通过节拍构筑场景的转折

### 场景（Scene）

- 在某一相对连续的时空中，通过冲突表现出的动作
- 至少在一个价值层面上，使人物生活情境发生转折
- **没有不含转折的场景**——如果价值未变化，则是"非事件"，应删除

### 序列（Sequence）

- 一系列场景（2-5个），冲击力递增，直至到达顶峰
- 序列终结场景必须实施比单场更强有力的改变

### 幕（Act）

- 一系列序列的组合，以高潮场景为顶点
- 导致价值的重大转折

### 故事（Story）

- 一系列幕的组合，渐次构成最后的幕高潮（故事高潮）
- 引发出**绝对而不可逆转**的变化

## 故事三角

```
          大情节（经典设计）
              △
             / \
            /   \
           /     \
          /       \
  小情节 ←---------→ 反情节
(最小主义)     (反结构)
```

### 大情节特征

- 闭合式结局、外在冲突、单一主人公、主动主人公、线性时间、因果关系、连贯现实

### 小情节特征

- 开放式结局、内在冲突、多重主人公、被动主人公、对大情节的精炼浓缩

### 反情节特征

- 非线性时间、巧合取代因果、非连贯现实、否认传统形式

### 核心洞见

- 经典设计是人类思维的镜像存在
- 大情节属于整个人类，既非东方亦非西方
- 作家必须精通经典形式，才能有意义地突破它

## 激励事件

- 彻底打破主人公生活中各种力量的平衡
- 必须发生在银幕上
- 创造需求，推动主人公行动

## 幕设计

### 进展纠葛

- 冲突必须不断升级
- 不能重复——每个场景都必须比前一个更有力
- 从内在→个人→个人外的螺旋升级

### 危机、高潮和结局

- **危机** = 危险 + 机会，主人公面对最困难的选择
- **高潮** = 故事最强点，人物生活中最大价值的逆转，必须绝对不可逆转
- **结局** = 高潮后的余波，不能拖沓

## 反面人物塑造原理

- 主人公和反面人物互为镜像
- 反面人物越强大，主人公越伟大
- 反面力量不一定是"坏人"

## 解说原则

- **展示，不要告知**
- 将解说戏剧化：在冲突中自然揭示
- 解说越晚给越好

## 文本技巧

### 对白

- 是压缩和省略的艺术
- 功能：推进动作或揭示人物，两者都不做的对白删掉

### 描写

- 只写镜头能看到的东西
- 现在时态、简洁、视觉化
