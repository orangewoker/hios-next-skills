# 镜头语言与摄影机运动

## 镜头契约

每个专业镜头都应声明：

| 字段 | 决策 |
|---|---|
| 景别 | 大远景/远景/中远景/中景/中近景/近景/特写/微距 |
| 角度 | 平视/低角度/高角度/俯拍/侧视/过肩/插入/产品四分之三 |
| 镜头质感 | 广角空间张力/35mm 自然透视/50mm 人像压缩/85mm 浅景深/微距材质 |
| 支撑方式 | 固定机位/手持/滑块/推车/摇臂/无人机/稳定器/虚拟产品台 |
| 运动 | 推/拉/横向跟拍/环绕/摇/俯仰/升降/摇臂上升/揭示/变焦对焦 |
| 主体关系 | 跟随、引导、发现、保持、观察、遮挡 |
| 起始帧 | 首个可辨识构图 |
| 结束帧 | 改变后的状态、揭示、产品主视觉或连续性交接 |
| 脆弱锚点 | 人脸、手、logo、文字、产品形状、服装、道具位置 |

## 提示词范式

```text
Shot: [景别/角度/镜头质感]。摄影机从 [构图] 开始，[单个运镜] 以 [速度] 进行，同时 [主体动作]，结束于 [清晰端点]。保留 [脆弱锚点]。
```

## 运动选择指南

- **固定机位**：口型同步、产品识别、文字、logo、精确 VFX、连续性锚点。
- **推近**：发现、醒悟、亲密感、产品揭示。
- **横向跟拍**：行进、队列、编舞、前景层掠过。
- **环绕**：产品主视觉与雕塑感主体；若身份只能单角度稳定则避免。
- **摇臂/无人机**：规模、出场、地理、揭示；避免用于对白或微小文字。
- **手持**：写实感或紧张感；当身份重要时保持运动克制。
- **变焦对焦**：两个锚定物体间注意力转移；避免与复杂运动叠加。

## 景别用法

| 景别 | 用于 | 注意事项 |
|---|---|---|
| 大远景 | 规模、出场、环境 | 远处人脸/logo 会漂移 |
| 远景 | 场面调度、舞蹈、运动 | 保持动作简单可辨识 |
| 中景 | 对白、产品使用、交接 | 角色广告常用默认 |
| 近景 | 情绪、质感、口型、产品细节 | 保持摄影机稳定、动作微小 |
| 微距 | 材质、食物、珠宝、机械 | 避免大幅运动与文字重绘 |

## 镜头锚点

仅在改善调度时使用：
- `24mm wide lens for spatial energy`
- `35mm natural street perspective`
- `50mm portrait compression`
- `85mm shallow close-up`
- `macro lens for material detail`

## 冲突规则

如果用户给出几个互不兼容的运动，选择一个主要镜头运动，其余归入可选变体。如果镜头需要多个节拍，建议拆分为独立片段或时间分段提示词。

## 序列状态

选择运动前，先继承：
- 已观察到的镜头阶段
- 屏幕方向
- 当前片段范围
- 连续性锁定
- 精确参考标签
- 预留后续节拍

续接镜头短语必须从已接受的源帧或观察到的结束状态开始。
