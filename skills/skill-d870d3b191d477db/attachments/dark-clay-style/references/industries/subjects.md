# 题材词库：人物角色 / 怪物生物 / 食物静物 / 场景建筑

这些是**可适配的模式与句式**，按场景改写，不要逐字照搬。

## 人物角色（黏土人偶）

- 造型取向三选一：大头小身（可怜又诡异）、细长扭曲（梦魇感）、被压扁的矮胖（笨拙荒诞）
- 面部细节：浑浊玻璃珠眼、不对称表情、被捏歪的鼻梁、过薄或过厚的嘴唇
- 服装：布料也做成黏土质感，衣褶像被手指捏出的压痕；纽扣是嵌进去的小圆珠
- 经典场景搭配：独坐昏暗房间、照镜但镜中形变不同、与"正常物件"并排出现

## 怪物生物

- 由熟悉生物扭曲而来（猫、乌鸦、昆虫），保留可辨识的特征锚点，其余部位形变
- 多余或缺失的器官用"被补捏上去/被抹掉"的手工感描述，而非 CG 怪物感
- 体型描述给参照：与画面里一枚硬币/火柴的比例关系

## 食物静物

- 食物仍保留可辨识形态，但表面是黏土质感：哑光、指纹、工具痕
- 腐坏暗示用色彩与形变表达（毒绿斑点、软塌下坠），不用腐烂写实质感
- 擅长表达"诱人与不安并存"：精致的蛋糕上一处正在融化

## 场景建筑

- 房屋像被 giant 手指捏出的：墙面向一侧倾斜、门窗开在错误位置
- 室内场景保持"定格动画布景感"：舞台化的单一空间、背景是绘制或布料质感
- 光源具体化：一扇小窗的灰蓝月光、桌上孤灯、壁炉余烬

## 落 prompt 前自检

- 题材是否已选定上述一类并套用其细节词？
- 形变是否写到了具体部位？
- 是否保留了可辨识锚点（观者能认出"这是什么"）？
