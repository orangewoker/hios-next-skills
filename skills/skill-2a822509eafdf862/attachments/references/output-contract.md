# 输出约定

## 目录

尽量整理为：

```text
project/
  backgrounds/
  transitions/
  subtitles/
  cards/
  illustrations/
  motion/
  manifest/
```

LibTV 返回文件无法自动判断类别时，先保留下载顺序，再根据内容分类，不根据扩展名猜测用途。

## Manifest

记录每个元素：

- 文件名或结果 URL；
- 元素类别；
- 对应的口播原句或段落；
- 章节顺序；
- 真实时间码（仅在输入含时间轴时）；
- 屏幕区域；
- 是否包含最终文字；
- 若为无字底板，应叠加的准确文案；
- 需要注意的安全区。

Manifest 可以是 Markdown 或 JSON。优先保证可读性，不为满足格式而添加虚假字段。

## 最终反馈

用简短自然语言告诉用户：

- 已生成的类别；
- 本地文件入口；
- LibTV 项目画布；
- 是否存在需要在剪辑软件中叠加的准确文字。

不要把内部风格分析、全部提示词或轮询日志当作主要交付。
