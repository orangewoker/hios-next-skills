# 示例｜Shot003 钟高速闯入挡刀｜Minimum 4s版

## 双时长
- Edit Duration：1.0–1.5秒
- Generation Duration：5秒
- Edit Target：约1.85–3.25秒

## 参考素材规则
- 动作参考视频：至少4秒，必须包含“冲入前准备 + 格挡 + 格挡后受力”
- Camera参考视频：至少4秒，必须包含“向下跟武器 + 碰撞换向 + 稳定”
- Previs：5秒

## 5秒Previs时间轴
- 0.00–1.20：Head Handle，AI举刀，Camera进入向下运动
- 1.20–1.85：AI高速下劈
- 1.85–2.45：钟高速切入
- 2.45–2.55：Pre-Impact
- 2.55：Impact Frame
- 2.55–3.25：碰撞与反作用力
- 3.25–5.00：Tail Handle，AI武器弹开，Camera换向并稳定

## 视频Prompt
严格参考钟、女孩、AI守卫、地表废墟、Shot003三关键帧与5秒Previs；动作参考与Camera参考均使用不少于4秒的完整上下文。

Generation Duration：5秒。
Edit Target：1.85–3.25秒。

0.00–1.20秒：AI守卫高举重型武器，女孩处于危险位置，钟仍在画外左侧；摄影机轻微跟随武器建立向下运动趋势。
1.20–1.85秒：AI武器高速下劈。
1.85–2.45秒：钟从左侧高速切入女孩与AI之间。
2.45–2.55秒：接触前极短降速。
2.55秒：赤兔刀与AI武器发生1–2帧Impact Frame。
2.55–3.25秒：猛烈碰撞，钟肩膀下沉、双脚向后滑动约30厘米，AI机械手臂被反弹，火花沿切线喷射，尘土向外推出。
3.25–5.00秒：AI武器继续被弹开，钟挡在女孩前方，Camera沿赤兔刀方向完成换轴并稳定到钟侧脸；烟尘与火花继续自然衰减。

禁止把核心动作压缩成不足4秒的视频；禁止钟完全不受力；禁止Tail Handle缺失。
