# 视频制作强制关卡

本文件适用于所有以视频为最终产物的任务，优先级高于“直接交付成品”“减少询问”“用户让 Agent 决定”等通用规则。严格按状态顺序推进，不得合并、倒置、预先授权或跨级执行。

## 总规则

- 每轮开始时，从当前对话中寻找已经完成关卡的明确证据，并停留在最早尚未完成的关卡。
- 只有用户在看到当前阶段的实际产物后作出的明确确认才有效。用户在前期说“全部继续”“一次做完”“你来决定”“直接生成视频”，均不能预先替代尚未发生的确认。
- “好的”“可以”等回复仅确认 Agent 上一条消息中唯一、明确提出的事项；如果上一条同时提出多个事项，不得把一次回复解释为多个关卡均已通过。
- 用户请求跳过任何关卡时，简要说明此视频流程必须逐阶段确认，并从当前最早未完成的关卡继续。
- 每次修改都会使该阶段旧版本的确认失效。只有最新版本得到确认，才能进入下一阶段。
- 在文字分镜最终确认前禁止生成分镜画面；在全部分镜画面最终确认且用户随后同意生成视频前，禁止生成任何视频。

## 状态 A：基础创意讨论

与用户沟通并形成《视频基础创意方案》，至少包含：

- 视频类型、目标、受众、平台、画幅和总时长。
- 一句话核心创意或故事命题。
- 视频结构与每一段的功能、预计时长和因果关系。
- 叙事视角、人物或产品驱动力、关键冲突/问题、转折和结尾落点。
- 视觉风格、厚涂表现方向、色彩与光线基调。
- 氛围、情绪曲线、节奏、音乐和声音方向。
- 主导与辅助镜头策略、景别曲线、运镜曲线、空间轴线、主要衔接系统和AI视频运动复杂度预算。
- 需要锁定的角色、产品、场景与禁止改变项。

让用户修改，直到用户在看到当前版本后明确同意进入文字分镜头脚本阶段。记录：`关卡A已通过：用户确认当前基础创意方案并同意进入文字分镜`。

**状态 A 允许：** 提问、分析、提出和修改创意、完成必要角色/产品/场景前期锚定。

**状态 A 禁止：** 输出正式文字分镜、生成分镜图片、生成视频。

## 状态 B：文字版分镜头脚本

只有关卡 A 已通过，才按照 `storyboard-script.md` 制作完整文字版分镜头脚本。脚本必须先作为可修改版本交付，不得在同一轮生成分镜图片或视频。

持续接收用户意见并修改。每次更新版本号，重新检查剧情因果、镜头总时长、轴线、人物方向、景别曲线、运镜曲线、相邻镜头衔接、角色/产品/场景连续性。直到用户明确确认最新文字分镜为最终版，记录：`关卡B已通过：用户确认文字版分镜头脚本最终版`。

关卡 B 通过后，必须单独询问：`文字版分镜头脚本已确认，是否同意现在按照这些镜号生成分镜画面？`

即使用户在确认脚本的同一条消息中同时要求生图，也先提出上述询问并等待下一次用户回复。用户随后明确同意后，记录：`关卡C已通过：用户同意生成分镜画面`。

**状态 B 允许：** 编写和修改文字分镜、解释镜头设计、请求脚本确认、询问是否生成分镜画面。

**状态 B 禁止：** 在关卡 C 通过前调用任何图片或视频生成能力。

## 状态 C：分镜画面生成与调整

只有关卡 C 已通过，才生成分镜画面：

1. 按最终文字分镜的镜号逐一生成，每个镜号对应一张代表性分镜画面；未经用户另行要求，不增减镜头数量。
2. 图片编号必须与文字分镜镜号一一对应，不得漏镜、并镜、换序或擅自新增画面。
3. 每张图复用已确认的角色、产品、场景、轴线侧、构图方向、景别曲线作用、时间、光线、色彩和状态锚点。
4. 全部分镜图生成后，汇总镜号与图片对应关系，并明确询问用户是否满意、哪些镜头需要调整。
5. 用户提出修改时，只重做受影响镜头，同时复查其与前后镜头的景别、方向、动作、构图、光线、视觉母题和连续性。

持续修改，直到用户明确确认最新版本的全部分镜图片均无问题，记录：`关卡D1已通过：用户确认全部分镜画面最终版`。

全部图片确认后仍不得生成视频。必须单独询问：`全部分镜画面已确认，是否同意现在进入视频生成？`

即使用户在确认全部图片的同一条消息中同时要求生成视频，也先提出上述询问并等待下一次用户回复。用户随后明确同意后，记录：`关卡D2已通过：用户明确同意生成视频`。

**状态 C 允许：** 按镜号生成分镜图片、修改指定图片、请求全部图片确认、询问是否生成视频。

**状态 C 禁止：** 在关卡 D1 与 D2 均通过前调用任何视频生成能力。

## 状态 D：视频生成

只有以下五项同时成立才能生成视频：

- 关卡 A：当前基础创意方案已确认。
- 关卡 B：当前文字分镜头脚本最终版已确认。
- 关卡 C：用户在脚本确认后，明确同意生成分镜画面。
- 关卡 D1：与脚本镜号一一对应的全部分镜画面已确认。
- 关卡 D2：用户在图片确认后，明确同意进入视频生成。

生成视频时严格使用已确认的文字分镜与分镜画面，执行已经批准的景别曲线、运镜曲线、运动方向、镜头衔接与声音主线；不擅自更换镜头、角色、产品、场景、剧情、构图方向或整体风格。平台能力不足时说明限制并停留在当前阶段，不能用默认固定镜头或未获确认的替代方案继续。

## 回退规则

- 修改基础创意：关卡 A 及后续确认全部失效，返回状态 A。
- 修改文字分镜：关卡 B、C、D1、D2 失效，返回状态 B。
- 修改任一分镜画面：关卡 D1、D2 失效，返回状态 C。
- 视频生成后要求改变剧情、镜头或关键画面：回到对应最早受影响阶段重新确认，不直接在未更新上游资产的情况下重做视频。
