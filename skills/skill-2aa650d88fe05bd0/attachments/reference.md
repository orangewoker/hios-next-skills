# 视觉基因参考

使用本参考资料做出具体视觉决策。只选择能够支持用户当前场景的特征，不要机械叠加全部内容。

## 1. 用户参考强度与优先级

先根据用户的措辞判断参考图或提示词属于强参考还是弱参考。不能只因为用户提供了参考就自动判定为强参考。

- **强参考：** 用户明确要求“严格按照”“直接迁移”“以此为准”“必须保持”“尽量一致”或表达同等强度的绝对意图。在传统动画手绘厚涂的大方向内，优先向用户参考靠拢。提取并锁定参考中的配色关系、造型比例、构图倾向、光线、笔触尺度、边缘处理和完成度；这些具体特征优先于本文件的默认选择，但不得滑向照片级写实、光滑三维或其它与手绘厚涂根基冲突的表现。
- **弱参考：** 用户使用“可以适当参考”“有点类似”“和……差不多”“带一点……的感觉”或同等模糊措辞。此时以本技能的视觉规范为主，只吸收与叙事厚涂体系兼容的局部特征，不让参考改变整体的低饱和冷暖关系、大色块塑形、自然笔触、选择性边缘和空气透视。

无论参考强弱，都保留用户指定的人物、产品、故事、时代和必要内容。参考中的具体题材与物件只有在用户明确要求时才迁移。

## 2. 叙事优先级

围绕一个明确的情绪瞬间组织画面，例如接近、离开、发现、对峙、失去、坚持、沉默或突然变化。让动作姿态、人物间距、尺度对比、天气和环境痕迹承担叙事。避免中性摆拍，以及没有叙事功能的装饰性风景。

## 3. 构图语法

- **环境大全景：** 让人物在主导性的环境中保持较小比例。使用负空间、倾斜地势、层叠剪影或远处路径表达尺度、孤独和命运感。
- **关系中景：** 把人物和关键物体组织为同一组清晰的大形。通过遮挡、身体朝向、视线和不对称关系，暗示刚刚发生或即将发生的事情。
- **情绪近景：** 大胆裁切，让面部、手部或人物距离主导画面，同时把背景处理成宽阔、概括的抽象笔触色块。
- **焦点层级：** 设置一个主要焦点，最多保留一个辅助焦点。降低其他区域的对比、边缘清晰度、细节和饱和度。
- **空间深度：** 通过遮挡、明度压缩、色温变化、雾气与细节递减，区分前景、中景和背景。

## 4. 色彩与光线

从范围狭窄的低饱和色系开始，例如蓝灰、石板灰、烟灰、暗淡土色、橄榄色或风化后的中性色。根据场景选择以下一种色彩结构：

- 以冷色氛围为主，只使用少量琥珀色、铁锈色、肤色、灯光或火光作为暖色点缀。
- 以前景中克制的土色和橄榄色，对比更冷的远景层次。
- 使用近乎单色的寒冷环境，只保留有限的肤色或材质暖色。

高光应宽阔并保留绘画感，不要呈现金属式或摄影式高光。避免在大面积区域使用纯黑或纯白。让最强的冷暖对比标记故事焦点。

## 5. 形体、边缘与表面

- 把人物、地形、云层、建筑和道具构造成相互咬合、由平面走向体积的绘画色块。
- 先用两到三个主要明度面暗示体积，再增加少量细节。
- 使用干刷划痕、薄擦颜料、拖拽笔触、擦抹过渡、断裂笔触，以及轻微的纸张或画布纹理。
- 混合使用硬边、软边和消失边。焦点区域的边缘稍清晰，外围形体可以互相融合。
- 把面部和人体结构概括成有表现力的块面；避免毛孔、睫毛、织物微观纹理和抛光式渲染。
- 保留部分明显未完全收束的区域，使画面呈现人工创作感，而不是机器式平滑感。

## 6. 细节预算

只在细节能够提高故事可读性时使用它。优先刻画面部朝向、手部、剪影、服装大形、关键道具、地形转折、天气动势，以及脚印、烟雾、散落物或反射光等痕迹。把重复的背景元素概括成节奏和群组。

## 7. 动态与视频关键帧

制作视频或分镜关键帧时，在不同镜头之间保持相同的色彩体系和笔触语言。可以改变景别，但应保持光线方向、空气密度、焦点色彩和边缘层级连续。用清晰剪影和宽阔的方向性力量描述运动，避免依赖微小细节才能读懂的动作。

## 8. 提示词组装顺序

按照以下顺序组装生成提示词：

`叙事主体与动作 + 具体环境与故事时刻 + 景别与构图 + 焦点层级与空间深度 + 克制配色与冷暖设计 + 大色块塑形与弱线稿 + 自然笔触与颜料肌理 + 柔和且有选择的边缘 + 空气透视 + 粗粝、未过度抛光的绘本与概念艺术质感`

随后添加简洁的排除项：

`不要照片级写实，不要光滑三维渲染，不要商业角色立绘，不要干净矢量或赛璐璐式描边，不要霓虹高饱和配色，不要全画面同等锐利，不要超精细纹理，不要美颜修饰，不要无菌式数字光滑感`

## 9. 风格偏移诊断

- 如果画面像照片，减少光学细节、皮肤写实、镜头效果和全局锐度，重新使用更大的明度色块与可见笔触塑形。
- 如果画面像商业角色立绘，减少居中英雄式摆拍、服装装饰、轮廓光和精修程度，恢复环境叙事与不对称构图。
- 如果画面显得扁平或过于卡通整洁，弱化描边、增加边缘变化、空气层次和颜料叠层。
- 如果画面显得浑浊，简化色彩范围，分离主要明度组，并只保留一个受控的对比色温作为焦点。
- 如果画面只有泛泛的“艺术感”，不要继续堆叠形容词；应明确叙事瞬间、景别、焦点层级、边缘计划和细节预算。
