# Restrained technology-launch copy cadence

Create an immediately recognizable premium technology-launch rhythm without copying Apple slogans, model names, typography, or campaign lockups. Treat the user’s examples as mechanisms to transform, not phrases to reproduce.

## Signature

- **Short:** usually 2–10 Chinese characters per card; one thought per line.
- **Paused:** one deliberate comma can create a hinge; do not comma-splice every line.
- **Certain:** state the conclusion first; explain only with visible proof.
- **Understated:** prefer a calm period to an exclamation mark.
- **Progressive:** verdict → proof → experience → name.
- **Product-first:** remove “我们” unless the film is a true brand manifesto.
- **Original:** preserve the rhythm, replace the wording, hierarchy, and brand codes.

## Copy ladder

Use 3–5 cards for a 10–20 second film:

1. **Verdict:** `更近。` / `更清楚。` / `这一刻，放大。`
2. **Proof:** name the visible feature or action.
3. **Turn:** translate proof into a supported experience.
4. **Name:** product name or real model family.
5. **Memory:** one original closing sentence.

Do not force all five cards when the film is short.

## Cadence families

### C01 — Renewal without “重新定义”

Mechanism: establish the familiar category, then show a new way it behaves.

- `让[品类/动作]，换一种方式发生。`
- `[熟悉事物]。现在，以[新证据]呈现。`
- `从这一刻，[品类体验]有了新的尺度。`

Use only when the brief contains a genuinely new or distinct feature. Avoid unqualified “颠覆、革命、重新定义.”

### C02 — Iteration without repetitive “再一次”

Mechanism: signal continuity, then name the concrete improvement.

- `这一次，[证据]更进一步。`
- `熟悉的[产品]。新的[真实变化]。`
- `向前一步。[体验]少一步。`
- `又近了一点。也[体验变化]了一点。`

Do not claim improvement when there is no comparison basis.

### C03 — Contrast turn

Mechanism: visible property first, experience second.

- `岂止于[可见属性]，更在于[真实体验]。`
- `不只[属性]。[体验]也随之而来。`
- `[属性]，是第一眼。[体验]，是下一秒。`
- `看得见[事实]。感受得到[体验]。`

Keep the second clause evidence-bound.

### C04 — Single-focus inversion

Mechanism: narrow many possibilities to one decisive point without copying “唯一的……是……”.

- `真正需要被看见的，是[核心证据]。`
- `留下的，只有[体验/产品]。`
- `所有变化，指向同一件事：[核心体验]。`
- `重要的，从来只有[用户价值]。`

Use “唯一” only when exclusivity is factually supportable.

### C05 — Sensory detonation, restrained

Mechanism: build from a small physical event to a larger sensory result.

- `[微观动作]发生。[感官结果]抵达。`
- `先是[声音/光/气泡]。然后，[体验]。`
- `[细节]被唤醒。[感受]随之展开。`
- `一瞬。[感官结果]全开。`

Avoid “引爆感官” when the visual and sound design do not earn it.

### C06 — Deliberate simplification

Mechanism: show a removed step or cleaner action instead of announcing “简化.”

- `少一步。更直接。`
- `把[复杂动作]，留给一次[简单动作]。`
- `省去[真实步骤]。留下[体验]。`
- `[动作]，就这么简单。`

Do not claim fewer steps unless the workflow proves it.

### C07 — Model/name reveal

Mechanism: let the product family land as the conclusion.

```text
[品牌或系列]
[真实型号A]   [真实型号B]
[one original difference line]
```

Use the user’s legal naming system. Do not rename an unrelated product `Pro / Pro Max` merely to evoke iPhone. When hierarchy is missing, propose descriptive original tiers such as `标准版 / 长续航版`, `轻巧版 / 大容量版`, or brand-specific names supported by real differences.

## Transform the user’s example mechanisms

| User-supplied habit | Preserve | Change |
|---|---|---|
| `我们，重新定义……` | manifesto pause + category shift | remove “我们” by default; name the actual new behavior |
| `再一次，简化……` | iteration + reduction | prove the removed step; vary the lead-in |
| `再一次，引爆感官` | escalation into sensation | ground it in a visible/sounded event; avoid the exact phrase |
| `岂止于……` | contrast hinge | use only with two supported clauses |
| `唯一的……是……` | single-focus reveal | avoid unsupported exclusivity; use narrowing rather than “唯一” |
| `Pro / Pro Max` | concise family reveal | use only actual authorized model names; otherwise create original tiers |

## Punctuation and typography direction

- Prefer full stops and line breaks; use at most one dramatic comma per card.
- Use exclamation marks rarely, at a true sensory peak only.
- Keep Chinese copy in post-production for accuracy.
- Use the user’s licensed neutral sans or brand typeface. Do not imitate Apple’s proprietary type or launch layout.
- Keep generous negative space, but derive alignment and scale from the user’s own brand system.

## Generation routine

1. Extract only supported facts and experiences.
2. Write one copy ladder in three different cadence families.
3. Remove generic superlatives and duplicate verbs.
4. Select the family that matches the picture rhythm.
5. Run an originality pass: replace any line that resembles a known campaign, reads like a translation, or depends on Apple model naming.
6. Output the selected ladder, two alternates, and a one-line reason.

## Example — lemon soda

### Selected: C05 sensory ladder

`一颗气泡，上升。`  
`一整口清爽，抵达。`  
`[品牌名]｜清爽柠檬味。`

### Alternate: C03 contrast

`岂止于大，更在于爽。`  
`气泡向上。清爽随之而来。`

### Alternate: C04 single focus

`留下的，只有清爽。`  
`[品牌名]｜清爽柠檬味。`

These examples are original teaching samples. Replace `[品牌名]` and only use claims supported by the product brief.
