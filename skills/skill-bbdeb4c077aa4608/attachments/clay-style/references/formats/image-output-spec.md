# 图片黏土风格输出规范

## 四件套结构

每张黏土风格图片的 prompt 必须包含四件套：

### 1. 构图

| 构图类型 | 适用场景 | 句式 |
|---|---|---|
| 居中特写 | 人物/动物/物品头像 | "居中构图，主体占据画面中心" |
| 全身展示 | 人物/动物全身 | "全身居中构图，从头到脚完整展示" |
| 场景全景 | 场景/风景 | "全景构图，微缩场景全貌展现" |
| 俯拍 | 物品/食物/微缩场景 | "俯拍视角，展现手工模型全貌" |

### 2. 光

| 光照类型 | 效果 | 句式 |
|---|---|---|
| 柔光环境 | 均匀柔光，无明显阴影 | "柔光环境，均匀漫反射，无强烈阴影" |
| 侧柔光 | 轻微立体感 | "侧柔光，轻微阴影增加立体感" |
| 背光轮廓光 | 黏土边缘发光 | "背光轮廓光，黏土边缘柔和发光" |

### 3. 材质

固定要素（每张图必含）：
- "黏土手工质感，表面保留指纹与工具压痕"
- "亚光漫反射光泽，不反光"
- "手工捏制的不完美圆润感，轻微不对称"
- "色彩高饱和但柔和"

### 4. 情绪

固定要素（每张图必含）：
- "呆萌可爱"
- "让人想捏一把的冲动"

## 画幅选择

| 画幅 | 适用 | 备注 |
|---|---|---|
| 1:1 | 头像/物品/通用 | 最常用 |
| 9:16 | 手机竖屏/短视频封面 | 抖音/小红书 |
| 16:9 | 横屏/电脑壁纸 | 宽幅场景 |
| 3:4 | 小红书图文 | 竖版展示 |

## prompt 完整示例

```
黏土手工风格，软糯Q弹质感，表面保留指纹与工具压痕，手工捏制的不完美圆润感，色彩高饱和但柔和。

一只黏土风格的小狗，整体球状圆润体型，四肢短粗，大而圆的眼睛，纽扣状棕色鼻子，拟人化呆萌表情张嘴傻笑，棕色饱和黏土色带白色斑块。尾巴简化为短粗黏土圆柱。

表面保留指纹与工具压痕，亚光漫反射光泽，手工捏制的不完美圆润感，轻微不对称。色彩高饱和但柔和。

居中构图，主体占据画面中心。柔光环境，均匀漫反射，无强烈阴影。

呆萌可爱，让人想捏一把。

画幅 1:1。
```

## 落 prompt 前自检

- [ ] 四件套（构图/光/材质/情绪）是否齐备
- [ ] 材质描述是否包含指纹/压痕/亚光/不完美
- [ ] 情绪是否包含"呆萌可爱"
- [ ] 画幅是否明确
- [ ] 措辞是否全部正向
