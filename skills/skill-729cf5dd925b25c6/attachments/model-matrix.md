# 六风格 × 模型适配表（平面大湿版）

LibTV 聚合 30+ 模型，不同模型对强风格的理解力差异巨大。本表为每个分支指定首选/备选/禁用模型与参考图配方。

**模型自动匹配机制（平面大湿规则）**：模型选择**不询问用户**，由本表按分支自动匹配首选模型；首选失败时自动换备选（重试策略见 libtv-operations.md）；匹配结果在 G9 积分确认时随报价一并汇报。用户如需更换，在 G9 或任意关卡提出即可。

**效果验证**：每个项目开工时，G6 风格样板图即是对首选模型的效果验证，不达标立即换备选，验证结果回填 manifest 供后续项目复用。
