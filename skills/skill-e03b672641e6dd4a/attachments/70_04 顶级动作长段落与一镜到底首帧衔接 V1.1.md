## 70_04 顶级动作长段落与一镜到底首帧衔接 V1.1\
**做什么**

解决动作片长段落生产“顶级在哪说不清、怎么拆不知道、一镜到底首帧接不上”的问题。定义顶级动作长段落的维度升级清单、三套时长方案、子镜拆解规则，以及一镜到底系列的首帧衔接通用规则（从第二关起不生成独立首帧图）。

## **需要什么输入**

- 已确定当前项目的长段落类型（长段落 / 一镜到底系列）。

- 已确定每关时长方案（A / B / C），不得默认。

- 已确定每关子镜数量与首尾帧衔接锚点。

- 需要配合70_00（真实打斗连击防崩铁律）、70_03（单关生产工作流）、70_05（伪一镜到底剪辑与展示）使用。

## **怎么做**

### **一、顶级在哪？（通用维度升级清单）**

**维度标准单关顶级长段落**对手一个敌人宿敌 / 数十人 / 自然环境环境普通场景火场、水下、高空、行驶载具、全黑体能一招制敌打到体力耗尽，靠意志力撑生理极限无浓烟窒息、水下缺氧、高空坠落恐惧心理战弱黑暗盲斗、宿命对决时长6秒30-60秒，或更长镜头数2段（前3+后3）8-15镜，或更多结局敌人瘫倒双方重伤、意志力决胜、可能同归于尽

**一句话：标准单关是“打赢对手”，顶级长段落是“打赢环境+打赢自己”。**

### **二、长段落时长与结构（三方案，用户选定后锁定）**

**方案时长镜头数结构**A40秒8-15镜开场对峙 + 三轮攻防 + 终结技 + 收势B20秒4-6镜开场对峙 + 两轮攻防 + 终结技C12秒3-4镜开场对峙 + 一轮攻防 + 终结技

每关开机前，用户必须明确选定方案A/B/C，不得默认。

### **三、长段落拆解规则**

每关按选定方案拆成子镜后，每个子镜必须标注：

- 子镜编号（如 S01、S02、S03……）

- 时长（3-5秒）

- 镜头信息栏（景别｜镜头运动｜节奏强度）

- 首尾帧衔接锚点（上一子镜末帧 = 下一子镜首帧）

- 情绪过渡帧ID

- 声音衔接点

每个3-5秒子镜，都必须按70_03五步流程执行：场景图 → 6宫图 → 首帧图 → 前3秒 → 后3秒。

### **四、一镜到底首帧衔接通用规则（核心）**

**1. 核心铁律**

一镜到底系列中，**严禁每一关都生成独立首帧图**。

- 第一关（或第一个子镜）可独立生成首帧图，仅此一次。

- 从第二关（或第二个子镜）起，`start_frame` 必须接上一关（或上一子镜）的尾帧截图。

- 从第二关起，每关只有“前3秒 + 后3秒”两段视频，没有独立首帧图。

**2. 标准 start_frame 来源表（通用）**

**步骤start_frame 来源**第1关首帧图独立生成（仅此一次）第1关前3秒第1关首帧图第1关后3秒第1关前3秒尾帧第2关前3秒第1关后3秒尾帧第2关后3秒第2关前3秒尾帧第3关前3秒第2关后3秒尾帧…………第N关后3秒第N关前3秒尾帧

**3. 通用要求**

- 每一段尾帧必须保存为截图，作为下一段 `start_frame`。

- 禁止跳段衔接。

- 禁止重新生成独立首帧图。

- 如果某段尾帧不符合衔接要求，重跑该段，而不是新生成首帧图。

**4. 案例说明**

- 示例：某项目有一镜到底系列 `K01-K08`。

- K01 独立生成首帧图。

- K01 后3秒尾帧 → K02 前3秒 `start_frame`。

- K02 后3秒尾帧 → K03 前3秒 `start_frame`。

- 以此类推，直到 K08 后3秒尾帧。

- 全程不生成 K02-K08 的独立首帧图。

## **产出什么**

1. 顶级长段落维度升级清单。

2. 长段落三方案（A/B/C）。

3. 长段落拆解规则（子镜编号、时长、镜头信息栏、首尾帧衔接锚点、情绪过渡帧ID、声音衔接点）。

4. 一镜到底首帧衔接通用规则（核心铁律、标准start_frame来源表、通用要求、案例说明）。

5. 与70_03、70_05的关系说明。

## **什么时候问你**

1. 当用户未明确选定长段落方案A/B/C时，停下询问，不得默认。

2. 当某段尾帧不符合衔接要求时，停下提醒重跑该段，不新生成首帧图。

3. 其余情况按长段落拆解规则自行推进。
