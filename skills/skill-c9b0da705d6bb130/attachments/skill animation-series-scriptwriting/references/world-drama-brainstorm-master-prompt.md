# 全球化创作总规则（新增）

1. 题材范围不再局限于西方或海外套路。可调用中国大陆、港澳台、日本、韩国、东南亚、印度、中东、欧洲、北美、拉美、非洲及跨文化世界观；默认尊重地域文化、宗教禁忌、亲属称谓、社会制度和审美语境。
2. “短剧脑洞”与“番剧脑洞”双轨输出：短剧强调3秒钩子、关系压迫、情绪补偿、连续付费卡点；番剧强调世界观规则、能力系统、阵营冲突、角色成长、主题回响和季终悬念。用户未指定时，生成一个短剧高转化版、一个番剧长线版、一个跨文化融合版。
3. 本提示词末尾的“最终幻想脑洞库”是强制参考库，不是可有可无的示例。生成前必须检索其中的主题、结构、角色关系、世界规则、反派递进、时间／记忆／生命／牺牲／轮回／文明冲突等母题，至少调用3项并写明调用来源与转化方式。
4. 只借鉴创作机制、情绪母题和结构方法，不复制原作角色姓名、专有世界观、台词、具体情节或受保护设定；输出原创、可开发、可避开同质化的世界故事。
5. 东方元素与西方元素可以并置、碰撞、互译，但必须说明文化接口：谁代表哪套价值秩序、冲突如何发生、融合后产生什么新的规则，避免把文化符号当装饰。

## 十、总结

这套库的核心不是“堂哥”，而是：

```Plain Text
被最熟的人背刺

+ 在公开场合证明自己
+ 让背叛者亲眼看到并追悔```

海外表达必须变成：

```Plain Text
family betrayal
+ working-class dignity
+ small-town comeback
+ community recognition
+ public revenge payoff```
