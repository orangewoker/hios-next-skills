# 商品广告视频生成 Skill - Showcase

## 📌 Skill 名称
商品广告视频生成

## 🎯 一句话简介
上传商品图或输入文字描述，一句话生成可投放的商品广告视频，全流程 Skill 内闭环完成。

## 📝 详细描述
专为电商卖家、品牌方、短视频创作者打造的商品广告视频生成工具。

你只需要：
- 上传一张商品图（或直接描述商品）
- 告诉我投放在哪个平台

剩下的全部由 Skill 自动完成：
✅ 商品三视图生成（锁定外观一致性）
✅ 人物形象确认与三视图（可选，支持上传参考图或AI生成虚拟人物，先确认形象再生成三视图）
✅ 品牌元素配置（Logo/Slogan/片头片尾）
✅ AI 广告剧本生成（基于商品卖点自动编排，内置钩子库+情绪节奏曲线）
✅ 专业分镜设计（行业 10 列标准格式，含转场/衔接/情绪映射）
✅ 场景图生成（逐镜头画面预览，人物+商品一致性保障）
✅ 视频合成（配音+音效+转场）
✅ 广告法合规检查（自动审查，避免违规）

支持快速模式（3步出片）和精细模式（逐环节打磨），适配抖音、小红书、朋友圈、电商平台等主流投放渠道。

## 🎬 适用场景

### 场景一：电商新品上架
> "我刚设计了一款手工陶瓷杯，帮我做一条15秒的抖音广告视频"
→ 上传商品图 → 选择抖音9:16 → 快速模式 → 15秒短视频直出

### 场景二：品牌促销活动
> "年底大促，给我的护肤品套装做一条30秒朋友圈广告"
→ 上传套装产品图 → 朋友圈1:1 → 精细模式 → 逐镜头确认 → 30秒品牌广告

### 场景三：没有商品图也能做
> "帮我做一款智能手表的广告视频，手表是黑色表带银色表盘"
→ 文字描述 → AI生成商品图 → 继续走完流程 → 成品视频

### 场景四：多商品套餐推广
> "我这个礼盒里有3样东西：口红、香水、手链，帮我做个推广视频"
→ 逐个上传/描述3个商品 → 确定主次关系 → 自动分配时长 → 完整套餐广告

## ✨ 核心亮点

### 🔄 双线入口
- 有图传图，没图用文字描述生成
- 两条线路在"确认商品图"节点自动合流

### 🎨 双路线支持
- **实拍质感**：16种实拍风格，从简约极简到高端奢华，从国潮东方到生活方式
- **动画风格**：6种动画子风格——MG动画、3D卡通、2D手绘、定格动画风、赛博科幻、国漫动画
- 选实拍还是动画，后续三视图、场景图、视频全部按路线执行

### ⚡ 两种模式
- **快速模式**：跳过中间确认环节，3步出片（商品图→基础设置→成片）
- **精细模式**：逐环节确认打磨，适合对品质有高要求的创作者

### 🛡️ 双轮合规检查
- 第一轮：分镜完成后自动审查剧本+文案合规性
- 第二轮：成片生成后审查最终画面+配音+文字
- 任何修改后自动重审，确保不踩广告法红线

### 🔧 可编辑工程
- 成片不是终点，可随时回溯到任意阶段修改
- 只重生成受影响的部分，不浪费积分
- 支持多版本派生（同一商品做不同风格/不同渠道版本）

### 📐 画面比例全程一致
- 第二阶段选定投放渠道后，比例贯穿全链路
- 三视图、场景图、视频全部统一比例，不会出现画面裁切

### 👤 人物出镜支持
- 支持上传参考图或 AI 生成虚拟人物
- 人物风格默认继承商品视觉路线，也可自定义
- 人物形象图 + 人物三视图（正面/正侧面/背面）作为全片视觉锚点
- 从设定到场景图到视频，人物形象全程一致

### 📦 素材单独导出
- 不必等到成片，任意阶段完成后可单独导出素材
- 支持导出：商品三视图、人物形象图、人物三视图、场景图、剧本、分镜文档等

## 🎛️ 支持配置项

| 配置项 | 可选值 |
|--------|--------|
| 视觉路线 | 实拍质感（16种风格） / 动画风格（6种子风格） |
| 投放渠道 | 抖音9:16 / 小红书9:16 / 朋友圈1:1 / 电商横屏16:9 / 自定义 |
| 视频时长 | 5秒 / 15秒 / 30秒 / 自定义 |
| 视觉风格 | 按商品品类智能推荐，支持参考图/视频 |
| 转场效果 | 硬切 / 溶解 / 划像 / 缩放 / 无转场 / 混合 |
| 人物出镜 | 否（纯商品展示）/ 是（上传参考图或AI生成虚拟人物） |
| 配音 | 自动匹配剧本类型（对话/旁白/独白），可指定音色 |
| 字幕 | 默认关闭，可选开启并指定语言和样式 |
| BGM | 默认关闭，可选开启 |
| 音效 | 用户自定义 / AI自动匹配 |
| 导出分辨率 | 720P / 1080P（默认）/ 2K / 4K |
| 多语言 | 中文 / 英文 / 其他（配音+字幕） |

## 🚀 快速开始

1. 安装 Skill 后，在 LibTV 对话框输入：
   ```
   帮我做一个商品广告视频
   ```
2. 上传商品图或描述商品信息
3. 选择投放渠道和时长
4. 选择快速/精细模式
5. 等待 Skill 自动完成全流程
6. 预览成片 → 满意则导出，不满意则修改

## 💡 使用建议

- **首次使用**：建议选精细模式，熟悉流程后切快速模式提效
- **源素材质量**：商品图越清晰，最终效果越好；选择2K/4K导出时注意源素材分辨率
- **多版本测试**：同一商品可派生多个版本，测试不同风格在不同平台的投放效果
- **合规优先**：涉及功效宣称、价格对比等敏感内容时，Skill 会自动审查并提醒

## ⚠️ 不适用场景

- 非商品类视频（个人vlog、纪录片、纯艺术创作）
- 需要真人实拍直播类内容（本 Skill 支持 AI 生成虚拟人物出镜，但不支持真人实拍）
- 超长视频（建议60秒以内，超长内容需分段制作）

## 📊 技术参数

- 依赖：LibTV 平台 + LIBTV_ACCESS_KEY
- 支持模型：Seedance 2.0 / Kling 3.0 / Midjourney / Seedream 5.0 等
- 单片段视频时长上限：5-10秒（由模型决定）
- 支持商品数量：单品 / 多商品套餐
