# 单字象形演化（子技能）

> 本技能是 **看图识字教学** 主技能的子技能，由主技能**逐字调用**，通常输入 `单字识字卡生成` 产出的**那张卡**作图像锚点。它只处理**一个字**，产出一段**图像 + 字形演化**的记忆小节。
>
> **核心理念：用图像让孩子记住字，不是教怎么写。** 不做笔画 / 笔顺演示——**AI 生成笔画视频并不好用**（笔画会抖动、顺序易错）。改用**象形/构字来源的图像演化**帮记忆。

## Skill 定位
- 只负责：给**一个字**做一段 **3~6s 的"图像 → 字形演化 → 楷字"记忆小节**——让孩子看见**字是怎么从图画来的**：
  - **象形字**（山、水、日、月、木、竹、雨、鸟、龟…）→ 实物图像逐步简化成字形（山：三座山峰 → 三个尖的字形）。
  - **会意/可图像联想字**（林=两棵树成树林、明=日+月、叶=一片叶子）→ 把**构字的图像理据**可视化（两棵树并排 → "林"）。
- 不负责：笔画/笔顺（**明确不做**）、选字（主技能定）、生识字卡（`单字识字卡生成` 干）、整片拼接（主技能干）。
- 产出**一个可被主技能拼接的记忆小节**。

## 输入
- **必需**：**目标汉字**；通常还有该字的**识字卡 / 图像 node_key**（来自 `单字识字卡生成`）作图像起点。
- **可选（主技能传入）**：小节时长、演化要几个阶段、是否配音、配音音色/语速、字幕、该字读音（多音字取定的音）、风格模板。
- 没依据的规格**不臆造**。

## 输入使用
- **严格遵守**：**用图像演化帮记忆，不出现笔画/笔顺教学**；字形来源要**站得住**（象形/构字理据真实，不编造）；最终**楷字写对、稳定不变形**。
- **只作参考**：图像画法、演化节奏、镜头——在"图像对应 + 字形正确稳定"前提下自由。

## 内部流程和 Knowhow
### 一、字形来源正确（红线一）
- 演化的**图像理据必须真实**：象形字的物象要对（山就是山峰、鸟就是鸟）、会意字的构件要对（林=两个"木"、明=日+月）。**别编造假来源、假古字形**——编错就误导。
- 若要展示古文字阶段（甲骨/金/篆）：**基于可靠字源**，用标准古文字字体/素材，别让模型自由"画"古字；拿不准就**只做"图像 → 楷字"两段**，不硬凑中间形态。
### 二、楷字正确 + 稳定（红线二）
- 最终楷字**标准、写对、清晰**；**AI 视频里字易抖动变形**——**让"变化"发生在图像→字形的演化上，楷字定格后保持稳定**（稳定叠加/锁定，别逐帧重绘）。逐段检查有没有跨帧变形。
### 三、演化小节结构（分镜）
1. **图像**：清晰的实物/场景（一座山 / 两棵并排的树 / 一片叶子），建立"这是什么"。
2. **简化/构成**：图像逐步简化成线条，或构件拼合（两棵树 → 林），点出"字照着图来"。
3. **字形定格**：morph 成标准楷字，居中定格。
- **morph 要顺滑**：用图生视频 / **首尾帧卡演化**（首帧=图像形态、尾帧=字形），变形连续可辨、不跳变。
- **对应关系要看得出**：哪部分图对应字的哪部分（山的三峰对三个尖、林的两树对两个木）——这是记忆钩子。
### 四、配音 / 节奏（适龄）
- 儿童向、放慢、短句领读（"看——山，有三座山峰。古人照着画，就成了'山'字"）。停留够久，可读两遍留跟读间隙。
- 字幕大而简单；字幕/拼音里的字也要写对；多音字取主技能给定的音。
### 五、prompt guide（运行时按实际填，别写死）
- **图像段**：clear illustration/photo of [山/两棵树/叶子], simple, bright, for kids。
- **演化段**：引用 `{{图像NodeKey}}`，说明"图像平滑演化/构件拼合成汉字'X'，对应关系可见，smooth morph, character crisp and stable"；用首/尾帧锁两端。
- **楷字定格**：大号标准楷体 'X'，居中，correct strokes，之后保持静止。
- **配音**：台词原文（领读、放慢、可两遍）。`duration_sec`=小节秒数；`sound` 按需；画幅/分辨率没依据留空。
- **别做的事**：**别做笔画/书写顺序演示**、别编造字源/古字形、别让字逐帧变形、别出错字/错读音。

## 输出
- **一个 3~6s 的象形演化记忆小节**（图像→字形演化→楷字定格，配音/字幕按需），返回**真实 node_key** 交回主技能拼接。
- 附一句说明：本字用了什么图像、做了哪几个演化阶段（是否含古文字）、对应关系是什么。

## 自检
- [ ] 是**图像演化记忆**，**没有**掺入笔画/笔顺教学？
- [ ] **字形来源真实**（象形物象/会意构件对），没编造假字源？
- [ ] 最终**楷字写对、全程稳定不变形**？
- [ ] morph 顺滑、**图与字对应关系看得出**（三峰=三尖、两树=两木）？
- [ ] 配音读音准、节奏适龄；风格贴合主技能模板？

## Ask User
- 一般**不直接问用户**（选字与形态由主技能统一决策）。
- 仅当**该字来源存疑**（只能做简化演化）、**读音存疑**（多音字）、或**难以图像化**时，反馈主技能确认。
