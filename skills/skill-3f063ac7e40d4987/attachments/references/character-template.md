# 角色设定卡模板

> 为「国风动漫宇宙·动画大师」Skill的每个核心角色生成完整的可视化设定卡。

---

## 使用说明

对于故事中的每个核心角色（主角、重要配角、反派），按以下模板逐项填写。模板中的所有标记 `[xxx]` 都必须替换为具体内容。维度越具体，后续AI生成的角色一致性越高。

---

## 角色设定卡模板

```
═══════════════════════════════════
角色名：[中文，2-4字，有古典韵味]
═══════════════════════════════════

身份定位：
[一句话点明角色本质，如"守护昆仑山最后一片雪莲的千年花仙"]

---

【面相】—— 工笔线描五官

- 眉型：[剑眉/柳叶眉/寿眉/火焰眉/一字眉] + 墨色浓淡
  → 示例："剑眉入鬓，浓墨一笔挥就，眉尾锋锐如刃"
- 眼型：[丹凤眼/杏眼/铜铃眼/凤眼/细长眯眼] + 点睛方式
  → 示例："丹凤眼，眼尾锐利上挑15°，焦墨点睛，眼白以淡花青微染"
- 鼻型：[悬胆鼻/琼鼻/狮鼻/鹰钩鼻/无鼻]
  → 示例："悬胆鼻，鼻梁挺秀如远山，侧锋线描"
- 唇型：[方唇/樱桃小口/含笑唇/紧抿唇] + 设色方式
  → 示例："方唇有型，上下唇线以淡墨勾勒，朱砂点染，下唇略厚于上唇"
- 脸型：[国字脸/鹅蛋脸/瓜子脸/甲字脸/圆脸/方脸]
  → 示例："鹅蛋脸，下颌线条流畅柔和，颧骨不突出"
- 面部戏曲元素：[如眉心火焰纹/额间莲花印/眼角金粉/脸颊戏曲纹样]
  → 示例："眉心一点朱砂火焰纹，参照京剧武生勾脸，纹样边缘有金色描边"

---

【妆发】—— 古典发式与饰品

- 发型：[具体古典发式名称 + 造型描述]
  → 示例："高髻凌云髻，发髻高耸于顶，以真发盘绕三层，留一缕垂于颈侧"
- 发饰：[发簪/步摇/花钿/冠冕/抹额] + 材质 + 纹样
  → 示例："金累丝嵌宝蝴蝶步摇一对，蝴蝶翅膀以极细金丝编成，镶嵌红玛瑙，行动时翅膀微颤"
- 发色：[墨黑/银白/霜白/花白/青灰]
  → 中国学派角色以墨黑为主，仙佛可为银白，老者可为花白

---

【服饰】—— 汉服形制

- 上衣：
  → 形制：交领右衽
  → 袖型：[宽袖(袖宽≥30cm)/窄袖(袖口收紧)]
  → 颜色：[从六色系统选择]
  → 纹样：[云纹/水纹/龙凤/缠枝莲/如意纹/无]
  → 示例："石青蓝交领右衽宽袖长袍，袖口绣有银线云纹二方连续"
- 下裳：
  → 形制：[长裙/裳/襦裙/马面裙]
  → 颜色：[从六色系统选择，与上衣有呼应或对比关系]
  → 示例："墨黑长裳，裙摆处有暗纹缠枝莲，行动间若隐若现"
- 腰带：
  → [束腰带颜色] + [玉佩/禁步/无] + [绦带颜色与长度]
  → 示例："琉璃黄束腰丝绦，左侧悬一枚翡翠如意佩，墨黑长绦带垂至膝下"
- 外披：
  → [披帛/大氅/斗篷/无]
  → 示例："宣纸白蝉翼纱披帛，绕臂后自然飘垂，半透明可见内层服饰纹样"
- 面料质感：[丝绸光泽/棉麻肌理/薄纱半透/锦缎厚重]
  → 示例："上衣为重磅丝绸，柔和光泽；披帛为上等蝉翼纱，轻盈半透"

---

【标志性道具】

- [如有标志性道具，描述材质、颜色、造型、特殊效果]
  → 示例："一柄通体翡翠绿的玉笛，长约二尺，笛身刻有缠枝莲纹，吹奏时笛孔有淡淡金色光点飘出"

---

【戏曲化动作风格】

- 核心动作：[动作方式的整体气质描述]
  → 示例："行走时如风拂柳，身姿微倾如斜柳，衣裙曳地无声"
- 亮相方式：[角色如何完成戏曲亮相]
  → 示例："转身180°后静止3拍，水袖自然从手臂滑落垂至地面，再缓缓抬头，眼波流转扫视全场"
- 施法/战斗动作：[如有]
  → 示例："施法时左手兰花指轻旋，右手玉笛横于胸前，周围花瓣随之盘旋升起"
- 情绪表达方式：
  - 喜时：[如"眼波流转如春水，水袖轻扬"]
  - 怒时：[如"水袖猛甩如裂帛，眉眼间剑锋乍现"]
  - 哀时：[如"背身微颤，肩头轻耸，水袖遮面"]
  - 静时：[如"如入定老僧，唯衣袂随风微动"]

---

【性格标签】

- [2-3个核心特质，用间隔号分隔]
  → 示例："清冷 · 慈悲 · 坚韧"

---

【色彩锚点】

- 主色：[角色专属主色调，1-2种六色系统色]
  → 示例："翡翠绿 + 宣纸白"
- 辅色：[辅助搭配色]
  → 示例："石青蓝（点缀）+ 金粉（纹样描边）"
- 禁忌色：[绝对不能出现在该角色身上的颜色]
  → 示例："朱砂红、荧光色系"
```

## 模板填写示例

以下是一个完整填写好的角色设定卡示例：

```
═══════════════════════════════════
角色名：青岚
═══════════════════════════════════

身份定位：
昆仑山青鸾峰上守护千年雪莲的花仙，已修炼九百年，只差最后一朵雪莲绽放即可飞升

【面相】
- 眉型：柳叶眉，淡墨轻扫，眉梢微扬带三分英气
- 眼型：杏眼含秋水，眼尾微垂，以淡花青晕染眼周，焦墨点睛
- 鼻型：琼鼻小巧，正面不见鼻梁，侧锋轻扫一道
- 唇型：樱桃小口不点而朱，胭脂淡染，嘴角天生微扬
- 脸型：鹅蛋脸，下颌弧线流畅
- 面部戏曲元素：眉心一朵六瓣青莲印，花瓣边缘有银粉微光

【妆发】
- 发型：半高髻，上半发丝盘成百合髻，下半披散至腰际
- 发饰：银质莲花簪一支，簪头莲花以月白色玉石雕成，花心嵌一粒碧玺
- 发色：墨黑，发尾在月光下泛幽蓝光泽

【服饰】
- 上衣：翡翠绿交领右衽宽袖长袍，袖口绣银线水波纹
- 下裳：宣纸白长裳，裙摆渐变晕染从白到淡青
- 腰带：石青蓝束腰丝绦，左侧悬一弯月形玉佩
- 外披：蝉翼纱披帛，通体淡青半透明，对光可见云纹暗花
- 面料质感：上衣丝绸光泽，披帛薄纱轻盈

【标志性道具】
左手持一柄青玉如意，如意头雕成莲花形，花心一滴露珠状水晶永恒不干

【戏曲化动作风格】
- 核心动作：行走时如云中漫步，足不沾尘，衣袂不动而风生
- 亮相方式：侧身而立，缓缓转头露出半张脸，先见眉目再见唇，停顿3拍
- 施法动作：双手捧如意于胸前，闭目凝神，如意中露珠渐亮，莲子大小光点环绕周围盘旋
- 情绪表达：
  - 喜时：眼波如水，唇角微扬，披帛无风自动
  - 怒时：柳眉倒竖如剑，水袖一甩破空有声
  - 哀时：背身而立，肩头微颤，披帛缓缓滑落
  - 静时：如莲独立，呼吸间仅见鬓发微动

【性格标签】
清冷 · 慈悲 · 坚韧

【色彩锚点】
- 主色：翡翠绿 + 宣纸白
- 辅色：石青蓝、银白
- 禁忌色：朱砂红、墨黑（大面积）、琉璃黄
```
