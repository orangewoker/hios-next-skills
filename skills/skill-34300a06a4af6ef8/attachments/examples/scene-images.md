# 静态场景资产示例

以下 Midjourney 仅提供提示词正文；按[模型适配](../references/model-adapters.md)的规则确认平台支持后，再另加画幅、版本等设置。

## S01｜宋韵花铺街巷环境底图

### Image

```text
生成一张16:9横幅无人场景照片，宋韵江南街巷中的日常花铺，真实古装影视外景摄影质感。
机位在街道对侧，平视斜看铺面。右侧木铺敞开，屋檐下有低矮木案，几只朴素陶器插着疏密自然的花枝；花量适度，露出案面与木构。铺前留出可供两人站立和走动的完整石地，左侧弯巷向后延伸，沿途灰瓦小屋尺度一致。
薄云下的柔和日光照亮街巷，铺内略暗但可辨，木纹、陶器和石板各有质感。景深足以看清铺面、空地与巷道，远处自然变柔。单张完整画面，无人物、文字、水印和额外黑边。
```

### Banana

```text
输出一张16:9横幅、没有人物的宋韵江南花铺场景图，呈现真实外景摄影效果。
构图以花铺和街巷空间为主体：从街对侧平视斜看，敞开的木铺位于右侧，低木案与陶制花器放在檐下；少量花枝不遮铺面结构。铺前保留连续石板空地，能容纳两人站立、转身和经过；弯曲巷道从左侧通向后方灰瓦民居。
柔和中性日光，檐下保留细节，浅色花朵亮部不过曝。木材、陶器、石板表面自然有别；前中景清楚，远处随距离略柔，空间比例可信。只输出一张图，不加人物、标注、文字、水印或黑边。
```

## S02｜溪边晾绢场所底图

### Image

```text
生成一张16:9横幅无人场景照片，宋韵江南村落溪边的晾绢场所，真实古装影视外景摄影质感。
平视斜看近处竹架，竹架稳立在右侧平整石地上，前方留出站立和整理布料的位置。一幅米白绢布搭在横杆上，两侧自然垂下，厚度、重量与折痕可见，下缘离地。左侧石阶接向浅水渠，渠岸线延伸到后方村屋和相邻田地，各处有真实可走的连接。
薄云过滤的柔和天光，绢布保留细腻织纹，水面轻映天色，湿石与干石有区别。环境景深适中，竹架、石地、渠岸与村屋均可辨。单张完整画面，无人物、文字、水印和额外黑边。
```

### Banana

```text
输出一张16:9横幅无人田园场景图：宋韵江南村落溪边晾绢处，真实自然外景摄影。
从石地边缘平视斜看，竹制晾架位于右侧，架脚全部落在平整石地上，架前留有操作空地。米白绢布搭住横杆，具有厚度和垂坠重量，布面有自然褶皱，下缘悬离地面。左侧石阶临着浅水渠，渠岸与小路通向后方村屋，屋旁接连田地，尺度与通路清楚。
采用柔和中性天光，绢布亮部保留织纹与厚度，水、竹、石和织物各有质感；近中景清晰，背景自然稍柔，保持环境可读。只输出单张图，无人物、标注、文字、水印和额外黑边。
```
