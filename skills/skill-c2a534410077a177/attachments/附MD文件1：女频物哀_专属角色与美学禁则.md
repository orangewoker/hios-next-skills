# 附MD文件1 | 女频物哀·专属角色与美学禁则

## #做什么

本模块为“女频物哀”题材专属的角色与美学底线约束库。

解决AI生成女频短剧漫剧时最容易出现的核心痛点：角色形象跨镜头不一致、面部崩坏、五官漂移、质感降级、美学风格不统一。

本模块只规定“绝不允许出现什么”，不替代主SKILL的流程调度、戏剧诊断和镜头叙事规则。

## #需要什么输入

**最少提供：**

- 女主设定：现代财阀千金 / 古装千金 / 未来仿生人。
- 题材方向：女频物哀、赛博未来、机器人主题。
- 目标画面比例：9:16竖屏。
- 风格参考：伊万里白瓷美学、#4A7FB5钻蓝呼吸灯等。

**可选提供：**

- 配角设定
- 场景环境设定
- 是否需要输出视频脚本、Prompt清单、视觉方案
- 上下游分镜、提示词、视觉方案结果

## #怎么做

### 一、角色锚点双重锁定（绝对强制）

- **女主**：精致高定造型，根据用户设定匹配现代财阀千金 / 古装千金 / 未来仿生人。皮肤质感为专业电影级写实，严格禁止出现非专业塑料质感。
- **绝对禁止**：低辨识度面部特征、面部崩坏、五官漂移。配角与主角的锚点必须绝对区分，严禁混用。
- **跨镜头一致性**：每一帧必须严格复用角色ID，绝对不允许出现五官漂移。

### 二、专业电影级质感（防塑料感）

- **画面基调**：女频柔光写实，低饱和度，低对比度，浅景深，35mm胶片颗粒感。
- **镜头语言**：侧视图45度，禁止正视图，镜头至多3秒，禁止全景。
- **绝对禁止**：高饱和滤镜、非专业高光、面部过度磨皮、像素感模糊。

### 三、执行原则

- 本禁则为“不可变核心”，任何下游分镜、Prompt转写、视频生成环节均不得违反。
- 如用户需求与本禁则冲突，必须优先执行本禁则，并告知用户冲突点。
- 如必须突破本禁则，必须由用户明确确认后，方可局部调整。

## #产出什么

最终交付：

- 角色锚点约束清单
- 美学风格约束清单
- 负面Prompt禁则清单
- 视频脚本、Prompt清单、视觉方案所需的角色与美学约束依据
- 每一帧均可作为独立海报级别的高清壁纸

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 女主设定不明确：现代财阀千金 / 古装千金 / 未来仿生人。
- 题材方向不明确：女频物哀 / 赛博未来 / 机器人主题。
- 用户要求突破本禁则，例如要求正视图、高饱和滤镜、过度磨皮。
- 用户要求输出视频脚本、Prompt清单、视觉方案，但缺少关键输入。
- 本禁则与上游主SKILL、其他附MD规则冲突。
