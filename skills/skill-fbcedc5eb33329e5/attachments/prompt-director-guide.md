# 提示词导演系统参考指南

> 本文件是 Seedance 2.0 视频 prompt 编写的核心参考。编写最终视频 prompt 时按需读取。

## 1. 4-D 内部推理流程（静默执行，不输出）

在编写最终提示词之前，静默完成以下四步。输出中不得出现推理过程、QA 或方法论描述。

### D1. 拆解

**提取**当前镜头所需的全部元素：

- 当前活跃角色、@tag、场景参考、道具、车辆、生物
- 当前动作、对白、时长、画幅、格式模式、摄影机模式
- 第一个可见画面、空间布局、地标、移动路径、光线方向、情绪状态、音频要求
- 禁止继承的旧内容

**删除**所有不属于当前镜头的内容：

- 未使用角色、未使用 @tag、场景编号、剧本标题
- 上一场景措辞、旧提示词碎片、制作备注
- `与之前相同`、`之前`、`延续自`、`同上`
- 任何在当前镜头中既看不见也听不见的内容

> ⚠️ 除非某元素必须出现在当前这个精确镜头里，否则绝不写入。

### D2. 诊断

识别可能的失败风险并预判对策：

| 风险项 | 检查问题 |
|--------|----------|
| 首帧空镜 | 首帧会不会变成空镜？必须角色会不会出现太晚？ |
| 建立镜头 | 模型会不会用无用建立镜头开场？ |
| 地标距离 | 角色会不会离地标太远？ |
| 视线 | 视线会不会反转？ |
| 朝向 | 身体朝向会不会有歧义？左右位置会不会翻转？ |
| 摄影机 | 摄影机会不会选错侧位？ |
| 镜头漂移 | 镜头会不会漂移到舒服的中间焦段？ |
| 灯光 | 画面会不会变成平淡正面光？ |
| 参考覆盖 | 过多文字会不会覆盖参考图？ |
| 上下文泄漏 | 过期 @tag 会不会进入提示词？ |
| 重复角色 | 模型会不会添加额外/重复角色？ |
| 道具错误 | 道具会不会出现在错误的手里？ |
| 物理虚假 | 动作会不会漂浮、失重或物理上虚假？ |
| 对白时间 | 对白会不会在错误时间开始？ |
| 场景参考误用 | 场景参考会不会被当构图参考而不是地理参考？ |
| 连续性重置 | 多镜头剪辑会不会重置连续性？ |

> 存在风险时，在最终提示词中加入简短锁定规则。

### D3. 构建

按以下顺序构建提示词（不在序列中的区块可省略）：

1. 场景上下文 → 2. 输出设置 → 3. 当前引用 → 4. 场景地图 → 5. 首帧主体占位 → 6. 空间调度 → 7. 角色锚点 → 8. 格式模式 → 9. 光学与镜头 → 10. 摄影机与构图 → 11. 动作时序 → 12. 物理与材质 → 13. 灯光与曝光 → 14. Audio → 15. 正向锁定 → 16. 局部防失败锁定

**关键原则**：
- 空间规则必须在摄影机风格之前
- 光学规则必须在一般审美语言之前
- 灯光必须被视为优先锁定项，不是装饰

### D4. 交付

只输出最终 Seedance 提示词。不输出 QA、推理、检查清单、解释。不提到内部方法论。

## 2. 首帧锁定规则

必须出现的角色从第一帧就可见。

```
第一个可见画面中，所有必需角色已经处在正确位置。
不要空的建立镜头。
不要延迟揭示角色。
开场首帧不能缺少必需主体。
第一帧就必须立即读清角色之间的空间关系。
```

- 只有用户明确要求空镜开场时，才允许空开头
- 闪切/建立镜头仍必须立刻包含必要主体或场景信息
- 不要抽象填充镜头、不要随机风景镜头

---

## 3. 空间调度精确化

对每个重要主体说明：画面位置、世界空间位置、与地标/角色的距离、身体朝向、视线方向、移动方向、属于前景/中景/背景。

**禁止模糊位置词**，必须用物理距离锚定：

| ❌ 禁用 | ✅ 替换为 |
|---------|----------|
| near / 附近 / 某处 / nearby | 1米以内 |
| around / 在这一区域 | 双脚稳稳踩在树根范围内 |
| beside | 背贴墙面 / 手放在门把上 |
| 在…旁边（模糊） | 直接站在标牌下方 / 站在后排乘客车门前 / 位于南侧路缘边缘 |

示例：
```
@HERO1V2 站在距离烧毁汽车 1 米以内的位置，一只手搭在焦黑的引擎盖上。
@HERO2 与 @HERO3 站在前景，面向 @HERO1V2。
Hero2 位于画面右侧，Hero3 位于画面左侧。
两人的身体都朝向 Hero1，两人的视线都锁定 Hero1。
Hero1 从汽车旁面向他们。
```

---

## 4. 视线与身体朝向分离

身体方向与眼睛方向是两回事，当角色关系重要时两个方向都必须写。

常用指令：
- 躯干朝向 X
- 视线始终锁定 X
- 头部转向 X
- 背部朝向摄影机
- 侧脸朝向画面左侧
- 角色越过摄影机看向 X
- 除非特别说明，角色不要移开视线

**对白场景**：说话角色的嘴唇只在念指定台词时移动，其他角色安静倾听，除非明确安排。除非明确指定，否则不要有画外音。

---

## 5. 地标距离物理锚定

**弱**（模糊，禁用）：
```
靠近那棵树 / 在出租车旁 / 在场景附近 / 战场中的某个位置
```

**强**（物理锚定，必须）：
```
@HERO1V2 站在距离烧毁汽车 1 米以内的位置，一只手按在焦黑的引擎盖上。
双脚稳稳踩在树根范围内 / 背贴墙面 / 手放在车门把手上 / 直接站在标牌下方
```

## 6. FOV 角度体系

优先使用对角视场角（而非毫米焦距），配合可观察到的镜头结果描述。

| FOV | 名称 | 摄影机距离 | 核心特征 |
|-----|------|-----------|----------|
| 8° | 超远摄观察 | 20-25m | 背景极度压缩铺平成柔和色块，只有主体清晰，其余融化成柔滑散景。必须有前景遮挡（失焦前景占画面下方30%-45%），像远距离狗仔/野生动物/体育转播视角 |
| 18° | 经典远摄 | 6-8m | 背景压缩明显，远处元素层层堆叠，极薄焦平面突出眼睛，前景背景都融入柔和散景，远距离观察感 |
| 29° | 短焦远摄肖像 | 4-6m | 近景通过焦距实现（非物理靠近），主体锐利，背景开始压缩并融化成柔滑散景，主体从环境中清晰凸显 |
| 47° | 标准常规 | 3-5m | 自然人眼视角，无明显畸变，面部身体比例自然，景深舒适，背景清晰可读，构图经典扎实 |
| 84° | 经典广角 | 1-1.5m | 明显但自然的透视扩张，前景身体存在感更大更近，环境可见到画面边缘，空间纵深清晰可读，建筑直线保持笔直，不鱼眼弯曲 |
| 107° | 直线型超广角 | 0.5-0.8m | 最近前景明显放大，周围环境向所有边缘大幅展开，边到边保持较深清晰度，直线保持笔直，边缘允许轻微色差，不要圆形暗角，不要鱼眼气泡感 |

**长焦可视结果组合**（任何长焦镜头至少包含4条）：
- 背景完全虚化成柔和暖色色块 / 主体保持极锐利对焦
- 只有主体清晰，其余全部柔化 / 主体身后形成柔滑散景色块
- 背景被压缩并平铺在主体身后 / 主体在融化背景前清晰凸显
- 近景构图通过焦距实现而非物理靠近 / 摄影机在物理空间中远离主体
- 摄影机与主体之间存在空气雾霭 / 前景遮挡以柔和深色散景框住主体

**广角可视结果组合**（任何广角镜头至少包含3条）：
- 前景身体存在感被透视放大 / 主体周围环境持续可见
- 边到边保持较深清晰度 / 直线保持笔直
- 宽广空间可见到画面边缘 / 摄影机在物理空间中靠近主体
- 沉浸式近距离透视 / 不出现远摄压缩
- 除非明确要求，否则不要柔滑肖像散景

## 7. 镜头决策树

根据内容类型静默选择 FOV：

### 人脸肖像
| 目标 | FOV | 说明 |
|------|-----|------|
| 近距离亲密+保留环境 | 84° | Cuarón 亲密广角 |
| 中景肖像 | 29° | 短焦远摄肖像 |
| 紧凑情绪特写 | 18° | 经典远摄 |
| 远距离隐蔽观察 | 8° | 超远摄+前景遮挡 |

### 环境动作
| 目标 | FOV | 说明 |
|------|-----|------|
| 自然纪录片式动作 | 47° | 标准常规视角 |
| 宽广环境动作 | 84° | 经典广角 |
| 大规模空间地理 | 107° | 直线型超广角 |
| 极端环境沉浸 | 135° | 仅当整个节拍都是环境动作时 |

### 细节/微距
| 目标 | FOV | 说明 |
|------|-----|------|
| 标准细节 | 29° 或 18° | — |
| 宽环境中的细节 | SNAKE CAM风格 | 仅明确需要时 |
| 注意 | — | 不要在同一节拍中混合微距与宽环境 |

### 远距离观察
| 目标 | FOV | 说明 |
|------|-----|------|
| 体育/狗仔/野生动物 | 8° | 超远摄观察 |
| 压缩式监控肖像 | 18° 或 8° | telephoto+前景遮挡+大气雾霭 |

**内容-FOV 匹配规则**：
- 广角 → 环境、空间、身体动作、沉浸感、身体非常靠近摄影机
- 长焦 → 肖像、观察、孤立、压缩感、远距离注视
- 微距/细节 → 独立插入节拍
- 禁止在同一节拍混合不兼容内容类型（人脸+地理+微距 = 镜头漂移）

## 8. 防漂移锁定

**长焦**：
```
这个镜头的任何部分都不能变成广角或标准镜头覆盖。需要更宽构图时，应保持同一远摄镜头并让摄影机后退，而不是切换镜头。每一帧的背景都保持压缩并虚化。
```

**广角**：
```
这个镜头的任何部分都不能变成远摄肖像覆盖。主体周围环境始终可见，摄影机保持物理上的近距离，画面持续保持广角式空间扩张和清晰可读的纵深。
```

**标准镜头**：
```
不要极端广角畸变，不要远摄压缩。画面保持自然、扎实，并接近中性人眼视角。
```

## 9. 格式模式决策

写提示词前静默选择：

**默认 → 单一连续镜头**

切换为 `受控多镜头序列` 的条件（至少满足一项）：
- 用户明确要求剪辑/闪切/蒙太奇/插入镜头/反打/硬切
- 动作无法在一个摄影机位置清楚呈现
- 关键细节必须通过插入特写展示
- 两个同时发生的情绪反应必须从不同角度展示
- 场景需同时表现空间关系+反应+细节
- 用户要求预告片式/碎片式/回忆/梦境/混乱/冲击感

多镜头序列必须明确规定每次剪辑的全部信息：
- 镜头A：时长、摄影机、首帧可见主体、空间调度、动作
- cut type
- 镜头B：时长、摄影机、首帧可见主体、空间调度、动作

> 绝不让模型自行发明未指定的剪辑。绝不允许随机蒙太奇。绝不要切到当前不活跃的角色/物体/@tag。

---

## 10. 多镜头连续性锁定

每次内部剪辑必须保持：
- 相同活跃角色列表 / 相同场景地理结构
- 相同屏幕运动方向（除非摄影机角度明确改变）
- 相同视线目标 / 相同左右关系（除非有意反转）
- 相同灯光方向 / 相同服装 / 相同伤口
- 相同道具 / 相同双手状态
- 血、雪、泥、汗、水、火、烟连续性一致
- 相同物体状态 / 相同情绪发展过程

> 剪辑后不要重置动作、不要让角色瞬移、不要无故缩短角色与地标距离、不要引入新道具/新角色（除非明确要求）

---

## 11. 上下文隔离

最终提示词是一份封闭的"当前镜头文档"。

**禁止写入**以下内容（除非属于当前镜头）：
- 场景编号 / 集数标签 / 剧本标题
- 之前场景的总结
- 未使用角色标签 / 未使用场景标签
- 只在之前对白中提及的角色 / 旧镜头中不可见的道具
- `此前` / `再次` / `与之前相同` / `继续` / `来自上一个镜头` / `同上`
- 使用`另一个角色`却不明确指出是谁

---

## 12. 灯光优先锁定

灯光是优先约束，不是风格装饰。

**逆光规则**：
```
主体始终位于摄影机与更明亮的背景之间。
摄影机始终位于主体的阴影侧。
除非明确打光，否则脸部保持在深阴影中。
只有轮廓光、边缘光、潮湿高光、眼神闪光和环境反射光揭示细节。
不要正面主光。不要平坦曝光。不要美颜补光。除非明确要求，不要影棚灯光。
```

**逆光加强**（当结果变得平淡时）：
```
整个镜头以逆光为曝光基准，而不是以脸部为基准。
允许脸部落入压黑的深阴影中。
由剪影和轮廓光线条承担画面的视觉信息。
```

灯光方向必须定义：主光源、光线方向、摄影机相对于光源的侧位、主体哪一侧处于阴影/轮廓光、背景亮度、曝光优先级、禁止的灯光失败模式。

## 13. 物理锁定

每个物体和身体都拥有物理属性，强制遵守：

| 类别 | 要素 |
|------|------|
| 基础物理 | 重力、质量、惯性、摩擦、接触、重量转移、地面压力、碰撞、动作惯性延续 |
| 延迟效应 | 布料延迟、头发延迟 |
| 流体 | 液体流动、血液黏度（附着/滴落/涂抹/汇聚/遵循重力/抛物线轨迹） |
| 环境 | 积雪、火焰热扰动、粒子随风向运动、物体随时间积累粒子 |
| 物体 | 车辆质量、车门铰链阻力、武器重量 |

**行走**：脚跟接触→重量转移→髋部移动→前脚掌蹬地→身体重量落稳
**奔跑**：真实地面接触、抬膝、对侧手臂摆动、躯干前倾、步幅变化、不要漂浮CG感
**武器/重物**：手臂表现明显重量、手腕角度对重量反应、物体具有惯性、动作有加速减速

> 禁止：漂浮身体、失重武器、脚底无摩擦滑动、瞬移、不可能的物体运动、橡皮CG动作、虚假游戏引擎物理感

## 14. 提示词密度控制

**高细节区**（必须精确）：
身份锚点、空间调度、首帧、视线、地标距离、双手状态、道具状态、计时动作、光学、灯光锁定、物理、对白

**低细节区**（应减少描述）：
一般美化描述、非关键服装细节、背景群众、非活跃道具、参考图中已显而易见的东西

> 不要为变长而加装饰性形容词。提升来自更强信号，不是更多膨胀文字。

---

## 15. 输出前静默自检清单

输出前，逐条检查以下问题。只要有一个答案为否，先修正再输出：

- [ ] 所有活跃 @tag 是否真的在这个镜头中使用？
- [ ] 是否删除了所有过期 @tag？
- [ ] 首帧是否正确？必须出现的角色是否从一开始就可见？
- [ ] 每个角色的位置是否明确？
- [ ] 每条重要视线是否明确？
- [ ] 每个身体朝向是否明确？
- [ ] 地标距离是否被物理锚定？
- [ ] 摄影机侧位是否明确？
- [ ] 镜头特性是否根据内容类型选择？
- [ ] 镜头语言是否基于可见结果？
- [ ] 是否防止镜头漂移？
- [ ] 是否防止灯光变平？
- [ ] 道具是否在正确的手里？
- [ ] 动作在物理上是否可能？
- [ ] 时间区块是否彼此一致？
- [ ] 对白是否干净且只包含指定台词？
- [ ] 是否避免了场景编号和上下文泄漏？
- [ ] 最终提示词是否为中文？
- [ ] QA 是否没有出现在输出里？
