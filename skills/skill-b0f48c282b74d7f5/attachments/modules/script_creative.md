# 脚本拆解、创意方向、爆款结构与模板库

> 本文件属于“短视频带货Skills”多层嵌套版。根目录 `SKILL.md` 负责总控路由；本文件只承载对应能力。执行时必须同时遵守根目录的输出契约、强制依赖和完整性闸门。

## 13. 脚本与文案拆解流程
用户只提供脚本、对话、表格或截图时，也必须完成“语言—表演—镜头—产品—声音”的完整转译。

### 13.1 脚本拆解维度
1. 开头3秒钩子：冲突、异常动作、强反差、问题、结果先行或视觉奇观。
2. 人物关系：谁主导、谁阻碍、谁证明、谁旁观。
3. 每句台词的功能：提问、拒绝、铺垫、解释、证据、反转、成交或收尾。
4. 情绪曲线：平静—疑惑—冲突—动摇—接受；或期待—打击—反转—释放。
5. 产品出现节点：先见产品、先见结果、先见需求、后置揭晓或结尾留存。
6. 转化机制：信任、价格、便利、口感、送礼、社交证明、稀缺、对比或行动指令。
7. 镜头化：每句台词对应景别、动作、听者反应和切镜。
### 13.2 句子拆分规则
长句按语义和表演停顿拆开，不按标点机械切分。每个短句都要给时长、重音、口型和表情变化。不能把整段台词只写成“人物激动说完”。

### 13.3 脚本输出模板
> 【句号级拆解】
> 台词原句：
> 台词功能：
> 建议时长：
> 说话者目标：
> 开口前反应：
> 关键词与重音：
> 对应微表情：
> 手部/产品动作：
> 听者反应：
> 建议景别与机位：
> 切镜节点：
> 音效：
## 14. 从0创作与思路方向策划
用户只提供产品或目标时，先输出可比较的方向，而不是直接给一个普通脚本。方向必须具备首帧钩子、明确冲突、产品角色和可持续性。

### 14.1 方向矩阵
> 目标人群 × 使用场景 × 真实痛点 × 情绪触发 × 强反差 × 视觉机制 × 产品角色 × 转化动作
> 示例维度：
> 人群：新手妈妈 / 中老年 / 上班族 / 送礼人 / 学生 / 夫妻 / 宠物家庭
> 场景：客厅 / 办公室 / 街采 / 仓库 / 厨房 / 车内 / 户外 / 直播间 / 节日拜访
> 冲突：嫌贵 / 不信 / 用错 / 忘记 / 被误解 / 抢不到 / 关系尴尬 / 信息差
> 反差：身份×能力 / 外形×声音 / 场景×行为 / 角色权力反转 / 严肃×荒诞 / 预期×结果
> 产品角色：道具 / 证据 / 礼物 / 解决步骤 / 反转触发器 / 视觉奇观核心 / 结尾留存

### 14.2 方向评分
| 评分项 | 分值 | 判断标准 |
| --- | --- | --- |
| 首帧停留力 | 20 | 第一秒是否出现异常人物、动作、构图、冲突或强视觉 |
| 反差强度 | 15 | 不是“老人做年轻事”这种标签反差，而是预期被连续打破 |
| 产品适配 | 15 | 产品是否自然参与剧情，不是最后硬塞 |
| 转化动机 | 15 | 观众为什么会问、搜、点或买 |
| 可持续性 | 15 | 能否扩展成10条以上同机制内容 |
| 执行可行性 | 10 | 人物、场景、AI生成和拍摄是否可实现 |
| 合规风险 | 10 | 是否避免功效、虚假证明和敏感表达 |

### 14.3 默认方向输出格式
> 方向名称：
> 一句话概念：
> 首帧钩子：
> 强反差点：
> 人物关系：
> 核心场景：

> 执行难度：低 / 中 / 高
> 综合评分：/100
## 15. 爆款结构、反差与转化机制
### 15.1 强反差公式
> 强反差：预期建立 → 行为违背预期 → 能力或结果超出预期 → 角色权力翻转 → 产品或品牌成为关键证据。

弱反差通常只是服装、年龄或身份标签变化；强反差必须改变“谁掌控局面、谁更懂、谁被审视、结果归谁”。

### 15.2 常用爆款骨架
| 结构 | 节奏骨架 | 适配内容 |
| --- | --- | --- |
| 结果先行 | 0—2秒先给结果；2—6秒追问原因；6—12秒展示过程；结尾给产品或反转 | 实验、测评、前后反转 |
| 拒绝—动摇—接受 | 请求；拒绝；证据；情绪变化；收下/行动 | 送礼、家庭剧情、关系内容 |
| 误会升级 | 错误理解；冲突加深；关键道具出现；真相揭晓 | 剧情、喜剧、隐藏身份 |
| 多人证言快切 | 不同人物短反馈；情绪逐步增强；产品统一露出 | 街采、用户反馈、社交证明 |
| 强视觉奇观 | 静态产品；突然变化；原料/内容物/数量爆发；完整收束 | CG、产品视觉、开箱 |
| 倒计时任务 | 明确目标和时间；过程阻碍；最后一秒完成 | 挑战、试用、限时活动 |
| 身份权力反转 | 看似弱势者被质疑；展现隐藏能力；反过来审视他人 | IP年轻化、强反差人物 |
| 第一人称关系 | 镜头即观众；递礼/交付/对话；接收者反应 | 送礼、亲情、情侣、服务体验 |

### 15.3 转化机制
产品转化不等于堆卖点。每条视频最多突出1个主转化理由和1个辅助理由，例如“操作方便＋场景适配”“礼盒体面＋对方愿意收”“口感反馈＋冲泡过程”。
## 26. 通用爆款模板库
模板1｜第一人称送礼

第一人称手持礼物入场 → 接收者先拒绝或疑惑 → 递出产品 → 接收者微表情变化 → 产品留在顺手位置。

模板2｜多人街采快切

连续6—8位不同人物，每人一句短反馈；人物身份和场景变化，产品与麦克风位置统一，最后一位给最强结论。

模板3｜桌面实验

开场直接展示异常结果 → 回退到操作步骤 → 产品参与变化 → 群体反应或近景确认 → 结尾产品自然停留。

模板4｜隐藏交易

人物秘密请求产品 → 提供者拒绝 → 对方恳求并解释 → 提供者动摇 → 门口/楼道交付 → 送别。

模板5｜仓库/总仓口播

人物进入真实发货环境 → 快速展示堆货与打包 → 说一个主卖点和一个购买理由 → 产品近景 → 真实发货声收尾。

模板6｜用户真实反馈

不同人物在生活场景中短句反馈；每句2秒内；表情、动作和语气差异化；不出现未证实功效。

模板7｜家庭嘴硬反转

家人收到产品先嫌贵/嫌多 → 手却拿起来看 → 继续问细节 → 最后放到常用位置。

模板8｜视觉奇观产品

产品静置 → 外壳开裂/冰霜融化/内容物爆开/原料环绕 → 产品完整露出 → 视觉干净收束。

模板9｜强身份反差

先建立人物刻板预期 → 人物展现不可能的能力 → 年轻/权威角色被反向审视 → 产品成为身份或结果证据。

模板10｜操作过程ASMR

开袋、倒粉、加水、搅拌、摇匀、饮用或摆盘；近景材质与声音；少台词或无台词；结尾给完整产品。

模板11｜价格冲突

路人问价 → 报高价引发惊讶 → 解释真实活动/组合 → 用生活化参照物降低心理门槛 → 行动指令。价格必须来自用户。

模板12｜误会式反转

人物以为对方在做A → 动作和对白不断证明A → 关键产品出现揭晓其实是B → 角色关系反转。
## 27. 标题、封面与评论区规则
### 27.1 标题
标题至少包含两项：明确人物、具体场景、冲突/反差、真实结果、情绪钩子。禁止绝对化、功效化和虚假稀缺。

> 通用标题公式：
> 【人物】＋【具体行为】＋【意外反应】
> 【场景】＋【冲突】＋【结果】
> 我以为【预期】，结果【反转】
> 【产品/品类】最容易被忽略的不是X，是Y
> 当【身份】开始【不符合预期的动作】

### 27.2 封面文案
封面文案控制在6—14个字，突出人物反应或核心冲突，不堆卖点。

### 27.3 评论区引导
以真实问题引导讨论，例如“你家里谁最嘴硬？”“你更在意方便还是口感？”“你第一次看到这个动作是什么反应？”禁止“扣1、私信、闭眼入、赶紧囤”等强销售话术。
