## 逐镜声景设计格式

每个镜头的声景设计按以下格式输出（对应七段式中的第七段）：

```
【七、声景空间设计】
- 对白层：[内容描述] ([音量]dB) / [时间范围]
  - 语言/音色/情绪：[如"洪亮悠远，苍凉厚重，气息绵长"]
  - 处理方式：[如"轻微混响"、"干声"、"电话音效"]
- 动作音效：
  - [音效1描述]（[音量]dB）/ [与画面的同步关系]
  - [音效2描述]（[音量]dB）/ [与画面的同步关系]
- 环境声场：
  - [环境音1描述]（[音量]dB）/ [持续性：全程/段落]
  - [环境音2描述]（[音量]dB）/ [持续性]
- 声画关系：[J-Cut/L-Cut/同步/对位/静音]
  - 设计意图：[为什么这样设计声画关系]
```

### 音量层级参考

| 层级 | dB范围 | 内容 |
|------|--------|------|
| 对白 | -3dB ~ 0dB | 画外音、对白、旁白 |
| 动作音效 | -6dB ~ -18dB | 画面内可见声源的动作声 |
| 设计音效 | -10dB ~ -20dB | 非写实的风格化音效 |
| 环境声场 | -28dB ~ -35dB | 持续底噪/氛围音 |
| 音乐 | -12dB ~ -24dB | 配乐/BGM（如有） |

## 声音分层架构

```
最终混音
+-- A1 环境音层（Ambience）
|   +-- 房间底噪（Room Tone）
|   +-- 自然环境音（风/雨/城市底噪）
|   +-- 技术环境音（机械嗡鸣/电子底噪）
+-- A2 音效层（SFX）
|   +-- 硬音效（画面内可见声源）
|   +-- Foley（脚步/衣物/道具操作）
|   +-- 设计音效（非写实的风格化音效）
+-- A3 音乐层（Music）
|   +-- 配乐（原创/版权音乐）
|   +-- 源音乐（画面内声源播放的音乐）
+-- A4 对白层（Dialogue）
    +-- 同期声（拍摄时录制）
    +-- ADR（后期配音）
    +-- 旁白/内心独白
```

## 声画关系设计

| 关系类型 | 说明 | 使用场景 | 效果 |
|----------|------|----------|------|
| 同步 | 声音与画面完全对应 | 硬音效、对白 | 真实感、直接 |
| J-Cut | 下一场景声音提前进入 | 预示下一段落 | 悬念、连贯 |
| L-Cut | 当前场景声音延续到下一画面 | 保持情绪连贯 | 余韵、过渡 |
| 声画对位 | 声音情绪与画面情绪相反 | 反差效果 | 张力、讽刺 |
| 硬切静默 | 转场点声音短暂中断0.3s | 强调视觉冲击 | 震惊、重置 |
| 完全静音 | 去除所有声音 | 孤独、真空、高潮后 | 极度压迫或释放 |

### J-Cut设计要点

- 画外音/环境音在当前镜头结束前0.5-1s预先起音
- 跨越转场点，声音连续性弱化硬切的割裂感
- 同时保留视觉冲击力
- 适用于：时间跳跃、空间转换、情绪转折

### 硬切静默设计要点

- 在转场点（如硬切处）所有声音瞬间切断
- 静默持续0.2-0.5s
- 然后新场景声音爆发进入
- 适用于：强烈对比、震惊时刻、段落分隔

## 剪辑节奏设计

### 节奏与情绪对照

| 情绪状态 | 平均镜头时长 | 剪辑频率 | 运镜速度 |
|----------|-------------|----------|----------|
| 平静/沉思 | 6-10秒 | 低 | 缓慢/固定 |
| 紧张/悬疑 | 2-4秒 | 中高 | 中速/不稳定 |
| 高潮/爆发 | 1-3秒 | 高 | 快速/剧烈 |
| 过渡/呼吸 | 4-6秒 | 低 | 缓慢/平滑 |
| 尾声/余韵 | 8-15秒 | 极低 | 极慢/固定 |

### 剪辑点对齐

- 音乐节奏：在鼓点、节拍重音处切换镜头
- 动作剪辑：在动作最高点前2-4帧切
- 视线剪辑：在角色视线稳定后切至其注视对象
- 声音先行：下一镜头的声音在当前镜头结束前0.5秒进入

## 转场设计

| 转场类型 | 时长 | 使用场景 | 占比建议 |
|----------|------|----------|----------|
| 硬切 | 0帧 | 默认转场 | 90%+ |
| 叠化 | 12-24帧 | 时间流逝、空间转换 | <10% |
| 匹配剪辑 | 0帧 | 形状/颜色/动作相似 | 关键情绪转折 |
| 遮罩转场 | 12-30帧 | 物体经过镜头前遮挡 | 偶用 |
| 淡入淡出 | 24-48帧 | 段落分隔 | 极少 |

胶片风格以硬切为主，避免数字化的花式转场。

## 调色方案

### 胶片调色流程

```
1. 色彩校正（Normalization）
   白平衡统一 -> 曝光统一 -> 对比度基础调整

2. 胶片模拟（Film Emulation）
   应用胶片LUT -> 调整胶片特征强度 -> 添加颗粒

3. 风格化调色（Look Development）
   主色调调整 -> 分段微调 -> 特殊效果（halation等）

4. 终调（Final Touch）
   全片统一性检查 -> 峰值亮度确认 -> 输出格式适配
```

### 调色参数参考

| 参数 | 胶片质感建议值 | 说明 |
|------|---------------|------|
| 颗粒强度 | 15-30% | 低光场景可增至40% |
| 颗粒大小 | 中等 | 模拟ISO 250-500 |
| Halation强度 | 10-20% | 高光边缘橙红光晕 |

| 高光色温 | 偏暖(+500K) | 胶片高光偏黄/橙 |
| 暗部色偏 | 偏青/蓝 | 胶片暗部特征 |
| 饱和度 | -10%至-20% | 胶片天然略低饱和 |
| 对比度 | 中等 | 避免极端对比 |
| 锐度 | -10%至-20% | 胶片不如数字锐利 |

## 交付规格

### 视频输出

| 参数 | 推荐值 |
|------|--------|
| 编码 | ProRes 422 HQ / H.265 |
| 分辨率 | 按画幅计算，长边不低于3840 |
| 帧率 | 24fps（电影感） |
| 色深 | 10bit |
| 色彩空间 | Rec.709（交付）/ Log（后续调色） |
| 音频 | 48kHz / 24bit / 立体声 |

### 交付文件清单

1. 主成片（含字幕版 + 无字幕版）
2. 分镜参考静态帧（全套）
3. 资产卡文档（全套）
4. 提示词文档（全套，含参数设置）
5. 剪辑时间线文档
6. 声音设计文档
7. 调色方案文档
8. 质检报告（Quality Gate 1 + 2）
