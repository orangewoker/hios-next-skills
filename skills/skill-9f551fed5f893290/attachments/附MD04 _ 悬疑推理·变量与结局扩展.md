# 附MD04 | 悬疑推理·变量与结局扩展

**所属主SKILL：** 悬疑推理 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“悬疑推理 | 上架Steam的互动影游”的专属变量系统与结局体系扩展库。

解决互动影游“变量设定空洞、结局无分支、选项假大空、数值不驱动剧情”的痛点。通过严格的变量字典、严密的结局触发条件与路径推演，确保玩家的每一次选择都能真实改变侦探与案件的因果命运。

## #需要什么输入

**最少提供：**

- 核心变量清单（如线索完整度、信任度、嫌疑人警觉度、时间压力、真相进度等）
- 路线设计（真相线、谎言线、背叛线、隐藏线）
- 侦探与关键NPC的信任设定

**可选提供：**

- 结局数量与类型偏好
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。变量与结局设计环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则，确保结局路径逻辑闭环。

### 二、变量字典（强制锁定）

核心变量

1. 线索完整度：counter，0-100，默认0；≥60真相浮现；&lt;30线索不足。
2. 信任度：relationship，0-100，默认0；≥70完全信任；&lt;30信任危机。
3. 嫌疑人警觉度：risk，0-100，默认0；≥70嫌疑人警觉；≥90嫌疑人逃亡。
4. 时间压力：counter，0-100，默认0；≥80案件告急；&lt;30从容调查。
5. 真相进度：counter，0-100，默认0；≥80真相大白；&lt;20谜团未解。

路线专属变量

1. 真相线专属真相值：relationship，0；≥50真相线锁定；&lt;20真相线崩塌。
2. 谎言线专属谎言值：relationship，0；≥50谎言线锁定；&lt;10谎言线失效。
3. 背叛线专属背叛值：relationship，0；≥50背叛线锁定；&lt;10背叛线失败。
4. 全员信任度：relationship，0；≥80解锁真结局条件。

道具与旗标变量

1. 关键证物A：item，false；true且线索完整度≥60可触发真相线结局。
2. 关键证物B：item，false；true且信任度≥60可触发背叛线结局。
3. 秘密档案：item，false；true且全员信任≥20可触发隐藏真结局。

### 三、结局体系（共15个）

正结局（5个）

1. E01·真相大白：真相线，线索完整度≥60，真相进度≥80。
2. E02·揭露谎言：谎言线，信任度≥70，谎言值≥50。
3. E03·背叛者伏法：背叛线，背叛值≥50，真相进度≥60。
4. E04·全员救赎：隐藏真结局，解锁秘密档案+全员信任≥20+真相进度≥80。
5. E05·孤独侦探：任意路线，真相进度30-59，时间压力&lt;30。

坏结局（10个）

 1. D01·嫌疑人逃亡：嫌疑人警觉度≥90。
 2. D02·信任崩塌：信任度&lt;30。
 3. D03·时间耗尽：时间压力≥90。
 4. D04·线索断裂：真相线，线索完整度&lt;20。
 5. D05·谎言反噬：谎言线，谎言值&lt;10。
 6. D06·背叛失败：背叛线，背叛值&lt;10。
 7. D07·真相被掩埋：真相进度&lt;20。
 8. D08·全员反目：全员信任&lt;10且真相进度≥60。
 9. D09·因果清算：所有变量失控。
10. D10·觉醒前陨落：N02选项B+嫌疑人警觉度≥70。

### 四、结局触发条件表（快速查表）

1. E01：N02A→N04A→N06A-2→N08B；线索完整度≥60·真相进度≥80·信任度≥30。
2. E02：N02A→N04B→N06B-1→N08B；信任度≥70·谎言值≥50·真相进度≥60。
3. E03：N02B→N04C→N06C-2→N07C-1；背叛值≥50·真相进度≥60·信任度≥40。
4. E04：N02B→N04C→N06C-2→N07C-2→N08C；秘密档案=true·全员信任≥20·真相进度≥80。
5. E05：N02A→N04B→N06B-3→N08B；真相进度30-59·时间压力&lt;30。
6. D01：任意路线累积嫌疑人警觉度≥90。
7. D06：N04A→N06A-1→N08A；背叛值&lt;10。

### 五、结局路径示例（以E04全员救赎为例）

N02B 质问真相（嫌疑人警觉度+10）\
→ N04C 参悟·秘密档案（线索完整度+20·全员信任+20）\
→ N06C-2 反问堵住反派（嫌疑人警觉度-20）\
→ N07C-2 抬头直视反派微笑（获得秘密档案）\
→ N08C 全员豪赌（线索完整度+30·全员信任+30）\
→ E04 全员救赎（全员信任≥20·秘密档案=true）

### 六、变量锚定规则（核心铁律）

1. 每个节点提示词末尾必须标注：节点ID+变量变化。
2. 变量名全部用英文（clue/trust/alert/pressure/truth/route），禁止中文变量名。
3. 变量一旦定义，中途不能改名。
4. 所有变量必须有定义、有使用、有结局影响。
5. 禁止无意义变量（定义了但从不影响结局）。

### 七、子级专属提示词模板（示例）

```text
节点ID：N05A
变量变化：线索完整度+40·信任度+25·嫌疑人警觉度+20·路线锁定=真相线
分支标识：真相线谜题判定
结局条件：线索完整度≥60·真相进度≥80
```

\
注：以上“侦探、嫌疑人A、秘密档案”仅为示例，实际使用时由用户自定义替换）
