# 附MD04 | 互动影游Agent调度链路与参数传递规范

**所属主SKILL：** 互动影游Agent | 自动串联调度下层Skill\
**版本：** V2.0 融合合规版

## #做什么

本模块为互动影游Agent的专属调度链路与参数传递规范库。

解决互动影游Agent“调用下层Skill时参数丢失、结果不汇总、异常无校验、与影视制作Agent协同边界不清”的痛点。通过统一的调用顺序、参数传递规则、结果汇总模板与异常处理流程，确保调度链路稳定、产出可控。

## #需要什么输入

**最少提供：**

- 项目主题与题材方向
- 目标分支数量与时长
- 目标平台

**可选提供：**

- 已完成的上游审查报告
- 角色/场景/变量设定
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。

### 二、调用链路与参数传递规则

1. 【总制片人】：传入项目名、主题、时长、分支数；返回算力预算、合规结论、门禁签字。
2. 【葵花宝典】：传入剧本、人物关系；返回困兽/体语/焚我三法则诊断结果。
3. 【顶级游戏开发大师】：传入剧本、抉择点、目标分支数；返回分支树、变量字典、结局路径。
4. 【风格影游选调库】：传入题材、目标平台；返回匹配的风格影游Skill slugID。
5. 【大导演思维】：传入分支树、情绪锚点；返回分镜脚本、镜头语言方案。
6. 【情绪大师】：传入分镜脚本、关键节点；返回七层微表情拆解与情绪曲线。
7. 【提示词】：传入分镜脚本、情绪锚点、锚点ID；返回物理参数、Prompt清单。

### 三、结果汇总模板

1. 汇总调用清单（含每个Skill的调用状态）。
2. 汇总调用顺序（含每一步的产出物）。
3. 汇总完整制作链路。
4. 汇总门禁审查报告（含三审签字）。
5. 汇总异常记录（含驳回原因与重跑次数）。

### 四、异常处理流程

1. 若上游Skill返回【驳回】，必须立刻停止，向用户报告驳回原因。
2. 若某一环节连续2次失败，必须执行引擎切换或修改策略。
3. 若出现参数缺失，必须向用户确认，不得自行补全。
4. 若出现Skill冲突，必须向用户确认优先级。

### 五、与影视制作Agent的协同边界

1. 互动影游Agent与影视制作Agent是平级Agent，互不隶属。
2. 互动影游Agent仅负责互动影游领域调度。
3. 影视制作Agent仅负责短剧/漫剧/TVC/参赛短片调度。
4. 两者共享底层Skill矩阵，但各自维护独立的调度链路。
5. 两个Agent的调用记录必须分开归档，严禁混淆。

### 六、生成与合成

根据上述调度链路与参数传递规范，调用底层视频生成Skill，输出MP4视频文件。
