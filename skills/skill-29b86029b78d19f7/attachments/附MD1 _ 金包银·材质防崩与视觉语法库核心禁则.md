# 附MD1 | 金包银·材质防崩与视觉语法库核心禁则

**所属主SKILL：** 金包银黄金珠宝 | 皮克斯动画漫剧TVC一键成片\
**版本：** V2.0 融合合规版

## #做什么

本模块为“金包银黄金珠宝 | 皮克斯动画漫剧TVC一键成片”的专属材质防崩与视觉语法核心禁则库。

解决AI生成金包银产品时“银白偏色、塑料感、文字穿帮、锦盒透视错误、手镯比例失真、高光死白”六大痛点。通过材质色号锁定、锦盒坐标系规范与佩戴比例物理锚定，确保金包银产品在TVC中呈现高水准电影级质感。本模块优先级最高，任何其他附MD不可覆盖。

## #需要什么输入

**最少提供：**

- 金包银产品类型（如手镯、项链、戒指等）
- 产品主色与材质要求
- 佩戴者手部或颈部参考图

**可选提供：**

- 锦盒/包装盒样式
- 打磨/佩戴场景需求
- 目标画幅（不限定，按项目需求或用户指定）
- 是否需要输出视频文件、视频脚本、Prompt清单、视觉方案

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。本环节重点参考【提示词】底座的3D动画电影级参数与【大导演思维】的微距镜头逻辑。

### 二、终极防崩铁律（血泪排雷，禁止触碰）

1. **文字净化锁死**：画面中所有实体（墙壁、牌匾、锦盒表面）绝对禁止生成任何中文字符、商标或品牌名称。背景牌匾仅保留空白木纹、纯色底板或装饰性花纹，后期由用户自行合成。
2. **足赤金材质锚定（防银白内圈）**：
   - 绝对禁用词：金包银、明晃晃的黄金。
   - 必须使用的正向词：足赤金、哑光暗金、暖金色拉丝金属、通体浑然一体的高级暖金色、无拼接感、零银白、零铂金、零冷灰。
3. **色号精确锁定（防塑料感/偏色）**：
   - 高级暖金黄色，色号参考HEX：**#D4AF37**（或HEX：**#CFB53B**）。
   - 光斑折射处保持同色系高亮。
4. **锦盒物理坐标系锁定**：锦盒为经典横开式红丝绒首饰盒。铰链结构绝对固定在盒子远离镜头的一侧（内侧后方）。盒子必须由下方向后方翻开，开口正面朝向镜头方向。禁止出现盒子侧翻、透视错误或前后颠倒。
5. **微距打磨光斑净化**：打磨过程中，手镯表面反光严格限制为柔和的暖金色漫反射光。绝对禁止出现刺眼的死白高光斑块、银白色拉丝错位或白线刮痕。

### 三、微小奢侈品体积扬长避短（六大必杀技）

1. **人体中介法**：不拍孤零零的手镯，拍“戴着手镯的手部特写”，人体是天然的尺寸标尺。
2. **光效膨胀法**：不让AI展示手镯实体，让手镯爆发出极柔和的“金色光环/光晕”，用“光”填满整个画面。
3. **超浅景深法**：用f/1.4大光圈，把背景的“巨大丝带/立柱”变成极致模糊的色块壁纸，消除空间对比。
4. **镜面倒影法**：把黑玻璃或大理石展台的倒影拍出来，上下对称的镜像能让产品的视觉体积膨胀一倍。
5. **失重悬浮法**：让手镯完全违背重力，静止悬浮在巨大场景的正中央，用非现实的物理姿态抹除尺寸劣势。
6. **微距推进法**：用100mm微距镜头把金银的花丝细节变成画面唯一的视觉主轴，观众只看到工艺，看不到场景大小。

### 四、完美佩戴比例物理锚定

- 手镯内径约**16厘米**（或按用户要求），精准贴合真人手腕佩戴。
- 手镯与手腕之间留有一根手指的自然缝隙，手镯在手腕上自然垂直，不紧绷、不松垮。
- 亚洲女性/男性手腕出镜，肤色自然真实，手部动作克制。
- **强制负向词**：禁止手镯缩小成戒指尺寸，禁止手镯放大成巨型环状物，禁止手镯穿透手腕皮肤，禁止手镯与手腕融合，保持1:1真实物理比例。

### 五、高定微距呼吸模板（奢侈品必杀技）

- 微距镜头极度缓慢地向下摇摄，扫过手镯的金属边缘，进入花丝镂空内部。
- 手镯缝隙中，一束金色的能量液如同被激活般瞬间沿着金属纹路流动，点亮了原本暗哑的金包银表面。
- 紧紧缠绕在（产品）外沿的一截干枯的百年老树根，像活的肌肉一样微微抽动，在金属表面摩擦出极其微小的金色光尘。
- 音效：极轻微的高频金石碰撞声，混合着老树皮在干燥环境中微微裂开的有机质声响。

### 六、生成与合成

根据上述防崩禁则与视觉语法，调用底层视频生成Skill，输出MP4视频文件。

## #产出什么

最终交付：

- **视频文件（MP4格式）、视频脚本、Prompt清单、视觉方案**。
- **材质防崩参数包**：色号、材质、锦盒坐标系、佩戴比例、光斑规范。
- **正向与反向Prompt清单**：确保AI生成时不出现银白、塑料感、文字穿帮、比例失真。
- **产品一致性校验报告**：跨镜头、跨场景的金包银材质统一。
- **六大必杀技执行清单**：人体中介法/光效膨胀法/超浅景深法/镜面倒影法/失重悬浮法/微距推进法。

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 金包银产品类型或佩戴比例不明确时。
- 用户要求突破材质防崩禁则（如允许银白色、塑料感、文字）时。
- 锦盒坐标系或佩戴比例与母级通用标准冲突时。
- 用户要求输出视频文件、视频脚本、Prompt清单、视觉方案，但缺少关键输入时。
- 本模块与上游主SKILL或其他附MD规则冲突时。
