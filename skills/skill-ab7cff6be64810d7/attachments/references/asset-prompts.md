# 人物、场景与道具提示词模板

只在生成基础资产时读取本文件。把方括号内容替换为剧本信息和“视觉设定”，不要固定题材、画风或比例。

## 人物三视图母图

每个反复出场人物默认只生成一张三视图母图。它是人物身份参考，不是人物分镜、情绪板或剧情画面。

```text
按照【视觉设定】制作【人物编号与名称】的人物三视图母图。

角色设定：【年龄、面部特征、发型、体态、服装、鞋履、配饰、材质、固定颜色和识别特征】。

纯白背景。左侧约三分之一为同一人物的面部近景；右侧约三分之二依次展示同一人物的正面全身、90度侧面全身和背面全身。三个全身视图必须从头到脚完整入镜、等比例、基线对齐、互不遮挡。

所有视图必须保持完全相同的身份、年龄、五官、发型、身体比例、服装结构、颜色、材质和配饰。人物自然站立，表情中性，不做剧情动作。

禁止场景、道具、其他人物、文字、标签、边框、色卡、尺寸线、分镜构图、额外肖像、裁切、换装、五官漂移、肢体重复、错误手指、噪点、胶片颗粒、过度锐化和塑料质感。
```

若“视觉设定”为真人电影级写实风格，可追加比赛 Skill 原有摄影块；动画、插画或 CG 风格不要强行追加：

```text
使用索尼 Venice 摄影机、Panavision C 系列镜头、24mm 焦距、f/1.4 光圈、全画幅拍摄，阴影干净，电影级布光，变形镜头，广角，超高细节。8k resolution, raw photography, cinematic, photorealistic。
```

验收：侧面必须是完整侧身而非只有侧脸；背面完整；三个全身不裁切；各视图服装与身份一致；不得出现多余画面。

## 人物持续状态图

只在剧情出现持续换装、年龄变化、受伤、污损或其他会影响多个镜头的状态时使用。

```text
以已批准的【人物三视图母图】为唯一身份来源，使用 Lib Navo Pro 制作【状态名称】参考图。只改变【明确变化项】，严格保留人物五官、发型、体态、基础服装结构、配饰和画风。使用简洁中性背景，完整展示后续镜头需要判断的状态。不得加入剧情场景、其他人物或无关道具。
```

## 空场景母图

```text
按照【视觉设定】制作【场景编号与名称】的可复用空环境母图。

场景信息：【年代、地点功能、建筑结构、入口、门窗、主要区域、固定家具与数量、材质、色彩、光源方向、时间和天气】。

画面采用【比例】的全景或大景，空间关系清楚，入口、出口、走位区和主要地标可辨认，透视与尺度自然，为后续放入人物和道具保留空间。固定物保持明确数量和位置。

画面中不得出现人物、临时尺度代理、剧情动作、随机文字、未批准道具、Logo或水印。禁止碎片化局部、过度景深、几何漂移、重复纹理、噪点、胶片颗粒和过度锐化。
```

## 独立道具母图

```text
按照【视觉设定】制作【道具编号与名称】的独立道具母图。

固定设计：【功能、长宽厚或人体比例、外轮廓、正反面差异、材质、颜色、按钮、接口、纹样、磨损和剧情状态】。

只展示这一个可独立使用的道具，使用纯白或浅中性背景。仅生成后续镜头实际需要的正面、背面、90度侧面或局部视图；各视图必须保持尺寸、比例、结构、颜色和材质一致。

禁止人物手持、剧情化摆拍、其他道具、复杂场景、广告海报构图、随机文字、乱码、Logo、水印、重复物体、尺寸漂移、透视畸变、噪点和过度锐化。
```

精确文字、数字、UI、地图或尺寸线不要交给图像模型随机生成；先做无字底图，再以确定性文字或矢量层补充。
