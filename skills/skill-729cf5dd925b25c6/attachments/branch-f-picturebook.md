# 分支F: 温暖绘本风 — 平面大湿子管线

## 平台执行要点

- 风格块：`style-locks.md` → STYLE_LOCK_F
- 模型（自动匹配）：图像 Seedream 5.0（水彩表现好）/ 备 Midjourney V7；视频 海螺（柔和运动）/ 备可灵 Kling 3.0
- 参考图配方：风格样板 + 色卡（必绑），角色设定图（人/动物/非人，条件绑）
- 转场：3D翻书/柔白过渡做成 1-1.5s 转场片段（尾帧图生视频，prompt 描述翻页/光晕过渡）

## 关卡衔接（上游已定）

风格样板与调参（G6）、节奏与输出格式（G7）已在上游确认；模型自动匹配。

- 换风格 / 调样板 → 回退 G6 ｜ 调节奏 / 换输出格式 → 回退 G7

**G6 样板图生成**：图片节点 → Seedream 5.0 → STYLE_LOCK_F + 剧本代表性场景，一次出 3 张（角色特写看笔触表情/室内暖光中景/自然全景）。

**F 分支精细调参备查（G6 阶段使用）**：

- 温暖程度: 微暖(奶油白+淡彩) / 深秋暖阳(暖黄+橙+棕) / 冬日壁炉(暖红+金+深褐)
- 笔触风格: 水彩晕染 / 彩铅 / 蜡笔 / 油画棒 / 混合(水彩底+彩铅细节+蜡笔高光)
- 角色造型(见 G10): 写实儿童 / 童话风格 / 动物拟人
- 叙事感: 像妈妈讲故事(柔光+暖调+慢) / 像老师上课(明亮+清晰) / 像朋友分享(自然+生活感)
- 纸张质感: 无 / 轻水彩纸纹 / 绘本纸质感
- 柔光效果: 无 / 轻微柔光 / 梦幻柔光(像透过薄纱)
