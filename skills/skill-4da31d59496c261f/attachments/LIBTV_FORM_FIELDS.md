# LibTV 表单建议

**Skill名称**
牛大师 Seedance 2.5 总导演

**一句话介绍**
保持原反推大师交互流程不变，后台由多专业导演协作提升镜头、台词、情绪、资产绑定和Prompt稳定性。

**使用场景**
用于授权短剧、剧情片、TVC等视频的逐段反推重制、角色替换、欧美化台词、微表情导演、多段连续生成与Seedance 2.5资产绑定。用户操作习惯与原版反推流程一致，内部采用总导演主脑统一调度专业模块。

**如何使用**
与原版相同：先上传当前反推视频；按提示依次确认人物映射、EP/S与衔接、角色/场景资产、站位、音色/道具、生成参数、英语台词、情绪、转换后分镜和最终Prompt。所有修改都可直接用自然语言提出。Prompt通过后再确认最终绑定清单并生成。

**输出内容**
包括原始镜头/对白锁定结果、英语口语化台词、微表情情绪导演表、转换后分镜、Seedance 2.5专业Prompt、最终绑定清单、正式成片验收与下一段连续性资产。
