# 附MD04 | 双男主·变量与结局扩展

**所属主SKILL：** 双男主 · 双向救赎 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“变量设定空洞、结局无分支”的痛点，确保选择真实改变两人的命运。

## #需要什么输入

- 核心变量清单、路线设计。

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 羁绊值：relationship，0-100，默认0；≥60灵魂契合；&lt;20形同陌路。
2. 信任度：relationship，0-100，默认0；≥70生死相托；&lt;30互相猜忌。
3. 黑化值：risk，0-100，默认0；≥80堕入深渊（两人皆可能黑化）。
4. 救赎进度：counter，0-100，默认0；≥80完成救赎；&lt;30陷入绝境。
5. 阵营敌意：faction，0-100，默认0；≥80被黑白两道全面追杀。

道具与旗标

1. 红丝线：item，false；true代表两人建立生死羁绊。
2. 关键证据：item，false；true可洗清冤屈或扳倒反派。
3. 双人机票：item，false；true可触发远走高飞结局。

### 二、结局体系（共15个）

正结局（5个）

1. E01·破晓余生：救赎进度≥80，羁绊值≥80，两人在晨光中活下来。
2. E02·深渊共沉：黑化值≥80，两人一起毁灭了世界，但也拥有了彼此。
3. E03·相忘江湖：信任度极高，但选择放手，各自成为传奇。
4. E04·真相大白：使用关键证据，两人洗清冤屈，光明正大站在一起。
5. E05·异国远航：使用双人机票，抛下一切恩怨，远走高飞。

坏结局（10个）

1. D01·死别：救赎进度&lt;20，一方为救另一方挡枪而死。
2. D02·死敌：信任度&lt;10，两人拔枪相向，同归于尽。
3. D03·背叛：黑化值≥90，一方彻底背叛，另一方入狱。
4. D04·深渊吞噬：两人被反派抓住，双双陨落。

### 三、变量锚定规则

1. 节点末尾必须标注节点ID+变量变化。
2. 变量名全英文（bond/trust/darkness/redemption/hostility）。
