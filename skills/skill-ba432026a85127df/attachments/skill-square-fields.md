# LibLib Skill 广场填写项

- 名称：东方修行视觉散文导演
- 简介：输入哲思文案或一句主题，自动生成中式修行视觉、提示词和视频
- 如何使用：可以直接粘贴一段哲学、道家、修心或人生感悟文案，也可以只输入“修行”“无相”“看淡得失”等主题，让Skill先创作文案。Skill会自动拆分视觉段落，调用Style Image V8.2为每个镜头生成四张候选图；选图后自动生成可灵3.0视频。也可以上传已有图片，直接从视频阶段继续。
- 输出结果：输出一篇可配音的哲思文案、默认12至18组统一中式修行电影质感的候选图片；确认图片后，为每张图生成中文视频提示词和5秒、16:9可灵3.0视频。
- 输出结果类型：视频

创建页面如有“Skill正文/规则”字段，粘贴同目录 `SKILL.md` 的完整内容。CVLM 5.5文本节点的系统提示词使用同目录 `CVLM5.5-video-system-prompt.txt` 全文。
