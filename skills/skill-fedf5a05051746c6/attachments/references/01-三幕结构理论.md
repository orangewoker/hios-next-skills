# 三幕结构理论

> 来源：《电影剧本写作基础》悉德·菲尔德

## 核心范式（Paradigm）

```
第一幕           第二幕           第三幕
开端(beginning)  中段(middle)    结尾(end)
     │                │
A──·──┼───·──────────┼─────Z
     │                │
建置(setup)     对抗(confrontation)  结局(resolution)

第1～30页        第30～90页          第90～120页

   情节点Ⅰ              情节点Ⅱ
  第25-27页            第85-90页
```

## 基本原则

1. **一部电影剧本就是一个由画面讲述出来的故事**
2. 电影是视觉媒介，把基本故事线戏剧化
3. 所有电影剧本都包括这一基本的线性结构
4. 一页剧本 = 银幕时间一分钟
5. 标准电影剧本约120页（2小时）

## 第一幕：建置（Setup）

- **篇幅**：约30页（30分钟）
- **任务**：用10页（10分钟）让观众知道：
  1. 谁是主要人物？
  2. 戏剧性前提是什么（故事讲什么）？
  3. 戏剧性情境是什么（围绕故事的戏剧性情况）？
- **核心**：抓住观众——前10页决定观众是否喜欢这部电影
- **情节点Ⅰ**：第25-27页，一个事变或事件，把故事转向另一方向

**案例**：《唐人街》

- 第1页：杰克·吉蒂斯是不拘小节的私人侦探
- 第5页：墨尔雷太太要雇他调查丈夫
- 情节点Ⅰ：真墨尔雷太太和律师来恐吓诉讼→故事转向

## 第二幕：对抗（Confrontation）

- **篇幅**：约60页（第30-90页）
- **核心**：一切戏剧的基础都是冲突（conflict）
- **方法**：
  1. 给人物规定需求（need）
  2. 为需求设置障碍（obstacles）
  3. 障碍产生冲突
- **情节点Ⅱ**：第85-90页，把故事引入结局

**案例**：《唐人街》

- 第二幕：杰克与不愿让他调查的势力发生冲突
- 情节点Ⅱ：在水池中找到一副眼镜→指向谋杀者

## 第三幕：结局（Resolution）

- **篇幅**：约30页（第90-120页）
- **问题**：故事如何结束？主人公怎样了？
- **原则**：需要有力的结尾，模棱两可的结尾已过时

## 戏剧性结构定义

**一系列互为关联的事情、情节或事件按线性安排最后导致一个戏剧性的结局。**

## 主题

- 主题 = 动作 + 人物
- 动作：发生了什么事情（有形的/情绪的）
- 人物：遇到这件事情的人
- 明确人物的需求→设置障碍→产生冲突

```
        主题
         |
    ┌────┴────┐
   动作        人物
    |           |
  ┌─┴─┐    ┌──┴──┐
有形的 情绪的 明确需求 动作即人物
```

## 人物创造

### 两个维度

内在的生活外在的生活从出生到影片开始从影片开始到结局形成人物揭示人物人物传记确定需求、动作即人物

### 三个方面

1. **职业的（Professional）**：以什么为生？与同事/老板的关系？
2. **个人的（Personal）**：婚姻/社交状况？与家人/朋友的关系？
3. **私生活的（Private）**：独处时做什么？爱好？

### 人物构成要素

- **观点**：怎样看待世界
- **态度**：展现观点的感情和行动方式
- **个性**：视觉上的个性特征
- **行为**：人物的实质就是动作——什么样的人干什么事
- **启示**：故事进程中了解到的人物新信息

### 核心法则

**动作即是人物！** 一个人的行为而不是他的言谈，表明了他是一个什么样的人。

## 对话

- 对话是人物的一种机能
- 功能：传达信息、推动故事发展、提示人物、展现矛盾冲突、展现感情和性格
- 来自人物的需求、希望与梦想
- 写得越多越容易——前60页别扭没关系，后60页会流畅

## 结尾与开端

**写电影剧本开端的最好方法：知道你的结尾！**

- 故事从A发展到Z，方向就是发展线
- 不必知道具体细节，但必须知道结尾发生了什么事
- 结尾类型：
  - "向上"的结尾：《星球大战》《洛奇》
  - "悲哀/暧昧"的结尾：《五首小乐曲》
  - "向下"的结尾：《邦妮与克莱德》

## 段落（Sequence）

- 段落是一系列用统一思想联结的场景
- 用1-2个词就能概括（如"婚礼""逃亡"）
- 每个段落都有明确的开端、中段和结尾

## 情节点

- 情节点 = 事变或事件，织入故事之中，把故事转向另一方向
- 功能：推动故事向前发展
- 情节点Ⅰ：第一幕结尾，进入第二幕
- 情节点Ⅱ：第二幕结尾，进入第三幕
- 不一定是重大场面，可以是简单对话，只要能把故事转向即可

## 场景

- 场景是在特定时间和地点发生的特定事件
- 每个场景都有目的
- 场景的构成：内景/外景 + 地点 + 日/夜
- 在场景中明确人物的视角

## 剧本格式

- 场景标题行：内景/外景 - 地点 - 日/夜
- 动作描写：现在时态，简练生动
- 角色名：居中大写
- 对白：居中，在角色名下方
- 括号说明：极少使用，只在必要时

## 改编

- 小说→剧本：将内在的、头脑中的东西转化为外在的、视觉的东西
- 戏剧→剧本：将舞台上的语言转化为画面
- 原则是：只保留能用视觉呈现的东西

## 写作流程

1. 确定主题（动作+人物）
2. 研究调查
3. 写人物传记
4. 构建三幕结构
5. 确定情节点
6. 用卡片法安排场景
7. 开始写初稿
8. 修改
