# 

《孤灯》——《隐形守护者》同风格谍战互动影游剧本分支结构

完全复刻《隐形守护者》核心创作逻辑：强历史锚点+步步惊心的生死抉择+树状可控分支+多线因果闭环+人设统一的角色羁绊+分层级结局体系，每一个选择都直接影响主角生死、阵营立场、角色命运与最终结局，无伪互动，所有分支均有明确的剧情因果与伏笔回收。

一、核心基础设定（锚定谍战基底）

核心世界观

时代背景：1939年上海孤岛时期-1945年抗战胜利，贴合真实历史节点，汪伪76号、日本特高课、军统上海站、中共地下党四方势力博弈，复刻《隐形守护者》的乱世沉浸感。

主角：林默，代号「孤灯」，22岁，原东吴大学新闻系学生，父亲为爱国教授被日军公开处决，放弃学业被中共地下党发展，以「汉奸」身份打入汪伪政府76号机要处，任特高课课长浅野英夫的专属秘书。

核心矛盾：在汉奸骂名、同志误解、日军猜忌、76号内斗的绝境中，守住信仰、完成情报任务、活下去，每一次抉择都是「信仰与生存」的终极考验。

核心羁绊角色（好感度/信任度直接决定剧情走向）

核心结构总览

全剧本分为序章+5个主线章节+终章结局，采用「章节内分支发散-章节末尾主线收束」的可控树状结构，单章节设置3-4个核心抉择点，区分「致命陷阱抉择」「主线拐点抉择」「支线羁绊抉择」，累计设置20+中途死亡/失败结局，4个主线终局，1个隐藏真结局。

二、分章节详细分支结构

序章：深渊入口（1939年，上海）

核心目标

完成投名状，获得浅野英夫的初步信任，成功打入76号，开启潜伏生涯

前置剧情

你拿着写满「亲日言论」的悔过书，站在特高课办公室，浅野英夫拿着你父亲的照片，对你发出第一个试探：「林先生，令尊是反日激进分子，你却要为大日本帝国效力，我该凭什么相信你？」

核心抉择点1：回应浅野的试探（主线第一个生死拐点）

核心抉择点2：入职后的第一个任务——公开批斗遇害的爱国教授（含你昔日恩师）

第一章：刀尖起舞（1940年，上海）

核心目标

获取日军针对地下党的「清乡计划」核心情报，传递给组织，同时化解丁万山的连环陷害，保住浅野的信任

章节收束规则

无论中间分支如何，只有成功拿到情报并完成传递，才能进入第二章；其余分支均触发中途结局，需回溯抉择点。

核心抉择点1：丁万山设局，将一份地下党名单放在你办公室，引来特高课搜查

主线分支A：正面硬刚丁万山

核心抉择点2：浅野让你负责丁万山的贪腐案调查，给了你处置权

主线分支B：极限自救线

核心抉择点2：3天期限，你需要找到栽赃的证据，洗清自己

主线收束节点：获取【清乡计划】情报后的终极抉择

第二章：歧路分野（1941年，上海）

核心目标

护送核心地下党领导撤离上海，同时应对军统的正式拉拢、日军的深度试探，完成阵营立场的第一次关键分野

核心分支规则

本章的抉择，将直接决定后续剧情的三大主线走向：中共地下党信仰线、军统合作线、汉奸黑化线，三大主线完全独立，剧情互不重叠。

核心抉择点1：老陈给你下达护送任务，同时沈青寒私下找你，开出军统的优厚条件，拉拢你归顺

三大主线独立分支核心拐点

信仰主线核心抉择：护送途中遭遇日军伏击，你需要牺牲一部分人掩护领导撤离

选项1：自己断后，让领导和同志先走 → 苏晚好感度+20，解锁隐藏线索【老陈的秘密】，进入第三章主线

选项2：牺牲苏晚所在的掩护小队，保住领导 → 苏晚被俘，苏晚好感度清零，触发坏结局【初心尽失】

选项3：带着领导投降，换取所有人的活路 → 触发坏结局【叛国者】，章节结束

军统合作主线核心抉择：护送途中，军统要求你借机除掉地下党领导，否则就曝光你的身份

选项1：拒绝军统要求，和沈青寒摊牌，终止合作 → 沈青寒好感度+30，她选择帮你隐瞒，进入第三章国共合作主线

选项2：答应军统要求，暗中下手除掉领导 → 老陈发现你的行为，地下党对你下达追杀令，触发坏结局【两面三刀】

选项3：把军统的计划告诉老陈，提前做好防备 → 老陈信任度+10，沈青寒好感度-30，她和你彻底决裂，进入第三章主线

汉奸黑化主线核心抉择：浅野让你带队清剿地下党剩余据点，亲手处决被俘的老陈

选项1：亲手开枪处决老陈 → 浅野对你完全信任，提拔你为76号副主任，进入第三章黑化主线

选项2：拒绝开枪，试图救老陈 → 浅野认定你通敌，当场将你和老陈一起处决，触发坏结局【迟来的忏悔】

选项3：现场放走老陈，自己跟着一起逃跑 → 被日军全城通缉，触发坏结局【亡命天涯】

第三章：生死棋局（1942年，太平洋战争爆发）

核心目标

获取日军太平洋战场作战情报，找出组织内部的内鬼，应对全线信任崩塌的危机

核心设计

复刻《隐形守护者》的核心反转：内鬼就是主角的上线老陈，他早已叛变，之前的多次危机都是他设局陷害，本章的抉择将决定你是否能识破反转，活下去。

核心抉择点1：情报多次泄露，组织认定你是内鬼，对你下达了清除令，同时浅野也开始怀疑你泄密

真相线核心抉择点2：你拿到了老陈叛变的证据，老陈约你单独见面，摊牌对峙

第四章：至暗时刻（1943年）

核心目标

在日军、军统、叛变的地下党三方追杀下，活下去，同时完成组织交给的终极潜伏任务，获取日军对华终极作战计划

核心设计

复刻《隐形守护者》的「绝境求生」剧情，主角失去所有靠山，孤立无援，每一个选择都关乎生死，只有羁绊角色的好感度达标，才能获得一线生机。

核心抉择点1：你的身份彻底暴露，浅野对你下达了全城通缉令，76号、特高课、军统都在找你

第五章：长夜将尽（1945年，抗战胜利前夕）

核心目标

完成最终任务，迎接抗战胜利，做出最终的人生抉择，导向对应的终章结局

核心设计

本章为结局前置章节，每一个选项直接锁定终章结局，无回溯空间，所有前期伏笔、好感度、线索收集，都将在本章完成回收。

三大主线对应结局锁定抉择

信仰主线结局锁定：抗战胜利，组织让你继续潜伏，打入军统内部，执行新的潜伏任务

选项1：接受任务，继续以「孤灯」代号，潜伏在黑暗中 → 锁定终章结局【孤灯长明】（红色芳华正结局）

四、《隐形守护者》风格核心创作要点复刻

抉择的道德困境：没有绝对正确的选项，很多时候，「做汉奸」的选择是活下去的唯一办法，而「善良」的选择往往会直接触发死亡，复刻谍战潜伏的极致残酷感。

因果闭环强绑定：序章的一个选择，会直接影响第五章的结局解锁，所有伏笔都有回收，所有选择都有对应的后果，避免剧情bug。

角色人设绝对统一：无论玩家做出什么选择，核心NPC的行为都符合其核心人设，不会出现OOC，每个角色都有自己的立场与弧光，不是推动剧情的工具人。

可控的分支结构：单章节分支层级不超过3级，章节末尾完成主线收束，避免分支爆炸导致的制作成本失控，同时保证剧情的自由度与沉浸感。

结局的氛围感：每个结局都有专属的剧情文案与主题，哪怕是死亡结局，也有对应的剧情收尾，而非简单的「游戏结束」，让玩家在每一次失败中，都能感受到乱世的沉重与信仰的重量。
