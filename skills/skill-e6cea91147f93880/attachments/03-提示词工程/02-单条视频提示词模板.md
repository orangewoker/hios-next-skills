# 单条视频提示词模板

## 导演公式

```text
主体 + 动作 + 场景 + 镜头 + 灯光/风格 + 音频 + 约束
```

把主体和主要动作放在最前面，靠前的分句确立镜头层级。

## 槽位说明

| 槽位 | 用途 | 示例 |
|---|---|---|
| 主体 | 模型必须跟踪的锚点 | 汉代仕女，手持升仙令，身着朱红曲裾深衣 |
| 动作 | 可见的变化 | 她缓缓抬头，望向云门缝隙中漏下的天光 |
| 场景 | 仅参考素材中尚未包含的部分 | 白玉云台，后方排着长队，远处云雾翻涌 |
| 镜头 | 一个带终点的主要运动 | 从腰部水平中景缓慢推近至面部特写 |
| 灯光/风格 | 物理光 + 安全视觉语言 | 暖金天光从门缝斜射，幽蓝阴影笼罩人群 |
| 音频 | 环境声、音效、对白或静默 | 远处钟磬声，布料轻响 |
| 约束 | 保持项与排除项 | 保持服装纹样不变；不要出现现代元素 |

## 可见节拍

每个镜头只能有一个主要可见节拍：
- reveal（揭示）
- arrival（抵达）
- decision（抉择）
- transformation（转变）
- contact（接触）
- pursuit（追逐）
- disappearance（消失）

## 提示词模板

```text
[主体] [动作]，[场景]。镜头：[景别] [运动] 从 [起始构图] 到 [终点构图]，速度 [速度]。灯光：[光源] 从 [方向] 射入，[色温]，[氛围]。声音：[声音层次]。约束：[保持项]；不要 [排除项]。
```

## 常见错误

| 错误 | 修复 |
|---|---|
| 单个片段事件过多 | 只保留一个可见节拍和一个终点 |
| 反复描述图像 | I2V 只写运动和变化 |
| 复制未授权肖像 | V2V 只迁移镜头/动作，不迁移身份 |
| 用情绪词代替动作 | "她感到悲伤" → "她垂下眼，手指收紧衣袖" |
| 镜头运动冲突 | 一个镜头只选一个主要运动 |
