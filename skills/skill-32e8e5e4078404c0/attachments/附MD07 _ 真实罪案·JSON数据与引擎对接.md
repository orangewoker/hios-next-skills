# 附MD07 | 真实罪案·JSON数据与引擎对接

**所属主SKILL：** 真实罪案 · 纯推理 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

确保互动影游能落地运行、可直接交付工程。

## #需要什么输入

完整节点清单、变量字典、视频文件。

## #怎么做

### 一、JSON数据结构

包含variables（真相进度、谎言识破、嫌疑值等）、nodes、endings。

### 二、Twine/SugarCube 工程规范

严格遵循SugarCube 1.0.35锁定规范。变量赋值使用标准set语法。

### 三、视频文件命名规范

N01.mp4（接手案件）、N02A.mp4（搜查卧室）、N02B.mp4（调取监控）等。

### 四、本地测试规范

VS Code + Live Server。重点测试线索收集不全时，是否能触发坏结局。
