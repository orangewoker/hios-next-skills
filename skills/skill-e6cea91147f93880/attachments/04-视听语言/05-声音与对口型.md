# 声音与对口型

## 核心规则

- 让对白简短，引用说出的台词，并给每句分配具名说话者。
- 对口型时优先使用锁定或稳定的取景。
- 嘴部精度重要时，移除转头、大幅面部运动、极端镜头运动和忙碌手势。
- 仅使用权利已清理的声音。

## 语言可靠性

普通话对口型最强，英语次之，其他语言较弱。非英语台词应非常简短，或使用声音参考，并为重拍预留预算。

## 声音层模式

```text
Dialogue: ...
Sound: ...
SFX: ...
Music: ...
Silence: ...
```

只纳入重要层次。当静默能强化戏剧性或避免对口型混淆时，静默是有效的。

## 场景示例

| 需求 | 稳定音频指导 |
|---|---|
| 对口型 | Character A, locked medium close-up, says "我找到了。" 清晰干声，不转头。 |
| 产品广告 | Sound: 低房间底噪。SFX: 盖子打开时磁吸咔哒，尾帧轻柔玻璃音。 |
| 节拍同步 | @Audio1 仅提供节奏；灯光脉冲与脚步重拍同步。 |
| 戏剧 | 远处雨声和冰箱嗡鸣；对白期间无音乐。 |
| 动作 | 呼吸渐重，落地时鞋吱响，终点金属门蜂鸣。 |

## 多角色对白

可靠性重要时，每个短片段只使用一个说话者。两个角色必须说话时，分开轮次并保持镜头稳定。复杂交流建议生成受控的单说话者片段并在后期合成。

## 故障修复

- 对白失步：缩短台词、锁定镜头、移除转头、清理音频角色、减少竞争音效。
- 错误说话者：分配标签并按说话者拆分台词。
- 音频被忽略：移除多余音乐/音效指令并明确参考角色。
- 音视频参考冲突：明确优先级 `@Video1 controls camera only; @Audio1 controls tempo and energy`。

## 序列状态

继承已完成对白、进行中对白、环境音、音乐阶段、音效阶段、当前片段范围、连续性锁定、精确参考标签和预留后续节拍。不要重复已完成对白，除非明确要求重演。
