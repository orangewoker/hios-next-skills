## 1. 手持自拍场景规范

### 视角参数

- 镜头类型：手机前置摄像头原生视角
- 拍摄距离：30-60cm（日常自拍距离）
- 镜头高度：与眼部平齐或略高5-15cm
- 拍摄角度：轻微俯角（5-15度）
- 画面构图：面部位于画面中心偏上，上半身入镜，头顶预留少量空间
- 畸变控制：轻微广角畸变可接受，但不得出现极端鱼眼效果

### 动作规范

- 握持手：单侧手（右手或左手）握持手机，拇指在手机一侧，其余四指在另一侧
- 手臂姿态：手臂自然抬起弯曲，肘部约90-120度
- 手臂入镜：握持手的前臂可部分出现在画面下边缘或侧边缘
- 自然晃动：说话时头部微动带动画面轻微晃动；走路时画面有规律的上下起伏
- 禁忌：不得出现"有自拍动作却看不到握持手势"；不得出现双手悬空无设备

### 画面特征

- 设备入镜：手机顶部边缘可极少量出现在画面上方（不超过画面高度的5%）
- 运镜限制：仅允许来自手臂移动、身体转动、行走晃动的自然运镜
- 禁止：专业推拉镜头、平滑摇移、轨道平移、无人机视角

### 提示词关键词组

```
手持手机自拍视角，第一人称拍摄设备视角，镜头距离面部约40cm，轻微俯角，
[主角描述]，[右手/左手]握持手机，手臂自然抬起，手指握持姿势正确，
画面下方可见少量前臂，说话时自然轻微晃动，真实生活质感，自然光影，
无专业运镜，仅手持自然抖动
```

## 2. 固定机位自拍场景规范

### 通用视角参数

- 镜头类型：固定设备视角（手机/相机放置在载体上）
- 画面稳定性：整体稳定，无手持抖动（极轻微环境震动可接受）
- 拍摄距离：1-3米（根据场景调整）
- 画面构图：中景或全景为主，主角全身或大半身入镜
- 畸变控制：无近距离广角畸变

### 细分场景参数

2.1 桌面摆放

- 镜头高度：与桌面平齐或略高（约70-80cm）
- 画面内容：包含桌面物品（前景）+ 主角上半身
- 适用：吃饭记录、桌面手工、电脑前工作、化妆记录
- 设备载体：画面下方可出现桌面边缘

2.2 落地支架/三脚架

- 镜头高度：匹配人物坐姿（约100-120cm）或站姿（约150-170cm）
- 画面内容：主角全身或大半身入镜
- 适用：健身记录、跳舞、穿搭展示、多人合影
- 设备载体：画面边缘可出现三脚架支腿

2.3 随手摆放

- 镜头高度：与放置位置完全对应
  - 车窗：约100-120cm，斜向拍摄
  - 货架：约150-180cm，俯拍
  - 台阶：根据台阶高度调整
- 画面内容：根据放置位置自然呈现
- 适用：户外记录、旅行打卡、特殊视角

### 动作规范

- 主角姿态：自然放松，无抬手握持设备动作
- 视线方向：可看向镜头，也可专注做其他事情
- 身体动作：正常生活动作，无刻意表演感

### 提示词关键词组

```
固定机位自拍视角，设备放置在[载体描述]上，镜头高度约[高度]cm，
画面稳定无手持抖动，[主角描述]，自然放松姿态，无手持设备动作，
画面中可见[载体特征]，中景/全景构图，真实生活质感，自然光影，固定机位无运镜
```

## 3. 佩戴式第一人称视角规范

### 通用视角参数

- 镜头类型：完全第一人称视线视角（POV）
- 视角同步：画面与主角视线方向完全同步
- 主角可见性：正常情况下看不到主角的脸；仅在镜子、水面、玻璃反射等场景中可出现主角影像
- 运动特征：画面随头部转动同步移动，具备头部运动的自然晃动与视差

### 细分差异

3.1 头戴式视角

- 镜头高度：与视线完全平齐（约150-175cm，根据人物身高）
- 画面特征：与人眼视野一致，上方可极少量出现帽檐/眼镜支架
- 晃动幅度：转头时画面快速转动；走路时上下起伏幅度较小
- 适用：运动记录、沉浸式探店、旅行vlog

3.2 胸戴式视角

- 镜头高度：略低于视线（约120-140cm）
- 画面特征：画面下方可出现少量胸前衣物/衣领；视角略微仰视
- 晃动幅度：走路时上下起伏幅度略大于头戴式
- 适用：手工制作、烹饪记录、骑行记录

### 动作规范

- 无手持设备手臂动作
- 手部动作：双手可在画面下方出现（如做手工、拿东西），但不得握持拍摄设备
- 头部运动：低头、抬头、转头时画面同步移动

### 提示词关键词组

```
[头戴/胸戴]第一人称视角，POV视角，画面与视线完全同步，
正常视角看不到拍摄者的脸，[场景描述]，
头部转动时画面同步移动，自然头部晃动与视差，
画面[下方/上方]可见少量[衣物/帽檐]，真实沉浸式体验，自然光影
```

## 4. 通用提示词构建模板

### 标准提示词结构

```
[自拍场景声明] + [视角参数] + [主角描述] + [动作细节] + [场景环境] + [运镜限制] + [画面质感] + [技术参数]
```

### 各部分说明

1. **自拍场景声明**：明确说明是哪种自拍视角（手持/固定机位/第一人称）
2. **视角参数**：镜头距离、高度、角度、构图
3. **主角描述**：人物外貌、穿着、表情
4. **动作细节**：握持方式、身体姿态、自然晃动
5. **场景环境**：地点、背景、光线
6. **运镜限制**：明确禁止专业运镜，仅允许自然移动
7. **画面质感**：真实生活感、胶片感、等
8. **技术参数**：分辨率、帧率（在工具参数中设置，提示词中可省略）
