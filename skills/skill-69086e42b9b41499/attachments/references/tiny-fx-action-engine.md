# 微缩小人 15 秒动作引擎

## 固定节拍

| 时间 | 动作功能 | 要求 |
| --- | --- | --- |
| 00:00-00:02 | 起点起跳 | 从巨大起点元素跃起或摆荡，立即建立 1:15 尺度 |
| 00:02-00:04.5 | 横向障碍 | 在瓶阵/书脊/杯碟等巨大障碍间连续跳跃，微距横向跟拍 |
| 00:04.5-00:07 | 穿越物 | 鱼跃、钻入或翻越巨大物件，短慢动作强调尺度与腾空 |
| 00:07-00:09.5 | 逃离段 | 在物件内部或狭窄通道中快跑，制造安全的紧迫感 |
| 00:09.5-00:12 | 移动载具 | 进入水面、桌面或纸面移动段，骑乘/搭乘本场景载具 |
| 00:12-00:15 | 终点胜利 | 借载具或最后一跃登上标志性高点，胜利姿态与画风匹配的成功图形收尾 |

## 比例与镜头

- 主角是约巴掌大的 1:15 微缩人；每个镜头都至少保留一个巨大日常物件作尺度锚点。
- 实拍用微距浅景深、低机位贴物跟拍和真实材质；3D/2D 用对应媒介表达尺度，不混风格。
- 动作必须有清楚起点、着力点和落点；不生成伤害、失控坠落、危险碰撞、肢体变形或无理由飞行。

## 产品露出节拍

有 `product_reference` 时，产品在 00:02-00:04.5 或 00:12-00:15 出现 0.8-1.5 秒的自然清晰露出：角色从产品旁跳过、借产品附近台面移动，或在终点附近自然陈列。不得把产品当水印或让角色踩踏/破坏产品。
