# 职业·工作环境词典（Occupation & Environment Lexicon）

> 服务：用户输入含职业、工作场景、工作环境描述时的翻译层。
> 输出仍是"同一人物的多视角肖像"——职业影响**装束（穿什么）**、**体貌印记（环境在身上留下的痕迹）**、**场景（站在什么光里）**三个可绘层面。人物与背景一起成立。

## 使用总则（先读）

1. **职业 ≠ 性格**：翻译只做视觉事实——穿什么、被环境磨出什么痕迹、站在哪。**禁止**由职业推出性格/阶层/道德判断（"警察威严、医生冷漠、骑手穷苦、工人粗鄙"全是禁句）。用户给的性格以气质断语为准。
2. **三层翻译法**：每个职业词一律翻成 ①装束（无标识通用款）＋②体貌印记（皮肤/手/体态）＋③场景空间与光线。缺用户明确信息时按表取默认，档案标"推断"。**注：当前交付形态为浅灰色纯色背景四视图设定图，只取 ①②两层入消息，③场景空间与光线不入画**——本词典的环境基线表降级为"推断依据"（用于解释人物为何有晒痕/油污/茧），不再产生背景句。
3. **真实机构标识一律去除**：军徽、警徽/警号、国徽、校徽、企业 LOGO、平台品牌字、制服臂章——生成时全部写"无标识 / 素色 / 通用款"。制服作**戏服级**处理（形似可辨、无任何真实符号）。
4. **背景恒为浅灰纯色（当前交付形态固定）**：交付物是浅灰底四视图设定图，故本词典原有的"背景浓度三档"在当前形态下**全部不适用**——不产生任何背景句、不写环境道具。原三档保留备查（改回带环境形态时启用）：轻（人物设定图/转面）→ 素色或虚化背景、仅保留光质；中（默认定妆语境）→ 场景语义 + 光质 + 2–4 个环境道具、背景略虚化让位于人物；重（环境剧照）→ 实化场景、人物与环境等权重。
5. **支持成年与未成年角色**；未成年角色可叠加校园/家庭/日常/年代场景，但不绑定危险职业与危险场所（消防现场、工地、警务事故、军旅前线等不叠加），并遵守未成年角色安全约束（非性化/年龄适配/不参照真实儿童）。
6. 危险职业（消防/警务/救援/军旅）只呈现**工作常态**（队站/训练/街面/现场外围），不渲染事故、血腥、火场实况、伤亡场面。

## 一、环境空间与光线基线表

用户报出工作环境或职业后，据此确定"人物站在什么光里"。每行 = 场景语义（可作背景文字）| 光质 | 背景锚点（2–4 个可绘元素）。

| 工作场景 | 空间与光线 | 背景锚点（可绘元素） |
|---|---|---|
| 工厂车间/产线 | 室内大空间，顶部荧光灯 + 高窗冷光，硬光，粉尘空气 | 传送带/机床、指示灯、金属机台 |
| 建筑工地/户外施工 | 露天或脚手架框架内，日光直射明暗反差大，扬尘光柱 | 脚手架、安全网、钢筋堆 |
| 农田/田间/大棚 | 开阔田野，自然天光（晨昏侧光/正午顶光） | 田垄、农机、草帽 |
| 渔港/渔船甲板 | 甲板或码头岸，海面反光 + 日光，硬光，风 | 渔网、缆绳、船体锈漆 |
| 医疗/诊所/手术室 | 洁净室内，无影灯冷白光或诊室日光灯，均匀无影 | 器械灯、监护屏、白墙 |
| 警务/治安 | 所内日光灯或街面混光 | 办公桌/记录本、街面巡逻车（无标识） |
| 消防救援 | 队站或事故现场外围，日光/场地泛光，烟尘环境光（克制） | 水带、车辆轮廓（无标识）、警戒带 |
| 军旅 | 营区/训练场，日光或战术泛光 | 通用作训场景（无旗无徽） |
| 教室/校园 | 室内日光灯或大窗自然光，均匀偏亮 | 黑板、课桌椅、讲台 |
| 办公楼/写字间 | 室内顶灯均匀 + 屏幕光，白领冷调或黄昏暖调 | 工位、显示器、落地窗 |
| 餐饮后厨 | 灶台区，灶火暖光 + 排烟罩冷光，蒸汽油烟 | 灶台、铁锅勺铲、不锈钢台 |
| 餐馆前厅/小店/市集摊 | 店面或摊口，招牌灯与日光混合，市井暖黄 | 货架/收银台、招牌（无真实品牌字） |
| 驾驶室/长途货运 | 车舱内，挡风玻璃天光 + 仪表盘冷光 | 方向盘、后视镜、窗外公路 |
| 城市街面/骑行配送 | 街道，街灯 + 车流光 + 建筑窗光混合 | 电动车、配送箱（无平台标识）、人流 |
| 汽修/机械手艺 | 地沟或工位，顶灯 + 局部工作灯，油污环境 | 举升机、工具柜、零件 |
| 理发/裁缝/市井手艺 | 老店面，窗光 + 顶灯，暖旧 | 工具椅/缝纫机、布料、镜子 |
| 片场/摄影棚/创作工作室 | 棚内可控光（柔光箱/电影灯），背景常深色 | 摄影机、灯架、反光板 |
| 实验室/科研台 | 荧光灯均匀冷白，洁净 | 试剂架、显微镜、白大褂（按装束段） |
| 山野/户外向导/运动场 | 自然光（山影/场地泛光） | 地形剪影、背包、场地线 |

**不在表内**：按"该职业最常见的工作空间 + 默认光质"推断，档案标"推断"，并向用户说明可改。

## 二、职业装束速查（全部无标识通用款）

规则：出现表内职业，取对应装束；**一切真实机构符号抹掉**，替换为"素色/无字/通用款"。年代设定（如"90年代国营厂"）可把款式旧化，不做史实考证。

| 职业（用户词） | 装束（无标识通用款） |
|---|---|
| 工厂工人 | 深蓝/灰工装连体或工装裤，棉质耐磨，安全帽或防尘口罩挂脖 |
| 建筑工 | 荧光安全背心（无字）、工地靴、黄色安全帽、耐磨工装 |
| 农民/农户 | 旧衬衫或汗衫、草帽/斗笠（按年代）、雨靴或布鞋、袖套 |
| 渔民 | 防水连体裤或深色旧衣、橡胶围裙、防雨帽 |
| 医生 | 白大褂内搭蓝/白刷手服或衬衫、听诊器（手术语境加手术帽口罩） |
| 护士 | 素色护士服（浅蓝/粉白，无徽章）、盘发或发网 |
| 警察/治安 | 深蓝制服式上衣（无警徽警号胸牌），街面可加反光背心 |
| 消防员 | 藏青/黑色防护服 + 银灰反光条（无字）、防护头盔 |
| 军人 | 通用迷彩作训服（无军衔、无臂章徽记） |
| 教师 | 衬衫 + 便装外套或中山装（按年代），眼镜随人设 |
| 白领/文员 | 衬衫 + 西装外套或通勤装，无工牌或素色工牌 |
| 厨师 | 白色厨师服、围裙、厨师帽或束发巾 |
| 店员/摊主 | 素色围裙 + 便装 |
| 货车司机 | 旧 T 恤或 Polo、遮阳袖套 |
| 骑手/外卖/快递 | 亮色（黄/蓝/绿）素色工服、头盔、配送箱（无品牌字） |
| 汽修工 | 深色连体工装、油污手套 |
| 理发师/裁缝 | 素色围裙（市井款） |
| 摄影师/片场人员 | 多口袋马甲（无字）、黑 T 恤、棒球帽 |
| 科研人员 | 白大褂内便装、护目镜（按语境） |
| 户外向导/教练 | 机能外套、户外靴、口哨绳 |

**无对应职业**：不硬造装束；把用户提到的工作环境转成"该环境下最常见的实用穿着"，档案标"推断"。

## 三、职业体貌印记表（环境在身体上留下的痕迹）

同一年龄档上叠加"环境增量"。取景半身时重点看**脸/颈/手臂/手**。用户没提职业但提了环境词（"常年跑船、风吹日晒"）时同样查本表。

| 印记来源 | 可绘印记 |
|---|---|
| 户外日晒（农/渔/建筑/向导） | 面颈与手臂日晒色差线明显，肤质粗粝，眼周晒纹，颧部色斑 |
| 焊工/炉前工 | 防护面罩覆盖区肤色浅于暴露区（面具形晒痕），前臂小烫疤（克制） |
| 粉尘车间/重尘作业 | 肤色卡灰（灰尘沉积的色感），近距离毛孔明显，手部干燥皲裂 |
| 体力搬运/重劳 | 虎口与掌根厚茧，指甲磨损，惯用侧肩颈肌略发达 |
| 后厨 | 前臂与手部旧烫痕（小而浅），手部偏干，臂肌结实 |
| 医疗 | 双手常洗偏干净细致，指节无茧，仪态端正（久站不强调） |
| 教师/白领 | 久坐体态（肩略前收），镜架鼻托压痕（若戴镜） |
| 骑手/司机 | 面颊风霜色差，前臂日晒分界，虎口握把茧 |
| 汽修/机械手艺 | 指缝油污沉淀细线，指甲剪短偏脏，手背旧伤疤（克制） |
| 冷库/低温作业 | 面颊与鼻尖泛红血丝（可选） |

**叠加规则**：皮肤印记 = 年龄档皮肤基线 + 本表环境增量；两者矛盾时（如白领却晒痕深）以环境增量为准（说明有户外活动），档案注明。

## 四、组合与冲突规则

- 用户给了职业没给场景 → 场景取表一该职业对应行。
- 职业与场景冲突（"白领，但在地下直播间当主播"）→ **场景决定背景与光线，职业决定装束**，两行分别填，档案注明取舍。
- 环境带年代（"90年代纺织厂"）→ 装束旧化 + 色调偏年代（胶片暖/冷），不做史实细节考证。
- 用户要"角色设定图/转面" → 背景浓度自动降为轻档（仅光质保留），人物为主体。
- 用户要"剧照感/氛围图" → 背景浓度重档，环境道具入画。

## 五、合规红线（硬性）

- **无真实标识**：军/警/政/校/企/平台徽章、警号胸牌、臂章、品牌字、LOGO 一律"无标识/素色/通用款"；制服戏服级呈现。
- 不渲染血腥、事故、火场实况、伤亡、犯罪现场细节；救援/警务只给工作常态或现场外围。
- 职业不作性格、阶层、道德的正负联想；用户气质断语才承载性格。
- **支持未成年角色**：可呈现学生、家庭、日常环境；不呈现危险、剥削性或高强度劳动中的儿童形象（与既有"不渲染事故/血腥"红线一致）。
- 危险装备（枪械等）不主动入画；用户明确要求时作道具级呈现，配合"虚构影视角色"边界。
