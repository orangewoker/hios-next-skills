# 电影分镜设计规范

## 目的

把故事节点转换成一条可拍、可剪、可被 Seedance 2.5 理解的镜头链。分镜不是给剧情换行，也不是摄影术语清单；每个镜头必须承担独立功能，并通过构图、调度、光影、运动和声音改变观众获得信息的方式。

## 一、先确定镜头功能

为每个镜头只指定一个主要功能，必要时附带一个次要功能：

- 钩子：立即暴露异常、危险、结果或未完成动作；
- 建立：交代人物、空间关系和世界规则；
- 聚焦：把注意力引向关键表情、物体或细节；
- 阻力：让目标受阻、规则被打破或代价显现；
- 升级：提高尺度、速度、危险、情绪或视觉强度；
- 揭示：提供会重新解释前文的新信息；
- 高潮：兑现最重要的动作、情绪或视觉奇观；
- 收束：完成反转、余味、定格或首尾循环。

如果两个相邻镜头承担完全相同的功能，合并或删除其中一个。

## 二、从信息控制出发设计镜头

先回答三个问题：

1. 观众在这个镜头开始前知道什么？
2. 镜头结束时新增了什么信息或感受？
3. 为什么必须换镜头才能获得它？

只有当信息、权力关系、情绪、空间关系或视觉状态发生变化时切镜。不要为了节奏快而机械切换。

## 三、判断开场是否需要定场镜头

先判断空间可读性是否是理解事件的硬约束。若观众不先理解地点、人物方位或环境规则就无法看懂后续动作，必须用全景、远景或具有完整空间关系的中远景开场。对于以单张环境概念图、公共空间、群像或复杂行动路线为基础的短片，通常优先判定为需要定场镜头。以下任一条件成立时，优先使用定场镜头：

- 场景本身是核心卖点，如架空城市、工坊、庙会、巨型建筑、特殊地貌；
- 后续动作依赖门、桌椅、街道、上下层、人物方位或逃生路线；
- 群像关系、人物数量或社会秩序需要先被看懂；
- 尺度对比、孤独感、压迫感或世界观主要来自环境；
- 多镜头连续性需要一个明确的空间锚点。

定场镜头不等于缓慢空镜。让主体已经在行动、异常已经发生，或让环境中存在一个可被立即发现的变化。开场全景应同时完成“交代空间”和“提出问题”。

允许先特写后全景，但把它视为有条件的冷开场。以下任一条件成立时可以先用特写：

- 特写内容本身就是最强钩子，如机械眼突然启动、手中关键物碎裂、异常伤口、即将落下的机关；
- 需要暂时隐藏主体身份、尺度或空间真相，随后用全景完成揭示；
- 特写动作能在一秒内产生明确问题，而全景能立即回答“它在哪里、影响了谁”；
- 输入概念图的核心审美集中在一个不可替代的细节，先展示细节能显著提高观看意愿。

使用特写冷开场时遵守：

1. 在紧接的下一镜或前几个镜头内补上全景、远景或清晰空间关系；
2. 特写与定场镜头通过动作、声音、视线或物体位置建立关系，不能像两个无关画面；
3. 不为制造悬念而故意隐藏所有信息；
4. 若故事依赖复杂空间调度，不连续使用多个无坐标特写。

自动判断顺序：先问“观众是否必须先理解空间才能看懂事件”；若是，用定场镜头。若否，不预设景别，再比较全景事件与细节异常谁能在前几秒提出更强问题；细节明显更强时可用特写冷开场，并尽快回到空间全貌。空间可读性是硬门槛，钩子强度是通过门槛后的选择标准。用户明确指定开场方式时优先服从，但若会破坏可读性，在风险提示中说明。

## 四、选择主观距离

景别代表观众与事件的心理距离：

- 超远景、远景：强调世界、尺度、孤独、处境和路线；
- 全景：展示完整身体、动作路径和人物间距离；
- 中景：平衡表演、动作与环境，适合大多数叙事动作；
- 中近景：突出关系变化、视线和上半身表演；
- 特写：强调决定、恐惧、欲望、触感或关键物体；
- 极特写：制造信息缺口、异常或强烈感官刺激。

不要每个镜头都追求大景别跳变。景别变化应对应叙事压力：通常由远到近表示逼近与聚焦，由近到远表示揭示处境、失去控制或情绪释放。

## 五、选择机位与视点

- 平视：相对中性，适合建立可信世界；
- 低机位：强化力量、威胁、尺度或神性；
- 高机位：表现脆弱、被控制、图案与空间关系；
- 过肩：建立人物对峙和视线关系；
- 主观视角：让观众共享角色的发现、危险或身体经验；
- 客观观察：制造疏离、宿命感或让环境压过人物；
- 贴近物体的非人视角：适合工具、动物、机器、植物和材料的微观事件。

同一段落不要无理由频繁改变视点。视点改变应标志信息权、情绪或身份发生变化。

## 六、决定摄影机是否需要运动

静止机位同样是主动选择。只在以下情况下使用运镜：

- 跟随：主体移动，摄影机保持关系；
- 发现：移动后揭示原先被遮挡的信息；
- 逼近：逐步增加心理压力或注意力；
- 退出：释放压力、揭示后果或扩大尺度；
- 环绕：改变人物关系、暴露空间或制造命运感；
- 失衡：短暂手持、侧倾或高速运动表达失控；
- 转移：从一个主体自然交接到另一个主体。

避免在同一镜头同时要求推、拉、摇、移、升降和环绕。优先选择一条主要相机路径。人物静止时允许环境或摄影机运动；人物动作复杂时优先简化摄影机运动。

## 七、判断是否使用快切镜头组

把快切视为一个有共同目的的“镜头组”，不是随意缩短所有镜头。以下任一条件成立时可以使用：

- 一个事件在多个位置同时引发连锁反应；
- 需要快速表现机械启动、准备流程、搜寻、组装、追逐或秩序失控；
- 需要压缩重复过程，只保留具有差异的关键节点；
- 情绪或危险正在加速，单个长镜头无法形成所需的节拍；
- 需要在高潮前连续提高信息密度，然后以长镜头或静止镜头释放压力。

以下情况不使用快切：

- 空间关系尚未建立，观众会不知道人物在哪里；
- 每个短镜头只是同一动作的不同角度，没有新信息；
- 核心表演依赖细微表情、等待或犹豫，需要时间被看见；
- 主体身份、服装或机械结构本就容易漂移，过多角度会增加不稳定；
- 只是为了显得“像预告片”或掩盖故事没有变化。

先检查禁用条件：只要空间可读性、动作连续性或主体身份稳定性尚未满足，就暂不使用快切，即使事件本身适合加速。通过这些门槛后，再判断快切是否能压缩过程、表现传播或提高节拍。

快切镜头组默认由 2–4 个短镜头组成，每个镜头只承载一个简单、可读的动作或反应。镜头组之前优先已有定场镜头，镜头组之后用一个相对稳定的镜头重新确认结果、人物位置或情绪。让多个短镜头共享至少一种连接：相同动作方向、逐级增强的声音、同一物体、相近构图、因果链或连续视线。

一条30秒短片通常最多使用一个快切镜头组。只有第二组承担明确不同的功能，例如前一组表现准备、后一组表现高潮传播，并且不会造成主体漂移或切点过载时，才允许使用第二组。

最终提示词把快切写成一个主分镜下的子镜头，避免把它误计为多个完整叙事段落：

```text
分镜3（快切镜头组）：
3A：木齿轮依次咬合；
3B：三根簧片连续弹开；
3C：桌上酒碗被震得同时跳动；
3D：工匠抬头，声音突然停止。
四个短镜头沿同一声音节拍递进，最后切回稳定中景确认机关已经启动。
```

不必机械标注每个子镜头时长；只有节奏必须精确时才给整个快切组建议时间范围。

## 八、设计场面调度

明确：

- 人物从画面哪一侧进入和离开；
- 人物与目标物的距离如何变化；
- 前景、中景、背景分别承载什么；
- 谁占据画面主导位置；
- 光域、遮挡物和空间边界如何影响动作；
- 动作结束时人物停在哪里，为下一镜留下什么状态。

用位置变化表达关系变化。例如：隔着巨大负空间表示疏离，进入同一光域表示关系建立，越过中轴表示权力逆转。

## 九、判断是否需要群像反应镜头

群像反应镜头用于证明“事件不仅影响主角，也改变了现场秩序、社会关系或危险等级”。只有群体反应能新增叙事信息时才使用；公共空间和周围人物本来就在场，只说明这个镜头可用，不构成单独的使用理由。以下至少一项叙事增量成立时使用：

- 群体的理解、恐惧、敬畏、嘲笑、退让或沉默会改变主角的处境；
- 需要通过不同反应说明这个世界如何看待异常事物；
- 需要放大事件规模，或在主角动作后给观众一个必要的情绪回声；
- 群体反应会形成下一步动作，如让路、围堵、逃散、跪下、举起工具或停止交谈；
- 某个代表性反应揭示了主角不知道的信息、职业判断或社会规则。

以下情况不使用：

- 群体只是背景装饰，对事件没有不同于主角的新信息；
- 需要临时新增大量人物才能成立；
- 主角正处于私密决定、细微表演或孤独状态，切走会削弱情绪；
- 群像反应会打断关键动作的因果连续；
- 所有人只做相同的夸张表情，形成模板化“齐刷刷震惊”。

先判断群体反应的叙事作用，再选择形式：

### 单镜群像反应

使用全景或中远景，在同一画面中呈现前、中、后景的不同反应。适合空间关系重要、人物较多、需要保持整体秩序的场面。优先让反应有层次：最近者本能避让，中景人物停下动作，远处人物尚未察觉。

### 代表性反应切镜

只选择 2–3 个具有不同信息的代表反应，不逐个展示所有人。例如：一名熟练工匠立刻看懂故障、一名食客恐惧后退、一名孩子反而靠近。每个反应都必须补充新的社会信息或情绪层次。

### 群像快切组

当异常迅速传播或高潮需要节奏加速时，把 2–4 个代表反应组织为快切组。使用共同声源、视线方向或动作递进连接，并在组后回到主角或事件主体。不要让群像快切替代核心事件本身。

群像反应默认使用输入画面中已经存在的人物，不无理由增加新角色。保持人物在空间中的原有方位，避免反应镜头后所有人位置重置。反应动作优先具体化为停筷、放下工具、后退半步、护住货物、让开路径、压低声音等，而不是只写“众人震惊”。

自动判断顺序：先问“群体反应是否改变事件的规模、压力、世界规则或下一步动作”；若没有，省略。若有，再问“空间整体反应是否比个人表情更重要”；若是，用单镜群像反应；若否，选择少量代表性反应。只有传播速度和节拍本身重要时，才使用群像快切组。

## 十、保持空间和动作连续

多镜头叙事优先保持：

- 银幕方向：角色向右移动后，下一镜继续向右，除非明确表达迷失或逆转；
- 视线匹配：角色看向画外右侧，下一镜目标应出现在符合视线的位置；
- 动作匹配：前一镜动作进行到一半切出，下一镜从同一动作阶段接续；
- 轴线稳定：双人对峙默认保持人物左右关系，不无理由越过180度轴线；
- 道具连续：位置、握持手、开合状态和破损程度保持一致；
- 光线连续：主光方向与阴影投射保持一致，除非光线变化就是事件；
- 情绪连续：表演强度逐级变化，不在切镜后突然归零。

需要越轴时，用移动镜头穿越轴线、中性正面镜头或明确的空间重建完成。

## 十一、建立镜头链

默认把短片控制在 4–6 个主要镜头，并按故事需要调整。推荐功能链：

### 微剧情

```text
分镜1 钩子
→ 分镜2 建立主体与目标
→ 分镜3 阻力出现
→ 分镜4 状态升级或关系逆转
→ 分镜5 揭示与高潮
→ 分镜6 收束或循环
```

### 故事—展示混合

```text
分镜1 视觉异常
→ 分镜2 极简事件启动
→ 分镜3 美术规则第一次变化
→ 分镜4 阻力推动视觉升级
→ 分镜5 标志性高潮
→ 分镜6 余味定格
```

### 纯视觉展示

```text
分镜1 最强视觉承诺
→ 分镜2 建立核心视觉规则
→ 分镜3 改变一个变量
→ 分镜4 改变第二个变量
→ 分镜5 尺度或材质跃迁
→ 分镜6 封面级定格或循环接口
```

不要强制凑够六镜。一个镜头能完整承担两个连续功能时可以合并；一个高风险动作过载时可以拆分。

## 十二、设计转场

优先使用有因果或视觉依据的转场：

- 动作匹配：相似动作在不同主体或空间中接续；
- 视线切换：角色看向某处，切到被观看对象；
- 遮挡转场：人物、布料、物体或黑暗掠过镜头；
- 形状匹配：相似轮廓、构图或纹理连接两个画面；
- 运动匹配：保持运动方向和速度；
- 光线切换：过曝、熄灭、闪烁或进入阴影；
- 声音桥：下一镜声音提前进入，或上一镜声音延续；
- 硬切：用于冲击、反差、骤停和状态断裂。

不要把所有镜头都用复杂转场连接。强烈的硬切往往比无动机的炫技转场更有效。

## 十三、控制短视频节奏

- 前段快速建立问题，不用多个镜头重复介绍环境；
- 中段通过状态变化维持注意力，不仅靠缩短镜头长度；
- 高潮前可以延长镜头、降低声音或短暂停顿，以制造释放空间；
- 结尾至少保留一个能被辨认的视觉状态，不在高潮发生后立即仓促结束；
- 允许一个关键镜头比其他镜头更长，形成节奏重心。

节奏快不等于镜头多。镜头内部的动作、景别变化和信息揭示也能产生节奏。

## 十四、逐镜写作格式

最终提示词中的每个分镜按以下顺序写成自然语言，不必显示字段标签，但信息应完整：

```text
分镜N（可选建议时间段）：
镜头功能；主体位置与动作；景别、机位和构图；主要相机路径；光影与环境动态；声音；结尾状态与下一镜衔接。
```

示例：

```text
分镜1（建议0–3秒）：视觉钩子。极近特写，一只沾着灰尘的手停在发光门缝前，指尖尚未触碰，门后的强光却突然像呼吸一样收缩；固定机位，只有手指轻颤和光线脉动。低频电流声先出现，门缝骤然熄灭时硬切到下一镜。
```

避免写成镜头参数表。让每个分镜仍然是一段明确、连贯、可执行的导演指令。

## 十五、分镜自检

逐镜确认：

- 删除这个镜头后，故事或视觉是否没有损失？若是，删除；
- 镜头开始和结束的状态是否不同？
- 主体、动作、空间和摄影机是否都能被同时执行？
- 是否只有一条主要相机路径？
- 下一镜是否继承人物位置、动作、视线、光线或声音中的至少一项？
- 是否把最复杂的动作和最复杂的运镜叠在同一镜头？若是，简化其中一个；
- 高潮镜头是否拥有最强的信息、尺度、表演或视觉变化，而不只是最复杂的运镜？
