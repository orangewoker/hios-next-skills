# 垂类锁定规则

只在 `专业影视 / MV` 与 `专业影视 / 风格美学` 中选择一个。以下标准用于判定，不是让成片同时满足两个类别。

## 专业影视 / MV

满足下列核心证据时锁定 MV：

- 音乐是时间结构的主驱动，不是后期随意铺底；
- 画面与引子、主歌、副歌、桥段、drop、尾奏等音乐段落有明确对应；
- 关键动作或微动作、剪辑点、运镜变化、光线/空间变化落在可指出的节拍或乐句上；
- 成片用于歌曲表达、音乐发行、艺人形象、表演或音乐主题内容。

优质方向：音乐段落与画面段落完整对应；视觉系统统一但随音乐发展；高潮在动作、凝视、构图、色彩、光线、声音或空间中至少有一种明确升级；开头与结尾呼应；封面具备成片级构图。情绪文艺 MV 可以克制、缓慢、留白，但不能缺少音乐与画面的结构对应。

仅有“DJ、耳机、舞台、节奏感”等元素不自动等于 MV。没有音频结构证据时，应锁定风格美学。

## 专业影视 / 风格美学

满足下列核心证据时锁定风格美学：

- 视觉风格、艺术实验或情绪氛围是核心；
- 不要求五要素叙事，但必须有统一视觉主题或可辨识的情绪曲线；
- 抽象、超现实、卡通或非写实都可以，但材质、光影、空间和运动逻辑需保持审美一致；
- 视觉符号应重复、演变或首尾呼应，不能只是随机好看片段拼接。

优质方向：视觉符号清晰；风格有阶段性演变；情绪由冷到暖、疏到密、静到动等变化可被观察；构图、色彩、材质和灯光服务同一主题。

## 明确排除

- 教程录屏、步骤讲解、工具经验分享：归社交媒体教学/经验分享。
- 具有主角、任务、动机、连贯冲突和结局的虚构作品：优先短片剧集。
- 直接推动产品购买、价格或优惠转化：电商广告。
- 以品牌精神、价值观或公益倡议为主：创意 TVC / 公益广告。
- 基于成熟动漫或游戏 IP 的重制、改编或同人：经典衍生。
- 动态漫画、二维/三维动画叙事：精品漫画 / 动画短片。

## 判定输出模板

```text
category_lock: 专业影视 / MV
evidence: 音乐段落驱动画面结构；关键动作与节拍绑定；用途是音乐表达。
rejected_nearby_category: 风格美学——本项目不是只靠视觉情绪成立，音乐是不可替代的时间骨架。
```
