# 套图一致性与系列感

这些是**可适配的模式与句式**，按场景改写，不要逐字照搬。

## 三不变一变

- **不变 1｜材质**：整套图用同一组质感描述（同一份指纹/接缝/哑光措辞，逐字复用）
- **不变 2｜光色**：同一光源方向与点睛色（如全部左侧灰蓝月光 + 暗红点睛）
- **不变 3｜镜头家族**：同一构图逻辑（如全部浅景深特写，或全部正面凝视构图）
- **一变｜主体与动作**：每张只换主体、形变部位与叙事瞬间

## 系列叙事结构（三图一组为例）

1. 图 1｜正常表象：主体略歪，第一处细微形变藏在角落
2. 图 2｜形变升级：异常扩大，观者确认"这世界不对劲"
3. 图 3｜定格余韵：形变停在静止的诡异瞬间，留一个未解细节

三图组合成"发现异常 -> 确认异常 -> 与异常共处"的微型叙事。

## 角色一致性

多图同一角色时：造型取向（大头小身/细长/矮胖）、面部锚点（玻璃珠眼、歪鼻梁）、服装与点睛色必须逐字一致；只允许新增与剧情相关的形变。

## 落 prompt 前自检

- 整套的材质/光色/镜头描述是否逐字一致？
- 每张是否只变了主体与动作？
- 系列叙事是否有递进关系而非同义重复？
