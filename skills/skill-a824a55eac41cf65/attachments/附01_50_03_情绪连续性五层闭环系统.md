## 一、核心铁律

AI生成视频，擅长单帧，不擅长连续情绪。\
五层闭环，缺一不可。\
设计层是地基，执行层是钢筋，验证层是质检，剪辑层是装修，升华层是灵魂。\
哲学主题是地基，哲学升华是屋顶。

## 二、五层闭环总架构

1. **第一层：设计层**——情绪连续性施工图 + 哲学锚点
2. **第二层：执行层**——锚点注入 + 哲学提示词 + 分帧生成
3. **第三层：验证层**——情绪对齐验证 + 哲学对齐验证 + 元叙事对齐验证
4. **第四层：剪辑层**——剪辑补偿 + 哲学余韵设计 + 元叙事余韵设计
5. **第五层：升华层**——元叙事彩蛋 + 不确定性美学 + 哲学金句

## 三、第一层：设计层

**核心内容：**

1. **微表情矩阵**：每个角色建立“情绪阶梯”（平静→微动→紧张→爆发→收束），每个情绪状态对应固定锚点ID。
2. **情绪锚点ID**：格式 `[角色缩写]-EMO-[两位数字]`，跨节点强制复用。
3. **对话节奏锁定**：每句台词的起始秒、停顿秒、重音秒。
4. **情绪过渡帧**：格式 `[角色缩写]-TRANS-[两位数字]`，A情绪到B情绪的物理因果链。
5. **哲学锚点ID**：格式 `[角色缩写]-PHIL-[两位数字]`，全片主题递进。
6. **元叙事锚点ID**：格式 `[角色缩写]-META-[两位数字]`，打破第四面墙的设计。

**强制执行**：没有设计层，禁止进入执行层。

## 四、第二层：执行层

**核心内容：**

1. **锚点注入法**：每次生成图片/视频时，提示词开头强制注入锚点ID。
2. **分帧生成法**：AI无法一次生成“从A情绪到B情绪”的连续过渡，必须人工拆分生成过渡帧。
3. **对话节奏标注法**：用时间轴标注对话节奏，让AI生成时对位。
4. **角色圣经**：每个角色的详细人物小传，生成每一场戏时喂给AI。
5. **倒推法写剧本**：先定高潮和结局，倒推角色在每个关键节点的情绪状态。
6. **哲学提示词注入**：每条提示词里加入哲学阶梯。

**强制执行**：禁止让AI“自由发挥”情绪；过渡帧必须单独生成。

## 五、第三层：验证层

**核心内容：**

1. **情绪曲线对齐验证**：AI生成的每一帧情绪状态，对照施工图的情绪曲线。
2. **锚点ID一致性验证**：跨场景、跨集时，对比同一个角色的锚点ID，看脸是否漂移。
3. **对话节奏验证**：AI生成的台词与画面同步，看是否对得上施工图的对话时间轴。
4. **情绪过渡帧验证**：检查A情绪到B情绪之间，是否有过渡帧。
5. **哲学对齐验证**：AI生成的内容是否符合哲学锚点。
6. **元叙事对齐验证**：AI生成的内容是否包含元叙事彩蛋。

**强制执行**：情绪偏离必须重新生成；锚点漂移必须重新注入锚点。

## 六、第四层：剪辑层

**核心内容：**

1. **剪辑补偿手法**：硬切/叠化/音效，掩盖AI无法生成的过渡帧。
2. **哲学余韵设计**：用空镜+音效留白，让观众自己思考。
3. **元叙事余韵设计**：用打破第四面墙的特写，让观众意识到“自己在看戏”。
4. **人机协同分工**：人类负责筛选、剪辑补偿；AI负责生成候选镜头。

**强制执行**：情绪跳跃用硬切+音效；微表情断层用叠化+特写。

## 七、第五层：升华层

**核心内容：**

1. **元叙事彩蛋**：打破第四面墙，直接对观众说话。
2. **不确定性美学**：结局留一根刺，不完美。
3. **空镜留白**：用空镜+音效让观众自己思考。
4. **哲学金句**：一句让观众记住的话。
5. **主题呼应**：开场和结尾形成哲学闭环。

**强制执行**：真结局必须包含元叙事彩蛋；所有正结局必须留一根刺。

## 九、哲学主题与哲学升华的区别

- **哲学主题**：故事探讨的核心命题（个人vs体制、规则漏洞、人性复杂性）。
- **哲学升华**：把主题提升到“元层面”（打破第四面墙、元叙事、不确定性美学）。
- **哲学金句**：一句让观众记住的话。

哲学主题是地基，哲学升华是屋顶。\
没有地基，屋顶飘在空中。没有屋顶，地基埋在地下。
