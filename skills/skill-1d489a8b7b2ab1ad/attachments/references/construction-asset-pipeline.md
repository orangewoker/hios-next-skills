# 建筑四图资产管线

## 全局不变量

四张图必须保持同一建筑身份、稳定的 2.5D 斜侧等距偏俯视、居中构图、同一光照方向、单体建筑范围和近距离环境逻辑。镜头以约 30-45 度水平斜侧角和约 20-35 度俯角观察，清楚同时展示正立面与一侧侧立面/进深结构；禁止完全正视立面、扁平正交前视或看不见侧面深度的构图。建筑主体在完整图中占 70% 以上视觉面积。默认横版 16:9；图中不得有文字标签、箭头、广告、现代施工机械、脚手架或临时支撑。

`model_showcase`：使用 `context_policy` 排除人流、车流、复杂城市背景与无关物件。`real_environment_timelapse`：遵循 `environment_policy`，允许稳定且与地点相符的道路、广场、植被、远景和少量背景行人/车辆作为环境基准，但不得让它们遮挡建筑、成为主体或混入施工纪录片元素。

## 1. `building_complete_reference`

```text
生成一张「{building_identity}」的单体建筑完整模型图。

建筑风格：{architecture_style}。建筑特征：{silhouette}。材料与色彩：{material_palette}。环境模式：{environment_mode}。{environment_policy}。突出建筑体量、正面结构、可见的一侧侧面/进深结构、顶部/屋顶形式、入口、立面、台基或基础。

视角为稳定 2.5D 斜侧等距偏俯视：约 30-45 度水平斜侧、约 20-35 度俯角，正立面与一侧侧面都清楚可见；构图居中、对称、清晰，像展示一栋独立建筑模型；建筑主体占画面 70% 以上。禁止完全正视、扁平立面图或隐藏侧面结构。统一自然光，适合作为后续从地基到完成的建造动画参考图。

`model_showcase` 时：不要人物、车辆、广告牌、文字标识、现代机械、脚手架、临时支撑或无关元素。`real_environment_timelapse` 时：允许远中景的少量行人、合理道路车流、植被和地点周边作为固定环境基准，但不要让其遮挡建筑、出现可辨识肖像、广告牌、现代机械、脚手架或临时支撑。{context_policy}
```

## 2. `building_exploded_reference`

必须实际引用 `@[building_complete_reference]`：

```text
使用 @[building_complete_reference] 作为「{building_identity}」建筑身份、2.5D 斜侧等距偏俯视角度、构图、比例、材料和整体外观的唯一来源。

生成一张建筑结构拆解图/爆炸图。保持同一 2.5D 斜侧等距偏俯视、中轴线、可见侧面进深和 `{environment_mode}` 的地点环境逻辑，将建筑按以下合理建造层级上下错开但保持主体对齐：{construction_layers}。每层清楚、干净、可辨认，清晰表现装配关系；像高质量建筑说明图，但不加文字编号、标签或箭头。真实环境模式下背景环境保持静止且克制，只作为地点连续性基准。

不得重新设计建筑外观、改变屋顶/顶部、替换材料或加入人物、现代机械、脚手架、临时支撑、文字或无关建筑。
```

## 3. `building_materials_reference`

必须实际引用 `@[building_complete_reference]` 与 `@[building_exploded_reference]`：

```text
使用 @[building_complete_reference] 锁定「{building_identity}」的外观、材料与色彩；使用 @[building_exploded_reference] 锁定合理构件层级和关键部件。

生成一张建筑材料与构件展示图。用与完整建筑一致的 2.5D 斜侧等距视角，把该建筑的主要材料和关键构件整齐排列为施工材料展示板：{按 construction_layers 提取的基础/台基、柱墙/框架、门窗/栏杆/入口、梁架/承重、屋顶/覆盖层、立面/装饰、特色构件}。每项是清晰的实物小样或独立构件模型，分组整齐、尺度可信，质感与 {material_palette} 一致。

不要文字标签、人物、现代机械、脚手架、广告、随机杂物或无关建筑。
```

## 4. `building_process_reference`

必须实际引用 `@[building_complete_reference]`、`@[building_exploded_reference]` 与 `@[building_materials_reference]`：

```text
使用 @[building_complete_reference] 锁定完整建筑外观、角度和构图；使用 @[building_exploded_reference] 锁定建造层级；使用 @[building_materials_reference] 锁定材料和关键构件。

生成一张 8 格建筑建造流程图，主题是「{building_identity}」从空地基到完整建筑。8 格全部使用统一的 2.5D 斜侧等距偏俯视（相同 30-45 度斜侧、相同 20-35 度俯角）、统一构图、统一光照和同一 `{environment_mode}` 环境逻辑，建筑始终居中且能看见同一侧面进深；模型展示只保留基础近景，真实环境模式则锁定同一道路/广场/植被/周边尺度作为背景基准。

八格顺序：
1. 空地基或底部基础出现。
2. 基础层、平台、台基或楼板形成。
3. 楼梯、栏杆、边界、入口或基础细节完成。
4. 柱子、墙体、门窗或主体框架竖立。
5. 梁架、承重结构、楼层或中间结构安装。
6. 屋顶骨架、顶部结构或主要外形完成。
7. 屋面、外立面、装饰件和关键特色构件接近完成但仍未完全收口。
8. 完整建筑最终呈现。

每格有明显递进关系，第 7 格与第 8 格不能相似。不要文字编号、文字标签、箭头、人物、车辆、现代机械、脚手架、临时支撑、广告牌或复杂背景。
```

## 依赖中断处理

任一前序图未生成、被用户否决或因风格/外观/角度变更而失效时，后续图不得继续生成或复用。先更新最早受影响资产，再沿依赖链重新生成后续资产。
