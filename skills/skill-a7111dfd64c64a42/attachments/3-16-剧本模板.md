# 广告剧本模板库

剧本由 AI 在第五阶段自动生成，或用户上传导入。本文档定义剧本生成的规则和模板。

---

## 一、剧本格式规范

每条剧本必须包含以下结构化字段：

| 字段 | 说明 | 必填 |
|------|------|------|
| 镜号 | 从1开始顺序编号 | 是 |
| 时长 | 该镜预计秒数 | 是 |
| 画面描述 | 画面内容、构图、商品位置、环境 | 是 |
| 台词/旁白 | 配音文字，标注（旁白）/（对话）/（独白） | 是 |
| 音效提示 | 背景音乐/环境音/特效音 | 否 |
| 产品露出 | 商品在画面中的展示方式 | 是 |

---

## 二、按时长的剧本结构

### 5秒剧本（2-3镜）

极致精简，一镜一信息。

| 结构名 | 节奏 | 适用场景 |
|--------|------|----------|
| **冲击型** | 震撼开场(1.5s) → 产品展示(2s) → 品牌logo(1.5s) | 品牌曝光、新品亮相 |
| **悬念型** | 疑问画面(2s) → 揭晓产品(2s) → Slogan(1s) | 引发好奇、社交传播 |
| **行动型** | 痛点画面(1.5s) → 产品解决(2.5s) → 行动指令(1s) | 促销转化、效果展示 |

### 15秒剧本（5-7镜）

短视频黄金时长，需要快速抓住注意力。

| 结构名 | 节奏 | 适用场景 |
|--------|------|----------|
| **痛点解决型** | 痛点呈现(3s) → 产品登场(2s) → 功能展示(5s) → 效果对比(3s) → CTA(2s) | 功能型产品、日常消费品 |
| **场景代入型** | 场景建立(2s) → 人物状态(3s) → 产品使用(5s) → 情感满足(3s) → CTA(2s) | 生活方式类、情感向品牌 |
| **节奏快切型** | 快剪吸引(2s) → 卖点1(3s) → 卖点2(3s) → 卖点3(3s) → CTA(4s) | 多卖点产品、科技感产品 |
| **故事微型** | 悬念钩子(3s) → 转折(4s) → 产品植入(5s) → 升华收尾(3s) | 品牌故事、情感营销 |

### 30秒剧本（8-12镜）

完整叙事空间，可承载品牌故事或多卖点深度展示。

| 结构名 | 节奏 | 适用场景 |
|--------|------|----------|
| **完整叙事型** | 钩子(3s) → 场景/人物建立(5s) → 冲突/需求(4s) → 产品登场(4s) → 卖点展示(6s) → 情感升华(4s) → CTA(4s) | 品牌广告、高端产品 |
| **多卖点展示型** | 开场(3s) → 卖点1+场景(5s) → 卖点2+场景(5s) → 卖点3+场景(5s) → 综合效果(4s) → CTA(3s) → 品牌收尾(5s) | 科技产品、多功能产品 |
| **对比论证型** | 问题呈现(4s) → 传统方案痛点(4s) → 产品登场(3s) → 解决方案展示(8s) → 数据/效果(4s) → CTA(4s) → 品牌(3s) | 功效型产品、B2B服务 |
| **情感共鸣型** | 生活切片(5s) → 情感铺垫(5s) → 产品自然植入(5s) → 情感高潮(5s) → 品牌理念(5s) → CTA(5s) | 节日营销、品牌温度 |

## 三、按广告目标的剧本策略

### 品牌曝光
- **核心**：让人记住品牌名/视觉符号
- **要求**：品牌名/Logo至少出现2次，Slogan收尾必须有
- **台词风格**：简洁有力，偏品牌调性表达
- **节奏**：不急不赶，留足品牌画面呼吸空间

### 促销转化
- **核心**：制造紧迫感，推动立即行动
- **要求**：价格/优惠信息清晰可见，CTA必须包含具体行动指令（"立即购买""限时抢购"）
- **台词风格**：口语化、有感染力、制造紧迫感
- **节奏**：前快后稳，前半段快速吸引，后半段给足决策信息

### 新品上市
- **核心**：制造期待感，突出"新"和"不同"
- **要求**：产品亮相有仪式感，至少1个差异化卖点重点展示
- **台词风格**：探索感、发现感，可用"全新""首发""颠覆"
- **节奏**：先抑后扬，有揭幕/揭晓的节点

### 活动引流
- **核心**：传递活动信息，引导参与
- **要求**：活动时间/入口/参与方式必须清晰，利益点前置
- **台词风格**：热情、有号召力
- **节奏**：信息密度高但不混乱，关键信息有视觉强化

## 四、台词/旁白写作规范

> 钩子/开场写法、CTA文案模板、情绪节奏曲线详见 `2-09-剧本生成详细规则.md` 第八至十节。

### 语速控制
- 中文旁白正常语速：每秒3-4个字
- 促销快节奏：每秒4-5个字
- 品牌舒缓调：每秒2-3个字
- **台词总字数必须与分配时长匹配**，Skill 自动校验

### 台词风格对照

| 风格路线 | 台词特征 | 示例 |
|----------|----------|------|
| 高端奢华 | 克制、留白、意象化 | "时间，只为懂得的人停留" |
| 自然清新 | 口语化、温暖、生活感 | "清晨第一口，是整个夏天的味道" |
| 促销爆款 | 直接、有冲击力、数字感 | "直降300，最后3小时，手慢无" |
| 科技未来 | 精准、理性、前瞻性 | "0.1秒响应，重新定义速度边界" |
| 国潮东方 | 诗意、典故、意境 | "千年匠心，一杯承古今" |
| 3D卡通/动画 | 活泼、拟人、趣味 | "嘿！我是小蓝，带你解锁新技能~" |

### 禁止用语（合规红线）
- 绝对化用语：最、第一、唯一、国家级、顶级、极致
- 虚假承诺：保证效果、100%有效、永久
- 诱导性用语：不买后悔、错过再等一年（除非确实是限时活动且属实）
- 贬低竞品：比XX好、吊打同行
- 医疗/健康类禁用：治愈、根治、药到病除

## 五、多商品套餐剧本规则

当广告包含多个商品时：

1. **主次分配**：主角商品占总时长60%，其余商品均分40%
2. **出场逻辑**：
   - 主角商品开场或压轴，至少出现2次
   - 配角商品穿插展示，每次有独立卖点
3. **统一主题**：多商品必须有统一场景或主题串联（如"周末露营套装""晨间护肤三步曲"）
4. **转场衔接**：商品间转场需自然，禁止硬切无逻辑跳跃

## 六、剧本生成输入参数

AI 生成剧本时，必须基于以下已确认参数：

| 参数 | 来源 | 用途 |
|------|------|------|
| 商品信息 | 第一阶段 | 确定展示重点 |
| 品类 | 第二阶段 | 选择剧本结构模板 |
| 视觉路线+风格 | 第二阶段 | 决定台词风格和画面调性 |
| 广告目标 | 第二阶段 | 选择剧本策略 |
| 目标受众 | 第二阶段 | 决定台词口吻和场景选择 |
| 时长 | 第二阶段 | 确定剧本结构和镜数 |
| 核心卖点 | 第五阶段前置确认 | 剧本核心信息 |
| 品牌元素 | 第四阶段 | 植入品牌信息 |

---

## 七、剧本输出格式

生成的剧本以结构化文本呈现给用户确认：

```
【广告剧本】
商品：[商品名]
时长：[X秒] | 风格：[风格名] | 目标：[广告目标]

镜1 [Xs]
画面：[画面描述]
台词：[台词/旁白内容]
产品露出：[商品展示方式]

镜2 [Xs]
画面：[画面描述]
台词：[台词/旁白内容]
产品露出：[商品展示方式]

...

【台词总字数】：XX字 / 预估时长：XX秒
【片头片尾占比】：XX秒 / 总时长XX秒 = XX%
```

用户确认后进入分镜阶段。
