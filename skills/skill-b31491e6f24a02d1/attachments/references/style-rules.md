# 风格锁定与风格隔离规则

> 本文件摘自完整系统，用于执行风格确认、风格层级、风格隔离和风格错误自查。

## 六、风格锁定编写规则

风格锁定不是把画面中已有的主体、场景、道具重新描述一遍，而是为本镜、本批镜头或全片建立可复用的整体呈现方式。风格提示词必须具备通用性，能够约束不同事物的渲染方式、媒介特征、线条逻辑、材质边界、光色基调和风格分离规则。

### 1. 生成前风格确认

在正式生成分镜脚本前，必须先确认风格来源：

1. 用户已给出明确风格：提炼为可执行的风格锁定提示词，并在分镜中精确引用。
2. 用户给出大段风格分析：压缩为“整体风格基调 / 场景风格 / 主体分类风格 / 材质与纹理规则 / 边界规则 / 缺漏提示”。
3. 用户未给风格：系统必须推荐一个适合故事与素材的风格，并给出可直接使用的风格提示词；若用户授权“你看着办”，则直接采用推荐风格。
4. 若风格信息存在缺口，必须在分镜脚本外部提示“风格缺漏”，说明缺的是场景风格、主体风格、材质规则、边界规则还是色彩策略。

### 2. 风格锁定字段职责

| 字段 | 职责 |
|---|---|
| 整体风格基调 | 定义媒介、渲染方式、时代感、整体视觉语言 |
| 场景风格 | 定义背景、空间、环境的绘制方式、纹理、光色倾向 |
| 主体风格 | 定义不同主体类别的造型语言、材质逻辑、线条/渲染边界 |
| 材质与纹理规则 | 定义哪些材质如何呈现，哪些纹理进入或禁止进入哪些区域 |
| 风格隔离规则 | 定义背景、角色、机械、路人、UI、道具等不同类别之间哪些风格可共享，哪些必须隔离 |
| 局部边界规则 | 定义本镜特有的不可破坏风格锚点与例外条件 |
| 风格缺漏提示 | 仅在风格信息不足时出现，且必须位于分镜脚本外部或作为可删除提示行 |

### 2.1 风格层级：全局风格 / 分类风格 / 局部边界

风格锁定优先采用三层结构，避免每个镜头重复粘贴完整风格提示词。

1. **全局风格**：定义全片或本批镜头的共同媒介、渲染方式、整体光色和质感基调。只在【风格确认区】完整写一次。
2. **分类风格**：定义不同对象类别的独立呈现方式，例如背景、成年主角、儿童路人、机械角色、怪物、UI屏幕、道具、光束。分类风格可以互相不同。
3. **局部边界**：只写本镜新增或特别需要强调的风格边界，例如“HUD为画内真实屏幕”“屏幕熄灭期间为绝对黑暗”“铅笔纹理不进入车灯光束”。

单镜头内部原则上只写引用式最小风格锁；若参考素材已确认，必须同时引用风格素材与色板：

```text
风格锁定：
引用全局风格：[风格名称]
引用风格素材：[@图_主体] [@图_场景]
引用色板：[@色板_段落]
本镜分类风格：[如本镜出现特殊主体，写清该主体沿用哪一类风格]
本镜局部边界：[只写本镜新增或容易混淆的风格/色彩/UI边界]
```

除非本镜风格发生变化，否则不得在每个镜头重复完整全局风格提示词。若无已确认风格参考图或色板，则使用 80–120 字风格胶囊，不得伪造 `@图_` 或 `@色板_` 引用。

### 2.2 风格锁长度原则

风格锁定不是越短越好，也不是全文复制；原则是：**写够用的，不写多余的。**

1. 没有新增风格边界时，只写引用式最小风格锁：全局风格名、风格素材 nodeKey、色板 nodeKey。
2. 出现新的光线、材质或空间约束时，写“参考风格 + 本镜局部边界”，局部边界控制在 1–3 句。
3. 出现新主体类型或明显风格偏移风险时，写“参考风格 + 分类风格 + 本镜局部边界”，明确该主体与其他类别的风格隔离。
4. 不得把完整视觉控制包逐镜复制，也不得把风格锁压缩到无法约束生成的空标签。

### 3. 允许内容

允许写入风格锁定：

- 媒介与渲染方式：photorealistic、modern Japanese anime background、semi-realistic 2D painted、cel-shaded、ink lineart。
- 线条与轮廓：subtle outlines、clean black ink lineart、rough crayon outlines、no sketch lines on machine。
- 场景光色基调：cool blue-grey ambient light、warm yellow interior light as the only emotional color accent。
- 主体分类呈现：机械角色、成年男主、路人、怪物、UI屏幕、HUD等不同类别的风格分离。
- 材质逻辑：worn rubber textures、faded moss-green paint、rust spots、clean specular reflections。
- 边界规则：划痕是否进入金属、铅笔纹理是否进入光束、HUD是否为画内真实屏幕、屏幕熄灭是否绝对黑暗。

### 3.1 多主体不同风格与材质隔离

当同一镜头或同一批镜头中存在多主体不同风格、背景与角色风格不一致、写实主体与插画主体并置、机械与人物材质逻辑不同、UI与真实屏幕并存时，必须显式写出风格隔离规则。

必须回答四个问题：

1. **谁使用哪种风格？** 例如：背景为 semi-realistic 2D painted，成年男主为普通日式动画人物，路人为儿童绘本蜡笔黑影。
2. **哪些风格不得互相污染？** 例如：儿童绘本蜡笔笔触不得进入成年男主、背景建筑和真实道具；背景的半写实渐变不得进入路人黑影。
3. **哪些材质规则只属于某一类主体？** 例如：机械角色有金属剥落、银色基体、雨痕和锈点；这些划痕规则不得进入人物皮肤和背景墙体。
4. **哪些画面元素是画内真实显示？** 例如：HUD、PARTIAL MATCH、屏幕文字、招牌、纸张文字只能作为画内真实物体存在，不得变成后期字幕或悬浮UI。

### 3.2 风格隔离模板

```text
风格隔离规则：
背景：[背景使用的媒介、渲染方式、线条/纹理/光色规则]
主体A：[主体A使用的风格、材质和渲染规则]
主体B：[主体B使用的风格、材质和渲染规则]
道具/UI/屏幕：[是否为画内真实显示，哪些文字允许出现]
禁止混用：[A风格不得进入B；背景纹理不得进入主体；某类划痕/线稿/蜡笔纹理不得进入哪些区域]
共享规则：[全片共同色彩、光影、颗粒、镜头质感；若无则删除]
```

### 3.3 多主体隔离合格示例

```text
风格隔离规则：
背景：modern Japanese anime background，semi-realistic 2D painted，overcast morning exterior and cold fluorescent interior，low-saturation blue-grey tones，subtle outlines，soft gradients，delicate material rendering。
成年男主：普通现代日式动画人物风格，干净线稿，半写实比例，低饱和上班服装，面部表情细节正常保留。
路人儿童：children's book illustration crayon stroke black silhouette figures，flat black fill，rough crayon outlines，no facial features，no clothing detail。
禁止混用：儿童绘本蜡笔笔触只作用于路人儿童黑影，不进入成年男主、背景建筑、室内家具或真实道具；背景的半写实渐变不进入路人黑影；成年男主不得被简笔黑影化。
共享规则：全镜使用低饱和蓝灰基调，阴天自然光与冷白室内荧光保持一致。
```

### 3.4 背景与机械主体隔离合格示例

```text
风格隔离规则：
背景：photorealistic urban environment，subtle graphite pencil sketch texture only in deepest shadows and crevices of brick and asphalt，clean specular reflections in puddles and glass，cool blue-grey ambient light，warm yellow interior light as the only emotional color accent。
机械角色：rounded industrial design with visible wear，faded moss-green paint with rain streaks and rust spots，worn rubber textures，field-repair welds，no pencil or sketch lines on the machine，distinct material logic，aging screen with backlight unevenness。
UI/屏幕：HUD界面为画内真实屏幕显示；PARTIAL MATCH提示为画内真实UI；屏幕熄灭期间为绝对黑暗。
禁止混用：划痕为全片机械材质锚点，只表现为金属剥落、银色基体和机械漆面磨损，不得变成铅笔痕迹；车灯光束边缘暗部可有铅笔纹理，但纹理不得进入光束内部；背景砖石铅笔纹理不得进入机械角色表面。
共享规则：冷蓝灰环境光统一全镜，暖黄室内光只作为情绪点缀。
```

### 4. 禁止内容

禁止把以下内容当作风格锁定：

- 只复述画面内物件：旧木桌、窗台、录音机、钥匙、门、花盆等。
- 只复述剧情状态：他回家、她等待、他们对峙、拆迁队敲门。
- 只复述构图或动作：位于画面左侧、走向门口、抱起花盆。
- 与风格无关的零件清单。
- 已由主体定义、空间与朝向、动作层、光影、色彩脚本承担的内容。

### 5. 大段风格提示词提炼规则

当用户提供大段风格分析时，不得原样塞入每个镜头。必须提炼为：

```text
风格锁定：
整体风格基调：[一句话概括整体媒介、类型、氛围]
场景风格：[背景/空间的通用呈现方式]
主体风格：[按主体类别分别定义：人物/机械/怪物/路人/UI/道具]
线条与上色：[线条、轮廓、阴影、上色方式]
材质与纹理规则：[皮肤/金属/玻璃/布料/屏幕等]
边界规则：[哪些风格只作用于哪些对象，哪些区域禁止混入]
```

### 6. 合格示例

```text
风格锁定：
整体风格基调：高细节日式动画 / 漫画插画，混合复古赛博朋克、黑暗奇幻、哥特机械与废土宗教视觉元素，冷峻、神秘、压迫，低饱和暗色基底配局部霓虹高光。
场景风格：semi-realistic 2D painted background，clean black ink lineart，cel-shaded coloring with hard edge shadows，复杂机械或建筑背景允许高密度内部细节线，暗部可有胶片颗粒与扫描纹理。
主体风格：人类角色为日式动画半写实比例，清晰外轮廓与硬边阴影；机械角色使用锐利硬边数字插画线条、切面明确、细节线密集；怪物允许粗糙漫画线稿与夸张比例。
材质与纹理规则：皮肤为哑光动画皮肤；皮革和玻璃使用锐利高光；金属与机甲使用硬边结构、螺丝、接口和局部磨损；霓虹、传感器、光环可带明显光晕。
边界规则：漫画线稿进入人物、服装、机械外轮廓和内部结构线；复古胶片颗粒只作用于整体画面质感，不改变主体身份；HUD 或屏幕文字必须是画内真实屏幕显示。
```

### 7. 不合格示例

```text
风格锁定：旧屋空荡，灰尘、木桌、窗台、拆迁前的冷清。角色动作克制。质感关键词：旧花盆、照片纸、窗台、走廊。
```

不合格原因：这只是重新描述画面内容，没有定义可复用的整体呈现方式。

### 8. 原有边界

**允许**：材质逻辑、表面处理、渲染方式、光影倾向、色彩倾向、媒介特征、主体类别风格分离、材质边界规则。

**禁止**：物理尺寸（应放在体型参数）、剧情状态、跨镜头记忆、与风格无关的零件清单、把主体/空间/动作字段内容重复写入风格锁定。

## 七、视觉控制包：风格与色板协同

风格控制和色板控制必须同时出现。风格控制回答“怎么画 / 怎么拍 / 什么媒介和材质逻辑”；色板控制回答“用什么色彩关系统一情绪、空间、主体身份和段落变化”。

### 1. 风格控制包必须包含

1. 简单风格描述：给用户快速理解。
2. 强风格锚定提示词：给参考图、色板、关键帧生成使用。
3. 分类风格锚定：角色、非人类主体、场景、道具、UI/屏幕分别定义。
4. 材质与纹理规则：定义材质如何呈现，哪些纹理进入或禁止进入哪些区域。
5. UI / 文字规则：所有文字是否为画内真实显示。
6. 风格隔离规则：多主体、多材质、多媒介或背景/角色风格不一致时必须写。
7. 负面风格偏移：禁止错误风格方向。

### 2. 色板控制包必须包含

1. 全片主色关系。
2. 段落色板清单。
3. 主体色彩锚点。
4. 情绪色彩变化。
5. 禁止色彩偏移。
6. 色板与风格的对应关系。

### 3. 色板需求模板

```text
@色板_[段落名]_[色彩用途]
用途：[服务哪些镜头 / 哪个段落]
色彩方向：[主色、辅色、点缀色、明暗关系]
主体色彩锚点：[角色/道具/UI/机械的稳定色]
关联风格：[这张色板强化哪个风格规则]
情绪功能：[建立/冲突/压迫/觉醒/收束]
必须避免：[禁止色彩偏移]
后续引用：[正式分镜中的引用名]
```

### 4. 正式分镜中的风格与色板引用

完整视觉控制包不得逐镜全文重复。正式分镜每镜只写引用式最小风格锁：

```text
风格锁定：
引用全局风格：[风格名称]
引用风格素材：[@图_主体] [@图_场景]
引用色板：[@色板_段落]
本镜分类风格：[本镜出现的特殊主体或空间沿用哪一类风格]
本镜局部边界：[本镜新增或容易混淆的风格/色彩/UI边界]
```

### 5. 风格与色板冲突处理

若风格和色板冲突，以主体身份锚点和叙事功能优先：

1. 段落色板不得改变主体身份色。
2. 色彩情绪不得破坏材质逻辑。
3. 局部点缀色不得扩散成全片主色。
4. UI 色彩必须符合状态含义，不能被段落色调吞掉。
5. 场景色板可以变化，但全局风格媒介和主体材质必须稳定。
