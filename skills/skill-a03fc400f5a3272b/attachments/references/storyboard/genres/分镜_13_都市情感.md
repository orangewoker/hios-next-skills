# 都市情感风（Urban Romance）分镜指令库

> **主打风格**：细腻的柔和光影、生活质感流露与角色间的微表情互动。
> **加载时机**：`/分集 {N}` Phase 2 时，若题材判定为都市 / 情感 / 甜宠 / 虐恋，加载本文件复用分镜。

| 分镜名称 | 完整指令 |
| -------- | -------- |
| **重逢一瞬** | 过肩慢推镜头，傍晚暖金色的落日余晖。拥挤的十字路口，人潮被虚化成流动的斑影。男主停在斑马线中央，瞳孔微缩，视线紧紧锁定在对面那个穿着米色风衣、正低头看手机的女孩身上。他手中的咖啡杯微微倾斜，洒出几滴液体，时间仿佛静止。 |
| **阳台独泣** | 侧面半身特写，忧郁的蓝调夜景光。未开灯的公寓阳台，女生抱着双膝坐在瓷砖地上。窗外斑斓的城市霓虹微弱地打在她布满泪痕的侧脸上，她咬紧发白的下唇努力不发出声音，宽松的纯棉睡衣褶皱里都透着深深的孤独。 |
| **微醺靠近** | 极近特写，居酒屋昏黄暧昧的灯笼光源。两人在狭窄的吧台前并肩而坐，男主微微偏头，鼻尖几乎碰到女生的耳廓。女生因微醺泛红的脸颊上有细腻的绒毛反光，眼神迷离地垂下眼帘，手指无意识地摩挲着玻璃酒杯的边缘，氛围感拉丝。 |
| **争吵过后** | 对称构图大远景，室内冷白炽灯硬光。宽敞但空荡的客厅两端，男生坐在沙发里烦躁地抓着头发，女生背对着他站在落地窗前。满地是被撕碎的合照和散落的书本，两人之间横亘着巨大的物理距离与无法跨越的沉默沟壑。 |
| **晨起温存** | 鸟瞰俯拍镜头，清晨柔和通透的自然漫反射。纯白凌乱的床铺上，阳光勾勒出两人相拥的轮廓。男生修长的手臂环着女生的腰，下巴抵在她的颈窝。女生的亚麻质地睡衣微微卷起，一只手正轻轻插在男生的乱发中，慵懒又极致温柔。 |
