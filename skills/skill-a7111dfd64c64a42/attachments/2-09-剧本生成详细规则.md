# 剧本生成详细规则

## 一、卖点提炼规则

### 1.1 卖点来源

卖点提炼基于以下信息综合判断：
- 用户上传的商品图片（外观、材质、设计细节）
- 用户提供的商品描述/文字信息
- 品类特征（该品类消费者最关注的核心诉求）
- 广告目标（不同目标侧重不同卖点维度）

### 1.2 卖点提炼方法

**Step 1：列出商品所有可识别特征**
- 外观特征：颜色、形状、材质、工艺
- 功能特征：核心功能、附加功能、技术参数
- 情感特征：品牌故事、设计理念、使用场景联想
- 价格/价值特征：性价比、独特性、稀缺性

**Step 2：按广告目标筛选核心卖点**

| 广告目标 | 卖点侧重维度 | 提炼方向 |
|---------|------------|---------|
| 品牌曝光 | 品牌差异化、情感价值 | 品牌理念、独特定位、情感共鸣点 |
| 促销转化 | 功能价值、价格优势 | 核心功能、使用效果、优惠信息 |
| 新品上市 | 创新性、差异化 | 新技术、新设计、与旧款/竞品区别 |
| 活动引流 | 利益点、参与价值 | 活动优惠、限时权益、参与方式 |

**Step 3：确定 2-3 个核心卖点**

选择标准：
- **可视觉化**：能在画面中直观展示（避免纯抽象概念）
- **有差异化**：与同类产品有区隔
- **受众关心**：目标受众真正在意的点
- **可验证**：有事实依据，不违反广告法

### 1.3 卖点确认流程

```
根据商品信息，我提炼了以下核心卖点：

1. [卖点1]：[简要说明]
2. [卖点2]：[简要说明]
3. [卖点3]：[简要说明]（可选）

这些卖点是否符合您的预期？或需要调整？
```

用户确认后，卖点进入剧本生成输入参数。

## 二、剧本质量评估标准

### 2.1 合格标准（必须全部满足）

| 评估维度 | 合格标准 | 检查方式 |
|---------|---------|---------|
| **时长匹配** | 总时长与目标时长误差 ≤1秒 | 各镜头时长加总 |
| **台词时长匹配** | 台词字数对应的朗读时长 ≤ 该镜头分配时长 | 按语速规则计算 |
| **片头片尾占比** | 片头+片尾合计 ≤ 总时长 1/3 | 计算占比 |
| **卖点覆盖** | 至少覆盖已确认的核心卖点 | 逐卖点检查 |
| **品牌元素植入** | 如有品牌元素，在剧本中有明确露出位置 | 检查品牌元素出现次数和位置 |
| **合规检查** | 无禁用词、无夸大宣传、符合广告法 | 按合规词库检查 |
| **逻辑连贯** | 镜头之间有合理过渡，无跳跃感 | 整体阅读评估 |
| **风格一致** | 台词风格、画面调性与选定风格一致 | 对照风格定义检查 |

### 2.2 优秀标准（在合格基础上）

- 开场3秒内有明确的吸引力钩子
- 卖点展示有层次递进，不是平铺直叙
- 情感节奏有起伏，不是全程平淡
- CTA 明确有力，与广告目标匹配
- 有记忆点（视觉锤或语言钉）

### 2.3 不合格处理

| 问题类型 | 处理方式 |
|---------|---------|
| 时长不匹配 | 自动调整镜头时长或删减/增加镜头 |
| 台词超长 | 精简台词或增加镜头时长 |
| 卖点缺失 | 补充对应镜头 |
| 合规问题 | 按合规规则修正后重新生成 |
| 风格偏离 | 重新生成对应镜头 |

## 三、剧本修改/迭代规则

### 3.1 用户反馈类型与处理

| 用户反馈类型 | 处理方式 |
|------------|---------|
| "整体不喜欢" | 询问具体不满意的点（节奏/风格/卖点侧重），重新生成 |
| "某镜不好" | 定位具体镜头，仅修改该镜头，保持其他镜头不变 |
| "卖点不对" | 返回卖点确认环节，重新提炼后重新生成剧本 |
| "太长/太短" | 调整镜头数量或单镜头时长，保持核心信息完整 |
| "台词不对" | 仅修改台词，保持画面描述不变 |
| "想要XX感觉" | 根据描述调整风格关键词，重新生成 |

### 3.2 修改轮次控制

- 每轮修改后，展示修改后的剧本摘要，请用户确认
- 单剧本修改上限：5轮
- 超过5轮仍不满意 → 建议：
  - 调整上游参数（风格/时长/卖点）后重新生成
  - 用户上传自己的剧本作为基础

### 3.3 修改影响提示

修改剧本时，提醒用户：
- 修改台词 → 可能影响配音时长 → 需要重新校验时长
- 修改镜头数量 → 可能影响总时长 → 需要重新校验
- 修改卖点 → 可能需要调整分镜和场景图

## 四、多语言剧本处理

### 4.1 语言选择

| 语言类型 | 适用场景 | 注意事项 |
|---------|---------|---------|
| 中文（默认） | 国内投放 | 语速按中文规则 |
| 英文 | 海外投放/国际化品牌 | 语速按英文规则（每秒2-3词） |
| 其他语言 | 特定市场 | 需用户确认语言类型 |

### 4.2 多语言生成规则

**配音语言与字幕语言：**
- 默认：字幕语言 = 配音语言
- 用户可单独指定字幕语言（如英文配音+中文字幕）
- 双语字幕：用户明确要求时启用，主字幕+翻译字幕

**台词字数/词数计算：**
- 中文：按字符数计算，每秒3-4字
- 英文：按单词数计算，每秒2-3词
- 其他语言：按音节数估算，具体语言具体分析

**文化适配：**
- 不同语言的台词不是直译，而是按目标语言习惯重写
- 避免文化禁忌（如某些数字、颜色在不同文化中的含义）
- CTA 文案需符合目标市场的表达习惯

### 4.3 多语言确认流程

```
配音语言：[语言]
字幕语言：[语言]（默认与配音一致，可修改）

台词预览：
[该语言的台词内容]

确认台词内容和语言设置？
```

## 五、剧本与品牌元素融合规则

### 5.1 Logo 植入规则

| 植入位置 | 植入方式 | 时长建议 |
|---------|---------|---------|
| 片头 | Logo 动画展示 | 按片头规则 |
| 片中 | 产品包装上的 Logo 自然露出 | 融入画面，不单独占时 |
| 片尾 | Logo + 品牌名定格 | 2-3秒 |

**植入次数：**
- 品牌曝光目标：至少2次（片头+片尾）
- 其他目标：1-2次（片头或片尾，必要时片中自然露出）

### 5.2 Slogan 植入规则

| 植入位置 | 适用场景 | 注意事项 |
|---------|---------|---------|
| 片头 | 品牌开场动画 | 配合 Logo 一起出现 |
| 片尾 | 品牌收尾 | 作为收尾语，配合 CTA |
| 片中 | 情感高潮点 | 仅在品牌曝光/品牌故事型剧本中使用 |

**植入原则：**
- Slogan 必须与已确认的内容一致，不自行修改
- Slogan 出现时，前后应有足够停顿，让观众消化
- 不与台词重叠，单独成句

### 5.3 品牌色融合

- 台词中如涉及颜色描述，优先使用品牌色
- 画面描述中可提示"以[品牌色]为主色调"
- 场景图生成时，品牌色作为环境/道具的参考色

### 5.4 品牌调性贯穿

| 品牌调性 | 剧本特征 |
|---------|---------|
| 高端奢华 | 台词克制、留白多、意象化表达 |
| 亲切温暖 | 台词口语化、有温度、生活化场景 |
| 科技专业 | 台词精准、数据支撑、理性说服 |
| 年轻活力 | 台词活泼、有梗、节奏快 |
| 国潮文化 | 台词有诗意、典故、意境感 |

## 六、剧本生成前置检查清单

在生成剧本前，Skill 必须确认以下参数已全部就绪：

```
前置参数检查：
□ 商品信息（名称、品类、图片）
□ 视觉路线（实拍/动画）
□ 视觉风格（已选定）
□ 广告目标（已选定）
□ 目标受众（已确认）
□ 投放渠道/画面比例（已选定）
□ 视频时长（已选定）
□ 核心卖点（2-3个，已确认）
□ 品牌元素（Logo/Slogan/片头片尾方案，已确认）

缺少任一项 → 返回对应阶段补充
```

## 六-A、人物出镜的剧本处理规则（仅当人物出镜=是时适用）

### A.1 人物融入剧本的原则

- 人物是商品展示的载体，不是独立角色；所有人物行为服务于商品卖点表达
- 人物动作/表情/台词必须与人物描述卡中的气质基调一致
- 人物的出场顺序、镜头分配、互动方式由品类特征和广告目标决定

### A.2 人物镜头编排规则

| 广告目标 | 人物镜头占比 | 人物角色定位 |
|---------|------------|------------|
| 品牌曝光 | 40-60% | 品牌代言人/体验者，传递品牌调性 |
| 促销转化 | 30-50% | 使用者/推荐者，展示使用效果 |
| 新品上市 | 30-50% | 体验者/发现者，展示新品亮点 |
| 活动引流 | 20-40% | 引导者，指向活动信息 |

### A.3 人物动作与商品互动规范

| 品类 | 典型人物动作 | 互动要点 |
|------|------------|---------|
| 食物饮品 | 品尝/举杯/冲泡/端盘 | 表情自然享受，不遮挡食物主体 |
| 美妆护肤 | 涂抹/展示妆容/照镜 | 展示使用效果，面部表情传递感受 |
| 服饰鞋包 | 行走/转身/搭配/整理 | 展示上身效果，动态展示版型/质感 |
| 电子产品 | 手持/操作/佩戴/使用 | 自然操作，展示使用体验 |
| 家居日用 | 使用/整理/布置/互动 | 生活化场景，展示便利性和氛围 |
| 母婴用品 | 拥抱/喂养/陪伴/互动 | 传递安全感和温馨感 |
| 运动户外 | 运动/奔跑/攀爬/骑行 | 展示运动状态和产品功能性 |
| 珠宝饰品 | 佩戴/展示/轻触 | 优雅动作，展示佩戴效果 |

### A.4 人物台词规则（有人物对话/旁白时）

- 人物语气/口吻需与人物气质基调匹配
- 人物对话场景：闺蜜推荐→口语化；专业解说→沉稳可信；生活场景→自然亲切
- 人物台词不超过总台词量的 60%（避免喧宾夺主）

## 七、剧本生成的 Prompt 构建规则

AI 生成剧本时，内部 prompt 必须包含以下要素：

```
你是一个专业的广告编剧。请根据以下参数生成广告剧本：

【商品信息】
- 商品名称：[名称]
- 品类：[品类]
- 商品特征：[从图片/描述提取的特征]

【创作参数】
- 视觉风格：[风格名] + [风格特征描述]
- 广告目标：[目标] + [对应创作策略]
- 目标受众：[受众画像]
- 视频时长：[X秒]
- 画面比例：[X:X]
- 配音语言：[语言]

【核心卖点】（按优先级排序）
1. [卖点1]
2. [卖点2]
3. [卖点3]

【品牌元素】
- Logo：[有/无] + [描述]
- Slogan：[内容/无]
- 片头方案：[类型] + [时长]
- 片尾方案：[类型] + [时长] + [CTA文案]

【人物设定】（仅当人物出镜=是时填写）
- 人物描述卡：[外貌/体型/服装/气质/风格关键词]
- 人物镜头占比：[X%-X%]
- 人物角色定位：[代言人/使用者/体验者/推荐者/引导者]
- 人物与商品互动方式：[具体互动描述]
- 人物语气/口吻：[与气质匹配的台词风格]

【剧本结构】
- 使用结构模板：[从模板库选择]
- 台词语速：[每秒X字]
- 片头+片尾合计不超过总时长的1/3

【输出要求】
- 按标准剧本格式输出
- 每个镜头标注时长
- 台词字数与镜头时长匹配
- 画面描述需考虑[画面比例]的构图

请生成剧本。
```

## 八、钩子/开场具体写法

### 8.1 钩子类型库

前3秒决定用户是否继续观看。以下为可用的钩子类型：

| 钩子类型 | 适用目标 | 写法示例 | 适用时长 |
|---------|---------|---------|---------|
| **视觉冲击型** | 品牌曝光/新品上市 | 画面：商品从黑暗中亮起/从水底浮起/碎裂重组 | 5s-30s |
| **悬念疑问型** | 品牌曝光/新品上市 | 台词："你知道吗？"/"如果有一种方法可以……" | 15s-30s |
| **痛点共鸣型** | 促销转化 | 画面：展示用户痛点场景（如皮肤暗沉/头发毛躁） | 15s-30s |
| **反差对比型** | 促销转化/新品上市 | 画面：前后效果对比/使用前后对比 | 15s-30s |
| **情感代入型** | 品牌曝光/情感营销 | 画面：生活场景切入（清晨/下班/约会前） | 15s-30s |
| **数据震撼型** | 促销转化/科技产品 | 台词："99%的人不知道……"/"每分钟卖出1000件" | 15s-30s |
| **动作引导型** | 促销转化/活动引流 | 画面：人物直接动作（拿起/打开/点击） | 5s-15s |
| **声音吸引型** | 品牌曝光 | 音效：特殊音效开场（碎裂声/水滴声/倒计时） | 5s-15s |

### 8.2 钩子选择规则

| 广告目标 | 推荐钩子类型（优先级从高到低） |
|---------|---------------------------|
| 品牌曝光 | 视觉冲击型 > 悬念疑问型 > 情感代入型 |
| 促销转化 | 痛点共鸣型 > 反差对比型 > 数据震撼型 |
| 新品上市 | 视觉冲击型 > 悬念疑问型 > 反差对比型 |
| 活动引流 | 动作引导型 > 数据震撼型 > 痛点共鸣型 |

### 8.3 钩子写作原则

- 钩子必须在**前1-2秒内**建立视觉或听觉焦点
- 钩子与产品露出之间必须有**逻辑关联**，不能为钩子而钩子
- 钩子时长不超过总时长的**1/5**
- 钩子的画面描述必须足够具体，让场景图生成阶段能准确还原

## 九、CTA 文案模板库

### 9.1 CTA 按广告目标分类

| 广告目标 | CTA 类型 | 文案模板 |
|---------|---------|---------|
| **品牌曝光** | 品牌认知型 | "记住这个名字"/"[品牌名]，为[目标人群]而生"/"了解更多，访问[品牌官网]" |
| **促销转化** | 立即购买型 | "立即抢购，限时优惠"/"点击下方链接，专属折扣等你领"/"现在下单，前100名享[优惠]" |
| **促销转化** | 紧迫限时型 | "仅剩[XX]小时"/"最后[XX]件，手慢无"/"限时[折扣]，错过等一年" |
| **新品上市** | 探索体验型 | "抢先体验，点击预约"/"全新[产品名]，现已上市"/"首发限定，即刻拥有" |
| **活动引流** | 参与引导型 | "扫码参与，赢取[奖品]"/"点击报名，[日期]见"/"搜索[关键词]，即刻参与" |
| **活动引流** | 利益驱动型 | "注册即送[礼品]"/"邀请好友，双方各得[奖励]"/"参与活动，赢取[大奖]" |

### 9.2 CTA 文案写作规范

- CTA 必须包含**明确的行动指令**（动词开头：点击/搜索/扫码/立即/马上）
- CTA 时长：5秒广告 1-2秒，15秒广告 2-3秒，30秒广告 3-5秒
- CTA 画面必须有**视觉引导**（箭头/按钮/二维码/搜索框示意）
- CTA 台词与画面文字**同步出现**，双重强化
- 合规红线：不得虚假限时（如长期使用"最后3小时"但实际不限时）

## 十、情绪节奏曲线

### 10.1 不同时长的节奏模板

**5秒广告（极致精简）**：
```
冲击 → 展示 → 收束
高    中    稳
```
- 情绪：开场即高潮，快速收束
- 节奏：快-快-稳

**15秒广告（短视频黄金时长）**：
```
钩子 → 铺垫 → 高潮 → 收束
高    中低   最高   稳
1-3s   3-8s   8-12s  12-15s
```
- 情绪：快速拉升 → 短暂平缓 → 推到最高点 → 干净收尾
- 节奏：快-慢-快-稳

**30秒广告（完整叙事）**：
```
钩子 → 铺垫 → 发展 → 高潮 → 升华 → 收束
高    中低   中    最高   中高   稳
1-4s   4-10s  10-18s 18-24s 24-27s 27-30s
```
- 情绪：有完整的起承转合，高潮点在中后段
- 节奏：快-慢-渐快-快-缓-稳

### 10.2 情绪节奏与镜头语言对应

| 情绪阶段 | 景别倾向 | 运镜倾向 | 台词密度 |
|---------|---------|---------|---------|
| 冲击/钩子 | 特写/近景 | 快推/快速切换 | 少或无 |
| 铺垫/建立 | 全景/中景 | 缓慢平移/固定 | 中等 |
| 发展/递进 | 中景/近景 | 跟随/缓慢推进 | 较多 |
| 高潮/爆发 | 特写/快切 | 快速切换/动感 | 密集或完全无台词 |
| 升华/情感 | 中景/全景 | 缓慢拉远/升格 | 少而精 |
| 收束/CTA | 中景/特写 | 固定 | CTA文案 |

### 10.3 节奏禁忌

- ❌ 全程高能量，无呼吸空间（观众疲劳）
- ❌ 高潮出现在前1/3，后续乏力
- ❌ 情绪平淡无起伏，像产品说明书
- ❌ 转场节奏与情绪不匹配（如高潮处用缓慢溶解转场）

## 十一、品类专属剧本范式

### 11.1 品类→剧本侧重对照表

| 品类 | 剧本核心侧重 | 典型叙事模式 | 台词风格 | 感官调动 |
|------|------------|------------|---------|---------|
| **美妆护肤** | 体验感+效果 | 使用前→使用中→效果展示 | 温柔/自信/分享感 | 视觉（肤质变化）+触觉（质地） |
| **食物饮品** | 感官刺激+场景 | 场景建立→食欲唤起→满足感 | 口语化/有食欲感 | 视觉（色泽）+味觉联想+听觉（酥脆声） |
| **服饰鞋包** | 穿搭效果+场景 | 场景设定→穿搭展示→自信状态 | 时尚/有态度 | 视觉（整体造型）+动态（走动/转身） |
| **电子产品** | 功能对比+体验 | 痛点→产品功能→效果对比 | 理性/专业/科技感 | 视觉（界面/效果）+听觉（操作反馈） |
| **家居日用** | 生活感+便利性 | 生活场景→产品使用→便捷体验 | 亲切/生活化 | 视觉（空间变化）+触觉（材质） |
| **母婴用品** | 安全感+温馨 | 育儿场景→产品呵护→安心状态 | 温柔/关怀 | 视觉（宝宝状态）+情感（亲子互动） |
| **运动户外** | 动感+功能性 | 运动场景→产品助力→突破瞬间 | 活力/激情 | 视觉（运动状态）+听觉（节奏感）+动态 |
| **珠宝饰品** | 精致感+仪式感 | 场景设定→细节展示→佩戴效果 | 优雅/精致 | 视觉（光泽/细节）+情感（仪式感） |
| **个护清洁** | 效果对比+清新感 | 问题场景→清洁过程→焕然效果 | 清爽/干净 | 视觉（前后对比）+嗅觉联想（清新） |
| **数码配件** | 搭配+功能 | 设备场景→配件功能→体验提升 | 简洁/实用 | 视觉（搭配效果）+功能演示 |
| **宠物用品** | 萌宠+关爱 | 宠物场景→产品互动→宠物满足 | 可爱/温馨 | 视觉（宠物反应）+情感（人宠互动） |
| **文具办公** | 效率+质感 | 办公/学习场景→产品使用→效率提升 | 简洁/有质感 | 视觉（书写/效果）+触觉（质感） |
| **汽车用品** | 品质+场景 | 车内场景→产品功能→驾驶体验提升 | 品质感/专业 | 视觉（车内环境）+听觉（安静/音乐） |
| **保健品** | 健康+信任 | 健康需求→产品成分/功效→健康状态 | 专业/可信 | 视觉（健康状态）+数据（成分/功效） |

### 11.2 品类剧本写作要点

**美妆护肤**：
- 必须有"使用前后"的视觉对比暗示
- 产品质地展示（涂抹/滴落/喷雾）是必选镜头
- 台词避免纯成分堆砌，侧重使用感受

**食物饮品**：
- 必须调动"味觉联想"（通过画面让人"想尝一口"）
- 食物特写是必选镜头，展示色泽/质感/蒸汽/水珠
- 环境音（酥脆声/倒水声/开瓶声）强化感官

**服饰鞋包**：
- 必须有动态展示（走动/转身/低头看）
- 多场景切换展示百搭性
- 台词侧重"穿搭态度"而非材质参数

**电子产品**：
- 功能演示必须有具体使用场景（不是空讲参数）
- 前后对比是核心说服力
- 界面操作展示要清晰，避免模糊

## 十二、场景描述写作标准

### 12.1 场景描述的粒度要求

场景描述是连接剧本和场景图生成的桥梁，必须达到以下粒度：

**必写项（缺一不可）**：
- **主体**：画面中的核心对象（商品/人物），含位置、姿态、朝向
- **动作/状态**：主体正在做什么或处于什么状态
- **环境**：背景场景（室内/室外/具体场所）
- **光线**：光照方向和质感（如"柔和自然光从左上方照入"）
- **构图**：画面比例和主体在画面中的位置（如"竖屏构图，商品居中偏左"）

**选写项（按需补充）**：
- 色调倾向（如"整体偏暖色调"）
- 氛围关键词（如"清新""高级感""科技感"）
- 特殊元素（如"背景虚化""光斑效果""烟雾弥漫"）
- 景深层次（如"前景有虚化的植物叶片"）

### 12.2 场景描述写作示例

**不合格示例**（太模糊）：
```
一瓶精华液放在桌子上
```

**合格示例**（达到生成标准）：
```
一瓶透明玻璃瓶身金色瓶盖的精华液置于画面中央偏左，瓶身微微倾斜15度，
背景为浅米色渐变桌面，柔和自然光从右上方45度角照入，瓶身呈现通透光泽，
背景微微虚化，竖屏9:16构图，商品占画面约40%
```

**含人物的合格示例**：
```
一位圆脸齐肩黑色短发的年轻女性（穿白色上衣），双手轻捧精华液瓶身展示在脸颊旁，
微微侧头微笑，柔和自然光从右侧照入，面部皮肤呈现自然光泽，
背景为浅粉色渐变，干净简洁，竖屏9:16构图，人物占画面约60%，商品在人物手部清晰可见
```

### 12.3 场景描述写作规范

- **禁止模糊词**：不得出现"好看的""漂亮的""高级的"等无具体指向的形容词
- **必须有参照**：颜色/大小/位置必须有参照物或具体描述
- **光线必写**：每条场景描述必须包含光线方向或质感描述
- **构图必写**：必须标注画面比例和主体位置
- **与分镜一致**：场景描述必须与分镜中的景别、运镜描述匹配
- **与人物设定一致**：如涉及人物，必须引用人物描述卡中的外貌特征
