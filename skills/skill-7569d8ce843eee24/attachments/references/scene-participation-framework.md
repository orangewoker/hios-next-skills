# 场景化活体口播框架

## 核心命题

真实感不等于人物持续移动。

真实感来自：

- 人物已经参与正在发生的生活或社交情境；
- 人物有明确交流对象或环境任务；
- 手中有场景天然存在的道具；
- 环境持续反馈；
- 镜头具有合理的观察身份。

## 四种传播模式

| 模式 | 观众关系 | 产品露出 |
|---|---|---|
| 直接推荐 | 主角直接告诉观众 | 可以较早 |
| 经验分享 | 像朋友分享 | 判断标准之后 |
| 偷听对话 | 观众像坐在旁边听 | 延迟露出 |
| 正式解释 | 采访或课程 | 根据内容 |

## 四种行为锚点

- 位移：走、进、出、停；
- 道具：端杯、敲签子、夹菜、整理毛巾；
- 社交：接话、回应、看同伴；
- 状态：靠椅、前倾、停顿、皱眉。

## 三人同桌模板

- 前景：一位同伴背影或肩部，形成自然遮挡；
- 中景：主角，主要对同伴说话；
- 侧面：另一位同伴倾听并轻微回应；
- 摄影机：桌边旁听者；
- 道具：只用一种场景原生道具；
- 产品：文案进入品牌段后再出现。

## 场景选择顺序

1. 话题自然度；
2. 信任与松弛感；
3. 人物关系；
4. 原生道具；
5. 光影美感。
