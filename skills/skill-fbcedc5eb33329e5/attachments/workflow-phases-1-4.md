## 操作步骤

### Phase 1：需求解析报告

收集用户输入后，输出结构化需求解析报告。读取 [references/style-routing.md](references/style-routing.md) 获取风格路由表和复杂度档位定义。

报告必须包含以下字段：

```
[需求解析报告]
- 题材/流派：[题材] / [流派分类]
- 核心情绪：[情绪描述]
- 时长/画幅：[时长] / [画幅]
- 节奏档位：[电影感中速 / 短视频中高密度 / 高密度动作或强钩子 / 慢节奏但高信息]（AI自动判定，用户可覆盖）
- 复杂度档位：[S/M/L]（[N]镜，[转场方式]）
- 风格路由：-> [流派] 行 -> [摄影机+镜头+胶片+布光+色调]
- 巨物检测：[是/否] -> [类别] / [尺度等级] / [是否激活巨物专项规则]
- 表情检测：[是/否] -> [角色数量] / [主要情绪] / [是否激活表情专项规则]
- 是否有角色：[是/否] -> [是否需要角色资产卡]
- 资产清单：[已有@图片N/@音频N列表] / [缺失项：角色设定图/场景设定图/音色/道具]
- 故事语言/对白语言：[语言及风格]
- 声音需求：[画外音/音效/音乐/背景音乐需求]
- 信息充足：[是/否] -> [进入方案输出/需补充项]
```

### Phase 2：AGENT-1A 叙事结构 + AGENT-1B 摄影工艺

两个智能体并行设计，输出后合并。

#### AGENT-1A：叙事结构 + 导演语法

1. 设计**情绪曲线**：标注每个时间节点的情绪值(1-10)和叙事节奏(ASL)
2. **节奏档位判定与继承**：从 Phase 1 继承节奏档位（电影感中速/短视频中高密度/高密度动作或强钩子/慢节奏但高信息），每个大分镜前置单元必须输出节奏档位判定、理由、建议镜头密度。用户不满意时允许指定某一组改档，不重做全项目
3. **镜头配方卡选型**：从 references/shot-cards/ 中为每个镜头选择匹配的配方卡（对话戏/情绪镜头/运镜/转场），读卡全文，将参数表和已知坑写入逐镜规划。用户已点名镜头卡时直接使用，不重新选型
3. 设计**逐镜规划表**：

| 镜号 | 时长 | 景别 | 运镜 | 视角 | 叙事理由 |
|------|------|------|------|------|----------|

> **单镜时长计算公式：时长(秒) = 台词字数 ÷ 3.5 + 其他时长**
> 按语速 3.5字/秒 计算对白所需时长，其他时长根据纯画面留白、情绪停顿、转场、运镜等叠加。总片长 = 各镜时长之和。单镜总时长不得超过15秒，超过15秒必须拆分为多个分镜。

**分镜详细参数标准返回格式（每个分镜必须输出）：**

```
镜头 XX-X（Xs）

摄影机：ARRI Alexa Mini LF，Cooke S4，XX° 视场角，24fps/180° 快门

摄像机位置：[物理位置/房间方位]，距离主体X米，高度X米（齐胸/平视/低机位/高机位），朝向[主体方向]

运镜：[具体运镜描述，起始景别→结束景别]

配方卡：[选用的镜头配方卡名称，多个用+连接]

灯光：[主光类型+色温+位置] + [辅光/轮廓光]，X:X 光比
```

格式说明：
- 镜头编号格式：主镜号-分镜号（如42-1），括号内为总时长秒数
- 摄影机：固定ARRI Alexa Mini LF + Cooke S4，FOV角度按内容选择（8°/18°/29°/47°/84°/107°），24fps/180°快门为院线标准
- 摄像机位置：必须写明物理位置（房间方位/参照物）、距离主体米数、高度（米数+机位描述）、朝向方向，禁止模糊位置词
- 运镜：必须写明具体运镜方式和起始→结束景别变化
- 配方卡：从 references/shot-cards/ 中选用，写明卡名
- 灯光：主光（类型+色温K值+位置）+ 辅光/轮廓光，写明光比

3. 设计**声音节拍点**：标注每个时间码的声音事件
4. 标注声画关系（J-Cut/L-Cut/同步/对位）
5. 当存在角色时，为每个包含角色的镜头标注目标情绪，读取 [references/emotion-prompt-guide.md](references/emotion-prompt-guide.md) 获取情绪分类索引和摄影参数联动表

#### AGENT-1B：IMAX摄影工艺

1. **摄影机系统**：机型+胶片型号+选型理由
2. **镜头系统**：焦段+光圈+畸变控制
3. **帧率/快门**：帧率+快门角度+动态特征
4. **布光方案**：主光/辅光/轮廓光/氛围介质的完整参数
5. **色彩方案**：主色/辅色/点缀色的色号 + 饱和度/对比度方向 + 胶片色彩响应

### Phase 3：Quality Gate 1

读取 [references/quality-gate-spec.md](references/quality-gate-spec.md) 获取检查清单。

四维审查：
1. 叙事情绪 <-> 光影色彩匹配？
2. 镜头焦段 <-> 摄影机画幅兼容？
3. 运镜选择 <-> 叙事理由成立？
4. 色彩方案 <-> 题材路由一致？

全部通过 -> 进入Phase 4；任一不通过 -> 回到Phase 2修正。

### Phase 4：串行精修

三个智能体串行执行，每个智能体的输出叠加到方案中。

#### AGENT-2A：去AI感工程

读取 [references/film-grain-guide.md](references/film-grain-guide.md) 获取瑕疵美学分类和肤质引擎定义。

1. **瑕疵美学注入**（必须>=3项，跨>=2类别）：
   - 胶片介质类：颗粒特征、halation、色彩漂移
   - 光学损失类：色差、畸变、呼吸感（**暗角/边缘压暗/四角晕影全局禁用，画面四角亮度必须均匀**）
   - 环境物理类：水雾、扬尘、镜头附着物
   - 时间物理类：风化、磨损、氧化、裂纹
2. **肤质引擎（场景版）**：逐层检查
   - L1 宏观形态（轮廓/走向/体量感）
   - L2 中观纹理（表面纹理/分层/断裂面）
   - L3 微观质感（矿物颗粒/纤维/毛孔级细节）
3. **角色面部微表情校验**：当镜头包含角色面部时，参考 `assets/emotion-prompt-library.txt` 中的"核心情绪拆解"，校验眼部肌肉/嘴部弧度/面部张力是否与目标情绪匹配

#### AGENT-2B：画质锁

1. **微观质感描述**：具体到可辨识的最小纹理单元
2. **分辨率保障关键词**：超细节IMAX分辨率、物理级渲染、高微对比度
3. **时间稳定性**（视频）：无闪烁、胶片颗粒稳定、无色彩渐变漂移、物理运动一致

#### AGENT-2C：声景设计

读取 [references/post-production.md](references/post-production.md) 获取逐镜声景设计格式。
**涉及角色时**，必须读取 [references/ai-real-person-dialogue.md](references/ai-real-person-dialogue.md)：
- **对白层**：按四层对白编排体系（语音重叠→言语卡顿→生理克制表演→时间轴标注）生成真人化对白
- **表演层**：使用三层提示词架构 + 八维表演公式 + FACS面部AU编码（含强度A-E分级），100+中英双语表情/肢体提示词，31种情绪递进表演模板
- 遵守10条绝对禁止红线，使用统一标记符号（〔呃〕/……/——/`<重叠Xs>`/（气音）等）
