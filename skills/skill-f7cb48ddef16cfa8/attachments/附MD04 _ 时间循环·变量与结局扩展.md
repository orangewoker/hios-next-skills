# 附MD04 | 时间循环·变量与结局扩展

**所属主SKILL：** 时间循环 · 死亡回溯 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“变量设定空洞、多结局逻辑不闭环”的痛点。

## #需要什么输入

- 核心变量清单、循环机制设计。

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 循环次数：counter，0-99，默认0；每次死亡+1。
2. 真相进度：counter，0-100，默认0；≥80可锁定真凶。
3. 心智值：counter，0-100，默认100；&lt;30出现幻觉；归零彻底发疯。
4. 线索收集：counter，0-20，默认0；解锁特定线索需要足够的数值。
5. 存活时间：counter，0-24小时，默认8:00 AM；死亡触发重置。

道具与旗标

1. 关键照片残片：item，false；true可拼凑真相。
2. 警局密档：item，false；true可查明真凶动机。

### 二、结局体系（共15个）

正结局（5个）

1. E01·破局者：真相进度≥80，成功阻止爆炸并存活。
2. E02·完美救赎：救下所有必死NPC，达成完美结局。
3. E03·看破红尘：心智值极低，虽然存活但选择结束循环，进入虚无。
4. E04·成为时间的主人：掌握循环机制，反向操控时间。

坏结局（10个）

1. D01·彻底疯狂：心智值=0。
2. D02·永远的困局：循环次数达到上限，永远被困在同一天。
3. D03·蒙冤入狱：被真凶陷害，在循环中被捕。
4. D04·死亡瞬间：未能在死亡前拿到关键线索。
