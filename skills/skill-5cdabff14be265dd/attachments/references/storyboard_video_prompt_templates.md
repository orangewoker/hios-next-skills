# 分镜视频Prompt模板库（libTV Agent / Seedance）｜Minimum 4s版

## 0. 强制时长规则
- 单条Generation Duration必须≥4.0秒。
- 最终Edit Duration允许短于4秒。
- Prompt必须显式写Generation Duration和Edit Target。
- 所有短动作必须使用：Head Handle → Core Action → Tail Handle。
- 时间轴最后一个时间点不得早于4.00秒。
