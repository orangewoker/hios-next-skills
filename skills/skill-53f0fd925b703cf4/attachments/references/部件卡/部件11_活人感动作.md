# 部件卡11 · 活人感动作 + 手部高危区

## 动作三拍法（2026-08-05外部参考吸收·克制型表演强制）
克制型角色（职业杀手/隐忍型/程序化）的动作写法，每动作拆三拍，防AI画成"鬼畜瞬移"或"僵硬无过程"：
```
三拍 = 起始触点 → 位移量 → 归位确认
  ✅「左手从膝盖极缓慢抬起，两指捏住袖口边缘（触点），将袖口向手腕方向拉平半寸（位移量），
     手指松开归位搭回膝盖（归位确认）」
  ❌「拉平袖口」（无触点无位移无归位，AI自由发挥）
  ❌「轻轻拉了拉袖口」（模糊量词）
位移量必须量化（半寸/两指宽/一个刻度），归位确认=动作完成后停半秒再离开
```

## 手部高危区（防手部崩坏，最高优先）
AI手部生成最不稳定。手指精细动作（指尖拧动/张合/逐一收放）容易崩坏成"蠕虫手指"。
```
活人感动作应选腕/肩/头/重心级别：
  ✅ 轻甩手腕、微偏头、肩放松下沉、重心微调、深吸气/长呼气
  ❌ 指尖拧了一下 → 改为「手腕轻微一转」
  ❌ 手指轻轻张合了一下 → 改为「整只手在握柄上放松了一下」
  每镜子镜头手指微调 ≤ 1处，多余动作移到大关节
  手部精细动作特写超3s = 加环境动元素承载或放宽景别（硬规则7）
```

## 微表情粒度表（按景别选级别）
| 景别 | 写法 | 示例 |
|:----|:-----|:------|
| 特写（CU/ECU） | 精确级（0.3mm、量化位移、肌肉名） | `上眼睑从完全低垂以每秒0.3mm速度上移` |
| 中近景（MCU/MS） | 情绪级 | `神情冷淡、近乎面无表情` |
| 全景/远景（WS/EWS） | 不写面部细节 | `身体前倾、步伐不稳斗篷拖地` |

⚠️ 中近景写微表情只写一句话，不堆砌肌肉名。全景写微表情是浪费。

## 静止角色的"活着声明"

  这种呼吸感让她整个人保持活着的状态而不是凝固静止」
