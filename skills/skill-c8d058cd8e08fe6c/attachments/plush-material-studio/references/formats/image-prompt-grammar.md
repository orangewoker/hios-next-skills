## 1. 图片 prompt 基本结构

每个图片 prompt 按以下顺序组织，用逗号分隔：

```
<风格声明>，<主体描述+引用>，<材质描述>，<配色>，<光照>，<构图/画幅>，<情绪关键词>，<画幅比例>
```

- **风格声明**：始终以"Q版卡通毛绒风格"开头，锁定风格
- **主体描述**：用 `@图片N` 引用参考图并说明主体是什么
- **材质描述**：绒毛类型 + 密度 + 光泽 + 接缝线（见下方词库）
- **配色**：主色 + 辅色 + 点缀色
- **光照**：光线方向 + 柔硬度 + 阴影特征
- **构图**：画幅 + 主体位置 + 留白 + 背景处理
- **情绪**：1-2个 feeling word

## 2. 毛绒材质描述词库

### 绒毛类型
- 短绒：丝绒感、缎面绒、密实贴合、微珠光
- 中绒：经典毛绒玩具感、蓬松饱满、柔软弹性
- 长绒：拖把飘逸感、蓬松炸开、绒毛飞扬
- 圈绒：羊羔绒卷曲、颗粒质感、波浪纹理

### 密度
- 高密度：密实不露底、绒毛紧贴
- 中密度：蓬松有弹性、可见绒毛间隙
- 低密度：稀疏炸毛、绒毛方向自由

### 光泽
- 哑光：无反光、绒面吸光
- 微珠光：轻微光泽、柔和反光
- 丝光：顺毛方向有光泽线
- 轮廓光：绒毛边缘发金光

### 接缝线（增强玩具感）
- 四肢与躯干连接处有毛绒玩具拼合缝线
- 头部与躯干连接处有圆形缝线
- 背后有纵向缝线
- 屁股位置有品牌小布标

## 3. 光照描述词库

| 用途 | 光照描述 |
|---|---|
| 电商主图 | 柔和均匀正面光照，无强阴影，微弱顶光补充 |
| 种草图 | 侧逆暖光从右侧/左侧照入，绒毛边缘金色轮廓光，柔和大面积阴影 |
| TVC静帧 | 影视级布光，主光侧前方，辅光弱1/3，背景有光比，景深虚化 |
| 治愈系 | 漫射柔光，无明显方向，整体均匀明亮 |
| 暖冬系 | 低角度暖光，金黄色调，绒毛投影柔和 |

## 4. 构图描述词库

| 画幅 | 适用场景 | 构图要点 |
|---|---|---|
| 1:1 | 电商主图、社媒方图 | 主体居中，四周留白，背景纯色或渐变 |
| 3:4 | 种草图、详情页 | 主体偏上或居中，底部留品牌信息位 |
| 9:16 | 抖音/小红书竖屏 | 主体偏上1/3，下方场景延伸 |
| 16:9 | TVC横屏 | 三分法构图，主体偏左或右1/3 |

## 5. 情绪/氛围关键词库

## 6. 完整 prompt 范例

### 电商主图（产品毛绒化）
```
Q版卡通毛绒风格，@图片1所示的润唇膏被重新雕塑为毛绒玩具形态，保留管状轮廓和品牌色彩，表面覆盖短绒丝绒材质，密实微珠光，四肢连接处有毛绒玩具拼合缝线，配色忠于产品包装的粉色和银色，柔和均匀正面光照，纯奶白色渐变背景，产品居中，四周大面积留白，治愈温暖，1:1画幅
```

### 种草图（角色+场景）
```
Q版卡通毛绒风格，@图片1所示的角色变成蓬松中绒毛绒玩具，头身比1:1大头圆身短四肢，保留其发型轮廓和服装配色，眼睛大而黑亮弯弯眼笑，面部短绒五官清晰，四肢连接处有拼合缝线，坐在毛绒化沙发上，沙发蓬松中绒质感，侧逆暖光从右侧照入，绒毛边缘金色轮廓光，暖冬焦糖奶咖配色，主体居中偏左，3:4画幅，治愈惬意
```

### 独立场景图
```
Q版卡通毛绒风格全景场景，整个世界由毛绒材质构成，毛绒化的圆滚滚山丘起伏，毛绒化的蓬松树木散布，天空飘着毛绒云朵，地面铺满短密绒毛草地，远景绒毛密度递减制造空气感，治愈系奶白蜜桃薄荷绿配色，柔和均匀漫射天光，梦幻治愈，1:1画幅
```

## 7. 落 prompt 前自检

- 是否以"Q版卡通毛绒风格"开头？
- 参考图是否用 `@图片N` 引用？
- 绒毛类型、密度、光泽是否都写了？
- 拼合缝线是否写了（增强玩具感）？
- 光照是否匹配用途？
- 配色是否具体到色名？
- 画幅是否明确？
- 情绪关键词是否1-2个到位？
- 是否全部正向措辞（无否定式）？
