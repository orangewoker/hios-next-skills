# 附MD2 | 胡金铨·角色锚点与造型一致性规范

**所属主SKILL：** 胡金铨 | 写意武侠一键成片\
**版本：** V2.0 融合合规版

## #做什么

本模块为“胡金铨 | 写意武侠一键成片”的专属角色锚点与造型一致性规范。

解决AI生成写意武侠时“侠客跨镜头换脸、服装漂移、发髻忽短忽长、身形比例失真、衣袂惯性不连贯”的痛点。胡金铨电影的灵魂是“禅意身法+衣袂成势”，人物每镜换脸，意境就崩了。本模块通过统一的角色锚点规范，确保全片人物形象100%一致。

## #需要什么输入

**最少提供：**

- 主要侠客、女性角色、配角的姓名与设定
- 角色三视图 + 面部特写（用户上传或AI生成）
- 角色标志性武器与服饰

**可选提供：**

- 特定服装风格偏好（宽袖长袍/飘逸披风/粗布麻衣）
- 特定姿态偏好（静立/爆发/回望）
- 目标画幅（不限定，按项目需求或用户指定）
- 是否需要输出视频文件、视频脚本、Prompt清单、视觉方案

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。本环节重点参考【提示词】底座的物理光学参数与【情绪大师】的七层微表情拆解规则。

### 二、角色锚点命名规范

- **格式**：`角色名_角度_版本号`
- **示例**：`侠客_正面三视图_v1`、`女侠_侧身特写_v2`
- **核心铁律**：所有锚点ID必须在跨镜头、跨场景时绝对一致，严禁“同角色两套ID”。

### 三、主要角色锚点

1\. 侠客（主角）

- **身份定位**：隐世侠客、文人气质的武者
- **外貌特征**：不怒自威、深藏不露，面部轮廓清瘦硬朗，眼神沉静
- **发型**：古代男子束发或发髻，发丝自然垂落
- **服装**：宽袖长袍、飘逸披风或粗布麻衣，布料必须体现“衣袂惯性”
- **核心微表情**：眉峰微蹙、目光沉静、下颌紧绷、嘴角轻抿
- **光影锚定**：窗缝漏光、竹影漏光，明暗对比强烈
- **锚点ID示例**：`i-xxxxxxx`（用户上传三视图后替换）

2\. 女侠（女性角色）

- **身份定位**：英气逼人、身法如燕的女性武者
- **外貌特征**：英气清冷，身形修长，气质独立
- **发型**：古代女子发髻或束发，发丝随动
- **服装**：宽袖长裙或窄袖劲装，飘带自然垂落
- **核心微表情**：眉眼坚定、嘴角轻抿、目光锐利
- **锚点ID示例**：`i-xxxxxxx`（用户上传三视图后替换）

3\. 反派/宿敌

- **身份定位**：对立方、隐世高手、东厂/锦衣卫
- **外貌特征**：与侠客形成视觉反差，面部线条冷峻或阴冷
- **服装**：深色长袍或官服，配金属配饰
- **核心微表情**：冷笑、眯眼、目露杀气
- **锚点ID示例**：`i-xxxxxxx`（用户上传三视图后替换）

4\. 僧侣/道者（意境人物）

- **身份定位**：修行者、旁观者、点拨者
- **外貌特征**：面部平静，眼神空灵，气质清冷
- **服装**：素色僧袍或道袍，无华丽装饰
- **核心微表情**：闭目、低眉、目光悠远
- **锚点ID示例**：`i-xxxxxxx`（用户上传三视图后替换）

### 四、衣袂惯性锚定（胡金铨专属标志）

- **静立姿态**：人物静止时，衣角、袖口、发丝仍在微微浮动。
- **爆发姿态**：人物启动瞬间，衣袂大幅度拉开，形成动势。
- **收势姿态**：人物停住后，衣袂仍有0.5-1秒的余韵飘动。
- **转身姿态**：转身瞬间，长袍划出完整弧线，不能突变。

以上衣袂状态必须在全片中保持物理连贯，禁止忽动忽静、突变定格。

### 五、跨镜头一致性锁定（核心铁律）

1. 同角色在不同镜头必须用同一人物锚点ID。
2. 所有镜头共用同一套角色锚点库。
3. 情绪切换必须使用同一角色的不同锚点帧，禁止换脸。
4. 服装、配饰、发髻在全片中必须保持绝对一致。
5. 禁止出现现代发型、动漫发型、现代服饰。

### 六、生成与合成

根据上述角色锚点与造型规范，调用底层视频生成Skill，输出MP4视频文件。

## #产出什么

最终交付：

- **视频文件（MP4格式）、视频脚本、Prompt清单、视觉方案**。
- **角色锚点库资产包**：所有角色三视图、面部特写、锚点ID清单。
- **衣袂惯性锚点清单**：静立/爆发/收势/转身四阶段衣袂参数。
- **角色一致性校验报告**：确保跨镜头、跨场景的锚点ID统一。

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 主要侠客、女侠或配角设定不明确时。
- 用户要求新增角色、变更现有角色锚点或修改衣袂惯性时。
- 用户要求突破跨镜头一致性规则时。
- 用户要求输出视频文件、视频脚本、Prompt清单、视觉方案，但缺少关键输入时。
- 本模块与上游主SKILL或其他附MD规则冲突时。
