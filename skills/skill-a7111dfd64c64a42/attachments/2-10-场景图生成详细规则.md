# 场景图生成详细规则

本文档为 Skill 第七阶段「场景图」的详细执行规则，SKILL.md 通过引用链接使用本文档。

---

## 一、场景图生成前置条件

生成场景图前，以下产物必须已全部确认：

| 前置产物 | 来源阶段 | 校验项 |
|----------|----------|--------|
| 商品图（含去背景结果） | 第一阶段 | 合格通过质检 |
| 投放渠道 / 画面比例 | 第二阶段 | 已确定 |
| 视觉路线 + 风格 | 第二阶段 | 已确定 |
| 三视图（3张） | 第三阶段 | 全部确认通过 |
| 品牌元素 + 片头片尾 | 第四阶段 | Logo/Slogan/片头片尾类型已确定 |
| 剧本 | 第五阶段 | 已确认，卖点/台词/结构已锁定 |
| 分镜脚本 | 第六阶段 | 10列分镜完整，合规检查通过，时长校验通过 |
| **人物描述卡 + 人物形象图 + 人物三视图**（如有人物出镜） | **第二阶段人物设定** | **人物描述卡已生成，人物形象图已确认，人物三视图已生成** |

**前置检查清单**（Skill 内部自动执行）：
- [ ] 分镜总镜头数已确定
- [ ] 每个镜头的画面描述、景别、运镜、时长已填写完整
- [ ] 三视图 3 张均存在且风格一致
- [ ] 画面比例参数已传入
- [ ] 风格关键词已确定
- [ ] 多商品出场顺序已明确（多商品场景）
- [ ] **若人物出镜=是：人物描述卡、人物形象图和人物三视图已就位，且与视觉风格一致**

任一项缺失 → 阻止进入场景图生成，提醒用户回到对应阶段补充。

## 二、场景图 Prompt 构建规则

### 2.1 Prompt 结构

每张场景图的生成 prompt 必须由以下 7-8 层信息组合：

```
[1] 参考声明 → [2] 镜头信息 → [3] 画面描述 → [4] 产品约束 → [4.5] 人物约束（如有人物出镜）→ [5] 风格与光照 → [6] 背景环境 → [7] 技术参数
```

### 2.2 各层详细规则

**[1] 参考声明**
- 必须以三视图作为视觉锚点引用
- 格式：`以三视图为参考，保持商品外观一致。参考图：[三视图1 URL] [三视图2 URL] [三视图3 URL]`
- 三视图引用策略：
  - 正面视图：所有包含商品正面的镜头必须引用
  - 侧面视图：侧面/45度角镜头引用
  - 背面/底部视图：对应角度镜头引用
  - 默认引用全部 3 张，让模型自行匹配最佳角度

**[2] 镜头信息**
- 从分镜脚本中提取：
  - 镜号：Scene {镜号}
  - 景别：远景/全景/中景/近景/特写/大特写/微距
  - 运镜：固定/推/拉/摇/移/跟/升/降/旋转/手持
- 景别影响构图：
  - 远景/全景：商品占比小，环境为主
  - 中景：商品占比约40-60%，可见部分使用场景
  - 近景：商品占比约60-80%，细节清晰
  - 特写/大特写/微距：商品占比80%以上，极致细节

**[3] 画面描述**
- 直接从分镜脚本第5列「画面描述」提取
- 不自行添加、不修饰、不缩写
- 若用户自定义画面描述（修改环节），以用户描述为准

**[4] 产品约束**
- 必须包含：
  - 商品外观一致性声明：`商品外观须与参考图（三视图）完全一致`
  - 商品在画面中的位置（根据分镜中的产品露出描述）
  - 商品材质/质感描述（从三视图阶段沿用）
- 多商品场景：
  - 逐一描述每个出现的商品
  - 明确主从关系和空间位置

**[4.5] 人物约束（仅当人物出镜=是 时添加）**
- 必须引用人物形象图和人物三视图作为人物视觉锚点：`人物外观须与人物形象图一致。人物参考图：[人物正面图 URL] [人物正侧面图 URL] [人物背面图 URL]`
- 必须引用人物描述卡中的关键特征：
  - 外貌一致性：发型发色、面部特征、肤色必须与描述卡一致
  - 服装一致性：穿着必须与描述卡中的服装设定一致
  - 气质/表情：符合描述卡中的气质基调
- 人物与产品的互动约束：
  - 人物动作须与分镜描述的商品互动方式一致（手持/使用/展示/佩戴）
  - 人物不得遮挡商品主体（商品始终是画面主角）
  - 人物与商品的比例关系须合理自然
- 多人物场景（如有多个角色）：
  - 每个角色都须引用各自的人物形象图和人物三视图
  - 明确各角色在画面中的位置和互动关系

**[5] 风格与光照**
- 风格关键词：从第二阶段选定的风格预设中提取
- 光照方案（根据镜头角色和氛围）：
  - 产品展示镜头：柔和均匀光，无强阴影，突出商品细节
  - 使用场景镜头：场景光照（自然光/室内光/夜景灯光），营造生活感
  - 情感镜头：戏剧光/逆光/侧光，强化情绪
  - 品牌镜头：品牌色光源
- 光照须与整体风格一致，同一场景的多镜头光照方向和强度保持统一

**[6] 背景环境**
- 根据分镜画面描述确定：
  - 纯色/渐变背景：产品展示类
  - 使用场景：厨房/客厅/户外/办公室/...
  - 抽象/图形化背景：动画风格/科技风格
  - 品牌色背景：品牌展示类
- 背景复杂度控制：
  - 特写/微距镜头：背景简洁虚化，不抢主体
  - 全景/远景：背景可丰富，但仍服务于主体
- 背景与商品之间须有视觉层次分离

**[7] 技术参数**
- 画面比例：必须与第二阶段选定的投放渠道比例一致
  - 抖音/小红书：9:16（竖屏）
  - 朋友圈：1:1（方形）
  - 电商横屏：16:9
  - 自定义：使用用户指定的比例
- 分辨率：与投放渠道要求匹配
  - 竖屏9:16：至少 1080×1920
  - 方形1:1：至少 1080×1080
  - 横屏16:9：至少 1920×1080
- 格式：PNG（无损，用于后续视频生成）

### 2.3 Prompt 示例

```

背景：渐变黄色到橙色，点缀几何图形
```

**含人物示例（美妆，竖屏，近景，人物出镜）**：

## 三、批量生成策略

### 3.1 生成顺序

场景图按分镜顺序逐张生成，不并行（避免风格漂移）：

1. **先生成片头场景图**（若有品牌开场动画/品牌名展示）
2. **按镜号顺序生成主体内容场景图**
3. **最后成片尾场景图**（若有CTA/品牌收尾）

### 3.2 生成节奏

- 每张场景图独立调用 LibTV 生成
- 单张生成完成后立即内部自检，不等待全部完成
- 全部生成完成后统一展示给用户

### 3.3 一致性保障

场景图之间的视觉一致性是全链路的关键，通过以下机制保障：

**强制一致项**：
- 商品外观：所有场景图中的商品必须与三视图完全一致（材质/颜色/形状/比例/细节）
- **人物外观**（如有人物出镜）：所有涉及人物的场景图，人物必须与人物形象图、人物三视图和描述卡完全一致（面部/发型/体型/服装/气质）
- 画面比例：所有场景图使用相同的宽高比
- 风格关键词：所有场景图使用相同的风格描述（从第二阶段沿用）
- 色调基调：整体色调统一，不出现某张突然偏冷/偏暖
- 光照方向：同一场景连续镜头的光照方向保持一致

**允许变化项**：
- 景别（远/中/近/特写）
- 运镜方向
- 背景场景（不同镜头可在不同场景中）
- 商品在画面中的位置和大小
- 环境元素（植物/道具/光效等）

### 3.4 内部自检（每张场景图生成后）

| 检查项 | 合格标准 | 不合格处理 |
|--------|----------|------------|
| 商品可识别 | 商品在画面中清晰可辨，与三视图外观一致 | 重新生成 |
| **人物一致性**（如有人物出镜） | **人物外貌与人物形象图和三视图一致，无面部/发型/服装突变** | **重新生成** |
| 画面比例 | 与选定比例一致（误差<2%） | 重新生成 |
| 风格匹配 | 与选定风格视觉感受一致 | 重新生成 |
| 无变形 | 商品无扭曲、拉伸、比例失调 | 重新生成 |
| 无伪影 | 无明显模糊/重影/异常色块/文字乱码 | 重新生成 |
| 分镜对应 | 画面内容与分镜描述匹配 | 重新生成 |

单张自检不通过 → 自动重试 1 次 → 仍不通过 → 标记为"待用户确认"，在批量展示时标注异常。

## 四、场景图展示与确认

### 4.1 展示方式

- 按镜号顺序排列展示所有场景图
- 每张场景图附带信息：
  - 镜号 + 景别 + 时长
  - 画面简要描述（一句话）
  - 自检状态（正常/异常待确认）
- 多商品场景：标注每个商品在画面中的位置

### 4.2 确认流程（精细模式）

逐张确认，每张场景图用户可选择：

| 操作 | 说明 | 后续 |
|------|------|------|
| **确认通过** | 满意当前效果 | 标记为已确认，进入下一张 |
| **整张重新生成** | 对整体不满意 | 使用原prompt重新生成 |
| **局部修改** | 大体OK但某个细节需调整 | 用户提供修改描述 → 在原prompt基础上追加修改指令 → 重新生成 |
| **自定义描述** | 用户完全自己描述画面 | 用户提供完整画面描述 → 替换原分镜描述 → 重新生成 |

### 4.3 确认流程（快速模式）

- 跳过逐张确认
- 展示全部场景图的缩略图总览
- 用户可选择：
  - A. 全部接受（默认）
  - B. 进入精细模式，逐张确认
  - C. 指定某几张重新生成

### 4.4 修改轮次控制

- 单张场景图修改上限：3 轮
- 超过 3 轮时提醒：
  > "该镜头已修改 X 次，是否接受当前效果？或考虑调整上游参数（分镜描述/风格/光照）后重试？"
- 用户选择：
  - A. 接受当前效果
  - B. 回到第六阶段修改分镜描述
  - C. 回到第二阶段调整风格/光照
  - D. 跳过该镜头（后续手动补）

### 4.5 级联影响提醒

当用户修改某张场景图时，Skill 自动检查：
- 修改是否影响相邻镜头的视觉连贯性（如光照方向变化、背景切换）
- 若有影响 → 提醒用户："修改该镜头可能影响第 X、Y 张场景图的连贯性，是否一并调整？"
- 用户确认后执行级联更新

## 五、多商品场景图规则

### 5.1 单镜头多商品

当某个分镜中多个商品同时出现：
- prompt 中逐一描述每个商品的外观、位置、大小比例
- 明确主从关系：主角商品在画面中心/视觉焦点，配角商品在辅助位置
- 所有商品均须与各自三视图一致

### 5.2 不同镜头不同商品

按分镜中各商品的出场编排：
- 主角商品出场镜头数 ≥ 总镜头数的 50%
- 每个商品至少有 1 张独立展示镜头
- 商品间切换镜头须有过渡（不能突然从商品A跳到商品B无任何关联）

### 5.3 一致性跨商品

多商品场景图中，所有商品须：
- 共享相同的光照环境
- 共享相同的风格/色调
- 各自保持与自身三视图一致的外观

## 六、场景图与下游传递

场景图确认后，以下信息传递到第八阶段（广告参数）和第九阶段（视频生成）：

| 传递信息 | 用途 |
|----------|------|
| 场景图文件（PNG） | 作为视频生成的起始帧参考 |
| 镜号 → 场景图映射 | 确保视频按正确顺序拼接 |
| 每镜头时长 | 控制视频片段长度 |
| 景别/运镜信息 | 控制视频生成时的镜头运动 |
| 商品一致性锚点 | 确保视频中的商品与场景图一致 |

## 七、异常处理

### 7.1 单张生成失败
- 自动重试 1 次（使用相同prompt）
- 仍失败 → 告知用户，提供选项：
  - A. 再试一次
  - B. 简化画面描述后重试
  - C. 跳过该镜头
  - D. 用户手动上传替代图

### 7.2 批量生成中断
- 记录已完成的镜头编号
- 告知用户进度："已完成 X/Y 张场景图，第 Z 张生成中断"
- 恢复时从中断处继续，不重生成已确认的场景图

### 7.3 风格漂移
- 若连续 3 张以上场景图出现明显风格不一致（色调偏差/商品变形/背景风格突变）：
  - 暂停批量生成
  - 提醒用户："检测到风格漂移，建议检查风格参数或重新锁定风格关键词"
  - 用户选择：
    - A. 接受当前效果继续
    - B. 调整风格关键词后重新生成偏移严重的镜头
    - C. 回到第二阶段重新确认风格

### 7.4 商品外观不一致
- 若场景图中的商品外观与三视图明显不符：
  - 标记该场景图为"商品外观异常"
  - 建议用户重新生成，或在prompt中加强商品一致性约束描述
  - 反复不一致 → 建议回到第三阶段重新生成三视图（可能三视图本身存在问题）

## 八、场景图质量标准

### 8.1 合格标准（必须全部满足）

- [ ] 商品外观与三视图一致（材质/颜色/形状/比例/细节）
- [ ] 画面比例与投放渠道匹配
- [ ] 画面内容与分镜描述对应
- [ ] 无伪影、模糊、重影、异常色块
- [ ] 无文字乱码或异常文字
- [ ] 风格与第二阶段选定风格一致
- [ ] 分辨率达到投放渠道最低要求

### 8.2 优秀标准（至少满足 3 项）

- [ ] 光照自然，阴影合理
- [ ] 背景与商品视觉层次分明
- [ ] 构图符合景别要求（商品占比正确）
- [ ] 色彩和谐，无突兀色块
- [ ] 整体画面有高级感/商业质感
- [ ] 多张场景图之间视觉风格高度统一
