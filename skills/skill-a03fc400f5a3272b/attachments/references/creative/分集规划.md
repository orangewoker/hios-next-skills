# 分集规划 · v2.0 — 零铺垫·冲击驱动

> **v2.0 重大变更**：砍掉四阶段（起势/攀升/风暴/决战），改为二阶段冲击模型。第一集第一秒即入冲突核心——无"建立世界观""场景引入""角色出场"等铺垫段落。信息在冲突进程中自然释放，无独立交代段。每集 = N 个冲击段连续叠加。
> ⚠️ **v3.6 决策锁定表**：本文件为判断知识库。执行 `/目录` 时，所有判断先在 `creative.md` §0.2 分集决策锁定表中一次性锁死，后续 Phase 0/1 只引用锁定表、不复判。

---

## 一、核心原则

| 原则 | 说明 |
|:---|:---|
| **零铺垫** | 全集全段禁用以下内容：场景空镜建立、角色站位定位、因果前置解释、"先展示环境再发生冲突"的任何变体 |
| **冲突先行** | 每段从冲突中间切入，15s 只做一件事——一个冲突事件从爆发→推进→钩子收尾 |
| **信息融入冲突** | 所有背景信息（角色身份/关系/动机/前情）在冲突进程中以对话/动作/视觉符号自然释放，不给独立交代段落 |
| **冲击连续** | 段与段之间不设"缓冲""过渡""发展"区域。每段结尾钩子直接衔接到下一段开场，拒绝情绪断崖 |

---

## 二、二阶段冲击模型

砍掉起势+攀升+风暴+决战的四阶段结构。全剧分两段：

| 阶段 | 集数占比 | 定位 |
|:---|:---:|:---|
| **冲击段** | 前 80% | 每集一个核心冲突从中间切入，连续推进，以最强钩子收尾。无"建立"集——第一集就是冲突核心 |
| **终结段** | 后 20% | 全剧收束。所有未闭合线索在此阶段解决——但保持冲突密度，拒绝"讲道理式结局" |

**集数分配**（以 30 集为例）：

| 总集数 | 冲击段 | 终结段 |
|:---:|:---|:---|
| 30 | 1-24 | 25-30 |
| 60 | 1-48 | 49-60 |
| 80 | 1-64 | 65-80 |
| 100 | 1-80 | 81-100 |

---

## 三、每集冲击标签

每集标注三标签——无"起势/攀升/风暴/决战"等阶段标签：

| 标签 | 说明 | 必填 |
|:---|:---|:---:|
| **核心冲突事件** | 一句话——本集唯一的核心冲突是什么。必须是可视觉化的事件（"对峙→揭穿"），不是抽象状态（"矛盾升级"） | ✓ |
| **情绪高点** | 什么情绪·大约哪一段·强度几级。如"恐惧→暴怒转折·S1E·8/10" | ✓ |
| **结尾钩子类型** | 悬念钩 / 反转钩 / 情绪钩 / 危机钩 四选一 | ✓ |

**禁止的标签措辞**：建立世界观、场景引入、角色出场、关系铺垫、背景交代、过渡集、缓冲集。

---

## 四、每集冲击结构

每集由 N 个冲击段连续叠加。无"中间发展部分"独立区域：

```
S1A（冲击段 1）：核心冲突从中间切入 → 钩子收尾
S1B（冲击段 2）：钩子接续 + 冲突升级 → 新钩子
S1C（冲击段 3）：...
...
S1H（冲击段 N）：冲突转折 → 终局钩子
```

每段产出一个 `S{N}A_即梦视频.md`。段与段之间不插入缓冲/过渡段。

---

## 五、冲击段三要素

每段 15s 内部：
- **0-3s**：冲突切入（身体关系/动作瞬间直接入画——无空镜、无定位、无建立）
- **3-12s**：冲突推进（对话+动作+光影同步升级，信息在冲突中释放）
- **12-15s**：钩子收尾（悬念/反转/情绪/危机 任选，情绪强度 ≥ 8/10）
