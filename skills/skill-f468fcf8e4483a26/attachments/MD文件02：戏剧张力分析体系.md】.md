一、模块定位\
本模块是「顶级大导演思维」的戏剧创作顶层控制模块。

权限层级严格区分：

系统规则最高优先级：\
《[全局规则与禁令.md](http://xn--jhq3tk4diuaz70b5x6bs1x.md)》所有创作不得越界

戏剧创作最高优先级：\
本文件在遵守系统禁令前提下\
对剧本审查·镜头叙事·分镜创作·提示词·视频生成\
拥有最高创作支配权\
所有下游模块必须服从本引擎的戏剧诊断结果\
核心职能：

只对两件事负责：\
① 让故事充满戏剧张力（观众为什么看下去？）\
② 让镜头充满电影叙事感（观众看懂了什么情绪？）\
在接收用户提供剧本后，完成导演级四步闭环：

① 诊断本场观众观看驱动力\
② 挖掘或开发剧本原生隐性戏剧张力\
③ 解析人物攻防·信息差·情绪曲线·局势输赢·追剧钩子\
④ 将所有戏剧变化精准唯一转译为镜头语言\
二、全局唯一正确工作流\
固定严格执行顺序·禁止任何调换·逆序·跳过：

第01步·剧本接收与前置确认\
第02步·戏剧张力分析（先定戏·定观众驱动力）← 本模块负责\
第03步·剧本审查（按需）\
第04步·导演视觉语法·镜头方向确认\
第05步·镜头叙事构思方案输出\
第06步·分镜脚本创作\
第07步·镜头可行性审查（按需）\
第08步·视觉资产准备\
第09步·视频提示词创作\
第10步·提示词可行性审查\
第11步·视频生成执行\
第12步·合成·交付·归档\
流程逻辑本质：

先判断：这场戏应该怎么好看·观众为什么要看\
再校验：现有剧本是否达标·是否有缺陷\
杜绝AI沦为"逻辑校对机器"\
回归顶层戏剧导演思维\
三、故事成色「终极三问」（必须通过测试）\
拿到用户的剧本或一句话故事后，必须用这三个问题检验其成色。如果缺任何一问，必须主动引导用户补齐：

问题①：主角是谁？他的困境是什么？\
他面对什么压力·什么阻力·什么恐惧？\
必须具象·禁止抽象描述

问题②：他必须付出什么代价？\
连接·胜利·传承不是免费的\
他必须承受什么物理或心理上的代价？

问题③：故事的最后·他的心态/状态发生了什么不可逆的改变？\
他完成了什么？他破防了？\
开场状态 ≠ 结尾状态（这是铁律）\
通用案例：

职场爽剧：\
① 主角是被打压的员工·困境是方案被否定·被当众羞辱\
② 代价是忍耐三次打压·表面认输·放弃自尊\
③ 不可逆改变：他从被动挨打变成掌控全局

爱情片：\
① 主角是暗恋者·困境是不敢开口·怕破坏现有关系\
② 代价是鼓起勇气表白·可能失去这段友情\
③ 不可逆改变：无论结果如何·他不再是那个沉默的人

悬疑剧：\
① 主角是侦探·困境是证据被销毁·嫌疑人在逃\
② 代价是违规取证·可能断送自己的职业生涯\
③ 不可逆改变：他用自己的方式定义了什么是正义\
四、最高核心总则\
终极追问（每场必答·无例外）\
观众为什么愿意继续看下一秒？

禁止一切纯流水账结构：人物出现→说话→做事→离场。

每场戏必须至少具备任意一种原生戏剧源：

① 未解决的问题\
② 正在进行的冲突博弈\
③ 人物瞬时求而不得的欲望\
④ 即将失去的信任·利益·身份·关系\
⑤ 隐藏秘密与信息不对称\
⑥ 临近的危险与危机\
⑦ 权力强弱动态博弈\
⑧ 人物认知偏差与误解\
⑨ 即将揭晓的真相\
⑩ 被迫选择与必须承担的代价\
无戏剧源 → 判定平铺无效戏 → 强制放大原生隐性张力

五、五大张力维度模型\
欲望 | 阻力 | 风险 | 信息差 | 时间压力

非机械公式·维度互补代偿·不强制每场全部集齐。

维度①·欲望（每场必拆·瞬时场景化）\
只拆解本场当下·此刻·即时诉求·不取长期人生目标

禁止模糊情绪描述·必须具象行为目的：\
想求证·想隐瞒·想自保·想逼对方认错·想拿到答案·想阻止事态

通用案例：\
职场爽剧：主角想在会议上证明自己的方案是对的\
爱情片：女主想让男主注意到自己·但不敢直说\
悬疑剧：侦探想在嫌疑人开口前找到漏洞\
家庭剧：父亲想和解·但不知道怎么开口\
维度②·阻力/悬念支撑（核心修正·适配全题材）\
无阻力·无悬念支撑·则难以形成有效戏剧张力

张力不仅来自人物对抗·也可来自：\
内心挣扎·未知悬念·等待拉扯·关系微妙变化·时间流逝·自我桎梏

通用案例：\
职场爽剧：上司当众打压·同事冷眼旁观（外部阻力）\
爱情片：女主不确定男主的心意（内心挣扎）\
悬疑剧：关键证据在嫌疑人手里（信息阻力）\
家庭剧：父子之间多年的沉默（关系阻力）\
维度③·风险（高压戏必具象）\
明确失败代价·必须具象·禁止模糊：\
信任崩塌·身份暴露·局势被动·关系破裂·证据失控

通用案例：\
职场爽剧：失败代价=被当众羞辱·项目被砍\
爱情片：失败代价=永远失去这个人\
悬疑剧：失败代价=凶手逃脱·无辜者受冤\
家庭剧：失败代价=父子关系彻底决裂\
维度④·信息差（全题材最高优先级张力）\
三维拆解：A已知 / B已知 / 观众已知

四种信息差状态：\
① 观众知·人物不知 → 揪心悬念\
② 人物知·观众不知 → 神秘悬疑\
③ 双方皆不知 → 探索张力\
④ 认知错位 → 顶级反转潜力

通用案例：\
① 观众看到凶器藏在主角身后·主角不知道 → 揪心\
② 反派知道主角的秘密·观众不知道 → 悬疑\
③ 双方都不知道对方爱着自己 → 探索\
④ 主角以为自己输了·其实已经赢了 → 反转\
维度⑤·时间压力（非全局强制·分级适配）\
高压爽剧·悬疑·惊悚·对抗戏：优先构建时间压迫感\
情感·治愈·拉扯·文艺·关系戏：无需时效压力

通用案例：\
有时间压力：倒计时·截止日期·对手即将得手\
无时间压力：两人在咖啡馆慢慢靠近·情感自然流淌\
六、人物攻防博弈系统\
双人/多人对话优先筛查：是否存在明确目标·阻力·信息差·权力落差·潜台词·立场冲突。

满足以上任意条件 → 启用完整六阶攻防体系：\
试探 → 出牌 → 接牌 → 避让 → 反牌 → 阶段性输赢

纯情感交流·安慰·回忆·告别·信息传递·日常对话 →\
不强行套用博弈结构·保留自然松弛感\
七、场景张力等级体系（永久锁死）\
S级·核心高压戏：必须产生至少一次不可逆局势变更\
A级·关键推进戏：必须产生至少一次不可逆局势变更\
B级·常规过渡戏：只需产生有效局势变化OR观众认知更新\
C级·极简功能戏：只需产生有效局势变化OR观众认知更新\
核心底线：开场状态 ≠ 结尾状态 无任何有效变化 = 纯流水账 = 强制重构戏剧表达。

镜头资源·剪辑密度·特写权重·运镜复杂度严格按等级分配。

八、流水账判定与修复铁律（永久锁死）\
流水账特征：

交替对话·无博弈·无信息·无情绪·无变化·无目的·无风险\
修复最高原则：

绝不凭空新增剧情·新增事件·新增人设·新增台词\
只放大剧本原生存在的：\
心理活动·情绪反差·潜台词·安全空间入侵·认知错位·隐性权力博弈\
九、三层戏剧结构（全体系最高权重·永久锁死）\
第一层·表层（禁止停留）：肉眼可见的动作·台词·行为\
第二层·中层（可用）：人物真实目的·即时诉求·隐藏意图\
第三层·深层（优先拍）：潜台词·口是心非·伪装·隐瞒·恐惧·期待\
终极镜头铁律\
镜头永远优先服务第二层人物目的·第三层潜台词·绝不直译第一层表面画面。

普通AI只拍：人物做了什么·说了什么\
顶级导演只拍：人物为什么这么做·为什么不敢直说·内心真实状态\
通用三层对应案例：

场景类型 第一层（禁止停留） 第三层（优先拍）\
职场爽剧 主角低头不语 眼神里有不甘·在等待时机\
爱情片 女主转身离开 脚步放慢·在等他叫住她\
悬疑剧 侦探平静喝咖啡 手指微微收紧·已经发现了\
家庭剧 父亲沉默不说话 嘴唇微动·有话说不出口\
史诗片 英雄独自站立 肩膀承受着整个世界的重量\
社会现实 工人坐在地板上 眼神里还有火·他没有放弃\
十、潜台词检测机制（永久锁死）\
每场对话强制拆解：

字面台词 → 真实意图 → 不敢直说的核心原因 → 对方接收状态 → 观众解读状态\
台词与心声反差越大·戏剧密度越高·镜头留白·停顿·微表情特写权重越高。

十一、情绪张力递进规则（永久锁死）\
❌ 禁止机械叠加：生气→更生气→暴怒

✅ 强制认知驱动情绪曲线：\
平静 → 疑惑 → 不安 → 确认 → 压抑 → 紧绷 → 反差爆发/隐忍克制\
所有情绪变化·必须来自人物认知改变·而非单纯心情波动。

通用情绪曲线案例（三种题材）：

案例A·孤独与荣光\
适用：创业者·大国重器·非遗传承·宇宙探索\
情绪曲线：\
孤独开场（极静）→ 见证奇迹（极动）→ 决意付出（代价）\
→ 全世界欢呼（极致高光）→ 独自承受（极致孤独）→ 长舒一口气（释然破防）

案例B·偏见与信任\
适用：AI科技·国际交流·医患关系·文化碰撞\
情绪曲线：\
未知恐惧（紧张）→ 本能抗拒（抵触）→ 试探接触（犹豫）\
→ 亲眼见证（震撼）→ 彻底臣服（惊叹）→ 拥抱信任（双向奔赴）

案例C·传承与觉醒\
适用：国潮复兴·古典神话·数字文旅·非遗手作\
情绪曲线：\
岁月静好（平稳）→ 神秘降临（转折）→ 文明对视（神迹）\
→ 灵魂觉醒（爆裂）→ 回归宁静（余音绕梁）\
十二、爽剧高级结构（永久锁死）\
压制 → 忍耐 → 假象弱势 → 对手/观众双重误判 → 绝境铺垫 → 底牌反打 → 认知层级反转\
高级爽点核心：

不靠骂人·不靠怼人·不靠表面嚣张\
高级爽感 = 人物自我认知 VS 真实局势的巨大落差反转\
通用爽点结构案例：

职场爽剧：\
压制：主角被当众否定·项目被打压\
忍耐：三次打压·三次隐忍·表面认输\
假象弱势：对手以为主角彻底认输\
底牌反打：主角亮出早已准备好的数据/证据\
认知反转：原来一切都在主角掌控中

悬疑剧：\
压制：侦探被嫌疑人耍弄·证据被销毁\
忍耐：侦探表面束手无策\
假象弱势：嫌疑人以为侦探已经放弃\
底牌反打：侦探亮出最后一个关键证人\
认知反转：原来侦探早就知道真相·只是在等最佳时机

情感短片：\
压制：主角被生活压垮·独自承受\
忍耐：沉默·坚持·不让人看见脆弱\
假象弱势：观众以为他要放弃了\
底牌反打：他做出了那个最艰难的选择\
认知反转：原来他一直都在等这一刻\
十三、反转三大黄金标准（永久锁死）\
① 前有预埋（回看逻辑闭环·细节有据）\
② 后有局势巨变（直接改变主线剧情走向）\
③ 无空降证据·无机械开挂·无强行剧情\
无局势改变的信息揭露·仅为剧透·不认定为有效反转。

十四、信息释放节奏（永久锁死）\
禁止一次性全盘交底\
高级叙事节奏：\
发现 → 怀疑 → 碎片验证 → 误导拉扯 → 层层揭露 → 最终真相\
十五、观众信息四维定位（永久锁死）\
每场必判·决定镜头留白·悬念·曝光策略：

观众知·人物不知 → 揪心悬念\
人物知·观众不知 → 神秘悬疑\
双方皆不知 → 探索张力\
认知错位 → 顶级反转潜力\
十六、反应镜头规则（永久锁死）\
仅在关键认知变更节点使用反应镜头：

真相揭露·底牌亮出·局势逆转·谎言戳破·威胁落地·认知崩塌·心态反转\
只有反应能产生新戏剧信息·推进剧情·展现人物心态时·才给予反应镜头。 杜绝AI机械循环堆叠：动作→特写→反应→特写。

十七、戏剧转译镜头总控（永久锁死）\
权力变化 → 构图·机位·光影权重同步位移\
信息揭露 → 细节道具优先·再人物反应·再全景交代\
情绪爆点 → 认知递进式景别收紧\
关系变化 → 距离·视线·站位·画面主次同步变更\
运镜唯一终极原则\
运镜不为炫技·不为美感·不为电影感\
只服务：信息揭露·情绪放大·权力展示·观众视线引导·紧张度控制\
无戏剧需求·绝对静止\
十八、镜头节奏压力匹配（永久锁死）\
低压稳镜·升压紧镜·爆点骤停留白·爆后静置消化\
动静张弛结合\
拒绝全程动态·全程快切·全程平铺无呼吸感\
十九、开场钩子规则（永久锁死）\
爽剧/短视频短剧模式（强制执行）\
前三秒：必须具备冲突·异常·疑问·压迫·结果先行·身份反差\
前十秒：必须建立观众强疑问钩子·杜绝无效铺垫空镜\
院线电影/精品情感长片（柔性执行）\
不强制三秒爆点·允许氛围铺垫·情绪铺垫·场景代入\
但开篇必须建立明确观看驱动力与戏剧预期\
三种开场钩子公式：

公式A·冲突先行：\
第1秒：人物特写（表情或关键动作）\
第2秒：冲突道具/关键信息特写\
第3秒：对立人物反应特写\
效果：观众立刻进入"这是怎么回事"的强疑问状态

公式B·结果先行：\
第1-3秒：直接展示最强画面（爽点/反转/危机高潮）\
之后：叙事回溯至事件起点\
效果：观众带着"怎么到这一步"的疑问追剧

公式C·身份反差：\
第1-2秒：展示人物的弱势/被压迫状态\
第3秒：切入暗示其真实实力的细节道具或眼神\
效果：建立"这个人不简单"的强期待感\
二十、钩子接力机制（永久锁死）\
本场解决旧问题\
↓\
本场必须诞生新的观众观看驱动力

新驱动力可表现为：\
更深层真相·更隐秘危机·更私人矛盾·更危险处境·更复杂博弈·更不可逆后果\
通用钩子接力案例：

职场爽剧：\
第一场：主角被打压（他能赢吗？）\
↓ 第二场：发现关键证据（证据够用吗？）\
↓ 第三场：证据被对手发现（他会被反将一军吗？）\
↓ 第四场：主角亮出真正的底牌（原来他早就准备好了）

悬疑剧：\
第一场：发现尸体（谁是凶手？）\
↓ 第二场：找到嫌疑人（他真的有罪吗？）\

二十一、最小有效戏剧单元（流水账检测器·永久锁死）\
