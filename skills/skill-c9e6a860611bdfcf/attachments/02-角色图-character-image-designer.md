# 做什么

把任意形态的角色需求（一句话、一段写坏的提示词、一段人物设定、一张参考图）转成一条能出实拍感**真人**角色图的高质量提示词。

目标：无限接近真实实拍、影视级人像摄影质感，不出 AI 感、塑料皮肤、蜡像脸、AI 美颜。**只做真人，不出二次元、不用动漫语言。**

只处理**单张角色图**，不管表演调度、镜头组、连续分镜。

# 需要什么输入

- 最少：一句话角色意图（“一个民国女学生”）
- 可选：年龄、性别、身份、职业、时代、地域、发型、服装、体型、画幅、景别
- 缺不得的三样：**年龄区间**、**画幅与用途**（剧照／标准资产图／头像）、**时代与地域**
- 用户给的原始提示词**多烂都直接收**，不要要求他先整理

# 怎么做

## 1. 把用户给的话逐句分成四类

- **意图**（要有书卷气、看着不好惹、疲惫的中年人）→ 保留，翻成视觉落点
- **事实**（年龄、性别、职业、时代、发型、服装、明确的身体特征）→ 一字不改
- **空词**（绝美、精致、高级脸、8K、大师作品、电影级质感、超写实）→ **删掉**。特别注意：**“漂亮、精致、绝美”这类词会直接激活网红脸的大眼小脸尖下巴偏好，是本类第一号要删的东西**
- **缺失** → 按下面第 2 条处理

意图翻译示例：书卷气→肩略内收、下颌微收、目光平视偏下、服装层次干净无装饰堆叠、手边有书或笔；不好惹→眉骨显、下颌线硬、下颌微抬、肩宽重心稳、衣服轮廓硬挺；疲惫→眼睑略垂、眼下有色素沉积、嘴角向下但闭合、肩线塌、重心偏一侧腿；常年劳作→手背纹理明显、指节粗、皮肤有日照色差（衣领内外不同）、站姿略前倾；年轻未历事→面部脂肪饱满、下颌线柔和、肩颈线条薄；上位者→视线微俯、下颌抬、体态挺、配饰少而质重（一件就够）。

## 2. 三档纪律

- **必问（最多 3 个）**：年龄区间未知、画幅与用途未知、时代与地域未知时才问。其余不问。
- **默认补**：气候季节按服装厚度反推、不主动加季节性元素；标准资产图用中性柔和光，剧照按场景光；景别（标准资产→全身或三分之四，剧照→半身）；姿态中性站立、重心在一侧腿、双手自然——**不写“手插兜”这类会引发手指错误的高风险姿态**；背景中性简洁、不编地点；服装三层以内。
- **绝不编造**：不加原文没有的疤、痣、纹身、伤、胎记、夸张配饰；不加“顺手给他一把剑”这类道具；不改身份、时代、职业、性别、年龄；**不因为“更好看”而改长相**（把宽脸改窄、单眼皮改双、薄唇改厚都属于越界）。

## 3. 硬判据（写的时候必须满足）

- **五官写“关系”，不写“类型名”**：
  - 不写“高鼻梁”，写“鼻梁起点在两眼之间靠上，鼻尖略向下，鼻翼窄”
  - 不写“大眼睛”，写“眼裂较长，外眼角略高于内眼角，上眼睑略压住瞳孔上缘”
  - 不写“小脸”，写“颧骨不外扩，下颌角靠内，下颌线从耳下向前收”
- **表情写“肌肉动作”，不写情绪词**：
  - 不写“愤怒”，写“眉的内侧下压、上眼睑抬起、鼻翼张开、下颌前移、嘴唇压成一条线”
  - 不写“悲伤”，写“眉的内侧上抬、上眼睑下垂、嘴角向下、下唇略外翻”
- **皮肤真实感的四件，缺一件就往塑料走**：
  1. 高光集中：「高光只出现在鼻尖、颧骨上缘与下唇，其余部分哑光」
  2. 体积过渡：「颧骨到下颌之间有一片柔和的暗部过渡」
  3. 少量不完美：毛孔、细小绒毛、色素不均、一两颗痣或小疤、眼下淡淡的暗色，**各写 1–2 项即可，多了变成堆细节**
  4. 环境光作用：「靠近窗外的一侧脸略亮，受天光影响偏冷」
- **皮肤真实感来自体积与光影关系，不是毛孔多、不是锐利高光、不是磨皮。**
- **头发三件**：头发成束、有重量、发尾有少量散开的碎发；写清**发际线与分缝**（不写就会像头盔扣在头上）；写头发与肩或领口的接触关系
- **服装要有重量**：写它怎么受力（肩线被拉起、下摆被压住、袖口堆在小臂）；三层为限；必须写使用状态（新的、常穿的、脏的、湿的、皱的）——不写就是崭新的道具服
- **手部简化**：只让手做必须的事，握住最安全；不写复杂手势；手在画面里占比不要大
- **光线**：一图一主光；脸部明暗比不超过 1:4；暗部不死黑，写“暗部仍能看出面部结构”

## 4. 冲突时的优先级（从上往下保）

人物身份与结构（年龄、性别、骨架、脸型关系）→ 轮廓与体态 → 服装与造型 → 表演与动作 → 镜头表现 → 细节。

越靠身份的越硬，越靠装饰的越软。出图不对时先砍最后一层，不要动第一层。

## 5. 防 AI 感

总判据：**AI 感来自“不符合物理的完美”**。真人的每一处都是不匀的。

三招解药：**有来源**（光从哪来）· **有约束**（写“只有一处”而不是“不要多处”）· **有不完美**（不对称、磨损、少量瑕疵）。

- **塑料皮肤／蜡质** → 「皮肤呈哑光，高光只在鼻尖、颧骨上缘与下唇；颧骨到下颌有柔和过渡；面颊保留少量细微起伏」
- **蜡像脸** → 给 1–2 处不对称（一侧眉毛略高、笑时嘴角不对称）＋写出年龄痕迹（眼下细纹、法令纹浅痕）
- **AI 美颜／网红脸** → **删掉“漂亮／精致／绝美”，改写成具体骨相**。描述结构永远比描述美感有效
- **磨皮感／无纹理** → 删掉“细腻／光滑／无瑕／高清毛孔”，改「保留真实皮肤纹理，含少量毛孔与细小绒毛」
- **CG 建模感** → 「轮廓边缘有轻微柔化；受环境光影响，暗部带一点环境色」
- **HDR 式高对比** → 「低对比、低饱和；亮部不过曝，暗部保留结构」
- **过密织物纹理** → 「面料以主色与垂坠感为主，纹理只在近处可见」
- **头发块状／头盔感** → 「头发成束有重量，发际线与分缝清晰可见，发尾有少量散落碎发」
- **服装穿模／饰品悬浮** → 层数减到 3 以内；写出饰品的连接或接触关系（“耳环垂在耳垂下方”）

**见到就删的词**：绝美、精致、高级脸、漂亮、帅气、细腻、光滑、无瑕、完美、8K、大师作品、超写实、细节丰富。

**不要用否定句**：不写“不要塑料皮肤”，改成写“皮肤呈哑光，高光只在……”

## 6. 画幅

- **9:16 竖屏**：全身像时人物占画面高度 60%–80%，头顶留一点空（不留是切头，留太多是人物变小）；重心放中下三分之一；靠纵深组织，不靠左右
- **16:9 宽幅**：人物偏一侧落在三分点，另一侧留给环境或负空间；以半身、胸像为主（宽幅里全身像会偏小）
- **1:1 或 4:3**：胸像、头肩为主，适合头像与资产图

**人脸近摄不要用广角**（会拉伸五官）；标准资产图首选长焦，结构最自然。

## 7. 同一角色出多张图时

**先钉不变项，再写变化项：**

- **不变项（每张图逐字照抄）**：年龄与性别、脸型与五官关系、发际线与发型轮廓、体型与头身比、服装主色与核心轮廓、识别物（1–3 件）
- **可变项**：景别与角度、表情与姿态、光线与环境、服装的破损与污渍状态

先写一段“人物结构描述”（脸、身、发、衣、识别物），后续每张**原样带上**，只写变化的部分。**不要每张重新描述一遍长相**——重描述会生成一个相似但不同的人，这就是“看着像两个人”的来源。

## 8. 标准资产图

正面全身、侧面全身、背面全身、三分之四全身、正面头像、三分之四头像、侧面头像。

标准资产图的三条纪律：背景中性（浅灰或素墙，不带剧情环境）· 光线中性（柔和顶侧光，能看清明暗交界，**不用戏剧光**）· 姿态中性但有重心（重心在一侧腿，双手自然有事做，纯直立会僵）。

# 产出什么

固定四件，顺序不变：

```
【正文提示词】一段自然语言，不分点、不写字段名、不叠同义词。
  顺序：身份与年龄 → 头脸 → 身体体态 → 服装 → 皮肤与质感
        → 表情眼神姿态 → 摄影 → 光线 → 整体质感。

【Negative】一行逗号分隔，例如：
  换脸, 结构漂移, 塑料皮肤, 蜡像脸, CG 建模感, AI 美颜, 过度磨皮, 过度锐化,
  手指错误, 多余肢体, 服装穿模, 饰物悬浮

【画幅与参数建议】画幅｜景别｜机位高度｜镜头倾向｜景深

【改动说明】替换了哪些空词｜补齐了哪些默认项｜保留了哪些事实
```

交付前逐条核对：是不是同一个人（多图时）· 头身比与肩宽手脚比例是否正常 · 发型与服装轮廓是否稳定 · 表情是否属于这个人物而非模板化 · 角度变化是否来自真实透视 · 材质是否过锐或细节过量 · 人物与场景的光线和色温是否统一 · 有没有重复人物、额外肢体、错误手指、服装穿模、悬浮饰品 · 皮肤是否呈现体积与光影关系而非磨皮或锐利高光。

# 什么时候问你

- 只在三种情况停下来问，**一次问完、最多 3 个**：年龄区间未知、画幅与用途未知、时代与地域未知。
- 其余一律按默认补，补完标注，**不要反复确认**。
- 用户说“这条不成立”时，撤销或改写那一条，不要辩解。
- 出图不对时：**先查比例、光、皮肤写法，不要第一时间加形容词**；一次只改一处。
