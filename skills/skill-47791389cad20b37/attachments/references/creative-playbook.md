# 动漫 PV 创意与导演手册

只在解释风格、编写导演方案、角色资产提示词、分镜或视频提示词时读取本文件。

## 目录

创意定位 → 时长与节拍 → 角色一致性卡 → 角色资产设定图 → 纯文本分镜 → 视频提示词 → 角色资产验收 → 台词 → 落版与文字 → 音乐 → 导演质检

## 创意定位

本 Skill 的统一视觉底座是“纯二维日式赛璐璐动画 + 扁平 Editorial MG 平面设计 + 高级游戏宣发海报动态视觉语言”。不同项目只改变剧情、主题符号、配色、角色气质、节奏密度和音乐，不切换成真实摄影或三维 CG。

- 潮流游戏 PV：高频切镜、撞色、原创 UI、贴纸、字体与图层运动。
- 电影叙事 PV：保留二维平面语言，增加镜头因果、情绪递进和悬念。
- 东方幻想 PV：二维角色与东方符号、书法/印章/纹样/自然意象结合。

## 时长与节拍

总时长建议内部镜头数结构15 秒12–240–1 秒强钩子；1–6 秒角色与主题；6–12 秒升级/高潮；12–15 秒落版30 秒20–360–2 秒钩子；2–10 秒建立；10–23 秒升级；23–27 秒高潮；27–30 秒落版45 秒28–480–3 秒钩子；3–14 秒建立；14–34 秒升级；34–41 秒高潮；41–45 秒落版60 秒36–600–4 秒钩子；4–18 秒建立；18–46 秒升级；46–55 秒高潮；55–60 秒落版

潮流/JRPG/角色宣传类默认镜头约 0.3–0.8 秒；需要剧情理解的镜头可延长，但不得用无信息空镜填时长。内部镜头数不等于视频节点数；视频节点仍按 `ceil(总时长/15秒)`。

## 角色一致性卡

每个重复角色建立唯一文本基准：

- 年龄感、脸型、眼睛、发型、发色、肤色、体型比例。
- 服装主辅色、剪裁、纹样、鞋、装备、饰品。
- 1–3 个远景也能识别的标志元素。
- 性格与动作气质。
- 允许变化与绝对禁止变化。

角色一致性卡只服务于生成一张完整角色资产设定图和后续视频提示词。

## 角色资产设定图

角色图片阶段只调用 [character-asset-template.md](character-asset-template.md)。

一个角色只生成 1 张完整资产设定图，必须包含：

- 左侧动态主视觉。
- 正/侧/背三视图。
- 六宫格表情。
- 同图配件与装备细节。
- 右下色板。
- 白色背景、专业角色概念艺术排版、创意标题和简洁注释。

禁止再生成场景图、道具单图、服装单图、分镜关键帧、首尾帧或任何额外辅助图片。

## 纯文本分镜最低字段

每个内部镜头至少记录：

 1. 精确时间码与叙事功能。
 2. 角色与动作起势/过程/收势。
 3. 表情、视线与角色朝向。
 4. 场景文字描述、前中后景与二维图形层。
 5. 景别、机位、轴线、焦段感与相机路径。
 6. 主色、辅色、线条和赛璐璐阴影。
 7. UI、贴纸、文字或主题符号。
 8. 同期声、动作音、对白与音乐节拍位置。
 9. 入场转场、出场转场和准确尾帧。
10. 与相邻镜头的转场交接契约。

不再为分镜创建 `imageGenerationPrompt`，也不运行 storyboard 生图。

## 视频提示词

每个视频节点的 `videoMotionPrompt` 必须读取 [reference-video-style.md](reference-video-style.md)，按以下章节完整输出：

`生成目标 → 整体风格 → 角色设定 → 主题设定 → 音乐与声音 → 画面风格 → 动态与转场要求 → 按时间码镜头 → 表演要求 → 节点尾帧与下段交接 → 不要出现`

视频提示词必须使用自然、详细、可执行的中文。只有成片中确实要显示或说出的英文才保留，并使用半角双引号。

相邻镜头至少在主体位置、运动方向、速度、颜色、遮挡、图形形状或视线中匹配两项。即使没有关键帧图，也要靠文本精确维护连续性。

## 角色资产验收

角色资产生成后先自动检查：

- 主图与三视图是否同一人物。
- 三视图服装、鞋、装备是否一致。
- 六表情脸型、瞳色、发型是否稳定。
- 配件是否属于角色本身。
- 色板是否与角色主视觉一致。
- 是否保持纯二维、白底、专业设定图排版。

用户点击满意前，不创建或运行视频节点。返修只重做对应角色设定图，不生成其它类型图片。

## 角色台词设计

需要台词时提供三类候选：标志性宣言、冲突对峙、克制留白。每类 1–4 句，每句尽量不超过 18 个汉字。确认后写入相应时间码镜头；需英文时把英文原句放在半角双引号中。

## 落版与文字

- 片名、角色代号、系统提示和关卡文字全部原创。
- 重要文字尽量放在独立落版或清晰安全区。
- 视频生成提示词写准文案与动画方式；需要精确文字时优先后期排版，禁止近似乱码。

## 音乐自动匹配

- 潮流/JRPG：132 BPM 左右可作为默认起点，电子朋克、电子摇滚、碎拍、Bass、短促合成器与街机提示音。
- 电影叙事：根据情绪降低或提高 BPM，使用电子 + 管弦混合。
- 东方幻想：民族音色 + 现代电子/电影打击，避免传统旅游宣传片感。

开头需要瞬时声学钩子，中段节拍密度增加，结尾通过定格与标题确认音收束。

## 导演质检

逐项确认：

- 第一秒是否建立角色和主题识别。
- 是否全片保持纯二维，不出现三维/摄影污染。
- 角色是否严格参考已验收角色资产。
- 是否没有生成或依赖场景图、关键帧、首尾帧。
- 内部镜头是否持续有新信息，且没有无意义空白。
- 转场是否爆、脆、快且逻辑可执行。
- 前景/中景/后景是否有多层运动。
- 人物脸、发型、服装、鞋、装备、配色是否稳定。
- 肢体、手指、文字、UI 是否正确。
- 相邻节点是否承接上一段真实尾帧。
- 视频原生轨是否没有模型自带 BGM；后期音乐是否与剪辑点对齐。
