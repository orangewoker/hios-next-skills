## #做什么

解决AI动作片“敌人站桩挨打、隔空假打、一碰就倒”的痛点。用双骨架系统（主动打击型 / 挨打反击）确保每一招都有真实攻防博弈、真实接触凹陷、物理环境反馈、二次追击补刀。最终输出具备电影级质感的动作实拍短片。

## #需要什么输入

**最少提供：**

- 每关必须选定骨架A（主动打击型）或骨架B（挨打反击），不得默认。

**可选提供：**

- 目标画幅（不限定，按项目需求或用户指定）

- 是否需要配合70_01（火柴人6宫格绘制SOP）、70_03（单关生产工作流）使用。

## #怎么做

### 【绝对工作流铁律】（永久锁死，严禁调换）

在收到任何题材的创作需求后，必须严格按以下固定顺序调度下层Skill。顺序一旦错误，直接判定为系统违规，必须打回重排：

1. 【总制片人】（前置算力审查，资产门禁）
2. 【葵花宝典】（剧本诊断与重构：困兽、体语、焚我）
3. 【大导演思维】（镜头转译与叙事构思）
4. 【情绪大师】（七层微表情拆解与情绪连贯）
5. 【风格Skill】（题材专属视觉定调）
6. 【提示词底座】（物理参数与Prompt落地生成）

**为什么必须这个顺序**：先过【总制片人】卡死算力，再让【葵花宝典】做剧本外科手术。剧本没有写出“困兽、体语、焚我”的底层内核，就不准进入【大导演】的镜头设计。剧本改了，分镜全废，必须杜绝这种算力黑洞。

### 一、骨架A：主动打击型

帧时间内容F1 0-1sB先手，A受击一次并立刻卸力反制F2 1-2sA第一击，真实接触凹陷F3 2-3sA第二击，真实接触凹陷F4 3-4sB飞出，撞实环境物，接触瞬间才裂F5 4-5s环境物反弹，A补刀，再次凹陷F6 5-6sB瘫倒，A收势定格

### 二、骨架B：挨打反击

帧时间内容F1 0-1sB先手，A受击，肩部凹陷，后脚滑动卸力，面部痛苦拉满F2 1-2sB追击，A格挡/闪避但仍被压制，未反击，痛苦渐退F3 2-3sB继续压制，A退步，重心下沉，寻找破绽，仍未反击，面部冷峻F4 3-4sA找准破绽，第一记反击命中，真实接触凹陷F5 4-5sA第二记反击命中，真实接触凹陷F6 5-6sB飞出撞环境物，A收势定格，面部冷峻

**骨架选择规则：**

- 普通街头对手 → 骨架A
- 强敌/宿敌 → 骨架B
- 女性对手 → 骨架B
- 最后8关车轮战 → 骨架A
- 需要戏剧张力的关键战 → 骨架B

### 三、痛苦表情规则

- 骨架A：禁止痛苦表情。
- 骨架B：F1痛苦拉满（皱眉、咬牙、面部肌肉受压），F2痛苦渐退，F3恢复冷峻；F4-F6完全冷峻。
- 痛苦只允许出现在F1，禁止持续3秒。
- 收势时富贵必须冷峻。

### 四、物理反馈死锁（通用）

- 攻击必须砸入肉体/衣物，必须画出物理凹陷，禁止隔空。
- 环境物必须在身体砸实瞬间才破裂，禁止提前崩坏；撞实后必须反弹。
- 无BGM，只有拳肉撞击、撞击环境、反弹的纯物理音效。
- 绝对禁止慢动作、悬空飘浮、子弹秒杀。

### 五、真实接触死锁（通用）

- 每一次攻击必须写 `SLAMS HARD into`。
- 每一次接触必须有：接触点凹陷 + 布料褶皱 + 身体位移。
- 禁止隔空打、禁止拳头停在半空、禁止假动作、禁止表演式打斗。
- 暴力密码必须双向：攻击方的力 + 受击方的受力反馈。

### 六、骨架B提示词强制写法

- 只写B的力，不写A的反应。
- 暴力密码必须双向：B的攻击动作 + A的物理反馈。
- 真实接触死锁：SLAMS HARD into + 接触点凹陷 + 身体位移。
- 禁止软化词：禁止“A does NOT counterattack”等，改为“A's stance stays SOLID and FIRM, eyes LOCKED on B”。
- 前3秒全程挨打，后3秒才反击。
- F1痛苦，F2渐退，F3冷峻。

### 七、视频提示词固定结构

1. 重申最高指令：严格遵守六宫火柴人图纸轨迹，禁止自己发明动作。
2. 图纸符号防泄漏：红箭头、黄圈、蓝虚线绝对禁止出现在画面中。
3. 身份与站位锁：A始终画框左，B始终画框右。
4. 真实接触死锁：攻击必须砸入肉体/衣物，必须画出物理凹陷。
5. 物理反馈死锁：环境物必须在身体砸实瞬间才破裂，禁止提前崩坏。
6. 声音叙事：无BGM，只有纯物理音效。
7. 骨架B专属：前3秒必须有痛苦表情，后3秒恢复冷峻。
