## Current segment prompt

```text
目标：生成第 <N> 段，9:16，<时长> 秒，真实手机直播质感。

参考职责：
- 角色参考：只锁定面部身份、发型、头饰、服装。
- 场景参考：只锁定仓库/门店空间、机位、桌面和道具位置。
- 产品参考：只锁定产品种类、包装结构、尺寸比例、内容物和数量。
- 姿势参考：只参考姿势，不继承人物、服装、背景、产品或文字。
- 音色参考：只锁定说话人的声线；不得改变台词。

开场状态：<姿势、视线、双手位置、可见产品数量、包装状态、空间锚点>。

连续时间线：
0.0–X.X 秒：<准确动作和表情>，说：“<逐字台词>”
X.X–Y.Y 秒：<下一个动作>，说：“<逐字台词>”

产品约束：<准确数量、尺寸或比例、填充线、接缝、开口状态、颗粒质感>。
机位：<只允许一种主导行为，例如固定手机机位加极轻微自然微动>。
收尾状态：<适合连续衔接的清洁状态>。

禁止：字幕、贴纸、价格字卡、品牌标、平台水印、背景音乐、额外人物、产品复制或消失、包装变形、镜头反复推拉。
```

## Open-package display addendum

```text
袋子始终直立，双手分别固定袋口两侧；拉链结构和红色封口线保持一致。
打开后将袋口朝摄影机方向倾斜到能看清内容物，但颗粒不倾倒、不漂浮、不变形。
产品最近距离约 <距离>，不完全遮挡人物面部。
展示结束后按原路径收回，恢复到明确的收尾状态。
```

如果从上一段尾帧无法可靠实现手部、袋口状态或产品可见度，必须改用经过确认的专用首帧。
