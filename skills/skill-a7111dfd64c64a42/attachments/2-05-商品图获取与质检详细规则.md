# 商品图获取与质检详细规则

## 一、图片质量检测量化标准

### 1.1 分辨率检测

| 质量等级 | 分辨率范围 | 判定结果 | 处理方式 |
|---------|-----------|---------|---------|
| 优秀 | ≥2000×2000px | 可用 | 直接使用 |
| 良好 | 1000×1000px ~ 1999×1999px | 可用 | 直接使用 |
| 勉强可用 | 500×500px ~ 999×999px | 需确认 | 提醒用户可能影响后期细节，征求同意后使用 |
| 不合格 | <500×500px | 不可用 | 拒绝使用，建议重拍或换图 |

### 1.2 清晰度检测

**检测维度：**
- 边缘锐度：商品轮廓是否清晰
- 细节保留：纹理/logo/文字是否可辨识
- 模糊程度：整体是否失焦

**判定标准：**
- ✅ 合格：放大 100% 后，商品关键细节（logo、纹理、边缘）清晰可辨
- ⚠️ 轻微模糊：细节略有损失但整体可接受，提醒用户后继续
- ❌ 严重模糊：关键细节无法辨识，拒绝使用

### 1.3 背景复杂度评分

| 背景类型 | 特征描述 | 处理难度 | 建议操作 |
|---------|---------|---------|---------|
| 纯白/纯色 | 单一颜色，无纹理 | 低 | 直接使用或简单抠图 |
| 简单渐变 | 均匀渐变，无杂色 | 低 | 可直接使用 |
| 简单场景 | 桌面/展台，物品少 | 中 | 建议去背景 |
| 复杂场景 | 多物品、杂乱环境 | 高 | 必须去背景 |
| 人像背景 | 有人/手/身体入镜 | 高 | 必须去背景（除非刻意保留） |

### 1.4 商品完整度检测

**遮挡检测：**
- ✅ 合格：商品完整可见，无遮挡或遮挡 <5%
- ⚠️ 轻微遮挡：遮挡 5%-20%，关键特征可见
- ❌ 严重遮挡：遮挡 >20% 或关键特征被遮挡

**完整性要求：**
- 商品主体必须完整（不能有截断）
- 关键特征必须可见（logo、特殊设计、材质纹理）
- 如果是包装类商品，包装正面信息需完整

## 二、文字描述生成的引导细节

### 2.1 结构化描述问题清单

**第一轮：基础信息（必填）**

1. **商品品类**：这是什么类型的商品？
   - 服装/鞋包、美妆护肤、食品饮料、数码3C、家居用品、母婴玩具、珠宝配饰、运动户外、家电厨卫、文具办公、汽车用品、医疗器械、宠物用品、其他

2. **商品主体颜色**：主要颜色是什么？
   - 可多选，标注主次（如"主体白色，logo金色"）

3. **材质/质感**：什么材质？
   - 金属/塑料/玻璃/陶瓷/布料/皮革/木材/纸质/其他

4. **形状特征**：整体形状？
   - 方形/圆形/长条/不规则/其他

**第二轮：细节信息（按需补充）**

5. **尺寸感**：大概多大？（提供参照物，如"和手机差不多大"）

6. **表面特征**：
   - 光滑/磨砂/纹理/图案/logo
   - 有无特殊工艺（烫金、浮雕、镂空）

7. **功能部件**：有哪些可识别的部件？
   - 如：按钮、拉链、纽扣、瓶盖、标签

8. **品牌元素**（可选）：
   - 有无 logo/文字/图案需要保留？
   - 如果有，位置和颜色？

9. **特殊要求**：
   - 是否需要展示特定角度？
   - 是否需要展示使用场景？

### 2.2 描述不充分时的追问策略

**判定标准：**
- 缺少第一轮任一必填项 → 必须追问
- 缺少第二轮信息 → 可基于品类默认值生成，但提醒用户可补充

**追问话术：**
- 缺少品类："您还没说明这是什么商品，方便告诉我品类吗？"
- 缺少颜色："商品的主要颜色是什么？"
- 缺少材质："材质是什么样的？比如金属、塑料、布料？"
- 描述模糊："您说的'好看的杯子'，能具体描述一下形状、颜色、材质吗？"

### 2.3 商品图生成的 prompt 模板

**通用模板结构：**
```
A [品类] with [颜色], [材质] material, [形状] shape, [表面特征],
[功能部件], [品牌元素if有],
white background, product photography, high quality, front view,
centered composition, soft studio lighting, 8k resolution
```

**按品类细分模板：**

**服装类：**
```

displayed on invisible model / flat lay style,
white background, fashion product photography, high detail
```

**美妆类：**
```

[特殊工艺如烫金/浮雕],
white background, cosmetics product photography, luxury feel,
soft reflection, high-end commercial shot
```

**食品类：**
```

[配料/装饰if有],
white background / natural setting, food photography,
appetizing, fresh, high detail
```

**数码3C：**
```

[logo/品牌标识if有],

```

**家居用品：**
```
A [颜色] [产品类型], [材质] material, [尺寸感],
[功能特征], [纹理/图案if有],
white background / lifestyle setting, home product photography,
warm lighting, cozy feel
```

### 2.4 生成后的质量确认

生成商品图后，必须：
1. 展示给用户
2. 询问："这是按您的描述生成的商品图，是否符合预期？"
3. 如不满意 → 收集修改意见 → 重新生成
4. 如满意 → 进入下一步

## 三、去背景处理规则

### 3.1 自动去背景触发条件

**自动执行（无需询问）：**
- 用户明确说"去背景"、"抠图"
- 图片背景为纯色（白/黑/灰）且与商品对比明显

**建议去背景（询问用户）：**
- 背景复杂度评分为"高"
- 背景杂乱影响商品主体突出

**不建议去背景：**
- 用户刻意保留场景（如"放在书桌上的笔记本电脑"）
- 去背景后商品边缘会严重损失（如毛发、透明材质）

### 3.2 去背景执行流程

```
1. 分析原图背景复杂度
2. 判断是否适合自动去背景
3. 执行去背景
4. 质量检查：
   - 边缘是否干净（无残留背景色）
   - 商品主体是否完整（无缺失）
   - 透明区域是否正确
5. 展示去背景结果 vs 原图对比
6. 用户确认
```

### 3.3 去背景失败处理

**常见失败情况：**
- 边缘残留背景色
- 商品主体缺失
- 透明区域错误

**处理方式：**
1. 自动重试 1 次（调整参数）
2. 仍失败 → 提供三个选项：
   - A. 使用原图（不去背景）
   - B. 用户手动提供已去背景的图
   - C. 更换一张更适合去背景的商品图

## 四、多商品场景的初始处理

### 4.1 多商品识别

**识别规则：**
- 用户上传 ≥2 张商品图 → 判定为多商品
- 用户文字描述包含多个商品 → 判定为多商品

**确认话术：**
- "您上传了 X 张商品图，是为多个商品制作广告吗？"
- "您提到了 A 和 B，是需要同时展示这两个商品吗？"

### 4.2 多商品命名与编号

**命名规则：**
```
商品1：[用户命名或品类描述]
商品2：[用户命名或品类描述]
...
```

**示例：**
```
商品1：红色口红
商品2：金色口红管
商品3：口红包装盒
```

**用途：**
- 后续三视图、分镜、场景图中标识不同商品
- 用户确认时指代明确

### 4.3 多商品关系确认

**询问内容：**
1. **主从关系**：哪个是主商品？哪个是配角/配件？
2. **展示方式**：
   - 同时展示（所有商品同框）
   - 分别展示（每个商品单独镜头）
   - 组合展示（先分后合）
3. **互动关系**：
   - 商品之间有物理接触（如口红插入管中）
   - 商品之间无接触（并排展示）

### 4.4 多商品质量检测

**逐张检测：**
- 每张图独立进行质量检测
- 任一不合格 → 单独指出，建议更换或补充

**整体协调性检查：**
- 多张图的风格是否一致（色调、光照、视角）
- 是否需要统一处理（如统一去背景、统一调色）

## 五、商品图不符合要求时的详细指引

### 5.1 问题分类与建议

**问题1：分辨率不足**

| 情况 | 建议 |
|-----|------|
| 轻微不足（1000-1500px） | "分辨率略低，可能影响后期细节放大，是否继续？" |
| 严重不足（<1000px） | "分辨率太低，建议更换高清图。可尝试：① 重新拍摄 ② 从官网/电商下载高清图 ③ 从文字描述重新生成" |

**问题2：模糊/失焦**

| 情况 | 建议 |
|-----|------|
| 轻微模糊 | "图片略有模糊，关键细节仍可辨识，是否继续？" |
| 严重模糊 | "图片太模糊，无法用于高质量广告。建议：① 重新拍摄（对焦清晰） ② 更换其他角度的图 ③ 从文字描述重新生成" |

**问题3：背景杂乱**

| 情况 | 建议 |
|-----|------|
| 可去背景 | "背景较杂乱，建议去背景处理。是否需要我帮您抠图？" |
| 去背景风险高 | "背景复杂且商品边缘精细（如毛发/透明材质），去背景可能损失质量。建议：① 重新拍摄（纯色背景） ② 保留原背景但调整构图" |

**问题4：商品不完整/被遮挡**

| 情况 | 建议 |
|-----|------|
| 轻微遮挡（<20%） | "商品有部分遮挡，关键特征仍可见，是否继续？" |
| 严重遮挡（>20%） | "商品被遮挡过多，无法完整展示。建议：① 更换角度的图 ② 补充其他角度的图 ③ 从文字描述重新生成" |

**问题5：光照不当**

| 情况 | 建议 |
|-----|------|
| 过曝 | "图片过曝，高光细节丢失。建议重新拍摄（降低曝光）" |
| 欠曝 | "图片太暗，细节看不清。建议重新拍摄（增加光照）" |
| 光照不均 | "光照不均匀，部分区域过亮/过暗。建议重新拍摄（均匀光照）" |

**问题6：角度不当**

| 情况 | 建议 |
|-----|------|
| 角度单一 | "当前角度只能展示商品一面，建议补充其他角度（正面/侧面/背面/45度）" |
| 角度奇怪 | "当前角度不适合展示商品特征，建议重新拍摄（正面/45度俯拍）" |

### 5.2 无法继续的兜底方案

如果用户无法提供合格商品图，提供以下选项：

**选项A：从文字描述生成**
- 引导用户完成结构化描述（见第二节）
- 调用 LibTV 生成商品图
- 用户确认后继续

**选项B：使用参考图（需警告）**
- 如果用户提供参考图（非实际商品），明确警告：
  - "参考图仅用于风格参考，最终生成的是全新商品图，不会与参考图相同"
  - "如果需要展示真实商品，必须提供实际商品图"

**选项C：暂停任务**
- "当前商品图无法用于生成高质量广告，建议准备好合适的素材后再继续"

## 六、商品图确认环节

### 6.1 确认内容

展示商品图后，必须确认：

1. **商品识别**："这是您要制作广告的商品吗？"
2. **质量确认**："图片质量是否满意？"
3. **去背景确认**（如已去背景）："去背景效果是否满意？"
4. **多商品确认**（如多商品）："商品数量和命名是否正确？"

### 6.2 确认话术

**单商品：**
```
这是您提供的商品图：[展示图片]

请确认：
1. 这是您要制作广告的商品吗？
2. 图片质量是否满意？
3. [如已去背景] 去背景效果是否满意？

确认后进入下一阶段（基础定义选择）。
```

**多商品：**
```
您提供了 X 个商品：

商品1：[命名] - [展示图片]
商品2：[命名] - [展示图片]
...

请确认：
1. 商品数量和命名是否正确？
2. 各商品图片质量是否满意？
3. 主从关系是否正确？[说明主商品]

确认后进入下一阶段。
```

### 6.3 用户不满意的处理

**情况1：识别错误**
- "抱歉识别有误，请告诉我正确的商品信息"
- 重新确认商品

**情况2：质量不满意**
- "理解，您希望更换图片还是从文字描述重新生成？"
- 根据选择进入对应流程

**情况3：多商品信息错误**
- "明白，请告诉我需要修改的部分"
- 更新商品命名/关系

## 七、商品图获取完成的标准

**必要条件（全部满足）：**
- ✅ 至少有 1 张合格商品图（分辨率、清晰度、完整度达标）
- ✅ 用户已确认商品识别正确
- ✅ 用户已确认图片质量满意
- ✅ 多商品场景已完成命名和关系确认

**完成后输出：**
```
商品图获取完成：
- 商品数量：X
- 主商品：[命名]
- 商品列表：
  1. [命名] - [文件路径]
  2. [命名] - [文件路径]
  ...

进入第二阶段：基础定义选择。
```

## 八、常见失败场景与处理

### 8.1 用户上传的不是商品图

**识别特征：**
- 图片内容为风景/人物/动物/抽象图案
- 无明确商品主体

**处理方式：**
```
"这张图看起来不是商品图，是否上传错误？
请上传您要制作广告的商品图片。
如果是场景图/氛围图，请同时上传商品图。"
```

### 8.2 用户上传的是效果图/mockup

**识别特征：**
- 商品在复杂场景中
- 可能是渲染图/mockup

**处理方式：**
```
"这是商品的效果图/mockup 吗？
如果是，请同时提供：
1. 实际商品图（用于生成真实广告）
2. 效果图仅作为风格参考
```

### 8.3 文字描述生成失败

**失败原因：**
- 描述过于模糊（"好看的东西"）
- 描述自相矛盾（"方形的球"）
- LibTV 生成失败

**处理方式：**
```
"根据您的描述生成的商品图效果不理想，可能需要更详细的描述。
是否愿意：
1. 补充更多细节（颜色、材质、形状）
2. 提供参考图（用于风格参考）
3. 直接上传商品图"
```

## 十、快速模式 vs 精细模式的第一阶段

### 10.1 快速模式

**保留：**
- 商品图质量检测（必须确保素材合格）
- 用户确认商品识别

**跳过：**
- 详细的背景分析（直接建议去背景）
- 多商品的详细关系确认（默认并排展示）

### 10.2 精细模式

**全部执行：**
- 完整的图片质量检测
- 详细的背景分析和建议
- 多商品的完整关系确认
- 去背景质量的精细检查

---

## 十一、总结

第一阶段的核心目标：
1. 获取合格的商品素材（图片质量达标）
2. 明确商品信息（数量、命名、关系）
3. 用户确认商品识别和质量

第一阶段的关键原则：
- 宁可多问一句，不要假设用户意图
- 质量问题必须提醒，不要默默使用不合格素材
- 多商品场景必须明确命名和关系
- 所有确认环节不可跳过
