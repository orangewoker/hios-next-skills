# 正式空间结构底图

## 上游门禁

只有相关北／南／西／东2×2场景板已经生成、上传并审核通过，才建立正式结构底图。结构底图必须引用这些真实上游资产；冲突时先返回场景板修正，不在错误底图上继续。

## 复杂单层俯视图

仅当人物明显换位、摄影机穿行或绕行、多人精确站位、跨镜头组位置继承，或文字易导致跳位／穿模／方向错误时生成。俯视图保留已审核结构、比例、物件和通行空间，不新增设计。简单固定单层不强制生成。

## 多层横切面／剖面

表达各层上下关系、相对高度、项目真实存在的跨层连接，以及人物和摄影机跨层路径的物理可能性。未确认部分写“待确认”；不得为了图面完整自动添加楼梯、扶梯、电梯、坡道或其他连接。

## 多层俯视图

每层分别清楚表示水平空间、可通行区域、影响运动的真实结构和动作点。各层与横切面的层级一一对应，不能把多个楼层重叠为一个无法阅读的平面。

## 保真检查

逐项对照上游2×2板中的结构、主要物件、尺度、光源与方向。只有各视角共同支持的事实可以标为已确认；被遮挡或冲突区域必须明确标注推断或待确认。
