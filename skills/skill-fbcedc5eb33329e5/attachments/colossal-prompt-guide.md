## 极简输入自动补全

当用户只输入极简概念（如"中国龙""古神""山海经巨兽""海底神明""诡异巨物"等），不要要求用户补充细节。直接根据主体类型、文化语境、情绪方向和默认电影大片规则，自动补全以下9个维度：

1. 主体身份与体量
2. 观众位置与权力关系
3. 场景地点、天气、时间与空间层级
4. 镜头角度、焦距、景别、构图和画幅
5. 主体动作、环境反应和物理尺度
6. 材质、纹理、细节密度和真实磨损
7. 主光源、空气介质、色彩基调和曝光逻辑
8. 电影机拍摄质感、胶片颗粒、高光行为和镜头瑕疵
9. 负面约束（使用通用视觉语言，不写媒介限定词）

默认视觉方向：**史诗尺度 + 现实目击 + 神秘压迫 + 纪录片式灾难真实感 + 好莱坞大片级宽银幕画面**。

默认观众位置：站在人类尺度中（街道地面/废墟边缘/山谷底部/港口岸边/人群后方），而非上帝视角。

## 主体类别判断

将用户输入归入最接近的类别：

| 类别 | 典型主体 | 默认场景基底 |
|------|----------|-------------|
| 东方神话巨物 | 中国龙、烛龙、鲲鹏、相柳、九尾狐、山海经巨兽 | 风暴云层/雨夜城市/群山峡谷/长江水汽/古城天际线 |
| 神明与宗教性存在 | 古神、天神、海神、山神、佛像、神像 | 荒原神庙/巨型石阶/极地冰原/沙漠日食/废弃城市广场 |
| 诡异不可名状存在 | 天空之眼、黑色太阳、雾中巨影、深海人形 | 低云层/暴风雨/军用探照灯/城市上空的云洞 |
| 自然灾难型巨物 | 沙虫、巨浪、云墙、火山巨兽、风暴实体 | 荒野/山脊/泥土/风沙/远处村落 |
| 城市灾难型巨物 | 巨型怪兽、机械遗迹、城市上方巨大生物 | 城市边缘/废墟/港口/暴风云层 |
| 宇宙天象型存在 | 月球背后神明、星云巨像、日食中的眼睛 | 日食天空/被压暗的人群/强烈逆光剪影 |

默认选择**神话现实主义**：主体可超现实，但空气/光线/材质/重力/尺度/天气和摄影机反应必须可信。主体必须与现实环境发生接触。

## 三层尺度体系

每张画面必须至少有三层尺度：

| 层级 | 内容 | 作用 |
|------|------|------|
| 人类尺度 | 人、车、船、帐篷、路灯、窗户、直升机、桥梁 | 观众代入点 |
| 建筑/自然尺度 | 高楼、山体、云层、海浪、树线、峡谷、城墙 | 中间参照 |
| 巨物尺度 | 主体遮蔽、穿越、压迫或超越第二层 | 视觉主体 |

巨物不能只写"大"，必须通过参照物表达大小。

正确：`龙身从云层后方横跨整片城市天际线，鳞片边缘被闪电短暂照亮，前景街道上几名行人停在积水中仰望。`

错误：`一条很大的龙，非常宏伟，电影感。`

## 巨物物理存在感规则

巨物不能像贴在背景上的图案。必须写出它对环境造成的影响：

- 压暗天空
- 推动云层
- 扰动水面
- 掀起尘土
- 让飞鸟逃散
- 让树冠倒伏
- 让街灯闪烁
- 让人群停住脚步
- 让玻璃反射出巨大轮廓
- 让雨幕在身体边缘被切开
- 让远处建筑被阴影吞没

## 巨物不完整展示策略

为了增强真实感和压迫感，巨物通常不应完整清晰地摆在画面中央。优先使用：

- 主体一部分被云、雾、雨、尘、建筑、山体遮挡
- 身体延伸到画框之外
- 只展示头部、眼睛、鳞片、手掌、轮廓、触须、神像面部的一部分
- 让观众意识到画框容不下它
- 远处只有局部轮廓可见，近处有真实参照物

完整展示只在仪式性、远景史诗场面或海报式需求中使用。

## 巨物尺度分级

| 等级 | 体量描述 | 适用主体 |
|------|----------|----------|
| 建筑级 | 高度接近高楼 | 城市怪兽、巨型雕像、机械遗迹 |
| 山脉级 | 体量接近山体 | 古神、巨龙、山海经巨兽、沙虫 |
| 云层级 | 身体进入云层 | 中国龙、天空神明、天象生物 |
| 天象级 | 改变天空/日食/月光/云层结构 | 黑色太阳、天空眼睛、宇宙神明 |

默认不使用宇宙级夸张尺度，除非用户输入包含宇宙/星球/银河/世界末日等词。太大的尺度会失去人类参照和实拍可信度。

## 巨物默认镜头策略

| 参数 | 默认值 | 理由 |
|------|--------|------|
| 画幅 | 2.39:1 宽银幕 | 史诗尺度 |
| 机位 | 地面人眼高度到胸口以下的低机位 | 人类视角渺小感 |
| 角度 | 轻微仰拍 | 让主体支配天空和建筑 |
| 焦距 | 中长焦到长焦 | 空间压缩制造不可逃离的逼近感 |
| 景别 | 大远景结合前景人类尺度 | 避免空旷无参照 |
| 构图 | 前景人类/现实物体 + 中景环境结构 + 远景巨物占据 | 三层尺度 |
| 景深 | 中等深度或深焦 | 保证尺度关系可读 |
| 运动感 | 空气/云/水/尘/衣物/旗帜/树木/火光显示巨物存在 | 物理互动 |

强临场感时可使用：肩扛纪实视角、略微不稳定的地面镜头、雨水打湿镜头边缘、轻微运动模糊。

广角使用条件：镜头贴近人群/车内强调恐慌、狭窄空间看到巨物局部、强调巨大空间环境。广角不应用来把巨物变成夸张变形的玩具。

## 中国龙专项规则

### 默认身份

中国龙应被处理为东方龙：蛇形长身、盘旋穿云、鳞片细密且受天气影响、长须与鬃毛被风雨牵动、鹿角或枝状角、深沉有智慧有神性压迫、身体与云层/水汽/闪电/山脉/城市发生互动。

### 禁止默认特征（除非用户明确要求）

- 西方蝙蝠翼
- 喷火怪兽姿态
- 卡通化大眼睛
- 过度鲜艳的节庆红金配色
- 纯装饰性祥云背景
- 只像纹身图案或年画图案
- 只在空白天空中摆姿势

### 推荐场景

暴雨中的现代城市、云海压低的山脉、江河洪水上方、古城城墙与远处雷暴、港口/桥梁/摩天楼/山谷村落。

### 推荐视觉语言

画面应像真实灾难新闻现场与神话史诗电影交汇：前景有人类/车辆/船只/城墙/桥梁作为尺度参照；龙身部分隐藏在云层与雨雾中；鳞片不是干净金属而是湿润/粗粝/有泥水/烟尘/高光和阴影；龙首不必完全露出；闪电/月光/城市灯光/晨曦只短暂揭示轮廓。

## 神明与宗教性恐惧规则

神明不能只写成巨大人形。必须体现"不可完全理解"和"被目击"的感觉：

- 局部可见
- 面部被阴影遮挡
- 眼睛不直接清晰展示
- 身体与山体/云层/海沟/神庙/城市结构融合
- 人类只看见一部分就已经意识到它的存在
- 光线像自然现象，不像装饰性舞台光

### 神性压迫画面语言

- 低机位让观众处于朝拜或被审判的位置
- 对称构图让画面具有仪式感
- 中长焦压缩台阶/柱廊/人群/神像和远处天空
- 阴影必须深，亮部必须克制，避免全身均匀发光
- 材质可以是石/骨/湿金属/灰烬/岩层/云/海水/风暴，不应像干净塑料

### 默认场景

暮色神庙台阶下、沙漠日食中的巨大人形轮廓、废弃城市广场尽头的石质神像、深海探照灯照到神明手掌的一角、暴风云洞中垂下的巨大面部阴影。

## 神秘与诡异规则

诡异来自"缺失的信息"。不要解释得太完整：

- 只显示局部，不完整展示全貌
- 主体边缘被雾/雨/灰尘/暗部吞没
- 让环境出现不合理但物理可见的异常（鸟群静止/水面无风起伏/街灯同步熄灭/远处人群沉默）
- 使用现实地点增强不安
- 让观众通过人物反应/尺度参照/光线变化推断主体存在

### 不可名状主体的写法

写成现实镜头无法完全捕捉的巨大现象：

- 云层中有缓慢转动的眼状空洞
- 海面下方有比船体更大的阴影掠过
- 山脊后方露出一排不合比例的手指
- 城市玻璃幕墙反射出天空中的巨大面孔
- 黑色太阳让整座城市进入异常低曝光

## 好莱坞实拍质感拆解

"大片感"不是词汇堆叠，必须拆成9个可见维度：

1. 大尺度环境
2. 多层前中后景
3. 真实空气介质
4. 复杂但可信的光源
5. 人类反应与现实参照
6. 物理接触与环境破坏
7. 电影机曝光和镜头行为
8. 受控色彩和高动态范围
9. 适度的不完美：雨滴/灰尘/烟雾/镜头边缘污染/运动柔化

### 真实摄影机语言（替代空泛"高级感"）

真实电影机拍摄、大格式电影摄影质感、2.39:1宽银幕构图、自然高动态范围曝光、真实镜头高光滚降、轻微胶片颗粒、细腻空气透视、雨滴/尘埃/烟雾与逆光发生真实散射、远处细节被空气吸收、暗部保留层次不做死黑、高光不过曝成纯白保留光晕边缘。

### 超清但不塑料

- 主体关键轮廓/材质/尺度关系必须清楚
- 远景允许被雾/雨/尘/空气压暗
- 高光边缘允许轻微泛光
- 快速运动处允许自然运动模糊
- 阴影不能被过度提亮
- 表面不能过度光滑/干净/均匀

## 光线与色彩规则

### 光源必须可信

所有光线来自可理解的来源：太阳/月亮/日食边缘/闪电/城市灯光/车灯/火焰/探照灯/神庙高窗/水下探照灯/云层后低角度天光。神性光可以存在，但必须像穿过真实空气/尘土/雨雾/水汽形成的自然现象。

### 巨物光线默认策略

- 主体正面不要均匀打亮
- 优先用侧逆光/低角度天光/闪电瞬间/探照灯扫过/城市反射光勾出轮廓
- 让暗部保留未知感
- 巨物越大，越不应该完全被照亮

### 色彩默认策略

低饱和、受控冷暖对比、灾难现实主义色盘：暗青灰/暴雨蓝灰/尘土赭石/暗金/石灰白/深棕黑/铁锈色/灰烬色/微弱钠灯暖色。除非用户明确要求，不要使用高饱和红/绿/蓝/紫/霓虹彩光。

## 构图与空间规则

### 前景服务真实感

可用元素：模糊人影肩部/雨水打湿车窗/破碎玻璃/神庙石阶/城市路灯/直升机舱门/船舷/潜水器窗口/树枝/旗帜/尘土/火星。前景必须让观众感觉镜头在真实空间里。

### 中景提供尺度

街道/桥梁/城墙/高楼/山脊/海浪/车队/人群/神庙柱廊。中景不能空，否则巨物失去真实比例。

### 远景形成压迫

主体应压迫天空或地平线。远处空间可被雾/尘/雨/烟吞没。不要留太多干净安全的天空。不要让巨物漂浮在空白背景上。

## 视频时间感结构

巨物视频不要一开始就完整展示主体。推荐节奏：

| 阶段 | 时间 | 内容 |
|------|------|------|
| 开始 | 0-3s | 人类世界细节：雨/风/车灯/人群/废墟/探照灯 |
| 异常 | 3-5s | 环境异常：影子压过街道/水面震动/云层移动 |
| 揭示 | 5-9s | 主体局部出现：头部/眼睛/手掌/鳞片/轮廓进入画面 |
| 结尾 | 9-12s | 停在人的渺小反应，或主体继续占据天空，留下未完成的压迫感 |

### 巨物运动规则

- 主体越大，动作越慢，环境反馈越明显
- 山脉级巨物不能快速弹跳
- 云层级龙身移动时云层和雨幕应被拖动
- 海底神明移动时泥沙/水流/探照灯光束应被扰乱
- 神像转头时碎石/灰尘/鸟群/远处建筑影子应有延迟反应

## 负面约束纪律

### 绝对禁止的写法

在最终提示词和负面约束中，不要写以下媒介限定词：3D动漫/动画/二次元/游戏CG/游戏截图/角色原画/概念设计图/手办感/卡通渲染/插画风。负面提示词中出现这些词仍可能把画面引向这些媒介。

### 推荐负面约束表达

使用通用视觉语言：避免廉价特效感/塑料表面/过度光滑/漂浮无重量感/干净空白背景/主体与环境没有接触/过亮轮廓边缘/不自然比例/过度锐化/均匀平光/海报式摆拍/主体完整居中平铺/没有人类尺度参照/天空过于干净明亮/颜色过度鲜艳/材质过度完美/空气中没有雾尘水汽或雨雪介质。

## 提示词模板

### 图像提示词模板

```
【最终提示词】
[主体] 出现在 [现实场景] 中，[体量与尺度参照]，[主体局部状态与动作]，[环境被主体影响的物理反馈]。镜头位于 [观众位置]，[机位与角度]，[焦距与构图]，[前景]，[中景]，[远景]。光线来自 [可信光源]，[空气介质与光线互动]，[色彩基调]。真实电影机拍摄，[画幅]，[摄影质感]，[曝光与高光行为]，[胶片颗粒与镜头细节]，超清电影画面，神话现实主义，物理可信。

【负面约束】
避免廉价特效感、塑料表面、过度光滑、漂浮无重量感、干净空白背景、主体与环境没有接触、过亮轮廓边缘、不自然比例、过度锐化、均匀平光、海报式摆拍、主体完整居中平铺、没有人类尺度参照、天空过于干净明亮、颜色过度鲜艳、材质过度完美。
```

### 视频提示词模板

```
【镜头目标】
```
