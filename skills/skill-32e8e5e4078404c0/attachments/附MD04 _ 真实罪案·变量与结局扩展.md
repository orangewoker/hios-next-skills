# 附MD04 | 真实罪案·变量与结局扩展

**所属主SKILL：** 真实罪案 · 纯推理 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“变量设定空洞、多结局逻辑不闭环”的痛点。

## #需要什么输入

- 核心变量清单、线索机制设计。

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 真相进度：counter，0-100，默认0；≥80可发起最终指控。
2. 谎言识破次数：counter，0-10，默认0；≥5嫌疑人防线崩溃。
3. 警探直觉：relationship，0-100，默认50；&lt;20陷入死胡同。
4. 嫌疑人嫌疑值：faction，0-100，默认0；某个嫌疑人≥80被锁定。
5. 关键证据：item，false；true可一锤定音。

### 二、结局体系（共15个）

正结局（5个）

1. E01·完美定罪：证据确凿，真凶认罪。
2. E02·零口供破案：纯靠逻辑闭环，让真凶在法庭上哑口无言。
3. E03·案中案：查出真凶，但牵扯出警局高层的黑幕。

坏结局（10个）

1. D01·冤假错案：指控错了人，真凶逍遥法外。
2. D02·证据不足：被律师推翻，嫌疑人当庭释放。
3. D03·被停职查办：查案手段违规，被内务部带走。
4. D04·悬案：线索断绝，案件永远沉底。
