# 空间层次示例库

本文件提供不同场景类型的空间层次建模示例，帮助生成具有深度感的站位描述。

## 一、空间层次基础概念

### 1. 垂直分层（高度轴）
- **高空层**：飞行角色、悬浮法术、空中建筑
- **地面层**：主要活动平面
- **地下层**：地穴、深坑、隐藏空间
- **高度象征**：越高通常代表权力/权威

### 2. 水平分区（平面轴）
- **中心区**：冲突焦点、对话核心
- **侧翼区**：支持角色、观察者
- **外围区**：群众、环境元素
- **入口/出口区**：进出动线

### 3. 景深层次（深度轴）
- **前景**：靠近镜头，细节特写，情绪冲击
- **中景**：叙事核心，人物互动，关键动作
- **背景**：环境氛围，大型建筑，群众场面
- **空间深度**：近→中→远的过渡层次

## 二、内景场景示例

### A. 洞府/室内对话场景

**示例1：山洞洞府（通用版）**
```
垂直分层：
├─【高处】洞顶岩壁、悬挂火把/荧光矿石
├─【中人高度】站立角色视线水平
├─【低处】石桌、座位、地面
└─【地下】阴影深处

水平分区：
├─【入口区】洞口光线，来者刚进入
├─【主位区】石桌+主导者（权力中心）
├─【客位区】来客站立位置（合适距离）
├─【游离区】次要角色靠柱位置（疏离表达）
└─【边缘区】洞府岩壁阴影

景深层次：
├─【前景】桌面物品（刚发生的冲突痕迹）
├─【中景】石桌对话圈（主导者+来客）
├─【中后景】次要角色靠柱、侍从脚边
└─【背景】洞府深处阴影、岩壁纹理
```

**示例2：宫殿朝堂**
```
垂直分层：
├─【高台】王座、台阶（权威象征）
├─【平台】大臣站立区（等级序列）
├─【平地】侍卫、群众区
└─【地下】地砖图案、阴影

水平分区：
├─【王座区】君主+近侍
├─【大臣前列】重臣、谏官
├─【大臣后列】普通官员
├─【侍卫列】两侧护卫
└─【入口区】大门、光线

景深层次：
├─【前景】王座扶手的装饰特写
├─【中景】君主与主要大臣的互动
├─【后景】后排官员的模糊身影
└─【背景】宫殿高柱、横幅、远处大门
```

### B. 室内对峙场景

**示例3：厅堂室内**
```
垂直分层：
├─【高区位】主位座椅、屏风（权力高点）
├─【中区位】站立对话者视线水平
├─【低区位】地面、门槛
└─【地下区】暗门、地道入口（隐藏空间）

水平分区：
├─【主位区】主人在主座，神情傲慢
├─【客位区】来客站立/就座，距离体现关系
├─【侧翼区】仆从、侍卫站立处
├─【游离区】次要角色靠墙站立
└─【入口区】大门敞开或紧闭

景深层次：
├─【前景】桌面物品、茶杯、花瓶
├─【中景】主客对峙焦点
├─【后景】侧翼仆从表情反应
└─【背景】屏风、字画、门窗
```

## 三、外景场景示例

### A. 广场/平台对峙场景

**示例1：宗门广场对峙**
```
垂直分层：
├─【云层之上】更高天际（概念空间）
├─【高空层】悬浮的飞行法器、远程攻击
├─【中空层】御剑飞行的角色（悬浮观望）
├─【地面层】主要对峙角色
├─【地面下层】广场地面纹理、台阶
└─【概念层】远处高山轮廓（背景）

水平分区：
├─【中心轴线】主角-反派对峙线（垂直或水平）
├─【支持侧翼】配角分列左右
├─【地面核心】主角团队（三角阵型或一字排开）
├─【包围半圆】敌方弟子/士兵松散包围
└─【建筑背景】主殿、牌坊、旗帜

景深层次：
├─【前景】武器特写、颤抖的手、表情细节
├─【中景】主要人物的对峙焦点
├─【中后景】配角表情、围观者反应
├─【背景】宗门建筑、旗帜飘扬
└─【概念背景】天空云层、光影变化
```

**示例2：悬崖/高台边缘对峙**
```
垂直分层：
├─【崖顶层】对峙角色站立位置
├─【崖壁层】陡峭山壁、突出岩石
├─【崖下层】云雾缭绕、深不见底
└─【远景层】远处山峦、天空

水平分区：
├─【对峙轴线】角色A-角色B面对面
├─【侧翼区】各自带来的帮手
├─【后方区】双方后援
└─【边缘危险区】悬崖边缘

景深层次：
├─【前景】脚下碎石、悬崖边缘
├─【中景】对峙两人全景
├─【后景】各自人马、剑拔弩张
└─【背景】云海、远山、天际
```

### B. 战场开阔地

**示例3：两军对垒**
```
垂直分层：
├─【法术层】空中飞行法宝、法术光芒
├─【骑兵层】骑乘坐骑（高于步兵）
├─【步兵层】地面主要战斗
├─【伏地层】匍匐、倒地角色
└─【烟尘层】地面扬起的尘土

水平分区：
├─【前线】两军接触带（刀剑交错）
├─【中军】指挥核心、精锐部队
├─【后军】预备队、补给线
├─【两翼】骑兵机动、侧翼包抄
└─【后方】营地、指挥部

景深层次：
├─【前景】血腥特写、断裂武器、痛苦表情
├─【中景】核心将领对战、阵型变化
├─【中后景】士兵混战、旗帜飘扬
├─【背景】远处山峦、天空阴云
└─【环境层】烟尘弥漫、火光闪烁
```

## 四、特殊场景示例

### A. 快速战斗剪辑场景
```
空间特征：快速切换，强调移动向量

【分段1：突进】
前景：进攻者面部特写（狰狞/决绝）
中景：进攻轨迹线（从A点→B点的动势）
背景：防守方惊讶表情、慌乱阵型

【分段2：撞击】
前景：武器/拳头接触瞬间（慢动作感）
中景：冲击波扩散、身体受力后仰
背景：周围角色被气浪吹动

【分段3：结果】
前景：伤口特写、破碎装备
中景：进攻者收势姿态、防守者倒地
背景：战场局势因此改变
```

### B. 情绪爆发场景
```
空间特征：焦点收缩，强调面部和身体语言

【情绪压抑期】
景深远：人物孤立在空旷环境中
身体语言：收缩、低头、武器下垂
空间距离：与他人保持疏远距离

【情绪触发点】
焦点收缩：镜头推进到面部特写
微表情变化：嘴角抽动、眼神闪烁
环境反应：周围光线/风声变化

【情绪爆发期】
身体舒展：仰头、张开手臂、武器高举
空间扩张：似乎占据更多画面空间
环境影响：情绪波动引发环境反应（风起、尘扬）
```

### C. 多人围观场景
```
空间特征：焦点+围观圈层结构

核心焦点：主要事件/人物（如师徒对峙）
第一围观圈：重要配角（长老，近距离观察）
第二围观圈：次要角色（弟子、亲信）
第三围观圈：普通群众（外门弟子，松散分布）
最外围：环境建筑、远景

情绪传递波：
核心事件 → 第一圈震惊 → 第二圈议论 → 第三圈骚动
```

## 五、空间过渡技巧

### 1. 分段间空间衔接
**正确示例**：
- 分段1结尾："角色A在地面仰视空中对手"
- 分段2开头："角色A从地面跃起，扑向空中的对手"

**错误示例**：
- 分段1结尾："角色A在地面"
- 分段2开头："角色A在空中攻击"（缺少衔接）

### 2. 镜头运动暗示
- **推镜头**："镜头从广角推进到角色A面部特写"
- **拉镜头**："镜头从特写拉到展现整个对峙场面"
- **摇镜头**："镜头从角色A摇到角色B，展现对峙轴线"
- **移镜头**："镜头跟随角色从右侧冲出"

### 3. 空间锚点使用
每个场景确定2-3个固定空间锚点：
- 宗门广场场景：广场中心点、台阶高度线、牌坊位置
- 山洞场景：石桌中心、洞口位置、深处阴影线
- 悬崖场景：崖顶边缘、崖壁突出岩石、云层线

### 4. 环境互动描述
- **光影**："火把摇曳的光影在众人脸上跳动"
- **天气**："晨雾中三道身影若隐若现"
- **建筑**："宗门牌坊在背景中如威严门户矗立"
- **特效**："法器金光在空中划出攻击轨迹"

## 六、复杂度处理策略

### 场景过于复杂时（>15人）
1. **分组描述法**：
   ```
   镜头展现群体对峙：
   【左侧阵营】反派+长老+前排弟子
   【右侧阵营】主角+同伴+倾向者
   【中立观望】后排弟子、远处守卫
   ```

2. **焦点+模糊法**：
   ```
   焦点清晰描述核心人物（前5人）
   中景稍模糊描述重要配角（5-10人）
   背景概括描述群众（"数十名弟子布满后方"）
   ```

3. **分层展示法**：
   ```
   先描述高空层（御剑飞行的长老）
   再描述地面核心（主要对峙角色）
   最后描述地面群众（弟子包围圈）
   每层内部再细分
   ```

## 七、经典空间构图参考

### 1. 三角构图（稳定、对峙）
```
       反派首领
        / \
       /   \
  配角A  配角B
```

### 2. 对角线构图（动态、冲突）
```
反派（左上）
    ↘
     对峙轴线
    ↗
主角B（右下）
```

### 3. 圆心放射构图（压迫、包围）
```
        敌方弟子
    敌方弟子  主角  敌方弟子
       敌方弟子  敌方弟子
           主角团队
```

### 4. 纵深隧道构图（引导、深入）
```
入口 → 前景 → 中景 → 后景 → 深处
光线  石桌  人物  岩壁  阴影
```

---

**使用建议**：分析剧本场景时，先画出简单的空间分层图，明确各个人物所在的层次和区域，再转化为描述性语言。
