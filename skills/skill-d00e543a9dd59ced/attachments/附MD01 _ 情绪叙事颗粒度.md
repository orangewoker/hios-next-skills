#  附MD01 | 情绪叙事颗粒度

**所属主SKILL：** 互动影游Agent | 自动串联调度下层Skill\
**版本：** V2.1 融合合规修订版

## #做什么

本模块为互动影游Agent的核心引擎之一。

将微短剧的“情绪颗粒度方法论”工程化，确保互动影游的每一帧、每一个分支节点都具备高密度情绪钩子。解决互动影游跨分支情绪断裂、跨场景跳戏、分支生成后情绪变脸的痛点。

## #需要什么输入

**最少提供：**

- 剧本大纲或分集梗概
- 角色设定与人物关系
- 当前剧情节点（时间戳、情绪状态）
- 项目品类（互动影游）

**可选提供：**

- 目标情绪基调
- 目标分支数量
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。情绪叙事环节重点参考【顶级情绪大师】的全量LOCK指令，确保情绪连续性与微表情拆解完全对齐。

### 二、七层微表情拆解

从面部微动到肢体语言，逐层标注情绪状态。每层必须包含：情绪状态、眼部表演、呼吸节奏、面部肌肉、生理反应、情绪过渡、镜头语言。

### 三、情绪连续性五层闭环

1. 设计层：情绪连续性施工图 + 哲学锚点。
2. 执行层：锚点注入 + 哲学提示词 + 分帧生成。
3. 验证层：情绪对齐验证 + 哲学对齐验证 + 元叙事对齐验证。
4. 剪辑层：剪辑补偿 + 哲学余韵设计 + 元叙事余韵设计。
5. 升华层：元叙事彩蛋 + 不确定性美学 + 哲学金句。

确保跨分支、跨场景的情绪不断裂、不跳戏。

### 四、互动影游品类情绪颗粒度标准（强制，按70_15 LOCK执行）

1. 前10秒钩子：开场必须建立观看驱动力。
2. 60秒冲突：单幕开场60秒内必须起冲突。
3. 180秒高能节点：每3分钟必须给一个高能节点。
4. 360秒大反转：每6分钟必须有一个反转。
5. 每个分支节点必须携带至少一个情绪驱动力。
6. 任何一段连续超过360秒无冲突、无高能、无反转，判定为叙事断裂，禁止进入下一环节。

### 五、分支情绪继承

1. 玩家选择A分支后，情绪状态必须被B分支继承或合理断裂。
2. 禁止分支之间出现“变脸式”情绪跳变。
3. 跨分支情绪必须通过情绪锚点ID与过渡帧ID严格衔接。
4. 情绪继承必须记录到跨集情绪记忆库，供后续分支调用。

### 六、情绪曲线图谱

为每个节点标注冲突强度、高能节点位置、反转时机，形成完整的情绪曲线图谱，作为分镜与提示词生成的依据。

### 七、生成与合成

根据上述情绪叙事规则，调用底层视频生成Skill，输出MP4视频文件。
