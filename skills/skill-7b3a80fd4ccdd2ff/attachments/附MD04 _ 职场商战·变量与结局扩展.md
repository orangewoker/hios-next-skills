# 附MD04 | 职场商战·变量与结局扩展

**所属主SKILL：** 职场商战 · 逆风翻盘 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“变量设定空洞、结局无分支”的痛点。

## #需要什么输入

- 核心变量清单。

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 资本值：counter，0-100，默认0；≥60掌握话语权。
2. 话语权：faction，0-100，默认0；≥70能左右公司决策。
3. 底线值：relationship，0-100，默认50；&lt;20黑化不择手段。
4. 职场人脉：counter，0-100，默认0；≥80一呼百应。
5. 对手破绽：risk，0-100，默认0；≥80可一击必杀。

道具与旗标

1. 绝密U盘：item，false；true可扳倒反派。
2. 录音笔：item，false；true可洗清嫌疑。

### 二、结局体系（共15个）

正结局（5个）

1. E01·商业帝王：资本值≥80，话语权≥80，执掌公司。
2. E02·正义使者：使用绝密U盘，将反派送进监狱，行业清明。
3. E03·独立创业：人脉≥80，带走核心团队自立门户。
4. E04·急流勇退：底线值极高，看透资本，辞职去追求真正的生活。

坏结局（10个）

1. D01·身败名裂：被反派做局陷害。
2. D02·背锅入狱：没有证据，成为替罪羊。
3. D03·黑化暴君：底线值&lt;10，虽然上位但众叛亲离。
4. D04·过劳猝死：长期高压，身体崩溃。
