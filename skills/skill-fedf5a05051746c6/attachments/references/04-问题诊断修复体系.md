# 问题诊断修复体系

> 来源：《电影剧作问题攻略》悉德·菲尔德 + 《你的剧本逊毙了！》威廉·M·埃克斯

## 一、问题诊断三维框架（菲尔德）

**所有剧本问题归结为三个维度：情节、人物、结构。三者相互关联，牵一发动全身。**

维度核心问题典型症状**情节**故事线的戏剧冲击力拖曳/模糊/事件太多/事件不够/对话打断/不可信**人物**人物的积极性与深度话太多/解释太多/太被动/人物过多/动作无法展开**结构**部分与整体的关系结尾太慢/太急/情节点不奏效/中间迷失

### 诊断四步法

1. **识别问题**：以"什么"开头提问（不用"为什么"），做自由联想写作
2. **确定位置**：在结构示例图上找到问题发生在哪一幕、哪个段落
3. **3篇短文诊断法**：
   - 第1篇：是什么吸引我来写这个剧本？
   - 第2篇：我写出来的和我当初想写的有什么不同？
   - 第3篇：我该怎么做才能把现有的改成我期望的？
4. **逐单元处理**：按戏剧动作单元（第一幕/第二幕前半/第二幕后半/第三幕）逐一解决

### 结构定位法

```
第一幕(1-30页)          第二幕(30-90页)           第三幕(90-120页)
├── 前10页               ├── 前半部(30-60)          ├── 结局
├── 第二个10页           │   ├── 紧要关头1(~45页)   │
└── 情节点I(25-27页)     │   └── 中间点(~60页)      │
                         ├── 后半部(60-90)          │
                         │   ├── 紧要关头2(~75页)   │
                         │   └── 情节点II(85-90页)  │
```

### 关键实操工具

- **自由联想写作**：随手写下所有想法，不评判，以"什么"提问
- **3篇短文**：每篇不超过一页半，自动书写方式
- **回顾练习**：写7-17岁之间对你影响最大的创伤事件
- **照明理论**：像灯光照亮舞台一样审视你的材料
- **批评专页**：列出你不喜欢的部分，然后找到里面有价值的东西
- **转换人物线索**：换一个人物的视角重写场景，打破僵局
- **卡片法**：用3×5英寸卡片重组场景顺序

## 三、跨书共识：诊断修复核心原则

 1. **所有问题归于三类**：情节、人物、结构（三者联动）
 2. **先识别后定位**：知道问题是什么→在结构图上找到它
 3. **以"什么"提问**：不用"为什么"，用"什么"获得具体答案
 4. **写是改的过程**：写作就是翻来覆去地写
 5. **从具体单元入手**：逐幕/逐段落/逐场景处理
 6. **人物是核心**：动作即人物，解决人物问题往往同时解决情节和结构问题
 7. **第一稿都是狗屎**：接受这个事实，然后改写、改写、再改写
 8. **读给别人听**：大声朗读能发现所有文字层面的问题
 9. **一句话大纲是瑞士军刀**：结构诊断和修改的最佳工具
10. **凯瑞斯·哈丁法则**：最完美的时候，就是一切即将崩塌的时候
