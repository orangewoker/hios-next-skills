# 附MD04 | 金包银·角色锚点与佩戴者一致性规范

**所属主SKILL：** 金包银短剧漫剧电影级TVC | 高水准拉片复刻\
**版本：** V2.0 融合合规版

## #做什么

本模块为“金包银短剧漫剧电影级TVC”的专属角色锚点与佩戴者一致性规范。

解决AI生成金包银TVC时“老匠人跨镜头换脸、年轻传承人气质漂移、佩戴者手部穿模、面部微表情失真”的痛点。通过统一的角色锚点规范与佩戴者手部动作锁定，确保全片角色形象100%一致。

## #需要什么输入

**最少提供：**

- 老匠人设定（三视图 + 面部特写）
- 年轻传承人设定（三视图 + 面部特写）
- 佩戴者设定（手部特写 + 颈部/腕部参考）

**可选提供：**

- 服装与配饰需求
- 特定情绪场景
- 目标画幅（不限定，按项目需求或用户指定）
- 是否需要输出视频文件、视频脚本、Prompt清单、视觉方案

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。本环节重点参考【提示词】底座的物理光学参数与【情绪大师】的七层微表情拆解规则。

### 二、角色锚点命名规范

- **格式**：`角色名_角度_版本号`
- **示例**：`老匠人_正面三视图_v1`、`传承人_微笑特写_v2`
- **核心铁律**：所有锚点ID必须在跨镜头、跨场景时绝对一致，严禁“同角色两套ID”。

### 三、主要角色锚点

1\. 老匠人

- **身份定位**：金包银古法工艺传承人，国家级非遗大师
- **外貌特征**：花白鬓角，手部有岁月老茧，眼神沉稳，面部皱纹自然
- **核心微表情**：眉头微蹙、嘴角微抿、目光专注、下颌紧绷
- **光影锚定**：暖黄油灯光，侧逆光勾出轮廓，暗部保留细节
- **锚点ID示例**：`i-xxxxxxx`（用户上传三视图后替换）
- **可替换状态**：专注錾刻/抬头凝视/微笑递物

2\. 年轻传承人

- **身份定位**：金包银新一代传承者，接棒人
- **外貌特征**：干净利落，眼神坚定，手部年轻但灵巧
- **核心微表情**：专注、敬畏、微微紧张、嘴角轻扬
- **光影锚定**：柔和侧光，暗金点缀
- **锚点ID示例**：`i-xxxxxxx`（用户上传三视图后替换）
- **可替换状态**：学习/佩戴/展示/守护

3\. 佩戴者

- **身份定位**：金包银手镯/项链佩戴者
- **外貌特征**：亚洲女性/男性手腕或颈部，肤色自然真实
- **核心要求**：手部动作克制，佩戴姿态自然，禁止夸张炫耀
- **锚点ID示例**：`i-xxxxxxx`（用户上传参考图后替换）

### 四、佩戴者手部动作规范（强制红线）

1. 每个镜头只做一个单一手部动作，禁止多动作并行。
2. 手部动作必须有物理因果链（抬手→佩戴→调整→展示）。
3. 禁止手指弯曲畸形、断指、多余手指。
4. 手镯必须自然套在手腕上，与皮肤之间留有一根手指的缝隙。
5. 佩戴产品在镜头内必须始终可见，禁止中途消失或穿帮。

### 五、跨镜头一致性锁定（核心铁律）

1. 同角色在不同镜头必须用同一人物锚点ID。
2. 所有镜头共用同一套角色锚点库。
3. 情绪切换必须使用同一角色的不同锚点帧，禁止换脸。
4. 服装、配饰、发型在全片中必须保持绝对一致。
5. 佩戴者手腕、颈部比例必须严格1:1，禁止忽大忽小。

### 六、生成与合成

根据上述角色锚点与佩戴者规范，调用底层视频生成Skill，输出MP4视频文件。

## #产出什么

最终交付：

- **视频文件（MP4格式）**：包含角色锚点与佩戴者一致性的金包银TVC演示片段。
- **视频脚本、Prompt清单、视觉方案**。
- **角色锚点库资产包**：所有角色三视图、面部特写、锚点ID清单。
- **佩戴者手部规范清单**：手部动作、佩戴姿态、比例参数。
- **角色一致性校验报告**：确保跨镜头、跨场景的锚点ID统一。

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 老匠人、年轻传承人或佩戴者设定不明确时。
- 用户要求新增角色、变更现有角色锚点或修改佩戴者时。
- 用户要求突破佩戴者手部规范或跨镜头一致性规则时。
- 用户要求输出视频文件、视频脚本、Prompt清单、视觉方案，但缺少关键输入时。
- 本模块与上游主SKILL或其他附MD规则冲突时。
