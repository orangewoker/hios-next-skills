# 建筑时装 Lookbook 生图规范

## 1. 目标与边界

将服装事实、人物设定、建筑空间、姿势任务、镜头和光线组装为可执行的写实生图提示词。默认服务于电商服装展示，同时支持建筑型 Lookbook、艺术展厅氛围图和无人物场景图。

遵守以下边界：

- 只使用成年人物；不生成未成年人、不良诱导或不适当场景。
- 参考图只提取建筑结构、摄影语言、构图、光线和色彩关系，不复制原人物身份、原服装组合、品牌标识、文字、可识别艺术作品或商业设计。
- 用户产品图和明确指定的人物参考图优先；没有参考图时使用宽约束，不把默认脸型、发型、身材或服装写死。
- 默认使用自然静态摆拍；只有用户明确要求形象片叙事时才使用行走、回身等动态。
- 不以“高级、大片、电影感、氛围感”等抽象词替代建筑结构、人物受力、光源方向和服装展示任务。
- 不把个人路径、账号、凭据、私密链接、测试截图或未经授权素材写入 Skill 或公开包。

## 2. 触发条件

以下请求触发本技能：

- 根据服装产品图生成男性、女性或中性模特图。
- 生成建筑极简、艺术展厅、私人画廊、现代建筑室内、窗边、门洞、台阶或玻璃空间的服装图。
- 生成电商全身、四分之三身、半身、坐姿、靠墙站姿或无人物场景图。
- 用户反馈人物比例不对、场景像住宅或酒店、姿势僵硬、人物像贴图、背景空白、动作重复、服装被遮挡或光影不统一。
- 需要把同一件服装扩展为不同场景、人物呈现、构图、镜头和静态动作。
- 用户要求把流程整理为可迁移、可公开分享的生图 Skill。

## 3. 输入与输出契约

### 必填或可推断输入

- 任务用途：电商主图、详情页、Lookbook、氛围图或广告素材。
- 服装事实：产品图优先；至少说明款型、颜色、材质、关键结构和需要展示的部位。
- 人物事实：人物参考图，或性别呈现、年龄感、气质、发型和体态中的必要变量。
- 场景倾向：艺术展厅、建筑室内、窗光、木墙、玻璃、门洞、台阶或其他建筑语法。
- 画幅和景别：默认 4:5 纵向；默认全身或按服装任务选择。

缺少非关键变量时采用明确默认值；缺少服装事实、人物是否成年或素材授权状态无法确认时，先询问或拦截，不凭空补全。

### 默认输出

- 可直接复制的正向 Prompt。
- 与任务匹配的负面 Prompt。
- 选用的场景、姿势、镜头和光线决策。
- 质量验收结果或待修正项。
- 公开分享时，额外提供安全审计、版权隐私声明、版本信息和任务交接文档。

## 4. 强制安全闸门

在分析参考图、生成 Prompt、处理产品图或打包 Skill 前，按以下顺序检查：

### 4.1 内容安全

拦截包含或要求生成以下内容的素材或指令：

- 政治敏感、违法犯罪、暴力伤害、恐怖主义、极端主义或危险行为。
- 色情、露骨性内容、未成年人性化或不当场景。
- 仇恨、歧视、骚扰、自残诱导或其他明显伤害性内容。
- 可能引发误导、诈骗或违法使用的证件、票据、支付凭证和身份材料。

检测到不可消除风险时，停止任务，不模糊处理、不绕过、不输出半成品，并说明需要移除或更换风险素材。

### 4.2 版权与商标

- 拒绝明星、公众人物、影视或游戏 IP、未经授权的艺术作品、品牌 Logo、广告文案、招牌和可识别商业设计的直接复刻。
- 可以提取一般性的建筑结构、镜头、色彩和光影语言；不要要求“完全复制原图”。
- 用户必须拥有产品图、人物图和参考素材的使用权；无法确认时只提供不含受保护元素的通用方案。
- 公开包不内置外部案例链接、品牌资料、原图、截图、水印图或未经授权的模型权重。

### 4.3 隐私脱敏

输入和输出前检查并移除：水印、二维码、手机号、邮箱、地址、证件号、票据、订单号、账号、定位信息、聊天记录和其他个人可溯源信息。

无法可靠清除的个人信息直接拦截，不以裁切、模糊或低清方式掩盖后继续发布。

### 4.4 公开包安全

公开 Skill 必须满足：

- 无外链、无广告、无引流话术、无邀请码、无统计脚本、无上传或下载副作用。
- 无 API Key、Token、Cookie、密码、私钥、个人路径、内部域名和账号信息。
- 无危险删除、覆盖、移动个人文件或绕过审核的命令。
- Prompt 与资源中不植入违规人物特征、敏感符号或诱导模型绕过平台限制的指令。
- 只打包通用文本、必要参考资料和无个人信息的本地校验脚本。

## 5. 工作流决策树

```text

       ├─ 有产品图 → 以产品图锁定服装事实

            ↓
       选择一个建筑空间骨架和一个人物关系
            ↓

            ↓

            ↓

```

## 6. 服装与人物解耦

### 6.1 人物设定卡

每次只选择 2–4 个必要变量：

```yaml
人物设定卡:
  性别呈现: 男性 / 女性 / 中性气质 / 由参考图决定
  年龄感: 成年，按品牌人群选择
  气质: 克制 / 松弛 / 知性 / 清冷 / 温和 / 力量感
  面部: 自然真实，保留皮肤纹理和轻微不对称
  发型: 由参考图或用户要求决定
  身材: 自然比例，服装版型优先
```

有参考人物图时只锁定用户要求保持的身份特征；没有参考图时，不固定单一族群、脸型、发型、年龄、肤色或身材模板。

### 6.2 服装事实卡

```yaml
服装事实卡:
  款型: 用户产品图或明确类别
  廓形: 合体 / 微宽松 / 宽松 / 结构化 / 垂坠
  材质: 产品图或用户提供的材质
  色彩: 以产品图为准
  关键结构: 领口 / 前襟 / 肩线 / 袖型 / 腰线 / 下摆 / 裤线 / 裙摆
  搭配: 只补足必要的鞋、内搭或一个低干扰道具
```

禁止擅自把服装替换为固定格纹衬衫、固定针织、固定阔腿裤或其他历史模板。产品图优先于文字描述。

## 7. 建筑场景规则

### 7.1 场景五段结构

按以下顺序组装：

```text
空间骨架 → 建筑锚点 → 人物与建筑关系 → 前中后景 → 主光与色彩
```

每张图只设置：

- 一个主空间骨架。
- 一个或两个建筑锚点。
- 一个服装展示任务。
- 一个主要人物接触点或支撑关系。
- 最多一个低干扰道具。
- 一个主光源和一个弱反射关系。

极简不等于空白。每张图必须至少看到三类空间信息中的三项：墙体或转角、窗/门洞/天窗/楼梯、带材质的地面/台阶/内置家具/腰高台。

### 7.2 可复用建筑语法

- **玻璃转角**：玻璃框线、混凝土墙和自然反射形成垂直结构；人物以肩胛、髋部或低台接触建筑。
- **厚墙门洞**：门洞提供纵深和光线出口；人物以前臂、肩背或髋部回应厚墙，不把手抬成装饰动作。
- **弧形木墙**：弧面墙提供引导线；木色只做结构重音，人物以髋部或肩部轻靠，不生成住宅家具。
- **天窗混凝土展厅**：天窗负责建筑投影；人物可背靠低展墙或站在明暗交界处，天窗不能过曝。
- **玻璃长窗与腰高台**：腰高台是建筑一体化支撑，不是咖啡桌；人物可用手掌撑台或髋部轻靠。
- **悬挑廊道与深门洞**：悬挑顶板建立尺度，门洞内部暗半级而非黑洞，人物双脚必须落在同一地面或平台。
- **内置坐凳或窗台**：只在服装需要生活方式关系时使用；坐姿必须有臀部、双脚和衣物受力。

禁止把圆柱、拱门、书架、雕塑、沙发、植物、展台和线性灯全部堆在一张图中。建筑高级感来自结构、比例、材质连接和光影，不来自装饰品数量。

## 8. 静态姿势与人物融合

### 8.1 站姿硬规则

- 明确承重腿和放松腿；放松腿只能轻微弯曲或向侧后方错开，不交叉、不内扣。
- 肩线与骨盆线错开约 5–15 度，胸腔转向光源或服装展示面约 5–20 度。
- 手部只做一个低干扰任务：自然垂落、轻触袖口、轻触衣摆侧缝、低位持道具、轻扶窗台、手掌撑台或前臂靠墙。
- 视线从镜头附近、窗光、画外远处、手中物或建筑深处中选择一个，不固定侧视角度。
- 站立必须可保持 2–3 秒；不默认行走、落步、回身、离开、跳跃或衣摆飞扬。

### 8.2 真实接触点

每张必须指定一个真实接触点，并写出受力：

- 肩背或肩胛轻触墙体：接触处有柔和环境阴影。
- 髋部轻靠腰高台或弧墙：身体不塌，承重腿仍清晰。
- 前臂或手掌接触门框：手臂自然弯曲，不能悬空。
- 手掌撑建筑台面：手掌与边缘有接触影，不能穿模。
- 坐在内置坐凳或台阶：臀部受力、双脚落地、衣物有自然褶皱。
- 双脚站在同一平台：鞋底有接触影，不能跨台阶制造不必要动态。

“手放在墙旁边”不等于靠墙；如果人体接触关系不成立，整图不通过。

### 8.3 咖啡道具规则

当用户要求男生手拿咖啡时：

- 只生成一杯小尺寸、无 Logo、无文字、无吸管的外带纸杯。
- 单手低位持握，位置在髋部到腰线以下，避免遮挡领口、胸前、前襟、腰线和下摆。
- 杯盖、杯身和手指关系真实，禁止漂浮杯、融合手、额外手指或第二只杯子。
- 咖啡只承担轻叙事，不举到嘴边，不做饮用动作，不变成饮品广告。
- 咖啡桌、托盘、品牌杯套、广告字样、手机、包和其他生活方式道具默认不加入。

## 9. 构图、镜头与尺度

- 默认 4:5 纵向，全画幅 65–85mm 中远景，眼平或胸口高度机位，垂直线端正。
- 全身人物占画面高度约 60–72%；场景叙事图可降至 55–65%，但不能缩成背景陪体。
- 头顶上方保留约 10–14% 空间；鞋底下方保留约 8–12% 地面或台阶。
- 至少保留一个可信尺度参照：门洞、窗台、墙板分缝、台阶、内置家具或建筑开口。
- 避免近距离 24–35mm 广角导致腿部拉长、建筑变形和人物接近房顶。
- 人物是第一视觉焦点；建筑对比度、饱和度和锐度低于服装主体。
- 前景遮挡不得切断人物头部、手部、领口、前襟、腰线、下摆和鞋底。

## 10. 光线与色彩

- 先写真实光源，再写光质：窗光、天窗、门洞天光、反射墙面或柔光源。
- 主光从人物前侧约 30–45 度进入，照清脸部、肩线、前襟、袖型、裤线和面料纹理。
- 后侧 120–150 度可加入低强度反射或轮廓光，只勾勒肩线、发丝、衣摆和腿侧，不形成白边。
- 背景比人物暗半级或低饱和半级；门洞暗半级即可，不能成为黑洞。
- 配色采用基底色 60–70%、结构色 20–30%、情绪重音 5–10% 的启发式关系。
- 暖木或暖侧光只作为局部重音，同时保留冷灰墙面、浅色石材或中性地面；禁止整张图橙黄、肤色发橙或高光过曝。

## 13. 质量门槛与迭代

### 13.1 六项整图验收

每张图逐项判定通过或不通过：

1. **安全与版权**：内容安全，素材授权可说明，无水印、二维码、个人信息、未授权 Logo 或 IP。
2. **空间结构**：至少三类建筑层次，墙地关系、开口和主光源可辨，不是空白棚拍。
3. **人物融合**：至少一个真实接触点，受力、接触影和身体朝向一致，不像贴图。
4. **姿势差异**：组图不能全部使用正面站立、双腿并齐或双手插袋；每张主动作不同且可复现。
5. **服装可读性**：领口、前襟、肩线、袖型、腰线、下摆、裤线、裙摆和鞋子清晰，不被手或道具遮挡。
6. **摄影质量**：人物尺度、镜头透视、光线方向、色彩层级、材质和主体层级成立。

### 13.2 一票否决

出现以下任一项直接淘汰，不用堆叠风格词修补：

- 空白或无缝棚拍背景。
- 未成年人、不安全动作、违法犯罪、色情或其他风险内容。
- 未授权明星、影视 IP、Logo、文字或艺术作品。
- 个人信息、水印、二维码、订单或证件信息未清除。
- 人物贴图、漂浮、接触点不可能、额外肢体或明显手部错误。
- 门洞黑洞、窗户过曝、人物接近天花或缩成远景陪体。
- 服装关键结构被手、咖啡或道具遮挡。

### 13.3 迭代规则

一次只修改一个最低分变量：空间结构、接触点、姿势、咖啡位置、光线、色彩或服装事实。不要同时增加道具和抽象风格词。

推荐修复顺序：

```text
安全/版权 → 人物尺度 → 鞋底与地面 → 接触点与受力 → 服装可读性 → 场景结构 → 光影 → 色彩与质感
```
