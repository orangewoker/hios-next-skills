# 场景黏土化词库

## 微缩化原则

黏土场景的核心是"微缩手工模型感"——所有建筑、植物、地形都像是被人用双手搭建的微缩世界。

| 场景元素 | 黏土化改造 | prompt 句式 |
|---|---|---|
| 建筑 | 圆润无棱角，窗户简化为色块 | "建筑圆润饱满无锐利棱角，窗户简化为色块，表面有捏制痕迹" |
| 树木 | 圆球状树冠+粗短树干 | "树冠为饱满圆球形黏土，树干粗短圆柱形" |
| 地形 | 柔和起伏的黏土地面 | "地面为柔和起伏的黏土地形，无尖锐边缘" |
| 天空 | 纯色饱和背景或渐变色块 | "天空为高饱和纯色色块或柔和渐变" |
| 水体 | 黏土波纹/片状水面 | "水面为黏土波纹造型，片状反光" |

## 场景类型

| 场景 | 关键元素 | 色调 |
|---|---|---|
| 城市街景 | 圆润建筑/小黏土车/路灯 | 暖色高饱和 |
| 自然风景 | 圆球树/黏土山丘/黏土河 | 绿色+蓝色高饱和 |
| 室内场景 | 圆润家具/简化装饰 | 暖色调柔和 |
| 童话小镇 | 倾斜圆润小屋/糖果色装饰 | 马卡龙色系 |
| 节日场景 | 对应节日元素黏土化 | 对应节日色调 |

## prompt 片段示例

```
黏土手工风格的童话小镇微缩场景，倾斜的圆润小屋无锐利棱角，窗户简化为马卡龙色色块。树冠为饱满圆球形黏土，树干粗短圆柱形。地面为柔和起伏的黏土地形。天空为粉色到蓝色的高饱和渐变色块。所有表面保留指纹与工具压痕，亚光漫反射光泽。马卡龙色系，色彩高饱和但柔和。微缩模型感，手工搭建的不完美与轻微不对称。呆萌可爱。
```

## 落 prompt 前自检

- [ ] 建筑是否圆润无棱角
- [ ] 植物是否球形化
- [ ] 天空是否色块化
- [ ] 是否有微缩模型感
- [ ] 是否有指纹/压痕描述
