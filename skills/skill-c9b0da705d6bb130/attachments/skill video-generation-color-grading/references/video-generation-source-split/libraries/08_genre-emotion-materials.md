## V2.2 日景冷光与色温误判防护：

日外、日内白天、阳光天气、自然天光、门外天光、窗外天光场景，禁止直接写“冷光、冷白光、蓝冷光、冰冷光线、冷色补光”。

白天场景如需清冷、疏离、压迫、肃杀，不写“冷光”，改写为：低饱和色彩、阴影偏青灰、人物处于背光边缘、门窗遮挡形成明暗反差、天光柔弱、环境反光偏淡。

门外亮光不得写成“刺眼强光、探照灯、白光爆开”；应写成“门外自然天光沿门缝进入，照亮地面边缘，人物脸部仍保留自然阴影”。

夜景不能用强白补光把脸打亮成棚拍；只允许使用烛火、灯笼、火盆、路灯、屏幕光等真实来源，并保持环境暗部。

同一场景色温变化必须有可见原因：人物移动到窗边、开门、灯笼靠近、火盆被遮挡、云层变化、车辆经过或原文明确时间变化。

画幅适配：

9:16：优先前中后纵深、上下压迫、近景特写。

16:9：优先左右关系、横向空间、环境宽度。

```text
无论画幅如何，【实际站位与构图】必须和镜头1的画面动作一致。
```

9:16 多人场景禁止横向一字排开，优先用前景遮挡、纵深站位、高低关系和主次焦点组织画面。

方位与站位锁定模块：

方位词定义：画面左/右 = 观众看成片的左/右；人物自身左/右 = 角色身体方向的左/右；场景左/右 = 以场景稳定锚点建立后的物理方位。三者不得混用。

```text
每个新场景或缺少上文承接的 S-Block，镜头1必须建立方位基准、动作轴线、主视觉主体、关键对手或关键物、两个以上稳定空间锚点。
```

同一场景连续时，默认继承上一镜的画面左右、前中后景、人物朝向、持物和相对距离；只写发生变化的人物或物体。

人物移动必须写“起点 → 可见路径 → 终点”，例如从画面右中景走到画面左前景、停在门框旁；不得只写“走过去、转身、靠近”而不更新终点。

对话反打、过肩、侧拍必须保持同一动作轴线；优先用同侧过肩和前景肩背维持左右关系，不使用会让两人换边的正反打。

```text
若剧情必须越轴、绕行或交换位置，必须让画面先出现可见转场动作，如绕过桌角、从柱后穿过、镜头跟随转到新轴线，再写新的方位基准。
```

9:16 竖屏多人场景可以用前景肩背、中景主角、背景压力形成纵深，但仍要锁定主视觉主体在画面哪一侧、对手或关键物在哪一层。

多人场景默认只锁一个主视觉主体；其他人物只作为背景压力、遮挡、反应点或空间参照，除非原文明确他们正在行动或说话。

```text
若【实际站位与构图】和镜头1画面冲突，优先修正【实际站位与构图】或简化机位；不得让成品同时存在两套相反方位。
```

```text
若无法确定上一组方位，不补编上一组站位；使用“承接上一组最后可见状态”，并在镜头1重新建立可见方位基准和空间轴线。
```

背景环境锁定模块：

每个新场景必须建立背景账本：实际地点、固定背景锚点、远中近景层、墙面/地面材质、门窗方向、家具摆放、灯具或真实光源、远景轮廓、人群密度、天气时间。

同一场景连续时，默认继承背景账本；只写发生变化的背景元素和变化原因。

```text
背景变化必须有可见原因：镜头移动、人物移动、开门入室、转场、车辆行进、时间流逝、灯光开关、天气变化或原文明确换景。
```

不得让墙面颜色、门窗位置、桌椅布局、灯具位置、楼梯/走廊方向、车窗外景、人群数量、天气时间和光源方向无原因改变。

```text
换景必须明确写“新场景”，并在镜头1重新建立背景账本；不得用同一地点名称承载完全不同的背景。
```

近景、特写和过肩镜即使背景虚化，也必须保留可识别的背景锚点，如门框边缘、窗光方向、桌角、墙面纹理、灯影或人群轮廓。

背景人物只作为密度、压力、遮挡或反应点存在；人数和位置层级必须连续，不得一镜拥挤、一镜消失，除非有可见散开或离场过程。

光影变化不得伪装成背景变化；同一场景只允许写真实光源的方向、强弱、遮挡或人物位置变化，不得换成无来源新光源。

```text
若背景环境继承和镜头画面冲突，优先简化镜头或重新建立背景账本；不得让同一组内出现两套互斥背景。
```

人物身份、说话人与道具状态锁定模块：

首次出现的人物必须建立身份账本：姓名/称呼、年龄感、发型、服装、妆容、体型、标志物、持物、污损和当前情绪状态。

```text
同一人物跨镜头、跨视觉单元默认继承身份账本；只有原文或可见动作导致变化时，才写变化点。
```

不得因景别、光影、风格、3D/写实适配或情绪模块，改变人物年龄感、脸型、发型、服装主色、身份气质或关键标志物。

台词必须绑定说话人，格式为“人物名：原文台词”；OS/VO 必须写“OS来源：原文”或“VO来源：原文”。

若原文没有明确说话人且会影响人物关系或剧情事实，先提出一个最小必要问题；若能从上下文唯一确定，则直接绑定。

关键道具必须建立状态账本：道具名称、持有人、画面位置、物理状态、是否破损/污损、是否被递交或放下。

道具变化必须写起点、动作过程和结果；未发生动作的道具默认停留在上一镜位置和状态。

不得让关键道具无过程出现、消失、换手、复原、破损、改名或从画外变成画内核心物。

本组结尾继承必须同时记录主视觉人物身份状态、关键对手位置、关键道具持有人和道具状态。

对白节奏保护模块：

总原则：短剧节奏要紧，但台词必须听清、听完整、听出人物关系；不能为了快而牺牲台词。

语速分档：

普通对白：约每秒 3.5-5 个汉字。

情绪低声、哽住、试探、暧昧：约每秒 3-4.5 个汉字。

争执、打断、急促反击：可短时到每秒 5-6 个汉字，但不得连续整组保持。

OS / VO：约每秒 3.5-4.5 个汉字，必须比普通对白更稳。

台词镜时长估算：先按台词字数估算基础时长，再加 0.2-0.5 秒起口或落口空间；不要用 1 秒硬塞长句。

```text
单句超过约 18-24 个汉字时，优先按语义拆成两个镜头、过肩镜或反应镜承载；不得让演员一口气极速念完。
```

```text
台词中含关键信息、身份揭示、反击金句、情感表白、威胁或误会解释时，必须使用稳定镜头，并给台词落点 0.3-0.8 秒反应。
```

台词镜禁止复杂运镜：不得使用快速环绕、急推急拉、连续变焦、强晃动、快切插空镜来抢发声。

台词镜禁止强音效遮盖：音乐、环境声、动作声必须低于台词；爆点音效只能在台词前或台词落点后短促出现。

多人对话必须一人一句或一人一反应；除非原文明确群体喊话，不得让多人同时说话。

反应镜服务台词，不抢台词：反应镜可接在台词后 0.5-1.5 秒，不得插在一句话中间切断语义。

台词密集组的节奏优化顺序：删空镜 → 减少质感描述 → 简化运镜 → 合并无台词反应 → 拆长句承载；最后才调整语速。

当“快节奏”和“听清台词”冲突时，听清台词优先。

## 阶段一：吸引（心动萌芽）

偷看：1-2秒；用侧脸、门框、杯沿、书页、车窗等遮挡形成不完全注视。

被发现：1-2秒；用视线对上、手部停顿、呼吸断点表现心动暴露。

同框距离：2-3秒；用两人之间的桌面、门槛、台阶、座椅或人群距离建立关系。

## 阶段二：连接（情感建立）

近距离：2-3秒；减少背景干扰，让距离缩短成为主要信息。

```text
眼神交换：1-2秒；镜头稳定，留出演员眼神和台词空间，不写长久对视。
```

第一次触碰：1-2秒；只写手背、袖口、肩侧、递物、扶住等原文允许的接触点。

## 阶段三：亲密（情感升温）

拥抱：2-3秒；写靠近、停住、身体贴合后的短促安静状态。

亲吻组：2-4秒；仅当原文已有亲吻，使用近景、遮挡、侧影或背影，不新增尺度。

依偎 / 靠肩：1.5-2.5秒；用肩线、发丝、衣料挤压和呼吸同步表现亲密。

```text
技巧要点：使用柔和真实光源、浅景深、暖色来源和稳定停点；镜头由中近到特写，情感由动作推进，不使用慢动作拖时长。
```

禁止：不得凭空新增拥抱、亲吻、告白、牵手、亲密关系或暧昧事实；不得用空泛“甜蜜、浪漫、宿命感”代替可见动作。


启动条件：当前剧情明确需要承接失去、离别、被抛弃、痛苦选择、关系断裂或强内心冲击。

## 阶段一：震惊（情绪冲击）

人物带环境远景：1.5-2.5秒；人物被空间压小，表现孤独和失重，不写无人物纯风景。

表情凝固特写：1-1.5秒；只抓眼神、嘴角、呼吸或手部一个变化点。

眼神空洞：1-2秒；视线失焦，动作停止，环境声变清。

## 阶段二：消化（内心沉淀）

物品聚焦：1-1.5秒；只使用原文已有或场景自然存在的物品，不新增遗物或证据。

环境衬托：1-2秒；优先人物带环境、背影、门口或窗边，不写长空房空座位。

眼泪特写：1-2秒；仅当原文允许哭泣，写泪光、泪滴、手背擦拭，不夸张表演。

## 阶段三：释放（情绪宣泄）

情绪崩溃：2-3秒；可以写无声痛哭、肩膀下沉、扶墙停住，但不得新增台词事实。

大雨 / 落泪：1-2秒；只有场景已有雨、窗水、屋檐滴水或合理天气时使用。

空椅子 / 空房间：0.5-1.5秒；仅作短促落点，不连续使用，不用解释观众感受。

视觉隐喻：下雨、落叶、空椅子、褪色照片、破碎物品只在原文或场景自然存在时调用；不得凭空新增关键道具或回忆事实。

技巧要点：悲伤不靠堆哭声，优先用停顿、空位、物品、环境声、背影和动作中断制造共情。

## 阶段一：铺垫（暗流涌动）

远距离紧张：2-3秒；用距离、障碍物、桌面、门槛、台阶、走廊纵深建立对立。

微表情特写：1-1.5秒；只抓一个可见变化，如眼神移开、唇线收紧、手指停住。

环境压迫感：1-2秒；用低顶灯、窄门框、长桌、围观人影、雨声或脚步声制造压力。

## 阶段二：升级（矛盾激化）

交替特写：2-3秒；一人一句或一人一反应，不让多人同时抢戏。

快速剪辑：1-2秒；只用于矛盾升高，不压缩关键台词。

推轨变焦：1.5-2.5秒；用于压力逼近或关系断裂，不乱用眩晕感。

## 阶段三：高潮（冲突爆发）

面对面：2-3秒；明确谁占据中心，谁被逼退或站稳。

惊怒手势：1-2秒；只写原文已有的拍桌、指向、后退、甩袖、抢物等动作。

争吵后沉默：1-2秒；爆发后只给一个短促停点，如环境停声、人物停住或道具停住。

技巧要点：可使用对比构图、低机位、俯拍、荷兰角度、逐渐加快的剪辑制造不安；但所有机位必须服务可拍性和站位继承。

禁止：不得为了冲突新增打斗、流血、摔物、耳光、死亡、爆炸、证据或身份反转。

情绪节奏引擎：

情绪曲线：上升（铺垫） → 高峰（爆发） → 回落（缓和） → 解决（释然）。

```text
上升：镜头短到中，1.5-3秒；运镜缓慢推进；剪辑逐渐加快；声音或环境压迫渐强。
```
