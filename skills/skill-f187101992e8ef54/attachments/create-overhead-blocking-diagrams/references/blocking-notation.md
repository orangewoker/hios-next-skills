# 调度图标注

## 底图职责

- 同层路线：以对应楼层俯视图为主要底图。
- 跨层路线：以横切面／剖面为主要底图，同时在起终点所属俯视图标出对应位置。
- 多层正式调度：横切面与分层俯视图共同构成底图，缺一不可。

## 图例

人物使用稳定字母／编号和颜色；摄影机使用独立颜色、机位图标和视线方向；道具用对象轮廓；障碍与不可通行区使用统一阴影。图例不能遮挡路线和结构。

## 人物路线

每条路线包含起点、终点、方向箭头、关键停顿／动作点和动作先后。多人互动标明顺序、接触点和距离变化。同层路线不得只画在横切面上。路线图不填写视频时长，也不按秒数拆图。

## 摄影机路线

标明起始机位、镜头朝向、移动路线、关注对象、转向点和最终落点，区分摄影机位置与镜头视线。摄影机必须处于真实可通行空间。

## 跨层对应

横切面上的跨层起点和终点必须与相应楼层俯视图上的位置一致；真实连接不存在时不得画穿越路线。不得为了路线方便修改已审核空间。

## 节拍记录

```text
节拍：
适用镜头组／范围／场景／连续段落：
剧情目的：
底图资产编号：
人物起点／终点：
人物路线与关键动作：
摄影机起点／路径／落点：
跨层对应（如有）：
障碍与道具：
连续性风险：
```

## 数量与复用

一张清楚的俯视调度图可供多个相关镜头组共同参考；一张多层横切面可供整个跨层段落参考。人物与摄影机路线清楚时合并，拥挤时拆成同一调度关系下的多张图。拆分依据是空间表达清晰度，不是视频时长。
