## 1. 建筑语言

### 形状轮廓

用词释义适用场景流线型圆弧建筑整体呈连续曲面，无直角棱角塔楼、观景台、交通枢纽倒抛物面穹顶向上收窄的抛物面屋顶，形似倒扣碗广场中心建筑、展览馆几何穹顶（富勒式）三角面拼接的球面结构大跨度空间、温室、展览悬挑屋顶屋顶向外延伸超出建筑立面，形成遮檐入口门廊、观景平台鳍片造型建筑顶部或侧面附有火箭尾鳍状装饰板塔楼顶部、入口标志上扬翼形屋顶屋顶两端向上翘起，形似机翼商业建筑、餐厅、车站胶囊体椭圆或橄榄形整体结构独立功能体（信息亭、观景舱）螺旋上升体建筑主体沿螺旋线上升标志性塔楼、纪念碑

### 材质

用词视觉效果铬金属高反光银色表面，反射周围天空和建筑玻璃纤维哑光白色壳体，柔和漫反射釉面砖彩色反光小块面，拼贴出几何图案透明曲面玻璃无缝弧面幕墙，可见室内暖光抛光不锈钢冷银色但带暖色反射亚克力板半透明彩色面板，光线穿透时有色散

### 组合范例

- "Building1为流线型圆弧观景塔，高约三十层，铬金属外壳在阳光下反射暖金色光，塔顶设三片鳍片造型装饰板，入口处悬挑屋顶形成遮檐"
- "Building2为倒抛物面穹顶展览馆，玻璃纤维哑光白色壳体，侧面覆青绿色釉面砖拼贴出星芒图案"

## 2. 交通工具

用词造型描述适用场景悬浮单轨列车流线型胶囊车厢，沿高架轨道滑行城市交通干线个人飞行器流线型舱体，底部或两侧有圆形推进器空中交通、个人通勤悬浮胶囊车椭圆体小型车辆，离地约半米悬浮地面交通火箭造型飞船锥形舱体，尾部有鳍片稳定器长途交通、标志性场景管道胶囊车在透明管道中穿行的橄榄形车厢区域交通、机场接驳悬浮观景舱球形或椭球形透明舱体，沿缆绳滑行旅游观景

## 3. 人物风貌

### 服饰风格

用词造型描述mod风格连体裙几何剪裁，及膝，纯色或色块拼接，PVC或金属面料太空服式连体装银色或白色，圆领，腰部收束，小腿处微喇叭银色go-go靴及膝亮银色靴，小粗跟泡泡头盔透明球形头盔，内部可见人物面部几何耳饰大号圆形或星芒形耳环金属质感披风轻薄反光面料，随风飘动

### 人物描写范例

- "Character1为年轻女性，短发，穿银色mod风格连体裙，搭配银色go-go靴，站于观景平台护栏前眺望城市"
- "Character2为男童，穿白色太空服式连体装，手持纸火箭模型，抬头望天"

### 无人物场景

纯场景氛围片中可不出现人物，用建筑的尺度感和生活痕迹（停泊的飞行器、亮灯的窗户）暗示人类活动。

## 5. 色彩体系

### 推荐色组

色组名色彩组合时代锚点情绪太空时代经典芥末黄 + 青绿 + 铬白 + 暖橙60年代乐观、活力、科技信心原子时代暖调橙红 + 米白 + 金属灰 + 柠檬黄50年代热情、家庭、舒适未来有机70年代焦橙 + 苔绿 + 奶油白 + 铜金70年代自然、柔和、有机喷气时代冷调蔚蓝 + 银白 + 珊瑚红 + 铬60年代后期速度、冷静、精密童话乌托邦薄荷绿 + 珊瑚粉 + 珍珠白 + 淡金通用梦幻、纯真、温暖

### 色彩使用规则

- 选定一套色组后，在所有 beat 中保持一致
- 主色占画面60%，辅助色30%，点缀色10%
- 铬金属色作为中性色，可出现在任何色组中
- 避免大面积纯黑或深灰，用深棕或深青绿替代暗部

## 7. 场景类型参考

### 城市全景

- 视角：高空或山顶俯瞰
- 元素：多组流线型建筑天际线、悬浮交通穿行、广场绿地
- 运镜：缓慢平移或缓慢推进
- 声音：开阔的管弦旋律

### 交通枢纽广场

- 视角：地面人物视角
- 元素：穹顶候车大厅、悬浮列车进站、标识牌、候车人群
- 运镜：低角度仰角上摇，或跟随列车平移
- 声音：列车低鸣 + 环境电子音

### 公园与休闲区

- 视角：平视或微仰
- 元素：几何花坛、悬挑遮阳棚、雕塑造型喷泉、休闲长椅
- 运镜：缓慢平移
- 声音：轻快木琴 + 鸟鸣电子音

### 室内中庭

- 视角：广角仰视
- 元素：穹顶内壁、悬空走廊、室内花园、暖色灯具
- 运镜：仰角上摇或旋转上升
- 声音：混响管弦乐

### 空中俯瞰

- 视角：鸟瞰
- 元素：城市整体布局、绿地与建筑比例、交通网络
- 运镜：缓慢前飞
- 声音：空灵电子音 + 远处铜管
