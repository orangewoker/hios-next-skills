# 燕云十六州 短片制作流程（九阶段）

状态机：`风格锁定 → 创意Brief → 剧本 → 角色 → 场景 → 道具 → 分镜 → 关键帧 → 视频提示词`。每个箭头是一个确认点。

## 阶段 0：风格锁定卡

直接引用 `SKILL.md` 的 DNA，产出锁定卡（风格名/来源/首选备选模型/DNA/禁用项/画幅/稳定性），确认后分配 `STYLE-YY`，全片下游引用。

## 阶段 1：交互式 Brief

每轮最多四问，推荐首轮：
1. 想讲什么故事，最想出现哪个爽点画面（如雨中拔剑、抚琴退敌）？
2. 成片多长、画幅（默认 9:16）、发到哪里？
3. 面向谁、要什么情绪与节奏？
4. 本轮做到哪一层：剧本 / 资产提示词 / 完整分镜 / 逐镜视频提示词？

信息不足时给 2–3 个贴合武侠仙侠的故事方向供选。

## 阶段 2：剧本

加载并调用 `ai-film-screenwriting`。
- 输入：Brief、STYLE-YY、时长、9:16、角色规模、生成预算。
- 产出：5 秒钩子 + 3–5 场起承转合 + 可见动作/对白/OS + 角色表/场景表/道具表 + 结尾钩子 + 每场时长。
- 确认后分配 Character / Scene / Prop ID。

## 阶段 3：角色

加载并调用 `ai-film-character-sheet`。
- 输入：燕云 DNA、验证公式、角色表、角色 ID、身份配饰、连续性要求。
- 先做主角与核心反派，确认脸型与比例后再批量配角。
- 产出角色验证版完整提示词（保留全套脸型/材质词），白底全身立绘；不把剧情写进白底资产。

## 阶段 4：场景

加载并调用 `ai-film-scene-design`。
- 输入：燕云 DNA、场景表、Scene ID、昼夜、建筑/地面/陈设、剧情锚点。
- 用 `style-recipe.md` 的场景净化模板，默认无人物；每条附中文画面说明；一个地点一份“不可变结构”，换镜只换机位。

## 阶段 5：道具（九段式公式）

顺序：`主体名 → 类别/用途 → 造型结构 → 材质 → 工艺纹样 → 尺寸/比例 → 磨损/年代 → 视角/光影 → 风格块 + 负向`。
优先设计推动剧情或区分身份的道具（名剑、古琴、令牌、信物）；不为普通装饰造冗余资产。关键道具给正面三分之四视角、材质、尺寸、磨损、剧情功能。

## 阶段 6：分镜

加载并调用 `ai-film-storyboard`。
- 输入：确认剧本、STYLE-YY、角色/场景/道具 ID、时长、9:16、节奏。
- 先快速版后生产版。每镜含：Scene ID、角色 ID、Prop ID、景别、机位、运镜、动作瞬间、台词/声音、时长、情绪、静帧交接、动态交接。
- 镜头数粗算：总时长 ÷ 4 秒；动作戏加密度，情绪高潮加特写与反应镜。

## 阶段 7：关键帧静帧

按「燕云 DNA + 场景 + 角色 + 道具 + 镜头」组装静帧提示词，风格块用验证公式，主体填 `{subject}`。

## 阶段 8：视频提示词

静帧满意后：单镜精修加载 `seedance2-skills`；整场批量加载 `mx-shell-prompt`。每镜保留单一主动作 + 单一主运镜。

## 阶段 9：一致性台账

维护四表：Style Bible（DNA/禁用项）、Character Bible（脸/发/服装/配饰/比例）、Scene Bible（结构/地面/陈设/光源）、Prop Bible（材质/尺寸/磨损/持有人）。改动任一不可变字段必须回写并检查后续镜头。

## 交付节奏

风格卡 → Brief/一句话故事 → 剧本 → 主角+主场景+核心道具三张测试图 → 快速分镜 → 生产版分镜与逐镜提示词。三张测试图同时通过才进入整片资产生产。生成前完成积分告知与数量确认。
