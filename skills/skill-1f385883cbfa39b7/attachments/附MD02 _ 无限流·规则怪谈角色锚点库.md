# 附MD02 | 无限流·规则怪谈角色锚点库

**所属主SKILL：** 无限流·规则怪谈 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“无限流·规则怪谈 | 上架Steam的互动影游”的专属角色锚点库。

解决AI生成时“生存者跨镜头换脸、诡异实体崩坏、服装漂移”的痛点。通过统一的角色锚点规范与跨镜头一致性锁定，确保全片所有角色形象100%一致。

## #需要什么输入

**最少提供：**

- 生存者与关键NPC的姓名与设定
- 角色三视图与面部特写（用户上传或AI生成）
- 角色标志性服装与配饰

**可选提供：**

- 特定伤痕或污染状态
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。角色锚点环节重点参考【提示词】底座的物理光学参数与【情绪大师】的七层微表情拆解规则。

### 二、角色锚点命名规范

- 格式：角色名\_角度\_版本号
- 示例：生存者\_正面三视图\_v1、护士长\_异常特写\_v2
- 核心铁律：所有锚点ID必须在跨节点、跨分支时绝对一致，严禁“同角色两套ID”。

### 三、主要角色锚点

1\. 生存者（主角）

- 身份定位：被卷入游戏的普通人、退役特种兵、调查记者。
- 外貌特征：气质警觉，五官深刻，眼神极具求生欲。
- 服装：现代战术风衣、破损的校服、染血的白大褂。
- 核心微表情：眉头紧锁、瞳孔收缩、咬紧牙关、冷汗直流。
- 光影锚定：主光冷白，手电筒局部照明。
- 锚点ID示例：i-xxxxxxx（用户上传三视图后替换）

2\. 诡异实体（追击者/规则执行者）

- 身份定位：护士长（蒙眼）、无面保安、游荡的玩偶。
- 外貌特征：类人但具有非人特征，动作僵直或反关节。
- 服装：破败的医院制服、保安服。
- 核心微表情：面无表情（或根本没有脸），脖颈歪斜。
- 光影锚定：逆光剪影、局部幽光。
- 锚点ID示例：i-xxxxxxx（用户上传三视图后替换）

3\. 其他幸存者（人性博弈）

- 身份定位：自私者、拖油瓶、智力担当。
- 外貌特征：各异，带有强烈的应激反应。
- 服装：普通现代装束，脏污。
- 核心微表情：惊恐、贪婪、崩溃、算计。
- 光影锚定：冷调侧光。
- 锚点ID示例：i-xxxxxxx（用户上传三视图后替换）

### 四、污染状态锚点（核心铁律）

1. 初始状态：正常人。
2. 轻度污染：皮肤出现黑色血管，眼角流血，眼神恍惚。
3. 重度污染：五官开始融化或移位，肢体出现非自然扭动。
4. 终极畸变：彻底变成下一个副本的实体怪物。

### 五、跨镜头一致性锁定（核心铁律）

1. 同角色在不同镜头必须用同一人物锚点ID。
2. 所有镜头共用同一套角色锚点库。
3. 情绪切换必须使用同一角色的不同锚点帧，禁止换脸。
4. 服装、配饰、污染状态在全片中必须严格按剧情推进。
5. 若剧情需要角色换装，必须单独建立新的锚点ID并明确标注。

### 六、生成与合成

根据上述角色锚点与一致性规范，调用底层视频生成Skill，输出MP4视频文件。
