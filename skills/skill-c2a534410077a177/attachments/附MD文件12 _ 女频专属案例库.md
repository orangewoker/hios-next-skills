# 附MD文件12 | 女频专属案例库

**所属主SKILL：** 爆款女频短剧漫剧|顶级大导演思维生产\
**版本：** V2.0 融合合规版

## #做什么

本模块为女频短剧漫剧的专属案例库。

本模块不新增强制规则、不替代其他附MD，仅回答：规则落地执行出来应该是什么样子。

AI仅可模仿推理逻辑、分析链路、镜头转译思路，禁止直接复制示例内剧情、台词、人物关系。

本模块只提供案例参考，不替代主SKILL的流程调度、戏剧诊断、角色美学、微表情、台词配音、场景光影、视觉底座、字幕、音乐音效等规则。

## #需要什么输入

**最少提供：**

- 待分析剧本或场次文本。
- 题材类型：现代 / 古装 / 科幻。
- 人物关系与情绪基调。
- 场次等级。
- 观众已知信息。
- 目标画面比例：9:16竖屏。

**可选提供：**

- 是否需要输出视频脚本、Prompt清单、视觉方案。
- 上下游分镜、Prompt清单、视觉方案结果。
- 是否需要中日双语字幕。
- 是否需要音乐与音效设计。
- 是否需要参考完整戏剧张力卡。

## #怎么做

### 总控原则

本模块为案例参考库。\
AI必须优先调用主MD全局路由表与《戏剧张力分析体系》进行诊断，再参考本模块案例的推理方式。

禁止直接复制案例中的剧情、台词、人物关系。\
只允许迁移：

- 推理逻辑
- 分析链路
- 镜头转译思路
- 自检方式
- 戏剧张力卡结构

### 案例一：普通对话为什么不能拍成流水账

**适用题材：** 家庭情感·日常对话·任何B/C级过渡戏。

**推理逻辑：**

- 表层：母亲询问女儿晚归原因。
- 中层：母亲真正在意的是女儿是否遭遇麻烦。
- 深层：女儿在隐瞒实情，不想被母亲察觉。

**镜头转译思路：**

不要立刻切镜头。女儿说完保留短暂停顿；母亲打量女儿；女儿回避视线，低头脱外套。镜头重点不落在“说出台词”，落在母亲是否相信、女儿的回避姿态。

**结论：** 普通家庭对话也可以生成观看驱动力。

### 案例二：同一句台词，信息差不同，戏完全不同

**适用题材：** 悬疑·谍战·任何需要信息差设计的场次。

**推理逻辑：**

- 对称信息：张力低，普通会面。
- 观众知·人物不知：揪心悬念。
- 人物知·观众不知：神秘悬疑。

**结论：** 信息差的三维结构决定镜头策略。

### 案例三：对峙戏，如何判断场上的输赢态势

**适用题材：** 职场权谋·悬疑·婚姻情感·任何对峙场次。

**推理逻辑：**

- 第一层输赢：谁暂时占据主动。
- 第二层信息变化：谁掌握了新信息。
- 第三层潜台词：双方真实诉求与恐惧。

**镜头优先级：**

证据特写 → 对方面部反应 → 主动方观察神态。

### 案例四：有效反转，拒绝空降底牌

**适用题材：** 职场逆袭·悬疑反转·任何需要反转的场次。

**推理逻辑：**

- 前置预埋。
- 隐性铺垫。
- 暗示台词。
- 反转落地。

**反转三大自检：**

- 前有预埋。
- 后有局势巨变。
- 无空降证据、无机械外挂。

### 案例五：强节奏短剧“假输”戏份处理

**适用题材：** 职场强节奏短剧·复仇剧·任何需要假输铺垫的场次。

**推理逻辑：**

压迫 → 假性失败 → 观众怀疑 → 留存好奇 → 下一场再揭露底牌。

**镜头策略：**

固定近景、群体反应、仰拍、停顿、切黑。

### 案例六：高冲突场景，懂得使用静止张力

**适用题材：** 家庭情感·悬疑·任何S级高压戏的情绪节点。

**推理逻辑：**

观众清楚人物已经知晓真相，但不知道后续走向。静止本身就承担悬念功能。

**镜头策略：**

固定全景、长时间留白、近景嘴唇微动但未出声、近景对视。

### 案例七：场景结尾钩子接力

**适用题材：** 连续剧·任何需要追剧钩子的场次结尾。

**推理逻辑：**

本场矛盾解决 → 最后5秒抛出新信息 → 不解释 → 切黑。

**镜头策略：**

争吵结束、意外发现、关键道具特写、神色骤变、切往下一场。

### 案例八：锚点一致性管理

**适用题材：** 任何女频短剧漫剧。

**推理逻辑：**

- 每个角色建立唯一角色 ID。
- 每个核心场景建立唯一场景 ID。
- 每个关键道具建立唯一道具 ID。
- 每个镜头必须引用锚点 ID。

**自检：**

角色面部、服装、配饰、发型、场景光源、道具状态是否前后一致。

### 案例九：Prompt输出模板

**适用题材：** 任何女频短剧漫剧。

**推理逻辑：**

正向 Prompt 结构：

`[角色ID] + [场景ID] + [道具ID] + [镜头语言] + [光影色调] + [女频视觉底座参数] + [微表情指令] + 9:16 + 3-5秒 + [负面Prompt]`

**自检：**

- 是否包含角色 ID。
- 是否包含防穿模负面词。
- 是否包含女频唯美数字电影参数。
- 是否与戏剧诊断一致。

### 案例十：完整戏剧张力卡参考样例

**适用题材：** 职场权谋·董事会博弈·任何S级高压核心戏。

**场次：** 董事会会议，主角面临被罢免。

**核心张力卡字段：**

- 本场核心瞬时目标。
- 核心阻力 / 悬念支撑。
- 风险代价。
- 五大张力维度适配情况。
- 三维信息差。
- 人物攻防链路。
- 潜台词解析。
- 情绪曲线。
- 开场 / 结尾局势对比。
- 表层输赢 / 深层输赢。
- 观众认知变化。
- 本场核心张力节点。
- 下一场钩子驱动力。
- 镜头重点表现。
- 场景张力等级。

**结论：** 完整张力卡可直接指导分镜、Prompt、视觉方案。

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 题材、类型、场次等级不明确。
- 用户要求直接复制案例剧情、台词、人物关系。
- 用户要求新增剧情、新增事件、新增人设、新增台词。
- 用户要求输出视频脚本、Prompt清单、视觉方案，但缺少关键输入。
- 案例参考与《戏剧张力分析体系》或其他附MD规则冲突。
- 是否启用反转、钩子接力、强节奏短剧模式存在歧义。
