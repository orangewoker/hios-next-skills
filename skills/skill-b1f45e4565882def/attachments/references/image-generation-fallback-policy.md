# 图片安全审核失败回退策略

只在 `character_reference` 或 `prize_reference` 明确因安全审核未通过、内容审核拦截或等价安全拒绝时触发；网络、超时、模型繁忙和画质问题不适用。

1. 原模型审核失败：保持原始提示词完全不变，切换 Navo Pro。
2. Navo Pro 仍审核失败：保持同一原始提示词完全不变，切换 Navo2。
3. Navo2 仍审核失败：仅最小化调整可能触发审核的合规措辞后重试。
4. 仍失败：停止，说明限制，并给出不改变水上闯关综艺核心目标的安全替代方向。

不得通过谐音、错拼、编码、拆分或伪装受限内容绕过审核。可做的最小调整包括明确成年、移除第三方肖像/真人明星复刻、移除不必要的性化或危险化表述，同时保留写实闯关、软垫水池和综艺动作目标。
