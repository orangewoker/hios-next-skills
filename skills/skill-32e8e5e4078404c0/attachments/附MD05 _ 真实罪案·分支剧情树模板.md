# 附MD05 | 真实罪案·分支剧情树模板

**所属主SKILL：** 真实罪案 · 纯推理 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“剧情线混乱、分支无收束”的痛点。

## #需要什么输入

- 主线剧情节点清单、核心抉择点设计。

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·接手案件（start节点）
2. N02 抉择点1·优先调查哪里（branch节点）
   - N02A 搜查死者卧室（获得线索：伪造的遗书）
   - N02B 调取街角监控（获得线索：神秘车辆）
3. N03 第一次传唤嫌疑人（normal节点）
4. N04 抉择点2·审讯策略（branch节点）
   - N04A 施压逼供（可能引发律师介入，直觉下降）
   - N04B 心理战（出示伪造证据诈对方，识破谎言+1）
5. N05-N08 层层推进（如：推翻不在场证明、追踪真凶）
6. ENDING_CHECK 结局判定

### 三、灵魂七问（每个抉择点必过审）

1. 玩家为什么选它？（逻辑推理/直觉）
2. 它改变了什么？（线索/嫌疑值）
3. 即时后果是什么？
4. 延迟后果在哪个节点出现？
5. 是否会导致证据链断裂？
6. 是否有新的疑点生成？
7. 是否符合刑侦逻辑？
