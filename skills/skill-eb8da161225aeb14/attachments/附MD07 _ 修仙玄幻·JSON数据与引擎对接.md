# 附MD07 | 修仙玄幻·JSON数据与引擎对接

**所属主SKILL：** 修仙玄幻 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“修仙玄幻 | 上架Steam的互动影游”的专属JSON数据与引擎对接规范。

解决互动影游“JSON数据与引擎对接失败、变量语法错误、Twine工程无法运行、视频文件命名混乱”的痛点。通过统一的JSON数据结构、Twine/SugarCube工程规范与Adventure Creator配置说明，确保互动影游能落地运行、可直接交付。

## #需要什么输入

**最少提供：**

- 完整节点清单与变量字典
- 结局清单与触发条件
- 视频文件（MP4格式）与Prompt清单

**可选提供：**

- 项目名称与项目ID
- 目标平台（Steam/视频平台/小程序）
- 是否需要输出JSON数据包

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。JSON数据与引擎对接环节重点参考【顶级游戏开发大师】的节点设计与引擎对接规则。

### 二、JSON数据结构（标准格式）

1. schemaVersion：JSON数据结构版本号，固定为1。
2. projectId：项目唯一ID，由用户自定义。
3. title：项目名称，由用户自定义。
4. variables：变量数组，含变量ID、名称、类型、默认值、最小值、最大值。
5. nodes：节点数组，含节点ID、类型、标题、场景描述、选择、下一节点。
6. endings：结局数组，含结局ID、类型、标题、触发条件。

### 三、变量字典（示例）

1. 道心值：ID为v_karma，类型counter，默认0，范围0-100。
2. 仙缘值：ID为v_fate，类型relationship，默认0，范围0-100。
3. 魔气侵蚀：ID为v_demon，类型risk，默认0，范围0-100。
4. 渡劫成功率：ID为v_tribulation，类型counter，默认50，范围0-100。
5. 帝气值：ID为v_emperor，类型faction，默认0，范围0-100。
6. 路线锁定：ID为v_route，类型routeLock，默认null。
7. 本命飞剑：ID为v_sword，类型item，默认false。
8. 古仙玉简：ID为v_jade，类型item，默认false。

### 四、Twine/SugarCube 工程规范

 1. 引擎锁定：SugarCube 1.0.35（唯一，不可更换/升级）。
 2. 禁用格式：Harlowe / Chapbook / SugarCube 2.x。
 3. 建立方式：手动一个一个建节点，禁止使用“导入twee或txt文件”方式。
 4. 变量语法：标准SugarCube set语法，变量赋值格式为 set空格美元符号变量名空格等于号空格值。禁止使用旧格式。
 5. 变量运算：标准SugarCube增量语法，格式为 set空格美元符号变量名空格等于号空格美元符号变量名空格加号空格数值。禁止使用加号等于号的简写。
 6. 条件判断：eq / ne / gt / gte / lt / lte 六个英文关键字，禁止使用数学符号。
 7. 跳转：标准SugarCube goto语法。链接格式为双方括号内写“显示文字 箭头符号 目标段落名”。
 8. 变量命名：美元符号F 代表主角，美元符号E 代表对手，美元符号snap 代表快照，逐字符一致。
 9. 临时变量：也必须用美元符号前缀。禁止裸用 roll 或 read。
10. 保留字禁令：禁止使用 read 作变量名，改用美元符号readv。
11. 随机数：random(1,100)，禁止 either。
12. 排版：相邻宏之间至少留一个空格。
13. 提交前：跑自检清单10条，全部通过才交付。

### 五、Adventure Creator 配置说明

1. 引擎版本：Unity 2021.3 LTS 或以上，Adventure Creator 1.79 或以上。
2. 场景模式：2D Screen。
3. 变量配置：在AC菜单 Variables → Global Variables 逐一创建。
4. 变量类型对应：道心值用Integer；仙缘值用Integer；魔气侵蚀用Integer；渡劫成功率用Integer；帝气值用Integer；路线锁定用String；本命飞剑用Boolean；古仙玉简用Boolean。
5. 节点配置：创建Cutscene资产，添加动作 PlayMovieClip 播放视频文件，添加动作 Turn On Menu 显示选择界面，等待玩家选择，根据选择执行Variable变化加Run Cutscene跳转。
6. 选择界面：菜单类型为 Appear In Screen Space，按钮点击动作列表为变量变化加跳转。

### 七、文件结构规范

1. 项目文件夹包含：项目主文件HTML，N01.mp4至N08.mp4，E01.mp4至E05.mp4，D01.mp4至D10.mp4。
2. HTML和所有视频必须在同一文件夹，缺一个视频就黑屏。
3. 项目文件夹命名规范：项目名\_修仙玄幻互动影游。

### 八、本地测试规范

1. 本地测试：用 VS Code 加 Live Server 插件，右键HTML选 Open with Live Server。
2. 不可用：直接双击HTML（浏览器会拦截本地视频）。
3. 推荐浏览器：Chrome 或 Edge。

### 九、避坑清单（最容易出错）

1. 变量显示在屏幕上：原因变量写在普通节点里，解决方案为必须写在StoryInit节点。
2. 黑屏：原因起始节点没设为起始片段，解决方案为右键节点设为起始片段。
3. 视频无法播放：原因直接双击HTML，解决方案为用Live Server打开。
4. 所有结局都跳同一个：原因用了错误的跳转语法，解决方案为ENDING_CHECK全部用标准goto语法。
5. 引擎报错：原因用了SugarCube 2.x语法，解决方案为只用SugarCube 1.0.35。
