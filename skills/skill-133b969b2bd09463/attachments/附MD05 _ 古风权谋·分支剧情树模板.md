## 八、附MD05 | 古风权谋·分支剧情树模板

```markdown
# 附MD05 | 古风权谋·分支剧情树模板

**所属主SKILL：** 古风权谋 | 上架Steam的互动影游  
**版本：** V2.0 融合合规版

## #做什么

本模块为“古风权谋 | 上架Steam的互动影游”的专属分支剧情树模板。

解决互动影游“剧情线混乱、分支无收束、假选项泛滥、路径无法抵达结局”的痛点。通过统一的节点命名规范、严密的三幕结构与收束铁律，确保所有分支最终收束回主线，每条路径都能抵达结局，零死胡同。

## #需要什么输入

**最少提供：**
- 主线剧情节点清单（N01-N08）
- 核心抉择点设计与变量影响
- 路线设计（忠臣线/权臣线/帝王线/隐藏线）

**可选提供：**
- 结局数量与路径偏好
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律
本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。分支剧情树环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则，确保所有分支逻辑闭环。

### 二、节点命名规范（强制执行）
1. 主线剧情节点：N+两位数字，如N01、N02、N05、N06。
2. 路线节点：N+两位数字+路线代号，如N05A、N06B、N07C。
3. 好结局/普通结局：E+两位数字，如E01、E02、E03、E04、E05。
4. 坏结局/死局：D+两位数字，如D01、D02至D10。
5. 变量初始化节点：StoryInit。
6. 结局判定节点：ENDING_CHECK。
7. 核心铁律：所有节点ID、视频文件名、代码中的引用必须100%完全一致，严禁中文、空格、字母O混入数字0。

### 三、剧情树核心结构（发散-回流-锁定-再发散）

1. N01 开场·朝堂惊变（start节点）
2. N02 抉择点1·初入朝堂（branch节点）
   - N02A 隐忍低调，暗中布局（获得密折）
   - N02B 锋芒毕露，直谏君王（增加阴谋值）
3. N03 核心权谋觉醒（normal节点）
4. N04 抉择点2·第一次博弈（branch节点·核心）
   - N04A 选择权臣线（锁定权臣线）
   - N04B 选择忠臣线（锁定忠臣线）
   - N04C 选择帝王线（锁定帝王线）
   - N04D 选择隐藏线（需前置道具）
5. N05A/B/C/D 朝堂判定（normal节点）
6. N06A/B/C/D 抉择点3·阵营质问或反派试探（branch节点）
7. N07A/B/C/D 抉择点4·权谋博弈收尾（branch节点）
8. N08 抉择点5·最终一搏（branch节点）
9. ENDING_CHECK 结局判定
   - E01/E02/E03/E04/E05 正结局
   - D01-D10 坏结局

### 四、分支收束铁律（核心铁律）
1. 每一章末尾必须收束回主线，防止分支指数爆炸。
2. 关键选择后路线锁定，不可逆。
3. 单章分支层级不超过3级。
4. 每条路径最终抵达结局，无死胡同。
5. 零假选项：每个选择必须改变至少一项变量或后续节点。
6. 所有路径必须能抵达结局，不允许无限延伸。

### 五、古风权谋专属分支模板

#### 第一幕：入局（N01-N04）
1. N01：朝堂惊变，主角卷入夺嫡之争。
2. N02：抉择点1，主角对局势的态度。
3. N03：核心权谋觉醒，主角获得改写命运的能力。
4. N04：抉择点2，第一次博弈，四条路线选择，锁定后续走向。

#### 第二幕：博弈（N05-N06）
1. N05A：权臣线·朝堂判定·权臣降临，权势值+40·阵营信任+25。
2. N05B：忠臣线·朝堂判定·忠臣沉默，声望值+30·忠诚+30。
3. N05C：帝王线·朝堂判定·帝王震惊，权势值+20·帝运+20。
4. N05D：隐藏线·朝堂判定·神秘势力降临，全员声望+20·阴谋值+20。
5. N06A：权臣质问身份，选择A1/A2/A3，影响野心值。
6. N06B：忠臣要求回报，选择B1/B2/B3，影响忠诚值。
7. N06C：帝王私下试探，选择C1/C2/C3，影响帝运值与道具。
8. N06D：隐藏线全员试探，选择D1/D2/D3，影响全员声望。

#### 第三幕：收束（N07-N08）
1. N07A：权臣阵营施压，选择A1/A2，影响阵营信任。
2. N07B：忠臣出手阻挠，选择B1/B2，影响忠诚值与人物关系。
3. N07C：帝王真相摊牌，选择C1/C2，影响帝运值。
4. N07D：隐藏线全员摊牌，选择D1/D2，影响权势值。
5. N08：最终一搏，选择A再博弈一次；选择B收手；选择C全员豪赌。
6. ENDING_CHECK：根据所有变量与路线自动判断。

### 六、结局路径示例（以E04千古一帝为例）

N02B 锋芒毕露（阴谋值+10）  
→ N04D 参悟·传国玉玺（权势值+20·全员声望+20）  
→ N06C-2 反问堵住权臣（阴谋值-20）  
→ N07C-2 抬头直视皇帝微笑（获得传国玉玺）  
→ N08C 全员豪赌（权势值+30·全员声望+30）  
→ E04 千古一帝（全员声望≥20·传国玉玺=true）

### 七、灵魂七问（每个抉择点必须过审）
1. 玩家为什么选它？（动机）
2. 它改变了什么？（信息/关系/资源/风险/路线）
3. 即时后果是什么？
4. 延迟后果在哪个后续节点出现？
5. 是否可能造成独特失败或隐藏路线？
6. 是否只是换台词而没有剧情差异？（绝不允许）
7. 是否与角色动机和世界规则一致？
