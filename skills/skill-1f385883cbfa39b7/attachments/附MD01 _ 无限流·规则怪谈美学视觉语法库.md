# 附MD01 | 无限流·规则怪谈美学视觉语法库

**所属主SKILL：** 无限流·规则怪谈 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“无限流·规则怪谈 | 上架Steam的互动影游”的专属美学视觉语法库。

解决互动影游在AI生成时“视觉风格漂移、恐怖感廉价、规则诡异感不足、场景质感降级”的痛点。确保全片画面保持高度一致的“逻辑悖论与心理压迫”美学调性。

## #需要什么输入

**最少提供：**

- 剧本或故事梗概
- 生存者与核心NPC的姓名、设定、外貌锚点
- 核心场景清单（如废弃医院、诡异学校、幽暗走廊等）

**可选提供：**

- 核心规则守则的设定
- 特定光影偏好
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。视觉语法环节重点参考【提示词】底座的物理光学参数与【大导演思维】的镜头逻辑。

### 二、核心美学基调

1. **日常异化**：原本正常的医院、学校，出现违背物理常识的扭曲（如无限循环的楼梯、长满眼睛的墙壁）。
2. **规则压迫**：大量发黄、破损、带有红色扭曲字体的纸张/告示牌。
3. **极简诡异**：不需要满屏的血浆，而是用空旷、阴影、微小的不合常理之处（如角落里没有脸的玩偶）制造窒息感。
4. **冷峻写实**：仿真人质感、末世生存感、电影级厚重，拒绝廉价CG感。

### 三、色彩系统（强制锁定）

1. **幽绿**：色值 #2E4A3A；用途为安全出口标志、诡异光源、有毒气体。
2. **血锈红**：色值 #6B1E1E；用途为警示标语、陈年血迹、危险区域。
3. **苍白冷灰**：色值 #C2C5CC；用途为医院墙壁、停尸房、冰冷灯光。
4. **纯黑**：色值 #000000；用途为深渊、无光走廊、压抑阴影。
5. **暖黄**：色值 #D4782F；用途为摇晃的灯泡、手电筒光晕。

**绝对禁止**：高饱和荧光色、明亮清新的日漫色调、大面积的廉价血浆特效。

### 四、专属场景视觉语法

1\. 废弃医院

- 视觉特征：泛黄的墙皮、剥落的病床漆、散落的医疗器具、幽暗的走廊。
- 主光源：闪烁的顶灯（冷白）+ 手电筒（暖黄），色温5000K。
- 材质：锈蚀的金属、湿润的瓷砖、陈旧的布料。

2\. 无尽回廊

- 视觉特征：一模一样的门、没有尽头的走廊、墙上的古怪挂画。
- 主光源：极暗的壁灯，色温2700K，高反差。
- 材质：深色木门、剥落的墙纸、暗色地毯。

3\. 诡异教室

- 视觉特征：整齐的黑板、凌乱的课桌、墙上用粉笔写的红色守则、窗户外的虚无。
- 主光源：窗外的幽绿光线+黑板上的聚光灯，色温4500K。
- 材质：木质桌椅、玻璃窗户、粉笔灰飘散。

4\. 规则陈列室

- 视觉特征：无数张发黄的告示纸贴满墙壁、红线串联、打字机。
- 主光源：单一的顶光，色温4000K。
- 材质：老旧纸张、木质相框、生锈的图钉。

### 五、角色视觉语法

1\. 生存者

- 外貌：气质警觉，眼神锐利，带有伤痕或污渍，身形紧绷。
- 服装：现代战术风衣、破损的校服、染血的白大褂。
- 光影：主光冷白，手电筒光晕。
- 微表情：瞳孔收缩、眉头紧锁、咬紧牙关。

2\. 诡异实体（NPC/怪物）

- 外貌：类人但具有非人特征（无面、过长的四肢、反向的关节）。
- 服装：破败的制服（护士服、保安服）、染血的病号服。
- 光影：逆光、阴影、局部发光（如眼睛）。
- 绝对禁止：设计得像低成本的橡胶怪兽。

3\. 其他幸存者

- 外貌：各异，有的神经质，有的冷静。
- 服装：普通现代装束，有脏污。

### 六、核心规则道具视觉语法

1. 生存守则：泛黄的纸张，边缘撕裂，红色/黑色墨水手写体，字迹扭曲。
2. 怀表：金属外壳磨光，指针狂乱旋转，内部齿轮外露。
3. 手电筒：战术手电筒，光束中能看到灰尘飞舞。
4. 门禁卡：老式磁条卡，带有一条暗红色的血迹。

### 七、交互UI视觉语法（互动影游专属）

1\. 选择界面规范

- 字体：打字机字体或扭曲的手写体。
- 主色：幽绿或血锈红。
- 警告色：刺眼的红色闪烁。
- 背景：半透明黑色90%。
- 按钮：撕裂的纸张样式或老旧的监控屏幕样式。
- 变量提示：理智值-10·污染度+20（按项目实际变量替换）。

2\. 变量变化视觉反馈

- 变量增加时：屏幕飘出幽绿色+数字。
- 变量减少时：屏幕飘出血锈红-数字。
- 触发死亡结局时：屏幕瞬间切黑，屏幕上出现如打字机般一个字一个字敲出的“GAME OVER”。
- 触发真结局时：屏幕闪白，悠长的钟声。

### 八、光影与运镜专属规范

1. 绝境压抑：底光/手电筒局部光，色温2700K，低角度仰视。
2. 规则揭示：顶光，色温5000K，特写镜头。
3. 追逐逃生：强频闪，不规则晃动。
4. 结局收尾：白光或彻底死黑。

### 九、防崩要求

1. 怪异感需要通过“不合逻辑的结构”体现，而不是靠“恶心”。
2. 光影必须统一，禁止忽明忽暗导致画面穿帮。
3. 纸张上的文字不要试图让AI生成，一律留白后期贴图。
4. 人物面部必须保持真实毛孔质感，禁止磨皮美颜。
5. 实体怪物动作必须符合物理规律（除非设定就是反物理）。

### 十、生成与合成

根据上述视觉标准，调用底层视频生成Skill，输出MP4视频文件。
