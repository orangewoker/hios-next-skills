# 图像与视频画面提示词规范

## 1. 生成前准备

先建立并重复使用一致性块：

```text
角色：年龄区间；脸型与可辨识特征；发型；服装材质与层次；状态/伤势；不可变特征。
场景：空间结构；固定光源；墙地材质；天气；时间；关键道具位置。
时间层：构图倾向；焦段范围；机位稳定度；主/辅/点缀色；对比与颗粒；声音特征。
```

只写用户已经提供或创作方案中已经锁定的身份特征。不要无依据推断敏感属性。

## 2. 图像提示词公式

按从重要到次要的顺序写：

```text
[画面类型与画幅] + [主体一致性块] + [当前可见动作] + [环境与空间关系] +
[景别、机位、焦段、构图] + [现场光源、色温、曝光] + [主辅点缀色] +
[材质与大气] + [叙事瞬间] + [原创性与质量约束]
```

示例骨架：

```text
电影静帧，2.39:1。三十岁左右的短发女性工程师，左眉细小疤痕，深灰羊毛大衣……
她把结霜的录音机贴近混凝土墙；走廊尽头的红色应急灯每四秒亮一次。
中近景，略低机位，50mm，人物位于右三分之一，左侧负空间……
```

提供中文主提示词；当用户要直接投喂主流模型或默认完整影视包时，再给紧凑英文版。不要逐字硬译，要保持镜头信息等价。

## 3. 视频提示词公式

```text
[时长/画幅/镜头类型] + [首帧状态] + [单一主要动作] + [摄影机起点与运动] +
[速度与节奏] + [环境中的次级运动] + [光线变化] + [末帧状态] +
[连续性锁定] + [声音建议（若模型支持）]
```

遵循以下限制：

- 默认把每个生成片段控制在 4–10 秒，只安排一个主要人物动作和一种主要运镜；用户指定模型支持其他时长时再调整。
- 分镜镜头超过稳定生成时长或包含多个动作节拍时，拆成 `a/b/c` 子片段提示词，再在剪辑中连接。
- 明确谁移动、向哪里移动、摄影机是否越轴。
- 用“从……到……”描述首尾帧，不写互相冲突的运动。
- 把变形、穿越、群体运动等高风险动作拆镜。
- 需要慢动作时写明拍摄速率或播放效果；不要同时要求实时和慢动作。

## 4. 负面约束

按镜头需要选择，不要堆砌：

```text
避免人物身份漂移、面部变化、服装变色、额外手指、重复人物、道具消失、
不合理反射、光源方向跳变、文字乱码、品牌标志、水印、过度锐化、塑料皮肤、
无动机镜头抖动、忽快忽慢、物体穿模、空间结构改变。
```

若模型不支持负面提示词，把关键约束改写为正向连续性指令。

## 5. 模型适配

默认输出模型无关版本。用户指定模型后，再适配其官方参数和语法；不确定当前参数时，先查该模型的官方文档，不编造参数。

区分：

- 文生图：强调单个决定性瞬间、构图和材质。
- 图生图：说明必须保留与允许改变的区域。
- 文生视频：强调首尾状态、时间顺序和运动可执行性。
- 首尾帧视频：分别写首帧、过渡动作、末帧，并锁定身份与空间。
- 多镜头视频：优先拆成独立提示词，使用镜号和连续性块连接。

## 6. 原创性与安全

不要把导演姓名、电影片名、受版权保护角色或“完全复制某镜头”写入提示词。把参考转译成可观察的摄影、灯光、色彩、剪辑和情绪特征。

涉及真实公众人物、危险行为、未成年人或其他敏感内容时，遵守当前生成工具的规则；必要时调整为虚构成年人或非操作性的表现方式，同时保留故事功能。

## 7. 提示词输出格式

```markdown
### P-S07-01｜墙内的第二个滴答声
- 用途：图像关键帧 / 6 秒视频
- 连续性引用：CHAR-LC-01，LOC-OBS-02，TL-B
- 中文主提示词：
- English prompt：
- 负面约束：
- 与前后镜连接：
```

确保每个提示词都能追溯到一个分镜；不要为未出现在分镜中的“漂亮画面”额外生成提示词。
