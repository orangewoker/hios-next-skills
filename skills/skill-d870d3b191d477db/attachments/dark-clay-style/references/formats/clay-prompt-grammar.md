# 黏土 prompt 文法与用词库

这些是**可适配的模式与句式**，按场景改写，不要逐字照搬。

## 材质四件套（每条 prompt 必备）

### 1. 黏土质感（选 2-3 条具体描述，避免笼统写"黏土材质"）

- 手工黏土模型，哑光吸光表面，无高光反射
- 表面可见清晰的指纹压痕与揉捏痕迹
- 模块拼接处露出黏土接缝与微小裂口
- 木制雕塑工具留下的刮痕与压线
- 微糙颗粒质感，像半干陶土
- 黏土表面附着细小绒毛与灰尘颗粒（定格动画工作台质感）

### 2. 造型与形变（怪诞的核心，必写具体部位）

- 脖颈被拉长扭转，头部与身体呈不自然角度
- 面部被挤压出不对称的笑容，一侧嘴角过度上扬
- 手指细长并轻微融化下坠，指尖拉出黏丝
- 身体某处被无形力量压扁，形成褶皱堆积
- 关节弯折方向错误，四肢像被随手捏就
- 眼窝深陷，眼珠是两颗被按进去的浑浊玻璃珠
- 物体一半保持原形、一半正缓慢软化变形（暗示"正在发生"）
- 阴影里的物体轮廓与本体不一致（暗示隐藏的形变）

### 3. 光线（默认单侧冷硬，可替换变体）

- 单侧冷硬光源（灰蓝月光从画面左侧切入），主体另一侧陷入深影
- 顶置昏黄灯泡光，在头顶压出浓重阴影，眼睛藏在暗处
- 烛光从下方打亮，制造怪谈式底光
- 雾气弥漫的漫射灰光，无明确光源方向，整体压抑
- 规则：黏土表面必须哑光吸光；若出现反光则描述为"湿润的、刚被捏过的地方才微微泛光"

### 4. 色彩

- 低饱和灰调主色（灰褐、烟灰、暗橄榄）+ 一处点睛色
- 点睛色选项：暗红（危险/秘密）、毒绿（异变/腐坏）、深紫（神秘/梦魇）、锈橙（旧物/时间）
- 暗调但不糊成一团黑：保留中间调的层次，阴影里仍有可辨认的细节

## 尺度参照（每图至少一处）

正常尺度的物件放进失真场景：一枚正常大小的硬币、一根火柴、一把真实比例的旧钥匙、一只停摆的怀表。参照物让黏土世界的夸张比例有了支点。

## 情绪基调措辞

- 荒诞幽默：笨拙可爱的扭曲、尴尬的静止瞬间、故作镇定的表情
- 诡谲不安：沉默的凝视、不知何时开始的形变、熟悉之物的陌生化
- 暗黑童话：阴郁叙事感、被遗忘的角落、旧故事的余烬

## 视频 prompt 文法

结构：**开头一次性声明材质四件套（精简为 2-3 句）+ 时间轴 beat**。每个 beat 以镜头起手，依次写画面动作与声音。

- 镜头词库：缓慢推近（slow push-in）、环绕半周、定机位凝视、手持微晃（模拟定格动画逐帧感）、俯视下降、从阴影中拉出主体
- 动态词库：黏土缓慢蠕动变形、身体一寸寸融化下坠、头部缓缓转向镜头、嘴角被无形力量扯开、阴影自行爬行、物体被捏住一角拉伸出黏丝
- 声音词库：黏土挤压的湿润闷响、指尖划过黏土表面的沙沙声、远处不规律的滴答、低频嗡鸣、突然的寂静
- 定格动画感：可加"逐帧动画质感、每秒 12 帧的轻微顿挫"强化手工黏土动画的物理感

示例骨架（改写后使用）：

```
手工黏土定格动画质感，哑光吸光表面可见指纹与接缝，低饱和灰调配暗红点睛，单侧冷硬光。
0-3s: 缓慢推近，Subject1 静坐于 Scene1，脖颈以不自然角度歪着，黏土挤压的湿润闷响
3-7s: 继续推近，Subject1 的笑容被无形力量缓缓扯开，阴影在墙上自行爬行，低频嗡鸣渐强
7-12s: 定机位凝视，主体一侧身体开始缓慢下坠融化，指尖拉出黏丝，滴答声不规律响起
12-15s: 镜头轻微后拉，形变停止在诡异的静止瞬间，突然的寂静，画面定格
```

## 落 prompt 前自检

- 材质四件套是否各至少一条具体描述？
- 形变是否写到了具体部位而非"扭曲的风格"这类空词？
- 有无尺度参照物？
- 声音词是否具体（湿润闷响/沙沙/滴答），而非"恐怖音效"？
- 是否全正向措辞、无伤害性元素？
