# 公众号文章改编策略

仅在判断文章类型、确定单集结构或压缩长文时读取本文件。

## 内容类型与结构

### 观点类

使用：反常识或争议钩子 → 常见认知 → 核心论点 → 2—3 个证据或例子 → 对观众的启示。

- 保留原文论证链，不把作者观点包装成公认事实。
- 每个证据只服务一个论点，删除重复解释。
- 结尾给出判断方法或行动建议，不机械复述开头。

### 教程类

使用：结果预告 → 适用对象 → 3—5 个关键步骤 → 常见错误 → 完成后的收益。

- 步骤必须能执行，顺序不得因压缩而失真。
- 将前置条件放在第一次用到之前。
- 每一步配一个动作画面、界面演示或视觉比喻。

### 案例类

使用：结果或转折 → 背景与目标 → 关键决策 → 执行过程 → 结果 → 可迁移经验。

- 区分事实、作者解释和推测。
- 保留决定结果的变量，删除无关时间线。
- 不把单个案例夸大为普遍规律。

### 故事类

使用：冲突瞬间 → 人物与目标 → 阻碍升级 → 关键选择 → 结果 → 余味或启示。

- 只使用原文能够支持的情节、对白和人物动机。
- 把背景信息嵌入行动，不连续堆叙述。
- 情绪来自处境和选择，不靠夸张形容词硬推。

### 产品或品牌解读类

使用：用户痛点 → 产品或方法如何解决 → 关键机制 → 使用场景 → 限制或边界 → 行动引导。

- 宣传性主张必须有原文依据；不得添加虚构效果、用户评价或数据。
- 优先展示使用前后差异、流程和适用场景。
- 行动引导保持克制，避免连续口号。

## 时长与口播字数

按普通话自然语速估算，实际以配音试听为准：

| 目标时长 | 建议口播字数 | 建议镜头数 |
| --- | ---: | ---: |
| 30 秒 | 120—160 字 | 5—8 |
| 60 秒 | 220—300 字 | 8—12 |
| 90 秒 | 330—450 字 | 10—16 |
| 180 秒 | 650—850 字 | 18—28 |

任何情况下口播不得超过 1000 个汉字。文章过长时缩小选题，不提高语速硬塞内容，也不拆成多集。

## 长文压缩顺序

1. 写出一句话核心结论。
2. 标记支撑结论必需的事实、步骤、例子和数字。
3. 合并表达同一意思的段落。
4. 每类证据只保留最强的一到两个。
5. 删除行业背景、作者寒暄、重复总结和无关推广。
6. 检查压缩后是否仍能回答“为什么可信”和“观众能得到什么”。

## 钩子选择

优先从原文已有信息中选择：

- 明确结果：“我用三个步骤，把……从 A 变成 B。”
- 认知冲突：“多数人以为……，真正决定结果的是……”
- 具体损失：“如果你还在……，最容易浪费的是……”
- 关键问题：“为什么同样做……，结果会差这么多？”
- 高价值清单：“看懂这三点，你就能判断……”

禁止使用原文无法兑现的夸张承诺、虚假悬念或与正文无关的标题党。

## 视觉模式选择

- 概念密集、人物较少：信息图、关键词动画、场景隐喻。
- 有明确人物或事件：纪实感场景、人物行动和时间推进。
- 教程或工具介绍：界面演示、步骤卡片、局部放大。
- 产品或案例：真实素材优先，辅以机制动画和数据可视化。
- 素材不足：统一风格的原创画面加动态排版，不拼凑无关图库。
