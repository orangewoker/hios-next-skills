# 正式2×2空场景板

## 固定版式

每个正式场景第一批先生成一张2×2场景板，固定四格：北视角、南视角、西视角、东视角。方向表示摄影机位于对应方向并朝当前空间内部观察，不表示主体朝向。每格都要写清摄影机所在方向、观察方向和能看见的真实结构。

第一批四格全部是水平视角，不放俯视图，不用九宫格或混合多层图替代。

## 一致性

四格属于同一连续空间，保持空间结构、主要物件位置、人物尺度基准、材质、光源方向和时间状态一致。同一结构不能在不同视角移动、消失或改变比例。

## 事实边界

只描述剧本、导演方案或参考素材确认存在的内容。不得为了模板完整而增加门、窗、入口、出口、楼梯、扶梯、电梯、家具、通道、障碍或连接结构。无法确认的结构写“待确认”，不重新设计空间。

## 多楼层

每个楼层／主要高度层级单独建立场景资产并生成自己的北／南／西／东2×2板。每张只表现当前层；各层统一建筑语言、尺度、材质和光影，不推断未确认的跨层连接。

## 无人物原则

场景板原则上为空场景，可使用不具身份的尺度标尺，但不生成正式角色、人影或人体剪影。只有资产用途明确要求人物尺度参照时，才使用非角色化比例参照。
