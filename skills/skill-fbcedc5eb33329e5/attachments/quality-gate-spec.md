## Quality Gate 1

在AGENT-1A（叙事）和AGENT-1B（摄影）完成后执行，确保叙事与摄影方案对齐。

### 四维检查清单

| 检查项 | 审查内容 | 通过标准 |
|--------|----------|----------|
| 叙事情绪 <-> 光影色彩 | 情绪曲线与光影方案是否匹配 | 高情绪=高对比/强光影，低情绪=柔光/低对比 |
| 镜头焦段 <-> 画幅兼容 | 焦段在对应画幅下是否产生预期效果 | 无畸变过载，构图空间充足 |
| 运镜选择 <-> 叙事理由 | 每个运镜是否有明确的叙事功能 | 运镜即叙事，非装饰性运动 |
| 色彩方案 <-> 题材路由 | 色彩是否符合风格路由结果 | 色调方向与流派一致 |

### 输出格式

```
Quality Gate 1 审查
| 检查项 | 结果 |
|--------|------|
| 叙事情绪 <-> 光影色彩匹配？ | [通过/不通过+原因] |
| 镜头焦段 <-> 摄影机画幅兼容？ | [通过/不通过+原因] |
| 运镜选择 <-> 叙事理由成立？ | [通过/不通过+原因] |
| 色彩方案 <-> 题材路由一致？ | [通过/不通过+原因] |
-> [全部通过 -> 进入Phase 4 / 不通过项 -> 回到Phase 2修正]
```

## Quality Gate 2 三代自检

在AGENT-3七段式整合输出完成后执行。

### Pass 1 叙事审查

- [ ] 故事节拍完整，无遗漏段落
- [ ] 情绪曲线流畅，转折有铺垫
- [ ] 每个运镜都有叙事理由（非装饰性）
- [ ] 声音节拍点与画面节拍对齐

### Pass 2 摄影审查

- [ ] 三件套齐：摄影机型号 + 镜头参数 + 光比
- [ ] 瑕疵美学 >= 3项，跨 >= 2类别
- [ ] 色温全片统一（或有意的色温变化有叙事理由）
- [ ] 胶片型号与场景光线条件匹配

### Pass 3 合规审查

- [ ] 无空洞词（"beautiful"、"amazing"等无信息量词汇）
- [ ] 确认门在结尾（未预设模型/分辨率）
- [ ] 微观描述具体（可辨识的最小纹理单元）
- [ ] 负向排除词覆盖常见AI问题
- [ ] 所有镜头的七段式输出完整无缺段

## 五重会审

三代自检通过后，从五个专业视角进行会审。

### 会审格式

```
五重会审：

| 席位 | 追问 | 结果 |
|------|------|------|
| IMAX摄影大师 | [摄影参数]匹配[题材]？ | [通过/不通过+说明] |
| 导演大师 | 镜头即叙事，情绪外化到位？ | [通过/不通过+说明] |
| 剪辑大师 | 转场衔接、景别衔接、色调无断层？ | [通过/不通过+说明] |
| 声景设计师 | 声音分层完整、声画关系合理？ | [通过/不通过+说明] |
| 去AI工程师 | 瑕疵项数/类别达标、负向词覆盖、微观具体？ | [通过/不通过+说明] |

-> [全部通过 -> 进入确认门 / 不通过 -> 回到对应Phase修正]
```

### 各席位关注点

**IMAX摄影大师**：
- 摄影机+胶片+镜头组合是否合理
- 光圈/焦段/画幅的物理兼容性
- 布光参数是否可执行

**导演大师**：
- 运镜是否承载叙事功能（不是单纯展示）
- 情绪外化是否通过视觉元素实现
- 景别变化是否有节奏逻辑

**剪辑大师**：
- 相邻镜头的景别跳跃是否合理（不违反30度规则除非刻意）
- 转场方式是否与情绪匹配
- 色调在转场处是否有断层

**声景设计师**：
- 四层声音（对白/音效/环境/音乐）是否完整
- 声画关系（J-Cut/L-Cut/同步）是否有设计意图
- dB分配是否合理（对白>音效>环境）

**去AI工程师**：
- 瑕疵美学项数>=3且跨>=2类别
- 肤质引擎L1/L2/L3是否逐层覆盖
- 负向排除词是否覆盖：CG/塑料/过度平滑/不自然对称/AI典型痕迹
- 微观描述是否具体到可辨识级别

## 确认门

双重Quality Gate通过后，锁定用户确认。

### 确认项清单

```
[确认门]
方案已通过双重Quality Gate + 五重会审。执行生成前，请确认：

1. 方案整体是否符合创作意图？
   [概述核心方案：镜头数/时长/转场/声画设计]

2. 请选择视频生成模型：
   [列出候选模型供用户选择，系统不预设]

3. 输出分辨率？
   [列出候选分辨率]

4. 画外音/TTS方案确认？（如适用）
   [声音模型/音色/覆盖范围]
```

### 确认门规则

- 模型必须由用户指定，系统不预设
- 分辨率必须由用户确认
- 用户可选择跳过某些确认项（如无需画外音）
- 全部确认后才可进入执行生成阶段
