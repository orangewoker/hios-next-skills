# 审计 · Phase 1 剧本质量审计

> **触发**：Phase 1 剧本生成完成，--done 推进 1.5 前
> **前提**：先运行 `python scripts/verify_phase.py 1 {N} --project-dir "{项目目录}" --json`
> **范围**：G2-G8 + GF + F1-F6

---

## 基线数据

```bash
python scripts/verify_phase.py 1 {N} --project-dir "{项目目录}" --json
```

对每个 `blocking_issues` 逐一确认修复状态。返回 JSON 含 overall_pass/checks/blocking_issues/warnings。

---

## 审计步骤

### G2 零万能词
取 `F5_NO_BLAND_WORDS`。pass=false→从 blocking_issues 提取 words_found，随机抽查30%(≥3处)用 Read 确认。检查是否声称"已修正"但未修正→标记"伪造修复"。

### G3 情绪弧线
Read 剧本全文。统计每场情绪关键词(愤怒/恐惧/惊讶/悲伤/喜悦/紧张/焦虑/绝望/兴奋)。检查触发事件+情绪变化。无变化→FAIL。

### G4 对话信息增量
提取所有台词，抽 max(3, N×0.3) 句。逐句判定三功能(推进剧情/揭示信息/塑造角色)。任一不满足→FAIL。

### G5 动作可表演性
从 JSON 万能词结果中提取残留词，确认涉及动作/表情。检查"微微一笑""淡淡地""眼神闪烁"等。

### G6 合规2026
搜索未成年+恋爱、吸烟/酗酒、极端仇恨关键词。每项命中标注行号+原文。

### GF 格式铁律
取 JSON 中 F1-F6 检查结果。blocking fail→FAIL，warning fail→PARTIAL。

### G7/G8 条件
第1集→执行 G7 开篇质量；非第1集→跳过 G7。全部集数→执行 G8 台词角色化。

## 报告输出

```
Phase 1 审计报告
审计对象: 分集剧本/ep{NNN}.md
基线: overall_pass={T/F} / 阻断{N}项 / 警告{N}项

G2 零万能词: PASS/FAIL — 发现"XX" L{行号}
G3 情绪弧线: PASS/FAIL — 场次1: 起点→触发→变化 / 场次2: 无变化
G4 对话增量: PASS/FAIL — 抽查{N}/{N}句: L{行号}"XX"推进剧情, L{行号}"XX"无增量
G5 可表演性: PASS/FAIL — L{行号}含万能词"XX"
G6 合规2026: PASS/FAIL
GF 格式铁律: PASS/FAIL — F1-F6: ...
G7/G8: ...

结论: PASS/PARTIAL/FAIL
FAIL项: {编号清单} / PARTIAL项: {清单}
允许推进: PASS→是 / PARTIAL→是(带警告) / FAIL→否
```

同时写入结构化判定文件：

路径：`.pipeline/audit-1-ep{NNN}.json`

```json
{
  "phase": "1",
  "episode": {NNN},
  "conclusion": "PASS",
  "allow_advance": true,
  "fail_items": [],
  "partial_items": [],
  "summary": "剧本审计通过"
}
```

字段规则：
- `conclusion` 只能是 `PASS`、`PARTIAL`、`FAIL`
- `allow_advance` 在 `PASS` 或 `PARTIAL` 时为 `true`，`FAIL` 时为 `false`
- `fail_items` / `partial_items` 填编号和简短证据，不得空口判定

## 规则

- 每个判定须有行号+原文或数据证据
- 步骤全部执行不可跳过
- 禁止编造证据
- 随机抽查≥30%≥3处
- 默认内容不合格，blocking_issue未修复→FAIL
