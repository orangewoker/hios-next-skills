# 每拍英文主运镜标签

## 输出规则

每个时间拍必须在时间码后紧接一个且仅一个英文主运镜标签：

`(00:00-00:03) [Slow Dolly In] [中文镜头正文]`

标签只概括本拍最主要的摄影机运动，不代替中文正文中的机位高度、物理距离、轴线侧、运动起点与终点、速度曲线、前景视差、焦点变化、受力反馈和拍尾落点。复合运动只选择承担本拍叙事任务的主运动作为标签，其余修正写入中文正文。固定机位确有叙事功能时使用 `[Static Camera]`，并在正文说明稳定原因及画内动势。

## 允许标签

- `[Slow Dolly In]`：缓慢逼近人物判断、关系压力或悬念。
- `[Fast Dolly In]`：快速逼近决定、威胁或冲击前兆。
- `[Slow Dolly Out]`：缓慢拉开关系、孤立或余韵。
- `[Fast Dolly Out]`：快速退让、揭示突发空间或承接冲势。
- `[Static Camera]`：保护精确接触、微表演、悬念或轴线。
- `[Handheld Tracking]`：贴身跟随紧张位移并保留人工受力。
- `[Shoulder Camera]`：肩扛重量感、近身临场与有限修正。
- `[Low Angle Tracking]`：低机位跟拍冲刺、压迫或强势位移。
- `[High Angle Tracking]`：高机位跟随空间调度或受困关系。
- `[Side Tracking]`：侧向平行跟拍步幅、距离与横向视差。
- `[Reverse Tracking]`：摄影机面对主体退行，放大逼近速度。
- `[Forward Tracking]`：从主体后方或侧后向目标推进。
- `[Orbit Shot]`：有明确空间揭示目的的环绕。
- `[Arc Shot]`：小幅弧移改变人物关系或遮挡。
- `[Macro Push In]`：推近眼睛、手部或关键道具细节。
- `[Push In]`：一般推近注意力目标。
- `[Pull Out]`：一般拉远揭示关系或结果。
- `[Fast Zoom]`：突发注意力跳转或高能细节。
- `[Crash Zoom]`：极短促冲击式变焦。
- `[Slow Zoom In]`：光学缓慢收紧主体。
- `[Slow Zoom Out]`：光学缓慢揭示环境。
- `[Top View Pan]`：俯视空间内的横向调度。
- `[Pan Left]`：向左摇摄连接明确目标。
- `[Pan Right]`：向右摇摄连接明确目标。
- `[Tilt Up]`：向上摇摄完成登场、尺度或视线揭示。
- `[Tilt Down]`：向下摇摄读取落地、倒下或道具结果。
- `[Whip Pan]`：由明确声源、视线或高速目标触发的甩摄。
- `[Crane Up]`：升高机位揭示空间、阵型或结果。
- `[Crane Down]`：降低机位进入人物、落点或细节。
- `[Boom Up]`：短距离垂直升镜。
- `[Boom Down]`：短距离垂直降镜。
- `[Reverse Zoom Out]`：主体占比受控而背景空间快速展开。
- `[Focus Pull]`：焦点在前中后景之间转移注意力。
- `[Rack Focus]`：快速焦点切换连接两个明确主体。
- `[POV Tracking]`：有明确人物视点依据的主观跟拍。
- `[Dutch Angle Push In]`：倾斜构图下推近失衡或威胁，必须有叙事动机。

不得自造近义英文标签、在同一拍并列多个标签，或只贴标签而省略中文运镜执行细节。
