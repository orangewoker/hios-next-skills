# 单字识字卡生成（子技能）

> 本技能是 **看图识字教学** 主技能的子技能，由主技能**逐字调用**。它只处理**一个字**，产出**一张识字卡**。选字规范、字形正确红线、模板规范由主技能作为输入传入，本技能遵守。

## Skill 定位
- 只负责：给**一个汉字**生成**一张识字卡**——一侧是**大号标准楷体字**，另一侧是**能让孩子看图猜字的插图**（人=奔跑小人、雨=乌云落雨、瓜=藤上的瓜）。图文分区、字为主角。
- 不负责：选字（主技能定）、把卡变视频（`单字动效小节` 干）、多卡排版成 A4（主技能/打印场景处理）。它是**可复用的原子件**：既是视频每个小节的底图，也能单独当打印卡。

## 输入
- **必需**：一个**目标汉字**。
- **可选（由主技能传入）**：模板规范（卡片样式/字体/配色/插图风）、风格、画幅、该字的插图指向（用户特别指定时）。
- 没依据的规格**不臆造**（走主技能默认或稳妥默认）。

## 输入使用
- **严格遵守**：卡上汉字必须是**给定的那个字、且写对**；沿用主技能给的**模板规范**保证与其它卡一致。
- **只作参考**：插图具体画法、构图细节——在"图文对应 + 字为主角"前提下自由。

## 内部流程和 Knowhow
### 一、字形正确（红线）
- 楷书标准、笔画完整、写对；字**大、居中、留白足**，笔画粗细适合幼儿辨认，不加多余装饰笔画。
- AI 直接画汉字易错字/畸形——**汉字优先用标准字体渲染**，生成后**逐字校对**，错字/缺笔立即重做。
### 二、图文对应（让孩子看图猜字）
- **象形字** → 直接画物象（山、雨、竹、瓜、龟）。
- **动作/会意字** → 画代表场景或动作（人=奔跑小人、坐=坐树桩、串=糖葫芦、叶=树叶）。
- **抽象/形容字** → 画唤起该义的具体物（甜=甘蔗/糖 + 笑脸）。
- 一张卡只表达**一个字义**；**图不喧宾夺主**，占卡约 1/3~1/2，另一侧放大字；**图文分区不重叠**（字保持清晰可读）。
### 三、prompt guide（运行时按实际填，别写死）
- flat cartoon flashcard, one big standard Kaiti character 'X' on one side, cute simple illustration of [对应物/动作] on the other, bright, clean, for kids。
- 强调 correct standard strokes（靠字体渲染 + 人工校字兜底）；插图放哪侧、简笔卡通、占比小于字。
- 画幅/分辨率没依据留空走默认；别让图压字、别加拼音/噪点、别偏离主技能模板风格。

## 输出
- **一张识字卡**（图节点，返回**真实 node_key** 交回主技能 / 供 `单字动效小节` 引用）。
- tag 用 `character` 或 `keyframe`（作视频底图时）。

## 自检
- [ ] 卡上是**给定的字**、**写对了**（笔画完整无畸形）？
- [ ] **图能对上字**，孩子看图能联想到该字？
- [ ] 字够大居中清晰、图不压字、图文分区？
- [ ] 风格是否**贴合主技能模板**（与其它卡一致）？

## Ask User
- 一般**不直接问用户**（选字与形态由主技能统一决策）。
- 仅当**该字插图不好表现**、或用户对这个字有特别指定但含糊时，反馈给主技能去确认。
