# Seedance 2.5 情绪导演标准

## 1. 核心原则：先理解，再更改

情绪导演不得看到“愤怒/害怕/爱慕”就自行增强。必须先建立 `SOURCE_EMOTION`，再生成 `DIRECTED_EMOTION`。

源理解记录：
- 情绪刺激来自谁/什么；
- 当前情绪基线；
- 可见证据；
- 起始→变化→峰值→回落；
- 与台词/停顿/动作的关系；
- 置信度。

## 2. 微表情要用可拍摄信号

禁止只写：震惊、愤怒、悲伤、心虚、爱慕、复杂。

优先从以下维度选择2-4个主信号，按实际发生顺序写：
- 视线：锁定、短暂移开、回看、失焦、停止扫视；
- 眼睑：轻抬、压低、眨眼中断、眨眼变慢；
- 眉部：内侧轻收、单侧轻抬、眉间短暂收紧；
- 嘴唇/下颌：微张后闭合、抿紧、下颌绷紧、嘴角短促抽动；
- 呼吸/吞咽：屏息、浅吸、一次吞咽、呼气延长；
- 头颈/重心：下巴回收、颈部僵住、身体轻微前倾/后撤但不改变源Blocking。

避免同时让所有器官都动，防止Seedance表演机械化。

## 3. 强度规则

默认 `DIRECTED_EMOTION.intensity <= SOURCE_EMOTION.intensity`。

除非用户明确要求增强，不新增：哭、笑、尖叫、攻击、后退、拥抱、摔物、跪地、明显身体失控或新的反应镜。

## 4. 与英语台词对齐

英语台词先通过口语化校对，再做最终情绪导演优化。微表情要对齐：
- 关键词前后的视线变化；
- 句中停顿；
- 被打断位置；
- 句尾压住/释放情绪；
- 画外对白时倾听者反应。

## 5. 用户情绪导演校对

展示：
`SH｜角色｜SOURCE_EMOTION｜源证据｜DIRECTED_EMOTION`

用户可自然语言修改：
- “不是害怕，是心虚。”
- “不要明显皱眉，只绷紧下颌。”
- “一直盯着他，不要躲眼神。”
- “说完先吞咽，再移开视线。”

保留SOURCE_EMOTION不变，仅更新DIRECTED_EMOTION并递增revision。

## 6. 写回分镜

每个需要表演细化的SH增加：
`表演与微表情：<按发生顺序写2-4个可见信号>`

若源镜头几乎没有表情变化，应允许写“保持中性表情，仅维持视线/呼吸连续”，不得强行加戏。
