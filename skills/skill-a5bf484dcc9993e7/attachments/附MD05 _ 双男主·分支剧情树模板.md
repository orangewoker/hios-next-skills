# 附MD05 | 双男主·分支剧情树模板

**所属主SKILL：** 双男主 · 双向救赎 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“剧情线混乱、分支无收束”的痛点，确保所有分支逻辑闭环。

## #需要什么输入

- 主线剧情节点清单、核心抉择点设计。

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·雨夜对峙（start节点）
2. N02 抉择点1·枪口下的选择（branch节点）
   - N02A 放下枪，选择相信（信任度+20）
   - N02B 扣下扳机，但打偏（黑化值+10，羁绊+5）
3. N03 共同卷入惊天阴谋（normal节点）
4. N04 抉择点2·秘密揭露（branch节点）
   - N04A 坦白自己的卧底身份（触发信任危机）
   - N04B 继续隐瞒，独自承受（黑化值+20）
5. N05-N08 层层推进（如：天台交心、联手反击、生死逃亡）
6. ENDING_CHECK 结局判定

### 三、灵魂七问（每个抉择点必过审）

1. 玩家为什么选它？（为了救他，还是为了任务？）
2. 它改变了什么？（信任崩塌，或羁绊加深）
3. 即时后果是什么？
4. 延迟后果在哪个节点出现？
5. 是否可能造成独特失败？（如黑化反杀）
6. 是否只是换台词？
7. 是否符合双强人设逻辑？

### 四、生成与合成

调用底层视频生成Skill，输出MP4视频文件。
