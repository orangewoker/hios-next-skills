## 四、构图与景别：画面怎么框

> 本章覆盖摄影机取什么、放在哪、什么角度——决定了观众"看到什么"和"如何感受"。

### 4-1 景别（Shot Size）

中文英文画面范围心理效果提示词电影示例大远景Extreme Long Shot人物极小，环境为主体渺小、孤独、史诗感`extreme wide shot, tiny figure in vast landscape`《阿拉伯的劳伦斯》(1962)——沙漠中的骆驼剪影全景Long Shot / Full Shot人物全身，带环境定位——"谁在哪"`full body shot, head to toe`《布达佩斯大饭店》(2014)——对称全景中全景Cowboy Shot膝盖以上英雄感、自信`cowboy shot, from knees up`《黄金三镖客》(1966)——枪套在画面底边中景Medium Shot腰部以上中性交谈距离`medium shot, waist up`《社交网络》(2010)——静态谈判棋局中近景Medium Close-Up胸部以上开始关注人物`medium close-up, chest up`《老无所依》(2007)——杀手安东的压迫感特写Close-Up面部/肩部亲密、强制关注`close-up, face filling the frame`《沉默的羔羊》(1991)——汉尼拔直视镜头大特写Extreme Close-Up单一器官极致强调、抽象化`extreme close-up, just the eyes`《2001 太空漫游》(1968)——HAL 9000 的红眼

---

### 4-2 构图规则

**物理层面**：构图（Composition）是画面元素的排布方式。以下是电影摄影中最核心的几种构图规则，每种在 AI 提示词中都有对应的可调用标签。

规则英文关键词怎么做心理效果电影示例**三分法**`rule of thirds`画面横竖各三等分，主体放在交叉点最自然的平衡——人眼默认搜索这些交点《疯狂麦克斯：狂暴之路》(2015)——动作场面主体始终在三分线交叉点**对称构图**`symmetrical composition`画面左右镜像平衡，主体在正中央秩序、仪式感、压迫或完美《布达佩斯大饭店》(2014)——韦斯·安德森的全部作品**引导线**`leading lines`用道路、栏杆、光线等线条引向主体强迫观众看向特定位置——宿命感《2001 太空漫游》(1968)——空间站走廊的透视引导线**负空间**`negative space`主体占画面极小面积，留大面积空白孤独、渺小、期待《她》(2013)——角色独自坐在大面积玻璃窗前**框中框**`frame within a frame`用门、窗、拱廊框住主体被困、被观察、或聚焦《搜索者》(1956)——约翰·韦恩从门框中走出走进旷野**低角度**`low angle shot`摄影机从下往上拍权力、威压、英雄化《公民凯恩》(1941)——凯恩被拍得像一座纪念碑**高角度**`high angle shot`摄影机从上往下拍脆弱、被支配、渺小《辛德勒的名单》(1993)——高角度俯瞰集中营**荷兰角**`dutch angle`画面故意倾斜不安、失衡、心理异常《第三人》(1949)——维也纳下水道的倾斜世界

```
rule of thirds composition, subject on left third     → 三分法
symmetrical composition, centered subject             → 对称
leading lines pointing to subject, deep perspective   → 引导线
negative space, solitary figure in empty room         → 负空间
frame within a frame, shot through doorway            → 框中框
low angle hero shot, looking up at subject            → 低角度
```

---

### 4-3 主观镜头（POV）

**物理层面**：`POV shot` = 摄影机代入角色眼睛，观众看到的就是角色看到的。

- **全片 POV**：极少见（《硬核亨利》《湖上艳尸》）
- **片段 POV**：恐怖片（杀手视角）、动作片（奔跑/坠落）、浪漫戏（凝视对方）

**在 AI 提示词中**：

```
POV shot, first-person perspective,
camera as character's eyes,
seeing what the character sees
```

**提示**：POV 在 AI 视频中容易被模型理解为"一个人举着手机自拍"。加 `not selfie`、`not vlog` 可以纠正。

## 五、光线与照明：光怎么打

> 本章覆盖照明方式——从经典的三点布光到极端的明暗对照，再到当代的霓虹美学。光决定了画面 80% 的情绪。

### 5-1 三点布光

**物理层面**：三点布光（Three-Point Lighting）是电影布光的**基本骨架**，由三盏灯构成：

```
               [ 背光 / Rim Light ]
                      │
                      │ 从后方斜上方照亮头发和肩膀轮廓
                      │ 把人物从背景中"剪"出来
                      ▼
   [ 主光 / Key Light ]──────▶ [ 人物 ] ◀────── [ 辅光 / Fill Light ]
   主要光源，决定阴影方向          │           减弱暗部阴影，控制反差
   通常位于人物前方 45°                           通常在主光对面，亮度更低
```

组件作用强弱变化的效果**主光（Key Light**）主要光源，决定阴影方向和画面基调强 = 戏剧性；柔 = 自然感**辅光（Fill Light**）减弱主光造成的暗部，控制反差弱/无 = 强烈对比（chiaroscuro）；强 = 柔和明亮**背光（Rim/Back Light**）从后方照亮轮廓，把人物从背景分离强 = 神圣感/剪贴感；柔 = 微妙的 3D 感

**在 AI 提示词中**：

```
three-point lighting, dramatic key light,
soft fill light, subtle rim light              → 均衡的三点布光
single key light, no fill, deep shadows        → 单光源强烈对比（chiaroscuro）
rim lit silhouette, backlit figure             → 背光剪影
```

---

### 5-2 自然光

**物理层面**：自然光（Natural Lighting）= 只用场景中实际存在的光源——太阳、窗户、蜡烛、街灯——不使用电影灯具。这本质上是**一种哲学选择**而非技术限制。

光源类型色温视觉特征导演标志**金色时刻（Golden Hour）**\~3500K低角度暖金阳光，长阴影，皮肤发光泰伦斯·马力克**蓝调时刻（Blue Hour）**\~10000K日落后的深蓝天空，街灯初亮罗杰·狄金斯**窗户光（Window Light）**\~5600K柔和的侧光，荷兰画派质感维米尔 → 库布里克**烛光（Candlelight）**\~2000K极暖，极暗，光源在画面内可见库布里克《巴里·林登》**阴天（Overcast）**\~6500K整个天空是巨大的柔光箱——无阴影《哈利·波特》系列

**电影参照**：

影片自然光手法极限《荒野猎人》(2015)全程自然光——连对话戏都不补光每天只能拍 90 分钟金色时刻《巴里·林登》(1975)用 NASA 订制的 f/0.7 镜头拍烛光场景不需要一盏电影灯《生命之树》(2011)马力克的自然光 + 手持——阳光穿过树叶的光斑摄影机像自然的一部分

```
natural lighting, golden hour sunlight,
no artificial lights, practical lighting only,
window light, soft directional shadows
```

> 📖 关于色温的具体数值，见 \[\[#1-6 色温与白平衡|§1.6\]\]。

### 5-3 明暗对照（chiaroscuro）

**物理层面**：Chiaroscuro（意大利语"明-暗"）是文艺复兴绘画的概念，在电影中指**极强的主光和极弱的辅光造成的剧烈光影对比**。暗部近乎纯黑，亮部被精确控制。

**黑色电影（Film Noir）的照明基石**：1940s–50s 的黑色电影将 chiaroscuro 变成了一种类型语言——百叶窗阴影划过人脸、烟雾中的单光源、永远无法被完全照亮的世界。

**电影参照**：

影片chiaroscuro 应用《第三人》(1949)维也纳下水道的单光源追逐——光与暗就是追捕者与逃亡者《教父》(1972)Gordon Willis 的顶光照法——眉骨阴影遮盖眼睛，观众看不到灵魂《辛德勒的名单》(1993)黑白摄影 + 硬单光源——集中营的明暗就是生与死《小丑》(2019)亚瑟的公寓楼梯——半边脸亮半边脸暗，人格分裂不需要台词

```
chiaroscuro lighting, dramatic single light source,
deep shadows, strong contrast,
high key light, low fill, film noir aesthetic
```

---

### 5-4 霓虹黑色（neon noir）

**物理层面**：Neon Noir 是 chiaroscuro 的当代变种——用**霓虹灯和城市人工光源替代烛光和百叶窗**。暗部依然深沉，但亮部变成了品红、青蓝、钠黄。

**核心视觉配方**：雨夜 + 霓虹反射 + 摩天楼阴影 + 孤独的个体。

**电影参照**：

影片neon noir 特征《银翼杀手》(1982)定义了整个美学——雨 + 霓虹 + 飞行警车探照灯《银翼杀手 2049》(2017)升级版：橙色废土沙漠 + 蓝色霓虹城市 + 巨型全息广告《唯神能恕》(2013)曼谷的红色走廊 + 青蓝街灯——极端的冷暖色暴力《霓虹恶魔》(2016)时尚产业的霓虹噩梦——品红和青蓝把人变成塑料模特

```
neon noir aesthetic, rainy night street,
neon reflections on wet pavement,
cyan and magenta lighting, deep shadows,
lonely figure in futuristic city
```

## 六、色彩与调色：颜色怎么处理

> 本章覆盖后期色彩处理——从基本的橙青调色到不同胶片型号的天然色彩倾向。

### 6-1 色彩分级基础

**物理层面**：色彩分级（Color Grading）是后期制作中调整画面颜色、对比度和饱和度的过程。在 AI 视频提示词中，你不需要真正的达芬奇调色台——你只需要调用色彩分级的**视觉结果**。

**最常见的调色方案**：

方案英文关键词特征电影示例**橙青调**`teal and orange color grade`肤色偏暖橙，背景偏青蓝——人从环境中"跳"出来《变形金刚》《疯狂的麦克斯：狂暴之路》——动作大片全在使用**漂白留银**`bleach bypass`跳过漂白步骤，银盐保留在胶片上——低饱和 + 高反差 + 颗粒《拯救大兵瑞恩》(1998)——战场的褪色暴力**去饱和**`desaturated`降低色彩饱和度——接近黑白但不完全是《人类之子》(2006)——未来的灰色绝望**高饱和**`high saturation, vibrant`色彩极度饱和——超现实、波普感《爱乐之城》(2016)——歌舞片的色彩狂欢**暖色调**`warm color palette, amber tones`整体偏暖黄/琥珀——怀旧、浪漫《请以你的名字呼唤我》(2017)**冷色调**`cool color palette, blue tints`整体偏蓝/青——冷静、科技、疏离《社交网络》(2010)

```
teal and orange color grade, cinematic look      → 橙青大片调
bleach bypass, desaturated, high contrast        → 漂白留银
warm amber color palette, golden skin tones      → 暖色调
cool blue color palette, sterile atmosphere      → 冷色调
cross-processed, color shifted, experimental     → 交叉冲洗（正片用负片药水）
```

---

### 6-2 胶片色彩倾向

**物理层面**：不同胶卷型号有天然的"色彩性格"——在没有调色的前提下，柯达偏暖、富士偏绿、爱克发偏红。

### 6-4 增感冲洗（Push/Pull Processing）

**物理层面**：增感（Push）和减感（Pull）是胶片时代的"曝光 + 冲洗"组合操作——拍摄时故意按不同 ISO 曝光，然后在冲洗时调整显影时间来补偿。它不是后期调色，而是在**化学层面**改变胶片的颗粒、反差和色彩。

操作做法效果**增感 +1 档**按 ISO 500 曝光 250D 胶卷，延长显影时间颗粒变粗、反差增强、色彩饱和度略降、暗部偏移**增感 +2 档**按 ISO 1000 曝光 250D，大幅延长显影颗粒极度粗糙、高反差、色彩偏冷、暗部几乎死黑**减感 -1 档**按 ISO 125 曝光 250D，缩短显影时间颗粒更细腻、反差更低、色彩更柔和

**增感在电影中的应用**：

影片增感方式为什么《拯救大兵瑞恩》(1998)EXR 200T 增感至 400 + bleach bypass诺曼底登陆——极端颗粒+褪色=战地新闻的暴力真实《人类之子》(2006)Vision 500T 增感至 1000著名的车内长镜头——在极暗车内不用额外灯光，靠增感"硬吃"《黑天鹅》(2010)Super 16mm + 增感芭蕾后台的幽闭恐惧——粗颗粒让每一帧都神经质

**在 AI 提示词中**：

增感不是一个"滤镜"，而是一组颗粒+反差+色彩的联动变化。在 AI 提示词中调用它时，需要同时描述这三个维度：

```
push processed +1 stop, enhanced film grain,       → 增感 1 档：粗颗粒 + 反差增强
increased contrast, slightly desaturated,
richer shadow texture, gritty aesthetic

Kodak Vision2 250D pushed to ISO 400,              → Vision2 250D 增感至 400
warmer color shift, pronounced grain structure,
cinematic texture, tactile imperfection
```

> 📌 **组合提示**：`Kodak Vision2 250D + push to 400 + 1/2 White Pro-Mist` = 暖调日光 + 增感颗粒 + 高光融化感。这是构建"记忆质感"的完整配方。

核心追求：皮肤纹理、毛孔、微表情、材质反射、环境光散射——所有物理精度的上限。

### 7-3 真实物理效果

**Practical Effects** = 不要任何 CG / 视觉特效 / 后期制作痕迹——一切都在真实世界中物理存在。

在 AI 提示词中，这个概念通过大量"禁止"指令来实现（详见 \[\[#十、提示词工程：Style Lock|第十章 Style Lock\]\]）：

- 禁止光影特效、禁止后期调色、禁止非实际光源
