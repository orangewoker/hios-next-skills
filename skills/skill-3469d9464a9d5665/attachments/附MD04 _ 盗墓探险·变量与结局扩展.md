# 附MD04 | 盗墓探险·变量与结局扩展

**所属主SKILL：** 盗墓探险 · 夺宝迷踪 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 氧气/体力：counter，0-100，默认100；&lt;20陷入昏迷。
2. 机关破解度：counter，0-100，默认0；≥60成功解锁主线机关。
3. 古物收集：counter，0-10，默认0；用于兑换财富或触发特殊结局。
4. 小队信任：relationship，0-100，默认50；&lt;20触发队友背叛。
5. 煞气/瘴气值：risk，0-100，默认0；≥80出现恐怖幻觉。

道具与旗标

1. 摸金符/护身符：item，false；true可抵挡一次致命机关。
2. 古国地图：item，false；true可发现隐藏的密道。

### 二、结局体系（共15个）

正结局（5个）

1. E01·满载而归：破解所有机关，带出至宝。
2. E02·考古留名：放弃部分财宝，将古迹公之于众。
3. E03·死里逃生：在氧气耗尽前，炸开通道逃出生天。

坏结局（10个）

1. D01·长眠地宫：氧气归零。
2. D02·万箭穿心：破解机关失败。
3. D03·队友背刺：小队信任过低，被抢走物资。
4. D04·陷入癫狂：瘴气值过高，彻底疯癫。
