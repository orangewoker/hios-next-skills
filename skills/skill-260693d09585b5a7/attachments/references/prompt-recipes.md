# 图像编辑指令配方

不要机械复制整篇规则。根据事实表组合以下区块，只写与当前产品和模式有关的内容。

## 通用身份锚点

```text
把全部输入视为同一件真实商品的证据。严格保持可确认的品牌、LOGO、文字、图案、色块、标签尺寸与位置、包装版式、主色、结构比例和关键部件。不要重设计、补写文字或改变产品身份；未知表面保持未知，不虚构。
```

## 原角度精修

```text
保持原始拍摄角度、机位高度、产品朝向、透视和构图逻辑。只清理背景与环境色，修复轻度透视、曝光、噪点、锯齿和边缘，按部件还原真实材质并重塑克制的商业棚拍光影。结果应像同一张照片经过专业修图，不像重新生成的相似产品。
```

## V01 标准正视

```text
建立 V01 标准正视图：主展示面中心线正对镜头，水平旋转和俯仰均为 0°，使用中长焦商业摄影透视。保持真实高宽厚或直径比例。方盒正面四边规整且不明显露侧面/顶部；圆柱主视觉居中并让标签随真实曲率包裹。
```

## 标签贴模

```text
结构和比例采用白模/模型参考；包装文字、LOGO、图案、色块和版式采用标签或包装原稿；材质和颜色采用清晰实拍。让包装内容贴合真实平面或曲率，保持接缝和标签起止位置，不把标签平贴、漂浮、镜像或重新排版。
```

## 指定视角

```text
目标为 {视角编号与名称}。严格按该视角定义改变朝向和机位，只显示参考证据支持的表面。保持与 V01 相同的产品身份、比例、部件、材质、颜色、标签位置、摄影棚环境和画面占比。
```

## V05/V07 悬浮仰视

仅在目标为 V05 或 V07 时追加：

```text
让产品悬浮在纯白背景中，不使用桌面、展台或接触阴影。V05 保持正面居中且不水平旋转；V07 保持右前旋转 30°–45°，不得镜像成左前方向。降低相机形成仰视并清楚露出瓶底/产品底部；底部轮廓、凹槽、厚度、接缝和材质必须有参考证据，不得补造。
```

## 棚拍与背景

```text
使用纯白或接近 #FFFFFF 背景、1:1 画幅和均衡留白。除 V05、V07 的悬浮视角外，使用轻微自然接触阴影。使用前上大型柔光主光和弱辅助光。让每个部件按真实材质分别响应，白色不过曝、黑色不死黑，文字与 LOGO 不被高光遮挡。不要增加展台、植物、水花、人物、手、价格、营销文字或水印。
```

## 局部返修

```text
只修正以下失败项：{列出失败项和位置}。其余已正确的产品身份、结构、包装、材质、颜色、视角、构图和背景全部保持不变，避免重新生成整件产品。
```
