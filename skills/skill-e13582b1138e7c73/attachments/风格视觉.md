\# 风格与视觉库

\## 1. 六个识别支柱

1\. 调度：身体、门口、桌面、画外空间构成可读的权力关系。

2\. 构图：对峙双人、正面舞台式、侧面张力、群像纵深、中心权威等有明确功能。

3\. 光学：广角至标准视角为主，人物仍属于房间；根据距离、画幅和构图选镜。

4\. 色彩：以美术、服装和材质建立色彩归属，深黑与受控饱和度相互支持。

5\. 光线：有动机、有选择地照亮叙事信息，脸部、空间和黑暗形成层次。

6\. 节奏：延迟、试探、普通行为、突然强调与事件后的停留相互构成张力。

重要场景默认至少 4 项有明确证据，核心场景争取 5 项。静帧的时间节奏标为不适用，不凑分；基于其余适用项解释风格。全片持续六项满载会削弱强调。分数是内部复核工具，不是经过验证的作者识别指标。

\## 2. 六种子模式

| 模式 | 适用场景 | 色彩家族 | 构图、光线与节奏 |

|---|---|---|---|

| A 通俗犯罪 | 餐馆、公寓、酒吧、仓库、闲谈中的威胁 | 深黑、旧奶油、烟草棕、芥末黄、稀少深红 | 双人或舞台式构图；实景暖光与中性暗部；表面松弛、暗流紧张 |

| B 加州自然犯罪 | 日常街区、车内、停车场、安静关系戏 | 沙色、米色、灰蓝、灰绿、少量红 | 克制双人和肖像；自然但塑形；安静、隐性危险；不据此改写故事地理 |

| C 图形复仇 | 决斗、仪式化对峙、心理倒计时 | 黄、黑、白、血红；有理由才加入电蓝 | 硬几何、剪影、硬光；集中在转折点强调，保持动作因果 |

| D 年代威胁 | 历史室内、盘问、社会压迫、多方试探 | 木棕、奶油、炭黑、酒红、少量天蓝 | 桌轴、群像、中心单人；选择性室内光；延迟、窒息、爆发 |

| E 通俗西部 | 荒地、木屋、风雪、泥地与旅途对峙 | 土棕、脏奶油、黑、深红、冷天蓝 | 横向距离与人物间隔；硬日光或阴天分离；耐心、怀疑、冲击 |

| F 六十年代好莱坞流行 | 摄影棚、街道、名人空间、轻快惆怅 | 真红、绿、天蓝、奶油、暖肤、深黑 | 招牌、车身与街道色块；日照光泽与真实质感；流动较轻快，仍节制 |

模式规定色彩家族，不要求每镜出现所有颜色。严格保持世界一致，不为模式名称强加地域、年代或电影标志物。

\## 3. 二十种构图及执行蓝图

坐标以有效画面左上角为原点，x 向右、y 向下，均为归一化百分比。以下区间是起点，按人物数量、画幅和景别调整；不能让数值覆盖表演和剪辑需求。

| 编号／构图 | 几何与空间蓝图 | 使用与变化 |

|---|---|---|

| C01 中心权威 | 主体轴约 x50，眼线约 y40–45，克制头顶空间；垂直背景强化主体 | 权力凝固、宣告或揭示；由偏位走入中心比一直居中更有变化 |

| C02 对峙双人 | 双方分占左右，桌边或座椅划出交战区；保留关键手部和面部可读性 | 谈判、试探；一方前倾或占据桌面改变画面重量 |

| C03 侧面张力 | 两人约 x20–30 与 x70–80，相对侧脸；中心空隙按距离安排 | 不立即切单人；利用伸手、杯子或沉默侵入中间空白 |

| C04 正面舞台式 | 相对正面的固定机位；墙面、桌边形成稳定框架 | 演员在镜内移动；重构画面先于移动摄影机 |

| C05 群像画面 | 前、中、后层均有明确人物功能；关键视线与手势不互相遮挡 | 同场多议程；通过一人动作把注意力传给另一层 |

| C06 前景遮挡 | 近侧门框或肩膀占据一条边；中远景保留主要行为 | 窥视、秘密；遮挡应藏住特定信息，不能只是装饰 |

| C07 物件视点 | 摄影机位于抽屉、台面、容器或地板的观察位置；人物向镜头所在物件行动 | 少量强调；先确定镜头能否看到目标，避免穿透实体表面 |

| C08 极低权威 | 机位靠近地面，仰视身体或建筑上部；地平线偏低 | 威胁强调；保持头部和身体比例可接受，不常态化 |

| C09 面部地形 | 眼、皮肤、嘴角占据主要面积；根据目的裁切头顶或下巴 | 当面部变化本身成为事件；保留纹理与不对称 |

| C10 带环境近景 | 主体靠近摄影机，背景空间关系仍可辨；焦段与距离联合选择 | 人物存在感与房间关系并存，禁止把“40/50mm”当跨画幅通用答案 |

| C11 门框权力 | 门框形成第二层边界，人物占门内或门外，出口保持位置可识别 | 控制出入；角色穿过门槛时改变支配关系 |

| C12 桌轴对峙 | 桌长边或纵深线连接双方，重要道具在可识别区域；摄影机位于已锁定轴线一侧 | 交涉与物权转移；插入镜也继承杯子、手和文件的位置 |

| C13 镜面信息 | 同时规划真人、镜面和反射视线；反射只显示按几何可见的空间 | 隐藏观察者或双重信息；必要时先简化为一个主要反射主体 |

| C14 三角权力 | 三人的屏幕位置组成不等边三角；让距离、遮挡和视线表明联盟 | 一人靠近或转向改变联盟；避免三人等距且功能不分 |

| C15 边缘威胁 | 主要人物清晰，威胁位于侧缘或后缘，预留进入路径 | 观众先发现危险；移动不能遮住主要反应时刻 |

| C16 负空间等待 | 人物偏在一侧，另一侧保留具名的入口、空椅或预期目标位置 | 让观众等待事件进入空白；不把无意义留白算悬念 |

| C17 横向列队 | 人物沿横向形成可辨剪影，脚步或身体朝向具有统一或有意错开的节奏 | 群体亮相和讽刺性自信；轮廓不融合成黑团 |

| C18 纵深走廊 | 通道或桌边汇入深处，近远人物各有动作职责；入口终点可识别 | 被观察、逼近与退路；跟踪运动维持近远层变化 |

| C19 窗内外分层 | 窗框限定内外空间；明确玻璃反光、透射、人物所在侧及两侧亮度 | 隔离与观看；反光不能无理由覆盖关键信息 |

| C20 细节标点 | 手、食物、钱、开关或关键道具占据阅读中心；保留方向或接续动作依据 | 必须交付因果信息或感官节拍；用完返回关系画面 |

同一镜头可由 C02 演变为 C01，再让另一人形成 C06。写明动作触发和结束状态，不必为每次构图变化新增剪辑。

\## 4. 光学家族

先决定摄影机位置、主体距离和所需视野，再选有效画幅与焦段。透视关系依赖观察位置；焦段改变视野，不单独决定“压迫感”。保留原版家族名称，但不混用其尺寸假设。

\- F1：35mm 胶片球面质感。必须声明模拟的有效成像区域；原版 24–32／35–40／50／65–75mm 为该风格工具的候选集合，不是任意画幅上的等效表。

\- F2：变形宽银幕。声明有效尺寸、挤压倍率、解压及裁切；不把 50mm 变形镜与 50mm 球面镜写成相同横纵视野。

\- F3：Super 35 数字／胶片混合意图。声明有效尺寸和最终裁切；按人物距离、视野需求选择实际焦段。

\- F4：65mm／大画幅社会空间。声明具体有效尺寸，匹配所需视野与景深；不为“大画幅”自动使用极浅焦点。

未知时默认 F1 球面质感，使用明确的模拟有效区域，保留广角至标准、环境可读的倾向；不用未经核验的品牌型号制造精确感。完整光学字段见专业镜头卡。

普通对白可从 T2.8–T5.6 的透光意图起步，景深仍需结合 f 值、距离和画幅核对；群像优先满足必要清晰层，心理断裂才选择浅景深。以上是创作默认，不是平台可控旋钮。

\## 5. 八种灯光结构

所有光型均需填专业镜头卡的光源位置、尺寸距离、覆盖、亮暗关系和色温。此库负责选择，不代替执行参数。

| 编号 | 结构 | 空间和光线逻辑 |

|---|---|---|

| L01 侧光塑形 | 一侧主光、克制补光或负补光 | 确定哪只眼、哪侧脸和手被照亮；背景可比脸低约 0.5–1.5 档，按材质调整 |

| L02 选择性顶光室内 | 上方灯池覆盖头肩和桌面 | 眼窝允许暗，但剧情需要的目光不能无意丢失；墙角保留暗区 |

| L03 热日光／暗室 | 窗外亮、室内有重量 | 先决定窗外是否需保留细节；用反射或窄区补光保护关键脸部，不把室内压成黑洞 |

| L04 实景暖光／深影 | 台灯、壁灯、餐馆灯具解释局部暖光 | 实景灯方位与脸部受光一致；暖色有归属，中性暗部保留层次 |

| L05 图形硬光高潮 | 硬边、剪影、简化色块 | 为一次揭示或爆发集中强调；随后恢复克制，不让全场变灯光秀 |

| L06 自然犯罪光 | 天空、橱窗、车窗和真实环境反射 | 自然中保留脸部结构、肤色和衣服分离，不能等同无设计平光 |

| L07 西部外景反差 | 日光或冷天光定义空间 | 帽檐、外套、风雪或尘土轮廓清楚；保持时间、天气和阴影方向 |

| L08 心理暗化 | 同一镜内缓慢压低选定背景区 | 写明起止秒与亮度变化，人物主曝光稳定；属于有意设计，不允许被当作随机曝光闪烁 |

可读不等于照亮全部：只保护叙事需要的脸、物件和空间。反过来，深黑不等于抹掉衣服、动作或逃生路线。

\## 6. 色彩与材质

参考锚点：深黑 #0A0A09；烟草棕 #4B3426；旧奶油 #D2C29D；芥末黄 #B58A22；深红 #8A1716；灰绿 #465847；天蓝 #6D94B3；酒红 #5C2028；脏白 #E2DDD0。HEX 只作沟通参照，不要求光照后逐像素一致。

每镜选择约 2–4 个主要色彩角色：环境基底、结构辅色、人物身份、危险或揭示强调；中性材质不必凑成另一主色。肤色按人物本身维护，不用一个固定 HEX 统一不同肤色。

分别记录：面积占比、明度、饱和度、画面位置、材质／反射／光源归属和出现时间。若采用互斥面积角色，填写的一组实际占比合计 100%；不要把注意力强度当像素面积，也不要将几组独立范围宣称已经合计 100%。

一枚小红物件可以面积小而注意力高。角色身份颜色跨镜稳定，画面分布可以随景别和权力变化。变装、污染、损失等色彩变化必须有剧情依据。

空间写明墙、地、桌、椅、灯、招牌、玻璃、布料、车内材料；每场只选一两个真正有记忆点的美术元素。磨损、汗、木纹、玻璃反射应服务时间与生活痕迹，不随机增加污渍。

\## 7. 摄影运动、机位与节奏

常态优先：固定 → 摇／俯仰 → 有理由的慢移 → 横向跟移 → 特定揭示中的升降。特殊强调：急变焦、甩镜、快速移动、局部手持；物件视点与极低机位属于位置设计，不再误列为运动类型。

运动必须交代揭示新信息、关系改变、空间重定义、角色取得控制或爆发的理由。没有理由就固定。禁止默认环绕、漂移和所有镜头慢推。

视平线用于观察和对峙；略低或略高需结合关系解释；极低、俯顶、物件视点控制频率。左右行进方向只是一致性线索，不能普遍等同“正义／邪恶”或固定心理含义。

切镜可由信息、决定、反应、空间变化或有意隐藏触发，不机械跟着每句对白切。特写需要明确戏剧功能；关键信息读取、情感裂缝或必要动作本身即可成立，不机械要求满足两项相互重叠的条件。

优先从关系画面发展到延迟单人或近景。长停留期间仍需存在聆听、策略、视线、道具或画外声音变化。没有变化的空耗时长不算张力。

强度 0–5：观察／经典呈现／受控风格化／主动紧张／强调／图形爆发。可以中途放松、误导和再攀升；事件后恢复简单画面与声音。不是每片必须暴力或从 0 升到 5。

\## 8. 强调手法预算

预算单位是一个连续戏剧段落，不按生成次数或文件数量计算。拆成多个 CL 不刷新预算。

基础双人、深黑、色彩分离、中等景深和普通中心构图不收费。预算只约束显著强调事件：

\- 中心英雄式揭示或刻意列队亮相：每个事件 1 分。

\- 物件视点、极低权威、急变焦、甩镜、明显硬光突变、媒体画幅插入：每个事件各 2 分。

\- 同一次事件跨片段只计一次；同一手法在不同事件重复出现分别计费；同一事件叠加不同手法累加。

\- 普通对白段建议 0–2 分；强张力段 2–4 分；核心揭示或高潮 4–6 分。属于复核阈值，不是必须用满的配额。

\- 超出时先减少装饰性手法；若多项都服务同一明确转折，可保留并说明为何需要，检查全片是否过密。

\## 9. 声音、字卡与反套路

保留鞋声、衣料、纸、杯盘、呼吸、引擎和房间底噪。音乐可晚入、骤停、跨场承接或与表面行为形成反差，写明出入点。静默通常是声音场收缩，不是默认删除所有环境声。

硬切、声音桥、音乐延续、突切、章节卡、图形或道具匹配、时间跳跃均可使用；每个转场要有作用。字体家族、排版、字卡配色和持续时间纳入全片锁定；没有章节需求时不强加章节卡。

禁用默认黄旧滤镜、全片橙青、全镜奶油散景、塑料磨皮、无动机 RGB、重雾光束、假划痕和 VHS 损坏。不要自动加入黑西装、武士刀、后备厢或霓虹。写实人物保留皮肤、胡茬、汗和细微不对称；无血腥场景也能通过对白和调度保持风格。

\## 10. 画幅与跨场统一

2.39:1 沿用为默认电影构图；1.85:1 可用于明确选择的自然犯罪项目；2.76:1 只用于特别需要横向社会空间的方案；1.33:1 可作为剧情内旧电视或档案媒介。16:9 与 9:16 由用户目标覆盖选择。所有比例都是创作选项，不是即梦支持列表。

每个项目只有一个主要有效画幅。片中切换比例须有具名的叙事或媒介理由，并在时间线记录，不能因为模型输出不同就默默变幅。风格家族、肤色、颗粒、高光、黑位、服装及世界材料跨地点保持一致；变化需来自剧情或明确的场景条件。
