## 1. 场景毛绒化的核心思路

把整个场景——建筑、家具、植物、天空、地面——全部替换为毛绒材质，创造一个"毛绒世界"。场景毛绒化常用作产品或角色的背景，也可以独立成画。

关键判断：场景中哪些元素最需要毛绒化？
- 主体是产品/角色 → 背景轻度毛绒化（虚化、简化），主体重度毛绒化
- 场景独立成画 → 全要素毛绒化，每个元素都要有质感差异

## 2. 场景元素毛绒化清单

| 元素 | 毛绒化方式 | 绒毛类型 |
|---|---|---|
| 建筑/墙面 | 轮廓圆润化，表面绒毛覆盖 | 短绒密实 |
| 家具（沙发/桌椅） | 比例圆润化，填充感蓬松 | 中绒饱满 |
| 植物/树 | 树冠蓬松炸毛，叶毛绒化 | 长绒飘逸 |
| 地面/草地 | 铺面绒毛感，短密均匀 | 短绒密实 |
| 天空/云 | 云朵蓬松毛绒球，天空色彩柔和 | 中绒蓬松 |
| 道路 | 带状绒毛铺面，边缘圆润 | 短绒 |
| 水/河流 | 波纹化为绒毛起伏，色彩保留 | 短绒丝光 |
| 山丘 | 圆润起伏，表面绒毛覆盖 | 中绒 |

## 3. 空间深度与景别

- **全景**：展示整个毛绒世界全貌，适合TVC开场或独立场景画。注意前景/中景/远景的绒毛密度递减，制造空气感。
- **中景**：毛绒角色/产品在毛绒场景中互动，场景占画面60%左右。
- **近景/特写**：聚焦某个毛绒化场景细节（如一朵毛绒云、一棵毛绒树），绒毛质感要极致。

## 4. 配色与氛围

- **治愈系**：奶白、蜜桃、薄荷绿、薰衣草紫，柔光均匀，无强对比
- **活力系**：鹅黄、珊瑚橙、天空蓝，明亮光照，色彩饱和
- **暖冬系**：焦糖、奶咖、暖红，侧逆暖光，绒毛边缘金色轮廓光
- **梦幻系**：粉紫渐变、珠光白、星光点缀，柔和发光，带微光粒子

## 5. prompt 句式库

### 全景毛绒场景
```
Q版卡通毛绒风格全景场景，整个世界由毛绒材质构成，毛绒化的圆滚滚山丘起伏，毛绒化的蓬松树木散布，天空飘着毛绒云朵，地面铺满短密绒毛草地，远景绒毛密度递减制造空气感，治愈系奶白蜜桃配色，柔和均匀天光，1:1画幅
```

### 产品+毛绒场景（种草图）
```
Q版卡通毛绒风格场景，@图片1所示的产品变成毛绒形态坐在毛绒化沙发上，沙发蓬松中绒质感，旁边有毛绒化抱枕和毛绒化小台灯，侧逆暖光，暖冬焦糖奶咖配色，场景占画面60%，产品居中偏左，3:4画幅
```

### 毛绒城市（TVC开场）
```
Q版卡通毛绒风格城市全景，建筑全部圆润化覆盖短绒材质，毛绒化的道路蜿蜒，毛绒树木排列街道两旁，天空毛绒云朵漂浮，活力系鹅黄珊瑚橙配色，明亮天光照射，绒毛边缘有光泽，16:9画幅
```

## 6. 落 prompt 前自检

- 场景元素是否全部毛绒化（没有遗漏的写实元素）？
- 主体与背景的毛绒密度是否有层次区分？
- 景别是否明确（全景/中景/特写）？
- 配色氛围是否与用途匹配？
- 前景/远景的空气感是否写了？
- 参考图是否正确引用（如主体有参考图）？
