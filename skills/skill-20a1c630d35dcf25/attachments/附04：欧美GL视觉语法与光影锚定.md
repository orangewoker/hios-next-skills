# 附MD04 | 欧美GL视觉语法与光影锚定

## 做什么

锁定欧美GL赛道的视觉DNA，确保全片光影、色彩、质感统一，符合欧美市场审美。

## 需要什么输入

- 参考作品（如《卡罗尔》《杀死伊芙》《绅士杰克》）
- 双女主各自的空间属性（冷蓝权力 vs 暖金冲动）

## 怎么做

1. 遵循主MD全局路由表与绝对工作流铁律。
2. 全片锁定冷蓝+暖金对比色调，权力方场景用冷蓝，冲动方场景用暖金，同框时色调交融。
3. 多用镜面反射、玻璃倒影、雨夜车窗，用视觉代替台词表达暧昧。
4. 道具承载情感：手表、加密日记、枪、戒指，每件道具必须有双重含义。
5. 全片禁止直白说“我爱你”，用眼神、触碰、枪口相对代替。
6. 强制写入光影统一预锁指令：保持环境光源方向、色温与上一镜头完全一致。
