# 附MD05 | 末世废土·分支剧情树模板

**所属主SKILL：** 末世废土 · 生存 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“剧情线混乱、分支无收束、假选项泛滥”的痛点。

## #需要什么输入

主线剧情节点清单、核心抉择点设计。

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·废墟苏醒（start节点）
2. N02 抉择点1·发现物资（branch节点）
   - N02A 独吞物资（人性-10，物资+20）
   - N02B 分给难民（人性+10，声望+10）
3. N03 危机爆发（normal节点）
4. N04 抉择点2·面临变异体（branch节点）
   - N04A 战斗路线（锁定战斗线）
   - N04B 潜行路线（锁定潜行线）
   - N04C 逃跑路线（锁定逃亡线）
5. ENDING_CHECK 结局判定

### 三、分支收束铁律

1. 每一章末尾必须收束回主线。
2. 关键选择后路线锁定。
3. 单章分支层级不超过3级。
4. 零假选项：每个选择必须改变至少一项变量。

### 四、灵魂七问（必过审）

1. 玩家为什么选它？
2. 它改变了什么？
3. 即时后果是什么？
4. 延迟后果在哪个节点出现？
5. 是否可能造成独特失败？
6. 是否只是换台词？
7. 是否与世界规则一致？
