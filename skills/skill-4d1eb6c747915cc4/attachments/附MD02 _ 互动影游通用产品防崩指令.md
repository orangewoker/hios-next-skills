## #做什么

本模块为互动影游中涉及实体产品的通用防崩参数库。

解决AI生成实体产品时“金属色号偏移、材质塑料感、手部穿模、产品比例失真、锦盒透视错误、手部动作畸形”的痛点。本模块只锁定所有互动影游中实体产品的通用防崩底线，具体产品参数由子级扩展。

## #需要什么输入

**最少提供：**

- 实体产品类型（如手镯、戒指、项链、道具等）
- 产品主色与材质要求
- 产品物理尺寸或比例参考

**可选提供：**

- 锦盒/包装盒样式
- 手部动作需求
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。产品防崩环节重点参考【提示词】底座的物理光学参数，确保产品材质与光影完全对齐。

### 二、防崩色号（黄金/金属类通用）

1. **足赤金**：色值 #D4AF37；用途为金属产品主色。
2. **暖金拉丝**：色值 #CFB53B；用途为金属拉丝质感。
3. **暗金**：色值 #B8860B；用途为金属阴影处。

**禁止色**：银白、铂金、冷灰、亮白。

### 三、材质防穿模

1. 金属表面必须拉丝、哑光、氧化痕迹。
2. 禁止塑料感、光滑无瑕。
3. 手部与产品之间留有自然缝隙。
4. 产品与皮肤不得融合。

### 四、物理比例锁定

1. 手镯内径约6厘米（或按实际数据）。
2. 手镯与手腕之间留有一根手指的缝隙。
3. 手镯在手腕上自然垂直，不紧绷、不松垮。
4. 禁止手镯缩小成戒指尺寸。
5. 禁止手镯放大成巨型环状物。
6. 保持1:1真实物理比例。

### 五、锦盒物理坐标系

1. 锦盒为经典横开式。
2. 铰链固定在远离镜头一侧。
3. 盒子由下方向后方翻开。
4. 开口正面朝向镜头方向。
5. 禁止盒子侧翻、透视错误、前后颠倒。

### 六、手部动作防崩

1. 每个镜头只做一个单一动作。
2. 禁止多个复杂动作在同一秒内完成。
3. 手部动作必须有物理因果链。
4. 禁止手指弯曲畸形、断指、多余手指。

### 七、材质描述强制词

**正向必加：**

- 足赤金、哑光暗金、暖金色拉丝金属
- 通体浑然一体的高级暖金色
- 无拼接感、零银白、零铂金、零冷灰

**反向禁止：**

- 禁止白色金属、银白反光
- 禁止冷白杂色、灰白质感
- 禁止塑料感、光滑无瑕

### 八、子级扩展规则

子级可在此母级基础上追加专属产品参数：

- 子级A（洪荒西游）：追加金箍棒、斩仙刀等专属道具参数。
- 子级B（乙女影游）：追加戒指、项链等情感信物参数。
- 子级C（悬疑互动剧）：追加线索道具、证据物品参数。
