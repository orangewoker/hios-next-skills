# 武打专项

> **定位**：打斗/搏杀/追逐分镜的专用 Prompt 库。Phase 2 含武打场景时按需加载。

## 核心规则

- 镜头密度：≥ 8 镜/15s，短镜 0.5-1.5s
- 接触时刻：L4-L5 特写
- 力度传递：烟尘/碎片/血迹/肌肉动态等视觉元素
- 空间方位：固定机位+固定站位+统一攻击方向，禁止跳轴

## 四类 Prompt

### 兵器交锋
```
两角色以[兵器]交战，[角色A]侧身斩击→[角色B]格挡金属碰撞火花四溅，
接[角色A]借力转身第二击，全程跟拍运动轨迹，L4特写接触瞬间，慢动作定格命中帧
```

### 拳脚格斗
```
近身缠斗，[角色A]右勾拳击出→[角色B]侧闪同时膝顶反击，
肢体接触时肌肉绷紧+汗珠飞溅，L4特写拳面接触腹部瞬间，背景模糊强调速度感
```

### 群战
```
[角色A]被多人包围，连续格挡三人攻击→借力翻滚突围→起身反击，
镜头环绕跟拍，每段攻防 1-1.5s 短镜快速切换，打击点烟尘扬起
```

### 轻功/身法
```
[角色]踏[物体]借力腾空，衣袂翻飞，空中旋转→落地无声，
仰拍角度强调高度，慢动作定格格空中姿态，背景虚化速度线
```

## 景别节奏

| 景别 | 占比 | 用途 |
|:---|:---:|:---|
| 远景/全景 | 20% | 建立地形/展示招式全貌 |
| 中景 | 30% | 双方交互/场景调度 |
| 近景/特写 | 50% | 关键打击/接触瞬间/表情 |
