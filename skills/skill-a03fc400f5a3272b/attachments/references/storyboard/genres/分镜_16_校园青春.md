# 校园青春风（Youth & Campus）分镜指令库

> **主打风格**：明亮通透、生活质感、青春气息，强调光影的温暖和角色的自然互动。
> **加载时机**：`/分集 {N}` Phase 2 时，若题材判定为校园 / 青春 / 初恋 / 同学，加载本文件复用分镜。

| 分镜名称 | 完整指令 |
| -------- | -------- |
| **操场追逐** | 跟拍长镜头，午后金色阳光洒满塑胶跑道。逆光中，少年白色的校服被风吹得鼓起如帆，他的轮廓在金色光晕中奔跑——鞋底与红色跑道摩擦溅起的细小橡胶颗粒在阳光中悬浮。前方少女的马尾辫随奔跑的节奏左右甩动，侧脸的碎发粘着汗珠在光中闪烁。 |
| **天台告白** | 侧面半身近景，傍晚暖橙色的"魔幻时刻"光线。学校天台的铁丝网上挂着一个易拉罐，风吹过发出清脆的碰撞声。少年靠在铁丝网上，半张脸被落日染成暖橘色，另一半隐在建筑的阴影中。他的嘴唇微微张开又合上，喉结上下滚动，手指死死攥着校服下摆——对面少女的帆布鞋在画面边缘轻轻踢了一下地面。 |
| **考场偷瞄** | 主观视角+浅景深，考场日光灯的冷白光线。镜头模拟偷瞄的角度，从试卷边缘斜向望向隔壁桌——模糊的前景是自己的考卷和握笔的手，焦点在对面那个正咬着笔帽皱眉思考的侧脸上。她的笔在草稿纸上画着无意识的圈圈，橡皮屑散落在桌角。监考老师走动的脚步声仿佛在空气中制造微弱的震动波纹。 |
| **图书馆偶遇** | 书架间的缝隙视角，透过两排书架的缝隙拍摄。暖黄色的阅读灯下，两只手同时伸向同一本书——一只手修长白皙，另一只手指节分明带着淡淡的墨水印。两人的视线从书脊上方相撞，书本从书架上滑落，在安静的图书馆里发出闷响，周围翻书的声音短暂停顿。 |
| **毕业离别** | 俯拍全景，阴天的漫反射柔光。空荡荡的教室里，课桌上还残留着没擦干净的涂鸦和用圆规刻的爱心。一把椅子的靠背上挂着校服外套，衣袖在穿堂风中轻轻摆动。地面上散落着碎纸片和几支没有帽的笔——画面中没有一个人，却充满了"人刚走"的缺席感和青春散场的怅然。 |
