## #做什么

本模块为“戏剧张力分析体系”的参考样例库，不新增强制规则、不替代其他规则模块。

本模块只回答一件事：规则落地执行出来应该是什么样子。

AI仅可模仿其中的推理逻辑、分析链路、镜头转译思路，禁止直接复制示例内剧情、台词。

### 案例一：普通对话为什么不能拍成流水账

**适用题材：** 家庭情感·日常对话·任何B/C级过渡戏

**原剧本通用版：**

女儿回家。母亲问：“怎么这么晚才回来？”女儿说：“加班。”母亲说：“吃饭了吗？”女儿说：“吃过了。”

**错误执行：**

人物进入房间 → 母亲提问 → 女儿回答 → 母亲提问 → 女儿回答 → 两人离开。

**问题：**

台词完整，但没有挖掘文本下的潜信息，对话沦为单纯信息播报，无戏剧驱动力。

**正确戏剧分析：**

层级内容表层母亲询问女儿晚归原因中层母亲真正在意的不是时间，是女儿是否遭遇麻烦深层女儿在隐瞒实情，不想被母亲察觉

“加班”这句回答本身就是一次掩饰行为。

**镜头转译思路：**

母亲：“怎么这么晚才回来？”\
女儿：“加班。”

不要立刻切镜头。\
女儿说完保留短暂停顿；母亲打量女儿；女儿回避视线，低头脱外套。\
镜头重点不落在“说出台词”，落在：母亲是否相信、女儿的回避姿态。

**戏剧结果：**

观众生出好奇心——她到底在隐瞒什么，把普通家庭对话生成观看驱动力。

### 案例二：同一句台词，信息差不同，戏完全不同

**适用题材：** 悬疑·谍战·任何需要信息差设计的场次

**台词：** “你终于来了。”

情况信息结构镜头策略戏剧效果A：双方互相预知对方到场对称信息，张力低如实呈现见面即可，不刻意制造悬念普通会面B：观众提前看见B已到场，A毫不知情观众知·A不知先给观众看见B的镜头，再切到A说台词强悬念C：B清楚自己的来意，观众完全不知情B知·观众不知刻意隐藏B的真实目的，只保留人物细微异常反应悬疑感

**核心结论：**

同一句台词，信息差的三维结构（A已知 / B已知 / 观众已知）决定了这场戏的全部镜头策略。

### 案例三：对峙戏，如何判断场上的输赢态势

**适用题材：** 职场权谋·悬疑·婚姻情感·任何对峙场次

**原剧本通用版：**

甲：“你不是说那天晚上没见过他吗？”\
乙：“我确实没见过。”\
甲：“那这个是什么？”甲拿出照片。\
乙沉默。

**三层输赢拆解：**

层级内容第一层输赢甲抛出证据，暂时占据场上主动第二层信息变化乙看到照片选择沉默，没有立刻反驳，引导观众怀疑她在撒谎第三层潜台词甲内心诉求：确认对方是否一直在欺骗自己；乙内心恐惧：对方是不是已经掌握全部真相

**戏剧张力核心：**

不在于“甲掏出照片”这个动作，而在于：看到证据后乙的反应，以及甲观察乙反应的双向博弈。

**镜头优先级：**

照片特写 → 乙的面部反应 → 甲观察对方神态。

而不是只机械拍摄掏照片的手部动作。

### 案例四：有效反转，拒绝空降底牌

**适用题材：** 职场逆袭·悬疑反转·任何需要反转的场次

**错误写法：**

前期主角持续被打压，毫无铺垫，突然掏出合同：“其实一切都在我的计划之内。”

**问题：**

属于作者外挂，没有前置伏笔，反转不成立。

**正确写法：**

步骤内容观众状态① 前置预埋主角曾经翻阅这份合同，但不解释用途看见但不理解② 隐性铺垫主角向律师提出一句看似无关的问题觉得是普通对话③ 暗示台词面对对手逼迫，主角不摊牌，只抛出：“你确定要我签？”隐约感到不对劲④ 反转落地合同发挥决定性作用，局势彻底翻转回看所有细节，逻辑闭环

**逻辑链路：**

前置隐晦细节 → 当时无法理解 → 后期重新解读 → 局势反转。

**反转三大黄金标准自检：**

- 前有预埋：合同·律师问题·暗示台词。
- 后有局势巨变：控制权易手。
- 无空降证据、无机械外挂。

### 案例五：强节奏短剧“假输”戏份处理

**适用题材：** 职场强节奏短剧·复仇剧·任何需要假输铺垫的场次

**场景：** 反派逼迫主角签署文件。

**错误拍法：**

主角直接爆发站起来：“哈哈，其实我赢了！”随即拿出证据反击。

**正确拍法：**

阶段画面镜头策略压迫段主角低头做出签字姿态固定近景，不给主角内心提示误判段反派心态逐步放松，在场所有人认定主角落败切群体反应，反派居高仰拍离场段反派丢下台词：“你再也没有翻身机会。”主角不作回应，保留停顿留钩段反派完全离开后，主角缓缓抬头，目光落在刚签好的文件上，切场近景静止，不输出台词，切黑

**戏剧链路：**

压迫 → 假性失败 → 观众怀疑 → 留存好奇 → 下一场再揭露底牌。

### 案例六：高冲突场景，懂得使用静止张力

**适用题材：** 家庭情感·悬疑·任何S级高压戏的情绪爆发节点

**场景：** 父亲得知儿子就是当年事故责任人。

儿子：“爸……”\
父亲沉默不语。

**错误拍法：**

急促推镜、高频快切父子、背景音乐瞬间爆发，镜头语言过载，破坏沉静张力氛围。

**正确拍法：**

动作镜头处理儿子站在原地固定全景，两人之间保留空间距离父亲缓缓放下手中杯子固定不切，长时间留白停顿儿子想要开口解释近景，嘴唇微动但未出声父亲抬眼看向儿子近景对视，依旧一言不发

**戏剧逻辑：**

观众清楚父亲已经知晓真相，但不知道后续走向是原谅还是决裂。静止本身就承担悬念功能。

### 案例七：场景结尾钩子接力，不要事件结束戏就结束

**适用题材：** 连续剧·任何需要追剧钩子的场次结尾

**错误处理：**

二人争吵收尾，甲说完：“那就这样吧。”乙离场，本场直接结束。本场矛盾解决，没有留给观众新疑问。

**正确处理：**

步骤内容争吵结束乙准备离开意外发现乙偶然看见桌上一张照片钩子落地拿起照片，看见背面标记的日期，神色骤变，直接切往下一场

**效果：**

本场冲突暂时了结，立刻抛出新疑问——这个日期代表什么，完成钩子接力，维持观众继续观看的欲望。

**钩子接力公式：**

本场矛盾解决 → 最后5秒抛出新信息 → 不解释 → 切黑。

### 案例八：最小有效戏剧单元拆解

**适用题材：** 任何题材·任何一场对话戏的自检工具

**原剧本：**

甲质问乙：“钱呢？”\
简单回答“花了”就结束，戏剧信息量极低。

**拆解为最小有效戏剧单元：**

步骤内容① 目标甲想要查清钱款去向② 阻力乙不愿意吐露实情③ 行动甲持续逼问④ 反馈乙刻意回避话题⑤ 新信息出现甲留意到乙手上的伤口⑥ 局势改写甲意识到钱未必是挥霍掉，背后另有隐情⑦ 生成新驱动力钱到底去哪里了？

**结论：**

一句简单问话，升级为完整有效戏剧片段。

**自检口诀：**

目标 → 阻力 → 行动 → 反馈 → 新信息 → 局势更迭。

六步不满足 = 流水账 = 必须放大隐性戏剧。

### 案例九：镜头翻译戏剧，而不是单纯记录动作

**适用题材：** 任何题材·任何涉及道具传递 / 信息揭露的分镜

**原剧本：**

女生把手机递给男生。

**错误镜头：**

单纯中景记录：女生递手机，男生接过手机，镜头结束，只复刻物理动作。

**正确推理判断逻辑——根据戏剧内核选择镜头重心：**

戏剧内核镜头重心镜头顺序手机内容是核心证据手机屏幕内容手机特写 → 男生看到内容后的表情变化重点是女生敢于交出手机这个行为本身女生递出的决心 + 男生的犹豫女生递手机 → 男生犹豫迟疑 → 男生接过 → 女生观察男生神态这是一场试探博弈女生的眼神微表情手机动作虚化处理，近景给女生眼神

**核心准则：**

镜头服务戏剧信息，而不是机械照搬剧本动作。

### 案例十：完整戏剧张力卡参考样例

**适用题材：** 职场权谋·董事会博弈·任何S级高压核心戏

**场次：** 董事会会议——甲方CEO面临被罢免。

**【本场核心瞬时目标】**

主角阻止董事会罢免自己CEO职位。

**【核心阻力 / 悬念支撑】**

董事会手握对主角不利证据，主角不清楚证据具体内容。

**【风险代价】**

丢失CEO岗位，公司控制权易手。

**【五大张力维度适配情况】**

维度内容欲望保住职位阻力董事会团体风险丧失控制权信息差董事会掌握完整证据，主角不知情时间压力马上就要开展投票表决

**【三维信息差】**

角色已知信息主角不清楚完整证据董事会全部知情观众仅知道对方持有证据，不知道证据细节

**【人物攻防链路】**

试探 → 质询 → 回避 → 放出部分证据 → 主角误判局势 → 董事长准备发起表决。

**【潜台词解析】**

人物字面台词真实意图董事长“我们只是依规执行公司制度。”夺取控制权主角“我愿意接受董事会调查。”不清楚对方底牌，不能贸然亮出自己的筹码

**【情绪曲线】**

平静 → 察觉异样 → 警觉 → 判断失误 → 遭受压制 → 表面顺从 → 暗藏反击计划。

**【开场 / 结尾局势对比】**

时间点局势开场主角自认为掌握主动权结尾董事会距离夺取控制权只差表决一步

**【表层输赢 / 深层输赢】**

层面结果表层主角落入下风深层真相暂不揭晓

**【观众认知变化】**

初始：主角应该可以化解危机。\
转变：主角有可能真的会输掉一切。

**【本场核心张力节点】**

绝境假象。

**【下一场钩子驱动力】**

明明已经濒临落败，主角为什么依旧没有出手反击？

**【镜头重点表现】**

董事会群体站位空间张力、证据文件特写、主角一瞬间失神、董事长从容神态。

**【场景张力等级】**

S级。

## #什么时候问你

- 剧本或场次信息不足，无法判断该参考哪组案例。
- 题材、类型、短剧 / 电影模式不明确。
- 场次等级无法判定。
- 用户要求直接复制案例剧情、台词、人物关系。
