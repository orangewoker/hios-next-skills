## 一、意境/空镜段总纲（PPT感的免疫针）

**PPT感的本质：起幅帧与落幅帧找不不同。** 意境片的高级感不靠"不动"，靠"大静中有明确可见的变化"。每条意境/空镜段必须完成三件事：

1. **状态改变≥1**：运镜构图漂移/光影事件/元素状态改变/主体事件/视线牵引点移动——五选一，写"从X到Y"
2. **动元素≥2+动静对比声明**（景别联动）：人物<10%画面时强制
3. **运镜二选一**：完全固定 或 可见运动起幅→落幅差异，禁"极缓不可察觉"中间态

## 二、万物生空镜公式（金标准原文对照）

### 呼吸感慢运镜句式（唯一合法的"极缓"写法）

> 万物生原文（部落崖壁空镜）：
> 「镜头**不是固定的**，以非常缓慢的速度做一个轻微的forward push in推进运镜，运动幅度极小，**几乎接近静止但有呼吸感**。」

句式结构：**先否定"固定" → 声明运动 → 落点"有呼吸感"**。禁落点"不可察觉"（barely perceptible = 模型给你零运动）。

### 动静对比声明（金标准句式）

> 万物生原文（极光对峙段）：
> 「她的长发被夜晚沙漠的风持续吹动，发丝飘动是这一整个静态画面里**唯一持续运动的元素，与她绝对静止的面部形成对比**。」

模板：「[动元素]是画面中唯一/主要持续运动的元素，与[静物]的绝对静止形成对比。」

⚠️ 万物生没有一帧是"无可见运动源"的——空镜也配火光/村落/人群。**"静"是声明出来的对比，不是真空。**

## 三、墨染少女·动静清单模块（I2V/氛围段工业化写法）

每段成对声明——**≥3个持续动元素 + ≥1个固定基底**：

```
环境天光缓慢流动变化，[人物投影/水面倒影]随光影同步缓慢拉伸、晃动形变；
全域细碎[鎏金粒子/尘埃/雪花]不间断缓慢飘动、散落流转；
[衣发/布料/水流]持续不间断波浪轻柔翻涌流动；
[基底元素：地面/山体轮廓/建筑]固定不变/无多余动态。
```

✅ 关键：动元素各带运动方式（飘动/翻涌/形变），固定元素明确点名——模型据此分配运动资源。

## 四、音轨两层写法库（ 配套）

### 4.1 镜级·时序三段式（默认模式）

```
音轨：[起幅——底层声源+空间体感词]→[事件叠入：音效绑画面事件节点]→[收幅：衰减/留白/余韵]
```

✅ 万物生拔剑段原文（动作段）：
> 「音轨：仅环境音与动作音，不配 BGM。起幅是道观殿内安静的环境底噪——香烟气流的极轻流动、**悠远的空间回响**；**随拔剑动作推进**，叠入衣料摩擦、脚步碾地、金属出鞘的清越摩擦与剑身震颤的嗡鸣；**收幅归于一种屏息般的寂静**，只余一缕剑鸣余韵与人物克制的呼吸。」

✅ 万物生草浪段（变速段）：「子弹时间慢速段落里这些声音**随之拉长、低沉、绵延，加速时骤然收紧回正**」——音效随画面事件变形。

✅ 静态段两段式：起幅（底层+体感词）→收幅（余韵/留白声明），中间叠入可省。

**空间体感词库**（禁技术参数）：悠远的空间回响/峡谷回声缓慢消散/贴耳/空谷回荡/密闭干涩/屏息般的寂静
❌ 违禁：杜比全景声/混响X秒/四层频段/音量降低X%/静音0.X秒（混音台语言+伪精度）

### 4.2 挂点模式（I2V/氛围段合法替代）

每个音源挂在一个可见动元素上 + 末尾精准同步总声明：

> 墨染少女原文：「琉璃流水长发与广袖持续翻涌的轻柔水流风声、金珠发饰轻微碰撞细碎叮咚声、毛笔笔尖划过宣纸的细腻摩擦沙沙声……音效与少女捋鬓动作、鎏金粒子流转、发丝长袍流体流动、镜头环绕转动动态**精准同步**。」

判别：音源挂"可见运动"=挂点模式✅；音源挂"持续静态背景"=罗列式❌。

### 4.3 场级·声浪弧线（多镜组/整段强制，历史故事式）

```
本场声浪：从[起]到[转]到[收]的落差，托出[情绪]
```

✅ 历史故事原文：
- 「以『烈焰轰鸣 → 风雪呼啸 → 炭笔沙沙的死寂』的声浪落差，托出'心志如钢'的坚硬」
- 「以『人群由嘈杂 → 静听 → 哄然激荡』的声浪起伏承托情绪」
- 「刻意舍去煽情的弦乐，让'一位老人的哭声与一句回来晚了'在近乎无乐的真实里，反而更催泪」——无配乐时声明**为什么不配乐**

### 4.4 主观听觉（POV听觉，情绪重场触发）

触发位：受惊/噩耗/顿悟/死亡/重大揭示瞬间。

```
[角色]耳中——周遭声响骤然抽空/虚化退远，只余[单一音源]与[呼吸/心跳]
```

✅ 历史故事原文：
- 「群诵在先生耳中渐渐虚化、退远，仿佛只剩张煌言的诵读声与窗外雨声」
- 「周遭声响骤然抽空，只余耳鸣般的嗡鸣与他自己粗重的呼吸／心跳」
- 「刀锋破空一声之后，一切声响骤然抽空，只余雨声掠过」

### 4.5 旁白/朗诵专项（有旁白强制）

```
断句落点 + 与画面事件同步节点：
✅「『通玄』二字与瀑布轰鸣最饱满瞬间同帧」
✅「『大罗天』念完后旁白止，风声单独延续约1秒作为余韵收幅」
❌「朗诵在0-12s内持续」——无节点=有声读物
字数+时长：「台词」（X字，约Xs念完）
旁白身份（非常规旁白时声明）：不是人在说话，是[沙漠/世界/旁白者]在说话
```

## 五、极致规范核心（防平庸·语境化版）

### 5.1 运镜二选一（与一致，此处为写法示例）

| 选择 | 写法 | 适配 |
|:----|:----|:----|
| ①极致静态 | 「镜头完全固定零运镜——氛围由[动元素1][动元素2]承载」 | 意境/空镜/凝视段首选 |
| ②可见运动 | 「起幅[构图]→落幅[可辨差异构图]」 | 行走/跟随/揭示 |

### 5.2 慢词语境化判定（与自检计数1一致）

- L1/L2段慢词合法条件 = **有可见运动载体**（节拍感比喻+微细节≥3+意图）
  ✅ 万物生：「像踩着一个缓慢而固定的节拍……水珠甩落、肩头起伏、湿布料窸窣」
- 空写「缓慢地X」无载体 = 违禁 → 替换：极静固定 或 可见运动（二选一）
- L3/L4段（打斗/追逐/爆发）慢词 = 违禁 → 换速度定性词/节奏括号
- 懒词全段违禁（无信息量）：清晰明亮/整体通透/干净整洁/普通/标准/舒服/平均

### 5.3 时长配比参考（历史故事实证）

```
快切 1-2s（动作连发/反应镜/三连击）
常态 2-3s（叙事推进）
重场 5-7s（情绪戏/宣言/顿悟特写）
禁：全片同一时长；4-5s镜必须配强状态改变
```

### 5.4 每镜极致点（填卡空格）

「一个镜头只极致一个点，其余克制」——六选一：
光影/构图/景别/运镜/动静对比/情绪
意境片优先选「动静对比」或「情绪」，不选「运镜」（避免为动而动）。

## 六、意境段常见翻车（对照 ref04-F/G）

| 翻车 | 病灶 | 处方 |
|:----|:----|:----|
| 高清壁纸感 | 全镜无状态改变 | 五类补1个，优先光影事件（不改气质） |
| 运镜写了等于没写 | barely perceptible级 | 改固定机位 或 补起幅→落幅构图差异 |
| 小人国壁纸 | 人物<10%且无动元素 | 景别联动：环境动元素≥2+动静对比声明 |
| 连环画 | 连续≥2个纯空镜 | 中间镜压至≤3s作过场 或 补状态改变 |

| 白噪音平铺 | 音轨行罗列式无起幅收幅 | §4.1三段式 或 §4.2挂点模式 |
| 音画两张皮 | 音效不绑画面事件 | "随X推进叠入Y"句式；情绪重场加§4.4主观听觉 |

## 八、万物生笔法十式（写正文通用 · 每式=用法+原文+仿写模板+为什么好+适用边界）

> 与 SKILL.md 落笔六问配套：六问定"写什么"，十式给"怎么写"。
> v2 原则：照仿写模板写+理解"为什么好"。每式的原文都是万物生30+段里反复出现的稳定句式。
> 万物生96KB实证：as if只2次/伴随98次/瞬间64次——不要被英文从句频率误导，中文动作驱动句才是核心。

### 式1 · 段首总起句（多镜组开头第一句）

用法：HARD CUT 链开头一句话讲完镜头序列+声音设计+情绪弧——先给地图再给旅程。
原文：「丹眉单人开场1秒不说话的引子帧硬切到江流卫星地图特写硬切到丹眉震颤张望特写，丹眉的台词从镜头一开始作为画外音响起跨越后续两个镜头，中段地震+蓝鲸嗡鸣+警报全爆发，末段镜头持续震颤+镜头缓推+气氛累积+全部音效突然戛然而止+丹眉露出疑惑表情结束。」
仿写：「[镜A内容]硬切到[镜B内容]硬切到[镜C内容]，[声音设计：台词/音效从镜X起跨越/中段Y爆发/末段Z收束]，[情绪弧：从X到Y]。」
**为什么好**：先给地图再给旅程——AI读到这段知道整段结构和情绪弧，不会迷失在细节中。
**适用边界**：多镜组（≥3镜）开头必写，单镜不写。

### 式2 · 构图快照（复杂构图段叙事末尾独立段）

用法：从上到下/从远到近逐区清点，每个主体带占比分数+位置声明（不居中要写"不居中"）。
原文：「画面下方约百分之十五区域是丹眉与江流的极小剪影背影…两人在画面中的整体尺寸约为画面高度的百分之五到百分之七…前景巨怪的甲壳节段每一节都有人体三到四倍的高度，巨怪的身躯横向充斥占据画面前景下半部分宽度的百分之六十以上区域。」
仿写：「画面里能看到的全部内容：画面[上/下]约[分数]区域是[元素+质感]；[主体]位于画面[方位+分数]（不居中），占画面[高度/宽度]约[分数]；画面[剩余区域]是[环境元素]。」
变体（分区主体声明）：「[元素]主导画面的[方位]部分：…」/「画面构图：前景是…；中段是…；远景延伸到…」
**为什么好**：分数化占比（百分之五到七/百分之六十）让AI精确分配画面资源，比"很小""很大"可控。
**适用边界**：复杂构图（≥3个主体）必写；简单构图（单主体）不用。

### 式3 · 静态三件套（每个静止主体）

用法：常态锁定+例外微动+动静对比声明——静止不是零运动，是"只动X"。
原文：「江流保持完全静止，LED面罩边缘的冷青色辉光保持极轻微的恒定漏光，没有任何明显的明暗变化…只在面罩边缘偶尔有极细微的反光闪动。」「发丝飘动是这一整个静态画面里唯一持续运动的元素，与她绝对静止的面部形成对比。」
仿写：「[主体]保持[常态]全程不变…只有[例外微动元素+幅度]；[动元素]是画面中唯一持续运动的元素，与[主体]的绝对静止形成对比。」
**为什么好**：声明"只动X"比"完全静止"更可执行——AI知道哪些可以动哪些不能动，不会把"完全静止"理解成"凝固木偶"。
**适用边界**：所有静止主体必写（剪影/远景人物/凝视角色）。

### 式4 · 自然语言时间锚（事件钉在时间轴上）

用法："画面第N秒/镜头进行到约X秒时"≥2处；重复事件细节逐次升级。
原文：「画面第二秒，远处的部落人群欢笑歌唱声浪逐渐变响传来。第三秒，杂货商的身体姿态明显凝固一瞬。」「镜头进行到约2秒时一阵风把右侧开衩处的裙摆吹开一下露出大腿外侧的皮肤约一秒钟然后裙摆落回，镜头进行到约4秒时第二次更长一些的风把裙摆持续掀开露出大腿外侧约一秒半然后落回。」
仿写：「约[X]秒，[事件A]。约[Y]秒，[事件B]。…约[M]秒时第二次[同类事件]，这一次[更长/更短/细节差异]。」（2026-08-05改：约X秒为万物生主流，禁0.5秒与逐秒）
**为什么好**：时间锚从远景→近景、从环境→主体逐次升级，节奏是渐进的，不是均匀的——均匀撒=无节奏感。
**适用边界**：所有≥3s段必用。重复事件必须细节升级（第一次1秒第二次1秒半）。

### 式5 · 声音四维（每个声音写满四维）

用法：来源物（具体到发丝级）+质感+空间动态（由远及近/从无到有）+拟声词中英。
原文：「整段镜头中持续伴随杂货商身上密集挂件的细碎金属碰撞声clink clink、部落鼓点由远及近的有节奏敲击声从弱到强thud thud thud、远处人群欢笑歌唱声浪由远及近」
仿写：「伴随[来源物]的[质感][声音][拟声中英]、[来源物]由远及近/从无到有迅速增强的[声音]、[远处/近处][声源]穿透[声场]」
堆叠变体（一句扫五层）：动作音+道具音+人群音+低频环境+远处生物。
**为什么好**：万物生98次"伴随"几乎都是多层堆叠——音效密度对应画面密度。AI读到的音效越多，画的画面元素越多。
**适用边界**：所有段强制≥4层。I2V国风（流体+粒子+发丝+衣料+镜头移动）/历史正剧（风+人群+脚步+旗帜+兵器）跨类型适用。

### 式6 · 事件触发句式（打断式爆发，声画同帧）

用法：事件在"某句话说到第几个字/某个动作进行到一半"的瞬间爆发，音效与爆发同帧。
原文：「她话音说到'什'字尚未结束的瞬间，沙面在两人之间的位置以两人所在水平线为轴心猛然剧烈爆裂炸开，画面整体剧烈震动camera shake…伴随震耳欲聋的爆裂声sand burst boom。」
仿写：「[角色][话/动作]进行到[具体位置]尚未结束的瞬间，[事件]猛然[爆发动词]，伴随[音效拟声词]。」
**为什么好**：万物生64次"瞬间"几乎都是这个用法——"X的瞬间，Y"把动作和音效焊在同一帧，AI会把两个事件画在同一帧。
**适用边界**：所有爆发/打断/转折瞬间必用。日常渐进动作不用。

### 式7 · 英文从句焊接（每句描述带从句级英文）

用法：多重形容词从句级（≥5连续英文词），禁单词级；体感类比从句优先于技术名词。
原文：「brisk purposeful rhythmic walking pace with quick clipping footstep tempo」「as if a primal flight instinct bypassed bipedal locomotion entirely」「with no transition no warm-up no anticipation」
仿写：「[多重形容词叠加]+[名词] ／ as if [体感类比从句] ／ with no [X] no [Y] no [Z]」
**为什么好**：英文是"精度锚"——锁定动作精度（violently snaps+explosive motion+single instant三关键词级精度），中文承载叙事流。
**适用边界**：只在动作精度需要锁定时用（突变/极端/特殊状态）。**误用警示**：万物生96KB里as if只2次/with no只1次——不要每句都撒英文。

### 式8 · 是A不是B + 性格归因（边界锁定）

用法：排除AI高频误读+把动作归到人设上；"不是默认X，而是Y"防姿态误读。
原文：「她不是慌乱的惊恐而是警觉的注意。整个张望动作是小幅度的、克制的、警觉的，不是大幅度的慌张四顾，符合她冷淡的性格。」「机械船不是默认的直立站姿，而是处于腿屈起倾倒在沙地上的休憩状态——像一头巨大的机械野兽蹲伏休息。」
仿写：「[主体]不是[误读项]而是[正确项]——[幅度/方式边界]，符合[人设]。」/「[物体]不是默认的[姿态A]，而是[姿态B]——[具体形态描述]。」
**为什么好**：把动作归到人设上，让AI理解"这个角色受惊的反应是什么样的"，不只是描述动作本身。
**适用边界**：克制型角色/反默认姿态物体必用。常规动作不用。

### 式9 · 运动可见性量化（禁"在动"裸写）

用法：运动必须可测量——每秒位移量/形态拉长/占比变化/重复时长递增。
原文：「每只怪物每秒都在画面中清晰可见地推进数米的位移」「掠过的沙丘轮廓拉成长条形虚化条纹」「远景产生明显的横向运动模糊horizontal motion blur」
仿写：「[元素]每[时间单位]在画面中清晰可见地[位移量/形态变化量]」/「[元素]被[速度]拉成[形态]」/「[占比]从X到Y」
**为什么好**：量化运动让AI知道"运动幅度有多大"，"在动"是裸写（AI可能给你微动）。
**适用边界**：所有可见运动必用。

### 式10 · 群体参差分布 + 空间三层衰减（≥3个"有的"）

用法：群像不写"各不相同"一句带过——≥3个维度具体分布；空间按近→中→远三层清晰度衰减。
原文：「有的庞大有的略小、有的姿态向前冲刺、有的奔跑节奏不一、有的甲壳形态略有差异、有的扬起的沙尘多有的少、有的位置靠前有的位置靠后形成参差错落的群体奔跑画面，中景的巨兽形态稍微模糊…远处地平线附近的巨兽变成密密麻麻的暗色剪影一直延伸到画面最深处。」
仿写：「有的[维度1]、有的[维度2]、有的[维度3]、有的[维度4]形成参差错落的[群体状态]；近处[清晰细节]，中景[可辨轮廓]，远处[剪影/密布延伸]。」
**为什么好**："各不相同"是抽象描述，AI会画一样的群演；"有的X有的Y"是具体维度分布，AI会按维度画差异。
**适用边界**：群像/兽群/虫群必用（≥3非主要角色时强制）。

### 补充式 · 每段背景完整重写（重复合法化）

用法：多镜组切换后，背景/环境要素在新段完整重写——宁可重复100字，不让模型猜上段。
原文：杂货商三段每段完整重复：「背景里那道庞然的地龙巨大身躯静止不动、如一道顶天立地、横贯整个背景的钢铁绝壁般横躺在废墟之上、一动不动、像一道死寂的钢铁山脉、占满背景、遮去半边天光，远处废墟间是仓皇奔逃的西域胡人村民模糊的身影与翻滚的赭黄沙尘。」
原则：与 + 子镜头自足同源——**重复是特性不是冗余**，禁"同上/如前所述"。

## 九、万物生好句分析（写正文前必读 · 理解为什么好）

> v2 核心：用"为什么好"代替"模块清单"——AI理解了逻辑，能跨类型套用。
> 不是模仿句式，是理解写法背后的逻辑。
> 万物生96KB实证：伴随98次/瞬间64次/猛地37次/as if只2次/with no只1次。**数据不说谎。**

### 9.1 中英混排的"精度锚"用法

**好句**：
> 江流突然被吓得猛地一个全身哆嗦**then violently snaps from completely still to explosive motion in a single instant**整个人从完全静止瞬间爆发成剧烈动作的极端突变

**为什么好**：
- 英文夹在中文中间，前后都有中文释义——英文是"精度锚"，中文是"主载体"
- 三关键词级精度：violently snaps（突变方式）+ explosive motion（动作性质）+ single instant（时间精度）
- 关键动作只用一次英文，不是每句都撒

**适用边界**：只在动作精度需要锁定时用（突变/极端/特殊状态），日常动作不用。
**误用警示**：万物生96KB里as if只2次——不要每句都撒英文。英文是精度锚不是装饰。

### 9.2 动作+音效同帧绑定（"瞬间"焊）

**好句**：
> 他猛地从坐姿弹起，**弹起的瞬间**他从喉咙里发出一声短促尖锐被吓到的破音惊叫

**为什么好**：
- "X的瞬间，Y"把动作和音效焊在同一帧
- AI读到"弹起的瞬间+破音惊叫"，会把两个事件画在同一帧
- 万物生64次"瞬间"几乎都是这个用法——不是偶然

**为什么"他弹起来了。他叫了一声"不好**：分两句写，AI可能分两帧画——先弹后叫，不是同帧。

**适用边界**：所有类型都适用。I2V国风的"动作+流体动态同帧"、科幻机甲的"动作+机械声同帧"、历史正剧的"动作+台词同帧"——都用"瞬间"焊。

### 9.3 体感类比 vs 技术名词

**好句**：
> **as if a primal flight instinct bypassed bipedal locomotion entirely**像原始求生本能完全跳过了双腿直立行走的方式

**为什么好**：
- "primal flight instinct"是体感（让AI理解动作气质：原始求生本能，不是恐惧）
- "bypassed bipedal locomotion"是动作机制（跳过双腿直立——AI知道不是跑也不是走，是爬）
- 体感类比让AI理解"动作为什么是这样"，不是只描述"动作是什么样"

**为什么"他像动物一样爬"不好**：这是简单比喻，AI会画一只动物在爬行。体感类比是给AI"动作气质"+"动作机制"，不是给"动作形态"。

**适用边界**：只在动作气质特殊时用（突变/极端/反常），常规动作不用。

### 9.4 否定列举焊死边界

**好句**：
> **with no transition no warm-up no anticipation**没有任何过渡没有任何预动作没有任何前摇

**为什么好**：
- 三连否定列举焊死边界——"transition+warm-up+anticipation"三个并列否定
- AI读到三个并列否定，无法加任何过渡——这是防AI"自作聪明加预备动作"的硬约束
- 比"无过渡"强10倍——单点否定"无过渡"是建议，三连否定"no X no Y no Z"是焊死

**适用边界**：只在防AI加默认行为时用（突变/极静/反常），常规动作不用。

### 9.5 音效五层堆叠（"伴随"句式）

**好句**：
> 整段镜头中持续伴随杂货商身上密集挂件的细碎金属碰撞声clink clink、部落鼓点由远及近的有节奏敲击声从弱到强thud thud thud、远处人群欢笑歌唱声浪由远及近、杂货商转头时挂件瞬时摆动撞击的短促响声

**为什么好**：
- 五层音效：道具音(挂件clink) + 鼓点(thud由远及近) + 人群(声浪) + 动作音(转头撞击) + 拟声词(clink/thud)
- 万物生98次"伴随"几乎都是多层堆叠——音效密度对应画面密度
- AI读到的音效越多，画的画面元素越多

**跨类型示例**：
- I2V国风：流体声+粒子声+发丝声+衣料声+镜头移动声（5层）
- 历史正剧：风声+人群+脚步+旗帜+兵器（5层）
- 科幻机甲：喷射声+撕裂空气+金属撞击+电子嗡鸣+沙尘翻滚（5层）

### 9.6 时间锚逐次升级（不均匀撒）

**好句**：
> 画面**第二秒**远景声浪渐响。**第三秒**人物凝固一瞬。**第七到第八秒**人群涌入。**第十秒**前景遮挡。

**为什么好**：
- 时间锚从远→近、从环境→主体、从静→动逐次升级
- 节奏渐进：2s远景铺垫→3s人物反应→7-8s高潮人群→10s收束遮挡
- 不是均匀撒（1sX/2sY/3sZ）——均匀撒=没有节奏感

**跨类型示例**：
- I2V国风编排型：0s起势→0.8s行笔→2s旋身→3.4s二次铺毫→4.3s定格（逐次升级）
- 历史正剧重场：0s静场→2s底声浪→5s台词入→7s主观听觉抽空→10s死寂（逐次升级）

## 十、场景类型策略总表（步骤3b-2 判定入口 · 配合 ref09）

> **密度不是"写得多"，是"在AI最容易跑偏的位置写多"。**
> 先验分区本质=按"AI在什么位置跑偏"分策略，不是按"打斗/日常"分（万物生日常段也极详细，只是维度=空间结构+防穿帮，不是物理因果链）。
> 万物生思维4原则是骨架（不变），主画面驱动轴+AI跑偏路径按类型换（血肉）。

| 类型 | 主画面驱动轴 | AI跑偏路径（一句话） | 3个必写句式 | 详解 |
|:----:|:-----------:|:-------------------|:-----------|:----:|
| 1.日常/街道/室内 | 空间结构+人群密度 | AI美化简化（空旷/特写/光影平均/元素重叠） | 三维坐标锁空间/物理否定防穿帮/动静对比声明 | ref09类型1 |
| 2.事件/叙事 | 人物动作链 | AI跳过过程（动作缺失/物理失真/加过渡） | 瞬间焊声画同帧/伴随堆叠≥4层/时间锚逐次升级 | ref09类型2 |
| 3.打斗/高动态 | 动作节点+防穿帮 | AI穿帮（姿势漂移/空间重叠/服装修复/对白不同步） | 一动作一结果不写因果链/防穿帮节点反复重述姿势/负面约束堵动漫化 | ref09类型3 |
| 4.意境/空镜 | 环境动元素+光影 | AI呆滞（全清晰/静止壁纸/无环境动力） | 动静对比声明/呼吸感慢运镜禁不可察觉/动静清单明确什么不动 | ref09类型4 |
| 5.I2V国风 | 流体动态持续 | AI丢原图崩手部（材质丢失/手部畸形/原图漂移） | 1:1复刻原图/手部穷举约束8种崩坏/动静清单 | ref09类型5 |
| 6.科幻机甲POV | 技术参数+POV | AI虚构物理跑偏（比例错/材质光滑/视角混乱/默认引擎） | 尺度对比硬声明数字+参照物/材质反复锚定/POV硬切标记 | ref09类型6 |

**复述闸（强制）**：判定类型后，读 ref09 对应类 → 向用户复述「本类AI跑偏路径是X，3个必写句式是Y1/Y2/Y3」→ 说不出来=没读=退回。
**判别口诀**：万物生4原则不变，看"谁在动"——空间复杂=日常/室内，人物动=事件/打斗，流体动=I2V，机甲动=科幻POV，声浪动=历史，光影动=意境，群体动=大场面，镜头切=切镜头。
**加密原则**：加密=防AI跑偏（针对性堵跑偏路径）；不加密=AI有先验能做好/AI画不出/外部资源能承担。
