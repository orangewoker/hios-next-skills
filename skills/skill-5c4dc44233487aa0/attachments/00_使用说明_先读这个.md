# MX25 专家 V6 · 使用说明（无尽冬日 / 奔奔王国）

> 这是「脚本优化系统」的**可直接交付版**，给生成岗用。
> 技能包全量在 `MX25专家V6_技能全量.zip`；本目录另把两条产品线的风格包单独拎出来，方便单看。
> **规则版本：V6.3**（SKILL.md 头部写的是 V6.2，以 V6.3 各条为准）。

---

## 一 · 它是什么

**输入**：脚本 / 分镜 / 对标视频 / 素材图。
**输出**：可直接复制给视频生成模型（Seedance 2.5 为主，可向下适配 2.0 / Wan 3.0 / H3）的**提示词**。

三层结构：

| 层 | 管什么 | 在哪 |
|---|---|---|
| **导演工艺层** | 表演节拍、相机-情绪同步、灯光色彩、空间布局、失效模式预警 | references/performance、camera-lighting、mx25-spec |
| **提示词协议层** | 三主任务路由、素材职责、`{}` 台词符号、参数分离、输出合同 | references/tasks、materials |
| **团队生产层** | 七段式交付、反散文铁律、画幅路由、画面硬约束、职责边界 | references/output-adaptor、team-rules |

**再加两块业务层**：产品风格包（本目录两份）＋ 反馈标签体系（feedback-tags）。

## 二 · 怎么用

### 方式 A：装成技能（推荐，长期用）
把 `MX25专家V6_技能全量.zip` 解压到：

```
C:\Users\Administrator\.workbuddy\skills\mx25-expert-v6\
```

解压后目录里应直接是 `SKILL.md` 和 `references\`。装好后，说"用 MX25 写提示词"或直接提到无尽冬日/奔奔王国，技能自动加载。

> 装到**用户级**（上面的路径）＝所有项目都能用；装到某个项目的 `.workbuddy\skills\` ＝ 只有那个项目能用。

### 方式 B：不装，直接喂
每次开工时把 `SKILL.md` + 需要的 references 贴进对话，说"按这套规则写"。适合临时用。

### 开工时怎么说话
一句话说清四件事：**产品线 + 脚本（或分镜）+ 画幅 + 时长**。
例：`无尽冬日，横版，这条脚本 28 秒，帮我把分镜提示词写出来。`

## 三 · 两条产品线的口径对照（最重要的一页）

| | **无尽冬日** | **奔奔王国** |
|---|---|---|
| 游戏类型 | 冰雪末日生存（3A 半写实） | 中世纪塔防休闲（3D 卡通） |
| 画风 | 半写实 / 仿真人，好莱坞电影质感，通透明亮 | 皮克斯式 3D 卡通渲染，游戏 CG 质感 |
| 锚定词 | `cinematic lighting, volumetric smoke, bright and transparent, Hollywood movie style, 8k, photorealistic` | `3D cartoon render, stylized game CG character, Pixar-style proportions, soft studio lighting, clean shading` |
| 情绪公式 | **危机态 ↔ 安全态** 成对冷暖反差 | **受辱 → 隐忍 → 爆发/反转 → 碾压收尾**（喜剧打脸） |
| 画幅 | **一律先横 16:9**，定稿后改竖 9:16 | 横竖都要 → 先横后竖；**只要竖就直接竖 9:16** |
| 时长 | 成片 ≤30 秒，单镜 ≤3 秒为主 | 30 秒上下（0-3s 钩子 / 3-17s 施压 / 17-27s 反转 / 27-30s 口播） |
| 台词 | 按脚本，短句 | 口语对喷，每句 ≤15 字，可带梗不带脏字 |
| 结尾 | 按脚本 | **固定卖点口播池**（三分钟一局、超爽超解压、没有日常任务…） |
| 高发翻车 | 儿童与成人同框拉伸变形；雪面大面积纹理平铺/闪烁 | 3D 手部崩坏；盔甲细节涂抹 |

**两线共用的铁律**：
1. **画幅开问不动笔**——没说画幅先问；统一只有 16:9 / 9:16 两种。
2. **横改竖不重写**——拿已定稿横版作参考改，禁止凭空重来。
3. **有资产图的角色**：`@图片N` 引用，**删掉服装/发型/体貌等静态外观描述**（重复描述会和参考图打架）。无资产图的角色才写全外观，并在【资产提示词三件套】里同步给人物图提示词。
4. **战力/等级/熔炉级数/幸存者数量不进画面**——后期加 UI 包装。
5. **60fps 在生成阶段落实**：画质段写 `60fps, smooth high-frame-rate motion, no dropped frames, silky smooth`，参数层帧率同时设 60。

## 四 · 交付长什么样：七段式（固定顺序）

| # | 段 | 要点 |
|---|---|---|
| 1 | **【开跑前确认】** | **永远放最顶部**（放文末＝必被漏看）。勾选清单：任务模式、产品线与画风、目标时长与模型建议、还需你提供什么素材 |
| 2 | **【通用提示词】** | 画风锚定＋氛围画质整段，所有分镜共用，复制一次反复用 |
| 3 | **【负面提示词】** | **按本单场景裁剪**，不套通用大而全——场景用不到的禁令删掉 |
| 4 | **【人物调度表】** | 每镜 × 每角色的位置、动线、朝向、表情强度；跨镜动线衔接一眼可查 |
| 5 | **【分镜画面】** | 逐镜正式 Prompt 正文，台词标在镜内 |
| 6 | **【对白清单】** | 逐镜台词＋台词前/中/后节拍，供配音字幕对齐 |
| 7 | **【资产提示词三件套】** | 场景图 / 人物图 / 道具图的生图提示词，**默认必附** |

附页：**【制作流程参考表】**——步骤｜产出｜用哪个工具｜下一步。

**不做**：剪辑点表、剪辑时间轴、精简版/快剪版方案（剪辑结构在脚本阶段就定好了）。

### 单镜 Prompt 的四段骨架
```
【基础设定】→【氛围与画质】→【声音】→【画面内容】
```
符号系统：台词 `{}`、音效 `<>`、音乐 `()`。

## 五 · 五条最容易犯的错（背下来）

1. **写散文**。提示词只写摄影机拍得到、录音机录得到的东西。
   禁：仿佛/好似/像是/宛如/似乎/某种/莫名/淡淡的、以及**裸情绪词**（悲伤/愤怒/震惊）。
   改法三步：**落到身体 → 给幅度速度 → 给可见结果**。
   > ✗ 男A很生气 → ✓ 男A面部紧绷，嘴紧闭，胸膛大幅度起伏，握紧拳头
2. **塞参数**。画幅、总时长、分辨率、帧率、声音开关**不写进 Prompt**。
3. **拼时长**。单次 SD2.0 ≤15 秒 / SD2.5 ≤30 秒。超了**自动拆批、每批自包含**，不问。
4. **人形立牌**。画面里只要有路人/群演，**绝对不许站着不动**——哪怕只写呼吸、眨眼、小幅晃动。
5. **越界**。不碰运营投放（消耗/转化/ROI），不给剪辑方案。只负责把素材做好。

## 六 · 生成前的四条硬约束（团队 389 条错误案例驱动）

| # | 约束 | 落字 |
|---|---|---|
| 7.1 | **物理成立**：大幅动作写明支撑脚/接触面、重心、力从哪来、惯性痕迹、可见结果 | ✗ 一拳打倒 → ✓ 右拳从腰侧水平击出击中左肩，上身后仰到肩线明显后倾，右脚后撤撑住，衣料压出褶皱，惯性又晃一下 |
| 7.2 | **细节保持**：镜内有织物/毛发/金属/雪面/木纹/砖墙时写 | `preserve fine texture details, no smudging, sharp edges, high micro-detail` |
| 7.3 | **比例参照**：2+ 人物同框必写体型比例（儿童与成人同框必写） | `男B 头顶高出男A 约一个头，男A 视线齐男B 胸口`（**不用小数倍率**） |
| 7.4 | **稳定类负面词默认池**：抗闪烁＋抗平铺，再按场景裁剪 | `no flickering, no frame-to-frame jitter, no strobing` / `no repetitive texture tiling, no looping background pattern` |

> **必加不裁**：大面积纯色墙面地面、规则几何纹样布景、慢速平移长镜头、雪地/沙漠等大面积同质纹理——这几类是平铺闪烁高发区。

## 七 · 鬼脑模式（默认开）

行文密度层：用连锁因果、微观姿态堆砌、量化数字把画面写厚。**格式标准不变，只改行文。**

- 输出首行加标识：`想象力岂是如此不便之物！鬼脑！开！`
- 密度自适应：动作/冲击/对决用**全密度**；细腻对手戏、轻量任务自动**降轻档**。
- 动态模糊/极限速度类描写必须 `**加粗**`，并附一行：
  `鬼脑提示：加粗处为动态模糊/极限速度描写，SD2.5 会字面执行；若成片出现拖影或主体模糊，删除加粗句即可。`
- 关闭：说"关闭鬼脑"。新会话自动恢复默认开启。

## 九 · 交付前自检（过一遍再交）

1. 【开跑前确认】在最顶部？
2. 七段齐不齐？
3. 时长是否 ≤30 秒（SD2.5）？超了拆批了吗？每批自包含吗？
4. 画幅问过没有？按产品线路由了吗？
5. 画面描述里有没有"仿佛/像是/某种/莫名"和裸情绪词？
6. 有资产图的角色，静态外观描述删干净了吗？用 `@图片N` 了吗？
7. 包内**每一条**：有大幅动作的写重心受力了吗？纹理密集的写细节保持了吗？多人同框写比例了吗？
8. 框内所有角色（含路人）都动了吗？
9. 60fps 锚定词写进画质段了吗？
10. 有没有混进投放数据、剪辑点表？

## 十 · 出问题怎么办（反馈闭环）

任何翻车（"表情太僵""画风飘了""提示词太长"）**直接说**，不用填表。系统按标签体系记录（问题标签/解决标签/坏习惯标签/产品标签），每周汇总高频项，**回流到风格包升版**——所以风格包是有版本的，现在：无尽冬日 **v0.2**，奔奔王国 **v0.3**。
