# 按镜头需要规划资产

## 触发与最小输入

在导演或分镜已明确局部拍摄需要、接手已有资产、准备跨场复用或发现资产缺口时读取。当前只有创意也可做视觉探索，但探索图不能自动升为全片母版。

最少读取当前 Scene/Shot 版本、需让观众感知的事件、人物与故事时段、空间/风格约束，以及已有素材的位置和观察记录。定义与版本以[核心记录](../core/03-records.md)为准。尚缺剧本全篇不妨碍规划已稳定的一场；局部场功能或身份事实冲突则先回对应源记录。

默认形式及完整样板分别见[人物/表演](04-character-and-performance-templates.md)、[场景/调度](05-scene-and-blocking-templates.md)、[道具/交互](06-prop-and-interaction-templates.md)。持续人形角色按稳定批次在首次正式使用前准备默认图组，首个身份探索不等母板；已有合格源按用途复用，背景群体/非人形/探索按职责分级。

## 从用途推导资产

先逐镜询问：必须看清谁、什么变化、哪些物体关系？当前素材能否支持？每项新建需求应有下游用途或探索问题；不按角色人数批量补齐固定数量的三视图、表情图或服装图。

| 维度 | 保存什么 | 不应混入什么 |
|---|---|---|
| 身份/基础设计 | 人物可辨特征、身体比例；道具结构；场景固定布局和地标 | 某一场的表情、伤势、湿衣或所有场次的灯光 |
| 故事状态 | 服装穿法与湿损、伤势阶段、道具持有人/损坏、场景陈设变化；生效故事时段和变化事件 | 仅因逆光变暗、视角变化而产生的外观差异 |
| 视角/构图 | 当前覆盖需要的观察侧、可见面、遮挡和画幅；场景反面与可通行路径 | 改换人物世界位置来迁就画面左右 |
| 光照/视觉处理 | 所在空间、时间、实际光源逻辑和本阶段外观；允许变动项 | 把某张母版的照明认定为角色身份或源素材技术色彩编码 |

这些是分开的决定，不要求每个维度各生一张图。母版可以同时表达若干维度，但消费时须明确它负责哪些。身份尚未确定时，不用一张过度戏剧化、遮脸或大幅透视的气氛图承担所有身份职责。

## 本批形式、计划与用途资格

沿用资产需求索引逐项接上“所需形式→复用/补建计划→实际对象版本与媒体→可观察验收→本次用途资格”。规划只列需要与判据；尚无真实图的行保留应出图计划，已有节点但未观察的行保留候选，不把名称、文字清单或图数报成默认图组已完成。图的形式由上述三个模板统一规定，验收与晋升交[制作验收](02-asset-build-review.md)，当前入口的对象与引用映射交[Binding](03-reference-binding.md)。

本批正式使用前，分别核人物母板/设定板、承担辨认或交互的关键道具、空间底图/必要视向与阶段调度是否具备当前叙事职责；一项存在不替另一项完成。长距离运动需能判断起止位置、沿途地标的顺序/间隔、路径、必要接触及停止阶段和摄影可见范围；接触或破坏是否发生依本场原文，不把“穿过”自动改成“撞穿”。一张彩色静态站位锚不足以确认这些关系，应按[空间图组](05-scene-and-blocking-templates.md#scene-set)补当前必要范围。图形设计作为前置，是否直接传模型另由Binding判断；独立设计/首次身份与道具探索不等待尚不存在的母板、交互图或下游视频。

同一人物的基础、受伤、觉醒等来源分别标生效阶段与消费职责。后期状态图出现的出鞘、悬浮、破损或新持有人不能随身份引用提前成为当前事件；本镜资产需求写清输入状态、允许变化及结束状态，具体源是否可限用途复用由验收决定，不用最新状态图覆盖整段故事。

<a id="voice-assets"></a>
## 角色声音母版与状态

声音按角色和用途单独规划，不是每张图都要填的第五个视觉维度。需要跨场辨识、对白归属或声音连续时，建立声音身份Asset；一次性无身份职责的背景声可只记场内声音设计。新项目尚无声音母版时，先写明确的声音设计，在已有创作/费用授权与网页真实能力范围内制作候选（可以来自首个实际Take），实际听取并选择后才晋升可复用母版。首次探索不以已有已听声音母版为前提；后续需要保持已锁身份时才消费对应合格来源。

- 关联稳定角色ID、声音设计及可变表演范围：可辨音色、说话习惯、口音/节奏等有依据的特征；情绪、距离、处理效果与故事造成的沙哑等状态分开。只有实际测量时才写声学数值。
- 登记确切音频/Take来源版本、允许用途、真实定位、源区间与时基；混合声轨须能在消费区间辨清哪位角色，不能把多人声音笼统当成一份通用身份母版。
- 记录生效集/场与故事时间、变化事件和父版本。例如术后新声态从第五集生效，旧母版仍可用于此前或符合原状态的闪回；另一角色声音不随之失效。
- 保存已听区间、实际听到的角色/词句与声音特征、观察者/证据和用途资格。只给描述、波形、转写或可播放链接仍是设计/候选，不能称已听合格母版。

建立与验收交[资产制作](02-asset-build-review.md#voice-build)，生成前沿用[Binding](03-reference-binding.md#voice-binding)链接源版本与职责。厂商有音频参考说明不代表网页Agent已提供相应输入；没有可用音频引用时保留声音设计和具体缺口，不发明声音工具。

<a id="identity-tracking"></a>
## 多人身份按叙事职责分级

按观众需要辨认同一人、人物是否承担关键事件或反应、跨镜/跨集连续性决定追踪范围，不以具名与否分级。无名服务员若藏起戒指并在反打后退向厨房，就须有稳定角色标识、必要可辨外观和持物/知情/去向记录；若生成或后续覆盖需复用该身份，建立相应独立资产与引用。只在远景上菜、没有个体事件的一次性侍者可按群体区域、服装范围和背景动作处理。主角也只补当前用途所需资产，不按等级机械生成全套图。

身份职责在后续场景升级时补充追踪与资产，不追认此前未观察的面孔已经锁定。声音需辨认同一角色时按上节另建声音资格；面孔一致不证明声线一致。

## 具体判断分支

| 发现 | 本轮决定 | 下一步 |
|---|---|---|
| 已有素材在目标用途与维度有合格观察 | 保留确切版本并复用；检查本次视角、状态和故事时段仍适用 | [参考绑定](03-reference-binding.md) |
| 身份已确定，只缺换装、湿损或伤势阶段 | 建立状态变体，引用合格身份/基础设计；记录父版本与变化事件 | [制作与验收](02-asset-build-review.md) |
| 同一身份需要新视角，现图未展示关键面 | 先说明该镜为何需要；可由镜头直接实现，或制作视角参考 | 依据当前模型参考能力选方案，不能宣称未见的一面已经合格 |
| 反打无法判断门、桌和椅子的关系 | 草拟关系后按[空间图组](05-scene-and-blocking-templates.md)补实际底图、必要方向及调度依据，不以草图代替正式图形 | 回[风格与美术](../visual/01-style-art.md)及[场面调度](../creative/05-blocking-action.md) |
| 只有一次性背景/远处道具，不承担身份或交互 | 可放入镜头描述直接制作；写清不独立建资产的理由 | [镜头到任务](../generation/01-shot-task-packaging.md) |
| 已有素材与新故事要求冲突 | 比较复用、局部派生、重建或改镜方案；不得无声改剧本迎合素材 | [变更影响](../core/05-change-impact.md) |

优先解决影响多个必做镜头的基础资产，以及一旦错误会迫使大量返工的空间/关键道具。少量尚未定调的探索应有要区分的方案与停止条件。实际制作和费用仍进入[项目契约](../core/01-project-contract.md)与生成调度，需求目录本身不代表付费授权。

## 可浏览产物

交付一页资产需求索引：列用途与必要镜头、角色/对象及追踪职责、故事状态/范围、所需形式与复用/补建计划、实际对象版本/媒体、观察依据与用途资格、真实前置；视觉项补所需视角/光照，声音项补角色声音版本、源区间及已听资格。只展开本用途相关字段。图组索引另列默认目标、本批必需/未来补项、触发镜号、图的消费者、设计前置或直接输入职责、实际文件/图内区域和观察范围；尚缺必要默认图不报整套完成，图数不等于调用或计费子任务数。

**原创纸面示例，未生成素材：**修理店姐弟戏需要林舟可辨识身份、当夜工作服与肩包、门—账桌—空椅的可通行关系，以及钥匙放在近侧靠门桌角后的状态。林岚将账本转向空椅是动作事件，不能仅用一张“账本朝空椅”的静态图证明动作发生。

| 需求 | 规划决定 | 真实前置 |
|---|---|---|
| 林舟工作服身份参考 | 若现有身份图已按用途验收，则只补必要服装状态 | 被消费的身份母版可定位且合格 |
| 修理店主镜与反应角度 | 用同一布局确定可见面；是否补反面取决于遮挡与参考能力 | 空间设计稳定；不依赖主镜视频先返回 |
| 包从肩上到地面的变化 | 分别记录动作前后状态；视频任务承担变化过程 | 仅在要求继承实际前段末态时等待对应 Take |

## 检查、返修与边界

逐项检查：是否有真实用途；是否重复已有合格资产；身份与故事状态是否混写；来源能否定位；派生依赖是否明确；视角和光照是否误锁。删去不能改变下游决定的资产需求。缺陷发生在图中则转[制作与验收](02-asset-build-review.md)；需求本身错误则回分镜或美术，不以反复生图代替决定。

工艺依据：[S06服装连续性](../evidence/01-sources.md#s06)、[S07美术与分镜](../evidence/01-sources.md#s07)。资产维度、声音母版与身份分级为本Skill的生产设计，验证及来源范围见[方法边界](../evidence/01-sources.md#method-boundaries)。
