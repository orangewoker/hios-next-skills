# 平台约束

last_verified: 2026-05-30

## 通用约束

- 不要假定每个 Seedance 2.0 界面都具有相同功能。
- 不要凭记忆假定 API 访问、定价、模型 ID、区域访问、上传限制、时长或人像授权。
- 不要从一张上传的图像、嗓音或视频推断同意。
- 在没有安全改写或明确授权背景下，不要提供受保护角色、名人、品牌 logo、歌曲复制、精确场景或嗓音模仿的指令。
- 不要把真实人脸输入一概当作允许或禁止。部分界面限制直接上传真人面部，同时允许已验证的虚拟人像资产、可信的同一账号生成资产或授权素材。
- 不要混用供应商特定字段名：火山引擎的首/末帧角色、Runway 的 promptImage 位置、包装器结构不可互换。

## 平台特定声明

当用户询问即梦（Dreamina）、即梦（Jimeng）、火山引擎方舟（Volcengine Ark）、BytePlus ModelArk、Runway、ComfyUI、Replicate、Higgsfield 或其他界面时，带上平台名称和日期作答。明确标注非官方/社区工具。

## 面向用户的默认

平台支持因界面而异。在生产规划前核对当前官方文档。

## LibTV 已知行为

- 视频模型常用：`Seedance 2.0 VIP`（文生视频）。
- 视频节点参数：`ratio=16:9`、`resolution=720p`、`duration=4-15s`、`modeType=text2video`。
- 续拍/编辑：以节点引用方式通过 LibTV 画布完成，不依赖本地文件。
- 音频：Seedance 2.0 音频能力因平台而异，LibTV 视频节点可写入音频提示词。
