# 快速开始

## 最小流程

1. 告诉我你的创意、剧本片段或参考素材。
2. 我会判断是单条还是序列，并选择模式（T2V/I2V/V2V/R2V/FLF2V/Extend）。
3. 我会返回一个可直接复制进 LibTV 视频节点的提示词 + 意图回声。
4. 生成后，把结果或末帧发给我，我再写下一个镜头。

## 单条提示词检查清单

| 关卡 | 通过条件 |
|---|---|
| 模式 | T2V/I2V/V2V/R2V/FLF2V/Edit/Extend 明确。 |
| 参考 | 每个素材恰好有一个主要角色。 |
| 主体 | 主要主体出现在首句，带稳定标签（角色 A / 产品 A）。 |
| 动作 | 一个可见节拍，有清晰终点。 |
| 镜头 | 一个主要运动，有起点、速度、终点。 |
| 灯光 | 光源、方向、颜色、氛围是物理性的。 |
| 音频 | 对白、环境声、音效、音乐或静默是有意为之。 |
| 安全 | 受保护身份、IP、不安全措辞被重写或加授权关卡。 |
| 反套路 | 空洞增强词被可观察的制作语言替代。 |

## 常用模式速查

- **T2V**：主体 + 动作 + 场景 + 镜头 + 光 + 声音 + 约束。
- **I2V**：保留 @Image1 主体；只补充运动、镜头、光变化、声音、保持项。
- **V2V**：@Video1 仅控制镜头/动作节奏；不要迁移身份、场景、logo。
- **R2V**：每个参考一个角色；写明谁控制身份、谁控制氛围、谁控制节奏。
- **FLF2V**：@Image1 为首帧，@Image2 为尾帧；只描述连续转场，不引入新元素。
- **Extend**：从已接受成片的实际末帧开始，标记已完成节拍和预留未来节拍。
