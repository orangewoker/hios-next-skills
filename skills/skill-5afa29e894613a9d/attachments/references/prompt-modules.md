# 中式天宫提示词模块库

使用时从每一类中选择相容内容，组合成一段连续中文提示词。不要机械地把所有选项并列；同一画面只能有一个机位逻辑、一个主光源和一套不矛盾的空间规则。

## 1. 固定风格锚点

默认放在提示词开头；根据用户目标可删减或替换“胶片”“全景清晰”等媒介词：

```text
东方仙侠概念设计，真实电影摄影质感，柯达 Vision3 电影胶片，35mm 胶片扫描，轻微胶片颗粒，长焦压缩，无广角畸变，画面锐利通透不发灰，低饱和、高级灰、接近褪色胶片的色彩控制。
```

用户要求现代数码感、插画感或特定模型时，可调整媒介词；其余结构仍保留。

## 2. 机位与构图模块（六选一）

### A. 中轴纵深 / 单点透视

```text
镜头架设在正中轴线上，正对纵深延伸方向，形成严格对称的单点透视，灭点位于画面水平中心。前景建筑与栏杆等距排列并向远处递减收束；中景保留完整的呼吸空间，远景只设置一处宏大的奇观。
```

适合：石阶、宫门、柱廊、人物向画面深处行走。

### B. 偏侧机位 / 左密右疏

```text
采用偏侧机位，主体不在画面正中。建筑压在画面左侧三分之一，右侧三分之二留给天空与云海，形成左密右疏的横向疏密关系；密侧结构层叠、信息集中，疏侧只保留云海与天际作为呼吸空间。
```

需要时可左右镜像，但所有后续位置也必须随之镜像。

### C. 偏侧机位 / 右密左疏

```text
采用偏侧机位，主体不在画面正中。宫殿压在画面右侧三分之一，左侧三分之二留给天空与云海，形成右密左疏的横向疏密关系；密侧结构层叠、信息集中，疏侧留出干净天际与云海。
```

### D. 正侧平视 / 横向画面

```text
机位为正侧平视，建筑立面完全平行于画面，屋檐与栏杆边缘保持水平，不使用斜角透视。前景为有秩序的建筑框架，中景开口留空，远景在开口处出现一处巨大奇观，横向构图保持清晰的密疏对照。
```

### E. 巨型框景 / 门洞、洞口或殿内开口

```text
以[巨大圆形门洞 / 横向椭圆观景洞口 / 柱廊开口]占据画面中上部，开口外只保留无边云海、孤绝仙山、巨月或远处天宫中的一处主奇观；前景建筑形成深色或暖色框景，开口内留白充足，空间由近到远逐层展开。
```

### F. 前景古松框景 / 宫阙远望

```text
画面上方与一侧由一株巨大古松横向框景，粗壮虬曲的树干从画外伸入并指向远处天宫；宫殿压在另一侧或远处山崖，中央大面积留给云海与天空。古松、平台或石阶形成引导线，远方天宫是最终视觉焦点。
```

## 3. 天宫空间模块

默认（悬浮天宫）：

```text
中式仙侠天界。场景悬浮于无边云海之上，下方只有虚空，没有山体、没有地基、没有任何支撑物；建筑顶部伸出画面，被画框自然切断，看不见完整轮廓。
```

有平台或石阶时必须补足：`人物和建筑明确落在抛光白玉平台 / 石阶上，不漂浮，脚边有接触阴影。`

## 4. 主体建筑与前中远景模块

任选一个作为主体，再具体化位置和边界。

- 柱廊开口：`前景上方是一整片鎏金木构藻井，金色卷云浮雕密集但轮廓清晰；左右两列深灰青石圆柱向内收束，中央矩形开口完全通透，开口中不出现柱子或遮挡物。`
- 中轴石阶：`左右是朱红漆木蟠花墙板与米白大理石圆柱，柱脚放置数座白玉雕成的莲花石座；中央巨型白玉石阶从画面下方笔直向深处延伸并逐级升高，每一级都清晰区分踏面与踢面。`
- 宫门与断桥：`左侧是一座朱红漆木门楼，重檐青瓦，檐下斗拱密集，檐角悬素净铜铃，门楼顶部超出画框；门楼向右伸出白玉悬空石桥，桥面笔直延伸至画面右侧三分之二处戛然而止，断口参差，桥下无支撑。`
- 宫殿与静水：`右侧是一座深色木构宫殿，层层飞檐向左伸出，檐下斗拱密集；中景横贯一道深色石栏杆桥，栏板有暗金镂空雕饰和方形平台；画面下方是完全静止的镜面水，完整倒映天空、云层、建筑与人物，水面无植物无杂物。`

建议明确四层：`前景为空旷的抛光地面 / 静水与投影；中景为人物、桥或石阶；左右为柱廊或宫殿；远景为云海与一处奇观。`

## 5. 材质模块

```text
石材为温暖的象牙白与米黄白，自带暖色底，不是中性灰白也不是死白；所有石材为抛光打磨过的质地，不是哑光。圆柱或栏板上有柔和而宽阔的高光带，向背光侧逐渐变暗，呈现明确的体积与圆润感；地面同为抛光石材，保留宽幅柔和反光。
```

只有在写深色木构时加入：`深色木构保留真实木纹和低亮度反射，局部暗金饰件只点缀在斗拱、栏板或藻井，不泛滥。`

## 6. 远景、云海与有机曲线模块

远景奇观只选一种：

- `开口正中的远处悬浮一座巨大浮空宫，岛顶是层层叠叠的深青灰宫殿群，正面垂落三道并排巨瀑，水流直落云海；岛上点缀深红秋林与数座细小高塔。`
- `右侧云海上方倒悬一座巨大山体，山尖朝下、山顶朝上，底面生长深青色林木，数道细瀑从倒悬山体向上方云中流去；它距离极远，受空气透视柔化。`
- `石阶尽头是一座巨大的白色崖台，崖壁陡直，崖顶坐落层层叠檐的白玉与青瓦宫殿，崖体缝隙生长数株小松，宫殿后方是一片堆叠成柱状的积雨云。`
- `门洞外是无边云海、数座孤绝高耸的仙山和一轮巨大苍白圆月；月球纹理清晰，体量远大于人物和建筑，作为画面唯一的天象奇观。`
- `云海上方远处悬浮规模恢弘的深青飞檐、朱红梁柱天宫建筑群，建筑层层递远、被薄雾柔化，暖金屋脊仅在受光边缘出现。`

云海默认：

```text
云层分为三层：前层云清晰厚实，中层云有明确受光面和阴影面，后层云受空气透视衰减为偏冷蓝；云海间留出裂缝，露出下层山峦或虚空轮廓，不是一整片均匀白雾。云顶是奶油白与暖调，云的凹陷和背光处为冷调灰蓝，天空清澈通透；不出现漂浮碎片、颗粒或杂物。
```

有机物最多设置一到两处，用来打破建筑直线：`一棵伞状平顶古松生长在[位置]，树冠横向平展伸入画面中部，枝干[平直 / 轻微虬曲]呈深青色，作为全画面唯一主要有机曲线。`

## 7. 光线、阴影与色彩模块

任选其一，其他内容必须跟随其方向：

### 左侧日落低角度侧逆光

```text
光线为日落的低角度侧逆光，太阳位于画面左外侧、接近地平线，不出现在画面中；光以极小掠射角擦过石材表面。单光源，不做人工补光。左侧受光面呈暖奶油白与浅象牙色，向右侧快速衰减；背光面没有直射光，只被天空照亮，呈冷蓝与淡紫而非灰黑。建筑轮廓和飞檐边缘有克制的暖金色轮廓光。
```

### 右侧清晨低角度侧光

```text
光线为清晨的低角度侧光，太阳位于画面右外侧、接近地平线，不出现在画面中；单光源，不做人工补光。右侧受光面最亮，向左侧快速衰减；背光面只保留天空环境光，呈明确冷蓝与浅紫，不发灰。每个受光面都有清晰的明暗渐变。
```

投影通用补充：`柱、栏杆与人物在地面投下清晰锐利的长投影，方向一致；衣摆与地面接触处有明确接触阴影，人物绝不漂浮。`

色彩收束：`冷暖分区明确：天空与云海偏冷蓝、青白；石材与鎏金偏暖象牙白、暗金或奶油白。整体低饱和、高级灰，光比强烈、明暗层次分明，暗部保留细节但不发白。`

## 8. 人物模块

人物必须保留中式天宫的“小人—大景”比例，先按下表选择尺度，再写人物。建立镜头中的人物只承担尺度参照功能，必须后置书写；除非用户明确要人物主视角、半身或特写，不要擅自放大人物。

场景人物比例与位置巨门、巨月、巨松、云海或远景天宫建立镜头一至三人合计只占画面高度的 `1/22–1/30`，位于石台、栏杆或平台边缘。断桥与宏大远景三人身高各占画面高度的 `1/18–1/22`，位于断口前，间距不均匀。巨型石阶纵深 / 长廊全景一至两人身高各占画面高度的 `1/18–1/20`，位于石阶或廊道中段。静水平台与倒影一至两人身高各占画面高度的 `1/18–1/22`，站在平台中段，倒影完整可见。人物叙事镜头一至两人身高可占画面高度的 `1/12–1/15`，仅限用户明确要求人物为叙事焦点。

人物极小不等于可省略。人物段必须写明：`仅有[人数]名人物作为尺度参照`、位置、朝向、服色对比、落脚位置与接触阴影。不要以“人物必须清晰出现”“人物完整可见”“人物优先”替代比例，也不要为了防止漏生成人物而改为画面高度的五分之一或六分之一。

两人默认：

```text
画面下方[偏左 / 偏右 / 石阶中段]仅有两名人物作为尺度参照，背对镜头望向远景，身高各只占画面高度的[二十二分之一 / 二十分之一]，不抢占视觉中心。一人以月白长袍形成亮色小轮廓，另一人以[黛青 / 深藏青 / 绛红]长袍形成深色或暖色小轮廓；仅需辨识服色与衣摆轮廓，不强调五官与近景服装细节。人物双脚明确站在地面或平台上，脚边有极小接触阴影和同方向投影。
```

只用一个人时，不要沿用“两名人物”的服色和站位。三人时必须说明中间、左右的服色、间距、姿态与道具。人物无论数量都应有明确的地面接触与同方向投影。

## 9. 成图结尾与负向约束

```text
整体构图层次分明、空间关系清晰，2.35:1 宽画幅，全画面清晰锐利，无景深虚化。不要广角畸变，不要鱼眼，不要镜头光晕泛滥，不要过曝死白，不要灰雾，不要漂浮人物，不要多余人物，不要无来源补光，不要文字、边框、水印，不要卡通或二次元质感。
```

## 10. 图生视频模块

视频从成图首帧开始。下列各方案只选一套，替换方括号信息。

### A. 快速稳定后拉 / 人物与巨构景（适合门洞、巨月、巨松、远景宫殿）

```text
镜头从[平台 / 栏杆]附近沿画面主轴快速、匀速后拉，让巨门、巨月、巨松或远景天宫的尺度迅速展开；保持水平稳定，不摇晃、不旋转、不突然变速。[人数]名小人物向[画面深处 / 画面左侧]快步移动数步，衣摆和长发被气流明显带起，人物比例不得改变。前层云海快速横向流动，中层云快速翻卷，[飞鸟从起点快速扇翼飞至终点 / 瀑布高速垂落并扬起水雾 / 静水保持镜面平静]；远景建筑、巨月与古松保持静止，光线与色调保持不变。
```

### B. 中轴快速前推或仰升（适合石阶、宫门、巨柱）

```text
镜头沿[石阶中轴 / 巨柱之间]以快速、匀速的速度向前推进，并[明显仰升 / 保持水平]，始终稳定，不摇晃、不横移、不旋转、不突然变焦。小人物保持[站立 / 快步向纵深走数步]，身体不转向镜头；若行走，步幅清晰，衣摆拖曳并被气流带动，投影连续前移，人物不能靠近镜头。前层云海快速翻涌，中层云沿建筑边缘快速流动，[瀑布高速持续垂落并带起水雾 / 静水保持镜面平静]；远景天宫、柱廊与山体完全静止。光位、投影方向和色调全程不变。
```

### C. 快速稳定横向平移（适合古松、柱廊、岩壁或长廊框景）

```text
镜头以快速、匀速的速度从[左向右 / 右向左]平移，保持水平稳定，前景柱廊、古松或岩壁产生明显横向视差，人物与远景始终处于稳定空间关系中；不摇镜、不手持、不突然变焦。人物沿[廊道 / 平台边缘]快步向纵深或侧前方移动，衣摆和发丝随步伐与气流明显摆动；前层云海快速横向掠过，中层云快速回卷，远景宫殿与光线保持不变。地面柱影随镜头快速位移。
```

### D. 快速稳定后拉展开（适合平台、静水、悬崖边缘）

```text
镜头从人物位置快速、匀速向后拉远，让平台、悬崖、云海与远景巨构在短时间内迅速展开；保持水平稳定，不摇晃、不旋转、不突然加速。人物沿平台或水岸快步向远处行走，衣摆与发丝被气流明显拉动，倒影随人物保持稳定对应；静水保持镜面平静，[瀑布高速持续下落并扬起水雾]，前层云海快速流过平台下方，远景建筑完全静止。光线、色温、投影方向均不变化，无转场。
```

### E. 垂直快速俯冲或上升（适合峡谷、瀑布、悬浮天宫）

```text
镜头从[高处俯视云海 / 低处仰望巨瀑与天宫]开始，以快速、匀速的速度[向下俯冲 / 向上抬升]，路径保持垂直稳定，不横摇、不旋转、不突然变焦。前景岩壁或屋檐产生明显纵向视差；小人物沿原平台或廊道快步向纵深移动，保持极小比例，衣摆被气流明显掀动。云雾快速升腾或下沉，[瀑布高速连续垂落，水幕边缘不断炸开细雾]；巨型建筑、远山、光位与色调完全稳定。无转场。
```

### F. 可见环境动态补充（按画面实际元素选一到两项）

```text
瀑布：水流以高速、连续不断的水势从高处垂直落下，水幕边缘持续分裂为飞散细雾，瀑底猛烈冲入云层并顶起局部水汽；瀑布不改道、不暴涨、不停止。

云海：前层云团以明显速度横向推移，中层云快速翻卷、回卷或穿过平台下方，远层云相对稳定；云海运动要清晰可见，但不要遮没人物与主建筑。

活体巨龙 / 神兽：巨物在原有空间内完成一次大幅度、快速且完整可读的动作，例如龙首快速抬起并大幅转向、巨翼连续有力扇动、尾鳍或龙尾大幅摆动后带动身体游移；胸腹、长须、鬃毛和周围云雾必须有对应的明显气流反馈。身体不冲向镜头，不越过人物，不改变主构图。

飞鸟：飞鸟在一个镜头内从明确起点快速扇动双翼飞向明确终点，连续快速扇翼并完成一次完整掠过或爬升；不悬停、不瞬移、不反复折返。
```

### 视频通用负向限制

按需附在末尾：`不要人物变脸或换装，不要额外人物，不要建筑形变或漂浮位移，不要云层遮没主体，不要水面大波浪，不要无规律强风，不要镜头抖动、手持感、突然变速、旋转、跳帧、闪烁、转场或色调漂移。`
