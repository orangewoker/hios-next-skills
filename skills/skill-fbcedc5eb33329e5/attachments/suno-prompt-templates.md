## 四、高级风格栏完整模板

```
This is a [风格] song with [情绪] in a [调式] Key.
It opens with [主乐器], blending [辅助乐器/铺底和弦] that remains [演奏技巧].
[Verse 段落的乐器编排与演奏方式]
[Pre-Chorus 的张力构建方式]
[Chorus 的全编制爆发与和声层次]
[Bridge 的变化与过渡]
立体声混音：[宽/窄声场，左右声道分布]
人声：[性别]，[音色描述]，[唱腔特点]，[情绪表达]
All instruments pure, balanced, distinct, no distortion, no harshness, no ambient noise.
```

**纯音乐必须在结尾加**：`There is no vocal present.`

## 六、调式参考（Key）

- 大调（Major）：C, D, E, F, G, A, B — 明亮、欢快、积极
- 小调（Minor）：Cm, Dm, Em, Fm, Gm, Am, Bm — 忧郁、深沉、情感丰富
- 示例：`in a C Major Key` / `in an A Minor Key`
