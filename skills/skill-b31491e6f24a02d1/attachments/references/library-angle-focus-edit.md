# 资料库：视角、焦点、剪辑衔接

### @ANGLE：视角类型


| 视角 | 视觉语言 | AI执行锚点 |

|------|----------|-----------|

| 客观全知 | 旁观者 | `omniscient third-person perspective, objective camera` |

| 主观POV | 摄影机成为角色的眼睛 | `first-person POV, unsteady handheld breathing, natural blink-like dark frames` |

| 过肩镜头 | 代入感、对话感 | `over-the-shoulder shot, OTS, foreground silhouette out-of-focus` |

| 上帝视角 | 宿命、审判 | `overhead top-down shot, bird's eye view, god's eye perspective` |

| 荷兰角 | 不平衡、紧张 | `dutch angle, canted framing, severe camera tilt, disorienting` |

| 窥视视角 | 主观偷窥、恐惧 | `peeping perspective, foreground obstruction blurry, hesitant nervous camera` |

| 虫眼视角 | 极致渺小 | `worm's-eye view, ultra-low ground angle, foreground grass blades as towering trees` |

| 监视器视角 | 客观冷酷 | `CCTV surveillance camera perspective, high corner angle, desaturated cold grey, 15fps staccato` |

| 濒死体验 | 意识抽离 | `near-death experience POV, tunnel vision, pulsating edge blur synced to fading heartbeat` |

| 鱼眼视角 | 扭曲心理 | `fisheye lens perspective, extreme 180-degree field of view, severe circular distortion` |

| 管窥视角 | 被囚禁的视线 | `keyhole perspective, frame masked by deep black vignette, only small circular area visible` |

### @FOCUS：移焦技术


| 移焦类型 | 叙事功能 | AI执行锚点 |

|----------|----------|-----------|

| 前后景切换 | 揭示信息 | `rack focus pull from [A] to [B], establishing relationship` |

| 动态跟焦 | 隔绝世界 | `dynamic follow focus locked on [subject], background streaks into motion blur` |

| 呼吸式变焦 | 情绪升温/冷却 | `imperceptibly slow creep zoom, subtle breath-like dolly` |

| 心理移焦 | 顿悟、走神 | `psychological focus pull, focus drifts from gaze object to distant background` |

| 模糊入画 | 梦的开始 | `focus fade-in, abstract bokeh resolving into sharp image, dream-like awakening` |

| 模糊出画 | 世界崩塌 | `focus dissolve-out, sharp image melting into soft blur` |

| 分焦面 | 平行故事线 | `split diopter shot, left and right at different focal distances` |

### @EDIT：景别衔接与剪辑法则


| 法则 | 说明 |

|------|------|

| 相邻不硬切 | 远景→中景、全景→近景、中景→特写，相邻景别相似产生跳跃感 |

| 两极不衔接 | 远景→中景→特写，两极直接切换观众反应不及 |

| 隔一别 | 连续相近景别遵循跳跃式切换 |

| 30度原则 | 机位角度差≥30°，避免跳剪 |

| 动作匹配 | 前镜"落势"与后镜"起势"拼接 |

| 镜头时长 | Seedance2.0 单次生成 4s~15s，最佳5s~12s；信息密度过高时拆镜或逐镜生成 |
