# 纯二维赛璐璐PV构成语法

## 1. 连续段落结构

每个≤15秒视频提示词使用：

`导演总述与规格 → 主题/世界观/色彩 → 声音与节奏 → 画面总体风格 → 题材图形库 → 平面空间表现 → 逐角色设计 → 分秒镜头 → 二维动效 → 严格限制`

写成连续制作说明段落，不使用编号式章节。先定义画什么和如何平面化，再写何时变化。

## 2. 绝对纯二维

允许：硬边赛璐璐、大面积纯色、黑色剪影、白色负形、单色描边、图层平移／缩放／旋转、平面推拉、二维鱼眼变形、遮罩、漫画分格、圆形扩散、纸片翻面、反相、拆解和版面重组。

禁止：3D、2.5D、裸眼3D、三维摄像机、立体模型、真实纵深、视差、景深、三维透视渲染、CG材质、真实皮肤、金属高光、体积光、柔和渐变阴影和电影摄影质感。

极端视角与鱼眼只表现为平面线条弯曲、轮廓压缩、大小跳变和版式倾斜。轮廓超框是固定画框中的二维遮罩关系，不描述物体朝观众伸出。

## 3. 画面总体风格

必须说明：赛璐璐阴影档数、纯色色块分布、正常填色／剪影／负形／描边的使用条件、Editorial MG的留白与漫画分区、UI层级、视觉中心，以及人物与背景如何靠明度和色块面积区分。

不用“高级、华丽、电影感”等无机制形容词；把形容词落到色块、线条、遮罩、构图或运动方法。

## 4. 题材图形库与平面空间

从当前项目提取6—10种原创视觉元素：核心物件转为背景母题或遮罩；圆形物件转为圆环和刻度；小型道具转为图标与纹样；场景结构转为线稿、网格、窗格、展开版面或漫画分区；抽象规则转为数值、方向线、警示条或符号阵列。

全片复用2—3个主母题。场景不是可进入的建筑，而是一张持续重排的设计版面：背景图形代替远景、遮罩边框代替前景、主体色块代替中景；关系通过覆盖、切割、大小变化和局部隐藏表达。

## 5. 角色与连续性

每名重要角色按以下顺序描述：

`身份与叙事职能；年龄段与气质；发型发色及线条逻辑；服装轮廓、层次、色块比例；标志道具；姿态、表情或习惯动作；剪影、负形与描边；3—5个连续性锚点；无真实材质、无复杂纹理、无立体光影。`

单人只写核心角色；明确对立关系时分别写主角和对手；群像先写共享规则再写独立识别点；无人物项目改为核心主体设计。

角色动作从姿态变化、画面位移、道具交互和情绪反应中选择。相邻镜头不得重复相同主要动作；静态镜头必须承担判断、蓄力、反转或情绪落点。

## 6. 核心角色／主体图提示词

角色图必须是可直接生图的单段提示词，并按顺序包含：

1. 身份、叙事职能、年龄段、头身比、身形和整体气质。
2. 脸型、眼睛、眉形、嘴部、表情和可重复面部标记。
3. 发型、发色、外轮廓、刘海、鬓发、束发方式和发梢形状。
4. 上装、内搭、下装、鞋靴的轮廓、层次、不对称结构和主次色块比例。
5. 配饰、手部设计、标志道具及道具正反面或关键符号。
6. 重心、身体倾斜、双手动作、衣摆和头发的动作趋势，以及角色性格。
7. 3—5个跨镜连续性锚点。
8. 硬边赛璐璐、Editorial MG、阴影档数、剪影、负形、描边、配色、平面背景和受控纹理。
9. 全身设定图、单一视觉中心、原创边界及纯二维负面限制。

从视频提示词提取已确认设定；只补齐低风险细节。不得把参考案例的具体年龄、五官标记、发型、服装、配饰、道具或配色当作默认模板。无人物项目用主体轮廓、部件、色块比例、标志符号、展示姿态和背景母题替换人体字段。

## 7. 色彩与纹理

使用一组主色与对比色，加黑白或灰阶中性色；明确颜色对应角色、规则、危险、记忆或转折。同一颜色保持同一语义。

圆点网屏、双色波点和不规则斑点只用于背景、遮罩和转场，默认覆盖≤15%，不得遮挡脸、动作和文字。禁止皮革、金属、玻璃、皮肤等写实材质词。

## 8. 二维运动、节奏与镜头句法

动作镜遵循：`人物动作 → 图形或蒙版响应 → 声音或转场落点`。使用画面横移、图层缩放、版面旋转、轮廓遮罩、漫画格切割、圆形扩张、剪影反相、色块拆解、纸片翻面和短促二维Glitch。每镜保留1—2个主效果。

镜头链使用 `动作镜 → 反应镜 → 停顿镜 → 爆发镜`，不机械循环。连续三镜不得使用相同时长或同强度转场。

每镜句法：

`时间范围：主体状态与主要动作；细节动作或道具反馈；平面场景锚点；构图与景别；二维画面运动；图形或蒙版响应；动作、色块或声音触发的转场；音乐、鼓点、环境声、动作声或静默。`

第一镜在0.5—1.5秒内建立钩子。每镜只有一个主要叙事动作；蒙太奇最多包含三个顺序可辨的微镜头。

## 9. 分段连续性与原创边界

- 每段≤15秒，时间码从本段0秒起算并闭合。
- 每段重复纯二维边界、色彩职能、角色锚点和必要图形库。
- 中间段保留姿态、道具位置、图形形态和声音尾音；下一段首镜逐项接续。
- 中间段不出现完整标题；最终段才把母题重组为原创标题。
- 不模仿特定导演、动画或游戏，不使用已有角色、Logo、商标图形、专有UI、标题或标志性台词。
- 禁止元素铺满、长段文字、随机Glitch、无意义碎切和连续多个同强度白闪。
