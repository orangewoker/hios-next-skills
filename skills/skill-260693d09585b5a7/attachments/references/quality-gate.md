# 输出质量门控

将输出与最高优先级输入证据逐项比较。身份、结构、包装或目标视角任一关键项失败时先返修，不直接交付。

## A. 证据与身份（阻断项）

- [ ] 每个可见表面都有输入证据，没有补造不可见背面、侧面、顶部或底部。
- [ ] 品牌、LOGO、产品名、规格、净含量、主图案和主色与参考一致。
- [ ] 没有新增、删除、镜像、乱码或貌似真实的伪文字。
- [ ] 无法可靠保持的小字已明确限制，没有声称像素级准确。

## B. 几何与视角（阻断项）

- [ ] 高宽厚、直径、瓶肩、瓶颈、瓶盖、泵头、滴管和底部比例正确。
- [ ] 目标视角符合固定定义，左右方向在同组中一致。
- [ ] V05 正面居中且未水平旋转；V07 保持右前旋转方向，没有镜像成左前方向。
- [ ] V05、V07 产品悬浮且瓶底/产品底部清楚可见；底部结构有证据支持，无桌面、展台或接触阴影。
- [ ] 方盒棱线和侧面宽度合理；圆柱轮廓和标签曲率自然。
- [ ] 软管/袋体仍有柔性；异形结构未被规则化。

## C. 标签与印刷（阻断项）

- [ ] 标签、文字、LOGO 和图案贴合真实平面或曲面，不漂浮、不穿透。
- [ ] 接缝、标签起止位置和印刷区域符合参考。
- [ ] 烫金、镭射、透明标签和局部 UV 只出现在对应区域。

## D. 材质与光影

- [ ] 纸张不塑料化，金属有真实反射，玻璃有厚度和折射。
- [ ] 透明材质没有变成白色实体；复合部件具有不同材质响应。
- [ ] 棚拍光源方向统一，无过曝、死黑、脏反射或廉价 CG 假高光。
- [ ] 核心文字和 LOGO 没有被高光遮挡。

## E. 背景、边缘与输出

- [ ] 白底干净；非 V05/V07 视角的接触阴影自然，V05/V07 不使用接触阴影；无桌面、展台、手、人物、设备或场景杂物。
- [ ] 无毛边、白边、锯齿、噪点、过锐化、过磨皮或水印。
- [ ] 产品居中、留白均衡、占比符合用户或平台要求。
- [ ] 多视角保持同一产品身份、颜色、材质、标签位置、摄影风格和视觉尺寸。

## 返修规则

1. 只列出失败项及其位置。
2. 使用局部返修指令，锁定所有已通过项。
3. 返修后重新执行全部阻断项。
4. 若工具仍无法保证关键文字或身份一致性，停止继续漂移，交付最佳安全结果并说明限制。
