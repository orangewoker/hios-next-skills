# 爽点矩阵

> **定位**：微短剧爽点设计规范——全剧爽点类型与分布规划。
> **核心逻辑**：压抑越深，释放越爽。
> ⚠️ **v3.6 决策锁定表**：本文件为判断知识库。爽点分配以 Phase 1 剧本生成为执行点，核心冲突事件已在 `creative.md` §0.2 锁定表中确定。

## 七大爽点类型

### 类型一：身份碾压
被人看不起→亮出真实身份→全场震惊。

**情绪公式**：轻视/侮辱 → 蓄力 → 身份揭露 → 碾压 → 跪地求饶

| 子模式 | 示例 |
|:---|:---|
| 身份证明碾压 | 亮出创始人名片、五星军衔 |
| 电话碾压 | 一个电话让对方老板亲自来赔罪 |
| 财富碾压 | 刷卡买下整栋楼 |
| 能力碾压 | 一只手击败所有保镖 |
| 关系碾压 | 大人物主动到场鞠躬 |

### 类型二：实力碾压
主角展示压倒性武力/技能/智力→对手恐惧→观众燃。

**情绪公式**：危机场景 → 主角淡然出手 → 一击制敌 → 对手崩溃 → 围观者傻眼

| 子模式 | 示例 |
|:---|:---|
| 武力碾压 | 一招放倒一群保镖 |
| 医术碾压 | 所有人都说没救了→主角三针救活 |
| 智力碾压 | 在所有算计中早已预判十步 |
| 技能碾压 | 万年难题3秒破解 |

### 类型三：反转打脸
主角被看不起→反击→身份或能力揭示→对方跪地求饶。

**情绪公式**：打压→积蓄→反转→碾压→现场反应（关键！必须展示围观者的震惊）

区别于身份碾压：反转打脸侧重"打脸过程"，对象是当面羞辱主角的人——情绪强度更高。

### 类型四：守护/救场
主角在乎的人被欺负→主角及时出现→霸气护短→对方溃退。

**情绪公式**：在乎的人被欺负 → 主角赶到 → 一句"谁让你动的？" → 碾压 → 被守护者感动落泪

核心：展示主角的"不容侵犯"，以此投射到观众对安全感和被重视的心理渴望。

### 类型五：悬念揭秘
长时间铺垫的疑问→在关键时刻揭示答案→观众恍然大悟。

**情绪公式**：铺垫(越多越好) → 接近答案 → 延迟满足 → 揭示 → 观众"原来如此！"

区别于钩子：爽点是揭秘的满足感，钩子是制造悬念的未满足。最佳组合：用悬念钩制造期待→用揭秘爽点释放。

### 类型六：情感共鸣
角色经历观众能共情的情绪→放大→释放→观众被触动。

**情绪公式**：建立共情(共鸣感) → 积蓄(压迫感) → 爆发(释放感) → 余味(感动/心疼/爽)

虐心=观众心疼角色但知道角色会赢；甜宠=观众代入角色体验被宠。

### 类型七：喜剧反差
制造预期→用完全相反的方式实现→观众意外地笑出来。

核心：铺垫必须认真（观众认真了才有反差），反差越极端越好，节奏要快。

## 爽点节奏规划

### 单集爽点密度

| 集位置 | 爽点数 | 强度 |
|:---|:---:|:---:|
| 前15%（起势段） | 1-2/集 | L2-L3 |
| 15-45%（攀升段） | 2-3/集 | L3-L4 |
| 45-80%（风暴段） | 3-4/集 | L4-L5 |
| 最后20%（决战段） | 4-5/集 | L5 |

### 爽点交替原则
- 禁止同一类型爽点连续3集
- 每集至少1个微型爽点（小反转/小碾压）
- 每5-8集1个大型爽点（身份揭露/终极打脸）
- 爽点之间必须有"憋屈"蓄力——没有压抑就没有爽

## 付费卡点位置

| 集数 | 付费点 | 爽点要求 |
|:---|:---|:---|
| 第10集附近 | 第一付费卡点 | 身份碾压或反转打脸（L4+），制造"必须看下一集"的悬念 |
| 第20-25集 | 第二付费卡点 | 守护+反转叠加（L5），最高情绪点切断 |
| 第30-35集 | 第三付费卡点 | 终极反转或身份全面揭露（L5），全剧情绪最高峰 |
