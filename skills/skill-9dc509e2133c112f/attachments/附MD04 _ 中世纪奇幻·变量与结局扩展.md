# 附MD04 | 中世纪奇幻·变量与结局扩展

**所属主SKILL：** 中世纪奇幻 · 跑团冒险 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“变量设定空洞、多结局逻辑不闭环”的痛点，确保选择真实改变冒险命运。

## #需要什么输入

- 核心变量清单、路线设计、掷骰子判定机制。

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 生命值：counter，0-100，默认100；&lt;20重伤；归零死亡。
2. 魔法值：counter，0-100，默认50；&lt;10无法施法。
3. 金币：counter，0-999，默认100；用于购买装备。
4. 队伍士气：relationship，0-100，默认50；&lt;20发生内讧。
5. 善恶值：relationship，0-100，默认50；&lt;20堕落；≥80神圣。

道具与旗标

1. 远古神器：item，false；true可击败最终BOSS。
2. 解毒剂：item，false；true可解除剧毒状态。

### 二、结局体系（共15个）

正结局（5个）

1. E01·屠龙勇士：使用远古神器，在巢穴击败巨龙，名垂青史。
2. E02·王国救星：解除诅咒，获得国王的封赏。
3. E03·归隐田园：放弃荣耀，带着金币在小镇买下酒馆。
4. E04·大法师：魔法值拉满，掌握禁忌魔法。

坏结局（10个）

1. D01·团灭：小队全灭，死于地牢。
2. D02·感染暴毙：未使用解毒剂。
3. D03·被队友背叛：士气过低，在背后被捅刀。
4. D04·被巨龙吞噬：挑战失败，成为龙巢的枯骨。
