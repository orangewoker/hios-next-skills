# 附MD06 | 金包银·钩子与节奏设计

**所属主SKILL：** 金包银短剧漫剧电影级TVC | 高水准拉片复刻\
**版本：** V2.0 融合合规版

## #做什么

本模块为“金包银短剧漫剧电影级TVC”的专属钩子与节奏设计库。

解决TVC“前3秒留不住观众、情绪节奏拖沓、高能节点分布不合理、结尾无余韵”的痛点。通过黄金前3秒钩子模板、情绪递进曲线与复刻对标的节奏踩点规范，确保复刻作品节奏精准、高能节点突出。

## #需要什么输入

**最少提供：**

- 高水准拉片复刻拆解报告（参考附MD02）
- 目标总时长
- 核心情绪基调

**可选提供：**

- 目标平台偏好（长视频/短视频）
- 特定高能节点需求
- 目标画幅（不限定，按项目需求或用户指定）
- 是否需要输出视频文件、视频脚本、Prompt清单、视觉方案

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。本环节重点参考【大导演思维】的观众为什么愿意看下一秒与【情绪大师】的情绪曲线。

### 二、黄金前3秒钩子模板

TVC前3秒必须至少具备一种：

- **异常画面**：非遗工艺的极致微距特写（錾刻、花丝）
- **结果先行**：金包银手镯在聚光灯下熠熠生辉
- **身份反差**：老匠人粗粝双手 vs 极致精细的工艺
- **情绪悬念**：传承人凝视手镯，眼中含泪
- **信息差预埋**：锦盒缓缓打开，但镜头只给一半

### 三、情绪递进曲线（强制认知驱动）

- 平静 → 疑惑 → 不安 → 确认 → 沉静紧绷 → 反差爆发 / 隐忍克制
- 所有情绪变化必须来自人物认知改变，而非单纯心情波动

### 四、节奏控制规范

段落类型单镜时长范围运镜速度/剪辑频率舒缓段落3-5秒慢推/慢摇/缓慢剪辑升级段落3-5秒加速推镜/切换频率提升高能节点段落1-3秒快切节奏落点段落3-5秒放慢方式与留白

### 五、复刻对标的节奏踩点规范（核心铁律）

1. 对标作品的黄金前3秒钩子，复刻时绝对不能有0.1秒的废片卡顿。
2. 高能节点必须精准踩点，与对标作品的时间轴对齐。
3. 情绪递进节奏必须严格复刻，禁止自行缩短或拉长。
4. 结尾留钩必须与对标作品的情绪余韵一致。

### 六、结尾留钩模板

结尾必须保留至少一个未解疑问或情绪余韵，可用方式：

- 新信息出现但不解释
- 人物表情骤变
- 关键道具特写（手镯在光芒中）
- 声音先入
- 切黑留白

### 七、生成与合成

根据上述钩子与节奏设计，调用底层视频生成Skill，输出MP4视频文件。

## #产出什么

最终交付：

- **视频文件（MP4格式）**：包含钩子与节奏设计的金包银TVC成片。
- **视频脚本、Prompt清单、视觉方案**。
- **黄金前3秒钩子方案**。
- **情绪递进曲线表**。
- **节奏控制表**（单镜时长、运镜速度、剪辑频率）。
- **复刻对标节奏踩点报告**。
- **结尾留钩方案**。

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 目标总时长或核心情绪基调不明确时。
- 高能节点分布需要用户决策时。
- 用户要求突破单镜时长或节奏禁则时。
- 用户要求输出视频文件、视频脚本、Prompt清单、视觉方案，但缺少关键输入时。
- 本模块与上游主SKILL或其他附MD规则冲突时。
