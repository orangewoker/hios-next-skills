# 30 秒视觉微叙事引擎

## 核心纪律

把 30 秒理解为一个完整的视觉事件，而不是压缩版长片。只保留：

- 一个主要主体；
- 一个可见目标；
- 一个阻力或异常；
- 一次升级或转折；
- 一个记忆点结尾。

优先使用动作、空间、光影和声音传递意义。避免依靠解释性对白、旁白或字幕补足剧情。

## 冲突的广义定义

不把冲突等同于争吵或打斗。优先考虑：

- 目标与阻力：人物靠近某物，某物不断远离；
- 规则与异常：稳定空间出现唯一违反规律的东西；
- 自我与投影：人物面对倒影、影子、过去或未来；
- 微小与巨大：小主体进入压倒性空间；
- 静止与运动：人物不动，整个环境开始移动；
- 欲望与代价：每接近目标一次，人物失去一种东西；
- 观看与被观看：人物观察某物，最终发现自己才是被观察者。

## 五类优先叙事模型

### 1. 异常—追寻—揭示

适合人物望向画外、走廊、门、光源、远处物体。

结构：异常先出现 → 主体追寻 → 空间阻止 → 接近真相 → 真相重新解释开场。

### 2. 接触—反应—失控—重构

适合产品、道具、植物、机械、液体和超现实物体。

结构：主体触碰 → 局部响应 → 反应扩散 → 世界短暂失控 → 形成新的稳定形态。

### 3. 镜像—差异—同步—身份揭示

适合两个人物、同一人物不同年龄、倒影或相似造型。

结构：建立对照 → 暴露微小差异 → 动作逐渐同步 → 揭示二者关系 → 以同构画面收束。

### 4. 侵入—对抗—吞没—反转

适合纯净场景中出现异物、颜色、光线、阴影或自然力量。

结构：异常侵入 → 主体试图保持秩序 → 异常扩大 → 看似吞没主体 → 主体与异常融为新形态。

### 5. 展示—变奏—升级—定格

适合没有明确剧情但美术强烈的概念图。

结构：展示核心视觉规则 → 改变一个变量 → 改变第二个变量 → 尺度或材质升级 → 标志性定格。

必须让变化具备方向，避免把多个漂亮镜头随机串联。

## 图片类型路由

### 单张人物图

优先寻找视线目标、未完成动作、隐藏欲望、影子、倒影、服装动态和环境压力。避免凭空增加复杂配角群。

### 单张场景图

把摄影机、光线、闯入者或空间本身设为行动主体。使用探索、苏醒、时间变化、隐藏结构或规则破坏。

### 单张物体或产品图

使用接触、拆解、重组、材质变化、环境适应、尺度变化或功能引发的世界变化。

### 多张人物图

先判断同一人物的不同阶段、不同角色、现实与幻想、对立与合作，再设计关系。不要仅因为有两张脸就强行安排打斗。

### 多张场景图

优先组织为空间穿越、同地异时、梦境层级、因果变化或形状匹配剪辑。

### 图片缺少直接关系

使用颜色、材质、轮廓、运动方向或声音进行象征性蒙太奇，不编造过量世界观。

## 无法建立冲突时的降级策略

依次尝试：

1. 用异常代替人物冲突；
2. 用视觉规则变化代替剧情转折；
3. 用尺度、材质、光影或速度升级形成观看动力；
4. 改为纯视觉展示，并设计清晰的开始、变化、高潮和定格。

不要用低质量冲突破坏高质量概念图。
