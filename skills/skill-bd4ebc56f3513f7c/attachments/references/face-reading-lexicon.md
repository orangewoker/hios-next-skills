# 面相翻译词典（Face-Reading Lexicon）

> 用途：把相学/气质"黑话"翻译成生图引擎可执行的中性可视特征。生图时只使用"可视特征"列；"气质提示词"列可选并入氛围。
> 原则：特征化 = 形状/比例/位置/质感/表情，不是价值判断。所有条目默认适用于虚构角色肖像创作。

## 一、脸型轮廓

| 相学术语/描述 | 可视特征 |
|---|---|
| 国字脸 / 方脸 | 下颌骨方正宽厚，下颌角接近直角，咬肌发达，颧弓平宽，轮廓硬朗 |
| 瓜子脸 | 额头略宽，颧骨适中，下颌收窄成尖下巴，整体呈倒三角 |
| 鹅蛋脸 | 额头与下颌等宽，颧骨微凸，下巴圆弧，轮廓流畅椭圆 |
| 圆脸 | 面部宽度与长度接近，颧骨宽圆，下巴短圆，软组织饱满 |
| 长脸 / 马脸 | 面部纵向明显大于横向，额头高，中庭长，下巴长 |
| 申字脸（菱形） | 额头窄、颧骨最宽、下颌再收窄，颧骨突出明显 |
| 田字脸 | 方中带短，下颌宽厚方正，面部宽扁敦实 |
| 天庭饱满 | 额头宽而饱满，发际线圆润，额骨平滑高隆，无塌陷 |
| 天庭窄 / 额头窄 | 发际线低且收窄，两侧额角内收 |
| 日月角隆起 | 额骨两侧（眉尾上方）微微隆起，眉骨上方有骨骼起伏 |
| 地阁方圆 | 下颌骨方圆圆润有肉，下巴饱满不外突，腮部厚实 |
| 下巴尖削 / 尖下巴 | 下颌快速收窄，下巴尖而薄，骨感明显 |
| 下巴短缩 | 下停短，下巴后收，侧面观下巴到颈部线条短 |
| 腮骨横张 | 两侧下颌角明显向外张开，腮部宽 |
| 颧骨高耸 | 颧弓位置偏高且外突，颧骨正面观可见明显支撑点 |
| 颧骨外扩 | 颧弓向两侧横张，脸最宽处在颧部 |
| 颧骨低平 | 颧骨不显，面部起伏平缓，软组织包裹 |
| 印堂开阔 | 两眉之间距离宽（可容两指），眉间皮肤平坦舒展 |
| 印堂狭窄 | 两眉距离近，眉间挤压 |
| 眉骨高 | 眼眶上缘骨骼突出，眉下形成阴影，眼睛显深邃 |

## 二、眉

| 术语 | 可视特征 |
|---|---|
| 剑眉 | 眉形浓黑，起势上扬，眉峰靠后，眉尾收尖如剑，英气 |
| 柳叶眉 | 眉形细弯如柳叶，眉头粗眉尾细，弧度柔和 |
| 一字眉 | 眉形平直如一字，眉峰不明显，粗细均匀 |
| 八字眉 | 眉头高、眉尾下垂，呈倒八，显愁苦或温和 |
| 卧蚕眉（蚕眉） | 眉形粗短圆润，眉峰圆，眉身如卧蚕，忠厚感 |
| 浓眉 | 眉毛浓密粗黑，覆盖度高，眉脊清晰 |
| 淡眉/疏眉 | 眉毛稀疏色淡，眉形轮廓不明显 |
| 眉压眼 | 眉眼间距近，眉骨低，眼神显锐利阴沉 |
| 眉尾散 | 眉尾毛发散乱不收，显苍老潦倒 |

## 三、眼

| 术语 | 可视特征 |
|---|---|
| 丹凤眼 | 眼型细长，眼尾上扬，内眼角微勾，外眼角上挑，单眼皮或内双，锐利有神 |
| 桃花眼 | 眼型偏圆润，眼尾微弯上挑，睫毛长，眼波含水，含情带媚 |
| 杏眼 | 眼型圆而饱满如杏核，眼裂宽，黑白分明，清亮灵动 |
| 三角眼 | 上眼皮中部下垂、眼尾上提或外眼角低，轮廓近似三角形，显阴鸷或老态 |
| 狐狸眼 | 眼型狭长，眼尾明显上挑，内眼角向下勾，媚而精明 |
| 垂眼 / 八字眼 | 眼尾明显下垂，显疲惫、温顺或哀愁 |
| 圆眼 / 大眼 | 眼裂大而圆，瞳仁占比高，显年轻天真 |
| 细长眼 | 眼裂窄长，常配单眼皮，沉静内敛 |
| 目光如炬 / 眼神锐利 | 瞳孔清晰，眉压眼，注视方向明确，眼部肌肉紧致，目光带穿透力 |
| 眼神柔和 | 眼周肌肉放松，上下眼睑弧度舒缓，目光低垂或平视温润 |
| 眼神涣散 | 焦点不集中，瞳孔光点弱，显疲惫失神 |
| 目露凶光 | 眉毛下压，上眼睑紧绷，瞳孔上翻位看人，白多黑少，目光狠厉 |
| 卧蚕 | 下眼睑紧贴睫毛处有饱满隆起（肌肉脂肪垫），笑时明显，亲和 |
| 眼袋 | 下眼睑松弛下垂成袋状，显疲惫衰老 |
| 鱼尾纹 | 外眼角放射状细纹 |

## 四、鼻

| 术语 | 可视特征 |
|---|---|
| 悬胆鼻 | 鼻梁挺直中正，鼻头圆润有肉，鼻翼适中，侧面观鼻头微垂如悬胆，端正 |
| 蒜头鼻 | 鼻头圆大肉厚，鼻翼宽圆，骨感弱 |
| 鹰钩鼻 | 鼻梁中段有驼峰，鼻头向下弯勾，侧面观如鹰喙 |
| 通天鼻 | 鼻梁高直，从印堂贯通至鼻头，山根高耸，立体感强 |
| 塌鼻 / 鼻梁塌 | 山根低平，鼻梁矮，面部立体感弱 |
| 山根断 / 山根低 | 两眉间至鼻梁起点低陷，鼻梁与额头连接处有明显落差 |
| 鼻梁有节 | 鼻梁骨节凸起（常伴驼峰），有硬朗感 |
| 鼻翼外张 / 鼻孔外露 | 鼻翼宽而外扩，正面可见鼻孔 |
| 鼻头尖薄 | 鼻头无肉、尖削，骨感 |

## 五、口（唇）

| 术语 | 可视特征 |
|---|---|
| 樱桃小口 | 唇形小巧，唇珠明显，唇峰清晰，嘴角收拢 |
| 四方口 | 口型方正宽厚，唇线平直，唇形大而有轮廓 |
| 覆舟口 | 嘴角明显下垂，唇线中间高两头低，如倒扣小船，显苦相 |
| 仰月口 | 嘴角自然上翘，唇线中间低两头高，如仰月，带笑意 |
| 薄唇 | 上下唇偏薄，唇线清晰，显冷静克制或刻薄（取决于搭配） |
| 厚唇 | 上下唇饱满肉感，唇峰圆润 |
| 唇色红润 | 唇部血色足、颜色偏红润 |
| 唇色苍白 | 唇部血色少、色淡 |
| 嘴角法令纹 | 鼻翼两侧延伸至嘴角的纹路，深则显严肃/沧桑 |

## 六、耳

| 术语 | 可视特征 |
|---|---|
| 耳垂厚大 | 耳垂圆厚垂长，有肉感，福态 |
| 耳垂薄小 | 耳垂短薄，贴面 |
| 招风耳 | 耳廓外张，与颅骨角度大 |
| 贴脑耳 | 耳廓贴近颅骨，正面几乎不可见 |
| 耳高过眉 | 耳轮上缘高于眉毛水平线 |

## 七、皮肤、气色与纹路

> **词条译文是"语义基线"**：消息里皮肤只带 realism-standard 5.3 极简默认句——禁写"纹理走向/排列/交叉"，这类词会生成鳞片伪影（见 5.6）。古风美人肤词（肤若凝脂/面如冠玉等）特别危险——只译"白净细腻"会被画成零毛孔瓷脸；应译为"细腻而微透血色、温润光泽"，保住美人设定同时去掉 CG 假。

| 术语 | 可视特征 |
|---|---|
| 肤若凝脂 | 皮肤细腻白净无毛孔，光滑润泽 |
| 面如冠玉 | 肤色白净透亮，光泽温润不反光 |
| 气色红润 | 脸颊与唇部血色充足，面色健康明亮 |
| 面色苍白/无华 | 肤色偏白而缺乏血色，光泽弱 |
| 面色晦暗 | 肤色暗沉发灰，光泽差 |
| 面黄肌瘦 | 肤色蜡黄，颧骨处消瘦，软组织薄 |
| 皮肤粗糙黝黑 | 肤色深，近距离看鼻翼与颧部毛孔明显，日晒形成色差 |
| 法令纹 | 见口部表；深法令纹显威严/老成 |
| 抬头纹 | 额部横向纹路，显年龄感/思虑 |
| 川字纹 | 眉间纵向纹，显愁苦/凝重 |
| 泪沟 | 下眼睑至颧骨上方凹陷沟纹，显疲惫 |
| 痣（美人痣/泪痣等） | 具体位置+大小；如"眼角下方一颗小泪痣" |
| 疤痕 | 位置+形状+新旧，如"左眉一道旧疤" |

## 八、气质断语 → 翻译表（核心）

断语不能直接画。以下每条给出「五官特征 + 表情/仪态」两级翻译。生图时把两者都纳入描写。

| 断语 | 五官/骨相特征化 | 表情仪态提示词 |
|---|---|---|
| 贵气 / 富贵相 | 五官比例端正对称，鼻梁中正挺拔，下颌线清晰利落，额头饱满 | 目光平静有定力，仪态舒展不谄媚 |
| 福相 / 有福之相 | 面形圆润饱满，天庭饱满地阁方圆，耳垂厚大，卧蚕明显，唇色红润 | 神情松弛温和，眼角带笑意 |
| 清冷 / 冷清感 | 面部线条瘦削骨感，鼻梁挺直，薄唇，眉形平直细长 | 表情收敛少波动，目光疏离，下巴微抬 |
| 温柔 / 面善 | 面部轮廓柔和圆润，卧蚕明显，眉眼间距舒展，唇形圆润 | 眉眼含笑，嘴角自然上扬，气质松弛 |
| 城府深 / 深沉 | 眼型细长或三角眼，颧骨微高，嘴角习惯性平直 | 目光内敛不直视，表情克制，下颌微收 |
| 精明 / 算计感 | 狐狸眼或眼尾上挑，鼻头尖或鹰钩鼻，唇线清晰薄 | 目光聚焦带审视，嘴角一侧微动 |
| 刚毅 / 坚毅 | 国字脸或下颌方正，剑眉，颧骨与眉骨突出，鼻梁高直 | 下颌收紧，目光坚定，唇线紧抿 |
| 阴鸷 / 凶相 | 眉压眼，三角眼或眼神凌厉，颧骨高，唇线下压 | 眉眼下压，目光阴沉，面部肌肉紧绷 |
| 忠厚 / 老实相 | 面部宽厚圆钝，眉形粗平或卧蚕眉，鼻头圆润，耳垂大 | 表情憨直放松，眼神真诚 |
| 愁苦 / 苦相 | 八字眉，嘴角下垂（覆舟口），法令纹/川字纹深，眼尾下垂 | 眉头微蹙，目光低垂 |
| 桃花相 / 多情 | 桃花眼或眼尾上挑，卧蚕饱满，唇形圆润微翘，肤色明亮 | 眼波流转带笑意，神情含情 |
| 威严 / 官相 | 天庭饱满，眉骨高，鼻梁直，法令纹深，下颌方圆 | 表情端肃，目光平视有压迫感 |
| 精明强干（职场感） | 脸型紧致，颧骨适中，眼型有神，唇线利落 | 目光专注，姿态挺拔 |
| 病弱 / 文弱 | 面色苍白，身形清瘦体现在面部凹陷，眉淡，唇色淡 | 神情倦怠，目光低垂 |
| 阳刚 / 粗犷 | 骨骼感强，颧弓明显，下颌宽，皮肤受日晒、近距离毛孔明显，眉浓 | 表情直接不修饰，目光坦率 |

## 九、相学术语 → 已含于上文的名词映射（快速查找）

- 天庭 = 额头；地阁 = 下巴/下颌；中停 = 眉至鼻区间（含鼻）；下停 = 鼻下至下巴
- 山根 = 两眉间至鼻梁起点；年上/寿上 = 鼻梁中段
- 印堂 = 两眉之间；鱼尾 = 外眼角；泪堂/卧蚕 = 下眼睑
- 法令 = 法令纹；人中 = 鼻下至唇上竖沟（人中长/短可作年龄与唇部描写参考）
- 五岳 = 额(南岳)、颧(左右为东岳西岳)、鼻(中岳)、下巴(北岳)；"五岳朝拱"≈ 中正立体
- 三停均匀 = 上(发际-眉)中(眉-鼻尖)下(鼻尖-下巴)三段比例接近三等分

## 十、避讳与偏置控制（加入负面/避免表述时参考）

- 避免将特定五官直接等同于道德判断（如"薄唇=刻薄"），仅在用户明确要求该气质时才按上表组合使用。
- 涉及特定民族/地域特征描述时，只使用客观形态词，不联系民族与刻板印象。
- 不使用真实历史人物/在世名人/政治人物姓名或特征。
- 未成年角色：**允许生成**（0–17），但相学词汇须按 `demographics-and-body.md` 2.2 未成年档重译——不做"格局/贵贱/刑克"类断言，不套用成人骨相词（颧高、腮阔、眉压眼等），只译该年龄段可见的圆钝/饱满/清瘦形态；须遵守未成年角色安全约束（非性化/年龄适配/不参照真实儿童）。
