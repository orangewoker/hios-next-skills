## 一、创意生成三步法

### Step 1：选反直觉设定

一句话能说清，但第一反应觉得"不可能"，细想又觉得"有意思"的核心设定。

**碰撞法**：从两个列表各选一词，碰撞出设定：

| A列表（能力/身份） | B列表（限制/代价） |
|:---|:---|
| 看见别人说谎 | 只能看见爱人说谎 |
| 听到别人的心声 | 只能听到骂自己的心声 |
| 时间倒流5分钟 | 每天只能用一次，用完晕倒 |
| 交换身体 | 只能和陌生人交换，持续24小时 |
| 预知死亡时间 | 无法改变，也无法告诉本人 |
| 读心术 | 停不下来，人群中全是噪音 |
| 看见前世记忆 | 只能看见自己前世的死法 |
| 隐身 | 碰到水就显形 |
| 改变天气 | 情绪失控时天气也失控 |

**碰撞示例**：
- 「看见别人说谎」+「只能看见爱人说谎」→ "她能看见所有人说真话，唯独看不见丈夫的谎言。直到有一天，她发现自己能看见了——这意味着丈夫从今天起说的全是谎话。"
- 「时间倒流5分钟」+「每天只能用一次，用完晕倒」→ "外卖小哥每次送单超时就倒流5分钟，直到他目睹了一起命案，必须在晕倒前救下受害者。"

**热门概念改编**：

| 原始概念 | 反直觉改编方向 |
|:---|:---|
| 重生 | 重生后发现前世仇人变成了恩人，前世恩人变成了仇人 |
| 穿越 | 穿越到历史书里，发现自己的存在会改写所有人的命运 |
| 隐婚 | 不是隐瞒身份，而是整个城市的人都假装不认识他 |
| 复仇 | 每次复仇成功一个，就失去一段记忆 |
| 替嫁 | 替嫁后发现新郎才是自己失散多年的初恋 |

### Step 2：设计情绪配方

选择主情绪 + 反转情绪：

| 主情绪 | + 反转情绪 = 混合类型 | 热度 | 示例 |
|:---|:---|:---:|:---|
| 甜蜜 | 恐惧 | 甜宠悬疑 | 表面甜蜜恋爱，背后暗藏杀机 |
| 愤怒 | 爽感 | 复仇打脸 | 从被欺压到步步反击 |
| 悲伤 | 希望 | 虐心治愈 | 绝境中发现温暖 |
| 搞笑 | 感动 | 喜剧温情 | 看着笑着就哭了 |
| 猎奇 | 共情 | 悬疑反转 | 越查越觉得凶手可怜 |

**每集情绪节奏模板（3分钟）**：

> **注意**：本模板为创意阶段的宏观概览。详细的单集节奏曲线（含情绪波形、高潮低谷、付费卡点定位）见 [节奏曲线.md](节奏曲线.md)。正式规划时以节奏曲线为权威。

```
0:00-0:15  情绪钩子（一句话/一个画面抓住注意力）
0:15-1:00  情绪积累（铺垫矛盾、加深代入感）
1:00-2:00  情绪爆发（冲突高潮、反转或虐点）
2:00-2:30  情绪余波（角色反应、观众消化）
2:30-3:00  悬念钩子（埋下一集的钩子，让观众追下一集）
```

### Step 3：打造社交传播要素

| 类型 | 设计方法 | 示例 |
|:---|:---|:---|
| **金句** | 每集至少一句可截图传播的台词 | "你看见我的眼泪了吗？那不是泪，是我流不出来的血。" |
| **站队** | 设计让观众产生"支持A还是支持B"的争议 | 婆媳矛盾中双方都有道理 |
| **共情炸弹** | 触及普遍情感痛点 | 被忽视的全职妈妈、加班到崩溃的打工人 |
| **爽感瞬间** | 观众期待已久的"扬眉吐气"时刻 | 被欺负3集后第4集当场反击 |
| **反转炸弹** | 颠覆观众预期的关键信息 | 一直以为是好人的角色突然黑化 |

## 二、开头策略速查

> **10种详细开场模板 + 31题材推荐表** → [开篇法则](../storyboard/extras/分镜_27_开篇法则.md)

核心原则：

| 编号 | 开头策略 | 定义 |
|:---:|:---|:---|
| 1 | 反常识画面 | 打破预期的视觉冲击 |

| 5 | 身份反转 | 展示与预期相反的身份 |
| 6 | 危险预告 | 暗示即将到来的威胁 |
| 7 | 视觉奇观 | 非日常的视觉冲击 |
| 8 | 情感炸弹 | 情感冲突的瞬间定格 |
| 9 | 信息不对称 | 观众知道但主角不知道 |
| 10 | 倒计时 | 时间压力制造紧迫感 |

## 三、创意自检

- [ ] **一句话测试**：能否用一句话说清故事？（如"一个能看见别人谎言的女孩，发现丈夫从今天起说的全是谎话"）
- [ ] **反直觉测试**：设定是否第一反应觉得"有意思/想看下去"？
- [ ] **情绪测试**：主线情绪是什么？有没有至少一次反转？
- [ ] **社交测试**：观众看完会不会截图/转发/讨论？
- [ ] **可执行测试**：能否用本Skill的11步流程落地？角色/场景/物品是否足够丰富？
- [ ] **合规测试**：是否涉及敏感内容？（详见 `合规清单.md`）

## 四、创作流程衔接

1. 使用 `/创意` 命令，按三步法生成创意概念

3. 在 `/创作方案` 阶段融入创意概念（核心设定、情绪配方、社交传播要素）
4. 后续按标准流程执行
