# 部件卡8 · 正反打环绕弧线装置

## 适用条件
对话段≥3个正反打时，[STYLE LOCK]必须声明统一运镜装置。

## 万物生原版（对照用）
```
全段七个近景特写正反打镜头，同用一条想象中的环绕弧线：镜头自始至终沿同一个顺时针方向
极缓慢地微微环绕被摄者移动，每个镜头都带着这一抹持续同向的轻微弧形移动，使画面不至呆板；
正反打切换时机位跳到这条弧线的对侧，但环绕的旋转方向始终保持顺时针不变，不越过两人之间的轴线。
```

## 每个子镜头写法
```
正打：「[角色名]的近景，不居中、偏在画面[左]侧，脸朝[右]，[前景元素]虚焦横切过画面[位置]，镜头沿[顺时针]弧线极缓慢地微微环绕」
反打：「反打，[对方]的近景，偏[右]脸朝[左]。机位跳到环绕弧线的对侧，镜头仍沿同一[顺时针]方向极缓慢地微微环绕」
复用镜：「反打回[角色名]的近景，构图同前、偏[左]脸朝[右]，前景仍是[前景元素]，镜头继续沿弧线微微环绕」
```

## 三要素
①同一条弧线+同一方向（不越轴）
②前景元素每镜重复（尾甲/桌沿虚焦横切）
③复用镜用「构图同前」简写

## ≥3人对话
不用正反打弧线，用群像构图+画外音。

## 匹配剪辑两种（HARD CUT升级形态）
```
视线匹配：✅「匹配丹眉向下一瞟的视线，硬切到一个略带俯角的低特写：正蹲跪在沙地上抱着昏迷刘回的女儿的下半身」
声音匹配（声桥/J-cut）：✅「在刘回的笑声爆发到达最饱满音量的瞬间，画面发生硬切HARD CUT声音匹配
  剪辑——切换到室内。笑声在声音轨道上是连续不间断的，从外景的画外音直接接续到室内画面里刘回
  正在张嘴大笑的状态，声音的连续性掩盖了画面的硬切。」
⚠️ 切点在声音的最饱满瞬间，不是开始也不是结束
```

## 画外音纵深事件（对白镜不只是脸）
「画外音进行过程中，画面[区域]的焦点适时由虚转实、推到[纵深事件]」
✅ 万物生：琉璃画外音求援 → 画面左侧远景焦点由虚转实推到盲可汗吞下铁匠 → 丹眉头几不可察地朝那个方向偏了一下旋即收回。
