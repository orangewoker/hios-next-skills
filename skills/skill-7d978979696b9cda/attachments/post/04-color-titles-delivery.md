# 调色、字幕片头尾与交付

当画面完成、镜间外观不匹配、字幕/片头尾制作、锁画后导出或用户索要最终母版时读取。输入为明确的 Timeline 版本、源媒体及编码证据、艺术 Look、声音版本、字幕/署名文本与权利资料、Project 交付约定、已验证后期及导出能力。

## 先分开技术解释与艺术外观

| 遇到的情况 | 判断与行动 |
|---|---|
| 同一素材在不同工具偏色 | 先核对输入解释、已经应用的变换、显示/监看路径；未明确前不靠叠加滤镜补偿 |
| 肤色/对比异常 | 查是否重复应用显示或 Look 变换，再比较原始素材与艺术设计 |
| 生成素材只给出显示图像/视频 | 保存可取得的编码信息与缺口；不能因为“电影感”推断为场景线性，也不能靠修改标签制造 HDR |
| 相邻镜亮度/颜色不同 | 区分源光照、技术路径错误、艺术设计的合理变化；只有不应变化的部分才匹配 |
| 项目采用不同显示/交付版本 | 分别记录目标和转换链，分别观察输出；一个版本合格不能覆盖所有版本 |
| 源编码或输出接口不明 | 可提出 Look 和处理意图；未知技术项保留，不能称最终色彩流程已核验 |

艺术 Look 说明色彩、对比、材质和注意力为何适合此场，以及哪些可随故事改变。技术记录说明输入如何解释、工作/监看环境、Look 何处应用、输出变换及已烘焙项。两份可同页相邻，但不能互相代替。项目不必须采用 ACES、AMF 或 HDR；使用其他受支持流程也要保持可追溯的解释和输出路径。

可浏览的色彩记录：

| 范围/源版本 | 已知源编码及证据 | 已应用/待应用变换 | Look 版本与艺术理由 | 目标观看条件 | 实际结果与限制 |
|---|---|---|---|---|---|
| 场/镜/Take明确版本 | 真实元数据/工具回执；未知项列出 | 次序、职责、是否已烘焙 | 例如保留修理店夜间的旧灯照明关系，不以全场变暖宣布和解 | 来自项目约定 | 样片观察、镜间匹配、缺证据项 |

未执行时这张表只保留意图栏；不能给出虚构完成状态。实际调用遵循[提交核对](../generation/05-submit-reconcile.md)，颜色处理导致新源或新导出版本时保留原版。

## 字幕、片头尾与信息呈现

字幕输入应区分已核实的实际对白、用户提供文字和仅按剧本预测的台词。无实际声音观察时可以准备字幕草案，不能报听写校对完成。烧录字幕、可开关字幕文件、翻译字幕与无障碍字幕是不同交付物，按项目要求准备。

检查断句是否保住语义，显隐时段是否对应实际声音，语言/人名是否一致，画面安全区域和可读性是否符合约定，字幕是否遮住钥匙交接等关键信息。故意不翻译、留白或声源标注应有明确表达/无障碍需求。不同语言的阅读时长依实际受众和规范复核，不填通用秒数字。

片头尾使用已确认片名、集名、署名顺序、权利与音乐素材信息；未知署名不编造。片尾所需时长、标志和字幕样式来自项目约定。标题改变时间线总长或声音尾部时，应连同输出范围更新；不能只在文件名改片名就称片内已改。

## 交付前的具体分支

1. **没有裁剪/装配/导出能力：**交付可浏览的选片清单、纸上 Timeline、声音/调色/字幕意图与缺口，明确“尚未装配/导出”。不称最终母版。
2. **能导出但不能取得文件/媒体：**保存回执与定位，等待实际访问；任务成功不等于观看和技术复核成功。
3. **能访问输出但规格字段不全：**观察可见/可听内容，列出缺失技术证据；不能由扩展名推定编码、声道或色彩正确。
4. **能完成所需操作及复核：**核对真实输出与锁画版本、源引用、完整时长和全部必要交付物；通过范围按实际证据给出。

交付规格中的分辨率、画幅、帧率、编码/容器、色彩/动态范围、音频声道与测量指标、字幕格式、文件命名和输出版本，全部引用[项目契约](../core/01-project-contract.md)的具体约定及规范来源，不在本模块自造默认数值。不满足且会改变质量/成本/体量时，形成具体替代方案交由既有授权决定，不能静默降低。

## 可浏览的交付包清单

每个交付物用一行记录：用途、实际文件/媒体定位、版本、关联 Timeline/声音/Look/字幕版本、真实导出回执、实际规格、观看/测量证据、未完成项。没有文件就写尚未取得，不伪造下载链接。

| 复核面 | 必须回答的具体问题 | 问题去向 |
|---|---|---|
| 完整性 | 是当前锁画版本吗？起止、场/集顺序、片头尾、字幕与必要素材齐全吗？ | Timeline/版本/导出范围 |
| 视听内容 | 黑帧、卡帧、断声、静音段是否有意？修改区间及接缝有没有新问题？ | 对应声画工序；必要时回源 |
| 技术符合性 | 实际文件和测量是否符合约定，而非仅导出面板设置？ | 输出/色彩/声音技术处理 |
| 项目质量 | 场、集、全片层的承诺、关系与风格是否已按范围复看？ | [分层审查](../quality/01-review-rubrics.md) |
| 可追溯性 | 接收者能找到文件、清楚版本及限制吗？还保留哪些未决尝试/费用？ | 项目索引与交付说明 |

只抽看关键段落时，报告“所列区间已观察”，不报全片无误。实际下载只是取得媒体的一步；复用旧文件、复制新文件名都不能代替实际输出对应核对。最终说明以完成的交付物、通过范围和具体缺口为主，见[用户输出](../core/06-user-output.md)。
