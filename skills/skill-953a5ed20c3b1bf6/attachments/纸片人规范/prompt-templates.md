# Q版角色真实场景成片与确认模板

按阶段使用模板。`【】` 内全部替换后再呈现给用户；模型调用按当前模式执行：全智能托管直接推进，手动确认才等待逐步确认。

## 开场模式选择

```markdown
请选择创作模式：
1. 全智能托管：我直接按你的角色、场景和目标生成；中途不反复确认。只有缺少必要信息、需要长视频时长选择、模型不可用/失败、或分段后要智能剪辑合成时才停下来问你。
2. 手动确认：我会按角色图、声音、分镜、视频模型、生成前确认一步步让你确认。

如果你已经说“直接生成 / 全托管 / 不需要确认”，我会默认使用全智能托管。
```

## 无角色图：角色风格选项

```markdown
请选择角色风格：
1. 2D 简笔画纸片人：扁平、干净描边、纸张质感，适合贴纸感和纸片夸张动作。
2. 2D Q版插画：圆润可爱、插画质感，适合表情夸张和轻喜剧。
3. 3D Q版 IP 角色：小体积、圆润玩具感、软萌材质，适合真实场景里的可爱互动。

无论选择哪种角色风格，后续视频场景、道具、光线和材质都必须是真实摄影感，不得变成卡通场景。
```

## 无角色图：角色图提示词

```markdown
【2D简笔画纸片人／2D Q版插画／3D Q版IP角色】风格的原创小角色。角色是【身份／物种】，具有【外观】、【服装】、主色【颜色】和标志物【特征】；【主表情与姿势】。白色或简洁浅色背景，完整全身，轮廓清楚，适合在后续短视频中持续复用。成片放入真实摄影感环境时，角色视觉尺寸固定为成人拇指大小（约 4–6 cm），不得放大或与真实物体等高。不要角色换脸换装、多余肢体、乱码文字、水印、写实真人皮肤或写实真人比例；不要使用未经授权的知名IP形象。
```

## 固定叫声确认卡

```markdown
角色图已锁定。请选择声音方案：
1. 固定拟声叫声： 【候选A】／【候选B】／【候选C】，或自定义一个；整条视频最多出现 2 次。

3. 说中文：只使用 1 句短台词，请提供台词，或回复“帮我写一句中文台词”。

除非用户明确要求同时使用，否则固定拟声叫声与中文台词不混用。

```

## 成片视频提示词

```markdown
【规格】15秒，竖屏9:16，【第一人称／第三人称】镜头，轻微稳定跟拍，无字幕、无旁白、无背景音乐。

【角色锁定】使用已确认的【角色名称／角色图片】。固定为【完整外观】；角色风格为【2D简笔画纸片人／2D Q版插画／3D Q版IP角色】；相对环境始终为成人拇指大小（约 4–6 cm）。环境、道具、光线、材质和空间必须是真实摄影感，不得卡通化。所有镜头中角色外观、服装、配色、风格和标志物完全一致。

【声音】使用已确认的【固定拟声叫声／无角色声／中文台词】；固定拟声叫声最多出现 2 次，中文只出现 1 句短台词；除非用户明确要求同时使用，否则不增加另一类角色声音。

【场景】在【具体地点】；必须保留【场景参考图锚点，如有】。画面预先出现【核心道具】、【目标物】与【结尾物件】；仅保留完成故事所需元素。

[00:00-00:03] 【正常动作】。第1秒，【角色名称】从【合理位置】进入，使用已出现的【核心道具】完成【单一视觉钩子】，第3秒清楚出现【结果】。
[00:03-00:10] 【意外／小挑战／Q版角色夸张冲突】引发【非写实物理反应】；可出现角色被拍打、殴打、撞飞、压扁、折皱、弹性变形、转圈飞出或被道具整蛊，但只表现为2D/3D Q版角色的夸张变形和快速恢复；角色和道具沿【方向】移动到【落点】，符合重力、惯性和材质反应；镜头不跳切，同步听到【声音】。
[00:10-00:15] 【角色名称】以【机智／反击／恢复／好笑定格】完成反转；【结尾物件】发生【合理变化】，角色保持【表情与姿势】定格，画面完整结束。

【限制】一个核心事件、最多四个主要动作；道具先出现再使用；只有 Q版角色可以出现非写实殴打、撞击、压扁、折皱、弹性变形、边角破损或夸张伤害效果；真实场景必须保持摄影感，不要变卡通；不要把冲突表现为真人、儿童、动物受伤，不要血液、真实伤口、骨折、残酷虐待、危险操作教学、乱码文字、水印或额外无关角色。
```

## 模型不可用或调用失败

```markdown
如果目标模型不可用：说明“【模型】当前不可用，原因：【已知原因／暂时无法确认】”，只展示系统实际提供的可选模型；不虚构模型、版本、价格或点数，也不执行调用。

如果模型调用失败、超时或平台因动作描述拒绝输出：立即停止，不自动重试、不自动追加生成。告知“调用失败／平台暂时无法输出；原因：【已知原因／暂时无法确认】；扣点状态：【已确认／未知，请以模型界面为准】”，并让用户选择：
1. 使用原配置重试 1 次；
2. 改写动作后重新确认；
3. 结束本次生成。
在用户明确选择前不得再次调用。
```

## 输出前检查

- 是否已确定全智能托管或手动确认；用户说直接生成时是否进入全智能托管？
- 全智能托管下是否直接生成，手动确认下是否才逐步确认？
- 无图时是否按模式选择或确认了图片模型，有图时是否跳过了角色图生成？
- 是否已按模式明确固定拟声叫声、不说话或中文台词？
- 是否能单条生成就不分段；需要分段时是否先设置总时长？
- 分段后是否先让用户确认片段和剪辑方案，再智能剪辑合成？
- 手动确认模式下是否已让用户选择 2.5 或 2.0，并在调用前收到与所选模型一致的确认？
- 模型调用前是否展示了完整配置、生成数量和点数提示？
- 是否确认角色可为 2D简笔画纸片人、2D Q版插画或 3D Q版IP，环境与道具必须为真实摄影感，且角色保持成人拇指大小？
- 固定拟声叫声是否最多 2 次，中文是否只有 1 句，且默认不与另一类角色声音混用？
- 模型不可用时是否说明原因、展示实际可用选项并跳过调用？调用失败／超时时是否停止并等待用户选择，未自动重试？
- 若用户要求殴打、伤害或整蛊，是否只表现为 2D/3D Q版角色的非写实夸张物理效果，并在平台输出不了时停止反馈而不是提前过度拒绝？
- 角色、场景、道具和镜头是否保持一致，且视频可以直接生成？
