## 八大构图公式

### 01 三分法 Rule of Thirds
主体放三分线交叉点，画面温和不压抑，视线流动自然。
```
[主体], rule of thirds composition, subject on third intersection,
balanced negative space, natural framing, cinematic breathing room
```
适用：自然/平衡/开阔，人物行走/旅途/抒情叙事。

### 02 对称构图 Symmetrical
中轴对称，极度稳定或庄重压迫。
```
[主体], symmetrical composition, centered on vertical axis,
balanced elements on both sides, formal, ritualistic, imposing
```
适用：秩序/仪式感/权力感，宫殿/对峙/正式场合。

### 03 引导线 Leading Lines
道路/走廊/栏杆等线条将视线引向主体。
```
[主体], leading lines composition, strong converging lines
drawing eye to subject, deep perspective, road or hallway vanishing point
```
适用：探索/命运/抉择，隧道/走廊/公路/楼梯。

### 04 框架构图 Frame Within a Frame
门框/窗框/拱门作为天然画框套住主体，聚焦视线。
```
[主体], frame within a frame, doorway framing subject,
layered depth, voyeuristic observation, intimate focus
```
适用：偷窥感/聚焦/封闭，门缝/车窗/镜中/拱门。

### 05 对角线构图 Diagonal
主体或动作沿对角线排布，制造张力与动感。
```
[主体], diagonal composition, subject on dynamic diagonal axis,
tilted horizon 5-15°, unbalanced tension, kinetic energy
```
适用：不安/动感/冲突，追逐/打斗/倾斜世界。

### 06 三角形构图 Triangular
主体形成稳定三角结构，古典绘画构图。
```
[主体], triangular composition, subjects forming pyramid structure,
stable balanced arrangement, classical painting composition
```
适用：稳定/权威/古典，三人对话/家庭/权力层级。

### 07 留白构图 Negative Space
主体偏居一侧，大面积留白，孤独或期待感。
```
[主体], negative space composition, subject small in vast empty space,
isolated, minimalist, contemplative loneliness
```
适用：孤独/渺小/期待，沙漠/雪原/空旷建筑/望向远方。

### 08 中心构图 Center
主体正中，强势直接，无歧义。
```
[主体], center composition, subject dead center,
direct confrontation, unavoidable presence, stark simplicity
```
适用：直面/宣誓/对抗，角色独白/终极对峙/身份宣告。

## 速查卡

| 构图 | 情绪 | 禁忌 |
|:---|:---|:---|
| 三分法 | 自然平衡 | 信息过载时主体淹没 |
| 对称 | 秩序压迫 | 过度使用=呆板 |
| 引导线 | 探索命运 | 线条无终点=失焦 |
| 框架 | 偷窥聚焦 | 框架过大=削弱聚焦 |
| 对角线 | 张力动感 | 连续使用=视觉疲劳 |
| 三角形 | 稳定权威 | 不适合双人戏 |
| 留白 | 孤独渺小 | 留白无意义=空洞 |
| 中心 | 直面对抗 | 连续使用=单调 |

## 三层构图模型

```
① 构图类型：选定策略（三分法/对称/...）
② 主体位置：在画框中的精确位置和占比
③ 空间层次：前中后景层次关系
```
