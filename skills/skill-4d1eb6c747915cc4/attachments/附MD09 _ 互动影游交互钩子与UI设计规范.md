## #做什么

本模块为互动影游专属的交互钩子与UI设计规范库。

解决互动影游“每次下一步无危机、无反转、无局势变化、UI与变量反馈脱节、交互界面廉价”的痛点。通过交互钩子检查表、选择界面UI规范与变量变化视觉反馈，确保玩家永远想点下一步。

## #需要什么输入

**最少提供：**

- 节点清单与抉择点设计
- 变量系统与结局体系
- UI风格偏好

**可选提供：**

- 特定视觉风格标签
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。交互钩子与UI设计环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则。

### 二、交互钩子检查表（核心铁律）

每次“下一步”必须至少满足以下任意一项：

1. 有危机（角色面临新威胁）
2. 有反转（局势发生剧变）
3. 有局势变化（力量对比、关系、利益发生改变）
4. 有信息揭露（关键信息浮出水面）
5. 有新的抉择（玩家面临两难）

**绝对禁止**：无危机、无反转、无局势变化的无意义翻页。

### 三、选择界面UI规范

1. **字体**：清晰可读，与世界观一致。
2. **主色**：与世界观匹配。
3. **警告色**：红色，用于高风险选项。
4. **背景**：半透明，不遮挡关键画面。
5. **按钮**：与世界观一致，有悬停效果。
6. **变量提示**：在按钮附近显示本选项带来的变量变化。

### 四、变量变化视觉反馈

1. 变量增加时：屏幕上飘出金色+数字。
2. 变量减少时：屏幕上飘出红色-数字。
3. 触发死亡结局时：屏幕闪红+黑屏。
4. 触发真结局时：屏幕闪金+慢镜头。
5. 变量变化反馈必须与节点ID、变量名称严格对应。

### 五、结局画面情绪收尾规范

1. **好结局**：暖光+缓慢拉远+余韵。
2. **坏结局**：冷光+黑屏+一句话收尾。
3. **真结局**：金光+史诗感+环形镜头。
4. 所有结局必须有独立的一句话收尾台词。

### 六、UI与变量系统联动（强制）

1. UI必须实时显示关键变量状态。
2. UI必须明确显示玩家的选择会带来什么后果（可选提示）。
3. UI必须与剧情氛围一致，禁止UI风格突变。
4. UI必须适配横屏与竖屏（按目标平台决定）。
