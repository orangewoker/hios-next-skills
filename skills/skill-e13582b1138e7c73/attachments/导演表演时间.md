# 导演、表演、时间与空间

## 1. 观众先于摄影

每场先写一句导演命题，例如“让观众先于客人发现，这场礼貌招待正在取消他的离开权”。再明确谁拥有这场戏，观众与谁共享信息，镜头主要是见证、陪伴、审视、空间观察还是延迟揭示。

逐节拍使用下表：

节拍与时间 人物目标／阻力 表面话题／潜台词 采取的策略 可见动作与聆听 角色知道 观众知道／被隐藏 转折触发／下一状态 按实际剧情填写 当下可执行目标及失败代价 不能只复述台词 试探、讨好、逼问、拖延、收买、撤退等 动作对象、开始和结束 分角色记录 明确信息先后 必须发生可识别变化

“愤怒、紧张、悲伤”不是完整表演指令。写成对另一个人做什么、听到什么后改变策略、用哪一个具体行为掩饰内心。

## 2. 对白与普通行为

对白承担至少一个任务：争夺定义权、测试秘密、拖延行动、转移注意、维护礼貌、迫使承诺、暴露矛盾。闲谈可以绕开正题，但要逐步增加人物关系或危险信息。

普通动作必须影响关系。例如不断续杯是拖延对方离席，倒扣杯子是拒绝控制。不要在每场机械加香烟、咖啡或切肉，也不照搬著名影片的对白或道具组合。

逐句或逐段注明：说话者、原文台词、指向对象、当前策略、动作、对方反应、停顿、打断与声音重叠。原文不可改时，只调整调度与切点；需要删改则提供可审查的具体文本和影响。

表演指导优先给一个可执行动作，保留自然聆听；不要把所有人统一成面无表情、低声慢说。克制与夸张的尺度由项目锁定，核心人物可存在差异。

## 3. 空间与机位坐标

每个场景绘制文本平面图或结构图，并附坐标表。以下为规范，不是固定布景：

```text
俯视；单位 m；房间西南角为 (0,0)，x 向东，y 向北，z 向上。
房间尺寸／门窗坐标与开向／桌椅范围／可通行区域：
人物 A、B、C 的起始位置、朝向、坐姿或站姿：
主要道具位置、归属、可见或被遮挡：
主光、实景灯及遮光物的世界坐标：
摄影机 C01、C02 的坐标、镜头高度、朝向和可行运动路径：
对话轴线端点／活动区域／观察者轴线／屏幕左右映射：
```

世界坐标和屏幕坐标分开。所有左右说明需注明“画面左”“角色自身右”或“场景西”，不要混写“左边”。无精确场地时尺寸标为设计假定，并保持后续统一。

摄影机的镜头高度以地面为基准；垂直角正值明确约定为向上或向下，并全片一致。建议直接写“俯拍 5°／仰拍 5°”，减少符号歧义。

## 4. 调度与轴线

逐节拍记录位置、朝向、视线、站坐、前中后景、谁控制出口、谁控制物件，以及动作的起止触发。动作路径不能穿过桌子、墙或另一人。

先决定人物为什么移动，再考虑画面变化。门口、空椅、窗边和台面是有用途的空间锚点，不是通用装饰。

建立轴线与出入方向；反打保持视线配对和物件左右逻辑。越轴若有戏剧动机，仍须通过可见跨轴运动、中性机位、人物重新布位或建立镜重置空间。仅写“权力反转”不足以解决剪辑方向混乱。

背景人物应有行为、路径、触发和复位规则。镜面和玻璃场景先检查反射几何，复杂反射无法稳定时减少同时可见人数，保留核心信息关系。

## 5. 成片时间线

目标时长由故事选择，默认不超过 300 秒。开场尽快让观众遇到异常、冲突或未解问题，不规定每次都在三秒内强台词或快速切镜。

可用结构：异常出现 → 礼貌或日常表面 → 信息差加深 → 策略受阻 → 决定性变化 → 后果与余味。按剧本调整，不强行加入反转或暴力。

规划时分别计算：

- 台词自然朗读时间，注明估算或实际试读；包含角色差异、语气、呼吸和打断。
- 不与对白重叠的动作、观察和反应停顿。
- 片头、章节卡、黑场、片尾及转场在主时间线中独占的时间。
- 音画重叠按真实占用计算，不把同时发生的台词与动作重复相加。

镜头在时间线上使用半开区间 \[in, out)，duration = out - in；总成片时长由主视频时间线终点确定。叠化重叠计一次，J/L 声音跨切不增加画面时长。生成头尾余量是素材，不自动计入成片。

对白主镜可持续较长，但必须有可见或可听的节拍变化；反应、细节和爆发镜头由信息需要定长。原版观察 5–15 秒、对白 10–60 秒以上、细节 0.5–2 秒等仅作风格候选，不是即梦能力或每镜强制长度。

平台单次生成长度不足时，由编译器设计片段和切点，不简单把每个长镜等分。若无法可靠连接成无切长镜，改成有动机的剪辑，并更新 SH 编号和总表；不得仍声称是一个连续长镜。

## 6. 覆盖与剪辑

每镜标记“必需／支持／可选”。先保住人物关系、信息揭示、转折和可剪辑性，再加入装饰镜头。时长超限时先移除重复信息与可选覆盖，不把所有台词机械加速。

写明切点：一句话尚未说完的动作、一次目光转移、道具落桌、揭示发生、声音先到或刻意不展示反应。反应可延迟，但必须解释延迟如何影响观众，而不是总是慢一拍。

首镜、末镜、首次特写、最宽镜、最长停留和最复杂运动具有结构意义，避免都集中在开头。

## 7. 声音与发布画布

声音分别记录对白、同期动作、环境底、画外事件、音乐和静默变化；为声音确定空间方位与远近。音乐说明节奏、乐器、质感和进出点，默认描述原创或可用音乐方向，不凭空宣称已获某首商业歌曲授权。

创作画幅、生成画幅、交付画布分别记录。默认沿用 2.39:1 只是创作决定。若平台不支持该生成比例，在支持的画幅内预留裁切并计算有效区；不能把最后裁切掉的门口或第二人物当作有效叙事信息。

16:9 或 9:16 是用户可覆盖的选择。变更后重新调度与构图，不能简单截去两侧。字卡和字幕默认后期制作，检查是否遮挡脸、手与道具；移动端缩小预览验证阅读。当前平台导出规格或界面遮挡范围需要实际核验，不写未经确认的官方数值。

发布前的画面、声音和字幕检查只评价可见成片；不承诺推荐量、爆款或平台审核结果。
