# 分镜生成与低噪点改图模板

只在制作分镜或修改已生成图片时读取本文件。

## 分镜参考职责

在每张分镜提示词开头说明参考职责：

```text
参考图1＝【人物三视图】：只锁定人物身份、五官、发型、体态、服装和材质；不复制纯白背景、面部特写和多视图排版。
参考图2＝【空场景母图】：锁定建筑结构、门窗、固定物、材质、色彩和光线方向。
参考图3＝【道具母图】：锁定道具外形、尺寸、正反面、材质和当前状态。
参考图4＝【已有构图或关系图，如有】：只锁定机位、轴线、遮挡、人物位置或构图中心。
```

只上传实际使用的参考图。Lib Navo Pro 最多使用 7 张；参考职责冲突时减少参考，而不是继续堆图。

## 单张分镜模板

```text
使用 Lib Navo Pro，按照【视觉设定】和以上参考职责生成一张独立分镜图，比例为【比例】。

镜头功能：【本镜唯一叙事任务】
景别与机位：【远景/全景/中景/近景/特写/过肩；镜头高度、方向和正反打侧】
场景锚点：【门窗、固定物、前景、中景、背景和构图中心】
人物关系：【人物位于左/中/右和前/中/后景；朝向、视线、动作起点、表情】
道具状态：【位置、朝向、是否接触、由谁操作】
光线与色彩：【继承视觉设定，只写本镜变化】
运动留白：【为后续推、拉、摇、移或人物运动保留的方向】

保持所有批准资产的身份、结构、尺寸、材质、年代和光线连续性。只生成这一张镜头图，不生成拼图、多面板、角色卡、文字、字幕、编号、Logo或水印。
```

当主体动作将用于后续视频时，优先表现“动作刚要发生”的起始状态，而不是动作完成后的终止状态。

## 是否需要新分镜图

以下情况才生成新图：

- 新的正反打侧、过肩前景、视线轴或屏幕方向需要锁定。
- 人物左右、前后、遮挡、出入口或多人站位发生关键变化。
- 关键接触、递交、门的状态、道具状态或动作衔接必须准确。
- 构图、揭示、反射、画中画或可读信息决定剧情理解。
- 地点、时间、光线、服装、参与人物或关键道具状态发生不连续变化。

新的镜号、台词、普通表情、时长、简单动作、常规景别调整或普通机位变化本身不要求新图。相同视觉设置优先复用已批准分镜。

## Lib Navo Pro 受限改图模板

每次从批准母图重新分支，不从多次改图结果继续编辑。

```text
以【批准母图】为唯一源图，只修改【一个明确区域或问题】。

必须保持：人物身份与五官、发型、服装、身体比例、场景结构、透视、构图、光线方向、道具尺寸与位置、画幅比例，以及所有未点名区域。

目标修改：【可核验的新状态】。

输出干净数字源：无胶片颗粒、传感器噪点、重复微纹理、压缩痕迹、脆硬HDR、过度锐化、光晕、边缘融化、随机文字、Logo或水印。不要增加未要求的人物、物体和装饰。
```

一次改图只解决一个问题。若构图、身份、透视、人体结构或大面积几何错误，直接从批准资产重新生成；不要用连续局部改图强行挽救。

## 验收

- 正常查看和放大检查时均无明显噪点、重复纹理、融边、光晕、畸形肢体或过度锐化。
- 人物、场景、道具均可追溯到批准母图，没有新发明的服装、建筑、物体或图案。
- 正反打遵守已建立的轴线、视线、左右关系和背景方向。
- 改图没有污染未点名区域，且仍能作为后续分镜参考。
