# CHANGELOG

- 明确真实感不以行走或位移为唯一标准；
- 新增行为、关系、环境三类开篇锚点；
- 新增直接推荐、经验分享、偷听对话、正式解释四种传播模式；
- 新增单人、双人、三人同桌和场景互动关系设计；
- 新增场景原生道具系统；
- 新增旁听感与反销售感构图；
- 新增产品延迟露出逻辑；
- 扩充传播策略、场景关系和产品露出预检；
- 更新提示词模板、项目状态和质检清单。
