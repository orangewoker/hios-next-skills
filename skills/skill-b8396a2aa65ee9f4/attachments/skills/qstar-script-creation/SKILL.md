# 启星旁白skill 发散版

## 一、适用场景

当用户没有提供详细材料，只提供一个大方向时使用，例如：

- 森林探索
- 海岛探索
- 沙漠戈壁
- 地质博物馆
- 星空露营
- 非遗体验
- 城市自然观察

## 二、任务目标

围绕用户主题进行启星亲子式内容发散，生成可执行的旁白逐字稿。

本 Skill 只负责：

- 主题理解
- 创意策略
- 场景和事件发散
- 旁白文案

不负责：

- 具体产品资料解析
- 分镜视频提示词
- 视频生成
- BGM
- 字幕
- 剪辑

## 三、发散边界

可以发散：

- 家庭处境
- 孩子的观察和任务
- 父母参与方式
- 环境氛围
- 通用的探索动作
- 情绪变化
- 家庭共同记忆

不得虚构：

- 真实机构
- 具体线路
- 价格
- 日期
- 认证
- 专业资质
- 教育结果
- 安全保障
- 已经存在的活动细节
- 特定品牌产品功能

如果用户主题需要依赖真实项目事实，应提醒用户补充材料，并切换材料解析版。

## 四、三步确认流程

必须逐步执行，不一次性输出全部结果。

### 第一步：发散视频策略

输出 1 个推荐策略，必要时可提供少量备选方向。

推荐策略需要说明：

- 核心家庭处境
- 孩子的探索目标
- 父母参与方式
- 情绪路径
- 最终家庭价值
- 为什么适合启星亲子

输出后停止，等待用户确认策略。

### 第二步：确认画面核心内容

策略确认后，规划：

- 核心人物
- 主要场景
- 时间与天气
- 探索事件
- 孩子动作
- 父母动作
- 安全动作
- 关键道具
- 情绪收束

内容应具有可视化可能，但保持通用，不伪装成真实已存在项目。

输出后停止，等待用户确认。

### 第三步：生成旁白逐字稿

只有前两步确认后才能生成。

## 五、文案要求

默认 60 秒版本：

- 正文旁白 180—200 个中文字符
- 固定 Slogan 不计入正文
- 每段不超过 40 个中文字符
- 段落之间空一行
- 不出现“第一段”“第 N 段”等字样
- 每段对应一段视频
- 文案段落建议为 5—7 段
- 最后一段品牌片尾由总控 Skill 添加

表达方式：

- 具体
- 温暖
- 克制
- 自然
- 有纪录片观察感
- 不叫卖
- 不强行升华
- 不写成活动清单
- 不使用人物对白
- 不提前念固定 Slogan

## 六、时长适配

60 秒参考：

- 正文旁白：180—200 字
- 正文时长：约 53—55 秒
- 固定片尾：约 5—7 秒

其他目标时长按自然语速调整。

文案过长时应重新编辑，不通过明显加速语音解决。

## 七、最终输出格式

### 视频策略

一句话概括已确认方向。

### 正文旁白

只输出最终旁白内容。

段落之间空行，不添加编号。

### 字数与时长

- 正文字数
- 预计正文时长
- 目标总时长
- 片尾预留时长

输出后停止，等待用户确认。

## 八、切换规则

出现以下情况时，停止发散并建议切换材料解析版：

- 用户补充了详细产品资料
- 用户要求严格呈现真实活动
- 用户要求具体路线、设施或服务
- 用户要求呈现认证、安全或教育成果
- 用户要求逐条提炼现有材料

## 九、自检

- 是否用户确实只有主题而没有详细材料
- 是否发散内容不冒充真实项目事实
- 是否逐步完成三次确认
- 是否只选择一个核心策略
- 是否不包含固定 Slogan
- 是否 60 秒控制在 180—200 字
- 是否每段不超过 40 字
- 是否段落之间空行
- 是否没有段落编号
