## 关卡衔接（上游已定）

风格样板与调参（G6）、节奏与输出格式（G7）已在上游确认；模型由 model-matrix 自动匹配并在 G9 汇报。

- 换风格 / 调样板 → 回退 G6

**G6 样板图生成**：图片节点 → 自动匹配首选模型(Seedream 5.0) → prompt = STYLE_LOCK_A + 剧本代表性场景，一次出 3 张（人物特写/室内中景/纯色舞台全景）。

**A 分支精细调参备查（G6 阶段使用）**：

- 人物比例: 更Q萌(2头身) ←→ 更成人(4-5头身)
- 线条风格: 无描边(纯色块) / 细线1px / 粗线3px
- 色块饱和度: 高饱和鲜艳 / 中等 / 莫兰迪柔和
- 光影: 纯平无阴影 / 轻投影 / 扁平长阴影
- 背景: 纯色底 / 几何图形装饰 / 场景化背景
- 动效密度: 密集 / 适中 / 稀疏

## G15 — 逐镜视频片段（分批）

```
[关卡G15-A: 视频确认 | 第N/N批]
  ├─ 🎵默认时长: ⚡3-4s/⏱5s/🧘6-8s(不超模型上限)
  ├─ ✅通过 | 🔄重生成 | 🎯指定重生成
  ├─ 🏃运动调整(指定镜号):
  │    ├─ 镜头: 推近/拉远/平移/固定/弹性推拉(先过冲再回弹)
  │    ├─ 速度: 快/中/慢(默认跟随节奏)
  │    ├─ 🧑有主角: 角色动作/表情变化/入场退场(弹入/滑入/缩放)
  │    ├─ 🚫无主角: UI弹入飞入/图标旋转弹跳脉冲/文字逐行出现/图形变形路径移动
  │    └─ 通用MG: 弹跳(橡皮筋)/缓入缓出/路径动画/遮罩揭示/循环动效
  ├─ ⏱时长: 默认→手动3/4/5/6/8s
  └─ 🔀此镜临时切换节奏(覆盖全局)
```

## 🖼 Poster / 📊 PPT 子管线（输出格式为海报/PPT 时）

**5A-Poster 广告词收集（对话侧）**：主标题/副标题/核心数据/CTA/品牌信息，智能体提取+用户确认。 展示效果：数量(3/5/8张)/主题分配/视觉风格(大字冲击/插画+文字/图标+数据/纯色彩碰撞/混合)/动画/尺寸(1:1/3:4/9:16/16:9)/单张时长/播放模式。 6A-Poster：图片节点逐张生成（STYLE_LOCK_A + 排版描述，绑风格样板+色卡）。 7A-Poster：视频节点逐张生成动画。

**5A-PPT 内容收集（对话侧）**：大纲(封面→痛点→方案→优势→数据→案例→流程→CTA)/页数/增删/重排。 展示效果：PPT风格(极简商务/活力创意/数据驱动/故事叙述)/布局/页面切换与内容出现动画/单页停留/比例/配音。 6A-PPT：图片节点逐页生成；7A-PPT：视频节点逐页动画；静态页用分镜组导出 4K 带序号大图。
