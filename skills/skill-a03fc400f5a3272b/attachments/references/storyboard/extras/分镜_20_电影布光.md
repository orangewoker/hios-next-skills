# 电影布光

> **定位**：10 种布光方案的 Prompt 公式库。Phase 2 D5.3 布光策略选型时查询。

## 十大布光公式

### 01 伦勃朗光 Rembrandt Lighting
光源：侧前方 45°、视平线以上。特征：暗侧眼下倒三角光斑，戏剧化明暗反差。
```
[主体], Rembrandt lighting, single key light from 45° upper side,
distinctive triangle of light under the far eye, deep shadows,
chiaroscuro, cinematic portrait
```
适用：深沉/力量感/古典肖像。禁忌：补光过强=三角光斑消失。

### 02 蝴蝶光 Butterfly Lighting
光源：相机正前方、高角度俯打。特征：鼻下蝶形阴影，对称精致。
```
[主体], butterfly lighting (Paramount), frontal key light high above camera,
butterfly-shaped shadow under nose, soft glamour, polished skin
```
适用：优雅/精致/女性肖像。禁忌：深眼窝需增加补光。

### 03 逆光/轮廓光 Backlighting
光源：主体正后方。特征：边缘发光/发丝金边/体积光/剪影。
```
[主体], backlit, strong rim light, hazy atmosphere,
golden hour edge glow, cinematic volumetric light
```
适用：浪漫/空灵/怀旧/回忆。搭配：正面适当补光防全黑。

### 04 侧光 Side Lighting
光源：正侧方 90°。特征：半脸明亮半脸暗沉，强质感。
```
[主体], side lighting at 90°, half face illuminated half in deep shadow,
hard single source, sharp shadow edges, dramatic contrast
```
适用：冲突/冷峻/强对抗。禁忌：放大面部瑕疵。

### 05 顶光 Top Lighting
光源：正上方。特征：眼窝深陷阴影，神圣或压迫（看场景）。
```
[主体], top-down harsh lighting, deep eye socket shadows,
single bare bulb from directly above, ominous interrogation lighting
```
适用：神殿神圣/审讯压迫。必须搭配场景定义。

### 06 底光 Bottom Lighting
光源：正下方。特征：倒置反常阴影，诡异/恐怖。
```
[主体], uplighting from below, distorted facial shadows,
eerie single low source, horror movie lighting
```
仅适配惊悚/恐怖/荒诞风格。

### 07 柔光 Soft Light
光源：大面积漫射。特征：无锐利阴影，温柔治愈。
```
[主体], soft diffused lighting, large softbox, wraparound light,
no harsh shadows, gentle healing atmosphere
```
适用：治愈/清新/唯美。禁忌：画面戏剧张力不足。

### 08 硬光 Hard Light
光源：小型点光源。特征：阴影锐利如刀，硬朗纪实感。
```
[主体], harsh hard lighting, bare single bulb,
razor-sharp shadow edges, gritty realistic texture
```
适用：硬朗/野性/纪实。禁忌：不适合唯美人像。

### 09 环形光 Loop Lighting
光源：前侧 30-40° 上方。特征：鼻侧小型环形阴影，自然亲和。
```
[主体], loop lighting, key light 30-40° to side and above,
small loop shadow beside nose, balanced contrast, natural look
```
万能通用款，几乎无禁忌。

### 10 分裂光 Split Lighting
光源：正侧方 90°。特征：鼻梁中线严格左右对半，矛盾/分裂。
```
[主体], split lighting at 90°, face bisected light and dark,
no fill light, stark chiaroscuro contrast, geometric composition
```
适用：矛盾人格/双重身份。禁忌：鼻梁扁平者分割效果弱。

## 三层光影模型

```
① 主光意图：布光类型 + 角度 + 强度
② 光质修饰：柔光/硬光 + 光源面积 + 补光
③ 环境情境光：窗光/台灯/夕阳/霓虹等辅助光源
```
