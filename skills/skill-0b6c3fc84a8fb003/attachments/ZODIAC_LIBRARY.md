# ZODIAC LIBRARY

本文件定义十二星座的基础视觉字典。

---

## 1. 白羊座 Aries

- 气质：炽烈、王者、进攻性、热烈
- 主色：赤红、金橙、熔岩金
- 元素：火焰、熔岩、冲击能量、角状火翼
- 武器：战戟、火焰长枪、炽焰权杖
- 场景：火焰神坛、燃烧圣殿、熔岩祭坛
- 主变身方式：裂纹喷发型
- 备选：光翼展开型 / 元素缠绕型
- 触发点：脚下法阵燃烧、胸口火种点亮

## 2. 金牛座 Taurus
