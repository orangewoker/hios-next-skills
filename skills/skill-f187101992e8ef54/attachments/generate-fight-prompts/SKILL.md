# AI 动作导演／武术指导

先设计武器、空间和攻防因果，再写画面。目标是少而清楚、可执行、可迭代的影视动作，不是罗列招式或提供现实伤害教学。

## 职责边界

在本套件正常运行中，由 `$ai-video-director` 根据剧本自动触发本 Skill。只负责打斗、追逐、摔倒、抓握、闪避、多人身体交互、道具受力，以及重心、受力、惯性、回弹、动作节奏、当前时长内可执行性和降级方案。结果属于内部制作过程，必须交回主导演；不生成第四个正式交付部分，不自行编译任何视频平台专属 Prompt，也不要求用户再次手动调用其他 Skill。

## 1. 建立输入简报

记录：

- 每名角色及稳定编号；
- 人物图、场景图、动作图和镜头参考的职责；
- 时长、画幅、风格、强度、胜负和特效；
- 用户明确的动作与不可改变项。

缺失信息不实质改变动作时采用可修改默认值。不要把默认值冒充用户要求。

## 2. 识别人物与武器

为每名角色记录武器类别、判断依据、握持、尺寸、单双手、适合距离、置信度和容易混淆的类别。

看不清时使用“长柄武器类、直刃剑类、单刃长兵器”等上位类别，不凭服装时代硬猜。需要现实技法时读取 [research-and-sources.md](references/research-and-sources.md)。

## 3. 分析空间

识别地面、障碍、出入口、纵深、高低差、可破坏物和光线。判断长兵器展开、近身、闪避、绕行和摄影机通过的区域。

复杂空间、多人物换位、一镜到底或人物与摄影机路线容易失控时，标记空间调度需求并交回 `$ai-video-director`，由主 Skill 自动协调 `$create-overhead-blocking-diagrams`。不得为了套招式无视墙体、家具、台阶或狭窄通道，也不得要求用户手动转交。

## 4. 设计动作链

读取 [weapon-physics.md](references/weapon-physics.md) 和 [action-chain-design.md](references/action-chain-design.md)。默认筛选三至五个主要节点：

1. 建立距离和起势；
2. 明确进攻；
3. 可见防御、闪避或卸力；
4. 一次清楚接触、反击或距离变化；
5. 击退、停手、对峙或决定性收束。

每个节点写清谁行动、武器轨迹、身体方向、脚步与重心、对手回应、距离变化、接触反馈和镜头关注。

## 5. 选择镜头与反馈

按剧情目的选择：

- 空间建立：展示双方位置和攻击距离；
- 动量跟随：镜头沿进攻、闪避或追击方向移动；
- 命中反馈：接触瞬间短暂停顿、轻震或跟随受力方向；
- 收束：镜头稳定，展示结果和人物位置。

只在动作仍然清楚时使用环绕、低机位、急推、横移或甩镜。镜头震动短、轻、有明确接触点。

## 6. 控制生成难度

按需输出：

- 稳定版：三个动作节点，空间和接触最清楚；
- 平衡版：三至五个节点，适量镜头和环境反馈；
- 高燃版：更快节奏、强反馈和特效，并标明更高失败风险。

用户只要一个版本时默认交付平衡版，同时给出精简降级指令。不要无条件生成三套长 Prompt。

## 7. 安全与真实性

- 研究影视动作和武器原理，不提供现实中伤害具体身体部位的操作性指导。
- 区分来源事实、合理推断和创意设计。
- 幻想武器以最近现实原型推演，并明确标注。
- 不复制受版权保护作品的独特长动作编排或完整分镜。

## 8. 交接主导演

只输出“研究摘要＋动作节拍／动作链＋重心与受力反馈＋镜头关注＋风险与降级方案”，并交回 `$ai-video-director`，由主 Skill 按照即梦正式模板编译。主 Skill 在第一部分体现动作导演策略，在第二部分登记必要动作资产与提交状态，在第三部分编译最终镜头组。本 Skill 不独立输出任何视频平台专属 Prompt，不改变三个正式部分的栏目，也不把内部风险清单原样塞入最终 Prompt。

## 自动检查

- 人物、武器和动作是否正确绑定；
- 武器长度、重量、惯性和距离是否成立；
- 前一动作能否自然进入后一动作；
- 攻击、防守、接触和受力是否形成因果；
- 场景是否容纳动作与摄影机；
- 一镜到底是否与频繁切镜冲突；
- 特效是否遮挡人物、武器和接触点；
- 是否存在换手、穿模、身份互换、额外肢体或位置跳变风险；
- 来源是否真正支持相关事实。

Prompt 过载时，先删次要招式和特效，保留身份、武器、空间、因果和关键反馈。
