# 情绪曲线与镜头逻辑（成片补强）

天野流不用传统起承转合，而是**呼吸式情绪曲线（即「无叙事呼吸式」）**——全片统一一个空灵妖异主题，不靠戏剧冲突推进，也不写故事脚本。

---

## 一、妖异呼吸式情绪曲线（通用，所有色系共用）

```
静滞 → 微动 → 妖艳凝滞 → 余韵消散
```

- 静滞：主体悬浮于黑 / 纸白，几乎不动，淡金线环境初现
- 微动：发 / 衣袂 / 环境淡线开始同向微浮
- 妖艳凝滞：人物定格，疏离妖艳 / 哀艳达顶点（镜2 / 镜3 强化帧）
- 余韵消散：金线 / 色彩渐溶入黑或纸白，留一丝冷艳

（线稿态用「静滞 → 微动 → 凝视 → 羽化消散」；彩稿妖异态用上列。本质都是呼吸式，无叙事。）

---

## 二、视觉符号重复（首尾呼应）

主符号（和服衣袂 / 长发 / 鸟居 / 月 / 樱枝）必须在片中**重复≥2 次**且**首尾呼应**：
- 例：镜1 鸟居淡线初现（几根线）→ 镜3 鸟居呼应（同一根线微光）→ 镜末 溶入黑 / 金，与开头同一根线呼应。
- 这是 LibTV 2.2.2 风格美学垂类的完整性硬指标（替代五要素）。

---

## 三、镜头语言（运镜动机）

- **无重力缓浮**：推 / 拉极慢，模拟失重漂浮，非手持抖动。
- **极浅景深**：主体锐、环境淡线虚，强化「梦」。
- **溶解转场**：镜间用线条尾端溶解 / 金箔晕开过渡，禁硬切。
- **运镜动机 = 角色漂移或衣袂飘动**：镜头随发 / 衣袂 / 环境淡线的同向微动而移，**禁无动机随机抖动**（AI 最易犯）。
- 画幅：2.39:1 宽银幕（天野签名画幅）；竖版成片约 1080×1920。

---

## 四、情绪段落 × 音乐同步映射（默认空灵 Ambient）

天野流无强节拍，不用传统主歌 / 副歌结构。剪辑点对齐「情绪顶点」而非「鼓点重拍」。

| 情绪段落 | 视觉 | 与音乐同步 |
|----------|------|------------|
| 静滞 / 铺底 | 主体悬浮留白，淡线环境初现 | 长镜停留，pad 铺底 |
| 微动 / 初显 | 发衣袂微浮 + 符号初现 | 偶发钢琴单音咬符号出现 |
| 妖艳凝滞 / 顶点 | 凝滞定格 / 衣袂华满 | 弦乐长音咬情绪顶点 |
| 余韵 / 收尾 | 金线消散 | 乐句渐隐入混响，溶解收尾 |

---

## 五、红线（风格美学 2.2.2）

- 真实感可放宽（天野梦幻非写实，天然合规）。
- 完整度 = 统一视觉主题 + 情绪曲线 + 符号呼应，不以叙事五要素计（**无叙事呼吸式**）。
- **无台词纯氛围**（默认）：成片不加字幕 / 旁白 / 任何文字，只有画面 + 音乐。
- 六维视听语言：运镜 / 剪辑点须与情绪 / 音乐同步（见上），禁无动机随机抖动机位。
