# 附MD04 | 男频后宫·变量与结局扩展

**所属主SKILL：** 男频后宫 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“男频后宫 | 上架Steam的互动影游”的专属变量系统与结局体系扩展库。

解决互动影游“变量设定空洞、结局无分支、选项假大空、数值不驱动剧情”的痛点。通过严格的变量字典、严密的结局触发条件与路径推演，确保玩家的每一次选择都能真实改变男主与多位女主的羁绊命运。

## #需要什么输入

**最少提供：**

- 核心变量清单（如好感度、羁绊值、信任度、修罗场值等）
- 路线设计（女主A线、女主B线、女主C线、女主D线、隐藏线）
- 男主与多位女主的羁绊设定

**可选提供：**

- 结局数量与类型偏好
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。变量与结局设计环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则，确保结局路径逻辑闭环。

### 二、变量字典（强制锁定）

核心变量

1. 综合好感度：counter，0-100，默认0；≥60情感稳固；&lt;30情感疏离。
2. 羁绊值：relationship，0-100，默认0；≥60羁绊深厚；&lt;20羁绊浅薄。
3. 信任度：risk，0-100，默认0；≥70完全信任；&lt;30信任危机。
4. 修罗场值：counter，0-100，默认0；≥70修罗场爆发；&lt;30相安无事。
5. 势力信任：faction，0-100，默认0；≥80势力支持；&lt;20势力敌对。

路线专属变量

1. 女主A专属好感：relationship，0；≥50女主A倾心；&lt;20女主A疏远。
2. 女主B专属好感：relationship，0；≥50女主B倾心；&lt;20女主B疏远。
3. 女主C专属好感：relationship，0；≥50女主C倾心；&lt;20女主C疏远。
4. 女主D专属好感：relationship，0；≥50女主D倾心；&lt;20女主D疏远。
5. 全员羁绊值：relationship，0；≥80解锁真结局条件。

道具与旗标变量

1. 定情信物A：item，false；true且女主A好感≥60可触发女主A专属结局。
2. 定情信物B：item，false；true且女主B好感≥60可触发女主B专属结局。
3. 神秘玉佩：item，false；true且全员羁绊≥20可触发隐藏真结局。

### 三、结局体系（共15个）

正结局（5个）

1. E01·独宠女主A：女主A线，女主A好感≥60，修罗场值&lt;50。
2. E02·独宠女主B：女主B线，女主B好感≥60，修罗场值&lt;50。
3. E03·独宠女主C：女主C线，女主C好感≥60，修罗场值&lt;50。
4. E04·全员羁绊：隐藏真结局，解锁神秘玉佩+全员羁绊≥20+综合好感≥80。
5. E05·江湖浪子：任意路线，综合好感30-59，修罗场值&lt;30。

坏结局（10个）

 1. D01·修罗场爆发：修罗场值≥90。
 2. D02·信任崩塌：信任度&lt;30。
 3. D03·势力清算：势力信任&lt;20。
 4. D04·女主A决裂：女主A线，女主A专属好感&lt;20。
 5. D05·女主B决裂：女主B线，女主B专属好感&lt;20。
 6. D06·女主C决裂：女主C线，女主C专属好感&lt;20。
 7. D07·女主D决裂：女主D线，女主D专属好感&lt;20。
 8. D08·全员反目：全员羁绊&lt;10且修罗场≥70。
 9. D09·因果清算：所有变量失控。
10. D10·觉醒前陨落：N02选项B+修罗场值≥70。

### 四、结局触发条件表（快速查表）

1. E01：N02A→N04A→N06A-2→N08B；女主A好感≥60·修罗场值&lt;50·羁绊值≥30。
2. E02：N02A→N04B→N06B-1→N08B；女主B好感≥60·修罗场值&lt;50·羁绊值≥30。
3. E03：N02B→N04C→N06C-2→N07C-1；女主C好感≥60·修罗场值&lt;50·羁绊值≥30。
4. E04：N02B→N04C→N06C-2→N07C-2→N08C；神秘玉佩=true·全员羁绊≥20·综合好感≥80。
5. E05：N02A→N04B→N06B-3→N08B；综合好感30-59·修罗场值&lt;30。
6. D01：任意路线累积修罗场值≥90。
7. D06：N04A→N06A-1→N08A；女主C专属好感&lt;20。

### 五、结局路径示例（以E04全员羁绊为例）

N02B 质问天道（修罗场值+10）\
→ N04C 参悟·神秘玉佩（综合好感+20·全员羁绊+20）\
→ N06C-2 反问堵住反派（修罗场值-20）\
→ N07C-2 抬头直视反派微笑（获得神秘玉佩）\
→ N08C 全员豪赌（综合好感+30·全员羁绊+30）\
→ E04 全员羁绊（全员羁绊≥20·神秘玉佩=true）

### 六、变量锚定规则（核心铁律）

1. 每个节点提示词末尾必须标注：节点ID+变量变化。
2. 变量名全部用英文（affection/bond/trust/chaos/route），禁止中文变量名。
3. 变量一旦定义，中途不能改名。
4. 所有变量必须有定义、有使用、有结局影响。
5. 禁止无意义变量（定义了但从不影响结局）。
