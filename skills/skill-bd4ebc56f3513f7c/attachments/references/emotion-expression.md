# 情绪表情词典（Emotion Expression）

> 与气质词典的分工：**气质（`face-reading-lexicon.md` 第八节）写长期底色，落在骨相与常态表情；本词典写当下瞬时情绪，落在肌肉张力/注视/呼吸**。同一句人设里两者都要翻译，但去向不同——气质进"长相"，情绪只进"表情状态"。
>
> **交付形态提示（当前）**：本 skill 的唯一交付物是**浅灰底角色四视图设定图**，规格要求**无表情**——故**瞬时情绪层在当前形态下整体关闭**：情绪词一律不写进消息，表情恒为"面部肌肉放松、无喜怒、目光平静平视"。用户若给了瞬时情绪词，只作**气质参考**（可影响仪态与五官形态），不产生表情描述。本词典以下内容（张力三档/泄露点/矛盾情绪两层）在改回"带表情肖像"形态时才启用。

## 一、核心原则（先读）

1. **情绪是"表演层"，长相是"身份层"**：瞬时情绪描述不进档案骨相行、**不进多视角一致性锚定句**（锚定句只锁脸型/五官/发型/真实感锚点）。否则四视图会被其中一张的瞬时情绪绑架，其他视角跟着歪。
2. **情绪翻译只落三处**：面部肌肉张力、注视方向、呼吸/姿态。发往生图端的消息里**不写情绪名词，写肌肉事实**——"平静"→"唇线放松，眼睑微垂，目光平缓不闪躲"，而非"他看起来很平静"。
3. 负面情绪词（愤怒/恐惧/愧疚）同样翻译为中性生理事实，不夹价值判断。
4. **"苦相/愁苦"这类长期词仍走气质词典**（八字眉是骨相，进长相）；"此刻很愁/刚哭过"这类瞬时词走本词典（只进表情段）——区分不清会把一次情绪画进角色一辈子。

## 二、张力三档（决定肌肉参与度）

| 档 | 肌肉特征 | 适用情绪 | 典型示例 |
|---|---|---|---|
| **外放** | 肌肉充分参与、幅度大、连带呼吸与动势 | 暴怒、崩溃、大笑、狂喜 | 皱眉压眼 + 口型大张或紧咬、肩胸起伏大 |
| **克制** | 表情轮廓在但幅度收 | 日常喜怒哀乐、职场微笑、警惕 | 嘴角轻扬但眼睑不紧、眉微动 |
| **压抑** | 面部几乎不动，靠微泄露点 | 隐忍、强撑、冷怒、麻木、绝望的平静 | 见下方泄露点表 |

**压抑档不是面无表情**——必带 ≥1 个微泄露点，否则退化成"面无表情"：

- 眼睑边缘微红 / 泛水光、下眼睑轻绷
- 鼻翼微张（强压呼吸）
- 咬肌（下颌侧）绷紧；唇线**用力闭合**（区别于放松的抿）
- 目光过于稳定不眨 / 或频繁飘向画外低处
- 呼吸浅：胸廓起伏大于肩动
- 喉结上下微动（吞咽）
- 手部入画时：指节攥紧或指尖轻颤

## 三、矛盾情绪：拆两层（"X 但 Y"结构）

用户说"笑着但眼底是冷的"，后端 Agent 只会画一个"微笑"把后半句丢掉。规则：**主导表情层 + 泄露层**，各给肌肉事实，两行并发送。

| 描述 | 主导层（给镜头看的） | 泄露层（藏不住的，≤2 点） |
|---|---|---|
| 笑着但眼睛是冷的 | 嘴角上扬、颧肌轻提（笑意只到嘴） | 眼轮匝肌不参与（眼睛不笑）、目光聚焦锐利、眉梢微压 |
| 平静但藏不住焦虑 | 唇线放松、表情平稳 | 目光频繁飘向画外一点、下眼睑微紧 |
| 疲惫但强撑清醒 | 眼睑努力抬起、站姿/坐姿努力端正 | 眼睑边缘微红、目光偶尔失焦、眼下肌肉松弛 |
| 刚哭过强撑没事 | 表情努力平直 | 眼周与鼻尖微红、眼角残余水光 |
| 客气但疏离 | 嘴角礼貌性上扬 | 目光不接触（略偏开）、身体微侧倾 |
| 笑着但刚受了辱 | 嘴角上扬弧度僵硬 | 下颌咬肌绷紧、笑意未到眼、目光下垂闪避 |

触发词：用户用了"但/却/仍/强/硬/藏不住/压着/忍着"，或表面词+内里词并列 → 触发分层。泄露层丢了 = 只剩一张假笑，必须两层都在。

## 四、中文情绪词 → 肌肉事实速查

落点统一为：眉 / 眼 / 口·下颌 / 注视 / 呼吸姿态。括号内为默认张力档。

- **愉悦·满足**（克制）：眉平缓，眼睑放松，嘴角自然上扬，目光温和。
- **微愠·不快**（克制）：眉轻压，唇线平直微抿，目光略下垂，呼吸稍重。
- **冷怒·压抑的愤怒**（压抑）：面部平静，下颌咬肌轻绷，目光定住不眨，呼吸刻意放缓。
- **暴怒外放**（外放）：眉头下压紧蹙，眼睑紧绷，口张开或紧咬，颈侧肌肉绷。
- **悲伤**（克制）：眉内端微扬下垂，眼睑低垂，嘴角下拉，目光失焦。
- **崩溃大哭**（外放）：五官挤压，口大张，眼周泛红，肩头抽动（泪痕至多 1–2 道，不画花脸）。
- **麻木·空洞**（压抑特例）：全脸肌肉松弛无张力，目光凝住不聚焦，唇微张不闭——靠"过度松弛"而非泄露点。
- **落寞·失意**（克制）：肩微塌，目光垂向低处，嘴角放松下垂，动作迟滞。
- **绝望的平静**（压抑）：极静——目光平直无波澜、唇线平、呼吸浅不可见，用"长时间不眨眼"作泄露点。
- **焦虑·不安**（克制）：眉间轻蹙，目光频繁扫动或飘向画外，下唇轻抿或微咬，坐姿前倾。
- **警惕**（克制）：眉微压，目光聚焦固定点，头部微侧，肩颈微绷。
- **恐惧**（外放/克制按人）：眼睑上提露眼白略多，呼吸急促可见，身体后倾或僵住。
- **愧疚**（克制/压抑）：目光低垂闪躲，眉内端上提，嘴角轻抿内收，头微低。
- **隐忍**（压抑典型）：面部控制得平静，咬肌绷、下颌微收，目光定在低处一点。
- **不屑·轻蔑**（克制）：单侧嘴角微提（不对称），眼睑微垂带俯视，鼻翼轻张。
- **怀疑**（克制）：单眉微挑，眼睛微眯，嘴角向一侧微偏，头微侧。
- **期待·急切**（克制）：眼睑微张有神，重心微前倾，眉轻扬，嘴角待发未扬。
- **心不在焉**（克制）：目光穿透镜头（失焦），面部肌肉静置无张力，头微偏。

## 五、情绪受气质 / 年龄 / 场景调制

1. **先查气质，再定档**（气质表在 `face-reading-lexicon.md` 第八节）：城府深 / 清冷 / 威严 / 阴鸷 → 表达**压一档**（外放降克制、克制降压抑）；刚毅 / 忠厚 / 阳刚 → 克制为默认。用户点名场景（"他当场拍案暴怒"）除外。
2. 年龄倾向（非硬规则）：青年允许外放档；中年以后默认低一档。
3. 场景定可接受档：`occupation-environment.md` 给公共场景（会议/车间/市井/驾驶）→ 默认压抑~克制；独处/私密场景才放开。公共场合外放情绪先与用户确认。

## 六、质检（并入 realism-standard 第九节与主文件第 4 步）

- 情绪是否画成"情绪贴纸"（瞪眼假惊 / 咧嘴假笑 / 挑眉假怒，肌肉不真实）？
- 矛盾情绪两层是否都在？泄露层有没有被吞只剩主导层（假笑）？
- 压抑档是否退化成面无表情（无泄露点）？
- 瞬时情绪有没有污染长相（骨相/锚点被情绪带歪 → 重发时把锚点提为"四个视图必须一致"）？
- 张力档与气质是否匹配（城府深者被画成崩溃大哭，且非用户点名场景）？
