# 广告参数配置详细规则

本文档为 Skill 第八阶段「广告参数确认」的详细执行规则，SKILL.md 通过引用链接使用本文档。

---

## 一、参数确认前置条件

进入第八阶段前，以下产物必须已全部就绪：

| 前置产物 | 来源阶段 | 校验项 |
|----------|----------|--------|
| 商品图 + 质检 | 第一阶段 | 合格 |
| 投放渠道 / 画面比例 / 风格 / 时长 | 第二阶段 | 已确定 |
| 三视图 | 第三阶段 | 全部确认 |
| 品牌元素 + 片头片尾 | 第四阶段 | Logo/Slogan/类型/时长已确定 |
| 剧本 | 第五阶段 | 已确认，台词/旁白已锁定 |
| 分镜脚本 + 合规检查 | 第六阶段 | 10列分镜完整，第一轮合规检查通过，时长校验通过 |
| 场景图 | 第七阶段 | 全部场景图已确认 |

**前置检查清单**（Skill 内部自动执行）：
- [ ] 分镜脚本总时长已确定
- [ ] 配音文本（台词+旁白）已锁定
- [ ] 音效方案已标注
- [ ] 场景图全部确认通过
- [ ] 片头片尾时长已确定
- [ ] 画面比例已确定

任一项缺失 → 阻止进入，提醒用户回到对应阶段补充。

## 二、参数逐项确认规则

### 2.1 旁白/台词内容确认（配音和字幕的基础）

配音和字幕都基于旁白/台词文本生成，必须先让用户确认和修改文案内容。

**展示方式**：
- 按镜头顺序，展示分镜脚本中所有旁白和台词的完整文本
- 格式示例：
  ```
  镜头1（旁白）：这款精华液，让你的肌肤重焕光彩
  镜头2（台词）：我真的太喜欢这个质地了，一点都不粘腻
  镜头3（旁白）：轻盈配方，28天见证改变
  ```
- 标注每段文本对应的镜头号、类型（旁白/台词/独白）

**用户操作**：
- 确认通过：文案锁定，进入配音风格确认
- 修改文案：用户可修改任意镜头的旁白/台词内容
  - 修改后自动更新分镜脚本中对应镜头的台词/旁白字段
  - 提示用户："文案已更新，是否继续调整其他镜头？还是确认进入配音配置？"
- 增删台词：用户可增加或删除某些镜头的台词/旁白

**级联影响**：
- 修改旁白/台词内容后，后续配音和字幕均基于修改后的版本生成
- 若台词时长变化较大，可能在音视频时长匹配预检时触发调整

---

### 2.2 配音风格

**自动匹配规则**：
根据剧本内容自动判断配音类型：

| 剧本内容 | 配音类型 | 说明 |
|----------|----------|------|
| 有对话/对白 | 对话配音 | 模拟真人对话语气，自然流畅 |
| 有旁白/解说词 | 旁白配音 | 专业播音腔或轻松口语化，根据风格匹配 |
| 有独白/内心OS | 独白配音 | 低语感/私密感，适合情感类 |
| 混合（对话+旁白） | 混合配音 | 按段落分别匹配，旁白段用旁白音色，对话段用对话音色 |
| 纯画面无台词 | 不配音 | 仅保留音效 |

**音色选择规则**：
- 默认根据广告目标和受众自动推荐：

| 广告目标 | 推荐音色 | 备选音色 |
|----------|----------|----------|
| 品牌曝光 | 沉稳大气（男/女） | 知性温和 |
| 促销转化 | 活力热情（女声优先） | 亲和力强（男女均可） |
| 新品上市 | 科技感/未来感 | 年轻活力 |
| 活动引流 | 紧迫感和热情 | 轻松愉快 |

| 目标受众 | 推荐音色特征 |
|----------|-------------|
| 18-25岁 | 年轻、活力、网感 |
| 25-35岁 | 专业、可信赖、有品质感 |
| 35-50岁 | 稳重、温和、有质感 |
| 50岁以上 | 清晰、亲切、语速稍慢 |
| 母婴群体 | 温柔、柔和、安全感 |
| 运动群体 | 有力、节奏感、激励 |

**人物出镜时的音色一致性**：
- 当人物出镜=是时，配音音色需与人物描述卡中的气质基调匹配（如：知性气质→沉稳女声/男声；活力气质→年轻有活力的音色）
- 若有多个人物角色，不同角色需使用不同音色区分
- 用户手动指定音色时，以用户指定为准

- 用户可手动指定音色（从 LibTV 音色库选择）或输入需求（如"像纪录片旁白那样"）
- 语速：默认正常偏快（配合广告节奏），用户可调整（0.75x / 1.0x / 1.25x / 1.5x）

**配音语言**：
- 默认与剧本语言一致
- 用户可单独指定配音语言（中文/英文/日语/韩语/...）
- 多语言混合时（如中文旁白+英文Slogan），按段落分别指定

→ **用户确认配音方案** ✓（音色+语速+语言）

### 2.2 字幕（默认不加）

**默认规则**：字幕默认禁止，仅在用户明确选择后才添加。

**引导话术**：
> "视频默认不加字幕，画面更干净。需要添加字幕吗？"

**用户选择添加后，配置项**：

| 配置项 | 默认值 | 可选范围 |
|--------|--------|----------|
| 字幕内容 | 与配音内容一致 | 用户可自定义（如翻译版本） |
| 字幕语言 | 与配音语言一致 | 可单独指定（如中配英字） |
| 字体 | 系统默认无衬线体 | 思源黑体/苹方/微软雅黑/用户指定 |
| 字号 | 根据画面比例自动适配 | 小/中/大/自定义 |
| 位置 | 画面底部居中 | 顶部/中部/底部/自定义坐标 |
| 颜色 | 白色 | 自定义颜色 |
| 描边 | 轻微黑色描边 | 无描边/白色描边/黑色描边/阴影 |
| 背景条 | 无 | 无/半透明黑底/半透明白底/品牌色底 |
| 出现方式 | 随语音逐句显示 | 逐字/逐句/逐段/全部同步显示 |

**字幕安全区域**（确保字幕不被平台UI遮挡）：

| 投放渠道 | 底部安全区域 | 说明 |
|----------|-------------|------|
| 抖音 9:16 | 底部 15% | 避免被评论区和互动按钮遮挡 |
| 小红书 9:16 | 底部 12% | 避免被底部导航遮挡 |
| 朋友圈 1:1 | 底部 10% | 较为宽松 |
| 电商横屏 16:9 | 底部 8% | 横屏遮挡少 |
| 自定义 | 默认 10% | 用户可指定 |

**字幕时长同步**：
- 字幕出现/消失时间严格与配音对齐
- 使用时长校验脚本中的语速计算结果
- 每句字幕最短显示 1.5 秒（过短影响阅读）
- 每句字幕最长显示 5 秒（过长影响画面）

→ **用户确认字幕设置** ✓（或确认不加字幕）

### 2.3 标题文字叠加

**定义**：视频画面上固定显示的文字层，区别于随语音滚动的字幕。

**常见用途**：
- 商品名称/品牌名
- 促销价格/折扣信息
- 品牌标语/Slogan
- 活动名称/日期
- "立即购买"/"限时优惠" 等引导文字

**配置项**：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 文字内容 | 用户输入 | 空（不添加） |
| 显示时段 | 全程/指定时间段/仅片头/仅片尾 | 仅片尾（CTA阶段） |
| 位置 | 顶部/中部/底部/自定义 | 顶部居中 |
| 字体 | 同字幕字体选项 | 与品牌调性匹配 |
| 字号 | 小/中/大 | 大（标题需醒目） |
| 颜色 | 自定义 | 品牌色/白色/与画面形成对比的颜色 |
| 动画效果 | 无/淡入/弹入/打字机/缩放 | 淡入 |
| 描边/阴影 | 确保可读性 | 根据背景自动适配 |

**文字安全区域**：
- 标题文字同样遵守平台安全区域规则
- 顶部安全区域：各平台顶部 8-12%（避免被状态栏/标题栏遮挡）
- 标题不得与字幕重叠

**合规检查**：
- 标题文字叠加内容需通过合规检查（与剧本/分镜内容同等审查标准）
- 特别检查：促销价格须真实、折扣须有依据、"限时"须有明确时限

→ **用户确认标题文字叠加** ✓（或确认不添加）

### 2.4 导出格式与分辨率

**导出格式**：
- 默认：MP4（H.264 编码）
- 可选：MOV（Apple ProRes，高质量但文件大）
- 用户指定其他格式时确认兼容性

**分辨率选项**：

| 分辨率 | 适用场景 | 文件大小参考 | 说明 |
|--------|----------|-------------|------|
| 720P | 社交媒体预览/快速分享 | 较小 | 适合快速传播 |
| 1080P | 标准投放 | 中等 | **默认值**，适合绝大多数场景 |
| 2K | 高质量展示 | 较大 | 需确认源素材分辨率足够 |
| 4K | 大屏/高端展示 | 很大 | 需确认源素材分辨率足够 |

**源素材质量预检**：
当用户选择 2K 或 4K 时，Skill 自动执行预检：

1. 检查所有场景图的实际分辨率
2. 检查三视图的实际分辨率
3. 检查商品图的原始分辨率
4. 计算最低源素材分辨率

**预检结果处理**：

| 情况 | 处理方式 |
|------|----------|
| 所有源素材分辨率 ≥ 目标输出分辨率 | 直接通过，无提醒 |
| 部分源素材分辨率 < 目标输出分辨率 | 提醒用户："以下素材分辨率可能不足：[列出素材]，强行导出可能出现模糊/像素化。是否继续？" |
| 所有源素材分辨率均 < 目标输出分辨率 | 强烈建议降级："当前所有源素材均为 [实际分辨率]，建议选择 1080P 输出以保证画质。是否仍要导出 [用户选择的分辨率]？" |

用户选择：
- A. 坚持高分辨率（接受可能的画质损失）
- B. 降级到推荐分辨率
- C. 回到第一阶段/第三阶段/第七阶段，上传或重新生成更高分辨率的源素材

**帧率**：
- 默认：30fps（标准广告）
- 可选：24fps（电影感）/ 60fps（流畅运动）
- 帧率影响文件大小和流畅度，按用途推荐

→ **用户确认导出格式和分辨率** ✓

### 2.5 BGM（默认不加）

**默认规则**：BGM 默认禁止，仅在用户明确选择后才添加。

**引导话术**：
> "视频默认不加背景音乐，配音和音效已经足够表达。需要添加 BGM 吗？"

**用户选择添加后**：

**BGM 来源**：
- 由 LibTV 根据视频风格和内容自动生成
- 用户也可上传自己的音频文件

**BGM 配置**：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 风格 | 匹配视频整体风格 | 自动推荐（见下表） |
| 音量 | 相对配音的音量 | 配音音量的 20-30%（不抢配音） |
| 节奏 | 匹配视频节奏 | 与转场节奏同步 |
| 淡入/淡出 | 避免突然开始/结束 | 片头淡入1秒，片尾淡出2秒 |
| 循环 | 短片通常不循环 | 自动适配视频时长 |

**BGM 风格自动推荐**：

| 视觉风格 | 推荐 BGM 风格 |
|----------|---------------|
| 质感商业摄影 | 轻电子/钢琴/极简氛围 |
| 生活方式 | 吉他弹唱/轻快民谣 |
| 高端奢华 | 管弦乐/爵士/古典 |
| 科技数码 | 电子/合成器/科技感 |
| 国潮中式 | 国风/古筝/琵琶+电子 |
| 年轻潮流 | Hip-hop/电子/流行 |
| MG动画 | 轻快电子/打击乐/节奏感 |
| 3D卡通 | 欢快管乐/木琴/卡通音效 |
| 2D手绘 | 手绘感配乐/原声吉他 |
| 赛博科幻 | 合成器/暗电子/赛博朋克 |
| 国漫动画 | 国风管弦/史诗配乐 |
| 温馨治愈 | 钢琴/弦乐/自然白噪音 |

**BGM 与配音关系**：
- BGM 音量不得超过配音音量（确保配音清晰可辨）
- 配音出现时 BGM 自动降低（ducking）
- 纯画面无配音段落 BGM 音量可恢复正常

→ **用户确认 BGM 设置** ✓（或确认不加 BGM）

### 2.6 音效（基于分镜方案）

**音效来源**：分镜脚本第 8 列「音效」，在第六阶段已由 Skill 逐镜头标注。

**确认方式**：三选一

| 选项 | 说明 | 适用场景 |
|------|------|----------|
| **A. 接受分镜方案** | 直接使用分镜中的音效描述 | 默认推荐，大多数情况 |
| **B. 手动修改** | 针对部分镜头调整音效描述 | 用户对某些镜头的音效有特定想法 |
| **C. AI 重新匹配** | 忽略分镜中的音效规划，根据分镜画面内容重新自动判断 | 用户不满意当前音效方案 |

**选项 A（接受）**：
- 直接展示分镜中的音效方案摘要
- 格式：`镜头1: [音效描述] | 镜头2: [音效描述] | ...`
- 用户确认后使用

**选项 B（手动修改）**：
- 展示完整音效方案，用户指定要修改的镜头编号和新描述
- 修改后重新确认
- 修改上限：3 轮（与场景图修改共享轮次计数逻辑）

**选项 C（AI 重新匹配）**：
- Skill 根据每个镜头的画面描述、景别、运镜、风格重新判断适合的音效
- 音效匹配规则：

| 画面元素 | 匹配音效方向 |
|----------|-------------|
| 商品出现/展示 | 产品音效（轻盈的"叮"/"嗡"/材质音） |
| 转场/切换 | 转场音效（嗖/刷/whoosh） |
| 文字出现 | UI音效（打字音/弹出音） |
| 使用场景 | 环境音效（厨房/户外/办公室环境声） |
| 情感高潮 | 氛围音效（渐强/爆发/舒缓） |
| 品牌展示 | 品牌音效（标志性声音/logo音） |

- 重新匹配后展示新方案 → 用户确认

**音效合规检查**：
- 音效描述中不得包含违规内容（与文字内容同等标准）
- 音效风格须与整体视频风格一致

→ **用户确认音效方案** ✓

### 2.7 音视频时长匹配预检

**目的**：确保配音总时长与视频分镜总时长匹配，避免成片出现音画不同步。

**预检流程**：

1. **计算配音总时长**：
   - 使用时长校验脚本（`4-21-duration_validator.py`）
   - 根据台词/旁白文本 + 选定语速，计算预估配音总时长
   - 包含标点停顿和显式停顿

2. **计算视频分镜总时长**：
   - 将所有镜头时长求和
   - 包含片头、主体、片尾所有镜头

3. **比对结果**：

| 差异范围 | 状态 | 处理 |
|----------|------|------|
| 差异 ≤ 0.5秒 | ✅ 匹配良好 | 直接通过 |
| 0.5秒 < 差异 ≤ 2秒 | ⚠️ 轻微偏差 | 告知用户，提供选项 |
| 差异 > 2秒 | ❌ 明显不匹配 | 必须调整后才能继续 |

4. **不匹配时的调整选项**：

| 选项 | 说明 | 影响 |
|------|------|------|
| **A. 自动调整镜头时长** | 拉伸/压缩部分镜头时长以匹配配音 | 可能影响画面节奏 |
| **B. 调整配音语速** | 加快或放慢配音以匹配视频时长 | 可能影响听感自然度 |
| **C. 手动微调分镜** | 用户手动调整某些镜头的时长分配 | 回到第六阶段修改 |
| **D. 接受差异** | 忽略差异，由后期自动处理 | 可能出现轻微音画不同步 |

**自动调整策略**（选项A）：
- 优先调整非关键镜头（如过渡镜头、空镜）
- 片头片尾时长不动（已确认）
- 产品特写镜头不动（关键展示）
- 调整幅度：单个镜头最多 ±1 秒
- 调整后重新校验，直到差异 ≤ 0.5秒

→ **用户确认音视频时长匹配** ✓

## 四、参数修改与级联规则

### 4.1 参数修改影响范围

| 修改的参数 | 影响范围 | 是否需要回到上游 |
|-----------|----------|-----------------|
| 配音音色/语速 | 仅影响音频层 | 否，直接重新合成 |
| 配音语言 | 影响配音+字幕 | 否，重新生成配音和字幕 |
| 字幕样式 | 仅影响字幕层 | 否，直接重新渲染 |
| 标题文字 | 仅影响文字叠加层 | 否，直接重新渲染 |
| 导出格式/分辨率 | 仅影响最终输出 | 否，重新导出 |
| BGM 风格/音量 | 仅影响音频层 | 否，重新生成/调整 |
| 音效方案 | 仅影响音频层 | 否，重新生成 |
| 片头片尾时长 | 影响总时长和分镜 | 是，需回到第四阶段 |
| 画面比例 | 影响场景图和视频 | 是，需回到第二阶段 |
| 视觉风格 | 影响场景图和视频 | 是，需回到第二阶段 |

### 4.2 确认后修改规则

- 参数确认后，用户仍可修改任何参数
- 修改不影响上游产物的参数：直接在当前阶段重新配置
- 修改影响上游产物的参数：触发级联依赖链，提醒用户回到对应阶段
- 级联提醒格式：
  > "修改 [参数名] 将影响 [受影响阶段] 的产物，需要重新生成 [受影响产物]。是否继续？"

| 帧率 | 30fps |
| BGM | **不添加** |
| 音效 | 接受分镜方案 |

快速模式仅展示参数汇总表，用户选择：
- A. 全部接受默认值
- B. 进入精细模式，逐项确认
- C. 指定修改某几项参数

## 六、异常处理

### 6.1 配音生成失败
- 自动重试 1 次
- 仍失败 → 告知用户，选项：
  - A. 更换音色重试
  - B. 使用简化版配音（降低语速/简化文本）
  - C. 暂时跳过配音，仅保留音效

### 6.2 BGM 生成失败
- 自动重试 1 次
- 仍失败 → 告知用户，选项：
  - A. 更换风格重试
  - B. 使用系统预设BGM库中的备选
  - C. 跳过BGM

### 6.3 音效生成失败
- 单个音效失败不影响整体，标记为"音效缺失"
- 告知用户哪些镜头的音效未生成成功
- 选项：
  - A. 重新生成失败的音效
  - B. 使用相近音效替代
  - C. 该镜头静音

### 6.4 时长匹配无法调和
- 差异 > 5秒且自动调整无法解决时：
  - 提醒用户差异过大
  - 建议回到第五阶段调整剧本，或回到第六阶段调整分镜时长
  - 用户选择是否接受当前差异继续
