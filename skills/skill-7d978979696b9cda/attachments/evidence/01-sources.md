## 影视工艺来源

<a id="s01"></a>
### S01 原创故事与人物行为

[Tony Gilroy／BAFTA编剧讲座](https://www.bafta.org/media-centre/press-releases/screenwriters-lecture-series-2013-tony-gilroy/)，2013-09-29，研究已读完整文字稿。用于具体情境、人物欲望/行为、完整构思与场景修订；候选比较表和引擎压力检查是本包推论。不是固定节拍、创造力分数或完整编剧室教材。

<a id="s02"></a>
### S02 长剧人物变化与前传

[The Call Back／Television Academy](https://www.televisionacademy.com/features/news/features/call-back)，Amy Dawes采访Gilligan、Gould等，2015-02-17，正文已读。支持从转变的问题和起点开发人物；本包的知情/误信账、季集职责与影响传播是设计推论，不是文章给出的完整流水线。

<a id="s03"></a>
### S03 排练、空间和道具

[Sidney Lumet与Network／DGA](https://www.dga.org/craft/dgaq/issues/0305-may-2003/under-the-influence-sidney-lumet)，Kevin Lewis，2003年5月，正文已读。支持排练走位、布景标记、道具和贯通动作；原案例排练周数/拍摄次数不固定化。行动谱、空间/画面/机位分层为本包推论。

<a id="s04"></a>
### S04 跨集导演规范与选择性覆盖

[Playing With a New Deck／DGA](https://www.dga.org/craft/dgaq/issues/1301-winter-2013/house-of-cards)，Robert Abele，2013年冬，正文已读。支持跨集理解、团队连续性、主镜与选择性反应覆盖、运镜理由。它不构成禁手持、禁特写或镜头配额；覆盖矩阵是本包转化设计。

<a id="s05"></a>
### S05 身体节奏与构图

[Tom Cruise访谈／BFI Sight and Sound](https://www.bfi.org.uk/sight-and-sound/interviews/i-never-made-movie-just-go-make-movie-it-was-always-exploration-filmmaking-our-world-exclusive-interview-with-tom-cruise)，2025-05-23，正文已读。用于身体动作、摄影节奏和场景探索的个人实践；不强制所有作品先无配乐或某种表演次序。

<a id="s06"></a>
### S06 服装与故事状态

[Academy服装设计教学指南](https://www.oscars.org/sites/oscars/files/teachersguide-costumedesign-2015.pdf)，版权2014、文件名含2015，20页PDF已打开核查。第16页术语及职责支持服装设定、连续性、磨损状态；身份/状态/观察分层是本包扩展，不是模型人物锁定技术。

<a id="s07"></a>
### S07 美术、空间与分镜

[Academy/YMI美术设计指南](https://www.oscars.org/sites/oscars/files/complete_art_direction_activities_guide.pdf)，2003，8页PDF已读。Activity4涉及人物/场所、取景/机位/运动、草图/模型及陈设色彩与故事；是基础教学，不冒充完整专业美术课程。
