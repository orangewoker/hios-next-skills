# 即梦措辞优化

## 不可协商

- 对白逐字、逐序、逐说话人保留；不得改写、翻译、删减、换标点或重排。
- 剧情、人物、场景、道具、时间轴、动作因果、表演策略和结束状态不变。
- 只优化非对白执行描述；不在最终提示词提及政策、审核、过滤、违规或本指南。

## 最终处理顺序

1. 锁定全部对白与声源属性。
2. 扫描非对白中的暴力、犯罪、违禁品、恐怖极端、时政、自伤、骚扰隐私、危险行为、色情低俗、血腥恐怖、未成年人、不实营销、诈骗导流和知识产权风险表达。
3. 保留场景功能，降低露骨程度；优先写动作、材质、环境反应、道具状态、表演和抽象电影信号。
4. 删除现实伤害、违法、规避、欺骗、隐私获取或限制物品的可操作细节。
5. 使用 `risk-terms.md` 和风险检查器复核；每句锁定对白按原顺序写成 `说话人｜声源属性｜正文` 重复传给 `--dialogue`。单一 `【时间轴】` 中全部 `（说话人｜声源属性）“正文”` 标记必须与参数列表逐项完全相等后才豁免对白正文；对白外同词仍命中，缺失、替换、逆序、错人、错声源、额外或无结构引号对白均报错。

## 中性表达方向

| 风险面 | 优先改为 |
|---|---|
| 暴力、伤害 | 冲击波、尘土、火花、裂纹、布料边缘破损、踉跄、保护距离、余波 |
| 犯罪、违禁、诈骗 | 警惕交换、密封容器、受限物件、安全灯、紧张协商、虚构案卷 |
| 恐怖、超自然 | 冷雾、旧走廊、未知能量、昏暗纹样、压迫静止、突然阴影 |
| 自伤、危险模仿 | 孤独姿态、低头、雨水玻璃、安静压力、安全管理的非教学性动作 |
| 性暗示 | 完整服装、织物纹理、克制眼神、柔和侧光、得体姿态 |
| 隐私、骚扰 | 匿名人物、模糊文件、不可读屏幕、间接紧张、封存信息 |
| 未成年人 | 年龄适配行为、监护安全构图、无性化或危险行为 |
| 营销、导流 | 虚构标牌、通用界面光、无二维码、无外链、无无关水印 |

## 一致性检查

- 对白字节内容未变。
- 事件仍按母版顺序发生。
- 人物、道具、场景、镜序、动作结果和表演意图相同。
- 风险措辞转为可见电影语言，而不是删除剧情功能。

`jimeng-official-policy.txt` 是随 Skill 保存的本地静态规则快照，用于边界不清或用户明确要求时查阅，不冒充当前在线规则，也不需要每次生成都加载。
