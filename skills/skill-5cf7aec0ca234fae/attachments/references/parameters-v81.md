# V8.1 参数系统与参考图机制 · Parameters & References

本文档是 MJ Prompt Expert 的深度参考，覆盖 V8.1 完整参数系统、双冒号显式权重语法、四种参考图机制、以及多参考图任务分配法。

---

## 一、V8.1 完整参数系统

参数是在提示词写完之后调整模型行为的旋钮，但它们无法挽救一条主体没写清楚的提示词。以下以 2026 年 6 月的官方状态为准。

### `--ar`（画幅比）

设定画幅比。常用值：1:1、3:2、4:5、16:9、9:16、21:9。不存在跨场景通用的默认值，每次都应当显式设定。

### `--stylize` / `--s`（风格化程度）

在「忠实执行提示词」与「让 Midjourney 自由发挥其美学倾向」之间取得平衡。

| 范围 | 效果 | 适用场景 |
|------|------|---------|
| 0–100 | 模型紧跟字面指令 | 写实摄影、产品摄影、技术插图 |
| 100（默认） | 平衡 | 通用 |
| 500–1000 | 允许模型创意性偏离 | 艺术探索 |

> **V8.1 关键行为变化：** `--s` 超过 100 时，不同风格的差异会趋于收敛而非发散。追求极端风格差异化的场景，应使用参考图或多工具后期处理，而非仅靠高 stylize 值。

### `--chaos` / `--c`（混沌度）

控制四宫格中四张图之间的差异程度。范围 0 到 100。

| 值 | 效果 | 使用阶段 |
|----|------|---------|
| 0 | 四张输出几乎相同 | — |
| 20–50 | 适度发散 | 收敛阶段（找到方向后） |
| 50–80 | 剧烈发散 | 探索阶段（遍历可能性空间） |
| 100 | 极端发散 | — |

### `--style raw`（原始风格）

**这是一个开关而非数值参数。** 它抑制 Midjourney 的默认「自动美化」倾向，让出图更贴近提示词的字面含义。

以下场景应视为必加项：
- 写实摄影
- 建筑可视化
- 产品摄影
- 技术插图
- 任何需要图像看起来像相机拍摄而非绘画渲染的场景

### `--hd`（高清渲染）

启用原生 2K 渲染，输出 2048×2048 像素。

- 在 V8.1 中 HD 模式已是默认选项，不需要额外指定（除非之前手动切回了标准分辨率）
- HD 生成的 GPU 消耗约是标准分辨率的 4 倍，但获得 4 倍的像素数量且无放大伪影
- 界面中有一个「Run as HD」按钮，可将任何标准分辨率作业一键重跑为 HD，无需重写提示词
- **不要在探索阶段支付 HD 模式的 4 倍 GPU 成本**——标准分辨率存在的原因就是快速便宜地探索

### `--q`（质量与一致性）

V8.1 中仅支持两个值：

| 值 | 效果 | 代价 |
|----|------|------|
| 1 | 标准 | — |
| 4 | 改善含有大量互相作用元素的复杂场景的视觉一致性 | 约 4 倍生成时间和 GPU 消耗 |

### `--no`（排除项）

指定排除项。建议默认附加的基线：

```
--no text, logo, signature, watermark, blurry
```

> 不要过度加载此参数——过多负面指令会产生抽象伪影。用它排除特定的不受欢迎元素，而不是作为通用的质量拐杖。

### `--seed`（种子）

锁定噪声模式。当找到一张接近理想效果的图像时，记下它的种子号，锁定种子后每次只改变一个变量。

**这是系统性迭代的基础：**
- 同一种子、相同构图、不同光线
- 同一种子、不同镜头
- 不锁定种子时，每一次重跑改变所有变量，无从判断究竟是哪个变量驱动了画面的变化

### `--iw`（图像提示词权重）

控制图像提示词权重，范围 0 到 3，默认 1。

- 高值让参考图更有主导力
- 低值给文本提示词更多话语权
- V8.1 已恢复图像提示词支持（V8.0 中曾暂时不可用）

### `--weird`（奇异度）

引入超现实、实验性特征。范围 0 到 3000。谨慎使用，仅在明确期望模型颠覆常规预期时调用。

## 二、双冒号显式权重系统 `::`

Midjourney 使用 `::` 作为唯一的显式权重运算符。

### 语法规则（极为严格）

双冒号必须紧贴前一个词和后一个数字，中间不能有任何空格。

**正确写法：**
```
steam locomotive emerging from tunnel::2 fog and smoke::1.5 forest background::0.5
```

**错误写法（将会解析失败）：**
```
steam locomotive :: 2     ← 冒号前后有空格
steam locomotive:: 2      ← 数字前有空格
steam locomotive :2       ← 单冒号
```

### 权重规则

- 每个由 `::` 分隔的段落获得指定的权重倍数
- 未标注权重的段落默认权重为 1
- 权重在 **0.3 到 3** 的范围内最稳定，超出此区间的值可能导致不可预测的解析行为

### 负权重

负权重也受支持，用于精细的概念排挤：

```
sunlit clearing:: dark shadows::-0.5
```

这会将「暗色阴影」从画面中推开。

> 对于常规的对象排除，`--no` 更直观且更不容易出错。将负权重保留给「降低而非消灭某种质感」的场景。

## 三、四种参考图机制

Midjourney 提供四种截然不同的参考图机制，各自承担不同的功能。**混淆这四种机制是跨图不一致的最常见根源。**

### 机制 1：`--sref`（风格参考）

从参考图中提取**视觉风格**——色彩调色盘、笔触质感、光影质量、整体美学肌理——并将其应用于新生成。

- **不复制**参考图的内容、构图或主体
- 用 `--sw`（风格权重，0 到 1000，默认 100）控制风格转移的强度，数值越高越贴近参考风格
- V8.1 显著改善了 sref 的稳定性，风格参考的跨次复现一致性远胜过 V8.0
- `--sref random` 从模型的潜在空间中抽取随机风格，适合发现意想不到的美学方向

### 机制 2：`--cref`（角色参考）

在不同生成中保持**面部身份、发型和服装**的一致性。

- 用 `--cw`（角色权重，0 到 100）控制锁定的范围

| `--cw` 值 | 锁定范围 |
|-----------|---------|
| 100 | 锁定完整外观（面部 + 发型 + 服装） |
| 0 | 仅锁定面部特征（允许换装换发） |

### 机制 3：`--oref`（全参考 / Omni Reference）

一个统一参考机制，可**同时影响构图、风格和主体**。

- 用 `--ow`（全参考权重）控制影响力
- 建议起始值 **200–300**
- 这是最宽泛的参考工具，适合用单张参考图捕获整体视觉方向

### 机制 4：图像提示词（传统垫图）

将图片 URL 放在提示词最前端的传统方式，把参考图当作**构图和内容的视觉起点**，而非仅仅风格。

**与 sref 的关键区别：**
| | 图像提示词 | `--sref` |
|---|----------|----------|
| 提取内容 | 构图 + 主体信息 | 仅美学表面 |
| 功能 | 构图锚点 | 风格调性 |

**两者可组合使用**——图像提示词设定构图锚点，sref 锁定风格调性。

## 四、多参考图任务分配法

多张参考图同时使用时，最高效的方法是「**任务分配法**」——显式指定每张图承担什么职能。

### 标准四图分配

| 参考图 | 职能 | 定义内容 |
|--------|------|---------|
| 参考图一 | 身份锚点 | 面部、五官、肤色、发型 |
| 参考图二 | 服装定义 | 服装风格、颜色、面料、配饰 |
| 参考图三 | 构图与光线 | 构图、机位、光线、情绪 |
| 参考图四 | 背景与美学 | 背景、道具、整体美学方向 |

### 冲突优先级

多参考图之间的冲突优先级：

```
面部 > 服装 > 构图 > 背景
```

### 效果

这一任务分配法是将盲投多参考图的成功率从约 10% 提升到约 90% 的**单一最大杠杆**。

## 五、品牌一致性工具

### Moodboard（情绪板）

品牌一致性场景中最强的稳定性工具。

- 上传 6–20 张参考图构建一个品牌 Moodboard
- 之后所有 prompt 都挂在这个 Moodboard 下生成
- 跨 50–100 张图的风格一致性显著提升

### Personalization（个性化配置）

配合 `--p` 参数使用。

- 通过评分 200 张以上图像对训练出的个人审美偏好编码
- 可将品牌视觉系统的稳定度再推高一个层次

### 组合策略

```
Moodboard（锁定风格大方向） + --p（编码个人审美偏好） + --sref（单图风格微调） + --cref（角色跨图一致）
```

这是品牌视觉系统的完整稳定度工具链。
