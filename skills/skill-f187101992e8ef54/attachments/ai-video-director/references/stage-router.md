# 即梦制作阶段路由

## 固定参数

- `target_video_model = 即梦`
- `single_shot_group_max_duration = 15秒`
- `single_shot_group_max_characters = 4000字`

“第0章”“第一集”“这一幕”只限制故事范围。用户未明确缩小交付范围时，默认完整运行并同时输出三份独立DOCX：第一部分导演大纲、第二部分提示词与资产整合、第三部分完整镜头组提示词包。

只有用户明确要求“只要第一部分／第二部分／第三部分”时才缩小交付。完整运行不等待图片生成、上传或审核；第三部分可引用第二部分已登记的稳定计划资产编号。

## 运行顺序

1. 识别故事范围、画幅、风格取向、必须保留项、禁止项和已有素材。
2. 估算原文自然时长、推荐精炼时长和用户目标时长；判断软目标或硬限制。
3. 执行导演分析与专业辅助路由，形成第一部分。
4. 规划真正需要的六类资产，形成第二部分唯一总表和待生成资产卡。
5. 用已登记稳定编号直接编译第三部分；单组≤15秒、≤4000可见字。
6. 运行 `scripts/validate_complete_package.py`，再通过Word导出流程生成三份DOCX。

完整流程不存在资产提交就绪门、状态解锁门或第二轮回填门。用户之后提供新素材时，可在相同编号下迭代，但不改变默认一次交付三部分的规则。
