# 微缩世界场景与随机路线库

## 抽取规则

- 每次只选择一个场景；用户未选择时，先在四个场景间均匀随机，再从该场景的 `scene_run` 中均匀随机。
- 用户选择场景时，只在该场景的三个命名 `scene_run` 中均匀随机；原案例“花洒-衣架-鳄鱼-橡皮鸭-水龙头”不是默认路线，也不得优先抽取。
- 一次只选完整路线，不再把零散元素独立拼接；同一条路线内六段功能不重复，也不跨场景混入物件。
- 输出时必须报出 `scene_run` 名称与六段链，供用户一次确认。产品植入只放在该路线注明的自然陈列位。

## 画风转换

- 实拍微距质感：真实材质、微距景深、日光或场景自然光、可见水珠/织物/塑料细节。
- 3D 渲染动画片：高质量风格化 3D、触感材质、可控光影、夸张但连贯的尺度。
- 2D 卡通片：赛璐璐色块、清楚轮廓、手绘速度线和夸张透视；不混用写实微距毛孔或 3D 反光。
