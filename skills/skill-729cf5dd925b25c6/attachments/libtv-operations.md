# LibTV 画布操作手册

本手册是本 Skill 在 LibTV 画布（liblib.tv）上执行一切操作的唯一依据。所有步骤通过浏览器自动化完成；执行前确认已登录且页面加载完成。

---

## 1. 账号与配额检查（每次开工必做）

1. 打开 liblib.tv，确认登录态（未登录则引导用户手动登录，验证码/扫码由用户完成）
2. 读取当前会员档位与积分余额，记录进 manifest：
   - 档位 → 并发上限：专业版 6 / 大师版 10 / 旗舰版 20 / 尊享版 无限
   - 积分余额 → 与本次预算比对，不足则在 Step 2 就预警
3. 存储空间：确认剩余空间（50GB/130GB/200GB/500GB），大型项目提前预警

---

## 2. 项目与画布

- 每个广告项目 = 画布中一个独立项目（画布空间）。命名规范：`AD_品牌名_日期`
- 节点多时定期用「画布整理」（左下角按钮）保持布局可读
- 每完成一个阶段，在 manifest 记录关键节点 ID/位置，便于断点续跑定位

---

## 3. 五类节点操作

### 3.1 文本节点（脚本/分镜载体）

- 用途：存放分镜表、prompt 草稿、文案
- 操作：双击画布空白 → 选文本节点 → 粘贴/输入内容
- 分镜表以结构化文本存入（镜号/时长/景别/画面描述/运镜/转场/音效事件）

### 3.2 图片节点（关键帧/设定图/色卡/海报）

- 创建：双击画布 → 图片节点
- 生成参数：选模型（30+ 模型一键切换）、画面比例（16:9 / 9:16 / 1:1 / 3:4）、填 prompt
- **参考图绑定（核心操作）**：从已有图片节点向新图片节点连线作为参考；多图参考数量以所选模型上限为准（HappyHorse 最多 9 张；其余模型以界面提示为准）
- 生成后操作（按需选用）：
  - 高清放大（2/4/6 倍）— 用于成片级关键帧与海报
  - 扩图 / 局部重绘 / 擦除 / 抠图 — 用于修正局部瑕疵，**优先于整图重生成**（省积分）
  - 720° 全景 — 场景展示类镜头可选
- 一致性检查通过的图片节点，在 manifest 登记为「档案资产」（风格样板/色卡/角色设定/场景背景板）

### 3.3 视频节点（逐镜片段/转场片段）

- 创建：从图片节点拉线 → 视频节点（图生视频，关键帧自动作为首帧）
- 生成参数：选视频模型、时长（按模型规格，3-15s）、填运动 prompt
- 运动 prompt 只写运动：镜头运动 + 主体动作 + 动效元素；**禁止**重复描述外观/风格/色彩
- 生成后操作（按需）：
  - 首尾帧截取（节点右下角小相机）— 取尾帧供下镜参考或转场片段使用
  - 画面推演（3 秒后 / 5 秒前）— 延长镜头或补足衔接
  - 帧率提升（最高 90fps）— 需要丝滑慢动作时
  - 高清放大 — 成片画质增强

### 3.4 音频节点（BGM/音效/旁白）

- 创建：音频节点，选 Mureka 模型
- BGM：用情绪+场景 prompt 生成（如 "轻快活力的尤克里里企业宣传配乐，无歌词"）
- 旁白：文本生成配音（如平台支持 TTS/歌声），否则 BGM-only 并在物料包中提示用户另行配音
- 单点音效：平台音效能力有限时，以 BGM + 留白处理，不强行生成
- 人声背景音分离：素材再利用时使用

### 3.5 脚本节点（仅作结构化分镜展示）

- **注意**：本 Skill 不使用脚本节点的自动分镜与批量转图/批量转视频能力（预设管线，禁用）
- 如使用，仅把脚本节点当结构化表格容器；生成一律走手动图片/视频节点逐镜执行

---

## 4. 多图参考配方（一致性核心机制）

替代 LibTV 主体库的自有方案。每个关键帧图片节点生成时按配方绑定参考图：

参考图作用绑定规则风格样板图锁定风格每镜必绑色卡图锁定配色每镜必绑角色设定图锁定角色外观该镜有角色时绑定（多角色则都绑，不超模型上限）场景背景板锁定场景复用场景时绑定

- 超模型参考上限时的优先级：风格样板 &gt; 主角设定图 &gt; 色卡 &gt; 场景 &gt; 配角
- 图生视频时参考关系自动继承（首帧即关键帧），视频节点无需再绑风格参考

---

## 5. 模型切换

- 每个生成节点上可切换模型；按 `references/model-matrix.md` 该分支的首选模型执行
- 首选模型生成失败 2 次 → 换备选模型重试 1 次 → 仍失败报用户
- 禁用模型不得使用（风格崩坏风险），即使首选/备选都失败也先报用户而非偷换

---

## 6. 转场片段制作（LibTV 适配方案）

LibTV 视频合成仅支持片段拼接，无滤镜转场。特殊转场一律做成「转场视频片段」：

1. 上镜视频节点 → 首尾帧截取 → 得到尾帧图
2. 新建视频节点，以尾帧为首帧，prompt 描述转场运动（按分支转场词库，如「纸张从右向左翻起，露出新场景」）
3. 时长 0.5-1.5s（按节奏档位）
4. 转场片段作为独立片段参与合成排序

基础转场（同场景硬切/轻微叠化）：直接拼接，不生成转场片段。

---

## 7. 视频合成与导出

1. 全部片段（镜头 + 转场片段 + 片头片尾）确认后，框选 → 「视频合成」
2. 按分镜表顺序拖排，实时预览核对
3. 关联音频节点（BGM/旁白）
4. 可选后处理：整片高清放大 / 帧率提升 / 一键消除字幕（素材复用时）
5. 导出 MP4（最长 20 分钟），下载到本地 `final/`
6. 动态海报若需 GIF：平台只出 MP4，下载后用本地 ffmpeg 转 GIF（本地工具，非平台功能；`ffmpeg -i in.mp4 -vf "fps=12,scale=1080:-1" out.gif`）

---

## 8. 分镜组（PPT 静态页导出）

动画 PPT 需要每页静态图时：

1. 多选全部 PPT 页面图片节点 → 顶部「打组」→ 合并分镜组
2. 自动从左到右、从上到下排序（排序不对的节点先在画布上摆好位置）
3. 「一键合成」导出带序号的 4K 大图，下载到本地 `final/ppt_static/`

---

## 9. 并发与分批

- 批大小 = min(会员并发上限, 5)，逐批生成逐批验收
- 每批生成前估算本批积分并核对余额：图片张数 × 0.25 + 视频段数 × 10（以平台实际扣费为准）
- 余额不足 → 暂停，向用户报告并等待充值/降规模决策

---

## 10. 失败处理与断点续跑

场景策略单图生成失败/报错同 prompt 重试 ≤2 次 → 换备选模型 1 次 → 报用户风格漂移（角色/色板/笔触跑偏）弃图，不进入视频环节；检查参考图绑定后重生成视频运动不符仅改运动 prompt 重生成，关键帧不动任务排队/超时等待并查询任务状态；连续超时降并发批大小会话中断/浏览器崩溃重新登录 → 打开画布项目 → 按 manifest 状态机从最近未完成镜继续积分耗尽立即停止一切生成，向用户报告已用/剩余/缺口

---

## 11. 安全操作规范

- 所有删除/覆盖类画布操作前先确认 manifest 已记录对应资产状态
- 不改动画布上与本项目无关的节点（用户可能有其他项目）
- 登录、支付、充值类页面一律交由用户手动完成，不代为操作
