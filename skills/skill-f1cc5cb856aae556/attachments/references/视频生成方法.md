# 视频生成方法（成片第四资产）

本文件补齐 成片 Skill 的第四类复用资产：视频生成工程 knowhow。图片生成解决"一帧"，视频解决"连贯成片"。

---

## 一、Seed 一致性

- 同成片所有镜**锁定同一 seed**，保证线语言/色板统一。
- 不同镜仅换构图参数，不动 seed，避免"换演员"。
- 记录 seed 到分镜表备注列，便于复现。

---

## 二、图生视频（image-to-video）

- 优先用**定稿静帧**做首帧，再图生视频，保证风格锚定。
- 运动幅度设**极低**（天野流是"微动"而非"大动作"）：飘浮位移≤画面 5%，发/翼尾端缓动。
- 运动类型选 `drift / float / breathe`，禁 `walk / run / fight`。

---

## 三、关键帧策略

- 呼吸式曲线：镜1 静帧 → 镜3 凝视（光环强化帧）→ 镜末 溶解帧。
- 关键帧间用**溶解/晕开**过渡，非硬切。
- 每镜 3–10s，全片 16s–5min。

---

## 四、循环与呼吸节奏

- 短视频（16–30s）做**无缝循环**：首尾帧线语言一致，溶解相接。
- 呼吸节奏：发/翼/衣袂同向微浮，周期 4–8s，与情绪曲线同步。
- 禁随机抖动机位（破坏气韵同源）。

---

## 五、分辨率与画幅

- 画幅 **2.39:1**（如 1536×640 / 1920×800）。
- 分辨率 **≥1080p**；导出避免压缩块（用无损/高码率）。
- 宽银幕黑边由画幅本身提供，不靠后期加框。

---

## 六、反闪烁 / 反碎裂

- 视频模型易在细线处闪烁：运动幅度压到极低 + 同源线语言可显著缓解。
- 若翼/发边缘碎裂，回退到"气韵总纲统领"重生成静帧，再图生视频。
- 天野流"未完成感"反而利好视频——轻微线抖可视作手绘呼吸，不必强行去噪。

---

## 七、叙事主题写法（无叙事呼吸式）

天野流成片**不写故事脚本**，不靠戏剧冲突推进。全片统一一个空灵主题，靠"情绪曲线 + 符号呼应"撑起完整度（这与 LibTV 2.2.2 风格美学垂类"不以叙事五要素计完整度"一致）。

skill 内"叙事"维度只写三样：
1. **主题锚点**（一句话，如"羽落之梦""月下神性""金线与虚空中"）
2. **情绪曲线**（线稿=静滞→微动→凝视→羽化消散；彩稿=华美展开→凝滞神性→余韵）
3. **符号首尾呼应**（翼 / 光环 / 长发 / 月 重复≥2 次且首尾同一根线）

**禁用**：角色动机、事件、对白、起承转合五要素。完整度 = 统一视觉主题 + 情绪曲线 + 符号呼应。

---

## 八、音乐风格词库（默认空灵 Ambient）

- **默认风格**：空灵氛围 Ambient —— 合成器铺底、无强节拍、大空间混响、偶发清冷乐句，最贴合天野梦幻非人、冷 fantasy 的气质。
- **风格词**（写入音乐需求时直接用）：
  `ambient, ethereal soundscape, analog synth pad, granular reverb, no strong beat, slow drift, cold space, minimal piano motif, bowed strings sustained, glassy bells`
- **段落映射**（对齐情绪曲线，非传统主歌副歌）：
  - 静滞 / 华美展开 → 长音 pad 铺底，极少变化，留白呼吸
  - 微动 / 凝滞神性 → 偶发钢琴单音或弦乐长音，咬情绪顶点
  - 羽化 / 余韵 → 乐句渐隐入混响，留白收尾
- **备选风格**（仅用户主动要求时更换）：古典弦乐+钟磬 / 新世纪 New Age / 留白静默。

---

## 九、台词策略（无台词纯氛围）

- **默认**：无台词纯氛围 —— 只有画面 + 音乐，不加任何文字、字幕、旁白。最克制、最天野、最高级，符合"气韵导向"第一性原理。
- skill 默认产出**不含任何台词资产**。
- 若用户后续明确要求加文案，仅两种降级选项（非默认）：
  - 极简字幕诗：每镜 1–2 句中 / 英留白诗，作为字幕不抢画面
  - 旁白散文：低沉人声旁白念诗 / 独白，偏 MV / 有声书感
