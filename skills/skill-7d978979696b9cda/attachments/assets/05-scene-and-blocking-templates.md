# 场景空间与阶段调度模板

重复空间、反向覆盖、多人物运动、交互或空间返修时读取。谁在哪里做什么归[场面调度](../creative/05-blocking-action.md)，摄影机怎样看归[摄影](../visual/02-cinematography-coverage.md)，本文件规定相应图怎样制作、使用与核对，不规定全片固定图数。

<a id="scene-set"></a>
## 正式图组与简化条件

| 工件 | 图的形式与职责 | 当前批次检查 |
|---|---|---|
| 场景主图 | 干净主透视，通常16:9；主要结构、材质、陈设和基准光线清楚，无临时人物/路线/编号；本场需要时补光区与前／中／后景承载物 | 地标、通路及基准状态；光区与层次是候选设计，不能以单图证明动作可见或机位已验证 |
| 黑白空间底图 | 实际黑白/灰线正交顶视图，无透视缩短，边界、门窗、固定家具、通道和连接区可读；近方形可用1:1、横/纵长可用16:9/9:16，按真实入口留白而不拉伸 | 主图与布局版本对齐；尺寸分实测、设计值、未知，未知图标“布局示意，非测量图” |
| 必要方向 | 从已定观察位置看目标区域的独立透视；主图计入覆盖，补本批反向/盲面/遮挡需要 | 地标对应和新机位画面关系；不是镜像，不机械做四面或九面 |
| 分阶段调度图 | 同底图版本、方向与比例，叠必要人物/物体/摄影机标记和路线；图内短ID，图外完整图例 | 时序、持有转移、视线、轴线、朝向及可读性；不改变底图给箭头让路 |
| 状态/条件图 | 日夜、光源开关、破坏、门窗、陈设或道具位置变化；需要比较时尽量同机位。高度/楼层/遮挡影响本镜才补立面、剖面或连接图 | 只改故事事件/设计变更允许项；关一盏灯不自动全黑，光源及范围有依据 |

简单独立空镜或局部探索可以只做其所需部分，说明不承担完整地理连续职责。持续正式空间按本批需要补齐，不在排戏前等待所有角度。外观与布局可迭代；主图隐藏的区域先标设计提案，不能把AI反推图称作实测或精确三维重建。

光区与层次只在本场需要时填写：对承担关键交互、反打或遮挡判断的正式场，记录每个区域由什么实际光源承载、人物或道具经过时注意力如何变化，以及前景遮挡会带来什么代价；独立空镜或不消费这些关系的场次可标“本场不适用”。灯位、家具或受光改变会影响其他视角，必须同步更新受影响的布局/方向/状态图；没有演员或动态预演时，不把“可见”“被挡”写成已验证事实。

对承担关键选择、交互或反打的正式场次，空间卡应至少补齐一份可供机位比较的光区／层次记录：前景、中景、后景各自的承载物或遮挡物；主要光源及其覆盖区域；人物经过时的注意力转移；以及该层次对遮挡、反光和动作可读性造成的代价。普通独立空镜或不承担空间连续的探索不必强行补齐，但一旦下游要据此判断反打、路线或接缝，就必须补齐并观察对应版本。

<a id="scene-consumers"></a>
## 设计前置、媒体输入与探索晋升

每图写消费者及用途：导演判断路径、摄影选择机位、分镜核对画格、模型引用都属于有效消费。用于判断本场通路、交互、视线或连续性的图，是相关正式Job的**设计前置**；它不直接上传视频模型，也不能取消这个前置。只有实际入口支持、职责与来源资格明确时，才另列为**直接媒体输入**。

正式的重复/反打/多人运动/交互批次，须有实际已观察并与主图对齐的布局版本，以及本镜必要方向、调度和状态依据。底图加文字阶段表可草拟，尚未形成实际调度图时，不报正式图形交付完成，也不放行依赖该图的正式批次。若用户已在项目契约中明确接受具体缺口、费用/次数上限和风险，可将已核黑白底图＋清晰阶段表＋人工确认走位或用户自绘合格图用于受限小样；记录“正式调度图缺项”，不把替代品贴成正式图形交付，也不授予正式连续性资格。独立创作与有明确范围的探索可继续；所有实际操作仍须[授权和就绪核对](../generation/04-scheduling.md)。

探索产物不自动升为正式接续基准，也不永久禁用。之后补足本用途所需设计/图组，核对实际素材、目标故事状态及确切Clip/Take出点，逐用途验收，再记录资格改变和依据，可晋升适用来源。来源未变时复用原Take关联；不是改标签就合格，也不虚构新的生成次数。

<a id="scene-graphics"></a>
## 产图路线与图例

先写场的布局关系、阶段事件和机位意图，再按它们准备图。优先复用合格用户图/平台已有图；没有时，在真实可用的Lib Image或Seedream图像入口编译黑白底图候选并实际查看。若已证实Agent可用绘图/标注能力，可直接使用；否则仅在图像入口确能编辑/引用时派生调度图，返回后核对箭头、编号、结构。文字过密则减少短ID、拆阶段并配图外图例，不能容忍错误指向。ASCII仅草案/辅助，不能替代本模板的正式图形。

人物路线用实线箭头、机位移动用虚线、物体转移用点划线；停点和阶段有编号。颜色只是辅助，图外将人偶编号/颜色映射到稳定角色ID和真实服装，颜色、箭头不能进入成片。人物自身左右、世界方位/局部墙号、画面左右分别核；同形人物、遮挡和反射另核。知道真实北向才标北，否则用A/B/C/D墙及入口侧等局部参照。

阶段在时序、持有/接触关系、视线与轴线仍清楚时可以合并；重叠、同点反复、物件易混或信息难读时拆图，不设所有场景1–2张，也不按E1–E4机械四次生成。每图记录覆盖阶段与消费者，图组数、文件数、调用数和计费子任务分开。

图生图补角度、主图+布局的候选总览、合格全景取普通视角、草图/导演台是按需路线，不是每场必走的工序。环境九宫格与叙事分镜分开；每格机位/方向/用途明确，格子不是已导出的独立图片。全景旋转不提供三维平移视差，穿门/绕近物/跨层需相应结构与观察。导演台官方GUI或人工教程不证明网页原生Agent会操作；工作区视角不等于输出相机，机位截图不等于动态预演。无真实能力时保留具体未完成项，仍只用[LibTV网页](../platform/01-libtv-capabilities.md)。

## 可填写空间与调度卡

- 地点ID、布局制作修订、故事状态/适用Scene；事实、设计提案、未知及其影响。
- 主图/底图/方向/状态/调度图索引：形式、真实位置或计划、消费者、设计前置或直接输入职责、覆盖镜号/阶段、观察与缺项。
- 固定拓扑：方向、墙/门窗/家具/通道/相邻空间、尺寸依据；未见结构提案和待核点。
- 阶段：人物ID的起点→停点→终点、朝向/注意对象；物件接触/归属/释放；机位位置→观看目标/路径、视线/行动轴线、光源及事件。
- 光区／层次（仅关键交互、反打或遮挡判断需要时）：前／中／后景承载物、光源覆盖、注意力转移、遮挡／反光代价；不适用或无依据时明确写出，不为填表编造陈设。
- 图例及身份映射；允许合并的阶段和须拆图理由；本批必需图与延后触发。
- 依赖用途：布局→方向/调度/状态/镜头设计，外观→材质/光照，故事状态→门灯/陈设/物件，实际输入→Binding。变更检查入画、遮挡、反射、光照和路径，不能只按墙名判不受影响。
- 实际观察判据、失败层级与下一步；场末状态交[快照](../core/03-records.md#continuity-snapshot)，生产索引交[Checkpoint](../core/04-state-recovery.md)。

## 完整填写例：修理店局部空间

原创应出图提案，未生成图片、未测量或验证机位。沿用[修理店贯通例](../examples/04-creative-to-assets.md)，局部A/B/C/D分别对应旧示意的上/右/下/左，旧“北/东”等仅为设计标签，不声明地理方向。

| 项 | 本例填写 |
|---|---|
| 地点/范围 | LOC-repair；布局L1 r1；S-repair当夜，Sh-master与Sh-reaction；未知真实尺寸，图面按规划比例，不断言净空合格 |
| 固定布局 | 账桌中央；A侧林岚座位偏D、空椅偏B；工具架沿A墙；B墙靠C段为门；桌B/C角为钥匙落点。包落点在桌B侧靠C、让开绕桌通路（导演提案） |
| 光源/状态 | L-desk桌灯与L-door门外光；默认均存在。改变开关/门开闭时另建故事状态，不因换机位搬灯；未定其他窗位不伪称已知 |
| 光区／层次 | 本场承担邀请后的反打与包路线判断，需补前景门框／中景人物与桌／后景账架的承载关系、桌灯与门外光覆盖、看门时注意力转移及桌角遮挡代价；当前均为设计计划，未称已观察 |
| 主图/底图 | 主图呈门、桌、空椅与材质；实际黑白顶视图示上述固定结构，门开向及净空需设计/观察核对；二者对齐后才作相关正式空间依据 |
| 动作阶段 | 局部图形阶段用P编号：P1对应原E1（进门、赶车与要钥匙）；P2对应E2（到桌B/C角，钥匙接触并收手）；P3对应E3（转账本并邀请）；P4覆盖E4及E5前段（看门时包仍在肩，之后卸包、沿B侧绕桌）；P5覆盖E5入座及E6（开口与笔置中）。原必要事件仍沿E1–E6，P仅作图形合并导航，不重命名事件或增加Shot |
| 调度图计划 | 图D-approach覆盖P1/P2，对应E1/E2，分别标人实线与钥匙点划线；图D-choice覆盖P3–P5，对应E3–E6，标包落点与绕桌路径。若同点反复/先后不清则拆，若可清楚复用则不多造图；目前只是拟合并决定 |
| 机位/方向 | C1候选在C/D侧朝桌与门；C2候选在D侧向林舟及桌B侧取反应。逐阶段检查视线/轴线和物件可见性，不凭坐标名称声称同侧可拍。确需A/B侧补盲时出C3方向图供设计核查，是否成为故事镜头另由摄影决定 |
| 输入与等待 | Sh-master/Sh-reaction先消费已核对布局和必要调度设计，不必把所有图都传模型；直接引用只列当前可用、职责清楚的源。二镜若不消费对方实际输出，可共享合格源独立准备 |
| 状态与返回 | 钥匙固定桌B/C角；包在肩→落地；账本朝向改变。看不见落点先查机位/设计，引用错误查Binding，实际漂移记录图/时段再返修；不删除邀请→选择的因果 |
| 完成层级 | 全部是图形需求及计划，无真实图、出点或已通过记录；正式图形未完成。下场需依故事关系及实际选段出点另核快照 |

## 本批观察与失败返回

并看主图、底图、方向和调度图，检查拓扑、门窗家具、地标、净空/接触、身份对应、轴线、阶段和光源。设计值不等于实测，线条未相交也不证明人体能通行。某方向变化可能经窗光、反射、遮挡或路径影响其他方向，先查实际依赖。

错误按[设计/映射/提示/生成四层](../quality/02-repair.md#asset-repair-layers)处理；修复后核本图及受影响角度/镜头，保留旧版。图正确不保证视频正确；正式视频仍按区间观察空间、动作和接缝。图像请求复用[原请求卡](../generation/02-image-prompt.md)，参考超限交[Binding容量分支](03-reference-binding.md#reference-capacity)。方法与已读范围见[公开来源](../evidence/01-sources.md#asset-space-methods)，不将教程当当前自动化能力证明。
