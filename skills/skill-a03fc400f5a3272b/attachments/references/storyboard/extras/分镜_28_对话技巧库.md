# 对话技巧

> **定位**：台词风格参考。角色对话设计时按需查询。

## 角色台词风格

| 类型 | 语言特征 | 典型句式 |
|:---|:---|:---|
| **霸总** | 短句、命令式、不解释 | "过来。""这件事不用你管。" |
| **独立女主** | 有理有据、不卑不亢、带反击 | "你说完了？那轮到我了。" |
| **反派** | 轻声细语>咆哮、反问句、预判 | "你以为你赢了？" |
| **喜剧** | 反差、自嘲、一本正经说荒唐话 | "我非常认真地决定——辞职去放羊。" |

## 场景对话指南

| 场景 | 核心原则 | 禁忌 |
|:---|:---|:---|
| **对峙** | 台词=武器，每句推进权力变化 | 禁止纯吵架无信息增量 |
| **吃醋** | 嘴上说没事+身体说有事 | 禁止直接说"我吃醋了" |
| **分手** | 最伤人的话用最平静的语气 | 禁止长篇哭诉 |
| **和好** | 先行为后语言，不说"对不起" | 禁止见面就抱头痛哭 |

## 台词节奏结构

| 结构 | 方式 | 示例 |
|:---|:---|:---|
| 对比反转 | A→B 180°翻转 | "我恨你。"→"我恨我恨不了你。" |
| 条件递进 | 如果A→那么B→但C | "如果你走，我就关门。但你知道——这扇门从不上锁。" |
| 身份对立 | 两个身份同时说话 | 表面：社交语言；潜台词：真实立场 |
| 时间压缩 | 一句话跨越时间 | "三年前你说会回来，三年后你还是这句话。" |

## 台词铁律

- 每句台词必须有信息增量，可删台词=应删台词
- 单句≤25字（中文），超过则拆分
- 关键台词前必有动作/神态（`**角色**（握紧拳头）："..."`）
- 禁止解释性台词（"你为什么这么做？因为我想…"）——用行动替代解释
- OS（内心独白）≤2句/场次，只在"角色嘴上说的和心里想的相反"时使用
