# Default Line-Art Style

Use these constraints when the user asks for "图 2 风格" or does not provide a separate style reference:

- White or near-white background.
- Bold, smooth, rounded black outlines.
- Minimal inner contour lines for anatomy, clothing seams, props, and readable facial features.
- No color, photorealism, gradients, halftones, or grayscale shading.
- Simple hand-drawn marker feel, not a technical CAD trace or auto-edge-detection artifact.
- Sparse environment lines only when needed to preserve the original scene geometry.

Good outputs look like a clean coloring-book or casual comic-panel sketch derived from the source image. They preserve composition first, then simplify all texture and lighting into essential contour lines.
