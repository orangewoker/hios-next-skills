# 短剧剧本与分镜脚本格式规范

> 本文件定义最终交付文档的两种内容格式：①分场剧本正文；②每场戏配套的专业分镜脚本表。创作时两者都必须产出，缺一不可。

## 一、交付文档整体结构

```text
《剧名》短剧剧本
├── 一、剧本信息卡（剧名 / 题材 / 时长 / 篇幅 / 风格基调 / 一句话梗概）
├── 二、人物表（主要人物：姓名、年龄、身份、性格标签、核心诉求）
├── 三、剧本正文（分场剧本，场号 1、2、3…）
└── 四、分镜脚本（按场对应，每场一张分镜表）
```

## 二、分场剧本正文格式

每场以"场号 + 场景标题"开头，正文按顺序书写：场景地点与时间 → 出场人物 → 动作与神态描写 → 台词 → 情绪/节奏标注。

```text
第1场  地下停车场·夜【钩子场】
人物：林晚（女主，30岁，落魄千金）、顾沉（男主，32岁，集团总裁）
【动作/神态】林晚被两个黑衣保镖按在冰冷的立柱上，指尖死死抠住水泥缝，指甲断裂渗血，她咬紧下唇，眼眶泛红却不落泪。
林晚（声音发抖却带刺）：顾沉，你把我绑来，就为了羞辱我？
【动作/神态】顾沉慢条斯理解开西装扣子，步步逼近，皮鞋声在空旷车库回响，停在离她一步之遥，居高临下俯视。
顾沉（冷笑，压低声音）：羞辱你？林晚，这才刚刚开始。
【节奏标注：开场即冲突，30秒内完成人物对立与悬念铺设】
```

书写规则：
- 动作与神态描写必须**具体可拍**（看得见肢体、表情、道具、环境细节），禁止"她很生气""气氛尴尬"这类抽象词。
- 台词按"角色名（情绪语气）：台词"格式；旁白/内心OS 标注〔旁白〕〔OS〕。
- 每场末尾标注节奏提示（如"结尾钩子：身份揭露""情绪峰值：反转"）。
- 篇幅控制：竖屏短剧约 150-200 字/分钟，按确认时长换算总字数。
- **细节颗粒度**：按下方"细节描写规范"执行，微表情、动作轨迹、环境动静缺一不可。

### 细节描写规范（颗粒度三级标准）

> 一切描写要"能直接拍、能直接演"。三个层面逐层检查，缺一层即不合格。

**第一级 · 人物微表情（逐帧变化，不是单一表情）**
- 写法：写清表情的**连续变化过程**（先…继而…最后…），按眼 → 眉 → 唇 → 面部肌肉的顺序递进。
- 示例（禁）：她很难过。
- 示例（合格）：她先是睫毛轻轻颤了一下，继而瞳孔骤然一缩，嘴角的笑僵在半空，最后抿成一条直线，喉头滚动了一下。

**第二级 · 动作轨迹（起点→路径→终点，含速度与停顿）**
- 写法：动作要写出**从哪里开始、经过什么路径、停在哪里、多快多慢、是否停顿**，补上重心、手部、脚步等细节。
- 示例（禁）：他走过去。
- 示例（合格）：他右脚尖先向外碾了半圈，才迈出半步，又停在原地——十秒后，他才把脚落下，鞋跟敲在瓷砖上发出一声脆响。

**第三级 · 环境风吹草动与物体反应**
- 写法：环境必须**有反应、有动静**——风怎么吹（吹起什么、吹向哪）、草/物怎么动（晃动的幅度频率）、光影怎么移（明暗过渡方向）、声音的远近层次。
- 示例（禁）：房间很安静。
- 示例（合格）：窗外风声卷过，窗帘鼓起又落下；桌上那张朱砂符纸的边缘被风掀起一角，又轻轻落回；墙上挂钟的秒针顿了一下，才重新走动。

**禁用词清单**：很生气、很紧张、很害怕、气氛凝固、气氛尴尬、若有所思、愣住了（单独用）、沉默了一会儿（单独用）等笼统情绪/状态词——必须拆成可拍的具体细节。

**分镜字段联动**：
- "人物动作"列按第二级写轨迹（起→路→终、速度、停顿），关键情绪点补第一级微表情。
- "场景美术"列按第三级写环境状态（含风/光/物的动态反应）。
- "光线色彩"列写明光影的**移动与变化**（如"光从左侧窗帘缝隙移入，随窗纱起伏明暗交替"）。
- "音效台词"列写明声音的**层次与远近**（近处呼吸声 / 远处车流声 / 静默中的秒针声）。

## 三、专业分镜脚本表（每场一张表）

每一场戏拆解为若干**镜头**，按镜头逐行填写下表全部 13 个字段。**禁止缺列，禁止用一句话笼统带过，每个字段都必须给出具体可执行的内容。**

| 镜号 | 段落 | 景别 | 场景美术 | 画面内容构图 | 人物动作 | 摄像机镜头 | 摄影参数 | 镜头调度 | 光线色彩 | 音效台词 | 画面包装/台词/制作备注 | 转场设计 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

### 字段填写规范

| 字段 | 含义 | 填写要求与示例 |
|---|---|---|
| **镜号** | 镜头顺序编号 | 每场独立从 1 递增，如"1-1、1-2、1-3"（场-镜）。 |
| **段落** | 该镜头属于哪个剧情段落 | 按叙事功能标段：开场钩子 / 铺垫 / 冲突升级 / 反转 / 结尾钩子。 |
| **景别** | 画面取景范围 | 竖屏短剧常用：大远景、全景、中景、近景、特写、大特写。明确标注，如"特写（女主眼睛）"。 |
| **场景美术** | 场景与道具的视觉设计 | 具体描述场景环境、色调、标志性道具及其状态。示例："破旧出租屋，墙面斑驳泛黄，桌上唯一一支枯萎的玫瑰"。 |
| **画面内容构图** | 画面内元素的布局关系 | 写清主体、陪体、前后景、留白方向（竖屏注意上下构图），并**点名构图手法**（对称式/框景/三分法/引导线/对角线/中心/前景遮挡等，手法库见 `references/ai-prompts.md`）。示例："女主居画面下方 1/3（三分法），身后门框形成框景构图，门口阴影处站着黑衣人"。 |
| **人物动作** | 人物的肢体与表情动作 | 具体、可表演、有情绪层次。示例："她后退半步，手指攥紧衣角，眼神从慌乱到决绝，猛地抬头"。**按细节三级标准写**：微表情逐帧变化 + 动作轨迹（起点→路径→终点、速度、停顿）。 |
| **摄像机镜头** | 使用的镜头焦段/类型 | 如：广角 24mm、标准 50mm、长焦 85mm、微距、变形宽银幕等，结合竖屏手机/电影机语境。 |
| **摄影参数** | 光圈、快门、ISO、帧率等 | 给出可执行的参数组合。示例："f/1.8，1/100s，ISO 400，25fps，浅景深"。 |
| **镜头调度** | 机位运动与演员调度 | 写明**运镜路线（起点→路径→终点，分步）**、运动方式（推/拉/摇/移/跟/升降/手持）与节奏，并写明**触发原因与叙事理由**（人物注意力延伸/信息揭示/视线引导），每次移动让观众多知道一件事；物理过程写实（人物真实汇合，禁止瞬移）。**镜头不强制运动**：可写"固定机位"，此时写明画面内如何承载动感与信息（人物入画出画/微表情变化/光影物体反应）；无叙事理由时优先固定机位。示例："镜头从女主特写缓慢后拉至全景，同时女主向前走两步出画；女主回头触发甩镜，沿其视线甩向男主下车方向"；或"固定机位，女主入画走向镜头，身后人影入画（画面内揭示）"。 |
| **光线色彩** | 光线设计、色温、色彩基调 | 写明主光/轮廓光/环境光、色温冷暖、整体色调，以及**光影的移动与变化**。示例："顶光打亮轮廓，冷蓝环境光，局部暖黄台灯光，光随窗纱起伏明暗交替，画面呈青橙对比"。 |
| **音效台词** | 本镜头的声音设计 | 台词（含语气）、音效（环境声/动作声/拟音）、音乐情绪，写明**声音的层次与远近**。示例："台词：'我不会再被你摆布。'；音效：雨声渐强+高跟鞋声由远及近；音乐：鼓点起"。 |
| **画面包装/台词/制作备注** | 字幕、花字、特效包装、台词落字与制作提示 | 写明字幕/花字内容与位置、特效标注、拍摄注意事项（如绿幕、慢动作、需要特殊道具）。示例："字幕居中'第3天'；花字'？'；慢动作拍摄；备注：需雨机+防风"。 |
| **转场设计** | 镜头结束到下一镜头的过渡方式 | 写明**转场手法 + 理由**（遮罩转场/动作连贯/甩镜/匹配剪辑/声音先入/叠化/硬切等，手法库见 `references/ai-prompts.md`）。示例："遮罩转场：男主进门，门扇划过画面切室内；理由：空间跳跃+视线引导"。 |

## 四、时长-字数对照（竖屏短剧经验值）

| 时长 | 剧本字数（约） | 镜头数（约） |
|---|---|---|
| 15 秒 | 250-350 字 | 3-5 个 |
| 1 分钟 | 900-1200 字 | 10-16 个 |
| 3 分钟 | 2800-3600 字 | 30-48 个 |
| 5 分钟 | 4500-6000 字 | 50-80 个 |

## 五、爆款节奏在分镜中的落地要求

- **黄金 3 秒**：第 1-2 个镜头必须是最强冲突/最怪场景/最大悬念，画面信息量拉满。
- **情绪峰值镜头**：每 30 秒安排一个强情绪镜头（特写反应、打脸动作、身份揭露），用大特写+慢动作+音效爆炸强化。
- **结尾钩子镜头**：最后一个镜头用"悬念信息+开放式构图+声音先入"，为下一部/下一段留钩。
- **竖屏适配**：主体居中，避免横向构图元素分散；人物对话用近景/特写交替；场景美术重前景纵深。
