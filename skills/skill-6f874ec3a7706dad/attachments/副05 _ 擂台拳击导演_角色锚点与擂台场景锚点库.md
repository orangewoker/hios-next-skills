# 附MD 副05 | 擂台拳击导演\_角色锚点与擂台场景锚点库

**所属主SKILL：** 擂台拳击导演 | 用AIGC做12回合拳击互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“擂台拳击导演”互动影游的专属角色锚点与擂台场景锚点库。

解决AI生成拳击内容时“角色跨回合换脸、服装漂移、擂台场景不统一、围绳角柱位置跳变”的痛点。通过统一的角色锚点规范与擂台九宫格视角，确保全片角色形象与场景空间100%一致。

本模块只规定角色与场景锚点规范，不替代主SKILL的流程调度与底层逻辑。

## #需要什么输入

**最少提供：**

- 主角A与主角B的姓名、设定、外貌锚点（三视图+面部特写）
- 对手设定（三视图+面部特写）
- 教练设定（三视图+面部特写）
- 裁判设定（三视图+面部特写）
- 擂台场景参考图

**可选提供：**

- 特殊装备或配饰需求
- 目标画幅（不限定，按项目需求或用户指定）
- 是否需要输出视频文件、视频脚本、Prompt清单、视觉方案

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。本环节重点参考【提示词】底座的物理光学参数与【大导演思维】的镜头逻辑，确保角色锚点与镜头语言完全对齐。

### 二、角色锚点命名规范

- **格式**：`角色名_角度_版本号`
- **示例**：`主角A_正面三视图_v1`、`对手_暴怒特写_v2`
- **核心铁律**：所有锚点ID必须在跨回合、跨分支时绝对一致，严禁“同角色两套ID”。

### 三、主要角色锚点

1\. 【主角A】（例如：富贵）

- **身份定位**：拳击手（用户可自定义）
- **外貌特征**：硬朗面部轮廓，短发或束发，肌肉线条明显，拳套为标志色
- **核心微表情**：下颌紧绷、瞳孔收缩、嘴角微扬、汗水滑落
- **光影锚定**：主光暖白，逆光火焰橙，擂台顶光强烈
- **锚点ID示例**：`i-xxxxxxx`（用户上传三视图后替换）
- **可替换状态**：赛前/赛中/受创/胜利/疲惫

2\. 【主角B】（例如：安九）

- **身份定位**：教练/伴侣/辅助者（用户可自定义）
- **外貌特征**：干练造型，运动风格服装，气质坚定
- **核心微表情**：眉头紧锁、嘴角轻抿、视线不离主角A
- **光影锚定**：柔和侧逆光，场边冷暖交界
- **锚点ID示例**：`i-xxxxxxx`（用户上传三视图后替换）
- **可替换状态**：赛前叮嘱/回合间隙/紧张观战

3\. 对手

- **外貌特征**：拳击手造型，与主角A形成视觉对比（体型/肤色/风格）
- **核心微表情**：挑衅、喘息、受击、倒下
- **光影锚定**：主光冷蓝，逆光猩红
- **锚点ID示例**：`i-xxxxxxx`（用户上传三视图后替换）

4\. 教练

- **外貌特征**：场边教练造型，手中毛巾或战术板
- **核心微表情**：专注、紧张、激动、沉默
- **光影锚定**：场边暖光

5\. 裁判

- **外貌特征**：标准裁判制服，佩戴手套
- **核心微表情**：严肃、读秒、判定
- **光影锚定**：擂台顶光

### 四、擂台场景锚点（九宫格物理坐标）

擂台场景必须包含9个角度：

1. 正面全景
2. 侧面全景
3. 背面全景
4. 俯视图
5. 仰视图
6. 左侧中景
7. 右侧中景
8. 正面特写
9. 背面特写

**擂台核心视觉锚点：**

- 角柱（红/蓝/白三色）
- 围绳（三层，高度固定）
- 地面标志（擂台中央logo）
- 场边座位（教练/裁判/观众）
- 顶灯光源方向

**锚点ID示例**：`i-xxxxxxx`（用户上传后替换）

### 五、状态切换锚点规则

- 角色在同一回合内的不同状态（如主角从冷静→受击→反击），必须使用同一角色的不同锚点帧，禁止换脸。
- 表情切换必须基于【情绪大师】的七层微表情拆解执行。
- 服装、装备、拳套颜色在全片中必须保持绝对一致。

### 六、分支一致性锁定规则（核心铁律）

1. 同角色在不同回合必须用同一人物锚点ID。
2. 所有回合共用同一套角色锚点库。
3. 配角也必须有独立锚点，禁止反复生成不同脸。
4. 擂台场景跨回合必须复用同一锚点ID。

### 七、子级专属提示词模板（示例）

```text
【主角A】（参考锚点i-xxxxxxx），
【对手】（参考锚点i-xxxxxxx），
在【擂台】场景中，【动作描述】，
主光源【顶光】，色温【5200K】，
擂台角柱位于画面【左/右】，
回合ID：【R0X】，变量变化：【变量列表】，
禁止人物变形、换脸、穿模、围绳位置漂移。
```

（注：以上“富贵、安九”仅为示例，实际使用时由用户自定义替换）

## **#产出什么**

最终交付：

- **视频文件（MP4格式）**：包含角色锚点与场景一致性的拳击互动影游演示片段。

- **视频脚本、Prompt清单、视觉方案**。

- **角色锚点库资产包**：所有角色三视图、面部特写、锚点ID清单。

- **擂台场景锚点库**：九宫格锚点图、角柱/围绳/地面标志位置参数。

- **角色一致性校验报告**：确保跨回合、跨分支的锚点ID统一且未被篡改。

## **#什么时候问你**

出现以下情况时，必须停下来问用户：

- 主角A、主角B、对手、教练、裁判的姓名或外貌锚点设定不明确时。

- 用户要求新增角色、变更现有角色锚点或修改擂台场景时。

- 用户要求突破分支一致性锁定规则，使用不同锚点ID时。

- 用户要求输出视频文件、视频脚本、Prompt清单、视觉方案，但缺少关键输入时。

- 本模块与上游主SKILL或其他附MD规则冲突时。
