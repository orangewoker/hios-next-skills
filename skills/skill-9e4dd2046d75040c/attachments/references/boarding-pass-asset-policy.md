# 四站登机牌资产策略

## `boarding_pass_reference` 合同

在角色资产确认后、最终视频前，必须生成且只生成一张 `boarding_pass_reference`。该图是最终视频的必需引用资产，不是预览图。

```text
生成一张横版 16:9 白底登机牌参考资产图。画面中横向整齐陈列四张完整的巨大竖版登机牌，四张卡之间留清晰白色间隔；无人物、无手、无场景、无行李、无阴影遮挡。

航司显示名：{airline_name}。四站按从左到右顺序为：
1. {city_1_english} {city_1_chinese}
2. {city_2_english} {city_2_chinese}
3. {city_3_english} {city_3_chinese}
4. {city_4_english} {city_4_chinese}

每张票必须是竖版白色实体登机牌：不同颜色边条、清晰条形码、NAME / FLT / GATE / SEAT 等规范票务信息排版。每张票中央必须用准确、清晰、可读的大号文字印出对应英文城市名和中文城市名；城市大字优先级最高，拼写、汉字和四站顺序必须完全按输入保留。小号票务信息可简化，但必须像真实票务版式，不能是乱码、伪文字或随机符号。

严格避免：人物、场景、横向机票、卡片互相遮挡、城市名拼错、中文乱码、英文乱码、难以辨认的小字堆砌、额外第五张票、广告文案。
```

## 引用规则

- 最终视频必须实际引用 `@[boarding_pass_reference]`。
- 视频中的四张背景登机牌必须逐张复用该资产中对应票的城市大字、航司、边条颜色、条形码位置与整体票面排版；允许随滑入产生透视和运动模糊，但不得重写文字。
- 用户修改任一城市或航司后，旧 `boarding_pass_reference` 立即失效，必须重新生成再进入视频阶段。
