# 09 - 15秒叙事单元规则

## 核心约束

因 AI 视频生成工具（如可灵、即梦、Sora、Runway 等）单次输出上限为 15-30 秒，全流程在分镜及之后环节必须以 **15秒叙事单元** 为基本单位进行规划与输出。

## 一、什么是15秒叙事单元

一个15秒叙事单元 = 一段总时长15秒的连续镜头序列，包含2-6个分镜，构成一个完整的小段落（起势-推进-落点）。

它不是随意切割，而是按叙事节拍划分：

- 一个完整的动作过程（如：拔剑→挥斩→收招→敌人倒地）
- 一段完整的对话交锋（如：对峙→质问→回答→反应）
- 一个完整的情绪弧线（如：平静→察觉→紧张→爆发）

## 二、划分规则

### 分镜规划阶段（环节⑤）

1. 通读正文，识别叙事节拍（动作完成点、对话回合结束、情绪转折点）。
2. 在节拍处切分，每个单元控制在 **12-18秒** 范围内（以15秒为基准，允许微调）。
3. 每个单元内分镜时间必须**衔接无断层**，总时长尽量为15秒整。
4. 单元内分镜数量：
   - 文戏为主：2-4个分镜（单镜时长较长）
   - 武戏为主：4-6个分镜（单镜时长较短，快切）
   - 混合：3-5个分镜

### 时长推算

总时长叙事单元数分镜总数（约）30秒2个4-121分钟4个8-242分钟8个16-483分钟12个24-725分钟20个40-12010分钟40个80-240

## 三、单元间衔接规则\
1. 每个单元第一镜必须承接上一单元最后一镜。\
2. 下一单元第一镜必须从上一单元 衔接点 中提取至少一个元素作为起点。\
3. 衔接方式必须显式写在第一镜的“衔接说明”中，例如：\
   - 动作延续\
   - 主体一致\
   - 视线匹配\
   - 声音先入\
   - 图形匹配\
   - 颜色/光影延续\
   - 台词/关键词重复\
   - 因果逻辑\
4. 禁止突然跳切到无关场景、人物或时间。如确需跳转，必须设计过渡。\
5. 每个单元最后一镜必须留下新的 衔接点，供下一单元承接。

叙事单元之间必须有明确的过渡衔接，不可生硬跳切。衔接方式包括：

衔接类型说明示例动作匹配剪辑上一单元结尾动作与下一单元开头动作匹配上单元：拳头挥出 → 下单元：拳头击中视线引导上一单元角色视线引导至下一单元场景上单元：角色望向远方 → 下单元：远方场景声音桥梁上一单元声音延续到下一单元画面上单元：钟声响起 → 下单元：钟声中切换场景光效转场用光效变化过渡上单元：闪光爆开 → 下单元：白光淡入新场景黑场淡出经典转场上单元：画面渐黑 → 下单元：从黑场淡入道具转场用同一道具连接上单元：手握信件 → 下单元：信件特写展开色彩转场用色彩变化过渡上单元：红色酒杯 → 下单元：红色夕阳

## 四、输出格式

每个叙事单元独立成组输出，格式如下：

```
═══════════════════════════════════════
【叙事单元 {编号}：{单元标题} | {起止时间}】
═══════════════════════════════════════

单元概述：{一句话概括本单元的核心事件与情绪}

分镜1：{持续秒数}，{景别}，{运镜}，{画面内容}。台词：{台词/无}。音效：{音效/无}。
分镜2：{持续秒数}，{景别}，{运镜}，{画面内容}。台词：{台词/无}。音效：{音效/无}。
分镜3：{持续秒数}，{景别}，{运镜}，{画面内容}。台词：{台词/无}。音效：{音效/无}。
...

【→ 下一单元衔接：{衔接类型} — {衔接说明}】
```

## 五、故事板阶段（环节⑦）

- 每个叙事单元生成**一张**故事板（2×4八宫格或手绘分镜稿）。
- 故事板内镜头数 = 该单元的分镜数。
- 不可跨单元混合镜头。
- 故事板顶部标注：叙事单元编号、单元标题、总时长15秒。

## 六、视频提示词阶段（环节⑦）

- 每个叙事单元生成**一组**逐镜视频提示词。
- 单组总时长 = 15秒。
- 组内分镜时间连续无断层。
- 全局视觉风格在所有单元间保持一致。
- 资产图锚定在所有单元间保持一致（同一角色/场景/道具引用同一资产图）。

## 七、质量检查清单

每个叙事单元输出后自检：

- \[ \] 总时长是否为15秒（允许12-18秒）？
- \[ \] 分镜时间是否衔接无断层？
- \[ \] 是否有明确的单元间衔接方式？
- \[ \] 单元是否构成完整的叙事节拍（有起有落）？
- \[ \] 文戏/武戏标注是否清晰？
- \[ \] 微表情/招式/特效是否具体可执行？
