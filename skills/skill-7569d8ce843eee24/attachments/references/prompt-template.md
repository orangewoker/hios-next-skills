# Seedance 单段提示词模板 v3

> 实际提示词只写当前段必要信息。完整逻辑在生成前内部检查，不要把所有规则堆进提示词。

```text
使用@角色资产图锁定唯一主角；使用@产品资产图作为产品外观和真实比例的唯一权威参考；使用@场景参考图锁定空间、光线和固定地标。

本段采用[直接推荐型 / 经验分享型 / 偷听对话型 / 正式解释型]。人物关系为[单人生活流 / 双人对聊 / 三人同桌 / 场景互动]。摄影机作为[自拍手机 / 同行者 / 桌边旁听者 / 第三人称记录者]存在。

第一画面已经处在进行中的情境：主角正在[行为锚点]；[同伴或场景人物]正在[关系锚点]；背景持续发生[环境锚点]。角色不必行走。主角手中的[场景原生道具]由[手掌/前臂/桌面]稳定支撑，只做[一个动作]。

0:00–0:__，[景别与唯一运镜]。主角主要看向[同伴/食物/环境]，在“关键词”处短暂接近镜头方向：
主角：“用户原文。”

0:__–0:__，连续镜头或有动机硬切。继承同一场景的[人物关系、桌面、道具位置、光线和背景地标]：
主角：“用户原文。”

0:__–0:__，[下一动作]。产品只在[产品露出阶段]自然成为视觉主体，最后保持[人物、关系、左右手、道具和空间位置]：
主角：“用户原文。”

主角只能逐字说指定台词，不得添加或改写。社交型口播中，主角主要对场内人物说话，不持续盯镜头。场景连续性锚点、产品比例和道具支撑不得变化。保留持续可闻的[至少三种现场声音]；严禁字幕、花字、背景音乐和额外转场音效。
```

## 内部必填项

- 传播接受方式；
- 人物关系模式；
- 摄影机在关系中的身份；
- 行为锚点；
- 关系锚点；
- 环境锚点；
- 场景原生道具；
- 左右手职责和道具支撑；
- 主要交流对象；
- 产品露出阶段；
- 场景连续性卡；
- 环境声床。
