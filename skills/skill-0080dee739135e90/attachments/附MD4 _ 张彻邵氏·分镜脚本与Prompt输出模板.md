# 附MD4 | 张彻邵氏·分镜脚本与Prompt输出模板

**所属主SKILL：** 张彻 | 邵氏硬派武侠一键成片\
**版本：** V2.0 融合合规版

## #做什么

本模块为“张彻 | 邵氏硬派武侠一键成片”的专属分镜脚本与Prompt输出模板。

解决主MD要求产出“视频脚本、Prompt清单、视觉方案”，但缺少统一字段结构、Prompt格式、变量替换规则与负面词库的问题。确保分镜脚本与Prompt可直接进入AI视频工具生成链路。

## #需要什么输入

**最少提供：**

- 主MD下发的创作方向与情绪基调
- 角色锚点清单、场景锚点清单（参考附MD2、附MD3）
- 张彻邵氏硬派美学禁则（参考附MD1）

**可选提供：**

- 目标总时长
- 目标画幅（不限定，按项目需求或用户指定）
- 是否需要输出视频文件、视频脚本、Prompt清单、视觉方案

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。本环节重点参考【提示词】底座的物理光学参数与【大导演思维】的镜头逻辑。

### 二、分镜脚本字段结构

每个镜头必须包含以下字段：

字段内容镜号按场次顺序编号场次场次名称与张力等级时长3-5秒，超限必须拆分景别全景/中景/近景/特写/极近特写摄影机状态固定/极稳跟拍为主（禁止花哨运镜）机位正面/侧面/过肩/俯拍/仰拍等视角客观/主观/第一视角等运动路径固定/极稳推/极稳跟焦点焦点位置与焦平面变化画面内容人物动作、表情、道具、环境台词台词文本与字数音效环境音、动作音、留白处理Prompt正向Prompt全文负面Prompt负面词清单参考来源卡号+具体参考

### 三、图片提示词·八要素填空公式

1. 【画面构图：机位/景别】
2. 【无角色 或 人物空间与互动关系：位置/距离/朝向】
3. 【极具体的微表情与面部特写：物理器官描述，禁止抽象词】
4. 【明确的场景环境元素与前景/背景道具：精确罗列实物】
5. 【光影几何与大气效果：硬光侧逆光/光源方向/颜色/明暗气氛】
6. 【视觉风格/胶片质感：张彻邵氏硬派+老式胶片颗粒】
7. 【技术参数：相机/镜头/光圈】
8. 【负面提示词：禁止文字/Logo/水印/现代物品】

### 四、视频提示词·七要素填空公式

1. 【时长与镜头运动：3-5秒/固定/极稳跟拍】
2. 【角色一致性锁定：首帧参考/人物锚点ID】
3. 【动作因果链：起势→发力→肉体碰撞反馈】
4. 【光影与色调锁定：暗红黄褐/硬光侧逆光/色温】
5. 【声音叙事：无BGM，纯物理音效（骨裂/闷响/喘息）】
6. 【防崩指令：禁止现代元素/塑料感/仙侠飘逸】
7. 【输出规格：16:9或9:16/24fps/720P以上】

### 五、张彻邵氏专属正向词库

- 赤膊血战、拳拳到肉、硬桥硬马
- 老式胶片颗粒、暗红黄褐、硬光侧逆光
- 青筋暴起、汗血交织、含血微笑
- 悲壮背影、肃杀空镜、煤油灯棚拍
- 肉体碰撞、沉重感、痛苦感、战损

### 六、张彻邵氏专属负向词库

**强制禁止：**

- 飘逸水墨意境、赛博霓虹灯、现代高饱和度
- 唯美古装仙侠、日式唯美滤镜
- 发射激光、飞剑、玄幻法术
- 现代建筑、现代车辆、高科技产品
- 文字、Logo、水印、乱码
- 磨皮美颜、光鲜亮丽影视古装

### 七、生成与合成

根据上述分镜脚本与Prompt模板，调用底层视频生成Skill，输出MP4视频文件。

## #产出什么

最终交付：

- **视频文件（MP4格式）、视频脚本、Prompt清单、视觉方案**。
- **分镜脚本大全**：所有镜头的完整字段表。
- **图片提示词模板**（八要素填空公式）。
- **视频提示词模板**（七要素填空公式）。
- **张彻邵氏专属正向与负向词库**。
- 可直接进入AI视频工具生成链路的执行清单。

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 缺少角色锚点清单、场景锚点清单或视觉语法时。
- 单镜时长需要超过5秒时。
- 用户要求突破张彻邵氏专属负向词库时。
- 用户要求输出视频文件、视频脚本、Prompt清单、视觉方案，但缺少关键输入时。
- 本模块与上游主SKILL或其他附MD规则冲突时。
