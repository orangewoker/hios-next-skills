# 资产映射规则

## 人物参考图

按人物名称精确映射。禁止根据性别、年龄或外观猜测。多个参考图属于同一人物时，保持用户指定顺序。

## 场景参考图

按分镜场景字段或用户锁定的场景名称映射。场景图只能进入工具的场景/参考图字段，不追加到提示词。

## 声纹

声纹ID例如 `CM`、`XH`、`PP`，必须对应用户提供的具体音频资产。不得用文字描述代替缺失音频，不得为相似人物共用声纹。

## 道具参考图

仅在用户提供并明确归属时传入。未提供道具图不构成提示词修改理由。

## 工具字段不支持

视频工具若不支持独立人物、场景、声纹或道具字段：

- 不把资产描述写进提示词；
- 不把图片文件名写进提示词；
- 不生成替代关键词；
- 停止相关镜头并报告缺失的工具能力。

## 映射登记

建议内部保存：

```json
{
  "characters": {"成明": "asset_character_cm"},
  "scenes": {"客厅": "asset_scene_livingroom"},
  "voices": {"CM": "asset_voice_cm"},
  "props": {"白色保温杯": "asset_prop_cup"}
}
```

映射登记只用于工具字段，不得改变分镜原文。
