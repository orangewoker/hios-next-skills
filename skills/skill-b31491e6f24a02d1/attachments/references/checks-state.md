# 错误、警告、时长核算、状态块与自查

## 十六、错误等级与警告机制

分镜脚本生成前后，必须按错误等级检查。

### 1. 阻断错误

出现后不得直接交付，必须先修正或警告用户。

包括：

1. Seedance2.0 时长超出 4s~15s。
2. 参考图超过 9 张。
3. 参考视频超过 3 个。
4. 参考音频超过 3 个。
5. 参考视频和参考音频合计时长超过 15s。
6. 分镜脚本不独立，依赖外部上下文。
7. 参考素材引用缺失或编号错误。
8. LibTV CLI / Agent 工具层场景下，文档层 `{{Node <nodeKey>}}` 未与左侧上游节点闭合，或 Agent `generate_video_v3` 执行前未转换为工具层 `{{nodeKey}}` / `sound: "off"` / `sound: "on"`。
9. 复杂动作未触发 @BLOCKING。
10. 台词总时长超过镜头时长 80%。
11. 单镜内容无法在设定时长内完成。
12. 时长核算结论已调整镜头时长，但分镜标题行时长未同步更新。
13. 创作确认清单未强制逐项确认选择，或用总确认代替逐项选择，却开始资产计划或生成提示词；模型、去噪选项或门禁审核细致度未明确选择具体值或“使用默认值”就继续执行。
14. 未完成 P0 色板确认就进入 P1 角色/场景资产，或试图让 P0 和 P1 并行。
15. 色板、角色、场景或道具参考图未通过硬性格式审核；场景参考图出现角色。
16. 资产缺少逐张审核状态，或把 `rejected / needs revision` 资产写入正式分镜引用区。
17. Agent `generate_video_v3` prompt 未按 prompt 字段组装顺序排列，或删除了可执行音效。
18. 有台词镜头未将实际发声角色音色节点加入 `reference_nodes`，或未在 prompt 台词行紧前方插入 `{{音色nodeKey}}`。
19. 运行本 Skill 时调用、套用或优先使用其他 Skill / agent 自带流程，导致本 Skill 流程、门禁、引用、代入或连线规则被覆盖。
20. 分镜脚本正文包含降级方案、所用模块、模块名或模板名等与视频生成无关的执行说明。
21. 深度故事板未生成、审核非 passed、nodeKey 不存在/非当前有效、故事板已失效，却开始视频 Promote 或视频生成。
22. 深度故事板引用色板、色彩脚本、音频、尾部 2 秒视频或其他视频节点。
23. 视频未引用已通过的深度故事板或本镜色板；故事板未进入视频 reference_nodes 或 Prompt。
24. 视频参考资产定义缺少空间位置、相对关系或朝向，或其定义与深度故事板冲突。
25. 有台词但缺少实际发声角色音色节点，音色不在 3–4 秒，或台词行前未插入音色 nodeKey。
26. 深度故事板、色板、首尾帧和普通资产的唯一图像节点合计超过 9。
27. 尾部 2 秒视频进入深度故事板生成，或故事板需要承接视频却未先抽取尾帧。
28. 视频 Prompt 未以一句话分镜总结开头，或使用表格、项目编号、父镜头、验收状态、链深度等跨镜头管理字段。
29. 本镜实际引用的人物、道具或场景没有在视频 Prompt 中写明定义、空间位置/关系和朝向；场景不得被强制写成“不可变空间结构”。
30. 视频 Prompt 未明确深度故事板不得以灰度、深度编码、九宫格、分隔线或白底形态出现在成片中。
31. 连续延长镜缺少本次传入的尾部 2 秒视频，未写明前 2 秒完整继承与第 2 秒后 P1→P9 的推进，或把九格误写为九个平均切分的独立镜头。
32. 尾部 2 秒视频含台词，但其角色、语言或原文没有对应同一角色的 3–4 秒音色节点。
33. 尾帧锁定节点重复进入普通参考节点，或其状态与深度故事板 P9 不一致。
34. 连续延长镜的深度故事板 P1 未与已抽取并审核的尾帧在主体位置、朝向、运动余势或摄影机状态上相符。
35. 连续延长镜把 0.0–2.0 秒尾部视频继承段写入深度故事板脚本，或未明确故事板只控制第 2 秒后的 P1→P9 段。
36. 实际引用的环境音、动作音或系统声音频未进入 `reference_nodes`，未在音效层紧邻插入对应 nodeKey，或未说明其声音角色。
37. 本次生产范围内仍有正式分镜待生成、未通过或待修改，却在单个分镜批次结束后生成深度故事板、视频 Promote 或视频。
38. 未对已闭合的全范围正式分镜和连续性方案完成派生参考图缺口检查，或确认需要的表情/状态、关键帧、首尾帧、尾帧抽取图、派生起幅图未审核通过，就生成深度故事板或视频。
39. 深度故事板图片 Prompt 未在固定提示词后完整写入当前有效正式分镜的深度相关正文，压缩为起幅/中段/落幅摘要、连续叙述或 Agent 预先设计的 P1–P9 具体画面。
40. 深度故事板实际引用的非色板图像资产未写入真实 nodeKey、定义、空间位置/关系、朝向或本镜状态，或遗留方括号、模板文字、空占位符、虚构 nodeKey。
41. 色板或灰度深度故事板进入 LibNano 2 去噪；其他参考图未经内容与格式初审即去噪，或去噪后未终审就用于后续引用。
42. 特效参考图未使用 LibNano Pro、2K、1:1，未使用纯白/纯黑/纯绿之一的最高对比背景，画面出现角色/道具/具体背景，或 Prompt 未自动代入实际引用、关联定义、使用场景和特效效果。
43. 深度故事板的 `深度字段原文副本` 未保留原字段标题、顺序、行/表行结构或字段值；缺少主体画面方位表、视觉优先级、速度差设计、动作/调度或连续性字段；除节点语法转换与规定排除项外发生自主删改、合并、转述、翻译、重排或补写；或 `source_fidelity_passed` 未记录却调用 `generate_image_v3`。

44. 相邻制作镜存在同场景时间连续、共同动作/状态、明确出入画方向或前镜预埋线索，却写“独立生成”或以建立镜头、景别/机位变化、静止摄影机、节奏对比、独立展示单元作为无连续性的依据；强/弱连续性缺少实际可传入的场景/状态/方向/首尾帧/派生起幅参考 nodeKey、触发证据、静态复查结论或运行时依赖结论。
45. 未在全部正式分镜审核闭合后，对每镜和每个相邻制作镜对完成全范围视觉参考完整性复查；未检查角色/主体、场景与点位、道具与状态、表情与表演、特效、关键帧和连续性参考，或静态补充资产未审核通过即生成故事板，或运行时依赖镜在前镜视频、尾帧、派生起幅图未通过前生成故事板。
46. 深度故事板仅通过结构/深度审核，未逐项完成 `storyboard_semantic_fidelity` 审核，或关键可见结果、结果瞬间、视觉优先级、主体方位/空间层级、动作因果顺序、摄影机观察任务/轨迹/速度差、实际资产或关键特效与当前有效正式分镜存在缺失、矛盾、无法辨认、方位反转、未定义机位重置/切换。
47. 视频实际传入的任一图像资产缺少唯一主控维度或禁止迁移项；深度故事板以外的资产覆盖时间线、动作过程、空间调度或摄影机过程；色板覆盖对象/空间/动作；或任一控制维度出现多个主控者。
48. 本镜时长可行性结论为“无法承载”却继续生成，或“高风险但可尝试”未取得用户明确接受、未通过已确认资产降低风险就生成故事板或视频。
49. 正式分镜中的关键可见结果、结果出现的瞬间或视觉优先级包含独立控制特效，但全范围视觉参考完整性复查未生成并审核特效参考图，却用色板、灰度故事板亮度或纯文字替代。

输出格式：

```text
【阻断错误：原因】
【处理建议：拆分 / 删减 / 修改时长 / 改逐镜生成】
```

### 2. 强警告

可以继续，但必须提示风险。

包括：

1. 台词总时长超过镜头时长 60%。
2. 动作、台词、运镜同时过密。
3. 同一镜头包含多个叙事转折。
4. 镜头预计需要超过最佳时长 12s。
5. 多主体调度复杂但仍在可执行范围边缘。
6. 使用快速模板但接近复杂调度边界。
7. 输出长度接近上下文上限。

输出格式：

```text
【警告：风险说明】
【建议：压缩 / 拆镜 / 改逐镜调试】
```

### 3. 优化提示

不阻断，只提示质量优化方向。

包括：

1. 情绪描写可进一步具体化。
2. 光影动机不够明确。
3. 运镜终点不够清晰。
4. 音效层次可精简。
5. 风格锁定存在少量重复。

输出格式：

```text
【优化提示：建议项】
```

## 十七、时长承载检查机制

每个镜头必须检查设定时长是否足以覆盖内容、动作和台词。

### 基础公式

```text
镜头所需最低时长 = 动作必需时长 + 台词总时长 + 首尾缓冲时长
```

默认缓冲：

- 起幅缓冲：0.3s~0.5s
- 落幅缓冲：0.3s~0.5s
- 情绪反应镜头额外缓冲：0.5s~1s

### 台词时长检查

1. 对白总时长 ≤ 镜头时长 60%：通过。
2. 对白总时长 > 镜头时长 60%：警告。
3. 对白总时长 > 镜头时长 80%：阻断。
4. 对白总时长 + 动作必需时长 > 镜头时长 90%：阻断或拆镜。

### 内容承载检查

以下情况说明镜头时长不足：

1. 同一镜头包含两个以上主要动作。
2. 同一镜头包含动作、反应、信息揭示三个完整阶段，但时长低于 8s。
3. 有台词、有复杂动作、有运镜变化同时存在，但时长低于 10s。
4. 需要建立空间、完成动作、给出情绪反应，但时长低于 8s。
5. 复杂调度含 3 人以上互动，却低于 10s。

### 处理策略

若时长不足，按优先级处理：

1. 删减台词。
2. 简化动作。
3. 拆分为多个镜头。
4. 延长到 5s~12s 最佳区间内。
5. 若仍不足，拆成多次 Seedance2.0 生成。

硬规则：时长核算区得出的最终时长必须回写到分镜标题行 `【镜XX】标题 | 时长：Xs`；若核算建议 S01B 改为 10s，标题行必须同步为 10s，不得保留旧时长。

## 十八、警告输出位置与分镜脚本隔离规则

所有警告、阻断错误、强警告、优化提示、生成限制说明、拆分建议，必须输出在回答顶部，并且位于分镜脚本正文之外。

警告不得写入分镜脚本内部，不得出现在镜头字段、负面提示词、动作层、声画关系、光影、风格锁定或任何可直接提交给 Seedance2.0 的提示词文本中。

原因：分镜脚本本身是可直接提交给 Seedance2.0 的独立提示词文本。警告属于编译系统对用户的说明，不属于模型提示词内容。若警告混入分镜脚本，会污染生成提示词。

### 标准输出结构

```markdown
【编译警告区】
- 若无警告：写“无阻断错误，可生成。”
- 若有警告：列出阻断错误 / 强警告 / 优化提示。
- 若无法继续：先说明原因与处理方案，不输出被污染的分镜脚本。

---

【制作清单】
- 需要制作清单时输出视觉控制包、参考图需求、参考音频需求、参考视频需求、素材生成顺序和待确认项。
- 用户未确认素材前，不得伪造正式引用。

---

【分镜时长核算区】
- 镜头目标时长、对白估算、动作/运镜估算、承载结论。
- 此区属于编译判断，不得进入分镜脚本正文。

---

【分镜脚本】
这里开始才是可提交给 Seedance2.0 的提示词文本。
不得包含警告、解释、系统提示、修改建议或时长核算过程。
```

### 阻断错误时

```markdown
【编译警告区】
【阻断错误】
1. 原因。

【处理建议】
1. 拆分 / 删减 / 修改时长 / 改逐镜生成。

---

【分镜脚本】
暂不输出。需先修正阻断错误，避免生成不可用提示词。
```

## 十九、断点续写与状态块机制

当故事、分镜数量或模块调用过多，可能导致上下文限制或输出中断时，必须启用断点续写机制。

### 触发条件

满足以下任一条件，应启用状态块：

1. 预计输出超过 3 个完整模板镜头。
2. 需要分批生成。
3. 逐镜调试。
4. 用户反复增删修改。
5. 已生成内容较长，后续仍需继续。
6. 上下文中已有多个资料库或长分镜。

### 状态块内容

```text
【分镜编译状态块】
项目/故事一句话概括：
Seedance2.0 限制：
已确认全局规则：
已确认视觉控制包：
已确认参考素材：
当前镜头索引：
已完成镜头：
待生成镜头：
当前使用模块：
已触发警告：
下一步建议：
```

### 中断后续写规则

如果生成中断或用户说“继续”，系统必须先读取状态块，再从下一个未完成镜头继续，不得重新开始，不得改变已确认规则。

状态块不属于 Seedance2.0 分镜脚本正文，不得混入【分镜脚本】区域。

## 二十、分级歧义自查

以下保留原自查表，并新增 Seedance2.0 限制检查、上下文与输出长度检查。

## 七、分级歧义自查


### 阻断性检查（必须全部通过，否则AI必然出错）


| # | 检查项 | 通过标准 |

|---|--------|----------|

| 1 | 任务类型是否正确？ | 编辑/延长已用`@视频N`指代 |

| 2 | 参考图是否已引用？ | `@图片N`出现在模板引用区 |

| 3 | 引用语法是否正确？ | 引用区使用 `@图片N=nodeKey` / `@色板_XXX=nodeKey`，正文主体或场景处使用文档层 `{{Node <nodeKey>}}`，不得只写裸 `@图片N` |

| 4 | 是否有显式运镜冲突？ | 单镜头运镜≤2种，方向一致 |

| 5 | 主体特征是否矛盾？ | 同一主体的体型/材质/朝向描述前后一致 |

| 6 | 参考人物是否超4人？ | 超4人→分组生图再合成 |

| 7 | 方向词在角色间是否一致？ | 各角色方向参照系已统一或分别声明 |

| 8 | 武器/道具是否已限定？ | 负面提示词中已声明武器数量与形态不变 |


### 优化性检查（通过则质量显著提升）


| # | 检查项 | 通过标准 |

|---|--------|----------|

| 9 | 空间是否明确？ | 读者可画出俯视位置图 |

| 10 | 朝向是否标注？ | 每个主体标注面对方向 |

| 11 | 对白字数是否核算？ | 对白总时长≤镜头时长-动作必需时间；核算后标题行时长已同步 |

| 11-1 | 对白格式是否规范？ | 每句台词用 `{}` 包裹，停顿使用 `(短停)` `(短叹)` `(换气)` 等标准符号，台词原文未被改写 |

| 12 | 动作是否正面描述？ | 无"不要""没有"等否定词 |

| 13 | 风格锁定是否具备通用呈现规则？ | 不复述画面物件；已定义媒介、渲染方式、主体分类风格、材质纹理边界和必要缺漏提示 |
| 13-1 | 多主体风格是否隔离？ | 背景、角色、机械、路人、UI、道具等类别已分别定义风格；明确哪些风格和材质不得互相污染 |

| 14 | AI能力预判是否通过？ | 无快速剧烈运动、>3人复杂互动、手部精细细节 |

| 15 | 动作幅度在真人可执行范围？ | 无超2.5米无助力跳跃、无滞空超1.5秒、无关节反向弯曲 |

| 16 | 手法是否过载？ | 当前手法未在前3镜中连续使用 |

| 17 | 是否使用多视图？ | 参考图非三视图/多视图 |

| 18 | 色板引用是否正确？ | 若启用色板，当前镜头已正确引用 |

| 19 | 色彩脚本与色板是否一致？ | 文字描述与色板图的情绪色调吻合；色板 nodeKey 已在色彩脚本处按当前层级语法插桩 |

| 20 | 画面目标是否与运镜动机一致？ | 摄影机运动动机服务于本镜关键可见结果 |
