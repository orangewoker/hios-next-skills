# 附MD07 | 欧美恐怖生存·JSON数据与引擎对接

**所属主SKILL：** 欧美恐怖生存 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

确保互动影游能落地运行、可直接交付工程。

## #需要什么输入

完整节点清单、变量字典、视频文件。

## #怎么做

### 一、JSON数据结构

包含variables（理智值、存活人数、怪物仇恨等）、nodes、endings。

### 二、Twine/SugarCube 工程规范

严格遵循SugarCube 1.0.35锁定规范。变量赋值使用标准set语法，禁止使用符号。

### 三、视频文件命名规范

N01.mp4（抵达木屋）、N02A.mp4（分头睡）、N02B.mp4（守夜）等。

### 四、本地测试规范

VS Code + Live Server。重点测试死亡结局（Game Over）后的变量重置。
