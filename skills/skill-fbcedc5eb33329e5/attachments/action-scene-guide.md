## 三阶段工作流

打戏场景严格分三个阶段执行，每个阶段必须等待用户确认后才能进入下一阶段：

```
阶段一：文字大纲 → [用户确认] → 阶段二：分镜图 → [用户确认] → 阶段三：视频提示词
```

### 状态机

| 状态 | 触发条件 | 允许执行 | 下一步 |
|------|----------|----------|--------|
| S1 输入锁定 | 用户上传参考图/资料 | 锁定角色、武器、场景、目标、结局 | → S2 |
| S2 文字大纲 | 输入已锁定 | 输出剧情简介+16格文字镜头表 | → S3 |
| S3 等待大纲确认 | 文字大纲已输出 | 只接收确认或修改意见 | 确认→S4；修改→S2 |
| S4 分镜图生成 | 用户确认文字大纲 | 生成4x4黑白分镜图 | → S5 |
| S5 图像自检 | 已得到图像文件 | 逐格检查+原图返修 | 合格→S6 |
| S6 等待分镜确认 | 图像自检通过 | 发送图像+确认问题 | 确认→S7；修改→S5 |
| S7 视频提示词 | 用户确认分镜图 | 生成16条视频提示词 | 完成交付 |

### 确认门禁（绝对禁止跳过）

- 文字大纲未确认时：禁止调用图像生成工具
- 分镜图未确认时：禁止生成视频提示词
- "继续""先看看""差不多"不等于确认，需追问

## 阶段一：剧情简介与16格文字镜头大纲

### 输入锁定

根据用户上传的参考图，明确并锁定：
- 角色A：身份、体型、服装、武器、能力、战斗风格
- 角色B：身份、体型、服装、武器、能力、战斗风格
- 场景：地形、建筑、空间层级、关键地标、可破坏物、光线方向
- 战斗目标：夺门/抢夺/护送/逃离/守护/阻止仪式/其他
- 结局：A获胜/B获胜/平局/反转/开放悬念

### 剧情简介（2-4句话）

必须说明：
1. 角色A想完成什么具体目标
2. 角色B怎样阻止或追击
3. 正面对抗为什么不够，角色如何改变战术
4. 场景或道具怎样参与因果链
5. 最终采用什么结局、反转或悬念

### 16格文字镜头大纲格式

| 格 | 时长 | 景别与机位 | 可见主体 | 画面动作 | 衔接与作用 |
|----|------|-----------|----------|----------|-----------|
| 1 | Xs | 景别、角度、运动 | 环境/A/B/双人/局部 | 本格可见动作 | 建立/触发/衔接 |
| 2-16 | ... | ... | ... | ... | ... |

### 文字大纲自检

- [ ] 总时长是否落在25-28秒或用户指定范围
- [ ] 是否存在明确目标、阻力、战术变化和结尾
- [ ] 是否有环境或道具参与战斗因果
- [ ] 是否包含空镜、单人、局部/主观和双人镜头
- [ ] 双人完整同框是否超量（不超过5-6格）
- [ ] 武器互指/正面对撞是否超量（不超过3格）
- [ ] 相邻镜头景别与机位是否有变化
- [ ] 是否至少有一次高速、一次骤停和一次高潮
- [ ] 前一格结束状态是否能连接下一格

## 阶段二：分镜图生成与自检

### 分镜图规格

- 总画幅：16:9横向，2048x1152
- 画格：严格4列x4行，共16格
- 每格：512x288横向
- 风格：黑白线稿，纯黑/深灰轮廓线，白色背景
- 阅读顺序：左到右、上到下

### 人物显隐规则

- 大纲写"环境空镜"时，该格不得出现人物
- 大纲写"A单人"或"B单人"时，只能出现指定角色
- 大纲写"局部/主观/道具特写"时，不得自动补成双人全身
- 只有大纲明确写"双人同框"才能突出显示双方

### 图像自检（硬性通过项）

- [ ] 总画幅16:9，目标尺寸2048x1152
- [ ] 正好4列x4行，共16格
- [ ] 16格大小相等，无合并/缺格/多格
- [ ] 只有用户指定的主要角色，无额外人物
- [ ] 每格可见主体符合已确认文字大纲
- [ ] 角色脸部、体型、服装、武器在16格中保持一致
- [ ] 场景类型与关键地标保持一致
- [ ] 180度轴线遵守，无无理由换边
- [ ] 前一格结束姿势可连接后一格开始姿势
- [ ] 至少有一次明确静止和一次高潮
- [ ] 双人完整同框没有成为多数
- [ ] 最后一格有清楚结局/反转/悬念
- [ ] 无严重肢体畸形、穿模
- [ ] 黑白线稿，无明显彩色污染
- [ ] 无字幕、对话、格号、水印

### 返修规则

1. 返修前必须打开当前整张分镜原图
2. 返修时把完整原图作为编辑目标，只修改指定格
3. 明确写"只修改第X格，其余15格保持不变"
4. 禁止为修一格而单独生成独立图片再拼接
5. 每次返修后重新检查非目标画格是否被误改

## 阶段三：视频提示词生成

### 触发条件

只有用户明确确认分镜图后才执行。

### 输出结构

1. 图片职责声明（分镜图/角色A/角色B/场景对应的图片编号）
2. 统一视频视觉前缀
3. 镜头1-16视频提示词
4. 连续性自检结果

### 单镜头视频提示词模板

```
镜头{{编号}}，时长{{秒数}}秒，{{节奏}}。

输入图片是已确认16格分镜图中的第{{编号}}格，是本镜头的构图、人物位置和起始姿势参考。保持角色身份、脸部、服装、武器和场景完全不变。

镜头开始：
{{描述第一帧中角色A、角色B、武器和环境的位置与状态}}

动作过程：
首先，{{第一个动作及身体发力方式}}。随后，{{第二个动作、移动方向与速度变化}}。当{{武器/身体/能量}}接触{{目标}}时，产生{{冲击、震动、火花、碎石、布料或能量反馈}}。动作在{{时间点}}突然加速、减速或停止，并自然保留余势。

环境反应：
{{头发、衣袖、斗篷、灰尘、碎石、建筑、火花或能量如何响应动作}}

摄像机：
{{景别}}，{{机位角度}}。摄像机从{{起点}}向{{方向}}进行{{推近/拉远/横移/跟拍/环绕/甩镜}}，运动速度{{缓慢/稳定/高速}}。只在{{命中或爆发时刻}}出现一次短促轻震，其余时间保持稳定。遵守已确认分镜图的180度轴线，不改变双方左右关系。

动作与运镜自然收束到{{下一镜头所需的连接姿势}}，不新增分镜图中不存在的角色、武器、招式或场景变化。
```

## 镜头配额与节奏设计

### 默认镜头配额（16格）

| 类型 | 格数 | 说明 |
|------|------|------|
| 环境空镜/环境主导 | 2-3格 | 建立空间、喘息节奏 |
| 单人全身/单人动作 | 4-6格 | 角色个人表现 |
| 主观/局部/武器/道具特写 | 3-5格 | 细节、紧张感 |
| 双人完整同框 | 3-5格（最多6格） | 对抗场面 |
| 武器互指/正面对撞 | 最多3格 | 避免重复 |

### 节奏曲线

```
慢 → 快 → 停 → 爆 → 静 → 高潮 → 定格
```

- 第1-4格：环境与单人登场，建立目标、距离和危险
- 第5-8格：第一次加速，试探失败后转向环境/道具/战术弱点
- 第9-12格：空间失衡、坠落、追逐或反制；安排一个明显静止或机械停顿
- 第13-15格：隐藏手段揭示、环境因果兑现与高潮位移
- 第16格：完全静止，用结果、反转、影子、空位、残留物或新威胁形成记忆点

### 因果链规则

- 每次动作必须有原因和结果
- 某格触发的破坏、伤势、落点或道具状态，要在后续格继续存在
- 高速动作后必须留出可感知停顿

---

## 180度轴线规则

- 角色A主要保持在画面左侧，角色B主要保持在右侧
- 180度轴线负责方向连续，不等于每格都必须同时出现两人
- 单人镜头、主观镜头、空镜也必须遵守行动方向
- 不得无理由让双方换边

## 图像自检清单

### 硬性通过项（任一失败则整图不可交付）

- [ ] 总画幅16:9，目标尺寸2048x1152
- [ ] 正好4列x4行，共16格
- [ ] 16格大小相等，无合并/缺格/多格/不规则格
- [ ] 只有用户指定的主要角色，无额外人物或重复人物
- [ ] 每格可见主体符合已确认文字大纲
- [ ] 参考图职责没有混淆，多角色没有融合
- [ ] 角色脸部、体型、发型、服装、武器在16格中保持一致
- [ ] 场景类型与关键地标保持一致
- [ ] 180度轴线遵守，无无理由换边
- [ ] 16格动作按左到右、上到下能连续阅读
- [ ] 前一格结束姿势可连接后一格开始姿势
- [ ] 至少有一次明确静止和一次高潮
- [ ] 双人完整同框没有成为多数
- [ ] 连续三格没有重复使用相似的双人中景对打构图
- [ ] 最后一格有清楚结局/反转/悬念
- [ ] 无严重肢体畸形、穿模、角色融化
- [ ] 黑白线稿，无明显彩色污染
- [ ] 无字幕、对话、格号、数字、水印

### 质量项

- [ ] 每格景别和机位有变化，但视觉语言统一
- [ ] 环境/单人/主观/双人镜头形成可读交替
- [ ] 环境或道具至少一次真正改变局势
- [ ] 动作剪影清楚，角色没有被遮挡
- [ ] 攻击能看出起势、接触、受力和余势
- [ ] 高速段之后有可感知停顿
- [ ] 环境破坏沿受力方向发生，并在后续格保持
- [ ] 线条轻盈克制，无厚重黑块
- [ ] 画格边缘保留安全空间

## 视频提示词模板

### 统一视频视觉前缀

```
图片{{分镜图编号}}按照分镜图的顺序，构建一个完整的故事剧情，运镜合理连贯。
图片{{角色A编号}}作为角色A。
图片{{角色B编号}}作为角色B。
图片{{场景编号}}作为{{场景名称}}场景。

项目类型与世界观：{{项目类型、时代、整体氛围}}。
角色A视觉锁定：{{脸部、体型、发型、服装、盔甲、武器、能力、标志性轮廓和颜色材质}}。
角色B视觉锁定：{{脸部、体型、发型、服装、盔甲、武器、能力、标志性轮廓和颜色材质}}。
场景视觉锁定：{{建筑、地形、空间、关键地标、可破坏物、光线方向、颜色和材质}}。

连续性规则：严格遵守已确认的16格分镜图。角色A主要保持在画面左侧，角色B主要保持在右侧；服装、武器、身体比例、光线方向、场景地标和累积战损保持一致。前一镜末姿势自然连接后一镜首姿势。

物理与摄影：动作具有真实重量、惯性、接触和受力反馈；高速后安排停顿；特效克制，不遮挡人物和命中点；镜头稳定为主，只在关键命中时短促轻震；高质量，2K，16:9宽银幕，清晰细节，干净边缘。
```

## 与IMAX基线融合

打戏场景在激活专项流程的同时，仍需遵守IMAX基线：

| 基线规则 | 打戏场景适配 |
|----------|-------------|
| IMAX胶片质感 | 分镜图为黑白线稿；视频提示词追加胶片颗粒/高光滚落 |
| 电影级画面风格 | 前中后景层级；空气介质（灰尘/碎石/火花） |
| 去AI感工程 | 动作有真实重量/惯性；特效不遮挡接触点 |
| 巨物检测 | 如战斗对象为巨物，同时激活巨物规则 |
| 表情检测 | 角色特写镜头激活情绪模板 |
| 科幻检测 | 如场景为科幻，同时激活库布里克风格 |

### 打戏专用负面约束（追加到通用负面约束）

避免：连续双人对峙、重复武器互指、角色融合、角色外观变化、换脸、服装变化、武器消失、额外人物、多余肢体、手掌畸形、关节反折、身体扭曲、动作方向混乱、角色突然换位、违反180度轴线、背景突变、建筑变形、环境破坏复原、合并画格、缺少画格、超过16格、不规则排版。
