## #做什么

本模块是“影视制作 Agent”的核心调度逻辑库与演示脚本库。

解决：不同题材的剧本，该调用哪些下层Skill、按什么顺序调用、最终如何生成调度演示视频的问题。

本模块将分散的Skill资产组装成标准化的视频演示链路，并直接交付**视频文件（MP4格式）**、视频脚本、Prompt清单与视觉方案。

## #需要什么输入

**最少提供：**

- 剧本或故事创意
- 题材方向：科幻、武侠、女频、3D动画等
- 目标制作类型：电影 / 精品短剧 / 强节奏短剧 / 短视频
- 目标时长

**可选提供：**

- 特定风格偏好，如徐克式武侠、卡朋特式悬疑
- 项目预算与算力限制
- 目标画幅，不限定，按项目需求或用户指定
- 是否需要参考案例库

## #怎么做

### 一、【绝对工作流铁律】（最高优先级，严禁调换）

在收到任何题材的创作需求后，必须严格按以下固定顺序调度下层Skill。顺序一旦错误，直接判定为系统违规，必须打回重排：

1. 【总制片人】（前置算力审查，资产门禁）
2. 【葵花宝典】（剧本诊断与重构：困兽、体语、焚我）
3. 【大导演思维】（镜头转译与叙事构思）
4. 【情绪大师】（七层微表情拆解与情绪连贯）
5. 【风格Skill】（题材专属视觉定调，如武侠/科幻/女频）
6. 【提示词底座】（物理参数与Prompt落地生成）

**为什么必须这个顺序**：先过【总制片人】卡死算力，再让【葵花宝典】做剧本外科手术。剧本没有写出“困兽、体语、焚我”的底层内核，就不准进入【大导演】的镜头设计。剧本改了，分镜全废，必须杜绝这种算力黑洞。

### 二、根据剧本匹配专属调度链路与演示视频内容

1. **科幻/悬疑剧本**

   - 风格Skill：卡朋特、维伦纽瓦、诺兰。
   - 演示视频重点：展示极地密闭悬疑、宏大孤独科幻、高概念非线性的视觉调用过程。

2. **3D动画剧本**

   - 风格Skill：皮克斯3D漫剧TVC。
   - 演示视频重点：展示替换3D动画专属渲染参数、柔和全局光照的调用过程。

3. **武打/动作剧本**

   - 风格Skill：硬核武术指导 + 徐克 / 张彻 / 胡金铨。
   - 演示视频重点：展示“火柴人动作拆解”视频分镜的调用与物理受力生成过程。

4. **女频/甜宠剧本**

   - 风格Skill：爆款女频短剧漫剧 | 顶级大导演思维生产。
   - 演示视频重点：展示柔光、唯美通透、低饱和度与物哀克制调性的参数替换过程。

5. **史诗/东方剧本**

   - 风格Skill：卡梅隆、东方巨构。
   - 演示视频重点：展示宏大构图、巨物张力、大景深的画面生成效果。

6. **互动影游剧本**

   - 风格Skill：专业游戏开发大师、互动影游。
   - 演示视频重点：展示多分支叙事、沉浸式交互钩子的调度与生成。

### 四、演示视频执行原则

1. 严格遵循“总制片人前置审查”原则，未通过算力与合规审查，不进入视频生成环节。
2. 调度链路一旦确定，所有下游模块必须服从，并直观体现在演示视频中。
3. 演示视频必须让用户一眼看懂“先调谁、再调谁、最后生成什么”。
4. **【生成演示视频】**：根据调度逻辑与执行节点，调用底层视频生成Skill，生成“如何调用本Skill矩阵”的演示与全链路指导视频。视频需包含调用清单、调用顺序、制作链路、门禁审查报告的可视化呈现。输出格式为MP4，画幅按项目需求或用户指定。

## #产出什么

最终交付：

- **视频文件（MP4格式）**：全品类调度演示视频，直观展示不同剧本题材对应的Skill调用顺序与组装过程。
- **视频脚本、Prompt清单、视觉方案**。
- 视频中穿插调用后实际生成的画面效果。
- 调用清单、调用顺序、制作链路、门禁审查报告的可视化呈现。
- 调度逻辑说明与执行节点。

演示视频内容包含：调用哪些Skill、按什么顺序调用、每步产出什么、门禁审查如何通过。视频可直接作为不同剧本项目的培训、展示与交付材料。
