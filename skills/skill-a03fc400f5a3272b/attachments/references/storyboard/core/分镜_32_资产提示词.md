# 资产生成规则（规则知识库 · v4.0 裁剪版）

> ⚠️ **v4.0 格式已迁移**：角色设定卡 → `templates/asset_character.md.j2`，物品三视图 → `templates/asset_prop.md.j2`，场景空间蓝图 → `templates/asset_scene.md.j2`。数据 schema → `scripts/_asset_schema.py`，渲染 → `scripts/render_assets.py`。
> 本文件仅保留**资产分类判定规则和全局约束**作为 AI 填 JSON 时的知识参考。

---

## 分类判定

| 类型 | 写入 | 判定 |
|:---|:---|:---|
| 角色绑定内容 | `角色设定卡.md` | 固定外观、配饰、身份标识、能力视觉 |
| 独立调度物 | `物品三视图.md` | 可离开角色独立存在，被传递、交换、破坏 |
| 场景组成物 | `场景三视图.md` | 固定属于空间结构或环境氛围 |

---

## 资产定义规则

- 资产名：短、稳定、全文一字不差
- 一图一资产：每个文件只含一个角色/物品/场景
- 角色绑定内容（固定外观/配饰/能力视觉）→ 角色设定卡
- 独立调度物（可被传递/交换/破坏）→ 物品三视图
- 场景组成物（固定属于空间结构）→ 场景三视图
- 尺度锚点：每个资产必须写明具体尺寸或实物参照
- 资产边界：角色档案不含场景和独立调度物，物品档案不含角色和场景，场景档案不含角色和独立调度物

---

## 全局风格约束

| 要素 | 资产图 | 视频 |
|:---|:---|:---|
| 渲染质量 | 8K，产品级渲染 | 电影级，一致性锁定 |
| 背景 | 纯白（物品）/ 场景（角色） | 场景图继承 |
| 标注 | 禁止任何文字/图解 | — |
| 风格关键词 | 继承 `.user-profile.json` image_style_pipeline | 继承 `_freeze_card.md` |
| 画面要求（v4.0 硬编码） | live action cinematic motion, controlled movement complexity, natural easing, controlled motion blur; clean temporal stability, consistent lighting; no jitter, no flicker; no noisy textures, no excessive micro-details, no over-sharpening, no chaotic surface patterns; clean visual hierarchy, details only in focal areas | 同左 |
