# 质量检查

在交付或保存每次成片前逐项检查。任何“否”都不能作为 Showcase 原始输出提交。

## 输入与事实

- [ ] 使用的是同一商品的 1–6 张实拍参考图，且至少一张清晰呈现完整主体。
- [ ] 仅提供 1 张图时，成片没有展示图片中不可见的背面、内部或未提供的使用状态。
- [ ] 商品名称、品类、3 条卖点、目标场景和禁用项齐全。
- [ ] 所有文案均能回溯到用户确认资料；无新增参数、认证、功效或价格。

## 商品保真

- [ ] 商品轮廓、比例、颜色、关键部件、接口、按钮和可见配件与参考图一致。
- [ ] 品牌、型号与小字没有被伪造、替换或以乱码呈现。
- [ ] 使用动作、产品接触、液体流向、阴影和受力关系可信。
- [ ] 未出现无关花瓶、植物、食物、额外产品或无关装饰。

## 成片质量

- [ ] 画面为 9:16；时长为 15 秒或 30 秒。
- [ ] 叙事包含商品呈现、至少两项卖点和清晰收束。
- [ ] 每个镜头只有一个视觉重点；转场与音乐节奏不打断卖点理解。
- [ ] 主商品清晰、曝光稳定；没有明显变形、闪烁、穿模、跳变或镜头漂移。
- [ ] 文字在安全区内、可读且不遮挡核心结构。

## 合规与提交

- [ ] 未使用未授权人物、音乐、商标、商品图或第三方成片。
- [ ] 未出现血腥、色情擦边、低俗、误导性或高风险内容。
- [ ] 该输出由同一 Skill 在 LibTV 中直接生成，未经过人工修片。
- [ ] 已保存对应输入、Skill 版本、Agent 对话/Showcase 链接和本次检查结果。

## 失败处理

- 商品外观不一致：回到产品事实表，锁定发生变化的部件后仅重生成相关镜头。
- 卖点不成立：删除或改为用户资料可证明的表达，不用同义词掩盖问题。
- 画面杂乱：移除无关道具，减少镜头内信息，只保留商品与卖点所需元素。
- 文字不可读：缩短为一个已确认卖点，增大字号并移入安全区；不要补造小字。
- 连续两次都无法稳定复现：记录为待迭代问题，不将该案例作为提交 Showcase。
