# 产品风格包：奔奔王国 v0.3

> 依据：丁总提供的 8 份 AI 漫剧准入表（260907-260915，北庭批次）+ 分镜参考图 + 对标视频索引。
> 参照图库：本地 `lark-ref/imgs/bb_*`（角色立绘与分镜参考，共 40+ 张）。
> 状态：主体可用。画风锚定词与母题已由真实脚本反推；**抽卡实测与客户反馈后持续迭代**。

## 1. 产品定位与调性

- 产品：中世纪塔防休闲游戏（国王/骑士/马/大头兵的职级世界观），对标视频多为塔防小程序素材。
- 调性：**喜剧 + 逆袭**。短平快，30 秒上下，笑点密度高于画面华丽度。
- 情绪公式：**受辱 → 隐忍 → 爆发/反转 → 强者碾压式收尾**（喜剧性打脸，不是爽剧式复仇）。

## 2. 画风锚定（核心）

- **3D 卡通渲染，游戏 CG 质感**（皮克斯式立体卡通，非日漫 2D，非写实）。
- 英文锚定词（Prompt 正文用）：
  `3D cartoon render, stylized game CG character, Pixar-style proportions, soft studio lighting, clean shading, high detail materials, vibrant colors`
- **角色立绘标准**：浅蓝纯色影棚背景（`plain light blue studio background`），全身单角色居中——生成人物资产图时照此构图，分镜参考图即用此标准。
- 材质重点：盔甲金属质感、粗布补丁衣料、木材与石墙——细节保持短语（output-adaptor 7.2）在这些元素上必加。

## 3. 固定角色档案（跨镜一致性重点）

| 角色 | 形象锚点 | 比例参照（防拉伸变形，见 7.3） |
|---|---|---|
| 主人公（胖子大头兵） | 寸头络腮胡、蓝色破洞补丁粗布衣、麻绳腰带、体型矮壮肥胖 | 站立约与马背同高；肩宽约为骑士的两倍 |
| 白马 | 极瘦、鬃毛灰白、表情疲惫无奈（喜剧担当） | 马背高度到胖子胸口；脖子细长 |
| 国王 | 华贵王袍、王冠、傲慢体态（躺床上指使人是常态） | 站立高出胖子一个头 |
| 骑士 | 银甲红袍、执旗枪（参照女骑士立绘）、中层官僚气 | 介于国王与胖子之间 |
| 功能角色 | 厨娘（隐藏强者）、路人、鉴定官——反差型配角 | 厨娘体型可夸张壮硕（喜剧反差） |

**人物资产图规则**：主人公、白马、国王、骑士已有定稿立绘的，视频提示词一律 `@图片N` 引用，删除静态外观描述（output-adaptor 第 4 节）。

## 4. 剧情母题库（脚本层的常用套路）

| 母题 | 结构 | 出处批次 |
|---|---|---|
| 等级准入 | 按职级享受不同待遇（打饭/宿舍铺位/鉴定），主角垫底受辱 | 铁水鉴定、打饭、阶级宿舍 |
| 逐层分包 | 国王→骑士→马→胖子层层压任务，胖子爆发 | 马桶公寓逐层分包 |
| 塔型 PK | 现实冲突升级为"掏塔互砸"：弩炮塔 vs 火箭塔 vs 狙击塔，更强者碾压 | 豆腐脑VS火箭塔、美女搭讪 |
| 身份反差 | 隐藏强者（厨娘）一招碾压气焰最盛者 | 美女搭讪篇结尾 |

写脚本时先归类母题，再套用第 5 节结构。

## 5. 结构模板（分镜表口径）

分镜时长用**秒级区间**（1~17s / 17~30s 这类），总长 30s 上下：

1. **0-3s 钩子**：反常动作或受辱瞬间开场（铁水烫手、火球砸门、插队被怼）。前 3s 必须贴分镜参考图。
2. **3-17s 铺垫与施压**：层层施压/冲突升级，每层一个节拍；喜剧比例反差随时插入（白马踉跄、胖子被压得眼珠突出）。
3. **17-27s 反转/爆发**：主人公反制或更强的第三方碾压；塔型实体砸桌是招牌动作。
4. **27-30s 收尾口播**：固定卖点话术接"奔奔王国，启动"式口令。

**结尾口播卖点池**（从对标视频原话沉淀）：三分钟一局、超爽超解压、没有日常任务、没有强制 PK、不打排位不搞赛季、时间自由随时开随时停、不占用私人时间。

## 6. 台词风格

- 口语对喷，短句，每句 ≤15 字为主；允许网络梗与轻微粗口气质（"臭肥仔""嘴臭"），无脏字。
- 台词必须挂微表情与动作（skill 既有规则），本产品尤其常用：翻白眼、嘴角抽搐、假笑、捂脸爆哭。
- 旁白仅在结尾口播出现，中段全部靠对白推进。

## 7. 生产参数

- 画幅：**两种模式，开局确认**（v0.4 修正：以使用说明 v1.0 为准）——① 横竖都要：**先出横版（16:9），横版定稿后再改竖版（9:16）**，横改竖贴定稿作参考不重写；② 只要竖版：**直接出竖版（9:16）**。对标视频历史规格为 1080x1920。
- 草稿：图稿（BGM、配音、创意 UI）；成片规格以订单要求为准。
- 模型初判：3D 卡通向，SD2.5 可用；待抽卡实测后在此登记推荐模型。

## 8. 对标视频索引

- 表内参考链接均为 mp4 文件名（如 `GOTCN3D17326_前贴_塔防_万箭归宗_铁水烧箭_小程序_1080x1920.mp4`、`媚上讨好+逐层分包.mp4`），原始文件由丁总/团队持有；需要分析时把文件给 AI 抽帧。
