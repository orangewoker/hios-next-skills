# 反套路与精炼词库

## 可见性测试

每个主要短语都应能被镜头看见、被测光表度量、在混音中被听到，或作为运动被观察到。通不过就替换为制作语言。

## 六大套路类别

1. **空洞评价词**：cinematic、epic、stunning、电影感 → 换成具体镜头/光/运动。
2. **借来的图像模型词**：8K、masterpiece、trending on ArtStation → 删除。
3. **标签杂烩**：逗号关键词堆 → 改写成拍摄简报式散文。
4. **否定式套路**：no blur、no artifacts → 改为描述"实际存在什么"。
5. **形容词堆叠**：三个同义词 → 挑出最要紧的一个。
6. **感觉后缀词**：氛围感、雰囲気、vibey → 点明产生这种感觉的物理原因。

## 常见替换表

| 填充词 | 有力替换 |
|---|---|
| cinematic | locked close-up, warm practical key, cool rim light |
| epic | wide low-angle shot, tiny figure against storm wall |
| beautiful | pearl highlights on wet ceramic, soft window bounce |
| dynamic | fast lateral track ending on the hero label |
| professional | clean commercial tabletop, controlled reflection, no clutter |
| 电影感 | 固定机位中近景，暖色主光，冷色轮廓光 |
| 大气 | 雾气在光柱中缓缓流动，尘埃被侧光勾勒 |
| 梦幻 | 柔焦高光，浅景深，缓慢推近 |
| 震撼 | 低角度大远景，主体向镜头走来逐渐变大 |

## 重写流程

1. 给所有最高程度形容词与模糊风格标签画线。
2. 按套路类别分类。
3. 判断每个词应变成镜头、光、运动、材质、声音还是约束。
4. 删减重复。
5. 控制字符预算，保留参考标签。

## 不要过度纠正

`Noir hallway with hard venetian-blind shadows` 是有用的类型语言；
`dramatic cinematic noir vibes` 则不是。
保留能传达媒介、年代、色调或焦段行为的术语。
