# 附MD04 | 谍战特工·变量与结局扩展

**所属主SKILL：** 谍战特工 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“谍战特工 | 上架Steam的互动影游”的专属变量系统与结局体系扩展库。

解决互动影游“变量设定空洞、结局无分支、选项假大空、数值不驱动剧情”的痛点。通过严格的变量字典、严密的结局触发条件与路径推演，确保玩家的每一次选择都能真实改变特工与阵营的因果命运。

## #需要什么输入

**最少提供：**

- 核心变量清单（如身份暴露度、情报值、信任度、任务进度、敌方警觉度等）
- 路线设计（地下党线、军统线、双面线、隐藏线）
- 特工与阵营NPC的信任设定

**可选提供：**

- 结局数量与类型偏好
- 目标平台（Steam/视频平台/小程序）
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。变量与结局设计环节重点参考【顶级游戏开发大师】的节点设计与变量系统规则，确保结局路径逻辑闭环。

### 二、变量字典（强制锁定）

核心变量

1. 身份暴露度：risk，0-100，默认0；≥70身份存疑；≥90身份暴露。
2. 情报值：counter，0-100，默认0；≥60情报充足；&lt;30情报不足。
3. 信任度：relationship，0-100，默认0；≥70完全信任；&lt;30信任危机。
4. 任务进度：counter，0-100，默认0；≥80任务完成；&lt;20任务失败。
5. 敌方警觉度：counter，0-100，默认0；≥80敌方警觉；≥90全面搜捕。

路线专属变量

1. 地下党线专属忠诚：relationship，0；≥50地下党线锁定；&lt;20地下党线崩塌。
2. 军统线专属军令：relationship，0；≥50军统线锁定；&lt;10军统线失效。
3. 双面线专属双面：relationship，0；≥50双面线锁定；&lt;10双面线失败。
4. 全员信任：relationship，0；≥80解锁真结局条件。

道具与旗标变量

1. 密电码本：item，false；true且情报值≥60可触发地下党线结局。
2. 假证件：item，false；true且身份暴露度&lt;30可触发军统线结局。
3. 双面档案：item，false；true且全员信任≥20可触发隐藏真结局。

### 三、结局体系（共15个）

正结局（5个）

1. E01·红旗飘扬：地下党线，情报值≥60，任务进度≥80。
2. E02·军统之刃：军统线，军令≥50，任务进度≥80。
3. E03·双面之王：双面线，双面≥50，身份暴露度&lt;50。
4. E04·家国天下：隐藏真结局，解锁双面档案+全员信任≥20+任务进度≥80。
5. E05·功成身退：任意路线，任务进度30-59，身份暴露度&lt;30。

坏结局（10个）

 1. D01·身份暴露：身份暴露度≥90。
 2. D02·信任崩塌：信任度&lt;30。
 3. D03·全面搜捕：敌方警觉度≥90。
 4. D04·地下党覆灭：地下党线，忠诚&lt;20。
 5. D05·军统除名：军统线，军令&lt;10。
 6. D06·双面败露：双面线，双面&lt;10。
 7. D07·任务失败：任务进度&lt;20。
 8. D08·全员反目：全员信任&lt;10且任务进度≥60。
 9. D09·因果清算：所有变量失控。
10. D10·觉醒前陨落：N02选项B+身份暴露度≥70。

### 四、结局触发条件表（快速查表）

1. E01：N02A→N04A→N06A-2→N08B；情报值≥60·任务进度≥80·忠诚≥30。
2. E02：N02A→N04B→N06B-1→N08B；军令≥50·任务进度≥80·信任度≥30。
3. E03：N02B→N04C→N06C-2→N07C-1；双面≥50·身份暴露度&lt;50·任务进度≥60。
4. E04：N02B→N04C→N06C-2→N07C-2→N08C；双面档案=true·全员信任≥20·任务进度≥80。
5. E05：N02A→N04B→N06B-3→N08B；任务进度30-59·身份暴露度&lt;30。
6. D01：任意路线累积身份暴露度≥90。
7. D06：N04A→N06A-1→N08A；双面&lt;10。

### 五、结局路径示例（以E04家国天下为例）

N02B 质问命运（身份暴露度+10）\
→ N04C 参悟·双面档案（情报值+20·全员信任+20）\
→ N06C-2 反问堵住敌特（身份暴露度-20）\
→ N07C-2 抬头直视敌特微笑（获得双面档案）\
→ N08C 全员豪赌（情报值+30·全员信任+30）\
→ E04 家国天下（全员信任≥20·双面档案=true）

### 六、变量锚定规则（核心铁律）

1. 每个节点提示词末尾必须标注：节点ID+变量变化。
2. 变量名全部用英文（exposure/intel/trust/mission/alert/route），禁止中文变量名。
3. 变量一旦定义，中途不能改名。
4. 所有变量必须有定义、有使用、有结局影响。
5. 禁止无意义变量（定义了但从不影响结局）。
