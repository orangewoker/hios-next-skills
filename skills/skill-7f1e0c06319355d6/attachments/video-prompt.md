# 视频提示词规范

> 本文件对应「故事板 Skill」的视频侧规范，供阶段二步骤6 生成视频使用（另在步骤2 判视角、步骤6 逐项落地时对照）。所有视频生成统一使用 **Seedance 2.0 Fast（2.0 mini）/ 480p / 4:3**。**本文件含全部格式规则、边界、负面词与正确示例 prompt 本体**（示例就在本文件内）。
> ****执行主体（流程与禁令）在主文件**：阶段二全步骤以 `SKILL.md` 为准；全局禁止规则（28 条，见 `SKILL.md`「全局禁止规则」章节）以 `SKILL.md` 为准；景别与运镜取值口径见 `image-prompt.md` 的「统一景别档位表与统一运镜词表」。

---

## 为什么要这么写（务必理解）

视频提示词**不是把故事板复述一遍**。故事板已经把整条剧情预演过一遍了；如果视频 prompt 又逐格写「参考故事板 01 格 / 02 格……」，等于把视频模型拽去**复刻那张低画质多格缩略图**——它会去猜缩略图的构图与像素，而不是去演剧情，剧情反而成了格号的附庸，动态与时间性信息被挤掉，最后拿到一条**僵硬复刻缩略图、不会动也不会呼吸**的片子。

正确的关系是：

1. **故事板是全片视觉底本**——场景、环境、道具、构图、景别一次性交代清楚，「全程以该图为准」**说一次、全程有效**；
2. **视频分镜时间轴是剧情演出脚本**——按剧情推进与总时长写，**不逐格回指**、不要求覆盖每一格；
3. **应有选择取用**——可以只取用其中若干格，也可以把相邻两格的画面演成一镜；唯一边界是不得超出故事板已预演的画面范围另编新场景、新环境、新道具。

理解了这一层，下面所有格式规则才不会被误用成「复刻缩略图的清单」。

---

## 前提：本 Skill 无场景锚点，故事板是场景与道具的唯一视觉底本

本 Skill 阶段一**不生成任何场景锚点图**；场景、道具、光线、色彩、构图、摄影机、声音七个维度已由阶段二的故事板分镜格全部承载。故事板身兼两职：**镜头构图参考** ＋ **场景/道具/环境的唯一视觉底本**。本 Skill 只有两类参考图：**故事板图**与**角色板（人物）图**——没有场景参考图，也没有道具参考图。

四条硬要求：

1. 故事板是视觉底本，参考关系在开头说一次、全程有效；视频按剧情**有选择取用**其中的格，**不逐格回指、不要求覆盖每格**；
2. 静态外观**以该底本为准**，不得自行更改、不得新增图中没有的环境元素或道具；
3. 故事板是**低画质多格缩略图**、单格细节有限：静态图给不了的「过程」必须靠动态信息补（见「静态禁写／动态必写」）；
4. **景别与运镜不在这里重新设计**：取值与 `image-prompt.md` 两表、`SKILL.md` 阶段二步骤3 的分镜设计表**同词同值**（可有选择取用其中的格）。

---

## 分镜对应与条目口径（两侧一致性的落点）

- **唯一事实源（只管术语）**：该条视频的分镜设计表（镜号 + 景别 + 运镜 + 核心动作）由 agent 在 `SKILL.md` 阶段二步骤3 定好，决定**故事板画几格、每格照填哪个景别与运镜**，并作为两侧景别与运镜的**统一口径**——图片侧写的与视频侧写的必须同词同值，不得一边写中近景、一边写特写。
- **有选择取用**：视频分镜时间轴的条数由该条剧情与时长自行决定，**不要求等于故事板格数**；可以只取用其中若干格，也可以把相邻两格的画面演成一镜。分镜时间轴按剧情推进写，不要求逐格对齐、不要求覆盖每一格。
- **唯一边界**：不得超出故事板已预演的画面范围另编新场景、新环境、新道具。
- **取值口径**：景别与运镜一律取自 `image-prompt.md` 两张表（运动方向：`推 / 拉 / 摇 / 移 / 跟 / 升 / 降`，稳定性：`手持拍摄`），**两侧同词同值**；固定机位是正当选择（需要画面纹丝不动时可写 `static shot`），本厂默认手持呼吸感；**不得把「手持拍摄」写成「跟拍」**。
- **两者不是同一份清单的两个副本**：分镜设计表是**故事板的镜头清单**；视频分镜时间轴是**剧情演出脚本**（按剧情与时长写，可有选择取用其中的格子）。

## 交付格式约定

- **整条视频 prompt 必须用代码块包裹输出**，便于整段复制、逐字复用。
- **参考声明块置最前、逐张附识别要点、按出场重要性排序**（故事板居首、其后逐个角色板）。
- **负面框仍在代码块内、与正文物理分离**，按分组照写，**不得混入正文句子里**；二者**不合并、不互相混写**。
- 代码块内顺序照「视频提示词固定格式」执行，不得调换。

## 视频提示词固定格式

严格按此顺序，不得增删结构：

**1. 开头：参考声明块（说一次，全程有效）**

```
参考故事板构图 {{故事板key}}：本片的场景、环境、道具、构图与景别的视觉底本，全程以该图为准，不得自行更改、不得新增图中没有的环境元素或道具。
参考角色板 {{角色key}}：{{角色名}} 的长相、发型、服装以此为准。
```

- **故事板居首**；此后**每个出场角色各列一张角色板**，按出场重要性排序。
- 🔴 **角色板只写类别名**：格式即上面第二行，**不附特征关键词、不加括号补充**；角色外观一律由**角色板图本身**承载。
- **底本定位**：故事板提供画面素材，视频按剧情取用；**不必逐格回指**，但不得脱离该底本另编画面。
- 正文里**每出现一个角色，就把对应角色板 node_key 跟在该角色名字后一次**（就地回指）。
- **POV 条另有适配规则**，见下面「POV 条的角色板与分镜适配」。

🔴 **职责隔离声明（必写，防脸污染/防分屏，学 Seedance 多图参考机制）**：Seedance 多图参考是把所有参考图**融合成一个向量**，不会自动区分「谁是人物、谁是场景」——同时传角色板（三视图+特写）和故事板（多格缩略图）时，故事板里的**小人缩略图会把脸稀释进角色**，导致脸漂；多格网格也可能被当成「一帧」复现出分屏/网格排版。因此参考声明块末尾必须补一段**职责隔离**，把两类图的用途钉死：

```
仅以 {{角色key}} 作为人物五官与身份的唯一参考，人物的面部、发型、服装只认这一张，不得从其他图提取。{{故事板key}} 只用于景别、构图、运镜与动作调度；按其中各分镜格的顺序依次取景、输出为连续单镜头，禁止保留网格排版、边框、分屏或格号，禁止从故事板缩略图中提取任何人物五官、发型或服装。
```

- 这条**不改变「角色板只写类别名」「故事板是视觉底本」两条既有规则**，只是在二者之间补一道「用途隔离」；角色板仍只写类别名，故事板仍作底本，但**脸的来源被显式锁死到角色板**。
- 对应负面词追加：`不新增人物、不换脸、五官脸型发型与参考图一致、no grid layout、no panel borders、no split screen`（并入「画面与生成质量类」负面框）。

🔴 **POV 条职责隔离声明分两组写（防"主角板被塞进取面部名单"）**：上面通用版职责隔离声明默认**所有角色板都锁「五官、面部」**，这是第三视角的写法。POV 条里，**主角（镜头=他的眼睛）全程不露脸**，主角的角色板只锁「服装、随身物件、手部可见部分」，**绝不写"取面部/五官"**——若把主角板混进通用版的"仅以 {{角色key}} 作为人物五官与身份的唯一参考"，就会出现「开头说主角只取服装手、后面又要取面部」的自相矛盾。因此 POV 条必须把职责隔离拆成**两组**：

```
仅以 {{出镜角色key 列表}} 作为出镜人物五官与身份的唯一参考，这些人物的面部、发型、服装只认这几张，不得从其他图提取。{{主角key}} 仅用于主角的服装、随身物件与手部可见部分，不得从其中提取任何面部或五官（POV 主体不露脸）。{{故事板key}} 只用于景别、构图、运镜与动作调度；按其中各分镜格的顺序依次取景、输出为连续单镜头，禁止保留网格排版、边框、分屏或格号，禁止从故事板缩略图中提取任何人物五官、发型或服装。
```

- **分组判据（一句话）**：**镜头是谁的眼睛，谁就不进"取面部"名单**——POV 主体只锁服装+手；画面里真实出镜的其他人，才锁长相发型服装。判据问一句：**这个人会不会在画面里露脸？露脸→锁脸；不露脸（POV 主体）→只锁服装+手。**

**2. 整体场景与氛围（固定段，必写）**

> 位置：**参考声明块之后、正文（核心动作概括）之前**；原第 2～5 段顺延为 3～6 段。本段只写该条视频的场景与氛围。

```
整体场景与氛围：环境（定位性一句简述）／光源方向／大气介质／视角设定
```

项写什么① 环境该条所处空间的**定位性一句简述**（在哪、什么性质的空间），**不展开布局与材质**② 光源方向本条主光**来自哪里、什么性质**（如「天光从窗纸漫射为主光」「烛火为近距暖源」）③ 大气介质**风、尘、水汽、烟气、热气**等可感的空气成分④ 视角设定沿用 `SKILL.md` 阶段二步骤2 为该条判定的视角（POV 第一视角 / 第三视角电影分镜），并写明**整条不混用**

🔴 **光源方向必须「锁定」而非「只描述」（防光向漂移）**：同场多镜光向乱跳（窗光左/右漂、暖/冷跳变）是「AI 感」主因，根因是只写了「暖光」「柔光」这类模糊词、没写死空间位置。因此第②项在描述光源之外，**必须追加一句「锁定光向句」**，把光的位置与色温钉死，一场戏写一条、逐字复用到该场的每一个镜头：

```
主光自画面左侧 45° 打来，柔和漫射，约 3200K 暖色，右侧自然落入阴影；整条镜头光源位置与方向保持不变。
```

- **图生视频特则（务必遵守）**：故事板起始帧**已经决定光向与对比**，视频提示词**不得重写一套不同的光**（否则模型在两者间漂移）；图生视频只写「光随时间的改变」（烛火摇曳、云过日蚀、人物走入光里），不重写光的方向与色温。
- **写光顺序固定**：光源（具名有动机）→ 方向 → 软硬 → 色温；同一场戏每个镜头用**完全相同的措辞**，不得 shot1 写「暖灯」、shot4 写「琥珀光」这种换说法（换说法＝漂移源头）。
- 对应负面词追加：`no flat frontal light、no multiple conflicting shadows、no random light direction change、no exposure pulsing`（并入「质感与光类」负面框）。

🔴 **三条边界（写死不得越界）**：

1. **不含质感正向描述段**——不得写入 35mm／胶片质感／柔光滤镜等正向质感语句；质感与光在本 Skill 视频侧**只以独立负面框的词条约束**。
2. **配色不另写**——色彩仍沿用正文里的「画面风格（照抄阶段一原文，所有视频同一句，不得改写）」一项，位置与规则不变，本段**不重复色彩描述**。
3. **环境一项只此一句、不得展开**。判据：**写「在哪、什么性质」可以，写「墙是什么材质、家具怎么摆」不行**。

**3. 正文**

按以下顺序写：核心动作一句话概括 → 台词逐条（含内心独白／旁白） → 分镜时间轴（按剧情推进写） → 运镜描述 → 环境音设计 → 画面风格（照抄阶段一提炼的原文，所有视频用同一句，不得改写）。

> 🔴 **视频侧画面风格 = 整句照抄、不拆短锚词**：`image-prompt.md` 里的「短锚词 / 完整原文」两分法**只用于故事板图的顶部通栏**（那里画面风格是被模型画成图内文字、长句会乱码）；**视频侧没有通栏，画面风格是纯渲染指令，必须整句照抄阶段一原文、一字不改、不得拆成短锚词**。两者各管各的，不得把图片侧的短锚词写法搬到视频侧。

- **台词格式（固定）**：`人物说：{台词}`。台词用花括号包裹，**逐字保留原文、不翻译、不改写、不节选**。
- **台词是音频与口型，与故事板禁字无关**：故事板图上严禁任何画面文字（台词、字幕、对话气泡）；视频提示词里的 `人物说：{台词}` 承载的是**音频与口型**，必须写。
- 🔴 **内心独白与旁白**：
  - 剧本中标注为「（内心独白）」「（心想）」「（旁白）」的内容，**不得写成** `人物说：{}`——`人物说：{}` 会驱动口型与发声，把内心戏演成开口说话，与剧情矛盾。
  - 正确写法：`内心独白（画外音，不开口）：{内容}`，并在该镜注明**人物嘴唇不动、无口型**；同样受**语言锁**约束。
  - 该处理**不影响前置过滤**：内心独白**计入台词字数**（它是需要时长的语音内容），参与 75 字切分与 `duration_sec` 计算。
- **道具点名制**：本 Skill 不设道具图，道具**在剧情中出现时点名**，规则为**名字 ＋ 动作过程 ＋ 状态，不描述外观、不带格号**：

  ```
  金钗被她从发间拔下、放入他掌心
  ```
  - **该镜没有道具就直接不提**，无须任何「本镜无道具」之类声明。
- **常驻兜底声明**：场景、道具、人物外观一律以故事板底本与角色板为准，不得自行更换、不得新增。
- 🔴 **历史题材形制锁定（涉古装/历史人物时必写，防朝代穿越与影楼风）**：古装图生视频容易退化成泛化「影楼汉服」或朝代混搭（明官服配清花翎）。纯写「汉服」「古风」几乎必漂。因此**凡历史题材条目，正文人物/服装描述必须写「朝代名 ＋ 具体形制术语 ＋ 禁混搭」**：

  ```
  [朝代]制式服装，形制严格：[具体形制，如唐代圆领襕袍＋幞头／宋代展脚幞头＋绯色公服／明代乌纱帽＋织金补子赐服／清代石青朝服＋朝珠凉帽花翎]。禁止混搭其他朝代服饰，禁止时代错置配饰，禁止泛化影楼风汉服。
  ```
  - **朝代→形制锚点词表（可直接复用，社区成品提示词已验证）**：汉＝进贤冠＋玄色汉制官服；唐＝圆领襕袍＋幞头／高腰襦裙＋披帛；宋＝展脚幞头＋绯色公服；明＝乌纱帽＋织金补子赐服；清＝石青朝服＋朝珠＋凉帽花翎。
  - **加材质结构细节**：丝质反光／纱透／刺绣层次，避开「廉价影楼汉服」。
  - 对应负面词追加：`no anachronistic elements、no mixed-dynasty costume、no generic hanfu`（并入「画面与生成质量类」负面框）。
- 🔴 **人物实体性常驻声明（与语言锁同级，每条必写）**：

  ```
  人物全程实体清晰、边缘扎实，动作自然生活化，不摆拍、不对镜、不表演式，无穿模、无肢体融解、无半透明、无多余肢体
  ```
- **环境音设计（必写）**：点名本片可闻的环境声（如烛火噼啪、风声、门外人声、脚步、水声），并声明「**只保留丰富真实的环境音与对白，无背景音乐无配乐**」。
- **皮肤去脏常驻声明（必写，仅视频阶段）**：

  ```
  人物皮肤干净通透、暗部提亮不脏、肤色均匀无杂色偏色、自然肤质不油腻不磨皮
  ```

  详见「皮肤去脏（仅视频阶段）」一节。

**4. 结尾：语言锁（常驻声明）**

```
本片人物对白一律[阶段一确定的对白语言]，即便模型自主补话也只用此语言，禁止任何其他语种的台词、字幕与口型。
```

**无台词镜头同样必须写**，防止模型自主加话时蹦错语种。🔴 **语言取值来自** `SKILL.md` **阶段一步骤0 入口问询采集并写入 memory 的结果，全程复用。**

**5. 结尾：独立负面框**（与正文物理分离，见下节；**仅视频适用**，不得与故事板图的负面框混用）

**6. 结尾：不加音乐**由调用参数 `need_bgm: false` 控制（字段落地见 `SKILL.md`「参数字段落地口径」：`sound: on` ＋ `need_bgm: false`；**不得把 sound 设为 off**）

## 镜间硬切与分镜时间轴写法（显式断开镜间）

- **每条分镜行必须以「硬切 分镜N（X-Y秒）：」起头**（N 为该条内分镜序号，X-Y 为秒数区间），**显式断开镜间**；**首条分镜可不带「硬切」字样**，写作「分镜1（X-Y秒）：」。
- **每镜内容＝景别 ＋ @角色具体动作 ＋ 运镜 ＋ 环境细节**（四项齐备）：景别取 `image-prompt.md` 统一景别档位表、运镜取统一运镜词表，与分镜设计表**同词同值**；角色以 @角色名 指称；环境细节写本镜可感的环境与动态。
- 分镜行照「谁动 + 镜头跟 + 什么时候切 + 别静止」口径写，**不逐格回指故事板格号**。
- **镜间一律硬切、禁止溶解叠化**（对应负面框「转场类」词条）；若剧情本就要同一景别静静停留，则**不切、一镜到底**。
- 🔴 **秒数区间的分配交给 agent 自行判断**：每镜标注 X-Y 秒区间即可；**具体如何分配、一镜到底时如何落行、未被视频取用的格子如何处理，均由 agent 按剧情与总时长自行判断，不作硬性规定**（不写「秒数区间必须连续覆盖 0 至总时长」这类硬约束）。

## 剪辑节奏

- **默认实时速度**，**镜头宁长勿短**：给动作与沉默留出完整时间，让时间自然流逝。
- **每镜承载一段完整的时间，而非一个动作节拍**——一个动作、一段对话、一次沉默完整发生，不打断、不催促。
- **禁快剪、禁频繁切换**（跳切已在负面框中，同样保持禁用）。
- **每镜标注秒数区间（X-Y秒）**；如何分配由 agent 按剧情与总时长自行判断，本部分**不作硬性规定**。

> 🔴 **「宁长勿短」的边界（防止拖长）**：「镜头宁长勿短」指的是**在单条视频的总时长内部，镜与镜之间不要切得太碎、给每个动作留够时间**；它**不等于**把单条视频无限拖长。单条视频总时长**仍唯一由「该条台词总字数 ÷ 5 = duration_sec」决定**（`SKILL.md` 阶段二步骤1），**常见落在 4–10 秒、最多 15 秒**。「宁长勿短」只能在**这一个已定的总时长里**做镜数取舍（少切镜、单镜长），**不得**反过来为了「长镜头」而增删台词、拉长 duration_sec。

> 🔴 **边界（防止误改时长）**：视频总时长**仍唯一由「该条台词总字数 ÷ 5 = duration_sec」计算得出**（`SKILL.md` 阶段二步骤1）；每镜秒数只是在该总时长**内部做分配**，**不得反过来用节奏或分镜秒数改动 duration_sec**，**不得为凑长镜而增删台词**；`duration_sec` 必传的规则不变。

## 皮肤去脏（仅视频阶段）

> **适用范围**：**仅视频生成阶段**。静态图（三视图、故事板图）**不做去脏提亮、真实肤色照旧**。

视频 prompt 须做三件事，防止真实肤质在动态中被劣化成脏：

1. **提亮**——皮肤（尤其暗部）较静态基准**轻微提亮约一档**、暗部干净通透；这是「**皮肤局部去脏性提亮**」，**不等于整体画面往高调推**，全片明度仍守阶段一画面风格口径（中等对比、暗部干净不死黑不压暗）。
2. **净化肤色**——肤色**均匀干净**、无杂色斑驳、无灰绿/蜡黄/发脏偏色、**血色自然通透**。
3. **收敛过度质感**——保留自然肤质但**适度收敛毛孔油光的过度锐化**，不粗糙不油腻；同时**仍禁磨皮塑料假脸**（去脏 ≠ 磨皮）。

**prompt 常驻声明句（必写）**：

```
人物皮肤干净通透、暗部提亮不脏、肤色均匀无杂色偏色、自然肤质不油腻不磨皮
```

对应负面词见「皮肤类」。

## 静态禁写／动态必写（判据）

> **图里一眼能看见的不写；图里看不出动静的才写。**

- **禁写（静态外观，由故事板与角色板承载）**：墙面家具的材质颜色、服装形制花纹、道具的形状颜色纹样、机位与构图描述、场景环境的空间介绍。
- **必写（动态与时间性信息，静态图承载不了）**：风、火苗、光影起伏、声响的来去、人物的动作过程、道具在人与人之间的交接、时间流逝造成的状态变化。

**理由（务必理解）**：故事板是**单帧缩略图**，它只能给出**静态外观**——墙是什么材质、衣服什么花纹、道具什么颜色，图上都摆着，再写一遍是冗余；但**它给不了过程**：风怎么吹、火苗怎么晃、动作怎么走完、道具怎么从一个人手里到另一个人手里、时间流过之后状态怎么变。这些「过程」若不在 prompt 里写出来，模型既不会从静态图里读到，也不会自己知道该演成什么样——**结果只能是自行编造动静，或者干脆让画面死掉**。所以动态信息**不是可选修饰，而是必需项**。

> **例外与限度**：上面「禁写」里的「场景环境的空间介绍」指**展开式的空间布局/材质介绍**；固定格式第 2 段的「环境」一项属于**受控例外**——只允许写**定位性一句简述**（在哪、什么性质的空间），**只此一句、不得展开**。**除这一处例外外，本 Skill 不为静态禁写开任何其它例外**（角色板声明句同样不写特征）。
> ****不往视频 prompt 正文加质感正向描述段**：质感口径在视频侧**只以负面词形式出现**（见「质感与光类」），**不在正文新增质感正向描述段落**。

## POV 条的角色板与分镜适配（当该条故事板采用 POV 第一视角时）

- 主角角色板的职责**降级**为锁定**服装、随身物件与手部可见部分**，**不要求面部可见**；声明块里不得写「长相以此为准」这类要求主角露脸的措辞。
- 正文里主角**不以面部出镜**，故不得写任何要求主角露脸（完整面部、全身像）的描述。
- 其他非 POV 主体的角色板仍按原规则锁长相、发型、服装（声明句同样**只写类别名**）。
- 该条景别取值**只用景别档位表中的 POV 相关档**（如「主观视角手部特写」），**不与第三视角各档混用**（沿用「一张故事板不混用两种视角」）。

🔴 **POV 镜头语言精髓（六维度 + 三拍语法 + 动作作用于镜头，必写，是 POV 与非 POV 的分水岭）**：POV 的镜头**是一个活人，不是一台机器**。六维度缺一不可——

1. **有身体**：手、前臂、呼吸雾、肩膀要入镜；画面边缘没有「身体」，就是广角空镜，不是 POV。
2. **有头**：镜头会扭头、前倾、后仰，运动**不完美**（转身前一顿、头比眼晚到一点）；太平滑＝无人机不是人。
3. **有眼高**：成人眼高 1.5–1.7 米，不是三脚架高度。
4. **有注意力**：镜头朝「人接下来会看的东西」移动，不是均匀扫过全场。
5. **会被挡**：门框、头发、起雾眼镜、挡太阳的手——真实视觉大部分时间被部分挡住。
6. **有冲击**：动作戏（巴掌、拳头、推搡、泼水）要「糊满+震动」的冲击，不是「看清」的清晰。

🔴 **三拍语法（元规则）**：看（谁的眼看）→ 见（看到什么）→ 反应（怎么反应）。第一人称镜头本身不自动成立，必须交代「这是谁的眼睛」。

🔴 **动作作用于镜头（POV 最易写错的一处）**：所有「作用于主角」的动作，必须转成「作用于镜头」的物理反馈，**不得写成第三视角的旁观描述**——

- 被打巴掌 → 巴掌从画面外朝镜头高速呼来、掌影盖满画面、镜头剧烈震动甚至黑一瞬（**不是**「展示手掌」）；
- 被推搡 → 镜头被推得后退/歪斜；
- 被人拽 → 镜头被拽着移动；
- 被泼水 → 水花扑向镜头、盖满画面。

> 判据一句话：**方向选了 POV，就每一镜都问「这一下是打在镜头上，还是打在旁边的人身上」——打在旁边的，就是写反了。**

🔴 **POV 视频提示词具体写法（五槽位骨架 + 命门约束，落地到视频 prompt 正文）**：上面六维度＋三拍＋动作作用于镜头是**认知口径**，落到视频 prompt 时按下面五槽位骨架写，命门约束逐字照抄——

**五槽位骨架（顺序固定）**：

1. **镜头声明（第一句）**：`the camera is the eyes of {角色}` —— 直接声明这是谁的眼睛，不给模型猜的空间。
2. **身体动作（镜头是谁的身体）**：写镜头的身体在做什么——手在画面里抓、扶、挡，前臂/衣领入镜，呼吸起伏、脚步、扭头。**身体动作是 POV 成立的根，缺了就是广角空镜。**
3. **环境光线**：写本镜可感的环境与光（与第三视角同规则，锁定光向句照抄）。
4. **镜头行为（动作作用于镜头）**：被打/被推/被拽/被泼等动作，转成镜头的物理反馈（巴掌糊满画面、镜头震动、画面被推歪），**不写旁观描述**。
5. **音频分层（锚定动作）**：声音跟着动作走（巴掌的脆响、脚步、呼吸声），**呼吸声只在需要强调紧张感时用一次，不得每镜都加呼吸声**（否则变成机械的"呼吸音轨"）。

**命门约束（逐字照抄，缺一条 POV 就塌）**：

```
no cuts, no zoom, natural head movement, the camera IS his eyes, his hands always visible in frame, the camera itself is never visible
```

- `no cuts`：POV 是一镜到底的"人眼看出去"，不许切（正文依据：`one continuous take` / `the camera does not cut anywhere else`，awesome-seedance POV 模板）。
- `no zoom`：人眼不能变焦推拉，POV 用**固定广角焦段**（正文依据：`焦段用广一点（24mm、18mm），长焦会把这个效果压平`，ZOOOP 主观镜头词条——对应概念是「固定焦段、不推拉」，正向写法可作 `fixed wide lens, no push or zoom`）。
- `natural head movement`：镜头是头，扭头、前倾、微晃是自然的，不是滑轨（正文近义：`slight natural head-motion sway`，ZOOOP）。
- `his hands always visible in frame`：手始终入镜，是"有身体"的硬证据（正文依据：`own hands visible at the bottom of the frame`，ZOOOP）。
- `the camera itself is never visible`：镜头永远不被看见（防模型把摄影机画进画面；正文依据：`Add "the camera itself is never visible" and describe only what the hands do`，awesome-seedance 逐字）。

**手分左右（防第三只手）**：POV 里手是身体参照，**必须写清左右手各自在干嘛**（如「右手举杯、左手抵着桌沿」），否则模型容易长出第三只多余的手。左右手分工写进身体动作槽。

**音频分层铁律**：声音**锚定动作**写（这个动作有这个声），**呼吸声只出现一次**、用在剧情需要的那一镜，其余镜不重复加呼吸；否则"呼吸感"被模型理解成每镜都要有喘气声，变成噪音。

## 运镜写法规则

**📌 agent 理解用（不写进视频提示词）**：判断运镜风格时避免的方向——静止画面、静态推镜、机械滑轨、剧烈抖动、快速摇晃；**不得将这些词写入视频提示词正文**。⚠️ 注意区分：「静止画面/机械滑轨」指**无动机的死机位**，与本厂「需要纹丝不动时可写 `static shot` 固定机位」不冲突——固定机位是**有意选择**，死机位是**无意识摆拍**，一字之差、天壤之别。

**✍️ 实际写进视频提示词的部分**

**取值来源**：运镜一律取自 `image-prompt.md` **统一运镜词表**（运动方向：`推 / 拉 / 摇 / 移 / 跟 / 升 / 降`，稳定性：`手持拍摄`），与该条视频的分镜设计表**同词同值**；叙述句必须能回指该镜在表中的取值，**不得出现词表之外的第三种叫法**；固定机位是正当选择（需画面纹丝不动时可写 `static shot`），**不得把「手持拍摄」写成「跟拍」**（维度区分见 `image-prompt.md`「统一运镜词表」）。

运镜描述必须按以下最小公式写，**四项缺一不可**：

> **谁动 + 镜头跟 + 什么时候切 + 别静止**

- **谁动**：明确写出画面主体是谁在动（如「阿杰走动」「郑成功挥剑」）。
- **镜头跟（写机位，分两步，两步都要写）**：
  1. **稳定性（每镜必写）**：一律写「**手持拍摄**」——人手握持不稳、画面轻微晃动、有呼吸感、稳定但不机械。
  2. **运动方向（按该镜取值写）**：取 **「跟」** 时写镜头随主体移动；取 **「移 / 推 / 拉 / 摇」** 时写对应的机位运动方向与速度感（同样带上述手持轻微晃动）；若该镜取值就是 **「手持拍摄」**，则**只写稳定性、不写位移方向**，靠主体动作与环境动静保证不静止。
- **什么时候切**：写明在什么动作节点切换景别（如「炮弹穿过时切全景，伸手碰铠甲时切近景特写」）。
  - **切到哪一档也要写**：相邻镜头硬切时景别\*\*明显不同（至少隔一档）\*\*为有效落差（如 全景→中景、中景→中近景）；**同一景别**不算有效切换；**跨多档（如全景→特写）只要叙事有理由（突转、强调、震惊）就是正当剪接，不是暴跳**。
  - 若剧情本就是要同一景别静静停留，则**不切、用一镜到底**，而不是切到一个几乎相同的景别。
- **别静止**：任何镜头都不得画面死掉无呼吸——靠**手持拍摄的轻微晃动与呼吸感、主体动作、环境动静**共同实现。

## 正确示例

> 视频的负面框见上六组；故事板图负面框另在 `image-prompt.md` 示例节，**两者不得混用**。
>
> 本示例演示的是：**角色板声明句只写类别名**（不附特征关键词、不加括号补充）／**整体场景与氛围不含质感正向句、不重复配色**／**分镜行以「硬切 分镜N（X-Y秒）：」硬切秒行起头**／**运镜取自统一运镜词表、相邻镜头景别明显不同**／**画面风格照抄阶段一产出**（所有视频同一句、不得改写）／**常驻声明含人物实体性声明与皮肤去脏声明两句**／**实拍以该条分镜设计表为准、术语与故事板同词同值**。
>
> 另请记住本 Skill 的核心关系：**故事板是视觉底本，视频按剧情取用**——**静态外观不复述**（图上有的不写），**动态信息必须写**（图上看不出动静的才写）。

```
参考故事板构图 {{Image 1}}：本片的场景、环境、道具、构图与景别的视觉底本，全程以该图为准，不得自行更改、不得新增图中没有的环境元素或道具。
参考角色板 {{Image 2}}：郑成功的长相、发型、服装以此为准。
```
