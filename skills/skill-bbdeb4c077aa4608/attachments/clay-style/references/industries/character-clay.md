# 人物黏土化词库

## 面部转译

| 原始特征 | 黏土化改造 | prompt 句式 |
|---|---|---|
| 写实五官 | 大眼圆脸、小鼻子、短嘴 | "圆润大眼睛，小巧纽扣鼻子，短而厚的嘴巴" |
| 写实肤色 | 黏土肤色（略偏橙/粉的亚光肤） | "黏土肤色，略带暖橙调，亚光质感" |
| 写实头发 | 黏土条状或片状发型，保留捏制痕迹 | "头发呈黏土条状造型，表面有指纹压痕" |
| 服装褶皱 | 简化的黏土色块服装，无明显褶皱 | "服装为简化的黏土色块，圆润饱满无锐利褶皱" |

## 呆萌化改造

- 头身比夸张为 1:1 或 1:1.5（大头小身）
- 眼睛放大至占面部 1/3
- 四肢缩短变粗，手指简化为圆胖的黏土柱
- 表情选择：茫然/好奇/微笑/鼓腮

## 色彩方案

| 风格 | 色调 | 适用场景 |
|---|---|---|
| 原色高饱和 | 黏土原色肤色+饱和服装色 | 通用 |
| 暖色调 | 全身偏橙黄暖色 | 温馨场景 |
| 马卡龙 | 粉/蓝/绿低饱和柔和色 | 童趣可爱 |
| 单色系 | 全身单一饱和色+白色点缀 | 极简风格 |

## prompt 片段示例

```
黏土手工风格人物，大头小身比例（1:1.5），圆润饱满的脸庞，大而圆的眼睛占面部三分之一，小巧纽扣鼻子，短而厚的嘴巴微微上扬。黏土肤色略带暖橙调，亚光漫反射质感。头发呈黏土条状造型，表面可见指纹压痕。服装为简化色块，圆润无锐利褶皱。表面保留手工捏制的不规则纹理和轻微不对称。色彩高饱和。纯色柔光背景。呆萌可爱，让人想捏一把。
```

## 落 prompt 前自检

- [ ] 肤色是否黏土质感
- [ ] 头发是否捏制造型
- [ ] 是否有指纹/压痕描述
