### 0.3 分镜决策锁定表

**填入时机**：Phase 2 Step G（导演判断）开始时，一次性填入全段构图/运镜/布光/表演策略。
**模板文件**：`references/storyboard/core/分镜决策锁定表_模板.md`
**产物路径**：`分镜提示词/ep{NNN}/_decision_lock.md`（从模板复制，替换 `{填入}` 占位符）
**校验**：verify_phase.py 2 `SB_DECISION_LOCK`——检查文件存在且所有 `{填入}` 已被替换为实际值。

- A 表：全局视觉策略（视觉风格/调色/布光/运镜/表演/风格串/多样性/母题）
- B 表：逐段锁定（S1A-S1H，每段构图主策略/次策略/运镜/景别/角度/开场类型）
- 8 种构图策略：权力压迫/负空间吞噬/对角线驱动/前景切割/边缘出画/倾斜失衡/尺度反差/纵深分层
- 构图多样性阻断规则：全段同构图→阻断 / 同构图连续≥3段→阻断 / 居中对称≥50%→阻断
- 锁定表自检 8 条（见模板文件）

### 8.2 导演判断（v4.0：JSON 数据 + 模板渲染）

**执行顺序（阻断级）**：
1. 加载固化卡
2. **填入 `§0.3 分镜决策锁定表`**——全段构图/运镜/角度/景别一次性锁定
3. 过锁定表自检（8 条全部通过）
4. 再执行 `分镜_99_导演决策协议.md` 的 Layer 1→2→3 决策——但 D5.2（构图策略）的选取结果必须与 `§0.3 锁定表` B 表一致
5. **将全部判断结果填入结构化 JSON**（格式定义：`scripts/_storyboard_schema.py`。AI 不接触 Markdown 格式——只填 key-value 数据）
6. **运行渲染脚本**产出最终文件：`python scripts/render_storyboard.py <data.json> -p <项目目录> --output <分镜提示词/ep{NNN}/S{N}A_即梦视频.md>`

**v4.0 关键变更**：AI 不再直接写 Markdown。产出格式由 `templates/storyboard.md.j2` 唯一定义，渲染脚本执行。AI 只负责创意判断和数据填充——**输出物是 JSON 数据文件，不是 .md 文件**。格式错位由模板保证，不再依赖 AI 照搬。

> ⛔️ **阻断规则**：AI 在任何情况下都不允许直接创建或编辑 `S{N}A_即梦视频.md`。唯一产出路径是：AI 写 JSON → render_storyboard.py 渲染。若发现 AI 直接写了 .md 文件，该文件无效，需删除后重走 JSON→渲染流程。

**v3.6 关键变更**：D5.2 构图策略不再从分镜_22 独立选取——先填 §0.3 锁定表 B 表，D5.2 以锁定表为权威。P7 导演技法映射从分镜_02 §1.2 选取技法后，参数转写结果以锁定表对应的构图策略字段为准。

**v3.4 导演技法激活**：新增 P7「导演技法映射」——三段式强制步骤（叙事目的判定→分镜_02 §1.2 技法选取→§1.3 转写为可执行参数）。P7 阻断后 D1-D6 决策不得执行。P7→D 决策追踪在 E5 输出前必做。
