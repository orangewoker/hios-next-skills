# Seedance 2.0 模式选择

## 模式判定

| 用户请求 | 模式 | 说明 |
|---|---|---|
| 一句话出视频 | T2V | 从无到有构建整个镜头 |
| 给图让它动 | I2V | 保留图主体，只补运动/镜头/光/声音 |
| 给视频改风格或动作 | V2V | 迁移镜头/动作/节奏，不迁移身份 |
| 多参考综合控制 | R2V | 每个参考负责一个独立角色 |
| 给首帧和尾帧 | FLF2V | 只生成两帧之间的连续过渡 |
| 在已有片段上改局部 | Edit | 改变某一层时保持源片段 |
| 接着上一段继续 | Extend | 从已接受成片的实际末帧开始 |

## 各模式起草优先级

### T2V

需要：主体、动作、场景、镜头、光、风格、约束。把主体和主要动作放在最前面。

### I2V

从 `@Image1` 出发，只补充：
- 运动
- 时间/时机
- 镜头运动
- 灯光过渡
- 音频
- 保持项

必须写明："严格保持 @Image1 主体/产品/构图不变"。

### V2V

将 `@Video1` 映射到：源片段、镜头运动、动作节奏、走位或续接锚点。
不要让它迁移身份，除非已授权。

### R2V

列出每个参考的角色：
- `@Image1` 控制身份
- `@Image2` 控制氛围
- `@Video1` 控制镜头节奏
- `@Audio1` 控制音乐节奏

### FLF2V

`@Image1` 为首帧，`@Image2` 为尾帧。只描述连续过渡，不引入新元素。

### Edit

写明：`@Video1 is the source clip; change only ...`。

### Extend

从已接受成片的实际末帧开始，标记已完成节拍和预留未来节拍。
