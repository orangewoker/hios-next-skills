## 分镜的真正任务

把分镜当作电影的低成本思考原型：在拍摄、动画或生成前，验证叙事是否看得懂、情绪是否发生、空间是否成立、镜头能否相接、时长是否可控。

分镜不是：

- 把剧本文字逐句配图
- 把所有景别平均轮换
- 给每句台词一个镜头
- 证明画面画得漂亮
- 在没有调度和信息逻辑时提前锁死焦段

分镜要回答：**观众为什么在这一刻看这个，而不是别的？看完后，他对下一刻期待什么？**

## 从 sequence question 开始

先为段落写一个 sequence question（段落问题）：

`观众在这组镜头里持续等待哪个答案？`

再写四项：

- **进入知识**：观众进入段落时已经知道什么？
- **角色差值**：观众比角色多知道、少知道，还是同步知道？
- **关键答案**：哪一镜给出答案，答案是否被延迟或反转？
- **离开问题**：段落结束时，哪个新问题把观众带到下一段？

如果无法写出持续问题，这组镜头通常只是事件记录，没有观看动力。

## 三层拆分：段落、beat、镜头

### 段落层

写清段落从什么状态变到什么状态，以及整体形状：接近、逃离、误导、围困、发现、对抗、释放或循环。

### Beat 层

只在目标、策略、信息、风险、权力或情绪发生变化时换 beat。先把每个 minor beat 暂定为 1–2 个镜头，之后再扩展或压缩。

### 镜头层

每个镜头只承担一个主要注意力任务。多个信息必须同镜出现时，安排观看顺序：先看谁、由什么触发转移、最后停在哪里。

镜头数量不是精细度。导演能力更多体现在选择与省略：什么必须拍，什么应留在画外，什么应晚一点才让观众看见。

## 单镜决策卡

画每一格前回答：

1. **Why now**：为什么现在需要新镜头？
2. **New value**：它新增或改变什么信息、情绪、关系、空间或节奏？
3. **POV**：这一刻跟随谁的知识、感受或观察位置？
4. **Information release**：观众第一眼、第二眼、最后分别发现什么？
5. **Eye trace**：上一镜视线停在哪里？本镜重要信息应从哪里进入？
6. **Duration**：镜头需要等待动作、台词、反应、声音还是观众理解完成？
7. **Exit value**：镜头结束时形成什么未完成期待？
8. **Cut trigger**：由动作、视线、声音、信息、情绪还是构图触发切出？

可用一行记录：

`S03｜因她撒谎而切｜观众先看她的手，再看空戒指位｜保持丈夫 POV｜手缩回触发切出｜下一镜等待丈夫是否发现`

## Shot-to-shot 镜头关系

不要逐镜孤立设计。让相邻镜头形成明确语法：

| 关系 | 作用 | 例子 |
|---|---|---|
| 建立 → 细化 | 先给空间，再指出重要细节 | 房间全貌 → 门锁特写 |
| 问题 → 回答 | 视线或声音提出问题，下一镜回答 | 角色抬头 → 天花板渗水 |
| 问题 → 延迟 | 暂不回答，制造等待 | 角色看门外 → 先切另一人的反应 |
| 陈述 → 反应 | 让后果落在人身上 | 证据出现 → 沉默的手指停住 |
| 行动 → 结果 | 保持动作因果 | 扳下开关 → 整层楼熄灭 |
| 表面 → 反证 | 下一镜推翻上一镜理解 | “我一个人” → 镜中出现第二个人 |
| 匹配 → 转义 | 形状、动作或声音相似，意义变化 | 落下的硬币 → 落下的子弹壳 |
| 碰撞 → 新意义 | 两个镜头并置产生第三层含义 | 豪华宴席 ↔ 门外饥饿人群 |
| 累积 → 升级 | 重复结构但每次代价更高 | 三次敲门，距离越来越近 |
| 收紧 → 释放 | 压缩视野后突然给出空间后果 | 连续近景 → 空旷远景 |

为每个切点写出关系名称。写不出时，检查是否只是习惯性换景别。

## 信息释放与观众视线

### 设计 reveal order

同一事件的意义会因揭示顺序改变：

- 先人物、后威胁：让观众与角色同步发现，偏惊讶。
- 先威胁、后人物：让观众等待角色发现，偏悬念。
- 先反应、后原因：让观众产生问题，偏谜团。
- 只给结果、不示原因：制造省略、冲击或不可靠感。

把信息写成时间线：`已知 → 怀疑 → 证据 → 重释 → 后果`。不要在建立“怀疑”之前就把证据拍得过分显眼。

### 设计 eye trace

记录每镜观众视线的进入点、主要落点和退出点。利用位置、视线、运动、明暗和声音把眼睛交给下一镜。

视线接力不要求所有主体处于同一画面坐标。可以故意制造大幅跳跃来表达惊醒、迷失或搜索，但要知道代价是增加重新定位时间。

### 决定何时给反应

- **先给原因，后给反应**：强调角色如何承受事件。
- **先给反应，后给原因**：强调未知与想象。
- **不给反应**：可保持冷峻、隐藏判断或让观众自行反应。
- **延迟反应**：让角色压抑或让影响在后续才显现。

反应镜头必须增加解释、潜台词或节奏；不要把每句台词后都配一个点头。

## 切镜触发器

先写 cut trigger（切镜触发器），再决定景别：

- **动作触发**：动作启动、完成、失败或被打断。
- **视线触发**：角色看向某处，产生问题或方向。
- **信息触发**：一句话、物件或背景事件改变理解。
- **情绪触发**：表演跨过压抑、决定、崩溃或伪装的边界。
- **声音触发**：画外声、节拍、静默或声音桥改变注意力。
- **空间触发**：新人物进入、距离改变、出口被封。
- **图形触发**：形状、方向、色彩或运动形成匹配/冲突。
- **拒绝切镜**：故意多停留，让尴尬、无力、观察或后果发生。

不要只因为台词换说话人就切。问：此刻最重要的是说话者、听者、两人的距离，还是画外的信息？

## 覆盖式与设计式分镜

### Coverage（覆盖式）

先获取 master、双人、单人、插入和反应，为现场表演与后期留选择。适合资源允许、表演存在不确定性或剧情需要多种节奏版本时。

风险：过度覆盖会稀释视觉立场、增加拍摄成本，并把关键导演选择推迟到剪辑室。

### Designed coverage（设计式）

围绕特定镜头关系和切点拍摄最低充分材料。适合视觉结构明确、调度精确、时间受限或特效依赖强的段落。

风险：缺少表演余量、转场保险或空间补救时，剪辑容易被锁死。

### 选择原则

先标出不可替代的“作者镜头”，再补最低保险。不要为了保险拍摄与核心语法冲突的所有可能角度。

## 不同场景的分镜策略

### 对话与潜台词

把镜头分配给权力变化而非台词数量。优先考虑同框关系、遮挡、听者反应、视线回避、道具动作和第一次独立近景的时机。

### 悬念

先决定观众是否看见危险。维持清晰地理与时间压力；用遮挡和画外空间延迟答案，不用混乱替代悬念。

### 动作

先画目标、障碍、方向和结果，再画冲击细节。每组动作保持“发起—碰撞—结果—新问题”可读；速度来自因果压缩，不来自随机抖动。

### 喜剧

保护 setup、预期和 punchline 的时间关系。决定笑点来自同框同时发生、观众比角色早知道、反应延迟，还是剪切产生误解。笑点后不要太快切走，给观众读取和反应的空间。

### 情绪揭示

决定先看说话者、听者、物证还是空位。谨慎分配特写；最靠近的一镜应对应最不可逆的内在变化，而不是最大声的台词。

### 蒙太奇

给重复结构一个变化轴：时间、代价、熟练度、关系、色彩、空间或声音。每镜都要推进这个轴；只是“不同漂亮画面”不构成蒙太奇逻辑。

## 分镜格与运动标注

一个 panel（分镜格）画动作中信息最充分的 key moment，不必画每个中间姿势。只有构图、方向、动作阶段或信息状态明显改变时增加格子。

每格至少标：

- 镜号、预计时长、画幅
- 角色姿态、视线、屏幕位置
- 前中后景与关键遮挡
- 动作箭头；区分人物运动与摄影机运动
- 入画、出画和屏幕方向
- 镜头开始构图与结束构图
- 台词、画外声、关键音效或静默
- 与前后镜头的关系和 cut trigger

摄影机移动跨越多个构图时，用起幅/落幅两格或连续格表达；不要只画一个静帧再写“运镜很电影感”。

## 八轮检查与重排

### 1. Story pass

只看缩略图顺序，不读台词。能否理解人物目标、阻碍、变化和结果？

### 2. Information pass

逐格写观众新知道什么。检查信息是否重复、过早、太晚或依赖解释。

### 3. Geography pass

检查入口、出口、距离、视线、轴线和屏幕方向。需要迷失时，先确认迷失是设计结果。

### 4. Eye-trace pass

逐格标出视线进入/退出点。检查重要信息是否在观众尚未完成重新定位时消失。

### 5. Rhythm and sound pass

朗读并拍手计时，标出动作完成、停顿、声音桥、音乐句尾和拒绝切镜的位置。

### 6. Reverse pass

从最后一镜倒推：为了让这一镜成立，上一镜必须建立什么？逐镜反推，找出缺失的 setup 和多余的解释。

### 7. Compression pass

尝试删除 20% 镜头。若意义和节奏未损失，保持删除；若损失，明确被删镜头的不可替代功能。合并只负责建立、反应或转场但可在同镜完成的内容。

### 8. Silent pass

关掉对白和字幕，只看画面与假想声音。关系、动作因果、注意力和关键 turn 是否仍成立？silent pass 失败时先修调度与信息顺序，不急着补旁白。

## 常见失败

| 失败 | 原因 | 修正 |
|---|---|---|
| 每句台词一切 | 把说话者当唯一信息 | 比较说者、听者、同框关系和画外信息 |
| 景别平均轮换 | 没有距离进程 | 决定第一次靠近、最远离和拒绝近景的节点 |
| 分镜像插画集 | 缺少 shot-to-shot 语法 | 为每个切点标关系和触发器 |
| 反转突然但不惊喜 | 没有可回看验证的 setup | 提前放入低显著度双重信息 |
| 动作快但看不懂 | 缺少地理、方向和结果 | 恢复目标—阻碍—动作—结果链 |
| 所有信息都在画面中央 | 没有 eye trace 和探索 | 设计进入点、第二落点与视线接力 |
| 分镜越画越多 | 不敢省略或缺少主问题 | 做 reverse pass 与 compression pass |
| 运镜代替剪辑思考 | 没有明确触发与落幅 | 写出起因、路径、新构图和停止原因 |
| 只看画面不听声音 | 忽略声音对时间和切点的控制 | 单独做 rhythm and sound pass |

## 分镜完成标准

只有同时满足以下条件才算完成：

- 每组镜头都有 sequence question 和状态变化
- 每镜都有不可替代的主要功能
- 每个切点都有 cut trigger 与 shot-to-shot 关系
- information release 和 eye trace 可被逐格说明
- 空间、动作、视线、道具和声音可以连续
- 能通过 reverse pass、compression pass 与 silent pass
- 关键作者镜头与必要 coverage 已区分
- 预计时长相加成立，并给重要反应和余波留时间
