# 动作与物理表现

## 动作契约

明确写出：执行者/物体、动作、力度、时序、物理后果、连续性要求、终点。

## 动作类型示例

| 动作类型 | 有力短语 | 避免 |
|---|---|---|
| 微妙表演 | 角色 A 吸气，握紧杯子，然后放下，目光不离开 | 她感到紧张 |
| 产品材质 | 凝结水珠聚集、合并并沿瓶颈滑下 | 产品看起来很清爽 |
| 编舞 | 角色 B 低头躲过挥来的包，向左转身，停在防守姿势 | 快节奏打斗场景 |
| 物体物理 | 纸质收据在风扇气流中升起，翻转一次，正面朝上落下 | 纸张动态飞舞 |
| 环境运动 | 雨丝斜向划过逆光，涟漪从脚步处扩散 | 暴风雨氛围 |

## 物理前置模式

说明质量、力、材质，然后命名镜头能看到的结果：

```text
沉重的橡木门甩上关上，烛火朝它弯去
```

优于：

```text
门戏剧性地关上
```

重量体现在落地压缩中，动量体现在过冲与回弹中，摩擦体现在打滑长度中，风体现在被推动位移的事物中。

## 时序模式

对短片使用三拍结构：
- 0-2s：铺垫
- 2-4s：动作
- 4-6s：改变的结束状态

示例：

```text
0-2s 烛火稳定；2-4s 门开、火苗弯向一边；4-6s 烟迹朝走廊卷曲。
```

当声音驱动动作时，把每个可见变化与节拍或音效配对：

```text
2s 门响，重拍时灯光脉冲，最后一声铃响时手松开杯子。
```

## 稳定性规则

当动作过多时，手、脸、标志和产品几何体会漂移。在脆弱细节周围减少运动：
- 为对口型锁定镜头
- 让手保持简单姿态
- 要求产品部件保持刚性
- 移动光或环境而非核心身份锚点

## 序列状态

继承已观察到的动作阶段、开放运动矢量、当前片段范围、连续性锁定、精确参考标签和预留后续节拍。不要重放已标记完成的动作，不要提前执行预留节拍。
