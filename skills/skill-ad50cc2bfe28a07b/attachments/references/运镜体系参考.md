# 运镜体系参考（参考）

用于核心需求中的镜头语言设计。

---

## 景别体系

| 景别 | 取景范围 | 焦段参考 | 适用场景 |
|------|---------|---------|---------|
| 超远景 | 超大范围环境，人物如蚂蚁 | 16mm以下 | 史诗开场、天兵压境 |
| 远景 | 大场景环境，人物极小 | 24-35mm | 宏大场面、环境全貌 |
| 全景 | 人物全身+环境 | 35-50mm | 角色与环境关系、阵型 |
| 中景 | 人物膝盖以上 | 50-85mm | 动作、对话 |
| 近景 | 人物胸部以上 | 85-135mm | 强调互动、表情 |
| 特写 | 人物面部或局部 | 135mm以上 | 强调情绪、细节 |
| 大特写 | 眼部、嘴部等局部 | 200mm以上 | 极度强调情绪细节 |

### 景别切换叙事逻辑

| 切换方向 | 叙事功能 | 示例 |
|---------|---------|------|
| 由远到近 | 展示→聚焦 | 战场全貌→角色动作→情绪细节 |
| 由近到远 | 聚焦→释放 | 表情震惊→环境反应→全局变化 |
| 同景别切换 | 平行叙事 | 角色A→角色B |

## 运镜方式

### 基础运镜

| 运镜 | 说明 | 适用场景 |
|------|------|---------|
| 固定 | 镜头静止 | 对峙、对话、情绪特写 |
| 推进/推近 | 镜头向前靠近 | 聚焦细节、强化情绪 |
| 拉远/拉开 | 镜头向后远离 | 展示环境、释放张力 |
| 摇镜 | 镜头水平旋转 | 展示空间、跟拍移动 |
| 横移 | 镜头平行移动 | 跟随角色、展示横向空间 |
| 跟拍 | 镜头跟随主体移动 | 追逐、战斗、移动 |
| 环绕 | 镜头绕主体旋转 | 展示角色全貌、制造紧张 |
| 升降 | 镜头垂直移动 | 揭示空间层次 |

### 进阶运镜

| 运镜 | 说明 | 适用场景 |
|------|------|---------|
| 一镜到底 | 全程无剪辑断点 | 强调连贯性、长镜头 |
| 慢动作 | 时间减速 | 关键瞬间放大、情绪强调 |
| 定格 | 镜头瞬间静止 | 强调关键画面、情绪凝固 |
| 快速切换 | 多角度快速切换 | 战斗节奏、紧张度飙升 |
| 快慢结合 | 常规与慢动作交替 | 戏剧张力、节奏对比 |

## 情绪→运镜映射

| 情绪/场景 | 推荐运镜 | 镜头特征 |
|-----------|---------|---------|
| 威压/威胁 | 固定+轻微推近 | 压迫感逐渐累积 |
| 对峙/僵持 | 固定 | 保持张力，不干扰情绪 |
| 嘲讽/轻蔑 | 固定+轻摇 | 轻微晃动体现轻蔑 |
| 愤怒爆发 | 快速切换+推进 | 情绪外化，节奏加快 |
| 坚定/决心 | 推进+稳定跟拍 | 强化决心 |
| 悲痛/绝望 | 缓慢拉远 | 拉开感强化孤独 |
| 狂喜/张扬 | 升降+环绕 | 释放感 |
| 揭示/震惊 | 固定→快速推近 | 情绪转折瞬间冲击 |
| 追逐/紧张 | 跟拍+快速横移 | 临场感，速度感 |
| 决胜/高潮 | 慢动作+定格 | 放大情感峰值 |

## 镜头格式规范

### 基本格式
```
（【镜头】运镜+景别+聚焦目标）动作描写内容
```

### 格式结构

| 元素 | 说明 | 示例 |
|------|------|------|
| 镜头括号 | 中文括号包裹 | `（【镜头】...）` |
| 运镜方式 | 镜头运动方式 | 固定、推进、拉远 |
| 景别 | 画面取景范围 | 全景、中景、近景 |
| 聚焦目标 | 具体角色或物品 | 角色A、三尖两刃刀 |

### 示例
```
（【镜头】近景固定聚焦角色A）角色A："你到底是什么人？"眼神充满警惕
（【镜头】全景展示战场阵型）老李手持金塔，立于半空
（【镜头】俯拍展示天兵涌来）天兵齐声呐喊，如黑色潮水扑向小杨
```

### 注意事项
- 每个镜头括号只包含"怎么拍"（景别、运镜、焦点），不描述动作结果
- ✅ 正确：`（【镜头】近景固定聚焦角色A面部）`
- ❌ 错误：`（【镜头】近景特写小杨咬牙痛苦表情）`——"咬牙痛苦"是演绎内容
- ❌ 错误：`（【镜头】拉远展示无力感）`——"无力感"是情绪演绎
