# 参考片视觉基因解析

> 可适配的模式与句式，按场景改写，不要逐字照搬。

当用户提供参考影片或要求模仿特定作品的视觉风格时，读取本文件。目标不是复刻，而是提取视觉基因并融入乌托邦风格的 prompt 编写。

## 《明日世界》（Tomorrowland, 2015）

### 视觉基因提取

- **建筑**：以圣地亚哥·卡拉特拉瓦设计的瓦伦西亚艺术与科学城为实景基础，流线型白色曲面、骨骼感拱肋、大面积水面反射
- **城市布局**：开阔的步行广场，建筑间距大，强调空间留白和天空占比
- **交通**：单轨列车、个人飞行器
- **光线**：强烈日光 + 水面反射柔光，高调画面，阴影柔和
- **色彩**：纯白建筑 + 蓝天水面 + 暖橙点缀
- **情绪**：好奇、惊叹、发现

### 转化为 prompt 的关键句式

- "白色流线型曲面建筑群，骨骼感拱肋结构，大面积水面在建筑前方反射天光"
- "开阔步行广场，建筑间距充足，天空占画面上半部分"
- "强烈日光从正上方照射，水面反射柔光映上建筑曲面"

### 适用场景

概念设定片、城市全景、发现式叙事片段

## 《杰森一家》（The Jetsons, 1962）

### 视觉基因提取

- **建筑**：高耸于空中的圆柱体和圆锥体住宅，底部由支柱撑起
- **交通**：透明穹顶飞行器、悬浮步道
- **色彩**：粉紫+青蓝+黄绿的粉彩组合，饱和但不刺眼
- **情绪**：家庭温馨、日常生活的未来感

### 转化为 prompt 的关键句式

- "高耸圆柱体住宅塔，底部由流线型支柱撑离地面，顶部圆锥帽"
- "透明穹顶私人飞行器，内部可见座椅暖光"
- "粉紫色天空背景，青蓝色建筑点缀柠檬黄标识"

### 适用场景

家庭叙事片段、街道生活场景

## 《禁忌星球》（Forbidden Planet, 1956）

### 视觉基因提取

- **建筑**：铬金属内饰、弧面墙体、能量护盾穹顶
- **色彩**：大面积银色铬面 + 深色背景中的暖光点缀
- **情绪**：庄严、神秘、人类面对未知文明

### 转化为 prompt 的关键句式

- "铬金属弧面内墙，高反射表面映出暖色灯光"
- "半透明能量穹顶，外层泛淡蓝色光晕"

### 适用场景

室内空间、神秘发现式叙事

## Googie 建筑（1950s-1960s 美国商业建筑）

### 视觉基因提取

- **屋顶**：上扬翼形、倒抛物面、 boomerang形
- **标识**：星芒霓虹灯、原子符号招牌
- **材质**：不锈钢、玻璃砖、彩色亚克力
- **情绪**：速度感、乐观、商业活力

### 转化为 prompt 的关键句式

- "上扬翼形屋顶，前缘向上翘起呈机翼状，不锈钢檐口反光"
- "星芒霓虹灯招牌，辐射状尖角从圆心向外延伸"
- "玻璃砖墙面透出暖色室内光"

### 适用场景

街道生活场景、商业区、交通枢纽
