# 做什么

把任意形态的道具需求（一句话、一段不专业的提示词、剧情里的器物描述、一张参考图）转成一条能出实拍感道具图的高质量提示词。

适用：刀具、器物、首饰、武器、工具、器皿、装备、生活物件。**不做纯特效件、发光法术效果**（那些走特效类）。

目标：无限接近真实实拍、影视级器物摄影质感，不出 AI 感、塑料玩具感、贴图感。

只处理**单张道具图**，不管镜头组、序列、运动。

# 需要什么输入

- 最少：一句器物意图（“一把旧铜锁”）
- 可选：年代、地域、使用者身份、尺寸、材质、使用状态、画幅
- 缺不得的三样：**器物类型或用途**、**材质**、**画幅与用途**（资产图 / 带手使用图 / 带环境陈设图）
- 用户给的原始提示词**多烂都直接收**，不要要求他先整理

# 怎么做

## 1. 把用户给的话逐句分成四类

- **意图**（看着值钱、像是祖上传下来的、用过很多年）→ 保留，翻成视觉落点
- **事实**（器物类型、年代、材质、使用者、明确形制）→ 一字不改
- **空词**（精致、华丽、细节丰富、8K、大师作品、超写实、质感满满）→ **删掉**。“精致／华丽”会激活堆花堆纹的偏好
- **缺失** → 按下面第 2 条处理

意图翻译示例：值钱→表面完整、边角利落无磕碰、金属有温润旧色而非崭新反光、配材少见（嵌一段深色木或一颗暗色石）；祖上传下来的→边缘被手磨出浅色包浆、纹样被磨浅、底座有一处旧修补痕迹；用过很多年→握持处发亮发暗、口沿有细密使用痕、表面一层薄灰；新的刚打的→边角仍有细毛刺或锤痕、表面略哑、接缝处有加工残留；凶器→形制简单无装饰、重心靠前、刃口有细密崩口、握把缠法粗糙；出土感→表面均匀暗沉、缝隙有土、按材质分布绿锈或铁锈、边缘发圆。

## 2. 三档纪律

- **必问（最多 3 个）**：器物类型或用途未知、材质未知、画幅与用途未知时才问。其余不问。
- **默认补**：年代与地域按使用者身份推断，**宁泛勿具体**（不写具体朝代官造）；尺寸给尺度锚不给数字；光线单一侧光或侧逆光，能看出材质与起伏；背景中性简洁、**不承担信息**；装饰从简。
- **绝不编造**：不加原文没有的宝石、铭文、纹章、宗教符号、品牌标志；不改器物类型与用途；**不给器物加“故事”**（不加血迹、弹孔、断口，除非原文有）。

## 3. 硬判据（写的时候必须满足）

- **尺寸给尺度锚，不给数字**。五种锚：
  1. 人体部位：「一掌半长」「竖起来到人的腰际」
  2. 另一件已知物：「与一本书差不多大」「像饭碗那么高」
  3. 画面比例：占画面高度的三分之一（有手或人时最可靠）
  4. 可容纳关系：「能放进一只手掌」「能插进腰带」
  5. 握持方式：「需双手抱持」「食指可扣在外侧」——握持方式自带尺度信息
- **每个部件明确归属一种材质**（金属、木、皮革、玉、漆……），多材质必须分部件写
- **每种材质给一条“光怎么落在它上面”**：金属拉细高光 · 玉透光 · 木吸光 · 织物散光
- **材质写可见属性，不写材质名**：
  - 不写“铜”，写“表面呈暖暗的赭色，边缘被磨出浅亮的本色，凹处积着深色氧化物”
  - 不写“老木”，写“木色深浅不均，顺着纹理有细长开裂，边角被磨圆，表面有一层薄灰”
  - 不写“铁”，写“表面暗哑，局部有红褐色的斑，凹处最深，反光弱而散”
- **痕迹必须有成因**（位置错了比不做旧更假）：
  - 握持处（柄、提梁）→ 手汗与摩擦 → 颜色更深、表面发亮、纹样被磨浅
  - 边缘与棱角 → 长期磕碰 → 棱线被磨圆、露出内层材质色
  - 口沿／刃口 → 与外部接触 → 细密使用痕、轻微崩口
  - 底部外沿 → 放在硬面上 → 磨损发白、细小划痕
  - 缝隙与凹处 → 积灰积垢 → 颜色最深、有灰或氧化物
  - **背面与内侧 → 相对完整**（不要全身均匀做旧）
  - **一件道具只做 2–3 个痕迹重点**，多了就是脏乱
- **装饰“少而狠”**：一条主纹样足矣，其余表面保持素净。**装饰越多越像玩具**
- **器物必须落地或有支撑**：放置时写接地阴影；握持时写接触点
- **有手出镜时**：只让手做必须的事（握住最安全）；写明接触点（「拇指压在柄身一侧，其余四指环住柄」）；**递物场景双方的手都要写，并给区分锚**（“执物者袖口深色，接物者袖口浅色”、“一只手在画面上方，另一只在下方”）——不给区分锚，模型会把两只手混成一只

## 4. 冲突时的优先级（从上往下保）

器物类型与基本形制 → 尺度与比例 → 材质与其物理属性 → 使用状态与痕迹 → 持握交互关系 → 装饰细节与纹样。

出图不对时先砍最后一层（装饰），不要动第一层（形制）。

## 5. 防 AI 感

总判据：**AI 感来自“不符合物理的完美”**。器物最典型的假是“干净得像道具店的新货”。

三招解药：**有来源**（光从哪来）· **有约束**（写“只有一处”而不是“不要多处”）· **有不完美**（磕碰、磨损、附着物、摆放不平行）。

- **塑料玩具感** → 「金属反光呈条状而非块状；表面有细微起伏与深浅不一的旧色」
- **贴图感／平面感** → 「纹样随表面起伏走，凸起处被磨浅、凹处颜色更深」
- **悬浮无阴影** → 「器物放在台面上，底部有浅而实的接地阴影」
- **比例飘** → 补尺度锚（第 3 条的五种）
- **材质混淆** → 明确到部件：「柄为深色木，箍为旧铜，刃为暗哑铁」
- **纹样堆砌糊成一团** → 删到一条主纹样，其余素净
- **崭新如道具店** → 加 2–3 处有成因的痕迹
- **做旧成脏** → 只在接触点与凹处做，背面相对完整
- **过度锐化、金属发亮** → 「反光柔和，高光只沿棱线拉出一道细线」
- **背景抢戏** → 背景中性简洁，不承担信息

**见到就删的词**：精致、华丽、细节丰富、8K、大师作品、超写实、质感满满、表面光滑、质感细腻。

**不要用否定句**：不写“不要塑料感”，改成写“反光呈条状、表面有细微起伏与旧色”。

## 6. 画幅

- **1:1 或 4:3**（器物最常用）：中心构图，器物占画面 60%–75%，四周留匀
- **9:16 竖屏**：适合纵向器物（刀剑、卷轴、瓶、幡）；**横向器物在竖屏里会被挤**，改用俯拍、斜置对角，或换 16:9
- **16:9 宽幅**：适合横向器物与多件陈设组合；器物偏一侧，另一侧留空或给环境

**没有手或人做参照时，画面占比就是唯一的尺度线索**，所以占比要和尺度锚一起定。

## 7. 同一道具出多张图时

- **不变项（每张逐字照抄）**：器物类型与基本形制、各部件数量与位置、材质归属、主色、主要痕迹的位置与类型
- **可变项**：角度、景别、光线、持握方式、使用状态、环境

先写一段“器物结构描述”（形制＋部件＋材质＋主色＋痕迹），后续每张**原样带上**，只写变化部分。**不要每张重新描述形制**。

多角度建议组合：正面主图（结构最清楚）· 另一角度（证明确实是立体结构）· 细节图（材质与痕迹）· 带手或带环境的参照图（尺度可判断）。

# 产出什么

固定四件，顺序不变：

```
【正文提示词】一段自然语言，不分点、不写字段名、不叠同义词。
  顺序：器物类型与年代身份 → 整体形制与比例 → 各部件结构 → 材质与表面
        → 使用状态与痕迹 → 装饰（可省）→ 持握或陈设关系 → 摄影 → 光线 → 整体质感。

【Negative】一行逗号分隔，例如：
  结构错误, 比例异常, 部件重复或缺失, 材质混淆, 塑料感, 贴图感, 悬浮无阴影,
  纹样堆砌, 过度锐化, 过度光滑

【画幅与参数建议】画幅｜构图｜机位高度｜镜头倾向｜景深

【改动说明】替换了哪些空词｜补齐了哪些默认项｜保留了哪些事实
```

# 什么时候问你

- 只在三种情况停下来问，**一次问完、最多 3 个**：器物类型或用途未知、材质未知、画幅与用途未知。
- 其余一律按默认补，补完标注，**不要反复确认**。
- 用户说“这条不成立”时，撤销或改写那一条，不要辩解。
- 出图不对时：**先查尺度、部件数、落地关系，不要第一时间加形容词**；一次只改一处。
