## Module 3 · 故事板规则（GPT Image 2）

### 0. 禁制清单（阻断级）

**抽象禁制**：
- ❌ 速度线（speed lines / motion lines）
- ❌ 残影/运动模糊（afterimage / motion blur）
- ❌ 同一角色在同一画格出现两次
- ❌ 漫画式分镜布局（comic panel layout / speech bubble / dialogue box）
- ❌ 跨格共享元素
- ❌ 拟声词（onomatopoeia / 「砰」「轰」「咻」等）

**具体形象禁制**：
- ❌ 外景建筑全景（Shot 描述指定室内时）
- ❌ 黑伞插入水面/积水（除非明确写了"伞尖触地溅水"）
- ❌ 雷电成为画面主体或唯一视觉焦点
- ❌ 写实漫画渲染（高光点/空气透视/环境光反射/雨水反光细节）
- ❌ 下区调度图画成俯视插图（必须是纯简化线稿：墙线+门洞+火柴人+虚线箭头）
- ❌ 同一画格合并多个动作阶段（起手和收手不能同格）
- ❌ 天气效果 emoji 或符号（⚡💧）
- ❌ Shot 1 画成外景大远景建立镜头

### 1. 一画格=一时点=一景别（阻断级）
- 景别字段只能有一个值（L0-L5 之一）
- 禁止一个画格囊括多个时间点
- 禁止同一画格描述两个景别
- 一镜到底/长镜头按关键帧拆为独立画格

### 1a. 单镜单一视觉任务（阻断级）
- 每格：1 个前景主体 + 最多 1 个背景暗示
- 禁止一个画格承担 ≥3 个等权重视觉任务
- 开场 Shot 1 必须是 P6 钩子画面的直接视觉呈现
- Shot 1 禁止：场景空镜、角色静态入画、"建立"标签
- Shot 1 必须含钩子元素：身体冲突/微表情+手部/威胁物/超自然痕迹/身份揭露
- Shot 1 因果锚点 = "第一镜·钩子即全段因果起点"

### 2. 高速/超自然事件拆分
- 按因果步骤拆为子编号镜（Shot N-1, N-2, N-3...）
- 每子镜 = 一个完整因果步骤
- 禁止省略中间步骤

### 3. 镜头因果链 + 因果锚点（阻断级）
- 相邻镜因果四模式（至少满足其一）：动作→反应 / 建立→推进 / 原因→结果 / 收紧聚焦
- 因果链断裂即阻断：位置跳变 / 无因果并置 / 关键步骤缺失
- 每个 Shot 必须有「因果锚点」——本镜与上一镜的可视因果连接

### 4. 景别渐进
- 相邻镜景别跳变 ≥2 档须有明确叙事理由
- 全段景别序列呈"渐进收紧"或波浪，禁止随机跳变

### 5. 一镜到底/连续长镜头拆分
- 按关键帧拆为独立画格：起幅→过渡关键帧→落幅
- 每画格 = 运动路径上一个关键帧

### 6. 画格格式
- 画布比例：16:9 横版
- 画格排列：3-5镜→3+2矩阵 / 6镜→3+3 / 7-8镜→4+4
- 空间层次驱动——每镜以"前景/中景/背景"三层锚定
- 禁止位置百分比语言（"占画面1/5""画面左下区"）
- 禁止成品渲染词汇（材质/光泽/光影/空气感/表面质感）
- 灰阶关系：浅灰（亮面）、中灰（暗面）、深灰（阴影）

### 6a. 调度信息（不进入产出）
- 景别（L0-L5）、因果锚点、主视觉任务、空间锚点、道具状态链
- 以上为 AI 内部构思信息，不暴露给生图模型

### 7. 跨镜连续性自检
轴线一致性、道具状态链完整性、角色移动连续性、景别因果链、因果锚点全覆盖

### 8. 空间连续性锁定
固定元素在所有画格中方位锁定不变；允许变化：距离/站位/姿势/道具角度/光线质量

### 9. 画格-镜头映射
画格数 = D1.3 因果步骤分解结果；覆盖率 = 100%

### 10. 单镜物理可行性（阻断级）
- L5：最多 1 主体局部 + 1 相邻小元素
- L4：单主体完整部位
- L3：上半身 + 手持物
- L2：全身 + 手持物 + 少量环境
- 景别-内容不匹配 → 拆镜或升级景别

### 11. 镜头语言多样化（阻断级）
- 运镜 ≥2 种 / 景别跨度 ≥3 档（含极值 L0/L5） / 角度 ≥2 种 / 构图 ≥2 种
- 爆点同步：冲突爆点处运镜+景别+角度+构图同步剧变

## Module 4 · 故事线规则（即梦 Seedance 2.0）

### R3 资产外观白名单
故事线禁止写：角色穿着/五官/体型/色彩、物品材质/颜色/形状、场景视觉细节
允许写：角色动作、物品状态变化、空间位置、布光方向（色温+方向是动态行为）

### 双职责体系

**故事线严禁复写**（以下由故事板绑定）：镜头数量、镜头顺序、构图关系、摄影机位置、镜头切换指令、景别

**故事线只写七类目**：
| 类目 | 要求 | 示例 |
|:---|:---|:---|
| 动作 | 角色名+具体动作+方向/速度 | "顾沉舟从货架取下一把黑伞" |
| 运镜方向 | 缓推/跟摇等——只写方向与速度 | "摄影机缓推逼近" |
| 布光方向 | 色温+光源方向+阴影落点 | "冷白背光从左肩切出轮廓带" |
| 音效 | 与画面同步，逗号/句号衔接 | "硬币落下，清脆金属声" |
| 台词 | 角色对白，与动作同步 | "她低声说：'别开门。'" |
| 表演 | 微表情/肢体/呼吸/眼神 | "手指平稳，没有多余动作" |
| 衔接词 | 隐含标记镜头边界 | "随后""紧接着""此时""与此同时" |

### S1A 钩子强制
- 首句必须正面覆盖 Module 3 Shot 1 的冲突切入画面
- 钩子画面为"场内+场外并置"时，首句必须同时呈现场内外两空间

### 修辞禁止（阻断级）
- 禁止文学语体：小说式场景描写、氛围散文、环境铺垫
- 禁止比喻词：像、仿佛、犹如、好似、似的、宛如、如同
- 禁止冗余外观：角色穿着/配饰/物品颜色/材质/形状
- 禁止拆成逐镜编号列表

### 叙事铁律
1. 动作-台词-反应链条
2. 视觉表达：动作标注方向/速度/幅度，光影标注方向/色温/强度
3. 戏剧峰值：运镜+光影+音效同步剧变
4. 收尾闭环：终镜画面与声音同步淡出/定格/拉远
5. 故事线固定开头：`按故事板镜头顺序自然推进`

### Module 4 禁止行为
- ❌ `[N-N秒]` 时间码分段
- ❌ `运动强度：` / `开头衔接：` 等 Module 3 元数据字段
- ❌ 分条列举镜头或以 `-` 开头逐镜罗列
- ❌ Shot N / Tn 编号出现在故事线正文
- ❌ "固定/锁机/静态/静止机位/不动/定格"
- ❌ 文学语体、冗余外观、故事板信息复写

## 构图策略空间层映射

| 策略 | 空间层映射 |
|:---|:---|
| 权力压迫 | 前景空，中景主体压到画框底部/角落，占比≤20%，背景上方大面积留空 |
| 负空间吞噬 | 前景空，中景主体偏居一侧1/3区，背景另一侧大面积留白 |
| 对角线驱动 | 前景可含对角线物体边缘，中景主体沿对角线排布，倾斜25-30° |
| 前景切割 | 前景物占1/3-1/2画面（虚焦），中景主体被部分遮挡 |
| 边缘出画 | 前景可含主体局部出画边缘，中景主体大部分在画框外 |
| 倾斜失衡 | 中景主体随地平线倾斜5-15°偏置，背景线随之倾斜 |
| 尺度反差 | 前景小物体居中近距，中景极端大小对比的另一方 |
| 纵深分层 | 前景物→中景主体→背景环境三层清晰，主体被前后夹击 |
