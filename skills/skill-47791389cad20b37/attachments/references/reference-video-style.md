# 视频提示词参考结构

本文件根据用户提供的“视频提示词参考”整理。它只继承提示词的结构、二维视觉语言、信息密度、转场方法和表演逻辑；具体角色、主题、颜色、标题与世界观必须来自当前项目，不能机械复制示例中的白发粉瞳角色、PINKNOISE 名称或黑白粉配色。

## 核心视觉定位

所有视频提示词默认采用：

**纯二维日式赛璐璐动画风格 + 扁平 Editorial MG 平面设计风格 + 高级游戏宣发海报动态视觉语言。**

全片必须保持纯二维。禁止任何 3D 效果、立体建模、真实空间纵深、CG 写实渲染和真实摄影感。所有人物、场景、道具、特效、UI、文字与图形都像二维动画插画与平面设计结合的作品。

角色外观严格参考已经验收的角色资产设定图。脸型、发型、发色、瞳色、服装版型、鞋、装备、饰品、身材比例与识别色不能偏离。

## 每个视频节点的固定提示词模板

### 1. 生成目标

先写：生成一支/一段约〔节点时长〕秒、〔画幅〕、原创〔PV 类型〕视频，本节点负责〔钩子/建立/升级/高潮/落版〕。

### 2. 整体风格

写明纯二维日式赛璐璐动画、扁平 Editorial MG 平面设计、高级游戏宣发海报动态视觉语言。人物使用大面积纯色填充、清晰线条与二维硬边阴影；背景由平面色块、漫画网点、贴纸、符号、几何图块、速度线、噪点、原创 UI 与文字碎片构成。不要真实皮肤质感，不要复杂写实光影。

### 3. 角色设定

明确写“角色外观严格参考已验收角色资产设定图”，随后列出当前角色：

- 发型、发色、眼睛、脸部识别点。
- 服装主辅色、鞋、装备、配饰。
- 性格关键词与表演气质。
- 本节点允许的动作与表情。

不得直接照抄示例角色；必须换成当前项目真实角色设定。

### 4. 主题设定

写本项目的原创主题概念和视觉空间，例如失控信号、都市电波、梦境裂缝、机械祭典、东方灵域等。围绕主题建立 5–10 个可以反复出现的原创二维符号，包括涂鸦、贴纸、几何图形、扑克牌花色、星星、心形、警告标识、游戏 UI、法阵、印章、文字碎片等。主色方案由当前角色和项目决定，保持 2–4 个主导色高对比，不要随机漂色。

### 5. 音乐与声音

写音乐为约〔BPM〕的〔当前音乐风格〕，列出电子鼓/低沉 Bass/碎拍/合成器/摇滚吉他/管弦/民族乐器等实际编制。

节奏结构至少包含：

- 开头：短促提示音、电流/机械/环境声或低频脉冲，第一秒制造吸引力。
- 中段：鼓点加密、切分节奏与音效切片推动高频剪辑。
- 结尾：强节奏突然定格，配原创标题确认音或收束音。


### 6. 画面风格

强调纯二维赛璐璐人物 + 平面 Graphic Design 海报感 + 游戏 UI 设计感。背景可使用漫画网点、涂鸦、贴纸、爱心、扑克花色、骷髅、星星、文字碎片、几何图块、故障 UI 条形、圆形波纹、速度线和噪点纹理，但必须根据当前主题筛选，不要无脑堆满。

整体气质可吸收 Y2K、街头朋克、二次元潮流杂志封面、独立游戏主视觉等平面视觉语言；保持原创，不使用现成游戏角色、Logo 或 IP 素材。

### 7. 动态与转场要求

潮流/JRPG/角色宣传类默认高密度信息轰炸与高频转场，平均单镜约 0.3–0.8 秒，不允许长时间停顿、空白过渡和普通淡入淡出。电影叙事或治愈方向可以适当延长单镜，但仍保持持续视觉信息推进。

开场 1 秒内快速抛出至少三类强识别信息：角色脸部特写、标志装备/配件、主题符号、标题碎片、原创 UI、噪点或电波元素。

中段持续在角色特写、半身姿态、夸张表情、手势动作、鞋/装备细节、UI 弹窗、主题符号、标题字样和贴纸元素之间快速切换。

可用转场：

- 图形碰撞切换。
- 故障闪断。
- 贴纸弹出覆盖。
- 图层滑移。
- 速度线推切。
- 圆形扩张。
- 漫画分格跳切。
- 文字爆闪。
- 瞬时拉近。
- 节奏卡点闪白。
- 噪点抖动。
- UI 面板插入。
- 符号遮挡切镜。

多层运动至少包含：前景贴纸/UI 飞入，中景人物动作，后景图形脉冲/色块位移，文字与 UI 可同步鼓点跳动。

每次切换尽量伴随画面方向变化、构图挤压、图层错位、符号爆开或纯色重拍，强化“每一拍都在切、每一秒都有新信息冲出来”的推进感。

### 8. 按时间码镜头

每个节点按精确时间码拆镜，例如 `0.0–0.6 秒`、`0.6–1.2 秒`。每镜都写：

- 叙事任务。
- 主体与起势/过程/收势。
- 表情与视线。
- 前景、中景、背景。
- 景别、机位、轴线与焦段感。
- 相机路径、速度、加速/减速、过冲/回弹。
- 图形/UI/文字运动。
- 主辅色与二维光影。
- 同期声、动作音、对白。
- 入场转场、出场转场、准确尾帧。

文字效果必须明确写“无”，或给出原创文字内容、位置、安全区、出现方式、停留和退出方式。

### 9. 表演要求

角色动作保持强烈二次元动画感：动作夸张、利落、张扬，表情具有明确人格。根据角色设定可选择坏笑、挑眉、眯眼、露齿、甩头发、拉耳机、指向镜头、踩步、转身回头、突然贴近画面等动作，也可以换成与当前角色更匹配的动作。

不要写实真人式表演，不要真实摄影式人物调度。

### 10. 节点尾帧与下段交接

固定最后一帧中的角色屏幕位置、身体朝向、视线、动作趋势、主色、主要图形遮挡边缘和相机动势。下一节点从同一状态继续。最后节点则固定落版前收束画面。

### 11. 不要出现

最后一段必须以 `不要出现：` 开头，至少覆盖：

3D、立体建模、CG 写实渲染、真实摄影感、真实皮肤纹理、真实空间景深、复杂写实光影、角色身份漂移、脸型变化、瞳色变化、发型发长变化、服装随机换色或融化、鞋和装备变化、手指缺失或多指、多余肢体、肢体穿插、背景结构闪变、主色随机漂移、无控制镜头抖动、动作方向断裂、转场不匹配、长时间静止、空白过渡、普通淡入淡出、低信息画面、随机乱码、错误文字、现成品牌 Logo、现成 IP、水印、播放器界面。

此段之后不再追加内容。
