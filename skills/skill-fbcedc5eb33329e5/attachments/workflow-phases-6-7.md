### Phase 6：Quality Gate 2

读取 [references/quality-gate-spec.md](references/quality-gate-spec.md) 获取完整检查清单。

#### 三代自检

- 第一轮【叙事】：节拍完整 / 情绪曲线流畅 / 运镜有叙事理由
- 第二轮【摄影】：三件套齐（摄影机+镜头+光比）/ 瑕疵>=3项跨>=2类别 / 色温统一
- 第三轮【合规】：无空洞词 / 确认门在结尾 / 模型未预设 / 微观描述具体

#### 五重会审

| 席位 | 追问方向 |
|------|----------|
| IMAX摄影大师 | 摄影参数匹配题材？ |
| 导演大师 | 镜头即叙事，情绪外化到位？ |
| 剪辑大师 | 转场衔接、景别衔接、色调无断层？ |
| 声景设计师 | 声音分层完整、声画关系合理？ |
| 去AI工程师 | 瑕疵项数/类别达标、负向词覆盖、微观具体？ |

全部通过 -> 进入确认门。

### Phase 7：确认门

生成前必须锁定用户确认以下项目：

1. 方案整体是否符合创作意图？
2. 视频生成模型确认？（默认 Seedance 2.0 Mini，用户可指定其他）
3. 输出分辨率确认？（默认 720P）
4. 帧率确认？（固定 60fps）
5. 参考模式确认？（全能参考模式）
6. 人物音色确认？（直接进入视频生成工作流，如有角色）

全部确认 -> 执行生成。

**prompt直出规则**：执行生成时每个镜头直接输出完整的视频prompt（Seedance 2.0 Mini / 21:9 / 720P / 60fps / 全能参考模式 / 开启声音 / 人物音色直接进入工作流），不拆分TTS prompt、不生成剪辑指令、不生成合成指令。台词/对白/人物音色直接内嵌在视频prompt中。**禁止在prompt前输出任何元数据头**（如"模型：xxx 模式：xxx 画幅：xxx 分辨率：xxx 声音：xxx"等参数信息），直接输出prompt正文。
