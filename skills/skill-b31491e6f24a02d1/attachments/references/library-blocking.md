# 资料库：复杂调度 BLOCKING

### @BLOCKING：角色与物体调度资料库 v1.1


适用范围：AI视频生成分镜中的动作场面、对话调度、追逐跑酷、武打设计。

不适用场景：纯静态对话（用@ANGLE+@MOVEMENT更高效）、抽象非叙事画面。


#### 一、核心设计原则


调度设计围绕一个目标：**在运镜的基础上，通过角色走位和物体运动，制造画面内的运动张力、空间深度和视觉节奏。**


- **运动张力**：摄影机与角色/物体之间存在速度差或方向差，产生视觉上的拉扯感。摄影机永远不与角色完全同速同向。

- **空间深度**：通过角色在不同纵深平面的走位、前景物体主动穿插、摄影机穿越遮挡物，让二维画面持续产生三维空间的错觉。

- **视觉节奏**：静与动、快与慢、近与远之间的切换形成有呼吸感的韵律。静止足够长，爆发足够短。

#### 三、经典调度模板（首批12个）


**模板1：杜琪峰静态对峙**


调度类型：对峙型。


角色调度：3-5人，不规则多边形站位，间距3-8米前后错落，各指向不同象限形成交叉视线网络。全员静止，仅一人在漫长停顿后缓收枪。


物体调度：枪械从腰间/腋下拔出，枪口火焰为唯一动态光源。立柱/货架部分遮挡角色。


摄影机·角色速度关系：摄影机固定或极缓横移，角色完全静止。


速度差设计：摄影机的极缓横移与角色的完全静止形成速度差--观众感受到的不是镜头在动，而是空间在呼吸。


节奏设计：蓄力为所有人完全静止，视线锁定。爆发为骤然拔枪射击后立即归静。收束为恢复静止，一人缓收枪。


可执行性评级：中。降级策略：多人同时拔枪拆为单人特写交替剪辑。


**模板2：迈克尔·贝环绕英雄**


调度类型：环绕型。


角色调度：1人立于圆心，双脚分开，缓自转保持面向摄影机。


物体调度：爆炸碎片从角色身后放射状飞出，沿摄影机环绕方向排布。


摄影机·角色速度关系：低角度360°轨道环绕，摄影机速度约为角色自转的3倍。


速度差设计：角色的缓自转与环境的急速旋转形成对比--英雄在风暴中心岿然不动。


可执行性评级：中。降级策略：背景爆炸用参考图单独控制。


**模板3：昆汀后备箱/受限视角**


调度类型：偷窥型。


角色调度：1-2人在画面框外上方，向下俯身探入框内翻找物品后退出。


物体调度：后备箱盖/车门形成天然黑色硬边框。被翻找物品在框内移动。


摄影机·角色速度关系：摄影机完全静止置于受限空间内部，角色从外部入侵。


速度差设计：空间的静态与角色的动态形成张力--观众感受到的不是在看画面，而是被关在里面。


节奏设计：蓄力为空画面，仅见受限空间内部和黑色边框。爆发为角色从上方探入翻找物品。收束为角色退出，画面恢复空框。


可执行性评级：高。降级策略：无需降级。


**模板4：斯皮尔伯格反应推镜**


调度类型：揭示型。


角色调度：1人完全静止望向画外，仅眼眶渐红、瞳孔放大、嘴唇微张。


物体调度：无。


摄影机·角色速度关系：极缓推进，角色完全静止。


速度差设计：摄影机的运动与角色的静止形成强烈对比--世界的重量正在压向这个一动不动的人。


可执行性评级：高。降级策略：首尾帧锁定构图。


**模板5：韦斯·安德森90°平移**


调度类型：仪式型。


角色调度：1-2人绝对居中，正面直视镜头，几乎完全静止。


物体调度：场景道具随背景平移变换。


摄影机·角色速度关系：90°横向平移，与角色保持固定距离。


速度差设计：摄影机动，角色不动，场景变--舞台在转，演员静止，产生剧场感。


可执行性评级：高。降级策略：无需降级。


**模板6：库布里克单点透视**


调度类型：压迫型。


角色调度：1-3人沿画面中轴线排列或行走，步速均匀不转向。


物体调度：走廊/门框/对称家具强化消失点透视。


摄影机·角色速度关系：对称广角固定镜头或极缓沿中轴线推进。


速度差设计：摄影机与角色同在中轴线上同向运动时，产生永远走不出这个空间的宿命感。


可执行性评级：高。降级策略：无需降级。


**模板7：奉俊昊升降揭示**


调度类型：揭示型。


角色调度：1-3人在画面下方空间或从低处走向高处。


物体调度：地平线/栏杆等水平参照物在升降中持续改变与角色的相对位置。


摄影机·角色速度关系：摄影机从极低角缓升或从高处缓降。角色移动速度慢于摄影机升降速度。


速度差设计：垂直运动揭示空间层次--低处是困境，高处是真相或更大的压迫。


可执行性评级：中高。降级策略：角色在升降中保持静止，运动结束后再走位。


**模板8：吴宇森双枪滑跪**


调度类型：追逐型。


角色调度：2人相向滑入或一人追击一人后退，身体后仰双手平伸持枪沿对角线滑行。


物体调度：弹壳缓慢弹出抛落，地面碎屑/水花慢动作飞溅。


摄影机·角色速度关系：与角色同向同速横移跟拍，或固定慢动作让角色高速滑过。


速度差设计：慢动作让弹壳和水花的空间轨迹被拉长--每一帧都是一幅完整的构图。


可执行性评级：中低。降级策略：单人滑行+跟拍。弹壳后期合成。


**模板9：黑泽明群像纵深走位**


调度类型：仪式型。


角色调度：5人以上沿纵深排列，前景缓速横向走位，中景向前迈出，后景原地静止。


物体调度：旗帜/兵器/建筑构件作为纵深参照物。


摄影机·角色速度关系：固定广角或极缓横移。


速度差设计：前景慢、中景快、后景静止--三个时间层在同一个画面内共存。


可执行性评级：中。降级策略：用前景先动→中景跟进→后景静止的时序分层，不做同时运动。


**模板10：塔可夫斯基长镜穿越**


调度类型：穿越型。


角色调度：1-2人极缓速穿过复杂空间，途经多个环境区域，路径上有自然障碍物反复遮挡。


物体调度：树枝/窗框/水雾持续进入又退出画面，形成遮挡→露出→再遮挡的呼吸节奏。


摄影机·角色速度关系：与角色等速后退跟拍或侧面跟移。


速度差设计：空间深度由前景遮挡物的进出节奏创造--观众始终意识到自己在穿过一个三维空间。


可执行性评级：中。降级策略：拆为2-3段，用前景遮挡处做隐藏剪辑点。


**模板11：冈萨雷斯空间穿越**


调度类型：穿越型。


角色调度：1-3人跟随摄影机穿过门/走廊/楼梯/房间，持续与环境交互。


物体调度：门/窗/柱作为空间转换节点和隐藏剪辑点。


摄影机·角色速度关系：在角色前方后退引导或后方跟随，速度始终同步。


速度差设计：狭窄空间处用短暂遮蔽做隐藏剪辑点--伪一镜到底。


可执行性评级：低。降级策略：每个空间独立生成，通过遮挡物剪辑拼接。


**模板12：王家卫抽帧步印**


调度类型：情绪型。


角色调度：1人正常速度行走，摄影机以低帧率拍摄形成断续拖影。


物体调度：人群以正常速度流动，与角色的断续拖影形成对比。


摄影机·角色速度关系：略慢于角色侧面跟移，配合抽帧效果，背景拉出模糊拖影，角色相对清晰但仍有断续感。


速度差设计：速度差产生时间被拉长的情绪效果。


可执行性评级：中低。降级策略：用step printing关键词尝试，不生效则后期实现。


#### 四、动作场面调度专项


**动作调度的六个子类型**：


- **蓄势**：角色从完全静止骤然进入高速运动。摄影机在蓄力阶段极缓推进，爆发瞬间急推或急甩。摄影机推进的极缓与爆发的极快形成速度对比，蓄力越长爆发冲击力越大。可执行性：中。

- **拔刀/拔枪**：瞬发制敌。武器轨迹为弧线或直线，动作完成后有收招静止。摄影机在爆发瞬间向动作反方向运动，180°方向差让武器移动速度被视觉加倍。可执行性：中。

- **突进**：角色以冲刺速度从画面深处冲向摄影机或穿越画面。摄影机在前方后退跟拍，后退速度略慢于冲刺速度时产生即将被追上的张力。可执行性：中。

- **跑酷**：角色利用垂直空间做跳跃/攀爬/翻越/滑行。每个障碍物是一个节奏节点--接近时加速，翻越时摄影机跟摇，落地时摄影机短暂震动。可执行性：低。降级：每次只生成一个障碍翻越，拆为起跳/空中/落地三段。

- **舞蹈/武舞**：连续有节奏的身体运动，摄影机与动作节奏同步。可执行性：低。降级：拆为起式/定式/收式三个静态造型，动态段用运动模糊过渡。

- **运动交接**：物体在角色间传递或转移。静止交接可行，运动中交接困难。降级：用手部特写完成交接。


**动作视觉畸变**：


- **拉伸畸变**：高速运动中肢体/武器被拉伸。AI可控性低，降级为后期手绘。

- **残影/叠影**：角色前一位置留下半透明残影。部分模型对motion trail有响应。

- **冲击定格**：撞击瞬间画面短暂静止。AI不可精确控制，降级为独立静态镜头剪辑拼接。

- **速度线/冲击线**：沿运动方向或放射状的密集线条。部分模型对speed lines有响应。

- **画面震动**：冲击力导致画面震动，震幅与冲击强度成正比。部分模型对camera shake有响应。

- **反向蓄力**：动作前先向反方向微动再出击。AI能理解此逻辑，精确幅度不可控。


**武器展示**：


- **战前亮械**：缓动作拔出/展开武器，摄影机从局部推至面部或环绕展示

- **战中换械**：旧武器损毁，急摇至新武器抽出

- **战后收械**：缓收刀/退弹，摄影机固定或极缓横移，声响放大

- **过场展械**：纯视觉炫耀，慢动作旋转/变形，摄影机环绕，光影流动


#### 五、防僵化机制


**三层使用层级**：


- **第一层：直接套用。** 当场景的叙事意图、角色数量、空间特征与某个模板完全一致时，直接调用该模板的全部参数。极少触发，仅限高度类型化场景。

- **第二层：模板骨架+自主变异。** 保留模板的"摄影机·角色速度关系"--这是模板的核心基因。若模板包含"节奏设计"则保留，若模板的视觉节奏来自空间关系则保留"空间纵深利用"。替换"角色站位几何"和"走位路径"。必须加入至少一个原模板没有的设计元素。最常用层级。

- **第三层：弃用模板，自主设计。** 当叙事意图与任何模板的核心情绪都不匹配时，放弃模板，用通用模板参数结构从零构建。


**层级判定逻辑**（线性递进，无互斥）：

- 能找到情绪匹配的模板？→ 是 → 进入第二层（骨架+变异）

- 情绪匹配且角色/空间也完全一致？→ 是 → 进入第一层（直接套用，极少触发）

- 找不到任何情绪匹配的模板？→ 进入第三层（自主设计）


**降级优先级**（独立于使用层级，仅当可执行性评级为不可行时触发）：

1. 多人同步→拆为先后时序（保留单镜）

2. 时序化后仍不可行→拆为多镜头（保留调度逻辑）

3. 拆镜仍不可行→替换为同情绪更简单调度（保留叙事意图）

4. 完全不可行→标注后期/实拍参考，改用静态构图+表演


#### 六、与编译系统现有模块联动


| 模块 | 分工 | 联动方式 |

|------|------|---------|

| @MOVEMENT | 摄影机运动指令 | @BLOCKING在摄影机运动上叠加角色走位和物体运动。摄影机运动描述引用@MOVEMENT锚点词 |

#### 七、使用流程


1. 确定叙事意图 → 识别这场戏需要传达什么感受

2. 匹配调度模板或自主设计 → 用通用模板参数结构构建调度方案

3. 确定摄影机·角色速度关系 → 速度差和方向差是质感的核心来源

4. 设计空间纵深层次 → 前景/中景/后景各层运动速度不同

5. 检查节奏设计 → 是否有蓄力→爆发→收束的呼吸节奏

6. 评级与降级 → 不可行则降级处理


#### 八、嵌入口与调用逻辑


**模块定位**：@BLOCKING是摄影机+角色+物体的复合调度方案库。@MOVEMENT是纯摄影机运动指令库。@BLOCKING在调用时引用@MOVEMENT的锚点词描述摄影机运动，自身核心价值是摄影机与角色的速度关系设计和节奏设计--这两个是@MOVEMENT不包含的。


**调用逻辑**：分镜编译时，系统先在@BLOCKING中确定调度方案，再将方案中的摄影机运动描述引用@MOVEMENT锚点词，最后在@CAMERA中选用匹配调度风格的摄影机和镜头。三个模块按调度设计→运动指令→设备选型的顺序串行调用。
