# 提示词原文保护

## 三个对象

- `prompt_source`：用户分镜表中提取的提示词字段；
- `prompt_canonical`：只完成允许的传输规范化后的文本；
- `tool_prompt`：真正写入视频工具主提示词字段的文本。

必须满足：

`prompt_canonical == tool_prompt`

## 允许的传输规范化

1. `<br>`、`<br/>`、`<br />` 转换为 LF 换行；
2. CRLF、CR 转换为 LF；
3. 去除 CSV 或 JSON 语法本身的字段包装。

不允许：

- `.strip()` 删除正文首尾空格；
- 合并连续空格；
- 删除空行；
- 中文标点与英文标点互换；
- 直引号与弯引号互换；
- 简繁转换；
- 翻译；
- 自动纠错；
- 模块排序；
- 删除重复约束；
- 补充模型关键词；
- 把负面约束移入单独字段后从原文删除。

## 哈希

统一使用 UTF-8 和 SHA-256：

```python
hashlib.sha256(prompt_canonical.encode("utf-8")).hexdigest()
```

工具调用前记录：

- 镜号；
- 字符数；
- SHA-256；
- 工具名；
- 任务参数中的提示词字符数；
- 任务参数中的提示词SHA-256。

两次结果不一致时禁止调用。

## 宿主自动处理

宿主若会在工具调用前自动摘要、翻译、优化或截断文本，即使 Agent 本身没有主动修改，也不能视为原文传递。应报告不兼容并停止。
