# 04 · 翻车诊断手册

> 读取时机：生成结果不满意时（反向诊断）
> 用法：用户描述生成视频的问题 → 按症状查下面对应的病灶 → 按处方修改提示词对应部分

---

## 诊断决策树

### A. 人物僵硬（像木偶·没活人感）

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **关节分解过多** | 搜"重心移至/腰腹带动/肩随后/头最后/依次带动"——打斗段出现即中 | 删分解，改导演指令：动作一句（结果级动词）+结果分解≥2句。模型从"执行清单"回到"演打斗" |
| **细节否定堆砌** | 叙事正文否定句堆砌（"没有睁大眼没有屏息没有皱眉/不早不晚"类） | 删堆砌：只保留画面状态类否定（不动/不居中/不是X），其余改正面不变量（v4：否定句是画面状态指令，但堆砌仍是病灶） |
| 表演锁定锁全身 | 全文搜"零反应""零情绪""does not flinch""完全静止"等关键词——是否用于角色身体 | 改为「锁表情不锁身体」：写身体的最小反应（脚尖微调/手指收紧/头偏一下→旋即收回）+表情克制 |
| 微动作通道不足 | 角色入镜段是否≥2个微动作通道（呼吸/重心/手指/视线/布料） | 增加通道，至少写到3个。静止镜头可以不写大动作但必须有2-3个微动元素 |
| 缺无用动作 | 角色是否每一个动作都有明确用途 | 加1处生活化小动作（拈衣袖/整衣摆/调呼吸/看手中物）或1处下意识反应（被吓到时手不自觉收紧） |
| 克制型幅度不可见 | MS以上景别写"脚下错半步/偏一偏头"级微反应 | 按景别-幅度对照放大：错半步→横错一整步；偏头→肩线级转开（ref01/六） |

### B. 动作假（物理不对劲）

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **攻防时序倒挂** | 攻击方"停稳"是否写在防御方"反应"之前 | 改为：攻击势头未收时防御已启动→攻方落空→攻方因势冲过头 |
| **次级物体多阶段** | 脱手武器是否写了"旋转N圈/弹起后平落"级联 | 一句话写完：脱手+落点+结果 |
| **力学解释句** | 搜"因/由于…产生惯性/重心/力矩" | 删解释留可见结果；动作链之间改用惯性焊接句（技法13） |
| **近身穿模** | 武器擦身/肢体相触无接触白名单 | 重申单块加：(只接触X不接触Y，保持可见间隙) |
| 缺受力反馈 | 被击/被缠后一方是否无反应 | 补：被击方产生可见物理位移（手臂被扯动/身体被带歪/惯性前冲） |
| 缺环境反馈 | 动作是否在空中完成不沾地 | 补：蹬踏/落地/碰撞留下的环境痕迹（水花/扬尘/碎石/布料扰动） |
| 附属物无延迟 | 衣料/头发是否与身体同步到位 | 补：布料/头发在动作完成后滞后半拍到位 |

### C. 动作慢（没节奏·不够快）

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **事件超载** | 每子镜头动作事件>2个（打斗段） | HARD CUT切分；每镜≤2事件。模型超载的标准行为是均匀放慢一切 |
| **无节奏括号** | 打斗/动作段是否缺（动作快速）类括号标注 | 动作句后嵌节奏括号；入口行补节奏定性词 |
| **slow传染** | 入口含slow时首个动作句是否无速度词对冲 | 首个动作句以（动作快速）或L4速度词开头（slow隔离规则） |
| 无变速对比 | 全段只有一种速度 | 在全段中插入一次"子弹时间→加速回正"变速 |
| 慢镜头缺细节 | 慢镜头只有"缓慢地X"没有微细节 | 慢镜头期间写 ≥3 个微动元素（水珠甩落/衣料褶变/发丝飘动/光斑移动） |

### D. 没打击感（打中像没打）

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **首触帧动词是过程级** | 搜"触及/碰到/接触/打（单字）" | 升结果级：触及→缠死/扣住/命中；打→打飞/干飞/拍飞（ref03动词表） |
| **结果没分解** | 命中后是否只有一句话没有后果 | 结果分解≥2句：命中部位崩坏/飞溅/瘫软/环境痕迹/镜头反应 |
| **连续打击同方式同部位** | 两次以上打击是否命中同部位同方式 | 部位与方式逐次不同（胸→头→腹；穿过→惯性转向→反杀），惯性焊接句衔接 |
| 缺三要素 | 每个打击是否有 结果动词+"拟声词"+（镜头猛地一震） | 三要素自然嵌入（ref01/四），"同时炸开"可选 |
| 攻击方轨迹不完整 | 攻击是否"突然出现"而非"来→攻→去"完整轨迹 | 补攻击方的来势方向、速度定性、轨迹描述 |
| 被打方反应太弱 | "被带了一下" / 无位移 / 无姿态崩坏 | 补：被打方位移距离+姿态崩坏程度+护甲/武器震动 |

### E. 画面崩/身份不一致

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **颜色/比例/部位错乱** | 生成结果与设定不符（X是暗红不是银蓝/比例反了/火焰位置错） | 写进项目《翻车修正库》（见下方双写格式）+重申单块，重生成 |
| **同框比例失控** | 多主体同框大小关系错 | 重申单块写现实参照物+相对比例（X只到Y腰部/高近一头） |
| @引用缺关键特征 | 角色/道具@引用是否有足够的视觉特征 | 补：年龄/发型/服装颜色+材质/关键配饰+功能句 |
| 参考图与文字打架 | 参考图姿态与剧本姿态冲突 | @引用范围限定：「仅锚X质感，姿态以本段文字为准」 |
| 多个角色共用同一参考 | 不同角色是否引用了同一张图 | 确保每人独立hash |
| 表演锁定与动作矛盾 | 角色说"冷静"但动作写"颤抖" | 统一表演锁定与动作描述 |

### F. 画面像PPT/壁纸（静图感）

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **全镜无状态改变** | 起幅帧与落幅帧"找不同"——找不出即中 | 五类补1个（运镜漂移/光影事件/元素状态/主体事件/视线牵引），优先光影事件（不改剧本气质） |
| **运镜低于感知阈** | 搜"不可察觉/barely perceptible/imperceptible" | 二选一重写：完全固定+动元素承载 或 补起幅→落幅构图可辨差异 |
| **小人物无动元素** | 人物<10%画面且无环境动元素声明 | 景别联动：环境动元素≥2+动静对比声明（"X是画面中唯一持续运动的元素，与Y的静止形成对比"） |
| **连续纯空镜** | 相邻≥2镜均无人物无事件 | 中间镜压至≤3s作过场，或补状态改变；纯空镜不得连续2镜 |
| **全片时长匀速** | 全部镜头同一时长（如全4s） | 按配比重排：快切1-2s+常态2-3s+重场5-7s，至少一对长短反差 |

### G. 音频平/没沉浸感（音画两张皮）

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **音轨行罗列式** | 音轨行只有"声源1+声源2"无起幅/收幅 | 时序三段式重写（起幅→事件叠入→收幅）；静态段至少补收幅声明（ref08/四） |
| **音效不绑事件** | 音效与画面事件不在同一句/同一节点 | "随X推进叠入Y"句式改写；打击/转折点音效与画面同帧 |
| **全程无留白** | "持续"出现≥3次且无"归于寂静/突静/余韵" | 收幅补衰减或留白；情绪重场加主观听觉（"周遭声响骤然抽空，只余X与呼吸"） |
| **旁白无节点** | 旁白只有"持续"无断句/同步点=有声读物 | 断句落点+与画面事件同帧（"X二字与Y事件同帧"）；尾句后留白余韵 |
| **空间感缺失** | 全干声无混响体感 | 补体感词（悠远的空间回响/峡谷回声缓慢消散），禁技术参数（杜比/混响X秒/音量X%） |

### H. 科幻机甲POV视角混乱

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **POV切换无声明** | 第一视角POV与第三视角跟拍混用无明确切换标记 | POV切换声明一行："POV高速跟拍镜头，摄影机如同一个独立的小型飞行器，紧贴在机甲身后" / "第三视角快速跟拍" |
| **尺度对比缺失** | 机甲与人体/建筑同框时无相对尺度声明 | 尺度对比硬声明一行："凛翼约8米，炽翎约6.5米，同框时凛翼高出近一头" |
| **反应式运镜句乱用** | L3级文戏段出现"剧烈晃动/失焦又恢复"类L4-L5运镜 | 反应式运镜句仅L4-L5可用（ref01/一·相机五级制检查） |
| **机械细节缺失** | 机甲表面只有颜色无材质/磨损/结构细节 | 补：粗粝哑光金属/沙蚀划痕/液压作动筒/铆接节点/冷凝水珠——完整材质链 |

### I. I2V材质/手部崩坏

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **材质变CG塑料** | 生成结果丢失原图琉璃/金属/流体质感，变成光滑塑料 | 补流体材质反光锁："通透[材质]流体质感，遍布柔和[光斑]，流体飘舞效果全程持续不会消失"（墨染少女式） |
| **手部崩坏** | 手指粘连/多指/少指/糊团/穿模 | 手部强制硬性约束独立模块："五指结构完整清晰分明，全程五根手指独立舒展，无多指/少指/断指/粘连/扭曲/糊团/穿模/反折变形" |
| **流体动态中断** | 长发/衣袍/粒子流动中途停止或消失 | 硬性全局约束重建："[元素]流体动态完全贴合物理规律，全程持续[动作]，永久不会消散消失" |
| **编排型动作卡顿** | 舞蹈/武术套路动作不连贯，节奏断裂 | 编排型秒级打点重写（0s起势→0.8s开势→2s主体→3.4s变化→4.3s收势定格，ref07/模块⑤） |

### J. 历史正剧血腥越界

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **血腥画面越界** | 战争/刑场/灾难段出现鲜血/断肢/直接杀戮画面（Seedance 会生成） | 题材安全边界补声明："壮烈不血腥：以刀光、剪影、水花、火星暗示，绝不出现鲜血、断肢或杀戮特写"——写入[STYLE LOCK]场景行末尾+文字负面声明 |
| **素材危险** | 死囚/押解/屠城等题材无安全边界，可能触发内容审核 | 每场独立重申；文字负面声明逐场确认含"鲜血/断肢/直接杀戮特写" |

### K. 群像双胞胎

| 病灶 | 检查点 | 处方 |
|:----|:------|:----|
| **群演长相雷同** | 人群/士兵/学生/路人所有面孔一样（Seedance 高频翻车） |  @引用行追加："每个人外貌五官都不一样，禁止出现双胞胎" |
| **服装千篇一律** | 群像服装完全一致 | @引用行追加：服装从参考图随机抽取组合+体型/肤色/年龄差异性声明 |
| **兽群/虫群动作同步** | 怪兽/动物/虫群所有个体动作一模一样 | 动作参差声明："各自/不齐整/此起彼伏/无一同步" | |

## 快速自检卡（用户自查用）

```
❏ 人物僵硬？ → 查关节分解违禁短语/正文零否定/微动作通道/克制型幅度
❏ 动作假？ → 查攻防时序/次级物体一句话/力学解释句/接触白名单/受力反馈
❏ 动作慢？ → 查事件数≤2/节奏括号/slow隔离/变速对比
❏ 没打击感？ → 查首触帧动词级别/结果分解≥2句/三要素/部位方式不重样
❏ 脸崩？ → 查@引用特征/范围限定/重申单块/项目《翻车修正库》
❏ 画面像PPT？ → 查状态改变/运镜量级二选一/动元素+动静对比/连续纯空镜/时长匀速/画面驱动4原则（每句有可见变化？）
❏ 音频平？ → 查音轨三段式/音效绑事件/收幅留白/旁白同步节点/空间体感词
❏ 科幻POV乱？ → 查POV切换声明/尺度对比硬声明/反应式运镜句层级/机械材质细节
❏ I2V材质崩？ → 查流体材质反光锁/手部强制约束/硬性全局约束/编排秒级打点
❏ 历史越界？ → 查题材安全/文字负面声明/壮烈不血腥重申
❏ 群像双胞胎？ → 查禁止双胞胎/@引用行差异性声明/服装随机抽取
```

## 修正沉淀双写（所有处方通用·红线）

每次按处方改完提示词后，修正条目必须**双写**：

```
① 写入本段【重申单块】+项目《翻车修正库》——格式：「对象+必须/禁+精确状态」
   ✅ 炽翎是暗红色，不是银蓝色
   ✅ 蓝色火焰只在翼尖和脚底喷射，背部没有主引擎喷口
   ✅ 扫描状态播报由电脑合成语音完成，不是芮晨的声音
   ✅ 凛翼比炽翎高近一头，同框时凛翼只到对方腰部
② 追加到项目《翻车修正库》（项目根目录翻车修正库.md，
   按 角色/场景/道具/声音/比例 分类记录）
```

之后本项目每生成新段，步骤3c读取《翻车修正库》相关条目，自动并入新段修正层。
**原则**：否定句从一次性消耗品变成可积累的项目资产——每一代提示词都站在上一次翻车上。
