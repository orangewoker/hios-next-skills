# 镜头、色彩、剪辑与声音语言

## 1. 先写镜头功能

为每个镜头先选一个主要功能，必要时再选一个次要功能：

- 建立空间与尺度；
- 暴露或隐藏信息；
- 贴近人物感知；
- 显示权力关系；
- 连接不同时间层；
- 重复或改变视觉母题；
- 加速、延迟或中断行动。

若无法说明功能，合并或删除镜头。

## 2. 景别与构图

| 选择 | 常见叙事作用 | 使用提醒 |
|---|---|---|
| 极远景/大全景 | 人物被空间、制度或时间压缩 | 保留清晰尺度参照物 |
| 中远景 | 展示身体、阻隔和空间因果 | 让动作在同一镜头内成立 |
| 中近景 | 平衡信息与表演 | 避免所有对白都用同一景别 |
| 特写/大特写 | 捕捉决定、证据或主观断裂 | 留到信息价值最高的时刻 |
| 中心/对称构图 | 秩序、控制、仪式感 | 用轻微破坏预示失控 |
| 框中框/遮挡 | 监视、隔绝、信息受限 | 确保遮挡有空间动机 |
| 负空间 | 缺席、等待、不可见威胁 | 让视线和声音激活空白区域 |

## 3. 摄影机与焦段

优先使用稳定、可读的空间摄影；把手持、急摇和极端畸变留给主观失稳。

- 18–28mm：强调建筑、尺度和空间关系；靠近人物时会产生压力。
- 35–50mm：保持自然透视，适合行动和克制表演。
- 65–100mm：压缩层次、隔离人物、制造观察感。
- 微距：让机械细节、时间标记或物证成为叙事事件。

为运镜写出起点、终点、速度、触发动作和叙事目的。不要只写“电影感推镜”。

## 4. 时间层视觉编码

每条时间线只改变两到三项，避免像滤镜演示：

- 构图：稳定中心 / 偏心受阻；
- 运动：轨道与摇臂 / 肩扛与呼吸感；
- 焦段：广角空间 / 长焦隔离；
- 色温：冷环境暖肤色 / 暖环境冷阴影；
- 质感：清晰低颗粒 / 柔和高颗粒；
- 声音：完整环境声 / 主观低通或高频缺失。

在时间线汇合时逐渐交换或融合编码，让形式预告因果交汇。

## 5. 色彩与光线

为项目建立色彩脚本，而不是给全片套一种色调：

1. 指定主色、辅色和低占比点缀色；
2. 为每个颜色写叙事含义和出现条件；
3. 随人物弧光改变饱和度、色温或对比度；
4. 保持肤色与关键道具可辨识；
5. 用现场可解释的光源建立方向：窗、顶灯、路灯、火焰、屏幕。

推荐基线：低至中等饱和、受控高光、深但保留细节的黑位、材质分明。避免把“冷峻”误写成全片青橙或压死阴影。

## 6. 剪辑结构

- 用动作匹配连接不同时间或地点。
- 用 J-cut 提前引入下一时空，用 L-cut 让上一时空残留。
- 让交叉剪辑线拥有不同但可比较的倒计时。
- 在高潮逐步缩短镜头，但在关键选择前留出一个更长镜头。
- 用省略制造推理空间，不要省略关键因果。
- 用重复镜头改变上下文，而不是原样重复。

## 7. 声音与音乐

建立四层声音：环境、动作、主观感知、音乐/节律。为每条时间线定义一个可变形的声音母题。

使用机械节律、呼吸、远处低频或规律环境声建立时间压力，但避免直接复制任何现有配乐主题。让静默承担信息：在揭示前移除预期声音，或在主观断裂时改变频段与空间混响。

## 8. 镜头分析格式

分析现有素材时按“观察 → 功能 → 效果 → 可迁移原则”写：

> 观察：低机位广角保持人物与建筑同框。  
> 功能：把制度空间塑造成对人物的压力。  
> 效果：观众先感到尺度失衡，再理解人物处境。  
> 可迁移原则：用空间比例表达权力，不复制原场景构图。

区分画面中能确认的事实与对创作意图的推断。不要把所有形式特征归因于某位导演。
