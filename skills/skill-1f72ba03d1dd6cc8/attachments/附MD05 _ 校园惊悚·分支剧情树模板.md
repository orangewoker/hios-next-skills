# 附MD05 | 校园惊悚·分支剧情树模板

**所属主SKILL：** 校园惊悚 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·大门被锁死（start节点）
2. N02 抉择点1·听到走廊有脚步声（branch节点）
   - N02A 躲进储物柜（安全，但错过线索）
   - N02B 去查看情况（遭遇怪物，理智下降）
3. N03 发现异常的报告厅（normal节点）
4. N04 抉择点2·同伴被机关困住（branch节点）
   - N04A 冒险救同伴（同伴信任大增，面临危险）
   - N04B 自己逃跑（理智值下降，后续被孤立）
5. N05-N08 层层推进（如：寻找总闸、解密校长室）
6. ENDING_CHECK 结局判定
