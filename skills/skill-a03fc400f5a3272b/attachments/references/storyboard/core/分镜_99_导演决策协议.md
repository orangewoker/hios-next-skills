# 导演决策协议 · v3.7

> **核心原则**：AI 不导演，AI 执行协议。协议承载导演知识。
> **定位**：Phase 2 前置决策引擎。阻断级——未完成全部决策 = 不得进入 Module 3/4 输出。
> ⚠️ D5.2 构图策略的选取结果以 `pipeline.md` §0.3 锁定表 B 表为权威；D1.7 视觉多样性检查以锁定表自检结果为准。

## 0. 协议使用说明

### 0.1 执行姿势

1. 通读协议全文，建立导演"肌肉记忆"
2. 读取本段剧本原文，让画面自然涌现
3. 对照 Layer 2 逐条决策——适用则执行，不适用则跳过
4. 每条决策必须引用剧本原文具体内容作为理由——禁止"打斗所以选密集蒙太奇"等去内容化答案
5. 每个画格只承担一个视觉主任务。辅助元素降级为最小可辨识轮廓。禁止一个画格 ≥ 3 个等权重视觉任务（与 D5.2 联动）
6. **禁止**：把本协议当成 D1.1→D1.2→D2.1 的线性清单依次执行

### 0.2 决策项格式

> D{X}.{N}：[决策领域]
>   [触发条件]：[条件]  [决策指令]：[AI 必须做出的选择]
>   路径 1：[策略] — 条件：[...]  路径 2：[策略] — 条件：[...]

### P6：开场钩子锚定（零铺垫版）

> 0-3s 必须是身体关系叙事或动作中间瞬间。三类铺垫全禁：场景空镜 / 角色定位 / 因果前置。

AI 必须填写以下字段并引用剧本原文：

> 开场类型={身体关系叙事/动作中间瞬间} — 引自 分镜_05 §2.1
> 钩子类型={强冲突/强危机/强福利/强反差} — 引自 分镜_05 §2.3
> 钩子画面={0-3s 冲突切入画面——非"建立空间"}
> 情绪强度={7-10}/10
> 人物关系呈现={权力差/距离/视线/朝向}
> 情绪冲突锚点={开场情绪对抗核心}
> 剧本依据：{引用支撑钩子的剧本描述}
> 
> D1.1 约束：开场镜必须直接呈现上述冲突切入画面。三类铺垫全段全禁：
>   ① 场景空镜 ② 角色定位 ③ 因果前置 → 任何可辨认为"铺垫"的视觉内容 = 阻断

**阻断**：钩子画面为"建立空间""展示场景"等非冲突切入 / 情绪强度 < 7 / 钩子类型为空或为"无""不适用""自然开场" / 出现三类铺垫内容任一 / D1.1 约束未遵守

**P6 自检（E5 输出前必做）**：

> Q1: 0-3s 内未看过剧本的观众能否一句话说出"谁和谁、什么关系、情绪对抗还是靠近"？
> Q2: 0-3s 画面是否包含：身体冲突/接触、身份揭露/认知颠覆、生存威胁、情绪爆发（至少其一）？
> Q3: 0-3s 是否零铺垫？（无场景空镜/角色定位/因果前置 → 有一项 = 阻断）
> Q4: 开场镜景别 ≤ L3 近景？（首段 S1A 开场镜 = L1/L2 → 阻断）
> Q5: 开场镜为运动镜头？（首段 S1A 开场镜 = 固定镜头 → 阻断）
> Q6: 0-3s 有至少一个声音冲击点？（无雷劈/门撞/金属坠地/尖叫/台词爆破 → 阻断）

## Layer 2：决策项

> 每条决策必须引用剧本原文具体内容。

### D1：镜头决策（7 项）

#### D1.1：开场镜景别 · 每段必决策

从六条路径选一，引用剧本原文为理由。

**路径 A — 压迫/吞噬**：核心情绪=恐惧/渺小/被控制 → 开场镜=L0 大远景 或 L5 极特写。禁止中景/近景。
**路径 B — 接缝入场**：承接上段未解信息 → 开场镜=上段尾镜同一主体延续。禁止重新建立空间。
**路径 C — 断裂入场**：情绪强烈反差 → 开场镜景别至少跳 2 档+不同角度+运动。禁止渐变。
**路径 D — 渐进入场**：平稳推进 → 开场镜=上段尾镜景别±1 档。禁止跳极端景别。
**路径 E — 悬念/延宕**：策略="不给答案" → 插入镜头拖延 2-3s 后再切入主体。
**路径 F — 钩子开场**：P6 已确定钩子。**所有 S1A 必须走此路径**；非首段情绪 ≥8 也须走。景别 L4/L5 或 L0；运动必须带急推/急降/甩镜/快摇；0-3s 须有声音冲击点（D5.6）。禁止 L1/L2/L3、固定镜头。与 D/E 互斥，可与 A/C 叠加。S1A 选 F 外任何路径 = 阻断。

**例外**：全集第一个片段 → B/C 不适用。打斗最高潮前段已在打斗 → 可跳过 A 直接 L4/L5。
**自检**：开场镜和上段尾镜能否互换？→ 能=失败。理由出现"自然过渡""常规开场""建立空间"→ 失败。

#### D1.2：收束镜决策 · 每段必决策

**路径 A — 悬念钩子**：尾镜展示观众知角色不知的信息（L4/L5 特写）。
**路径 B — 情绪沉淀**：尾镜用空镜收束，不给叙事信息。
**路径 C — 动作断裂**：在动作中间帧切断——不完成不解释不给结果。
**路径 D — 意象落点**：收在重复视觉意象上，形成记忆铆钉。

**例外**：无。每段必选且写理由。
**自检**：尾镜画面能用其他段尾镜替换？→ 能=失败。

#### D1.3：镜头数量决策 · 每段必决策

镜头数由五个维度交叉决定，不查表：

- **维度 1 时间感知**：飞逝=8+镜/0.5-2s · 停滞=1-3镜/4-12s · 正常=4-7镜/2-4s
- **维度 2 信息密度**：5+独立信息→5+镜 · 1-2核心信息→1-2长镜
- **维度 3 身体动作**：有激烈动作→短镜(0.5-1.5s)推高镜头数 · 否→可持续更久
- **维度 4 台词负载**：0-15字=不显著影响 · 16-35字=镜头数+1~2 · 36-55字=对话对切每2-3s一切(5-7镜)、独白+反应每4-5s一切(3-4镜) · 56+字=超载阻断
- **维度 5 因果步骤**：1-3步骤→3-5画格 · 4-6步骤→6-9画格 · 7+步骤→10-15画格。画格数={N}，镜头数由故事线覆盖规则决定

**画格→故事线**：Module 4 按画格顺序推进，连续因果画格可用一个描述句覆盖。约束：画格覆盖率=100%、不新增/跳过/重排、Tn 编号不暴露。

**例外**：碎片化蒙太奇→允许 15+ 镜。
**自检**：时间感知目标理由引用剧本原文 / 列出每个信息节点 / 相邻段镜数相同+动作不同=失败 / 画格覆盖率=100% / 三项画格约束全满足

**跨段节奏差异化（阻断）**：任意两段动作类型不同→镜数差≥2 / 全集同属 {4,5} 窄区间→阻断 / 标准差<2.0、最长最短<2.5倍的段≥50%→阻断 / 全段情绪最高峰→镜数取极端值 / 动作→飞逝(8+)、对峙高潮→飞逝或停滞、独白→优先停滞，"正常"段≤3

**首段 S1A 例外**：动作类型由 P6a 优先清单映射，禁止低冲突分类。

#### D1.4：关键镜决策 · 每段必决策

读完剧本后自问："如果只能记住一个画面，是什么？"
- 标记：L4/L5 特写（信息放大）或 L0 大远景（规模震撼）。禁止 L2/L3
- 位置：中段(7-10s) / 开场(0-3s) / 收束(13-15s)
- **S1A 硬约束**：必须 0-3s，必须是 P6 钩子画面呈现。禁止中段或收束

**例外**：全段 1-2 镜→无独立关键镜，须声明理由。
**自检**：画面只能用在这一段？换到其他段=失败 / 删掉关键镜本段还有存在必要？→没=有效

#### D1.5：视点策略 · 每段必决策

- **A 客观全知**：观众看到角色看不到的。角色可能不在场、俯视、信息不对称。
- **B 跟随**（第三人称有限）：视野跟随一个角色，不进入主观。该角色始终在场。
- **C POV**（第一人称）：观众用角色眼睛看。角色不出镜，摄像机模拟头部/眼球运动。
- **D 混合视点**：段内切换，必须在镜头边界处。

**例外**：无。必选。**自检**：删掉视点声明镜头设计不变？→ 一样=失败。

#### D1.6：角度策略 · 每段必决策

- **A 平视**：观众与角色平等。对话/对峙/日常。
- **B 俯视**：角色渺小/脆弱/被审视。压迫感/角色无力/全知视角。
- **C 仰视**：角色强大/威胁/权威。权力关系/反派登场/英雄时刻。
- **D 倾斜（Dutch angle）**：世界不对劲。心理失衡/危险逼近。全段 ≤2 镜。

**例外**：对峙段允许单一角度。其他须 ≥2 种。
**自检**：角度是否服务权力关系？有明确权力不对等则必须体现。

### D1.7：视觉多样性约束（阻断级）· 每段必决策

完成 D1.1-D1.6 后逐项自检四维：

- **运镜变化 ≥2 种**：禁止全程固定位/同种运镜重复 ≥3 镜
- **景别跨度 ≥3 档**：须含至少 1 个极值景别(L5/L0)。禁止全程中景正反打
- **角度变化 ≥2 种**：平视连续 ≤2 镜。禁止全程平视
- **构图变化 ≥2 种**：禁止全程主体居中对称

**爆点同步**：冲突爆点处须同步触发运镜急推/甩镜+景别跳变≥2档+角度倾斜+构图破坏。

**阻断**：任一维度不达标 / 冲突爆点镜头语言无剧变。

### D2：节奏与呼吸（5 项）

#### D2.1：节奏曲线设计 · 每段必决策

画出 0s→3s→7s→12s→15s 强度曲线（1=平静→10=极度紧张）。
约束：必须有一个强度变化（变化幅度 ≥2）/ 最高点=关键镜位置 / 最低点=呼吸空镜或情绪沉淀位置。

**例外**：蒙太奇→允许跳跃 · 极限紧绷→允许全程高强度须声明。
**自检**：最高最低差 ≥3？/ 曲线与相邻段形成对比？

#### D2.2：呼吸点决策 · 每段必决策

**必须插入空镜**：高情绪释放后(1-2s C类) / 连续 3 镜高强度(0.5-1s B类) / 收束镜路径 B。
**不需要**：全段 ≤3 镜 / 全程绷紧 / 冲突爆点段。

**例外**：全程绷紧可零呼吸，须声明意图。
**自检**：空镜画面与剧情有明确关联？→ 无关的漂亮雨滴=失败。

#### D2.3：单镜时长差异化 · 镜头数 ≥4 触发

最长镜 ≥ 最短镜的 2.5 倍。均匀时长=节拍器=观众预判切镜=失去悬念。台词长镜(≥4s)由 D2.5 决定，不视为"节奏拖沓"。

**例外**：蒙太奇(10+镜)→允许短镜均匀但须有长镜锚点 · 台词长镜→允许超典型时长。
**自检**：最长/最短 ≥ 2.5？台词是差异化合法理由。

#### D2.4：运动强度段内变化 · 每段必决策

标尺：0.1-0.3 定格/呼吸 · 0.3-0.5 微动作 · 0.5-0.7 常规 · 0.7-0.9 快速 · 0.9-1.0 极限。
要求：|起始-结束| ≥ 0.15。方向：递增=升温、递减=释放、V形=高潮回落。

**例外**：无。强度不变=机器人切镜。**自检**：变化方向匹配 D2.1 情绪曲线？

#### D2.5：台词时长约束 · 含台词时触发

**步骤 1** 判定节奏：独白≈3.3字/s · 日常≈3.7字/s · 争吵≈4.3字/s（引用剧本原文）。
**步骤 2** 总占用=字数÷速率。≤15s，超出=阻断。
**步骤 3** 纯画面=15s-台词-呼吸空镜。<0=阻断、0=台词驱动、>0=余秒用于无声画面。
**步骤 4** 逐句校验：短句(3-8字)镜≥1.5s · 正常句(8-18字)镜≥3s · 长句(20-30字)镜≥6s。字数÷覆盖秒数 ≤4.3。
**步骤 5** 跨镜铁律三条：①台词覆盖总时长≥字数/速率 ②切反应镜时声音连续 ③切点在句间停顿处（，。！？……、；），不可词中间。

**例外**：蒙太奇→短台词(≤8字)不受③约束 · 声音桥转场→连续性向上一段延伸。
**自检**：总秒数≤15s？/ 单镜字数>镜长×4.3=装不下 / 切点在句间停顿？/ 反应镜中声音连续？

### D6：跨镜连续性（9 项）

> D6 整合跨镜约束为逐项必过决策域。**前置知识（阻断）**：执行 D6 前须完成知识预载（`pipeline.md` §8.1、`_routing.yaml` phase_2）。核心地基：`分镜_02_导演逻辑.md`。
> **触发**：D6.1-6.9 每条必决策（镜数≥2）。单镜段跳过。

#### D6.1：180° 轴线锁定 · ≥2 镜且含双人对视/对话/对峙

**步骤 1** 确定轴线：穿越对视角色鼻尖画假想线，所有镜头摄影机须在同一侧。
**步骤 2** 逐镜标注 A侧/B侧。
**步骤 3** 越轴检测：相邻镜分布在轴线两侧→越轴。修复：插入中性镜头/画入角色转向动作/重排镜头顺序。
**步骤 4** 标记锚定镜：景别≥L2、前 30% 位置、后续双人镜头左右以它为基准。

**例外**：纯主观 POV→跳过 / 打斗(运动≥0.7)→撞击/落地/爆炸点可越轴 / 单镜→跳过。
**自检**：双人镜头摄影机始终同侧？/ 锚定镜在前 30%？/ Shot N 和 N+1 人物左右位置互换叙事不变=轴线不成立。

#### D6.2：道具状态链 · 有被操作/移动/状态变化的道具

**步骤 1** 识别关键道具：会被触碰/拿起/放下/传递/使用的。
**步骤 2** 逐镜标注：位置/朝向/持有者/可见性。
**步骤 3** 状态跳跃：相邻镜状态变化→须有过渡镜覆盖。无=阻断。
**步骤 4** 动作链完整：道具 A→B 全部动作步骤须在亮场镜头中覆盖。缺失=断裂。约束：每次状态变化须有"接触时刻"镜(≥L4 特写)。

**例外**：口袋内未取出→恒定 / 非关键背景道具→不追踪 / 全程状态不变→自动通过。
**自检**：状态链完整？有接触时刻特写？无瞬移？

#### D6.3：关键道具出场序列 · 有叙事功能道具时触发

叙事高光镜 Shot N → 须在 Shot K(k<n) 中有至少 1 个预展镜。预展不揭示叙事功能。约束：预展到高光至少间隔 1 镜、预展不得 L5 极特写(建议 L2-L3)。

**例外**：道具本身是惊喜核心→故意不预展须声明理由 / 0-2s 建立镜中自然出现=已预展。
**自检**：每个叙事道具在 Shot 1 到高光镜间有 ≥1 个非 L5 预展镜？

#### D6.4：环境-行为因果链 · 有明确天气/时间/环境设定时触发

逐镜对照：1. 天气→角色外观（雨→湿发/湿衣/雨具，缺=阻断；雪→积雪/呼气白雾；夜→光比差异）2. 天气→角色行为（雨→收伞/抖水；雨→撑伞/快步；夜→开灯/摸黑）3. 环境元素→空间逻辑（伞桶须有使用/绕过镜头；自动门/铃须触发）4. 天气连续性（同场景同段雨量/风量/光量一致）。

**例外**：超自然角色→不受物理约束 (须标明) / 剧本写"浑然不觉"→故意 / 室内无窗→不受直接天气影响。
**自检**：一眼看出"他从雨中来"？功能性道具都被使用？天气一致？

#### D6.5：情绪过渡镜强制 · 角色情绪相邻镜显著变化时触发

标注情绪状态(1-10+方向) → 检测方向翻转或强度跳跃≥4 → 须有过渡镜(≥L4 特写, ≥0.5s)承载"变化过程"。约束：过渡镜须展示"正在变"、与触发事件同步。

**例外**：跳变是叙事卖点→故意不设须声明 / 本段≤3镜→允许但须声明。
**自检**：能画出情绪变化曲线？跳变点前后有功能差异？

#### D6.6：空间锚点一致性 · 同场景≥2 镜

**步骤 1** 提取锚点：入口/功能区/货架/隔断/柱子/窗户方位。
**步骤 2** 逐镜标注：摄影机朝向/可见锚点/方位关系。
**步骤 3** 一致性检查：入口同侧/同方向、核心物体比例匹配、背景布局与俯视图一致。摄影机翻转→画面位置反转合法，但锚点相对方位不变。违者=空间混乱。
**步骤 4** 构图锚点锁定："{锚点名}→画框{方位}"。漂移检测（方位/比例/存在/布局，任一=阻断）。远景建立镜声明为"同一空间·更远距离"。

**例外**：单镜→不适用 / 抽象/梦境空间→允许非欧（须声明）。
**自检**：俯视图贴到每镜上方→方位对得上？入口位置唯一？构图锚点跨镜一致？远景镜声明"同一地点"？背景没被"重新设计"？

#### D6.7：调度俯视图→画格一致性 · 每段必决策

俯视图标注与画格 Tn 逐项对应：入口方位 / 人物站位 / 动线与动作对应（箭头路径→至少 1 画格视觉呈现）/ 功能区标签同术语 / 道具位置一致。

**例外**：无。俯视图=空间真理，矛盾=逻辑崩溃。
**自检**：俯视图标注的道具在所有画格中位置一致？

#### D6.8：镜头因果链完整性 · ≥2 镜必决策（构思时执行）

**步骤 0 因果锚点**（Shot N≥2 前必做）：上一镜 {具体画面元素} 导致了本镜 {具体画面元素} / 视线从 {区域} 移到 {区域} / 可视证据是什么？无回答=不得构思。禁止"自然过渡"。

**步骤 1** 逐对标注因果模式：A 动作→反应 / B 建立→推进 / C 原因→结果 / D 收紧聚焦。
**步骤 2** 断裂检测（任一=阻断）：
- a) 位置跳变：角色场所 A→B，无过渡镜→须插移动镜
- b) 无因果并置：A 独立动作→B 独立动作，无视线/动作连接→须插反应镜
- c) 因果缺失：事前最后一帧→事后物理证据，无过程/反应镜→须插至少 1 镜。禁止以"导演意图""惊吓"为由省略
  - **S1A 例外**：Shot 1 为"第一因"，不受前镜约束。Shot 1→2 允许钩子冲击→反应/展开。检测从 Shot 2→3 生效。钩子"惊吓"即合法因果（P6a）
- d) 景别跳变无因果见 D6.9
- e) 因果锚点字段缺失→阻断

**步骤 3** 角色移动连续性：相邻镜空间位置不同且距离 ≥2 步→须有移动过渡镜。同功能区小范围可一镜完成 / 跨功能区须移动镜 / 跨场景须过渡镜(推门/跨门槛/步入)。

**例外**：单镜/蒙太奇(10+镜、须有统一主题)/闪回/闪前/梦境（须声明跳变理由）。
**自检**：逐对满足四模式之一？删除任一镜相邻能连=该镜可能冗余。角色位置改变有过渡镜？

#### D6.9：景别渐进约束 · ≥2 镜必决策

**步骤 1** 逐对标注景别变化及跳变幅度。
**步骤 2** 跳变≥2档须有合法理由（≥1）：角色视线引导 / 动作物理结果 / 渐进收紧链 / 情绪冲击点 / 超自然因果拆解。无理由=阻断→插入过渡镜或补充理由。
**步骤 3** 序列形态：✓渐进收紧 ✓收紧→放开→再收紧 ✗随机跳变 ✗全段均匀。
