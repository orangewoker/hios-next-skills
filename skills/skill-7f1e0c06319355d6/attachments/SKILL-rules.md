## 全局禁止规则

> 本清单是**本 Skill 的硬约束集合**，散落在各步骤里的「不得 / 禁止 / 强制」在这里汇总成一份可速查的总表。任何一条违反，都视为该步骤未完成，须回退修正，不得带病推进。执行过程中若两条规则冲突，**以「不浪费积分、不糊弄老大、不碰老大核心资产」为最终裁决原则**。

### 一、流程与门禁类

1. **禁止混淆「创建节点」与「运行节点」的前置条件**：创建下游节点只要求上游 node_key 已存在（哪怕尚未出片）；只有**实际运行**才要求上游已生效。不得因「上游图没出」就暂停流程、或向用户索要「是否必须先生成图片才能继续」的确认。
2. 🔴 **搭建与生成是两条命令，默认只搭建、不跑生成（LibTV 官方口径，2026-10-06 查文档坐实）**：`libtv node create` / 连边（`--left` 等）/ 写参（`-s`/`-u`/`--prompt`）**只搭不跑、零积分**；「生成」必须**显式**触发——要么用户在网页画布手动点，要么 agent 加 `--run`。官方原文：「`libtv node create` —— **仅新建**……可配合 `--run` 新建后生成」；「仅改入边、不触发生成；要触发请加 `--run`」。**因此 agent 默认只做搭建，把节点与引用一次建完交给用户手动生成；除非用户明确说「帮我生成」，否则不碰** `--run`**、不主动询问「是否消耗积分生成节点」**（只搭不跑不扣费，无可确认项；只有用户要求跑生成时，才确认平台与数量、走逐波批准）。
3. **禁止静默跳过步骤5**：步骤5（资产与分镜表统一确认）在生成模式下强制执行；搭建模式下不适用但**必须在账本备注写明「搭建模式，步骤5 挂起」**，不得留空、不得静默跳过。
4. **禁止在阶段一四步未完成前发起任何图片生成**：任务初始化 → 角色出镜前置过滤 → 锚点集写入 → 任务状态更新，四步串行完成后才可发图。
5. **禁止未完成角色出镜前置过滤就生成三视图**：必须先列出「建图名单 / 不建图名单」，未完成不得发任何三视图调用。
6. **禁止不回读账本就断点续做**：会话中断、重新接手或用户说「继续」时，必须先回读三份工作文件（压缩稿、锚点清单、进度账本），从「未生效/未完成」环节继续，不重新划分、不重做已确认条目。

### 二、模板与口径类

1. **禁止凭印象复述模板**：三视图模板、两套故事板后缀模板、视频固定格式六段、负面框，**必须从** `image-prompt.md` **/** `video-prompt.md` **原文逐字复制**，不得转写、缩写专名（「柘黄」不得写「黄」、「halation」不得写「哈雷」）、不得凭记忆替代。
2. **禁止拼接后不回读比对**：prompt 拼完后必须回读，逐句核对模板段与原文一致、占位符只剩已替换的三处。
3. **禁止生图模型自行设计景别/运镜/排版**：景别与运镜一律由 agent 在分镜设计表中决定一次，故事板逐格照填，生图模型不得自行设计或更改。
4. **禁止自创景别运镜第三种叫法**：景别取值只限六档位表，运镜取值只限统一运镜词表（运动方向：`推/拉/摇/移/跟/升/降`，稳定性：`手持拍摄`），两侧同词同值。
5. **固定机位是正当选择，不搞一刀切禁用**：英文 `static shot / locked-off shot` 是标准机位，需要画面纹丝不动时（静止、凝视、屏息、庄重）可写「固定机位 / static shot」；本厂默认手持呼吸感，机位不位移时取「手持拍摄」。禁止的是**无动机的死机位**（当"静止画面"处理），不是**有意的固定机位**。不得把「手持拍摄」写成「跟拍」。
6. **禁止无动机地切到几乎相同的景别**：相邻硬切景别须**明显不同**（至少隔一档）；同景别不切、一镜到底；跨多档（如全景→特写）**只要有叙事动机（突转、强调、震惊）就是正当剪接，不是暴跳**。判定标准是「这一刀有没有叙事动机」，不是「隔了几档」。

### 三、资产与内容类

1. **禁止单独生成场景锚点图**：本 Skill 只有两类参考图——故事板图 + 角色板图；场景/道具/环境由故事板分镜格承载，不另出场景图、道具图、moodboard。
2. **禁止脱离故事板底本另编画面**：视频不得超出故事板已预演的画面范围另编新场景、新环境、新道具。
3. **禁止故事板图上出现画面文字**：台词、字幕、对话气泡、描述性文字一律不得出现在故事板图上（视频侧 `人物说：{台词}` 承载音频口型，两者不冲突）。
4. **禁止台词删改**：台词逐字保留原文、不翻译、不改写、不节选；内心独白/旁白用 `内心独白（画外音，不开口）：{内容}`，不得写成 `人物说：{}`。🔴 **边界（与第零阶段改剧本衔接）**：本条禁的是「**生成视频时**对定稿台词动手」；第零阶段改剧本属于**定稿之前**的创作，两者时序不同、不冲突——**先改（第零阶段）后禁（阶段二之后照稿不改）**。
5. **禁止臆造角色外貌**：只写画面可见特征；剧本未写的外貌特征按「剧本原文 &gt; 史料/画像记载 &gt; 不写」优先级，不得凭空编造、不得千篇一律套默认词。
6. **禁止违反儿童安全约束**：涉及未成年角色，禁止「未成年数字年龄 + 身体围度 + 暴露服装」同时出现，年龄用学龄气质词。

### 四、时长与切分类

1. **禁止用节奏/分镜秒数改动总时长**：`duration_sec` 唯一由「该条台词总字数 ÷ 5」决定，必传；每镜秒数只是总时长内部分配。
2. **禁止按文档幕/场/章/段落切分视频**：一律以 75 字为上限按台词字数切分，以自然语义为边界。
3. **禁止单条低于 30 字不合并**：过碎条目须并入相邻条，除非是剧情必须独立成镜的收束句/转折句。

### 五、画面风格类

1. **禁止「暗部压重高光克制」等压暗措辞**：出现即改写为「中等对比、暗部干净不死黑」。
2. **禁止把角色统一压成灰黑基调**：自然色调两色不得同为灰系，至少一个须为暖点。
3. **禁止画面风格生成参考图**：画面风格只输出为一段统一文字，全剧本复用，不生成色彩参考图。

### 六、生成参数与积分类

1. **禁止为「显得高级」擅自升级画质**：默认参数（Lib Image 2.5 Pro 低画质 1K 16:9 / Seedance 2.0 Fast 480p 4:3）除非有明确需要，不得擅改浪费积分。
2. **禁止擅自生成不建图角色/无台词条目的资产**：不出镜/不建图角色不生成三视图，不含台词的条目跳过不生成故事板和视频，避免浪费积分。
3. **禁止把「低画质 1K」写进 quality 字段**：quality 只填 `low`。
4. **禁止把 sound 设为 off**：无音乐用 `sound: on` + `need_bgm: false`，不得关 sound（会丢环境音与对白）。
