# 短片导演·场记链工作法（连续性导演OS）v2.1.0 上传包

## 在 LibTV 使用

方式一：Agent首页 → Skill自定义创建 → 按文件夹上传本目录（推荐，references随包可用）。 方式二：只粘贴/上传 SKILL.md 单文件。SKILL.md 自足运行，references 是深度模板与清单，缺失时Skill按正文压缩版规则执行。

## v2.1.0 相对 v2.0.0（GPT重构版）的变化

1. 格式修正为 Agent Skill 规范：YAML frontmatter（name＋触发式description），正文169行（规范建议&lt;500行），深度内容按渐进披露拆入 references/ 四个文件并在正文标注读取时机。
2. 新增「成片级交付标准」并设为默认项目目标：时长≥30秒、情节完整、剪辑转场、配乐节奏对齐切点、中英双语字幕、画面质感，对应 LibTV 最新统一成片要求；新增阶段5成片装配指令（对Agent直接下的剪辑/配乐/字幕话术）。
3. 新增 `成片` 与 `重新抽卡：{角色}` 指令；重新抽卡按角色资产级返修走状态机广播。
4. 保留 v2.0 全部核心机制：四维状态机、八条连续性链、canonical防代际漂移、能力校准（unknown_conservative）、空间/时间解耦编译、标准版/诊断版双模板、根因路由与止损、快拍快车道、恢复快照、附件提示注入防护。
5. 删除运行时不需要的展示性内容（竞争力叙述、论文引用等），移至开发仓库自存。
