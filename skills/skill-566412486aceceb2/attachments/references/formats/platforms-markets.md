# 平台规则与市场本地化

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 画幅与时长

平台画幅推荐时长备注抖音/快手9:16 竖屏8-15秒竖屏构图需注意建筑垂直线条的完整性，避免截断穹顶或塔尖B站/西瓜16:9 横屏10-15秒横屏适合壮阔城市全景，可容纳更多建筑层次小红书3:4 或 1:18-12秒偏精美静态构图感，减少大幅运镜

## 抖音竖屏构图要点

- 竖屏画面宽度有限，避免一次性展示过宽的建筑群全景，改用纵向仰角或从低到高的上摇运镜
- 高耸的穹顶、火箭造型塔楼在竖屏中天然有利，善用垂直线条增强壮阔感
- 前景可放置一个标志性元素（如飞行器掠过、人物剪影），中景展示建筑主体，远景留天空和光线
- 黄金时段的暖色天空在竖屏顶部1/3区域最有表现力

## 横屏构图要点

- 适合展示乌托邦城市的完整天际线，多栋流线型建筑并置
- 可用水平平移运镜从左至右展示建筑群层次
- 远景可放置山脉或地平线作为自然背景，增强理想世界感

## 合规注意

- 不出现可辨识的真实品牌标识或logo
- 建筑造型避免直接复刻真实地标建筑（如迪士尼Epcot、特定世界博览会馆）
- 不涉及政治符号、国旗、军事元素
- 人物服饰避免与特定历史制服雷同
- 画面情绪保持积极乐观，不滑向政治乌托邦/反乌托邦叙事
