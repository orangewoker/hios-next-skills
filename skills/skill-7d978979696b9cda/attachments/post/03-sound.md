# 声音设计、修复与混音

当设计一场的听觉、接续对白、检查口型/声源、修复声音或准备混音交付时读取。输入为场功能、人物声音与知情状态、空间/故事时间、当前 Timeline 版本、可用声音来源、观察能力及项目交付规格。

## 把五种能力分别核实

| 能力 | 成立所需证据 | 不可据此推定 |
|---|---|---|
| 音视频直出 | 真实返回媒体具有可定位音频及输出回执 | Agent 已听过；对白正确；有可分轨素材 |
| 可听/可观察 | 确切区间实际进入声音观察，记录听到的内容与限制 | 转写正确就说明音色、距离或口型同步正确 |
| 可分轨/编辑声音 | 实际可访问独立素材或已验证的分离/轨道接口 | 一条混合音频可以无损拆为对白、环境、音乐 |
| 可修复 | 明确修复操作、输入输出、成本与样片结果 | 有音量字段就能消除混响、换字或重配音 |
| 可混音/导出 | 轨道、路由、自动化、输出及所需测量的真实契约和结果 | 完成一次静音或增益调整就已完成完整混音与响度验收 |

某一能力缺失只约束相关操作。只拿到混合声轨时可以审听并设计方案；若需单独压低音乐而接口不能分离，不能凭空声称已改。声音不可观察时登记 unobservable，可继续已合格视觉用途，但不能验收声画同步或接续。

## 从场功能决定听见什么

先逐项写对白、环境、动作/拟音、音乐的职责，不以“每场铺满”作为完成标准。声音可以引导注意、建立空间、透露离画行动、保留倾听或制造主观经验；同时检查是否会让观众误判同地、同时或人物知情。

以修理店为**假设声音方案**：

| 提示 | 所属层与作用 | 声源/空间 | 同步与版本要求 | 可选择的处理 |
|---|---|---|---|---|
| “爸的字，你认得。” | 对白；把命令改成含蓄求助 | 林岚在账桌远侧，室内真实距离 | 关联邀请事件与画面版本；实际词句、停顿另听 | 可让句尾留在林舟反应上；先保住他听完才选择 |
| 钥匙触桌 | 动作声；完成责任交还 | 靠门的桌角 | 锚定实际接触帧/时刻，不能按计划时刻硬贴 | 原声可用则保留；有证据的缺失才补拟音 |
| 店内底声 | 环境；空间持续存在 | 与本场声源和距离一致 | 检查跨切点是否突变/循环暴露 | 可以很轻，也可有意断开，不强填所有静默 |
| 末班车相关声音 | 可能改变剧情理解 | 声源目前未在故事中确立 | 不能自行加入“车已离开”事实 | 默认不新增；需要时先回 Scene 决定其意义 |
| 音乐 | 是否参与此刻关系变化仍待比较 | 故事内/外必须分清 | 关联所选 Timeline，保留对白可懂性 | 可不用；不靠煽情替代卸包和坐下的表演 |

正式声音提示清单再补真实源 Take/音频版本、源 `[start,end)`、Timeline 位置、实际观察证据与待处理项。时基遵循[剪辑约定](02-editing.md#time-ranges)，未生成的声音只登记事件锚点和计划。

## 接续与问题判断

J-cut 是下一段声音先于其画面进入；L-cut 是前段声音在其画面切出后继续。先检查叙事关系与可用声音余量，再试切点；它们是表达选择，不是所有接缝的美化按钮。钥匙撞击、嘴部发声等同步事件不能为了顺滑任意位移。反应镜中的人物不能在尚未听到内容前表现已知，除非剧本已有其他信息来源。

| 听见或看见的问题 | 先区分什么 | 合理的最小处理与例外 |
|---|---|---|
| 对白听不清 | 原录制含混、音乐遮蔽、距离设计还是播放条件 | 先比较混音安排；词句本身错误不能只加音量；有意含混须有表达约定 |
| 口型/动作不同步 | 固定偏移、持续漂移、局部速度差、内容根本不同 | 固定偏移可测试对齐；漂移查时基/速度；错词或动作内容不符需重配或重做，不能承诺平移解决 |
| 跨场像换了人或对白错配角色 | 角色声音Asset版本/生效范围、Binding角色与源区间映射、情绪/故事状态、录制/处理变化 | 对照已听声音母版与目标区间，分清源、绑定、实现或后期问题；合理声态变化保留，只修受影响角色/区间 |
| 同场忽近忽远 | 透视、混响、声源位置、处理差异 | 先确定听觉视点；主观声音可偏离真实，但需设计依据 |
| 噪声/破音/尾音断裂 | 原始缺陷、剪辑切点还是导出产生 | 在可用源中换段/加余量；修复能力经过验证才用，复听有无新伪影 |
| 声桥让场景误读 | 同时性、地点、离画声归属和知情 | 改声音入出点或取消桥接，必要时回叙事结构 |

声音身份问题先回[母版验收](../assets/02-asset-build-review.md#voice-build)与[声音Binding](../assets/03-reference-binding.md#voice-binding)。若从第五集改变声态，旧母版和已交付前集保留原适用范围；扫描实际受影响的Job/Take/Clip，其他角色或未消费声音的视觉用途可继续。新声源或修复后声音无法听取时保留unobservable，不把已看过画面或旧母版已听当新声态通过。

ADR/补录、生成配音、音频分离、噪声修复、拟音和混音是不同任务。每项保存目标、源/画面版本、能力与费用依据，按[任务包装](../generation/01-shot-task-packaging.md)与[提交核对](../generation/05-submit-reconcile.md)执行；不能把同一工具按钮名当成全套工序已支持。

## 可浏览产物与复听

输出“声音提示清单＋问题/处理清单＋交付清单”。处理清单保留修改前后来源、影响区间、理由与复听结果；交付清单说明实际获得的是混合声轨、哪些真实分轨、哪些只要求但未取得。未经验证的分离不能称原生分轨。

复听至少覆盖修改区间、前后接续、整场可懂性和视点，再检查受影响的跨场声音身份/音乐关系。锁画后若时长变化，重新对齐声音、字幕和音乐锚点。所需响度、峰值、声道/声道顺序、采样率、位深及分轨格式均取[项目约定](../core/01-project-contract.md)；没有约定或测量证据，明确待确认/未核验，不制造合规阈值。

场景声音审美是有理由的评价；文件声道、时长和测量数值属于技术证据。两者分开给出，最终导出仍需[交付复核](04-color-titles-delivery.md)。修复后表演或内容改变，回[变更影响](../core/05-change-impact.md)与[分层审查](../quality/01-review-rubrics.md)。
