# 叙事节奏与场景架构

## 场景定义

场景是重新锚定的单元：同一个地点、同一个时间区间，镜头可以互相从已接受的成片链式衔接。

## 场景卡片

| 字段 | 说明 |
|---|---|
| scene_id | 场景编号 |
| 叙事功能 | 本场景在故事中的任务 |
| arc_position | 开场 / 上升 / 转折 / 高潮 / 释放 |
| 地点 | |
| 时间 | 白天/夜晚/黄昏/黎明 |
| 锚定参考 | 规范参考图/规范角色设定 |
| 最大链式深度 | 默认 2，硬上限 3 |
| 音频计划 | 环境音/音乐/音效阶段 |
| 过渡出 | 如何切到下一场景 |

## 镜头链式规则

- 无缝续拍仅在场景内部合法。
- 场景边界是有意剪辑，从规范参考开启，链式深度重置为 0。
- 连续以输出来源的生成限制在 2 次以内（硬上限 3），否则按计划重新锚定。
- 剪辑是最廉价的连续性工具；长故事应拆为多个场景，而非一条长链。

## 弧位置与视听趋势

| 弧位置 | 景别趋势 | 运动趋势 | 光趋势 | 声音趋势 |
|---|---|---|---|---|
| 开场 | 大远景→中景 | 稳定或缓慢揭示 | 建立主光源 | 环境音渐入 |
| 上升 | 中景为主 | 运动增强 | 反差加大 | 音效密度增加 |
| 转折 | 一个打破模式的镜头 | 突变或静止 | 色温/方向变化 | 音乐或静默转折 |
| 高潮 | 近景+大远景交错 | 最快或最稳 | 最大反差 | 最大声音能量 |
| 释放 | 中景或远景 | 放缓或停止 | 柔化或扩散 | 余音/环境音 |

## 镜头序列图字段

每个镜头卡包含：clip_id、scene_id、sequence_index、parent_clip_id、narrative_job、felt_intent、target_duration_sec、generation_mode、shot_structure、already_happened、this_clip_only、reserved_for_later、planned_start_state、planned_end_state、transition_in、transition_out、continuity_locks、allowed_changes、arc_position、status。
