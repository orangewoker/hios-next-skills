# 11 - 风格锁定与提示词注入机制

> 实现三项核心能力：
>
> 1. 题材到电影美学风格的精确映射（可扩展+模糊匹配容错）
> 2. 风格锁定状态的持久化存储
> 3. 提示词生成时自动追加锁定风格质感词的注入机制（对现有流程无侵入）

---

## 一、整体流程

```
用户提供题材/故事背景
      ↓
环节①创意输入：识别题材
      ↓
查映射表 → 精确/模糊匹配 → 选定参考电影
      ↓
风格锁定 → 写入持久化文件
      ↓
环节⑥⑦生成提示词时 → 自动注入质感词包
      ↓
输出含美学风格的全中文提示词
```

## 二、能力一：题材到电影美学风格的精确映射

### 2.1 映射数据源

映射表文件：`references/10-电影美学风格映射表.md`

包含 17 题材 × 5 部电影 = 85 条美学质感记录，每条记录包含：

- 题材名称
- 电影参考作品（含年份）
- 核心美学质感描述词：色彩体系、光影逻辑、空间与置景、材质质感、镜头与成像、核心美术气质
- 精确色卡：环境主色、辅助色、暗部倾向色、高光倾向色、点缀强调色（十六进制）
- **质感词包**：从上述字段精炼提取的关键词组合，用于直接注入提示词

### 2.2 精确匹配流程

```
Step 1: 提取用户输入中的题材关键词
Step 2: 在"题材别名表"中查找映射
Step 3: 精确匹配到题材分类（如"科幻"→科幻类）
Step 4: 默认取该题材第1部电影作为主参考风格
Step 5: 若用户指定了具体电影，则取对应电影
Step 6: 提取该电影的"质感词包"
Step 7: 进入风格锁定流程
```

### 2.3 模糊匹配容错

当精确匹配失败时，按以下优先级容错：

优先级容错方式示例1近义词匹配"修仙"→东方玄幻类，"末日"→科幻类2组合题材拆分"科幻动作"→主取科幻类，辅取动作类3场景关键词反推"雨夜霓虹城市"→科幻类（赛博朋克）4情绪基调匹配"压抑阴暗"→悬疑类或惊悚恐怖类5兜底默认无法匹配→现代都市类第1部，向用户确认

### 2.4 模糊匹配实现规则

```
1. 将用户输入分词，提取名词和形容词
2. 遍历"题材别名表"，计算与每个题材的相似度
3. 相似度 = 匹配关键词数 ÷ 题材关键词总数
4. 取相似度最高的题材
5. 若最高相似度 < 0.3，进入场景关键词反推
6. 若仍无法匹配，使用兜底默认并向用户确认
```

### 2.5 风格选择确认

匹配完成后，向用户展示匹配结果并确认：

```
🎬 美学风格已匹配

题材分类：{题材名}
参考电影：《{电影名}》（{年份}）
美学气质：{核心美术气质}
色彩基调：{色彩体系摘要}

是否采用此美学风格？
- 回复"确认"锁定此风格
- 回复"换一部"切换同题材其他电影
- 回复"换题材"重新选择题材
```

## 三、能力二：风格锁定状态的持久化存储

### 3.1 存储位置

风格锁定状态持久化存储在 Skill 根目录：

```
./style-lock.json
```

### 3.2 存储格式

```json
{
  "project_name": "{项目名}",
  "locked": true,
  "lock_time": "{ISO 8601 时间戳}",
  "genre": "{题材分类}",
  "genre_aliases_matched": "{匹配时使用的用户原始题材词}",
  "reference_movie": "{电影名}",
  "reference_movie_year": "{年份}",
  "aesthetic_essence": "{核心美术气质}",
  "texture_pack": "{质感词包完整内容}",
  "color_palette": {
    "environment_primary": "{环境主色#XXXXXX}",
    "auxiliary": "{辅助色#XXXXXX}",
    "shadow_tendency": "{暗部倾向色#XXXXXX}",
    "highlight_tendency": "{高光倾向色#XXXXXX}",
    "accent": "{点缀强调色#XXXXXX}"
  },
  "injection_count": 0,
  "last_injection_target": null
}
```

### 3.3 存储规则

1. **锁定时机**：用户在环节①创意输入时确认美学风格后，立即写入 `style-lock.json`。
2. **读取时机**：每次进入环节⑥视觉资产提取和环节⑦故事板与视频提示词前，先读取 `style-lock.json`。
3. **会话恢复**：会话中断后重新启动时，若 `style-lock.json` 存在且 `locked=true`，自动恢复锁定状态，并向用户提示"已恢复美学风格锁定：《{电影名}》"。
4. **解锁/切换**：用户说"换风格""解锁风格"时，清除锁定或重新匹配。
5. **仅真人实拍锁定**：当画面风格为"真人拍摄"时才执行风格锁定。若为3D漫剧或2D漫剧，不执行锁定，但仍可参考美学气质作为风格指导。

### 3.4 持久化文件管理

- 文件随项目存在，不随会话结束而删除
- 每次锁定/切换时覆盖写入
- 读取失败时（文件损坏/不存在）视为未锁定，正常进入匹配流程
- 不存储敏感信息，仅存储美学风格参数

## 四、能力三：提示词生成时自动追加质感词的注入机制

### 4.1 注入原则

**无侵入注入**：注入逻辑不改变现有提示词模板的结构和生成流程，仅在最终输出的提示词末尾追加美学风格质感词包。

### 4.2 注入触发条件

环节是否注入条件① 创意输入否此环节是锁定环节，不注入② 人物小传否文字内容，不需要美学质感③ 故事大纲否文字内容，不需要美学质感④ 正文小说否文字内容，不需要美学质感⑤ 分镜剧本否分镜表本身不需要，但色温标注可参考色卡⑥ 人物资产**是**读取锁定风格，注入质感词包⑥ 道具资产**是**读取锁定风格，注入质感词包⑥ 场景资产**是**读取锁定风格，注入质感词包（注入力度最大）⑦ 故事板**是**读取锁定风格，注入质感词包⑦ 视频提示词**是**读取锁定风格，注入质感词包（注入力度最大）

### 4.3 注入流程

```
Step 1: 生成环节⑥或⑦的提示词（按现有模板正常生成）
Step 2: 读取 style-lock.json
Step 3: 若 locked=true 且画面风格=真人拍摄：
        → 提取 texture_pack（质感词包）和 color_palette（色卡）
        → 在提示词末尾追加美学风格注入块
Step 4: 若 locked=false 或画面风格≠真人拍摄：
        → 不注入，正常输出提示词
Step 5: 更新 injection_count 和 last_injection_target
```

### 4.4 注入格式

在现有提示词的末尾追加以下格式块（不修改原有内容）：

```
【美学风格锚定】
参考电影：《{电影名}》（{年份}）
美学气质：{核心美术气质}

【美学质感注入】
{质感词包完整内容}

【色卡参考】
环境主色：{#XXXXXX}
辅助色：{#XXXXXX}
暗部倾向色：{#XXXXXX}
高光倾向色：{#XXXXXX}
点缀强调色：{#XXXXXX}
```

### 4.5 注入示例

假设用户题材为"赛博朋克科幻"，匹配到《攻壳机动队》（1995），生成场景资产提示词时：

```
[原有场景资产提示词内容...]
封魔渊外围冷崖，暮色，漫天飞雪...

【美学风格锚定】
参考电影：《攻壳机动队》（1995）
美学气质：日式赛博朋克哲思感，清冷潮湿的未来疏离美学

【美学质感注入】
冷灰为主搭配霓虹彩光，高对比暗部死黑，城市雨雾色彩弥散，赛博日本风格，硬光漫射光混合雨夜地面反光，新港市雨夜高楼狭窄巷道拥挤潮湿未来都市，潮湿金属反光玻璃全息广告牌，固定机位全景慢镜头手绘赛璐璐质感

【色卡参考】
环境主色：#4A5A6B
辅助色：#6B3A8A
暗部倾向色：#121A25
高光倾向色：#A8D8F0
点缀强调色：#A82A2A
```

### 4.6 注入力度控制

不同环节的注入力度不同：

环节注入力度说明⑥ 人物资产中等注入色彩体系、光影逻辑、材质质感；不注入空间置景（人物资产用白色背景）⑥ 道具资产中等注入色彩体系、材质质感；不注入空间置景⑥ 场景资产**完整**注入全部质感词包+色卡（场景资产最依赖美学风格）⑦ 故事板完整注入全部质感词包+色卡⑦ 视频提示词**完整+强化**注入全部质感词包+色卡，并将参考电影名写入"导演与电影风格"字段

### 4.7 中文约束

注入的质感词包**全部为中文**，与 Skill 的"提示词禁止英文"红线一致。色卡的十六进制色值（如 `#4A5A6B`）为数值参数，不属于英文，可保留。

## 五、与现有 Skill 流程的集成点

### 5.1 环节①创意输入（新增）

在环节①的执行规则中新增第5步：

```
5. 美学风格匹配（仅当画面风格为真人拍摄时）：
   a. 从用户题材/故事背景中提取题材关键词
   b. 查 references/10-电影美学风格映射表.md 精确/模糊匹配
   c. 选定参考电影，提取质感词包
   d. 向用户展示匹配结果并确认
   e. 确认后写入 style-lock.json 持久化
   f. 详见 references/11-风格锁定与注入机制.md
```

### 5.2 环节⑥视觉资产提取（新增注入步骤）

在环节⑥的执行规则末尾新增：

```
**美学风格注入**（仅当 style-lock.json 中 locked=true 且画面风格=真人拍摄时）：
- 读取 style-lock.json，提取质感词包和色卡
- 在每个资产提示词末尾追加"美学风格锚定"+"美学质感注入"+"色卡参考"格式块
- 场景资产注入完整质感词包，人物/道具资产注入中等力度
- 详见 references/11-风格锁定与注入机制.md
```

### 5.3 环节⑦故事板与视频提示词（新增注入步骤）

在环节⑦的执行规则末尾新增：

```
**美学风格注入**（仅当 style-lock.json 中 locked=true 且画面风格=真人拍摄时）：
- 读取 style-lock.json，提取质感词包和色卡
- 故事板提示词末尾追加完整质感词包+色卡
- 视频提示词末尾追加完整质感词包+色卡，并将参考电影名写入"导演与电影风格"字段
- 详见 references/11-风格锁定与注入机制.md
```

### 5.4 会话恢复（新增）

Skill 启动时（环节①之前），新增检查步骤：

```
1. 读取 style-lock.json
2. 若 locked=true：
   → 向用户提示"检测到已锁定的美学风格：《{电影名}》（{年份}），{核心美术气质}"
   → 询问"是否继续使用此风格？回复'继续'保持锁定，回复'换风格'重新匹配"
3. 若 locked=false 或文件不存在：
   → 正常进入环节①
```
