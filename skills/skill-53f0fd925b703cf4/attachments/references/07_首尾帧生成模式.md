# 07 · 首尾帧生成模式 + I2V 单图视频化

> 读取时机：任务为"首尾帧生成"（提供首帧+尾帧两张参考图，让模型生成中间过程），或"图生视频"（单张定帧图视频化，I2V）
> 复述要求：向用户复述本段的锚点声明（"还是她/它"的视觉线索）

---

## 平台判定

| 平台 | 能力 | 用法 |
|:----|:----|:----|
| **Seedance / 即梦** | 分镜栏多镜组（HARD CUT）、@引用多图锚定 | 默认模式，走SKILL.md主流程 |
| **Kling 等首尾帧模式** | 起幅=首帧图、收幅=尾帧图，中间连续生成 | 用本文件规范 |

万物生实证：沙漠段用 Seedance 分镜栏（"Seedance 2.0 1080p·21:9·15s 分镜栏"），年龄形变/转身拔剑用 Kling 首尾帧（"Kling v3 1080p·4s"）。**按平台能力选模式，不硬套。**

---

## 首尾帧写法规范

### ① 模式声明（开头一句）

```
这是一段首尾帧生成：起幅严格为首帧画面（[首帧内容一句话]），收幅严格为尾帧画面
（[尾帧内容一句话]）。中间是[连续不断的X过程]，一气呵成、中途绝不切断。
```

### ② 锚点声明（最重要——防止中间过程"换人"）

贯穿首尾的视觉线索必须显式声明，含"还是她/它"的识别逻辑：
✅ 万物生·年龄形变：「贯穿首尾的锚点是童年丹眉本人（黑色齐眉短发、红绳流苏发饰、立领衣装），以及她身上那缕红穗流苏——它在静立时垂坠、在转身时被甩动、在俯身时垂落贴近剑身，是连接首尾、标识"还是她"的视觉线索。观众能清楚认出这张越变越小的脸，始终是同一个丹眉。」

### ③ 起幅/收幅严格继承

```
起幅与首帧完全一致：[镜头与主体的距离、主体占比、构图、光照、姿态——逐项锁定]
收幅严格收束到尾帧画面：[同上]
```

### ④ 收幅呼吸感（定格≠死静）

收幅定格后保留2-3个微动元素：
✅「定住的那一刻起，她俯身贴剑的姿态基本不动，但肩背随一次次缓慢而克制的呼吸几不可察地轻轻起伏，鼻息拂过冰冷的剑刃、在炽亮的刃面上凝起一小片若有似无、转瞬即散的雾气；垂在脸前的发丝与红穗流苏被呼吸的气流带得极轻微地颤动；剑身上那道过曝高光随她呼吸与持剑手的细微稳颤而极轻地明灭流动。」

### ⑤ 中间过程写法

- 过程事件仍按 （动作简写+结果详写）与分段型细则
- 变化类过程（形变/光变/场景转换）写明"与动作严格同步"（技法15 光随动演化）
- 形变类必须写"与背景消融重塑严格同步进行、彼此交融，在同一段连续过程中完成"

## 完整示例骨架（万物生·转身拔剑段）

```
[STYLE LOCK]（模式2动画风格：胡金铨武侠电影质感…）
这是一段首尾帧生成：起幅严格为首帧画面（童年丹眉在道观香雾中正脸平视镜头的特写），
```

## I2V 单图视频化五模块（墨染少女提炼）

> 适用：单张定帧原图 → 视频化（"完整1:1复刻原图"类任务）。五模块按段取用，全部写法经墨染少女30+段实证。

### 模块① 运镜规范（每段开头）

```
全程[第一人称/高空俯视]视角，镜头伴随[风]产生极轻微自然随风漂浮呼吸感，
全程以[主体]为视觉核心，以人物为中心平稳缓慢[顺时针环绕/向后小幅退行]；
无原地急推、无剧烈抖动、无大幅度变焦推拉、无切镜跳变；
全程维持原图[景别]构图比例，完整容纳[元素清单]；
依据画面美学做多层级自然景深虚化，柔和虚化[远景元素]，
视觉重心集中于[主体动作]。
```
固定机位变体：「镜头全程固定不动，仅带有极轻微自然呼吸式漂浮微动，无环绕、无推拉、无平移、无变焦」
⚠️ 慢运镜必须带方向+轨迹终点（如"顺时针完整环绕360度一圈并同步小幅后退"）——无轨迹的"极缓"违禁。

### 模块② 环境持续动态（动静清单成对）

```
环境天光缓慢流动变化，[投影/倒影]随光影同步缓慢拉伸、晃动形变；
全域细碎[粒子/尘埃]不间断缓慢飘动、散落流转；
[衣发/流体/特定元素]持续不间断波浪轻柔翻涌流动；
[基底：地面/轮廓/背景]固定不变/无多余动态。
```
≥3个持续动元素+≥1个固定基底，成对声明（详见 ref08/三）。

### 模块③ 手部强制约束（有手部近景/动作时独立成块）

```
[动作]的双手五指结构完整清晰分明，全程五根手指独立舒展，
无多指、少指、断指、粘连、扭曲、糊团、穿模、反折变形；
[执笔/特定手势]符合[标准姿态]，宽袖不会遮挡完整手部结构，
风吹流体动态手指不会糊成一团，[动作]时手部姿态稳定，无手部崩坏形变。
```

### 模块④ 同期声音效（挂点模式）

```
仅生成画面同期环境动态音效，全程不添加任何背景音乐，无BGM。
包含：[元素A]的[声音]、[元素B]的[声音]、[动作C]的[声音]……
——每个音源挂在一个可见动元素上。
音效与[动作清单]动态精准同步。
```

### 模块⑤ 编排型动作秒级打点（豁免条款）

舞蹈/武术套路/仪式动作允许秒级打点（叙事型镜头仍禁"第X秒"）：
```
0s—0.8s [起势：姿态+蓄势]｜0.8s—2s [开势：动作+身韵]｜
2s—3.4s [主体动作]｜3.4s—4.3s [变化/二次动作]｜4.3s—5s [收势定格]
```
✅ 墨染少女：书法古典舞段
> 0s—0.8s 起势凝神，落笔蓄势。人物保持原图初始侧身站姿，气息沉静内敛；主手稳定标准书法握笔横置长笔于身前，辅助手自然舒展垂落身侧。
> 0.8s—2s 执笔开势，起笔行笔。顺势完成标准古典舞云手+顺风旗身韵动作，主手持笔向前上方划出舒展大气长弧线。手臂开合带动宽大鎏金广袖向外大幅翻卷舒展。
> 2s—3.4s 旋身挥毫，行笔收锋。脚下配合小幅古典舞圆场步带动身体轻盈半圈回旋。持笔手从高位斜向平缓带下，再绕身前回带至身体侧方。
> 3.4s—4.3s 大开大合二次铺毫。再次向外舒展送出持笔手，辅助手向后舒展拉开形成帅气对角线构图。
> 4.3s—5s 收锋定格，执笔亮相。匀速平稳收束全部动作，重心稳定落定。持笔手将长笔横斜停于肩前，标准古典舞干净亮相造型。

⚠️ 编排型打点至少3段，每段动作描述独立。禁止叙事流写成"她先做X，然后做Y，最后做Z"（叙事流写不出节奏细分）。
