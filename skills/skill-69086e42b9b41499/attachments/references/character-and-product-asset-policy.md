# 角色与产品资产策略

## 自动资产判定

| 资产 | `direct_use` | `extract_asset` |
| --- | --- | --- |
| `character_reference` | 单人、成年、脸/发型/服装清晰、画风与用户选择兼容、主体未遮挡 | 背景杂乱、多人、细节不清、裁断严重、年龄不明或画风不兼容；生成白底同画风角色资产 |
| `product_reference` | 单一产品、包装/瓶身/主要 logo 清晰、主体完整、无干扰背景 | 多产品、标签不清、强遮挡、复杂背景；生成白底同画风产品资产 |

系统自动执行，不询问用户是否提取。没有产品图时，不创建 `product_reference`，也不添加产品露出描述。

## `character_reference` 提示词

```text
基于用户角色卡，生成横版 16:9 白底角色设定图。角色必须为成年人；锁定脸、发型、肤色、身材比例、性别表达和主要服装。

画风：{实拍微距质感 / 3D 渲染动画片 / 2D 卡通片}。左侧同一角色全身正面站姿，完整露出脸、发型、服装、鞋和手部；右侧脸部与肩部特写。纯白背景，无文字、无 logo、无场景、无其他人物。
```

## `product_reference` 提示词

```text
基于用户产品图，生成横版 16:9 白底产品资产图。保持同一包装轮廓、主色、材质、瓶身/盒体结构与可见 logo；画风匹配 {用户选定画风}。左侧完整产品三分之四视图，右侧产品正面近景。纯白背景，无人物、无其他产品、无场景、无额外文字。
```
