# 部件卡10 · 群像约束

## 适用条件
画面≥3个非主要角色时使用（人群/士兵/学生/路人等）。

## 完整模板
```
本段所有[人群身份]均为[族群/时代描述]，
[长相共性特征]、[肤色描述]。
人群中每一个人的长相、年龄、性别都各不相同，
体型有高有矮有壮有瘦，肤色深浅各异，
服装从[参考图]中随机抽取组合，共享同一套[人群]服装语言。
```

## 嵌入@引用行
`@[人群图hash] 作为人群服装视觉参考，人群中每一个人的长相、年龄、性别、体型都各不相同，共享同一套服装语言。`

## 万物生原版（对照用）
```
@[IMG_GEN_xxx] 作为部落人群服装风格视觉参考,人群中每一个人都不戴帽子,不戴白色头巾,
个体的服装组合、皮革绑带、铃铛饰物、青铜挂件、颜料色块标记都从这张物料图中随机抽取并组合,
共享同一套部落服装语言,但人群中每一个人的长相、年龄、性别都各不相同,既有年轻男性也有年轻女性、
既有中年壮汉也有中年妇人、既有白发老者也有半大少年,体型有高有矮有壮有瘦,肤色深浅各异,
整体读作一个真实多样化的部落群体。
```

## 约束三要素
①长相多样性 ②体型多样性 ③服装统一性

## 兽群/虫群动作参差声明
```
[兽群]各自拱地、挪移、掀翻篷帐，动作各不相同、彼此不齐整、此起彼伏、无一同步。
```
