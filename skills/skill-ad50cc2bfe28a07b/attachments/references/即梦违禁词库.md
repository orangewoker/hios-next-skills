# 即梦违禁词库

本词库用于检测和优化即梦（Seedance 2.0）平台AI视频生成的提示词内容，避免因违规内容导致审核失败、视频下架或账号封禁风险。

## 词库使用原则

### 1. 检测范围
- **仅扫描**【核心需求】部分的文本内容
- **不扫描**：绑定区、目前的状态描述、核心设定等固定模板内容
- **智能过滤**：区分台词内容与叙述内容，考虑语境

### 2. 处理优先级
1. **显性IP违规**（最高优先级） - 直接引用知名作品角色
2. **内容敏感词** - 血腥、暴力、色情、惊悚等元素
3. **隐性IP违规** - 通用词汇组合可能联想特定IP
4. **平台通用违禁** - 歧视、虚假宣传、侵权等

### 3. 剧本特定处理
- **通用处理**：角色名直接使用剧本原名
- **神话元素允许**：仙侠、玄幻世界观下的法术、法宝等元素
- **战斗描述允许**：功法对决、法宝碰撞等元素

### D. 平台通用违禁类型

#### 1. 歧视/攻击性言论
- **种族歧视**：`黑人`→`深肤色角色`、`肤色较深的仙人`
- **地域歧视**：避免具体地域贬低词汇
- **性别歧视**：避免性别刻板印象标签
- **职业歧视**：避免职业贬低词汇

**用户举例词汇处理**：
- `黑人` → 神话语境可用"黑肤仙人"、"深色法相的修炼者"
- `各个天王` → 可能涉及宗教，建议用"四大守护者"、"四方神将"

#### 2. 虚假/夸大宣传
- 避免"最強"、"无敌"、"百分百有效"等绝对化表述
- 用"强大"、"卓越"、"显著效果"等相对表述

#### 3. 侵权风险
- 避免描述具体品牌、商标、现实人物肖像
- 神话人物直接使用剧本原名

#### 4. 敏感社会议题
- 避免明确政治立场、历史事件评价
- 神话故事天然规避现世议题

#### 5. 危险行为示范
- 避免详细描述自杀、自残、高危动作步骤
- 战斗场景应艺术化处理

## 检测与替换工作流程

### 1. 检测阶段
1. **文本提取**：从`【核心需求】`部分提取纯文本
2. **去噪处理**：移除角色名、标点符号、格式化标记
3. **分层匹配**：按A→D优先级顺序匹配词库
4. **语境分析**：检查词汇出现位置（台词/叙述/动作描述）

### 2. 标记阶段（标准模式）
- **高亮标记**：在生成提示词中用`【⚠疑似违禁】`标记
- **分类标注**：注明风险类型（IP/暴力/歧视等）
- **替换建议**：提供1-2个安全替换选项
- **语境保留示例**：
  ```
  原句：角色A："我角色A在此，谁敢与我一战！"
  标记：角色A："我角色A【⚠疑似违禁：显性IP】在此，谁敢与我一战！"
  建议：台词中角色名为剧本原创，可保留
  ```

### 3. 输出格式

#### 安全检查摘要模板
```
【安全检查摘要 - 分段X】
- 检测段落：【分段X】的【核心需求】
- 扫描结果：发现疑似问题词汇 N 处
- 处理建议：
  1. 【高优先级】显性IP违规：M处 → 建议替换为原创描述
  2. 【中优先级】内容敏感词：K处 → 建议使用安全词汇
  3. 【低优先级】隐性IP/其他：L处 → 可保留但注意审查
- 详细标记见各段内【⚠疑似违禁】标注
```

#### 段落内标记示例
```
【分段3】
@图片1 是当前场景（宗门广场）。
...

【核心需求】拍摄和演绎下面的剧情: 
反派A（怒喝）："尔等叛贼，今日必让你们血溅【⚠疑似违禁：血腥元素】宗门广场！"
建议替换："血溅"→"灵气尽散于"、"光芒消逝在"

角色A（大笑）："反派A，你看这神器，像不像奇幻森林【⚠疑似违禁：隐性IP】中的魔法树？"
建议替换："奇幻森林"→"发光植物森林"，"魔法树"→"灵气巨木"
```

## 词库维护与更新

### 更新频率
- **每月检查**：即梦平台规则变化
- **剧本适配**：根据具体剧本类型调整敏感度
- **用户反馈**：根据实际审核结果优化词库

### 定制化建议
1. **不同剧本类型**：
   - 神话战斗剧：放宽战斗词汇，收紧现实敏感词
   - 现代都市剧：收紧现实元素，放宽神话词汇
   - 奇幻冒险剧：平衡处理各类词汇

2. **输出平台差异**：
   - 即梦（Seedance 2.0）：最严格，需全面检测
   - 其他AI平台：参考但不完全套用本词库
