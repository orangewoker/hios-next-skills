# 资料库：声画、情绪、音效、节奏与对白

### @AUDIOVISUAL：声画关系资料库 v1.0


适用范围：所有含台词或声音设计的分镜。决定声音与画面在叙事层面的协作方式。


#### 一、模式选择逻辑


**第一步：声音来源是什么？**

- 观众听到的声音，画面中的角色也能听到吗？

  - 能，但经过某角色耳朵处理 → **聚焦类**（模式22-25）

  - 不能，是角色内心的直接投射 → **投射类**（模式26-28）

  - 能，且未处理 → 进入第二步


**第二步：声音与画面的时间关系？**

- 声音/画面时间错位 → **错时类**（模式18-21）

- 各自时间线崩溃 → **断裂类**"解体"（模式16）

- 同一时间 → 进入第三步


**第三步：声音与画面的信息关系？**

- 同向强化 → **同步类**（模式1-2）

- 异向张力 → **对位类**（模式3-9）

- 各自独立 → **平行类**（模式10-13）

- 有意错位 → **断裂类**（模式14-16）


#### 二、全量模式（首批28种）


##### 同步类（2种）


**模式1：直接同步** - 声画指向同一事实互相强化。用于告白、宣战、结论。`角色动作与台词内容完全同步`


**模式2：节奏同步** - 声画节奏合拍内容独立。用于建立秩序感、仪式感。`画面切换或运镜节奏与台词重音断句同步`


##### 对位类（7种）


**模式3：画面揭露台词真伪** - 画面证明台词真假。`角色台词与身体语言/环境细节矛盾`


**模式4：画面揭示潜台词** - 画面展示角色真正在意的事。`说话者视线不在台词对象上`


**模式5：画面预示后果** - 画面展示台词将导致的未来。`台词指向判断，画面有细节暗示落空`


**模式6：画面揭示过去** - 画面让台词获得过去的含义。`插入过去画面碎片揭示台词历史根源`


**模式7：画面否定台词** - 画面与台词相反。`台词描述与客观现实截然相反`


**模式8：画面削弱台词** - 画面比台词轻，制造荒诞。`画面事态明显轻于台词描述`


**模式9：画面加重台词** - 画面比台词重，制造恐怖。`台词平淡，画面细节暗示严重事实`


##### 平行类（4种）


**模式10：旁白与画面平行** - 画外音一条线，画面另一条线。


**模式11：台词属A画面属B** - A在说，画面焦点是B的反应。


**模式12：环境声与画面平行** - 环境对话与主角活动各自独立。


**模式13：多声部并行** - 多组对话同时进行，画面选择焦点。


##### 断裂类（4种）


**模式14：台词先行** - 台词描述某事，画面延迟展示。


**模式15：声画完全错位** - 声画来自不同时空语境强行并置。


**模式16：声画解体** - 声音与画面各自独立崩溃互不参照。


**模式17：循环阻断** - 同一声音在画面不同状态下反复出现，声音不变画面已变。


##### 错时类（4种）


**模式18：台词闪前** - 未来的声音出现在当前画面。


**模式19：台词闪回** - 过去的声音出现在当前画面。


**模式20：画面先行/闪前** - 画面展示的结果发生在台词事件之后。


**模式21：嵌套错时** - 多层时间在声画中同时存在。


##### 聚焦类（4种）


**模式22：听觉聚焦** - 观众听到某角色主观听到的声音。


**模式23：听觉屏蔽** - 客观声音被角色听觉过滤掉。


**模式24：幻听/耳鸣** - 声音只存在于角色主观感知中。


**模式25：听觉误导** - 主观声音被误认为客观声音。


##### 投射类（3种）


**模式26：内心声音化** - 角色内心状态直接转化为声音。


**模式27：情感声景** - 环境声被角色情绪渲染扭曲。


**模式28：象征音效** - 抽象概念用非现实声音来隐喻。


#### 三、时长核算联动


- 模式11（台词属A画面属B）：分镜时长 = max(台词时长, B反应时长)

- 模式14（台词先行）：分镜时长 = 台词时长 + 画面延迟时长

- 模式16（声画解体）：分镜时长 = max(声音线时长, 画面线时长)

- 模式18-21（错时类）：分镜时长 = max(各时间层最长时长)

- 其余模式：分镜时长 = max(台词总时长, 动作所需时长)


#### 四、开放性设计接口


触发自定义条件：用户关键词/28种模式无法覆盖/聚焦投射无法判定/用户拒绝推荐/四种以上模式复合。


自定义模板包含：叙事意图、声音层设计、画面层设计、声画交互逻辑、预期效果、AI执行锚点。

### @SOUND：音效设计


**音效层次优先级**：1.对白（最优先，200-400Hz基频）2.关键动作音效 3.持续环境音（最底层）


**音效描述规范**：

- 发声方式：呼啸/低沉轰鸣/尖锐嘶鸣/柔和沙沙/清脆碰撞/沉闷撞击/细微摩擦

- 方向性：从左到右/从远处逼近/环绕旋转/从上到下

- 频率：低频嗡鸣(<100Hz) / 中频共鸣(200-800Hz) / 高频刺耳(>2000Hz)

- 音量曲线：渐强/渐弱/骤停/脉冲式起伏/波浪式

## 二十二、对白设计子模块 v3.0

对白模块仅在存在台词、旁白、通讯声、画外音或声音叙事时启用。

对白不是解释剧情的工具，而是角色状态、关系变化、信息差和声画关系的执行手段。

对白必须经过时长核算，并遵守 Seedance2.0 单次时长边界。

**对白时长核算**（系统内部）：

- 纯台词时长 = 字数/单词数 × 语速系数（按语速档位）

- 停顿总时长 = 所有标注停顿的时长之和

- 首尾预留 = 0.3-0.5s + 0.3-0.5s

- 对白总时长 = 纯台词时长 + 停顿总时长 + 首尾预留


**联动检查规则**：

1. 对白时长 > 镜头总时长 × 60% → 【警告】

2. 对白时长 + 必需动作时长 > 镜头总时长 × 90% → 【警告】

3. 对白时长 > 镜头总时长 × 80% → 【拒绝】

4. 对白时长 < 镜头总时长 × 10%（非静默镜头）→ 【提示】
