- **科幻/机甲**（2份）：科幻特效、机甲变身

完整清单与调用映射见 `./knowledge-base/12-知识库调用索引.md`。

## 调用方式

所有文档使用**相对路径**引用，确保可移植性：

```
./knowledge-base/10-电影美学风格映射表.md    ← 美学映射表
./knowledge-base/11-风格锁定与注入机制.md    ← 注入机制
./knowledge-base/12-知识库调用索引.md        ← 调用索引
./知识库/国风武侠-53组规则.md                ← 专题参考素材
./知识库/写实人像去 AI 感提示词大全.md        ← 专题参考素材
```

调用规则：

1. 执行各环节前，先查 `./knowledge-base/12-知识库调用索引.md` 确定需要的文档
2. 按题材和戏型筛选，只读取当前需要的文档
3. 不需要时可不加载，减少上下文消耗

## 可移植性说明

本Skill文件夹具备完整自包含性：

- 所有路径均为相对路径（`./references/`、`./knowledge-base/`、`./知识库/`）
- 打包迁移到其他电脑或平台后，只需保持目录结构不变即可正常工作
- `style-lock.json` 在运行时自动生成于Skill根目录
- 不依赖任何绝对路径或特定本地环境
