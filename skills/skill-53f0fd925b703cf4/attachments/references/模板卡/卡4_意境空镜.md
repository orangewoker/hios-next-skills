## 层1b 本类骨架清单（写正文前必抄，2026-08-04补）
```
本类场景（意境/空镜）万物生原段里最值得抄的固定骨架，按需提取2-6条：
① 动静对比声明句：「[动元素]是画面中唯一持续运动的元素，与[静物]的绝对静止形成对比」
② 呼吸感慢运镜句：「镜头不是固定的，以非常缓慢的速度[运镜]，运动幅度极小，几乎接近静止但有呼吸感」
③ 动静清单句：「[基底元素]固定不变」（明确什么不动）
④ 实物锚句（防云水画假）：「峰/树/人影作参照」+「洞口漏出的油灯光像蜂巢一样在崖壁上点亮成一片暖色光点」
⑤ 光影因果句：「光从__来→照到__→路径__」
⑥ 环境微动/静止声明句：「沙地保持完全静止」「两人在整段镜头中始终保持静止状态」
本类不抄：对白/反应链（静物镜写NA）/常规动作链（AI先验强）
```

## 层2 11样抄什么（每样配本类原段例句）
```
1.初始状态帧：例「画面主体是部落崖壁村落的整体外观...每个洞口都漏出微弱的暖橙色油灯光」
2.运镜句：例「镜头极缓慢的轻微推进运镜」（慢运镜三要素=方向+目标+量级）
3.分层句：例「画面远景延伸到部落之外的沙漠地平线...夜空高远处出现一道淡淡的极光带」
4.遮挡关系句：例「洞口漏出的油灯光像蜂巢一样在崖壁上点亮成一片暖色光点」（光遮挡暗）
5.虚实焦句：例「画面上方80%被heavily blurred严重失焦的flat sole主导」（大虚焦面积）
6.声画绑定句：例「火堆燃烧的低沉噼啪声crackle」（声源绑可见元素）
7.声学属性句：例「岩窟里漏出的微弱说话声」（远处+漏出+微弱）
8.动作边界句（否定写正文）：例「沙地保持完全静止」「两人在整段镜头中始终保持静止状态」
9.反应链句：静物镜写NA
10.节拍切分句：例「0-2s空镜→2-4s人群散场→4-6s火光摇曳」（环境演变节拍）
11.硬切声音延续句：本类写NA（无切镜）
```

## 层3 3个必写句式（写正文时抄进自己的段）
```
①「[动元素]是画面中唯一持续运动的元素，与[静物]的绝对静止形成对比」（动静对比声明）
②「镜头不是固定的，以非常缓慢的速度[运镜]，运动幅度极小，几乎接近静止但有呼吸感」（呼吸感慢运镜）
③「[基底元素]固定不变」（动静清单，明确什么不动）
```

## 层4 AI跑偏清单+加密位置
```
AI跑偏：☐云画假（塑料/贴图）☐极远景假 ☐人物不出现 ☐光影平均 ☐静成死画 ☐元素少显空
⚠️ 空镜要"满"防假：元素≥6，不能只云+峰两元素
加密位置填空：
  实物锚：__（峰/树/人影作参照，防云水画假）
  光影因果：光从__来→照到__→路径__
  动静对比声明：__是唯一运动元素，与__静止对比
  多重比喻锁形态：__处（如/像，锁云水形态防假）
  环境双光源硬声明：既有__光+禁额外面光
不加密：静态基底描述（一句话锁定即可）
```
