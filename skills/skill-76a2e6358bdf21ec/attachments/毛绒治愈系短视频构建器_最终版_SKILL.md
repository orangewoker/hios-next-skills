## 做什么

把"现实场景 + 毛绒萌系 IP 角色"的治愈短视频，拆成中文分镜脚本与可直接粘贴的视频提示词，覆盖抖音 / 视频号 / 小红书毛绒账号的竖屏内容生产。

严格执行**四阶段确认流程**：确认内容方向 → 剧情脚本审阅 → 分镜与分镜图确认 → 生成视频。每阶段必须经用户确认后才能进入下一步。

## 需要什么输入

- 题材或剧情方向（可选；可从附录 2 剧情库 / 附录 3 节气日历里挑）
- 角色参考图：毛绒 IP 的正面 / 侧面 / 背面三视图 + 材质微距（已有或现设计）
- 场景与道具参考图（每个提示词组需要）
- 画幅：默认 9:16 竖屏，少数 16:9 横屏
- 单条时长：默认 5-10 秒
- 视频生成模型：可灵 / Seedance / MiniMax 等
- 是否需要背景音乐及风格偏好（**生成前必须主动询问**）

最少输入只要给一句话方向，其他按"固定治愈风格底座"和附录剧情库自行决定，不要反复反问。

## 怎么做

### 一、四阶段确认流程（硬性流程，不可跳过）

**阶段 1 · 确认内容方向**：先与用户确认要做什么方向。给出 2-3 个候选方案（从剧情库或节气日历挑选），每个方案写清：一句话情节、情绪落点、高潮的物理瞬间、推荐象声词、推荐画幅。同时确认画幅、时长、生成模型。**用户确认后才进入阶段 2。**

**阶段 2 · 剧情脚本审阅**：输出完整剧情脚本供审阅。脚本必须包含：情节发展、情绪落点、核心治愈机制（那个打动人的物理瞬间）、象声词出现的时间点、建议分段。脚本格式：

```
【题材】【画幅】【总时长】【情绪基调】
剧情：一句话讲清发生什么事
情绪落点：观众在第几秒被打动，被什么打动
核心治愈机制：那个最打动人的物理瞬间
象声词：第X秒 [发音]，身体动作 + 声音质感
分段建议：第1段 XX-XX秒 / 第2段 XX-XX秒 / ……
```

**用户确认脚本后才进入阶段 3。**

**阶段 3 · 分镜与分镜图确认**：输出分镜表 + **分镜图提示词**，并实际生成分镜图供确认。分镜表字段：镜头号 / 时间段 / 画面动作概述 / 画面构图 / 机位 / 动作 / 象声词 / 音效。分镜图为**每个镜头一张静态示意图**，用于确认构图、站位、道具位置、光影方向，规范见附录 4。**用户确认分镜图后才进入阶段 4。**

**阶段 4 · 生成视频**：按确认过的分镜图逐条生成视频，每条单独生成、单独检查角色一致性，全部通过后再进入下一条。

### 二、画面质量要求

**严禁穿模**：角色与物体的接触点、包裹关系、受力变形必须写清。抱着碗时手不能穿过碗壁、坐在椅子上身体不能穿进椅背、躺在毯子上身体不能穿过毯子。写法：`角色两条小臂环抱住碗的外壁，接触处绒毛被压出弧形凹陷，碗的重量让角色身体前倾约5度`。

**严禁穿帮**：季节物品必须对应（夏天不出现厚棉被、冬天不出现冰西瓜）；现代物品不出现在古代场景；场景陈设要符合真实生活环境。

**空间关系与物理合理性**：任何两个以上角色、关键道具落在具体台面、或角色与大型物体（洗衣机 / 购物车 / 伞 / 纸箱）互动的镜头，必须先出俯视调度图，写清厘米级尺寸、朝向、遮挡关系、接触点、光影方向。

**影子一致性**：影子方向必须与主光方向一致，禁止影子丢失、方向相反、多个影子。

**左右一致性**：提示词里的"左"指摄影机视角的左，写"画面左"比写"角色左手"更安全。禁止左右颠倒、前后错位。

**结尾剪辑与镜头过渡**：镜头之间必须有动作延续、视线延续或光线延续，禁止突兀跳切。多镜头提示词要在每个镜头写明"紧接上一镜头硬切而来"或"延续上一镜头的动作"。结尾镜头必须让动作完整完成并延续 0.5 秒，禁止动作中途切断、禁止突然黑屏、禁止无收尾的淡出。

### 三、音频与背景音乐（生成前必须主动询问）

**重要区分**：视频生成提示词内固定写 `不要出现BGM，不要出现字幕`（防止模型生成劣质音乐和乱码字幕），但**成片配乐是后期独立确认的事**，两者不冲突。

**生成前必须主动问**：`这条片子成片需要配背景音乐吗？如果需要，偏好什么风格？（见附录 5 BGM 风格对照表）`

用户选"需要"时：在交付物中附 BGM 建议（风格、节奏、情绪、推荐曲目方向），并在分镜表里标出音乐进入点和情绪起伏点。

用户选"不要"或"你定"时：默认不加 BGM，只保留环境音、材质摩擦声、象声词。

**音效设计是核心卖点**：每个镜头必须写 `音效：`，毛绒材质的摩擦声、布料挤压声、环境白噪音是内容质感的一部分。治愈系视频至少保留环境音层，完全无声会很干。

### 四、动作与表演

**修正动作生硬**：每个动作拆成 5 个编号节拍，形成完整弧线——①起势（准备）②过程（主动作）③停顿（找平衡 / 犹豫，关键萌点）④高潮（动作完成 / 意外）⑤余韵（身体回弹 / 呼吸 / 静止）。禁止只写"角色拿起碗"这种一步到位。

**角色是活的，必须会眨眼，瞳孔必须有变化**：主体是活的生命，眨眼和瞳孔变化是生命感的核心，禁止做成完全静止的死鱼眼。具体要求：

- **眨眼频率**：每 2-4 秒自然眨一次，动作快速（0.1-0.2 秒）不拖沓，不要慢眨
- **眨眼时机**：发象声词前眨、视线转移时眨、情绪转折时眨、被突然的声音惊到时眨得更慢更大、满足放松时眨眼变慢变少
- **瞳孔变化**：好奇 / 惊喜时瞳孔轻微放大，专注 / 用力时瞳孔略微收缩，光线变化时瞳孔随之调整，情绪强烈时瞳孔明显放大
- **眼神光**：眼睛表面有柔和反光点，会随头部转动而移动，眨眼时反光点短暂消失再出现，不要做成死板贴纸
- **眨眼带动眼周**：眨眼时眼睛周围的绒毛轻微牵动，眼皮（或眼部绒毛）下压再抬起，眼尾绒毛跟着动一下
- **视线方向**：眼睛会看向具体目标（看向锅、看向对方、看向镜头），视线移动时先转眼珠再转头，禁止视线永远直勾勾朝一个方向
- **防崩坏**：眼睛保持圆润可爱的造型，禁止变成写实人类眼睛（禁止眼白占比过大、禁止虹膜纹理、禁止眼角细纹过多、禁止睫毛）

**每一秒画面都有运动，不浪费帧数**：区分"角色静止"和"画面静止"——角色可以安静待着（那是在享受或等待），但**画面必须有持续变化的物理细节**。每一条提示词的 `【核心治愈机制】` 字段就是为此存在，它必须是一个"持续变化的物理过程"，不能是一个静态状态：热气持续上升并在冷空气中变淡、绒毛被风持续吹向一侧、水珠在叶尖积累到滴落、光影在地面缓慢移动、背景有人经过 / 猫尾巴摆动 / 树叶晃动。禁止整条视频只有一个瞬间的动作。

**人物之间的互动感**：多角色时反应必须错开 0.3-0.5 秒，不完美同步；要有视线交流（谁看向谁、看了多久、何时移开）；要有身体接触（碰一下、靠一下、被推一下）；一方动作要引起另一方延迟反应。

**表情丰富 + 可爱活泼好动的气质**：毛绒角色的"表情"靠姿态 + 象声词 + 绒毛状态三者叠加，不靠五官。可爱活泼的具体身体版本：原地小跳、身体左右摇、脑袋一歪、小碎步、够不着时踮脚、成功后原地转半圈、被夸时身体缩一下又弹开。

**恰当的象声词**：基础音 `呼呼` `悠悠` `baba` `波比波比` `瓜皮` `哈皮`，完整词库见附录 1。每个象声词必须写成"发声 + 身体同步动作 + 声音质感"三件套。**严禁只写"角色说 XX"**，正确写法：`第3秒发出"呼呼"，身体整体缓慢起伏一次，腹部绒毛鼓起再回落，眼睛微眯，头顶绒毛随气流轻微飘动；声音为鼻腔柔和气流声，无爆破音，尾音拖长约0.8秒`。

### 五、问题处理与收敛（生成出问题时）

**必须先说明再改**：生成视频出现问题时，不要沉默继续、不要自作主张改完就发。正确流程：

1. **说明问题**：明确指出崩坏点（真人化 / 长手指 / 漂浮 / 穿模 / 穿帮 / 绒毛不动 / 镜头突兀跳切 / 动作生硬 / 象声词错位 / 角色漂移），说明出现在第几秒、具体是什么
2. **告知修改方案**：说明打算怎么改（加强哪条禁令、调整哪个字段、重写哪段提示词、是否需要更新三视图）
3. **征求意见**：`我打算这样修改，你看可以吗？`
4. **同时询问是否有其他问题**：`另外，这条片子还有其他需要调整的地方吗？`
5. **待全部反馈确认后再继续**：用户把所有反馈一次给完、确认后，再重新生成

**禁止**：一次只改一处就重生成导致反复返工；禁止用户还没回完就往下走；禁止把多个问题攒着不问。

### 六、固定治愈风格底座

**画风固定成治愈系**：现实生活场景 + 毛绒萌系 IP 角色（不限制材质：长毛绒 / 短毛绒 / 针织 / 羊毛毡 / 软胶 / 灯芯绒 / 布艺 / 混合均可），慢节奏，象声词表演，低饱和暖调。**禁止棚拍 / 纯色背景 / 三维渲染感 / 动画感 / 插画感 / 塑料感**。角色材质必须可信：绒向、压痕、起球、飞绒、重量变形、接缝走线、鼻头脚印 / 肚子上洗不掉的印子必须可见。

**节奏固定成 5-10 秒单镜头**：每条提示词不超过 10 秒，最多 2 个镜头，禁止快切。摄影机总位移不超过 20 厘米，缓慢手持呼吸感，禁止环绕 / 无人机 / 慢动作 / 慢门拖影 / 横摇 / 变焦。竖屏用垂直微位移，横屏用横向微移，不要把竖屏构图直接拉伸成 16:9。

### 七、镜头结构固定成 7 块（顺序不可换）

```
不要出现BGM，不要出现字幕
【全局画质】【角色材质】【灯光与风格】【核心治愈机制】   ← 四段风格控制
@image1 @image2 @image3 ……                                ← 素材句柄
⚠️空间布局 / 人物位置
⚠️本视频严格只有 N 个镜头
【镜头1】画面动作概述： → 画面构图： → 机位： → 动作： → 象声词： → 音效：
环境活动 / 全场音效
⚠️防错警告（按本条实际需要挑）
```

**第四段的关键改造**：通用版叫 `【核心特效】`，本 skill 改名 `【核心治愈机制】`，因为治愈系没有超现实特效——这段写"本条最打动人的那个物理瞬间"，且**必须是一个持续变化的物理过程**（热气上升、绒毛飘动、水珠积累滴落、光影移动），写清形态、运动速度、变化过程、与角色或物体的接触反应，禁止写"温馨治愈的氛围"这种空话。

**四段风格控制的标准模板**：

- `【全局画质】真实实拍摄影质感，高解析，画面符合真实物理。场景为[具体真实环境，含使用痕迹]。角色是实体毛绒玩偶，被当作真实存在的物体拍摄。禁止动画感、禁止插画感、禁止三维渲染感、禁止棚拍塑料感、禁止纯色背景。`
- `【角色材质】[材质]材质，绒长约[X]，[压塌/起球/飞绒/接缝/重量变形/面部材质/清洁度痕迹]，眼睛[颜色]圆润灵动，会自然眨动。`
- `【灯光与风格】[主光来源与方向]，[角色哪侧受光]，[暖色小光源]，[色调]，[颗粒/暗部]。`
- `【核心治愈机制】[本条最打动人的物理瞬间，且必须是持续变化的物理过程：形态、运动速度、变化过程、与角色或物体的接触反应]。`

**镜头段内部固定字段顺序**：`画面动作概述：` → `画面构图：` → `机位：` → `动作：` → `象声词：` → `音效：`。象声词为本 skill 特有字段，位于动作与音效之间；无象声词的极少数镜头可省略，但一条片子里至少要有一次。

### 八、八道 gate 必须逐道确认

1. 角色锁定 → 必须有三视图 + 材质微距，禁止"凭空生成"角色
2. 剧情与象声词 → 从附录挑或自编，象声词第几秒出现要标
3. 画幅 → 默认 9:16
4. 空间调度 → 多角色 / 关键道具落点 / 大型物体互动时必须出俯视调度图
5. 时间划分 → 提示词条数 + 每条时间段
6. 提示词结构 → 首次或变更时确认
7. 交付形式 → 文字 or 网页
8. HTML QA → 仅网页交付时

另加两道：**BGM 确认**（生成前主动问，见"三、音频与背景音乐"）、**问题收敛确认**（出问题时按"五、问题处理与收敛"执行）。

### 九、防崩坏硬约束（每条提示词带以下 6 条为基础）

- ⚠️⚠️⚠️ 禁止角色被画成真人（禁止真人皮肤 / 写实五官 / 鼻孔 / 睫毛 / 嘴唇 / 牙齿 / 舌头）
- ⚠️⚠️⚠️ 禁止长出人类手指，手部保持毛绒整体造型
- ⚠️⚠️⚠️ 禁止悬空漂浮，必须始终有接触面和接触阴影，接触处绒毛要有受力压扁的变形
- ⚠️ 角色是活的：眼睛必须会眨（每2-4秒一次），瞳孔随情绪和光线变化，眼神光随头部转动移动，禁止做成完全静止的死鱼眼、禁止全程不眨
- ⚠️ 眼睛保持圆润可爱的造型：禁止变成写实人类眼睛（禁止眼白占比过大、禁止虹膜纹理、禁止眼角细纹过多、禁止睫毛）
- ⚠️ 嘴部为固定线迹（不随发声开合）
- ⚠️ 绒毛必须有物理反应（被压塌要回弹 / 遇水要黏成一撮 / 遇热要贴伏 / 风吹要倒伏），禁止绒毛全程纹丝不动

可选追加：`⚠️` 体型配色五官以 @image1 为准禁止身份漂移；`⚠️` 影子方向必须与主光一致；`⚠️` 禁止穿模，接触点与包裹关系已写明；`⚠️` 季节物品必须对应，禁止穿帮；`⚠️` 真实生活环境必须有陈设和使用痕迹；`⚠️` 道具必须落在指定台面、有接触阴影和重量感；`⚠️` 本视频严格只有 N 个镜头；`⚠️` 镜头过渡必须自然，禁止突兀跳切；`⚠️` 道具大小关系（西瓜≈角色 2 倍，西瓜必须用两条小臂环抱而不能单手拿）。

**能力边界即萌点**：毛绒角色无手指精细动作，写"环抱 / 捧 / 整个身体压上去"；够不着灶台、拧不开瓶盖、拿不动雨伞、跳不上沙发——让角色努力失败比轻松成功更治愈。

**提示词长度上限**：每条可复制提示词正文 ≤ 1800 中文字符，目标 1200-1600。超长时按此顺序压缩：删重复风格形容词 → 合并环境描述 → 缩短非关键音效 → 减少普通 `⚠️`（只留最关键）。

**竖屏构图要点**：角色位于画面中下部（身体中心约 y=60%），占画面高度 40-65%，头顶上方留 30% 给热气 / 光 / 天空，底部 15% 避免放关键信息（抖音 UI 遮挡）。画面底部不要放象声词发生的部位。

## 产出什么

- 阶段 1 产出：2-3 个内容方向候选方案

3. 摄影机高度、角度、焦段、景别
4. 主光方向与角色受光面
5. 关键道具的位置与尺寸关系
6. 本镜头的动作定格瞬间（不是动作的结束，是动作进行中）


**分镜图的使用规则**：

- 分镜图只作为构图 / 动作 / 空间关系参考，最终视频画面禁止出现任何分镜图痕迹
- 每个镜头的分镜图单独生成，不要一张图塞多个镜头
- 分镜图确认后，视频提示词的空间描述必须与分镜图一致
- 若用户修改分镜图，所有依赖该图的提示词都要同步修改

# 附录 6：角色设定卡字段表 + 常见错误对照表

## 角色设定卡（三视图确认后必须写死，后续所有提示词引用它）

```markdown
**角色名**：
**原型**：蘑菇 / 小熊 / 兔子 / 云朵 / 团子 / 自创
**材质**：长毛绒 / 短毛绒 / 针织 / 羊毛毡 / 软胶 / 灯芯绒 / 布艺 / 混合
**主色与辅色**：主色 + 辅色 + 点缀色（写明色值感受，例如"米白偏黄，不是纯白"）
**真实身高**：约 X 厘米（用参照物锚定：约等于一个马克杯 / 手机 / 拖鞋）
**体型**：头身比、胖瘦、四肢长短
**五官**：眼睛材质与颜色、眼距、鼻子做法、嘴的做法、是否有腮红；眼睛默认会眨会动，瞳孔随情绪变化
**识别点（3个）**：例如"左耳尖有一小块补丁""后颈有洗不掉的小黄印""右脚脚底磨薄了"
  └ 至少 1 个是"不完美"的痕迹，不完美才让人心疼
**四肢能力边界**：能不能抓握精细物体、能不能站立、能不能提重物
**性格**：笨拙 / 好奇 / 慢半拍 / 爱操心 / 贪吃
**专属象声词**：主音（满足时必发）+ 第二音（呼唤时）+ 偶发音（特定情境，制造反差）
**禁止音**：这个角色永远不会发的音（例如温吞的角色不发"嘚嘚嘚"）
```

能力边界是萌点来源。做不了的事情越多，剧情越好笑越治愈：够不着灶台、拧不开瓶盖、拿不动雨伞、跳不上沙发。
