# 附MD文件6 | 女频专属分镜脚本与Prompt输出模板

## #做什么

本模块为女频短剧漫剧的专属分镜脚本与 Prompt 输出模板。

解决：主MD要求产出“视频脚本、Prompt清单、视觉方案”，但缺少统一字段结构、Prompt格式、变量替换规则与负面词库的问题。

本模块只规定分镜脚本与 Prompt 的输出格式，不替代主SKILL的流程调度、戏剧诊断、角色美学禁则、微表情、台词配音、场景光影、视觉底座等规则。

## #需要什么输入

**最少提供：**

- 主MD下发的创作方向与情绪基调。
- 《戏剧张力分析体系》诊断结果。
- 《镜头叙事构思方案》。
- 角色锚点清单、场景锚点清单、道具锚点清单。
- 台词与配音规范。
- 女频专属电影级视觉底座参数。
- 目标画面比例：9:16竖屏。
- 单镜时长：3–5秒。

**可选提供：**

- 目标总时长。
- 是否需要中日双语字幕。
- 是否需要输出视频脚本、Prompt清单、视觉方案。
- 上下游分镜、提示词、视觉方案结果。
- 是否需要参考案例库。

## #怎么做

### 一、遵循主MD全局路由表

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【前置强制指令】。

在分镜脚本与 Prompt 输出环节，重点参考以下父级输出结果：

- 【顶级大导演思维】的戏剧诊断与镜头叙事构思。
- 【提示词】的电影级物理参数底座。
- 【顶级情绪大师】的七层微表情拆解结果。

本模块不再重复列出父级 slugID，也不重复设置门禁指令。若上述父级输出缺失，按本模块“#什么时候问你”处理。

### 二、分镜脚本字段结构

每个镜头必须包含以下字段：

字段内容镜号按场次顺序编号场次场次名称与张力等级时长3–5秒，超限必须拆分景别全景 / 中景 / 近景 / 特写摄影机状态固定 / 手持 / 稳定器 / 轨道等机位正面 / 侧面 / 过肩 / 俯拍 / 仰拍等视角客观 / 主观 / 第一视角等运动路径推 / 拉 / 摇 / 移 / 跟 / 升 / 降等焦点焦点位置与焦平面变化画面内容人物动作、表情、道具、环境台词台词文本与字数音效环境音、动作音、留白处理Prompt正向 Prompt 全文负面Prompt负面词清单参考来源卡号+具体参考

### 【绝对轴线锁定】

在生成任何双人对话、对峙、动作戏Prompt时，必须强制锁定“180度轴线原则”。禁止在剪辑中出现“越轴”（如：上一镜男看左，下一镜女也看左）。\
分镜字段必须增加“轴线侧”标识。Prompt强制写入：`Camera on the left side of the 180-degree line, consistent screen direction.`

### 三、Prompt输出模板

正向 Prompt 必须按以下结构输出：

1. 角色锚点 ID
2. 场景锚点 ID
3. 道具锚点 ID
4. 镜头语言：景别、机位、角度、运动、焦点
5. 光影与色调
6. 女频唯美数字电影参数
7. 情绪与微表情指令
8. 画面比例与时长
9. 负面 Prompt

示例结构：

`[角色ID] + [场景ID] + [道具ID] + [景别/机位/角度/运动/焦点] + [光影色调] + [女频视觉底座参数] + [微表情指令] + 9:16 + 3-5秒 + [负面Prompt]`

### 四、输出规则

- 单镜时长 3–5 秒，禁止超过 5 秒的复杂长镜头。
- 台词字数 ÷ 4 = 所需秒数；超过 4 秒必须拆分为两个独立节点。
- 每个 Prompt 必须包含角色 ID，禁止五官漂移。
- 每个 Prompt 必须包含防穿模负面词。
- 每个 Prompt 必须与《戏剧张力分析体系》的诊断结果一致。
- 禁止使用平台/模型专属词汇，统一写“AI视频工具、AI生成链路、AI工业化链路”。

【绝对轴线锁定】\
在生成任何双人对话、对峙、动作戏Prompt时，必须强制锁定“180度轴线原则”。禁止在剪辑中出现“越轴”（如：上一镜男看左，下一镜女也看左）。\
分镜字段必须增加“轴线侧”标识。Prompt强制写入：Camera on the left side of the 180-degree line, consistent screen direction.

## #产出什么

最终交付：

- 女频专属分镜脚本
- Prompt清单
- 视觉方案
- 视频脚本
- 负面Prompt禁则清单
- 镜头字段表
- 每个镜头对应的参考来源索引
- 可直接进入AI视频工具生成链路的执行清单

## #什么时候问你

出现以下情况时，必须停下来问用户：

- 缺少戏剧诊断、镜头叙事构思或锚点清单。
- 单镜时长需要超过 5 秒。
- 台词超过 15 字且需要拆分。
- 用户要求突破防崩、防穿模、防塑料感禁则。
- 用户要求输出视频脚本、Prompt清单、视觉方案，但缺少关键输入。
- 本模块与上游主SKILL、提示词Skill、情绪大师或其他附MD规则冲突。
