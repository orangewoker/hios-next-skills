# 垂类适配 — 风格美学 2.2.2

本 Skill 归入 LibTV **2.2.2 风格美学 / MV** 垂类。以下是对齐要点与量化阈值。

---

## 一、完整性标准（替代五要素）

风格美学垂类**不要求**叙事五要素，而要求：
- **统一视觉主题**：全片同一套天野流线语言 + 气韵三律。
- **情绪曲线**：呼吸式（线稿）或华美式（彩稿），首尾情绪呼应。
- **视觉符号重复 ≥2 次 + 首尾呼应**：翼/光环/长发/月。
- **写实要求可放宽**：天野梦幻非写实天然合规。

---

## 二、六维视听语言覆盖

| 维 | 本 Skill 做法 |
|----|--------------|
| 视觉主题 | 天野流四元 + 双模式 |
| 情绪曲线 | 呼吸式/华美式，贯穿全片 |
| 视觉符号 | 主符号重复呼应 |
| 运镜 | 无重力缓浮、溶解转场、动机=漂移 |
| 剪辑点 | 对齐 MV 节拍/咬音 |
| 音乐同步 | MV 段落映射表（见情绪曲线文件） |

---

## 三、量化阈值（自检对照）

- 画幅：**2.39:1** 宽银幕。
- 分辨率：**≥1080p**（建议 1536×640 或 1920×800）。
- 成片时长：**16s–5min**（单镜 3–10s）。
- 留白（线稿）：**≥65%**；金箔（彩稿）：作线非色块。
- 视觉符号重复：**≥2 次**且首尾呼应。

---

## 四、红线清单（LibTV 平台）

- 无硬编码绝对路径 ✅（全用 `references/*.md` 相对引用）
- 无代码执行 ✅（纯 prompt / 模板 / 判断逻辑）
- SKILL.md ≤ 10000 字符 ✅
- 单集成片，非长剧集 ✅
- 内容安全合规 ✅（无违规元素）
