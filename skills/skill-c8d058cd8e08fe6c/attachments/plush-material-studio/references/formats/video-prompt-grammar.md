## 1. 视频 prompt 基本结构

TVC 毛绒广告的视频 prompt 按时间轴 beat 组织，每个 beat 包含：相机、画面、毛绒主体/动态、声音线索。

```
Q版卡通毛绒风格，
0-3s: <相机> <画面> <毛绒主体登场> <声音>
3-7s: <相机> <画面> <毛绒质感特写/互动> <声音>
7-12s: <相机> <画面> <产品曝光/卖点> <声音>
12-15s: <相机> <画面> <品牌记忆点> <声音>
```

时长 ≤15s 的成片用一次视频生成即可拿到完整片段。上面的 beat 是同一条 prompt 内的时间轴描述，不是分段多次生成。只有成片超过 15s 时才拆成多个 ≤15s 片段分别生成再做后处理拼接。

## 2. beat 模板与时间轴

### 0-3s 钩子 beat
- 目标：3秒内让观众看到"毛绒世界"并产生好奇
- 常见模式：毛绒主体从画面外滚入/蹦入/从毛绒云后面冒出
- 相机：全景或中景，可带轻微推近
- 声音：轻快弹跳音/蓬松接触音/环境治愈BGM起

### 3-7s 展示 beat
- 目标：展示毛绒质感细节和产品/角色特征
- 常见模式：特写绒毛纹理、产品Logo、角色表情
- 相机：近景或特写，缓慢平移或环绕
- 声音：绒毛摩擦沙沙声/角色可爱音效

### 7-12s 卖点 beat
- 目标：把产品卖点融入毛绒互动
- 常见模式：产品毛绒化后的功能演示（如毛绒润唇膏被轻轻挤压弹回）
- 相机：中景，可带产品特写穿插
- 声音：产品功能对应音效/品牌口播旁白

### 12-15s 品牌收束 beat
- 目标：品牌记忆点——产品可见 + logo可读 + 品牌语 + 声音收束
- 常见模式：毛绒主体定格在品牌场景中，logo淡入，品牌语出现
- 相机：中全景，稳定或缓慢拉远
- 声音：BGM收尾/品牌音效/旁白收束

## 3. 毛绒动态描述词库

### 弹性与形变
- 落地弹跳两下后回弹定型
- 被轻压后缓慢弹回原形
- 绒毛随弹跳波动起伏
- 被风吹起绒毛方向统一飘动

### 蓬松感动态
- 炸毛蓬松随动作抖动
- 落地时绒毛压扁后恢复
- 角色转身时绒毛惯性甩动
- 摸绒毛后手指留下压痕

### 互动动态
- 毛绒角色抱住毛绒产品
- 毛绒角色把产品举过头顶
- 产品从毛绒包装中蹦出
- 毛绒场景元素随风轻微摆动

## 4. 相机运镜词库

| 运镜 | 描述词 | 适用 beat |
|---|---|---|
| 推近 | 镜头缓缓推近，从全景到近景 | 钩子→展示 |
| 平移 | 镜头横向缓慢平移，展示毛绒场景 | 展示 |
| 环绕 | 镜头绕主体缓慢旋转 | 展示产品 |
| 俯拍 | 俯视角度，毛绒主体在画面中央 | 钩子/收束 |
| 仰拍 | 仰视角度，毛绒主体显得高大 | 收束 |
| 拉远 | 镜头缓缓拉远，从近景到全景 | 收束品牌 |
| 固定 | 镜头固定不动，主体在画面中活动 | 展示互动 |

## 5. 声音线索词库

- 轻快弹跳音：蹦、弹、落地的Q弹声
- 蓬松接触音：沙沙、轻柔摩擦绒毛声
- 治愈BGM：温暖钢琴、木琴、轻柔铃铛
- 活泼BGM：轻快ukulele、电子可爱
- 品牌音效：品牌标志性声音
- 旁白口播：品牌语/产品卖点口播

## 6. 完整 TVC prompt 范例

### 产品毛绒化 TVC（15s）
```
Q版卡通毛绒风格，
0-3s: 全景镜头缓缓推近，毛绒化厨房场景中，@图片1所示的饼干盒变成圆滚滚的中绒毛绒角色从画面左侧蹦跳入场，落地弹了两下绒毛随弹跳波动，轻快弹跳音起，治愈温暖BGM进入
3-7s: 近景镜头缓慢平移特写毛绒角色面部，大而黑亮的眼睛眨了眨，面部短绒质感清晰可见，中绒蓬松身体微微晃动，绒毛摩擦沙沙声
7-12s: 中景镜头环绕毛绒角色，角色把毛绒化的饼干举过头顶展示，保留品牌配色和logo辨识，活泼BGM加强，旁白"毛绒化的XX，治愈每一刻"
12-15s: 中全景镜头缓慢拉远，毛绒角色定格在毛绒化厨房场景中央，品牌logo在画面下方淡入，品牌暖色调收束，BGM温暖收尾
```

### 角色毛绒化 TVC（15s）
```
Q版卡通毛绒风格，
0-3s: 俯拍全景，毛绒化草地上，@图片1所示的角色变成Q版毛绒玩具从毛绒云后面冒出，头身比1:1大头圆身，炸毛蓬松，蓬松接触音起
3-7s: 近景特写，镜头缓缓推近毛绒角色面部，保留原发型轮廓，面部短绒五官清晰，弯弯眼笑表情，绒毛边缘有金色轮廓光，温暖BGM
7-12s: 中景环绕镜头，毛绒角色转身时绒毛惯性甩动，穿着毛绒化标志性服装，拼合缝线可见，俏皮活泼BGM
12-15s: 镜头缓缓拉远到全景，毛绒角色站在毛绒化场景中央挥手，品牌色背景，logo淡入，治愈BGM收束
```

## 7. 落 prompt 前自检

- 是否以"Q版卡通毛绒风格"开头？
- 每个 beat 是否以相机起手？
- 0-3s 是否有钩子且与首个画面动作一致？
- 毛绒动态描述是否具体（弹跳/甩动/压扁恢复）？
- 产品卖点是否融入互动 beat？
- 12-15s 是否有品牌记忆点（产品+logo+品牌语+声音）？
- 声音线索是否每个 beat 都写了？
- 参考图是否用 `@图片N` 引用？
- 总时长是否 ≤15s（一次生成完整片段）？
- 是否全部正向措辞？
