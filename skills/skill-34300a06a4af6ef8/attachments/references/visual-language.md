# 视觉语言：柔润、真实、有生活

这些是宋韵生活题材的默认方向。用户提出不同天气、时段、人物阶层或情绪时，重新安排光色和材料，不把宋韵锁成一张滤镜。

## 光影如何成立

先写清场景里的光从哪里来，再写它落在什么上。可采用以下关系，按本镜需要选择：

| 场景关系 | 可以看见的结果 | 容易偏离的写法 |
| --- | --- | --- |
| 薄云过滤日光，天空与地面自然补光 | 脸部有方向但不过硬，浅色衣服保留织纹与褶皱 | 全脸没有明暗的“均匀补光”、通体发亮 |
| 屋檐外较亮、铺内较暗 | 人物从深色木构背景中显现，铺内仍有层次 | 背景死黑、脸上无来由的聚光灯 |
| 克制的侧后方日光 | 鬓发和肩部局部轻亮，脸部由环境光照亮 | 一整圈发光描边、金黄色滤镜 |
| 远山与村落随距离逐渐变淡 | 近处真实可辨，远处松开，空间有空气 | 浓雾盖住全部场景、近处皮肤也变糊 |
| 水面与湿土分开反光 | 水面局部映天，泥土较暗、有湿润感 | 全地面如镜面、满屏闪烁 |

“朦胧”可以来自自然空气透视、柔和亮部过渡和轻微光学扩散。保留皮肤、布料与器物的辨识度，不把失焦、低分辨率或磨皮当成质感。不要机械地让每一镜都同时拥有薄雾、逆光、胶片颗粒和光晕。

阴天、雨天、清晨、傍晚或室内也可以成立；根据天气与实际光源修改，而不是沿用白天侧逆光后再叠加另一套效果。

## 色彩与材质

可用灰瓦、木色、土色、草木绿作环境基底，以米白、浅杏、青灰等人物衣色形成轻重关系，花朵或器物提供少量色彩焦点。颜色服从地点、季节与身份，不能把所有场景统一调灰、调黄。

- **皮肤：** 有细微纹理、自然肤色差异和符合年龄的面部结构；保留正常表情，不靠“网红脸”撑美感。
- **衣料：** 丝织物可细腻柔和，农作粗布可哑光、有纤维与重量；袖口、腰带和衣摆随动作形成不同褶皱。
- **木材与器物：** 木铺、竹篮、陶碗各有表面与接触声音，不要求每件物品都破旧肮脏。
- **田园：** 湿泥、水、秧苗、草叶能分开读出；风、水波和劳动引起的变化有各自原因。

近景需要支持这些细节，远景需要支持田块、建筑和活动的结构。避免全片大光圈导致环境消失，也不把“50mm、f1.4、35mm 胶片”作为电影感的通用配方。

## 构图与场面

### 市井与花市

前景可用花枝、门框、栏杆或摊位边缘，建立“从这里看进去”的位置；中景留给主要人物；背景延伸街道、摊铺与生活。少量遮挡有纵深，不能遮住递物、簪花等关键动作。

浅衣人物可放在深木背景前。主角有明确目标，商贩与行人做各自的事。热闹程度可调，不把满屏人群、灯笼、飞檐与华服当作古风的必要条件。

### 田园与宏大场景

用地势、水路、田埂、树丛、村落和山色组织前后关系。田块大小和方向可有差异；人物与建筑的相对尺度可信，主要行动仍可辨认。

前景柳枝或草叶提供近处尺度，中景有农事与主要事件，远处村落与山色收住空间。几组农人动作自然错开，避免整齐复制、集体同时抬头、所有人都为主角表演。

“大景—人物—大景”适合田园送茶等叙事；如故事需要持续跟随、固定远景或别的节奏，可以更换。宏大感不强制航拍，不要求悬浮山、巨型建筑、密集群演或快速俯冲。

农事与季节协调：新插秧水田不能同时成为成熟金黄稻浪。送水、插秧、晾绢、收物、洗菜等日常内容可按当前故事选用，视觉质感需统一。

## 人物在画面里为什么可信

每个主要动作都有对象、来由和结果。例如：发现对方的需要或心情 → 接近 → 递出或接触 → 对方理解 → 新的状态。不是所有动作都要拆成五镜，也不要把微表情规定到每一帧。

交接时看得见物件从谁手中到谁手中，接稳后再放手；簪花时有接近、轻放或固定、松手和受赠者的反应；跨越田埂时考虑高差、脚步和重量。用必要细节指导生成，不堆积不可能同时完成的动作。

含蓄可以是欲言又止、短暂停留、视线变化或轻微笑意；人物也可以惊喜、急切、失落。不要把温情和微笑设为所有宋韵故事的唯一情绪。

## 时代感的边界

按场景需要写宋韵生活与日常衣着，避免默认宫廷盛装、仙侠披风和现代物件。审美参考中的建筑、发式和服饰不能直接作为宋代制度或形制的证明。用户要求严格历史复原时，先对具体地区、时期和关键物件查证，再创作；不把审美认可称为考据通过。

## 静态资产的光影与景深

场景底图优先选择可读的自然侧光、开阔天光或窗光，保持足够景深，让建筑开口、路径与物件位置清楚。前景遮挡可选，不默认放巨大虚焦花团。柔光仍有朝向与落影，不能把所有表面照成同一亮度。

角色定妆优先使用中性、柔和、带轻微方向的照明，面部两侧与衣装结构可辨；不要求金色轮廓光、强戏剧光或极浅景深。素绢保留厚度、垂坠和细织纹，局部透光不能变成整幅发亮的薄纱。剧情关键帧可以根据情境增加明暗反差，但不能牺牲人物与场所的关系。
