# 场景写作：把变化写成可演、可看、可听的经验

需要将大纲写成场景、把小说改成可拍剧本、修对白、压缩或删场，或现有场只有解释没有可经历的行动时读取。忠实处理单场时只在本场权限内工作，不顺势改写人物长期关系或扩成全剧。

## 最小输入

取得该场原文或目标、前后相关场、人物进入状态、故事日期、观众与人物知情、必须保留的事件以及改编权限。缺少非关键细节可以提出注明来源的导演候选；缺关键事实先保留分支，不能静默补成原文。

场记录与版本依[核心记录](../core/03-records.md)。故事与人物依据来自[长片与剧集](02-series-and-feature.md)，权限来自[项目契约](../core/01-project-contract.md)。已知授权内的写作继续推进，不要求先获得图像、模型参数或完整资产表。

## 先决定这场为何存在

用一句具体的话说明：观众在经历此场后，对信息、关系、压力、认识、情绪或时间有何不同。再找到完成它的可见行动、声音、停顿或观察经验。变化可以很小；不要求每场都有争吵、秘密或反转。

| 场的主要功能 | 写作时追问 | 不适用的机械判断 |
|---|---|---|
| 人物选择与关系变化 | 对谁做什么，阻力在哪里，选择留下什么后果 | 有情绪形容词就视为行动充分 |
| 信息揭示 | 谁用什么方式得到信息，观众何时理解 | 所有信息都由对白解释 |
| 日常、等待、沉默、余波 | 观众在停留中发现什么，注意力如何变化 | 因没有冲突词而删场或强加动作 |
| 空间／时间转换 | 需要哪些线索避免误判，转换本身有何体验 | 为了更快删掉全部定位信息 |
| 蒙太奇、梦境、内心经验 | 声画关系与选择顺序形成什么理解 | 强制改成写实对话场 |

删场或合并前，写清将失去的独特经验，以及由哪一场实际承担它。若新承担场尚未成立，不把“其他地方会补”当作已经修好。

## 写作判断的顺序

1. **进入与离开。** 人在何处、带着什么关系与知识进入，离开时发生了什么。把表面任务和深层需要区分开，但不要求每场都表达完整人物弧。
2. **行动与阻力。** 人物采取什么可演的做法，另一人或环境如何回应；若只写“终于放下了”，改成观众能经历的选择及后果。内心独白、旁白也可以是作品手段，须明确声音归属与画面职责。
3. **转折与反应。** 哪个事件改变策略，谁先察觉，观众如何看到或听到。关键沉默与倾听反应写出触发和作用，不用固定停顿秒数代替表演。
4. **对白。** 台词是行动的一部分：试探、拖延、安抚、拒绝，或确实需要传达信息。保留角色的具体说法、回避方式与对手影响；不要让每人轮流总结主题。
5. **可拍性。** 交物、开门、发现、决定、受伤等必要事件是否有具体发生位置和可感知形式。尚未确定的手别、机位和精确节奏留给导演与预演，不从文字段落数派生镜头数。

先改场功能和人物逻辑，再打磨句子。若对白声称人物已和解，行动却只支持暂时合作，应调整表述或补足经历，而非只换同义词。

### 台词诊断与候选改写

需要改台词时先问三件事：这句话压着什么没有说出的意图或关系压力；对方已经知道哪些信息，哪些内容不必再次解释；说出口后局面、立场、情绪或行动推进了什么。三问用于发现病灶，不要求每句归入固定攻防类别，也不擅自删除用户锁定的对白。

保留一个短对照：原句 → 候选改写 → 表达收益、代价与适用条件。改写可能提高潜台词或节奏，也可能损失人物直白、类型语感或剧本原有措辞；若改变人物承诺、知情或关系进度，应标为改编提议并走[变更影响](../core/05-change-impact.md)，不能伪装成润色。

## 原文、改编与导演补充

保留短对照，足以让人辨认变化的来源：原文事实及位置、必须保留的体验、删压合并的提议与理由、新增内容的作用、涉及的人物／故事影响。导演补的空间或道具安排标“实现候选”；改剧情结果标“改编提议”。不把隐含推测写成原作明确事实。

比如原文只有“钥匙放桌角”，可比较靠门角与远侧角如何影响走位；原文未给手别，可先留未定。把“问从哪开始”改成“我永远不会走”，已经改变人物承诺，应按[变更影响](../core/05-change-impact.md)处理，不能当对白润色。

## 可浏览的场景交付

正式 Scene 页先给场景卡，再给可直接阅读的剧本正文；已存在正文不重复抄写。卡片保留场功能、人物进入与离开状态、故事日期／知情依据、必要行动与反应、空间／声音需求、与前后场关系、未定处。正文区分场景标题、行动、角色与对白；需要内心或非现实声画时明确表达方式，避免把无法外显的心理说明误当已拍到的内容。

以下为原创纸面示例，未生成图像、视频或声音，未排练：

> **场功能：** 林舟从结束交接，转为愿意共同处理一项责任。仍不承诺长期留下。  
> **进入：** 林舟背包在门内、想赶车；林岚守着账本、不愿直接求人。  
> **离开：** 两人同桌认账；钥匙已交还，离城计划仍未决。  
> **不可丢失：** 交钥匙、邀请、听见邀请后的选择、坐下；“看门”是选择压力的可见线索。

```text
内景　修理店　夜

林舟站在门内，包还背着。

林舟：末班车快到了。

林岚没有抬头。

林岚：钥匙留下。

林舟把钥匙放在账桌靠门的一角，缩回手。
林岚把账本转向身旁的空椅。

林岚：爸的字，你认得。

林舟看一眼门。包带仍绷在肩上。
他卸下包，绕过桌角，拉开空椅坐下。

林舟：从哪儿开始？

林岚把笔放到两人中间。
```

导演可以探索停顿、视线、卸包与坐下的具体节奏；“在邀请之前就卸包”会使选择提前，属于需要检查的变化。剧本没有规定每句一个特写，也没有承诺整场应一次生成。

## 检查与返修入口

先读完整场，再连前后场读：是否出现只有作者知道的必要信息；是否让人物提前知道或承诺；是否重复已明白的内容；反应有无被对白挤掉；关键物理事件是否缺步骤；静默是否给观众真实的观察对象。口头读台词可帮助发现语言拥挤，但纸面朗读不能证明实际声画表演成立。

| 发现的问题 | 首选处理 |
|---|---|
| 只剩说明与总结 | 回场功能与行动，让信息经选择、阻力或视听经验出现 |
| 台词过长、必须猛删才能容纳 | 判断信息与表演是否过载，再决定拆场、改表达或延长；不按固定秒数硬裁意义 |
| 动机突然、知情错误 | 回[长篇人物与信息](02-series-and-feature.md)核对经历与日期 |
| 人物逻辑成立，但表演空泛 | 交[导演与表演](04-directing-performance.md)建立触发、策略和对手反应 |
| 交物或走位无法看清 | 交[场面调度](05-blocking-action.md)与[摄影覆盖](../visual/02-cinematography-coverage.md) |
| 剧本写对了，素材没有实现 | 以实际观察建 Issue，经[问题返修](../quality/02-repair.md)区分制作与剪辑原因，不先重写剧情 |

场景完成写作后可进入导演设计；进入生产的依据按核心记录登记确切版本。重大关系、信息和场功能变更走核心影响检查；执行由生成模块负责。
