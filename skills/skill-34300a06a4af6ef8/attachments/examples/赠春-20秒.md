# 赠春：约 20 秒视频示例

```text
约20秒，横向画幅，宋代江南花市的生活短片，真实古装电影外景摄影质感。温润、自然，有人间烟火气。

自然日光经薄云与铺檐柔化，人物面部由街面和天空自然补光，脸上有柔和的明暗过渡。人物靠近敞开的花铺侧面，身后木构与铺内稍暗，浅色衣服从背景中显现。皮肤保留细微纹理，衣料有褶皱，花瓣、竹篮、陶花器和木台各有质感。近处清楚，街道远处自然变柔；亮部克制，空气清润，不用浓雾和大片光晕。

年轻成年姑娘在画面左侧，穿米白与淡青灰的日常衣裙，发式简洁；四十多岁的卖花妇人在右侧，穿青灰粗布衣，发髻朴素，用一支简单发簪固定。两人站在花摊敞开的侧边，之间没有桌案阻隔。姑娘刚买下一朵小巧的粉色芍药，铜钱已经放在摊边小碟中，花在姑娘手里。花茎短且便于轻插在妇人现有发簪旁，不能横穿头部。

0—4秒：
花铺侧面的中景，前景有少量虚化花枝，身后可辨木铺和缓慢经过的行人。姑娘低头看手里的花，妇人看着她，自然地说：“这朵衬你。”姑娘听见，目光从花转向妇人。

4—7秒：
稍近的双人镜头，姑娘看见妇人素净的发髻，生出一个念头，轻轻笑着说：“也衬您。”她抬起拿花的手，朝妇人靠近半步。妇人看懂她的意思，略微低头配合。

7—12秒：
侧面中景，两人的手、花与妇人发髻都能看见。姑娘把花移近妇人鬓边，轻轻将短茎固定在已有发簪与发髻之间。花稳定停住后，她才松开手，手自然退回。妇人保持配合的姿态，视线随着姑娘的动作变化。

12—16秒：
妇人的中近景，姑娘的肩部在画面边缘轻微虚化。妇人先停一拍，抬手轻触鬓边的花，再抬眼看姑娘，笑容逐渐展开。保留面部的年龄纹理、轻微呼吸和这一刻的停顿。

16—20秒：
回到花铺双人中景，妇人放下触花的手，两人自然对视微笑。粉色花留在妇人鬓边，花铺、陶器、枝叶与身后继续生活的街道构成完整空间。镜头稳定停留，让这一刻结束。

人物面容、衣着、花朵与发簪跨镜保持连贯。动作按接近、固定、松手、触花与回应的顺序发生，花不能凭空出现在头上。摄影机从容，以自然切换连接镜头。

声音保留轻微街市声、衣料摩擦声与两句自然对白，配乐可轻淡陪衬，不抢人物反应。无旁白，无字幕、标题、水印和额外黑边。
```
