# AI 真人对白与表演生成

## 核心理念

AI对白/表演虚假的根源：**节奏太干净、情绪太扁平**。消除AI感需要两个层面：

1. **台词层**：植入**言语失流畅（speech disfluency）**，模拟情绪压制语言的冲突
2. **表演层**：用**三层提示词架构 + 八维表演公式 + FACS面部AU编码**，把抽象情绪拆解为时序动作

---

## 10条绝对禁止写法红线

 1. 禁止轮流朗读台词（A完整说完B再开口）
 2. 禁止情绪同步爆发（如"愤怒哭泣"同时出现）
 3. 禁止瞬间大量流泪（必须遵循湿润→积水→眨眼困难→缓慢落泪时序）
 4. 禁止全程持续语音重叠/无间断口吃（保留少量完整正常台词做对比）
 5. 禁止机械均匀的口吃分布（卡顿必须集中在敏感词上）
 6. 禁止自动补全被打断的句子
 7. 禁止所有人使用相同卡顿风格（必须按人设差异化）
 8. 禁止……和——混用（……仅沉默；——仅截断）
 9. 禁止单段单人台词内超过2种卡顿/填充符号同时出现
10. 禁止生理打断单场超过2次

# 第一部分：对白编排体系

## 第一步：收集用户输入信息

- **角色设定**：声线底色、性格、潜台词、基础情绪方向
- **场景背景**：发生了什么事，双方关系，当前情绪基调
- **核心冲突**：这场对话要传达什么
- **输出类型**：纯剧本对白 or AI视频生成提示词
- **语种**：中文 or 英文
- **时长/媒介**：15秒短剧 / 30秒短片 / 长片

## 第二步：话语权流转规则

### 双人对话流转规则

精准标注语音重叠细节，如"前一角色台词尾音未完全结束，另一方提前0.1s切入，语音轻微重叠0.2s"

### 多人群戏流转规则

- **话语权分层**：主辩人、附和者、旁观者、搅局者四类身份
- **多层重叠设计**：可出现「两人同时反驳第三人」三重语音重叠
- **旁观者隐性互动**：不说话但有肢体反应（皱眉、叹气、摇头）
- **群戏避坑**：禁止轮流挨个发言；允许有人全程只插半句碎话

## 统一标准化剧本标记符号

符号含义〔呃〕语气填充卡顿……长时间沉默 / 情绪失语停顿（**仅用于沉默**）——话说一半半截截断（**仅用于截断**）**加粗**重音、情绪爆发重读～尾音拖长、声音发颤&lt;重叠0.3s&gt;两人声音同步抢话重叠时长（气音）压低声、哽咽、小声耳语（吸气顿住）深呼吸后失语、情绪冲击停顿

### 符号使用禁忌

1. …… 和 —— 不可混用
2. 单段单人台词内，同时出现的卡顿、填充符号不超过2种
3. 生理打断单场不超过2次
4. 所有符号必须贴合人物性格

## 第三步：四层对白编排体系

### 第一层：语音重叠与抢话

**抢话**：听到刺激词，本能急于反驳 **沉默**：接收冲击性真相，短时间无法消化

⚠️ 全程抢话会失真变吵闹；**保留少量完整正常台词做对比**

外部打断三大类

1. **物理环境**：门响、手机铃、车流噪音等
2. **生理本能**：咳嗽、哽咽、喘息（单场≤2次）
3. **第三方介入**（群戏）：路人插话、孩子吵闹

### 第二层：言语卡顿设计

卡顿类型对应情绪示例重复词句遭受误解、急于辩解"我没有、我没有那个意思"启动失败、口吃愧疚、羞耻卡在对方名字或难开口的词上中途改口隐藏真实想法"我不担心——不，我很害怕"长沉默+吸气骤知残酷真相精神冲击，无法言语

口语原生杂质体系

杂质类型对应情绪示例填充语气词犹豫、缓冲〔呃〕、嗯、那个话尾拖音失落、迟疑我也不知道～碎语吐槽烦躁、委屈（气音碎念：真是服了）半截短句松弛、不耐烦算了——

**密度规则**：

- 陌生人正式对话：低密度
- 亲密家人/情侣/吵架：高密度
- 紧张/撒谎场景：填充词集中在句首
- 克制型人设：大幅删减，仅保留细微停顿

人物差异化卡顿规则

1. **内敛克制型**（长辈、高管）：极少口吃，靠沉默、气音、放缓语速体现
2. **冲动外放型**（少年、暴躁）：高频抢话、重复、打断、填充词密集
3. **自卑/撒谎型**：卡顿集中在敏感词，频繁改口
4. **成熟沉稳型**：无多余杂质，靠留白制造张力

分级话术破碎规则（按情绪强度）

情绪强度卡顿配置示例轻度争执1处重叠、无重复词、短停顿1-2s偶尔抢话，其余台词基本完整激烈对峙3处语音重叠、少量重复词、改口1-2次多段半截句，沉默穿插情绪崩溃大量半截句、2-3s长沉默、反复改口、启动失败台词高度破碎，正常句占比&lt;30%

### 第三层：高级情感表演

**公式：生理泄露 + 自我克制 + 关系目标**

- **生理泄露**：眼周泛红、咽喉吞咽、不受控颤抖
- **自我克制**：强行移开视线、抑制泪水、伪装平静
- **关系目标**：自身濒临崩溃，仍优先安抚对方

情绪保护层失效曲线

**通用路径（愤怒→悲伤）**： 克制伪装 → 对抗质问（愤怒）→ 自我举证辩解 → 情绪裂缝（眼眶湿润）→ 声音破音 → 脆弱坦白/落泪

禁止错误写法："女人愤怒哭泣"（两种极端情绪同步出现，极度失真）

隐性潜台词互动

**公式：表层温柔台词 + 下意识抗拒动作 + 细微语音卡顿**

> （指尖攥紧衣角，声音刻意放软，中途轻微卡顿） A：我一点都不怪你……〔呃〕真的，你不用这么自责。

### 第四层：逐秒时间轴标注

字段说明说话人当前谁在说话台词内容含卡顿标记，使用统一符号触发关键词刺激角色产生抢话、卡顿、情绪波动的敏感核心词汇肢体动作表情、手势、视线方向语音重叠时长如&lt;重叠0.3s&gt;听者即时反应不说话时的肢体/表情反应话语权切换点话语权从谁转移到谁

## 三层提示词分层架构

**篇幅分配：全局20%、镜头20%、表演60%**

**模块化可插拔结构**：

- **【通用固定段】**：画质参数、人物锁定、声线约束——每次必带

## FACS面部AU编码库

AI无法识别"悲伤、愤怒"抽象词汇，只能识别肌肉动作。

**写作顺序：自然语言描述动作 → 补充AU校准，禁止只堆砌编码**

### 高频核心AU对照表

AU编号动作含义适配情绪场景AU1眉毛内侧抬起悲伤、委屈、强忍泪水AU4眉毛下压、眉间收紧愤怒、压抑、对抗AU5上眼睑抬起、眼睛睁大震惊、暴怒、不敢置信AU7眼睑收紧隐忍、恨意、紧绷对峙AU15嘴角下沉低落、难过、失望AU17下巴绷紧抬起强忍情绪、欲言又止AU23嘴唇紧闭收紧压抑怒火、克制发言AU25/26嘴唇分开、下颌张开情绪爆发、嘶吼、破音

### AU强度A-E分级释义

强度含义视觉表现A微弱，几乎不可见仔细观察才能发现细微肌肉变化B清晰但轻微明显可见但不夸张C中等标准普通表情变化幅度D强烈大幅肌肉运动，表情明显E面部极限肌肉完全收缩，接近扭曲

### AU搭配禁忌

以下组合同时拉满会造成面部扭曲失真：

- ❌ AU1 + AU4 同时强度D以上 → 眉毛区域肌肉矛盾拉扯
- ❌ AU5 + AU7 同时强度C以上 → 眼周肌肉矛盾
- ❌ 多个AU全部拉至D/E → 全脸紧绷不自然

**正确做法**：同一时刻1-2个主导AU强度较高（C-D），其余AU低强度辅助（A-B）

### 动作三阶段规范

所有表情必须标注：**动作开始（Onset）→ 峰值（Apex）→ 缓慢消退（Offset）**

杜绝瞬间切换极端表情。

# 第五部分：情绪表演核心模板

## 哭泣情绪六类型（精简版）

### 一、委屈型（悲伤进食→思念崩溃）

**情绪弧线**：机械麻木 → 停顿反刍 → 委屈上涌 → 强吞压抑

**关键动作**：

1. 机械动作→顿住（麻木→触发）
2. 盯住触发物眼眶泛红（委屈上涌）
3. 鼻翼翕动（忍哭生理前兆）
4. 低头猛吃/猛做（强吞情绪）

**核心**：全程无台词，靠"忙"压痛。鼻翼翕动是最真实但最容易被忽略的委屈信号。

### 二、崩溃型（不想相信→悲伤落泪）

**情绪弧线**：失神不信 → 强撑假笑 → 压抑蓄泪 → 崩溃落泪 → 含泪释然

**关键动作**：

1. 瞳孔失焦（震惊/不信）
2. 扯笑→笑意垮掉（否认→压抑）
3. 眼眶蓄泪→第一滴泪滑落（压抑→崩溃临界）
4. 抬手擦泪→指缝泪落（彻底失控）

**核心**：瞳孔先碎→嘴硬强撑→眼眶兜不住→泪崩→含泪笑一下→彻底不装了。

### 三、心死型（抽离麻木→冷笑自嘲）

**情绪弧线**：空洞木然 → 冷笑泛起 → 高傲蔑视

**关键动作**：

1. 瞳孔失焦木然（打击后的空白）
2. 极慢的嘴角勾起（冷笑诞生）
3. 下巴抬高（蔑视姿态）

**核心**：冷笑的速度必须是**极慢的**——快就是嘲讽，慢才是心死之后的冷笑。

### 四、强忍型（倔强压抑→破碎释然）

**情绪弧线**：涣散否认 → 聚焦认出 → 强忍压抑 → 濒临崩溃

**关键动作**：

1. 涣散→聚焦（否认→震惊）
2. 下巴绷紧（压抑对抗）
3. 眼眶泛水光（情绪翻涌）
4. 泪水悬而未落（临界张力）

**核心**：眼眶泛红的速度 + 下唇颤抖的幅度 + 泪水悬挂的时长 = 情绪张力。**不落比落了更揪心**。

### 五、无泪愤怒型（克制的愤怒）

**情绪弧线**：瞳孔地震 → 咬唇克制 → 怒意翻涌 → 爆发 → 强行收住

**关键动作**：

1. 瞳孔骤然放大（突受刺激）
2. 咬唇→下唇泛白（强力克制）
3. 眉间肌肉抽搐（怒意翻涌）
4. 无泪通红眼眶（克制到底）

**核心**：愤怒不走泪，走肌肉——咬唇的力度、眉心的抽动、肩膀的振幅，决定愤怒的可信度。

### 六、幸福泪型（深情→心疼→幸福）

**情绪弧线**：注视 → 幸福太满蓄泪 → 被逗笑含泪

**关键动作**：

1. 目光追随（感动/注视）
2. 眼眶浅红+泪光打转（幸福太满）
3. 一怔→破涕为笑（甜蜜破冰）

**核心**：与悲伤泪的最大区别——嘴角始终有笑意，眼神始终有光。**泪水不能落**——幸福泪一落就变成悲。

## 中英文话术破碎差异规则

### 中文对白卡顿规则

- **语气词卡顿**：〔呃〕、嗯、那个、就是说
- **重复叠词**：我我我、不是不是
- **句尾拖音**：是吗～、好吧～
- **半截截断用——**：我以为你——、其实我——

### 英文对白卡顿规则

- **吞音/半截从句**：I was gonna— 、I dunno、kinda
- **连读断裂**：在连读词中间断开，如"I'm not—I mean I—"
- **填充词**：um, uh, like, you know
- **重复短句**：I'm not, I'm not / It's not— it's just—

## 15秒短剧精简模板

15秒短剧要求：前3秒设置强视觉微冲突，全程高密度情绪，无铺垫直接进入冲突核心

```
【全局固定段】生成15秒写实电影质感短片，24fps，20:9画幅；[角色+场景]全程稳定不变；原生同步人声对白。

【镜头时间轴】
镜头1【0-3s】：[角色A]近景大特写，开场即冲突触发词，面部AU变化立即开始；
镜头2【3-10s】：双人过肩近景，核心情绪递进段，含1次语音重叠+1次卡顿；
镜头3【10-15s】：[角色B]反应特写+沉默留白收尾。

【表演层】精简为2段情绪：[初始情绪]→[转折情绪]，不设置多层保护曲线。
```

**15秒关键规则**：

- 压缩情绪曲线为2段（不做多步递进）
- 前3秒必须有视觉冲突（AU变化/抢话/环境打断）
- 语音重叠≤1次，时长≤0.3s
- 结尾1-2s沉默留白
