# 视频黏土风格 prompt 文法

## 动态物理规则

黏土视频的核心是"弹性物理"——所有运动都带有黏土特有的软弹回弹感，不是刚体运动。

| 动态类型 | 物理表现 | prompt 句式 |
|---|---|---|
| 弹跳 | 柔软的弹跳，落地后轻微变形再回弹 | "柔软弹跳，落地时轻微压扁后回弹恢复" |
| 晃动 | 整体晃动后缓慢回正 | "轻柔晃动，缓慢回正" |
| 变形 | 拉伸或压缩后恢复原形 | "拉伸变形后弹性回弹恢复原形" |
| 转动 | 圆润旋转，重心略偏 | "圆润旋转，重心略偏带呆萌感" |
| 表情变化 | 五官黏土式形变 | "五官以黏土形变方式变化，眼睛放大/嘴巴张开" |

## Beat 结构模板（≤15s 一次生成完整片段）

| 时间段 | 功能 | 内容要点 |
|---|---|---|
| 0-3s | 入画亮相 | 主体以弹跳或晃动方式入画，展现黏土弹性，第一帧即呆萌 |
| 3-7s | 动作展开 | 主体做核心动作（转动/变形/走动），持续展现黏土物理 |
| 7-12s | 高潮动态 | 最有趣的动态：大变形回弹/表情大变化/场景互动 |
| 12-15s | 收束定格 | 主体定格可爱pose，画面稳定 |

## 正向措辞规则

- 只描述"有什么""怎么动"，不写"不要""避免"等否定式
- 材质描述集中放在 prompt 前段，一次性锚定风格
- 动态描述按 beat 时间顺序排列
- 情绪词放在末尾定调

## 完整 prompt 示例

```
黏土手工风格，软糯Q弹质感，表面保留指纹与工具压痕，手工捏制的不完美圆润感。

一只黏土风格的小猫，整体球状圆润体型，四肢短粗，大而圆的眼睛，纽扣状粉色鼻子，橙色饱和黏土色。纯色柔光背景。

主体以柔软弹跳方式入画，落地时轻微压扁后回弹恢复。接着小猫歪头好奇地转动身体，圆润旋转重心略偏带呆萌感。然后小猫全身拉伸变形后弹性回弹恢复原形，眼睛放大嘴巴张开做惊讶表情。最后小猫定格坐姿，微微歪头呆萌pose。

黏土表面亚光漫反射光泽，色彩高饱和。柔光环境。

呆萌可爱，让人想捏一把。

画幅 9:16，时长 5 秒。
```

## 落 prompt 前自检

- [ ] 动态是否体现黏土弹性物理（非刚体）
- [ ] beat 是否按时间顺序排列
- [ ] 材质描述是否在 prompt 前段
- [ ] 措辞是否全部正向
- [ ] 时长 ≤15s 是否标注为一次生成
- [ ] 画幅是否明确
