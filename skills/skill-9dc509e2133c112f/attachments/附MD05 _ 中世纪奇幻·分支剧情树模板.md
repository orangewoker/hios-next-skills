# 附MD05 | 中世纪奇幻·分支剧情树模板

**所属主SKILL：** 中世纪奇幻 · 跑团冒险 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

解决“剧情线混乱、分支无收束”的痛点。

## #需要什么输入

- 主线剧情节点清单、核心抉择点设计。

## #怎么做

### 一、节点命名规范

主线N01-N08，路线N05A，结局E01/D01。

### 二、剧情树核心结构

1. N01 开场·酒馆接取悬赏任务（start节点）
2. N02 抉择点1·如何进入被封锁的地牢（branch节点）
   - N02A 强行破门（消耗生命值，惊动守卫）
   - N02B 寻找下水道密道（消耗金币，可能遇到老鼠怪）
3. N03 发现被诅咒的祭坛（normal节点）
4. N04 抉择点2·面对宝箱里的黑魔法书（branch节点）
   - N04A 烧毁邪书（善恶值+20，队伍士气+10）
   - N04B 阅读邪书（魔法值+50，善恶值-20，可能陷入疯狂）
5. N05-N08 层层推进（如：遭遇巨龙、神器的觉醒）
6. ENDING_CHECK 结局判定

### 三、灵魂七问（每个抉择点必过审）

1. 玩家为什么选它？（贪婪、正义、求生）
2. 它改变了什么？（善恶值、资源）
3. 即时后果是什么？
4. 延迟后果在哪个节点出现？
5. 是否会导致队伍解散？
6. 是否有新的世界观信息揭露？
7. 是否符合跑团机制的随机性？
