# 表演表情

> **定位**：Phase 1 剧本与 Phase 2 分镜中角色情绪场景的表演指令规范。
> **核心铁律**：抽象情绪词 = 0；可观测物理细节 = 100%。

## 快速使用指南

**三步公式**：情绪 → 部位 → 具体动作

```
"紧张" → 手部 → 指节泛白，食指在伞柄上反复摩挲
"克制" → 面部 → 口轮匝肌松弛，唇角不扬不压
"愤怒" → 眼部 → 下眼睑微提，瞳孔表面泛起充血光泽
```

**常用肌肉-情绪速查**：

| 情绪 | 典型部位 | 典型动作 |
|:---|:---|:---|
| 克制/冷静 | 口轮匝肌、眉弓 | 嘴唇不抿不张、眉间平坦无竖纹 |
| 愤怒/压抑 | 咬肌、尺侧腕屈肌 | 牙关咬紧、肌腱隆成斜线 |
| 惊讶/意外 | 额肌、瞳孔 | 眉毛本能抬高、瞳孔短暂收缩 |
| 轻蔑/嘲讽 | 口角提肌 | 单侧嘴角上扬，不对称收缩 |
| 在乎/心动 | 手指、无名指 | 指尖极轻摩挲、戒指反转半圈 |
| 释压/松一口气 | 胸廓、眼睑 | 吸气短呼气长、眼睑微垂 |

**表演强度分级**：L1(微) → L3(中) → L5(极限)。肌肉动作幅度和持续时间随档位递增。

## 一、三层结构体系

| 层级 | 写法 | 禁止 |
|:---:|------|------|
| 微表情层 | 器官+运动：`眼睫颤动两下`、`耳尖泛红` | 抽象情绪词 |
| 肢体动作层 | 部位+幅度+力度：`手指蜷缩进掌心`、`身体微后仰半步` | 模糊虚写 |
| 情绪气质层 | 一个词定调：`清冷`、`隐忍`、`暗涌` | 长篇心理描写 |

情绪气质层只在提示词首尾各声明一次，不展开。

## 二、表情指令速查

### 2.1 眼部

- 眼轮匝肌收缩 → 外眼角细纹、下眼睑微上推 → 真诚笑/喜悦
- 皱眉肌收缩 → 眉头内端下沉、眉间竖纹 → 愤怒/专注/困惑
- 额肌上提 → 眉毛整体抬高、额头横纹 → 惊讶/恐惧
- 上睑提肌紧张 → 瞳孔暴露面积↑ → 震惊/警觉
- 瞳孔放大/收缩 → 放大=兴趣/恐惧，收缩=厌恶/专注
- 眨眼频率变化 → 加快=紧张/撒谎，减慢=沉思/威胁
- 泪腺激活 → 眼眶泛红→泪膜聚积→滑落 → 悲伤/感动

### 2.2 嘴部

- 颧大肌收缩 → 嘴角向外上提拉 → 开心/愉悦
- 口角提肌单侧收缩 → 单侧嘴角上扬 → 轻蔑/冷笑
- 降口角肌收缩 → 嘴角下压呈倒U形 → 悲伤/失望
- 口轮匝肌收紧 → 嘴唇抿成细线、唇色变浅 → 隐忍/克制
- 下唇颤抖 → 极度克制/即将哭泣
- 咬肌收紧 → 下颌角隆起、牙关紧咬 → 愤怒/忍耐
- 嘴唇微张 → 双唇分开、齿间有缝 → 惊讶/欲言又止

### 2.3 眉毛组合

- 额肌+皱眉肌同时 → 抬高+眉间紧锁 → 痛苦惊讶
- 仅皱眉肌 → 压低呈V形 → 愤怒/威胁
- 仅额肌 → 拱起呈倒U形 → 纯惊讶/无辜
- 单侧眉毛上挑 → 怀疑/调侃

### 2.4 五部位动作编码

- ①头部：角度+幅度+速度 → `头偏向一侧约10度`
- ②肩背：紧张度+位移 → `肩膀微僵——比自然状态上提约2cm`
- ③手部：对象+力度+频率 → `手指无意识揉搓袖口，指节微泛白`
- ④身形：方向+幅度+距离 → `上半身前倾15度——停在半步距离`
- ⑤身段：整体气质 → 古典闺秀/京剧老生/现代舞者/松弛市井

## 三、眼部拆解公式

```
眼部微表情 = 瞳孔变化 + 眼睫运动 + 眼尾/眼周 + 视线方向
```

| 要素 | 写法 | 高频搭配 |
|:---|:---|:---|
| 瞳孔 | 收缩/放大（幅度+速度） | `瞳孔骤缩`=警觉；`瞳孔放大`=兴趣/恐惧 |
| 眼睫 | 颤动频率+幅度 | `颤动两下`=紧张/心动 |
| 眼尾/眼周 | 泛红程度+泪光 | `眼尾泛红+泪光`=悲伤/感动 |
| 视线 | 方向+停留+往返 | `弹开又偷瞄`=羞涩；`锁定不动`=对峙 |

**写法纪律**：眼部描述放最前；四要素必须同时写齐。

## 四、时序变化

### 4.1 标准三段式（3-5秒单镜头）

| 阶段 | 时间 | 物理变化 |
|:---|:---|:---|
| 接收/愣住 | 0-1秒 | 表情肌短暂放松、瞳孔微调、头部定格（表情清零） |
| 酝酿/发酵 | 1-3秒 | 肌肉群按序激活（眼部→嘴部→身体） |
| 释放/呈现 | 3-5秒 | 面部肌群达峰值+身体联动+生理细节 |

### 4.2 三幕递进（≥10秒）

```
铺垫层(30-40%)：角色用力维持某状态（咬唇/攥拳/喉结滚动）
  ↓ 触发点打破维持
转折层(20-30%)：维持态肌肉突然松脱/反向激活
  ↓
爆发/收束层(30-40%)：峰值表情+全身联动+生理细节
```

### 4.3 时间轴纪律

- 禁止跳变：必须经过中间态
- 肌肉激活顺序：眼部永远先于嘴部（提前0.3-0.5秒）
- 身体滞后面部：肢体反应比面部滞后0.5-1秒
- 节拍上限：每秒≤2个肌肉变化
- 压制→释放循环：完整情绪弧线必有至少一次

## 五、12种高频情绪模板

> 每条模板结构：微表情层 + 肢体动作层 + 生理细节 + 光影参数。

### 5.1 悲伤（隐忍）
眉头内端微抬，下眼睑从内向外渐泛红，泪膜在睫毛根部聚积强忍不落；下巴微收，喉结缓慢滚动，指尖掐进手掌至发白；呼吸从平稳渐变急促又被迫压回。冷调侧光。

### 5.2 喜悦（内敛）
眼角先于嘴角：外眼角挤出极细纹路，下眼睑微推上；嘴角从外端被眼角"带动"上扬；肩膀从微绷变放松下沉，头部轻偏5-10度。暖调柔光。

### 5.3 愤怒（压制）
下颌咬紧咬肌隆起，颈侧颈动脉搏动；鼻孔微张，呼吸粗重；垂侧拳头渐握至指节发白——面部保持克制，仅眉间极浅竖纹。低角度仰拍，单侧伦勃朗光。

### 5.4 恐惧（渐进）
0-1秒脖颈微僵转头减速；1-2秒上半身不自觉后倾，喉结快滚，舌尖无意识舔下唇；2-4秒呼吸变浅变快。冷调暗光，深景浅焦。

### 5.5 惊讶（冲击）
眉毛瞬间抬高、嘴微张停在齿间、瞳孔先骤缩后缓慢放大；上半身微后退再前倾。瞬间冷白HDR光。

### 5.6 厌恶（社交克制）
鼻孔轻微收缩，上唇微提露出上排齿根；头部轻后仰2-3cm，躯干微后倾；恢复时面部不对称复位。中性漫反射光。

### 5.7 思念/怅然
目光失焦看向中景，头微偏15度；瞳孔微放大，眨眼频率减半；手指无意识摩挲旧物；胸腔起伏变深变慢。暖调逆光勾剪影，背景虚化。

### 5.8 紧张/撒谎
眨眼频率加快至1.5-2倍，瞳孔微放大；喉结滚动增加，唇干致舌尖舔下唇；手指无意识揉搓袖口。浅景深。

### 5.9 心动（暗恋）
瞳孔微放大+眼睫颤动两下+眼尾泛红，视线弹开0.8秒后偷瞄回来；指尖掐衣角，身体前倾又后撤——反复两次停半步距离。柔光暖调。

### 5.10 震惊（信息冲击）
瞳孔骤缩如针尖保持0.3秒后缓慢放大，视线锁定信源；眉毛抬高+额肌+皱眉肌各50%力度；嘴微张未发声。冷调高对比。

### 5.11 崩溃（防线击穿）
0-1秒表情清零→1-3秒咬唇+眼眶渐红→3-6秒强行眨眼→6-7秒嘴唇防线松脱下唇颤抖→7-10秒单手抬到半空→10-15秒第一滴泪滑落。冷调自然光。

### 5.12 强颜欢笑
嘴角上扬但只到平时一半——眼轮匝肌未同步收缩造成假笑；瞳孔轻度放大暴露真实情绪。中性光。

## 六、表演强度分级

| 级别 | 面部幅度 | 身体联动 | 适合类型 |
|:---:|:---|:---|:---|
| L1 微表情 | 仅单肌群微动 | 几乎无 | 悬疑、心理战 |
| L2 克制 | 多肌群≤60% | 手部微动 | 都市情感、职场 |
| L3 自然 | 正常幅度 | 中度联动 | 青春校园、甜宠 |
| L4 戏剧化 | 略大于日常 | 大幅联动 | 热血动作、仙侠 |
| L5 爆发 | 接近生理最大 | 全身+环境反馈 | 虐心高潮、生死时刻 |

**arc_intensity → 强度映射**：0-20→L1 / 20-40→L2 / 40-60→L3 / 60-80→L4 / 80-100→L5

**单镜头约束（3-5秒）**：≤3个动作 = 1主体动作 + 1微动作陪衬 + 1身体联动。

## 七、避坑指南

| 错误 | 修正 |
|:---|:---|
| `又惊又喜的表情` | 分时序：`0-0.5秒惊吓→0.5-3秒转喜悦` |
| `眉头紧锁+眉毛抬高` | 取其一或标力度比例 |
| `嘴角上扬+嘴唇抿紧` | 分时序：`先抿紧→再松开→上扬` |
| 听到噩耗→立刻嚎啕 | 补0-1秒表情清零 |
| 愤怒对话→全程吼叫 | 改用压制信号：`咬肌隆起+指节发白+颈动脉搏动` |

## 八、边界限制

提示词末尾必须包含边界声明：

```text
【边界限制】
尺度：表演在真人范畴内，不卡通化。
一致性：角色五官锁定为资产卡设定，全片段不漂移不换脸。
稳定性：人物面部稳定，无明显畸变。
节奏：情绪递进经过完整"铺垫→转折→爆发"，不跳变。
排除：无表情包化、无五官扭曲、无卡通变形、无画面闪烁。
```

**距离精确化**：所有空间关系必须有数值——`半步距离`/`鼻尖距离约20cm`/`三米对峙线`。

## 九、长镜头连贯性（≥10秒）

### 情绪锚点法
设置3-5个锚点（间距3-5秒），AI自动补间过渡：

```
锚点1（0秒）：初始状态
锚点2（3秒）：第一层变化
锚点3（7秒）：情绪转折
锚点4（11秒）：释放/峰值
锚点5（15秒）：余韵/收束
```

### 肌肉渐变式过渡
不用"从A变到B"跳变，用渐进式：`眼眶的红潮从第3秒开始缓慢消退——首先下眼睑恢复正常血色，接着眉头内端逐步放松，最后嘴角从倒U形渐变为微弯——跨越3-8秒。`

### 无情绪空白填充
`角色沉默——但胸腔起伏从急促渐变平缓，垂在身侧手指从蜷缩一根一根缓慢松开，喉结滚动一次。`

## 十、镜头选择

| 景别 | 微表情可见度 | 典型用法 |
|:---|:---:|:---|
| 大特写 | 极高 | 恐惧眼神、泪水滑落瞬间 |
| 特写 | 高 | 情绪爆发峰值、微表情泄露 |
| 中特写 | 中高 | 需身体语言配合的情绪戏 |
| 中景 | 中 | 多人对手戏、带手部动作 |

**选镜规则**：L1-L2微表情→大特写或特写；L3-L4→特写或中特写；L5爆发→中特写或中景。对手戏反应镜头→特写。镜头运动推荐极慢速推进，禁止硬切到特写。

## 十一、对手戏

### 视线匹配
- 锁定对视：双方瞳孔轴精确对准
- 扫视回避：扫一眼→转开→0.8秒偷瞄回来
- 追逐视线：A看B时B移开→B偷看A时A转过来
- 威压注视：仰拍俯视+俯拍仰视交替强化权力不对等

### 情绪呼应
- 共鸣：B的眼眶比A晚2秒同步泛红+加咬唇动作
- 对抗：A逐层升级愤怒，B表面冷静内收→达峰值时B嘴角单侧微颤
- 传染：A微笑→B困惑→嘴角被"带"着上扬→发现自己也在笑
- 错位：A深情告白时B嘴角上扬但眼轮匝肌未同步收缩

### 反应镜头
- 理解瞬间：听者特写恰好在他"听懂了"那帧
- 被打断的防御：0.2-0.5秒内微表情泄露→快速恢复→切换社交微笑
- 沉默的审判：听者全程不说话，眨眼频率从3秒/次降到8秒/次
- 延迟反应：A说完走开→B站原地3秒：愣住→消化→情绪炸开

## 十二、动作戏中的表演

核心差异：文戏面部为主，动作戏**身体为主、面部为辅**。用锚点法——3-5个表情关键帧，帧间由运动过渡。

**三种模式**：

- **战斗愤怒/决心**：蓄力(咬肌隆起瞳孔收缩)→出拳(嘴微张无声怒吼)→命中(瞳孔放大嘴角微扬)→喘息(目光重新锁定)
- **逃亡恐惧/求生**：察觉(脖颈僵住转头减速)→决定(表情清零0.2秒后嘴唇被恐惧拉开)→奔跑(嘴张开呼吸眼神扫描)→躲藏(身体紧贴墙壁呼吸强行压住)
- **受伤疼痛/意志**：受伤(瞳孔骤缩空白表情)→疼痛(眉毛垮下嘴咬紧手按伤口)→压制(喉结滚动肌肉被意志压回)→站起(手腕颤抖嘴唇发白眼神重新聚焦)

## 十三、嵌入流程

1. 识别情绪锚点：读取剧本标记情绪变化节点
2. 匹配情绪类型：从 §五 12种模板选最匹配项
3. 确定表演强度：映射到 L1-L5
4. 撰写指令：用具体肌肉动作替代万能情绪词
5. 校验：避坑检查 + 边界声明 + 时间轴

**嵌入示例**：
```
李土豆站在原地——0-1秒面部肌肉瞬间清零，瞳孔微缩。
1-3秒他的下颌咬紧，咬肌在脸颊两侧缓慢隆起。
3秒后嘴角拉开冷硬弧度——不是笑，是单侧上扬的讽刺。
垂侧拳头不知不觉已经握紧至指节发白。
```
