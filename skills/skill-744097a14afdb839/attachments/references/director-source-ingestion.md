## 唯一来源

按以下优先级选择：

1. 用户当前明确指定的完整母版版本。
2. 用户当前消息直接粘贴的完整片段。
3. 当前项目中名称、集数、片段号一致且修改时间最新的完整 `director-shot-script-2-5-higg-short` 母版。
4. 只有用户明确继续使用旧版时，才选择完整 `director-shot-script-2-5-higg` 母版。

只给片段号且找不到正文时索取正文。不得从旧提示词、相似片段、旧导演稿、零散提醒或另一集内容拼装来源。文件名或正文中的“待确认”“未锁定”不构成人工锁定门。

## 两种兼容母版

### 当前旗舰短版母版

公开骨架应包含：

1. `【台词提醒】`
2. `【人物建模提醒】`
3. `【场景提醒】`
4. `【道具提醒】`
5. `【一句话概述】`
6. 带连续时间码的全部镜头，每镜包含任务/表演、景别/光学、摄影机/构图、因果动作和镜尾状态。

第一镜正文承担开场状态，最后一镜正文承担结束状态和承接点；不要求独立开场锁、空间总控、物理/灯光/声音总控或结束锁栏目。

### 旧 Higg 母版

用户明确提供时，可摄取旧版十部分母版：台词、表演节拍、开场状态、人物、场景、道具、空间/镜头总控、物理/灯光/声音总控、全部镜头及结束状态。编译时只取事实，不恢复旧 Seedance 十一栏输出。

## 完整性核对

不以栏目多少判断质量，而检查完成编译所需事实是否可从提醒与镜头获得：

- 总时长、剧情事件顺序、导演原镜头方案和连续时间码；原镜数与切点用于理解意图，但可在技法强化时重新设计。
- 人物闭集、身份/外形/服装锚点、位置、身体状态和出场边界。
- 说话人、对白原字原序与标点、OS/旁白/录音/画外声属性、口型和可听范围。
- 场景时间、结构、地标、前中后景、轴线、左右、进出方向、主光和环境相位。
- 道具外形、开场归属、手部占用、方向、数量、开关、完整度、路径和终点。
- 每镜触发、连续动作、聆听/反馈、摄影机、光学、物理、灯光、声音和镜尾结果。
- 第一帧、跨镜连续性、末镜最终状态与多段接口。

缺失会改变人物、对白、因果、空间、道具、镜序、时长或结局的事实时，不生成成功提示词；先回导演短版母版补全。

## 剧情事实防火墙

编译期间固定：

- 剧情、事件顺序、人物闭集、身份及外形锚点。
- 说话人、对白字词/标点/句序、声源属性、口型和可听范围。
- 场景、地理、轴线、左右、屏幕方向、进出方向和地标关系。
- 关键动作因果、剧情信息出现顺序、人物目标与关系、总时长。
- 道具归属、手部、方向、数量、开关、完整度、路径和终点。
- 实际光源、声音责任、伤势、体力、环境相位与最终结果。

用户要求改变上述剧情硬事实时停止编译，要求先用 `director-shot-script-2-5-higg-short` 修改母版。不得静默忽略剧情改动，也不得自行猜修事实冲突。

## 技法强化权

以下内容是导演母版提供的技法起点，不是逐字照抄锁：镜数、镜序、切点、切型、景别、构图、摄影机路径、视场、焦点、镜内动作细分、表演外化程度、灯光表现、环境动态、物理反馈和声音层次。

编译时必须使用本 Skill 的表演、摄影、空间、光学、物理、灯光和声音资料主动诊断并强化这些技法。允许在总时长内拆镜、并镜、移动切点、改变切型与重设运镜，只要不改变剧情事件、对白、人物、场景、关键道具、因果顺序、开场和结尾。母版明确要求摄影机不动、单镜到底、延迟揭示或某动作必须完整同镜读取时，该要求属于本段叙事意图，应保留。

## 就地编译映射

短版不建立十一栏或一对多中间文档，但仍完成同等事实流动：

| 母版事实 | 时间轴落点 |
|---|---|
| 台词与声源 | 实际发声拍的结构化对白、口型、听者反应与环境让位 |
| 人物提醒 | 后台完成参考限权，第一拍或首次出现拍只写必要可见身份锚点；后续变化拍写状态防漂移 |
| 场景提醒 | 后台完成参考限权，第一拍只写可见空间、光源与声音；有关拍写地标、纵深和环境变化 |
| 道具提醒 | 后台完成参考限权，首次出现拍只写可见外形、持有人和手部；接触、路径、物理和终点写入变化拍 |
| 一句话概述 | 只用于理解片段任务，不复制成标题或重复文案 |
| 镜头字段 | 提取注意力目标、动作因果和镜尾结果，再以表演、切镜、构图、摄影机、光影、物理和声音知识重新强化，不机械照抄原切点 |
| 第一镜状态 | `00:00` 第一拍的完整可生成首帧 |
| 最后一镜状态 | 最后一拍由动作真实到达的人物、道具、环境和声音终点 |

事实只在首次生效拍、发生变化拍或防止真实漂移所需拍写入，不建立重复人物表、空间表、连续性表或结束表。

## 整段重编译

母版发生任何修改后：

1. 丢弃旧提示词中的全部事实、时间码、参考权限和结束状态。
2. 从最新母版重新提取所有固定事实。
3. 保留剧情事件与关键因果顺序，重新诊断并设计强化后的镜序、切点、构图、运镜和节奏，形成完整连续时间轴。
4. 重新核对人物、对白、空间、道具、因果、表演、光源、声音和结束状态。
5. 重新运行短版两个检查器。

不复制旧时间拍缝补，不保留已经失效但看似更丰富的旧细节。

## 必须执行的技法强化

在不改变剧情硬事实的前提下，必须主动强化：

- 镜数、切点、切型、景别、构图、摄影机物理位置、路径、速度曲线、操作者反馈和焦点结果。
- 物理机距对应的透视、压缩、前后景和景深结果。
- 人体、道具、布料、介质和机械的接触、惯性、阻力和余波。
- 实际光源、摄影机相对光源侧、明暗面、背景亮度和曝光优先。
- 声源位置、接触声、环境让位、对白起止和口型。
- 母版目标/策略对应的眼神、呼吸、重心、手部、距离和聆听证据。
- 当前拍真实风险需要的局部正向防漂移锁。

强化不得创造新剧情事件、人物、心理动机、关键道具、对白、总时长或结局，也不得占用锁定对白和关键动作所需时间。允许新增、删除或调整镜头与切点，但每一处变化都必须服务注意力、表演、动作可读性、空间纵深或节奏。
