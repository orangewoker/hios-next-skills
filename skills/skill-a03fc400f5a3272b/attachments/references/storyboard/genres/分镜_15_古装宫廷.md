# 古装宫廷风（Period Drama）分镜指令库

> **主打风格**：东方古典美学、色彩饱和度高、服饰细节精致，强调权力与情感的张力。
> **加载时机**：`/分集 {N}` Phase 2 时，若题材判定为宫廷 / 古装 / 宅斗 / 权谋，加载本文件复用分镜。

| 分镜名称 | 完整指令 |
| -------- | -------- |
| **深宫请安** | 极低视角仰拍，清晨冷调的漫反射自然光。太极殿内金碧辉煌，巨大的红漆柱投下深重的阴影。一排宫女低着头跪在殿门口，丝绸裙摆铺展在汉白玉地面上如静止的湖水。端坐在龙椅上的帝王只露出明黄衣摆的一角和一只戴着玉扳指的手，压迫感从画面上方倾泻而下。 |
| **夜宴暗涌** | 长焦压缩构图，烛光摇曳的暖橘色光影交错。宫廷夜宴上，觥筹交错间焦点锁定在相隔三桌的两人身上——左侧的贵妃端着酒杯微笑，右侧的将军握着筷子的指节发白。周围群臣虚化成流动的色块，两人之间横亘着整个朝堂的暗流涌动。 |
| **御花园密谋** | 过肩主观镜头，月光透过竹叶的冷蓝色丁达尔光斑。御花园深处，两名宫装女子面对面低声交谈。前景女子的侧脸被月光照亮，耳坠随微微点头的动作轻晃。后景女子的面容隐在阴影中，只有手中的帕子被绞紧又松开，手指上的护甲在月光下闪过一道寒芒。 |
| **殿前杖刑** | 侧面中景，正午刺眼的顶光如审判之柱。大殿前的青石广场上，太监手持红漆杖跪在阳光中，受刑人趴在地上，丝绸官服已被撕裂，露出血迹斑斑的后背。围观大臣的官帽在烈日下投下一排整齐的暗影，无人敢抬头。画面构图如同一幅审判画。 |
| **凤冠霞帔** | 居中对称构图，柔和的室内暖光。大婚之日，铜镜中映出新娘的面容——凤冠上的珠翠流苏垂至眉梢，红色嫁衣上金线绣的龙凤在烛光中若隐若现。她的眼神透过铜镜望向身后的某个方向，嘴角有一丝旁人察觉不到的苦涩微笑，红盖头尚未覆上，自由的最后一秒定格。 |
