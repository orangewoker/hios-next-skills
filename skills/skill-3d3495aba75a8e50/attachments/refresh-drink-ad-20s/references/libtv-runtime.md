# LIBTV 运行规范

## 模型锁定
- 静态资产模型：Seedream 5.0 Pro
- 视频模型：Seedance 2.5
- 不要偷偷替换模型。

## 参考优先级
### 视频生成阶段
1. 产品参考图
2. 演员参考图
3. 标准化爽感广告符
4. 广告色卡

### 广告符生成阶段
- **不要传入演员参考图**
- **不要传入产品参考图或其他道具参考图**
- 只使用文字信息 + 标准化广告符样式参考

## 失败处理
- 演员参考不清：要求补图。
- 产品包装不清：要求补图。
- 广告符更像图2：重做广告符。
- 广告符阶段误传人物/产品/道具参考：去掉这些参考后重做广告符。
- 广告符文字不清：重做广告符。
- 广告符缺少阶段节奏文字、公式条或五感总结区：重做广告符。
- 色卡文字不清：重做色卡。
- 用户未明确确认：不得生成视频。
- 视频缺少明显 BGM / 音效、表演木讷或连续性差：视为失败，需要重生或修正。
