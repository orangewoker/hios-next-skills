# 产品档案、动态变量、事实边界与自然植入

> 本文件属于“短视频带货Skills”多层嵌套版。根目录 `SKILL.md` 负责总控路由；本文件只承载对应能力。执行时必须同时遵守根目录的输出契约、强制依赖和完整性闸门。

## 5. 产品档案系统
每次处理新产品，先建立“本轮产品档案”。档案是脚本、画面、提示词和质检的唯一产品事实来源。

> 【本轮产品档案】
> 产品中文名称：
> 产品类别：
> 品牌名称：
> 主包装形态：
> 辅助包装形态：
> 参考图片：
> 外形比例与结构：
> 主色/辅色：
> 材质与表面质感：
> 正面文字与图案位置：
> 盖子/提手/封口/侧面结构：
> 单件真实尺寸或相对比例：
> 允许动作：
> 禁止动作：
> 已确认卖点：
> 已确认成分/规格/价格：
> 禁用表达：
> 目标人群：
> 购买场景：
> 视频目标：播放 / 点击 / 转化 / 种草 / 品牌年轻化 / 其他
> 未提供信息：统一标记“未提供”，禁止猜测。

### 5.1 产品图片优先级
- 用户上传的正面产品图优先于文字描述。
- 多张产品图中，选择结构最完整、透视最正、标签最清晰的一张作为主锁定图；其余用于补充侧面、顶部和材质。
- 若产品图互相矛盾，先指出冲突，不擅自合并为新包装。
- 产品图只作为形态与视觉事实，不自动推断功效、成分和适用人群。
## 6. 动态产品变量与物体注册表
不再预设任何品牌专属变量。每轮根据真实产品形态建立变量，只调用实际存在的对象。

| 通用变量 | 适用对象 | 示例写法 |
| --- | --- | --- |
| PRODUCT_PRIMARY | 主产品统一入口 | 人物把【产品中文名】 PRODUCT_PRIMARY 放到桌面上。 |
| PRODUCT_BOX | 单盒/方盒包装 | 人物拿起【产品中文名盒】 PRODUCT_BOX。 |
| PRODUCT_GIFTBOX | 礼盒 | 人物双手递出【产品中文名礼盒】 PRODUCT_GIFTBOX。 |
| PRODUCT_JAR | 圆罐/桶装 | 人物打开【产品中文名罐】 PRODUCT_JAR。 |
| PRODUCT_BOTTLE | 瓶装 | 人物拿起【产品中文名瓶】 PRODUCT_BOTTLE。 |
| PRODUCT_POUCH | 自立袋/软袋 | 人物把【产品中文名袋】 PRODUCT_POUCH 立放在桌面。 |
| PRODUCT_SACHET_DISPLAY | 展示小袋 | 人物把【产品中文名展示小袋】 PRODUCT_SACHET_DISPLAY 放在掌心。 |
| PRODUCT_SACHET_USE | 实际使用小袋 | 人物撕开【产品中文名使用小袋】 PRODUCT_SACHET_USE。 |
| PRODUCT_DRINK | 冲调后饮品 | 人物端起【产品中文名冲调饮品】 PRODUCT_DRINK。 |
| PRODUCT_RAW_MATERIALS | 原料组合 | 镜头扫过【产品中文名原料】 PRODUCT_RAW_MATERIALS。 |
| PRODUCT_SHOPPING_BAG | 手提袋 | 人物拎着【产品中文名手提袋】 PRODUCT_SHOPPING_BAG 进门。 |
| PRODUCT_CARTON | 整箱 | 人物抱起【产品中文名整箱】 PRODUCT_CARTON。 |
| PRODUCT_COMBO | 同框组合 | 桌面出现【产品中文名组合】 PRODUCT_COMBO。 |
| PRODUCT_ACCESSORY | 配套器具 | 人物使用【配套器具中文名】 PRODUCT_ACCESSORY。 |

### 6.1 产品物体注册表
> 每个变量必须记录：
> 1. 中文名称与变量名
> 2. 几何形态：长方体 / 圆柱 / 瓶 / 袋 / 异形
> 3. 正面、侧面、顶部与底部结构
> 4. 长宽高比例与人物手持比例
> 5. 材质：哑光纸盒 / 亮膜 / 金属 / 玻璃 / PET / 软袋等
> 6. 标签、文字、图案、色块和封口位置
> 7. 允许动作：拿起、递出、打开、倾倒、冲泡、摆放等
> 8. 禁止变化：变形、异形、压扁、拉长、标签重绘、颜色漂移、对象融合
> 9. 连续性：每段开始与结束时的数量、位置、朝向、开合状态

### 6.2 最终命名硬规则
> 正确：人物把【五红粉盒】 PRODUCT_BOX 放在桌面上。人物端起【冲调后的五红粉饮品】 PRODUCT_DRINK。

> 错误：人物拿起 PRODUCT_BOX；人物拿起产品；人物拿起一个盒子。变量和中文名不得单独出现。
## 7. 产品事实、卖点与合规边界
### 7.1 事实分层
| 层级 | 可用内容 | 处理规则 |
| --- | --- | --- |
| A 已确认事实 | 用户提供的包装文字、说明书、备案资料、价格、活动、成分、规格 | 可准确使用，但不得夸大或改写成承诺 |
| B 用户主张 | 用户提供的体验、评价、卖点口径 | 标记为用户提供；涉及功效时转为中性表达或要求合规依据 |
| C 未提供信息 | 模型根据品类可能猜到的内容 | 禁止写入脚本、画面、字幕或提示词 |

### 7.2 通用禁区
- 治疗、治愈、预防疾病、根治、药效、替代药物、保证有效、立刻见效、几天见效。
- 100%有效、全网第一、销量第一、唯一、最好、必须买、所有人都适合。
- 医生、医院、专家、白大褂、检测机构或权威背书，除非素材真实、授权且表达合法。
- 伪造检测报告、认证、备案号、成分含量、优惠价格、库存、销量或用户体验。
- 用人物前后状态制造未证实的身体功效对比。
### 7.3 推荐表达方式
优先写真实场景、使用便利、口感、包装、送礼、情绪价值、生活习惯、用户选择逻辑、实际操作过程和已确认信息；不把产品变成万能解决方案。
## 18. 产品自然植入规则
### 18.1 产品在剧情中的六种角色
- 道具：人物自然拿、递、开、倒、冲、喝、摆放。
- 证据：解决人物质疑的包装、过程、数量、口感或真实操作。
- 礼物：推动关系变化和情绪反应。
- 冲突触发器：因为价格、选择、使用方式或误会产生对话。
- 视觉核心：爆开、堆叠、原料出现、液体变化、开箱或机械动作。
- 结尾留存：产品留在顺手位置，成为态度变化的视觉结果。
### 18.2 露出强度
| 级别 | 表现 | 适用 |
| --- | --- | --- |
| 弱露出 | 产品在桌面或手边，非中心，不解释 | 剧情前段、生活流 |
| 中露出 | 人物拿起、查看、打开或使用，镜头1—3秒 | 种草、演示、对话 |
| 强露出 | 产品近景、操作细节或数量展示，3秒以内 | 结尾确认、视觉奇观、价格节点 |

### 18.3 禁止
禁止长时间居中硬怼、产品发光、无剧情堆满画面、人物持续对镜头夸赞、包装文字乱码、产品与手融合、多个变量混成一个物体。
