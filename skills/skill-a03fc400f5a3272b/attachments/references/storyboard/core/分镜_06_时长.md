# 分镜时长与时间轴

> **原则**：每片段独立计时，从 0 秒开始；标准片段 15s；末段可短于 15s（详见 [分镜_02_导演逻辑](./分镜_02_导演逻辑.md) §三连续变形铁律）。
> **v2 变更**：§二 台词时长从单一 `÷3.0` 升级为多模式系统（独白/日常/争吵三档 + 段落级参考 + 单句约束），与 `scripts/_rules.py` 的 `DIALOGUE_TIMING_MODES` 保持唯一来源。

---

## 一、秒级分段时间轴（参考框架）

> **定位**：四段时间轴是叙事节奏的参考框架，不是镜头分配的模板。实际各段时长由镜头数×单镜时长决定，不受四段等分约束。一段 15s 内可以是 3 个长镜头（每镜 5s）或 15 个短镜头（每镜 1s）——时间轴只描述"叙事功能在时间维度上的理想分布"，不强制每段放 1-2 镜。

| 时间段 | 秒数 | 叙事功能 |
|-------|------|---------|
| 开篇冲击 | 0-3s | 强视觉冲击/悬念/情绪爆发 |
| 发展铺垫 | 3-6s | 叙事推进/动作展开 |
| 高潮蓄力 | 6-10s | 情绪递进/冲突升级/核心画面 |
| 收尾定格 | 10-15s | 悬念收束/结尾钩子 |

输出时按 Module 4 模板的逐镜指令格式（Shot 1/Shot 2/Shot 3/...），不强制四段均分。**实际镜头数由 [分镜_99_导演决策协议](./分镜_99_导演决策协议.md) D1.3 决定——时间轴只在确定了镜头数之后，用于校验叙事节奏是否覆盖了应有的功能区间，而非反过来用时间轴推导镜头数。**

## 二、台词时长参考（多模式 · 唯一权威）

> **数据来源**：`scripts/_rules.py` 的 `DIALOGUE_TIMING_MODES`、`DIALOGUE_DURATION_REFERENCE`、`DIALOGUE_LINE_CONSTRAINTS` 三个常量（本文件为说明文档，数值以脚本为准）。

### 2.1 宏观速率（按台词节奏模式判定）

生成分镜前，AI 必须从以下三档中判定本段台词的节奏模式：

| 模式 | 语速 | 适用场景 |
|:---|:---|:---|
| **独白/旁白** | 偏慢，≈200 字/分钟（≈3.3 字/秒） | 单人独白、画外旁白、内心 OS——留白多、情绪停顿多 |
| **日常对话** | 正常，≈220 字/分钟（≈3.7 字/秒） | 双人/多人日常交谈、谈判、日常对峙 |
| **快节奏争吵** | 偏快，≈260 字/分钟（≈4.3 字/秒） | 吵架、激烈争论、紧急警告——停顿少 |

**判定规则**：
- 剧本标注"激烈""争吵""大声"→ 快节奏
- 剧本标注"喃喃""低语""独白""旁白"→ 独白
- 其余情况 → 日常对话

### 2.2 中观段落（按总秒数快速估算）

| 时长 | 字数范围 | 说明 |
|:---|:---|:---|
| 1 秒 | 3-4 字 | 一个短词或半句 |
| 5 秒 | 18-22 字 | 一句完整的短台词 |
| 10 秒 | 38-42 字 | 一段对话中的连续发言 |
| 15 秒 | 55-60 字 | 微短剧一个片段的理论上限 |
| 30 秒 | 110-120 字 | 两个片段拼接的对话量 |
| 1 分钟 | 220-240 字 | 整段独白或密集对话 |

**使用方式**：AI 读完剧本原文后，先数台词总字数 → 查表得音频轨道占用秒数 → 剩余秒数分配给纯画面镜头。

### 2.3 微观单句（逐句约束 · 阻断级）

| 类别 | 字数 | 所需秒数 | 最小所在镜头时长 |
|:---|:---|:---|:---|
| 短句 | 3-8 字 | 1-2s | ≥1.5s |
| 正常句 | 8-18 字 | 2-4s | ≥3.0s |
| 长句情绪台词 | 20-30 字 | 5-7s | ≥6.0s |

**逐句校验规则**（生成后必跑）：
- 单镜台词字数 ÷ 镜头所在时间段的实际秒数 ≤ 最高语速 4.3 字/秒
- 若一条台词跨多个镜头，跨镜总覆盖秒数 ≥ 台词字数 ÷ 该台词的节奏模式速率
- 跨镜切点必须在句间自然停顿处（逗号/句号/换气点）

## 三、台词跨镜规则（画面轨与声音轨独立）

> **核心原则**：台词是声音轨道，镜头是画面轨道，两者可以独立切分。

### 3.1 合法跨镜

```
✓ 正确：甲说「你为什么要这样做？」（正常句, 8字, 需2.2s）
   镜1(1.2s, 甲L3近景, 甲说前半句)→切 镜2(1.0s, 乙L4特写反应, 甲声继续)→镜3(1.5s, 甲L4特写, 甲说完)
   总覆盖 = 1.2+1.0+1.5 = 3.7s ≥ 2.2s ✓
   切点在"做？"处——句末自然停顿 ✓
```

### 3.2 非法跨镜

```
✗ 错误：甲说「我不同意——」（快节奏15字, 需3.5s）
   镜1(1.0s, 甲L3)→切 镜2(1.0s, 乙反应)→镜3(1.0s, 空镜)
   总覆盖 = 3.0s < 3.5s ✗（台词装不下）
   
✗ 错误：在"我不——"的词中间切到反应镜 ✗（听觉断裂）
```

### 3.3 跨镜约束清单

| 规则 | 阻断条件 |
|:---|:---|
| 时间总量 | 台词覆盖的所有镜头的总时长 < 台词字数/速率 |
| 听觉连续性 | 切到反应镜/空镜时，台词声音必须保持连续（除非是有意设计的声音断裂） |
| 切点位置 | 切点必须在句间自然停顿处（标点：，。！？……、；），不可在词中间 |
| 镜头数影响 | 台词跨镜会使镜头数+1~2（D1.3 第四维纳入计算） |

## 四、时长校验

### 4.1 生成前（协议 D1.3 与 D2.5 阶段）
- 判定台词节奏模式（三选一）
- 台词总字数 ÷ 选定速率 ≤ 15s
- 预估纯画面秒数 = 15s - 台词总秒数 - 呼吸空镜秒数
- 台词字数 ≥ 20字（微短剧最低信息量要求）
- 预估动作数量 ≥ 2个

### 4.2 生成后
- 分镜总时长 = 15秒（标准片段，可±1秒）；末段按实际剩余秒数
- 时间连续性：从 0 秒开始，无跳跃无重叠
- 逐句台词校验：每句台词字数/所在镜头覆盖秒数 ≤ 4.3
- 台词总载量校验：总字数/选定速率 ≤ 15s

## 五、时长不足补充策略

按优先级：增加高潮段动作细节 → 增加开篇冲击内容 → 增加环境氛围描写 → 增加音效同步描述

**禁止**用水词凑时长（"慢慢地""轻轻地"等）。

- [ ] 台词节奏模式已判定（三选一）

- [ ] 预估纯画面秒数 ≥ 0
- [ ] 台词字数 ≥ 20字
- [ ] 动作数量 ≥ 2个

- [ ] 跨镜台词切点在句间自然停顿处
