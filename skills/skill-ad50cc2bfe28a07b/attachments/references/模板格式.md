# 模板格式.md

本文件提供漫剧剧本的标准格式参考，帮助识别剧本结构并正确转换为分段提示词。

---

## 剧本格式规范

### 基础格式要素

**1. 场景标注**
```
场景：夜/外 城市废墟
```
格式：`[时间]/[内外] [具体地点]`

**2. 人物标注**
```
人物：主角A、反派B、女主C、路人N
```

**3. 剧本正文格式**
```
△ 远镜描述，环境/氛围交代
△ 中景/近景动作描写
角色名（情绪/动作）："台词内容"
△ 镜头指示（如【特写】、【中景跟拍】）
```

**4. 特殊标注**
- VO（旁白）：画外音/旁白
- OS：内心独白
- △：画面描述/动作描写
- 【字幕】：字幕内容
- 【闪回】：闪回画面

## 示例：完整剧本格式

```
第一集

【钩子设计】
镜头1｜极近景｜高速→慢动作切换
画面：两根武器从左右两侧猛然砸向画面中心
动作："轰——！"瞬间对撞
特效：金光爆裂、粒子飞溅、画面过曝0.2秒
运镜：轻微震屏 + 冲击波扩散（镜头轻抖）
音效设计：金属重击 + 能量爆炸低频

镜头2｜超近景｜慢动作推进
画面：金光褪去，两张一模一样的脸贴近
运镜：镜头极慢推进到两人眼睛之间
细节：其中一只眼睛隐约泛出金色微光
情绪：时间仿佛被拉长，空气压抑

1-1
场景：日/外 仙魔战场
人物：主角A、反派B、女主C

△ 天空布满巨大的裂痕，像破碎的镜面，世界正在像素化崩塌。
主角A OV：我是主角A，一次意外穿越到了这个世界，必须完成系统任务，才能回到现实。
系统（急促）：警告！气运之子生命体征消失，任务失败。

△ 主角A从天上掉下来，摔到地上。系统光球冒着红光弹出字幕。
主角A（麻木）：第99次了，累了，毁灭吧。

△ 空间被撕裂，浑身浴血的反派B从虚空中踏出。
反派B（面目狰狞）：蠢货！我特么的陪你重生了99次！你怎么还搞不定？！

反派B（指向系统）：还有你，带了她99次连个男人的手都摸不到，你是人工智障吗！
△ 被指到的系统光球紧张到冒汗。

主角A（委屈，要哭了）：我只是个普通社畜，他修的可是无情道啊……

△ 反派B气不打一处来，暴躁地一脚踹开系统，手中凝聚出黑炎。
反派B（狠厉）：下一次重生立刻来找我！我亲自教你！

△ 毁灭性的黑炎将主角A包裹住。

1-2
场景：日/内 后山禁地山洞
人物：主角A、反派B

【字幕：第100次重生】

△ 主角A被扔到地上，包袱丢到一边，瑟瑟发抖地跪坐起来。
主角A（疼痛）：哎哟……嘶……

△ 光线昏暗的山洞内，反派B一身墨色长袍，俯视主角A，周围妖气森森。
反派B（阴森）：怎么，想跑？

主角A OS（害怕）：这大魔头太可怕了，不跑等死吗？
主角A（结巴）：大、大佬，你要不考虑一下找其他人？

反派B（怒极反笑）：如果有其他人，我会选你这个猪队友？

△ 反派B半蹲下，两指捏住主角A的下巴，强迫她对视。
反派B（咬牙切齿）：攻略不了目标，我就把你炼进我的万魂幡里！

主角A（打了个哆嗦，疯狂点头）：我攻略我攻略！我听你的还不行吗！

△ 反派B掐了个决，一本厚书狠狠摔在主角A面前。
反派B（冷漠）：从今天起，你的每一个眼神，每一个动作，都要让男人想犯罪。

△ 主角A拿起书震惊，书面上硕大的封面《绿茶的自我修养》。
```

## 剧本类型识别

### 类型A：动作/战斗型
- 特点：大量动作描写、特效描述、战斗场面
- 示例：《sss级机娘》、《西游逆局》战斗片段
- 处理重点：动作流畅性、镜头切换、空间层次

### 类型B：对话/情感型
- 特点：大量台词、情绪描写、心理活动
- 示例：《重生之我是白骨精》内心独白片段
- 处理重点：面部表情、眼神交流、肢体语言

### 类型C：叙事/揭示型
- 特点：旁白为主、画面切换、闪回穿插
- 示例：《西游逆局》钩子部分
- 处理重点：镜头设计、氛围营造、转场衔接

### 类型D：混合型
- 大多数剧本都是混合型，需要综合运用多种处理方式

---

## 格式注意事项

1. **台词必须用双引号**：`"台词内容"`
2. **动作描写用△开头**：与台词区分
3. **角色情绪标注**：紧跟角色名后，如"（愤怒）"、"（冷笑）"
4. **镜头指示用【】**：【特写】、【中景】、【闪回】
5. **旁白标注VO**：区分台词和叙述

---

**使用建议**：读取用户提供的剧本后，先识别其格式类型，对照本文件确认剧本结构完整，再进入分段处理流程。
