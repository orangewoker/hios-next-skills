# 终点奖品资产策略

## 输入与决策

| 用户输入 | 系统动作 | 最终引用 |
| --- | --- | --- |
| 清晰的单一产品图 | 直接使用，或自动提取为白底写实奖品资产 | `prize_reference` |
| 仅上传 logo | 必须先问“希望把这个 logo 放在哪类奖品上？”；用户回答后生成写实奖品资产 | `prize_reference` |
| 未提供产品图或 logo | 不创建奖品资产，保持纯胜利定格 | 无 |

不得把 logo 浮在画面上、贴成水印或擅自假定奖品品类。

## `prize_reference` 产品图提取提示词

```text
基于用户提供的产品图，生成横版 16:9 白底写实奖品资产图。保持产品的外观轮廓、材质、主色、关键结构和可见 logo；产品完整清晰，适合真人综艺终点奖品展示。纯白背景，无人物、无赛场、无文字说明、无额外产品。
```

## `prize_reference` logo 合成提示词

```text
基于用户提供的 logo，生成一件写实的 {奖品品类} 奖品资产图，横版 16:9 白底。产品造型、材质和结构符合真实可展示的 {奖品品类}；将 logo 作为自然、克制、清晰的品牌标识应用在合理位置，不做水印、不悬浮、不扭曲。纯白背景，无人物、无赛场、无额外文字。
```
