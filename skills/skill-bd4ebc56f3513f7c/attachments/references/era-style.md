# 年代·造型词典（Era & Style Lexicon）

> 服务：用户输入含年代/时代词（"90年代国营厂女工""民国教书先生""2000年左右的青年""69年生人"）时的翻译层。
> 输出：人物肖像的年代感 = ①发型/妆容大众款 ②服装剪裁与单品 ③随身物/场景道具 ④影像基调。年代只做**大众日常造型翻译**，不做时尚史考据。
> 覆盖范围：近现代（民国→当代→近未来）。**古代朝代词（"唐代仕女""宋朝书生"）走 `classical-physiognomy.md` 古风层**，不在本词典。

## 使用总则（先读）

1. **年代 = 视觉造型所处时代（故事时间）**，独立于年龄档但必须自洽。"1990年、30岁" = 年龄档取 30 岁 + 造型档取 90s。
2. **只给出生年**（"69年生人"）→ 造型年代默认按"出生年 + 年龄档"推算当下（69 年生、50 岁 → 2010s 末当代），档案标"推断"，并向用户说明可改（故事可能设定在他 30 岁的 90s）。
3. **大众日常款优先**，禁舞台化/猎奇标签：不画"爆炸头花衬衫迪斯科 80 年代"这类刻板漫画，取该年代主流日常样式。
4. 历史服饰只到**形制特征**；**不出现真实政治符号**（旗帜、标语、领袖像、特定时期徽章袖章一律不生成）。
5. 与古风词典的边界：近现代词（有照相术的年代）查本词典；朝代古装词查古风词典。
6. 近未来档按第五节"三档演化锚"取**可绘制、克制的演化默认**；用户若给了作品专属未来设定（如你自建的世界观文档），**以用户设定为准**，锚降级为背景参考，不硬套。

## 一、年代档位速查表（核心）

每档四层：男女大众造型 / 随身物与场景道具 / 影像基调。取 30–50 岁大众款式；青年可跟潮流款、中老年取同档"素色宽松中老年款"（发型服从年龄档，见"二"）。

|---|---|---|---|---|

## 二、年代 × 年龄 自洽规则

- **发型先服从年龄档，服装/道具/影像服从年代档**：60 岁在 90s 的人，头发按中老年档（花白/脱发），不画成 90s 青年中分。
- 服装按年龄微调：同一年代内青年可跟潮流款；中老年取"素色、宽松剪裁、深色系"日常款。
- 反例自查：30 岁的脸配 50s 老干部发型 + 00s 服饰 = 年代错乱，质检拦截。

## 三、年代 × 职业 联动规则

- 职业决定**身份形制**（工装/制服/长衫），年代决定**面料、剪裁、色彩、随身物**。
- 例："90年代国营厂工人" = 工厂工人形制（深蓝劳动布、白线帽/安全帽按岗位）+"90s 档面料剪裁"；"民国教书先生" = 长衫或中山装 + 圆框眼镜 + 怀表。
- 合并写法：`装束：[职业形制]的[年代]款（[面料/剪彩色关键词]，无标识）`。词典未列的组合 → 按常识推断并在档案标"推断"。

## 四、年代 × 影像基调（照片/剧照感）

- 用户要"老照片/档案照/时代剧照"质感 → 直接使用档位表"影像基调"列。
- 当代默认不加滤镜。
- 影像基调只作为氛围许可词，遵循主文件"不堆风格词"原则，每张消息至多给 2 个基调词（如"泛黄暖棕胶片感"）。

## 五、近未来设定锚（三档演化基线）

> 服务：用户给"近未来/未来/××年后"设定时的默认演化基线。演化主轴 = **环境压力（气候/灾害）+ 资源实用主义 + 科技渗透度**。原则：**克制、可信、可绘制**——科技"渗透而非炫示"，不做霓虹赛博/飞行汽车/全息广告这类陈词，除非用户点名该风格。
> 取档：用户给年份 → 就近取档（2030s→A / 2040s–50s→B / 2060s+→C）；只给"未来/近未来" → 默认 A 档并询问；用户的世界观自带设定 → 用户设定优先，本锚仅补视觉翻译。

### 锚 A · 近未来 10 年（≈2030s）——当代的下一代

- **演化主轴**：极端天气事件（高温/暴雨/尘霾）频率上升，服装开始功能化；AI 成为贴身工具。城市形制仍是当代，只多了"防"的痕迹。
- **服装**：当代剪裁为主 + 功能面料（防晒透气、快干防水、轻薄保温）；流行"气候分层穿搭"（内层亲肤温控、外层防风防雨薄壳）；旧衣修补仍常见（经济压力，不作末世化处理）。
- **造型/配件**：发型延续当代大众款；AI 耳机 / AI 眼镜（无品牌字）、智能手环成为常见配饰；便携过滤口罩挂颈侧（非全罩）。
- **随身物**：折叠屏手机、无感支付；**个人应急小包**普及（水、滤片、哨、保温毯）——大灾之后的习惯残留。
- **环境与光**：街面加装遮阳廊、应急棚、防洪挡板；傍晚尘霭使天空光散射偏柔。
- **人体痕迹**：晒痕因防护习惯略减；户外职业者仍有"防护装备边缘压痕"（帽带、口罩绳）。
- **影像基调**：现代纪实微偏冷，天空高光受控（强日光 / 尘霭天光）。
- **危机叙事提示**：人物身上留"一次大灾后的痕迹"——补丁、常备应急包、面罩晒痕；情感道具多用当代旧物。

### 锚 B · 近未来 30 年（≈2050s）——气候适应成为生活基线

- **演化主轴**：高温与极端气候常态化 → 城市"半封闭化"（连廊、地下通道、集中供冷节点）；能源与材料成本上升 → **"实用修补"成为主流审美**（惜物，非末日朋克）。
- **服装**：模块化功能服成为城市日常（可拆领/袖、多袋、快干调节面料）；宽檐帽 / 遮阳领巾常见（防晒防尘）；鞋靴防水增高（内涝常态化）；色彩偏实用（沙色/灰绿/雾蓝），高可见度反光条用于安全而非炫酷；少数人有温控织物，多数靠分层加减。
- **造型/配件**：发型偏短、易打理（水与时间成本）；遮阳帽、面巾成为日常（户外习惯泛化）；功能中性剪裁为主流。
- **随身物**：**个人应急包常态**（滤水、压缩粮、应急灯、迷你净电）；轻量信息目镜（部分人群常戴）；数字身份全民化（无纸）。
- **环境与光**：城市见垂直绿植、太阳能顶棚、封闭连廊；低空少量物流无人机航线；防热玻璃与遮蔽使室内外光多呈**柔散光**，强日光被遮阳系统过滤。
- **人体痕迹**：长期防晒习惯使户外晒痕减少；体力/户外职业仍见"装备缝隙晒痕"。
- **影像基调**：通透的"适应后"色调——日光过滤后的均匀亮度、偏蓝白高光；灾害戏可用尘雾逆光。
- **危机叙事提示**：**旧物即情感**——当代夹克、纸质书等成为代际对比道具；人物疤痕指向"过去的那场灾"。

### 锚 C · 近未来 50 年（≈2070s+）——硬适应与材料分化

- **演化主轴**：环境剧变被"硬适应"消化——城市向垂直与地下发展（防洪、沙尘系统化）；材料科技成熟但供给分化 → 服装差异以**技术密度**显形（用面料质感/贴合度/磨损表现，不画"富人发光穷人破烂"刻板）。
- **服装**：专业功能面料（自调温、自清洁、轻防割）在基建/户外/公务人群普及（合身、低磨损）；日常大众为**"多层旧衣 + 功能外层"的工整修补风**（补丁规整、缝线工整）；防水抗沙尘罩袍式外套城市常见（可收纳）；鞋具集成缓震结构（远距通勤）。
- **造型/配件**：发型偏功能（短发或束发）；防护目镜/滤片面罩按场景出现（尘暴日/污染日），半透明贴脸型而非全封闭；**年龄表现更年轻**（医疗与营养改善：50 岁≈当代 40 岁观感）。
- **随身物**：多合一终端（通讯/证照/投影）；滤水与微净电为随身基础；应急装备内嵌进衣袋。
- **环境与光**：廊道化街区 + 垂直农场立面；地下枢纽人工照明均匀亮如白昼；户外远景受尘层影响**雾化**；防洪堤坝与气象塔成为天际线元素。
- **人体痕迹**：长期过滤环境生活者皮肤偏净少晒（户外职业除外）；医疗痕迹细看不可见，不强画。
- **影像基调**：城内冷白均匀人工光；城外尘霭漫射天光；冷暖对比在"廊道内暖 / 外部冷"。
- **危机叙事提示**：**废墟与重建共存**——老建筑残骸上覆新功能层；人物多为"灾后世代"（无灾前记忆、对旧物好奇）。

## 六、合规红线（硬性）

- **无真实政治符号**：旗帜、标语口号、领袖画像、特定历史时期徽章/袖章/臂章一律不生成。
- 造型取大众日常款，不做年代刻板漫画、不猎奇化（禁夸张烫头+蛤蟆镜迪斯科标签）。
- 不生成真实历史人物/名人形象；服饰只到"形制"程度，不与真实个体撞款。
- 未成年人 + 年代组合（如"90年代小学生""民国少年"）**允许**：造型取该年代同年龄段的真实童装/少年日常款（无标识、无政治符号），发型服从年龄档。
- 近未来/科幻语境下的未成年角色同样允许；仍守"非性化 + 年龄适配"底线（禁成人化改造身体、成人化装束与妆容）。
- **近未来不预设政权形态**：不生成真实或虚构的政府/机构/企业标识（含未来徽章、旗帜、臂章、LOGO），官方与制服一律"无标识通用款"；社会制度描述不进入生成消息，只保留可绘的器物与服饰。
- 近未来演化锚是**可覆盖默认**：用户世界观已有设定（时间轴/政权/科技程度）时以其为准，锚仅作视觉补全，不反驳用户设定。
