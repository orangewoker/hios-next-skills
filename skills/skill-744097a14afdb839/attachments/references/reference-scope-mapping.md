# 参考体权限与时间轴就地映射

## 后台固定映射

每个实际使用的参考体在后台建立一次权限映射：

`名称 → 控制对象 → 允许继承 → 不参与 → 生效时间/镜头`

该映射只用于内部核对，不进入最终时间轴。最终提示词只将授权后的可见结果自然写成角色外形、场景结构、材质、天气、道具外观或动作状态，不输出箭头映射、权限术语、图号或参考说明。英文人物名、人物简称与人物素材文件名不受普通英文拦截；只有在用户输入、素材调用或平台引用确实需要时才写入时间轴，并分别通过结构检查器的角色或人物素材文件声明放行，不能替代可见外形锚点。只有用户明确要求保留平台引用标签时，才原样保留来源中的标签并完成来源证明。没有外部参考时直接以导演母版为唯一依据。

若同一参考在后续拍改变授权对象或时间窗，必须由用户或母版明确支持，并在后台更新映射；最终时间轴仍只写改变后的可见结果，不输出权限变化说明。

## 类型边界

| 类型 | 可控制 | 默认不控制 |
|---|---|---|
| 人物参考 | 被点名的脸、发型、年龄感、体型、服装、配饰 | 场景、动作、运镜、其他人物 |
| 场景参考 | 地理、结构、材质、地标、天气、授权光向或色调 | 原图构图、摄影机角度、人物身份、动作、道具归属 |
| 道具参考 | 外形、尺寸、材质、颜色、磨损、开关结构 | 持有人、场景、动作结果 |
| 姿态/动作参考 | 姿态、重心、肢体轨迹、速度、节奏、接触关系 | 脸、服装、场景、道具外观 |
| 视频参考 | 用户点名的动作、运镜、节奏、构图、遮挡、表演或物理反馈 | 未授权的脸、服装、场景与道具 |

场景参考默认提供地理和材质，不自动继承原图机位与构图；风格参考不得覆盖身份、空间、动作、光学、灯光或道具事实。

## 冲突优先级

1. 用户当前消息中不改变导演事实的明确限权。
2. 用户点名的当前完整 Higg-short 母版事实。
3. 用户明确提供的旧 Higg 母版事实。
4. 专属参考体。
5. 综合参考体中的相关部分。

用户当前要求若会改变剧情、人物集合、对白、镜序、动作因果、道具结果、时长或结局，不作为限权覆盖；停止编译并回导演短版母版修改。

## 防污染

- 一个参考体只承担清楚的主要职责；多种授权逐项拆清。
- 只列当前片段实际使用的参考，清除旧参考、旧标签和未出场对象。
- 参考中的偶然背景人物、道具、标牌和文字不得进入当前闭集。
- 人物脸由人物专属参考控制，动作由动作/视频参考控制，场景由场景参考控制，除非用户明确重新分工且不冲突母版。
- 新上传参考只属于用户点名片段，不自动成为全剧或前后片段的全局参考。
- 每次切镜继续用姓名、左右、服装锚点、手部和专属道具保持身份与状态；引用标签本身不能替代这些可见锚点。
- 参考体不能覆盖对白、剧情顺序、镜序/切镜、动作因果、道具终点或结束状态。

## 时间轴写法示例

```text
(00:00-00:03) 罗安位于画面左侧，瘦高体型，穿深灰短夹克，右手握住样本瓶；摄影机从台面右端横移……
(00:03-00:06) 检验室保持冷灰金属墙面，扫描仪位于后景中央；罗安沿台面左端向中央移动……
(00:06-00:09) 罗安右臂按授权动作轨迹递出样本瓶，接近接收者时减速，摄影机同步推近手部……
```

示例只说明如何把后台参考权限转译成可见镜头，不得照抄人物或场景。除非用户明确要求平台标签，实际输出不保留参考名称或标签。

## 来源证明

任何自动 `@/#` 引用必须在 `--source-file` 指向的当前完整母版中以完全相同的标签和边界存在。标签必须含至少一个字母或数字；纯下划线、纯连字符、粘连普通正文、相似前缀或只出现子串都不能证明。

任何允许英文/字母数字标识都用 `--allow-english-token` 逐项传入，并由同一来源精确证明。摄影、风格和技术英文不能借来源或全角/混合脚本绕过。

锁定对白内出现自动引用时，对白仍逐字保留，但引用本身同样必须通过来源证明。

## 复核

- 每个参考是否只控制被授权对象、属性和时间窗？
- 是否无旧参考、偶然背景人物或跨片段污染？
- 引用标签是否来自当前母版且边界完整？
- 是否只输出可见结果，没有把箭头映射、权限术语、图号、文件名或参考说明泄漏进时间轴？
- 后续切镜是否用可见身份与状态锚点保持连续，而不依赖标签省略？
