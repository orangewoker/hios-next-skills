# 附MD04 | 黑帮风云·变量与结局扩展

**所属主SKILL：** 黑帮风云 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #怎么做

### 一、变量字典（强制锁定）

核心变量

1. 地盘势力：counter，0-100，默认10；≥80控制全城。
2. 资金：counter，0-9999，默认1000；用于购买军火和收买人心。
3. 兄弟忠诚：relationship，0-100，默认50；&lt;20发生叛变。
4. 警方通缉度：risk，0-100，默认0；≥80遭到全面扫黄打黑。
5. 威望：faction，0-100，默认0；≥70被尊称为教父。

道具与旗标

1. 黑账本：item，false；true可要挟警局高层或敌对大亨。
2. 军火库钥匙：item，false；true可发动大规模火拼。

### 二、结局体系（共15个）

正结局（5个）

1. E01·一代教父：地盘≥80，威望≥70，成为地下皇帝。
2. E02·洗白上岸：资金极高，转型合法商人，安度晚年。
3. E03·复仇成功：手刃仇人，为兄弟报仇。

坏结局（10个）

1. D01·横尸街头：地盘归零，被敌对帮派火拼杀死。
2. D02·众叛亲离：兄弟忠诚过低，被心腹爆头。
3. D03·牢底坐穿：通缉度≥90，被警方逮捕。
