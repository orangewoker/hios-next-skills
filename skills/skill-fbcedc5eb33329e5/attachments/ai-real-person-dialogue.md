# AI 真人对白与表演生成

## 核心理念

AI对白/表演虚假的根源不是台词写得差，而是**节奏太干净、情绪太扁平**：A完整说完B再开口，如同轮流朗读；只会贴"悲伤/愤怒"标签，无情绪递进曲线。

消除AI感需要两个层面同时解决：
1. **台词层**：主动植入**言语失流畅（speech disfluency）**，模拟情绪压制语言的冲突
2. **表演层**：用**三层提示词架构 + 八维表演公式 + FACS面部AU编码**，把抽象情绪拆解为可执行的时序动作

真人对白的断裂与卡顿，本质是**语言表达速度跟不上内心情绪流速**：
1. **情绪过载**：心里想法太多，语言跟不上，出现抢话、重复
2. **情绪匮乏**：内心空洞无话可说，出现长时间沉默、简单敷衍短句
3. **心理防御**：害怕说出真心话，刻意卡顿、改口、打断自己

---

## ⚠️ 10条绝对禁止写法红线

1. **禁止轮流朗读台词**：A完整说完B再开口
2. **禁止情绪同步爆发**：如"愤怒哭泣"同时出现
3. **禁止瞬间大量流泪**：必须遵循「眼球湿润→下眼睑积水→眨眼困难→缓慢落泪」时序
4. **禁止全程持续语音重叠/无间断口吃**：保留少量完整正常台词做对比
5. **禁止机械均匀的口吃分布**：卡顿必须集中在敏感词/难开口的词上
6. **禁止自动补全被打断的句子**：被打断后不可由同一角色续完
7. **禁止所有人使用相同卡顿风格**：必须按人设差异化
8. **禁止……和——混用**：……仅沉默/失语；——仅截断
9. **禁止单段单人台词内超过2种卡顿/填充符号同时出现**
10. **禁止生理打断（咳嗽、哽咽等）单场超过2次**

# 第一部分：对白编排体系

## 第一步：收集用户输入信息

从用户获取以下信息（缺少时主动询问，禁止自行脑补人设）：

- **角色设定**：声线底色、性格、潜台词、基础情绪方向
- **场景背景**：发生了什么事，双方关系，当前情绪基调
- **对白的核心冲突**：这场对话要传达什么
- **输出类型**：纯剧本对白 or AI视频生成提示词（含表演控制）
- **语种**：中文 or 英文（影响卡顿规则）
- **时长/媒介**：30秒短片 / 长片

---

## 第二步：话语权流转规则

### 双人对话
精准标注语音重叠细节，如"前一角色台词尾音未完全结束，另一方提前0.1s切入，语音轻微重叠0.2s"

### 多人群戏（三人及以上）
- **话语权分层**：主辩人、附和者、旁观者、搅局者四类
- **多层重叠**：可出现「两人同时反驳第三人」三重语音重叠
- **旁观者隐性互动**：不说话但有肢体反应（皱眉、叹气、摇头）
- **群戏避坑**：禁止轮流挨个发言；区分主次发言者，避免多人同时抢话

---

## 统一标准化剧本标记符号

| 符号 | 含义 |
|------|------|
| 〔呃〕 | 语气填充卡顿 |
| …… | 长时间沉默/情绪失语停顿（**仅沉默，不可截断**） |
| —— | 话说一半截断（**仅截断，不可沉默**） |
| **加粗** | 重音、情绪爆发重读 |
| ～ | 尾音拖长、声音发颤 |
| <重叠0.3s> | 两人声音同步抢话重叠时长 |
| （气音） | 压低声、哽咽、耳语 |
| （吸气顿住） | 深呼吸后失语、情绪冲击停顿 |
| （打断-前句尾） | 精准卡在对方句尾打断 |
| （后半句改口） | 说到一半自我推翻修正 |
| （背景杂音盖过半句） | 环境噪音干扰台词 |

## 第三步：四层对白编排体系

### 第一层：语音重叠与抢话

**抢话**：听到刺激词，本能急于反驳。**沉默**：接收冲击性真相，短时间无法消化。

⚠️ 全程抢话会失真；**保留少量完整正常台词做对比**

**外部打断三类**：①物理环境（门响、手机铃）②生理本能（咳嗽、哽咽，单场≤2次）③第三方介入

### 第二层：言语卡顿设计

| 卡顿类型 | 对应情绪 |
|---------|---------|
| 重复词句 | 遭受误解、急于辩解 |
| 启动失败/口吃 | 愧疚、羞耻，卡在敏感词上 |
| 中途改口 | 隐藏真实想法 |
| 长沉默+吸气 | 骤知残酷真相 |

**口语杂质体系**：填充语气词（〔呃〕、嗯）、话尾拖音（～）、碎语吐槽（气音碎念）、半截短句（——）、反问穿插、口头禅重复

**密度规则**：陌生人→低密度；亲密/吵架→高密度；紧张/撒谎→填充词集中在句首；克制型人设→大幅删减

**人物差异化卡顿**：
- 内敛克制型：极少口吃，靠沉默、气音、放缓语速
- 冲动外放型：高频抢话、重复、填充词密集
- 自卑/撒谎型：卡顿集中在敏感词，频繁改口
- 成熟沉稳型：无多余杂质，靠留白制造张力
- 低龄幼儿（≤6岁）：语序颠倒、短句破碎、反复重复
- 青少年（12-18岁）：口头禅密集、情绪化断句

**分级话术破碎**：
| 情绪强度 | 卡顿配置 | 正常台词占比 |
|---------|---------|------------|
| 轻度争执 | 1处重叠、短停顿1-2s | >70% |
| 激烈对峙 | 3处重叠、改口1-2次 | ~50% |
| 情绪崩溃 | 大量半截句、长沉默、启动失败 | <30% |

### 第三层：高级情感表演

**公式：生理泄露 + 自我克制 + 关系目标**

**情绪保护层失效曲线**（通用路径 愤怒→悲伤）：
克制伪装 → 对抗质问 → 自我举证辩解 → 情绪裂缝（眼眶湿润）→ 声音破音 → 脆弱坦白/落泪

补充模板：①压抑喜悦：平静→细微笑意→眼眶发热→小声哽咽 ②恐惧慌乱：强装镇定→眼神躲闪→肢体紧绷→声音发颤 ③愧疚自责：回避话题→低声辩解→长沉默→自我贬低

**隐性潜台词**：表层温柔台词 + 下意识抗拒动作 + 细微语音卡顿。越想掩饰，卡顿越多。

**对话收尾**：①戛然而止（被打断/情绪冲击）②循环碎念（争执无果）③逃避离场（话说一半转身）④沉默冷场（无话可说）

### 第四层：逐秒时间轴标注

| 字段 | 说明 |
|------|------|
| 说话人 | 当前谁在说话 |
| 台词内容 | 含卡顿标记 |
| 触发关键词 | 刺激情绪波动的敏感词汇 |
| 肢体动作 | 表情、手势、视线方向 |
| 语音重叠时长 | 如<重叠0.3s> |
| 听者即时反应 | 不说话时的肢体/表情反应 |
| 话语权切换点 | 话语权从谁转移到谁 |

## 对白输出格式

```
[时间码] 说话人标记
台词内容（使用统一标记符号）
（肢体动作/表情描述）
{语音重叠/沉默标注}
→ 听者反应
```

# 第二部分：AI视频表演控制体系

## 分级写作模式

- **简易版**（快速试片）：去掉AU编码，用自然语言；情绪段落划分而非逐秒；保留言语失流畅规则
- **专业版**（精细成片）：完整八维公式 + FACS AU编码 + 逐秒时间轴 + 三层架构完整输出

**默认使用专业版，除非用户明确要求简易版**

---

## 三层提示词架构

**篇幅分配：全局20%、镜头20%、表演60%**

**模块化结构**：【通用固定段】画质/人物/声线必带 + 【场景替换段】按题材替换 + 【情绪自定义段】按剧情调整

### 第一层：全局控制（锁人物不变形）

固定参数：视频时长、画幅比例、24fps胶片质感、场景年代环境、人物外貌/服装一致性、光影风格、原生同步对白。

**示例**：
> 生成20s写实电影质感剧情短片，24fps，35mm胶片颗粒，20:9宽屏；场景为[现代公寓客厅]；[角色描述]全程五官、服装稳定不变；光影为暖色台灯侧光；原生同步人声对白，环境仅有都市环境音。

### 第二层：镜头时间轴（定分镜与时序）

拆分镜头区间，标注起止秒数、机位（近景/过肩/反应镜头）、运镜逻辑。将情绪节拍嵌入对应时间码。

**示例**：
> 镜头1【0-4s】：男性单人胸部近景，固定机位；
> 镜头2【4-22s】：双人过肩近景，镜头极缓慢微推，内分四段时序；
> 镜头3【22-30s】：男性反应特写，轻微手持抖动。

### 第三层：表演控制（八维公式落地）

## 八维表演公式

| 维度 | 内容 |
|------|------|
| 1. 时间段 | 精准绑定镜头内秒数区间 |
| 2. 人物目的 | 角色当下内心诉求 |
| 3. 情绪变化 | 完整情绪曲线（积累→转折→崩塌） |
| 4. 台词触发词 | 激活面部/肢体变化的关键词 |
| 5. 面部动作与AU | 肌肉动作 + FACS AU校准（强度A-E） |
| 6. 目光和身体 | 视线、身体姿态、手部小动作 |
| 7. 声音/呼吸/停顿 | 换气点、沉默、破音、抢话、口吃 |
| 8. 结束状态与禁止反应 | 定格状态；禁止失真行为 |

### 示范：女性愤怒转悲伤

> **时间段：4-8s 情绪阶段：压抑辩解**
> 1. 人物目的：不想承认多年付出被无视，先用强硬伪装掩盖难过
> 2. 情绪变化：表层强硬克制，眼底透出委屈
> 3. 触发台词："我从来没有奢求过什么"
> 4. 面部AU：AU4眉间下压强度B，AU7下眼睑收紧强度A，AU23嘴唇紧闭
> 5. 肢体目光：直视对方，肩膀绷紧，右手攥衣角
> 6. 声音停顿：语速平稳偏快，语音重叠0.5s，句尾轻微卡顿
> 7. 禁止反应：不低头、不流泪

### 年龄表演区分

| 年龄段 | 动作特征 | 卡顿特征 |
|--------|---------|---------|
| 幼儿（≤6岁） | 动作无逻辑，情绪外放 | 语序颠倒、无克制 |
| 少年（12-18岁） | 冲动直接，身体语言夸张 | 高频抢话、口头禅密集 |
| 青年/中年 | 动作有控制，情绪有层次 | 按人设差异化 |
| 老年 | 动作迟缓，面部变化幅度小 | 语速慢，长沉默，偶尔忘词 |

## FACS面部AU编码库

AI无法识别抽象情绪词，只能识别肌肉动作。**写作顺序：自然语言描述动作 → 补充AU校准**

### 高频核心AU表

| AU | 动作 | 适配情绪 |
|----|------|---------|
| AU1 | 眉毛内侧抬起 | 悲伤、委屈、强忍泪水 |
| AU4 | 眉毛下压、眉间收紧 | 愤怒、压抑、对抗 |
| AU5 | 上眼睑抬起 | 震惊、暴怒 |
| AU7 | 眼睑收紧 | 隐忍、恨意、紧绷 |
| AU15 | 嘴角下沉 | 低落、难过、失望 |
| AU17 | 下巴绷紧抬起 | 强忍情绪、欲言又止 |
| AU23 | 嘴唇紧闭收紧 | 压抑怒火、克制 |
| AU25/26 | 嘴唇分开、下颌张开 | 情绪爆发、嘶吼 |

### AU强度分级

| 强度 | 含义 |
|------|------|
| A | 微弱，仔细观察才能发现 |
| B | 清晰但轻微 |
| C | 中等标准 |
| D | 强烈，大幅肌肉运动 |
| E | 面部极限，接近扭曲 |

### AU搭配禁忌

- ❌ AU1+AU4 同时强度D以上 → 眉毛矛盾拉扯
- ❌ AU5+AU7 同时强度C以上 → 眼周肌肉矛盾
- ❌ 多AU全拉至D/E → 全脸不自然
- **正确做法**：1-2个主导AU强度C-D，其余低强度A-B辅助

### 动作三阶段规范

所有表情必须标注：**Onset（开始）→ Apex（峰值）→ Offset（缓慢消退）**，杜绝瞬间切换。

## 对白去AI机械感附加指令

在表演层末尾统一添加：禁止轮流朗读；台词含重复词句/改口/半截短句；崩溃段伴换气卡顿、长沉默；禁止规整轮流朗读节奏。

## Seedance2.5推荐参数

| 参数 | 推荐值 | 作用 |
|------|--------|------|
| 面部一致性权重 | 0.85 | 防止换脸/漂移 |

| # | 问题 | 解法 |

# 第五部分：表情控制提示词库

## 万能公式

### 真人摄影级提示词模板
电影级特写肖像，**[表情词]**，休闲优雅服装，柔和自然光，浅景深，85mm镜头，8k，高细节，获奖摄影作品。

## 情绪核心提示词

### 喜悦类
- 微笑：柔和微笑，嘴角微弯，眼神明亮
- 大笑：放声大笑，嘴巴大张，喜极含泪
- 喜极而泣：喜悦的泪水，笑着流泪，湿润闪亮的双眼
- 苦笑：苦涩微笑，五味杂陈，皱眉中带笑
- 假笑：虚假笑容，眼睛没有笑意

### 悲伤类
- 流泪：哭泣，泪水沿脸颊滑落，湿润的双眼
- 无声落泪：无声的泪，单颗泪珠落下，强忍悲痛
- 红眼眶：泪眼婆娑，眼中含泪，眼白发红
- 心碎：心如刀割，神情崩溃，嘴唇颤抖
- 绝望：空洞的眼神，凝视虚空，面容死寂

### 愤怒类
- 怒视：怒目而视，死亡凝视，锐利穿透的目光
- 皱眉：紧锁眉头，眉心拧起，额头褶皱

### 恐惧/惊讶类
- 惊恐：惊恐万状，双眼圆睁，面色苍白，嘴唇发颤
- 震惊：震惊失色，双眼圆睁，眉毛上扬，嘴巴微张

### 生理状态类
- 吞咽：紧张地用力吞咽，喉结明显滚动
- 深呼吸：深深吸气，双眼短暂闭合

### 暧昧/特殊类
- 脸红：满脸通红，双颊绯红
- 坚定：目光坚定，眼神不屈，炯炯有神
- 迷离：眼神迷离，半阖双眼，慵懒妩媚

## 微表情动态公式

```
[镜头运动] + [情绪阶段1：初始状态] +
[转折触发（接着/随即/然后）] +
[情绪阶段2：过程变化] +
[收尾定态：最终表情定格]
```

### 示范1：崩溃痛哭
> 固定镜头，初始:双眼瞪大(不敢置信);接着:眼眶迸裂出泪，嘴角失控抽搐;然后:喉间哽咽，额纹拧起;收尾:泪雨糊住视线，下颌痉挛般颤抖

### 示范2：从伤心到决绝
> 固定镜头，初始:眼眶泛红嘴角微颤(不可置信);接着:眼珠瞪大，眼尾眦裂，脸颊肌肉抽搐;收尾:嘴角狠狠下压，下颌扬起，眼神冰冷如霜

# 第六部分：肢体动作提示词库

## 6.1 单人动作模板（6类各1核心）

### 走路（出场/退场）
> 电影级中景，{{角色}}沿{{场景}}缓步前行，步伐稳定，肩线平稳，目光直视前方。衣摆/发丝随步伐轻摆。正面迎镜/侧面跟拍/背面跟拍。❌禁止同手同脚。

### 奔跑（追逐）
> 电影级中景/全景，{{角色}}全力奔跑，发丝飞扬，表情焦急或决绝。手持晃动增强紧张感。❌禁止肢体僵硬、脚离地不自然。

### 下跪（屈辱/忏悔）
> 电影级中景，{{角色}}双膝缓缓落地，可搭配双手撑地/仰头望人。低角度仰拍增强压迫感。❌禁止膝盖穿地。

### 喝茶饮酒（过渡/决断）
> 四段式：①举杯→②杯沿触唇停顿→③喉结滚动饮下→④放下杯，眼神已变。

### 转身回头（名场面）
> 类型：决绝转身/蓦然回首/被叫住回头/回头一笑。逆光回眸效果最佳。❌禁止身体僵硬。

### 手部特写（情绪暗示）
> 核心动作：握拳（克制怒意）、颤抖的手（端杯洒水）、擦泪（指背轻拭）、递物（指尖犹豫）、执笔（悬腕停顿）。❌禁止多指/畸形。

## 6.2 双人动作模板（6类各1核心）

### 拥抱
> 类型：重逢紧拥/安慰拍背/告别收紧又松开/强迫挣扎。手部位置自然，避免穿模。❌禁止多余手指。

### 打斗
> 格挡、闪避、擒拿、踢击，快慢结合有打击停顿感。手持晃动+多角度切换。❌禁止肢体扭曲。

### 对峙
> 两人面对面，A下颌微抬眼神冰冷，B眉头紧锁眼底有怒。一左一右中间留白，侧光一明一暗。

### 诀别
> 雨夜长街，A背影向前不回头，B原地伸手想挽留又收回。冷蓝雨夜+昏黄路灯。

### 重逢拥抱（逐秒）
> 【0-2s】看到来人瞳孔一亮→【2-4s】奔跑+张开双臂→【4-6s】紧紧搂入+闭眼→【6-8s】脸埋肩窝，肩膀微抽。

### 扇巴掌
> 【0-1s】手臂高扬→【1-2s】头偏向一侧，发丝飞扬→【2-4s】缓缓转回，眼神从震惊变阴鸷→【4-6s】胸口起伏，手发抖但倔强瞪着。

# 第七部分：情绪表演提示词库

## 7.1 哭泣六类型（保留2代表+4概括）

### 代表1：委屈型（机械动作→思念崩溃）
**弧线**：机械麻木→停顿反刍→委屈上涌→强吞压抑
- 通用公式：[固定镜头][暖色单侧光]，深夜独处，面前放着触发委屈的[食物/物品]
- 关键动作：机械动作→顿住→盯触发物眼眶泛红→鼻翼翕动→低头猛做→边做边落泪
- **核心**：全程无台词，靠"忙"压痛。鼻翼翕动是最真实的委屈信号。

### 代表2：崩溃型（不想相信→悲伤落泪）
**弧线**：失神不信→强撑假笑→压抑蓄泪→崩溃落泪→含泪释然→彻底放手
- 关键动作：瞳孔失焦→扯笑→笑意垮掉→眼眶蓄泪→第一滴泪→含泪浅笑→抬手擦泪→指缝泪落
- **核心**：六段情绪链——瞳孔先碎→嘴硬→眼眶兜不住→泪崩→含泪笑→彻底不装

### 其余4类（一句话特征）
- **心死型**：空洞→极慢冷笑→下巴抬高蔑视。冷笑必须极慢——快是嘲讽，慢才是心死。
- **强忍型**：涣散→聚焦认出→下巴绷紧→下唇颤抖→泪水悬而未落。不落比落了更揪心。
- **无泪型（克制愤怒）**：瞳孔放大→咬唇泛白→眉间抽搐→身体发抖→无泪通红眼眶。愤怒走肌肉不走泪。
- **幸福型**：注视→眼眶浅红→泪光打转→破涕为笑。嘴角始终有笑意，泪水不能落。

## 7.2 笑五类型（保留2代表+3概括）

### 代表1：大笑（全然释放型）
**弧线**：仰头大笑→道具遮口鼻→眉眼舒展平静
- 关键动作：仰头敞开→抬手/道具遮面→恢复平静
- **核心**：收尾眉眼必须平和（不冷、不媚），否则误解为别有用心。

### 代表2：害羞的笑（端庄内敛型）
**弧线**：面色淡然→嘴角不受控上扬→拼命忍笑→道具遮掩
- 关键动作：嘴角上扬→肩膀微抖眼泛光→道具轻掩/低头藏笑
- **核心**：端庄人设vs身体本能的冲突。

### 其余3类（一句话特征）
- **娇羞型**：低头专注→被唤抬头→瞳孔0.3秒闪光→歪头笑。歪头+梨涡是天真标志。
- **微醺型**：闭眼沉醉→睫毛缓缓打开→目光软凝视+笑容慢绽。所有速度都要慢。
- **妩媚型**：静默背对→揭帘慢转头→目光锁定+嘴角上扬暖心笑。关键在慢。

## 7.3 复杂情绪15种（保留5代表+10概括）

### 代表1：复仇冷意
**弧线**：抬眉审视→皮笑肉不笑→开口如刀→笑不变眼如刀。**核心**：嘴角弧度和眼底寒意完全割裂。

### 代表2：决绝
**弧线**：强压恐惧→闭眼叹气→睁眼气场反转→冷笑蔑视。**核心**：闭眼前是弱者，睁眼后是王者。

### 代表3：绝望
**弧线**：呆立流泪→瞳孔失焦→拼命摇头→腿软瘫坐。**核心**：一上来就塌，不给准备时间。

### 代表4：恐惧
**弧线**：瞳孔放大→呼吸骤停→后退撞墙→咬唇→蜷缩。**核心**：从内到外层层吞噬：瞳孔→呼吸→肌肉→全身。

### 代表5：重逢克制
**弧线**：僵住→吞回眼泪→社交微笑→转身泪落不回头。**核心**：戏剧张力在于不给看，转身才允许崩溃。

### 其余10种（一句话特征）
- **暗爽**：道具遮脸→眼底闪光→偷瞄。不能让人发现。
- **悲伤**：失神→强笑→压抑→泪崩。先笑后崩更揪心。
- **得意**：挑眉→扫视→笑意漫上→笃定。得意不张扬，是从容。
- **冷笑（嗤笑）**：瞳孔涣散→病态嗤笑→狂笑→断裂。用笑代替哭。
- **嫉妒**：微笑→笑意冻结→嘴角变直线→封口冷笑。比哭更心碎的笑。
- **奸佞**：谄媚堆笑→僵硬→笑容退潮→冷淡了然。笑瓦解越慢越有戏剧性。
- **冷静（阴狠剥落）**：微笑→眼底降温→瞳孔微缩→笑意变面具。嘴角在笑眼睛在冷。
- **心疼**：注视→伸手半空停住→擦泪强笑。疼的不是自己更难受。
- **厌恶**：职业微笑→偏头避对视→嘴角下拉→冷淡。像看空气里的灰尘。
- **震惊**：瞳孔骤放(0.3s)→手抖→眼圈速红→闭眼接受。震惊一瞬消化几秒。

## 7.4 男性专属5种（保留2代表+3概括）

### 代表1：崩溃边缘
**弧线**：站碑前呆立→泪下→张嘴无声→捶地嘶吼→低头抽泣。**核心**：捶地一拳是物理高潮。

### 代表2：隐忍怒意
**弧线**：微怔→指关节泛白→下巴收紧→冷笑→抬眸如刀。**核心**：笑得越冷怒越深。

### 其余3种（一句话特征）
- **得逞邪笑**：转笔→抬眸邪笑→回味→宣布。眼底算计比嘴角诚实。
- **温柔宠溺**：闭眼带笑→慢聚焦→眼底水光→埋头藏笑。身体比大脑更早知道幸福。
- **心疼到窒息**：盯着→眼眶速红→伸手摸玻璃→闭眼落泪。没力气撑了。

# 通用规范

## 硬性约束（不可违反）

1. 禁止轮流朗读台词
2. 禁止自动补全被打断的句子
3. 禁止机械均匀口吃分布
4. 禁止情绪同步爆发（如"愤怒哭泣"同时出现）
5. 禁止瞬间大量流泪
6. 禁止单场生理打断超过2次

## 七项自检清单

1. 不同角色卡顿风格是否区分？
2. 公共/私密场景环境音是否匹配？
3. 对话结尾是否有非完美收尾？
4. 克制角色是否未过度抢话/填充词？
5. 语音重叠时长是否匹配情绪激烈程度？
6. 哽咽/喘息是否绑定对应情绪？
7. 多人场景是否有旁观者留白/多层抢话？

## 权重说明

- 对白优先级：**语音重叠&停顿 > 情绪匹配卡顿 > 生理克制表演 > 时间轴标注**
- 人设逻辑优先级高于口语杂质
- 单段单人台词同时出现的卡顿/填充符号不超过2种
- AI视频提示词篇幅：全局20%、镜头20%、表演60%
- 所有符号/打断设计必须贴合人物性格

## 创作内核

AI人物拥有真人质感，不在于学会标准的哭泣、标准的愤怒；而是呈现出一种**无力感**：有些话语，难以顺畅说出口。

优秀对白设计，不是雕琢华丽台词，而是安排两个角色的情绪在同一时刻相遇、碰撞，而后归于沉默。

世界本身不存在绝对规整完美的秩序，适度的断裂、卡顿、失衡，才是真实，也是独有的美感。
