# 提示词模板与条件模块

## 1. 资产生图提示词模板

```text
【资产ID与用途】单一职责：FACE|BODY|LOOK|MARK|LOC|GEOGRAPHY|PROP
【唯一主体】明确是谁/是什么，画面只完成一项资产任务
【不可变身份】五官、体型、年龄、自然不对称标记、核心结构
【本态造型】服装、妆发、材质、磨损或状态（确定性写法，禁止"或"字）
【构图与视角】与未来镜头需求匹配；载具与关键道具面朝画面右
【光线与背景】便于辨认，不让背景承担故事动作；场景资产必写影调明度行
【视觉指纹】本项目必要风格属性（引用冻结的style_line要点）
【禁止】多余人物、排版感、未登记文字、混合其他造型、镜像导致关键标记换侧
```

需要多个方向时分别生成独立资产ID，执行提示词中不得出现未决替代方案。

## 2. 关键帧提示词模板

```text
【Keyframe ID】KF-段-镜-A/B；此图＝电影镜头定格，非设定图
【镜头职责】首状态｜过渡状态｜终状态
【空间锁】角色身份、造型状态、道具持有、站位、朝向、场景地理、关键标记侧
【构图】画幅、安全区、景别、机位高度、角度、前中后景、视线对象
【动作瞬间】只描述此帧可见姿态与受力，不写整段动作
【光线与视觉指纹】仅本镜相关属性；影调行
【参考】逐图写允许控制/禁止迁移；身份图仅供五官与本形态服装，不迁移站姿
【文字】非文字镜不得出现未登记文字；关键文字镜生成干净载体，文字后期叠加
【排除】只列与本帧直接相关的2-5项高风险失败模式
```

接触表（按镜号拼图）只供人审四查：方向、标记侧、影调对场景图、形态对连续性卡；每帧与canonical主档并排比对眼距/鼻梁/嘴型。

## 3. 视频提示词·标准生成版（默认）

紧凑自然语言，约180-350中文字符核心信息：

```text
【Clip】{ID}｜{时长}｜{画幅}｜单一连续镜头
【空间锁】{批准的角色/造型/道具/场景/站位/朝向；未声明内容保持不变}
【起始状态】{第0秒可见状态，通常＝首帧}
【时间动作】{单一主动作，按因果顺序；必要时少量时间段}
【摄影】{机位、运动、焦点、可信的不完美；不与关键帧冲突}
【结束状态】{最后可剪状态＋头尾把手}
【声音】{按audio_route编译；post_audio时写：无音乐、无旁白，仅动作与环境声线索}
【参考】{逐图职责、禁止迁移、优先级}
【排除】{仅本镜最高风险少量失败模式；节点不支持负面词时改写为正向锁}
```

## 4. 视频提示词·诊断版（仅高风险/返修）

在标准版上按需加：更细时间片、局部不变量与变形边界、首/尾/过渡帧职责、身体与道具接触顺序、相机与主体运动分离说明、针对本次失败的负面限定、种子与参数记录。与当前失败无关的约束一律删除。

## 5. 条件模块（按镜头特征挂载，不全局复制）

**变身/换装**：一Clip一处主变化；人与载具大变形拆开。写清起始→变化机制→落定，旧件退场动词、新件登场、残留物处理、一声定音。特效推进至颈部绕行，五官只被照亮；模型不能可靠首尾控制时拆成触发镜＋结果镜。

**对话与表演**：有录音以音频时长为时钟；不支持口型时用侧脸/背影/听者反应/后期配音。微表情只给一条可读路径（视线停住，嘴角收紧，呼吸变浅），不强制周期眨眼。双人同框写清左右、视线对象、谁在前景，遵守已建立对话轴。

**追逐与动作**：Sequence内建立屏幕运动方向，改向必须在画面中发生或经中性镜重建立；主体运动与机器运动分开写；复杂接触拆动作或加遮挡镜。

**产品与关键道具**：轮廓、标签区、接口、开合方式入不可变资产；精确标签走后期；使用前/中/后状态分别登记，禁止无因变形。

**文字/UI**：默认生成无字载体；字幕、倒计时、UI进后期清单。必须模型出字时先短样验证，失败立即回后期路线。

**参考视频**：仅supports_reference_video=true时用；只控制动作节奏/主体运动/机运其中一项；污染身份或背景先裁切静音遮罩。
