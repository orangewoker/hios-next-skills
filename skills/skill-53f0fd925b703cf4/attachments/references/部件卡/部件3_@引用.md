# 部件卡3 · @引用（含扩展5种）

## 基础引用（2026-08-05升级：加「这是一张XX图」+颜色隔离）

> ⚠️ 铁律（硬规则13）：@引用禁写视角/机位/空间/运镜/表演指令。@引用只回答"这张图是什么+干什么用"，视角机位构图全部在正文。违者退回。
> ⚠️ 颜色隔离：@引用不写hex颜色值（色卡锚定行除外），颜色统一由色卡图锚定，防止重复锚定打架。
> ⚠️ 类型词从资产卡抄录：图片类型（角色设计图/环境图/俯视图/入口视角/外观图/道具图/画面色卡图）按资产卡实际定义写，不臆造。

```
角色：@[hash] 这是一张[角色名]的角色设计图，作为[角色名]的形象视觉锚定（关键特征括号补，可带本段状态；非打斗段功能句=身体状态/性格，打斗段功能句=战斗风格）
色卡：@[hash] 这是一张画面色卡图，作为整段画面色卡锚定+严格按色卡执行+[hex][色名]光色落点+[材质]（照万物生句式，视觉钉子用"画面唯一允许的高饱和色"；唯一允许写颜色的行）
环境：@[hash] 这是一张[场景名]的俯视图/入口视角图/环境图，作为[场景名]环境视觉锚定（布局细节可写，颜色不写）
道具：@[hash] 这是一张[道具名]的道具图，作为[道具名]的形象视觉锚定（关键特征，颜色不写）
音频：@[XX音色hash] 作为[角色名]说话的音色锚定（有对白必写，对白角色每段各1行；音色资产由用户自制/外部提供，占位hash格式=@[XX音色hash]）
  铁律（2026-08-05用户确认）：凡有对白的段，对白角色必须挂音色锚定行，格式照万物生「作为XX说话的音色锚定」。漏挂=退回。
群像：@[人群hash] 作为人群服装风格视觉参考，人群中每一个人的长相、年龄、性别、体型都各不相同，共享同一套服装语言
```

## 衔接方式5选1（跨段，按分镜表"衔接方式"标注选）
```
①尾帧继承：@上段尾帧图做本段图生视频首帧（适合连续长镜头；不适合蒙太奇/快剪）
②动作峰值衔接：段尾定格动作最高点+段首续同动作下一阶段（适合快节奏打斗；不适合慢动作/缠斗）
③遮挡过渡：段首"第一帧被烟尘铺满→散开→露出人物"+只拍单方避同框（适合同场景跨视频续）
④完全重新起幅：不@图，文字完整定义新机位/站位/姿态（适合不同事件/回合切换）
⑤首尾帧双锚定：起幅图+收幅图（需支持首尾帧的平台）
禁选：段边界=停顿对峙但选尾帧继承=退回；写两个混选=退回
```

## @引用完整性核验（2026-08-05重写·封闭集合勾选+正文扫描双机制）

> ⚠️ 旧版"从正文逐道具检索"废弃——回忆式检索会漏（实证：镜5引擎盖掀开时漏灰车，分镜表同坑）。改用双机制，两步都是机械动作不是检查项。

```
机制① 资产清单封闭勾选（主机制·写@引用时必过）：
  资产清单是全片固定封闭集合（从出图总清单/资产卡抄录，逐段不变）。
  每段写@引用时：逐张过清单，每张问"本段出现？不出现？"
    出现→写锚定行（含本段状态）
    不出现→明确跳过（不写）
  封闭集合逐张判断不会漏；回忆/抄录可变文本都会漏。

机制② 正文扫描复核（写完正文后必过）：
  正文逐句扫描，圈出所有实体名词（角色/场景/道具，含画外声源与入画局部如"爪/手/引擎盖"），
  与@引用列表逐项对照。正文出现但@引用无锚定=退回补写。
  特别注意：入画局部（爪/手/引擎盖/车身局部）=画面出现，必须锚定；画外声源（收音机播报延续）=声明声音来源不锚视觉。

禁止"跨段默认"：每段@引用独立完整，上一段的锚定不跨段生效，跨段道具（车/枪/收音机/维修单）每段重新@。
```
