## 真实感的定义

场景真实感不是日常动作越多越真实，而是人物行为能够由处境、目标、判断和策略解释。表演强度可以夸张，但行为因果不能空缺。

不要先要求演员“悲伤、紧张、狠、破碎”。先建立人物正在对谁做什么、为什么现在做、想让对方发生什么变化。

## 行为生成链

每个关键行为按此链条设计：

`stimulus（刺激） → judgment（人物判断） → objective（当下目标） → tactic（策略） → playable action（可表演行动） → 对方反应 → 新判断`

例：

`丈夫提到医院 → 她判断秘密可能暴露 → 想阻止继续追问 → 用照顾孩子转移话题 → 把药瓶藏进围裙并主动给孩子添饭 → 丈夫没有接话而看向围裙 → 她改用攻击策略`

只写“她紧张地藏起药瓶”缺少判断、目标和策略，演员只能表演标签。

## Objective、tactic 与 playable action

### Objective

用“让某人做出某种可观察变化”表达：

- 让母亲签字
- 让丈夫停止追问
- 让上司相信自己不知情
- 让孩子离开房间

避免“获得尊重”“寻找自我”等无法在本场验证的抽象目标。

### Tactic

人物遇到阻力后改变策略。常用策略：安抚、试探、拖延、诱导、羞辱、讨好、威胁、装傻、转移、隔离、逼近、退出。

一个 beat 通常对应一次策略状态。策略没有改变时，不要因为台词换行就划新 beat。

### Playable action

给演员的 playable action 必须是可以“对另一个人做”的动词：

| 不可执行标签 | 可表演行动 |
|---|---|
| 更悲伤 | 让他为伤害你负责 |
| 更生气 | 逼他承认自己撒谎 |
| 更神秘 | 让他意识到你知道，但不说破 |
| 更强势 | 占住出口，让他必须向你请求 |
| 更脆弱 | 让他留下，同时假装你不需要 |

## 移动、停顿和距离

每次明显移动至少由一项触发：

- 获取或保护某物
- 改变与对方的距离
- 占据出口、光源、前景或权力位置
- 避开视线、触碰或危险
- 掩盖身体反应
- 迫使对方移动
- 完成习惯或维持表面秩序

不要让人物为了配合机位无故走到窗边。若摄影需要位置变化，先为角色建立可相信的目标或刺激。

### 停顿

pause（停顿）不是统一的“情绪加重”。标明停顿中发生什么判断：

- 搜索答案
- 决定是否撒谎
- 抑制身体反应
- 等待对方先让步
- 重新解释刚听到的信息
- 发现计划失效

停顿持续到判断完成、压力升级或被外部事件打断。不要每句重要台词前都加停顿。

### 距离

用距离表达可执行关系：谁靠近、谁不退、谁绕开、谁迫使对方让路。亲密不总是靠近，恐惧也不总是后退；根据人物策略决定。

## 视线与回避

eyeline（视线）必须有对象和目的：

- 看人：寻找反应、施压、求助、核验谎言
- 看出口：评估离开可能
- 看道具：担心证据、拖延回答、提示欲望
- 不看：惩罚、隐藏、维持自控、拒绝关系

回避视线不能自动等于撒谎。先决定人物害怕对方看到什么：愧疚、欲望、软弱、知识或身体反应。

给每场设计有限的视线变化节点。持续低头或持续瞪视会失去信息价值。

## 道具动作

prop action（道具动作）需要至少一种职责：

- 完成现实任务
- 维持表面秩序
- 占有、交换或拒绝关系
- 隐藏或暴露信息
- 让身体有策略性出口
- 记录连续性和时间变化

道具应进入因果：人物为何触碰、动作如何被看见、对方如何反应、状态如何延续。

避免无功能的喝水、点烟、擦桌子。若动作不改变表演、信息、声音或连续性，删除。

## 身体状态与环境压力

记录影响行为的现实条件：

- 疲劳、疼痛、饥饿、寒冷、醉酒、药物、伤口
- 空间拥挤、噪声、温度、光线、隐私、时间压力
- 服装、鞋、湿度、妆发、道具重量

身体状态应改变节奏、呼吸、姿势、动作范围和注意力，而不是只靠台词说明。

环境不是背景。门是否能锁、桌子是否挡路、声音是否会被听见，都能改变人物策略。

## 潜台词和对白

为关键台词写四层：

`字面内容｜真实意图｜对方听见的含义｜身体行为`

例：

| 台词 | 真实意图 | 对方理解 | 身体行为 |
|---|---|---|---|
| “你今天回来得挺早。” | 试探他去了哪里 | 她可能知道 | 不接外套，先看鞋底 |

当身体行为已经清楚时，缩短解释台词。人物可以说反话、答非所问、重复无关信息或用现实任务躲避，但必须服务 tactic。

## 演员指令翻译

按以下顺序给指令：

1. 场景事实：刚发生什么、人物知道什么
2. 当下 objective
3. 对手和阻力
4. 本 beat 的 tactic/playable action
5. 必须完成的空间或道具动作
6. 允许演员探索的部分
7. 何处触发策略改变

避免结果式指令：

- “这里哭一下”
- “更狠一点”
- “演出复杂感”
- “停三秒再回头”

改为行为指令：

- “让他相信你不在乎；只有当他准备离开时才阻止他。”
- “逼他承认，但不能让门外的人听见。”
- “继续完成收拾动作，直到他说出孩子的名字。”

技术要求需要精确时，把原因告诉演员：视线落点、动作接点、焦点范围、安全边界和连续性位置。

## 表演连续性

维护 performance continuity（表演连续性）台账：

| 镜头/Take | 进入情绪与知识 | Objective | Tactic | 身体状态 | 道具/视线 | 结束变化 | 强度 1–5 |
|---|---|---|---|---|---|---|---:|
|  |  |  |  |  |  |  |  |

非顺序拍摄或 AI 分镜尤其要锁定：

- 人物此刻知道哪些信息
- 是否已经做出决定
- 身体疲劳、伤势和呼吸程度
- 与对方的关系距离
- 道具在手上还是空间中
- 上一镜结束姿态和下一镜起始姿态

连续性不要求每条 take 情绪完全相同，但必须能剪成可信的策略和状态变化。

## 场景真实感检查

逐场回答：

- 人物是否拥有可观察 objective？
- 每个 beat 是否有新 stimulus、判断或 tactic？
- 移动是否来自人物需要，而非摄影方便？
- pause 中是否发生具体判断？
- eyeline 是否有对象和目的？
- prop action 是否参与关系、信息或现实任务？
- 身体和环境条件是否真正影响行为？
- 台词与身体是否形成潜台词，而不是重复？
- 场景结束后人物关系、知识或选择是否变化？
- performance continuity 是否足以跨镜和跨生成保持？

## 常见失败

| 失败 | 根因 | 修正 |
|---|---|---|
| 人物不断走动 | 用走位制造虚假活力 | 找 stimulus、objective 和空间目的 |
| 所有人都用停顿演深沉 | 没有具体判断 | 标明停顿内的选择或删除 |
| 回避视线等于撒谎 | 行为符号化 | 明确人物害怕被看见什么 |
| 道具动作很多但无意义 | 用忙碌掩盖空戏 | 让道具进入因果或删除 |
| 演员只收到情绪形容词 | 没有 playable action | 改成对他人实施的策略 |
| 特写很多却不动人 | 没有积累和行为转折 | 先建立目标、压力和不可逆选择 |
| AI 表演每镜重置 | 缺少状态台账 | 锁定知识、策略、身体和首尾姿态 |
