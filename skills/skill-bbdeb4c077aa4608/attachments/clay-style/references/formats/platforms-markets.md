# 平台规则与画幅

## 画幅与时长

| 平台 | 画幅 | 视频时长 | 备注 |
|---|---|---|---|
| 抖音/快手 | 9:16 | 5-15s | 竖屏短视频 |
| 小红书 | 3:4 或 1:1 | 5-15s | 图文或短视频 |
| B站 | 16:9 | 5-15s | 横屏 |
| 微信视频号 | 9:16 | 5-15s | 竖屏 |
| 通用图片 | 1:1 | - | 头像/海报/插画 |
| 通用横屏 | 16:9 | - | 壁纸/封面 |

## 合规要点

- 人物肖像：不生成真实 identifiable 人物的黏土化形象
- 品牌标识：不生成品牌 logo 或商标的黏土版本
- 儿童：儿童相关内容保持纯真健康
- 动物：不生成虐待或不当对待动物的内容
