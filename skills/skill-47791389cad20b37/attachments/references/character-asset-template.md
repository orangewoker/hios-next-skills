# 角色资产设定图提示词模板

本文件来自用户提供的角色设定集提示词模板，并改写为本 Skill 的固定角色资产规范。只允许生成完整角色设定图，不拆成多张资产。

## 固定模板

一张极致细节角色设定图，采用专业角色概念艺术的排版风格。整个画面以干净的白色为背景，清晰划分为多个信息模块，并配有标题（创意感艺术字）和简洁文本注释。

核心主体：画面左侧是主要角色，以一个极具张力、最能体现角色人格与身份的动态姿势呈现。角色脸型、眼睛、瞳色、发型、发色、体型、服装、鞋、装备、饰品和主配色必须与角色定义或输入参考保持一致。

排版模块：

1. **三视图**：在角色右边主图旁清晰展示同一角色的正面、侧面和背面标准站姿，用于完整呈现服装和装备结构。三个视角必须是同一人物、同一套服装、同一体型比例。
2. **表情集**：以六个小方格面部特写捕捉角色丰富表情，默认包含大笑、惊讶、专注、挑衅、困惑和生气。可根据角色人格替换等价情绪，但脸型、五官、瞳色、发型与饰品不能漂移。
3. **配件与细节**：将角色关键装备、耳机、武器、徽记、腰带、鞋、首饰、机械件或其它识别配件在同一张画面内单独放大展示，并配简洁注释。禁止另外生成配件图。
4. **色彩方案**：右下角设置清晰色板区域，列出角色主要颜色、辅助色、强调色、金属色或发光色。
5. **整体风格与光影**：画风参考当前角色或用户上传角色图。光影着重表现角色身上的反射与鲜明边缘光，用于区分衣物、皮革、金属、塑料、透明或发光配饰等不同材质。整体色彩参考角色配色。

最终成品：一张信息量巨大但层级清楚、设计感十足的专业角色概念设定图。纯二维概念艺术呈现，不做真实摄影，不做三维建模，不出现无关环境，不生成第二张拆分图，不添加与角色设定无关的新服装或装备。

## 使用规则

- 一个角色只生成一张设定图；三视图、六表情、配件细节、色板全部包含在这张图里。
- 用户提供参考角色图时，严格锁定角色身份和穿搭，不擅自二创换装。
- 多角色项目分别为每个主要/重复角色生成一张，不把多个不同角色塞进同一张设定图。
- 角色资产通过验收后永久作为视频阶段人物一致性锚点；不再补画场景、道具或逐镜图。
