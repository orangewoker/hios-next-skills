# 分镜与 prompt 模板（双模式）

写 prompt 的**总原则**：先气韵总纲统领 → 正面气质引导 → 否定词只在 negative 块。正向不堆砌 `no veins/no bones`。

---

## 一、气韵总纲句（每个 prompt 第一句必写）

```
Everything breathes the same breath — the figure, the wings, the halo, the drifting
motes — all rendered in hair-thin lines that dissolve at the edges, as if the whole
scene were a half-remembered dream.
```
（中文意：万物同息——人物、翼、光环、浮尘，皆以尾端消散的极细线绘成，仿佛整幕是一段将醒未醒的梦。）

---

## 二、Negative Prompt 块（统一压制写实翻车项）

直接复制到生成工具 negative 栏：
```
realistic feathers, plumage, membranous wings, wing bones, anatomical wing structure,
glowing halo bloom, radiant mass, cherub baby face, cute anime style, heavy shading,
cast shadow, solid hair mass, thick outline, 3d render, photorealistic, extra limbs,
volumetric shading, soft 3d skin, smooth gradient skin, subsurface scattering,
chiaroscuro, glossy highlight, octane render, baroque oil painting, realistic skin texture,
detailed realistic eyes, environmental lighting, depth of field photograph
```

## 五、分镜表（成片用，含每镜动画提示词）

视频成片采用 **双轨分镜**：① 图文 prompt（出静帧）② 每镜独立 **动画提示词（motion）**，描述该镜发/翼/衣袂的具体微动 + 转场 + 循环。动画提示词汇总进分镜表，与静帧 prompt 一一对应。

### 动画提示词（motion）写法铁则
- 幅度极低：飘浮位移 ≤ 画面 5%，发/翼尾端缓动；天野流是"微动"非"大动作"。
- 运动类型限 `drift / float / breathe / sway / dissolve`，禁 `walk / run / fight / zoom`。
- 转场只用 `dissolve / bloom / fade`，禁硬切。
- 循环：首尾帧线语言一致，溶解相接，周期 4–8s，与情绪曲线同步。
- 运镜动机 = 角色漂移或羽落，禁无动机随机抖动（破坏气韵同源）。
