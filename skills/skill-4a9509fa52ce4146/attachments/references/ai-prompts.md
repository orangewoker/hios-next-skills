# AI 素材提示词文档规范（图片 + 视频）

> 用途：步骤 6 生成《AI 素材提示词文档》时读取。该文档**单独交付**（与剧本/分镜文档分开），内容是：关键人物、场景、物品的 **AI 生成图片提示词** + **视频生成提示词**，供用户直接用于文生图/图生图/文生视频/图生视频工具。
>
> **边界**：本 skill 只产出提示词文字，不实际调用生图/生视频工具。

## 一、提示词文档结构

```text
《剧名》AI 素材提示词
├── 一、总则（画幅 / 风格 / 人物一致性要求 / 负面词通用段）
├── 二、关键人物提示词（每人：图片提示词 1-2 条 + 可选表情/动作变体）
├── 三、关键场景提示词（每场景：图片提示词 1 条 + 图生视频提示词 1 条）
├── 四、关键物品提示词（每物品：图片提示词 1 条）
└── 五、关键情节视频提示词（按爆款名场面选 2-4 段，含镜头轨迹/构图/转场设计）
```

## 二、图片提示词编写规范

### 结构模板（一条完整提示词按顺序包含）

```text
[主体设定] + [外貌细节] + [服装道具] + [动作神态] + [场景环境] + [光线色彩] + [画面风格] + [镜头与构图] + [画幅与画质]
```

- 主体设定：谁、什么身份（如"24 岁中国年轻道士"）
- 外貌细节：发色发型、脸型、眼睛、身材（供人物一致性）
- 服装道具：标志性服装与随身物（如"青色道袍、朱砂符纸、桃木剑"）
- 动作神态：正在做什么、什么表情（可拍、可表演，按细节三级标准写微表情与动作轨迹）
- 场景环境：地点、关键道具、环境状态（含风/光/物的动态反应）
- 光线色彩：按整体画面风格（如"冷调夜光 + 朱砂红点缀"）
- 画面风格：按 `references/visual-style.md` 选定的风格名与特征
- 镜头与构图：景别、机位角度、构图手法（见下方"构图手法库"）
- 画幅与画质：如"9:16 竖屏，超高清，8k，电影质感"

### 人物一致性要求

- 每人至少 1 条**基础形象提示词**（正面 + 全身 + 标志物），作为全剧人物基准。
- 建议附变体：三视图 / 正面特写 / 表情集，方便后续图生图保持同一人物。
- 服装变化时（换装/受伤/身份伪装）单独写变体条，并注明"基于基础形象，服装改为……"。

### 负面词通用段（附在每条提示词后）

```text
（负面提示词建议）：多余手指、畸形手、变形脸、低分辨率、模糊、水印、文字水印、多余人物、比例失调
```

## 三、视频提示词编写规范（核心）

> **设计理念（本 skill 的视频提示词灵魂）**：
> 一镜到底提示词，设计的不是"镜头一直运动"，而是 **人物注意力 + 空间关系 + 摄影机路线 + 动作因果 + 信息释放** 五件事。摄影机每移动一次，都应该让观众多知道一件事；每一次移动都有叙事理由。运镜不是炫技，是人物注意力的延伸。信息要分层揭示，不第一秒把全部信息塞给观众；物理过程必须写清楚（人物真实汇合而非瞬移）；结尾只给反应、不给答案，悬念留在画外。
>
> **镜头不强制运动（重要）**：静止机位/固定镜头是默认合法状态，不是"缺少运镜"。运动与否的唯一依据是叙事理由——没有理由就固定机位，让画面内的元素（人物动作、微表情、光影变化、物体反应）承载动感与信息；有理由（视线引导/信息揭示/空间建立/情绪推进）才运镜，禁止为动而动、为炫技而动。
>
> 本规范提供的构图/运镜/转场手法是**工具库**，实际创作时根据剧情自行设计、自由组合，禁止机械套模板。

### 3.1 视频提示词结构模板

```text
[起始画面：主体+场景+景别+构图] → [镜头运动轨迹：起点→路径→终点，分步写清] → [人物动作序列：起→路→终+触发运镜的动作] → [信息揭示：本段观众新知道的事] → [转场设计：怎么过渡到下一段] → [时长] → [情绪/节奏] → [声音/氛围]
```

### 3.2 镜头运动轨迹写法（路线必须明确）

- **分步写路线**，不写"镜头移动"这种笼统词。示例：
  "镜头1（0-3秒）：女主侧面近景 → 镜头后移并降为低机位，同时向后拉开，揭示背后整栋住宅楼 → 镜头转正面后退，女主随之后退半步 → 女主回头（未完成）触发甩镜，沿她视线快速甩向男主下车方向。"
- **每步注明触发原因**：是跟人物、揭信息、还是视线引导——不给无理由运动。
- **动作因果链**：物理过程写清楚（下车→关门→步行靠近→汇合→穿警戒线→绕到正面收尾），禁止瞬移。
- **允许固定机位**：镜头运动轨迹可写"固定机位"（静止镜头），此时必须在"人物动作/画面内容"中写明画面内如何承载动感与信息（人物入画出画、微表情变化、光影/物体反应）；无叙事理由时优先固定机位。

### 3.3 运镜触发原则（人物注意力延伸）

- 用**人物动作触发运镜**：如"女主听见车门声后先减速、回头，回望还没完成，摄影机就沿她的视线甩向男主"——甩镜是注意力的延伸，不是炫技。
- 机位跟随人物注意力的转移而转移；人物看哪里，镜头引导观众看哪里。

### 3.4 信息分层揭示原则

- 不第一秒塞满信息。示例顺序：开场先看建筑 → 中段看人物到场 → 进入封锁区后才完整展示地面物证。
- 每个镜头揭示一层新信息，观众每次获得一点，保持好奇与追看欲。
- 结尾只给反应、不给答案：先看地面→再抬头确认异常→镜头始终不展示他们看到的目标，悬念留在画外。

### 3.5 画面构图手法库（选用时写明构图名）

| 构图手法 | 说明 | 适用 |
|---|---|---|
| 对称式构图 | 主体居中，两侧对称 | 仪式感、对峙、身份揭露名场面 |
| 框景构图 | 用门框/窗框/立柱/前景遮挡框住主体 | 窥视感、压迫、身份反差（主角被"框"在底层） |
| 三分法 | 主体置于画面 1/3 分割线 | 竖屏主体偏下 1/3，留白引导视线 |
| 引导线构图 | 用道路/栏杆/光影线条引向主体 | 运镜跟随、汇合、揭示 |
| 对角线构图 | 主体沿对角线排布 | 冲突、动势、跌倒/扑救 |
| 中心构图 | 主体居中大特写 | 微表情峰值、情绪爆点 |
| 低机位仰拍 | 从下往上拍 | 男主/反派威压、大楼压迫 |
| 高机位俯拍 | 从上往下拍 | 主角受困、弱小、全场打脸场面 |
| 前景遮挡 | 前景虚化物体遮挡主体 | 偷窥视角、悬念、转场遮罩基础 |

### 3.6 转场设计手法库（写明转场方式与理由）

| 转场手法 | 说明 | 示例 |
|---|---|---|
| 遮罩转场 | 利用运镜中物体（门/柱子/手/黑影）划过画面遮挡完成切换 | 镜头跟男主进门，门扇划过画面→切到室内新场景 |
| 动作连贯转场 | 用人物连贯动作跨场景衔接 | 主角甩笔动作接笔落下的另一时空/另一场景 |
| 甩镜转场 | 快速甩动镜头模糊后接入新画面 | 视线甩向某人→硬切其特写 |
| 匹配剪辑 | 形状/动作/构图相似的两个画面相接 | 符纸燃烧的旋涡→首尔夜景的霓虹旋涡 |
| 声音先入 | 下一场景声音先到，画面后到 | 先听到刹车声，再切停车场 |
| 叠化/淡入淡出 | 时间流逝、回忆、情绪过渡 | 回忆段落用叠化 |
| 硬切 | 无过渡直接切，强化冲突 | 打脸、反转、惊吓瞬间 |
- 每条转场**必须写明理由**（强化冲突/时间跳跃/视线引导/悬念），不写"硬切"两个字了事。

### 3.7 参考样例（专业一镜到底提示词，标注"参考"）

> 以下为参考样例（用户提供），仅展示设计思路，不构成标准；其他剧情根据剧情自行设计。

- **镜头运动轨迹路线（分步明确）**：女主侧面 → 背后低机位揭示住宅楼 → 正面后退 → 回头触发甩镜 → 接男主下车 → 两人汇合 → 穿警戒线 → 背后揭示物证区 → 绕到正面收尾。
- **运镜触发（注意力延伸）**：女主听见车门声后先减速、回头，回望还没完成，摄影机就沿她的视线甩向男主。甩镜不是炫技，而是人物注意力的延伸。
- **信息分层揭示**：开场先看建筑，中段看同事到场，进入封锁区后才完整展示地面物证。不要第一秒就把所有信息塞给观众。
- **物理过程写实**：男主不是突然出现在女主身边，而是下车、点头、关门、步行靠近，再真实汇合。
- **结尾只给反应不给答案**：女主先看地面，再抬头确认异常，男主晚半拍跟随，但镜头始终不展示他们看到的目标，把悬念留在画外。

## 四、与剧本/分镜的衔接

- 提示词内容**必须与确认版剧情、分镜脚本一致**：人物形象对应人物表，场景对应分镜"场景美术"列，动作对应"人物动作"列，光线色彩对应整体画面风格。
- 从分镜"场景美术/光线色彩/人物动作"列可直接转写为提示词，禁止出现与分镜矛盾的设定。
- **分镜"镜头调度/画面构图/转场设计"列必须与视频提示词的运镜轨迹、构图手法、转场方式一一对应**，保证从纸面到提示词可执行。
- 标志性物品（如"朱砂符纸""桃木剑""玉佩"）在剧情中承担彩蛋/伏笔的，必须在提示词中突出并注明"关键道具"。

## 五、覆盖范围与数量

- **关键人物**：主角 + 重要配角/反派/感情线对象，每人 1-2 条图片提示词（含变体）。
- **关键场景**：全剧主要场景 2-4 个，每场景 1 条图片提示词 + 1 条图生视频提示词。
- **关键物品**：标志性道具 2-5 件，每件 1 条图片提示词。
- **关键情节**：按爆款节奏选 2-4 个名场面（开场钩子/大反转/结尾钩子），每条 1 段视频提示词——**必须包含明确的镜头运动轨迹路线、构图手法、转场设计、信息揭示顺序**。
