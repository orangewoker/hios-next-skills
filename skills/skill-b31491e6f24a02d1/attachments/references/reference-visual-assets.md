# 参考视觉资产生成规划模块

本模块负责把【制作清单】中的参考图需求转化为可执行的参考视觉资产规划、图片提示词、LibTV 连线计划和充分性检查；用户确认后可调用图片工具生成参考图。

---

## 一、创作确认清单

在规划任何参考视觉资产前，必须先完成创作确认清单：

1. **风格确认和输入**：用户上传合适的风格提示词（推荐）、用户文字输入、用户上传风格参考图、指定电影/导演/游戏/动画/艺术风格，或要求先给风格方向。
2. **角色音色音频处理方式**：Agent 设计并生成配音/音色样本（推荐）、仅文字描述、用户上传音色样本、主要角色分段音色控制，或用户上传与 Agent 生成混合。
3. **夸张及特殊表情列表**：确认是否需要表情参考图；列出角色、具体表情、相关剧情内容、镜头/段落、夸张程度、来源方式（用户上传 / Agent 生成 / 混合）。
4. **默认生成模型与项目比例确认**：用户须为本项明确选择自定义值或“使用默认值”。默认值为：图像 `ai_model: Lib Image`、2K；角色图 3:4；场景、道具、色板 16:9；特效参考图固定 `ai_model: LibNano Pro`、2K、1:1；视频 `ai_model: Seedance 2.0`、720p。项目比例可选 16:9、9:16、4:3、3:4 等，只同步到视频 `aspect_ratio` 和关键帧/首帧/尾帧参考图 `aspect_ratio`，其他参考图类型不跟随改变。
5. **参考图去噪选项确认**：确认是否对已通过初审的普通参考图启用 LibNano 2 去噪；色板和灰度深度故事板永不去噪。启用时只对初审通过的图去噪，再审核修复图后才可用于后续引用。
6. **门禁审核细致度确认**：`默认`（推荐）=按批次审核，不通过时该批次逐个审核；`全自动`=所有审核默认通过；`细致`=所有资产逐个审核。

硬规则：创作确认清单必须强制逐项确认选择；每一项都要得到用户明确回答或对该项明确授权，不得由 Agent 推断。用户必须逐项写明“使用默认值”或具体选择；一句“都行/按默认/确认”不能替代多项闭合。任一项未答，不得进入参考资产计划或生成提示词。未确认风格，不进入色板和视觉资产规划；未确认音色方式，不进入含台词镜头音频规划；未确认特殊表情需求，不擅自规划夸张表情图；未确认模型、去噪选项或门禁审核细致度时，均只能列为待确认，不得自动采用默认值或跳过门禁。

## 二、色板体系

色板只分两类：

1. **全局色板**：整部视频的基础影调，默认用于贯穿全片或大部分剧情的角色、场景、道具和关键帧。
2. **特定剧情部分色板**：在特定环境、特定氛围或特定剧情状态下替代全局色板。

不得按角色、场景、道具或关键帧建立独立的色板归属类别。

角色色板选择规则：主角或贯穿角色使用全局色板；只在一个特定影调段落出现的角色使用该段特定剧情部分色板；出现在两个特定影调段落的角色优先使用首次出现的特定剧情部分色板；出现在三个及以上特定影调段落的角色使用全局色板。

色板硬性规则：必须先调用内部 `@COLOR_PALETTE` 模块完成色彩决策，再把生成的色板提示词作为 promote 输入给 `generate_image_v3` 图片模型生成；参数固定为 `ai_model: Lib Image`、`aspect_ratio: 16:9`、标准画质 2K。提示词必须明确写出参考的影视作品色调（可列 1-3 部影视作品名及其色调特征），并要求独立电影级色板参考图，网格化纯白背景，无网格线，纯色板，无场景、无人物、无文字装饰、无画面内容，所有色板等宽、等距。

## 三、参考视觉资产类型

必须支持以下一级资产：

1. **角色参考图**：人物、非人类主体、生物、机械主体；群像图走单独分支。
2. **场景参考图**：主场景、场景变体、其他视角、其他时间、损害状态、延展空间。
3. **道具参考图**：与角色互动的物件、人物设定图内绑定物件、场景内可互动物件、跨分镜物件、叙事物件、状态变化物件，以及特效参考图。
4. **特殊表情图**：基于角色图生成 1:1 特殊夸张表情参考。
5. **关键帧参考图**：关键剧情处的动态进行中静态定格垫图。

除灰度深度故事板外，普通故事板与动作设计只提示是否需要，由用户自行决定或外部处理；本模块不内置普通故事板和动作设计生成模板。灰度深度故事板按第九节为视频 Promote 前强制资产。

## 四、硬性格式模板

### 角色参考图

使用 `generate_image_v3`，`ai_model: Lib Image`，`aspect_ratio: 3:4`，标准画质 2K。生成纯白网格化背景，无网格线的角色展示图。上半部分左侧为角色正面头部特写，上半部分右侧为角色侧面头部特写；下半部分左侧为角色正面全身照，下半部分中间为角色侧面全身照，下半部分右侧为角色背面全身照。下半部分展示强制不生成角色头部。必须包含角色全量风格提示词、身份、年龄、体型、面部特征、服装、材质、不可变锚点和禁止偏移。

### 群像角色参考图

识别条件：用户要求群像、团队、家族、班级、组织成员、多人角色合照或一次生成 2 人及以上共同角色参考时，走群像图分支，不套用单角色五视图模板。使用 `generate_image_v3`，`ai_model: Lib Image`，标准画质 2K；2-7 人用 `aspect_ratio: 16:9`，8 人及以上用 `aspect_ratio: 21:9`。画面只生成所有角色正面照，不生成侧面、背面、多视图或动作分镜。7 人及 7 人以下，每个角色都必须细致描写身份、年龄、体型、面部特征、服装、材质和不可变锚点；8 人及以上，不逐个角色细致描写，只写群体构成、阵营层级、核心代表角色和整体视觉规律。群像图必须强调角色多样性：年龄、体型、脸型、气质、服装轮廓、职业/阵营标识和站位层次不得同质化。

### 场景参考图

使用 `generate_image_v3`，`ai_model: Lib Image`，`aspect_ratio: 16:9`，标准画质 2K。生成场景参考图时不得包含任何角色。必须明确空间结构、入口、出口、纵深、遮挡物、光源、可调度区域、剧情用途、使用全局色板或特定剧情部分色板。

### 道具参考图

使用 `generate_image_v3`，`ai_model: Lib Image`，`aspect_ratio: 16:9`，标准画质 2K。生成纯白网格化背景，无网格线的道具展示图，三视图。若道具与角色或场景有关，必须连线引用相关角色图或场景图，并在提示词中说明该道具与角色/场景的互动关系。

### 特效参考图

特效参考图属于 P2 道具/变体资产，只在正式分镜或连续性规划确认需要时生成。固定调用：`generate_image_v3`；`ai_model: LibNano Pro`；`aspect_ratio: 1:1`；`quality_spec: 2K`。

固定提示词开头必须原样写入：

```text
根据以下角色/道具/场景，生成相应特效效果图，要求根据特效颜色，选择对比度最高的纯白色/纯黑色/纯绿色背景，画面中无角色，无道具，无具体背景，只有特效效果展示，要求如下：
```

其后由 Agent 自动连续写入实际引用的角色/道具/场景 nodeKey 与关联定义、特效使用场景和需要的特效效果；不得原样输出“+{{引用的参考图}}+定义和使用场景+需要的特效效果”、方括号提示或空占位符。参考图只用于确定特效来源、交互、尺度、颜色与使用语境，最终画面不得出现角色、道具或具体背景，也不要求写入位置或朝向。特效效果描述必须写明特效类别、触发源/载体、形态与边缘、主/辅色、密度或透明度、变化过程、交互对象及禁止项。

### 特殊表情图

1:1 格式；通过对应角色参考图连线引用生成；用于强情绪、喜剧夸张、惊恐、愤怒、绝望、觉醒等剧情表情，必须保持角色身份一致。

### 关键帧图

使用 `generate_image_v3`，`ai_model: Lib Image`，`aspect_ratio` 跟随项目比例，标准画质 2K。关键帧是为关键剧情处提高表现力而生成的垫图，是动态过程中的静态定格画面；可以包含挥动、加速、动态模糊、冲击、水花、烟尘、碎片、运动轨迹和摄影机运动感。必须设计影调、光影、色彩、构图、隐喻、情绪峰值和画面优先级。是否需要关键帧、需要几张，由剧情需求决定，不作固定数量要求。

## 五、专业子身份规则

完善参考图提示词时必须按资产类型切换专业子身份：角色基础设定用角色设计师；服装变化用服装设计师；机械主体用工业设计师/机械概念设计师；场景图用电影美术指导/场景概念设计师；道具图用道具设计师；武器图用武器概念设计师；特效图用视觉特效概念设计师；色板图用电影调色师/视觉开发艺术家；关键帧用电影分镜导演/概念艺术家/摄影指导；表情图用角色表演设计师/动画表情设计师。

## 六、生成顺序规划

P0：全局色板、特定剧情部分色板。

P1：基于对应色板规划基础角色图、基础场景图和参考音频节点。

P2：基于已生成角色/场景图规划角色变体、场景变体、相关道具图、独立道具图和特效参考图。

P3：基于道具图规划道具状态图；基于角色图规划特殊表情图。

P4：基于相关角色、场景、道具、色板规划关键帧。

### 生成顺序强制门禁

1. **P0 色板优先**：必须先输出 P0 色板生成计划或提示词，等待用户确认通过后，才能进入 P1。P0 和 P1 不可并行；未确认色板时，不得先规划或生成角色图、场景图、道具图和关键帧，除非用户明确关闭色板流程。
2. **逐阶段确认**：P0、P1、P2、P3、P4 每一阶段完成后必须等待用户确认，再进入下一阶段；不得自动从 P0 跳到 P1、P2 或 P3。
3. **逐张审核 / 批量审核**：每张资产必须有状态：`pending / passed / rejected / needs revision`。审核粒度按创作确认清单执行：全自动=默认通过；默认=批次审核，不通过批次逐个审核；细致=逐个审核。被标记为 `rejected` 或 `needs revision` 的资产不得进入正式分镜引用区。
4. **色板格式审核**：色板提示词输出前必须逐项检查：已调用 `@COLOR_PALETTE`、已作为 `generate_image_v3` promote 输入、`ai_model: Lib Image`、`aspect_ratio: 16:9`、网格化纯白背景且无网格线、纯色块、等宽等距、无人物、无场景、无文字、无装饰、无画面内容。缺任一项必须先补入提示词。
5. **角色格式审核**：单角色图检查 `ai_model: Lib Image`、`aspect_ratio: 3:4`、纯白网格化背景但无网格线、正面头部特写、侧面头部特写、正面全身、侧面全身、背面全身、下方全身视图不得生成头部、包含全量风格提示词。群像图检查 `ai_model: Lib Image`、2-7 人 `aspect_ratio: 16:9`、8 人及以上 `aspect_ratio: 21:9`、只生成正面照、7 人及以下逐个细致描写、8 人及以上写群体规律、角色多样性。缺任一项必须先补入提示词。
6. **场景/道具/关键帧/特效参数审核**：场景、道具等普通参考图检查 `ai_model: Lib Image`、`aspect_ratio: 16:9`、2K；关键帧/首帧/尾帧检查 `aspect_ratio` 跟随项目比例；特效图检查 `ai_model: LibNano Pro`、`aspect_ratio: 1:1`、2K、纯白/纯黑/纯绿三选一的最高对比背景、无角色/道具/具体背景、仅特效本体，且实际引用、关联定义、使用场景与特效描述均已写入。场景图必须写“不得包含任何角色”。若场景图出现角色，或特效图出现角色、道具、具体背景、占位符或错误模型/比例，该资产必须标记 `rejected` 并重生成。
7. **参考图初审、去噪与终审路径**：色板生成后只做色板审核；灰度深度故事板做结构/深度与正式分镜语义合规审核；二者永不去噪。其他参考图必须先完成内容与格式初审；初审未通过时直接 `rejected / needs revision` 并重生成，禁止去噪。初审通过后，只有已确认启用去噪且确有画质修复需要时才调用 LibNano 2；去噪完成后必须终审修复图，确认未改变主体、构图、资产细节或引用关系，终审通过的 nodeKey 才可用于后续引用。未启用或不需要去噪时，也须记录“初审 passed；去噪未启用/不需要”。

### LibNano 2 图片去噪固定方法

模型：LibNano 2。清晰度：4K。比例参数：使用和原图一致的比例。任务：只做整体修复与画质优化，不得重构画面。

固定提示词：

```text
请基于上传的图片进行整体修复与画质优化，不要重新生成画面。严格保留原图的排版、主体内容、人物/物体、动作、场景关系、构图和分镜顺序，不要改变故事内容，不要随意增删元素。重点优化以下问题：1. 去除画面脏感、灰感、噪点、颗粒感、压缩痕迹、杂乱纹理、模糊边缘和低质量伪影；2. 提升整体清晰度、细节干净度和画面通透感；3. 优化色彩，让颜色更纯净、更协调、更有层次，避免浑浊、发灰、发闷、过脏的颜色；4. 统一画面的视觉风格，包括色调、亮度、对比度、清晰度、线条质感、细节密度和整体精致度；5. 让画面看起来更干净、更高级、更适合展示，只做优化和统一，不要重构场景，不要改变角色外观，不要改变主体姿势，不要改变重要物体的位置。最终效果要求：画面干净、噪点少、边缘清晰、色彩通透、明暗自然、风格统一、观感高级。不要添加文字、logo、水印，不要多出新角色或多余元素，不要把图片改成完全不同的风格。100% pure CG, Unreal Engine 5 cinematic cutscene, Octane render quality, 8K ultra-detailed, ray tracing, global illumination, MetaHuman high quality digital humans, AAA game cinematic quality, The Last of Us Part II / Death Stranding / Detroit Become Human style cinematic restraint.超写实CG数字人，3A游戏过场动画级人物质感，Unreal Engine 5 / MetaHuman级角色精度。只强调人物本体质感，不依赖场景叙事。
```

## 七、LibTV / Agent 连线计划

若某张参考图依赖上游图，必须在计划中写明：上游节点、下游节点、连线方向、文档层 prompt 中的 `{{Node <nodeKey>}}` 插入位置。图片、色板、道具、特效、关键帧和音频锚点都必须满足“已连线到生成节点左侧，且文档层 prompt 内有对应 `{{Node <nodeKey>}}`”的闭合规则。

若后续交给 Agent `generate_video_v3` 工具执行，必须在执行前把 `{{Node <nodeKey>}}` 转换为 `{{nodeKey}}`；普通参考节点进入 `reference_nodes`，首帧锁定节点进入 `start_frame_image_node`，同一节点不得重复进入同义参数。

## 八、充分性检查

每批资产规划后必须检查：角色设定是否足够稳定；场景是否足够支撑剧情调度；道具是否覆盖角色互动和跨分镜变化；特效参考图是否覆盖需要独立控制的能量、火焰、烟雾、粒子或破坏效果；色板是否覆盖全局与特定剧情影调；关键帧是否覆盖需要强视觉控制的剧情点；是否有故事板或动作设计需要提示用户外部处理。若缺口影响正式分镜或视频生成，必须先补充规划，不得直接进入正式分镜。

### 全范围视觉参考完整性复查（静态阶段）

本次生产范围的全部正式分镜通过后，必须基于最终正式分镜和逐边界连续性报告再做一次完整复查。这不是只查“派生帧”，而是检查原有参考资产能否让每一个视频单元按正式分镜被可靠生成；不得以此前资产计划已完成代替。

逐镜从当前有效正式分镜的主体定义、空间与朝向、主体画面方位表、动作层、视觉优先级、台词、光影/风格和连续性字段提取核查证据，不得把字段压缩成概述。逐项核对：

1. **角色/主体**：每个清晰可见、承担动作、对白、视觉优先级或跨镜状态的角色/生物/车辆，是否已有身份、服装、伤痕和当前状态足够的参考图；戏份少不构成省略理由。
2. **场景与点位**：现有场景图能否覆盖本镜实际可见区域、空间结构、入口/出口、固定元素、主体相对方位、时间/天气/受损状态和镜头角度；同场景连续多点位须确认一张可实际引用的场景连续参考。
3. **道具与状态**：所有被拿取、使用、受损、改变状态、承担因果或作为视觉优先级的道具，是否已有正确版本、材质与当前状态参考。
4. **表情与表演**：剧情关键、极端或必须稳定复现的表情/姿态是否需要专门表情图、状态图或关键帧；普通可由角色基础图稳定表现的表演不重复生成。
5. **特效**：独立控制颜色、形态、边缘、密度、交互或持续状态的特效，是否已有相应特效参考图；若特效承担关键可见结果、结果出现的瞬间或本镜视觉优先级，色板、灰度故事板亮度或纯文字均不得代替特效参考图，必须生成并审核相应 P2 特效图。只有确属普通光影、且模型可由现有资产稳定确定时才不新增。
6. **连续性**：每个相邻制作镜的场景、状态、方向、首尾帧或派生起幅参考是否已存在并可在当前调用传入；同场景时间连续不可留空。

每项记录：正式分镜原文证据、已有资产名/nodeKey、覆盖结论（足够/不足）、需补充的资产类型与用途、初审/去噪/终审状态；足够时写“复用该 nodeKey＋依据”，不足时写入静态补图任务。需要母本前镜实际视频的尾帧或派生起幅图，标为运行时依赖而不伪造 nodeKey。所有静态补图审核通过、所有复用依据和运行时依赖均已记录，才可开始已就绪镜的深度故事板。

## 九、灰度深度故事板资产（视频 Promote 前强制）

深度故事板是正式分镜到视频之间的专用中间资产，不属于 P0–P4 的常规风格、色板或关键帧资产。其生成包、参数、引用、输出、审核和失效处理均以 `references/prompt-assembly.md` 为唯一准则；不得改写、删减或以自由提示词替代。

本模块仅保留资产生命周期规则：灰度深度故事板永不进入 LibNano 2 去噪，以免重绘或改变距离灰阶；必须进行结构/深度与正式分镜语义合规审核。任一审核失败标记 `rejected` 或 `needs revision` 并重生成。
