# 动态变化追踪表

本文件提供人物移动、形态转换、道具状态变化的追踪方法，确保跨分段的空间一致性。

## 一、变化类型分类

### 1. 位置移动类
- **平移移动**：地面水平移动
- **垂直移动**：上升/下降/跳跃
- **斜向移动**：复合方向移动
- **快速突进**：高速直线冲击
- **缓慢踱步**：焦虑/思考时的移动
- **撤退后撤**：因恐惧/战术而后退

### 2. 形态转换类
- **人形↔其他形态**：人形态↔兽形态/元素形态
- **体型变化**：法天象地、缩小术
- **分身/幻影**：一化多、残影
- **附体/附身**：灵魂转移、控制他人
- **元素化**：化为火焰、水流等

### 3. 道具状态类
- **手持道具**：武器、法宝、物品
- **离手道具**：抛出、掉落、被夺
- **激活道具**：注入法力、启动效果
- **损坏道具**：断裂、破碎、失效
- **轨迹道具**：飞行中、坠落中、旋转中

### 4. 姿态情绪类
- **情绪引发姿态**：愤怒前倾、狂喜后仰
- **战斗姿态变化**：进攻架势、防守架势
- **互动姿态调整**：因对话对象变化而转身
- **受伤姿态**：踉跄、跪地、扶物

## 三、变化描述规范

### 1. 移动描述必须包含
- **起始点参考**："从角色A身侧冲出"（关联已知位置）
- **移动方向**："向左上斜冲"、"垂直跃起"
- **移动速度**："快如闪电"、"缓慢沉重"
- **移动轨迹**："弧线绕过"、"直线突进"
- **结束点状态**："停在敌人面前三步"、"坠向云层"

**示例**：
> 角色C从角色A身侧突然化为银色闪电，轨迹从右下向左上斜冲，直指敌方首领手中的神器。

### 2. 形态转换描述必须包含
- **转换触发**："趁所有人不注意时"、"在狂笑声中"
- **转换过程**："身形扭曲拉长"、"化为一道银光"
- **前后对比**："从壮汉变成细犬"、"从实体变为残影"
- **转换时长**："瞬间完成"、"缓缓变化"

**示例**：
> 角色C在冲锋过程中身形扭曲，从人形态瞬间压缩为兽形态，体积缩小但速度倍增，化作银色残影。

### 3. 道具状态描述必须包含
- **状态变化**："从稳定持握到脱手翻滚"
- **视觉效果**："金光从盛转衰"、"塔身出现裂纹"
- **空间位置**："在空中划出坠落弧线"
- **影响范围**："光芒暗淡影响全场气势"

**示例**：
> 神器被撞得脱手飞出，塔身金光乱颤，在空中翻滚着划出歪斜的坠落轨迹，朝下方云层直直坠去。

## 四、跨分段衔接规则

### 规则1：位置连续性
- 如果人物在分段A末尾位于位置X
- 在分段B开头必须在位置X或清晰说明如何到达新位置
- **禁止**：分段A"在地面"，分段B"在空中"且不说明如何上去

### 规则2：状态继承性
- 形态转换后，新形态要保持到下次转换或有意识恢复
- **禁止**：分段4"化为兽形态"，分段5未说明变回，分段6"人形态攻击"

### 规则3：道具存在性
- 重要道具出现后，必须持续追踪直到：
  - 明确消失（被毁、远离、收起）
  - 场景切换不再相关
  - **禁止**：道具出现后莫名消失不再提及

### 规则4：情绪渐进性
- 情绪变化要有渐进过程，除非有强烈触发事件
- **示例合理**：压抑 → 嘲讽 → 狂笑 → 战意（有触发点：神器消失）
- **示例不合理**：压抑 → 直接战意（缺少情绪发展）

## 五、复杂变化处理

### 案例：角色C完整变化线
```
分段1-3: 【基础态】兽形态，角色A脚边，警惕观察
    ↓ (突袭决定，注意力空隙)
分段4:  【转换1】兽形态→高速冲击态（化为银影）
    ↓ (侧冲轨迹，目标神器)
分段4:  【动作】撞击神器，自身受反作用力
    ↓ (物理规律)
分段5:  【状态】跟随神器一起下坠（兽形态）
    ↓ (自由落体，稍后恢复)
分段6:  【场外】未出现在画面，隐含在下坠/飞回过程
    ↓ (完成任务，返回战场)
分段7:  【转换2】兽形态→人形态（飞回过程中转换）
    ↓ (抵达位置)
分段7:  【最终态】人形态，带伤但笑，站到角色A左侧
```

**描述要点分段分配**：
- 分段4：描述冲锋轨迹+撞击瞬间
- 分段5：描述下坠状态（可选，如果镜头跟随）
- 分段7：描述飞回+形态转换+最终站位

### 案例：神器坠落轨迹
```
分段4初: 敌方手中，金光流转
分段4末: 被撞脱手，空中翻滚，金光乱颤
分段5:   继续下坠，金光渐暗，越来越小
分段5末: 化作金色光点，消失云层下
分段6+:  不再出现，但其消失影响情绪和战局
```

## 六、错误检测清单

在生成完所有分段后，检查以下问题：

### 位置类错误
- [ ] 人物是否在分段间"瞬移"而未说明移动过程？
- [ ] 空中角色是否突然落地未说明？
- [ ] 地面角色是否突然升空未说明？
- [ ] 相对位置关系是否不合理变化（如A在B左边→突然右边）？

### 形态类错误
- [ ] 形态转换是否缺少转换过程描述？
- [ ] 是否转换后莫名恢复而未说明？
- [ ] 分身/幻影是否出现后未处理（未消失或未解释）？

### 道具类错误
- [ ] 重要道具是否出现后莫名消失？
- [ ] 道具状态变化是否缺少视觉描述？
- [ ] 道具持有者是否未说明交接过程？

### 情绪类错误
- [ ] 情绪是否跳跃式变化而无触发？
- [ ] 身体语言是否与情绪状态不符？
- [ ] 情绪是否未影响站位/距离？

## 七、一致性维护工具

### 1. 变化摘要表
为每个分段准备简短摘要：
```
【分段4】变化摘要：
- 角色C：位置[角色A侧→空中→下坠] 形态[兽→冲击→兽]
- 神器：状态[持握→脱手→坠落] 位置[敌方手→空中→下坠]
- 敌方：姿态[威严持神器→震惊脱手→呆滞目送]
- 情绪转折点：神器被撞飞，战局转折
```

### 2. 空间快照对比
分段间对比关键人物的位置：
```
分段3结尾快照：
- 敌方首领：半空持神器
- 角色A：地面仰视嘲讽
- 角色B：地面沉稳观察
- 角色C：角色B脚边兽形态

分段4开头快照：
- 敌方首领：半空注意力在角色A
- 角色A：地面继续嘲讽
- 角色B：地面目光微动（察觉角色C）
- 角色C：已从侧方冲出（需说明"从角色A身侧"）
```

### 3. 视觉连续性检查
检查描述是否形成连续画面：
```
连续画面线：
1. 神器在敌方手中金光流转（分段3）
2. 银色影子侧冲撞神器（分段4）
3. 神器脱手在空中翻滚下坠（分段4-5）
4. 神器变成金色光点消失云层（分段5）
5. 角色A因神器消失而狂笑跃起（分段6）
逻辑连贯：视觉事件引发情绪事件
```

---

**使用流程**：
1. 首次阅读剧本时，标记所有变化节点
2. 建立变化追踪表（如上示例）
3. 分段生成时参考追踪表，确保描述连续性
4. 完成所有分段后，用错误检测清单检查
5. 输出最终提示词前，快速浏览变化摘要表确认一致性
