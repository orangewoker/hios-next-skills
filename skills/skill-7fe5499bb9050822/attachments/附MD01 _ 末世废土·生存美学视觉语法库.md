# 附MD01 | 末世废土·生存美学视觉语法库

**所属主SKILL：** 末世废土 · 生存 | 上架Steam的互动影游\
**版本：** V2.0 融合合规版

## #做什么

本模块为“末世废土 · 生存 | 上架Steam的互动影游”的专属生存美学视觉语法库。

解决互动影游在AI生成时“视觉风格漂移、废土感不足、场景质感廉价、缺少生存压迫感”的痛点。确保全片画面保持高度一致的末日写实调性。

## #需要什么输入

**最少提供：**

- 剧本或故事梗概
- 幸存者与关键NPC的姓名、设定、外貌锚点
- 核心场景清单（如废弃都市、地下避难所、辐射荒野等）

**可选提供：**

- 核心物资设定
- 特定光影偏好
- 目标画幅（不限定，按项目需求或用户指定）

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。视觉语法环节重点参考【提示词】底座的物理光学参数与【大导演思维】的镜头逻辑。

### 二、核心美学基调

1. **末日写实**：低饱和、高反差、土黄与灰暗为主。
2. **废铁都市**：坍塌的大楼、废弃的汽车、生锈的钢铁丛林。
3. **生存压迫**：漫天黄沙、灰霾天空、稀缺的干净水源。
4. **人性微光**：破败场景中的一团篝火、一束微弱的手电筒光。
5. **东方写实**：仿真人质感、生存废土感、电影级厚重，拒绝塑料感。

### 三、色彩系统（强制锁定）

1. **土黄**：色值 #C2A878；用途为沙尘、荒野、破败墙壁。
2. **废铁锈红**：色值 #8B4513；用途为生锈汽车、废弃金属、血迹。
3. **灰暗**：色值 #4A4A4A；用途为废墟、防毒面具、天空。
4. **辐射幽绿**：色值 #4CAF50；用途为辐射区、变异体眼睛、有毒物质。
5. **篝火暖黄**：色值 #D4782F；用途为营地、希望、温暖光源。

**绝对禁止**：高饱和荧光色、明亮清新的日漫色调、无脑血浆。

### 四、专属场景视觉语法

1\. 废弃都市

- 视觉特征：倒塌的摩天大楼、生锈废弃汽车、散落的垃圾、漫天黄沙。
- 主光源：昏暗日光，色温4500K，高反差。
- 材质：锈蚀金属、破碎玻璃、粗糙混凝土。

2\. 地下避难所

- 视觉特征：狭窄的通道、生锈的管道、昏暗的荧光灯、堆放的物资。
- 主光源：闪烁的荧光灯，色温5000K，压抑感。
- 材质：水泥墙面、金属管道、积灰的木箱。

3\. 辐射荒野

- 视觉特征：寸草不生的焦土、发光的绿色污水坑、变异的巨型植物。
- 主光源：幽绿的辐射微光+昏黄天光，色温6000K。
- 材质：焦土、发光粘液、变异树皮。

4\. 军事检查站

- 视觉特征：沙袋防线、铁丝网、废弃的装甲车、哨塔。
- 主光源：车灯或探照灯，色温4000K，明暗对比强烈。
- 材质：帆布沙袋、生锈铁网、金属装甲。

### 五、角色视觉语法

1\. 幸存者

- 外貌：气质粗犷，面容沧桑，带有伤痕或污渍。
- 服装：破旧战术风衣、防弹背心、防毒面具、护目镜。
- 光影：主光冷白，逆光篝火暖黄。
- 微表情：眼神警惕、眉头紧锁、咬紧牙关。

2\. 变异体（怪物）

- 外貌：变异的人类或动物，肢体扭曲，皮肤腐烂。
- 服装：破烂不堪，沾满污血。
- 光影：逆光剪影，眼部幽绿发光。

3\. 避难所领袖

- 外貌：气质威严或阴险，衣着相对整洁。
- 服装：干净的皮衣或军装。
- 光影：顶光冷白，压迫感强。

### 六、核心物资视觉语法

1. 净水芯片：金属质感，带有蓝色微光，极其精密。
2. 防辐射药剂：绿色的玻璃针管，液体浑浊。
3. 改装步枪：缠绕着胶带，加装了瞄准镜和手电筒。
4. 罐头：生锈的铁皮，标签模糊。

### 七、交互UI视觉语法（互动影游专属）

1\. 选择界面规范

- 字体：打字机字体或做旧的粗体字。
- 主色：暗金或辐射绿。
- 警告色：铁锈红。
- 背景：半透明黑色90%。
- 按钮：做旧的金属面板样式。
- 变量提示：物资-10·人性-20（按项目实际变量替换）。

2\. 变量变化视觉反馈

- 变量增加时：屏幕飘出暗金色+数字。
- 变量减少时：屏幕飘出铁锈红-数字。
- 触发死亡结局时：屏幕闪红+黑屏+打字机音效。
- 触发真结局时：屏幕闪白+暖光。

### 八、光影与运镜专属规范

1. 绝境压抑：底光/手电筒局部光，色温3000K，低角度仰视。
2. 物资发现：顶光，色温4500K，特写镜头。
3. 追逐逃生：强频闪，不规则晃动。
4. 结局收尾：火光或死黑。

### 九、防崩要求

1. 废土感需要通过“破败与生锈”体现，而不是单纯的暗。
2. 光影必须统一，禁止忽明忽暗导致穿帮。
3. 物资道具必须1:1真实物理比例。
4. 人物面部必须保持真实毛孔质感，带有灰尘。

### 十、生成与合成

根据上述视觉标准，调用底层视频生成Skill，输出MP4视频文件。
