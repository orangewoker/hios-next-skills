# 中文电影剧本格式规范

## 场景标题行

格式：**内景/外景 - 地点 - 日/夜**

```
内景 - 张伟的公寓 - 夜
外景 - 北京长安街 - 日
```

## 动作描写

- 现在时态、简洁、视觉化
- 只写镜头能看到的东西
- 人物首次出现时注明年龄和简短特征

## 对白

- 角色名单独一行居中，对白在其下方
- 每句对白都有功能：推进动作或揭示人物

## 画外音与旁白

- V.O.：角色不在场景中的声音
- O.S.：角色在场景中但不在画面内

## 转场标记

通常省略，必要时标注：切至、闪回、闪回结束、叠化

## 特殊格式

闪回：标注"闪回 - 时间地点"和"闪回结束" 蒙太奇：用破折号列出片段，标注"蒙太奇开始/结束"

## 中文剧本注意

1. 对白口语化，避免书面语
2. 场景描写融入中国文化视觉细节
3. 角色称谓尊重中文习惯

## 完整场景示例

```
内景 - 派出所审讯室 - 夜

日光灯嗡嗡作响。白瓷砖墙壁上有一面单向镜。

张伟（30岁，瘦削，黑眼圈很重）坐在铁椅上，
双手铐在桌面的铁环上。

门开了。李警官（45岁，精干）走进来，
把一个文件夹摔在桌上。

              李警官
      张伟，我再问你一次。
      7月15号晚上，你在哪？

              张伟
      我说了……在家睡觉。

              李警官
        （俯身压低声音）
      你前妻可不这么说。

张伟猛地抬头，眼中闪过一丝恐惧。
```
