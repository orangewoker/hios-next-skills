# 东方仙侠风（Eastern Fantasy）分镜指令库

> **主打风格**：东方留白气韵、极致的动态美与宿命感，强调衣袂飘飘与清冷氛围。
> **加载时机**：`/分集 {N}` Phase 2 时，若题材判定为仙侠 / 古风 / 修真 / 武侠，加载本文件复用分镜。

| 分镜名称 | 完整指令 |
| -------- | -------- |
| **长阶罚跪** | 远景对称构图，清晨苍白的漫反射柔光。白雪皑皑的宗门万级青石阶上，白衣剑修脊背挺直地跪在风雪中。粗糙的麻布外袍覆满寒霜，他微微仰头看着被云雾遮挡的巍峨大殿。 |
| **红绫破阵** | 低视角仰拍，极具视觉冲击力的暖橘色黄昏光。狂风大作的断崖边，魔尊少女的赤色裙摆和暗纹红绫如火焰般在半空狂舞。她赤足轻点在一柄悬空的残剑上，俯视着下方，嘴角勾起一抹邪魅的冷笑，张力十足。 |
| **竹榻疗伤** | 侧逆光半身近景，透过竹叶缝隙洒下的丁达尔光斑。昏暗的竹楼内，青衣医仙正为榻上的重伤刀客包扎。医仙修长白皙的手指沾着鲜红的血迹，垂落的发丝刚好擦过刀客紧绷的下颌线，空气中仿佛飘散着苦涩药香，极具暧昧拉扯。 |
| **水月剑舞** | 水面贴地极低视角，幽蓝色的夜间冷月光。平静如镜的幽潭中央，白发盲眼剑客单脚踩在一片飘落的柳叶上。剑锋划破水面，带起一串如珍珠般的水滴，水珠在月光下折射出冷冽的杀意，极具东方留白意境。 |
| **古刹逢魔** | 深景深全景，压抑的灰暗色调伴随诡异紫光。破败的佛像前香灰散落一地，提着灯笼的红衣新娘背对镜头站在阴影中。灯笼透出微弱的血色光晕，照亮了佛像垂落的悲悯双眼，画面透着一种中式中邪的诡谲美学。 |
