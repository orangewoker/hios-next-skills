# 角色妆造

> **定位**：角色设定卡妆造字段的生成规范。三问推导 + 铁律 + 防错。

## 注入流程

1. 读角色档案：身份/处境/核心动作
2. 用三问推导妆造方向
3. 从关键词池按需取词拼入，禁止套 archetype
4. 防错检查：8 项全过才允许写入

## 三问推导

```
身份 → 什么阶层/职业？→ 服装面料/剪裁/配饰
处境 → 什么经济/情绪状态？→ 磨损程度/整洁度/新旧
动作 → 出场第一镜做什么？→ 服装是否妨碍动作/是否需要特殊设计
```

## 核心铁律

| # | 铁律 | 注入句 |
|:---:|:---|:---|
| R1 | 皮肤真实 | `natural skin texture, visible pores, subtle imperfections, no plastic skin` |
| R2 | 男性无妆 | `面部不施粉黛 / 无妆容` |
| R3 | 女性有妆有分寸 | `妆面完整但有节制，不浓艳不寡淡` |
| R4 | 维度齐 | 发型 + 服装面料 + ≥1配饰 + 身段姿态 |
| R5 | 磨损可见 | 劳动角色→衣物有使用痕迹；富贵角色→衣物挺括 |
| R6 | 独特标识 | 每个角色 ≥1 个独特视觉标识（配饰/发型/疤痕/纹身） |

## 关键词池（按需取用，禁止整段复制）

**发型**：短发/中长发/长发/盘发/马尾/寸头/微乱/一丝不苟/自然散落/束起
**面料**：棉麻/真丝/羊绒/粗呢/皮革/牛仔/化纤/针织
**配饰**：戒指/项链/手表/手镯/耳环/发夹/围巾/帽子/手套/眼镜
**身段**：脊背挺直/肩线下垂/微驼/松弛/紧绷/舒展/内收
**磨损度**：簇新/微旧/陈旧/破损/缝补痕迹

## 防错检查

- [ ] 是否包含 R1 皮肤真实关键词？
- [ ] 性别对应 R2 或 R3？
- [ ] 是否至少含发型+面料+配饰+身段（R4）？
- [ ] 是否避免套用 archetype（"古风白衣仙子"等）？
- [ ] 是否与角色处境一致（穷人不穿丝绸）？
- [ ] 是否与核心动作兼容（打架角色不穿紧身裙）？
- [ ] 是否有一个独特视觉标识（R6）？
- [ ] 所有描述词是否是具体的而非抽象的？
