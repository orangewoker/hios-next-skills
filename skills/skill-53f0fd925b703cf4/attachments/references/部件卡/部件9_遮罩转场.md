# 部件卡9 · 遮罩转场 + 镜头终点

## 遮罩转场（多段一镜到底的换气装置）
纯黑遮罩进出=同一遮挡物+同一移动方向+"绝非剪辑切换"声明。

万物生原版（对照用）：
```
镜头平滑地转到一株湿黑大树的位置——它自画面右侧、由右向左地移入画面、迅速逼近遮挡镜头，
湿黑暗部一点点抹满整个画面，直到完全挡住镜头、画面化为纯黑。镜头紧接着继续同向运动，
这株湿黑大树自画面、由右向左地继续移出镜头、逐渐让开，画面从纯黑里一点点平滑地露出近处
对剑的小女孩——整个遮罩进出是一段连续运镜，绝非剪辑切换。
```
要点：同一遮挡物+同一方向+"绝非剪辑切换"声明。

## 镜头终点（四种通用方式，选一）
```
① 物体填满镜头：「[物体]逐渐覆盖整个镜头，画面终结于[颜色]」
② 烟雾/尘/水吞没：「[元素]吞没/笼罩整个画面，画面终结于[颜色]雾」
③ 角色走出画框：「[角色]走出画面[方向]边缘消失在[颜色]中」
④ 定格呼吸收：「画面定格——并不是死寂的静止，而是带着克制的呼吸感：[2-3个微动元素：呼吸起伏/发丝颤动/光明灭流动]」
```
❌ 不用「画面渐黑」「淡出」「Fade out」——Seedance不处理后制过渡效果。
