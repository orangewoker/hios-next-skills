# 工业级导演语言与镜头策略

本文件用于把厚涂绘本视觉转化为具有完整电影语法的视频。厚涂质感解决“画面长什么样”，导演语言解决“观众如何被带着看、理解和感受”；两者必须同时成立。

## 1. 先设计段落，再设计单镜

不要先逐镜挑选好看的构图或运镜。每个叙事段落先建立一份《段落镜头策略》：

- **段落任务：** 本段使人物处境、观众认知、产品价值或情绪强度发生什么变化。
- **空间底图：** 人物、产品、入口、出口、地标、主光源、动作轴线和摄影机可用区域。
- **信息路线：** 哪些信息先隐藏、后揭示；观众跟随谁的视角。
- **景别曲线：** 从空间、行动、关系、反应到细节如何递进或释放。
- **运镜曲线：** 静止、跟随、推进、揭示、加速和停顿如何形成节奏，而不是每镜独立选运动。
- **连接系统：** 主要使用哪几种动作、视线、声音、构图、色彩或因果连接。
- **视觉母题：** 反复出现的方向、形状、颜色、遮挡、距离或运动模式。
- **声音主线：** 环境声、动作声、音乐和静默如何跨镜维持同一段落。

只有段落策略成立后再拆镜头。一个镜头的设计必须同时服务本镜任务和段落整体曲线。

## 2. 方法来源与内部选择

以下导演只作为内部方法来源，不作为机械模仿对象。默认不在用户可见的创意方案或分镜中堆砌导演姓名，只说明实际采用的镜头策略。

| 方法来源 | 可提炼的专业原则 | 适合解决的问题 | 禁止的表面化模仿 |
|---|---|---|---|
| 库布里克 | 几何空间、透视中心、精确调度、缓慢而必然的摄影机运动 | 秩序、压迫、仪式感、心理控制 | 所有画面都强行中轴对称 |
| 黑泽明 | 多层次动作调度、清晰运动方向、天气和环境参与动作 | 群像、冲突、动作场面、空间可读性 | 无动机增加风雨烟尘 |
| 希区柯克 | 主客观视角切换、信息延迟、视线链与因果剪辑 | 悬念、发现、误导、危险预期 | 用突兀特写代替信息铺垫 |
| 斯皮尔伯格 | 观众定位清楚、镜内完成信息递进、反应镜头与情感落点 | 商业叙事、家庭情感、奇观揭示 | 每次揭示都使用夸张推镜 |
| 王家卫 | 主观时间、遮挡与碎片、色彩和节奏表达关系距离 | 情绪、记忆、亲密与疏离 | 无内容地滥用拖影和慢动作 |
| 大卫·芬奇 | 精确构图、受控运动、信息驱动的微妙推移、剪辑克制 | 现代感、程序感、心理控制、信息密度 | 为“高级”而让一切过冷过稳 |
| 塔可夫斯基 | 镜头持续时间、环境变化、人物与空间的精神关系 | 沉浸、余韵、时间感、内在变化 | 没有内部变化的冗长镜头 |
| 诺兰 | 多时间线清晰标记、平行推进、重复母题和结构回响 | 时间结构、交叉叙事、规模升级 | 在缺少标记时强行打乱时序 |
| 维伦纽瓦 | 尺度对比、负空间、缓慢揭示、建筑与人物关系 | 科幻、宏大世界、压迫和未知 | 只有空旷大全景而缺少人物视点 |
| 丹尼尔斯 | 动作/构图匹配、节奏碰撞、媒介切换仍保持情感锚点 | 快节奏实验、反差、现代剪辑 | 为猎奇而随机跳切和换风格 |
| 阿方索·卡隆 | 长镜头中的空间揭示、复杂调度、摄影机与人物关系变化 | 沉浸、行动连续性、空间探索 | 把无法承载的内容强塞进一镜 |
| 韦斯·安德森 | 正面性、对称秩序、横向运动、色彩和陈设系统 | 荒诞、秩序、童话感、图像化叙事 | 每镜都做成静态对称海报 |

每个项目只选择一个**主导方法族**和最多一个**辅助方法族**。先满足叙事与连续性，再吸收方法特征；禁止把所有导演特点混合进同一条片子。

## 3. 主导方法族

- **几何与控制：** 通过稳定轴线、精确调度、构图秩序和克制移动建立力量。适用于庄重、压迫、科技、奢华。
- **动作与空间：** 通过多层调度、进入/退出方向、环境运动和可读动作线建立能量。适用于冲突、追逐、群像、产品使用。
- **悬念与信息：** 通过主观视线、信息隐藏、反应镜头和因果剪辑控制观众知道什么。适用于悬疑、发现、产品揭示。
- **情绪与时间：** 通过镜头持续时间、色彩、遮挡、环境细节和节奏停顿表达内在变化。适用于情绪短片、回忆、关系叙事。
- **尺度与世界：** 通过人物与空间的尺度对比、负空间、声画反差和渐进揭示建立世界。适用于科幻、史诗、品牌世界观。
- **结构与实验：** 通过重复母题、平行剪辑、动作/构图匹配和明确时间标记组织复杂结构。适用于多线叙事、快节奏社媒和概念片。

## 4. 景别曲线

景别变化必须对应信息距离变化：

- 大远景/远景回答“在哪里、规模如何”。
- 全景/中全景回答“人物如何处于空间并行动”。
- 中景回答“关系和主要行为如何发展”。
- 近景回答“态度与反应如何变化”。
- 特写/大特写回答“哪个决定性证据必须被看见”。

不要随机轮换景别。先设计段落的景别起点、收紧点、峰值和释放点。五镜及以上的段落通常至少使用三种有效景别；连续三个以上几乎相同的景别、机位和主体尺度，必须有明确的形式动机，否则重做。

从大远景直接切到大特写，或反向跳变时，必须由视线、动作、声音、信息冲击或构图形状建立桥梁；没有桥梁就增加中间镜或重新设计切点。

## 5. 运镜曲线与动机

摄影机运动只允许由以下变化驱动：

- 跟随人物或产品行动。
- 揭示新的空间、关系、信息或危险。
- 改变观众与人物的心理距离。
- 转移权力、注意力或叙事视角。
- 建立段落节奏的加速、峰值、减速或停顿。

固定镜头也是主动选择，适合观察、等待、压迫、表演和让画内运动主导。不得因为生成方便而默认固定。连续固定镜头原则上不超过两个；若继续固定，必须在分镜中写明形式动机，并通过人物、环境、光线或构图内部变化保持镜内发展。

同一种主运镜原则上不连续重复超过两次，除非它是经过设计的视觉母题。一个短镜头只保留一种主运镜；复杂主体动作时简化摄影机，复杂摄影机运动时简化主体动作。

为每个段落设计“静止/建立 → 运动/推进 → 变化/峰值 → 停顿/落点”的运动节奏，可按内容省略或重排，但不能全段处于同一运动强度。

## 6. 相邻镜头合约

每一对相邻镜头必须写清：

1. 前镜在什么动作、视线、信息、声音或情绪点退出。
2. 后镜用什么依据进入。
3. 观众在后镜新增什么信息或感受。
4. 人物左右关系、视线、运动方向、主光和场景地理是否连续。

避免同一主体、相近景别、相近机位只发生微小变化的无意跳切；此类剪辑应改变机位角度约30度以上、显著改变景别，或使用动作/遮挡完成有意跳切。大幅改变机位、方向或景别前，先判断是否需要建立镜头、中性机位、沿轴镜头、反应镜头或声音桥。

镜头不能只因“画面已经够好看”而存在。删除后不影响信息、动作、情绪或节奏的镜头必须删除。

## 7. 长镜头与实验剪辑

长镜头必须在镜内至少完成两次有效变化，例如空间揭示、人物关系改变、信息转移或情绪转折。先设计人物路径、摄影机路径、焦点转移和遮挡节点；不能把多个普通镜头简单粘成一次移动。

实验剪辑必须保留至少一个稳定锚点：相同动作、构图位置、声音、颜色、道具、人物情绪或因果关系。节奏越激进，锚点越要清楚。

复杂时间结构必须用色彩、场景、声音、构图母题或明确事件标记时间层，不能只依赖字幕解释。

## 8. AI视频运动预算

工业级设计必须能被当前生成能力执行：

- 每镜只指定一个主摄影机运动和一个主要主体动作。
- 将复杂长运动拆成可连续生成的动作阶段，但在剪辑上保持为同一设计逻辑。
- 大幅环绕、快速变焦、复杂群体调度和强透视变化可能造成角色、产品或厚涂笔触漂移；只在叙事收益明显时使用。
- 运镜提示必须写明起点、路径、速度、终点和运动动机，不能只写“电影感推进”。
- 生成结果若破坏角色、产品、空间或厚涂质感，优先降低运动复杂度，不用视觉漂移换取表面动感。

## 9. 对用户的表达

默认输出“主导镜头策略、辅助镜头策略、景别曲线、运镜曲线、空间与剪辑原则”，不主动展示导演姓名。用户明确询问参考来源时，才说明所借鉴的是可执行原则而非复刻个人风格。
