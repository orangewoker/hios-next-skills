# 微缩场景专用视觉规范

生成每个片段画面时的技术要点。目标观感：像用微距镜头实拍的精致实体模型，配合真人手部的巨物介入。

## 比例锚定（每个片段必须遵守）

这是该类型最容易穿帮的地方。必须用具体参照物锁定比例，且在片段内保持稳定：

- 小人偶身高约 3 到 5 厘米，火柴人大小
- 手部为真人成年男性或女性的手，一根手指约等于场景中一辆汽车的长度
- 工具为真实尺寸的日常物品（一块海绵能盖住整条街道，一根棉签比渔船还长）
- 画面描述示例：一只真人成年人的手握着真实尺寸的黄色厨房海绵，海绵大到足以盖住下方整条被淹的微缩街道，4 厘米高的小人偶齐腰泡在水里

## 材质规范（营造实体模型感，对抗 CG 感）

- 小人偶：手绘微缩人偶、哑光塑料质感、可见笔触、雨衣微微反光
- 建筑：火车模型比例建筑、纸板与树脂纹理墙面、微型印刷招牌
- 植被：模型植被、植绒微缩树木、静电草粉草丛
- 水体：树脂水面效果或带表面张力的真实液体、微缩涟漪
- 火焰：真实小火苗或背光橙色丝绸效果，真实小火苗在微缩尺度下自带巨焰感
- 地面：干裂黏土表现干旱、细沙碎石、散落小石块

负面约束（每个片段必加）：不要卡通渲染、不要 CG 感、不要光滑的 3D 渲染质感，必须是照片级微距实拍质感。

## 镜头与光影

- 机位：默认片段内固定机位一镜到底，俯视 30 到 45 度，取景一次性框住灾难主体、小人偶和手部动作区域，想突出手部质感就整体架近，禁止用切镜解决
- 景深：微距镜头，极浅景深，画面远端边缘移轴虚化。移轴模糊是"小人国感"的核心开关，每个片段必须有
- 光线：明亮的柔光箱棚拍光线或温暖自然日光，明亮饱和，阴影柔和。灾难段可稍压暗，修复后瞬间提亮，用光线参与情绪叙事
- 色调：鲜艳饱和的玩具感调色，修复前后要有明确的色彩对比（浑浊黄水变清澈、灰雪变暖阳、红湖变蓝湖）
- 镜头稳定无晃动

## 手部动作规则

手部是 AI 视频画面的重灾区，遵守以下限制：

1. 单手入画，动作单一：一个片段只做一个动词（按压、滴落、轻点、放下、吹拂、倾倒）
2. 手从画面顶部或斜上方进入，动作完成后可以不出画，直接进入下一片段
3. 避免手指精细操作（系、拧、翻页），优先大肌肉动作（按、放、倒）
4. 工具与手的接触点要明确（例如拇指和食指捏住棉签），握持方式在片段内不可变化

## 小人偶情绪表达

小人偶没有面部表情可用，全靠肢体语言：

- 惊慌：抱头、奔逃姿态、跪地、互相搀扶、指向灾难
- 欢呼：双臂高举、跳跃、拥抱、挥舞帽子
- 数量 3 到 6 个为宜，穿高饱和度纯色衣服（黄雨衣、蓝夹克、橙背心），既是视觉焦点也方便片段内保持一致性

## 音频规范

修复动作的特写 ASMR 音效（海绵吸水声、水滴声、胶枪挤出声、吹风机风声）+ 轻快治愈的背景音乐 + 小人偶欢呼的微弱人声。灾难段可加低沉水流声或火焰噼啪声。
