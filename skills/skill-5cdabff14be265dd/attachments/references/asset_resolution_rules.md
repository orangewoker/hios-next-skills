# 资产自动解析规则

## 1. 目标
将用户请求中的“人物 / 机械 / 场景 / 道具 / 镜头号 / 动作”自动映射到项目资产ID。

## 2. 解析顺序
1. 识别镜头号（如 Shot003 / 镜头003 / BM04）
2. 识别人物实体
3. 识别机械实体
4. 识别场景实体
5. 识别道具 / 武器实体
6. 识别该镜头是否需要：
   - FRAME
   - PREVIS
   - ACTREF
   - CAMREF

## 3. 选择优先级
1. 镜头专属资产优先
2. 实体匹配优先
3. 状态优先：LOCK > APPROVED > DRAFT
4. 最新版本优先

## 4. 缺失资产判定
满足以下任一条件即判定为“缺失资产”：
- 无同实体标准资产
- 无镜头专用Previs
- S / S+镜无关键帧
- 世界观S镜无场景标准图

## 5. 输出要求
无论是否缺失，都必须输出：
- 已自动引用资产表
- 缺失资产表
- 后续Prompt里明确引用这些资产ID
