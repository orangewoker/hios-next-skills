# 导演式需求访谈与前期开发

本文件用于把模糊想法发展成可生产的创作简报，并在分镜前锁定角色、产品和场景。只执行当前任务需要的部分，不为简单任务堆叠无关流程。

## 1. 判断需求清晰度

先判断能否明确以下三项：内容类型、创作目的、核心内容。任意两项无法判断时，视为高度模糊需求，进入分层访谈；已经明确时直接补齐 `SKILL.md` 的交付规格，不重复询问。

高度模糊需求的常见表现包括：“我想做个短片”“我有一个想法，你帮我想怎么做”“想做得有感觉一点”，但没有说明片型、受众、内容或用途。

## 2. 分层导演访谈

每轮只询问2至4个同层级问题。先简要复述已经理解的内容，再提出下一组问题；不要重复询问用户已经回答的信息。

### 第一层：片型与任务

优先确定：

- 是广告片、剧情短片、品牌内容、电商产品展示、博主好物推荐或种草视频，还是其它类型。
- 最终希望得到图片、角色或场景资产、分镜、视频，还是一套组合交付。
- 内容要解决什么问题，希望观众看完产生什么感受或行动。

用户无法选择时，结合现有想法给出2至3个明显不同的专业方向，并说明各自适合的目标。用户说“你来决定”时，选择最合理方向并把依据写入《需求分析与确认》。

### 第二层：受众、平台与情绪

确定目标受众、投放平台、画幅比例、视频时长和观看情境，再确定主导情绪，例如快乐、温暖、忧伤、悬疑、紧张、庄重、荒诞或正剧严肃向。

情绪不能只停留在形容词；进一步明确它如何影响表演、节奏、色彩、声音和结尾余韵。

### 第三层：按内容类型深化

**剧情向内容：** 补齐 Who、When、Where、What、Why、How，并确认人物关系、欲望、阻碍、关键转折和结局落点。短内容允许合并信息，但不能缺少观看理由和落点。

**广告与品牌内容：** 确认品牌或产品、目标消费者、核心卖点、可信证据、使用情境、品牌气质、竞争差异和行动指令。卖点必须能转化为画面中的行为、变化或结果。

**电商展示与种草内容：** 确认推荐者身份、真实使用场景、用户痛点、体验过程、可见证据、购买理由、口播可信度和平台原生表达方式。不要把种草视频做成缺少人物立场的产品说明书。

## 3. 访谈停止条件

只有当以下信息可以形成自洽的《需求分析与确认》时，才结束访谈：

- 片型、目的、受众和最终交付物明确。
- 核心内容、主要情绪和故事或卖点落点明确。
- 投放平台、画幅比例和视频任务的总时长明确。
- 已判断是否需要角色、产品和场景前期开发。

用户明确授权 Agent 决定时，可视为需求参数与普通创作细节已经确认，但必须把推荐结果写清楚。该授权不能代替 `video-gates.md` 对当前基础创意方案、文字分镜、分镜图片和视频生成的逐阶段确认。不要因为追求“信息完整”而询问不会改变创作结果的问题。

## 4. 视频创意开发关卡

视频需求完成基础访谈后，不要立刻罗列镜头。先把创意发展为可供用户讨论的故事方案，并至少说明：

- 一句话故事或核心说服命题。
- 主角、产品或叙事主体想实现什么，以及阻碍或问题是什么。
- 开端、触发、升级、转折和落点之间的因果关系。
- 观众为何继续观看，情绪或信息如何逐段变化。
- 结尾如何回应开头，并完成剧情、产品利益或品牌记忆。

故事复杂度要与片长匹配：短片不等于逻辑可以省略，长片也不等于可以堆叠无关支线。剧情、广告或产品内容都要用行动、变化和可见结果推进，不依赖旁白解释没有被画面建立的关系。

如果存在两个会显著改变剧情或制作方向的方案，提供少量清楚选项供用户选择；否则直接发展最合理的单一方向。把结构、风格、氛围情绪、节奏、声音方向和必要资产锚点整合为《视频基础创意方案》，持续修改。只有用户在看到当前版本后明确同意进入后续流程，才进入 `storyboard-script.md` 的文字分镜头脚本阶段；不得自行判断创意已经通过。

## 5. 身份锚点与风格参考分离

“这就是角色、产品或场景”属于身份与结构指定；“参考这种画风”才属于风格参考。两者必须分开处理：

- 用户上传并指定的图片、文字设定和官方产品资料，是身份与事实的最高依据。
- AI 生成后经用户确认，或用户明确授权采用的角色、产品与场景，拥有同等主锚点地位。
- 尚未确认的草稿只是候选方案，不得作为整片复现依据。
- 身份锚点不因风格参考的强弱而降低优先级。即使用户只说“适当参考画风”，被明确指定的脸、产品结构和空间布局也必须保持一致。

为每类资产记录：锁定项、允许变化项、变化条件和参考来源。避免使用与生产无关的冗长描述。

## 6. 角色设计关卡

剧情片存在明确且反复出现的角色，但用户没有提供可复现设定时，先进入角色设计，不直接写分镜或生成动态镜头。

按照传统影视前期流程逐步建立：

1. **角色小传与戏剧功能：** 身份、年龄感、时代与社会背景、欲望、阻碍、性格矛盾、人物关系和故事中的作用。
2. **外观圣经：** 体型比例、脸型、五官关系、肤色、发型、识别轮廓、标志性特征和不可改变项。
3. **服化道连续性：** 服装结构、层次、材质、色彩、鞋履、饰品、标志性道具，以及不同剧情阶段允许的状态变化。
4. **角色模卡：** 正面、四分之三侧、侧面、全身和必要背面；保持同一比例与设计，不在不同角度重新创作。
5. **表演锚点：** 核心表情、典型姿态、动作习惯、情绪边界、视线与身体语言。
6. **人物情绪版：** 色彩、材质、光线与环境关系，用于统一人物气质；情绪版不能替代结构清晰的模卡。

每完成一个阶段，简要列出新增锁定项和仍可调整项。用户确认或授权采用核心角色方案后，冻结为角色主锚点，再进入场景、分镜和镜头生产。

## 7. 产品核准关卡

广告、电商或种草内容出现明确产品时，产品准确性优先于画面风格。产品尚未核准前，不进入分镜或动态生成。

**真实产品：** 优先使用官方正面、背面、侧面、关键细节、包装、标志、色号、材质、接口和功能资料。资料不足以确认外观时继续向用户索取，不用相似产品代替，也不虚构看不见的结构与功能。

**原创或 AI 生成产品：** 先建立产品主设定，锁定比例、轮廓、颜色、材质、部件、标志位置、包装和功能逻辑；经用户确认或授权采用后再展开镜头。

**服装与可穿戴产品：** 额外锁定正背面结构、版型、面料、色号、图案、装饰、闭合方式和穿着后的轮廓。不同镜头不得无故改变长度、颜色、图案位置或材质。

产品只允许因明确的使用状态、开合、消耗、损伤或剧情原因发生变化。把这些变化记录为状态，不得误判为重新设计的许可。

## 8. 场景锚定关卡

反复出现的空间在分镜前锁定：平面关系、入口与出口、地标、家具或建筑位置、时代材质、时间、天气、主光方向、色彩基调，以及人物与产品的初始位置。

用户上传并指定的场景图片属于空间身份锚点。近景可以省略信息，但不能与大全景中的方向、光源和关键物体矛盾。需要改变空间时必须有移动、时间、剧情或转场依据。

## 9. 资产冻结与漂移回退

主锚点确认后，所有后续图片和镜头都复用同一身份、结构和空间事实：

- 产品不得无故变色、变形、改变标志或部件位置。
- 人物不得无故改变脸型、五官关系、发型、体型、服装结构和识别特征。
- 场景不得无故改变入口、地标、关键物体位置、主光方向和空间尺度。

发现漂移时，先定位发生偏差的镜头，再按“身份轮廓与结构 → 颜色与材质 → 光线与环境 → 局部细节”的顺序修复。重做受影响镜头，不用新增细节掩盖错误，也不重新解释已经确认的主锚点。

用户明确要求修改主锚点时，说明变化会影响哪些后续资产，并从指定阶段起使用更新后的版本；已经完成的镜头是否回改由用户决定。

## 10. LibTV 生产边界与内容合规

- 不设计过长剧本的多集拆分流程。用户输入多集内容或超过千字的长剧本时，请其选择一个单集、一个段落或压缩到千字以内，再进入本技能的成片流程。
- 在需求确认阶段排除血腥暴力、色情擦边和其它违规内容。可以保留合理的戏剧冲突，但不得依靠违规刺激作为创意卖点。
- 本技能只提供创作判断与生产方法，不要求 Agent 运行代码、脚本，也不指定成品写入什么文件位置。
