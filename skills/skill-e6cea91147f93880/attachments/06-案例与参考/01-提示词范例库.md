# 提示词范例库

## 文生视频（T2V）产品发布

```text
哑光黑无线耳机盒在深色亚克力桌面上自行打开，露出内里并排的两只光面耳机。镜头：从中景主光镜头缓慢推近到铰链微距细节。光照：一道窄冷条光掠过曲面塑料，桌面留下柔和边缘反光。声音：安静的房间底噪，盖子完全打开时一声细微磁吸咔哒。约束：无文字叠层，logo 不变。
```

**为何有效**：一个产品锚点、一次揭晓、材质专属光照。

## 图生视频（I2V）产品保真

```text
@Image1 为产品参考；严格保持 logo、标签、瓶身形状、盖体几何与颜色不变。从中景产品镜头缓慢推近到标签微距细节。暖色侧光滑过玻璃，凝结水珠形成并向下流动，背景保持暗色静止。声音：柔和房间底噪，尾帧一声清脆玻璃轻响。
```

**为何有效**：可见身份被保留，同时加入运动与光照。

## 文生视频（T2V）角色戏剧

```text
角色 A 站在狭窄公寓走廊下，头顶暖色吊灯闪烁。她缓缓放下一只未拆封的信封，屏住呼吸，目光紧锁在关着的门上。镜头：锁定中近景，五秒内极轻微推近。光照：暖色头顶实用光，墙面映出冷色雨光反射。声音：远处雨声，无音乐。结束于她的手收紧握住纸张。
```

**为何有效**：情绪转折通过手势与时机呈现。

## 图生视频（I2V）肖像微表演

```text
@Image1 为肖像参考；严格保持面部身份、发型、服装与背景构图不变。人物眨眼一次，视线垂向桌面，随后露出一丝克制的微笑。镜头保持锁定，不重新取景。光照除脸颊上一丝微妙暖灯闪烁外保持不变。声音：安静室内房间底噪。
```

**为何有效**：小幅受控面部与手部运动避免身份漂移。

## 视频生视频（V2V）运动传递而不传递身份

```text
@Video1 仅提供节奏与侧移编舞；不要传递表演者身份、面部、服装、房间或 logo。新主体是一名原创蒙面街头舞者，身处湿漉的霓虹小巷。舞者镜像脚步节奏，向左转身，单手举起停住。镜头：稳定的腰部水平跟拍。光照：青色店面辉光与品红边缘光。声音：压抑的低音脉冲，与每一步同步。
```

**为何有效**：参考角色狭窄且排除肖像。

## 参考生视频（R2V）多参考产品广告

```text
@Image1 为产品身份参考；严格保持形状、标签、logo 与颜色不变。@Image2 仅为背景氛围参考：暖色木质吧台，低亮度琥珀色实用光。@Audio1 仅提供音乐节奏。产品置于黑色石材上，一道细窄的琥珀光随节拍扫过标签。镜头：受控的滑块移动，从剪影到正面四分之三主光角度。声音：来自 @Audio1 的音乐节奏，尾帧一声轻柔玻璃轻叩。
```

**为何有效**：每个参考都有单一角色。

## 对白与口型同步

```text
角色 A 坐在厨房桌前，双肩不动，面向镜头锁定中近景。她轻声说："我找到了钥匙。" 嘴部动作小而精确；说话时不转头。光照：来自画面右侧的柔和窗光，背景有暖色灯辉。声音：清晰干燥的对话，低沉冰箱嗡鸣，无音乐。
```

**为何有效**：单一说话者、简短台词、稳定取景。

## 双角色走位

```text
角色 A 立于前景左侧，手持一部碎屏手机。角色 B 从背景右侧进入，停在门框处，双手扶住门框。镜头锁定中远景走廊构图。角色 A 仅将视线转向角色 B；角色 B 不靠近。光照：蓝色傍晚窗光，角色 A 身后一盏暖灯。声音：地板吱呀，随后寂静。
```

**为何有效**：标签让动作归属无歧义。

## 动作节拍

```text
原创快递员冲过雨水湿滑的屋顶，奔向一扇正在关闭的检修门。他跃过一道窄缝，单膝着地重重落地，随后在门锁上前刚好够到门。镜头：低机位手持从身后跟拍，轻微呼吸晃动，不环绕。光照：冷色屋顶泛光灯与湿面反射。声音：沉重呼吸，雨点撞击，端点处金属门蜂鸣。
```

**为何有效**：动作有目标、障碍、端点。

## 安全的原创动画

```text
原创 2D 动画沙漠快递员，围着超大围巾，骑乘迷你风力小车穿过浅色沙丘。风格：手绘背景质感，圆润角色造型，柔和粉彩配色，轻微的挤压拉伸车轮运动。镜头以稳定节奏侧拍。尘尾随车轮扬起并在车后落定。声音：柔和风声，细微木质车轮辘辘。
```

**为何有效**：使用制作描述词而非受保护风格名称。

## 美食生活方式

```text
小餐馆柜台上陶瓷碗装的拉面特写。蒸汽成层轻柔升起，筷子挑起一束面条，汤汁滴落回碗。镜头：锁定微距四分之三角度。光照：柜台上方大暖色实用光，汤面泛起柔和高光。声音：安静店铺环境声，陶瓷轻碰，无音乐。
```

**为何有效**：质感、光照与动作都具体。

## 风景氛围

```text
黎明时分的开阔海岸悬崖，薄雾穿过草丛飘移，下方浪拍岩石。镜头：从草层前景缓慢摇臂升起，揭示地平线。光照：冷蓝黎明，云后透出一线暖色阳光边缘。运动：草在风中弯折，海鸟掠过远处背景。声音：远处海浪，风过草丛。
```

**为何有效**：缓慢镜头与天气运动营造纵深。

## 视觉特效（VFX）能量

```text
旧黄铜钥匙浮于木桌上方，细小蓝色电弧从钥匙齿爬向一圈粉笔标记。电弧短暂照亮尘屑与划痕，随后坍缩为一小团白色火花。镜头：锁定特写，浅景深。光照：昏暗暖色烛光主光，指尖近画面边缘映出蓝色弧光。声音：微弱电流噼啪，坍缩时一声轻柔爆响。
```

**为何有效**：效果有来源、路径、光照交互与端点。

## 中文压缩提示词

```text
@Image1 为产品参考，严格保持 logo、标签、瓶身形状和颜色不变。镜头缓慢推进到标签特写；左侧暖光扫过玻璃，水珠沿瓶身下滑，背景保持暗色静止。声音：轻微环境声，结尾一声清脆玻璃音。
```

## 中文首帧/尾帧

```text
@图片1 为首帧，@图片2 为尾帧。保持同一原创角色、服装和房间布局，角色从椅子上缓慢站起，走到窗边并停在尾帧姿势。动作连续自然，不跳切，不改变脸部、衣服或房间结构。镜头固定中景，仅轻微推镜。声音：安静室内环境声。
```
