# 附MD03 | 内容合规校验

**所属主SKILL：** 互动影游Agent | 自动串联调度下层Skill\
**版本：** V2.0 融合合规版

## #做什么

本模块为互动影游Agent的安全阀。

分支越多，剧情越难管控，每一条支线都必须经过合规校验，避免上线后因违规内容下架。解决互动影游多分支内容的合规风险管控问题。

## #需要什么输入

**最少提供：**

- 分支树全部剧情文本
- 角色对话与行为描述
- 画面生成指令（含视觉元素描述）

**可选提供：**

- 目标平台合规规范
- 特定题材的红线清单

## #怎么做

### 一、遵循主MD全局路由表与绝对工作流铁律

本模块执行时，必须严格遵循主MD的【全局 Skill 调用路由表】与【绝对工作流铁律】。合规校验环节重点参考【顶级总制片人】的门禁审查规则。

### 二、红线词库扫描

1. 内置政策红线词库，自动匹配并标注。
2. 所有分支必须经过全量扫描，不允许漏检。
3. 风险等级分为红、黄、绿三级。

### 三、价值观校验

1. 检测分支剧情是否存在违背主流价值观的导向。
2. 检测人物关系设定是否符合公序良俗。
3. 检测剧情走向是否有不当引导。

### 四、画面元素审查

1. 对视频生成指令中的视觉元素进行合规预判。
2. 检测是否包含违禁视觉元素。
3. 检测是否包含敏感符号与文字。

### 五、强制节点（核心铁律）

1. 本模块是Agent流程中的强制节点。
2. 未通过校验的分支，绝对禁止进入视频生成阶段。
3. 高风险内容必须提供替换建议。
4. 中风险内容必须人工复审。

### 六、风险报告与复审

1. 输出合规风险报告，标注风险等级。
2. 高风险节点自动推送人工复审。
3. 提供最终合规版本的分支树。
4. 所有复审记录必须归档，供后续项目参考。

### 七、生成与合成

根据上述合规校验规则，调用底层视频生成Skill，输出MP4视频文件。
