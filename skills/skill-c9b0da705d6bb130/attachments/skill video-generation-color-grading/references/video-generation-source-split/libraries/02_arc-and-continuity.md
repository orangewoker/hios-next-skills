# 段落弧线与空间连续性

> 本库来自原始视频生成规则第 138—183 行，按模块拆分，正文保留。

## 【段落弧线表】

情感核心：一句话，不超过 25 字。

节奏曲线：R1 渐快 / R2 渐慢 / R3 波浪 / R4 静爆。

运镜弧线：铺垫 → 发展 → 高潮 → 收尾，每段标强度档和具体运镜。

主蒙太奇类型：动作接 / 视线接 / 声音桥 / match cut / 对比蒙太奇 / 平行交叉等。

逐镜规划：镜号、Beat 功能、时长、景别、机位态度、运镜强度、景深功能、与下一镜的衔接方式。

后台完成后，可转译为前台逐镜确认表；除非用户要求“展示创作思路”，否则不外显完整 Layer 1。

场景空间快照规则：

每个新场景必须内部建立空间快照：

场景名、固定背景锚点、远中近景层、墙面/门窗/家具/灯具/人群密度/天气时间/光源方向。

主视觉主体和关键对手的画面左/右、前景/中景/背景、朝向、距离、持物、情绪状态。

关键道具的持有人、位置、物理状态和变化结果。

180 度轴线和视线方向矩阵；对话反打不得无说明跳轴。

同场景连续时只写变化点，默认继承空间快照；换场景时重新建立。

跨生成单元衔接规则：

同一场景跨多个 4-15 秒生成单元时，下一单元首镜必须承接上一单元末镜：

沿用同一个空间快照，不漂移、不换边、不跳轴。

首镜与上一末镜避免景别雷同；至少满足景别差 1 档，或机位角度变化 30 度以上；若刻意同景别僵持，必须有明确戏剧意图。

情绪值、节奏、对白状态、关键道具状态连续。

不跨生成单元硬留半句对白，除非用户接受声音断点；优先在单元内部完成对白。

每个成品结尾必须写清下一组可继承的人物位置、持物、情绪和场景状态。
