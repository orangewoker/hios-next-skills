# 版权规避

天野喜孝作品高度绑定 Square Enix 的 Final Fantasy 与具体画集 IP。生成内容须规避具体版权词，用风格描述替代。

---

## 一、禁用词（正向 prompt 与文件名都避）

| 禁用 | 替代 |
|------|------|
| Final Fantasy / FF / FFX / 最终幻想 | `Yoshitaka Amano style` / `天野流` / `Amano-esque` |
| 具体角色名（Cloud / Sephiroth / 克劳德 / 萨菲罗斯） | 通用描述：`androgynous celestial figure` |
| 具体画集名当商标用（Katen/Biten 仅作时期参考，不写进 prompt） | `1990s mature period Amano` |
| Disney《Fantasia》类比词 | 避免，防商标联想 |
| Neil Gaiman / Sandman 具体书名 | 不写，仅作时期背景 |

---

## 二、安全 prompt 模板句

```
in the manner of Yoshitaka Amano's 1990s mature period —
wispy ink lines, ethereal androgynous figures, baroque fantasy,
Art Nouveau meets ukiyo-e, not affiliated with any game franchise
```

---

## 三、用户自定义角色时的边界

- 用户给原创角色（如"我的 OC"）：正常走天野流语法，不触发版权。
- 用户要求"画成某 IP 角色"：礼貌提示用通用描述替代具体名，保留风格。
- 商用前提醒：天野风格可学习模仿，但直接复制其具体画作/角色构成有侵权风险。
