# 风格圣经

## 意图

用户指向他们热爱的艺术，并请求靠近它。本技能的灵魂在于：尊重这份热爱，同时拒绝窃取——找出这份热爱由何构成（光、纹理、节奏、年代），并把它重建为用户所拥有的东西。

## 风格安全规则

除非用户拥有明确授权，否则不要使用影棚、版权作品、艺术家或在世创作者名称作为风格锚点。通过描述媒介、纹理、调色板、灯光、构图、年代、线条质感和运动节奏来保留视觉功能。

## 分层风格法

把风格拆分为层：
- **媒介**：实拍、定格、2D、3D、微缩
- **表面**：纸纹、黏土、拉丝金属、玻璃、织物
- **调色板**：柔彩、单色、钠橙、暖金幽蓝
- **镜头/渲染**：微距、浅景深、正交、手持
- **运动节奏**：柔和、断奏、弹性、真实重量

## 风格替换示例

| 用户意图 | 安全制作描述符 |
|---|---|
| 温馨手绘奇幻 | hand-painted 2D animation, soft watercolor backgrounds, rounded character silhouettes, warm pastel palette, gentle parallax |
| 锐利赛博朋克动作 | neon noir city, wet pavement reflections, high-contrast magenta and cyan light, fast lateral tracking, angular silhouettes |
| 高级产品真实感 | clean commercial realism, controlled reflections, shallow depth of field, neutral background, polished material detail |
| 复古纪录片 | 1970s documentary texture, muted film grain, practical daylight, handheld observational framing |
| 儿童动画 | soft clay-like characters, simple expressive faces, bright primary palette, bouncy squash-and-stretch motion |

## 源观感锁定

| 来源观感 | 锁定其瑕疵 |
|---|---|
| 手机日常 / UGC | vertical handheld phone footage, slight grip sway, auto-exposure shifts, ambient room sound |
| 直播 | fixed webcam framing, flat ring light, mild compression, real-time caption pacing |
| 监控 / 行车记录仪 | locked high-angle camera, timestamp burn-in feel, low-light noise, no camera response to events |
| 复古胶片 | grainy film texture, gate weave, halation around highlights, era-correct contrast |
| 影棚商业 | controlled reflections, clean background, polished material detail, zero handheld motion |

## 汉风动画参考风格（以《辛追升仙奇遇记》为例）

- 媒介：汉代工笔重彩动画
- 表面：绢帛质感、矿物颜料颗粒、细腻服饰纹样
- 调色板：暖金、朱砂、石青、幽蓝
- 镜头：电影感横屏 16:9，缓慢推近与横向跟拍为主
- 运动节奏：柔和、优雅，带轻微飘逸感
- 光源：天光、烛火、门缝光
- 音频质感：古风乐器、钟磬、环境音
- 约束：不出现现代元素、不出现机械镜头运动
