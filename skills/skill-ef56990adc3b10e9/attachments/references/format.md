# 剧本格式规范 · Format Guide

规范的格式让剧本专业、可读、可拍。

## 模式：传统剧本体

场景标题 + 人物列表 + 动作段落 + 对白块。运镜/景别可内嵌进动作行，\
情绪、语气、微动作写进角色名后的括注。

### 排版规范

- **场景标题行**：`集号-场号　时间(日/夜)　内/外　地点`例：`2-1 日 外 西山悬崖`

- **人物行**：`人物：角色A、角色B`（列出本场在场角色）

- **动作段落**：现在时叙述画面与动作，可内嵌``` [特写]``[升格慢镜] ```等提示

- **对白块**：角色名 + 括注 + 冒号，对白\
  角色名（情绪/语气/微动作）：”对白内容“

- **内心 OS**：括注写明`（内心 OS，情绪描述）`，与出声对白区分

- **潜台词/表演**：括注可叠加，如`（压低嗓音，蟾首轻点，语气诚恳）`

### B 模式范例

【剧名】第 2 集《忘恩推老汉坠崖，石蟾崖底相救》\
时长：约 90 秒 | 主场景：西山悬崖 / 崖底山谷 | 涉及档位：待定\
本集钩子：黑狐撕下伪装，一爪把恩人推下悬崖\
本集爽点：以为必死的老汉，被崖底丑蟾稳稳接住，恶有报善有救\
集尾扣子：黑狐追下崖来，救命之后紧接杀机

2-1 日 外 西山悬崖\
人物：周老汉、黑狐精

黑狐精不再伪装，四肢绷紧，周身毛发因戾气竖起，朝毫无防备的周老汉\
猛扑过去，利爪狠狠拍在他胸口，将其推下悬崖。\[特写\]采药锄脱手飞出，\
周老汉身体急速坠落，耳边只剩风声与黑狐的狞笑，心中满是绝望与悔恨。\
黑狐趴在崖边探头观望，见周老汉身影消失在浓雾中，不屑嗤笑。\
黑狐精（狞笑，语气轻蔑）：“装半天柔弱白费功夫，这老东西心善天真，活该成为我的腹中餐。”

2-2 日 外 崖底山谷\
人物：周老汉、石蟾仙

周老汉顺崖壁翻滚下坠，衣衫被枯枝怪石刮破，身上多处擦伤渗血，\
草药筐与采药锄早已遗失。他双手胡乱抓挠，只抓到碎石枯草，\
心中满是绝望，以为必死无疑。\
周老汉（内心 OS，声音颤抖悔恨）：“好心施救反倒丧命，世间精怪竟如此薄情！若是重来一次，我绝不会再心软！”\
\[崖底浓雾中\]一道黑影闪过，一只体型硕大的千年石蟾伏在谷底，\
宽厚蟾甲稳稳接住周老汉，缓冲了下坠的冲击力，让他免受致命伤害。\
周老汉撑着酸痛的身体坐起，抬头看向石蟾，瞬间吓得浑身僵硬、脸色惨白。\
周老汉（声音发颤，下意识后退）：“这般丑陋的巨型蟾蜍，莫不是山中脏物？你要干什么？”\
石蟾仙（压低温和嗓音，蟾首轻点，语气诚恳）：“老伯不必惧怕，我不会伤你。我在此修行多年，今日救你，皆因你昔日善举，\
这份恩情我一直记在心中。”\
石蟾仙话音刚落，谷口深处传来一声沉闷兽吼。\[特写\]它神色一凛，\
庞大身躯缓缓横移，挡在周老汉身前，蟾目沉沉望向浓雾。\
周老汉（内心 OS，倒吸一口凉气）：“那声音……是那畜生！它追下来了？！”\
\[远景\]浓雾翻涌，一双泛着幽绿的眼睛自雾中亮起——黑狐精，竟追下崖来。\
石蟾仙蟾甲绷紧，谷中气压骤沉。切黑。
