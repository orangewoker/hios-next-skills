# 情感线

> **系统定位**：微短剧情感线推进核心规范 - 设计感情发展的参考标准
> **输出标准**：规划全剧情感线节奏，确保感情推进合理、高潮有效

---

# 情感线推进时间轴

## 一、情感线七阶段模型

微短剧情感线通常遵循七阶段推进模型：

| 阶段 | 名称 | 集数占比 | 核心任务 | 典型情节 |
|------|------|---------|---------|---------|
| 1 | **相遇** | 5-10% | 建立初始印象，制造冲突或吸引 | 误会相遇、意外碰撞、身份差异初显 |
| 2 | **破冰** | 10-15% | 打破隔阂，产生互动必要性 | 被迫合作、救命恩情、利益绑定 |
| 3 | **暧昧** | 15-25% | 好感累积，试探性互动 | 小动作、眼神交流、第三方助攻 |
| 4 | **确认** | 10-15% | 关系确定，告白/亲吻 | 告白场景、确认关系、公开/秘密 |
| 5 | **考验** | 25-35% | 外部压力、误会、分离 | 反派阻挠、家庭反对、身份悬殊 |
| 6 | **高潮** | 5-10% | 情感最高点，生死/抉择 | 为对方牺牲、绝境表白、生死与共 |
| 7 | **收束** | 5-10% | 结局定格，情感归宿 | 大团圆/开放式/分离式结局 |

## 二、不同题材的情感线节奏差异

> **注意**：本节内容属于节奏设计范畴。详细的单集微结构、情绪波形、高潮分布见 [节奏曲线.md](节奏曲线.md)。本节仅标注各题材的情感线节奏特征速查，不作完整节奏规划。

| 题材类型 | 节奏特征 | 确认时间 | 高潮频率 | 典型模式 |
|---------|---------|---------|---------|---------|
| **甜宠** | 快节奏，高频甜蜜 | 第3-5集 | 每3集一次小高潮 | 糖分密集，虐点轻 |
| **虐恋** | 慢节奏，先苦后甜 | 第10-15集 | 每5集一次大转折 | 误会→分离→重逢 |
| **霸总** | 强推进，快速确认 | 第1-2集 | 每5集一次身份揭示 | 契约→真心→反转 |
| **都市情感** | 中等节奏，写实推进 | 第8-10集 | 每10集一次情感危机 | 相遇→试探→确定→考验 |
| **古装** | 慢热，身份悬殊 | 第15-20集 | 每10集一次大事件 | 救赎→复仇→情深 |
| **重生复仇** | 情感线为辅，复仇为主 | 第20集后 | 随复仇节奏推进 | 利用→真心→选择 |

## 三、情感线与主线交织策略

### 3.1 情感线与复仇/事业线配合

```
主线类型      情感线定位
━━━━━━━━━━━━━━━━━━━━━━━━━━━
复仇主线   → 情感是软肋，也是救赎
事业主线   → 情感是支撑，也是考验
悬疑主线   → 情感是线索，也是陷阱
成长主线   → 情感是动力，也是试炼
```

### 3.2 双线交织模板

| 集数区间 | 主线任务 | 情感线任务 | 交织点 |
|---------|---------|---------|-------|
| 1-5集 | 建立世界观/铺垫冲突 | 相遇+破冰 | 冲突引发相遇 |
| 6-10集 | 第一次冲突爆发 | 暧昧升温 | 主线危机中感情升温 |
| 11-15集 | 揭示核心矛盾 | 确认关系 | 确认后遭遇主线考验 |
| 16-30集 | 升级对抗 | 考验期 | 情感成为主线筹码 |
| 31-50集 | 最终对决准备 | 高潮期 | 为对方牺牲/选择 |
| 51-60集 | 结局收束 | 收束期 | 情感与主线同步收束 |

## 四、亲密戏写作指南

### 4.1 告白戏模板

**模板一：直球式告白**
```
场景：私密空间/重要时刻
铺垫：积累足够好感度
告白词：简洁有力，符合角色性格
反应：不要立刻答应，要有情绪波动
后续：告白后不立刻甜蜜，要留悬念
```

**模板二：告白被拒→逆袭式**
```
场景：公开场合/高光时刻
铺垫：之前的告白被拒绝/忽视
告白词：展现改变的真心
反应：对方的震惊和重新审视
后续：关系重新定义
```

### 4.2 亲吻戏设计

| 亲吻类型 | 适用阶段 | 铺垫要求 | 典型写法 |
|---------|---------|---------|---------|
| **意外吻** | 暧昧期 | 制造意外接触 | 跌倒→碰撞→唇触→慌乱分开 |
| **告白吻** | 确认期 | 情绪积累到顶点 | 告白后沉默→对视→靠近→吻 |
| **和好吻** | 考验期 | 误会解除 | 解释→原谅→拥吻 |
| **离别吻** | 高潮期 | 生死/分离 | 以为永别→珍惜当下→深情一吻 |
| **占有吻** | 确认后 | 吃醋/宣誓主权 | 看到情敌→拉走→强吻 |

### 4.3 亲密戏写作要点

-  亲密戏需要充分铺垫
-  保持角色性格一致性
-  适度描述情感细节
-  亲密后留情绪余韵

## 五、情感高潮设计

### 5.1 情感高潮类型

| 类型 | 触发条件 | 情绪曲线 | 经典套路 |
|------|---------|---------|---------|
| **牺牲型** | 一方为对方付出代价 | 痛苦→震撼→感动 | 替挡/放弃机会/自我牺牲 |
| **选择型** | 二选一的困境 | 纠结→决断→无悔 | 事业vs爱情/家族vs爱人 |
| **揭示型** | 真相浮出水面 | 震惊→理解→释然 | 身份揭秘/苦衷说明 |
| **重逢型** | 分离后的再遇 | 绝望→意外→狂喜 | 失而复得/久别重逢 |
| **守护型** | 危机中的保护 | 恐惧→安心→依赖 | 绝境中挺身而出 |

### 5.2 情感高潮与爽点配合

```
情感高潮类型  →  配合爽点类型
━━━━━━━━━━━━━━━━━━━━━━━━━━━
牺牲型     →  打脸/身份揭秘
选择型     →  反转/逆袭
揭示型     →  真相浮出
重逢型     →  情感爆发
守护型     →  英雄归来
```

## 六、不同角色类型的情感线

### 6.1 霸总类角色的情感线

| 阶段 | 霸总特征 | 典型行为 |
|------|---------|---------|
| 相遇 | 高冷/傲慢/不屑 | 故意为难、冷漠对待 |
| 破冰 | 被吸引但否认 | 嘴硬心软、暗中帮助 |
| 暧昧 | 开始动摇 | 试探性示好、吃醋 |
| 确认 | 放下身段 | 主动告白、强势追求 |
| 考验 | 为爱改变 | 放弃部分利益、做出选择 |
| 高潮 | 全力守护 | 为对方牺牲、打破底线 |

### 6.2 独立女主的情感线

| 阶段 | 女主特征 | 典型行为 |
|------|---------|---------|
| 相遇 | 不卑不亢 | 智慧应对、保持距离 |
| 破冰 | 主动权在手 | 利用对方、各取所需 |
| 暧昧 | 内心动摇 | 理智vs情感、试探真心 |
| 确认 | 勇敢面对 | 直面感情、不逃避 |
| 考验 | 坚守自我 | 不为爱放弃原则 |
| 高潮 | 共同成长 | 并肩作战、互相成就 |

## 七、情感线推进检查清单

**每5集检查：**
- [ ] 情感线有推进（不能停滞）
- [ ] 推进方式符合角色性格
- [ ] 情感变化有铺垫（不是突然转变）
- [ ] 甜蜜点/虐点交替（不能一直甜或一直虐）

**每阶段检查：**
- [ ] 阶段转换有标志性事件
- [ ] 情绪曲线完整
- [ ] 与主线配合合理

**全剧检查：**
- [ ] 情感线节奏符合题材特征
- [ ] 高潮位置与付费卡点配合
- [ ] 结局类型符合观众期待
